异常处理 try/except#

程序运行的时候难免会出错：想打开的文件不存在、用户输入了字母你却把它当数字用、除以了零……如果放任不管，程序会直接崩溃退出。这一课我们学习如何用 try/except 来"接住"这些错误，让程序更健壮、更友好。

一、概念讲解#

1. 什么是异常#

异常（Exception） 是程序运行中发生错误时，Python 抛出的一个"信号"。它会打断正常的执行流程，如果没有人处理，程序就会打印一串红色的报错信息然后终止。

常见的异常类型有：

异常类型 什么时候出现
ValueError 值不符合要求，比如 int("abc")
TypeError 类型不对，比如 "1" + 1
ZeroDivisionError 除以了零
FileNotFoundError 要打开的文件不存在
KeyError 字典里没有这个键
IndexError 列表下标越界

2. try/except 的基本结构#

把"可能出错"的代码放进 try 块，出错后 Python 会跳到 except 块来执行补救代码：

try:
    # 尝试执行、可能出错的代码
    ...
except 异常类型:
    # 出错时执行的代码
    ...

一句话理解："试着做，做不成我再兜底"。

3. except 的几种写法#

  • 捕获指定类型：except ValueError: 只接住 ValueError；
  • 捕获多种类型：except (ValueError, TypeError):；
  • 捕获所有异常：except Exception:（Exception 是绝大多数异常的父类）；
  • 拿到异常对象：except ValueError as e:，其中 e 里装着具体的错误信息，方便我们打印。

一个小建议：尽量捕获"具体"的异常类型，不要图省事直接 except: 把所有错误都吞掉，否则真正的 bug 会被隐藏起来。

4. else 与 finally#

  • else：try 块没有出错时才会执行，适合放"只有成功后才做"的代码；
  • finally：无论有没有出错都会执行，适合放"一定要收尾"的代码，比如关闭文件。

5. 主动抛出异常：raise#

除了被动等错误发生，我们也可以自己制造异常，比如当参数不符合要求时：

raise ValueError("年龄不能是负数")

这通常在"条件不满足就拒绝继续"的场景下使用。

二、可运行代码示例#

示例 1：捕获用户输入错误#

while True:
    raw = input("请输入一个整数：")
    try:
        num = int(raw)          # 如果用户输入的不是数字，这里会抛 ValueError
    except ValueError:
        print("输入的不是整数，请重试。")
    else:
        # 转换成功才会走到这里
        print("你输入的整数是：", num)
        break

示例 2：处理文件不存在的情况#

filename = "不存在的文件.txt"
try:
    f = open(filename, "r", encoding="utf-8")
    print(f.read())
    f.close()
except FileNotFoundError:
    print("文件找不到：", filename, "，请先确认路径是否正确。")

示例 3：finally 确保收尾#

try:
    num = int(input("请输入被除数："))
    result = 10 / num
    print("结果是：", result)
except ZeroDivisionError as e:
    print("出错了：不能除以零。", e)
except ValueError:
    print("出错了：请输入数字。")
finally:
    # 无论成功还是失败，这里都会执行
    print("本次计算结束。")

示例 4：用 raise 主动报错#

def set_age(age):
    if age < 0:
        raise ValueError("年龄不能是负数")
    print("年龄设置为：", age)

try:
    set_age(-3)
except ValueError as e:
    print("捕获到异常：", e)

三、练习#

  1. 写一个程序，让用户输入两个数并做除法，用 try/except 分别处理"除数为零"和"输入不是数字"两种情况。
  2. 把上一课的"读取文件"代码加上异常处理：文件不存在时给出友好提示，而不是让程序崩溃。
  3. 写一个 divide(a, b) 函数，当 b 为 0 时用 raise 抛出自定义提示，然后在调用处用 try/except 捕获并打印。
