客户分群#

终于到了把聚类用到真实业务的一刻。客户分群（customer segmentation）是零售、电商、会员运营里最常见的无监督学习场景：把成千上万名客户按照消费行为自动分成几组，再对每组制定差异化策略——比如给"高价值客户"推 VIP 服务，给"流失风险客户"发挽回优惠券。这一课用一个完整的 KMeans 流程，讲清从特征构造、标准化、选 K 到解读簇的每一步。

一、概念讲解#

1. 用什么特征描述客户：RFM 思想#

客户分群通常不直接用原始流水，而是先聚合成每个客户一行、几个有业务含义的特征。经典做法是 RFM 三个指标：

  • R（Recency）：最近一次购买距今多久，越小说明越活跃；
  • F（Frequency）：一段时间内的购买频次，越大越忠诚；
  • M（Monetary）：累计消费金额，越大价值越高。

本课就用"消费金额、购买频次、最近购买距今月数"三个特征来演示，思路与 RFM 一致。

2. 为什么要标准化#

这三个特征量纲差异巨大：金额是几百到上千，频次是几到几十，距今月数是个位数。KMeans 靠欧氏距离划簇，若不标准化，金额会主导距离计算，另外两个特征几乎被忽略。所以必须先 StandardScaler，让三个特征站在同一起跑线上。

3. 怎么选 K：肘部法与轮廓系数#

KMeans 需要提前给定簇数 K。两个常用的辅助工具：

  • 肘部法：画出"惯性（inertia，簇内平方和）随 K 变化"的曲线，找到下降速度明显变缓的"肘部"作为候选 K。
  • 轮廓系数（silhouette score）：衡量每个点"与同簇点的相似度"相比"与最近邻簇的相似度"高多少，取值在 -1 到 1 之间，越接近 1 表示簇越紧凑、分离越好。取轮廓系数最高的 K。

两者配合使用最稳：肘部法给方向，轮廓系数给数值佐证。

4. 怎么解读结果：看质心#

聚类完成后，每个簇有一个质心（cluster center），它是该簇内所有点在特征空间里的平均位置。把质心换算回原始量纲，就能回答"这一群人平均消费多少、多久来一次"。结合业务知识给每个簇起个名字（如"高价值活跃客户""价格敏感型客户""流失风险客户"），聚类才算真正落地。

二、可运行代码示例#

示例 1：构造模拟客户数据并标准化#

先造一批包含三个真实群体的客户数据：

import numpy as np
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(42)

# 每个群体用 (消费金额, 购买频次, 最近购买距今月数) 描述
def make_group(size, center, spread):
    return rng.normal(loc=center, scale=spread, size=(size, 3))

# A：高价值（高消费、高频、最近活跃）
# B：普通（中等水平）
# C：流失风险（低消费、低频、很久没来）
group_a = make_group(200, [900, 30, 1], [120, 6, 0.5])
group_b = make_group(250, [400, 15, 4], [80, 4, 1.0])
group_c = make_group(150, [80, 3, 10], [25, 1.5, 2.0])

X = np.vstack([group_a, group_b, group_c])
X = np.clip(X, 0, None)          # 金额/频次/月数都不为负

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
print("数据形状:", X.shape)

要点：np.clip(X, 0, None) 把随机生成时偶尔出现的负值截断为 0，让数据更符合业务常识。现实中这一步换成"从数据库/数仓聚合真实特征"即可。

示例 2：肘部法与轮廓系数选 K#

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

inertias, silhouettes = [], []
ks = list(range(2, 8))
for k in ks:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X_scaled)
    inertias.append(km.inertia_)
    silhouettes.append(silhouette_score(X_scaled, labels))

fig, axes = plt.subplots(1, 2, figsize=(12, 4.5))
axes[0].plot(ks, inertias, marker='o')
axes[0].set_xlabel('K'); axes[0].set_ylabel('惯性（簇内平方和）')
axes[0].set_title('肘部法')
axes[1].plot(ks, silhouettes, marker='o')
axes[1].set_xlabel('K'); axes[1].set_ylabel('轮廓系数')
axes[1].set_title('轮廓系数法')
plt.show()

best_k = ks[int(np.argmax(silhouettes))]
print("轮廓系数最高的 K =", best_k, "，得分 =", max(silhouettes).round(3))

要点：肘部曲线在 K=3 附近明显变缓，轮廓系数也应在 K=3 处出现峰值——两个证据互相印证，K=3 就是答案。inertia_ 是簇内平方和，随 K 增大必然单调下降，所以不能只看它变小就盲目加 K。

示例 3：用 K=3 分群并解读质心#

km = KMeans(n_clusters=3, random_state=42, n_init=10)
labels = km.fit_predict(X_scaled)

# 把质心换算回原始量纲，方便业务解读
centers = scaler.inverse_transform(km.cluster_centers_)
names = ["消费金额", "购买频次", "最近购买距今月数"]
for i, c in enumerate(centers):
    desc = "，".join(f"{n}={v:.1f}" for n, v in zip(names, c))
    print(f"簇 {i}：{desc}（样本数 {int((labels == i).sum())}）")

要点：对照三个群体的原始参数，你应该能看到一个簇"金额高、频次高、最近活跃"，另一个"金额低、频次低、很久没来"——据此即可给簇命名并设计运营动作。inverse_transform 把质心从"标准化坐标"还原成人类可读的原始单位。

三、练习#

  1. 换 K 观察：把示例 2 的 K 范围改成 2 到 12，重新画两条曲线，确认肘部是否仍稳定在 3 附近；若换成 4 或 5，各簇的质心会发生什么变化？
  2. 加入新特征：给模拟数据增加第四个特征"客单价"（金额/频次），重跑整个流程，看看肘部与轮廓系数的结论是否改变。
  3. 可视化分群：用 PCA(n_components=2) 把 X_scaled 降到 2 维，按 labels 着色画散点，并在图上标出各簇质心投影后的位置。
  4. 思考：如果某位业务方坚持要分 7 个簇（因为想对应 7 个运营小组），你会怎么用肘部法和轮廓系数说服他少分一些？
