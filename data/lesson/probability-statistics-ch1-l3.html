贝叶斯公式#

第 2 课我们学了条件概率：给定"观察到的证据"，更新对某件事的判断。贝叶斯公式把这个思想推到了极致——它给出了一套"用新证据倒推原因"的通用框架，是垃圾邮件过滤、医疗诊断、推荐系统等大量机器学习应用的数学核心。

一、概念讲解#

1. 从条件概率到贝叶斯公式#

条件概率定义告诉我们：P(A | B) = P(A ∩ B) / P(B)。交换 A、B 的角色，又有 P(B | A) = P(A ∩ B) / P(A)。两式都含有 P(A ∩ B)，联立消去它就得到贝叶斯公式：

P(A | B) = P(B | A) · P(A) / P(B)

其中分母 P(B) 通常用全概率公式展开成 P(B) = P(B | A)P(A) + P(B | Ā)P(Ā)。

2. 四个量的名字与含义#

把 A 看作"我们要判断的原因/假设"，B 看作"观察到的证据"，则：

  • 先验概率 P(A)：还没看到证据时，对 A 的初始判断。例如"人群中有 1% 患病"。
  • 似然 P(B | A)：假设 A 成立时，观察到证据 B 的可能性。例如"患病者中 99% 检测为阳性"。
  • 证据（边缘）概率 P(B)：无论 A 是否成立，观察到 B 的总概率，起归一化作用。
  • 后验概率 P(A | B)：看到证据 B 之后，更新过的对 A 的判断。这才是我们真正想要的。

一句话概括：后验 ∝ 似然 × 先验。证据到来之前我们有先验，证据的"似然"告诉我们这个证据在多大程度上支持 A，两者相乘再归一化，就得到后验。

3. 医疗检测的"反直觉"结论#

假设某病发病率 1%，检测灵敏度（患病者测出阳性）99%，假阳性率（健康人测出阳性）1%。一个人检测为阳性，他真正患病的概率是多少？

直觉上很多人会猜"接近 99%"，但代入贝叶斯公式：

P(阳性) = 0.99 × 0.01 + 0.01 × 0.99 = 0.0198 P(患病 | 阳性) = 0.99 × 0.01 / 0.0198 ≈ 0.5

只有约 50%！原因在于先验极低（发病率只有 1%），假阳性虽然"比例低"，但健康人口基数巨大，产生的假阳性总数反而盖过了真阳性。这就是基础比率谬误：只看似然、忽视先验会严重高估。这也是贝叶斯公式最著名的现实意义。

4. 朴素贝叶斯分类器#

把贝叶斯公式用到分类：给定样本特征 x，想求它属于每个类别 c 的后验概率 P(c | x)。由贝叶斯公式：

P(c | x) ∝ P(x | c) · P(c)

再加上"朴素"的特征独立性假设，P(x | c) 可以拆成各个特征条件概率的乘积。预测时，选后验概率最大的类别即可。虽然假设朴素，朴素贝叶斯在文本分类（尤其是垃圾邮件过滤）上表现非常好，而且训练和预测都极快，常被当作分类任务的基线。

二、可运行示例#

示例 1：医疗检测的贝叶斯计算#

# 已知条件
p_disease = 0.01            # 先验：患病概率
p_pos_given_disease = 0.99  # 灵敏度：患病者测出阳性的概率
p_pos_given_healthy = 0.01  # 假阳性率：健康人测出阳性的概率

p_healthy = 1 - p_disease

# 全概率公式求边缘概率 P(阳性)
p_pos = p_pos_given_disease * p_disease + p_pos_given_healthy * p_healthy

# 贝叶斯公式求后验 P(患病 | 阳性)
p_disease_given_pos = (p_pos_given_disease * p_disease) / p_pos

print(f"P(阳性) = {p_pos:.4f}")
print(f"P(患病 | 阳性) = {p_disease_given_pos:.4f}")
print("结论：阳性并不代表一定患病，先验过低时后验只有约 50%。")

示例 2：手写朴素贝叶斯垃圾邮件分类器#

import math
from collections import Counter

# 训练数据：每条是 (文本, 标签)，1 = 垃圾邮件，0 = 正常邮件
train = [
    ("免费 领取 大奖 点击 链接", 1),
    ("恭喜 中奖 免费 礼物", 1),
    ("明天 开会 记得 带 报告", 0),
    ("免费 优惠 促销 点击", 1),
    ("周末 一起 吃饭 吗", 0),
    ("项目 进度 汇报 会议", 0),
]


def tokenize(text):
    """把文本按空格切成词列表（真实项目里要接中文分词工具）。"""
    return text.split()


def train_naive_bayes(samples):
    """训练朴素贝叶斯：统计先验 P(c) 与条件概率 P(词|c)。"""
    docs_by_class = {0: [], 1: []}
    for text, label in samples:
        docs_by_class[label].append(tokenize(text))

    vocab = {w for t, _ in samples for w in tokenize(t)}  # 词表
    priors = {}
    word_given_class = {}  # (词, 类别) -> P(词|类别)

    for cls in (0, 1):
        docs = docs_by_class[cls]
        priors[cls] = len(docs) / len(samples)          # 先验概率
        counts = Counter(w for d in docs for w in d)
        total = sum(counts.values())
        for w in vocab:
            # 拉普拉斯平滑：分子 +1、分母 +词表大小，避免未出现词的 0 概率
            word_given_class[(w, cls)] = (counts[w] + 1) / (total + len(vocab))

    return priors, word_given_class, vocab


def predict(text, priors, word_given_class, vocab):
    """用对数求和计算各类别得分，避免大量小概率连乘下溢。"""
    words = tokenize(text)
    scores = {}
    for cls in (0, 1):
        score = math.log(priors[cls])
        for w in words:
            if w in vocab:
                score += math.log(word_given_class[(w, cls)])
        scores[cls] = score
    return max(scores, key=scores.get), scores


priors, word_given_class, vocab = train_naive_bayes(train)

text = "免费 点击 领取 大奖"
pred, scores = predict(text, priors, word_given_class, vocab)
print(f"文本「{text}」→ 预测为：{'垃圾邮件' if pred == 1 else '正常邮件'}")
print(f"对数得分：垃圾={scores[1]:.2f}，正常={scores[0]:.2f}")
