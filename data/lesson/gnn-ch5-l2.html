图分类#

节点分类回答"这个点是什么"，图分类回答"这张图整体是什么"——判断一个分子是否有毒、预测一个蛋白质的功能、识别一张社交网络子图是否异常。它比节点分类多一道坎：模型不再输出每个节点的标签，而是要先把手上一堆节点嵌入浓缩成一个图级表示，再交给分类器。这道"浓缩"工序叫 readout（读出），是本课的核心。

一、概念讲解#

1. 从节点嵌入到图表示：readout#

图分类的模型同样分编码器和分类头，但中间多了一步：

Z = GNN(X, A)              # ① 编码：得到每个节点的嵌入 Z ∈ R^(N × H)
g = READOUT( Z )           # ② 读出：把所有节点嵌入聚合成一个向量 g ∈ R^H
P = softmax( g · W_cls )   # ③ 分类：图级表示过分类器

READOUT 必须满足两个条件：置换不变（节点顺序打乱不影响结果）和可处理变长输入（不同图的节点数不同）。最常用的三种：

  • 全局均值池化：g = (1/N) Σ_i z_i。简单稳定，但会丢失"哪类节点多、哪些节点特殊"的分布信息。
  • 全局求和池化：g = Σ_i z_i。保留了"数量/规模"信息，是理论上表达力更强的选择（见下文 GIN）。
  • 全局最大池化：g = max_i z_i（逐元素）。对"是否存在某类极端特征"敏感，但容易忽略多数节点。

PyG 里对应 global_mean_pool、global_add_pool、global_max_pool。

2. 为什么求和池化最强：与 GIN 的联系#

这是图分类里"知其所以然"的关键。可以证明：均值/最大池化都可能把两个结构不同的图映射成相同的表示，从而无法区分它们。

  • 均值池化：{1,1,1,1} 和 {2,2} 平均后都是 1，区分不了"四个 1"与"两个 2"。
  • 最大池化：{1,2,3,4} 和 {4,4,4,4} 最大值都是 4，区分不了。

求和池化则能保留这些差异。基于这一观察，Xu 等人提出了 GIN（Graph Isomorphism Network），其聚合更新规则是：

h_v^k = MLP^k( (1 + ε^k) · h_v^(k-1) + Σ_{u ∈ N(v)} h_u^(k-1) )

其中 ε 是可学习标量，MLP 是多层感知机。GIN 把"邻居求和 + 自身加权"与一个 MLP 结合，配合求和读出，被证明在区分图结构的能力上逼近 WL（Weisfeiler-Lehman）图同构测试的上界——这是当前图分类任务里最常用、也最强悍的基线之一。

3. 层级池化：更精细的"浓缩"#

全局池化把所有节点一步压平，对小图够用，但大图会损失层级结构。更精细的做法是层级池化（hierarchical pooling）：逐步把节点"合并"成粗粒度节点，形成图的金字塔，最后再读出。代表方法有：

  • DiffPool：学一个软分配矩阵，把节点可微地聚类到更少的超节点。
  • Top-K Pooling：按节点的重要性分数保留 Top-K 个节点，丢弃其余，逐层"剪枝"。

它们表达力更强，但训练更不稳定、实现更复杂。工程上默认先上全局池化，效果不够再考虑层级池化。

4. 变长图的批处理：batch 向量#

图分类要一次处理多个大小不同的图。PyG 的解法是把多张图沿节点维拼接成一张大图，边索引做相应偏移，再用一个 batch 向量记录"每个节点属于哪张图"：

batch = [0, 0, 0, 1, 1, 1, 1, 2, ...]   # 第 1 张图 3 个节点，第 2 张 4 个节点…

这样 global_mean_pool(z, batch) 就能按 batch 分组做池化，一次算出每个图的 g。这也是 GNN 处理"图里套图"（batch of graphs）的标准范式，务必理解。

5. 与节点分类的对照#

节点分类 图分类
预测对象 每个节点 每张图
数据形态 通常一张大图 一批互不连通的小图
关键模块 编码器 + 节点分类头 编码器 + readout + 图分类头
批处理 整图前向 batch 向量拼接
典型数据集 Cora、PubMed MUTAG、PROTEINS、ENZYMES

二、可运行示例#

示例：GIN + 求和读出，在 MUTAG 分子数据集上做图分类

import torch
import torch.nn.functional as F
from torch_geometric.nn import GINConv, global_add_pool
from torch_geometric.datasets import TUDataset
from torch_geometric.loader import DataLoader

# 1. MUTAG：188 个分子图，标签为"是否诱变"（二分类）
dataset = TUDataset(root='./data/MUTAG', name='MUTAG')
print(f'图数量 {len(dataset)} | 特征维 {dataset.num_features} | 类别数 {dataset.num_classes}')

# 划分训练/测试（图分类要按"图"划分，不是按节点）
dataset = dataset.shuffle()
n_train = int(len(dataset) * 0.8)
train_ds, test_ds = dataset[:n_train], dataset[n_train:]
train_loader = DataLoader(train_ds, batch_size=32, shuffle=True)
test_loader = DataLoader(test_ds, batch_size=32)

# 2. GIN：每一层 = MLP( (1+eps)·h_v + Σ h_u )，两层 + 求和读出
class GIN(torch.nn.Module):
    def __init__(self, in_ch, hidden_ch, out_ch):
        super().__init__()
        # GINConv 内部要求一个可微的"邻居聚合函数"，这里用两层线性+ReLU 的 MLP
        nn1 = torch.nn.Sequential(
            torch.nn.Linear(in_ch, hidden_ch), torch.nn.ReLU(),
            torch.nn.Linear(hidden_ch, hidden_ch))
        nn2 = torch.nn.Sequential(
            torch.nn.Linear(hidden_ch, hidden_ch), torch.nn.ReLU(),
            torch.nn.Linear(hidden_ch, out_ch))
        self.conv1 = GINConv(nn1)   # 第一层，输出 hidden_ch 维
        self.conv2 = GINConv(nn2)   # 第二层，输出 out_ch 维（图嵌入维）

    def forward(self, x, edge_index, batch):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = self.conv2(x, edge_index)
        x = global_add_pool(x, batch)   # 关键：按 batch 做求和读出
        return F.log_softmax(x, dim=1)

model = GIN(dataset.num_features, 32, dataset.num_classes)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

def train():
    model.train()
    total_loss = 0
    for data in train_loader:       # 每个 data 是一批图
        optimizer.zero_grad()
        out = model(data.x, data.edge_index, data.batch)
        loss = F.nll_loss(out, data.y)   # y 是整图标签
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * data.num_graphs
    return total_loss / len(train_ds)

@torch.no_grad()
def evaluate(loader):
    model.eval()
    correct = total = 0
    for data in loader:
        out = model(data.x, data.edge_index, data.batch)
        correct += (out.argmax(dim=1) == data.y).sum().item()
        total += data.num_graphs
    return correct / total

for epoch in range(100):
    loss = train()
    if epoch % 10 == 0:
        print(f'Epoch {epoch:03d} | Loss {loss:.4f} | '
              f'Train {evaluate(train_loader):.4f} | Test {evaluate(test_loader):.4f}')

MUTAG 是经典小数据集，GIN 通常能到 0.85 以上的测试准确率。注意代码里的两个关键点：DataLoader 自动生成 batch 向量，global_add_pool(x, batch) 依赖它分组。

动手改动：把 global_add_pool 换成 global_mean_pool 再跑，通常准确率会小幅下降——这正是"求和池化保留数量信息、表达力更强"的实证。

三、练习#

  1. readout 三选一：给定两个图，节点嵌入分别为 {1,1,1,1} 和 {2,2}，分别计算均值、求和、最大三种读出结果，指出哪些读出能区分这两张图，哪些不能。
  2. 置换不变性：把一张图的节点顺序打乱，观察三种全局池化的输出是否改变，说明 readout 为什么必须置换不变。
  3. batch 向量实验：打印一个 batch_size=3 的 batch 里 data.batch 的内容，验证它是否正确标记了每个节点所属的图，以及 global_add_pool 的分组逻辑。
  4. GIN vs GCN：把 GINConv 换成 GCNConv 加 global_add_pool，对比图分类准确率，结合 GIN 的"求和聚合 + MLP"设计解释差异。
  5. 层级池化前瞻：查阅 PyG 的 TopKPooling 或 DiffPool 文档，用一段话说明层级池化相对全局池化的优势与代价。
