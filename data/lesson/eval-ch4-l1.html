这一节要解决什么#

LLM-as-judge 现在是开放式生成评测的事实标准。它的基本假设是：一个强模型对两个候选输出的偏好排序，与人类专家的偏好排序足够接近。 这个假设在什么条件下成立、偏差有多大、方向朝哪，是本课程里最需要定量回答的问题之一。

本节的立场是：不要把 judge 当评分器，要把它当仪表。 仪表有三件事必须知道：量程（它测什么）、系统误差（偏差有多大、朝哪个方向）、随机误差（同条件重复测量的散布）。本节只讲系统误差，因为它最危险——偏差不会随着样本量增大而消失：你把样本量翻十倍，偏差一分不减，置信区间只是把你更精确地钉在错误的答案上。

内容安排：

  1. 偏差的分类学：位置、长度、自我偏好、格式、评分尺度。给出每一类的定义与预期方向。
  2. 为什么会有这些偏差：从自回归到注意力、从解码到提示的机制解释。知道机制才知道哪种缓解有效、哪种是安慰剂。
  3. 怎么量化：每一类偏差的最小实验设计（配对设计 / 随机化 / 安慰剂对照）与效应量（含置信区间）。
  4. 缓解手段与它们的边界：顺序交换、题目交换、长度控制、多 judge 集成、位置随机化。哪些偏差能消除、哪些只能稀释、哪些会被缓解手段引入新的偏差。

一、先分清两种误差：偏差与方差#

设候选 A、B 的真实质量差是 δ（人类专家的偏好），judge 给出的估计差是 δ^。那么：

δ^=真值δ​​+系统性偏差b(特征)​​+随机误差ε​​,E[ε]=0

  • 随机误差 ε 靠重复采样/多样本消掉：它对结论的影响随 n 下降，最终可以报成置信区间。
  • 系统性偏差 b 与样本量无关：它可能依赖位置（A 在前还是后）、长度、模型家族、格式、甚至是 prompt 里的措辞。它是本节的唯一焦点。

为什么这个区分重要：因为工程上最常见的错误做法是"用更多样本提高 judge 的可靠性"。如果偏差是主要误差源，加样本只会让你更自信地错。诊断的第一步永远是测量偏差是否存在（用配对/交换设计），第二步才是加样本。

二、偏差谱系：五类与它们的预期方向#

偏差 定义 预期方向 典型量级
位置偏差 偏好取决于候选出现的位置 偏向先出现（少数模型偏向后者） 翻转率 10%~35%
长度/啰嗦偏差 更长的回答更容易被选中 偏向更长 win-rate 高估 5~20 个点
自我偏好（self-preference） 偏向自己（或其家族）生成的输出 偏向自身家族 胜率虚高 5~25 个点
格式/风格偏差 偏好 markdown、列表、小标题、礼貌语气 偏向"看起来结构化" 难以先验判断，需实测
评分尺度偏差 绝对打分受尺度、锚点、集中趋势影响 向中间收缩、不使用极端值 1∼5 分实际只用 3∼4

位置偏差：最普遍、最容易测#

定义上它就是一个配对实验：把同一对候选（A,B）分别以 (A,B) 和 (B,A) 两种顺序给 judge，比较它两次的选择。

  • 翻转率（flip rate）：两次选择不一致的比例。
  • 位置胜率偏向：在判 A 胜的场次中，A 在前面的比例与 0.5 的距离。

为什么它存在：自回归模型对 prompt 末尾的内容与先出现的内容有不对称的处理；pairwise 判定里"先读到的"往往充当了参照系，后续内容被相对化。也有实现层面的原因（prompt 模板里的位置标签、分隔符格式）。

量级：不同模型差异很大。工程经验是翻转率 10%35%。这意味着：如果你的评测只跑一种顺序，那么有 10%35% 的样本的判定是"位置决定的"，其贡献会系统性地偏向某个候选——而且这个偏向的方向与模型家族有关，不能靠"两边都跑一遍取平均"以外的方法消除。

缓解：两种顺序都跑，按三种方式聚合（见第 2 节）：(a) 只有两次一致才计胜；(b) 两次不一致记 0.5 胜（等价于平均）；(c) 不一致的样本转人工。三者的统计性质不同，(a) 会丢失信息、(b) 无偏但方差更大、(c) 最准但最贵。

长度偏差：最容易与被测目标混淆#

定义：在控制质量后，judge 仍偏向更长的回答。

为什么危险：长度与质量在真实数据里是正相关的（更好的模型往往写得更充分）。所以你不能用"更长的赢了"来证明存在长度偏差——你必须打破这个相关：对同一对候选，把它们的长度交换/对齐，或者用回归控制长度后看质量的效应是否仍在。

三种最小设计：

  1. 长度置换（length permutation）：取一对质量相近但长度不同的回答，把它们的长度信息人工互换（比如截断/续写），看 judge 是否跟着长度走。
  2. 长度平衡的相关分析：对大量配对，拟合 Pr(A 胜)=σ(α+βq​Δq+βL​ΔL)，其中 Δq 是人类质量差、ΔL 是长度差。βL​ 显著不为 0 即长度偏差；βq​ 是"质量敏感度"。这个模型同时给你偏差与敏感度两个数字，比单一翻转率信息量更大。
  3. 长度锚定实验：给同一个回答人为加一段无信息的礼貌话术，看胜率是否上升。这是最干净的因果识别。

量级：文献中的典型报告是"长度每增加 100 token，胜率上升几个到十几个点"。如果你在做 A/B 比较两个模型的输出，而两个模型的平均长度差 30%，那么这个长度差会主导结论。

自我偏好（self-preference）#

定义：judge 对自己（或其训练家族）产生的输出给出更高评价。

为什么存在：三个可能机制——(a) 训练分布上"自己风格"的文本概率更高，judge 把它当成"更自然"；(b) 指令微调后的偏好数据里，自己家族的输出占比过高；(c) 表面特征（措辞、格式习惯）的自相似性。

怎么测：你需要两个可归属到不同家族的生成模型（A 家族、B 家族）与至少两个来自不同家族的 judge（JA​、JB​）。设计一个 2×2：

JA​ 判 A 胜率 JB​ 判 A 胜率
差异 wAA​ wBA​

自我偏好的大小可估为 (wAA​−wBA​)——同一个候选，被自己家族 judge 评出的胜率与被别的家族 judge 评出的胜率之差。这个差分设计把候选质量消掉了，剩下的就是 judge 家族效应。

关键实践结论：用被评模型自己当 judge 是无效的（尤其是"让模型给自己打分"）。其次，单 judge 的绝对胜率无法跨论文比较——因为对手集合变了、judge 家族变了。所以报告必须写明 judge 的家族与版本。

格式/风格偏差#

定义：judge 偏好结构化输出（markdown、小标题、bullet、加粗）、特定语气（礼貌、自信）与特定长度单位的排版。

为什么难：它与"用户真的更喜欢"高度纠缠。用户确实可能更喜欢结构化输出——这时它不是偏差，是有效信号。判据是：这个风格特征是否与你关心的构念无关？ 如果评测目标是"事实正确性"，那么格式偏好就是污染；如果目标是"用户满意度"，格式就是构念的一部分。

怎么测：格式置换——把同一个内容的两种排版（纯段落 vs markdown 列表）配成对，让 judge 选。若某侧显著占优，说明存在格式偏差。这个实验成本极低（内容相同），是少数能做到"干净因果识别"的偏差测量。

评分尺度偏差#

当你要求 judge 打绝对分（15、110）时：

  • 集中趋势：judge 极少使用 1 和 5，实际取值集中在 3~4，方差被压缩 → 分辨率下降。
  • 锚点效应：prompt 里描述"3 分 = 一般"会显著改变分布。
  • 尺度不线性：4→5 与 1→2 的"难度"不同，因此分数差不可做算术（这与第 1 章的胜率不可加是同一类问题）。

实践结论：只要可能，用相对判断（pairwise）而不是绝对打分。 相对判断的偏差更少、方差更小、跨批次可比性更好。绝对分的唯一优势是便宜（一次一个样本），可以用在"粗筛/排序"而不是"定值/门禁"上。

三、把偏差写成可估计的参数#

上面五类偏差可以直接进一个统一的回归模型。对每一对 (i)，令 yi​∈{0,1} 表示"judge 认为先出现的那个更好"，Δqi​ 是人工标注的质量差，ΔLi​ 是长度差，zi​∈{0,1} 表示"先出现的是不是 J 自己的家族"，Δsi​ 是格式分差：

logitPr(yi​=1)=α+βq​Δqi​+βL​ΔLi​+βS​zi​+βF​Δsi​+uitem(i)​+vbatch(i)​

  • βq​ 是敏感度：judge 对真实质量差有多敏感。它应该显著为正。
  • βL​,βS​,βF​ 是偏差参数：理想情况是 0。它们的大小直接给出"每单位特征值换取多少对数几率"，比"胜率上升 5 个点"更可迁移。
  • uitem​ 是题目随机效应（题目难度），vbatch​ 是批次效应（不同时间的 judge 版本/温度）。批次效应是 judge 评测的隐形杀手：如果你在不同时间用不同版本跑了两组对比，v 会吸收掉你想测的效应。

取舍：这个模型需要足够的数据（几百对以上）与正确的随机化（位置、家族、长度都要被随机或交叉）。它的收益是把"judge 靠不靠谱"变成一个带置信区间的判断，而不是一个印象。

四、缓解手段的适用边界#

手段 消除位置偏差 消除长度偏差 消除自我偏好 代价
顺序交换（双次判定） 是（配对消除） 否 否 成本 ×2
只保留两次一致的样本 是（但对偏差样本有选择效应） 否 否 样本量损失大，且改变总体
长度控制（回归/配对） 否 是（统计上） 否 需要长度数据 + 建模
长度对齐（截断/续写） 否 是（实验上） 否 可能改变质量本身
换家族 judge 否 部分（不同家族偏差不同，平均后减小） 是 成本 ×k；需要多家族可用
多 judge 集成取多数 部分（不同位置偏差可比） 部分 是 成本 ×k；分歧需要仲裁规则
用 rubric 分解评分 部分 显著减小 部分 prompt 工程量大；rubric 本身要验收

三条必须记住的边界：

  1. 顺序交换只消除"位置"这一个维度的偏差。 它不能消除长度、自我偏好、格式。
  2. 缓解不等于消除。 多 judge 集成是把不同方向的偏差平均，得到的是"偏差更小的估计量"，不是无偏估计量。除非你能证明家族偏差的期望为 0——而这正是难以证明的。
  3. 缓解手段会引入新偏差。 "只保留两次一致的样本"会把"位置敏感的样本"整体丢掉，得到一个在位置稳健性上经过选择的子总体——它对"哪些题容易判"有偏。报告里必须写明样本损失比例。

五、诊断清单：拿到一个 judge 该先做什么#

按"最便宜优先"排序，前四步都能在一天内完成：

  1. 位置交换实验：抽 200~500 对，两种顺序都跑，报翻转率与位置胜率偏向（含置信区间）。
  2. 格式置换实验：同内容的两种排版配成对，报胜率偏向。
  3. 长度回归：在已有的配对数据上拟合 ΔL 的系数，报 βL​ 与 CI。
  4. 批次一致性：同一批样本隔一天/换个版本重跑，报一致率。这一项能发现最致命的隐性错误（版本漂移）。
  5. 自我偏好差分：需要两个家族的生成模型与两个家族的 judge，成本最高，但对"用哪个 judge"这个决策最关键。
  6. 与人工的校准：第 3 节的内容，报一致率 + 有序 κ + 分层误差。

为什么是这个顺序：位置与格式的测量是成对的、可以做到干净因果识别的，且能立刻改变你的协议（比如强制双顺序）。长度回归只需已有数据。自我偏好与人工校准成本高，应该在基本协议定下来之后做。

代码#

以下代码只用标准库。⚠️ 全部为合成数据，用于展示偏差的可测量性与统计量的行为；数值不对应任何真实模型。

import math
import random
import statistics

rng = random.Random(101)


def phi(x):
    return 0.5 * (1 + math.erf(x / math.sqrt(2)))


def wilson(k, n, z=1.959963985):
    if n == 0:
        return 0.0, 0.0
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return max(0.0, c - h), min(1.0, c + h)


# ============================================================
# 1. 位置偏差：交换顺序后的翻转率与位置胜率偏向
# ============================================================
# 合成模型：judge 有 prob_first 的概率"偷懒选先出现的"，否则按真实质量 + 噪声判断
N_PAIRS = 500
TRUE_QUALITY_SD = 1.0
NOISE_SD = 0.5
PROB_LAZY = 0.15          # 位置偏差强度：15% 的判定直接选"先出现的"


def judge_choice(dq, first_is_self, prob_lazy, noise_sd, r):
    # dq = 先出现的那个 - 后出现的那个（真实质量差）
    # 返回 True 表示 judge 选了先出现的那个
    if r.random() < prob_lazy:
        return True                                   # 位置偏差：直接选先出现的
    z = dq + (0.8 if first_is_self else 0.0) + r.gauss(0, noise_sd)
    return z > 0                                      # 感知到的质量差决定选择


r = random.Random(7)
n_flip = 0
a_first_win = b_first_win = 0
n_disagree_issues = 0
for _ in range(N_PAIRS):
    qa = r.gauss(0, TRUE_QUALITY_SD)
    qb = r.gauss(0, TRUE_QUALITY_SD)
    first_is_self = False          # 位置偏差实验里先关掉自我偏好
    # 顺序 1：A 在前
    pick_first_1 = judge_choice(qa - qb, first_is_self, PROB_LAZY, NOISE_SD, r)
    win_a_1 = pick_first_1                       # 选先出现 = 选 A
    # 顺序 2：B 在前
    pick_first_2 = judge_choice(qb - qa, first_is_self, PROB_LAZY, NOISE_SD, r)
    win_a_2 = not pick_first_2                   # 选先出现 = 选 B -> A 没赢
    if win_a_1 != win_a_2:
        n_flip += 1
    a_first_win += int(win_a_1)
    b_first_win += int(win_a_2)

lo, hi = wilson(n_flip, N_PAIRS)
print("== 1. 位置偏差（合成） ==")
print(f"翻转率 = {n_flip/N_PAIRS:.3f}  95% CI [{lo:.3f}, {hi:.3f}]  (n={N_PAIRS})")
print(f"只跑顺序 1 时的 A 胜率 = {a_first_win/N_PAIRS:.3f}")
print(f"只跑顺序 2 时的 A 胜率 = {b_first_win/N_PAIRS:.3f}")
print(f"两个顺序的差 = {(a_first_win-b_first_win)/N_PAIRS:+.3f}  <- 位置偏差的净效应")
print("  <- 翻转率是'两次结论不一致'的比例；两个顺序的胜率差才是位置偏差的净效应")
print("     只用一种顺序时，这部分偏差不会出现在任何置信区间里 —— ")
print("     区间会围绕一个被偏差平移过的点估计，仍然是'精确地错'")

# 2. 长度偏差：把长度与质量解耦，估计 beta_L
# ============================================================
def fit_logit(X, y, iters=3000, lr=0.3, l2=1e-3):
    # 先把特征标准化再拟合（否则量纲差异会让梯度下降几乎不收敛）
    n, d = len(X), len(X[0])
    cols = [[X[i][j] for i in range(n)] for j in range(d)]
    mu = [statistics.mean(c) for c in cols]
    sd = [statistics.stdev(c) or 1.0 for c in cols]
    Z = [[(X[i][j] - mu[j]) / sd[j] for j in range(d)] for i in range(n)]
    w = [0.0] * d
    for _ in range(iters):
        g = [0.0] * d
        for i in range(n):
            z = sum(w[j] * Z[i][j] for j in range(d))
            p = 1 / (1 + math.exp(-max(-30.0, min(30.0, z))))
            e = p - y[i]
            for j in range(d):
                g[j] += e * Z[i][j]
        for j in range(d):
            w[j] -= lr * (g[j] / n + l2 * w[j])
    # 还原到原始量纲：原始单位每 1 单位特征对应的 logit 变化
    w_orig = [w[j] / sd[j] for j in range(d)]
    intercept_orig = sum(-w[j] * mu[j] / sd[j] for j in range(d))
    return [intercept_orig] + w_orig[1:], w


N = 1200
r = random.Random(11)
X, y, dq_true, dL_true = [], [], [], []
for _ in range(N):
    dq = r.gauss(0, 1.0)             # 真实质量差（人类）
    dL = r.gauss(0, 120.0)           # 长度差（token）
    # judge 的判定：质量权重 1.0，长度权重 0.004/token（约每 100 token +0.4 logit）
    logit = 1.0 * dq + 0.004 * dL
    yy = 1 if r.random() < 1 / (1 + math.exp(-logit)) else 0
    X.append([1.0, dq, dL, dq * dL])
    y.append(yy)
    dq_true.append(dq)
    dL_true.append(dL)

w, w_std = fit_logit(X, y)
print("\n== 2. 长度偏差（合成，logistic 回归） ==")
print("真实生成过程: logit = 1.00 * dq + 0.004 * dL")
print(f"拟合（原始量纲）: 截距={w[0]:+.3f}  beta_q={w[1]:+.3f}  "
      f"beta_L={w[2]:+.5f}  交互={w[3]:+.5f}")
print(f"解释：质量差 1 个标准差 ≈ {w[1] * statistics.stdev(dq_true):.2f} logit；")
print(f"      长度差 120 token ≈ {w[2] * 120:.2f} logit  <- 与质量效应同量级")
ratio = (w[2] * 120) / (w[1] * statistics.stdev(dq_true))
print(f"      两者之比 = {ratio:.2f}  (即 120 token 的长度差 ≈ {ratio:.2f} 个质量标准差)")
# 只报"长度更长的赢了"会有什么结论
long_win = sum(1 for i in range(N) if (dL_true[i] > 0) == (y[i] == 1))
print(f"朴素指标：'更长的一侧胜率' = {long_win/N:.3f}（含质量与长度的共同作用）")
print("  <- 朴素指标无法区分'长度偏差'与'更长确实更好'；")
print("     必须用回归控制质量，或用长度置换实验做因果识别")

# 3. 自我偏好：差分设计（同一候选，不同家族 judge）
# ============================================================
def win_rate_selfpref(delta_self, n=2000, seed=3):
    r = random.Random(seed)
    wins = 0
    for _ in range(n):
        dq = r.gauss(0, 1.0)
        logit = dq + delta_self          # 自我家族的额外加成
        # 位置偏差取平均（两次顺序交替）
        p = 1 / (1 + math.exp(-logit))
        wins += 1 if r.random() < p else 0
    return wins / n


print("\n== 3. 自我偏好（合成，差分设计） ==")
for delta_self in (0.0, 0.3, 0.6, 1.0):
    w_same = win_rate_selfpref(delta_self)
    w_other = win_rate_selfpref(0.0, seed=3)
    print(f"自身家族 judge 加成 delta={delta_self:.1f} -> 胜率 {w_same:.3f} "
          f"(异家族 judge 估计 {w_other:.3f})  虚高 {w_same-w_other:+.3f}")
print("  <- 同一个候选、同一批对手，只换 judge 家族：胜率差就是自我偏好的下界估计")
print("     所以'用被测模型给自己打分'是无效协议")

# 4. 方差分解：偏差、题目异质性、随机噪声各占多少
# ============================================================
def var_components(groups, iters=200, seed=5):
    # 单向随机效应模型的矩估计（ANOVA 风格）
    k = len(groups)
    ns = [len(g) for g in groups]
    means = [statistics.mean(g) for g in groups]
    grand = sum(m * n for m, n in zip(means, ns)) / sum(ns)
    ss_between = sum(n * (m - grand) ** 2 for m, n in zip(means, ns))
    ss_within = sum(sum((x - m) ** 2 for x in g) for g, m in zip(groups, means))
    df_b, df_w = k - 1, sum(ns) - k
    ms_b, ms_w = ss_between / df_b, ss_within / df_w
    n0 = (sum(ns) - sum(n * n for n in ns) / sum(ns)) / (k - 1)
    var_between = max(0.0, (ms_b - ms_w) / n0)
    return var_between, ms_w


r = random.Random(13)
# 40 道题、每题 5 次 judge 重复：题目间方差大、题内噪声也大
groups = []
for i in range(40):
    item_effect = r.gauss(0, 0.30)          # 题目难度（真实差异）
    groups.append([item_effect + r.gauss(0, 0.25) for _ in range(5)])
var_b, var_w = var_components(groups)
print("\n== 4. 方差分解（合成） ==")
print(f"题目间方差 = {var_b:.4f}，题内（judge 重复）方差 = {var_w:.4f}")
print(f"题目因素占 {var_b/(var_b+var_w):.1%}，judge 噪声占 {var_w/(var_b+var_w):.1%}")
print(f"单次 judge 的测量信度 = {var_b/(var_b+var_w):.3f}")
print("  <- 信度低时，单次 judge 的分数里有很大一部分不是模型差异")
print("     取 5 次平均可把噪声方差降到 1/5，信度升到 "
      f"{var_b/(var_b+var_w/5):.3f}")

代码里四个值得注意的点：

  • 第 1 段给出位置偏差的完整测量：翻转率（含 Wilson 区间）+ 两种顺序下的胜率差。注意只跑一种顺序时的胜率与真实质量的对应关系是断的——这正是"同一份数据换个顺序就换结论"的原因。工程做法是强制双顺序，按"两次一致算胜、不一致算 0.5 或转人工"聚合（第 2 节细讲）。
  • 第 2 段的关键是"朴素指标骗人"：更长的一侧胜率 这个数把质量效应与长度效应混在一起。只有把 Δq 放进回归，βL​ 才可解释——合成数据的真实生成过程是 logit=1.00Δq+0.004ΔL，拟合能把它还原出来（注意标准化后才收敛：原始量纲的特征相差三个数量级时，不标准化会让梯度下降几乎不收敛，这也是很多人"跑出来系数离谱"的真实原因）。解读方式是把长度差换算成质量标准差：120 token 的长度差约等于 0.5 个质量标准差——当两个模型的输出平均长度差 30% 时，这个量级足以主导结论。
  • 第 3 段的差分设计是最干净的自我偏好测量：同一个候选、同一批对手，只换 judge 家族，胜率差就是偏差的下界。注意这只是下界，因为两个家族的 judge 在其他方面（能力、位置偏差）也不同，那些差异会与自我偏好混在一起。严格测量需要交叉设计 + 能力匹配。
  • 第 4 段是判断"要不要多跑几次"的依据：如果题目间方差只占 55%，那么单次 judge 的分数里 45% 是噪声。取 5 次平均能把噪声降到 1/5，信度升到约 0.85。先做这个分解，再决定重复次数，比盲目"多跑几次取多数"有效得多。

小结#

  • 偏差与随机误差必须分开：δ^=δ+b(特征)+ε。偏差不随样本量下降，加样本只会更精确地错。诊断的第一步永远是测偏差（配对/交换/置换设计），不是加样本。
  • 五类偏差及方向：位置（偏先出现，翻转率 10%~35%）、长度（偏长）、自我偏好（偏自身家族）、格式（偏结构化/礼貌）、评分尺度（向中间收缩、非线性）。前四类都有可测的效应量。
  • 统一的可估计形式是 logitPr(胜)=α+βq​Δq+βL​ΔL+βS​z+βF​Δs+uitem​+vbatch​。βq​ 是敏感度（应显著为正），βL​,βS​,βF​ 是偏差参数（理想为 0）。批次效应 v 会吞掉版本漂移造成的差异，是隐形杀手。
  • 朴素指标会骗人："更长的一侧胜率"把质量与长度混在一起；必须用回归控制或置换实验做因果识别。
  • 缓解手段各有边界：顺序交换只消位置偏差；长度控制只消长度偏差（统计层面）；多 judge 集成把不同方向的偏差平均而非消除；"只保留一致样本"会引入选择偏差并损失样本量。所有缓解都要在报告里写明。
  • 最小验收流程（一天内可完成）：位置交换 → 格式置换 → 长度回归 → 批次一致性。自我偏好差分与人工校准成本更高，但决定"用哪个 judge"。
