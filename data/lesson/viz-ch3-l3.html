饼图与密度图#

这一课学习两种用途迥异的图：饼图展示各部分占比，密度图展示连续分布的光滑形状。学完后，你对"分布与构成"这类问题就有了一套完整工具。

一、概念讲解#

1. 饼图：展示构成比例#

饼图把一个整体切成若干扇形，每个扇形的角度与该部分所占比例成正比，适合回答"各组成部分占多少"。

基础用法 ax.pie(x)，其中 x 是各部分数值（会自动归一化成占比）。常用参数：

参数 含义
labels 各部分名称
autopct 在扇形上标注百分比的格式，如 "%.1f%%"
explode 让某些扇形向外偏移突出，长度与扇区一一对应
startangle 起始角度（逆时针）
colors 各扇区颜色

使用建议：饼图的类别不宜过多（一般不超过 5~6 类），否则扇区过密难以阅读；类别太多时，柱状图往往是更好的选择。饼图不适合精确比较大小，更多用于直观感受"占比"。

2. 密度图：分布的光滑轮廓#

直方图的形状受分箱数量影响较大，而密度图（核密度估计，KDE）用光滑曲线刻画分布，不受分箱影响。其核心思想：在样本中的每个点上放一个"小凸包"（核函数，常用高斯核），把所有点的贡献叠加并归一化，就得到一条光滑的密度曲线。

不需要额外的库，用 NumPy 就能手写一个高斯核密度估计——这正是我们把 NumPy 知识用到可视化上的好例子。

3. 一个画布放两张图#

本课示例用 plt.subplots(1, 2) 在同一行并排放两个 Axes，分别画饼图和密度图，复习第一章学的 Figure/Axes 结构。

二、可运行代码示例#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False

# ---------- 左图：饼图 ----------
labels = ["Python", "Java", "JavaScript", "其他"]
sizes = [45, 28, 18, 9]
explode = (0.05, 0, 0, 0)   # 只让第一个扇区略向外突出

fig, axes = plt.subplots(1, 2, figsize=(12, 5))

axes[0].pie(sizes, labels=labels, explode=explode,
            autopct="%.1f%%", startangle=90,
            colors=["#4c72b0", "#dd8452", "#55a868", "#c44e52"])
axes[0].set_title("饼图：编程语言使用占比")

# ---------- 右图：密度图（手写高斯核 KDE） ----------
rng = np.random.default_rng(3)
sample = np.concatenate([rng.normal(0, 1, 300), rng.normal(3, 1.2, 200)])

def gaussian_kde(sample, xs, bandwidth):
    # 对每个 xs 位置，累加所有样本点的高斯核贡献
    diff = (xs[:, None] - sample[None, :]) / bandwidth
    density = np.exp(-0.5 * diff ** 2).sum(axis=1)
    return density / (len(sample) * bandwidth * np.sqrt(2 * np.pi))

xs = np.linspace(sample.min() - 1, sample.max() + 1, 300)
density = gaussian_kde(sample, xs, bandwidth=0.5)

axes[1].plot(xs, density, color="#55a868", linewidth=2, label="核密度估计")
axes[1].fill_between(xs, density, alpha=0.25, color="#55a868")
axes[1].set_xlabel("取值")
axes[1].set_ylabel("密度")
axes[1].set_title("密度图：双峰分布")
axes[1].legend()

fig.tight_layout()   # 自动调整子图间距，避免标签重叠
plt.show()

观察：右图出现两个"峰"，对应样本中两个均值不同的正态分布叠加；这就是双峰分布，用直方图也能隐约看出，但密度曲线更直观。

三、练习#

  1. 把饼图示例的 autopct 改为 "%d%%"，观察显示格式变化，并解释 %.1f%% 中 %% 的作用。
  2. 给饼图加一个数值为 0 的类别（如 ["Rust"] 且 sizes 追加 0），观察该扇区的显示。
  3. 把密度图示例中的 bandwidth 分别改成 0.2 和 1.5，对比曲线光滑程度，说明带宽对密度估计的影响。
