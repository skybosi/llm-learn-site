数组属性与重塑#

掌握了形状和 dtype 之后，本课进一步深入 ndarray 的属性，以及重塑（reshape）相关操作。在数据科学流程里，重塑无处不在：把一维的标签列转成二维、把图像展平喂给模型、把一批数据从 (n, d) 转成 (n, d, 1) 等。理解"哪些操作产生视图、哪些产生拷贝"，能帮我们写出更高效、更不容易出 bug 的代码。

一、概念讲解#

1. 常用属性一览#

属性 含义
shape 形状元组
ndim 维度数
size 元素总个数
itemsize 每个元素的字节数
nbytes 数组占用的总字节数（= size * itemsize）
dtype 数据类型
T 转置（二维矩阵的行列互换）

2. 重塑 reshape#

reshape(new_shape) 在不改变元素总数和元素逻辑顺序的前提下，把数组重新排布成新形状。数据是按"行优先（C 顺序）"展开的——即先把第一行的元素依次排完，再排第二行，以此类推。

  • 新形状各维长度的乘积必须等于 size，否则报错；
  • 可以用 -1 让 NumPy 自动推断那一维的长度；
  • 关键点：reshape 在内存布局允许时返回的是原数组的视图（view）——视图和原数组共享同一块数据，修改其中一个会影响另一个；只有在无法共享内存时才会产生拷贝。

3. 展平：ravel 与 flatten#

  • ravel()：把多维数组展平成一维，尽可能返回视图；
  • flatten()：同样展平成一维，但总是返回拷贝。

两者的区别在于是否与原数组共享内存：ravel 更省内存，flatten 更安全（改它不影响原数组）。

4. 转置与轴交换#

对二维数组，.T 返回转置；对更高维数组，用 transpose(axes) 按指定顺序交换轴。

二、可运行代码示例#

示例 1：属性总览#

import numpy as np

a = np.arange(12).reshape(3, 4)  # 0~11 排成 3 行 4 列
print("a:\n", a)

print("shape:", a.shape)       # (3, 4)
print("ndim:", a.ndim)         # 2
print("size:", a.size)         # 12
print("itemsize:", a.itemsize) # 8（int64）
print("nbytes:", a.nbytes)     # 96
print("dtype:", a.dtype)
print("T:\n", a.T)             # 转置 4 行 3 列

示例 2：reshape 与 -1 自动推断#

import numpy as np

x = np.arange(24)              # 一维 0~23
print("1D:", x.shape)

m1 = x.reshape(4, 6)           # 4 行 6 列
m2 = x.reshape(2, 3, 4)        # 三维：2 x 3 x 4
m3 = x.reshape(4, -1)          # -1 让 NumPy 推断为 6

print("reshape(4, 6):\n", m1)
print("reshape(2, 3, 4):\n", m2)
print("reshape(4, -1) shape:", m3.shape)  # (4, 6)

# reshape 返回的是视图：修改 m1 会影响 x
m1[0, 0] = 999
print("x[0] after modifying view:", x[0])  # 第一个元素变成了 999

示例 3：ravel 与 flatten 的区别#

import numpy as np

a = np.arange(6).reshape(2, 3)
print("a:\n", a)

r = a.ravel()    # 视图
f = a.flatten()  # 拷贝

r[0] = 100       # 改 r 会影响 a
f[1] = 200       # 改 f 不影响 a

print("after modifying ravel and flatten:")
print("a:\n", a)          # a[0,0] 变成了 100
print("r:", r)
print("f:", f)

示例 4：数据科学中的形状调整#

import numpy as np

# 把一维的预测值（3 个样本）转成列向量 (3, 1)，便于后续矩阵运算
y = np.array([1.0, 0.0, 1.0])
y_col = y.reshape(-1, 1)
print("y shape:", y.shape, "-> y_col shape:", y_col.shape)
print("y_col:\n", y_col)

# 把一批图像展平成特征向量：假设 2 张 3x3 灰度图
images = np.arange(18).reshape(2, 3, 3)
flattened = images.reshape(2, -1)   # 每张图展平成 9 维
print("images shape:", images.shape)
print("flattened shape:", flattened.shape)
