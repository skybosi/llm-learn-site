参数管理#

模型定义好了，接下来要面对"参数"这一整套生命周期：它们是什么、如何初始化、如何交给优化器、如何冻结一部分、如何保存与加载。这些是真正把模型从"能定义"推进到"能训练、能复用"的关键。本课把这些操作串成一条线。

一、概念讲解#

1. nn.Parameter：被"登记"的张量#

模型里可学习的量（权重、偏置）都是 nn.Parameter，它本质是一个特殊的 Tensor，但有两点不同：

  • 创建时默认 requires_grad=True；
  • 被赋值给某个 nn.Module 的属性后，会被自动登记进该模块的参数集合。

所以 nn.Linear 内部做的，就是把 weight、bias 两个 nn.Parameter 登记起来，model.parameters() 才能把它们一网打尽。反过来，如果你随便用一个普通 torch.tensor 存参数，它不会被优化器"看见"。图 3-3 画出参数从登记到被优化器消费的路径。

2. 参数初始化#

nn.Linear 等内置层有默认初始化（如 Linear 用 kaiming uniform 初始化权重、均匀分布初始化偏置）。但很多场景需要自定义，常见做法是遍历参数、用 nn.init 里的函数原地修改：

  • nn.init.xavier_uniform_(p)、nn.init.kaiming_normal_(p)、nn.init.zeros_(p) 等。

注意这些函数带 _ 后缀，是原地修改传入的 nn.Parameter，不需要返回值。

3. 冻结与局部更新#

迁移学习里常要"冻结"预训练部分、只训练新加的头。冻结 = 把参数的 requires_grad 设为 False：

  • 单个参数：param.requires_grad = False；
  • 传优化器时只传要更新的参数：optimizer = torch.optim.SGD(filter(lambda p: p.requires_grad, model.parameters()), lr=...)。

被冻结的参数不再计算梯度、不被更新，既省显存又加快反向。

4. 优化器：参数更新的执行者#

优化器不关心模型结构，只关心"给我哪些参数 + 学习率"。torch.optim.SGD(model.parameters(), lr=0.01) 拿到参数列表后，在训练循环里配合 loss.backward() 与 optimizer.step() 完成一次更新。上一章讲的"梯度清零"在这里对应 optimizer.zero_grad()。

5. state_dict：保存与加载#

model.state_dict() 返回"参数名 → 张量"的有序字典，torch.save(model.state_dict(), path) 保存，model.load_state_dict(torch.load(path)) 加载。推荐保存 state_dict 而不是整个模型对象——它更小、更灵活、跨代码版本更稳。

二、可运行代码示例#

import torch
import torch.nn as nn
import torch.nn.init as init

# ---- 1. 参数的类型与登记 ----
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(4, 2)
        self.extra = nn.Parameter(torch.zeros(3))   # 自定义参数也会被登记

net = Net()
for name, p in net.named_parameters():
    is_param = isinstance(p, nn.Parameter)
    print(f"{name:12s} 形状={str(p.shape):12s} requires_grad={p.requires_grad}")

# ---- 2. 自定义初始化 ----
def init_weights(m):
    if isinstance(m, nn.Linear):
        init.xavier_uniform_(m.weight)   # 原地修改权重
        init.zeros_(m.bias)              # 偏置置零

net.apply(init_weights)                  # 递归应用到所有子模块
print("\n初始化后 fc.bias =", net.fc.bias)

# ---- 3. 冻结部分参数 ----
net.fc.weight.requires_grad = False      # 冻结权重，只留 bias 可训练
trainable = [p for p in net.parameters() if p.requires_grad]
print("\n可训练参数数量:", len(trainable))

# ---- 4. 优化器只更新可训练参数 ----
optimizer = torch.optim.SGD(
    filter(lambda p: p.requires_grad, net.parameters()), lr=0.01
)
print("优化器管理的参数组数量:", len(optimizer.param_groups[0]['params']))

# ---- 5. 一次迷你训练步 ----
x = torch.randn(2, 4)
target = torch.randn(2, 2)
optimizer.zero_grad()                    # 清零上一轮梯度
loss = ((net(x) - target) ** 2).sum()    # MSE 损失
loss.backward()                          # 反向求梯度
optimizer.step()                         # 用梯度更新参数
print("\n一次更新后 fc.bias =", net.fc.bias)

# ---- 6. 保存与加载 ----
torch.save(net.state_dict(), "net_state.pt")
loaded = Net()
loaded.load_state_dict(torch.load("net_state.pt"))
print("\n加载后 loaded.fc.weight 等于 net.fc.weight：",
      torch.equal(loaded.fc.weight, net.fc.weight))

运行要点：net.extra（自定义 nn.Parameter）出现在 named_parameters() 里；冻结 fc.weight 后，优化器参数组里不再包含它；保存的 .pt 文件用 load_state_dict 可完整还原。

三、练习#

  1. 定义一个含 nn.Linear(10, 5) 的模块，用 named_parameters() 打印每个参数的名字、形状、requires_grad，并指出哪个是权重、哪个是偏置。
  2. 写一个 init_weights，对 Linear 层用 kaiming_normal_ 初始化权重、用 ones_ 初始化偏置，通过 apply 应用到模型上，验证结果。
  3. 冻结模型第一层、只训练第二层：把 fc1 的所有参数 requires_grad 设为 False，构建一个只包含可训练参数的 SGD 优化器，打印它实际管理的参数名。
  4. 把上面的模型训练一步后保存 state_dict，新建一个同结构模型加载，用 torch.equal 逐参数核对是否完全一致。思考：为什么推荐保存 state_dict 而不是 torch.save(model) 整个对象？
