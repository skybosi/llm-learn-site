项目二：数据统计脚本#

现实中我们经常要处理一堆数据：比如一份学生成绩表，想知道平均分是多少、谁最高、分数都集中在哪个区间。第二个项目就来做这样一个数据统计脚本：读取 CSV 数据，算出各种统计指标，并输出一份清晰的小报告。

一、概念讲解#

1. 需求分析#

假设我们有一份成绩单 CSV 文件，内容如下：

姓名,语文,数学,英语
小明,88,92,85
小红,95,88,91
小刚,76,84,80
小丽,91,90,93

我们要做的统计包括：

  1. 每位学生的总分和平均分；
  2. 全班的各科平均分；
  3. 找出总分最高的学生；
  4. 统计每科不及格（低于 60） 的人数。

2. 设计思路#

  • 读数据：用 csv.DictReader 把 CSV 读成"每行一个字典"，键是表头；
  • 遍历计算：对每位学生累加各科成绩，算总分和平均分；
  • 汇总统计：用字典保存"各科总成绩 / 人数"，最后求平均；用变量追踪最高分学生；用 Counter 或普通计数统计不及格人数；
  • 输出报告：用格式化的 print 打印结果，也可以用 f-string 让数字对齐、保留小数。

3. 用到的知识点#

这一课会把前面学过的多个知识点组合起来：csv 读表格、collections.Counter 计数、循环与累加求平均、f-string 格式化输出、异常处理保证文件不存在时友好退出。

二、可运行代码示例#

import csv
import os
from collections import Counter

FILENAME = "scores.csv"


def load_scores(filename):
    """读取 CSV，返回行列表（每行是一个字典）。"""
    rows = []
    with open(filename, "r", newline="", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        for row in reader:
            rows.append(row)
    return rows


def analyze(rows):
    """对读取到的成绩数据做统计，返回一份报告。"""
    subjects = ["语文", "数学", "英语"]

    # 各科累计总分，用于求平均
    subject_total = {s: 0 for s in subjects}
    # 各科不及格人数
    subject_fail = Counter()
    # 记录总分最高的学生
    best_name, best_total = "", -1

    # 每个人的总分和平均分
    student_lines = []

    for row in rows:
        name = row["姓名"]
        total = 0
        for s in subjects:
            score = int(row[s])          # CSV 读出来是字符串，转成整数
            total += score
            subject_total[s] += score
            if score < 60:
                subject_fail[s] += 1

        avg = total / len(subjects)
        student_lines.append(f"{name}: 总分 {total}，平均 {avg:.1f}")

        if total > best_total:
            best_name, best_total = name, total

    return {
        "student_lines": student_lines,
        "subject_total": subject_total,
        "subject_fail": subject_fail,
        "best_name": best_name,
        "best_total": best_total,
        "count": len(rows),
    }


def main():
    if not os.path.exists(FILENAME):
        print("找不到数据文件：", FILENAME)
        return

    rows = load_scores(FILENAME)
    result = analyze(rows)

    print("===== 成绩统计报告 =====")
    print(f"共 {result['count']} 名学生\n")

    print("【每位学生】")
    for line in result["student_lines"]:
        print("  " + line)

    print("\n【各科平均分】")
    for s, total in result["subject_total"].items():
        print(f"  {s}: {total / result['count']:.1f}")

    print("\n【各科不及格人数】")
    for s in result["subject_fail"]:
        print(f"  {s}: {result['subject_fail'][s]} 人")

    print(f"\n【总分最高】{result['best_name']}，总分 {result['best_total']}")


if __name__ == "__main__":
    main()
