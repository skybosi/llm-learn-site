聚合与更新函数#

消息传递框架里，"消息"通常就是邻居特征的线性变换，真正的设计自由度集中在另外两个地方：聚合函数（怎么合并邻居消息）和更新函数（怎么用消息刷新自己）。选 sum 还是 mean？要不要加自环？更新用 MLP 还是残差？这些看似琐碎的选择，直接决定了 GNN 的表达能力和训练稳定性。这一课逐个拆解，并引入图神经网络里最著名的理论结论之一——GIN 与图同构判别。

一、概念讲解#

1. 三种聚合函数：sum、mean、max#

假设节点 v 收集到一组邻居消息（一个多重集，允许重复）。三种最常用的聚合：

  • 求和（sum）：把消息加起来。它能反映邻居的数量和总强度——度数高、邻居多的节点，聚合值天然更大。
  • 平均（mean）：把消息除以邻居个数。它丢掉了"邻居有多少"这个信息，但对度数差异大的节点更公平，数值也更稳定。
  • 取最大（max）：只保留每一维的最大值。它最"粗"，只关心"最强邻居"，完全忽略数量。

三者各有取舍，不存在绝对最优。但有一个关键差别：sum 是唯一能严格区分"邻居多重集"里元素重数的聚合。考虑邻居特征值 {2} 和 {2, 2}（一个邻居值是 2，对比两个邻居都是 2）：mean 都得到 2，max 也都得到 2，只有 sum 得到 2 和 4——只有 sum 能看出"来了几个邻居"。

2. 表达能力：GIN 与图同构#

这个"能不能区分多重集"的差别，正是 Xu 等人《How Powerful are Graph Neural Networks?》论文的核心洞见。他们证明：一个 GNN 的表达能力上限，不会超过 Weisfeiler-Lehman（WL）图同构判别测试，而能达到这个上限的充要条件是——聚合用求和、更新用一个单射（injective）函数。

于是他们提出了 GIN（Graph Isomorphism Network），其更新公式为：

h_v^{(k)} = MLP^{(k)}( (1 + ε^{(k)}) · h_v^{(k−1)} + Σ_{u∈N(v)} h_u^{(k−1)} )

其中 ε 是可学习（或固定为 0）的标量，MLP 是多层感知机。和 GCN 对比，GIN 的关键区别在于：聚合用"自身 + 邻居之和"（求和），而不是归一化平均。这是为了保留多重集信息、逼近 WL 测试的判别能力。理解 GIN，你就理解了"为什么聚合函数的选择不是细节，而是表达能力的根本"。

3. 自环与自身信息#

聚合时要不要把节点自己的表示也算进去？两种做法：

  • 显式自环：在邻接矩阵上加单位阵（A + I），让 v 成为自己的邻居，聚合时自然带上 h_v。GCN 的标准做法就是"加自环 + 对称归一化"。
  • 更新函数里保留自身：聚合只针对邻居，但更新函数把 h_v^(k−1) 显式地加回来（如上面的 GIN 的 (1+ε)·h_v，或残差连接 h_v + m_v）。

无论如何，节点必须保留一部分自身信息，否则层层聚合后自己就"消失"在邻居里了（第一章练习 1 就是这个现象）。

4. 更新函数：线性、MLP 与残差#

更新函数 U(h_v, m_v) 的常见选择：

  • 线性 + 激活：GCN 用的 σ(W·(自身+聚合))，简单高效；
  • 拼接 + MLP：GraphSAGE 用的 σ(W·concat(h_v, m_v))，让模型能区分"自身"和"邻居"两个来源，再交给 MLP 融合；
  • 残差（skip connection）：h_v^{(k+1)} = h_v^{(k)} + U'(h_v^{(k)}, m_v)，让上一层的信息直接跨越传递。残差能显著缓解深层 GNN 的过度平滑和梯度消失，是加深 GNN 的标配手段。

选哪种更新函数，取决于任务：浅层分类用线性就够；要逼近 WL 上限用 MLP；要堆深网络就加残差。

二、可运行代码示例#

下面用 NumPy 直接对比 sum / mean / max 三种聚合，直观验证"只有 sum 能区分邻居重数"，并实现一个简化版 GIN 层。

import numpy as np

def relu(x):
    return np.maximum(0.0, x)

# 1) 构造一个"多重集"场景：节点 v 收到两个邻居的消息
#    情形 A：两个邻居的特征都是 [2, 1]
#    情形 B：只有一个邻居，特征也是 [2, 1]
msgs_A = np.array([[2.0, 1.0], [2.0, 1.0]])   # 两个邻居，值相同
msgs_B = np.array([[2.0, 1.0]])                # 一个邻居

for name, msgs in [("情形A(两个邻居)", msgs_A), ("情形B(一个邻居)", msgs_B)]:
    print(name, "-> sum:", msgs.sum(axis=0),
          "| mean:", msgs.mean(axis=0),
          "| max:", msgs.max(axis=0))

# 结论：mean 和 max 都无法区分"一个邻居"和"两个相同邻居"，只有 sum 能区分。

# 2) 简化版 GIN 层：h_v' = MLP( (1+eps)*h_v + sum(h_u) )
def gin_layer(H, A, eps, W, b):
    """H: (n, d) 节点特征；A: (n, n) 邻接矩阵（不含自环）；W,b: MLP 一层"""
    agg = A @ H                 # 邻居求和
    z = (1 + eps) * H + agg     # 自身 + 邻居之和
    return relu(z @ W + b)

n, d = 5, 3
rng = np.random.default_rng(1)
H = rng.normal(size=(n, d))
A = np.zeros((n, n))
for u, v in [(0, 1), (1, 2), (2, 3), (3, 4), (4, 0)]:
    A[u, v] = A[v, u] = 1.0

W = rng.normal(size=(d, 4))
b = np.zeros(4)
H_out = gin_layer(H, A, eps=0.0, W=W, b=b)
print("GIN 层输出形状：", H_out.shape)   # (5, 4)
print("GIN 层输出：\n", np.round(H_out, 3))

运行后你会看到：情形 A 和情形 B 的 mean 都是 [2, 1]、max 都是 [2, 1]，只有 sum 一个是 [4, 2]、一个是 [2, 1]——这就是 sum 保多重集信息的直观体现。GIN 层则把"自身（带 ε 权重）+ 邻居求和"送进 MLP，正是论文里的核心更新式。

三、练习#

  1. 构造另一个"不可区分"的例子：邻居特征 {1, 3} 和 {1, 1, 3, 3}，分别用 sum / mean / max 计算，验证 mean 和 max 是否都无法区分这两组多重集（提示：两组 sum 分别是 4 和 8）。
  2. 把 GIN 里的 ε 从 0 改成一个可学习标量，用 PyTorch 实现并在一张图上训练节点分类，观察 ε 是否会被学成一个非零值，并讨论 ε 的作用。
  3. 实现 GraphSAGE 的更新函数 σ(W · concat(h_v, m_v))，其中 m_v 用 mean 聚合，对比它与 GCN 更新（σ(W · (h_v + m_v))）在"自身与邻居信息分离"上的差别。
  4. 思考：为什么说"sum 的表达能力 > mean ≥ max"？在什么任务里 max 聚合反而更合适（提示：考虑邻居特征里极少数强信号的场景）？
