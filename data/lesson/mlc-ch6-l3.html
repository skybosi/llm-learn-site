自动调优：AutoTVM / Ansor 的搜索与代价模型#

第 2 课说明好调度是稀有资源：720 条候选里只有 10% 值得考虑，问题于是变成"怎么找"。最朴素的办法是每条都在真机上跑一遍，但一次编译 + 计时通常要几十到几百毫秒，720 条就是几分钟到几十分钟；一个模型有几百个算子就是几十小时。自动调优的核心成果不是搜索算法，而是"用学出来的代价模型代替真机计时"——它把绝大多数候选的评估从"跑一次"降到"预测一次"。本课用一个 12 棵树的随机森林跑通这条路，并给出它相对随机搜索的实测优势。

一、概念讲解#

1. 问题形式：离散、昂贵、带噪声的黑盒优化#

自动调优（auto-tuning）要解的是：在调度空间上最小化真实执行时间 f(s)，而 f 只能通过编译 + 运行得到，一次调用昂贵、结果带测量噪声、不同 shape 还不通用。三类经典解法都不完全适用：穷举太贵，梯度法需要可微目标，纯随机搜索受制于"好区域只占 10%"。可行做法只有一个：少量真测 + 大量廉价预测。

2. AutoTVM：模板 + 参数空间 + 学出来的代价模型#

AutoTVM 走模板驱动：人先写好调度模板（如"先分块再向量化的卷积"），模板上开出参数（tile 大小、unroll 次数、向量宽度……）构成参数空间。官方博客把这个循环写得很清楚：每轮从搜索空间挑一批有希望的候选，在真机上 profile，用结果拟合预测模型，再按预测挑下一批——"真测喂模型、模型指导真测"的闭环。论文报告它在 CPU、移动 GPU、服务器 GPU 上都能让自动生成的算子接近手工调优库的量级（加速比随平台不同，以论文表格为准）。

关键分工是：模型负责便宜地排序，搜索负责决定下一个测谁，真测负责把模型拉回现实。

3. Ansor：不写模板，先枚举结构再精调#

模板路线的天花板来自模板本身——模板里没写的实现搜不到。Ansor 改成两段式：先从层次化表示里采样大量 sketch（粗略循环结构，如次序与并行方式），再对每个 sketch 施加 annotation（tile、向量化、unroll 等），用进化搜索精调并用学出来的代价模型筛选。论文摘要的量级是相对当时最优方案最多 3.8× / 2.6× / 1.7×（Intel CPU / ARM CPU / NVIDIA GPU，以论文为准）；它还用任务调度器让多个子图并行调优。

两段式带来最重要的认识：搜索空间的形状比搜索算法本身更决定上限——模板法在被给定的空间里优化，Ansor 把结构也纳入搜索。

4. 代价模型长什么样：特征 → 时间#

代价模型的输入是编译期可得的特征（tile 大小、循环次序、展开次数、向量宽度，以及从 IR 抽出的访存量、算术强度、并行度），输出是预测时间。三条关键做法：

  1. 只要排序、不要精度：模型只需把候选排对顺序，不必预测到毫秒级。
  2. 样本必须带噪声：代码给真测值乘了 3% 扰动，逼模型学趋势而不是背样本；第 4 课量化噪声的代价。
  3. 留验证集：预测永远要真测校验，第 3 节只对模型排出的前 5 条真测。

5. 常见坑#

  • 把模型当 oracle：它预测的是相关性不是真值，真实系统都保留"最后若干条真测"。
  • 训练集覆盖不到最优区域：30 条样本全落在小 tile 上时，模型对"大 tile 更好"一无所知。
  • 同一批数据既训练又调参：会系统性高估模型质量，验证集必须独立。
  • 忽略编译与运行的比值：若编译远贵于运行，代价模型应拟合"编译+运行"总时间，而不是只看 kernel 时间。

二、可运行代码示例#

# ---- 第 3 课：学习型代价模型 + 搜索（纯 Python，无第三方依赖）----
import itertools, random

TILES = [(1, 1, 1), (8, 8, 1), (16, 16, 1), (32, 32, 1), (64, 64, 1), (128, 64, 8)]
ORDERS = [('i', 'j', 'k'), ('j', 'i', 'k')]
VECS = [1, 4]
UNROLLS = [1, 4, 8]
FIELDS = ['ti', 'tj', 'tk', 'is_ijk', 'vec', 'par_ij', 'unroll', 'tile_area']


def space():
    for t, o, v, u in itertools.product(TILES, ORDERS, VECS, UNROLLS):
        yield dict(tiles=t, order=o, vec=v, unroll=u, parallel=('i', 'j'))


def true_cost(s):
    """本课用解析模型扮演"真机"：调优程序只能通过 measure() 看它（带测量噪声）。"""
    area = s['tiles'][0] * s['tiles'][1]
    e = 1.0 + 2.0 * abs(area - 4096) / 4096 + 0.8 * abs(s['unroll'] - 4) / 4
    e += 0.2 if s['order'][0] != 'i' else 0.0
    return e * (1.0 + 0.15 * (1 if s['vec'] == 1 else 0))


def features(s):
    """代价模型的输入：把一条调度写成 8 维向量（真实系统里还会有更多结构特征）。"""
    ti, tj, tk = s['tiles']
    return [ti, tj, tk, 1.0 if s['order'][0] == 'i' else 0.0,
            s['vec'], 1.0 if s['parallel'] == ('i', 'j') else 0.0, s['unroll'], ti * tj]


# ---------- 极简回归树 + 随机森林：能学出"哪片区域便宜"就够用 ----------
def build_tree(rows, depth=0, max_depth=5, min_leaf=4):
    y = [r[1] for r in rows]
    if depth >= max_depth or len(rows) < 2 * min_leaf or max(y) - min(y) < 1e-12:
        return ('leaf', sum(y) / len(y))
    best = None
    for f in range(len(rows[0][0])):
        vals = sorted({r[0][f] for r in rows})
        for th in [(a + b) / 2 for a, b in zip(vals, vals[1:])]:
            L = [r for r in rows if r[0][f] <= th]
            R = [r for r in rows if r[0][f] > th]
            if len(L) < min_leaf or len(R) < min_leaf:
                continue
            def sse(rs):
                m = sum(r[1] for r in rs) / len(rs)
                return sum((r[1] - m) ** 2 for r in rs)
            err = sse(L) + sse(R)
            if best is None or err < best[0]:
                best = (err, f, th, L, R)
    if best is None:
        return ('leaf', sum(y) / len(y))
    _, f, th, L, R = best
    return ('node', f, th, build_tree(L, depth + 1, max_depth, min_leaf),
            build_tree(R, depth + 1, max_depth, min_leaf))


def predict(tree, x):
    while tree[0] == 'node':
        _, f, th, L, R = tree
        tree = L if x[f] <= th else R
    return tree[1]


class Forest:
    def __init__(self, n_trees=12, max_depth=6, seed=0):
        self.n_trees, self.max_depth, self.seed, self.trees = n_trees, max_depth, seed, []

    def fit(self, xs, ys):
        rng = random.Random(self.seed)
        for _ in range(self.n_trees):
            idx = [rng.randrange(len(xs)) for _ in xs]          # bootstrap 采样
            self.trees.append(build_tree([(xs[i], ys[i]) for i in idx], max_depth=self.max_depth))
        return self

    def predict(self, x):
        return sum(predict(t, x) for t in self.trees) / len(self.trees)


if __name__ == '__main__':
    pool = list(space())
    oracle = min(true_cost(s) for s in pool)
    print(f'=== 1. 全空间 {len(pool)} 条；真值最优 {oracle:.4f}（只有解析模型知道它）===')

    rng = random.Random(11)
    sample = rng.sample(range(len(pool)), 30)
    best_rand = min(true_cost(pool[i]) for i in sample)
    print(f'\n=== 2. 随机搜索：抽 30 条真测，最好 {best_rand:.4f}（最优的 {best_rand / oracle:.2f} 倍）===')
    print('  随机搜索的问题不是"测不起"，而是"好区域太小，抽不到"')

    xs = [features(pool[i]) for i in sample]
    ys = [true_cost(pool[i]) * (1.0 + rng.gauss(0, 0.03)) for i in sample]   # 实测带噪
    forest = Forest(n_trees=12, max_depth=6, seed=1).fit(xs, ys)
    rest = [i for i in range(len(pool)) if i not in sample]
    pred = {i: forest.predict(features(pool[i])) for i in rest}
    ranked = sorted(rest, key=lambda i: pred[i])
    checked = ranked[:5]
    best_model = min(true_cost(pool[i]) for i in checked)
    print(f'\n=== 3. 学习型代价模型：同一批 30 条实测做训练，给其余 {len(rest)} 条排序，只挑前 5 条真测 ===')
    for rank, i in enumerate(checked, 1):
        s = pool[i]
        print(f'  第{rank}候选 预测={pred[i]:5.3f} 真值={true_cost(s):5.3f} '
              f'tile={str(s["tiles"]):<12} vec={s["vec"]} unroll={s["unroll"]}')
    print(f'  代价模型挑出的最好一条 = {best_model:.4f}（最优的 {best_model / oracle:.2f} 倍）')

    print('\n=== 4. 谁更划算：20 次独立比较，各自用了多少次"真测" ===')
    wins_r = wins_m = 0
    for trial in range(20):
        r2 = random.Random(900 + trial)
        idx = r2.sample(range(len(pool)), 30)
        if min(true_cost(pool[i]) for i in idx) <= oracle * 1.02:
            wins_r += 1
        xs2 = [features(pool[i]) for i in idx]
        ys2 = [true_cost(pool[i]) * (1.0 + r2.gauss(0, 0.03)) for i in idx]
        f2 = Forest(n_trees=12, max_depth=6, seed=trial).fit(xs2, ys2)
        rest2 = [i for i in range(len(pool)) if i not in idx]
        top = sorted(rest2, key=lambda i: f2.predict(features(pool[i])))[:5]
        if min(true_cost(pool[i]) for i in top) <= oracle * 1.02:
            wins_m += 1
    print(f'  随机搜索 30 条真测：{wins_r}/20 次落在最优 2% 以内（真测 30 次）')
    print(f'  代价模型 30 条训练 + 5 条验证：{wins_m}/20 次（真测 35 次）')
    print('  差异的根源：模型把"tile 面积、unroll"这些结构特征用上了，'
          '把预算花在预测值最好的那几条上')

    print('\n=== 5. 预测质量：模型认为的前 25% 里有多少真属于前 25% ===')
    n = len(rest)
    truth_rank = {i: r for r, i in enumerate(sorted(rest, key=lambda i: true_cost(pool[i])))}
    top_q = ranked[:n // 4]
    hit = sum(1 for i in top_q if truth_rank[i] < n // 4)
    print(f'  前 25%（{len(top_q)} 条）命中 {hit} 条；随机瞎猜的期望命中率是 25%')

运行结果（Python 3.10.14，无第三方依赖）：

=== 1. 全空间 72 条；真值最优 1.0000（只有解析模型知道它）===

=== 2. 随机搜索：抽 30 条真测，最好 1.1500（最优的 1.15 倍）===
  随机搜索的问题不是"测不起"，而是"好区域太小，抽不到"

=== 3. 学习型代价模型：同一批 30 条实测做训练，给其余 42 条排序，只挑前 5 条真测 ===
  第1候选 预测=2.001 真值=1.000 tile=(64, 64, 1)  vec=4 unroll=4
  第2候选 预测=2.090 真值=1.200 tile=(64, 64, 1)  vec=4 unroll=4
  第3候选 预测=2.291 真值=1.800 tile=(64, 64, 1)  vec=4 unroll=8
  第4候选 预测=2.427 真值=1.380 tile=(64, 64, 1)  vec=1 unroll=4
  第5候选 预测=2.432 真值=2.070 tile=(64, 64, 1)  vec=1 unroll=8
  代价模型挑出的最好一条 = 1.0000（最优的 1.00 倍）

=== 4. 谁更划算：20 次独立比较，各自用了多少次"真测" ===
  随机搜索 30 条真测：7/20 次落在最优 2% 以内（真测 30 次）
  代价模型 30 条训练 + 5 条验证：12/20 次（真测 35 次）
  差异的根源：模型把"tile 面积、unroll"这些结构特征用上了，把预算花在预测值最好的那几条上

=== 5. 预测质量：模型认为的前 25% 里有多少真属于前 25% ===
  前 25%（10 条）命中 8 条；随机瞎猜的期望命中率是 25%

可核对的结论：随机搜索受限于覆盖率（20 次独立比较只有 7 次落在最优 2% 以内）；同一批 30 条真测喂给模型后升到 12/20（真测 35 次，只多 5 次）；模型认为的前 25% 里 8 条真属于前 25%；模型最看好的一条恰是真正最优（第 1 候选：预测 2.001、真值 1.000）。

三、练习#

  1. 实现：给 features() 增加两个特征：tiles[2]（归约维 tile）与"tile 面积是否超过 L2 容量"的布尔量，用同一批 30 条样本重训，看第 5 节命中率是否变化，并说明哪个特征真正贡献了信息。
  2. 解释：为什么本课给训练标签乘了 3% 的噪声（rng.gauss(0, 0.03)）而不是用干净的真值？如果把噪声调到 0，模型在"同一档 72 条差别极小"的情形下会有什么行为变化？
  3. 对比/验证：把 n_trees 从 12 改成 1（单棵回归树）与 48，重跑第 4 节的 20 次比较并记录命中次数，讨论"模型复杂度—样本量"的匹配。
  4. 思考：代价模型的训练数据来自真测；若模型有系统偏差（例如系统性高估大 tile），进化搜索会朝哪边漂移？这算搜索问题还是数据问题？
