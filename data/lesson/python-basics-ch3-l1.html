条件判断 if/elif/else#

程序不能只会"一条路走到黑"。本节课学习用 if 语句，让程序根据不同的情况做出不同的选择。

一、概念讲解#

现实生活里，我们每天都在做判断：如果下雨就带伞，否则就不带。写程序也一样，我们希望代码能够"看情况办事"。在 Python 里，做判断靠的是 if 语句。

1. 判断的依据：布尔值#

if 后面跟着一个"条件"，这个条件最终会算出一个布尔值（True 或 False）。前面学过的大于 >、小于 <、等于 == 等比较运算，得到的结果都是布尔值：

print(3 > 2)    # True
print(1 == 2)   # False

只要表达式能算出布尔值，就能放进 if 里当条件。

2. if：只有一种选择#

if 条件:
    要执行的代码
  • if 这一行末尾要有冒号 :；
  • 冒号下面缩进的代码块，只有在"条件为真"时才会执行；
  • Python 用缩进（通常 4 个空格）来表示"哪些代码属于 if"，这是它与很多语言不同的地方。

3. if...else：二选一#

if 条件:
    条件为真时执行
else:
    条件为假时执行

else 后面不用写条件，它负责承接"前面所有情况之外"的那个分支。if 和 else 只能走一个，不会两个都执行。

4. if...elif...else：多选一#

当情况多于两种时，用 elif（可以理解为"否则如果"）来继续判断：

if 条件1:
    分支1
elif 条件2:
    分支2
else:
    都不满足时执行

程序会从上到下依次检查条件，只要命中一个分支，执行完这一支后整个 if 结构就结束了，后面的分支不会再判断。elif 可以写很多个。

5. 判断可以嵌套#

在一个 if 里面还可以再放 if，用来处理更细致的逻辑。嵌套时每一层都要正确缩进，缩进错位是最常见的报错原因之一。

二、代码示例#

下面几个例子都可以直接复制运行。

示例 1：判断奇偶#

num = int(input("请输入一个整数："))

if num % 2 == 0:            # 能被 2 整除就是偶数
    print(f"{num} 是偶数")
else:
    print(f"{num} 是奇数")

示例 2：根据分数给出等级#

score = 85

if score >= 90:
    grade = "优秀"
elif score >= 75:
    grade = "良好"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

print(f"成绩 {score} 分的等级是：{grade}")

示例 3：嵌套判断——判断闰年#

闰年的规则是：能被 4 整除但不能被 100 整除，或者能被 400 整除。

year = 2000

if year % 4 == 0:
    if year % 100 == 0:
        if year % 400 == 0:
            print(f"{year} 是闰年")
        else:
            print(f"{year} 不是闰年")
    else:
        print(f"{year} 是闰年")
else:
    print(f"{year} 不是闰年")

三、练习#

  1. 写一个程序，读入一个数字，判断它是正数、负数还是零，并打印对应的提示。
  2. 输入年龄，判断能否购买一张"18 岁以上才能观看"的电影票（提示：用 >=）。
  3. 输入用户名和密码，判断是否同时等于 "admin" 和 "123456"：是则打印"登录成功"，否则打印"用户名或密码错误"（提示：用 and 连接两个条件）。
