评测协议与陷阱：分布、种子、算力对齐与一份可执行的清单#

这一节要解决什么#

前三节把"测什么"讲完了：预测质量（第 1 节）、长时一致性（第 2 节）、规划收益（第 3 节）。但一个评测结论的可信度不只取决于测什么，还取决于怎么组织的。同一批模型、同一批指标，换一套协议就能得到相反的结论——而且每一处改动都看起来很正常。

这一节处理这件事。四类最常见的作弊路径都能在"看似规范"的外表下发生：

① 在评测环境上调参  —— "我们试了几组超参，这是最好的一组"（在 test 上挑的）
② 模型自评当结果    —— "模型内评估回报 0.47"（没有真环境复核）
③ 只报均值不报方差  —— "平均回报 0.31"（尾部可能撞墙 100%）
④ 不等算力/预算比较 —— "我们的模型更好"（一个用了 8 倍搜索预算）

这一节的交付是两样东西：

  1. 协议的五条骨架：分布分离、种子与方差、算力对齐、基线阶梯、报告坐标。每条都给出本课量出来的数字，说明不做它会差多少；
  2. 一份可执行的清单：既是给作者的检查表，也是一个能直接跑的审查函数 audit(record)——把评测记录喂进去，吐红旗。

一、协议的五条骨架#

骨架 一句话要求 不做会怎样（本课实测）
分布 分布内/分布外分开报，并列出 OOD 轴 自评 +0.1625、ID 真值 +0.0796、OOD 动力学 +0.0382 —— 一个自评数掩盖一个分布族
种子 训练种子与评测种子分开，各 ≥3 只有 1 个种子时，"差异"与"种子噪声"不可分
方差 报方差/分位数/CVaR，不只报均值 均值相同（0.00）的两条分布，CVaR10 是 0.00 与 −0.90
算力 与基线同预算；或报整条预算曲线 不给对齐时，"乐观模型更好"（−0.187>−0.282）；对齐后反转（+0.008>−0.187）
基线 报阶梯，不只报单点 "收益"无法归因（模型？搜索？数据？）

前四条这一节各用一节展开，第五条已在第 3 节展开。

二、分布内/分布外：一个自评数掩盖一个分布族#

2.1 OOD 轴必须先列出来#

"分布外"是一个方向，不是一个布尔值。世界模型至少有四条独立的 OOD 轴：

OOD 轴 例子 为什么它独立
动力学 打滑率 0.12→0.35；摩擦系数变化 观测分布可能几乎不变，条件分布变了
起点/初始状态 数据从 s0​ 采，评测从别处开始 模型在未见状态上的外推不可控
动作范围 训练动作 ∈[−1,1]，评测到 [−2,2] 接口存在，但该区间没被约束
观测/外观 光照、纹理、相机位姿变化 表征可能崩，动力学可能仍对

必须逐轴报，不能合并成一个"OOD 分数"。 因为四条轴的失败机制完全不同，修法也完全不同。

2.2 本课实测：自评不变，真值分裂#

实验 A：在分布内数据（N=200）上训练一个模型，规划出策略 π，然后测四次：

口径 数值 与自评的间隙
模型自评（只在数据分布内成立） +0.1625 ——
真环境 分布内（打滑 0.12） +0.0796 +0.0828
真环境 分布外·动力学（0.35） +0.0382 +0.1242
值误差 ∣V^−V∣：已见起点 0.3196 ——
值误差 ∣V^−V∣：未见起点 0.4758 ——

两个读数：

  1. 自评只有一个数，真环境值有一个族。 动力学漂移后真值降到 +0.0382（不到 ID 值的一半），而自评完全不动——因为模型不知道自己被搬到了新环境里。只报自评等于默认 OOD 不存在。
  2. 未见起点上的值误差大 49%（0.4758 vs 0.3196）。这与第 3 节实验三（策略诱导分布上的误差是数据分布的 6.5 倍）是同一个现象的两个版本。

2.3 怎么做#

① 评测前写出 OOD 轴的清单（至少覆盖上表四条）
② 每条轴给出 2~3 个"偏移量级"（内插 vs 外推要分开）
③ 每条轴单独报一个数，并报 ID→OOD 的下降幅度
④ 报"自评 - 真值"在每条轴上的间隙（它本身就是模型乐观度的度量）

三、种子与方差：把"差异"从噪声里拆出来#

3.1 三个方差来源#

世界模型评测至少有三个独立的随机性来源，它们的相对大小决定你该在哪里加预算：

Var(J^)≈训练种子Strain​σtrain2​​​​+评测种子Seval​σeval2​​​​+起点/回合数nep​σstart2​​​​.

  • 训练种子：换一个数据顺序/初始化，模型与策略都换。同一个训练种子下的多个评测回合不能替代训练种子——它们只降第三项。
  • 评测种子：环境随机性、采样噪声。
  • 起点分布：回合数与起点抽样。

因此"跑 20 个回合"与"跑 5 个种子 × 4 个回合"不是一回事：前者只降 σstart2​/n，后者还给你训练方差的估计。这与大语言模型评测里"题目数 vs 模板数"的分解结构完全同构（对照 llm-evaluation 第 2 章第 3 节：加到错误的方差项上等于浪费预算）。

3.2 报什么#

① 每个配置：均值 + 标准差 + 中位数 + 最差回合 + CVaR10%
② 比较两个配置：配对 bootstrap 的 95% CI（同起点、同评测种子）
③ 报"最小可检出差异" MDD ≈ 2.80·σ/√n，并说明本评测能分辨多小的差
④ 种子之间的方差要单独报（不要把它塞进回合噪声里）

3.3 "CI 跨 0"必须写"未检出"#

实验 B 演示了一个非常常见的情形：把模型策略在一个极少访问状态上的动作改掉一个（几乎不改变真实水平），然后比较：

量 数值
均值差（点估计） +0.0826
配对 bootstrap 95% CI [−0.1119, +0.2777]
单回合标准差 σ 0.3800
n=24 时的 MDD 0.2172

点估计是 +0.0826，看起来"改进了"，但 CI 跨 0，且点估计小于 MDD。正确表述是：未检出差异。工程上最常见的错误不是算错，而是在信息不足时给了确定语气——而"未检出"本身就是一个合格的交付物。

四、只报均值：尾部与均值可以给出不同结论#

4.1 一个隔离演示#

先用一个纯算术的例子把机制隔离出来（⚠️ 合成的两点分布，只为说明结构）：

分布 均值 CVaR10%
A：90% 得 +0.10，10% 得 −0.90 0.00 −0.90
B：永远得 0.00 0.00 0.00

均值完全相同，尾部差 0.9。 任何只看均值的比较都会判它们平手；而"10% 的概率灾难"正是安全关键系统最需要知道的事。

4.2 环境里的版本#

同一个表格 MDP 上的两个策略（n=24 回合）：

策略 均值 最差回合 CVaR10%
模型规划 +0.1457 −0.7527 −0.5334
行为策略 +0.5035 +0.3084 +0.3271

均值差是 0.36，而 CVaR 差是 0.86——尾部差距是均值差距的 2.4 倍。只报均值会系统性低估这个模型的风险。

4.3 怎么做#

① 报均值 + 中位数 + 最差回合 + CVaR(α)（α 写死，例如 10%）
② 安全关键任务：把"约束违反率"作为一等指标，与回报并列
③ 画回报的分布（或用分位数表），不要只给一个数
④ 当均值与 CVaR 排序不同时，两个都要报，并说明决策口径

五、算力对齐：预算可以直接制造排序#

5.1 预算是多维的#

"同样的算力"至少有四个独立的轴，必须逐轴对齐或逐轴报曲线：

预算轴 例子
训练 环境步数、梯度步数、FLOPs、墙钟时间
规划 视界 H、采样数 K、迭代数
评估 回合数、起点数、评测种子数
搜索/调参 超参组合数、checkpoint 数（= 第 3 节的选择预算）

5.2 本课实测：等预算下排序反转#

实验 C：两个模型（保守外推 / 乐观外推）训练数据相同，规划器相同（K=32 条随机射击），只改规划视界（把 H 当预算）：

模型（K=32） H=1 H=3 H=5 H=8
保守外推 −0.282 −0.050 +0.001 +0.008
乐观外推 −0.282 −0.302 −0.297 −0.187
  • 不等预算：保守@H=1 =−0.282 vs 乐观@H=8 =−0.187 ⇒ 结论"乐观模型更好"；
  • 等预算 H=8：保守 =+0.008 vs 乐观 =−0.187 ⇒ 结论相反。

这就是"算力对齐"为什么是协议问题而不是礼貌问题：多给一个模型 8 倍视界，可以翻转排序。值得注意的是，更多规划把保守模型变好（−0.282→+0.008）、把乐观模型基本变差（−0.282→−0.187）——因为乐观模型的偏差正好是规划器要利用的方向（第 2 节实验二的同一条机制）。

5.3 怎么做#

① 对齐所有四个预算轴；做不到时，报"性能 vs 预算"的整条曲线
② 报告里写出每个数字对应的预算元组 (train, plan, eval, search)
③ 基线必须与被测对象同预算；不同预算的对比要显式标注
④ 选择预算 K 单独写（第 3 节：它带来 σ√(2 ln K) 的乐观偏置）

六、四类作弊路径#

6.1 在评测环境上调参#

做法：用同一批评测数据挑配置（超参、种子、checkpoint），然后把这批数据上的最好结果当结论。

本课实测（实验 D，40 个配置、每配置 10 回合、30 次重复）：

做法 报出来的数
40 个配置的真实水平：均值 +0.4020
40 个配置的真实水平：最高（任何方法的上界） +0.4634
预注册单一配置，报 fresh test +0.3907
用 dev 挑配置，报 fresh test +0.4221
用 test 挑配置并直接报 test（作弊） +0.6824
同一配置换一批 fresh test 复核 +0.4397
——虚高 +0.2427

作弊报数 +0.6824 甚至高过"40 个配置里最好的那个真实水平" +0.4634。 这不是模型变好了，而是噪声被挑出来了（第 3 节 3.2 节的同一个命题）。

预防：预注册 + 留出集（dev/test 分离）+ 报"选择预算 K" + 最终数字只来自从未用于任何选择的那一批数据。

6.2 模型自评当结果#

做法：在模型里规划、用模型算回报，然后报告这个数。

本课实测（第 3 节实验二）：K=1 时自评间隙为负（−0.164∼−0.213），K=32 时翻正（+0.167∼+0.434）——同一批模型、同一套评估，只因为"挑最好的那一个"，间隙就差 0.65。

预防：自评只用于筛查；最终结论必须真环境复核；报自评与真值两个数及其差。

6.3 只报均值不报方差#

见第四节。预防：均值 + 方差 + 分位数 + CVaR + 约束违反率；CI 跨 0 就写"未检出"。

6.4 不等预算比较#

见第五节。预防：预算元组写进报告；基线同预算；选择预算单独列。

还有一类更隐蔽的变体值得单独点名："评测集复用"——同一批评测数据先用于模型选择、又用于超参选择、最后用于报告。它在形式上"预注册了"，实际上每一次选择都在同一批数据上发生。判据很简单：问一句"这个数字所在的数据，被用来做过任何一次决定吗？"

七、一份可执行的评测清单#

7.1 预注册（跑之前写死）#

【任务与回报】任务族、回报函数、折扣、终止条件、起点分布
【OOD 轴】至少四条：动力学 / 起点 / 动作范围 / 观测外观，每条给偏移量级
【预算元组】(train, plan, eval, search)——被测对象与所有基线逐轴对齐
【基线阶梯】random / behavior / model-free(同样本量) / model+plan / oracle
【种子】训练种子 ≥3、评测种子 ≥3、回合数 ≥30，且三类方差分别报
【指标】① 收益与后悔 ② log-N 的 AUC ③ 均值 + 方差 + 分位数 + CVaR ④ 约束违反率
        ⑤ 自评间隙（K=1 与 K=选择预算两口径）⑥ 数据加权与策略加权误差
【决策阈值】多大的差异才值得换；必须在跑之前写下
【禁止清单】不在评测集上调参；不用模型自评当结论；不与不同预算的基线比；不隐藏 K

7.2 跑之后的自查（逐条打勾）#

□ 每个数字都带四个坐标：基线、预算元组、起点分布、评估分布
□ 分布内与每条 OOD 轴分别报告，且报了 ID→OOD 的下降幅度
□ 训练种子与评测种子分开报；方差分解到三类来源
□ 报了 CI 与 MDD；CI 跨 0 的地方写"未检出"
□ 报了均值之外的至少两个尾部量（最差回合、CVaR(α)）
□ 报了选择预算 K；最终数字来自未参与任何选择的数据
□ 模型自评与真环境评估成对出现，且报了间隙
□ 误差同时报数据分布加权与策略诱导分布加权
□ 规划收益相对整条基线阶梯；收益归因说清"模型 vs 搜索"
□ 算力逐轴对齐，或报了性能-预算曲线

7.3 把它变成一个函数#

def audit(rec):
    """对一份'评测记录'做体检，返回红旗列表；字段缺失一律记为红旗。"""
    flags = []
    for k in ("env", "env_version", "eval_seeds", "train_seeds", "n_episodes",
              "start_dist", "ood_axes", "budget", "baseline_budget", "baselines",
              "metric", "ci", "variance"):
        if k not in rec:
            flags.append(f"缺字段：{k}")
    if rec.get("n_episodes", 0) < 30:
        flags.append("回合数 < 30：均值不可靠，尾部不可估计")
    if not rec.get("ood_axes"):
        flags.append("未声明分布外轴：ID 分数不能外推到新动力学/新起点/新动作范围")
    if len(rec.get("eval_seeds", [])) < 3:
        flags.append("评测种子 < 3：无法分离种子方差")
    if len(rec.get("train_seeds", [])) < 3:
        flags.append("训练种子 < 3：无法分离训练方差")
    if rec.get("tuned_on") == "eval":
        flags.append("在评测环境上调过参：报出的数是被挑选过的乐观估计")
    if rec.get("selected_by") == "model_value":
        flags.append("用模型自评挑选模型/策略：必须真环境复核后才能报")
    if rec.get("budget") != rec.get("baseline_budget"):
        flags.append("与基线的算力/预算不对齐：排序可能由预算造成")
    if rec.get("only_mean"):
        flags.append("只报均值：未报方差/分位数/CVaR，尾部风险不可见")
    if rec.get("ci") and rec["ci"][0] <= 0 <= rec["ci"][1]:
        flags.append("置信区间跨 0：只能表述为'未检出差异'")
    if not rec.get("baselines"):
        flags.append("无基线阶梯：无法判断收益来自模型还是来自搜索")
    return flags

这个函数的用途不是"打分"，而是把上文每一条都变成可机械执行的红旗。 它的每一条都对应本课量出来的一个数字——清单不是礼仪，是有代价的。

八、取舍与边界#

做法 好处 代价 / 边界
预注册 + 留出集 彻底堵住"在评测集上调参" 需要提前定死任务与回报；探索性研究难预注册
多训练种子 分离训练方差 成本线性增长；大模型上常常负担不起
多 OOD 轴逐个报 结论可外推 轴的设计本身是主观的；组合爆炸
报尾部 安全相关结论 尾部估计需要更多回合；小 n 下 CVaR 极不稳定
同预算对齐 排序可信 最强基线常常贵得多；"公平预算"的定义有争议
真环境复核 唯一可信的最终口径 贵、慢、可能有安全风险
自评筛查 便宜、可大批量 有 O(lnK​) 的选择偏差

三条必须写进报告的边界：

  1. "公平预算"没有唯一答案。 对齐环境步数、墙钟时间与 FLOPs 会给出不同结论。正确做法是选一个主轴对齐、报其余轴的曲线，并说明选择理由。
  2. OOD 轴的选取是主观的。 报"我们在 4 条轴上测了"不等于"OOD 被覆盖了"；漏掉的那条轴正是风险所在。
  3. 清单能防的是已知陷阱。 audit() 只能检出记录里写出来的问题——一个把 tuned_on 写成 "dev" 而实际在 test 上调过参的报告，任何自动审查都抓不到。协议的作用是让诚实的人更容易诚实，不是让不诚实的人无法作弊。

代码#

下面的代码把四类陷阱各做成一个可复现的最小实验，全部只用 Python 标准库：

  • 陷阱 A（分布分离）：同一个模型自评不变，动力学漂移后真值塌、未见起点上值误差更大；
  • 陷阱 B（均值 vs 尾部）：一个纯算术的两点分布隔离演示 + 环境里的两个策略 + CI/MDD 与"未检出"；
  • 陷阱 C（算力对齐）：把规划视界当预算，展示等预算前后排序反转；
  • 陷阱 D（评测集调参）：40 个配置 × 30 次重复，量出"作弊报数"能高过"最好配置的真实水平"；
  • 最后是 audit() 审查函数在两条记录上的输出。

⚠️ 数据全部为本代码合成，不代表任何真实数据集。

"""WM ch6-l4 演示：评测协议与四类陷阱（每类都给可复现的数字）
A) 分布内/分布外必须分开报：同一个模型自评不变，动力学漂移后真值塌、未见起点上值误差更大
B) 只报均值不报尾部：均值相同、CVaR 差 0.9；以及 CI 跨 0 时必须写"未检出"
C) 算力对齐：规划视界预算不同会直接制造排序（等预算下排序反转）
D) 在评测集上调参：报出来的数可以高过"最好配置的真实水平"
最后给可执行的评测清单审查函数 audit()。
环境与数据全部为合成数据（⚠️ 不代表任何真实数据集），只用 Python 标准库。
运行：/opt/homebrew/bin/python3.10 <file>   环境：python 3.10.16
"""
import math
import random

W = H = 5
NS = W * H
GOAL, PIT = (4, 4), (2, 2)
GAMMA = 0.95
R_STEP, R_GOAL, R_PIT = -0.02, 1.0, -1.0
MOVES = [(-1, 0), (1, 0), (0, -1), (0, 1)]
NA = 4
S0 = 0

def idx(r, c):
    return r * W + c

def build_mdp(slip):
    """P[s][a]=[(s',p)]；R[s][a] 含进入目标/陷阱那一步的一次性回报，吸收后为 0。"""
    P = [[[] for _ in range(NA)] for _ in range(NS)]
    R = [[0.0] * NA for _ in range(NS)]
    for r in range(H):
        for c in range(W):
            s = idx(r, c)
            if (r, c) in (GOAL, PIT):
                for a in range(NA):
                    P[s][a] = [(s, 1.0)]
                continue
            for a in range(NA):
                agg = {}
                for b, pr in ((a, 1 - slip), (a ^ 1, slip / 2), ((a + 2) % 4, slip / 2)):
                    dr, dc = MOVES[b]
                    s2 = idx(min(max(r + dr, 0), H - 1), min(max(c + dc, 0), W - 1))
                    agg[s2] = agg.get(s2, 0.0) + pr
                P[s][a] = list(agg.items())
                R[s][a] = R_STEP + sum(pr * (R_GOAL if s2 == idx(*GOAL)
                                             else R_PIT if s2 == idx(*PIT) else 0.0)
                                       for s2, pr in P[s][a])
    return P, R

P_ID, R_ID = build_mdp(0.12)
P_OOD, R_OOD = build_mdp(0.35)          # 分布外轴之一：打滑率 0.12 -> 0.35

def solve(A, b):
    n = len(A)
    M = [list(row) + [b[i]] for i, row in enumerate(A)]
    for col in range(n):
        p = max(range(col, n), key=lambda r: abs(M[r][col]))
        M[col], M[p] = M[p], M[col]
        pv = M[col][col]
        for j in range(col, n + 1):
            M[col][j] /= pv
        for r in range(n):
            if r != col and M[r][col] != 0.0:
                f = M[r][col]
                for j in range(col, n + 1):
                    M[r][j] -= f * M[col][j]
    return [M[i][n] for i in range(n)]

def policy_value(P, R, pi, gamma=GAMMA):
    A = [[0.0] * NS for _ in range(NS)]
    b = [0.0] * NS
    for s in range(NS):
        a = pi[s]
        A[s][s] += 1.0
        b[s] = R[s][a]
        for s2, pr in P[s][a]:
            A[s][s2] -= gamma * pr
    return solve(A, b)

def value_iteration(P, R, gamma=GAMMA, iters=400):
    V = [0.0] * NS
    for _ in range(iters):
        nv, d = [0.0] * NS, 0.0
        for s in range(NS):
            nv[s] = max(R[s][a] + gamma * sum(pr * V[s2] for s2, pr in P[s][a])
                        for a in range(NA))
            d = max(d, abs(nv[s] - V[s]))
        V = nv
        if d < 1e-12:
            break
    Q = [[R[s][a] + gamma * sum(pr * V[s2] for s2, pr in P[s][a]) for a in range(NA)]
         for s in range(NS)]
    return V, Q

def greedy_policy(Q):
    return [max(range(NA), key=lambda a: Q[s][a]) for s in range(NS)]

def sample_data(N, rng, P, R, pi_ref, eps=0.25):
    s, data = S0, []
    for _ in range(N):
        a = rng.randrange(NA) if rng.random() < eps else pi_ref[s]
        outs = P[s][a]
        x, acc, s2 = rng.random(), 0.0, outs[-1][0]
        for ss, pr in outs:
            acc += pr
            if x <= acc:
                s2 = ss
                break
        data.append((s, a, R[s][a], s2))
        s = S0 if s2 in (idx(*GOAL), idx(*PIT)) else s2
    return data

def learn_model(data, prior_self=0.5):
    cnt = [[{} for _ in range(NA)] for _ in range(NS)]
    rsum = [[0.0] * NA for _ in range(NS)]
    rn = [[0] * NA for _ in range(NS)]
    for s, a, r, s2 in data:
        cnt[s][a][s2] = cnt[s][a].get(s2, 0) + 1
        rsum[s][a] += r
        rn[s][a] += 1
    Ph = [[[] for _ in range(NA)] for _ in range(NS)]
    Rh = [[0.0] * NA for _ in range(NS)]
    for s in range(NS):
        for a in range(NA):
            if not cnt[s][a]:
                Ph[s][a] = [(s, 1.0)]
                Rh[s][a] = R_STEP
                continue
            agg = dict(cnt[s][a])
            agg[s] = agg.get(s, 0) + prior_self
            T = sum(agg.values())
            Ph[s][a] = [(s2, c / T) for s2, c in agg.items()]
            Rh[s][a] = (rsum[s][a] + prior_self * R_STEP) / (rn[s][a] + prior_self)
    return Ph, Rh

def learn_leak(data, eps=0.06):
    """乐观外推变体：把 eps 质量摊到所有状态（模拟对没见过的转移也给概率的模型）。"""
    cnt = [[{} for _ in range(NA)] for _ in range(NS)]
    rsum = [[0.0] * NA for _ in range(NS)]
    rn = [[0] * NA for _ in range(NS)]
    for s, a, r, s2 in data:
        cnt[s][a][s2] = cnt[s][a].get(s2, 0) + 1
        rsum[s][a] += r
        rn[s][a] += 1
    Ph = [[[] for _ in range(NA)] for _ in range(NS)]
    Rh = [[0.0] * NA for _ in range(NS)]
    for s in range(NS):
        for a in range(NA):
            agg = {s2: eps / NS for s2 in range(NS)}
            tot = sum(cnt[s][a].values())
            for s2, c in cnt[s][a].items():
                agg[s2] += (1 - eps) * c / max(tot, 1)
            T = sum(agg.values())
            Ph[s][a] = [(s2, c / T) for s2, c in agg.items()]
            Rh[s][a] = (rsum[s][a] + 0.5 * R_STEP) / (rn[s][a] + 0.5)
    return Ph, Rh

def rollout(P, R, pi, rng, start=S0, max_steps=30):
    s, tot, disc = start, 0.0, 1.0
    for _ in range(max_steps):
        a = pi[s]
        outs = P[s][a]
        x, acc, s2 = rng.random(), 0.0, outs[-1][0]
        for ss, pr in outs:
            acc += pr
            if x <= acc:
                s2 = ss
                break
        r = R_STEP + (R_GOAL if s2 == idx(*GOAL) else R_PIT if s2 == idx(*PIT) else 0.0)
        tot += disc * r
        disc *= GAMMA
        s = s2
        if s in (idx(*GOAL), idx(*PIT)):
            break
    return tot

def boot_ci(xs, ys, B=2000, seed=0):
    rng = random.Random(seed)
    n, ds = len(xs), []
    for _ in range(B):
        ii = [rng.randrange(n) for _ in range(n)]
        ds.append(sum(xs[i] - ys[i] for i in ii) / n)
    ds.sort()
    return ds[int(0.025 * B)], ds[int(0.975 * B) - 1]

def cvar(xs, q=0.1):
    k = max(1, int(q * len(xs)))
    return sum(sorted(xs)[:k]) / k

def plan_action(Ph, Rh, s_obs, K, rng, Hp):
    """随机射击规划：试 K 条长度 Hp 的随机动作序列，取模型内回报最高那条的第一步。"""
    best, besta = None, 0
    for _ in range(K):
        seq = [rng.randrange(NA) for _ in range(Hp)]
        s, tot, disc = s_obs, 0.0, 1.0
        for a in seq:
            tot += disc * Rh[s][a]
            disc *= GAMMA
            outs = Ph[s][a]
            x, acc, s2 = rng.random(), 0.0, outs[-1][0]
            for ss, pr in outs:
                acc += pr
                if x <= acc:
                    s2 = ss
                    break
            s = s2
        if best is None or tot > best:
            best, besta = tot, seq[0]
    return besta

def eval_planner(Ph, Rh, K, Hp, n_ep=60, seed=3):
    rng = random.Random(seed)
    rr = []
    for _ in range(n_ep):
        s, tot, disc = S0, 0.0, 1.0
        for _ in range(24):
            a = plan_action(Ph, Rh, s, K, rng, Hp)
            outs = P_ID[s][a]
            x, acc, s2 = rng.random(), 0.0, outs[-1][0]
            for ss, pr in outs:
                acc += pr
                if x <= acc:
                    s2 = ss
                    break
            r = R_STEP + (R_GOAL if s2 == idx(*GOAL) else R_PIT if s2 == idx(*PIT) else 0.0)
            tot += disc * r
            disc *= GAMMA
            s = s2
            if s in (idx(*GOAL), idx(*PIT)):
                break
        rr.append(tot)
    return sum(rr) / len(rr)

# ==================== 评测清单审查函数 ====================
def audit(rec):
    """对一份"评测记录"做体检，返回红旗列表；字段缺失一律记为红旗。"""
    flags = []
    for k in ("env", "env_version", "eval_seeds", "train_seeds", "n_episodes",
              "start_dist", "ood_axes", "budget", "baseline_budget", "baselines",
              "metric", "ci", "variance"):
        if k not in rec:
            flags.append(f"缺字段：{k}")
    if rec.get("n_episodes", 0) < 30:
        flags.append("回合数 < 30：均值不可靠，尾部不可估计")
    if not rec.get("ood_axes"):
        flags.append("未声明分布外轴：ID 分数不能外推到新动力学/新起点/新动作范围")
    if len(rec.get("eval_seeds", [])) < 3:
        flags.append("评测种子 < 3：无法分离种子方差")
    if len(rec.get("train_seeds", [])) < 3:
        flags.append("训练种子 < 3：无法分离训练方差")
    if rec.get("tuned_on") == "eval":
        flags.append("在评测环境上调过参：报出的数是被挑选过的乐观估计")
    if rec.get("selected_by") == "model_value":
        flags.append("用模型自评挑选模型/策略：必须真环境复核后才能报")
    if rec.get("budget") != rec.get("baseline_budget"):
        flags.append("与基线的算力/预算不对齐：排序可能由预算造成")
    if rec.get("only_mean"):
        flags.append("只报均值：未报方差/分位数/CVaR，尾部风险不可见")
    if rec.get("ci") and rec["ci"][0] <= 0 <= rec["ci"][1]:
        flags.append("置信区间跨 0：只能表述为'未检出差异'")
    if not rec.get("baselines"):
        flags.append("无基线阶梯：无法判断收益来自模型还是来自搜索")
    return flags

   同一个配置换一批 fresh test 复核    = +0.4397  -> 虚高 +0.2427
   读法：作弊报数甚至高过'40 个配置里最好的那个真实水平'；只要在评测集上挑过，
         报出的数就不再是该配置水平的估计。

这段代码想让你看到的四件事：

  1. 自评只有一个数，真环境值有一个族。 陷阱 A：自评 +0.1625，ID 真值 +0.0796，OOD 动力学真值 +0.0382；未见起点上的值误差比已见起点大 49%（0.4758 vs 0.3196）。"我们的模型自评 0.16"这句话在 OOD 上什么也不保证。
  2. 均值相同的两条分布可以有完全不同的尾部。 陷阱 B 的隔离演示：两条分布的均值都是 0.00，CVaR10 是 −0.90 与 0.00；环境里两个策略的均值差 0.36，而 CVaR 差 0.86（2.4 倍）。只报均值会系统性低估风险。
  3. 预算可以直接翻转排序。 陷阱 C：不等预算下"乐观模型更好"（−0.187>−0.282），等预算 H=8 下"保守模型更好"（+0.008>−0.187）。值得注意的是更多规划把保守模型变好、把乐观模型变差 —— 与第 2 节的机制一致。
  4. 在评测集上调参能把数字刷到"超过最好配置的真实水平"。 陷阱 D：40 个配置的真实上限是 +0.4634，作弊报数是 +0.6824（虚高 +0.2427）。这不是模型变强，是噪声被挑出来。

⚠️ 诚实说明这个实验的边界：环境是5×5 表格 MDP + 随机射击规划器，所以策略值可以精确求值、四类陷阱都能用极小的算力量出来；陷阱 D 的"配置"是同一个模型类在不同平滑强度下的 40 个实例（不是真实超参搜索），评测噪声是显式加的高斯噪声（σ=0.4、每配置 10 回合）。audit() 只检查记录里写出来的字段，它抓不到"字段写对了但流程做错了"的情况。它证明的是四类陷阱的量级与方向（分布分离差 2 倍、尾部差 2.4 倍、预算翻转排序、作弊虚高 0.24），以及一份可机械执行的清单长什么样，而不是任何具体系统的水平。

练习#

  1. 给 audit() 加三条规则。 至少覆盖：① 评测集被复用于多次选择（"数据复用"）；② 只报了 OOD 的一条轴；③ 报告里的基线与被测对象不同训练预算。每条都要给出可判定的字段与红旗文案，并说明它在什么情况下会误报。
  2. 方差预算分配。 假设你有 120 个回合的评测预算，三个方差来源的估计是 σtrain​=0.20、σeval​=0.10、σstart​=0.35。分别在"1 训练种子 × 120 回合""4 训练种子 × 30 回合""8 训练种子 × 15 回合"下估算总方差，并给出最优分配。解释它与 llm-evaluation 第 2 章第 3 节"模板 vs 题目"的分解为什么同构。
  3. 重做陷阱 D，但用 dev 选择。 把"用 dev 挑配置"再拆成"用 dev 的 10 回合挑"与"用 dev 的 50 回合挑"，比较二者的 fresh test 值。解释：为什么增加 dev 的回合数能减少选择偏差，而增加 test 的回合数不能减少"在 test 上挑"的偏差？
  4. 算力对齐的三种口径。 在陷阱 C 里，把预算轴从"规划视界 H"换成"射击条数 K"，重跑并画出两条曲线。然后回答：如果只能对齐一个轴，你会选训练步数、规划预算还是墙钟时间？ 给出判据（提示：结论要对谁负责——算法研究还是工程落地）。
  5. OOD 轴的组合。 在陷阱 A 的框架里，同时偏移动力学（0.12→0.35）与起点（从未见状态开始），测"两条轴同时偏移"与"各自偏移"的下降幅度。说明为什么不能从单轴结果外推到多轴（提示：误差可能放大也可能饱和）。
  6. 写一份完整的报告卡。 用本课的四个实验数据，写一份不超过 30 行的评测报告，要求满足 7.2 节清单的全部十条。然后故意违反其中一条，指出读者会因此得出什么错误结论。
  7. 讨论题（有唯一答案）。 有人说："这些都是统计常识，工程上没必要这么麻烦。"请给出至少三条反驳，每条都落到本课实测的数字上（提示：陷阱 D 的虚高 0.2427 超过了配置间的真实差距；陷阱 C 的排序反转幅度是 0.195；陷阱 B 的尾部差距是均值的 2.4 倍）。

小结#

  • 协议五骨架：分布（ID/OOD 分轴）、种子（训练/评测分开）、方差（均值 + 尾部）、算力（逐轴对齐）、基线（阶梯）。每一条不做都有可量化的代价。
  • 分布外是一个方向不是一个布尔值。 至少四条独立轴（动力学/起点/动作范围/观测外观）。本课实测：自评 +0.1625 不变，ID 真值 +0.0796、OOD 动力学 +0.0382；未见起点的值误差比已见起点大 49%。
  • 种子要分三类方差：训练/评测/起点。Var(J^)≈σtrain2​/Strain​+σeval2​/Seval​+σstart2​/n —— 加到错误的项上等于浪费预算（与题目 vs 模板的分解同构）。
  • 只报均值会同时丢掉尾部与不确定性。 本课：两条分布均值都是 0.00 而 CVaR10 是 0.00 与 −0.90；环境里均值差 0.36 而 CVaR 差 0.86（2.4 倍）。CI 跨 0 时必须写"未检出"（本课点估计 +0.0826、CI [−0.1119,+0.2777]、MDD 0.2172）。
  • 算力不对齐可以直接翻转排序。 本课：不等预算"乐观模型更好"（−0.187>−0.282），等预算 H=8 结论相反（+0.008>−0.187）；且更多规划把保守模型变好、把乐观模型变差。
  • 四类作弊路径：在评测环境上调参、模型自评当结果、只报均值不报方差、不等预算比较。本课把第四类的量级也量了出来：作弊报数 +0.6824 超过 40 个配置的真实上限 +0.4634，虚高 +0.2427。
  • 一份可执行清单（7.1 预注册 + 7.2 自查 + 7.3 的 audit()）。它的每一条都对应本课量出来的一个数字——清单不是礼仪，是有代价的。
  • 边界：清单只能防已知陷阱、只能检查记录里写出来的字段；"公平预算"没有唯一答案；OOD 轴的选取本身是主观的。协议的作用是让诚实的人更容易诚实。
