训练与评估#

数据集备好了，模型选好了，剩下的就是把这台机器跑起来。这一课把训练与评估的完整流程串成一条闭环：训练循环怎么写、优化器和学习率怎么配、怎么在验证集上评估、怎么判断过拟合并保存最佳模型。学完这一课，你就具备了自己训练一个 CNN 分类器的完整能力。

一、概念讲解#

1. 训练循环的五个要素#

一个 epoch（把训练集完整过一遍）的训练循环，本质是五步的重复：

for 每个 batch (x, y):
    1. 清零梯度        optimizer.zero_grad()
    2. 前向传播        out = model(x)
    3. 计算损失        loss = criterion(out, y)
    4. 反向传播        loss.backward()
    5. 更新参数        optimizer.step()

这五步是 PyTorch 训练的"万能模板"，换模型、换任务都长这样。

2. 优化器与学习率#

  • 优化器：torch.optim.SGD（随机梯度下降，可配动量 momentum=0.9）与 torch.optim.Adam（自适应学习率，收敛快、对学习率不那么敏感）是最常用的两个。CNN 训练里 SGD + 动量是经典组合，Adam 则更省心。
  • 学习率调度器：训练中逐渐调低学习率能帮助收敛到更优的点。torch.optim.lr_scheduler.StepLR（每隔若干 epoch 降一次）和 CosineAnnealingLR（余弦退火）都很常用。

3. 训练与评估的切换#

模型在 train() 与 eval() 两种模式下行为不同：Dropout 只在 train() 时随机丢弃，BatchNorm 在两种模式下统计量的计算方式也不同。所以评估前必须 model.eval()，评估时用 torch.no_grad() 关掉梯度，评估完再切回 model.train()。这是新手最容易踩的坑。

4. 评估指标：准确率与混淆矩阵#

  • 准确率（accuracy）：预测正确的样本数 ÷ 总样本数，最直观的指标；
  • 混淆矩阵（confusion matrix）：一个 K×K 的表格，第 i 行第 j 列表示"真实类别 i 被预测成 j"的数量，能看出模型在哪些类别上容易混淆。

当类别不均衡时，只看准确率会失真，还需要精确率、召回率等指标——但图像分类入门阶段，先吃透准确率与混淆矩阵即可。

5. 过拟合与模型保存#

训练中如果训练集准确率一路涨、验证集准确率却开始掉，就是过拟合的信号。对策有：加数据增强、加 Dropout、加正则化、早停。最终交付时，应保存验证集上表现最好的模型，而不是最后一个 epoch 的模型：

torch.save(model.state_dict(), "best.pt")   # 保存权重
model.load_state_dict(torch.load("best.pt"))  # 载回

二、可运行代码示例#

下面用上一课的 CIFAR-10 数据，训练一个小型 CNN，完整演示训练 + 评估 + 保存最佳模型。为便于快速跑通，示例只训 5 个 epoch。

import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# 1) 数据准备（与上一课一致）
train_transform = transforms.Compose([
    transforms.RandomCrop(32, padding=4),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465),
                         (0.2470, 0.2435, 0.2616)),
])
val_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465),
                         (0.2470, 0.2435, 0.2616)),
])
train_set = datasets.CIFAR10("./data", train=True, download=True, transform=train_transform)
val_set = datasets.CIFAR10("./data", train=False, download=True, transform=val_transform)
train_loader = DataLoader(train_set, batch_size=128, shuffle=True, num_workers=2)
val_loader = DataLoader(val_set, batch_size=128, shuffle=False, num_workers=2)

# 2) 一个够用的小 CNN
class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1), nn.ReLU(inplace=True),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(inplace=True),
            nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(inplace=True),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(), nn.Linear(128 * 4 * 4, 256),
            nn.ReLU(inplace=True), nn.Dropout(0.5), nn.Linear(256, num_classes),
        )
    def forward(self, x):
        return self.classifier(self.features(x))

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = SmallCNN().to(device)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# 3) 训练 + 评估循环
def evaluate(model, loader):
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            pred = model(x).argmax(dim=1)
            correct += (pred == y).sum().item()
            total += y.size(0)
    return correct / total

best_acc = 0.0
for epoch in range(5):
    model.train()
    running_loss = 0.0
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        optimizer.zero_grad()          # 1. 清零梯度
        out = model(x)                 # 2. 前向
        loss = criterion(out, y)       # 3. 计算损失
        loss.backward()                # 4. 反向
        optimizer.step()               # 5. 更新参数
        running_loss += loss.item()
    acc = evaluate(model, val_loader)
    print(f"Epoch {epoch+1}: 平均损失 {running_loss/len(train_loader):.3f}, 验证准确率 {acc:.3f}")
    if acc > best_acc:                 # 保存验证集上最好的模型
        best_acc = acc
        torch.save(model.state_dict(), "best.pt")

print(f"最佳验证准确率: {best_acc:.3f}")

运行后你会看到损失逐轮下降、验证准确率逐步上升（5 个 epoch 的小模型大概能到 60%~70%）。换成预训练 ResNet 并微调，准确率会轻松突破 90%——迁移学习的力量在实战中非常明显。

三、练习#

  1. 把优化器从 Adam 换成 SGD(model.parameters(), lr=0.01, momentum=0.9)，观察收敛速度与最终准确率的变化。
  2. 加一个 torch.optim.lr_scheduler.StepLR(optimizer, step_size=3, gamma=0.1)，在每个 epoch 结束后调用 scheduler.step()，观察学习率衰减对结果的影响。
  3. 把训练 epoch 数加到 20，同时每轮打印训练集准确率，画出训练/验证准确率曲线，找出过拟合开始出现的 epoch。
  4. 思考：为什么要在验证集最好时保存 best.pt，而不是训练结束后保存最后一个 epoch 的模型？评估时忘记 model.eval() 会发生什么？
