训练目标推导#

前两课给了前向与反向过程，但还没回答最核心的问题：那个去噪网络 ε_θ 到底拿什么目标来训练？ 这一课把 DDPM 的训练目标从"最大化数据似然"一路推导到那个著名的极简形式——"预测噪声"的均方误差。你会发现，看似神奇的目标，本质是变分下界经过三步化简 + 一个大胆简化的结果。

一、概念讲解#

1. 起点：最大化对数似然，套变分下界#

和 VAE 一样，DDPM 的目标是最大化真实数据的对数似然 log p_θ(x_0)。引入潜变量 x_{1:T}（前向过程的中间状态），用 Jensen 不等式（或直接对 log 用变分分解）得到变分下界（VLB / ELBO）：

-log p_θ(x_0) ≤ E_q [ log q(x_{1:T} | x_0) / p_θ(x_{0:T}) ]  =: L_VLB

也就是说，最小化 L_VLB 就是在最大化似然的下界。接下来把 L_VLB 展开，拆成可计算的项。

2. 展开：拆成三个 KL 项#

把 q(x_{1:T}|x_0) 和 p_θ(x_{0:T}) 都按马尔可夫链分解，再利用 q(x_t|x_{t-1}) = q(x_t|x_{t-1}, x_0)（马尔可夫性质），经过一番代数整理，L_VLB 变成三个部分：

L_VLB =  L_0  +  Σ_{t=2}^{T} L_{t-1}  +  L_T

其中：
  L_0    = - E_q[ log p_θ(x_0 | x_1) ]                       # 最后一步"重建"干净图
  L_{t-1} = E_q[ D_KL( q(x_{t-1}|x_t,x_0) ‖ p_θ(x_{t-1}|x_t) ) ]  # 每步去噪是否贴合真实后验
  L_T    = D_KL( q(x_T|x_0) ‖ p(x_T) )                       # 末期是否接近先验 N(0,I)

最关键的是 L_{t-1}：它要求"网络的反向步 p_θ(x_{t-1}|x_t) 尽量贴近可解析的真实后验 q(x_{t-1}|x_t,x_0)"。而后者上一课已经算出是高斯——于是这个 KL 可以闭式求解。

3. 化简 KL：高斯对高斯，消成均方差#

q(x_{t-1}|x_t,x_0) 是方差 β̃_t 已知的高斯，p_θ(x_{t-1}|x_t) 也是高斯。两个同方差高斯之间的 KL 散度，恰好正比于它们均值的平方差：

L_{t-1} = E_q [ (1 / (2 σ_t^2)) · ‖ μ̃_t(x_t, x_0) - μ_θ(x_t, t) ‖^2 ]

于是问题归结为：让网络的均值 μ_θ 逼近可解析的 μ̃_t。这正是"扩散模型训练 = 拟合一个高斯均值"的由来。

4. 参数化：把"预测均值"换成"预测噪声"#

上一课推导过 μ̃_t 可以用噪声 ε 改写：

μ̃_t(x_t, x_0) = (1 / sqrt(α_t)) · ( x_t - (β_t / sqrt(1 - ᾱ_t)) · ε )

于是让网络以相同形式预测均值，等价于让它预测 ε：

μ_θ(x_t, t) = (1 / sqrt(α_t)) · ( x_t - (β_t / sqrt(1 - ᾱ_t)) · ε_θ(x_t, t) )

代入上一步的均方差，消去公共系数，得到：

L_{t-1} = E_{x_0, ε} [ (β_t^2 / (2 σ_t^2 α_t (1 - ᾱ_t))) · ‖ ε - ε_θ(x_t, t) ‖^2 ]

其中 x_t = sqrt(ᾱ_t) x_0 + sqrt(1 - ᾱ_t) ε。

5. 大胆简化：丢掉权重，得到 L_simple#

上式前面那串系数随 t 剧烈变化，DDPM 论文发现：直接丢掉系数、对每个时间步等权，训练更稳、样本更好。于是得到贯穿全文的简化目标：

L_simple(θ) = E_{t, x_0, ε} [ ‖ ε - ε_θ( sqrt(ᾱ_t) x_0 + sqrt(1-ᾱ_t) ε ,  t ) ‖^2 ]

一句话总结整个推导：最大化似然 → 变分下界 → 三个 KL 项 → 高斯 KL 化成均方差 → 用 ε 重写均值 → 丢掉权重系数，最终收敛到"预测噪声"的均方误差。 这也是为什么 DDPM 训练起来异常简单稳定：没有判别器对抗、没有可逆约束、没有配分函数，只剩一个 L2 回归。

6. 训练算法与"噪声预测"的直观理解#

训练循环（DDPM Algorithm 1）就是反复做四件事：取真实样本 x_0 → 抽时间步 t → 抽噪声 ε → 最小化 ‖ε - ε_θ(x_t, t)‖²。它的直观含义是：给网络看一张"掺了 t 步噪声的图"，告诉它"这里面的噪声是 ε，你把它找出来"。当网络对所有时间步、所有样本都能精确分离噪声时，反向采样循环（上一课）就能一步步把纯噪声还原成真实数据——这正是扩散模型能生成高质量样本的底层原因。

二、可运行代码示例#

用一个 2D 玩具任务完整训练一个迷你 DDPM：真实数据是"瑞士卷"曲线，训练一个噪声预测网络，亲眼看着损失下降。

import torch
import torch.nn as nn

torch.manual_seed(0)
T = 1000
beta = torch.linspace(1e-4, 0.02, T)
alpha = 1 - beta
alpha_bar = torch.cumprod(alpha, dim=0)      # ᾱ_t
sqrt_alpha_bar = alpha_bar.sqrt()
sqrt_omab = (1 - alpha_bar).sqrt()           # sqrt(1-ᾱ_t)

# —— 真实数据：2D 瑞士卷（"卷起来的螺旋线"） ——
def get_batch(n=256):
    theta = torch.rand(n) * 6 * torch.pi
    r = theta / (6 * torch.pi)
    return torch.stack([r * torch.cos(theta), r * torch.sin(theta)], dim=1)

# —— 噪声预测网络：输入 (x_t, t)，输出预测的噪声 ε ——
class EpsNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.t_emb = nn.Embedding(T, 32)          # 时间步嵌入：告诉网络"加噪到第几步"
        self.net = nn.Sequential(
            nn.Linear(2 + 32, 128), nn.ReLU(),
            nn.Linear(128, 128), nn.ReLU(),
            nn.Linear(128, 2),                    # 输出和 x_t 同维的噪声
        )
    def forward(self, x, t):
        te = self.t_emb(t)                        # [B, 32]
        return self.net(torch.cat([x, te], dim=-1))

model = EpsNet()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

# —— 训练循环（DDPM Algorithm 1 的简化版） ——
for step in range(5000):
    x0 = get_batch(256)                     # 1) 取真实样本
    t = torch.randint(0, T, (256,))         # 2) 随机时间步
    eps = torch.randn_like(x0)              # 3) 随机噪声
    a = sqrt_alpha_bar[t].unsqueeze(1)
    b = sqrt_omab[t].unsqueeze(1)
    xt = a * x0 + b * eps                   # 前向一步到位：构造加噪样本 x_t

    loss = ((model(xt, t) - eps) ** 2).mean()   # 4) L_simple：预测噪声的均方误差
    opt.zero_grad(); loss.backward(); opt.step()

    if step % 1000 == 0:
        print(f"step {step}: loss={loss.item():.4f}")

运行后损失应持续下降。这就是扩散模型训练目标推导的最终产物——loss = ((model(xt, t) - eps) ** 2).mean() 这短短一行，背后是变分下界一路化简的全部数学。

三、练习#

  1. 把训练步数从 5000 提到 20000，观察损失曲线的收敛趋势；再实现上一课的 sample() 并用训练好的 EpsNet 采样，画出生成点云与真实瑞士卷对比。
  2. 手推"两个同方差高斯的 KL 散度正比于均值平方差"：写出 KL(N(μ1,σ²)‖N(μ2,σ²)) 的积分形式并化简，验证系数为 1/(2σ²)。
  3. 把损失里"预测 ε"改成"预测 x_0"（即让网络输出 x_0，损失为 ‖x_0_hat - x_0‖²），对比两种目标下的训练效果，讨论哪个更稳。
  4. 在损失里加回权重系数 β_t^2/(2 σ_t^2 α_t (1-ᾱ_t))，对比有无权重时的收敛速度与最终质量，印证 DDPM "丢权重反而更好"的经验。
  5. 思考题：L_T 项 KL(q(x_T|x_0)‖p(x_T)) 为什么在前向调度设计合理时（ᾱ_T≈0）近似为 0？说明这一项在训练里通常被忽略的原因。
