综合项目#

这是《深度学习架构》的最后一课。我们把前面学过的所有零件——词表与嵌入、LSTM、teacher forcing、自回归解码——组装成一个完整的 序列到序列（seq2seq） 项目。任务很经典：输入一串乱序字母，模型输出排好序的字母。它麻雀虽小，却完整复刻了机器翻译的核心结构：编码器读入 → 解码器生成。

一、概念讲解#

1. 任务与架构总览#

任务定义：输入如 c a b d，输出 a b c d。输入输出长度相同但顺序不同，正好用来演示 seq2seq 的编码器-解码器结构：

  • 编码器（Encoder）：一个 LSTM，把输入序列从头到尾读一遍，把最终的记忆（隐藏状态 h 和细胞状态 c）作为整句的"语义压缩"；
  • 解码器（Decoder）：另一个 LSTM，用编码器传来的记忆作为初始状态，然后一个字符一个字符地生成输出序列。

两个 LSTM 是两套独立的参数，靠"初始状态"传递信息：编码器最后的状态，就是解码器最初的状态。这相当于把"读懂的内容"递交给"负责写的人"。

2. 三个特殊符号：SOS、EOS、PAD#

生成式模型需要三个特殊标记来约定"何时开始、何时结束、怎么补长"：

  • <sos>（start of sequence）：解码器第一个时间步的输入，表示"开始生成"；
  • <eos>（end of sequence）：生成到它表示"这句话写完了"，训练时也作为目标序列的结尾；
  • <pad>（padding）：把不等长的序列补成等长，本身不参与损失计算。

它们让变长序列的生成有了明确的"起止信号"，是几乎所有生成式 NLP 系统的标配。

3. 训练：teacher forcing#

训练解码器时，我们用 teacher forcing（上一课学的）：解码器每一步的输入是真实的目标字符，而不是自己上一步的预测。整体流程：

  1. 编码器读入乱序输入，得到最终状态；
  2. 解码器以 <sos> 开头，每一步喂真实的"上一个目标字符"，输出对下一个字符的预测；
  3. 用预测和真实目标（含 <eos>）算交叉熵，反向传播更新两个 LSTM。

这样训练稳定高效，模型很快就能学会"把字母排好序"。

4. 推理：自回归 + 贪心解码#

推理时没有老师，解码器改为自回归：以 <sos> 起步，每步取预测概率最大的字符（贪心），把它当作下一步的输入，直到输出 <eos> 或到达最大长度。这就是上一课生成流程在 seq2seq 上的完整应用。

二、可运行代码示例#

下面完整实现并训练这个"字母排序"seq2seq 模型。代码刻意写得直白、贴近讲解，方便你照葫芦画瓢改造成自己的翻译/摘要任务。

import torch
import torch.nn as nn

torch.manual_seed(0)

# 1) 词汇表：<pad> <sos> <eos> + 四个字母 a b c d
chars = "abcd"
tokens = ["<pad>", "<sos>", "<eos>"] + list(chars)
t2i = {t: i for i, t in enumerate(tokens)}
i2t = {i: t for t, i in t2i.items()}

class Seq2Seq(nn.Module):
    def __init__(self, vocab_size, hidden):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, hidden)
        self.encoder = nn.LSTM(hidden, hidden, batch_first=True)
        self.decoder = nn.LSTM(hidden, hidden, batch_first=True)
        self.fc = nn.Linear(hidden, vocab_size)

    def forward(self, src, tgt):
        """训练用（teacher forcing）。src: 乱序输入，tgt: 目标序列（以 <sos> 开头）。"""
        # 编码器：读完整条输入，取最终状态 (h, c)
        _, (h, c) = self.encoder(self.embed(src))
        # 解码器：逐个喂真实目标字符
        dec_in = self.embed(tgt)                       # (batch, tgt_len, hidden)
        out, _ = self.decoder(dec_in, (h, c))
        return self.fc(out)                            # (batch, tgt_len, vocab)

    def decode(self, src, max_len=8):
        """推理用（自回归贪心解码）。"""
        _, (h, c) = self.encoder(self.embed(src))
        token = torch.tensor([t2i["<sos>"]] * src.size(0))   # 每个样本都以 <sos> 起步
        result = []
        for _ in range(max_len):
            out, (h, c) = self.decoder(self.embed(token).unsqueeze(1), (h, c))
            token = self.fc(out.squeeze(1)).argmax(1)         # 贪心取最大概率
            result.append(token)
        return torch.stack(result, dim=1)                     # (batch, max_len)

model = Seq2Seq(len(tokens), hidden=16)
loss_fn = nn.CrossEntropyLoss(ignore_index=t2i["<pad>"])     # 忽略 <pad>
opt = torch.optim.Adam(model.parameters(), lr=0.01)

# 2) 构造数据：对 abcd 的随机排列做排序
def make_batch(n):
    src, tgt = [], []
    for _ in range(n):
        perm = torch.randperm(len(chars))                     # 随机排列
        src.append(perm + len(tokens) - len(chars))           # 映射到字母的索引
        sorted_ = torch.sort(perm).values + len(tokens) - len(chars)
        tgt.append(torch.cat([torch.tensor([t2i["<sos>"]]), sorted_,
                              torch.tensor([t2i["<eos>"]])]))
    return torch.stack(src), torch.stack(tgt)

# 3) 训练
for step in range(1000):
    src, tgt = make_batch(64)
    logits = model(src, tgt[:, :-1])                         # 输入不含 <eos>
    loss = loss_fn(logits.reshape(-1, len(tokens)), tgt[:, 1:].reshape(-1))
    opt.zero_grad()
    loss.backward()
    opt.step()
    if step % 200 == 0:
        print(f"step {step:4d} | loss={loss.item():.4f}")

# 4) 推理：拿几条新乱序输入，看能否正确排序
test_src = torch.stack([torch.randperm(len(chars)) + len(tokens) - len(chars)
                        for _ in range(4)])
with torch.no_grad():
    pred = model.decode(test_src)

for s, p in zip(test_src, pred):
    src_str = "".join(i2t[i.item()] for i in s)
    out_str = "".join(i2t[i.item()] for i in p if i2t[i.item()] not in ("<eos>", "<pad>"))
    print(f"输入 {src_str} → 输出 {out_str}")

运行后，损失会稳步下降，最后对新的乱序输入，模型基本能输出正确的 abcd 排序。这就是 seq2seq 的完整闭环：编码器读懂、解码器写出。把字母换成词、把"排序"换成"翻译"，结构完全不变——这正是机器翻译、文本摘要这些大模型的骨架。

三、练习#

  1. 把字母表从 4 个扩充到 6 个（abcdef），重新训练并测试，观察模型是否仍能学会排序，训练时间发生了什么变化。
  2. 把"排序"任务改成"反转"任务（输入 abcd 输出 dcba），只需改动 make_batch 里的目标构造，重训并验证。
  3. 把贪心解码改成带温度采样（参考上一课的 torch.multinomial），观察生成结果是否出现"乱序"错误，并解释为什么序列任务里贪心通常更稳。
  4. 思考：编码器把整句压缩成一个固定长度的状态 (h, c)，当输入序列很长时会遇到什么瓶颈？结合注意力机制的作用谈谈你的理解。
