os/pathlib 系统操作#

写程序经常要和"文件夹、路径、文件"打交道：看看当前目录在哪、创建或删除文件夹、判断文件是否存在、把多个路径拼接起来。Python 提供了两套工具：传统的 os 模块，以及更现代、更好用的 pathlib。这一课我们把两者都认识一下。

一、概念讲解#

1. os 模块：操作系统的接口#

os 模块封装了和操作系统交互的功能，最常用的是目录和文件操作：

函数 作用
os.getcwd() 获取当前工作目录
os.listdir(path) 列出目录里的所有文件/文件夹名
os.mkdir(path) 新建一个文件夹
os.makedirs(path) 递归新建多级文件夹
os.remove(path) 删除文件
os.rmdir(path) 删除空文件夹
os.rename(old, new) 重命名/移动文件
os.path.exists(path) 判断路径是否存在
os.path.join(a, b) 按系统规则拼接路径

其中 os.path.join() 很重要：不同系统分隔符不一样（Windows 是 \，Linux/macOS 是 /），用 join 拼接就能自动选对分隔符，代码也更通用。

2. pathlib 模块：面向对象的路径#

pathlib 把"路径"变成了一个对象，使用起来更像人话。核心是 Path 类：

from pathlib import Path
p = Path("docs") / "note.txt"   # 用 / 符号拼接路径

Path 对象有很多实用方法：

方法 作用
p.exists() 路径是否存在
p.is_file() / p.is_dir() 是文件 / 是文件夹
p.mkdir() 创建文件夹
p.read_text(encoding="utf-8") 直接读出文本内容
p.write_text(内容, encoding="utf-8") 直接写入文本
p.iterdir() 遍历目录内容
p.glob("*.txt") 按通配符匹配文件
p.name / p.suffix / p.parent 文件名 / 后缀 / 父目录

read_text() 和 write_text() 尤其方便：一行代码就能完成"打开、读写、关闭"整个流程，连 with 都不用写了。

3. 用哪个？#

  • 想快速写、代码更清晰：优先用 pathlib；
  • 需要调用某些 os 特有的功能（比如 os.getcwd()、进程相关操作）：用 os。

两者可以混用，很多老项目里 os.path 也很常见，所以都值得了解。

二、可运行代码示例#

示例 1：用 os 查看目录和拼接路径#

import os

# 当前工作目录
print("当前目录：", os.getcwd())

# 用 join 拼接路径，自动处理分隔符
data_dir = os.path.join("workspace", "data", "scores.txt")
print("拼接出的路径：", data_dir)

# 列出当前目录内容
print("目录内容：", os.listdir("."))

示例 2：用 os 创建和删除文件夹#

import os

folder = "tmp_demo"
if not os.path.exists(folder):
    os.mkdir(folder)                 # 新建文件夹
    print("已创建文件夹：", folder)
else:
    print("文件夹已存在")

os.rmdir(folder)                     # 删除空的文件夹
print("已删除文件夹：", folder)

示例 3：用 pathlib 读写文本#

from pathlib import Path

p = Path("hello.txt")

# 写入：一行搞定，无需手动 open 和 close
p.write_text("你好，pathlib！\n这是第二行。\n", encoding="utf-8")

# 读取
print(p.read_text(encoding="utf-8"))

# 查看文件信息
print("是否存在：", p.exists())
print("文件后缀：", p.suffix)
print("所在目录：", p.parent)

示例 4：用 pathlib 遍历文件夹#

from pathlib import Path

# 准备几个文件用于演示
Path("demo").mkdir(exist_ok=True)          # exist_ok=True 表示已存在也不报错
(Path("demo") / "a.txt").write_text("A", encoding="utf-8")
(Path("demo") / "b.py").write_text("print('B')", encoding="utf-8")

# 用 glob 匹配所有 .txt 文件
for f in Path("demo").glob("*.txt"):
    print("找到：", f)

三、练习#

  1. 用 os.getcwd() 打印当前目录，再用 os.listdir() 列出里面所有内容，统计一共有多少个文件、多少个文件夹。
  2. 用 pathlib 新建一个文件夹 my_notes，在其中写入三个 .txt 文件，再用 glob("*.txt") 把它们全部找出来打印。
  3. 写一个函数，接收一个路径字符串，判断它是否存在、是文件还是文件夹，并打印对应的提示信息（分别用 os.path 和 pathlib 各实现一次）。
