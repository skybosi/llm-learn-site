从 MLE 推出 MSE#

线性回归为什么用平方和作为损失？教科书总说"因为平方方便求导、惩罚大误差"，但这些只是工程上的甜头，不是根本原因。这一课我们要给出真正的第一性原理答案：假设观测噪声服从高斯分布，那么对参数做最大似然估计，目标函数会自动变成平方和——MSE 不是被"选"出来的，而是被高斯噪声"推导"出来的。

一、概念讲解#

1. 线性回归的概率模型#

线性回归的出发点是一个数据生成假设：真实目标值 y 等于一个线性函数加上随机噪声 ε：

y = wᵀx + b + ε,    ε ~ N(0, σ²)

含义有三层：

  1. 系统性部分 wᵀx + b：输入对输出的"可预测"贡献，是我们要学的；
  2. 随机噪声 ε：观测里无法由输入解释的部分，均值为 0（平均无系统偏差）；
  3. 同方差高斯 σ²：噪声的波动幅度处处相同，且服从高斯分布。

由高斯分布的可加性，这个模型等价于说：给定 x 时，y 服从以 wᵀx + b 为均值、σ² 为方差的高斯分布：

y | x  ~  N(wᵀx + b, σ²)

这是整节课的支点。记住：我们不是"硬凑"高斯，而是把"线性关系 + 高斯噪声"这个最常见的生成假设写清楚，然后看它会推出什么。

2. 写出似然函数#

对第 i 个样本，其标签 yᵢ 的概率密度为：

p(yᵢ | xᵢ; w, b, σ²) = (1/√(2πσ²)) · exp( −(yᵢ − wᵀxᵢ − b)² / 2σ² )

由于样本独立同分布，整个训练集的似然是各样本密度的乘积：

L(w, b, σ²) = ∏ᵢ₌₁ᵐ p(yᵢ | xᵢ; w, b, σ²)

3. 取对数，拆出平方和#

取对数，把乘积变求和：

log L = Σᵢ [ −(1/2) log(2πσ²) − (yᵢ − wᵀxᵢ − b)² / (2σ²) ]
      = −(m/2) log(2πσ²) − (1/2σ²) · Σᵢ (yᵢ − wᵀxᵢ − b)²

现在做最大似然：关于 (w, b) 最大化 log L。第一项 −(m/2)log(2πσ²) 与 (w, b) 无关，第二项的系数 1/2σ² 是正的常数，因此：

max_{w,b} log L  ⟺  max_{w,b} [ −(1/2σ²) Σᵢ (yᵢ − wᵀxᵢ − b)² ]
                ⟺  min_{w,b} Σᵢ (yᵢ − wᵀxᵢ − b)²

结论：在线性回归的高斯噪声假设下，最大似然估计 (w, b) 恰好就是最小化残差平方和 Σᵢ(yᵢ − ŷᵢ)²。除以样本数 m（不改变最小值点）就是均方误差 MSE：

J(w, b) = (1/m) Σᵢ (yᵢ − wᵀxᵢ − b)²

MSE 由此诞生。它不是"拍脑袋选了个方便的损失"，而是"假设误差是高斯后，MLE 的唯一结论"。

4. 反过来看：MSE 隐含了什么假设#

把推导倒着读，同样重要。当你最小化 MSE 时，你其实是在默认：

  1. 噪声服从高斯分布；
  2. 噪声均值为 0；
  3. 噪声同方差（各处波动相同，不随 x 变化）。

如果真实噪声有厚尾（出现极端离群点的概率远高于高斯），MSE 的平方项会被离群点"绑架"，导致模型剧烈偏移——这时绝对值损失（对应拉普拉斯噪声）反而更稳健。损失函数的选择，本质上是噪声分布的选择，这是"知其所以然"后最重要的实战直觉。

5. 噪声方差 σ² 的 MLE#

顺带把 σ² 也做 MLE。固定 (w, b) 后对 σ² 求导令零：

∂/∂σ² log L = −m/(2σ²) + (1/2σ⁴) Σᵢ (yᵢ − ŷᵢ)² = 0
⟹  σ̂² = (1/m) Σᵢ (yᵢ − ŷᵢ)² = MSE(w, b)

噪声方差的 MLE，正好等于最优参数下的 MSE 值。这个漂亮的闭环说明：MSE 不只是"损失"，它本身就是对噪声强度 σ² 的估计——损失的最小值是有物理含义的。

6. 从高斯假设到正规方程（解析解）#

既然 MSE 关于 w 是凸二次函数，就可以解析求解。用矩阵记号（把 b 并入 w，X 前加全 1 列）：

J(w) = (1/m) ‖Xw − y‖²

求梯度并令零：

∇J(w) = (2/m) Xᵀ(Xw − y) = 0
⟹  XᵀXw = Xᵀy
⟹  w* = (XᵀX)⁻¹ Xᵀy

这串推导的起点，就是上面的高斯似然。所以整条链是：高斯噪声假设 → MLE → 平方损失 → 凸优化 → 正规方程。一条假设，贯穿到解。

二、可运行代码示例#

手工验证两件事：① 用"高斯噪声假设"生成数据，再分别用 MLE（正规方程）和直接最小化 MSE 求解，两者应完全一致；② 反过来展示：当噪声换成"厚尾"的拉普拉斯分布时，MSE 解会被离群点带偏，而绝对损失解更稳。

import numpy as np

rng = np.random.default_rng(3)
m = 200
X = np.c_[np.ones(m), rng.uniform(-3, 3, size=m)]
true_w = np.array([2.0, 3.0])

# —— 场景 A：高斯噪声，MLE 与 MSE 应一致 ——
y_gauss = X @ true_w + rng.normal(0, 1, size=m)
w_ml = np.linalg.inv(X.T @ X) @ X.T @ y_gauss          # 正规方程 = MLE
w_mse = np.linalg.lstsq(X, y_gauss, rcond=None)[0]     # 直接最小二乘 = 最小化 MSE
print("高斯噪声下：MLE(正规方程) =", np.round(w_ml, 4))
print("高斯噪声下：最小 MSE      =", np.round(w_mse, 4))
print("两者一致：", np.allclose(w_ml, w_mse))

# —— 场景 B：厚尾（拉普拉斯）噪声 + 人为离群点 ——
y_heavy = X @ true_w + rng.laplace(0, 1, size=m)
y_heavy[0:5] += 60.0                                   # 注入 5 个离群点
w_mse2 = np.linalg.lstsq(X, y_heavy, rcond=None)[0]    # MSE 被离群点拖偏

# 绝对损失（对应拉普拉斯噪声）用次梯度下降求解
w = np.zeros(2); lr = 0.05
for _ in range(5000):
    r = X @ w - y_heavy
    w = w - lr * X.T @ np.sign(r)
w_abs = w
print("厚尾噪声下：MSE 解  =", np.round(w_mse2, 4), "（被离群点带偏）")
print("厚尾噪声下：绝对损失解 =", np.round(w_abs, 4), "（更接近真实 [2,3]）")

两个结论都清楚：高斯噪声下 MLE 与 MSE 完全重合；一旦噪声变厚尾，MSE 立刻被离群点拖走，而绝对损失（对应拉普拉斯噪声的 MLE）稳如泰山。损失函数 = 噪声分布，代码里看得一清二楚。

三、练习#

  1. 从头到尾默写一遍推导：从 y = wᵀx + b + ε, ε~N(0,σ²) 出发，写出似然、取对数、对 w 求导令零，最终得到正规方程。每一步都要说明"为什么可以这么做"。
  2. 若噪声是同方差但非高斯（比如均匀分布 U(−a, a)），MSE 还是 MLE 吗？提示：均匀分布的似然是什么形状，最大似然对应哪种损失？
  3. 证明：把 MSE 换成"加权平方损失" Σᵢ γᵢ(yᵢ−ŷᵢ)²（每个样本权重 γᵢ 不同），等价于假设每个样本的噪声方差不同（异方差）且 σᵢ² ∝ 1/γᵢ。这说明加权回归的由来。
  4. 思考：为什么"噪声高斯"与"噪声拉普拉斯"分别导出平方损失和绝对损失？从两个分布的密度 e^{−x²} 与 e^{−|x|} 的负对数形状上解释。

母原理连接#

本课属于母原理 "概率视角统一"，并且是第一座"概率 ↔ 优化"桥的正式通车。我们证明了：MSE = 高斯噪声 + MLE。平方损失那看似武断的"平方"，其实源自高斯密度里 e^{−x²/2σ²} 的那个平方。从此你选损失函数时就不再"查手册"，而是先问："我认为噪声服从什么分布？"——母原理让你把损失函数的选择，变成了一个可推导、可质疑的概率建模决策。
