SVD 与 ALS#

上一课我们得到了矩阵分解的优化目标，并用 SGD 求解。但 SGD 有一个痛点：它串行地逐样本更新，隐因子维度一多就慢。这一课讲两个"名头很大"的解法——SVD（这里的 SVD 特指推荐领域的 FunkSVD/正则化 SVD）与 ALS（交替最小二乘）：前者讲清"为什么不能直接用线性代数的 SVD"，后者给出一种把非凸问题拆成一串凸子问题的漂亮解法，也是 Implicit 库处理隐式反馈的主力。

一、概念讲解#

1. 线性代数的 SVD：理论与现实的鸿沟#

线性代数里的 SVD 是精确分解 R = U Σ Vᵀ，且 U、V 正交。截断 SVD 取前 k 个奇异值，得到 Frobenius 范数下的最佳低秩近似。但把它直接搬来做推荐会撞上三堵墙：

  1. 缺失值：SVD 要求矩阵完整，评分矩阵却大面积缺失；用 0 或均值填充会把"没评分"错当成"打了 0 分"。
  2. 无正则化：原始 SVD 最小化的是对全矩阵的重构误差，没有防过拟合的惩罚项，稀疏场景下极易过拟合。
  3. 正交约束：U、V 必须正交，这纯粹是线性代数的性质，对推荐任务毫无必要，反而限制了模型的表达自由。

所以推荐领域说的 "SVD"，通常指 Simon Funk 在 Netflix Prize 里提出的 FunkSVD——它放弃了正交约束，把目标改成"观测值上的平方损失 + L2 正则化"，用 SGD 求解。这就是上一课我们手写的那套东西；它在工程上被广泛称为"正则化 SVD"或"隐语义模型"。

2. FunkSVD 与 SGD 的代价#

SGD 求 FunkSVD 的更新规则上一课已经推导：

p_u ← p_u + η ( e_ui · q_i − λ p_u )
q_i ← q_i + η ( e_ui · p_u − λ q_i )

它实现简单、内存友好（每次只处理一个样本），缺点是：每轮要串行扫过所有观测，难以并行；且学习率 η 要细心调，大了震荡、小了慢。

3. ALS：把非凸问题切成凸问题#

回顾优化目标：

J(P, Q) = Σ_{(u,i) ∈ Ω} (R[u,i] − p_uᵀ q_i)² + λ ( Σ_u ‖p_u‖² + Σ_i ‖q_i‖² )

J 对 (P, Q) 整体是非凸的（因为 p_uᵀ q_i 是两个变量相乘）。但 ALS 注意到一个关键事实：固定 Q，J 对 P 是凸的（二次函数）；固定 P，J 对 Q 也是凸的。于是可以用交替（Alternating）策略：

  1. 固定 Q，对每个用户 u 独立地最小化关于 p_u 的二次目标，得到闭式解；
  2. 固定 P，对每个物品 i 独立地最小化关于 q_i 的二次目标，得到闭式解；
  3. 反复交替，直到收敛。

"最小二乘（Least Squares）" 正是指这两步的闭式解——每步都是一个带 L2 正则化的最小二乘问题，可用正规方程解出：

p_u = ( Q_uᵀ Q_u + λ I )⁻¹ Q_uᵀ r_u
q_i = ( P_iᵀ P_i + λ I )⁻¹ P_iᵀ r_i

其中 Q_u 是用户 u 评过分的那些物品的隐向量堆成的矩阵，r_u 是对应的真实评分列向量（P_i、r_i 同理）。

ALS 的优势非常突出：

  • 每步都是凸问题，收敛稳定，不依赖学习率；
  • 高度可并行：固定 Q 求所有 p_u 时，不同用户之间互不依赖，可以并行（Spark MLlib 正是靠这点做分布式 ALS）；
  • 易于扩展：隐式反馈的置信度加权、时间衰减等，都能自然塞进这个二次目标。

4. 隐式反馈的 ALS（Implicit 库的核心）#

隐式反馈里，R[u,i] 不是评分而是"偏好置信度"。Implicit 库采用的形式是：把"是否有交互"记为偏好 p_ui ∈ {0, 1}，再给每个交互一个置信度 c_ui = 1 + α·r_ui（交互次数越多越可信），目标变成：

J = Σ_{(u,i)} c_ui ( p_ui − p_uᵀ q_i )² + λ ( Σ_u ‖p_u‖² + Σ_i ‖q_i‖² )

注意这里连"未交互"的 0 也参与拟合（只是置信度低），因为隐式反馈里"0"代表"尚未观察到"，而非"不喜欢"。于是 ALS 的闭式解里，Q_uᵀ Q_u 项要换成带权重的 Qᵀ C_u Q。这个形式让 ALS 能高效处理上亿规模的隐式行为数据，是 Implicit 库的理论基石。

二、可运行代码示例#

用 NumPy 手写 ALS：每轮先固定 Q 解出所有用户的 P，再固定 P 解出所有物品的 Q。

import numpy as np

R = np.array([
    [5, 3, 0, 1],
    [4, 0, 0, 1],
    [1, 1, 0, 5],
    [0, 0, 0, 4],
    [0, 1, 5, 4],
], dtype=float)

n_users, n_items = R.shape
k = 3
lam = 0.1
iters = 20

rng = np.random.default_rng(0)
P = rng.normal(0, 0.1, (n_users, k))
Q = rng.normal(0, 0.1, (n_items, k))

def solve_users(R, Q, lam):
    """固定 Q，对每个用户独立解 p_u（正规方程）。"""
    k = Q.shape[1]
    P = np.zeros((n_users, k))
    eye = np.eye(k)
    for u in range(n_users):
        idx = np.where(R[u] > 0)[0]          # 该用户评过分的物品编号
        if idx.size == 0:
            continue                          # 没有评分，保持零向量
        Q_u = Q[idx]                          # 对应物品的隐向量矩阵
        r_u = R[u, idx]                       # 真实评分
        # 正规方程: (Q_uᵀQ_u + λI) p_u = Q_uᵀ r_u
        P[u] = np.linalg.solve(Q_u.T @ Q_u + lam * eye, Q_u.T @ r_u)
    return P

def solve_items(R, P, lam):
    """固定 P，对每个物品独立解 q_i（正规方程）。"""
    k = P.shape[1]
    Q = np.zeros((n_items, k))
    eye = np.eye(k)
    for i in range(n_items):
        idx = np.where(R[:, i] > 0)[0]        # 评过该物品的用户编号
        if idx.size == 0:
            continue
        P_i = P[idx]
        r_i = R[idx, i]
        Q[i] = np.linalg.solve(P_i.T @ P_i + lam * eye, P_i.T @ r_i)
    return Q

for it in range(iters):
    P = solve_users(R, Q, lam)   # 第一步：固定 Q，解 P
    Q = solve_items(R, P, lam)   # 第二步：固定 P，解 Q

R_hat = P @ Q.T
print("ALS 补全后的评分矩阵 R̂：\n", np.round(R_hat, 2))

观察要点：ALS 不需要学习率，每步都是精确解，20 轮左右就能稳定收敛。把 iters 加大、lam 调小，会发现解趋向"更贴训练值"；增大 lam 则隐向量被压小、更保守——与 SGD 版同一权衡，但收敛行为更可控。

三、练习#

  1. 把 lam 设为 0，观察 ALS 是否还能稳定求解；当某个用户只评了 1 个物品时，(Q_uᵀ Q_u + λI) 的可逆性会怎样？说明正则化项 λI 除了防过拟合，还承担了"保证可逆"的作用。
  2. 手写推导 p_u 的正规方程：从 min_{p_u} Σ_{i∈Ω_u} (r_ui − p_uᵀq_i)² + λ‖p_u‖² 出发，对 p_u 求梯度并令其为 0，验证 (Q_uᵀQ_u + λI)p_u = Q_uᵀ r_u。
  3. 改造代码实现隐式反馈 ALS：把 R 换成 0/1 交互矩阵 + 置信度 c_ui = 1 + α·R_ui，目标项变为 c_ui (p_ui − p_uᵀq_i)²，写出新的正规方程（提示：Q_uᵀ Q_u 要换成 Qᵀ C_u Q，C_u 是用户 u 的置信度对角阵）。
  4. 对比：用同一矩阵分别跑上一课的 SGD 和本课的 ALS，记录两者收敛所需的"扫描轮数"，谈谈"梯度下降要调学习率"与"ALS 闭式解"在工程上的优劣。

为什么这样做？——理论推导#

为什么"固定一边"就把非凸变成了凸#

J 里唯一的非线性来自 p_uᵀ q_i（两个变量相乘）。固定 Q 后，p_uᵀ q_i 变成"关于 p_u 的线性函数"，于是 (r − p_uᵀ q_i)² 是关于 p_u 的二次函数，加上 λ‖p_u‖² 仍是二次函数——二次函数的 Hessian 是 2(Q_uᵀQ_u + λI)，半正定，故是凸的。凸函数求极值只需"令梯度为 0"，这正是正规方程能直接给出闭式解的原因。

为什么 ALS 能收敛#

ALS 每一步都不增目标函数值（每步在凸子问题里取到最优），且 J ≥ 0 有下界，于是目标值单调递减且有下界 → 必收敛（到某个驻点）。注意它不保证收敛到全局最优（原问题非凸），但实践中结果稳定且够好——这是"坐标下降（Coordinate Descent）"这一大类优化算法的通用保证：把难的非凸问题拆成逐坐标/逐块的凸子问题轮流优化。

母原理连接： ALS 是坐标下降的实例，而坐标下降的核心思想——"抓住一个变量不动、优化另一个"——与机器学习里 EM 算法、k-means 的交替分配/更新，是同一套"交替优化"母题。SGD 是"沿随机梯度一步步下山"，ALS 是"交替地在每个方向上一步到位"，二者分别代表了优化里的一阶随机方法与块坐标方法两大流派。
