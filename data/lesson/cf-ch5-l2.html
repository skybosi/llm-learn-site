常量传播与折叠、死代码消除、公共子表达式#

第 4 章末尾那次 lowering 留下了一串"看得见的低效"：t2 = sum + i; sum = t2、同一个 a + b 算了两次、某些临时名根本没人用。这些不是 lowering 写错了，而是留给优化 pass 的作业。这一课把上一课的三个数据流分析变成三个具体改写：常量传播与折叠、公共子表达式消除（CSE）、死代码消除（DCE）。跑完还会撞见一个反直觉的事实：一轮 pass 往往不够，得跑到不动点。

一、概念讲解#

1. 折叠是局部的，传播是全局的#

  • 常量折叠（constant folding）：同一条指令的两个操作数在编译期都已知，直接算出结果。它只看指令本身，块内一趟扫描就够。
  • 常量传播（constant propagation）：把"某变量在某点必然为常量"的事实沿 CFG 传下去，让远处的指令也有机会折叠。

传播用的格有三个元素：UNDEF（还没有信息，是 meet 的单位元）、CONST(c)、NAC（not-a-constant，一条路径上不是常量就永远是它）。两个不同常量在汇合点 meet 成 NAC——这就是"两条分支分别赋 d = 1 与 d = 2、汇合点无法折叠"的来源。

Kaleidoscope 教程第 4 章给了直观对照：1+2+x 在构造 IR 时就被 IRBuilder 顺手折成 3+x（"trivial constant folding"）；但 (1+2+x)*(x+(1+2)) 里左右两棵子树同值，需要 reassociation（把加法重排成字面相同）加 CSE 才能消掉一次加法。折叠能在前端顺手做，传播与 CSE 必须是独立 pass。

2. 公共子表达式消除需要两个事实#

CSE 的判据听起来简单："右值相同的两条指令只留一条"。要让它正确，需要两个事实合起来：

  1. 这个右值在这一点必然已经算过——上一课的可用表达式（前向 + ∩ + Must）。
  2. 那个"已经算过的结果"现在落在哪个变量里——值编号（value numbering），或者 SSA 直接给出。

只拿第 1 条就动手会出错：知道"a+b 算过"不等于知道"结果还在 t1 里"。只要 t1 被重新赋值，旧结果就作废——传递函数里的 KILL 正是在维护这件事。

3. 复制传播是 CSE 的收尾，也是 DCE 的前提#

CSE 的产物通常是 t = copy t1（"这个值等于 t1"）。就此收手的话，程序里多了一堆 copy，DCE 也不敢删（它们还被后面的指令用着）。标准做法是紧接着做复制传播：把后续对 t 的使用都换成 t1，于是 t 变成一条没人使用的 copy，DCE 才能清掉它。本课代码把三步串起来，最终 4 条指令就是它们的联合成果。

4. 死代码消除的判据：无使用 且 无副作用#

DCE 只有一条硬规则：结果无人使用，并且这条指令不会产生可观察行为。判据要记牢：

指令 结果没人用能否删 原因
copy / 加 / 减 / 乘 / 比较 能 纯计算，不影响可观察状态
除法、可能越界的 load 视情况 可能陷阱，删掉会改变"程序是否出错"
store、函数调用 不能 副作用本身就可观察

"删掉一条没人用的除法"是真实编译器里最常见的正确性 bug 之一，第 5 课会用差分测试把它抓出来。DCE 还必须迭代：删掉 t9 = c * 100 之后，可能又有新的死代码浮出来。

5. 一轮 pass 不够：实测 19 → 6 → 4 → 4#

第 1 轮输出里有一件奇怪的事：f = cc add d 没被折叠，尽管 cc 已经是 18。原因是第 1 轮开始时 d 在两条分支上分别是 1 和 2，汇合点只能保守地判 NAC。直到常量条件 9 > 10 被折成假、B2 变不可达、B1/B3/B4 合并成直线之后，d = 2 才第一次成为确定的事实，第 2 轮才把 f 折成 20：

轮次 指令数 本轮折叠 本轮删除 说明
起始 19 — — 算术指令 8 条
1 6 4 9 常量条件 → 删不可达块、合并、CSE、DCE
2 4 1 2 d = 2 确定后 f 折叠
3 4 0 0 无任何改写 → 到达不动点

Kaleidoscope 第 4 章挂在 FunctionPassManager 上的四个 pass 就是最小组合：InstCombine（窥孔与位运算化简）→ Reassociate（重排加法暴露 CSE 机会）→ GVN（全局值编号做 CSE）→ SimplifyCFG（删不可达块、简化分支）。

6. 常见坑#

  • 折叠会陷阱的表达式：100 / 0 不能"折叠成一个陷阱"，因为原程序可能根本不执行那条指令。
  • 忽略溢出语义：x * 2 → x + x 在补码回绕下等价，但 x / 2 → x >> 1 不等价（第 5 课给反例）。
  • DCE 把 store 或调用删掉："结果没人用"对副作用指令不成立。

二、可运行代码示例#

下面这段纯 Python 实现一条四段式过程内管线：常量传播/折叠（CFG 上的前向不动点）→ 删不可达块与合并线性链 → 块内值编号（CSE）与复制传播 → 死代码消除。外层驱动一直跑到"本轮没有任何改写"为止，并把每一轮的指令序列打印出来。

# ---- 常量传播/折叠 + 分支化简 + 复制传播/CSE + 死代码消除（纯 Python，无第三方依赖）----
BIN = {'add', 'sub', 'mul', 'div'}
OPS = {'add': lambda x, y: x + y, 'sub': lambda x, y: x - y,
       'mul': lambda x, y: x * y, 'div': lambda x, y: x // y}
CMPS = {'>': lambda x, y: x > y, '<': lambda x, y: x < y,
        '>=': lambda x, y: x >= y, '<=': lambda x, y: x <= y,
        '==': lambda x, y: x == y, '!=': lambda x, y: x != y}


def nm(x):
    return ('name', x)


def ct(k):
    return ('const', k)


def op_str(x):
    return str(x[1]) if x else '-'


def fmt(ins):
    op = ins[0]
    if op == 'copy':
        return f'{ins[3]} = {op_str(ins[1])}'
    if op in BIN:
        return f'{ins[3]} = {op_str(ins[1])} {op} {op_str(ins[2])}'
    if op == 'cmp':
        return f'{ins[4]} = {op_str(ins[2])} {ins[1]} {op_str(ins[3])}'
    if op == 'ifgoto':
        return f'if {op_str(ins[1])} goto {ins[2]} else {ins[3]}'
    if op == 'goto':
        return f'goto {ins[1]}'
    if op == 'return':
        return f'return {op_str(ins[1])}'
    return str(ins)


def def_use(ins):
    op = ins[0]
    if op == 'copy':
        return ins[3], [ins[1]]
    if op in BIN:
        return ins[3], [ins[1], ins[2]]
    if op == 'cmp':
        return ins[4], [ins[2], ins[3]]
    if op in ('ifgoto', 'return'):
        return None, [ins[1]]
    return None, []


PROG = {
    'B1': [('copy', ct(3), None, 'n'),
           ('copy', ct(4), None, 'a'),
           ('copy', ct(5), None, 'b'),
           ('add', nm('a'), nm('b'), 't1'),
           ('mul', nm('t1'), ct(2), 'c'),
           ('cmp', '>', nm('t1'), ct(10), 't2'),
           ('ifgoto', nm('t2'), 'B2', 'B3')],
    'B2': [('copy', ct(1), None, 'd'), ('goto', 'B4')],
    'B3': [('copy', ct(2), None, 'd'), ('goto', 'B4')],
    'B4': [('add', nm('p'), nm('q'), 'e'),
           ('copy', nm('c'), None, 'cc'),
           ('add', nm('cc'), nm('d'), 'f'),
           ('mul', nm('c'), ct(100), 't9'),
           ('add', nm('p'), nm('q'), 'g'),
           ('add', nm('e'), nm('f'), 'r'),
           ('add', nm('r'), nm('g'), 's'),
           ('return', nm('s'))],
}


def succ_of(prog):
    s = {}
    for b, ins_list in prog.items():
        last = ins_list[-1] if ins_list else None
        if last and last[0] == 'goto':
            s[b] = [last[1]]
        elif last and last[0] == 'ifgoto':
            s[b] = [last[2], last[3]]
        else:
            s[b] = []
    return s


def preds_of(prog):
    succ, order = succ_of(prog), list(prog)
    return {b: [p for p in order if b in succ[p]] for b in order}


# ---------- pass 1：常量传播 + 常量折叠（CFG 上的前向不动点，格 = UNDEF/常量/NAC）----------
def lattice_value(ins, state):
    """指令执行后，结果变量的格值：('C', v) 或 ('NAC',)；无定义返回 None"""
    op = ins[0]
    d, ops = def_use(ins)
    if d is None:
        return None
    vals = [state.get(x[1]) if x[0] == 'name' else ('C', x[1]) for x in ops]
    if op == 'copy':
        return vals[0] if vals[0] and vals[0][0] == 'C' else ('NAC',)
    if all(v and v[0] == 'C' for v in vals):
        f = OPS[op] if op in BIN else CMPS[ins[1]]
        return ('C', int(f(*[v[1] for v in vals])))
    return ('NAC',)


def const_prop(prog):
    order, entry = list(prog), list(prog)[0]
    pred = preds_of(prog)

    def meet(maps):
        keys = set().union(*[set(m) for m in maps]) if maps else set()
        out = {}
        for k in keys:
            vals = [m.get(k) for m in maps]
            if any(v is None for v in vals):
                continue                                # 某条路径还没有信息 → UNDEF 是单位元
            out[k] = vals[0] if all(v == vals[0] for v in vals) else ('NAC',)
        return out

    IN, folds, props = {b: {} for b in order}, 0, 0
    for _ in range(50):                                 # 阶段 A：只算不动点，不改程序
        changed = False
        for b in order:
            nin = {} if b == entry else (meet([IN[p] for p in pred[b]]) if pred[b] else {})
            state, cur = dict(nin), dict(nin)
            for ins in prog[b]:
                v = lattice_value(ins, cur)
                if v is not None:
                    cur[def_use(ins)[0]] = v
            if cur != IN[b]:
                IN[b], changed = cur, True
        if not changed:
            break

    out_prog = {}
    for b in order:                                     # 阶段 B：带着定局的信息改写指令
        nin = {} if b == entry else (meet([IN[p] for p in pred[b]]) if pred[b] else {})
        state, new_list = dict(nin), []
        for ins in prog[b]:
            op = ins[0]
            if op == 'goto':
                new_list.append(ins)
                continue
            if op == 'ifgoto':
                v = state.get(ins[1][1])
                if v and v[0] == 'C':                   # 条件已知 → 分支退化成一条边
                    new_list.append(('goto', ins[2] if v[1] else ins[3]))
                else:
                    new_list.append(ins)
                continue
            d, ops = def_use(ins)
            vals = [state.get(x[1]) if x[0] == 'name' else ('C', x[1]) for x in ops]
            known = all(v and v[0] == 'C' for v in vals)
            if op == 'copy' and known:
                if ops[0][0] == 'name':
                    props += 1
                new_list.append(('copy', ct(vals[0][1]), None, d))
            elif op in BIN or op == 'cmp':
                if known:
                    folds += 1
                    f = OPS[op] if op in BIN else CMPS[ins[1]]
                    new_list.append(('copy', ct(int(f(*[v[1] for v in vals]))), None, d))
                else:
                    new_ops = [ct(state[x[1]][1]) if x[0] == 'name' and state.get(x[1], ('NAC',))[0] == 'C' else x
                               for x in ops]
                    new_list.append(('copy', new_ops[0], None, d) if op == 'copy' else
                                    ((op, new_ops[0], new_ops[1], d) if op in BIN else
                                     ('cmp', ins[1], new_ops[0], new_ops[1], d)))
            else:
                new_list.append(ins)
            v = lattice_value(ins, state)
            if v is not None:
                state[d] = v
        out_prog[b] = new_list
    return out_prog, folds, props


# ---------- pass 2：删不可达块 + 合并线性链 ----------
def prune_and_merge(prog):
    reach, stack = {list(prog)[0]}, [list(prog)[0]]
    while stack:
        for s in succ_of(prog)[stack.pop()]:
            if s not in reach:
                reach.add(s)
                stack.append(s)
    prog = {b: prog[b] for b in prog if b in reach}
    merged = True
    while merged:
        merged = False
        succ, pred = succ_of(prog), preds_of(prog)
        for b in list(prog):
            s = succ[b]
            if len(s) == 1 and s[0] != b and len(pred[s[0]]) == 1 and prog[b][-1][0] == 'goto':
                tgt = s[0]
                body = prog[b][:-1] + prog[tgt]
                prog = {k: (body if k == b else v) for k, v in prog.items() if k != tgt}
                merged = True
                break
    return prog


# ---------- pass 3：块内值编号（CSE）+ 复制传播 ----------
def cse_and_copy_prop(prog):
    for b, ins_list in prog.items():
        vn, out = {}, []
        for ins in ins_list:
            op = ins[0]
            if op == 'copy':
                key = ('copy', ins[1])
                if key in vn:
                    out.append(('copy', nm(vn[key]), None, ins[3]))
                else:
                    vn[key] = ins[3]
                    out.append(ins)
                continue
            if op not in BIN and op != 'cmp':
                out.append(ins)
                continue
            key = (op, ins[1], ins[2]) if op in BIN else (op, ins[1], ins[2], ins[3])
            d = ins[3] if op in BIN else ins[4]
            if key in vn:                               # 右值相同 → 复用已有结果
                out.append(('copy', nm(vn[key]), None, d))
            else:
                vn[key] = d
                out.append(ins)
                for k in [k for k in vn if any(isinstance(x, tuple) and x == nm(d) for x in k[1:])]:
                    del vn[k]                           # d 被重定义 → 含它的表达式失效
        prog[b] = out
    alias = {}
    for b in prog:                                      # 复制传播
        for i, ins in enumerate(prog[b]):
            if ins[0] == 'copy' and ins[1] and ins[1][0] == 'name':
                src = alias.get(ins[1][1], ins[1][1])
                alias[ins[3]] = src
                prog[b][i] = ('copy', nm(src), None, ins[3])
    for b in prog:
        prog[b] = [rewrite(ins, alias) for ins in prog[b]]
    return prog


def rewrite(ins, alias):
    op = ins[0]

    def sub(x):
        return nm(alias[x[1]]) if x and x[0] == 'name' and x[1] in alias else x
    if op == 'copy':
        return ('copy', sub(ins[1]), None, ins[3])
    if op in BIN:
        return (op, sub(ins[1]), sub(ins[2]), ins[3])
    if op == 'cmp':
        return ('cmp', ins[1], sub(ins[2]), sub(ins[3]), ins[4])
    if op == 'ifgoto':
        return ('ifgoto', sub(ins[1]), ins[2], ins[3])
    return ins


# ---------- pass 4：死代码消除（迭代到不动点）----------
def dce(prog):
    removed = 0
    while True:
        used = {x[1] for b in prog for ins in prog[b] for x in def_use(ins)[1]
                if x and x[0] == 'name'}
        new, cut = {}, 0
        for b in prog:
            keep = []
            for ins in prog[b]:
                d, _ = def_use(ins)
                if d is not None and d not in used:     # 结果无人使用且无副作用 → 删
                    cut += 1
                    continue
                keep.append(ins)
            new[b] = keep
        removed, prog = removed + cut, new
        if cut == 0:
            return prog, removed


def stats(prog):
    return (sum(len(v) for v in prog.values()),
            sum(1 for v in prog.values() for i in v if i[0] in BIN))


prog = PROG
print('=== 原始程序 ===')
for b in prog:
    for ins in prog[b]:
        print(f'  {b}: {fmt(ins)}')
print(f'  指令 {stats(prog)[0]} 条，算术 {stats(prog)[1]} 条\n')

tot_f = tot_p = tot_d = 0
for rnd in range(1, 6):
    before = repr(prog)
    prog, folds, props = const_prop(prog)
    prog = prune_and_merge(prog)
    prog = cse_and_copy_prop(prog)
    prog, cut = dce(prog)
    tot_f, tot_p, tot_d = tot_f + folds, tot_p + props, tot_d + cut
    n, arith = stats(prog)
    print(f'=== 第 {rnd} 轮 pass 管线：指令 {n} 条 / 算术 {arith} 条'
          f'（本轮折叠 {folds}、常量传播 {props}、删除 {cut}）===')
    for b in prog:
        for ins in prog[b]:
            print(f'  {b}: {fmt(ins)}')
    print()
    if repr(prog) == before and folds == props == cut == 0:
        print('本轮没有任何改写 → pass 管线到达不动点，停止')
        break
print(f'累计：常量折叠 {tot_f} 次、常量传播 {tot_p} 次、死代码删除 {tot_d} 条；'
      f'算术指令 {stats(PROG)[1]} → {stats(prog)[1]}')

三、练习#

  1. 实现：给常量格加"除零/移位量非法 → 拒绝折叠"的保护，用 t = 100 / y（y 未知）验证它不会被折成常量；再把 y 换成常量 0，观察输出变成什么（提示：真实编译器的选择是保留这条指令，而不是制造一个编译期错误）。
  2. 解释：为什么 CSE 需要"可用表达式 + 值编号"两件事？只拿"可用表达式"会写错在哪一步？只拿"块内值编号"又会漏掉什么？
  3. 对比/验证：把管线里的 DCE 去掉跑一遍，指出第 1 轮输出里多出哪些指令；再去掉 CSE 与复制传播，比较最终指令数（提示：体会三个 pass 的收益是乘法关系，不是各自独立相加）。
  4. 思考：如果把顺序换成"先 DCE 再折叠再 CSE"，最终程序会不会一样？举一个某种顺序需要多跑一轮、而另一种顺序一轮就够的例子。
