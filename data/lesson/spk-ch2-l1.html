从 HMM-GMM 到端到端：序列级训练改变了什么#

这一节要解决什么#

上一章把声音变成了坐标：采样率、帧长、帧移、梅尔刻度、倒谱阶数。坐标定好之后，声学模型的第一个问题不是"用什么网络"，而是：

输入是一串 T 帧、输出是一串 L 个符号，两边长度不等、边界不知道。这个"不知道的对应关系"该怎么处理？

三十年来只有三种答案，它们是这一章的主线：

答案 对齐是什么 训练目标 代表
把它当隐变量，用生成式模型积分掉 HMM 的状态序列 maxλ​logpλ​(x) 或 logpλ​(x,y) GMM-HMM
把它当隐变量，但目标是后验 同上（HMM 拓扑） maxλ​logpλ​(y∣x) 或直接接近 WER 的量 MMI / MPE / sMBR（仍是 HMM）
把它当隐变量，用神经网络给每个候选路径打分 CTC 的路径 / 注意力权重 / RNN-T 格点 maxθ​logpθ​(y∣x)，y 只有符号序列 CTC / attention encoder-decoder / RNN-T

第三行就是"端到端"。它常被说成"把声学模型、发音词典、语言模型合成一个网络"，这个说法对但没用——它没有说出到底哪一步变了。本节要用一组可复算的算术把变化定位到三个具体的量上：

  1. 责任度（responsibility）：帧 t 的标签 s 由"只看这一帧的发射后验"变成"在全部可行对齐上归一后的后验 γt​(s)"（§2.2，表 6）；
  2. 时间信息的流向：从"逐帧因果"变成"整句非因果"（§2.3，表 6b，最大 L1 差 0.2510）；
  3. 求和范围：从 NT 条状态路径变成"与 y 一致的那部分路径"，规模 T(2L+1) 或 TU（§3.3，表 9：10360.2 → 104）。

而代价也是三笔，且每一笔都能算成数：

  • 帧级指标与序列级后果脱钩：帧准确率从 0.7355 提到 0.9307（1.27 倍），句子全对率从 0.0030 涨到 0.4240（141.33 倍）（表 5）；
  • 流式约束被打破：非因果平滑把未来帧的证据回传到当前帧，流式系统必须重新把它切掉（表 6b）；
  • 标注与先验的账变了：不再需要帧级对齐，但需要把语言先验从模型里显式拆出来（第 2 节表 12 给出 CTC 的标签相依只有 0.0776 nats，第 4 节讲怎么补）。

本节不讨论"端到端是否更好"这种问法，因为它没有判据。本节讨论的是：换了哪个量、买到什么、欠什么、在什么条件下会整体失效。

1.2 帧级独立假设买到了什么：对数似然可分解#

这个假设的准确表述是：给定状态序列 π，各帧的观测条件独立，

p(x1:T​∣π1:T​)=t=1∏T​p(xt​∣πt​)

于是对数似然变成逐帧可加：

logp(x1:T​∣π1:T​)=t=1∑T​logp(xt​∣πt​),logp(x1:T​,π1:T​)=t=1∑T​logp(xt​∣πt​)+t=2∑T​logaπt−1​πt​​+logπ0,π1​​

这不是一个技术细节，它是整套训练算法成立的前提：

  1. E 步有闭式解：Baum-Welch 的 E 步要算每个状态的占用后验 γt​(s)=p(πt​=s∣x1:T​)，它由前向后向给出（§1.3）。如果帧之间不独立，γt​(s) 没有因子分解形式，E 步就没有闭式。
  2. 目标函数单调上升：EM 的单调性证明依赖 logp(x)≥Eq​[logp(x,π)]+H(q) 这个下界，而下界里那一项正是"逐帧求和"。
  3. 状态后验可以只用局部量递推：前向 αt​(s) 只依赖 αt−1​(⋅) 与第 t 帧的发射概率，复杂度 O(TN2)。

买到的另一个东西是可解释的对齐：γt​(s) 直接给出"第 t 帧属于哪个音素"的后验，Viterbi 的 argmax 给出唯一的一条切分。这是 GMM-HMM 时代的强制对齐（forced alignment）工具的基础，也是它今天仍然在做的事（给 TTS 造时长标注、给 CTC 造初始对齐）。

二、判别式转向：从最大化观测似然到最大化正确序列后验#

2.1 目标函数换了什么#

HMM 的 ML 训练最大化 logpλ​(x)（或 logpλ​(x,π∗)）。它有一个结构性错配：训练目标里没有 y。对识别任务而言，模型把概率质量花在区分 x 的各种可能来源上（说话人、信道、噪声），而这些对"这句话是什么"没有用。

判别式训练把目标换成后验。三种常见形式：

FMMI​=u∑​log∑π​pλ​(xu​∣π)P(π)pλ​(xu​∣πu∗​)P(πu∗​)​

FMMI​=u∑​log∑π​pλ​(xu​∣π)P(π)pλ​(xu​∣πu∗​)P(πu∗​)​

FMPE​=u∑​π∑​pλ​(π∣xu​)Accuracy(π,πu∗​)

FMPE​=u∑​π∑​pλ​(π∣xu​)Accuracy(π,πu∗​)

FsMBR​=u∑​∑π​pλ​(π∣xu​)∑π​pλ​(π∣xu​)e−σWER(π,πu∗​)​​

FsMBR​=u∑​∑π​pλ​(π∣xu​)∑π​pλ​(π∣xu​)e−σWER(π,πu∗​)​​

三者的共同结构是：分子奖励正确序列，分母（或期望）惩罚全部竞争序列。MMI 的分母就是那个配分函数。本节用 MMI 做算例，因为它的形式最简单且能精确算：

FMMI​=logp(x,π∗)−logp(x)

FMMI​=logp(x,π∗)−logp(x)

也就是 §1.3 那个"边缘化增益"的相反数。序列级目标与帧级目标的差别就是这一项，它把全部竞争序列的概率压下去，而不只是把正确状态的概率抬上来。

2.3 代价二：非因果，以及仍然需要帧级标注#

表 6b 对比了两种 γ：

  • γtcausal​：只用 x1:t​（前向归一，滤波）；
  • γtfull​：用整句 x1:T​（前向后向，平滑）。

逐帧 L1 差的最大值是 t=6 处的 0.2510，中间帧普遍在 0.11∼0.18，两端为 0。序列级训练会把未来的证据回传到当前帧。 这不只是一个实现细节：

  • 它解释了为什么整句训练的模型在流式场景下会掉点——推理时看不到未来，训练时看到了；
  • 它解释了为什么"双向编码器 + CTC"与"单向编码器 + CTC"不是同一个模型；
  • 它给出了流式改造的判据：把 γfull 换成 γcausal 后，若 L1 差超过某个阈值 ε，就必须在训练时显式加因果约束，而不能指望模型自动学会等待。 本算例里 maxt​∥γtcausal​−γtfull​∥1​=0.2510。

第二笔代价是仍然需要帧级标注：MMI/MPE/sMBR 都要求一个 HMM 拓扑（发音词典、状态绑定、决策树），而这些需要帧级对齐来训练。发音词典本身也是人工产物。这就是为什么"端到端"的价值主要不在精度，而在把这条标注链拆掉。

第三笔代价是 MPE/sMBR 的目标不可微：WER(π,π∗) 对参数没有梯度，只能写成期望的形式，并且要对全部候选路径求期望（实践中用 lattice 近似）。要直接优化 WER 就必须把 WER 写成一个可求期望的量——这是第 4 节评测那节的伏笔：如果一个指标无法被写成期望，它就只能用来评测，不能用来训练。

三、端到端：换了什么#

3.1 三个结构，三种对齐假设#

端到端的共同点是把上面的三样东西一次性换掉：

  • 声学模型 + 发音词典 + 语言模型 → 一个神经网络；
  • 帧级状态标注 → 只有符号序列 y；
  • HMM 状态图 → 一个由模型自己定义的"对齐空间"。

真正重要的是第三点，因为三种结构就是三种不同的对齐空间：

结构 对齐空间 定义 关键约束
CTC 长度 T 的路径 π∈(A∪{∅})T 合并相邻重复、删 blank 每帧一个符号；标签之间条件独立
注意力 encoder-decoder 长度 L 的注意力矩阵 al,t​ cl​=∑t​al,t​ht​ 无单调约束，无长度约束
RNN-T T×U 格点上的单调路径 删 blank（不合并重复） u 随 t 不减；允许一帧连发多标签

它们的训练目标都是 maxθ​logpθ​(y∣x)，但 pθ​(y∣x) 的定义完全不同：

pCTC​(y∣x)=π∈B−1(y)∑​t=1∏T​p(πt​∣x),B:合并重复后删空

patt​(y∣x)=l=1∏L​p(yl​∣y<l​,x),cl​=t=1∑T​al,t​ht​

pRNN-T​(y∣x)=单调路径∑​∏(blank 或标签)

这三种定义带来三种完全不同的性质，第 2、3 节会各自展开并给出完整推导与数值算例。本节只处理它们共同的"代价账"。

3.2 表 8：对齐从监督信号变成损失的副产品#

GMM-HMM 的对齐是训练出来的隐变量（Baum-Welch）或标注出来的（强制对齐）。CTC 的对齐是损失的副产品：因为

−logp(y∣x)

在 p(y∣x) 上单调递减，而 p(y∣x) 是全部对齐路径的和，最小化这个损失会间接把概率质量往少数几条路径上集中——也就是让对齐变尖（peakiness）。输出表 8 用温度 τ 把这件事扫出来：

把本节的全部结论收成一张表。这是本节要交付的核心：

这张表要读的方式：每一行的右侧不是"更好"，而是"换了一笔账"。三个最容易被忽略的账：

  1. 数据账。端到端把发音词典与状态绑定这些先验扔了，等于把它们的泛化能力也扔了。在小数据（<100 h）下，hybrid 系统通常仍占优，因为它把大量语言学先验白送进来。这条结论是经验性的（属于"已确证的机制"，不是本课算出来的）。
  2. 上下文偏置账。hybrid 系统改一个词只要改发音词典与 LM 的 n-gram 计数，可以做到按会话注入；端到端要改就得动解码（如 shallow fusion 的偏置列表、或前缀树约束）。这一项的工程代价在本表里不占任何列，但它是工业系统选 RNN-T + 外接 LM 的最主要理由。
  3. 可审计账。hybrid 的中间产物（帧级对齐、LM 分数、发音序列）都是可打印可核对的；端到端的中间产物只有一堆后验。第 4 节讲评测时会看到，端到端系统里最容易被平均掉的恰是最需要被看见的那部分（实体）。

六、取舍与边界#

(1) 帧级独立假设的边界不是"错"，而是"够不够"。 在观测足够判别（信噪比高、音素区分度大）时，pL 与实测序列准确率的差距小；在表 5 这种噪声大到帧准确率只有 0.7355 的设置里，差距放大到 141 倍。可算判据：先算 Viterbi 的帧准确率 p 与句长 L，若 pL 已经能解释实测句子全对率的 80% 以上，说明帧间相关性弱，帧级指标可以近似用；否则必须报序列级指标。表 5 里 0.2377/0.4240=0.56，远低于 0.8，所以帧级指标不可用。

(2) 判别式训练的边界是配分函数的可算性。 MMI 的分母要对全部竞争序列求和。在 HMM 里这是一次前向后向；在端到端里这就是 pθ​(y∣x) 的分母。如果分母不可算，判别式目标就写不出来——这一步把"用哪个模型"的问题变成了"哪个对齐空间允许高效的边缘化"的问题。第 2 节的 CTC 递推与第 3 节的 RNN-T 递推就是两个答案。

(3) 缩放律在本节的算术里不出现，必须单独说。 上面所有账都是机制账：给定模型，责任度怎么算、时间信息怎么流、搜索空间多大。它们不含"数据量从 100 h 涨到 10 kh 时谁更好"这类结论，因为那需要经验曲线。本课会在第 5 节（端到端语音大模型）再回到这个问题，并明确标注哪些是机制、哪些是经验观察。

(4) 一个常见误读要在这里掐掉。 "CTC/RNN-T 假设帧间独立"这句话是错的。它们不假设输入帧独立——编码器可以是任意函数，能看到全部 x（CTC 的 p(πt​∣x) 依赖整句 x）。它们假设的是输出符号在给定 x 后独立：

p(π∣x)=t=1∏T​p(πt​∣x)

折叠成标签序列后，p(y∣x) 也不再独立（第 2 节表 12 实测 I(y1​;y2​)=0.0776 nats）。所以准确的说法是：CTC 的标签相依完全由对齐竞争产生，模型没有为"语言"单独留参数。这解释了为什么 CTC 系统几乎总要外接 LM，也解释了为什么在低资源下 CTC 的 WER 常高于注意力模型（后者的解码器本身就是一个语言模型）。

(5) 本节所有数字的可复现性。 观测、状态路径、GMM 参数、分类实验全部是合成的（⚠️），随机种子固定为 20240903 与 7。代码只用标准库。给定同一份代码，输出逐字节一致。凡引用外部经验结论（例如 §4 的数据账）都已标注。

下面的脚本用纯标准库算出本节全部数字，共六部分：HMM-GMM 的似然分解与前向验证、帧准确率到序列准确率的换算、帧级与序列级目标的梯度对照、CTC 对齐熵的温度扫描、搜索空间账，以及换代的三笔账（参数、标注、改动面）。所有信号与打分都是合成的。

"""
spk-ch2-l1  HMM-GMM 到端到端：帧级目标与序列级目标差在哪
仅用标准库。⚠️ 所有观测、状态路径、发射参数与打分都是合成的。
"""
import math
import random

# ======================================================================
# 0. 工具
# ======================================================================
NEG = float("-inf")

def logsumexp(xs):
    m = max(xs)
    if m == NEG:
        return NEG
    return m + math.log(sum(math.exp(x - m) for x in xs))

def gauss_logpdf(x, mu, var):
    return -0.5 * math.log(2.0 * math.pi * var) - (x - mu) ** 2 / (2.0 * var)

def softmax(xs):
    m = max(xs)
    e = [math.exp(x - m) for x in xs]
    z = sum(e)
    return [v / z for v in e]

def entropy(ps):
    return -sum(p * math.log(p) for p in ps if p > 1e-300)

def safe_log(p):
    return math.log(p) if p > 0 else NEG

def dw(s):
    """显示宽度：CJK 与全角标点按 2 列计。"""
    return sum(2 if (ord(c) > 0x1100 and (ord(c) <= 0x115f or 0x2e80 <= ord(c) <= 0xa4cf
               or 0xac00 <= ord(c) <= 0xd7a3 or 0xf900 <= ord(c) <= 0xfaff
               or 0xfe30 <= ord(c) <= 0xfe6f or 0xff00 <= ord(c) <= 0xff60
               or 0xffe0 <= ord(c) <= 0xffe6 or 0x3000 <= ord(c) <= 0x303f)) else 1
               for c in s)

def pad(s, w, left=False):
    n = w - dw(s)
    return (" " * n + s) if left else (s + " " * n)

# ======================================================================
# 1. HMM-GMM：似然怎么分解，前向怎么把它求和起来
# ======================================================================
# 3 状态左到右 HMM，每状态 2 分量一维 GMM（对角协方差）
N = 3
A = [[0.60, 0.40, 0.00],
     [0.00, 0.60, 0.40],
     [0.00, 0.00, 1.00]]
LOGA = [[safe_log(p) for p in row] for row in A]
PI0 = [1.0, 0.0, 0.0]           # 初始分布：从状态 0 出发
LOGP0 = [safe_log(p) for p in PI0]
W = [[0.65, 0.35], [0.50, 0.50], [0.40, 0.60]]
MU = [[-1.20, 0.90], [0.10, 1.30], [1.10, -0.60]]
VAR = [[0.25, 0.36], [0.30, 0.25], [0.30, 0.25]]
T = 8
SEED = 20240903

def emit_logpdf(s, x):
    """log p(x|s)：该状态两个高斯分量的加权和（logsumexp 而不是取最大）。"""
    return logsumexp([math.log(W[s][k]) + gauss_logpdf(x, MU[s][k], VAR[s][k])
                      for k in range(2)])

def sample_sequence(rng, T):
    path, xs, comps = [], [], []
    s = 0
    for t in range(T):
        if t > 0 and rng.random() > A[s][s] and s + 1 < N:
            s += 1
        k = 0 if rng.random() < W[s][0] else 1
        xs.append(rng.gauss(MU[s][k], math.sqrt(VAR[s][k])))
        path.append(s); comps.append(k)
    return path, xs, comps

def forward_log(xs):
    T = len(xs)
    al = [[NEG] * N for _ in range(T)]
    for s in range(N):
        al[0][s] = LOGP0[s] + emit_logpdf(s, xs[0])
    for t in range(1, T):
        for s in range(N):
            al[t][s] = logsumexp([al[t - 1][r] + LOGA[r][s] for r in range(N)]) \
                       + emit_logpdf(s, xs[t])
    return al

def backward_log(xs):
    T = len(xs)
    be = [[NEG] * N for _ in range(T)]
    for s in range(N):
        be[T - 1][s] = 0.0
    for t in range(T - 2, -1, -1):
        for s in range(N):
            be[t][s] = logsumexp([LOGA[s][r] + emit_logpdf(r, xs[t + 1]) + be[t + 1][r]
                                  for r in range(N)])
    return be

def loglik_path(path, xs):
    """log p(x_{1..T}, pi*) = 逐帧发射求和 + 逐转移求和。"""
    v = LOGP0[path[0]]
    for t in range(1, len(path)):
        v += LOGA[path[t - 1]][path[t]]
    v += sum(emit_logpdf(path[t], xs[t]) for t in range(len(xs)))
    return v

def all_valid_paths(T):
    out = []
    def rec(t, s, cur):
        if t == T:
            out.append(list(cur)); return
        for r in range(N):
            if (t == 0 and PI0[r] > 0) or (t > 0 and A[s][r] > 0):
                rec(t + 1, r, cur + [r])
    rec(0, 0, [])
    return out

            dp[0][s] = LOGT[0][s] + gauss_logpdf(obs[0], mu[s], sd * sd)
        for t in range(1, Tt):
            for s in range(2):
                best, arg = NEG, 0
                for r in range(2):
                    v = dp[t - 1][r] + LOGT[r][s]
                    if v > best:
                        best, arg = v, r
                dp[t][s] = best + gauss_logpdf(obs[t], mu[s], sd * sd)
                bp[t][s] = arg
        s = 0 if dp[Tt - 1][0] > dp[Tt - 1][1] else 1
        dec_vit = [0] * Tt
        for t in range(Tt - 1, -1, -1):
            dec_vit[t] = s; s = bp[t][s]
        ok_l = sum(1 for t in range(Tt) if dec_loc[t] == truth[t])
        ok_v = sum(1 for t in range(Tt) if dec_vit[t] == truth[t])
        frm_loc += ok_l; frm_vit += ok_v
        sent_loc += (ok_l == Tt); sent_vit += (ok_v == Tt)
    a_loc = frm_loc / tot; a_vit = frm_vit / tot
    print("=" * 78)
    print("表 5  实测：同一批观测，帧独立判决 vs 用转移矩阵的 Viterbi（%d 句 x %d 帧）"

    print("=" * 78)

          % (Tr[0][0], Tr[0][1], Tr[1][1], sd, sd))
    print()
    print("   解码器             |  帧准确率 |  句子全对率（实测） | 句子全对率（按 p^L 独立外推）")

def part_4():
    print()
    print("=" * 78)
    print("表 8  CTC 对齐的模糊度：峰锐度 -> 损失 与 对齐熵")
    print("=" * 78)
    print("   合成发射：u[t][c] = -|t - center_c| / tau，T=8，center(空)= -0.30/tau，center(a)=3，center(b)=6")
    print("   标签 y='ab'，L=2，扩展标签 l = [空,a,空,b,空]（2L+1 = 5）")
    print()
    print("     tau |  p(y|x)  | -log p(y|x) | H(对齐|a) | H(对齐|b) | 平均 H(状态占用)")
    print("   ------+----------+-------------+-----------+-----------+-----------------")
    BL = '-'
    l = [BL, 'a', BL, 'b', BL]
    S = len(l)
    Tt = 8
    cen = {'a': 3.0, 'b': 6.0}
    for tau in (2.5, 1.5, 1.0, 0.6, 0.35, 0.2):
        ps_t = []
        for t in range(Tt):
            row = [-0.30 / tau]
            for c in ('a', 'b'):
                row.append(-abs(t - cen[c]) / tau)
            ps_t.append(softmax(row))
        def em(c, t):
            return ps_t[t][{BL: 0, 'a': 1, 'b': 2}[c]]
        fa = [[0.0] * (S + 1) for _ in range(Tt + 1)]
        fa[1][1] = em(l[0], 0); fa[1][2] = em(l[1], 0)
        for t in range(2, Tt + 1):
            for s in range(1, S + 1):
                if s == 1:
                    fa[t][s] = fa[t - 1][s] * em(l[s - 1], t - 1); continue
                v = fa[t - 1][s] + fa[t - 1][s - 1]
                if l[s - 1] != BL and s - 3 >= 0 and l[s - 1] != l[s - 3]:
                    v += fa[t - 1][s - 2]
                fa[t][s] = v * em(l[s - 1], t - 1)
        fb = [[0.0] * (S + 2) for _ in range(Tt + 2)]
        fb[Tt][S] = 1.0; fb[Tt][S - 1] = 1.0
        for t in range(Tt - 1, 0, -1):
            for s in range(1, S + 1):
                v = fb[t + 1][s] * em(l[s - 1], t)
                if s + 1 <= S:
                    v += fb[t + 1][s + 1] * em(l[s], t)
                if s + 2 <= S and l[s - 1] != BL and l[s + 1] != l[s - 1]:
                    v += fb[t + 1][s + 2] * em(l[s + 1], t)
                fb[t][s] = v
        py = fa[Tt][S] + fa[Tt][S - 1]
        g = [[fa[t][s] * fb[t][s] / py for s in range(1, S + 1)] for t in range(1, Tt + 1)]
        def align_H(st):
            w = [g[t][st - 1] for t in range(Tt)]
            z = sum(w)
            return entropy([v / z for v in w])
        print("   %5.2f | %8.5f | %11.5f | %9.4f | %9.4f | %15.4f"
              % (tau, py, -math.log(py), align_H(2), align_H(4),
                 sum(entropy(g[t]) for t in range(Tt)) / Tt))
    print()
    print("   读数一：-log p(y|x) 单调降时，两个标签的对齐熵也单调降 —— 损失函数自己在把对齐推向确定。")
    print("   读数二：对齐熵是一个可算的责任度读数（此处以 nats 计），帧级监督把它直接写成 one-hot，熵恒为 0。")

小结#

  • 端到端改变了三个具体的量，不是一句"合成了一个模型"：责任度（局部后验 → 前后向 γ，真实状态的平均责任度 0.5231→0.7427）、时间信息流向（因果 → 非因果，最大 L1 差 0.2510）、求和范围（NT → T(2L+1) 或 TU）。
  • HMM-GMM 的帧级独立假设买到的是可分解的对数似然，它带来 E 步闭式、EM 单调上升与 O(TN2) 的前向；本算例中前向与暴力枚举的差只有 1.776×10−15，边缘化增益 +2.803697 nats。
  • 帧级指标与序列级后果脱钩：帧准确率 0.7355→0.9307（×1.2653）对应句子全对率 0.0030→0.4240（×141.33）。"帧准确率 90%"连 2 帧全对都保证不了（0.902=0.81）。
  • MMI 与 ML 的梯度形式相同，只差责任度那一项；序列级目标多出来的是 −logp(x)，本算例为 −2.803697。
  • 端到端的代价是三笔有数的账：流式失守（非因果平滑）、标注换数据（不需要帧级对齐，但要更多小时数）、先验外置（CTC 的标签相依只有 0.0776 nats，语言必须外接）。
  • 对齐从"监督信号"变成"损失的副产品"：损失从 1.69233 降到 0.37805 时，对齐熵从 1.6744 降到 0.2919——这条曲线也给出了训练后期梯度变脆的原因。
  • 搜索空间的替换是端到端能训练的直接原因：10360.2 → 104。
  • 换代的三笔账：参数 5,064,000（GMM-HMM）对 40,309,248（7.96 倍），但性质从"可读的频谱统计量"变成"不可读的投影"；标注单元 3,600,000 帧级对 90,000 词（40.0 倍）；热词注入的改动面 2 个组件对"全量重训"。

下一节：CTC —— 条件独立假设到底独立了什么、前向后向的完整推导与手算数值算例、blank 的三件事，以及 CTC 的对齐后验怎么读
