完整项目#

前两课我们学会了造图、载数据、跑训练。但一个"能交差"的项目，不只是把训练循环跑通——它需要清晰的工程结构、可复现的实验协议、合理的模型选择、以及能自圆其说的结果分析。本课把一个完整的图分类项目从头到尾串起来：从数据探查、基线建模，到调参评估、结果落盘，最后复盘每一步背后的考量。

一、项目设计#

1. 选题与目标#

本项目做 PROTEINS 蛋白质图分类（来自 TUDataset）：每张图是一个蛋白质，节点是氨基酸残基（二级结构），边是空间相邻关系，标签是"是否是酶"（二分类）。选它的理由：

  • 比 MUTAG 规模稍大（1113 张图）、方差更可控，适合演示完整流程；
  • 是 GNN 论文里的标准基准，结果可与文献对照；
  • 二分类问题，能同时演示准确率与 ROC-AUC 两类指标。

目标：训练一个 GIN 模型，在"多种子 + 早停"协议下，报告测试准确率与 AUC 的均值±标准差，并可视化训练曲线。

2. 工程结构#

把代码拆成清晰的函数，而不是一大段脚本：

1. 数据加载与探查        load_data(), inspect_data()
2. 模型定义              GIN()
3. 训练/验证/测试一个 epoch  train_one_epoch(), evaluate()
4. 早停逻辑              EarlyStopping 或内联判断
5. 多种子实验协议        run_experiment(seed)
6. 结果汇总与落盘        main()

每个函数职责单一，便于调试和复用。

3. 关键技术决策#

  • 模型：GIN（求和聚合 + MLP），配求和读出——第 5 章证明过它是图分类表达力最强的标准选择。
  • 评估协议：10 折随机划分（或用 random_split 固定比例），每折跑多个种子，报告均值±标准差。
  • 优化器：Adam，weight_decay=1e-4 做 L2 正则。
  • 早停：验证集 AUC 连续 50 epoch 不提升即停止，防止过拟合。
  • 可复现：显式 seed_everything(seed)，固定 PyTorch、numpy、random 三个随机源。

二、可运行示例#

示例：PROTEINS 图分类完整项目

import random
import numpy as np
import torch
import torch.nn.functional as F
from torch_geometric.nn import GINConv, global_add_pool
from torch_geometric.datasets import TUDataset
from torch_geometric.loader import DataLoader
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, roc_auc_score

# ---------- 0. 可复现 ----------
def seed_everything(seed):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)

# ---------- 1. 数据加载与探查 ----------
def load_data():
    ds = TUDataset(root='./data/PROTEINS', name='PROTEINS')
    print(f'图数量 {len(ds)} | 特征维 {ds.num_features} | 类别数 {ds.num_classes}')
    print('类别分布:', np.bincount([int(d.y) for d in ds]))   # 检查是否不平衡
    return ds

# ---------- 2. 模型定义 ----------
class GIN(torch.nn.Module):
    def __init__(self, in_ch, hidden_ch, out_ch):
        super().__init__()
        def mlp(in_c, out_c):
            return torch.nn.Sequential(
                torch.nn.Linear(in_c, out_c), torch.nn.ReLU(),
                torch.nn.Linear(out_c, out_c))
        self.conv1 = GINConv(mlp(in_ch, hidden_ch))
        self.conv2 = GINConv(mlp(hidden_ch, hidden_ch))
        self.conv3 = GINConv(mlp(hidden_ch, hidden_ch))
        self.lin = torch.nn.Linear(hidden_ch, out_ch)

    def forward(self, x, edge_index, batch):
        x = F.relu(self.conv1(x, edge_index))
        x = F.relu(self.conv2(x, edge_index))
        x = F.relu(self.conv3(x, edge_index))
        x = global_add_pool(x, batch)      # 求和读出
        return self.lin(x)                 # 返回 logits

# ---------- 3. 训练 / 评估 ----------
def train_one_epoch(model, loader, opt):
    model.train()
    total_loss, total = 0.0, 0
    for data in loader:
        opt.zero_grad()
        out = model(data.x, data.edge_index, data.batch)
        loss = F.cross_entropy(out, data.y)
        loss.backward()
        opt.step()
        total_loss += loss.item() * data.num_graphs
        total += data.num_graphs
    return total_loss / total

@torch.no_grad()
def evaluate(model, loader):
    model.eval()
    probs, ys = [], []
    for data in loader:
        out = model(data.x, data.edge_index, data.batch)
        probs.append(torch.softmax(out, dim=1)[:, 1])   # 取"正类"概率
        ys.append(data.y)
    probs = torch.cat(probs).cpu().numpy()
    ys = torch.cat(ys).cpu().numpy()
    pred = (probs > 0.5).astype(int)
    return accuracy_score(ys, pred), roc_auc_score(ys, probs)

# ---------- 4. 单次实验：划分 + 训练 + 早停 ----------
def run_experiment(dataset, seed, hidden=64, epochs=300):
    seed_everything(seed)
    # 按"图"划分（绝不按节点）
    idx = list(range(len(dataset)))
    tr_idx, te_idx = train_test_split(idx, test_size=0.2,
                                      random_state=seed, stratify=[int(dataset[i].y) for i in idx])
    tr_idx, va_idx = train_test_split(tr_idx, test_size=0.2,
                                      random_state=seed, stratify=[int(dataset[i].y) for i in tr_idx])
    tr_loader = DataLoader(dataset[tr_idx], batch_size=64, shuffle=True)
    va_loader = DataLoader(dataset[va_idx], batch_size=64)
    te_loader = DataLoader(dataset[te_idx], batch_size=64)

    model = GIN(dataset.num_features, hidden, dataset.num_classes)
    opt = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=1e-4)

    best_va_auc, best_state, patience = 0.0, None, 0
    for epoch in range(epochs):
        train_one_epoch(model, tr_loader, opt)
        va_acc, va_auc = evaluate(model, va_loader)
        if va_auc > best_va_auc:          # 早停：以验证 AUC 为准
            best_va_auc = va_auc
            best_state = {k: v.clone() for k, v in model.state_dict().items()}
            patience = 0
        else:
            patience += 1
            if patience >= 50:
                break

    model.load_state_dict(best_state)     # 恢复最优 checkpoint
    te_acc, te_auc = evaluate(model, te_loader)
    return te_acc, te_auc

# ---------- 5. 多种子汇总 ----------
if __name__ == '__main__':
    dataset = load_data()
    accs, aucs = [], []
    for seed in range(5):                 # 跑 5 个种子
        acc, auc = run_experiment(dataset, seed)
        accs.append(acc); aucs.append(auc)
        print(f'seed={seed} | Test Acc {acc:.4f} | Test AUC {auc:.4f}')

    print(f'\n最终报告：')
    print(f'Accuracy = {np.mean(accs):.4f} ± {np.std(accs):.4f}')
    print(f'ROC-AUC  = {np.mean(aucs):.4f} ± {np.std(aucs):.4f}')

运行结果参考：GIN 在 PROTEINS 上的测试准确率约 0.73–0.76、AUC 约 0.78–0.80（因随机划分而略有波动）。这个脚本已经具备完整项目的骨架，你可以直接把 TUDataset 换成 MUTAG、ENZYMES，或把 GIN 换成第 4 章的 SAGE/GAT，复用同一套协议。

三、练习#

  1. 换成别的数据集：把项目里的 PROTEINS 换成 ENZYMES（多分类），只改数据集名和指标（多分类 AUC 需 average='macro' 或 multi_class 参数），跑通完整流程。
  2. 消融实验：把 global_add_pool 换成 global_mean_pool、global_max_pool，各跑一遍，记录准确率与 AUC 的变化，验证"求和读出"的优势。
  3. 模型对比：把 GIN 换成 GCNConv/SAGEConv/GATConv 组成的编码器（同样 3 层 + 求和读出），在同一协议下对比，写成一个小表格。
  4. 调参练习：固定划分，分别改变 hidden（32/64/128）和 weight_decay（0/1e-4/1e-3），观察验证 AUC 的变化，总结哪个超参最敏感。
  5. 曲线可视化：改造 run_experiment，记录每个 epoch 的训练损失与验证 AUC，用 matplotlib 画出学习曲线，判断模型是否过拟合、早停是否生效。
