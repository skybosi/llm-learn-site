LSTM 时间序列预测#

前面几章我们用 ARIMA、指数平滑、Prophet 等经典模型做预测。它们有一条共同的隐含假设：序列的未来主要取决于它的历史统计规律，比如趋势、季节性和近期残差。但现实中有大量序列——电力负荷、交通流量、股价波动——背后是一个非线性动态系统在演化，历史对未来的影响既非线性，又跨越很长的距离。这一章我们进入深度学习时间序列，第一站就是 LSTM：它凭什么能记住长程依赖，又如何被改造成一个预测器。

一、概念讲解#

1. 为什么普通 RNN 记不住"长程依赖"#

先回忆普通 RNN：每个时间步把当前输入和上一个隐藏状态合在一起，算出新的隐藏状态。

h_t = tanh(W_x x_t + W_h h_{t-1} + b)

问题出在反向传播。当误差从最后一步往回传时，每一步都要乘一次"隐藏状态对上一时刻"的导数（大致是 W_h 的特征值）。如果这些值小于 1，连乘几十步后梯度会指数级衰减；如果大于 1，又会指数级爆炸。于是普通 RNN 实际上只能"记住"很近的过去，几十步之前的信息早已被冲淡。时序里的"长程依赖"——比如今天用电量对一周前同一时刻用电量的依赖——普通 RNN 很难学到。

2. LSTM 的核心思想：一条"信息传送带"#

LSTM 的解法，是给记忆加一条可以长期稳定传输的高速通道，这条通道叫做细胞状态（cell state），记作 C_t。它只做逐元素的加法更新：

C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t

关键就在于这个 +。反向传播时，梯度沿着细胞状态往回走，经过的是加法分支——加法对输入的导数恒为 1。也就是说，只要 f_t 接近 1（门开着），梯度就能几乎无损地穿过很多个时间步，不会像普通 RNN 那样被连乘冲淡。这条"常数误差传送带"（constant error carousel）就是 LSTM 能捕捉长程依赖的数学根源。

3. 三个门：忘记、输入、输出#

细胞状态不能盲目累加，需要三个"门"来精确控制信息的进与出。每个门都是一个 sigmoid 层，输出 0 到 1 之间的数，用来"按比例放行"。

  • 遗忘门 f_t：决定旧的 C_{t-1} 里哪些要丢掉。f_t = σ(W_f·[h_{t-1}, x_t] + b_f)。当它接近 0，就"忘掉"过去。
  • 输入门 i_t 与候选值 C̃_t：决定把多少新信息写进细胞状态。i_t 控制"写不写"，C̃_t = tanh(...) 是"写什么"。
  • 输出门 o_t：决定从细胞状态里取出多少，作为本步的隐藏状态 h_t = o_t ⊙ tanh(C_t)。

⊙ 是逐元素乘法。门名字很直白：忘记旧信息、输入新信息、输出当前结果。三个门加起来，让网络能学会"什么时候记住、记住多久、什么时候该翻篇"。

4. LSTM 如何变成"时间序列预测器"#

LSTM 本身只是处理序列的单元。要做预测，需要把它摆进一个标准的监督学习框架里：用过去一段窗口预测未来。

给定序列 x_1, x_2, ...，我们取一个长度 L 的滑动窗口 [x_{t-L+1}, ..., x_t] 作为输入，让 LSTM 逐时间步读进去，最后一步的隐藏状态 h_t 就浓缩了整段窗口的信息；再把它喂给一个全连接层，输出未来若干步的预测值 ŷ_{t+1}, ..., ŷ_{t+H}。训练时用真实未来值做标签，算 MSE 之类的回归损失，反向传播更新参数。

这里有一个重要选择：单步还是多步。单步预测输出一个值，简单但只能"预测明天"；多步预测可以一次输出未来 H 个值，或采用自回归方式——预测出 ŷ_{t+1} 后把它当作已知输入再推 ŷ_{t+2}，逐点滚动。自回归方式误差会累积，但更贴近真实部署。

二、可运行代码示例#

下面用 PyTorch 实现一个最简 LSTM 单步预测器。我们生成一条带正弦和噪声的序列，用过去 L 个点预测下一个点。代码刻意保持精简，重点是看清"窗口构造 → LSTM → 全连接输出"这条链路。

import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt

torch.manual_seed(0)
np.random.seed(0)

# 1) 生成一条"趋势 + 周期 + 噪声"的序列，模拟真实负荷数据
t = np.arange(0, 600)
series = 0.02 * t + 5 * np.sin(t / 12.0) + np.random.randn(600) * 0.3

# 2) 构造滑动窗口样本：用过去 L 个点预测下 1 个点
def make_dataset(series, L):
    X, y = [], []
    for i in range(len(series) - L):
        X.append(series[i:i + L])          # 输入窗口，长度 L
        y.append(series[i + L])            # 标签：窗口之后的下一个值
    return torch.tensor(X, dtype=torch.float32), torch.tensor(y, dtype=torch.float32)

L = 30                                    # 窗口长度
X, y = make_dataset(series, L)
X = X.unsqueeze(-1)                       # 加特征维：(样本数, L, 1)
y = y.unsqueeze(-1)                       # (样本数, 1)
print("X 形状:", X.shape, " y 形状:", y.shape)

# 3) 定义模型：LSTM 读入窗口，取最后一步隐藏状态再过全连接输出一个预测值
class LSTMPredictor(nn.Module):
    def __init__(self, input_size=1, hidden_size=32, num_layers=1):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers, batch_first=True)
        self.fc = nn.Linear(hidden_size, 1)

    def forward(self, x):
        # x: (batch, L, 1)
        out, (h_n, c_n) = self.lstm(x)
        # h_n: (num_layers, batch, hidden)，取最后一层最后一个时间步的隐藏状态
        last_hidden = h_n[-1]             # (batch, hidden)
        return self.fc(last_hidden)       # (batch, 1)

model = LSTMPredictor()
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# 4) 训练：整批数据反复迭代
model.train()
for epoch in range(300):
    optimizer.zero_grad()
    pred = model(X)
    loss = criterion(pred, y)
    loss.backward()
    optimizer.step()
    if (epoch + 1) % 50 == 0:
        print(f"epoch {epoch+1:3d}  loss={loss.item():.4f}")

# 5) 预测：用最后 L 个真实点预测下一步，然后滚动外推 60 步（自回归）
model.eval()
with torch.no_grad():
    window = torch.tensor(series[-L:], dtype=torch.float32).reshape(1, L, 1)
    preds = []
    for _ in range(60):
        nxt = model(window)               # 预测下一步
        preds.append(nxt.item())
        # 把预测值接进窗口末尾、丢掉最旧一个点，实现自回归滚动
        window = torch.cat([window[:, 1:, :], nxt.reshape(1, 1, 1)], dim=1)

plt.figure(figsize=(9, 3.5))
plt.plot(range(-60, 0), series[-60:], label="真实值")
plt.plot(range(0, 60), preds, label="预测值", linestyle="--")
plt.legend(); plt.title("LSTM 自回归外推 60 步")
plt.show()

运行后观察两个现象：

  • 训练损失会很快降到噪声量级（约 0.3² = 0.09 附近），说明模型学到了趋势与周期；
  • 自回归外推的头几步还算贴合，越往后越偏离——误差逐步累积，这是自回归预测的通病，后面讲 seq2seq 和 Transformer 时我们会看到改进思路。

三、练习#

  1. 把 L 从 30 改到 5 和 100，分别训练，观察训练损失与外推质量的差异。思考：窗口太短会丢什么信息？太长又会带来什么代价（计算量、过拟合）？
  2. 把噪声系数从 0.3 提高到 1.5，重跑。模型还能学到周期吗？为什么信噪比下降会让 LSTM 倾向于"躺平"预测均值？
  3. 在 nn.LSTM 里设置 num_layers=2，比较单层与双层的表现。多层 LSTM 的 h_n[-1] 取的是哪一层的隐藏状态？
  4. 思考：为什么细胞状态用加法更新就能缓解梯度消失，而普通 RNN 的 h_t = tanh(W_h h_{t-1} + ...) 不行？把两者的反向传播梯度公式写出来对比。

为什么这样做？——理论推导#

这一节把"加法传送带"的直觉用梯度公式钉死。普通 RNN 在时间步 t 的隐藏状态对 t-1 的导数是：

∂ht−1​∂ht​​=diag(1−tanh2(⋅))Wh​

tanh 的导数最大是 1，且大部分区域远小于 1；W_h 的特征值又常常小于 1。于是从 t 一路乘回 t-n 时：

∂ht−n​∂ht​​=k=t−n+1∏t​∂hk−1​∂hk​​

每一项都小于 1，乘积随 n 指数衰减——这就是梯度消失。

LSTM 的细胞状态更新是 C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t。对 C_{t-1} 求导：

∂Ct−1​∂Ct​​=diag(ft​)

当遗忘门 f_t → 1 时，这个导数趋近单位矩阵，于是跨 n 步的导数：

∂Ct−n​∂Ct​​=k∏​diag(fk​)≈I

梯度几乎不衰减。更重要的是，这条"高速公路"的梯度是可学习的——f_t 由网络自己决定，它可以对"需要长期记住"的维度让 f_t 接近 1，对"该遗忘"的维度让 f_t 接近 0。也就是说，LSTM 不是粗暴地保留一切，而是按维度有选择地决定记忆时长。这才是它既稳又灵的完整原因。

母原理连接：LSTM 是"门控 + 残差式信息传递"这一母原理的实例。让信息沿一条近恒等映射的捷径流动、再让可学习门决定"流多少"，这个套路在 ResNet（恒等跳跃连接缓解梯度消失）、GRU（更新门合并遗忘与输入）、甚至 Transformer 的残差连接里反复出现。抓住"用加法给梯度留一条高速公路"这个母原理，后面读任何深层架构都能一眼看懂它在防什么。
