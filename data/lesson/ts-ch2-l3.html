模型选择与诊断#

前面两课教会你"造"模型：ARIMA 和指数平滑都有一大堆可调参数，p, d, q、α, β, γ、趋势季节的组合……那到底选哪一组？模型选择回答"哪个模型更好"，诊断回答"选的这个够不够好"。这两步合起来，是把"调包跑通"升级成"可交代的预测"的分水岭。

一、概念讲解#

1. 信息准则：AIC / AICc / BIC#

最朴素的选模型思路是"谁拟合误差小选谁"，但这会必然选中最复杂的模型——参数越多，拟合误差几乎总是越小，代价却是过拟合和更大的预测方差。信息准则的做法是：拟合好坏 + 复杂度惩罚，两者一起打分。

AIC（赤池信息准则）：

AIC = −2·log(L̂) + 2k

其中 L̂ 是模型的最大似然，k 是估计参数的个数。第一项度量拟合好坏（似然越大、−2logL 越小），第二项 2k 惩罚参数数量。AIC 越小越好。

它的理论根基是信息论里的 Kullback–Leibler 散度：我们其实想选"与真实生成机制 KL 距离最小"的模型，而 AIC 是这个期望距离的渐近无偏估计。所以 AIC 的目标不是"找到真模型"，而是"找一个在新数据上预测误差尽量小的近似"。

两个变体：

  • AICc（校正 AIC）：AICc = AIC + 2k(k+1)/(T−k−1)。当样本量 T 不大、而参数 k 又不少时，AIC 的惩罚偏轻，AICc 补上一个随 k 增大而变大的校正项。小样本务必用 AICc（Hyndman 建议 T 较小时优先 AICc）。
  • BIC（贝叶斯信息准则）：BIC = −2·log(L̂) + k·log(T)。它源自贝叶斯框架下的模型后验概率，惩罚力度与 log(T) 挂钩，样本越多越"重罚"复杂模型，倾向选更简单的模型。

三者都"越小越好"，但倾向不同：AIC/AICc 偏向预测，BIC 偏向找到更简、更接近真实的模型。做预测一般报 AIC/AICc。

2. 残差诊断：模型有没有"榨干"信息#

一个合格的模型，拟合后的残差应当像白噪声——序列里所有可解释的结构（趋势、季节、自相关）都应被模型拿走，剩下的只有不可预测的随机扰动。诊断就是检验"残差是不是白噪声"：

  1. 残差时序图：残差应在 0 附近随机波动，没有明显趋势或"一段正一段负"的聚集；
  2. 残差 ACF/PACF：任意非零滞后都不应显著越出置信带；
  3. Ljung–Box 检验：对前若干阶自相关做联合检验，原假设"残差无自相关（是白噪声）"。p 值很大 → 通过；p 值很小 → 残差还有结构，模型阶数不够或选错了；
  4. 正态性与异方差：理想残差近似正态（看 QQ 图或偏度/峰度）。若残差方差随时间变化（如波动越来越大），说明存在异方差，可能需要对数据做变换（如 Box–Cox）或换用允许变方差的结构。

诊断不通过怎么办？按线索回头调：残差 ACF 在滞后 1 显著 → 可能缺 AR(1) 或 MA(1)；残差还有季节自相关 → 缺季节项；残差方差不稳 → 先做变换。

3. 自动定阶：把规则交给算法#

手工看图识别阶数费时且主观，现代做法是用信息准则自动搜索：

  • 先用单位根检验（ADF/KPSS）决定差分阶数 d 和季节差分阶数 D（KPSS 与 ADF 结论互为印证更稳）；
  • 在候选的 p, q, P, Q 网格里，对每个组合拟合、算 AICc，选最小者。

pmdarima 的 auto_arima 就是这套流程的封装（内部做 stepwise 搜索，比暴力网格更快）。但它不是魔法：自动搜索也可能过拟合，且对小样本不稳定，最终仍要用残差诊断把关。

4. 一个完整的选型流程#

把上面串起来，标准流程是：

① 画图 + 分解：识别趋势、季节、是否需变换
② 决定差分阶数 d、D（ADF/KPSS + 看图）
③ 候选模型集合：ARIMA / SARIMA / ETS 若干
④ 用 AICc 横向比较，选最小者
⑤ 残差诊断（白噪声 / Ljung-Box / 正态性）
⑥ 若诊断不过，回到 ③ 修正；通过则用其预测

二、可运行示例#

对一条带季节的序列，比较若干 SARIMA 候选模型的 AIC，并对最优模型做残差诊断。

import numpy as np
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.stats.diagnostic import acorr_ljungbox

# 构造带年度季节的序列
idx = pd.date_range("2018-01-01", periods=96, freq="MS")
n = len(idx)
rng = np.random.default_rng(9)
y = 50 + 0.5 * np.arange(n) + 12 * np.sin(2 * np.pi * np.arange(n) / 12) \
    + rng.normal(0, 4, size=n)
series = pd.Series(y, index=idx)

# 1) 网格搜索 SARIMA：常规阶 (p,d,q) 搭配季节阶 (1,1,1,12)
candidates = []
for p, q in [(0, 0), (1, 0), (0, 1), (1, 1), (2, 1)]:
    for P, Q in [(0, 0), (1, 0), (0, 1), (1, 1)]:
        try:
            m = ARIMA(series, order=(p, 1, q),
                      seasonal_order=(P, 1, Q, 12)).fit(method_kwargs={"maxiter": 300})
            candidates.append((m.aicc, f"({p},1,{q})({P},1,{Q})12"))
        except Exception:
            pass  # 某些阶数可能不收敛，跳过

candidates.sort()
print("AICc 最小的 5 个候选模型：")
for aicc, name in candidates[:5]:
    print(f"  {name:20s} AICc = {aicc:.1f}")

# 2) 取 AICc 最小的那个模型做残差诊断
best_spec = candidates[0][1]
p, q = int(best_spec[1]), int(best_spec[3])
P, Q = int(best_spec[5]), int(best_spec[7])
best = ARIMA(series, order=(p, 1, q),
             seasonal_order=(P, 1, Q, 12)).fit()
print("\n最优模型：", best_spec)

# 3) Ljung–Box 检验残差是否为白噪声（滞后 1~12）
lb = acorr_ljungbox(best.resid, lags=[6, 12, 24], return_df=True)
print("\n残差 Ljung–Box 检验：")
print(lb.round(3))

# 4) 残差均值/方差粗检
print("残差均值 =", round(best.resid.mean(), 3),
      "（越接近 0 越好）")
print("残差标准差 =", round(best.resid.std(), 3))

如果 Ljung–Box 的 p 值都远大于 0.05，说明最优模型的残差已接近白噪声，模型通过了诊断；反之则提示还要继续加阶或换结构。

三、练习#

  1. 在网格搜索里把候选阶数上限扩大（如 p,q 到 3），观察 AICc 是否会"为了更复杂而更低"，并结合残差诊断说明"AICc 最低 ≠ 一定最好"。
  2. 用手头数据分别拟合 SARIMA 和一个 ETSModel(error='add', trend='add', seasonal='add')，比较两者的 AIC，说明你会选谁。
  3. 解释 AIC 公式里 2k 惩罚项的直觉：为什么参数越多，−2logL 会变小？如果完全不加惩罚会发生什么？
  4. 思考：为什么做预测时更推荐 AICc 而不是 BIC？两者在"选复杂模型"上的倾向有何不同？
