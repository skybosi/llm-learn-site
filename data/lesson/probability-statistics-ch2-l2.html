离散与连续随机变量#

上一课我们把随机变量分成了"离散"和"连续"两大类。这一课分别深入：离散变量用概率质量函数（PMF）描述，连续变量用概率密度函数（PDF）描述，并认识机器学习里最常出现的几种分布。理解"质量"和"密度"两个词的区别，是读懂一切概率模型的关键。

一、概念讲解#

1. 离散随机变量与概率质量函数（PMF）#

离散随机变量 X 的取值是有限个或可列无限个。它的概率质量函数（Probability Mass Function）记为 p(k) = P(X = k)，满足：

  • 非负：p(k) ≥ 0；
  • 归一：所有取值的概率之和等于 1，即 Σₖ p(k) = 1。

"质量"这个词很形象：概率就像一块块"质量"，被分配在离散的取值点上，加总等于 1。

2. 三种最常见的离散分布#

  • 伯努利分布 Bernoulli(p)：一次试验只有两个结果（成功/失败），成功概率为 p。比如抛一次硬币、判断一封邮件是不是垃圾邮件。P(X = 1) = p，P(X = 0) = 1 − p。
  • 二项分布 Binomial(n, p)：n 次独立伯努利试验中成功的次数。比如抛 n 次硬币正面出现的次数。P(X = k) = C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ。
  • 泊松分布 Poisson(λ)：单位时间/空间内稀有事件发生的次数，λ 是平均发生率。比如网站每小时被点击的次数、一定长度布匹上的瑕疵数。它在 λ = np 时是二项分布的良好近似。

3. 连续随机变量与概率密度函数（PDF）#

连续随机变量的取值充满一个区间，任何一个单点的概率都是 0（想想看：一条线段上有无限多个点，把总概率 1 分给无限个点，每个点分到的只能是 0）。所以我们不能问 P(X = k)，只能问"落在区间里"的概率。

连续变量用概率密度函数（Probability Density Function）f(x) 描述，它满足：

  • 非负：f(x) ≥ 0；
  • 归一：曲线下的总面积等于 1，即 ∫ f(x) dx = 1。

区间 [a, b] 上的概率就是密度函数在 [a, b] 上的积分，也就是曲线下这块面积：

P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx

注意：密度值 f(x) 本身不是概率，可以大于 1（只要总面积是 1 即可）。这是初学者最容易踩的坑。

4. 两种最常见的连续分布#

  • 均匀分布 Uniform(a, b)：在区间 [a, b] 上取值等可能，密度是常数 1/(b−a)。适合描述"完全没有偏好"的情形，也是随机数生成的基础。
  • 正态分布（高斯分布）Normal(μ, σ²)：钟形曲线，中心是均值 μ，σ 控制"胖瘦"。它在自然界和机器学习里无处不在——测量误差、身高分布、很多特征的分布都近似正态，这背后有中心极限定理在支撑。

5. 机器学习视角：特征分布#

理解数据，往往从"画一下特征的分布"开始。特征是离散的（如点击次数），我们就看它的 PMF；特征是连续的（如价格），我们就看它的直方图（直方图就是 PDF 的经验近似）。知道特征服从什么分布，还能帮助我们做异常检测（概率极低的值很可能是异常）、数据生成（按分布采样做数据增强）等。

二、可运行示例#

示例 1：模拟二项分布#

import random
from collections import Counter

random.seed(5)


def binomial_sample(n, p):
    """一次二项试验：抛 n 次硬币（成功概率 p），返回成功次数。"""
    return sum(1 for _ in range(n) if random.random() < p)


# 抛 10 次硬币，重复 20000 轮，统计成功次数的频率分布
n, p, rounds = 10, 0.5, 20000
samples = [binomial_sample(n, p) for _ in range(rounds)]
counts = Counter(samples)

print("成功次数  频率")
for k in range(n + 1):
    print(f"   {k:>2}     {counts[k] / rounds:.4f}")

示例 2：泊松分布模拟（网站每分钟点击次数）#

import random

random.seed(10)


def poisson_approximation(lam, trials):
    """把一分钟切成很多个极短小段，每段最多一次点击，近似泊松分布。"""
    # 把 1 分钟切成 1000 小段，每段点击一次的概率为 lam/1000
    bins = 1000
    per_bin = lam / bins
    for _ in range(trials):
        clicks = sum(1 for _ in range(bins) if random.random() < per_bin)
        yield clicks


lam = 3.0  # 平均每分钟 3 次点击
samples = list(poisson_approximation(lam, 20000))
from collections import Counter
counts = Counter(samples)

print("点击次数  频率")
for k in range(0, 12):
    print(f"   {k:>2}     {counts[k] / len(samples):.4f}")

示例 3：正态分布抽样与直方图#

import random
from collections import Counter

random.seed(0)

# random.gauss(mu, sigma) 直接按正态分布采样
mu, sigma = 0.0, 1.0
samples = [random.gauss(mu, sigma) for _ in range(20000)]


def histogram(samples, bins=20, lo=-4.0, hi=4.0):
    """把样本分箱，返回每个箱的（中心点, 占比），用于近似密度。"""
    width = (hi - lo) / bins
    counts = Counter()
    for x in samples:
        if lo <= x < hi:
            counts[int((x - lo) // width)] += 1
    return [(lo + (i + 0.5) * width, counts[i] / len(samples)) for i in range(bins)]


print("区间中心   密度近似")
for center, freq in histogram(samples):
    bar = "#" * int(freq * 40)
    print(f"{center:>6.2f}  {freq:.4f} {bar}")
