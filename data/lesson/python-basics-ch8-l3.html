random/collections 等常用模块#

Python 自带的"标准库"非常丰富，除了前面学过的，还有两个日常编程经常遇到的模块：生成随机数的 random，以及提供更强大容器类型的 collections。这一课我们把它们以及另外几个实用模块快速过一遍。

一、概念讲解#

1. random：生成随机数#

random 模块能产生"伪随机"的结果，常用于抽奖、打乱顺序、随机挑选等场景：

函数 作用
random.random() 返回 0 到 1 之间的随机小数
random.randint(a, b) 返回 a 到 b 之间的随机整数（含两端）
random.choice(序列) 从序列里随机挑一个元素
random.sample(序列, k) 随机挑 k 个不重复的元素
random.shuffle(列表) 原地打乱列表顺序
random.seed(n) 设置随机种子，让结果可复现

小知识：seed(n) 里的 n 一样时，之后产生的"随机"序列也完全一样。这在调试和做实验时很有用，能保证每次运行结果一致。

2. collections：更强大的容器#

collections 提供了几个比内置类型更"聪明"的容器：

类型 相对内置类型的增强
Counter 自动统计元素出现次数
defaultdict 访问不存在的键时自动给默认值
OrderedDict 记住键插入的顺序
deque 两端都能快速增删的双端队列
namedtuple 有字段名的元组，可读性更好

其中最常用的两个是 Counter 和 defaultdict：

from collections import Counter
c = Counter("abracadabra")   # 统计每个字符出现次数

3. 其他常用模块速览#

模块 用途
math 数学函数，如 sqrt、ceil、floor、pi
statistics 统计函数，如 mean（平均）、median（中位数）
string 常用字符串常量，如 string.ascii_letters
time 时间戳、休眠 sleep

二、可运行代码示例#

示例 1：random 的常见用法#

import random

print("0到1的随机小数：", random.random())
print("1到6的随机整数：", random.randint(1, 6))

fruits = ["苹果", "香蕉", "橙子", "葡萄"]
print("随机选一个：", random.choice(fruits))
print("随机选两个（不重复）：", random.sample(fruits, 2))

random.shuffle(fruits)      # 原地打乱
print("打乱后的顺序：", fruits)

# 设置种子，结果可复现
random.seed(42)
print("种子42下的随机数：", random.randint(1, 100))
random.seed(42)
print("再设一次种子42：", random.randint(1, 100))   # 和上面一样

示例 2：用 Counter 统计#

from collections import Counter

votes = ["张三", "李四", "张三", "王五", "张三", "李四"]
c = Counter(votes)

print("投票统计：", c)
print("张三的票数：", c["张三"])
print("得票最多的人：", c.most_common(1)[0][0])

示例 3：用 defaultdict 分组#

from collections import defaultdict

# 普通字典访问不存在的键会报错，defaultdict 会自动创建空列表
by_city = defaultdict(list)

students = [("小明", "北京"), ("小红", "上海"), ("小刚", "北京")]
for name, city in students:
    by_city[city].append(name)

print("按城市分组：", dict(by_city))

示例 4：math 与 statistics#

import math
import statistics

print("根号16：", math.sqrt(16))
print("圆周率：", math.pi)

scores = [80, 90, 85, 95, 70]
print("平均分：", statistics.mean(scores))
print("中位数：", statistics.median(scores))

三、练习#

  1. 用 random 写一个"猜数字"游戏：程序在 1 到 100 之间随机选一个数，让用户猜，每次提示"大了"或"小了"，直到猜对为止。
  2. 用 Counter 统计一篇文章（可以是一个较长的字符串）里每个字母出现的次数，并打印出现次数最多的前 3 个字母。
  3. 用 defaultdict 把一组"学生姓名 + 班级"的数据按班级分组，然后打印每个班级有哪些学生。
