表格 Q-learning#

上一章已经见过 Q-learning 的更新公式。本课把"表格版" Q-learning 做成一个能直接落地的完整算法：讲清 ε-greedy 与探索衰减、学习率该怎么定、为什么它保证收敛（Bellman 最优算子是一个压缩映射），最后指出表格方法的死穴，为函数逼近铺路。

一、概念讲解#

1. 完整算法：一步到位#

"表格"指的是用一张 Q[s, a] 二维表存所有状态-动作对的价值。算法只有五步：

  1. 初始化 Q(s,a) 为任意值（通常全 0），设定 α、γ、探索率 ε。
  2. 对每个 episode：从初始状态 s 出发。
  3. 用 ε-greedy 选动作：以 1-ε 概率选 argmax_a Q(s,a)，以 ε 概率随机选一个。
  4. 执行 a，观测 (r, s')，做更新：Q(s,a) ← Q(s,a) + α [ r + γ max_a' Q(s',a') - Q(s,a) ]。
  5. 回到第 3 步，直到 s' 终止；进入下一个 episode。

它继承了 TD 的优点——每走一步就更新一次，也继承了 Q-learning 的 off-policy 属性——目标永远指向贪婪最优。

2. ε-greedy：探索与利用的平衡#

Q(s,a) 一开始全是 0（或随便填的数），如果每次只选 argmax，智能体会永远卡在第一次遇到的"看起来还行"的动作上，根本没机会发现真正好的动作。ε-greedy 用一个 ε 保证每个动作都有被尝试的机会：

  • ε 大 → 探索多、收敛慢、学到终点的路径更"实"；
  • ε 小 → 利用多、收敛快、但可能错过更优解。

工程上的标准做法是 ε 衰减：训练初期 ε 接近 1（狂试），随训练线性或指数衰减到一个小值 ε_min（如 0.01）。这对应一个重要的收敛条件 GLIE（Greedy in the Limit with Infinite Exploration）：无限训练中，每个 (s,a) 被访问无限多次（探索无限），且策略最终趋于贪婪（greedy in the limit）。

3. 学习率 α 与随机逼近条件#

更新式里的 α 决定"新样本"的分量。若环境平稳、且要保证收敛到精确最优，α 不能是常数，而应满足 Robbins–Monro 条件：

Σ_{t} α_t = ∞        （步长之和发散：保证能"走得足够远"，最终抹掉任意初始化）
Σ_{t} α_t² < ∞       （平方和收敛：保证后期噪声被压下去，估计最终稳住）

典型例子是 α_t = 1/t（上一课 MC 增量均值的步长）。实践中为应对非平稳、或追求更快响应，常用常数 α（如 0.1）——它牺牲了"严格收敛到精确值"，换取对近期数据的敏感，是工程上的实用折中。

4. 收敛性：为什么 max 不会把更新带偏#

Q-learning 的收敛不是经验巧合，而有一条硬保证（Watkins & Dayan）。核心直觉是：把 Q-learning 看成对 Bellman 最优算子 的不断逼近。定义算子：

(𝒯 Q)(s,a) = E[ R + γ max_{a'} Q(S', a') | s, a ]

Q* 恰好是它的不动点：𝒯 Q* = Q*。这个算子是 γ-压缩映射——对任意两张 Q 表 Q₁、Q₂：

‖ 𝒯 Q₁ - 𝒯 Q₂ ‖∞ ≤ γ ‖ Q₁ - Q₂ ‖∞

因为 γ < 1，每作用一次 𝒯，两张表的"最大分歧"至少缩到原来的 γ 倍。反复作用，任何初始 Q 表都会被"吸"向唯一的不动点 Q*。Q-learning 的采样更新，就是在用带噪的样本去逐步逼近 𝒯 Q；只要采样充分（探索条件）且步长合宜（Robbins–Monro 条件），估计值就会收敛到 Q*。max 运算符"压缩"了分歧，这正是它收敛的根源。

5. 表格方法的死穴：状态爆炸#

表格 Q-learning 要求"每个状态都能单独占一行"。可一旦状态是连续的（小车位置、摆角），或状态维度稍高，状态数就指数爆炸——10 个二元特征就是 2¹⁰ = 1024 个状态，30 个就是 2³⁰ ≈ 10 亿，表格根本装不下。更糟的是，相邻状态的价值通常高度相似，表格却把它们当完全无关的独立变量，一点泛化能力都没有。这直接引出下一课的主题：函数逼近。

二、可运行代码示例#

手写一个自包含的 4×4 "冻湖"（冰面打滑），跑通完整表格 Q-learning。

import numpy as np

np.random.seed(0)               # 固定随机种子，结果可复现

# ---- 自包含的 4×4 冻湖环境 ----
HOLE = {5, 7, 11, 12}          # 洞：掉进去终止，奖励 0
GOAL = 15                     # 终点：到达奖励 1，终止
DELTA = [(-1, 0), (1, 0), (0, -1), (0, 1)]   # 0=上, 1=下, 2=左, 3=右

def step(s, a):
    row, col = divmod(s, 4)
    p = np.random.rand()
    if p < 0.1:                     # 冰面打滑：10% 偏左
        a = (a - 1) % 4
    elif p > 0.9:                   # 10% 偏右
        a = (a + 1) % 4
    dr, dc = DELTA[a]
    nr, nc = max(0, min(3, row + dr)), max(0, min(3, col + dc))
    s_next = nr * 4 + nc
    if s_next in HOLE:
        return s_next, 0.0, True    # 掉洞
    if s_next == GOAL:
        return s_next, 1.0, True    # 到终点
    return s_next, 0.0, False

# ---- 表格 Q-learning ----
def q_learning(n_episodes=3000, alpha=0.1, gamma=0.99,
               eps_start=1.0, eps_min=0.01, eps_decay=0.997):
    Q = np.zeros((16, 4))
    eps, wins = eps_start, []
    for _ in range(n_episodes):
        s, done, total = 0, False, 0.0
        while not done:
            # ε-greedy 选择动作
            a = np.random.randint(4) if np.random.rand() < eps else np.argmax(Q[s])
            s_next, r, done = step(s, a)
            # Q-learning 更新：目标 = r + γ·max_a Q(s',a)
            Q[s, a] += alpha * (r + gamma * np.max(Q[s_next]) - Q[s, a])
            s = s_next
            total += r
        eps = max(eps_min, eps * eps_decay)   # ε 指数衰减
        wins.append(total)
    return Q, wins

Q, wins = q_learning()
print("最后 100 回合成功率：{:.2f}".format(np.mean(wins[-100:])))

# 打印学到的贪婪策略（箭头 = argmax Q(s,·)）
arrows = {0: '↑', 1: '↓', 2: '←', 3: '→'}
for r in range(4):
    print('  '.join(arrows[np.argmax(Q[r * 4 + c])] for c in range(4)))

要点：终端态（洞/终点）的 Q 始终保持初始值 0，所以 np.max(Q[s_next]) 在 s_next 为终端时自然等于 0，等价于"终止后价值为 0"；eps 从 1.0 指数衰减，兼顾前期探索与后期利用。

三、练习#

  1. 关掉 ε 衰减（eps_decay=1.0 且 eps_start=0.0），跑同样回合，观察成功率与学到的策略发生了什么变化，解释"纯利用"的失败原因。
  2. 把 alpha 改成 0.05、0.5、0.9，画出最后 100 回合成功率曲线，观察过大 α 带来的震荡。
  3. 把冰面打滑概率（0.1/0.1）改成确定性转移（0.0/0.0），再跑，比较收敛回合数；打滑对 Q-learning 的影响是什么？
  4. 思考题：为什么说"γ < 1"是 Q-learning 收敛的关键？如果 γ = 1 且环境有环（可能永不终止），Bellman 最优算子还是压缩映射吗？
