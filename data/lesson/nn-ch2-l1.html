MLP 结构#

从这一课起，我们正式进入多层感知机（Multi-Layer Perceptron, MLP）——最基础、也最常被用作"入门积木"的前馈神经网络。MLP 就是"多层 + 全连接 + 非线性激活"的组合：输入一层层往后传，直到输出。这一课先把它长什么样、每一层怎么定义、参数是怎么组织的讲清楚，为下一课"前向传播"铺路。

一、概念讲解#

1. 三层结构：输入层、隐藏层、输出层#

一个 MLP 通常由三类层组成：

  • 输入层（input layer）：接收原始特征，本身不做计算，只是把数据"摆"进网络。它的神经元个数等于特征维度；
  • 隐藏层（hidden layer）：位于输入和输出之间的层，负责把输入变换成越来越"好用"的表示。可以有一层，也可以有多层——层数越多，网络越"深"；
  • 输出层（output layer）：给出最终结果。做回归可能是 1 个神经元输出连续值；做 k 分类可能是 k 个神经元，配合 softmax 输出各类概率。

一个典型的"输入 4 维 → 隐藏 5 维 → 隐藏 3 维 → 输出 2 维"的 MLP，可以记作 4 → 5 → 3 → 2。我们称它是一个含两个隐藏层的三层结构网络（输出层不算"隐藏"）。

2. 一个神经元在做什么：加权求和 + 激活#

MLP 的每个隐藏/输出神经元，做的都是同一件两步骤的事，与感知机几乎一样，只是激活函数换成了可导的非线性函数（下一章专题讲）：

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b      # ① 线性：加权求和 + 偏置
a = f(z)                             # ② 非线性：激活函数

其中 w 是本神经元与上一层之间的权重，b 是偏置，f 是激活函数，a 是这个神经元的输出（activation），会作为下一层的输入继续往后传。

3. 把整层写成矩阵：权重矩阵与偏置向量#

一个个神经元写太啰嗦，实际都用矩阵统一表达。设第 l 层有 n 个神经元，上一层有 m 个神经元，那么：

  • 权重矩阵 W 的形状是 (n, m)：第 i 行是"第 i 个神经元对上一层 m 个输入的权重"；
  • 偏置向量 b 的形状是 (n,)：每个神经元一个偏置；
  • 上一层输出向量 x 的形状是 (m,)。

整层计算就是一次矩阵乘再加偏置：

z = W·x + b       # z 的形状为 (n,)
a = f(z)          # 逐元素应用激活

注意权重的两个维度谁在前：PyTorch 里 nn.Linear(m, n) 的第一个参数是输入维度 m，第二个是输出维度 n，内部维护的权重矩阵形状是 (n, m)。这个顺序经常被搞反，务必记牢——nn.Linear(in_features, out_features)。

4. 全连接的含义#

MLP 的相邻两层之间是全连接（fully connected / dense）：上一层的每个神经元都连接到下一层的每个神经元，各有一条独立的权重。这意味着参数数量随层宽平方级增长：

一层全连接（输入 m，输出 n）的参数量 = m·n（权重）+ n（偏置）

例如输入 784 维（28×28 的图片拉平）、隐藏层 128 维，光这一层就有 784×128 + 128 = 100,480 个参数。全连接层参数多、但表达能力也强，是理解一切网络结构的起点；后续的卷积、循环网络，都是在这个基础上做的"特殊化改造"。

5. 层间尺寸必须对齐#

一个容易踩的坑是维度不匹配：前一层的输出维度，必须等于后一层的输入维度。搭网络时，通常先定好"输入维度"和"输出维度"（由任务决定），再在中间自由设计隐藏层的个数与宽度。隐藏层越宽、越多，模型容量越大，但参数也越多、越容易过拟合——这与前面学的"偏差-方差权衡"一脉相承。

二、可运行代码示例#

下面用 PyTorch 搭一个 4 → 5 → 3 → 2 的 MLP，并打印每一层的参数形状，把"结构"和"维度"看得一清二楚。

import torch
import torch.nn as nn

# 定义一个 MLP：输入 4 维，两个隐藏层（5 维、3 维），输出 2 维
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        # nn.Linear(in_features, out_features)
        self.fc1 = nn.Linear(4, 5)   # 输入层 -> 隐藏层1
        self.fc2 = nn.Linear(5, 3)   # 隐藏层1 -> 隐藏层2
        self.fc3 = nn.Linear(3, 2)   # 隐藏层2 -> 输出层
        self.act = nn.ReLU()         # 非线性激活

    def forward(self, x):
        x = self.act(self.fc1(x))    # 第 1 层：线性 + ReLU
        x = self.act(self.fc2(x))    # 第 2 层：线性 + ReLU
        return self.fc3(x)           # 输出层：只做线性（分类时再接 softmax/损失）

model = MLP()
print(model)
print()

# 查看每一层参数的形状，验证"权重 (输出, 输入)"的约定
for name, p in model.named_parameters():
    print(f"{name:14s} 形状 = {tuple(p.shape)}")

# 构造一个 batch：3 个样本，每个样本 4 维特征
x = torch.randn(3, 4)     # 形状 (batch=3, 特征=4)
out = model(x)            # 前向传播
print("\n输入形状：", tuple(x.shape))
print("输出形状：", tuple(out.shape), "（3 个样本 × 2 个输出单元）")

运行后你会看到 fc1.weight 的形状是 (5, 4)、fc1.bias 是 (5,)、fc2.weight 是 (3, 5)、fc3.weight 是 (2, 3)——完全符合"权重矩阵形状 = (输出维度, 输入维度)"的约定。输入 3 个样本，输出形状就是 (3, 2)，对应每个样本的两个输出单元。

再用 NumPy 手写一遍，体会"矩阵乘 + 偏置 + 激活"就是一层：

import numpy as np

# 固定一层的权重与偏置（随机生成，权当是"学好的参数"）
rng = np.random.default_rng(0)
W = rng.normal(0, 0.5, size=(5, 4))   # 输出 5 维，输入 4 维
b = rng.normal(0, 0.5, size=(5,))     # 偏置 5 维

x = rng.normal(0, 1, size=(4,))       # 一个 4 维输入
z = W @ x + b                         # 加权求和 + 偏置
a = np.maximum(0, z)                  # ReLU 激活：max(0, z)

print("z =", z)
print("a = ReLU(z) =", a)

这一小段就是全连接层的完整计算：矩阵乘 + 偏置 + 逐元素激活。下一课我们把多层的这一步接起来，完整走一遍前向传播。

三、练习#

  1. 读结构：写出 784 → 256 → 128 → 10 这个网络里，每一层权重矩阵的形状（按 PyTorch 约定），并算出三个全连接层的总参数量。
  2. 验证维度：运行示例代码，确认 fc1.weight 是 (5,4) 而非 (4,5)；说说如果把 nn.Linear(5,3) 误写成 nn.Linear(3,5) 会发生什么报错。
  3. 数参数：用 sum(p.numel() for p in model.parameters()) 统计上面 MLP 的总参数量，并与手工计算 4×5+5 + 5×3+3 + 3×2+2 对比。
  4. 批处理思维：把示例里的输入改成 torch.randn(10, 4)（10 个样本），观察输出形状如何变化，理解为什么"batch 维"不参与权重形状。
  5. 思考：MLP 为什么要求相邻层"输出维度 = 输入维度"？如果输入是 784 维、输出要 10 类，隐藏层设计成 784 → 10 → 10 会有什么问题？
