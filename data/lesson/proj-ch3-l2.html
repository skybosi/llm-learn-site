核心实现（LLM 领域微调）#

本课实现微调的三段核心：数据准备 → LoRA 微调 → 评估。每一段都面向"能复现、能解释"，尤其要把 LoRA 的关键超参（rank/alpha/target modules）和显存优化讲清楚——这是面试最常被追问的地方。

一、目标与步骤#

  1. 数据准备：把原始数据清洗成统一的指令格式，并正确切分训练/验证集。
  2. LoRA 微调：配置 LoRA 参数，用 TRL SFTTrainer 完成训练，给出 LoRA/QLoRA 两种显存方案。
  3. 评估：在同一测试集上对比基座与微调模型，量化"格式遵循率"与"领域准确率"。

二、代码骨架与实现指导#

1. 数据准备#

统一成 instruction / input / output 或 messages 格式，关键是用模型的 chat template 正确编码，而不是手动拼字符串：

import json
from datasets import Dataset

# 读取并清洗：去空、去重、统一字段名
def load_and_clean(path):
    rows = []
    for line in open(path, encoding="utf-8"):
        d = json.loads(line)
        inst, inp, out = d.get("instruction", "").strip(), d.get("input", "").strip(), d.get("output", "").strip()
        if not out:            # 丢弃无输出的脏数据
            continue
        rows.append({"instruction": inst, "input": inp, "output": out})
    # 按 (instruction, input, output) 去重
    seen, dedup = set(), []
    for r in rows:
        key = (r["instruction"], r["input"], r["output"])
        if key not in seen:
            seen.add(key); dedup.append(r)
    return dedup

train_rows = load_and_clean("data/train.jsonl")
val_rows = load_and_clean("data/val.jsonl")
print(f"训练 {len(train_rows)} 条, 验证 {len(val_rows)} 条")

# 组织成 messages 格式，交给 chat template 编码
def format_example(r):
    user = r["instruction"] + (("\n" + r["input"]) if r["input"] else "")
    return {"messages": [
        {"role": "user", "content": user},
        {"role": "assistant", "content": r["output"]},
    ]}

train_ds = Dataset.from_list([format_example(r) for r in train_rows])
val_ds = Dataset.from_list([format_example(r) for r in val_rows])

数据要点：去重与抽检是微调质量的半壁江山；messages 格式让 tokenizer 自动套用 chat template，避免手动拼接带来的格式偏差（例如缺少 <|im_end|>）。

2. LoRA 配置与显存方案#

LoRA 只在部分权重旁挂"低秩增量"，冻结原权重，因此可训练参数极少：

from peft import LoraConfig, get_peft_model, TaskType

# 方案 A：LoRA（bf16，需约 16-20GB 显存）
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=8,                          # 低秩维度：越大表达力越强、参数越多
    lora_alpha=16,                # 缩放系数，通常取 r 的 2 倍
    lora_dropout=0.05,            # 防止 LoRA 分支过拟合
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj",
                    "gate_proj", "up_proj", "down_proj"],  # Qwen 全注意力+MLP
)

参数含义与选择（第 3 课会用实验验证）：

参数 作用 起步建议
r 低秩矩阵秩，决定增量表达能力 8（简单任务）~64（复杂/大数据）
lora_alpha 缩放到 r 的比例，等效学习率量级 取 r 的 1~2 倍
lora_dropout LoRA 分支 dropout 0.05~0.1
target_modules 注入 LoRA 的层 至少 q_proj/v_proj，效果优先可加 MLP

方案 B：QLoRA——基座 4-bit 量化 + LoRA，显存降到 ~8-10GB：

from transformers import BitsAndBytesConfig

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",           # 4bit NormalFloat
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,      # 二次量化，进一步省显存
)
model = AutoModelForCausalLM.from_pretrained(
    model_name, quantization_config=bnb_config, device_map="auto",
    torch_dtype=torch.bfloat16,
)

3. 训练（TRL SFTTrainer）#

用 SFTTrainer 把 tokenize、损失计算、梯度累积、显存优化都封装好：

from trl import SFTTrainer, SFTConfig
from transformers import TrainingArguments

def format_chat(example):
    # 用 tokenizer 的 chat template 转成文本
    return tokenizer.apply_chat_template(example["messages"], tokenize=False)

training_args = SFTConfig(
    output_dir="outputs/lora",
    num_train_epochs=3,
    per_device_train_batch_size=2,        # 小批量 + 梯度累积，适配单卡
    gradient_accumulation_steps=8,
    gradient_checkpointing=True,          # 用计算换显存
    learning_rate=2e-4,                   # LoRA 常用学习率，比全参微调高
    lr_scheduler_type="cosine",
    warmup_ratio=0.03,
    logging_steps=10,
    save_strategy="steps",
    save_steps=200,
    eval_strategy="steps",
    eval_steps=200,
    bf16=True,
    max_seq_length=1024,                  # 截断/打包长度
    report_to="none",
)

trainer = SFTTrainer(
    model=model,
    args=training_args,
    train_dataset=train_ds,
    eval_dataset=val_ds,
    formatting_func=format_chat,          # 关键：统一用 chat template
    peft_config=lora_config,              # 传入 LoRA 配置
)
trainer.train()
trainer.save_model("outputs/lora")       # 保存 LoRA 权重（Adapter）

显存不足的排查顺序：减小 per_device_train_batch_size → 开 gradient_checkpointing → 缩短 max_seq_length → 换 QLoRA（4bit）。学习率 2e-4 是 LoRA 常见起点，明显高于全参数微调的 1e-5~5e-5，别照搬。

4. 合并与加载（可部署）#

from peft import PeftModel

# 推理时：基座 + LoRA 权重，无需重新训练
base = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.bfloat16, device_map="auto")
model = PeftModel.from_pretrained(base, "outputs/lora")
model = model.merge_and_unload()   # 合并回权重，便于直接部署/导出

# 生成对比：同样的输入，分别用基座与微调模型生成
def generate(model, prompt):
    messages = [{"role": "user", "content": prompt}]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(text, return_tensors="pt").to(model.device)
    out = model.generate(**inputs, max_new_tokens=256, do_sample=False)
    return tokenizer.decode(out[0][inputs["input_ids"].shape[1]:], skip_special_tokens=True)

5. 评估#

评估不能只看 loss（loss 低不等于答案好），要测"格式遵循率"和"领域准确率"：

def eval_format_following(model, eval_rows):
    """格式遵循率：输出是否以 { 开头、能被 json.loads 解析。"""
    ok = 0
    for r in eval_rows:
        user = r["instruction"] + (("\n" + r["input"]) if r["input"] else "")
        ans = generate(model, user)
        try:
            json.loads(ans)      # 期望模型输出合法 JSON
            ok += 1
        except Exception:
            pass
    return ok / len(eval_rows)

def eval_domain_accuracy(model, eval_rows):
    """领域准确率：用关键词/规则判断答案是否包含正确结论。"""
    ok = 0
    for r in eval_rows:
        user = r["instruction"] + (("\n" + r["input"]) if r["input"] else "")
        ans = generate(model, user)
        if r["gold_keywords"] and all(k in ans for k in r["gold_keywords"]):
            ok += 1
    return ok / len(eval_rows)

把这两个函数分别跑在基座模型和微调模型上，输出同一批问题的对比分数，就是第 3 课的"微调前后对比表"。

三、验收与复盘#

  1. 数据口径验收：训练/验证集无重叠（按原文去重后仍要检查跨集重复）；验证集不参与训练。
  2. 训练可复现验收：固定随机种子后，两个 seed 的验证 loss 趋势一致。
  3. 显存/时间记账：记录实际峰值显存、单 epoch 时长、总时长——第 3 课复盘成本必用。
  4. 评估双指标验收：格式遵循率与领域准确率都已跑出"基座 vs 微调"两组数字。
  5. 复盘提示：记录训练中遇到的一个真实问题（如 loss 不降 → 发现学习率太高/数据没套 chat template），这是面试"你踩过什么坑"的最佳答案。
