双轴与图例#

把两张图并排放是一种"横向对照"；但有些数据天生就该叠在同一张图里，却因为量纲或数量级不同而没法共用一把尺子。比如温度和降雨量、销售额和增长率。这一课讲两个工具：用双轴解决"两把尺子"的问题，用图例告诉读者每根线代表什么。

一、概念讲解#

1. 为什么要用双轴#

如果两组数据的数值范围相差巨大——比如温度在 -10 到 40 之间、降雨量在 0 到 300 之间——把两者画在同一个 y 轴上，量小的那条曲线会被"压扁"成一条贴地的直线，完全失去可读性。双轴（twin axes）的思路是：在同一张图上叠加第二个坐标系，它共享 x 轴，但拥有独立的 y 轴（标在右侧）。

Matplotlib 提供 ax.twinx()（共享 x 轴、新建右 y 轴）和 ax.twiny()（共享 y 轴、新建上 x 轴）。最常用的是 twinx。

2. 双轴的正确用法与注意事项#

双轴是"强对比"工具，但也容易被误用。两条守则：

  • 务必用颜色把轴和曲线一一对应：左轴、右轴的刻度颜色要和对应曲线一致，否则读者不知道哪条线读哪把尺子。
  • 不要为了"显得专业"而滥用：只有当两组数据量纲确实不同、且同轴会失去信息时才用。若两组数据同量纲，应优先共用一把尺子，诚实比较。

3. 图例：图的"图例说明"#

图例（legend）用一小块带颜色/标记的说明，告诉读者"红色实线是温度、蓝色虚线是降雨量"。核心是：

  • 标签（label）：绘图时给每条线/每个数据系列加 label= 参数。
  • 显示位置（loc）：loc='upper left' 等，或 loc='best' 让 Matplotlib 自动选空白处。
  • 合并多轴图例：双轴图里，两条曲线分属两个坐标轴对象，需要把两个轴上的图例"合并"到一起显示。

二、可运行代码示例#

示例 1：温度与降雨量的双轴图#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

# 模拟某城市一年 12 个月的平均气温（℃）与月降水量（mm）
month = np.arange(1, 13)
temp = [3, 5, 10, 16, 21, 25, 28, 27, 23, 17, 11, 6]      # 气温
rain = [15, 18, 30, 45, 65, 90, 140, 130, 70, 40, 25, 18]  # 降水量

fig, ax1 = plt.subplots(figsize=(9, 5))

# 左轴：气温折线（蓝色）
ax1.plot(month, temp, color='tab:blue', marker='o', label='平均气温')
ax1.set_xlabel('月份')
ax1.set_ylabel('平均气温（℃）', color='tab:blue')
ax1.tick_params(axis='y', labelcolor='tab:blue')

# 右轴：降水量柱状（浅橙色）
ax2 = ax1.twinx()
ax2.bar(month, rain, alpha=0.35, color='tab:orange', label='月降水量')
ax2.set_ylabel('月降水量（mm）', color='tab:orange')
ax2.tick_params(axis='y', labelcolor='tab:orange')

# 合并两个轴上的图例，放到左上角
lines1, labels1 = ax1.get_legend_handles_labels()
lines2, labels2 = ax2.get_legend_handles_labels()
ax1.legend(lines1 + lines2, labels1 + labels2, loc='upper left')

plt.title('某城市全年气温与降水量')
fig.tight_layout()
plt.show()

要点：ax1.twinx() 返回一个新的坐标轴对象 ax2，它和 ax1 共享 x 轴；tick_params(labelcolor=...) 让刻度颜色和曲线颜色一致；合并图例的关键是 get_legend_handles_labels() 把两个轴上的"线 + 标签"拼起来。

示例 2：多条曲线的图例与位置#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

x = np.linspace(0, 10, 200)

fig, ax = plt.subplots(figsize=(8, 5))
# 用不同线型和颜色区分三条曲线，并都加上标签
ax.plot(x, np.sin(x), color='tab:blue', linestyle='-', label='sin(x)')
ax.plot(x, np.cos(x), color='tab:red', linestyle='--', label='cos(x)')
ax.plot(x, np.sin(x) * np.cos(x), color='tab:green', linestyle=':', label='sin(x)·cos(x)')

ax.axhline(0, color='gray', linewidth=0.8)          # 画一条 y=0 的参考线
ax.set_xlabel('x')
ax.set_ylabel('y')
ax.set_title('多曲线与图例')
ax.legend(loc='upper right', frameon=True)          # 图例放在右上角，保留边框
fig.tight_layout()
plt.show()

要点：linestyle 可以写全称或简写（如 '--' 对应虚线）；当一条线视觉上和其他线太接近时，用"颜色 + 线型 + 标记"三者组合来区分，而不是只靠颜色——这样即使黑白打印也能辨认。

三、练习#

  1. 动手练习：用 twinx 画一张"网站每日访问量（柱状）与转化率（折线）"的双轴图，访问量用左轴、转化率用右轴，并让轴颜色与曲线颜色对应。
  2. 合并图例：在上面的双轴图中，把两个轴的图例合并显示在左上角，验证 get_legend_handles_labels() 的拼接写法。
  3. 尝试位置：把 loc 依次改成 'upper left'、'lower right'、'best'，观察图例位置的变化，理解 'best' 是如何自动避让曲线的。
  4. 思考：什么情况下你不应该用双轴？举一个"两组数据同量纲、却有人故意用双轴制造误导"的例子。
