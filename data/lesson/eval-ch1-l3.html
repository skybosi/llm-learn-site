指标设计：准确率、通过率、胜率与 BLEU 类的陷阱#

这一节要解决什么#

指标是把"测量系统"的输出压缩成一个数字的函数。压缩必然丢信息，问题在于丢掉的是噪声还是信号。这一节逐个拆解四类最常见指标：

  1. 分类指标（准确率 / 精确率 / 召回 / F1 / 宏微平均）——它藏起了类别不平衡与代价不对称；
  2. 通过率与 pass@k——它混同了能力与行为，且有一个经典的有偏估计陷阱；
  3. 胜率——它最像产品指标，却不是一把可加的尺子（第 2 节已开这个头，这里做定量）；
  4. BLEU / ROUGE 类 n-gram 指标——公式本身决定它在开放式生成上测的其实是"表面形式重合"。

最后落到一个贯穿全课程的技术点：配对比较。为什么"同一批题目上的分差"的置信区间比"两次独立评测的分差"更窄？这个收益的上界在哪里（什么时候配对完全没用）？这不是技巧，是方差分解的必然结果，也是"分差多少才算真差异"（第 2 章第 3 节）的数学基础。

分类指标：从一个混淆矩阵出发#

所有分类指标都从这张表长出来：

预测正类 预测负类
实际正类 TP FN
实际负类 FP TN

Accuracy=NTP+TN​,Precision=TP+FPTP​,Recall=TP+FNTP​

Fβ​=(1+β2)⋅β2⋅Precision+RecallPrecision⋅Recall​

陷阱一：不平衡下 accuracy 无意义#

设某安全过滤器：1000 条输入里 10 条有害。一个永远说"无害"的模型：

Accuracy=1000990​=99%

而它的召回是 0——它一个有害内容都没拦住。这不是极端例子，而是评测里最普遍的错误：当任务的基线（多数类比例）很高时，accuracy 与"有用"几乎无关。

诊断：永远先报基线（多数类比例、随机猜测比例 1/k）。如果 accuracy 只比基线高几个点，就必须看别的指标。

陷阱二：宏平均与微平均在回答不同的问题#

多分类任务里，"平均"有三种，含义完全不同。用一组示意值（与下面的代码同结构）：

类别 样本数 该类 F1
A 900 0.95
B 90 0.57
C 10 0.00（全错）
  • 微平均（micro）：把所有类的 TP/FP/FN 汇总再算 → 等于总 accuracy ≈0.91。大类的表现主导结果。
  • 宏平均（macro）：先算每类指标再等权平均 → (0.95+0.57+0.00)/3≈0.51。每个类同等重要。
  • 加权平均（weighted）：按类样本数加权 → 接近微平均。

同一个模型的 macro 与 micro 可以相差 40 个点（0.51 vs 0.91）——这不是精度问题，是"在回答哪个问题"的问题。

为什么这个区分重要？ 因为它对应两种不同的价值判断：如果 C 类是罕见但代价极高的场景（比如某些法律条款问答），微平均会把它完全掩盖（占比 1%，全错也只掉 1 个点）；宏平均则会让它占 1/3 的权重。报告指标时必须说清用的是哪一种，"F1 = 0.9"这句话不足以复现。

陷阱三：代价不对称时，accuracy 与 F1 都不是目标函数#

真实业务里 FP 与 FN 的代价通常差很多（漏掉一条违规 vs 误伤一条正常请求）。此时正确的做法不是选一个更漂亮的通用指标，而是写加权代价：

Cost=cFP​⋅FP+cFN​⋅FN

然后在这个代价下比较模型与阈值。指标的作用是沟通，不是决策；决策要用代价。

通过率与 pass@k：能力与行为的分界#

第 1 节讲过 pass@1 是行为、pass@k 是能力。这里把估计量讲清楚，因为它是"估计量设计"的一个教科书级案例。

pass@k 的无偏估计#

设定：每题采样 n 次，其中 c 次通过。一个自然的想法是用 p^​=c/n 再算 1−(1−p^​)k。这是有偏的——因为 p^​ 本身有噪声，而 x↦1−(1−x)k 是凹函数/凸函数的组合，期望不等于函数在期望处的值（Jensen 不等式）。

正确的做法是不经过 p^​，直接算"从这 n 个样本里抽 k 个，至少有一个通过"的概率：

pass@k​=1−(kn​)(kn−c​)​=1−i=0∏k−1​n−in−c−i​

可以证明它是 1−(1−p)k 的无偏估计（对所有 p）。数值感受一下：

n c k 无偏估计 朴素 1−(1−c/n)k 偏差
10 1 5 0.500 0.410 −0.090
10 3 5 0.917 0.832 −0.085
20 2 10 0.763 0.651 −0.112
200 20 10 0.660 0.651 −0.009

n 越小，朴素公式的偏差越大（n=10 时低估近 9 个点）。这就是为什么"pass@k 只能在自己采样的 n 次里算"：估计量依赖 n，n 不同结果不可比。

三个必须遵守的规则#

  1. k≤n，且报 n。k>n 时估计量无定义（分母为 0）。
  2. 跨模型比较必须固定 k 与 n。pass@10 vs pass@1 是无意义对比。
  3. pass@k 的方差比 pass@1 大，因为它由尾部事件驱动（"至少一次成功"），对 c=0 的题目极敏感。n 很小的时候，pass@k 的估计极不稳定。

一个容易被忽略的解读陷阱#

pass@kk→n​1(只要 c≥1)

也就是说，足够大的 k 下所有"能做对一次"的模型都会趋近 100%。pass@k 的绝对值没有跨任务意义（k 与 n 是人为选的），有意义的只是"在固定协议下的相对比较"。想度量"能力"更稳的方式通常是固定 k、增加 n（更多次采样），而不是加大 k。

胜率：最像产品指标，也最容易误读#

胜率的定义与它的三个病（对手集合依赖、非传递性、平局规则）在第 2 节已经出现，这里补上定量部分。

病一的定量：胜率是强度的非线性函数#

在 Bradley-Terry 下，模型 i 对模型 j 的期望胜率是

wij​=σ(βi​−βj​)

同样的强度差，在不同水平上给出的胜率不一样：βi​−βj​=0.5 → 62%；=1.0 → 73%；=2.0 → 88%。因此"胜率从 62% 提到 73%"与"从 88% 提到 99%"需要的强度提升完全不同。胜率不是一个等距量表，把胜率当分数做算术（"平均胜率""胜率提升 10 个点"）在数学上没有依据。

病二的定量：非传递性有多常见#

非传递性来自"模型 × 任务类型"的交互：A 擅代码、B 擅写作、C 擅数学，题目集合固定时就会出现循环。可以构造一个最小例子：

  • 题目 1/2 是代码题，题目 3 是写作题；
  • A 对 B：代码赢 2/3；
  • B 对 C：写作 + 一道代码赢 2/3；
  • C 对 A：靠写作与另一道代码赢 2/3。

此时"总排名"不存在。这不是数据噪声，而是真实的多元结构被一维排名强行压平。 实用对策：先按子域分别排名（第 2 章的自建评测集会讲分层设计），再看是否仍存在全局一致序；不要用一个总榜掩盖子域差距。

平局的处理会改变结论#

三种常见约定：平局各记 0.5；平局不计入分母；平局算"都不好"单列。当平局率高（比如 40%）时，三种约定给出的胜率可以差很多。必须预先声明规则，并且最好把平局率本身作为一个报告量——它往往说明"两个模型在这个任务上都不可用"，这是比谁赢更有价值的信息。

正确做法#

  1. 报告对手集合与题目集合；
  2. 用 BT（或 Elo）拟合强度参数 β，并给 bootstrap 置信区间；
  3. 报告平局率；
  4. 分域报告，不要只给总分。

BLEU / ROUGE 类：n-gram 重叠的数学与失效#

BLEU 的定义#

设候选译文为 c、参考译文为 r，pn​ 是裁剪后的 n-gram 精确率：

pn​=∑g∈n-grams(c)​countc​(g)∑g∈n-grams(c)​min(countc​(g),maxr​countr​(g))​

裁剪（clip）的作用是防止"the the the the"这类重复刷高精确率。再加简短惩罚（brevity penalty）与几何平均：

BP=exp(min(0,1−rlen​/clen​)),BLEU=BP⋅exp(n=1∑N​wn​logpn​)

典型 N=4、wn​=1/N。理解这三个零件就能理解它的失效：

  • 几何平均：任一阶 pn​=0 则整体为 0。对短句极不稳定（真实实现用平滑，平滑方式直接影响可比性）；
  • 简短惩罚：BP 只在候选更短时生效，且是长度比的函数，因此长度是分数的一部分；
  • 裁剪：它惩罚重复，但不惩罚漏译——BLEU 没有召回项，漏掉一半内容可以得高分。

为什么它在开放式生成上几乎无用#

失效 机制 例子
同义改写 n-gram 不重合但语义相同 "降雨概率 30%" vs "三成可能下雨"
语序变化 n-gram 对位置敏感 主动/被动句
多参考不足 单一参考覆盖不了合法答案空间 开放问答、摘要
长度偏差 BP 与 pn​ 都受长度影响 长回答更容易覆盖参考 n-gram
与人类判断弱相关 它测形式，人类测内容/有用性 机器翻译外任务上相关性常显著下降

ROUGE 是召回导向的变体（分母用参考的 n-gram 数），常用于摘要；它同样只看表面重合。chrF 用字符 n-gram，缓解形态丰富语言的词形变化问题。BERTScore 用上下文嵌入做贪心匹配并加权，COMET 直接在有真人评分的语料上训练回归——它们把"与人类判断的相关性"做成了模型目标，因此通常相关性更好，但代价是引入了不可解释性与新的分布依赖（换领域即需重验）。

一条纪律：任何"与人类判断的相关性"都是任务相关的结论，不能跨任务搬运。"BLEU 在机器翻译上与人类相关 0.6"不能推出"BLEU 在客服摘要上可以用"。选指标的唯一合法流程是：在你的任务上，用人工标注的样本，测这个指标与人类判断的相关性（第 2 节的一致性工具）。

配对比较：为什么同一批样本上的分差更可信#

这是本节最重要的一节。假设模型 A、B 在同一批 n 道题上的每题得分是 ai​,bi​∈{0,1}，我们关心

Δ^=n1​i=1∑n​(ai​−bi​)=n1​i=1∑n​di​

方差分解：配对消掉了题目难度#

把每题的得分写成"题目难度 + 模型效应 + 噪声"：

ai​=μ+τA​+δi​+εAi​,bi​=μ+τB​+δi​+εBi​

其中 δi​ 是题目难度（对所有模型相同）。当两个模型跑同一批题时：

di​=ai​−bi​=(τA​−τB​)+(εAi​−εBi​)

题目难度项 δi​ 被完全消掉了。 因此

Var(di​)=Var(ai​)+Var(bi​)−2Cov(ai​,bi​)

而题目难度正是让 ai​,bi​ 高度相关的原因（Cov>0）。题目难度方差越大（评测集越"难易混杂"），配对带来的方差缩减越多。

于是两个标准误：

SEpaired​=n​sd​​,SEunpaired​=nsa2​​+nsb2​​​

比值 SEpaired​/SEunpaired​ 可以显著小于 1——同样的题目数，配对的置信区间更窄。这就是"两次独立评测的分差"与"同一评测集上的分差"可信度不同的根本原因：后者是一次配对实验，前者是两个独立实验的差，题目难度的方差没有被消掉。随机性相同、信息量却不同。

⚠️ 但必须给这个结论加一个边界：0/1 计分下，配对能消掉的只有"题目异质性"那一部分方差，伯努利噪声（p(1−p)）在两次独立抽样之间是独立的，配对消不掉它。 因此配对的收益有上界：

SEunpaired​SEpaired​​≥E[p(1−p)]+Var(p)E[p(1−p)]​​

含义很直接：题目难度越分散（Var(p) 越大），配对越值钱；如果所有题目的通过率都差不多（例如都在 0.5 附近），配对几乎不带来收益。实测里典型收益是 1.2 ~ 2 倍（题目异质性大的评测集靠近 2 倍），而不是数量级——所以"配对是免费的方差缩减"这句话要理解为"免费的、有上界的缩减"。想进一步降方差，只能靠加题、加模板或降低生成随机性（第 2 章第 3 节）。

McNemar：只看"不一致"的格子#

对 0/1 配对数据，四格里只有两格携带模型差异的信息：

B 对 B 错
A 对 a（都对） b（A 对 B 错）
A 错 c（A 错 B 对） d（都错）

a,d 两格完全不含"谁更好"的信息。检验 τA​=τB​ 只需看 b 与 c：

χ2=b+c(∣b−c∣−1)2​∼χ12​(连续性校正)

b+c 小时用精确二项检验（b∼Binomial(b+c,0.5)）。

为什么这个检验比"两个准确率之差的 t 检验"合适？ 因为它直接建模了配对结构（谁对谁错），而把"都对/都错"的题目排除在证据之外——那些题只贡献了噪声中的公共部分。这也是"配对设计提高检验效能"的具体机制。

bootstrap：给任意指标配一个置信区间#

当指标不是简单均值（F1、pass@k、BLEU、胜率）时，闭式标准误很难写。用 bootstrap 重采样题目：

for b in 1..B:
    从 n 道题里有放回抽 n 道（配对！同一次抽样同时用于 A 和 B）
    在原样本上重算指标差 Δ*
取 Δ* 的 2.5% / 97.5% 分位数 → 95% CI

三个关键点：

  1. 必须按题配对重采样，否则丢掉方差缩减的好处；
  2. 题目成簇时必须按簇重采样（整簇 bootstrap），否则 CI 会被系统性地低估（第 2 章第 3 节）；
  3. B≥2000 是常规起点；CI 平滑度随 B 提高。

指标设计检查清单#

设计或验收一个指标时，逐条过：

  1. 它对应的构念是什么？ 能力、行为还是偏好？（第 1 节）
  2. 它的基线是多少？ 多数类比例 / 1/k 随机猜测 / 恒定输出的得分。
  3. 它对不平衡敏感吗？ 需要宏平均还是微平均？
  4. 它把代价不对称编码进去了吗？ 还是把 FP/FN 当等代价？
  5. 它对长度、格式、重复敏感吗？ 具体是哪个零件引入的敏感？
  6. 它区分能力与行为吗？ 有没有同时报 pass@1 与 pass@k？
  7. 它可加吗？ 能不能对两个分数做算术？（胜率不能）
  8. 它的不确定性有多大？ 报了 CI/SE 没有？配对了吗？按簇重采样了吗？
  9. 它作为代理被人优化之后会怎样？ （Goodhart，第 4 节）
  10. 它与人类判断的相关性在你自己的任务上测过吗？

代码：四个指标的实现与它们的"病"#

import numpy as np
from collections import Counter
from math import comb, exp, log

# ---------- 1. 宏/微平均：同一份预测，两个答案 ----------
# y_true/y_pred 为 3 类标签；类别极不平衡
y_true = np.array([0]*900 + [1]*90 + [2]*10)
y_pred = y_true.copy()
flip = np.random.default_rng(0)
y_pred[:45] = 1           # 类 0 错 45 个
y_pred[900:936] = 0       # 类 1 错 36 个
y_pred[990:] = 0          # 类 2 全错 10 个

def prf(y_true, y_pred, cls):
    tp = np.sum((y_pred == cls) & (y_true == cls))
    fp = np.sum((y_pred == cls) & (y_true != cls))
    fn = np.sum((y_pred != cls) & (y_true == cls))
    p = tp / (tp + fp) if tp + fp else 0.0
    r = tp / (tp + fn) if tp + fn else 0.0
    f = 2*p*r/(p+r) if p + r else 0.0
    return p, r, f

per_cls = [prf(y_true, y_pred, c) for c in (0, 1, 2)]
print("每类 (P,R,F1):", [(round(p,3), round(r,3), round(f,3)) for p,r,f in per_cls])
print(f"macro-F1 = {np.mean([f for _,_,f in per_cls]):.3f}")
print(f"micro-F1 = {np.mean(y_pred == y_true):.3f}  (= accuracy，被大类主导)")
print(f"基线(多数类) = {np.mean(y_true == 0):.3f}")

# ---------- 2. pass@k：有偏 vs 无偏 ----------
def pass_at_k(n, c, k):
    """从 n 次采样中抽 k 次，至少一次通过的概率（无偏估计量）。"""
    if n - c < k:
        return 1.0
    return 1.0 - comb(n - c, k) / comb(n, k)

for n, c, k in [(10,1,5), (10,3,5), (20,2,10), (200,20,10)]:
    naive = 1 - (1 - c/n)**k
    print(f"n={n:3d} c={c:2d} k={k:2d} | 无偏={pass_at_k(n,c,k):.3f}  朴素={naive:.3f}  偏差={naive-pass_at_k(n,c,k):+.3f}")

# ---------- 3. 配对 vs 非配对：方差缩减有多大（以及它的上界） ----------
rng = np.random.default_rng(1)
n = 500
# 题目难度双峰：一半"简单"、一半"难" —— 题目异质性越大，配对的收益越明显
difficulty = rng.choice([-2.2, 2.2], size=n)
p_a = 1/(1 + np.exp(-(0.9 - difficulty)))
p_b = 1/(1 + np.exp(-(1.15 - difficulty)))               # B 略强
A = (rng.random(n) < p_a).astype(int)
B = (rng.random(n) < p_b).astype(int)

d = A - B
se_paired = d.std(ddof=1) / np.sqrt(n)
se_unpaired = np.sqrt(A.var(ddof=1)/n + B.var(ddof=1)/n)
print(f"\n准确率: A={A.mean():.3f} B={B.mean():.3f} 分差={d.mean():+.4f}")
print(f"A/B 逐题相关 = {np.corrcoef(A, B)[0,1]:.3f}   <- 配对收益的唯一来源")
print(f"配对 SE   = {se_paired:.4f} -> 95% CI 半宽 {1.96*se_paired:.4f}")
print(f"非配对 SE = {se_unpaired:.4f} -> 95% CI 半宽 {1.96*se_unpaired:.4f}")
print(f"配对把 CI 缩到 {se_paired/se_unpaired:.2f} 倍（题越异质收益越大，但有上界）")

# 对照：如果所有题目通过率都接近 0.5（题目同质），配对几乎没用
difficulty_flat = rng.normal(0, 0.15, n)                 # 难度几乎无差异
q_a = 1/(1 + np.exp(-(0.9 - difficulty_flat)))
q_b = 1/(1 + np.exp(-(1.15 - difficulty_flat)))
A2 = (rng.random(n) < q_a).astype(int)
B2 = (rng.random(n) < q_b).astype(int)
d2 = A2 - B2
ratio_flat = (d2.std(ddof=1)/np.sqrt(n)) / np.sqrt(A2.var(ddof=1)/n + B2.var(ddof=1)/n)
print(f"题目同质时，配对只能把 CI 缩到 {ratio_flat:.2f} 倍（收益几乎为零）")

# McNemar：只用不一致的格子
b01 = int(np.sum((A == 1) & (B == 0)))
c10 = int(np.sum((A == 0) & (B == 1)))
chi2 = (abs(b01 - c10) - 1)**2 / (b01 + c10) if b01 + c10 else 0.0
print(f"McNemar: b={b01} c={c10} chi2={chi2:.2f}  (df=1, 0.05 临界值 3.84)")

# 整簇 bootstrap（这里以"连续 10 题为一簇"模拟同源题目）
cluster = np.arange(n) // 10
boot = []
for _ in range(2000):
    picked = rng.choice(cluster.max()+1, cluster.max()+1, replace=True)
    idx = np.concatenate([np.where(cluster == p)[0] for p in picked])
    boot.append(d[idx].mean())
print(f"簇 bootstrap 95% CI: [{np.percentile(boot,2.5):+.4f}, {np.percentile(boot,97.5):+.4f}]")

# ---------- 4. BLEU 的最小实现 ----------
def ngrams(tokens, n):
    return Counter(tuple(tokens[i:i+n]) for i in range(len(tokens)-n+1))

def corpus_bleu(cands, refs, max_n=4):
    num = [0.0]*(max_n+1); den = [0.0]*(max_n+1); c_len = r_len = 0
    for cand, ref in zip(cands, refs):
        c_len += len(cand); r_len += len(ref)
        for k in range(1, max_n+1):
            cc, rc = ngrams(cand, k), ngrams(ref, k)
            num[k] += sum(min(v, rc[g]) for g, v in cc.items())   # 裁剪：不超过参考次数
            den[k] += sum(cc.values())
    prec = [num[k]/den[k] if den[k] else 0.0 for k in range(1, max_n+1)]
    if min(prec) == 0.0:
        return 0.0            # 几何平均：任一阶为 0 则整体为 0（真实实现用平滑）
    bp = exp(min(0.0, 1 - r_len/c_len))                       # 简短惩罚
    return bp * exp(sum(log(p) for p in prec) / max_n)

cands = [["降雨", "概率", "为", "30", "%"], ["可能有", "三成", "概率", "下雨"]]
refs  = [["降雨", "概率", "为", "30", "%"], ["降雨", "概率", "为", "30", "%"]]
print(f"\nBLEU(逐字相同) = {corpus_bleu(cands[:1], refs[:1]):.3f}")
print(f"BLEU(同义改写) = {corpus_bleu(cands[1:], refs[1:]):.3f}   <- 语义相同，分数为 0")

四个设计决策值得注意：

  • 宏/微平均的差异不是小数点后的差异：这个例子里 macro-F1 远低于 micro-F1，因为小类全错。选哪个取决于 C 类对你重不重要——这是价值判断，不是技术判断。
  • 朴素 pass@k 系统性低估（且 n 越小越严重）。这是一个"直觉公式错在哪"的典型案例：问题在于把估计量代入了非线性函数。
  • 配对 CI 的缩小幅度取决于题目异质性：难度方差越大，Cov(ai​,bi​) 越大，配对收益越大。代码里的对照实验给出了两端：题目双峰分布（异质性大）时缩到 0.63 倍；题目几乎同质时缩到 1.01 倍（等于白配）。这也解释了为什么"难度跨度大"的评测集上配对设计几乎是必须的，而"所有题都差不多难"的评测集上配对帮不上忙。
  • BLEU 在第二句上是 0：语义完全正确，一字未重。这不是实现 bug，而是指标的定义。任何把 BLEU 当"答案质量"的用法，都必须先在自己的任务上验证它与人类判断的相关性。
  • ⚠️ 上面对 judge/评测的模拟都是合成数据：它们的用途是理解统计量的行为，不是给出任何真实基准的数值结论。

练习#

  1. 指标选型：一个二分类内容审核系统，正类（违规）占比 1%，cFN​:cFP​=20:1。 （a）写出一个永远输出"不违规"的模型的 accuracy、precision、recall、F1； （b）在 20:1 的代价下算它的总代价，并给出一个"代价更低"的平凡策略（提示：考虑全部判违规）； （c）说明为什么这类场景不能只报 F1。

  2. pass@k 的偏差：证明或数值验证朴素估计 1−(1−c/n)k 系统性低估 pass@k。 （a）用 n=10,c=1 手算两个值； （b）说明为什么偏差随 n 增大而减小（提示：p^​ 的方差 ∝1/n，以及 Jensen 不等式）； （c）如果某论文只报"pass@100 = 92%（n=100）"，你能从中读出哪些信息、读不出哪些？

  3. 配对设计：你要在 300 道题上比较两个模型，预计分差只有 2 个百分点。 （a）用 SE=p(1−p)/n​ 估计非配对方案的 95% CI 半宽，判断能否得出结论； （b）假设题目难度使两个模型得分的相关系数 r=0.6，用 Var(d)=2σ2(1−r) 估计配对方案的标准误，再看能否得出结论； （c）如果仍然不显著，你有三个选择：加题、减少生成随机性、提高每题的采样数并做多数投票。分别分析它们降低了哪一部分方差，以及对"能力 vs 行为"这两层提问各有什么影响。

  4. 换指标就换结论：构造一个（模型 A、模型 B、评测集）的小例子，使得： （a）按 accuracy，A 更好；（b）按 macro-F1，B 更好；（c）按 BLEU，B 更好。 写出你的数据构造（可以只有 10 个样本），并解释这三条结论分别在回答什么问题——它们矛盾吗？

  5. 平局与胜率：某成对评测 1000 组，结果：A 胜 300、B 胜 300、平局 400。 分别按"平局记 0.5""平局不计入分母""平局单列"算 A 的胜率，并说明如果要对外只报一个数，你会报什么、附哪些说明。

小结#

  • 分类指标：accuracy 在不平衡下会被基线主导；宏/微/加权平均回答不同问题，必须声明；代价不对称时要写加权代价，而不是挑一个"更好看"的通用指标。
  • 通过率与 pass@k：pass@k 的无偏估计是 1−(kn−c​)/(kn​)，朴素公式系统性低估且 n 越小越严重。pass@1 是行为、pass@k 是能力，必须固定 k 与 n 才能跨模型比较。
  • 胜率：依赖对手集合与题目集合、可能非传递、受平局规则影响；它是强度的非线性函数，不可当等距分数做算术。要比较就拟合 Bradley-Terry + 置信区间，并分域报告。
  • BLEU/ROUGE 类：本质是裁剪后的 n-gram 精确率 + 简短惩罚的几何平均，测的是表面重合而非内容；同义改写直接得 0。任何"与人类判断相关"的结论都必须在本任务上重新验证。
  • 配对比较是本节的技术核心：同一批题上的分差把题目难度方差消掉（Var(d)=Var(a)+Var(b)−2Cov），配对的 CI 更窄——但有上界：0/1 计分下的伯努利噪声配对消不掉，题目越异质收益越大（典型 1.2~2 倍），题目同质时几乎为零。0/1 数据用 McNemar 只看不一致格；复杂指标用按题（按簇）配对 bootstrap 给 CI。
  • 指标设计的终点不是"选一个数字"，而是让这个数字与决策挂钩：它必须能改变你下一步做什么。
