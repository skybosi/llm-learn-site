项目一：命令行待办清单#

从这一课开始，我们进入实战：把前面学到的变量、循环、函数、文件读写、异常处理串起来，做出三个真正能用的小程序。第一个项目是一个命令行待办清单——在终端里记录你要做的事，支持增删查改，并且退出后数据不会丢。

一、概念讲解#

1. 需求分析#

动手写代码前，先想清楚程序要做什么：

  1. 显示一个菜单，让用户选择操作；
  2. 能添加一条待办；
  3. 能查看所有待办；
  4. 能把做完的待办标记为完成，或者直接删除；
  5. 退出时把待办保存到文件，下次启动自动读回来。

2. 设计思路#

  • 数据存储：用一个列表 todos，每个元素是一条待办。为了能区分"已完成"，每条待办用一个字典表示，例如 {"text": "买菜", "done": False}。
  • 持久化：退出时用 json.dump 把列表存进文件，启动时用 json.load 读回来；文件不存在就当作空列表。
  • 主循环：用 while True 循环显示菜单、读取用户输入，根据输入执行对应功能，直到用户选择"退出"。
  • 健壮性：对读取文件用 try/except 处理文件不存在的情况，对菜单输入做校验。

3. 功能拆解#

把每个功能写成一个函数，主循环只负责"分发"，这样代码清晰、好维护：

  • load_todos()：从文件读取待办列表；
  • save_todos(todos)：把列表写回文件；
  • show_menu()：打印菜单；
  • add_todo(todos)：添加待办；
  • list_todos(todos)：列出所有待办；
  • mark_done(todos)：标记完成；
  • delete_todo(todos)：删除待办。

二、可运行代码示例#

下面是一份完整、可以直接运行的程序。你可以把它保存成 todo.py，在终端用 python todo.py 启动。

import json
import os

FILENAME = "todos.json"   # 保存待办的文件名


def load_todos():
    """从文件读取待办列表；文件不存在则返回空列表。"""
    if os.path.exists(FILENAME):
        with open(FILENAME, "r", encoding="utf-8") as f:
            return json.load(f)
    return []


def save_todos(todos):
    """把待办列表写回文件。"""
    with open(FILENAME, "w", encoding="utf-8") as f:
        json.dump(todos, f, ensure_ascii=False, indent=2)


def show_menu():
    """打印操作菜单。"""
    print("\n===== 待办清单 =====")
    print("1. 添加待办")
    print("2. 查看所有待办")
    print("3. 标记完成")
    print("4. 删除待办")
    print("5. 退出")


def add_todo(todos):
    """添加一条新待办。"""
    text = input("请输入待办内容：").strip()
    if text:
        todos.append({"text": text, "done": False})
        print("已添加：", text)
    else:
        print("内容不能为空。")


def list_todos(todos):
    """列出所有待办及完成状态。"""
    if not todos:
        print("当前没有待办。")
        return
    for i, item in enumerate(todos, start=1):
        status = "已完成" if item["done"] else "未完成"
        print(f"{i}. [{status}] {item['text']}")


def mark_done(todos):
    """按编号把某条待办标记为完成。"""
    list_todos(todos)
    try:
        idx = int(input("请输入要标记完成的编号：")) - 1
        todos[idx]["done"] = True
        print("已标记完成：", todos[idx]["text"])
    except (ValueError, IndexError):
        print("编号无效。")


def delete_todo(todos):
    """按编号删除某条待办。"""
    list_todos(todos)
    try:
        idx = int(input("请输入要删除的编号：")) - 1
        removed = todos.pop(idx)
        print("已删除：", removed["text"])
    except (ValueError, IndexError):
        print("编号无效。")


def main():
    """程序入口：循环处理用户选择。"""
    todos = load_todos()
    while True:
        show_menu()
        choice = input("请选择操作（1-5）：").strip()
        if choice == "1":
            add_todo(todos)
        elif choice == "2":
            list_todos(todos)
        elif choice == "3":
            mark_done(todos)
        elif choice == "4":
            delete_todo(todos)
        elif choice == "5":
            save_todos(todos)          # 退出前保存
            print("已保存，再见！")
            break
        else:
            print("无效选择，请输入 1-5。")


if __name__ == "__main__":
    main()
