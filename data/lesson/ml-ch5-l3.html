随机搜索#

网格搜索很直观，但有个致命短板：它穷举所有组合。超参数一多、候选值一密，组合数立刻爆炸，根本跑不完。随机搜索（Random Search） 换了个思路——不穷举，而是在参数空间里随机抽样，用固定的预算（比如只试 30 组）去碰运气，往往比网格搜索更快找到好参数。

一、概念讲解#

1. 随机搜索的思路：固定预算，随机抽样#

给每个超参数一个分布（而不是固定列表），然后随机抽 n_iter 组参数组合去试：

  • 整数型参数（如 n_estimators、max_depth）用 randint 或离散列表。
  • 连续型参数（如 C、learning_rate）用 uniform 或 loguniform。
  • n_iter 是预算：想试多少组就抽多少组，与参数个数、候选值个数无关。

每一组抽到的参数仍用交叉验证打分，最后同样返回 best_params_、best_score_、best_estimator_。

2. 为什么随机搜索常常赢过网格搜索#

关键洞察来自 Bergstra & Bengio 的经典论文：当只有少数几个超参数真正影响性能时，网格搜索的大量组合都浪费在"无关紧要的维度"上。

举例：假设真正影响结果的只有超参数 A，而超参数 B 几乎无所谓。网格搜索给 A 试了 9 个值、B 试了 9 个值，A 的 9 个值每个只被试 1 次；而随机搜索抽 30 组，A 会被抽到大约 30 个互不相同的值——对真正重要的那个维度覆盖得更密、更有效。

3. 连续分布：loguniform 的妙用#

有些超参数的取值范围横跨好几个数量级，比如 SVM 的 C 可能从 0.0001 到 10000。若用 uniform 均匀抽样，绝大多数样本会落在数值大的区间，小值区间被忽略；用 loguniform 则按对数尺度均匀抽样，让每个数量级都被公平覆盖。

4. 什么时候用哪个#

  • 参数少、候选值少、计算快 → 网格搜索，穷举彻底。
  • 参数多、取值范围大、单次训练慢 → 随机搜索，预算可控、效率更高。

实际项目里，随机搜索常用来快速圈定大方向，再用网格搜索在最优区域附近精细微调。

二、可运行示例#

示例 1：用 RandomizedSearchCV 调随机森林

from scipy.stats import randint, uniform
from sklearn.datasets import load_iris
from sklearn.model_selection import RandomizedSearchCV, train_test_split
from sklearn.ensemble import RandomForestClassifier

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0, stratify=y)

# 用"分布"描述搜索空间，而不是列出所有候选值
param_dist = {
    "n_estimators": randint(10, 200),     # 在 [10, 200) 内随机取整数
    "max_depth": [None, 5, 10, 20, 30],   # 也可以混合使用固定列表
    "min_samples_split": randint(2, 20),  # 在 [2, 20) 内随机取整数
    "max_features": uniform(0.3, 0.7),    # 在 [0.3, 1.0) 内均匀取连续值
}

# n_iter=30：不管组合总数有多少，只随机抽 30 组来试
rs = RandomizedSearchCV(
    RandomForestClassifier(random_state=0),
    param_dist, n_iter=30, cv=5, scoring="accuracy", random_state=42)
rs.fit(X_train, y_train)

print("最优参数：", rs.best_params_)
print("最优交叉验证得分：", round(rs.best_score_, 3))
print("测试集得分：", round(rs.score(X_test, y_test), 3))

示例 2：loguniform 按对数尺度采样

from scipy.stats import loguniform
from sklearn.datasets import load_iris
from sklearn.model_selection import RandomizedSearchCV
from sklearn.svm import SVC

X, y = load_iris(return_X_y=True)

# C 的取值范围跨越多个数量级，用 loguniform 让每个数量级都被覆盖
param_dist = {
    "C": loguniform(1e-3, 1e3),   # 在 [0.001, 1000] 内按对数尺度均匀抽样
    "gamma": loguniform(1e-4, 1e0),
}
rs = RandomizedSearchCV(SVC(), param_dist, n_iter=20, cv=5,
                        scoring="accuracy", random_state=0)
rs.fit(X, y)

print("最优参数：", rs.best_params_)
print("最优交叉验证得分：", round(rs.best_score_, 3))

示例 3：随机搜索 vs 网格搜索——同样的预算下比较

from sklearn.datasets import load_digits
from sklearn.model_selection import (GridSearchCV, RandomizedSearchCV,
                                     train_test_split)
from sklearn.ensemble import RandomForestClassifier
from scipy.stats import randint

X, y = load_digits(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0, stratify=y)

# 网格搜索：3*3*3 = 27 组
grid = GridSearchCV(
    RandomForestClassifier(random_state=0),
    {"n_estimators": [50, 100, 150],
     "max_depth": [10, 20, 30],
     "min_samples_split": [2, 5, 10]},
    cv=3, n_jobs=-1)
grid.fit(X_train, y_train)

# 随机搜索：同样只试 27 组，但覆盖的取值范围更广
rand = RandomizedSearchCV(
    RandomForestClassifier(random_state=0),
    {"n_estimators": randint(50, 200),
     "max_depth": randint(5, 40),
     "min_samples_split": randint(2, 20)},
    n_iter=27, cv=3, random_state=0, n_jobs=-1)
rand.fit(X_train, y_train)

print("网格搜索最优得分：", round(grid.best_score_, 3))
print("随机搜索最优得分：", round(rand.best_score_, 3))
print("网格最优参数：", grid.best_params_)
print("随机最优参数：", rand.best_params_)

三、练习#

  1. 理解分布：说明 randint(2, 20) 和 uniform(0.3, 0.7) 各自会在什么范围内抽样，为什么整数型参数不用 uniform。
  2. 预算的意义：把示例 1 的 n_iter 分别设为 10 和 100，比较最优得分的变化，说说预算大小如何影响搜索质量。
  3. 对数尺度：用手算或画图的方式，比较 uniform(0.001, 1000) 与 loguniform(0.001, 1000) 各抽 1000 个点时，落在 [0.001, 1] 区间的比例，体会 loguniform 的作用。
  4. 复现实验：运行示例 3，观察同样试 27 组，随机搜索是否能逼近甚至超过网格搜索，并结合"少数超参数才重要"的观点解释。
  5. 思考：既然随机搜索这么好，为什么网格搜索仍然存在？什么场景下它反而是更好的选择？
