安装与环境配置#

上一课我们认识了 Python。这一课，我们要真正把它装到你的电脑上，让它"能跑起来"。整个过程大概需要十分钟。

一、概念讲解#

1. 安装 Python 的三个关键概念#

在动手之前，先理解三个词，后面操作时会顺畅很多：

  • 解释器（Interpreter）：Python 的"翻译引擎"。你把 Python 代码交给它，它逐条翻译并执行。安装 Python，本质就是安装这个解释器。
  • IDLE：随 Python 一起送的一个最简编辑器。对新手来说够用，可以马上开始写代码，不用额外安装别的软件。
  • 代码编辑器 / 集成开发环境（IDE）：更方便的写代码工具，比如 VS Code、PyCharm。等入门后想更高效地写代码，可以再装。

2. 下载前确认两点#

  1. 操作系统：Windows、macOS、Linux 都能装 Python。下面的例子以 Windows 为主，其他系统思路相同。
  2. 版本：安装最新的 Python 3.x 即可（例如 3.11、3.12、3.13 都属于 3.x）。注意：Python 有一个很老的 2.x 系列，已经停止维护，一定不要装 2.x。认准版本号以 "3." 开头。

3. 一个必须勾选的选项#

在 Windows 上安装时，安装向导第一屏的底部有一个选项：

Add Python to PATH（把 Python 加入环境变量）

请务必勾选它。 它的作用是：让你在任意位置打开命令行，敲一个 python 就能用，而不用每次先切换到 Python 的安装目录。很多人装完后发现命令不识别，都是这一步漏掉了。

4. 命令行是什么#

命令行（也叫终端、命令提示符）是一个"用文字给电脑下命令"的窗口。写程序经常会用到它：

  • Windows 上，按 Win + R，输入 cmd 回车；或搜索"命令提示符"。
  • macOS 上，打开"终端"（Terminal）。

5. 验证安装是否成功#

安装完成后，打开命令行，输入：

python --version

如果屏幕上出现类似下面的内容，就说明安装成功了：

Python 3.12.4

（具体版本号可能不同，只要以 "Python 3." 开头就对了。）

二、可运行代码示例#

装好后，让我们验证一下"解释器真的能工作"。打开命令行，输入 python 回车，会进入一个交互模式（提示符从 C:\> 变成 >>>）。在这里，你敲一行，Python 立刻回一行，非常适合做实验。

# 在 >>> 提示符后面，一行一行输入下面的内容

>>> 1 + 1
2

>>> print("环境配置成功！")
环境配置成功！

>>> 2 * 3
6

>>> exit()

看到上面的结果，说明你的 Python 已经可以正常使用了。最后一行 exit() 用来退出交互模式。

小提示：交互模式是"即问即答"的草稿纸；第三课我们还会学到"把代码写进文件再运行"的正规做法。

三、练习#

  1. 完成安装：按本课步骤，在你自己的电脑上装好 Python 3.x（记得勾选 Add Python to PATH）。
  2. 验证版本：打开命令行，运行 python --version，把输出的版本号截图或记下来。
  3. 进入交互模式：输入 python 进入 >>> 模式，分别输入 7 - 3、10 / 2、"你好" + "世界"，观察结果。
  4. 退出：输入 exit() 退出交互模式，确认能正常回到普通命令行。
  5. 故障排查：如果 python --version 提示"不是内部或外部命令"，回想一下是不是漏勾了 PATH 选项，并尝试重新安装或搜索解决方案。
