全景：捕获 → 图 IR → 优化 → 调度 → 代码生成 → 运行时#

前两课讲清了"贵在哪"与"三层各管什么"。一段 Python 代码要变成能跑的目标代码，中间要经过六段流水线，每段回答一个问题，也各有失败方式。它最实用的价值是排障——"编译后没变快"时，你能判断是捕获不全、图 IR 表达力不够、优化太保守、调度没搜到好解、代码生成质量差，还是反复重编译。

一、概念讲解#

1. 六段流水线，一段一个问题#

阶段 输入 → 输出 关键决策 失败会怎样 后续
① 捕获 capture Python 程序 → 算子图 记哪些算子、在哪停下 图断裂，片段退回 eager 第 2 章
② 图 IR 算子图 → 中间表示 表达力与可优化性 信息丢失，后面无从下手 第 3 章
③ 优化 passes 图 IR → 更小的图 哪些变换是安全的 保守则收益小，冒进则算错 第 4 章
④ 调度 scheduling 算子/子图 → 循环结构 分块、循环序、向量化、并行 性能不达标 第 6 章
⑤ 代码生成 codegen 循环结构 → 目标代码 发射成什么（Triton/CUDA/LLVM） 质量差或编不出来 第 7 章
⑥ 运行时 runtime 目标代码 → 一次执行 内存池、缓存键、执行顺序 反复重编译、峰值爆 第 8 章

记法：②③ 在"算什么"上做减法，④⑤ 在"怎么算"上做选择，①⑥ 是两道闸门；闸门关不严（捕获漏、缓存不命中），中间做得再好也只剩部分收益。

2. 三条真实路线的逐段对照#

阶段 torch.compile / TorchInductor XLA TVM
① 捕获 TorchDynamo 在字节码层拦截记录并生成守卫（guards）；AOTAutograd 把前向反向一起捕获 JAX / TensorFlow 导出 HLO / StableHLO 各前端导入图级 IR（OSDI'18 论文里是 Relay）
② 图 IR FX/ATen 图 → Inductor IR HLO / StableHLO Relay（图级）+ TE/TIR（算子级）
③ 优化 图级 pass：融合、布局、内存 HLO pass（含 fusion） Relay pass
④ 调度 后端启发式自动决定 后端内建 显式 schedule + 自动调优（AutoTVM、Ansor）
⑤ 代码生成 GPU → Triton；CPU → C++/OpenMP 降到 LLVM 多后端（CUDA / LLVM / Metal）
⑥ 运行时 编译缓存、内存池、CUDA Graphs XLA runtime（PJRT 接口） TVM runtime

三条路线代表三种取向：TorchInductor 要"零改动接管既有框架代码"（力气全花在捕获与守卫）；XLA 要"一套 HLO 打遍所有后端"（图 IR 边界最严）；TVM 要"调度可搜索"（调度是一等公民，配代价模型与搜索器，第 6 章会展开 Ansor 的分层空间 + 演化搜索 + 代价模型）。MLIR 是正交的另一条路：多级 IR 做成可扩展框架，让高层张量方言与低层 LLVM 方言逐级下降。

3. 什么时候编译：JIT、AOT 与缓存#

  • JIT（即时编译）：第一次遇到这张图才编译，好处是能看到真实 shape/dtype/设备，代价是首次延迟（torch.compile 属于这类）。
  • AOT（提前编译）：编译在部署前完成，无编译期抖动，代价是形状通常要预先固定。
  • 编译缓存：键通常含"图结构 + 形状 + dtype + 设备 + 调度参数"，命中即跳过编译。

T总​=T编译​+N×T执行​,缓存命中时 T编译​→0

所以"编译贵不贵"的答案是"看编译几次"：只跑一次的脚本，编译是纯开销；跑一万次的推理服务，成本可忽略。动态形状会让形状进入缓存键，一变就重编译——这是第 2 章的主题。

4. 四个"可检查的窗口"#

看什么 对应阶段 典型手段（PyTorch 日志开关）
图在哪里断、为什么断 ① 捕获 TORCH_LOGS=graph_breaks
生成的代码长什么样 ⑤ 代码生成 TORCH_LOGS=output_code
pass 前后图变成什么样 ③ 优化 TORCH_LOGS=post_grad_graphs
有没有反复重编译、守卫为何失效 ⑥ 运行时 TORCH_LOGS=recompiles、guards

排障顺序：先看捕获是否完整，再看优化有没有生效，最后才怀疑代码生成质量。顺序反了，就会在"内核为什么慢"上白花时间。

5. 常见坑#

  • 图断裂吃掉收益：编译器只优化它看得见的部分，断成 5 段就是 5 个小编译器各自为战。
  • 缓存永不命中：动态 shape、变化的分支、每步都变的常量会让键一直变，编译时间吃掉收益。
  • 把"能编译"当"会更快"：算子链本就带宽受限时融合收益明显；单算子打满带宽时几乎无收益。
  • 只看首次运行：首次运行含编译开销，测性能必须先预热。

二、可运行代码示例#

最后把六段装成一个能跑的迷你编译器（标准库 + numpy，本机 python 3.10.16 + numpy 1.26.2 实跑）：① 用符号张量代理把算子调用记成 IR；② 打印带 shape 的节点表；③ 做常量折叠、CSE、死代码消除；④ 为 GEMM 搜 block tile、为逐元素子图搜 TILE；⑤ 生成源码并 exec 编译；⑥ 运行时带编译缓存与内存池，跑 4 次推理（前三次同形状、第四次变形）并与 eager 参考对拍。

# ===== 第 3 课示例：一个六段式迷你 ML 编译器 =====
# 捕获 → 图 IR → 优化 → 调度 → 代码生成 → 运行时（缓存 + 内存池 + 执行）
# 只用标准库 + numpy（本机 python3.10 + numpy 1.26.2 验证），不需要 GPU / 不需要 torch。
import math

import numpy as np

# ================= 阶段 1：捕获（capture）—— 只记录"做什么"，不立刻算 =================
class GraphIR:
    def __init__(self):
        self.ins, self.n = [], 0

    def emit(self, op, args, shape, kind, const=None):
        self.n += 1
        name = f'%{self.n}'
        self.ins.append({'name': name, 'op': op, 'args': list(args),
                         'shape': shape, 'kind': kind, 'const': const})
        return name


class Sym:
    """符号张量：算子重载只往 IR 追加一条记录，不做任何计算。"""
    def __init__(self, g, name, shape, kind):
        self.g, self.name, self.shape, self.kind = g, name, shape, kind

    def _bin(self, other, op):
        if isinstance(other, Sym):
            arg, shape = other.name, (other.shape or self.shape)
        else:                                        # Python 标量 → 捕获成 const 节点
            arg = self.g.emit('const', [], (), 'const', const=float(other))
            shape = self.shape
        return Sym(self.g, self.g.emit(op, [self.name, arg], shape, 'elementwise'), shape, 'elementwise')

    __add__ = lambda self, o: self._bin(o, 'add')
    __radd__ = lambda self, o: self._bin(o, 'add')
    __mul__ = lambda self, o: self._bin(o, 'mul')
    __rmul__ = lambda self, o: self._bin(o, 'mul')

    def relu(self):
        return Sym(self.g, self.g.emit('relu', [self.name], self.shape, 'elementwise'),
                   self.shape, 'elementwise')

    def matmul(self, other):
        shape = (self.shape[0], other.shape[1])
        return Sym(self.g, self.g.emit('matmul', [self.name, other.name], shape, 'gemm'),
                   shape, 'gemm')


def const_sym(g, v):
    return Sym(g, g.emit('const', [], (), 'const', const=float(v)), (), 'const')


def capture_model(B=32, K=64, N=48):
    g = GraphIR()

    def inp(shape):
        return Sym(g, g.emit('input', [], shape, 'input'), shape, 'input')

    x, w, bias, res = inp((B, K)), inp((K, N)), inp((B, N)), inp((B, N))
    alpha = const_sym(g, 1.5) * const_sym(g, 2.0)      # 常量×常量 → 折叠的原料
    h = x.matmul(w)
    y = (h + bias).relu() + res
    z1, z2 = y * alpha, y * alpha                       # 完全相同的两次计算 → CSE 的原料
    dead = y.relu()                                     # 结果没人用 → 死代码
    out = z1 + z2
    return g, {'x': x.name, 'w': w.name, 'bias': bias.name, 'res': res.name}, out.name, dead.name


def dump(g, ins=None):
    lines = []
    for i in (g.ins if ins is None else ins):
        if i['op'] == 'const':
            lines.append(f"  {i['name']} = const {i['const']}  : scalar")
        elif i['op'] == 'input':
            lines.append(f"  {i['name']} = input  : shape={i['shape']}")
        else:
            lines.append(f"  {i['name']} = {i['op']} {', '.join(i['args'])}  : shape={i['shape']}")
    return '\n'.join(lines)


g, feeds, OUT, DEAD = capture_model()
print('=== 阶段 1-2：捕获得到的图 IR ===')
print(dump(g))
print(f'  （输入映射 {feeds}；{DEAD} 是死代码）')

# ================= 阶段 3：图级优化 =================
BINOP = {'add': lambda a, b: a + b, 'mul': lambda a, b: a * b}


def opt_const_fold(ins):
    known, out, hits = {}, [], 0
    for i in ins:
        if i['op'] == 'const':
            known[i['name']] = i['const']
            out.append(i)
            continue
        if i['op'] in BINOP and all(a in known for a in i['args']):
            v = BINOP[i['op']](*[known[a] for a in i['args']])
            known[i['name']] = v
            out.append(dict(i, op='const', args=[], kind='const', const=v))
            hits += 1
            continue
        out.append(i)
    return out, hits


def opt_cse(ins):
    seen, alias, out, hits = {}, {}, [], 0
    for i in ins:
        args = tuple(alias.get(a, a) for a in i['args'])
        key = (i['op'], args)
        if i['kind'] == 'elementwise':
            if key in seen:
                alias[i['name']] = seen[key]
                hits += 1
                continue
            seen[key] = i['name']
        out.append(dict(i, args=list(args)))
    return out, alias, hits


def opt_dce(ins, outputs):
    alive, keep = set(outputs), set()
    for i in reversed(ins):
        if i['name'] in alive:
            keep.add(i['name'])
            alive.update(i['args'])
    return [i for i in ins if i['name'] in keep]


def resolve(n, alias):
    while n in alias:
        n = alias[n]
    return n


ins1, n_fold = opt_const_fold(g.ins)
ins2, alias, n_cse = opt_cse(ins1)
ins3 = opt_dce(ins2, [OUT])
print('\n=== 阶段 3：图级 pass 之后（常量折叠 → CSE → 死代码消除）===')
print(dump(g, ins3))
print(f'  节点 {len(g.ins)} → {len(ins3)}：折叠 {n_fold}、CSE {n_cse}、'
      f'死代码 {len(ins2) - len(ins3)}；输出别名链 {OUT} → {resolve(OUT, alias)}')
scalars = {i['name']: i['const'] for i in ins3 if i['op'] == 'const'}
print(f'  标量常量表（折叠结果）：{scalars}')

# ================= 阶段 4：调度（schedule）=================
def gemm_hbm(M, N, K, bm, bn, bk, itemsize=4):
    return (math.ceil(M / bm) * math.ceil(N / bn) * math.ceil(K / bk)
            * (bm * bk + bk * bn) * itemsize)


B, K, N = 32, 64, 48
print('\n=== 阶段 4a：GEMM 的 block tile 搜索（代价模型 = HBM 搬运量）===')
best = None
for t in ((16, 16, 16), (16, 24, 16), (32, 48, 16), (32, 48, 32), (32, 48, 64)):
    cost = gemm_hbm(B, N, K, *t)
    mark = ''
    if best is None or cost < best[1]:
        best, mark = (t, cost), '  ← 当前最优'
    print(f'  (bm,bn,bk)={str(t):<12} HBM {cost / 1024:>6.1f} KB{mark}')
tile = best[0]
print(f'  选定 tile = {tile}（代价模型只负责给候选排序，绝对值不可当真）')

print('\n=== 阶段 4b：逐元素子图的 TILE 搜索（示例代价模型，参数是假设值）===')
C_LOOP, ACTIVE_BUFS, BUDGET, C_SPILL = 2e-6, 6, 32 * 1024, 4e-9
ELEMS = B * N
print(f"{'TILE':>6} {'轮数':>5} {'循环开销(µs)':>12} {'工作集(KB)':>10} {'溢出罚项(µs)':>13} {'总代价(µs)':>11}")
best_tile, best_cost = None, None
for TILE in (16, 64, 128, 256, 512, 1024, 2048):
    rounds = math.ceil(ELEMS / TILE)
    loop = rounds * C_LOOP
    ws = TILE * ACTIVE_BUFS * 4
    pen = C_SPILL * max(0, ws - BUDGET)
    cost = loop + pen
    mark = ''
    if best_cost is None or cost < best_cost:
        best_tile, best_cost, mark = TILE, cost, '  ← 当前最优'
    print(f'{TILE:>6} {rounds:>5} {loop * 1e6:>12.2f} {ws / 1024:>10.1f} '
          f'{pen * 1e6:>13.2f} {cost * 1e6:>11.2f}{mark}')
print(f'  选定 TILE = {best_tile}：循环开销随 TILE 单调下降，但工作集超过片上预算后溢出代价反超')
print('  → 这就是"融合不是越大越好"的最小可打印版本（第 5 章会算这笔账）')

# ================= 阶段 5：代码生成（codegen）=================
def gen_gemm_source(bm, bn, bk):
    return f'''def kernel_gemm(A, B, out):
    M, K = A.shape
    N = B.shape[1]
    for i0 in range(0, M, {bm}):
        for j0 in range(0, N, {bn}):
            acc = out[i0:i0 + {bm}, j0:j0 + {bn}]
            acc[...] = 0.0
            for k0 in range(0, K, {bk}):
                acc += A[i0:i0 + {bm}, k0:k0 + {bk}] @ B[k0:k0 + {bk}, j0:j0 + {bn}]
    return out
'''


def gen_elementwise_source(nodes, out_name, bound, tile):
    """把逐元素子图生成成一段可 exec 的 Python 源码（块内一次遍历走完全链）。"""
    params = list(bound) + ['out']
    lines = [f'def kernel_fused({", ".join(params)}, TILE={tile}):',
             f'    n = src.shape[0]',
             '    for i0 in range(0, n, TILE):']
    tmpl = {node: f'{param}[i0:i0 + TILE]' for param, node in bound.items()}
    assigned = False
    for i in nodes:
        if i['op'] == 'const':
            tmpl[i['name']] = repr(i['const'])
            continue
        a = [tmpl[x] for x in i['args']]
        if i['op'] == 'add':                     # 每个子表达式都显式加括号：代码生成必须保证优先级
            expr = f'({a[0]} + {a[1]})'
        elif i['op'] == 'mul':
            expr = f'({a[0]} * {a[1]})'
        elif i['op'] == 'relu':
            expr = f'np.maximum({a[0]}, 0.0)'
        else:
            raise ValueError(f'逐元素子图里出现了无法生成的算子 {i["op"]}')
        if i['name'] == out_name:
            lines.append(f'        out[i0:i0 + TILE] = {expr}')
            assigned = True
        else:
            tmpl[i['name']] = expr
    if not assigned:
        lines.append(f'        out[i0:i0 + TILE] = {tmpl[out_name]}')
    return '\n'.join(lines) + '\n'


gemm_src = gen_gemm_source(*tile)
post = [i for i in ins3 if i['kind'] in ('elementwise', 'const')]   # 含子图用到的标量常量
EW_OUT = resolve(OUT, alias)
matmul_out = next(i['name'] for i in ins3 if i['op'] == 'matmul')
ew_src = gen_elementwise_source(post, EW_OUT,
                               {'src': matmul_out, 'bias': feeds['bias'], 'res': feeds['res']},
                               best_tile)
print('\n=== 阶段 5：生成的 kernel 源码 ===')
print('--- kernel_gemm（块级累加；块内仍走 BLAS 内积，真实编译器在这一层发射 MMA）---')
print(gemm_src)
print('--- kernel_fused（由逐元素子图自动生成）---')
print(ew_src)
print('--- 同一段子图若目标是 CUDA，会被发射成（示意，不执行）---')
print('''__global__ void fused_kernel(const float* src, const float* bias, const float* res,
                            float* out, int n, float alpha) {
  int i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i < n) out[i] = (fmaxf(src[i] + bias[i], 0.f) + res[i]) * alpha * 2.f;
}''')

ns = {'np': np}
exec(gemm_src, ns)
exec(ew_src, ns)
kernel_gemm, kernel_fused = ns['kernel_gemm'], ns['kernel_fused']

# ================= 阶段 6：运行时（编译缓存 + 内存池 + 执行）=================
class Runtime:
    def __init__(self):
        self.cache, self.compiles, self.hits = {}, 0, 0
        self.pool, self.pool_hits, self.pool_new = {}, 0, 0
        self.launches = 0

    def get(self, key):
        if key in self.cache:
            self.hits += 1
            return self.cache[key]
        self.compiles += 1
        self.cache[key] = (kernel_gemm, kernel_fused)
        return self.cache[key]

    def buffer(self, key, shape):
        if key in self.pool:
            self.pool_hits += 1
        else:
            self.pool[key] = np.zeros(shape, dtype=np.float32)
            self.pool_new += 1
        return self.pool[key]

    def __call__(self, x, w, bias, res):
        key = ('f32', x.shape, w.shape, tile, best_tile)   # 形状与 schedule 进键 → 变形即重编译
        kg, kf = self.get(key)
        mat_shape = (x.shape[0], w.shape[1])
        mat = self.buffer(('mat',) + mat_shape, mat_shape)
        out = self.buffer(('out',) + mat_shape, mat_shape)
        kf_input = mat
        kg(x, w, mat)
        self.launches += 1
        kf(kf_input, bias, res, out)
        self.launches += 1
        return out


def eager_reference(x, w, bias, res):
    alpha = 1.5 * 2.0                       # 与图里 %7 折叠出来的常量一致
    z = ((x @ w + bias).clip(min=0) + res) * alpha
    return z + z                            # out = z1 + z2


rng = np.random.default_rng(0)
rt = Runtime()
print('=== 阶段 6：跑起来（前三次同形状 → 1 次编译 + 2 次缓存命中；第四次变形 → 重编译）===')
for Bx in (32, 32, 32, 64):
    x = rng.standard_normal((Bx, K)).astype(np.float32)
    w = rng.standard_normal((K, N)).astype(np.float32)
    bias = rng.standard_normal((Bx, N)).astype(np.float32)
    res = rng.standard_normal((Bx, N)).astype(np.float32)
    got = rt(x, w, bias, res)
    ref = eager_reference(x, w, bias, res)
    d = float(np.abs(got - ref).max())
    rel = d / float(np.abs(ref).max())
    print(f'  B={Bx:>3}: vs eager 参考 最大绝对误差 {d:.2e}（相对 {rel:.1e}）'
          f' | 编译次数={rt.compiles} 命中={rt.hits}')

elem_ops = [i for i in g.ins if i['kind'] == 'elementwise']
eager_ew_bytes = sum(2 * B * N * 4 for _ in elem_ops)
print('\n=== 六段流水线的产出对照 ===')
print(f'  捕获：{len(g.ins)} 个 IR 节点（含 {sum(1 for i in g.ins if i["op"] == "const")} 个 const）')
print(f'  优化：{len(ins3)} 个节点（折叠 {n_fold}、CSE {n_cse}、死代码 {len(ins2) - len(ins3)}）')
print(f'  调度：GEMM tile={tile}，逐元素 TILE={best_tile}')
gen_lines = len([l for l in (gemm_src + ew_src).splitlines() if l.strip()])
print(f'  代码生成：{gen_lines} 行可执行的 Python kernel 源码 + 1 段 CUDA 示意')
print(f'  运行时：kernel 下发 {rt.launches} 次（4 次推理 × 2 个 kernel）；编译={rt.compiles}、'
      f'缓存命中={rt.hits}；内存池新建 {rt.pool_new} 块 / 复用 {rt.pool_hits} 次')
print(f'  算子边界：捕获到 {len(elem_ops)} 个逐元素节点（其中 1 个是常量×常量，编译期直接消掉），'
      f'eager 要逐次派发 + 1 次 GEMM；编译后 = 1 次 GEMM + 1 次融合 kernel')
print(f'  逐元素访存：eager 约 {eager_ew_bytes / 1024:.1f} KB（每步都读写中间结果）；'
      f'融合后 {2 * B * N * 4 / 1024:.1f} KB')
print('  形状从 32 变 64 → 缓存未命中又编译一次：这就是第 2 章 guard 与重编译的雏形')

--- kernel_gemm（块级累加；块内仍走 BLAS 内积，真实编译器在这一层发射 MMA）---
def kernel_gemm(A, B, out):
    M, K = A.shape
    N = B.shape[1]
    for i0 in range(0, M, 32):
        for j0 in range(0, N, 48):
            acc = out[i0:i0 + 32, j0:j0 + 48]
            acc[...] = 0.0
            for k0 in range(0, K, 16):
                acc += A[i0:i0 + 32, k0:k0 + 16] @ B[k0:k0 + 16, j0:j0 + 48]
    return out

--- kernel_fused（由逐元素子图自动生成）---
def kernel_fused(src, bias, res, out, TILE=1024):
    n = src.shape[0]
    for i0 in range(0, n, TILE):
        out[i0:i0 + TILE] = (((np.maximum((src[i0:i0 + TILE] + bias[i0:i0 + TILE]), 0.0) + res[i0:i0 + TILE]) * 3.0) + ((np.maximum((src[i0:i0 + TILE] + bias[i0:i0 + TILE]), 0.0) + res[i0:i0 + TILE]) * 3.0))

--- 同一段子图若目标是 CUDA，会被发射成（示意，不执行）---
__global__ void fused_kernel(const float* src, const float* bias, const float* res,
                            float* out, int n, float alpha) {
  int i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i < n) out[i] = (fmaxf(src[i] + bias[i], 0.f) + res[i]) * alpha * 2.f;
}
