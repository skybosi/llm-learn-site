现代架构#

从 ResNet 之后，CNN 的设计逐渐转向两个方向：更强的表示（多尺度、通道注意力）与更低的计算成本（分组卷积、深度可分离卷积），还衍生出"用算法自动搜索最优结构"的 NAS 和把 Transformer 搬进视觉的 ViT。这一课不求穷尽，而是抓住几条贯穿现代架构的主线，让你在遇到 MobileNet、EfficientNet、ResNeXt 这些名字时，能一眼看出它们的"基因"。

一、概念讲解#

1. 从"手工设计"到"可复用积木"#

现代骨干网络的共性，是把网络拆成一个个重复的 stage：每个 stage 内部是若干相同结构的块，块与块之间通过降采样缩小分辨率。VGG、ResNet 已经这么做了，现代架构不过是把块做得更聪明。读架构论文时，先找到"块长什么样、有几个 stage、通道怎么涨"，就能抓住主干。

2. 分组卷积：让每个核只负责一部分通道#

标准卷积里，每个输出通道都要与所有输入通道做运算。分组卷积（grouped convolution） 则把输入通道分成 g 组，每组独立做卷积：

参数量 = kernel_h × kernel_w × (in_channels/g) × out_channels

当 g = in_channels 时，每个输入通道只配一个卷积核，这就是深度可分离卷积的第一步——逐通道卷积（depthwise convolution）。PyTorch 里只需给 nn.Conv2d 传 groups=in_channels 即可。

3. 深度可分离卷积：MobileNet 的省参利器#

深度可分离卷积把标准卷积拆成两步：

  1. 逐通道卷积：每个输入通道单独卷积，只提"空间"上的特征；
  2. 逐点卷积（pointwise）：用 1×1 卷积混合通道信息。

以 3×3 卷积、输入输出都是 64 通道为例，标准卷积参数为 3×3×64×64 = 36864，深度可分离卷积只有 3×3×64 + 1×1×64×64 = 4672，省了约 87%。MobileNet 系列正是靠这一招把网络塞进手机。

4. Inception：并行多尺度#

Inception（GoogLeNet）块的核心思想是：不纠结用 3×3 还是 5×5，干脆都来一套。块里并行放着 1×1、3×3、5×5 卷积和池化，各自输出后沿通道拼接，让网络自己决定用哪个尺度。为避免直接上大卷积导致参数爆炸，Inception 会在前面用 1×1 卷积先降维——这也是"1×1 卷积做通道压缩"的经典用法。

5. 通道注意力与规模扩展#

  • SE 模块（Squeeze-and-Excitation）：先全局平均池化把每个通道压成一个数，再用两个全连接层学出每个通道的"重要程度"，最后乘回原特征图。相当于让网络学会"哪些通道值得多看一眼"，SENet 因此拿下 2017 年 ImageNet 冠军。
  • EfficientNet：提出"深度、宽度、分辨率"三个维度按比例一起扩（复合缩放），用搜索找到一个平衡点，在更少参数下达到更高精度。

6. 两条新路线：NAS 与 Vision Transformer#

  • NAS（神经架构搜索）：让算法在搜索空间里自动找结构，代表作如 NASNet、EfficientNet（结合缩放）；
  • Vision Transformer（ViT）：把图片切成若干 patch 当"词"，交给 Transformer 处理，2020 年后在视觉领域快速崛起，标志着 CNN 之外的又一条技术路线。

二、可运行代码示例#

下面用 PyTorch 实现一个深度可分离卷积块，并与标准卷积对比参数量，直观感受"省参"的效果。

import torch
import torch.nn as nn

class DepthwiseSeparableConv(nn.Module):
    """深度可分离卷积：逐通道卷积 + 1x1 逐点卷积。"""
    def __init__(self, in_c, out_c, kernel_size=3):
        super().__init__()
        # 第一步：逐通道卷积，groups=in_c 表示每个输入通道单独卷积
        self.depthwise = nn.Conv2d(in_c, in_c, kernel_size,
                                   padding=kernel_size // 2, groups=in_c)
        # 第二步：逐点卷积，用 1x1 混合通道信息
        self.pointwise = nn.Conv2d(in_c, out_c, kernel_size=1)

    def forward(self, x):
        return self.pointwise(self.depthwise(x))

in_c, out_c = 64, 64
x = torch.randn(1, in_c, 32, 32)

# 标准 3x3 卷积
std = nn.Conv2d(in_c, out_c, kernel_size=3, padding=1)
# 深度可分离卷积
ds = DepthwiseSeparableConv(in_c, out_c, kernel_size=3)

def num_params(m):
    return sum(p.numel() for p in m.parameters())

print("标准卷积参数量:", num_params(std))     # 3*3*64*64 + 64
print("深度可分离参数量:", num_params(ds))   # (3*3*64 + 64) + (1*1*64*64 + 64)
print("参数比:", round(num_params(ds) / num_params(std), 3))

# 验证输出形状一致
print("标准卷积输出:", tuple(std(x).shape))  # [1, 64, 32, 32]
print("深度可分离输出:", tuple(ds(x).shape)) # [1, 64, 32, 32]

运行后会看到，两者输出形状完全相同，但深度可分离卷积的参数量约为标准卷积的八分之一。这正是 MobileNet 能在手机上实时运行的关键。

再看一个 SE 通道注意力模块的极简实现：

class SEBlock(nn.Module):
    """Squeeze-and-Excitation：给每个通道学一个 0~1 的权重。"""
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.gap = nn.AdaptiveAvgPool2d(1)              # 压缩：HxW -> 1x1
        self.fc = nn.Sequential(
            nn.Linear(channels, channels // reduction), # 降维
            nn.ReLU(inplace=True),
            nn.Linear(channels // reduction, channels), # 升维
            nn.Sigmoid(),                               # 权重压到 0~1
        )

    def forward(self, x):
        b, c, _, _ = x.shape
        scale = self.fc(self.gap(x).view(b, c))        # (B, C)
        return x * scale.view(b, c, 1, 1)              # 逐通道加权

x = torch.randn(2, 64, 16, 16)
print("SE 输出形状:", tuple(SEBlock(64)(x).shape))     # [2, 64, 16, 16]

SE 模块不改变特征图形状，只重新分配各通道的权重，可以像积木一样插进任何卷积块。

三、练习#

  1. 把 DepthwiseSeparableConv 的 groups 参数去掉（或改成 1），观察参数量变化，说明分组卷积为什么能省参数。
  2. 手算 3×3 深度可分离卷积（in=out=64）的参数量，与代码打印值对比，写出逐通道 + 逐点两步的公式。
  3. 在 SEBlock 里把 reduction 改成 4 和 32，统计模块参数量如何变化，谈谈 reduction 的权衡。
  4. 思考：分组卷积中 groups=in_channels 和 groups=2 分别对应什么？为什么逐通道卷积之后必须接 1×1 卷积？
