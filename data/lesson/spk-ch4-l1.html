说话人识别与验证：从 i-vector 到 ECAPA，以及开集验证的判据#

这一节要解决什么#

前三章处理的都是内容：第 2 章把一段音频变成它说了什么，第 3 章把一段文本变成它该怎么被说出来。这一节换一个变量：这段音频是谁说的。

这不是同一类问题的换皮。语音识别的输出是离散符号序列，判据是编辑距离；说话人验证的输出是一个判决（同一人 / 不同人），判据是一个在连续分数上取阈值的二分类决策。两者的差别带来三个新的结构性问题：

  1. 说话人是开集（open-set）的。 识别系统的输出类别在训练时就固定了；说话人系统必须在测试时面对训练中从未出现过的人。所以它不能是一个 softmax 分类器——分类器无法给一个"新类别"打分。它必须输出一个可比较的表示，然后用一个与身份无关的判据（余弦距离、PLDA 似然比）去比较两条音频。
  2. 注册集与测试集是失配的。 同一个人在不同信道（手机 / 座机 / 远场）、不同语言、不同健康状况下的声音分布不同。这是"域偏移"，而它的后果不是"精度下降一点"，而是一个在开发集上标定好的阈值直接失效。
  3. 判据本身有陷阱。 行业最常报的 EER 是一个与部署无关的量，而 minDCF 是一个依赖先验与代价的量。二者可以给出相反的系统排序——这不是理论上的可能性，本节会用完全确定的算术把它做出来。

本节的判据是：任何"我们的说话人验证更好"的说法，都必须同时给出先验、代价、以及工作点。为此本节把四种读数全部算出来：

  1. EER 是 DET 曲线与反对角线的交点，minDCF 是同一条曲线上某个先验加权点的最小值。 同一个打分器（d′=2.5、同方差、Cfa​=Cmiss​=1）：Ptar​=0.5 时 EER =0.1060、minDCF =0.1055；Ptar​=0.01 时 EER 仍是 0.0973，minDCF 掉到 0.0080（表 A）。EER 与先验无关，minDCF 与先验强相关。
  2. 连续情形的贝叶斯锚点。 d′=2.5 时 EER =Φ(−d′/2)=0.1056；Ptar​=0.01 时最优阈值 t∗=3.0880，此时 FA=0.001007、miss=0.7217、miss/FA=716.5=π0​/π1​、minDCF =0.0082。最优点上 72% 的目标试次被拒——在代价函数里这是最优的，因为一个 FA 的代价是 miss 的 99 倍。
  3. 按 EER 取阈值要多付两个数量级。 在 Ptar​=0.01 的部署下，用 EER 工作点当阈值，DCF =0.9900，是最优值 0.0083 的 118.63 倍（表 E）。"我们的 EER 是 10%"这句话完全不告诉你该把阈值放在哪。
  4. 两个系统可以给出相反的排序。 系统 A（同方差）EER =0.1276、minDCF =0.0087；系统 B（三峰混合）EER =0.1603、minDCF =0.0091。按 EER 排序 A 更好，按 minDCF 排序 B 更好（表 B）。而且在 Ptar​=0.01 下换预算：FA≤0.10% 时 B 更省（0.0034 vs 0.0089），FA≤10% 时 A 更省（0.1006 vs 0.1016）。两条 DET 曲线交叉，所以"哪个系统更好"没有唯一答案。
  5. 域偏移的两种形态要分开算。 分数分布不动、只有先验变：固定阈值在 Ptar​=0.5 时 DCF 是最优值的 3.51 倍；把阈值按 ln(π0​/π1​) 平移后倍率降到 1.003。先验不动、冒充者分数整体抬升 +2.0：FA 从 0.0008 涨到 0.1420，DCF 从 0.0080 涨到 0.1478（18.5 倍），而 EER 只从 0.1066 涨到 0.4025。分布偏移是阈值问题，先验偏移是标定问题，两者的修法不同。
  6. 阈值本身也有估计方差。 开发集只有 5 个说话人时，std(tdev​)=0.630；500 个说话人时降到 0.324。但在本例里，用真值阈值的代价（0.0103∼0.0105）始终不低于在同一个池上估计出的 minDCF（0.0043∼0.0085）——这是过拟合开发集的表现：估计阈值在同一个集合上看到的数据比真值阈值多。

 EER 回答「两个分数分布交叉在哪」，minDCF 回答「在这个先验和代价下最省的做法要付多少」；后者才对应部署 ​

⚠️ 本节代码中的分数、试次与说话人全部是合成的，只用标准库。它们的作用是把"判据口径"变成可核对的算术，不是对任何真实系统成绩的断言。所有涉及具体模型结构的描述（TDNN、统计池化、SE-Res2Block）都标注为机制而非实测数字。

一、从 GMM-UBM 到 i-vector：为什么需要"因子分析"#

1.1 这一代要解决的问题#

最早的说话人识别系统把语音的声学特征（第 1 章的 MFCC + 差分）当成一个高维分布，为每个说话人训练一个 GMM，然后用对数似然比做判决。问题立刻出现：每个说话人只有几分钟的注册语音，而一个 39 维、512 个高斯的 GMM 有 512×(39+39×40/2+1)≈4.2×105 个参数（均值 39、协方差上三角 780、权重 1）。数据量比参数量小两三个数量级。

解决办法是把"说话人"和"内容/信道"在参数空间里拆开。UBM（universal background model）先在所有说话人的混合数据上训练一个"通用"GMM；每个说话人只允许在这个通用模型上做均值偏移。于是一个说话人被表示为一堆高斯均值拼起来的超向量（supervector）：

M=m+ΔM,ΔM∈RCF

其中 C 是高斯个数、F 是特征维数。C=512、F=60（39 维 MFCC + 一阶二阶差分）时，超向量维度是 CF=30720。

这已经比"每人一个 GMM"小得多，但仍然有两个问题：维度太高（3 万维，注册数据只有几百帧）；信道信息也混在 ΔM 里——同一个人换一个麦克风，超向量就变了。

1.2 i-vector：把超向量投到一个低维隐空间#

总变化（total variability）模型把 ΔM 写成

M=m+Tw,w∼N(0,I)

T 是 CF×R 的总变化矩阵（R 通常取几百，本节算例取 R=400），w 就是 i-vector。它把"声道"和"信道"混在同一个低维空间里——名字里的"total"就是这个意思。

给定一段语音的 Baum-Welch 统计量（每个高斯的零阶 Nc​ 与一阶 Fc​），i-vector 的后验均值有闭式解。把它写成矩阵形式：设 N 是把 Nc​IF​ 按高斯块对角拼起来的 CF×CF 矩阵，F~ 是把 Fc​−Nc​mc​ 拼起来的 CF 向量，则

w=(I+T⊤Σ−1NT)−1T⊤Σ−1F~

这个式子值得逐项读：

  • T⊤Σ−1F~ 是"把超向量空间的证据投到隐空间"，是一个 R 维向量；
  • I+T⊤Σ−1NT 是后验精度矩阵，N 越大（这段语音在某高斯上占的帧越多），先验 I 就越被数据压过去；
  • 于是短语音的 i-vector 被先验收缩到原点附近，方差更大。这不是缺陷，是贝叶斯后验的正确行为——但它直接导致"注册语音越短，打分越不可靠"，这是后面 3.4 节阈值方差的来源之一。

维度账：30720→400，压缩比 76.8 倍。而 400 维的 i-vector 里，真正的说话人信息只占一部分，其余是信道。所以 i-vector 之后必接两步线性变换：

  1. 类内协方差归一化（WCCN）：用同说话人内部的协方差白化，压掉信道方向；
  2. 线性判别分析（LDA）：按说话人标签做类间/类内散度比最大化，把维度再降到 150～200。

然后才是打分。早期用余弦距离，后来用 PLDA（probabilistic LDA）——它把 i-vector 分解成"说话人因子 + 信道因子 + 残差"，给出一个似然比：

LR=p(w1​,w2​∣不同人)p(w1​,w2​∣同人)​

PLDA 的价值不只是精度，而是它输出的是似然比，因此可以与先验相乘：

后验对数几率=lnLR+lnπ0​π1​​

这条式子是 2.4 节"按先验平移阈值"的全部依据。如果打分器输出的不是似然比（比如余弦距离），那么先验变化时就必须重新标定，而不能简单地平移。

1.3 i-vector 的三个结构性缺点#

缺点 机制 后果
统计量由 UBM 决定 N,F 由 GMM 的帧级责任度算出来；UBM 的帧级独立假设与"哪一帧属于哪个说话人"无关 判别信息在池化前就被压成一组充分统计量，无法端到端优化
线性假设 M=m+Tw 假设说话人变化是线性子空间 语音里的非线性变化（不同语速、不同音高）需要更多维数才能覆盖
与后端解耦 T、WCCN、LDA、PLDA 分四步独立训练，各自的准则不同 每一步最优不等于整体最优；误差无法反向传播

这三条决定了下一代：把"帧 → 定长嵌入"整条路径换成神经网络，用验证损失直接训练。这就是 x-vector。

二、x-vector 与统计池化#

2.1 结构：TDNN + 统计池化#

x-vector 的核心改动只有一处，但它改变了整个体系：不再用 GMM 的充分统计量，而是用网络的统计池化。

设编码器输出的帧级表示是 h1​,…,hT​（T 帧）。统计池化把整个序列压成定长向量：

μ=T1​t=1∑T​ht​,σ=T1​t=1∑T​(ht​−μ)2​,e=[μ;σ]

为什么是"均值 + 标准差"而不是"均值"？ 均值只保留一阶信息。两个说话人说同一句话，如果一个人音高抖动大、另一个人平稳，他们的帧级表示均值可能相同，但方差不同。加进标准差就把二阶信息也保留下来，而且这一步不引入任何参数——它没有可训练权重，因此不会过拟合短语音。

为什么用 TDNN 而不是 RNN？ TDNN（时延神经网络）在每一层对"当前帧 + 前后若干帧的拼接"做线性变换。L 层、每层上下各取 k 帧时，第 L 层的感受野是 2kL+1 帧。它没有循环，因此训练可以完全并行，而且对每句话的帧数不敏感。缺点同样明显：感受野是固定的，长时依赖只能靠堆层数换取。

统计池化带来一个必须验证的性质：把同一段语音的帧顺序打乱，池化输出不变（置换不变）。这是优点（对内容顺序不敏感）也是缺点（丢掉时序结构，无法区分"先说 A 后说 B"）。

2.2 从统计池化到注意力池化#

统计池化对所有帧等权。但一段语音里有静音、有噪声段、有重叠语音——这些帧对说话人身份几乎没有信息。于是自然的一步是给每帧一个权重：

at​=∑s​exp(v⊤f(hs​))exp(v⊤f(ht​))​,μ~​=t∑​at​ht​

这就是注意力统计池化（attentive stat pooling）。要小心的是：只有加权均值还不够，加权标准差如果直接用 μ~​ 算，会低估方差（因为权重集中在少数帧上）。所以实现里必须加一个修正项（常见写法是在方差项上乘 T−1T​ 或加一个可学习的小偏置），否则短语音上的嵌入会系统性地"过于自信"。

2.3 ECAPA-TDNN：三处改动#

ECAPA-TDNN 在 x-vector 的骨架上做了三处结构性改动，每一处都对应一个明确的问题：

改动 解决的问题 机制
一维压缩激励（SE） 各通道的重要性不同，但卷积对所有通道一视同仁 对通道维度做全局平均得到描述子，再经两层小 MLP 产生 [0,1] 的通道权重，逐通道缩放
多尺度残差块（Res2Block） 单一卷积核尺寸只能看到一个时间尺度 把输入按通道切成几组，用不同膨胀率的卷积并行处理，再拼接融合
多层特征聚合 只用最后一层会丢掉浅层（更接近频谱）的信息 把每个残差块的输出拼接后再送入池化层

取舍/边界：

  • SE 与多尺度拼接都增加参数量与显存。它们换来的是在短语音（< 3 秒）上的稳定性，而短语音正是实际部署中最常见的情形。
  • 统计池化与注意力池化都丢掉了帧序。因此它们无法区分"两个说话人交替说话"的语音——那需要第 2 节的分离，或者带时序的池化。
  • 所有这类嵌入的维度是超参数，而不是学出来的。维度取小了信息不够，取大了在小注册集上过拟合；而"多大合适"必须用开集协议（而不是闭集分类准确率）来选。

2.4 打分层：从余弦到 PLDA#

嵌入 e 出来后，判据通常是：

  • 余弦相似度 cos(e1​,e2​)：需要嵌入已经做过长度归一化与中心化；
  • PLDA：把 e 分解为 μ+Fy+ϵ（y 是说话人因子），给出似然比；
  • 后端归一化：AS-Norm（adaptive score normalization）用一组"冒名者队列"（cohort）估计每条测试分数的均值与标准差，把分数归一化为 (score−μcohort​)/σcohort​。

为什么需要后端归一化？ 因为不同测试语音的"难度"不同。一个短、噪声大的测试语音，与任何人的分数都偏低；一个长的干净语音与任何人的分数都偏高。如果不做归一化，同一个阈值对前者的 miss 高、对后者的 FA 高。AS-Norm 用 cohort 给每条测试单独标定零点。

这一句话的代价必须说清：AS-Norm 需要额外的 cohort 数据，且 cohort 必须与部署域相近。cohort 选错，归一化反而放大域偏移。

三、开集验证的判据：EER、minDCF，以及为什么 EER 不够#

3.1 形式化#

开集验证的输入是试次（trial）：一对语音 (enroll,test)，标签 y∈{target,nontarget}。系统输出一个分数 s，判决规则是 s≥θ 判同一人。

两个错误率：

FA(θ)=Pr(s≥θ∣nontarget),miss(θ)=Pr(s<θ∣target)

试次级的统计口径：目标是 R 个目标试次（同人、不同语音），背景是 I 个背景试次（不同人）。R 与 I 的比例不代表部署先验——它只决定 EER 等指标的估计方差。这一点是很多论文报错的地方：用 1:1 的评测集算 EER 是标准做法，但不能用这个比例去算 DCF；DCF 的先验必须单独声明。

3.2 EER 的定义与统计口径#

EER 是满足 FA(θ)=miss(θ) 的那个错误率。经验计算必须说清三件事：

  1. 阈值取值集合：全部试次分数排序后的每个切点（不是等距网格）；
  2. 等值分数的处理：分数相同的试次必须一起跨过阈值，不能拆开；
  3. 插值方式：在 DET 图（FA、miss 各取正弦刻度）的折线上线性插值，而不是在 (FA, miss) 平面上插。

第 3 条经常被忽略，但影响不小：在 (FA, miss) 平面上直接线性插值，得到的 EER 与在 DET 图上插值可以差好几个百分点——因为两个刻度都被拉伸过。

3.3 minDCF 的定义#

Cfa​=1,Cmiss​=1 时（常见约定）:DCF(θ)=Cfa​(1−π1​)FA(θ)+Cmiss​π1​miss(θ)

minDCF=θmin​DCF(θ),minDCFn​=min{Cfa​(1−π1​),Cmiss​π1​}minDCF​

规范化分母 min{Cfa​(1−π1​),Cmiss​π1​} 是平凡系统的代价——"全部判为目标"或"全部判为背景"里更便宜的那个。所以 minDCFn​=1 表示"与不做判别一样好"。

连续情形的解很干净。假设两类分数同方差、均值差 d′（本节代码里均值为 +d′ 与 0、标准差 1），则对数似然比

λ(s)=(s−μn​)2−(s−μt​)2=2d′s−d′2

在目标下服从 N(d′2,4d′2)、背景下服从 N(−d′2,4d′2)。最优阈值由 λ(t∗)=lnπ1​Cmiss​π0​Cfa​​ 解出：

t∗=2d′​+d′1​lnπ1​Cmiss​π0​Cfa​​(等方差、单位标准差、μn​=0, μt​=d′)

t∗=2d′​+d′1​lnπ1​Cmiss​π0​Cfa​​(等方差、单位标准差、μn​=0, μt​=d′)

对 d′=2.5、π1​=0.01、Cfa​=Cmiss​=1：t∗=1.25+ln99/2.5=1.25+1.8380=3.0880。此时

FA=Φ(−t∗)=0.001007,miss=Φ(t∗−d′)=0.7217

FA=Φ(−t∗)=0.001007,miss=Φ(t∗−d′)=0.7217

miss/FA=0.7217/0.001007=716.5(=99)

这个 716.5 不等于 π0​/π1​=99，是一个必须说清的口径问题。"最优点的 miss/FA 等于先验比"这句话只在似然比刻度上成立：在似然比刻度上，最优阈值满足 p(λ∣tar)/p(λ∣non)=π0​/π1​；而代码里的分数 s 不是似然比，λ(s)=2.5(2s−2.5) 才是（差一个仿射变换）。所以 716.5 是分数刻度上两个错误率的比，它与 99 的差别正好来自这个仿射变换。报告时必须说清报的是哪个刻度上的量——这也是"用余弦相似度当分数、却想直接套用似然比理论"会出错的地方。

3.4 为什么 EER 不够#

EER 有两个结构性缺陷：

缺陷一：EER 与部署先验无关，而部署代价与先验强相关。

代码表 A 用同一个打分器（d′=2.5、目标均值 +2.5、背景均值 0）：

试次配比 Ptar​ EER minDCF minDCFn​ DCF@EER阈值
等量 1000:1000 0.50 0.1060 0.1055 0.2110 0.5000
等量 4000:4000 0.50 0.1074 0.1064 0.2127 0.5000
部署 2000:198000 0.01 0.0973 0.0080 0.8040 0.9900
部署 40000:3960000 0.01 0.1057 0.0082 0.8230 0.9900

读法：EER 在四行里都落在 0.097∼0.107，而 minDCF 从 0.1055 跳到 0.0080（13.2 倍）。差别全部来自先验，与系统本身无关。

表 E 把这一点量化得更狠：在同一个池上，用 EER 工作点的阈值算 DCF：

先验 DCF@EER阈值 DCF最优 倍数
Ptar​=0.01 0.9900 0.0083 118.63
Ptar​=0.10 0.9000 0.0500 18.01
Ptar​=0.50 0.5000 0.1107 4.52

Ptar​=0.01 时，"把阈值放在 EER 点"要付 118.63 倍的代价。EER 是一个方便的汇总数，但它不携带"阈值该放哪"的任何信息。

缺陷二：EER 是曲线上一个点，而两条 DET 曲线可以交叉。

3.5 常用试次规模下的置信区间#

EER 与 minDCF 都是估计量。在 N 个试次上，EER 的标准误量级是 EER(1−EER)/Neff​​，其中 Neff​ 受试次间相关（同一说话人的多个试次、同一模型对）影响，通常远小于名义试次数。报 EER 不报试次数与置信区间，等于报一个没有刻度的数。

import math

from statistics import NormalDist

ND = NormalDist()


def cdf(x):
    return ND.cdf(x)


# ---------- 打分：一维正态对数似然比 ----------
def lr(target_scores, nontarget_scores, sigma=1.0):
    mu_t = sum(target_scores) / len(target_scores)
    mu_n = sum(nontarget_scores) / len(nontarget_scores)
    out, labels = [], []
    for s in target_scores:
        out.append(((s - mu_n) ** 2 - (s - mu_t) ** 2) / (2.0 * sigma * sigma))
        labels.append(True)
    for s in nontarget_scores:
        out.append(((s - mu_n) ** 2 - (s - mu_t) ** 2) / (2.0 * sigma * sigma))
        labels.append(False)
    return out, labels


# ---------- 一次排序一次扫描：全部阈值的 (thr, FA, miss, DCF) ----------
def sweep(tar, non, cfa=1.0, cmiss=1.0, p_tar=0.01):
    n_tar, n_non = len(tar), len(non)
    tagged = sorted([(s, True) for s in tar] + [(s, False) for s in non],
                    key=lambda p: -p[0])
    fa, miss = 0, n_tar
    out = [(tagged[0][0] + 1.0, 0.0, 1.0, cmiss * p_tar)]
    i, n = 0, len(tagged)
    while i < n:
        s = tagged[i][0]
        while i < n and tagged[i][0] == s:
            if tagged[i][1]:
                miss -= 1
            else:
                fa += 1
            i += 1
        out.append((s, fa / n_non, miss / n_tar,
                    cfa * (1.0 - p_tar) * (fa / n_non)
                    + cmiss * p_tar * (miss / n_tar)))
    return out


def dcf_at(tar, non, thr, cfa=1.0, cmiss=1.0, p_tar=0.01):
    miss = sum(1 for s in tar if s < thr) / len(tar)
    fa = sum(1 for s in non if s >= thr) / len(non)
    return cfa * (1.0 - p_tar) * fa + cmiss * p_tar * miss


def min_dcf(tar, non, cfa=1.0, cmiss=1.0, p_tar=0.01):
    best, best_thr, best_fa, best_miss = None, None, 0.0, 0.0
    for thr, fa, miss, c in sweep(tar, non, cfa, cmiss, p_tar):
        if best is None or c < best:
            best, best_thr, best_fa, best_miss = c, thr, fa, miss
    return best, best_thr, best_fa, best_miss


def norm_factor(cfa=1.0, cmiss=1.0, p_tar=0.01):
    return min(cfa * (1.0 - p_tar), cmiss * p_tar)


def roc(tar, non):
    pts = [(fa, miss) for _t, fa, miss, _c in sweep(tar, non)]
    pts.sort(key=lambda p: (p[0], -p[1]))
    out = [(0.0, 1.0)]
    for fa, miss in pts:
        if out and miss >= out[-1][1]:
            continue
        out.append((fa, miss))
    if out[-1] != (1.0, 0.0):
        out.append((1.0, 0.0))
    return out


def eer(tar, non):
    """DET 折线上等错误率点：正弦刻度下线性插值。"""
    pts = roc(tar, non)
    f = lambda p: math.sin(math.radians(p[0] * 90.0)) - math.sin(
        math.radians(p[1] * 90.0))
    lo = None
    for i in range(len(pts) - 1):
        a, b = pts[i], pts[i + 1]
        fa_, fb = f(a), f(b)
        if fa_ == 0.0:
            lo = a
            break
        if fb == 0.0:
            lo = b
            break
        if (fa_ < 0.0) != (fb < 0.0):
            lam = fa_ / (fa_ - fb)
            lo = (a[0] + lam * (b[0] - a[0]), a[1] + lam * (b[1] - a[1]))
            break
    if lo is None:
        lo = pts[-1]
    return (lo[0] + lo[1]) / 2.0, lo


def thr_at_eer(tar, non):
    e, lo = eer(tar, non)
    t = None
    for thr, fa, miss, _c in sweep(tar, non):
        if fa >= lo[0] and miss <= lo[1]:
            t = thr
    return e, t


def miss_at_fa(tar, non, fa_budget):
    return min((m for fa, m in roc(tar, non) if fa <= fa_budget), default=1.0)


def fa_at_miss(tar, non, miss_budget):
    return min((fa for fa, m in roc(tar, non) if m <= miss_budget), default=1.0)


def gen(delta, n_tar, n_non, seed):

    return ([rng.gauss(delta, 1.0) for _ in range(n_tar)],
            [rng.gauss(0.0, 1.0) for _ in range(n_non)])

小结#

  • 说话人验证是开集问题，所以它的核心不是分类器而是可比较的嵌入 + 一个标定过的判据。i-vector 的总变化空间、x-vector 的统计池化、ECAPA 的多尺度通道注意力，都是"如何得到一个好的嵌入"这条线上的三代答案；而 PLDA 与 AS-Norm 决定"如何把这个嵌入变成一个可跨先验使用的分数"。
  • EER 与 minDCF 回答不同的问题。EER 是 DET 曲线与反对角线的交点，与先验无关；minDCF 是同一条曲线在一个先验加权下的最小值。本节的两个合成系统 EER 排序与 minDCF 排序相反，且在任何预先指定的 FA 预算下都是 EER 更差的那个更省。
  • minDCF 的最优点常常在一个"miss 很高"的位置。Ptar​=0.01、C 相等时，最优点 miss =0.72。如果只报 minDCF 不报工作点，读者无法判断这个系统在可用区间内的表现。
  • 域偏移要拆成先验偏移与分布偏移。前者可以用 ln(π0​/π1​) 的加法修掉（前提是打分器输出似然比）；后者的代价在本节算例里 98.4% 来自阈值没有跟着移动，而不是判别力真的下降了。
  • 阈值本身是一个估计量。开发集说话人数少时它的方差很大，而且在同一集合上选阈值再报 minDCF 会带来乐观偏差。
  • 报告规范：任何说话人验证的读数都必须带上——试次数与说话人数、先验与代价、阈值选取集合、以及 minDCF 取到的工作点。少任何一项，"我们的 EER 更低"都不构成一个可比较的结论。
