编译器要解决什么：图级/算子级/内存级#

"知道贵在哪"离"知道怎么改"还差一步。一个常见误解是：ML 编译器就是"把算子换成更快的 kernel"。它实际干的是三件不同层次的事——图级决定要不要执行这个算子，算子级决定这一个算子怎么算，内存级决定张量放在哪、何时能复用。三层的收益与失败方式都不同，还会互相拆台。本课给三层各写一个最小 pass，作用在同一份 IR 上，并用"优化前后结果逐元素相同"守住正确性。

一、概念讲解#

1. 三层职责的一句话分工#

层次 做的决策 收益来源 典型变换 失败方式
图级 graph-level 执行哪些算子、什么顺序 省掉整段执行 常量折叠、CSE、DCE、算子消除 信息不足，收益打折
算子级 operator-level 循环怎么组织（调度） 数据复用与并行度 分块、循环序、展开、向量化、并行、流水 越出依赖/边界就算错
内存级 memory-level 放哪块存储、能否复用 降低峰值 复用与内存池、原地、重算 别名分析不成立不能原地写

三者看到的信息不同：图级只有算子与依赖，算子级才有循环与索引，内存级要知道每个值"用到什么时候"——这正是第 3 章要展开的张量 IR 要素（shape / dtype / layout / 依赖）。

2. 图级：先干掉"根本不该算的"#

图级 pass 做的是减法，收益按"整段执行"计：常量折叠（constant folding）把全常量表达式在编译期算完——推理时权重与超参已知，机会很多；CSE 让同一右值只算一次（本课 IR 里 %12 与 %13 完全相同）；死代码消除（DCE）从输出逆向标记可达节点，其余全删；此外还有代数化简（x*1、x+0）与算子消除（推理期 dropout 退化为恒等）。图级为什么优先？它省掉整段执行，量级上一般大于算子级调优，还能缩小后两层的搜索空间。

3. 算子级：同一份"算法"，很多种"调度"#

算法-调度分离（algorithm–schedule separation）是 Halide 与 TVM 的核心思想：算法只声明"算什么"，调度声明"怎么算"。同一个矩阵乘可以有完全不同的搬运量：

HBM 元素数=bm​M​⋅bn​N​⋅bk​K​(bm​bk​+bk​bn​)

本课代码把三组 (bm​,bn​,bk​) 的搬运量与算术强度对照着算出来。算子级的动作与 CUDA 课一一对应（tile/unroll/vectorize/parallel/pipeline 就是分块、展开、向量化访存、grid 映射、双缓冲），区别在于那些选择由你手写，ML 编译器要把它们变成搜索问题（第 6 章）。约束是硬的：依赖方向不能反、边界要单独处理、浮点加法不满足结合律（第 4 章）。

4. 内存级：峰值是可以"规划"出来的#

给每个中间值定义生命周期（liveness interval：从被定义到最后一次被读），则

峰值占用=tmax​v 在 t 活跃∑​size(v)

活跃区间不重叠的两个值可以共用同一片存储。三个手段：按生命周期复用（首次适配 first-fit，真实内存池还会合并相邻空闲块）、原地计算（in-place，需证明读输入时它还没被写坏）、重算（rematerialization，用算力换显存，反向传播常用）。它与融合强耦合：融合减少中间张量个数通常降峰值，却可能拉长某个输入的活跃区间而推高峰值——第 5 章要处理的正是这笔联合决策。

5. 三层会互相拆台#

把 A → B → C 全融合成一次遍历：边界与搬运都省了，但每个元素要同时持有多个中间值（算子级受限：寄存器压力）；若把 A 的计算推到最靠近使用点，A 的寿命被拉长，内存峰值反而升高。所以真实编译器是先做便宜且决定性的图级变换，再在算子级调度与内存级规划之间联合决策，每步都重新验证。

6. 常见坑#

  • 先抠算子级微优化，图上却还剩冗余算子：顺序反了，天花板很低。
  • 把"等价变换"当无条件安全：浮点非结合、除法陷阱值、随机算子、副作用算子都会让"等价"失效。
  • 忽略布局与别名：同 shape 不同格式性能可差几倍（布局变换自己也要搬运）；没做别名分析就 in-place 会读到已覆盖的数据。

二、可运行代码示例#

下面只用标准库 + numpy（本机 python 3.10.16 + numpy 1.26.2 实跑）。同一份 SSA 文本 IR 上依次跑三层变换：图级常量折叠 → CSE → 死代码消除；算子级给逐元素链两种调度的账与 GEMM 三种 tile 的搬运量；内存级做生命周期分析与首次适配复用，最后在同一份随机输入上对拍。

# ===== 第 2 课示例：三层职责各写一个 pass，作用在同一份文本 IR 上 =====
# 只用标准库 + numpy（本机 python3.10 + numpy 1.26.2 验证），不需要 GPU / torch。
import operator

import numpy as np

BIN = {'add': operator.add, 'sub': operator.sub, 'mul': operator.mul, 'div': operator.truediv}
UN = {'relu': lambda v: max(v, 0.0), 'neg': operator.neg}
INPUTS = ('v0',)
OUTPUTS = ('out1', 'out2')


# ---------- IR：SSA 形式的四元式，纯文本可打印 ----------
IR = [
    ('v0', 'input', ()),            # 输入张量
    ('c1', 'const', (2.0,)),
    ('c2', 'const', (0.5,)),
    ('a1', 'mul', ('v0', 'c1')),    # x*2
    ('a2', 'mul', ('v0', 'c1')),    # 与 a1 完全重复 → CSE 的原料
    ('b1', 'add', ('a1', 'c1')),    # x*2+2
    ('b2', 'add', ('a2', 'c1')),    # CSE 后与 b1 同值
    ('d1', 'mul', ('c1', 'c2')),    # 2.0*0.5 → 常量折叠的原料
    ('d2', 'mul', ('d1', 'c1')),    # 1.0*2.0 → 继续折叠
    ('k1', 'mul', ('d2', 'd2')),    # 4.0，但没人用 → 死代码
    ('e1', 'relu', ('b1',)),
    ('e2', 'relu', ('b2',)),
    ('out1', 'add', ('e1', 'e2')),
    ('k2', 'relu', ('d2',)),        # 同样没人用 → 死代码
    ('out2', 'mul', ('out1', 'v0')),
]


def dump(ir):
    lines = []
    for dst, op, args in ir:
        if op == 'const':
            lines.append(f'  {dst} = {op} {args[0]}')
        elif op == 'input':
            lines.append(f'  {dst} = {op}')
        else:
            lines.append(f'  {dst} = {op} {", ".join(args)}')
    return '\n'.join(lines)


# ================= 层次一：图级 pass（常量折叠 → CSE → 死代码消除）=================
def const_fold(ir):
    known, out, hits = {}, [], 0
    for dst, op, args in ir:
        if op == 'const':
            known[dst] = args[0]
            out.append((dst, op, args))
        elif op in BIN | UN and all(a in known for a in args):
            fn = (BIN | UN)[op]
            v = fn(*[known[a] for a in args])
            known[dst] = v
            out.append((dst, 'const', (v,)))
            hits += 1
        else:
            out.append((dst, op, args))
    return out, hits


def cse(ir):
    seen, alias, out, hits = {}, {}, [], 0
    def canon(x):
        return alias.get(x, x)
    for dst, op, args in ir:
        cargs = tuple(canon(a) for a in args)
        if op in BIN | UN:
            key = (op, cargs)
            if key in seen:
                alias[dst] = seen[key]
                hits += 1
                continue
            seen[key] = dst
        out.append((dst, op, cargs))
    return out, alias, hits


def dce(ir, outputs):
    alive, live = set(outputs), set()
    for dst, op, args in reversed(ir):
        if dst in alive:
            live.add(dst)
            alive.update(args)
    return [ins for ins in ir if ins[0] in live]


def resolve(name, alias):
    while name in alias:
        name = alias[name]
    return name


print('=== 图级 pass：优化前的 IR ===')
print(dump(IR))
n0 = len(IR)
ir1, folds = const_fold(IR)
ir2, alias, cses = cse(ir1)
ir3 = dce(ir2, OUTPUTS)
print('\n=== 图级 pass：优化后的 IR（常量折叠 → CSE → 死代码消除）===')
print(dump(ir3))
print(f'\n  指令数 {n0} → {len(ir3)}：常量折叠 {folds} 条、CSE 命中 {cses} 条、'
      f'死代码消除 {len(ir2) - len(ir3)} 条')
print('  别名表（CSE 合并掉的等价值）：', {k: v for k, v in alias.items()})
def show_expr(name, defs):
    op, args = defs[name]
    if op == 'const':
        return str(args[0])
    if op == 'input':
        return 'x'
    return f'{op}(' + ', '.join(show_expr(a, defs) for a in args) + ')'

defs = {dst: (op, tuple(resolve(a, alias) for a in args)) for dst, op, args in ir3}
print('  最终表达式（两次 relu 已被 CSE 合并成同一个值 e1）：')
for n in ('out1', 'out2'):
    op, args = defs[n]
    print(f'    {n} = {op}({", ".join(args)})')
print('    out1 展开 =', show_expr('out1', defs))
print('    out2 展开 =', show_expr('out2', defs))


# ================= 层次二：算子级 schedule（同一算法，两种算账方式）=================
def elementwise_chain_traffic(L, M, itemsize=4):
    """L 个逐元素算子串成链：eager 每个算子都要把中间结果写回再读出。"""
    return {'kernel 数': L, '访存字节': 2 * L * M * itemsize, '每元素同时活跃的中间值': 1}


def elementwise_fused_traffic(L, M, itemsize=4):
    """全部融合成一次遍历：每个元素读完只用寄存器走完全链，只写最终结果一次。"""
    return {'kernel 数': 1, '访存字节': 2 * M * itemsize, '每元素同时活跃的中间值': L}


def gemm_traffic(M, N, K, bm, bn, bk, itemsize=4):
    """块级 tiling 的 HBM 搬运量（与 CUDA 课第 6 课的公式同一份账）。"""
    hbm = (M // bm) * (N // bn) * (K // bk) * (bm * bk + bk * bn) * itemsize
    return hbm, 2 * M * N * K / hbm


M = 1_000_000
L = 6
print(f'\n=== 算子级 schedule：同一条 {L} 段逐元素链，两种算法的账（M={M:,}）===')
print(f"{'schedule':>10} {'kernel 数':>10} {'访存(MB)':>10} {'每元素活跃中间值':>17}")
for name, f in (('chain', elementwise_chain_traffic), ('fused', elementwise_fused_traffic)):
    r = f(L, M)
    print(f"{name:>10} {r['kernel 数']:>10} {r['访存字节'] / 1e6:>10.1f} {r['每元素同时活跃的中间值']:>17}")
print('  → 融合把访存与 kernel 数都压成常数，代价是"每元素要同时持有的中间值"从 1 涨到 L（寄存器压力）')

print('\n=== 算子级 schedule：GEMM 的 HBM 搬运与算术强度（M=N=K=4096, float32）===')
print(f"{'(bm,bn,bk)':>14} {'HBM(MB)':>9} {'算术强度(FLOP/Byte)':>20}")
for t in ((64, 64, 8), (128, 128, 8), (256, 128, 16)):
    hbm, inten = gemm_traffic(4096, 4096, 4096, *t)
    print(f'{str(t):>14} {hbm / 2**20:>9.0f} {inten:>20.1f}')
print('  → 同一份"算法"（矩阵乘），换 schedule 就换搬运量：这正是算法-调度分离的意义')


# ================= 层次三：内存级（生命周期分析 + 贪心复用）=================
def liveness(ir, outputs):
    """线性顺序下的活跃区间：定义为 [定义位置, 最后一次被读的位置]。"""
    pos = {dst: i for i, (dst, _, _) in enumerate(ir)}
    last = {}
    for i, (dst, op, args) in enumerate(ir):
        for a in args:
            if a in pos:
                last[a] = max(last.get(a, pos[a]), i)
    iv = {}
    for dst, op, args in ir:
        if dst in INPUTS:
            continue
        iv[dst] = (pos[dst], last.get(dst, pos[dst]))
    return iv


def pool(intervals, sizes):
    """贪心首次适配（first-fit）：值结束就回收缓冲，新值优先塞进能放下的空闲块。

    返回 (同时活跃字节数峰值, 实际占用高水位, 分配表)。
    这里不做空闲块合并（coalescing），真实内存池还会合并相邻块。
    """
    inuse, end_at, assign, free, top, peak = {}, {}, {}, [], 0, 0
    for name, (s, e) in sorted(intervals.items(), key=lambda kv: kv[1][0]):
        for n in [n for n, ee in end_at.items() if ee < s]:        # 已结束 → 回收
            free.append(inuse.pop(n))
            del end_at[n]
        free.sort()
        need = sizes[name]
        pick = next((i for i, (_, sz) in enumerate(free) if sz >= need), None)
        if pick is None:
            off = top
            top += need
        else:
            off, sz = free.pop(pick)
            if sz > need:                                          # 切出剩余部分
                free.append((off + need, sz - need))
        inuse[name] = (off, need)
        assign[name] = off
        end_at[name] = e
        peak = max(peak, sum(sz for _, sz in inuse.values()))
    return peak, top, assign


ITEM = 4
M2 = 4096
iv = liveness(ir3, OUTPUTS)
sizes = {d: M2 * ITEM for d in iv}
peak_naive = sum(sizes.values())
peak_live, top, alloc = pool(iv, sizes)
print(f'\n=== 内存级：{len(iv)} 个中间张量的显存规划（每个 {M2 * ITEM / 1024:.0f} KB）===')
print('  生命周期区间（[定义序号, 最后一次被读的序号]）：')
for name, (s, e) in sorted(iv.items(), key=lambda kv: kv[1][0]):
    print(f'    {name:<5} [{s:>2}, {e:>2}]')
print(f'  不复用（每个中间值各占一块）：{peak_naive / 1024:.0f} KB，共 {len(sizes)} 块')
print(f'  生命周期复用（首次适配）：同时活跃峰值 {peak_live / 1024:.0f} KB，'
      f'实际占用高水位 {top / 1024:.0f} KB → 省下 {1 - top / peak_naive:.0%}')
overlap = {k: f'@{off // 1024}KB' for k, off in sorted(alloc.items())}
print('  复用方案（每个值落在哪块缓冲的偏移）：', overlap)
print('  对照：分配顺序 = {c1,a1,b1} 各占一块（此时三者同时活跃，峰值 48 KB），')
print('        之后 e1/out1/out2 依次复用已空出的块 → 高水位停在同一位置，不再增长')


# ================= 正确性对拍：优化后的 IR 必须给出同一个答案 =================
def evaluate(ir, feeds, alias=None, iters=None):
    alias = alias or {}
    env = dict(feeds)
    for dst, op, args in ir:
        a = [resolve(x, alias) for x in args]
        if op == 'input':
            env[dst] = feeds[dst]
        elif op == 'const':
            env[dst] = args[0]
        elif op in BIN:
            env[dst] = BIN[op](env[a[0]], env[a[1]])
        elif op in UN:
            env[dst] = np.maximum(env[a[0]], 0.0) if op == 'relu' else UN[op](env[a[0]])
    return env


rng = np.random.default_rng(0)
xv = rng.standard_normal(M2).astype(np.float32)

y_raw = evaluate(IR, {'v0': xv}, alias=alias)          # 优化前（含冗余与死代码）
y_opt = evaluate(ir3, {'v0': xv}, alias=alias)         # 优化后
print('\n=== 正确性对拍：优化前 vs 优化后（同一份随机输入，4096 元素 float32）===')
for name in OUTPUTS:
    d = float(np.abs(y_raw[name] - y_opt[name]).max())
    scale = float(np.abs(y_raw[name]).max())
    print(f'  {name}: 最大绝对误差 {d:.1e}，相对最大误差 {d / scale:.1e}')
print('  误差为 0：常量折叠、CSE、死代码消除、内存复用都没有改变语义')
