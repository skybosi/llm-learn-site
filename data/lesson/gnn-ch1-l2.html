图的表示#

上一课我们用人话描述了图——节点、边、邻居。但神经网络只吃数字，所以这一课要把"图"翻译成机器能计算的数学对象：邻接矩阵、特征矩阵、度矩阵，以及它们组合出的拉普拉斯矩阵。这些是图神经网络所有公式的"零件"，尤其是拉普拉斯矩阵，它在第三章的谱方法里会反复登场。理解它们之间的关系，比记住定义更重要。

一、概念讲解#

1. 三种存储方式：邻接矩阵、邻接表、边列表#

同一个图至少有三种等价的存储方式，各有各的用途：

  • 邻接矩阵 A：一个 n×n 的方阵，n 是节点数。A[u, v] = 1 表示存在边 (u, v)，否则为 0；加权图则存权重。无向图的 A 是对称矩阵。
  • 邻接表：每个节点存一个邻居列表。上一课我们用 adj = {v: [邻居...]} 的形式，空间开销只和边数成正比。
  • 边列表 / edge index：把边集中存成"起点数组 + 终点数组"，形状为 (2, E)。PyTorch Geometric 的 edge_index 用的就是这种形式，并且无向边会存正反两个方向。

三种方式各有取舍：邻接矩阵方便做矩阵运算（GNN 推导全用它），但 n 很大时是 n² 的稠密矩阵，内存爆炸；邻接表和边列表更省空间，适合真实的大图。工程上常把边列表转成稀疏矩阵存储，只保留非零元素。

2. 特征矩阵 X#

除了连接关系，节点往往还带属性，统称节点特征。把所有节点的特征向量堆叠起来，就是特征矩阵 X，形状为 (n, d)，其中 d 是每个节点的特征维度。

  • 社交网络里，X 可以是用户的年龄、活跃度、兴趣标签向量；
  • 分子图里，X 可以是每个原子的原子序数、电荷等性质；
  • 论文引用网络（如经典的 Cora 数据集）里，X 是每篇论文的词袋向量。

X 是 GNN 的输入。如果没有现成特征，可以人为造一个，比如用节点的度、用 one-hot 编码，甚至直接让每个节点从随机向量开始学习——这些"无属性图"的处理方式会在后面遇到。

3. 度矩阵 D 与拉普拉斯矩阵 L#

从邻接矩阵 A 出发，可以构造两个对 GNN 至关重要的矩阵：

  • 度矩阵 D：对角矩阵，对角线元素 D[v, v] = deg(v)，也就是 A 每一行（或列）的和。

  • 拉普拉斯矩阵 L = D − A：它刻画了图的"平滑度"。给定一个定义在节点上的实数值（图信号）x，二次型

    xᵀ L x = Σ_{(u,v)∈E} (x_u − x_v)²

    恰好是所有相连节点之间取值差的平方和。这个量越小，说明相邻节点的取值越接近、图信号越平滑。第三章会证明，GCN 本质上就是在做"让相邻节点特征趋于一致"的平滑传播。

拉普拉斯矩阵还有两个常用变体：对称归一化形式 L_sym = D^{−1/2} L D^{−1/2}，以及随机游走形式 L_rw = D^{−1} L。前者直接出现在 GCN 公式里。

4. 稀疏表示：为什么大图不能存稠密矩阵#

真实图通常极度稀疏：一个有 10⁷ 个节点的社交网络，边数可能只有 10⁸，邻接矩阵的稠密度不到百万分之一。存成 n×n 的稠密矩阵既浪费内存，矩阵乘法也慢。所以工程上常用稀疏格式：

  • COO（坐标格式）：直接存三个数组 (row, col, val)，每个非零元素一条记录。这正是"边列表 + 权重"的形态，PyG 的 edge_index 等价于 COO。
  • CSR（压缩行格式）：按行压缩，用 indptr 标记每行从哪开始，用 indices 存列号，适合按行取邻居（消息传递恰好是"对每个节点取它的邻居"）。

理解稀疏存储，才能看懂 PyG 内部为什么用一个 edge_index 而不是一个 n×n 矩阵来表示图。

二、可运行代码示例#

下面用 NumPy 走一遍"边列表 → 邻接矩阵 → 度矩阵 → 拉普拉斯矩阵"，并验证拉普拉斯二次型与"相邻节点差的平方和"相等这个关键等式。

import numpy as np

# 1) 一个小图：4 个节点，3 条边（一个"T"字形）
edges = [(0, 1), (0, 2), (1, 3)]
n = 4

# 2) 邻接矩阵（无向图，对称）
A = np.zeros((n, n))
for u, v in edges:
    A[u, v] = 1.0
    A[v, u] = 1.0
print("邻接矩阵 A：\n", A)

# 3) 度矩阵 D = diag(每行之和)
D = np.diag(A.sum(axis=1))
print("度矩阵 D：\n", D)

# 4) 拉普拉斯矩阵 L = D - A
L = D - A
print("拉普拉斯矩阵 L：\n", L)

# 5) 边列表（无向边存正反两个方向，等价于 COO）
edge_index = np.array(
    [[u for u, v in edges] + [v for u, v in edges],
     [v for u, v in edges] + [u for u, v in edges]]
)
print("edge_index 形状：", edge_index.shape)   # (2, 6)
print("edge_index：\n", edge_index)

# 6) COO 三数组：只存非零元素的行、列、值
row, col = edge_index[0], edge_index[1]
val = np.ones(len(row), dtype=int)
print("COO 表示 -> row:", row, "col:", col, "val:", val)

# 7) 验证关键等式：x^T L x = Σ (x_u - x_v)^2
x = np.array([1.0, 2.0, 2.0, 3.0])   # 一个"图信号"
sum_sq = sum((x[u] - x[v]) ** 2 for u, v in edges)
quad_form = x @ L @ x
print("Σ (x_u - x_v)^2 =", sum_sq)
print("x^T L x         =", quad_form)
print("两者是否相等：", np.isclose(sum_sq, quad_form))

运行后你会看到：拉普拉斯矩阵的主对角线是每个节点的度，非对角线的 −1 标记了边的位置；最后一步验证了 xᵀ L x = Σ (x_u − x_v)²，这个等式是理解图信号平滑度的钥匙，第三章谱方法推导会反复依赖它。

三、练习#

  1. 把边 (0, 2) 换成 (2, 3)，重新构造 A、D、L，观察 L 的每一行元素之和是否都等于 0，并解释为什么拉普拉斯矩阵每行和为 0。
  2. 给边加权重（如 (0, 1, 0.5)、(0, 2, 2.0)、(1, 3, 1.0)），写出对应的加权邻接矩阵和加权度矩阵，推导加权情形下 xᵀ L x = Σ w_uv (x_u − x_v)²。
  3. 手工计算对称归一化拉普拉斯 L_sym = D^{-1/2} L D^{-1/2}（用上面 4 个节点的图），验证它的对角线元素是否都等于 1。
  4. 思考：为什么 PyG 用 edge_index（边列表）而不是稠密邻接矩阵来表示图？在节点数 n 很大但边很少时，两者内存差距有多大？
