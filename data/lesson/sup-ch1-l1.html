线性回归原理#

监督学习里最简单、也最能说明"模型是怎么学出来的"的算法，就是线性回归。它解决的问题是：给定一批"特征 → 目标值"的样本，找出一条直线（或高维空间里的一个超平面），让它尽可能贴合这些数据。别小看这条直线——后面要学的逻辑回归、神经网络，本质上都是从"线性组合 + 非线性变换"这个骨架演化出来的。这一课我们先把原理讲透：模型长什么样、用什么损失函数衡量好坏、以及怎么求参数。

一、概念讲解#

1. 模型：一条直线背后的向量#

一元线性回归的形式你一定见过：

y = w·x + b

x 是输入特征，y 是预测值，w 是权重（斜率），b 是偏置（截距）。当特征有多个时，模型推广为多元线性回归：

y = w₁x₁ + w₂x₂ + … + wₙxₙ + b

把它写成向量形式，会清爽得多：

y = wᵀx + b

其中 w = [w₁, …, wₙ]ᵀ 是权重向量，x = [x₁, …, xₙ]ᵀ 是特征向量。"线性"的含义是：预测值是特征的线性组合，每个特征对结果的贡献是独立且按比例的。也就是说，wᵢ 表示"特征 xᵢ 每变化一个单位，预测值变化多少"。

为了方便，我们常把偏置 b 也并入权重向量：给 x 前面拼一列全 1，得到扩展特征 x' = [1, x₁, …, xₙ]ᵀ，模型就变成更简洁的 y = w'ᵀx'。这样所有参数统一用一套公式求解。

2. 损失函数：均方误差（MSE）#

一条直线能画无数条，哪条"最好"？我们需要一个标准来量化"预测得有多差"。线性回归最常用的损失函数是均方误差（Mean Squared Error, MSE）：

J(w) = (1/m) · Σᵢ (yᵢ − ŷᵢ)²
  • m 是样本数；
  • ŷᵢ = wᵀxᵢ + b 是第 i 个样本的预测值；
  • yᵢ − ŷᵢ 叫做残差（residual），即真实值与预测值的差距。

为什么用平方？ 平方把正负残差都变成正数，避免相互抵消；同时平方让大误差被"放大惩罚"，模型会更努力地避免出现特别离谱的预测。MSE 是一个凸函数，只有一个全局最小值——这意味着用梯度类方法求解时，不会掉进局部最优的坑，这也是线性回归"好脾气"的原因之一。

3. 求解方式一：正规方程（解析解）#

当特征维度不高、样本量适中时，可以直接用微积分求解析解：令损失函数对 w 的梯度为 0，解得：

w = (XᵀX)⁻¹ Xᵀy

其中 X 是 m×(n+1) 的设计矩阵（每行一个样本，第一列全是 1），y 是目标值列向量。这个式子就是正规方程（Normal Equation）。

它的优点是一次性算出精确解，不用调学习率；缺点是计算 (XᵀX)⁻¹ 的代价随特征维度立方级增长，维度很高时会吃不消，而且当特征之间存在强相关（XᵀX 接近奇异）时数值上不稳定。所以 sklearn 的 LinearRegression 底层用的是更稳健的最小二乘分解，而不是直接求逆。

4. 求解方式二：梯度下降（迭代解）#

当特征很多、样本很大时，更常用梯度下降（Gradient Descent）：从任意一组参数出发，沿损失函数梯度相反的方向一步步走，每步更新：

w ← w − α · ∇J(w)

α 是学习率，决定每步迈多大。MSE 的梯度可以漂亮地写成矩阵形式：

∇J(w) = (2/m) · Xᵀ(Xw − y)
  • α 太小：收敛慢，跑很多轮才到山脚；
  • α 太大：在最低点附近来回震荡甚至发散。

梯度下降是一个通用框架，在深度学习中无处不在。理解它，等于提前拿到了一张通往神经网络的"地图"。

5. 模型的隐含假设#

线性回归虽然简单，但它自带几条假设，用之前要心里有数：

  1. 线性关系：目标值与特征之间近似线性；
  2. 误差独立同分布：各样本的误差相互独立，且服从均值为 0 的正态分布；
  3. 等方差性：不同特征取值处的误差波动幅度差不多；
  4. 特征间无严重共线性：特征之间不能有太强的线性相关。

这些假设不满足时，模型未必"报错"，但预测质量会打折扣——这正是下一课和"评估与诊断"一课要重点排查的内容。

二、可运行代码示例#

下面用 numpy 从零实现一次"正规方程"和"梯度下降"两种求解，直观对比两者的结果。数据用 sklearn 内置的糖尿病数据集（糖尿病进展指数与各项生理指标），这里只取 BMI 这一个特征，方便画图和理解。

import numpy as np
from sklearn.datasets import load_diabetes
from sklearn.preprocessing import StandardScaler

# 载入数据：只取 BMI（第 2 个特征）做一元回归
X, y = load_diabetes(return_X_y=True)
X = X[:, 2:3]                      # 取 BMI 特征列
X = StandardScaler().fit_transform(X)   # 标准化，便于梯度下降收敛
y = y.reshape(-1, 1)

# 给特征前加一列全 1，把截距 b 并入参数 w
X_b = np.c_[np.ones((X.shape[0], 1)), X]

# —— 方式一：正规方程，直接解 w = (XᵀX)⁻¹ Xᵀy ——
w_normal = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y
print("正规方程求出的参数 w =", w_normal.ravel())

# —— 方式二：梯度下降，迭代更新 ——
def mse(w, Xb, y):
    """均方误差损失：平均值除以样本数"""
    pred = Xb @ w
    return float(np.mean((pred - y) ** 2))

w = np.zeros((2, 1))               # 初始化参数为 0
lr = 0.1                           # 学习率
for step in range(300):
    pred = X_b @ w
    grad = (2 / len(y)) * X_b.T @ (pred - y)   # MSE 对 w 的梯度
    w = w - lr * grad              # 沿负梯度方向更新
    if step % 60 == 0:
        print(f"迭代 {step:3d} 步，损失 = {mse(w, X_b, y):.4f}")

print("梯度下降求出的参数 w =", w.ravel())

运行后大致会看到：梯度下降的损失从某个较大值一路下降并趋于平稳，最终参数与正规方程的结果非常接近（误差来自迭代精度和学习率选择）。

这段代码揭示了机器学习训练的全貌：定义模型 → 定义损失 → 迭代优化。sklearn 帮我们做的，正是把这套流程封装成一个 .fit() 调用，下一课就来看它。

三、练习#

  1. 把学习率 lr 改成 0.5 和 0.001，观察损失曲线分别发生什么变化，解释"震荡"与"收敛过慢"。
  2. 把上面的一元回归改成多元回归：使用糖尿病数据集全部 10 个特征，重写梯度下降，注意 w 的维度会变成 11（10 个权重 + 1 个截距）。
  3. 用笔算验证：当只有一个样本 (x=2, y=5) 时，正规方程给出的直线是什么？为什么此时能"完美拟合"却毫无泛化意义？
  4. 思考：如果某个特征的单位从"米"换成"厘米"（数值放大 100 倍），对应权重 w 会怎样变化？这提示我们在回归前通常要对特征做什么处理？

为什么这样做？——理论推导#

从最大似然推出 MSE 损失#

先问"为什么"。 前面说损失"用平方"，理由是"正负抵消""放大惩罚"——但那只是事后修辞，不是第一性原理。真正的问题是：凭什么最小化平方误差，就等于"找到了最好的直线"？答案藏在一条假设里：我们假设数据是被模型加噪声生成的，然后问"哪个模型最可能生成这批数据"。

假设噪声是高斯。 观测值不会精确落在直线上，总有扰动。记：

y = wᵀx + b + ε，ε ~ N(0, σ²)

即噪声 ε 均值为 0、方差为 σ²。于是给定 x，y 是一个随机变量，服从：

p(y | x; w) = (1 / √(2πσ²)) · exp( −(y − wᵀx − b)² / (2σ²) )

写出似然。 假设 m 个样本独立同分布，联合概率（似然函数）是每个样本概率的连乘：

L(w) = Πᵢ p(yᵢ | xᵢ; w)
     = Πᵢ (1 / √(2πσ²)) · exp( −(yᵢ − wᵀxᵢ − b)² / (2σ²) )

取负对数。 连乘难求极值，取对数（单调变换，不改变极值点位置），再取负号把"最大化"变成"最小化"：

−ln L(w) = −Σᵢ ln p(yᵢ | xᵢ; w)
         = −Σᵢ [ −(1/2)ln(2πσ²) − (yᵢ − wᵀxᵢ − b)² / (2σ²) ]
         = m·(1/2)ln(2πσ²) + (1 / 2σ²) · Σᵢ (yᵢ − wᵀxᵢ − b)²

第一项 m·(1/2)ln(2πσ²) 不含 w、b，是常数；第二项里的 1/(2σ²) 也是常数因子。丢弃常数后，最小化负对数似然就等价于最小化 Σᵢ (yᵢ − ŷᵢ)²，再除以 m 即得 MSE：

J(w) = (1/m) · Σᵢ (yᵢ − ŷᵢ)²

结论：MSE 不是"拍脑袋选平方"，而是"假设误差服从高斯分布 + 最大似然"这两个前提的必然结果。 反向推论同样成立：若误差不服从高斯（比如存在离群点、重尾分布），MSE 就不再是最优选择——这正解释了后面鲁棒回归为何改用绝对误差。

母原理连接： "最大化似然 = 最小化负对数似然"是全课程反复出现的一台通用引擎。线性回归的 MSE，正是这台引擎在"高斯噪声"这种燃料下的第一次点火。
