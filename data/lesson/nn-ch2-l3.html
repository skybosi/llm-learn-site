万能逼近#

我们已经会搭 MLP、会做前向传播了。但一个自然的问题冒出来：神经网络到底能表达多复杂的函数？有没有它学不会的东西？ 答案由万能逼近定理（Universal Approximation Theorem） 给出：只要给够隐藏神经元，一个带非线性激活的单隐藏层网络就能以任意精度逼近任意连续函数。这一课讲清楚这一定理"承诺了什么、没承诺什么"，并用代码直观验证——为什么我们依然需要"深"网络。

一、概念讲解#

1. 定理在说什么#

万能逼近定理（Cybenko 1989、Hornik 1991 等先后证明）的核心结论可以通俗表述为：

对任意闭区间上的连续函数 f(x)，以及任意小的误差 ε > 0，都存在一个单隐藏层的前馈网络（隐藏层使用 Sigmoid 这类"非多项式"激活），使它在整个区间上对 f(x) 的逼近误差小于 ε。

换句话说：一个隐藏层 + 足够多的神经元，理论上什么光滑函数都能近似。 无论目标函数是正弦波、螺旋线还是奇形怪状的曲线，都能被"足够宽"的单隐层 MLP 以任意精度逼近。

2. 直觉：用"台阶"拼出任意形状#

为什么一层隐藏层就够了？以 Sigmoid 神经元为例，通过调整权重和偏置，一个隐藏神经元可以输出一个"S 形台阶"——在某个位置从 0 平滑跳到 1。多个这样的神经元，台阶的位置（靠偏置）、陡峭程度（靠权重）各不相同；把它们按不同权重叠加起来，就能拼出任意形状的阶梯状逼近。台阶越多、越细，拼出的形状就越接近目标函数。

这就像用很多块矩形砖去砌一堵任意形状的墙：砖越多越细，砌出的墙就越接近目标轮廓。Sigmoid 的平滑 S 形正是"砖块"的理想材料，因为它连续、有界、且可通过参数任意平移和缩放。

3. 定理没承诺什么（三个关键"但是"）#

这个定理听起来很厉害，但它有几个重要限定，理解它们才能正确使用 MLP：

  1. 没承诺"神经元数量有限且够小"：逼近任意精度可能需要指数级的隐藏神经元。定理保证"存在"，不保证"便宜"；
  2. 没承诺"能被梯度下降找到"：定理说的是"存在一组权重能逼近"，但没说从随机初始化出发、用梯度下降一定能学出来。学习可能卡在局部最优、可能收敛极慢；
  3. 没承诺"泛化好"：逼近训练集上的函数，不代表在没见过的数据上表现好。逼得太狠反而过拟合。

所以万能逼近定理是"能力的上界"（网络有潜力表达复杂函数），而不是"训练的保证"。真正让深度学习work的，是"够深 + 够数据 + 好的优化"，三者缺一不可。

4. 那为什么还要"深"？表达效率的差别#

既然一层就够，为什么实际都堆很多层？关键在效率。有研究（如 Telgarsky 2016 等）表明：某些函数用浅而宽的网络逼近需要指数级神经元，而用深而窄的网络只需多项式级神经元。也就是说：

  • 宽而浅：表达能力"够"，但要表达的代价可能高得离谱；
  • 深而窄：用多步简单变换层层组合，同样精度下参数少得多。

这就是上一章"为什么需要深度学习"在逼近论视角下的答案：深度带来的是"用更少参数逼近更复杂函数"的效率优势，而非表达能力的绝对上限。

5. 现实含义#

  • 面对一个回归/分类任务，先不必担心"网络能不能表达目标函数"——只要网络有非线性激活且不算太小，它理论上足够强；
  • 真正的挑战在训练（能不能找到好参数）和泛化（能不能用到新数据），这两点要靠优化、正则化、数据去解决，是后续章节的主角；
  • "深度"的价值是参数效率，这让深层网络在大规模任务上既省参数又省数据。

二、可运行代码示例#

下面用 PyTorch 训练一个单隐层 MLP 去拟合正弦函数 y = sin(x)，直观感受"神经元越多，逼近越准"，同时看到"神经元太少会欠拟合"。

import torch
import torch.nn as nn

torch.manual_seed(0)

# 训练数据：在 [-π, π] 上取 200 个点，目标为 sin(x)
x = torch.linspace(-torch.pi, torch.pi, 200).reshape(-1, 1)
y = torch.sin(x)

def make_mlp(hidden):
    """单隐层 MLP：输入 1 -> 隐藏 hidden（Tanh）-> 输出 1"""
    return nn.Sequential(
        nn.Linear(1, hidden),
        nn.Tanh(),
        nn.Linear(hidden, 1),
    )

def train(hidden, epochs=3000):
    model = make_mlp(hidden)
    criterion = nn.MSELoss()
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
    for epoch in range(epochs):
        optimizer.zero_grad()
        loss = criterion(model(x), y)
        loss.backward()
        optimizer.step()
    return loss.item()

# 对比不同隐藏神经元数量下的最终拟合误差（MSE）
for hidden in [1, 2, 4, 16]:
    final_loss = train(hidden)
    print(f"隐藏神经元 = {hidden:2d} 时，最终 MSE = {final_loss:.5f}")

运行结果大致是：隐藏神经元只有 1 个时，误差很大（网络只能表达单调的 S 形，无法拟合正弦的起伏）；随着神经元增加到 4、16，误差明显下降，网络能逼出一个相当接近正弦的波形。这正是万能逼近的直观体现：同一个单隐层结构，靠"加宽"就能逼近越来越复杂的函数。

你还可以把 nn.Tanh() 换成 nn.ReLU() 再跑一遍，会发现 ReLU 也能逼近，只是可能收敛稍慢或需要更多神经元——这印证了"激活函数只要是充分非线性的，就能充当万能逼近的砖块"。

三、练习#

  1. 复现趋势：运行上面代码，记录 1/2/4/16 个隐藏神经元下的 MSE，画出"神经元数 vs 误差"的下降趋势，解释为什么。
  2. 换激活：把 Tanh 换成 ReLU，同样比较不同神经元数的误差，观察 ReLU 逼近正弦是否更慢/需要更多神经元，说说你的发现。
  3. 逼近更难的函数：把目标函数换成 y = sin(5x) 或 y = |x|，用 16 个隐藏神经元训练，对比逼近难度，思考为什么有的函数更难逼近。
  4. 区分"能"与"会"：用一句话说明万能逼近定理保证的是什么、不保证的是什么；再举一个"网络结构足够强但训练失败"的例子（提示：学习率、局部最优、过拟合）。
  5. 思考：如果单隐层网络理论上就能逼近一切，为什么还要堆很多层？请从"参数效率"角度解释深层网络在实践中的价值。

为什么这样做？——理论推导#

万能逼近定理的直观证明#

第一步：把"逼近任意连续函数"约化为"逼近分段常数函数"。

设目标 f 在闭区间 [a,b] 上连续。由闭区间上连续函数的一致连续性，任给 ε > 0，都存在一个足够细的分划 a = x₀ < x₁ < … < x_N = b，使得只要 |x − x_i| 足够小，就有 |f(x) − f(x_i)| < ε/2。于是令每个子区间上取常数 c_i = f(x_i)，就得到一列"台阶"组成的分段常数函数 g，满足 sup|f − g| < ε/2。结论：连续函数可用分段常数函数任意逼近，台阶数 N 取够大即可——这正是黎曼和/阶梯逼近的思想。

第二步：用一个隐藏神经元造出"单个台阶"。

考虑单个神经元 h(x) = σ(wx + b)。当 σ 足够陡（如 Sigmoid 在 wx+b 过零处快速从 0 跳到 1），令 w → ∞，h(x) 就在 x = −b/w 处完成一次 0→1 跳变——一个神经元就是一个"位置可调的台阶"：偏置 b 决定台阶位置，权重 w 决定陡峭程度与方向。

第三步：用"台阶之差"拼出任意高度的矩形脉冲，再线性叠加。

两个相邻台阶相减，得到高度为 1 的矩形脉冲：h(x; b_i) − h(x; b_{i+1}) 在 [x_i, x_{i+1}] 上约等于 1、其余为 0。给每个脉冲乘上高度系数，再由输出层线性加权求和：

g(x) ≈ Σᵢ a_i · [σ(wx + b_i) − σ(wx + b_{i+1})]

这是一个单隐藏层网络（隐藏层每个神经元一个台阶，输出层做线性叠加）。当 w 足够大、台阶足够密，g 能以任意精度逼近分段常数函数，进而逼近 f。合起来用三角不等式：

|f − g| ≤ |f − 分段常数| + |分段常数 − g| < ε/2 + ε/2 = ε

这就从第一性原理证明了：单隐藏层 + 足够多神经元 + 充分非线性激活，能逼近任意连续函数。注意证明只用到"平移 + 缩放 + 叠加"，不依赖 σ 的具体形状——这正是 Cybenko/Hornik 定理中"非多项式"条件如此宽松的原因。

第四步：为什么深度带来"组合性"表达力？

上面的构造虽然"存在"，却可能需要指数级神经元：在 [0,1]^d 上每个维度分 N 份就要 N^d 个台阶，维度一高就爆炸。深层网络不靠"铺满所有格子"，而是逐层组合：第一层识别局部特征，第二层把这些特征组合成更抽象的结构，每加深一层都在做"空间上的乘法"而非加法。因而深网用 O(d·k) 个神经元即可表达需要浅网 O(k^d) 个神经元才能表达的函数（Telgarsky 2016 给出严格下界例子）。深度 = 组合性 = 指数级的表达效率红利，而非表达能力上限的突破。

母原理连接：万能逼近的证明本质是函数空间中的"基底展开"——神经元是"基函数"，输出权重是叠加系数，逼近就是"用有限个基逼近目标"。这与傅里叶级数（三角基）、泰勒展开（幂基）、样条插值（分段基）共享同一母原理：把复杂对象分解为简单元件的加权和。深度学习的独特之处，是让这些"基函数"本身也由数据学习出来（表示学习），而不是预先固定——这是"表示"优于"手工特征"的数学根源。
