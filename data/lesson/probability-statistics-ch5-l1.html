最大似然估计（MLE）#

机器学习训练模型，本质上就是在"从数据里估计参数"。而估计参数最经典、使用最广的方法，就是最大似然估计（Maximum Likelihood Estimation，简称 MLE）。理解 MLE，你就理解了"模型为什么这样学"：逻辑回归、神经网络训练时最小化的那个损失函数，绝大多数都可以追溯到"最大化似然"。

一、概念讲解#

1. 问题：有数据，但不知道参数#

我们已经知道数据服从某个分布族（比如二项分布、正态分布），但分布的参数 θ 是未知的。我们手里只有一批观测数据。问题来了：θ 取什么值，"最可能"产生我们看到的这批数据？

MLE 的回答非常直接：选一个 θ，使得"观察到当前这批数据"的概率最大。

2. 似然函数：把"数据 → 概率"翻过来看#

固定参数 θ 时，数据 D 出现的概率是 P(D | θ)。现在反过来：数据 D 已经固定（我们真的看到了），把 P(D | θ) 当作 θ 的函数，这个函数就叫似然函数：

L(θ) = P(D | θ)

"似然"（likelihood）这个词就是"看起来有多像"的意思——θ 取某个值时，这批数据看起来有多"合理"。

如果样本彼此独立，似然就是每个样本概率的连乘。例如抛 n 次硬币、观察到 k 次正面，似然为：

L(p) = p^k · (1 − p)^(n − k)

3. 取对数：把连乘变成求和#

概率都是 0 到 1 之间的小数，n 个连乘会让结果小到几乎等于 0，计算机很容易下溢。所以实际中几乎总是用对数似然（log-likelihood）：

log L(θ) = Σ log P(xᵢ | θ)

因为 log 是单调递增函数，让 log L 最大的 θ，也就是让 L 最大的 θ。取对数不改变最优解，却把乘法变成加法，既稳定又好求导。

4. 求最大：令导数为零#

求 MLE 的标准流程就是三步：

  1. 写出似然（或对数似然）；
  2. 对 θ 求导，令导数等于 0；
  3. 解出 θ̂。

举两个你会反复用到的结论：

  • 二项分布：抛 n 次硬币 k 次正面，p 的 MLE 就是 p̂ = k / n（即"成功比例"）。
  • 正态分布：μ 的 MLE 是样本均值，σ² 的 MLE 是"样本方差"（除以 n 的版本）。

5. 与机器学习损失函数的联系#

机器学习的很多损失函数，本质上就是负对数似然。最小化"负对数似然"= 最大化"对数似然"= 最大化似然。例如：

  • 线性回归的最小二乘 → 假设误差是正态分布后的 MLE；
  • 二分类的交叉熵损失 → 伯努利分布的负对数似然；
  • 多分类的交叉熵 → 多项分布的负对数似然。

所以这一课不是孤立的数学，而是机器学习"损失函数"背后的统一原理。

6. 解析解与数值解#

有的问题能直接求出公式（解析解，如上面的 p̂ = k/n）；有的问题似然太复杂、求导得不到闭式解，就用数值优化（梯度上升 / 网格搜索）来找最大值。下面代码两种方式都会演示。

二、可运行示例#

示例 A：抛硬币，估计正面概率 p#

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(1)
# 真实概率 p_true=0.7，我们"假装不知道"，只看到 40 次试验中 28 次正面
p_true = 0.7
n, k = 40, 28

# ---- 方法 1：解析解 MLE = k / n ----
p_mle = k / n
print("解析 MLE：", p_mle)

# ---- 方法 2：数值扫描对数似然曲线，找到最大值 ----
p_grid = np.linspace(0.01, 0.99, 500)
# 对数似然：log L(p) = k*log(p) + (n-k)*log(1-p)
log_lik = k * np.log(p_grid) + (n - k) * np.log(1 - p_grid)
best_p = p_grid[np.argmax(log_lik)]
print("数值 MLE：", best_p, "（应与解析解一致）")

plt.plot(p_grid, log_lik, lw=2)
plt.axvline(p_mle, color="red", ls="--", label=f"MLE p={p_mle:.3f}")
plt.xlabel("p")
plt.ylabel("对数似然 log L(p)")
plt.title("对数似然曲线在 MLE 处达到最大值")
plt.legend()
plt.show()

预期输出：

解析 MLE： 0.7
数值 MLE： 0.6993 （应与解析解一致）

示例 B：用样本拟合正态分布的 μ 和 σ#

# 从 N(5, 2) 抽样 5000 个点，再用 MLE 公式"还原"参数
np.random.seed(2)
data = np.random.normal(loc=5.0, scale=2.0, size=5000)

mu_mle = data.mean()                       # μ 的 MLE = 样本均值
sigma_mle = np.sqrt(((data - data.mean())**2).mean())  # σ 的 MLE = 样本标准差（除以 n）
print(f"真实 μ=5.0, σ=2.0")
print(f"MLE  μ={mu_mle:.3f}, σ={sigma_mle:.3f}")

# 用 scipy 的对数似然函数验证：在 MLE 处确实取到最大
from scipy.stats import norm
def nll(params):
    """负对数似然：最小化它就等于最大化似然"""
    mu, sigma = params
    return -np.sum(norm.logpdf(data, loc=mu, scale=sigma))

from scipy.optimize import minimize
res = minimize(nll, x0=[0.0, 1.0], bounds=[(None, None), (1e-6, None)])
print("数值优化得到的 μ, σ：", res.x)

预期输出（部分）：

真实 μ=5.0, σ=2.0
MLE  μ=4.953, σ=2.011
数值优化得到的 μ, σ： [4.95288864 2.01056732]

要点：两种方式（手推公式 + 数值优化）得到的参数几乎一致，也都贴近真实值——这就是 MLE 的威力：样本越多，估计越准。

三、练习#

  1. 推导：从二项分布的对数似然 log L(p) = k·log p + (n−k)·log(1−p) 出发，对 p 求导并令其等于 0，验证 MLE 是 p̂ = k/n。
  2. 改数据：把示例 A 的 (n, k) 改成 (40, 10) 和 (400, 280)，观察对数似然曲线的"尖窄"程度如何变化，并解释为什么样本越多估计越集中。
  3. 正态 MLE：证明"使正态分布对数似然最大的 μ 等于样本均值"（提示：对 μ 求导，令导数 = 0）。
  4. 联系机器学习：写出伯努利分布的负对数似然，说明为什么它等价于二分类的交叉熵损失。
