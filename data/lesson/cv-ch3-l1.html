实例分割（Mask R-CNN）#

语义分割给每个像素一个类别，却分不清"两个人"是两个人；目标检测框出了每个人，却画不出每个人的精确轮廓。实例分割（Instance Segmentation） 把两者合二为一：既要框出每个物体，又要给每个物体单独画出一张像素级掩码。

Mask R-CNN 是这个任务最经典、也最好懂的答案：它在 Faster R-CNN 上加了一个分支，就同时拿到了框和掩码。这一课我们拆解它"加在哪儿、怎么加、为什么这么加"，以及它贡献的那个著名改进——RoIAlign。

一、概念讲解#

1. 从 Faster R-CNN 到 Mask R-CNN：加一个"掩码分支"#

回顾 Faster R-CNN 的检测头：对每个候选框（RoI），RoI 池化出一个定长特征，再接两个并行的全连接头——一个分类、一个框回归。Mask R-CNN 的结构几乎原封不动，只做一件事：在分类头和框回归头旁边，再加一个"掩码分支（mask branch）"。

这个掩码分支是一个小型全卷积网络（FCN）：对同一个 RoI 特征，输出一张 K × m × m 的输出，其中 K 是类别数、m×m 是掩码的分辨率（如 28×28）。它"看到"的特征和分类/回归头是共享的，所以增加的额外计算量很小，却让网络同时学会了三件事。

2. 关键设计一：掩码与类别"解耦"#

一个容易踩的坑是：掩码分支要不要和分类一样用 softmax 做"每像素多分类"？Mask R-CNN 的答案是不。

它对每个类别独立预测一张二值掩码，即第 k 个通道只回答"这个像素属于第 k 类吗？"，损失用逐像素的 sigmoid + 二值交叉熵。训练时只对"该 RoI 的真实类别"那一张掩码计算损失，其他类别的通道不参与。这样就把"这是什么"（由分类头决定）和"这个物体的像素在哪"（由掩码分支决定）解耦了：

  • 分类头负责挑出类别，掩码分支负责为每个候选类别画轮廓，互不打架；
  • 避免了"像素级多分类"里类别间的竞争，对每个物体能画出更干净的掩码。

这一设计是 Mask R-CNN 的精华之一，务必理解"解耦"二字。

3. 关键设计二：RoIAlign——修掉量化误差#

Mask R-CNN 另一个里程碑式的贡献是把 RoI Pooling 换成了 RoIAlign。问题出在 RoI Pooling 的两次量化：

  1. 候选框坐标是浮点数（如 x1=2.4），RoI Pooling 先把它取整到整数像素边界；
  2. 把框内区域等分成 m×m 子网格时，若框的宽高不能被 m 整除，子网格边界再次取整。

这两次取整对"框检测"影响不大（框偏一两个像素无所谓），但对"像素级掩码"是灾难——掩码直接错位、边界出现锯齿。

RoIAlign 的做法是全程不做取整：保留浮点坐标，在每个子网格里按固定规则取若干采样点，对每个采样点用双线性插值从特征图上取值，再取平均。这样特征与像素之间建立了连续、可微的对应，掩码精度大幅提升。

4. 多任务损失与整体训练#

Mask R-CNN 的总损失是三部分之和：

L=Lcls​+Lbox​+Lmask​

即分类交叉熵 + 框回归平滑 L1 + 掩码二值交叉熵。三者共享骨干特征、联合反向传播。骨干通常用 ResNet + FPN（特征金字塔），让不同尺度的物体都能被检测与分割。推理时：RPN 出候选 → RoIAlign → 分类/回归给出框与类别 → 掩码分支按分类头选定的类别取出对应掩码，得到最终"框 + 类别 + 掩码"的实例分割结果。

二、可运行代码示例#

第一段用 torchvision 直接跑预训练的 Mask R-CNN；第二段从零实现 RoIAlign 的核心——双线性插值，亲手体会"浮点坐标连续采样"是怎么回事。

import torch
from torchvision.models.detection import maskrcnn_resnet50_fpn, MaskRCNN_ResNet50_FPN_Weights

# ---------- 1) 预训练 Mask R-CNN 推理 ----------
weights = MaskRCNN_ResNet50_FPN_Weights.DEFAULT
model = maskrcnn_resnet50_fpn(weights=weights).eval()

img = torch.rand(3, 800, 800)          # 真实使用时换成 PIL 图并走 weights.transforms()
with torch.no_grad():
    out = model([img])[0]
print("实例数量：", len(out["boxes"]))
if len(out["boxes"]):
    print("第一个实例 框：", out["boxes"][0].tolist())
    print("第一个实例 类别：", out["labels"][0].item(), " 分数：", round(out["scores"][0].item(), 3))
    print("第一个实例 掩码形状：", tuple(out["masks"][0].shape))   # (1, H, W)，二值概率图

# ---------- 2) 从零实现双线性插值（RoIAlign 的核心） ----------
def bilinear_sample(feat, y, x):
    """
    feat: (C, H, W) 单张特征图；y, x: 浮点坐标（可能落在像素之间）
    做法：取 (y, x) 周围四个最近像素的值，按与它们的距离做加权平均。
    """
    H, W = feat.shape[1], feat.shape[2]
    y0, x0 = int(torch.floor(y)), int(torch.floor(x))
    y1, x1 = min(y0 + 1, H - 1), min(x0 + 1, W - 1)
    # 把坐标夹在有效范围内，避免越界
    y0, x0 = max(y0, 0), max(x0, 0)
    wy = y - y0          # y 方向到左上像素的权重
    wx = x - x0
    # 四个角的值按"面积"加权组合
    top = feat[:, y0, x0] * (1 - wx) + feat[:, y0, x1] * wx
    bottom = feat[:, y1, x0] * (1 - wx) + feat[:, y1, x1] * wx
    return top * (1 - wy) + bottom * wy

feat = torch.rand(256, 50, 50)
val = bilinear_sample(feat, y=12.4, x=7.8)   # 浮点坐标采样
print("双线性插值得到的特征向量形状：", tuple(val.shape))   # (256,)

第 2 段是 RoIAlign 的最小内核：它不在 y=12.4 处取整成 12，而是用周围四个像素（12、13 行 × 7、8 列）按距离加权，从而在浮点坐标上得到连续、可微的取值。RoIAlign 就是把这个操作应用到候选框内每个子网格的采样点上再取平均。

三、练习#

  1. 把 bilinear_sample 改成向量化版本：一次对一张 (C, H, W) 特征图上的 N 个浮点坐标 (y, x) 批量采样，并验证与逐点版本结果一致。
  2. 解释 RoIPool 的"两次取整"具体发生在哪两个环节；构造一个"框宽 7、要分成 2×2 子网格"的例子，算一算取整带来的最大偏移量。
  3. 说明 Mask R-CNN 的掩码分支为什么用"每类一张二值掩码 + sigmoid"，而不是"像素级 softmax 多分类"；如果改成 softmax 多分类，会带来什么问题？
  4. 用 torchvision 的 maskrcnn_resnet50_fpn 对真实照片推理，把第一个实例的 masks[0] 阈值化（如 > 0.5）后可视化，观察掩码边缘的精细程度。
