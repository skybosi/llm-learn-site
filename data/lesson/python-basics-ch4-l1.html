定义与调用函数#

函数是一段可以反复使用的"代码积木"。本节课学习如何自己造积木，以及如何拿起来用。

一、概念讲解#

1. 为什么需要函数#

代码写多了你会发现：同样的逻辑经常要重复出现。比如"打印一条分隔线"这个动作可能被用到十几次。与其复制粘贴，不如把这段逻辑打包成一个函数，给它起个名字，以后喊名字就能用。好处是：

  • 减少重复代码；
  • 想改逻辑时只改一处；
  • 让程序结构更清晰，像搭积木一样。

2. 用 def 定义函数#

def 函数名():
    函数体
  • def 是定义函数的关键字；
  • 函数名要有意义，习惯用"小写字母 + 下划线"命名；
  • 函数体要缩进；
  • 定义函数只是让 Python "记住"这段代码，并不会马上执行。

3. 调用函数#

定义之后，用 函数名() 来"调用"它。调用一次就执行一次函数体；调用几次就执行几次。

4. 定义和调用的先后顺序#

在 Python 里，函数必须先定义、后调用。如果调用发生在定义之前，会报 NameError。

5. 用 docstring 写说明#

函数体的第一行可以写一个三引号字符串，用来解释函数是干嘛的，这叫"文档字符串（docstring）"。它不影响运行，但能帮助别人（以及未来的自己）读懂代码，也可以被工具读取生成文档。

二、代码示例#

示例 1：最简单的函数#

def greet():
    print("你好，欢迎学习 Python！")

greet()   # 第一次调用
greet()   # 第二次调用

示例 2：带 docstring 的函数#

def show_line():
    """打印一条由 20 个横线组成的分隔线。"""
    print("-" * 20)

show_line()
print(show_line.__doc__)   # 查看函数的说明文字

示例 3：函数里再调用函数#

def header():
    print("=" * 20)
    print("  我的程序")
    print("=" * 20)

def main():
    header()          # main 里调用 header
    print("正文内容")
    header()          # 再次调用

main()

示例 4：多个小函数配合的简单计算器#

def add():
    a = int(input("第一个数："))
    b = int(input("第二个数："))
    print(f"和是 {a + b}")

def menu():
    print("1. 加法")
    print("2. 退出")

menu()
choice = input("请选择：")
if choice == "1":
    add()

三、练习#

  1. 定义一个名为 say_hello 的函数，让它打印三行文字，然后调用两次。
  2. 定义一个 print_banner 函数，用 * 打印一个矩形边框（至少 3 行），并给它写一句 docstring。
  3. 定义一个函数，在函数内部计算并打印 1 到 10 的和，然后调用它，验证结果是否为 55。
