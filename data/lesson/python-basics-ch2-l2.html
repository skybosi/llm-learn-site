基本数据类型（数字、字符串、布尔）#

变量是"盒子"，而数据类型决定了这个盒子里能装什么、能做什么。这一课我们认识三种最基础的类型：数字、字符串和布尔值。

一、概念讲解#

1. 为什么要有数据类型#

不同类型的数据，能做的操作不一样。数字可以相加减，文字可以拼接，但你不能拿"你好"去做乘法。Python 需要知道每个数据的类型，才能正确地处理它。查看一个数据的类型，用内置函数 type()：

print(type(10))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("你好"))    # <class 'str'>

2. 数字：整数 int 和浮点数 float#

Python 里常用的数字有两种：

  • 整数（int）：不带小数点的数，如 3、-7、2025。可以是负数，也可以非常大。
  • 浮点数（float）：带小数点的数，如 3.14、-0.5、2.0。"浮点"就是"带小数"的意思。
apples = 5          # int
price = 6.5         # float
print(apples, price)

注意：5 和 5.0 是不同的类型——前者是 int，后者是 float，虽然数值相等。

3. 字符串 str：文字#

字符串就是一串文字，用引号包起来。单引号、双引号都可以，只要前后一致：

a = "你好"
b = '世界'
c = "I'm fine"      # 内部有单引号时，外面用双引号

字符串可以拼接（用 +）和重复（用 *）：

print("你好" + "世界")   # 你好世界
print("哈" * 3)          # 哈哈哈

空字符串 "" 也是合法的，表示"没有文字"。

4. 布尔 bool：真与假#

布尔值只有两个取值：True（真）和 False（假）。注意首字母必须大写，否则会被当成未定义的变量名。布尔值常用来表示"是/否"、"开/关"这类两种状态：

is_student = True
is_raining = False
print(is_student, is_raining)

布尔值通常来自比较的结果，下一课讲运算符时会大量用到，例如 3 > 2 的结果就是 True。

5. 快速小结#

类型 中文名 例子 说明
int 整数 10、-3 不带小数点
float 浮点数 3.14、2.0 带小数点
str 字符串 "你好" 引号包住的文字
bool 布尔值 True、False 只有真/假两种

二、可运行代码示例#

# 演示三种基础数据类型及它们的典型操作

# 1. 数字
length = 12          # int
width = 3.5          # float
area = length * width
print("面积是：", area)            # 面积是： 42.0

# 2. 字符串
first_name = "张"
last_name = "三"
full_name = first_name + last_name   # 字符串拼接
print("全名：", full_name)           # 全名： 张三
print("分隔线" + "-" * 10)           # 字符串重复：分隔线----------

# 3. 布尔值
age = 18
can_vote = age >= 18                 # 比较运算，结果是布尔值
print("可以投票吗？", can_vote)      # 可以投票吗？ True

# 4. 用 type() 查看类型
print(type(area))      # <class 'float'>
print(type(full_name)) # <class 'str'>
print(type(can_vote))  # <class 'bool'>

预期输出：

面积是： 42.0
全名： 张三
分隔线----------
可以投票吗？ True
<class 'float'>
<class 'str'>
<class 'bool'>

要点：12 * 3.5 里一个是整数一个是浮点数，结果会变成浮点数 42.0；字符串的 + 是拼接而不是数学加法。

三、练习#

  1. 判断类型：写出以下数据的类型（int / float / str / bool）：100、"100"、9.9、True、-5、"hello"、3.0。
  2. 动手验证：用 type() 把上一题每个数据的类型实际打印出来，对照你的答案。
  3. 字符串拼接：定义 first = "中国"、second = "加油"，用拼接得到 "中国加油" 并打印；再用 * 把 "加油" 重复 3 次打印。
  4. 布尔值来源：用比较运算得到三个布尔值并打印，例如 5 > 3、10 == 10、2 > 100。
  5. 找不同：5 和 "5" 有什么区别？试着分别 print(type(...))，再用一句话解释为什么它们不能做同一种运算。
