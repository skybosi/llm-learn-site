K 折交叉验证#

上一章我们学会了把数据切成训练集和测试集。但这个办法有个隐患：一次随机的切分，结果可能碰巧偏乐观或偏悲观。比如测试集恰好都是"好判的样本"，分数就虚高；反之则虚低。数据越少，波动越明显。

K 折交叉验证（K-Fold Cross-Validation） 就是为了解决这个"一锤子买卖"的问题：它把数据切成 K 份，轮流让每一份当"测试集"，最后取平均，让评估结果更稳、更可信。

一、概念讲解#

1. 核心思想：人人都有机会当一次"考官"#

把整份数据平均分成 K 份（叫 K 折）。然后循环 K 轮：

  • 每一轮，拿其中 1 折当验证集，剩下 K-1 折当训练集。
  • 训练、打分，记下这一折的分数。
  • 下一轮换一折当验证集，如此往复，直到每一折都当过验证集。

最后把 K 个分数取平均，就是模型更可靠的性能估计；它们的标准差则反映性能的稳定性。

2. 为什么它比单次划分更靠谱#

  1. 每个样本都被验证过：不浪费任何数据，小数据集尤其受益。
  2. 结果更稳定：K 个分数的平均能平滑掉单次随机切分的运气成分。
  3. 数据利用率高：单次划分时测试集里的样本永远没参与训练，交叉验证里每个样本既当过训练也当过验证。

代价是计算量变成原来的 K 倍——要训练 K 次模型。K 的常见取值是 5 或 10。

3. 分层 K 折（StratifiedKFold）——分类任务的首选#

普通 KFold 是"机械地切 K 份"，可能让某一折里某个类别一个都没有。StratifiedKFold 在切分时保证每一折的类别比例都与整体一致，对分类问题（尤其类别不平衡时）更稳妥，分类场景应默认用它。

4. 三个常用工具#

  • KFold(n_splits, shuffle, random_state)：手动控制每一折的切法。
  • StratifiedKFold(...)：分层版本。
  • cross_val_score(model, X, y, cv=...)：一行完成 K 折并返回每折分数；cv=5 时分类默认就是分层 K 折。

二、可运行示例#

示例 1：手动 KFold，看清每一折在做什么

from sklearn.datasets import load_iris
from sklearn.model_selection import KFold
from sklearn.linear_model import LogisticRegression

X, y = load_iris(return_X_y=True)
model = LogisticRegression(max_iter=1000)

# shuffle=True 先打乱再切，避免数据本身有顺序造成偏差
kf = KFold(n_splits=5, shuffle=True, random_state=42)
for fold, (train_idx, val_idx) in enumerate(kf.split(X), start=1):
    # train_idx / val_idx 是样本的"位置编号"，据此取子集
    model.fit(X[train_idx], y[train_idx])
    acc = model.score(X[val_idx], y[val_idx])
    print(f"第 {fold} 折验证准确率：{acc:.3f}")

示例 2：一行完成的 cross_val_score

from sklearn.datasets import load_iris
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression

X, y = load_iris(return_X_y=True)
model = LogisticRegression(max_iter=1000)

# cv=5 表示 5 折；对分类任务会自动使用分层 K 折
scores = cross_val_score(model, X, y, cv=5)
print("各折分数：", [round(s, 3) for s in scores])
print("平均准确率：", round(scores.mean(), 3))
print("标准差：", round(scores.std(), 3))   # 越小说明越稳定

示例 3：StratifiedKFold 在类别不平衡数据上的表现

import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import KFold, StratifiedKFold

# 1 类只占 10% 的不平衡数据
X, y = make_classification(
    n_samples=300, n_features=5, weights=[0.9, 0.1], random_state=0)

# 普通 KFold：可能出现某一折几乎没有 1 类样本
print("普通 KFold 各折中 1 类占比：")
kf = KFold(n_splits=5, shuffle=True, random_state=42)
for _, val_idx in kf.split(X):
    print("  ", round(np.mean(y[val_idx] == 1), 3), end="")
print()

# 分层 KFold：每一折都保持约 10% 的 1 类占比
print("分层 KFold 各折中 1 类占比：")
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for _, val_idx in skf.split(X, y):
    print("  ", round(np.mean(y[val_idx] == 1), 3), end="")
print()

三、练习#

  1. 改折数：把 cross_val_score 的 cv 改成 3、5、10，观察平均分与标准差的变化趋势，思考 K 太大或太小的代价。
  2. 对比单次划分：对同一份数据，跑 5 次"单次 7:3 划分"和一次"5 折交叉验证"，比较两者结果的波动范围。
  3. 手动验证 cross_val_score：用示例 1 的手动 KFold 把 5 折分数求平均，与示例 2 的 cross_val_score 结果对比，确认一致。
  4. 思考用途：为什么说"交叉验证用于调参与选模型，独立的测试集用于最终验收"？如果两者混用会出什么问题？
  5. 回归任务：把示例 2 换成 load_diabetes 数据集与 LinearRegression，cross_val_score 默认用什么指标？不指定 scoring 时得到的是什么分数？
