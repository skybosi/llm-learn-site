特征选择#

PCA 这类降维方法会把原始特征"揉"成全新的主成分，虽然维度降下来了，但新特征是抽象的组合，很难向业务方解释。特征选择走的是另一条路：它不创造新特征，而是从原始特征里挑出一批最有用的，保留原汁原味、可解释的特征。这一课讲特征选择的三大类方法，以及 scikit-learn 里对应的实现。

一、概念讲解#

1. 特征选择与降维的区别#

  • 降维（特征提取）：把原始特征线性/非线性组合成新特征，新特征数量少但含义抽象（如 PCA 的主成分）。
  • 特征选择：在原始特征中做"减法"，留下一个子集，特征仍是原来的物理量，可解释性强。

特征选择能带来三个好处：减少过拟合、加快训练、让模型更容易被理解。尤其是当后续要给人讲清楚"模型为什么这么判断"时，特征选择通常优于 PCA。

2. 三大类方法#

特征选择方法按"怎么判断一个特征有没有用"分为三类：

  • 过滤法（Filter）：在训练模型之前，用一个统计量给每个特征打分，按分数排序取前 k 个。速度快、与具体模型无关，但忽略了特征之间的组合效应。
  • 包裹法（Wrapper）：反复"训练模型 → 评估 → 增删特征"，用模型表现作为选择标准。通常更准，但计算开销大。
  • 嵌入法（Embedded）：特征选择"内嵌"在模型训练过程中，模型自己会产出特征重要性，据此筛选。兼顾了效果与效率。

3. 常用工具一览#

  • VarianceThreshold：过滤法，剔除方差低于阈值的特征（近乎常数的列对预测没用）。
  • SelectKBest + 评分函数：过滤法，用卡方、F 值、互信息等给特征打分，取分数最高的 k 个。mutual_info_classif 用于分类任务，能捕捉非线性相关。
  • RFE（递归特征消除）：包裹法，从一个模型出发，反复训练并淘汰"最不重要"的特征，直到剩下指定个数。
  • SelectFromModel：嵌入法，借助 Lasso、树模型等的 coef_ 或 feature_importances_ 保留超过阈值的特征。

二、可运行代码示例#

示例 1：用方差阈值剔除"僵尸"特征#

方差几乎为零的特征对任何预测都帮不上忙，先把它清掉：

import numpy as np
from sklearn.feature_selection import VarianceThreshold

rng = np.random.default_rng(0)
X = rng.normal(size=(100, 5))
X[:, 1] = 0.001 * rng.normal(size=100)   # 方差极小的特征
X[:, 3] = 5.0                            # 完全恒定的特征

sel = VarianceThreshold(threshold=0.1)   # 方差低于 0.1 的特征被剔除
X_new = sel.fit_transform(X)
print("原始特征数:", X.shape[1], "→ 保留特征数:", X_new.shape[1])
print("被保留的特征列索引:", sel.get_support(indices=True))

要点：threshold=0.1 表示"方差小于 0.1 就删"。get_support(indices=True) 返回被保留下来的原始列下标，方便你知道删了谁、留了谁。

示例 2：互信息打分 + 取前 k 个#

用 SelectKBest 结合互信息，从葡萄酒数据的 13 个特征里挑出 5 个：

from sklearn.datasets import load_wine
from sklearn.feature_selection import SelectKBest, mutual_info_classif

wine = load_wine()
X, y = wine.data, wine.target

sel = SelectKBest(mutual_info_classif, k=5)
X_new = sel.fit_transform(X, y)

keep = sel.get_support(indices=True)
print("选出的 5 个特征列索引:", keep)
print("对应特征名:", [wine.feature_names[i] for i in keep])
print("各特征互信息分数:", sel.scores_.round(3))

要点：互信息衡量"知道这个特征后，类别标签的不确定性下降了多少"，分数越高说明该特征与标签的关联越强。注意 fit_transform(X, y) 这里多传了标签 y，因为评分需要用到类别信息。

示例 3：递归特征消除（RFE）#

让随机森林反复"投票"，淘汰最不重要的特征：

from sklearn.datasets import load_wine
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier

wine = load_wine()
X, y = wine.data, wine.target

model = RandomForestClassifier(n_estimators=100, random_state=42)
rfe = RFE(estimator=model, n_features_to_select=5)
rfe.fit(X, y)

keep = rfe.get_support(indices=True)
print("被保留的特征:", [wine.feature_names[i] for i in keep])
print("特征排名 ranking_（1 表示被选中，越大越先被淘汰）:", rfe.ranking_)

要点：ranking_ 里数值为 1 的特征被选中，其余按"被淘汰的先后"编号，编号越大越早出局。RFE 每次训练一个完整模型，所以比过滤法慢，但在小数据集上完全可以接受。

三、练习#

  1. 阈值实验：在示例 1 里把 threshold 分别设为 0、0.5、2，观察保留特征数的变化，说明阈值与"删多删少"的关系。
  2. 换评分函数：把示例 2 里的 mutual_info_classif 换成 f_classif（需要 from sklearn.feature_selection import f_classif），比较两次选出的特征集是否一致。
  3. 嵌入法体验：用 SelectFromModel 配合 RandomForestClassifier，对 load_wine 做一次基于特征重要性的筛选，打印 get_support(indices=True) 并与 RFE 的结果对比。
  4. 思考：为什么"单个特征都与目标相关"不一定等于"这一组特征组合起来最好"？这暴露了过滤法的什么弱点？
