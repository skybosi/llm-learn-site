指令选择：树覆盖（tiling 的另一种视角）#

第 5 章交到后端手上的 IR 已经语义正确，但 IR 与目标机指令并不一一对应：一句 t1 = a + b 可能是 add r, r, r，可能是 add r, r, #3，还可能是"取数、加法、存回"三条。定下这层对应关系的动作叫指令选择（instruction selection），它最经典的模型是把表达式看成树、用指令模板去覆盖（tiling）整棵树。本课讲清这个模型，并把它与 GPU 里同名的那个 tiling 对齐。

一、概念讲解#

1. 覆盖：IR 是树，指令是模板#

表达式部分天然是一棵树（第 4 课）。每条目标指令都可以写成一条改写规则：左边是一小棵模式树，右边是这条指令——add dst, src, #imm 对应"add(X, 常量)"，madd 对应"add(mul(X,Y), Z)"。指令选择于是变成一道拼图题：给整棵 IR 树选一组互不重叠、恰好盖满的模板。这就是 tiling（铺砖）。

tiling 在 GPU 课里的含义是"数据分块"，两者结构同构：

覆盖式 tiling（本课） 数据式 tiling（CUDA 第 4 章）
被盖的东西 IR 表达式树 / 指令 DAG 迭代空间（张量分块）
砖块 指令模板 + 成本 数据块 + 复用距离
优化目标 指令数 / 总成本最小 访存次数 / 带宽最小
主要约束 模板依赖、寄存器压力 共享内存容量、线程数

最后一列值得留意：两种 tiling 都受资源上限约束——那边是共享内存，这边是寄存器。

2. 模板的粒度#

模板可细可宽：细（一节点一指令，ldr r, [x_a]）；中（把常量折进指令，add r, x, #3 省掉一次 mov）；宽（madd 一次盖住 add(mul(a,b),c)，或带移位的 add r, r, r, lsl #k）。

直觉上"盖得越多越省"，但成本不按节点数线性摊薄：真实的宽指令往往吞吐更差或延迟更长。更要紧的是，一条指令盖住的子树越大，同时需要的操作数寄存器越多——这正是下一课寄存器压力的来源。所以指令选择不是"挑最大的模板"就完事。

3. 贪心最大覆盖与动态规划#

贪心最大覆盖（maximal munch）：从根往下走，每次挑"盖住节点最多"的模板，剩余子操作数递归处理。实现简单，缺点是决策依据是面积而非成本。

动态规划：自底向上求 cost(v) = min(模板成本 + Σ 各子操作数成本)，在树形 IR 上是多项式时间（龙书第 8 章 §8.11 的动态规划代码生成）。它挑的是总成本最小，因此能处理"宽指令看着省、实际更贵"的情形。

还有一条相关结论：若目标机指令都是"寄存器-寄存器"形式、每条最多产生一个寄存器结果，那么用 Ershov 数 / Sethi–Ullman 标注可以同时得到最优求值顺序与最少寄存器数。这解释了早期 RISC 机器为什么敢用最简单的覆盖策略：成本高度统一时，面积就近似等于成本。

4. 真实编译器怎么做#

LLVM 把指令选择放在后端第一阶段的头一步，产物是"目标指令的 DAG + 虚拟寄存器"，文档明确要求这一步使用最优的模式匹配选择器（"模式展开 + 反复 peephole"的替代设计要慢得多）。模板用 TableGen 描述：经典路径是 SelectionDAG，新路径 GlobalISel 把这一阶段拆成多步。CISC 后端还会把寻址模式当模板，一条 mov rax, [rbx + rcx*8] 同时完成移位、加法与取数。

5. 常见坑#

  • 拿节点数当成本：宽指令盖得多但可能更贵；同理，立即数范围这类前提必须写进模板校验，否则会生成非法指令。
  • 先选完再想寄存器：tile 越大、活跃值越多，可能选完才发现必须溢出，收益被抵消（第 2 课）。
  • 只按树选、忽略共享：同一子表达式出现两次会被算两遍；DAG 覆盖能共享但其一般形式是 NP-hard，实践做法是"树覆盖 + 局部合并"。

二、可运行代码示例#

下面这段纯 Python（无第三方依赖）实现同一套模板的两种覆盖策略，并自动枚举小树搜出"贪心不是最优"的反例。目标机是本课自定义的玩具机器：指令形状参考 AArch64，成本是自定的小整数，不代表任何真实机器的数字。其中 wide_fma 是刻意放进来的"宽指令"（盖 5 个节点、成本 5），对应真实机器上"省了一条取数、但本身更慢"的复合指令。

# ---- 指令选择：树覆盖（tiling）的两种做法 ----
# 纯 Python，无第三方依赖。
# 目标机是"本课自定义的玩具机器"：成本只为对比算法，不代表任何真实机器的数字。
# 指令形状参考 AArch64 的常见形态（add/mul/madd/lsl/带移位的 add）。

# ---------- 1. 输入 IR：表达式树 ----------
def Var(n): return ('var', n)
def Num(v): return ('num', v)
def Add(a, b): return ('add', a, b)
def Mul(a, b): return ('mul', a, b)

def size(t):
    return 1 if t[0] in ('var', 'num') else 1 + size(t[1]) + size(t[2])

def render(t):
    if t[0] == 'var': return t[1]
    if t[0] == 'num': return str(t[1])
    return f'({render(t[1])} {"+" if t[0] == "add" else "*"} {render(t[2])})'

# ---------- 2. 指令模板：模板里的大写字母 = 必须先算进寄存器的子树 ----------
def pow2(n): return isinstance(n, int) and n > 0 and (n & (n - 1)) == 0
def log2(n):
    k = 0
    while (1 << k) < n: k += 1
    return k

# (名字, 模板, 成本, 发射函数(dst, regs, binds), 额外校验(binds))
RULES = [
    # 注意规则顺序：纯"面积优先"的贪心在同尺寸模板上按此顺序 tie-break
    ('add_rr',  ('add', 'A', 'B'),                        1,
     lambda d, r, b: f'add   {d}, {r["A"]}, {r["B"]}',                       lambda b: True),
    ('add_imm', ('add', 'A', ('num', 'B')),               1,
     lambda d, r, b: f'add   {d}, {r["A"]}, #{b["B"]}',                      lambda b: True),
    ('mul_rr',  ('mul', 'A', 'B'),                        3,
     lambda d, r, b: f'mul   {d}, {r["A"]}, {r["B"]}',                       lambda b: True),
    ('lsl_imm', ('mul', 'A', ('num', 'B')),               1,
     lambda d, r, b: f'lsl   {d}, {r["A"]}, #{log2(b["B"])}',                lambda b: pow2(b['B'])),
    ('madd',    ('add', ('mul', 'A', 'B'), 'C'),          1,
     lambda d, r, b: f'madd  {d}, {r["A"]}, {r["B"]}, {r["C"]}',             lambda b: True),
    ('add_lsl', ('add', 'A', ('mul', 'B', ('num', 'C'))), 1,
     lambda d, r, b: f'add   {d}, {r["A"]}, {r["B"]}, lsl #{log2(b["C"])}',  lambda b: pow2(b['C'])),
    # "宽指令"：盖住的节点多，但单条成本高（真实机器上的对应物：带内存操作数、
    # 需要额外地址生成的复合指令）—— 它的存在就是为了暴露"面积 ≠ 成本"
    ('wide_fma', ('add', ('mul', 'A', 'B'), ('mul', 'C', 'D')), 5,
     lambda d, r, b: f'fma   {d}, {r["A"]}, {r["B"]}, {r["C"]}, {r["D"]}',  lambda b: True),
]

def match(pat, t, b):
    """模板匹配：大写字符串是通配符，绑到子树；常量子模式只绑值"""
    if isinstance(pat, str):
        if pat in b: return b[pat] == t
        b[pat] = t
        return True
    if pat[0] != t[0]: return False
    if pat[0] in ('var', 'num'):
        b[pat[1]] = t[1]
        return True
    return match(pat[1], t[1], b) and match(pat[2], t[2], b)

def holes(pat):
    """模板里"必须算进寄存器"的位置（常量子模式不算）"""
    out = []
    def walk(p):
        if isinstance(p, str): out.append(p); return
        if p[0] in ('var', 'num'): return
        walk(p[1]); walk(p[2])
    walk(pat)
    return out

def pat_size(pat):
    if isinstance(pat, str): return 0
    if pat[0] in ('var', 'num'): return 0
    return 1 + pat_size(pat[1]) + pat_size(pat[2])

def applicable(t):
    if t[0] in ('var', 'num'): return []          # 叶子由 ldr / mov 直接处理，成本 1
    rs = []
    for i, (name, pat, cost, emit, guard) in enumerate(RULES):
        b = {}
        if match(pat, t, b) and guard(b):
            rs.append((i, name, pat, cost, emit, b))
    return rs

# ---------- 3. 贪心最大覆盖（maximal munch） ----------
def greedy_rule(t, use_cost_tiebreak):
    cands = applicable(t)
    if not cands: raise KeyError(f'没有模板能盖住 {t}')
    key = (lambda c: (pat_size(c[2]), -c[0])) if not use_cost_tiebreak \
        else (lambda c: (pat_size(c[2]), -c[3], -c[0]))
    return max(cands, key=key)

# ---------- 4. 动态规划最优覆盖：cost(v) = min(模板成本 + 各子操作数成本) ----------
def dp_rule(t, memo):
    if t in memo: return memo[t]
    if t[0] in ('var', 'num'):
        memo[t] = (1, None)                        # 一条 ldr / mov
        return memo[t]
    best = None
    for i, name, pat, cost, emit, b in applicable(t):
        total = cost + sum(dp_rule(b[h], memo)[0] for h in holes(pat))
        if best is None or total < best[0]:
            best = (total, (i, name, pat, cost, emit, b))
    memo[t] = best
    return best

# ---------- 5. 按覆盖结果发射指令 ----------
class Emitter:
    def __init__(self):
        self.code, self.n = [], 0
    def reg(self):
        self.n += 1
        return f'x{self.n}'
    def emit(self, t, choose):
        if t[0] in ('var', 'num'):                 # 叶子：一条取数指令
            dst = self.reg()
            self.code.append((f'ldr   {dst}, [x_{t[1]}]' if t[0] == 'var'
                              else f'mov   {dst}, #{t[1]}', 1))
            return dst
        _, name, pat, cost, f, b = choose(t)
        regs = {h: self.emit(b[h], choose) for h in holes(pat)}   # 先子后父
        dst = self.reg()
        self.code.append((f(dst, regs, b), cost))
        return dst

def run(t, which):
    em = Emitter()
    if which == 'dp':
        memo = {}
        em.emit(t, lambda x: dp_rule(x, memo)[1])
    elif which == 'greedy':
        em.emit(t, lambda x: greedy_rule(x, False))
    else:
        em.emit(t, lambda x: greedy_rule(x, True))
    return em.code, sum(c for _, c in em.code)

# ---------- 6. 枚举小树，自动搜"贪心不是最优"的反例 ----------
def all_trees(n, leaves):
    """内部节点恰为 n 个的所有表达式树"""
    if n == 0: return list(leaves)
    out = []
    for k in range(n):
        for l in all_trees(k, leaves):
            for r in all_trees(n - 1 - k, leaves):
                out.append(('add', l, r)); out.append(('mul', l, r))
    return out

if __name__ == '__main__':
    print('=== 例 1：s = a*b + (c+3)*d ===')
    tree = Add(Mul(Var('a'), Var('b')), Mul(Add(Var('c'), Num(3)), Var('d')))
    print('IR：', render(tree), f'（{size(tree)} 个节点）')
    for which, label in (('greedy', '贪心：面积优先'), ('greedy_cost', '贪心：面积优先+成本 tie-break'),
                         ('dp', 'DP：最小成本')):
        code, cost = run(tree, which)
        print(f'\n--- {label}：{len(code)} 条指令，总成本 {cost} ---')
        for text, c in code:
            print(f'    {text:<34} (成本 {c})')

    print('\n=== 例 2：s = (a*b) + (c*d)（宽指令 vs 拆开） ===')
    tree2 = Add(Mul(Var('a'), Var('b')), Mul(Var('c'), Var('d')))
    print('IR：', render(tree2), f'（{size(tree2)} 个节点）')
    for which, label in (('greedy', '贪心：面积优先'), ('dp', 'DP：最小成本')):
        code, cost = run(tree2, which)
        print(f'  {label}: 成本 {cost} → ' + ' | '.join(x.strip() for x, _ in code))

    print('\n=== 反例搜索：内部节点 ≤ 4 个的全部小树 ===')
    for which, label in (('greedy', '面积优先贪心'), ('greedy_cost', '面积+成本 tie-break 贪心')):
        bad, total = None, 0
        for n in range(1, 5):
            for t in all_trees(n, [Var('a'), Var('b'), Num(4)]):
                total += 1
                cg, _ = run(t, which); cd, _ = run(t, 'dp')
                sg, sd = sum(c for _, c in cg), sum(c for _, c in cd)
                if sg > sd and (bad is None or sg - sd > bad[0]):
                    bad = (sg - sd, render(t), cg, cd, sg, sd)
        print(f'  {label}：检查 {total} 棵树；', end='')
        if bad:
            _, r, cg, cd, sg, sd = bad
            print(f'最差反例 {r}（贪心 {sg} > DP {sd}）')
            print('    贪心：', ' | '.join(x.strip() for x, _ in cg))
            print('    DP  ：', ' | '.join(x.strip() for x, _ in cd))
        else:
            print('未发现反例')

三、练习#

  1. 实现：给 RULES 加一条 sub_imm（sub(X, 常量)，成本 1），再跑反例搜索，看"面积优先贪心"的最差反例是否变化，并解释原因。
  2. 解释：为什么 DP 在树形 IR 上是多项式时间，而同样的思想搬到 DAG 上就变成 NP-hard？提示：树上的子问题是什么，DAG 上的子问题又是什么？
  3. 对比/验证：把 wide_fma 的成本从 5 改成 3，重跑例 2。贪心与 DP 的结论一致吗？这说明"成本模型"与"覆盖算法"各自对结果负什么责任？
  4. 思考：如果一条模板要求固定的物理寄存器（例如除法只能用指定寄存器），覆盖阶段该怎么表达？提示：LLVM 文档把这类情形称为 fixed register，并说明指令选择器需要插入搬运。
