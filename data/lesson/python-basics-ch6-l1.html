类与对象#

一、概念讲解#

面向对象编程（OOP）是一种把程序组织起来的方式。在写复杂程序时，如果只用一个个变量和函数，代码会越来越乱、越来越难维护。面向对象帮我们把"数据"和"操作这些数据的函数"打包在一起。

1. 类是什么，对象是什么#

  • 类（class）：可以理解成一张"设计图纸"。它描述了某一类事物应该有哪些属性（数据）和哪些行为（方法）。
  • 对象（object）：根据图纸制造出来的"具体实物"。一个类可以造出很多个对象，每个对象都独立拥有自己的数据。

打个比方：Dog（狗）这个类描述了"狗都有名字和年龄，都会叫"；而 旺财、小黑 是两条具体的狗，它们是 Dog 类的两个对象，各自的名字、年龄可以不同。

2. 定义一个类#

定义类用 class 关键字。类里可以定义一个特殊的方法 __init__，它会在创建对象时自动执行，用来给对象设置初始数据：

class Dog:
    def __init__(self, name, age):
        self.name = name   # 把传入的名字存到这个对象上
        self.age = age     # 把传入的年龄存到这个对象上

    def bark(self):
        print(f"{self.name} 在汪汪叫！")

这里有三个需要理解的关键点：

  1. class Dog: 后面的冒号表示下面是类的定义体，里面的方法都要缩进。
  2. __init__ 方法前面和后面各有两个下划线，它是 Python 规定好的"初始化方法"，不要写错。
  3. self 代表"当前这个对象"。当你写 self.name = name 时，意思是"把这个对象自己的 name 属性设成传入的 name"。

3. 创建对象#

有了类之后，就可以"按图纸生产"对象了。创建对象看起来就像调用一个函数：

dog1 = Dog("旺财", 3)   # 创建第一个对象
dog2 = Dog("小黑", 1)   # 创建第二个对象

创建对象时传入的参数，会自动交给 __init__ 方法（self 除外）。上面的代码相当于：第一个对象执行了 self.name = "旺财"、self.age = 3。

每个对象的数据是独立的：

dog1 = Dog("旺财", 3)
dog2 = Dog("小黑", 1)

print(dog1.name, dog1.age)   # 旺财 3
print(dog2.name, dog2.age)   # 小黑 1

dog1.bark()   # 旺财 在汪汪叫！
dog2.bark()   # 小黑 在汪汪叫！

注意：调用 dog1.bark() 时，Python 会自动把 dog1 传给 self，所以方法里的 self.name 就是 dog1 的 name。

二、可运行代码示例#

# ---- 1. 定义一个"学生"类 ----
class Student:
    def __init__(self, name, score):
        self.name = name      # 学生姓名
        self.score = score    # 学生分数

    def introduce(self):
        print(f"我叫 {self.name}，考了 {self.score} 分。")

    def is_pass(self):
        # 判断是否及格（60 分及格）
        return self.score >= 60


# ---- 2. 创建两个学生对象 ----
s1 = Student("小明", 85)
s2 = Student("小红", 55)

# ---- 3. 调用对象的方法 ----
s1.introduce()          # 我叫 小明，考了 85 分。
s2.introduce()          # 我叫 小红，考了 55 分。

print(s1.name, "及格了吗？", s1.is_pass())   # 小明 及格了吗？ True
print(s2.name, "及格了吗？", s2.is_pass())   # 小红 及格了吗？ False

# ---- 4. 每个对象的数据互不影响 ----
s1.score = 90           # 只修改 s1 的分数
print(s1.score)         # 90
print(s2.score)         # 55，不受影响
