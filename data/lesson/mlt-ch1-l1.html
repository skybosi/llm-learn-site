什么是学习#

"机器学习"这个词，拆开是"机器"和"学习"。机器好理解——就是一个能执行计算的程序；真正模糊的是"学习"二字：一堆数据喂给程序，它怎么就"学会"了呢？这一课我们不碰任何具体算法，而是先用一套严格的数学语言，把"学习"这件事本身定义清楚。因为后面所有算法——线性回归、逻辑回归、神经网络——都只是在这个定义上换了不同的零件而已。先定义清楚，我们才能"知其所以然"。

一、概念讲解#

1. 学习问题的数学建模#

把"学习"抽象成一个问题，需要五样东西：

  • 输入空间 𝒳：所有可能输入的集合，比如一张图片所有像素值构成的向量空间。
  • 输出空间 𝒴：所有可能输出的集合，比如分类任务里的标签集合 {猫, 狗}，或回归任务里的实数集 ℝ。
  • 真实规律（目标函数） f：一个我们不知道、但客观存在的映射 f: 𝒳 → 𝒴。它把输入映射到"正确答案"。
  • 未知分布 𝒟：输入（有时连同输出）在真实世界里服从的概率分布。我们永远看不到 𝒟 的完整形态，只能从它里面采样。
  • 训练集 S：从 𝒟 中独立同分布（i.i.d.）采样出的 m 个样本：
S = {(x₁, y₁), (x₂, y₂), …, (xₘ, yₘ)}

其中每个 (xᵢ, yᵢ) 都独立地服从 𝒟。学习问题的目标可以一句话概括：给定训练集 S，输出一个函数 h: 𝒳 → 𝒴，使 h 在"没见过的样本"上尽可能接近真实的 f。

关键点在于"没见过的样本"。如果只要求在训练集上表现好，那把 S 背下来就行——但那不是学习，是死记硬背。学习的本质是从有限样本归纳出对整体的预测能力。

2. 假设空间：学习者"能想到"的所有函数#

学习者不可能凭空搜索所有可能的函数——那是无穷的。它会事先圈定一个候选函数集合，叫做假设空间（hypothesis space），记作 ℋ：

ℋ = { h : 𝒳 → 𝒴 }

ℋ 里的每个元素 h 叫做一个假设（hypothesis）。比如：

  • 所有线性函数 h(x) = wᵀx + b 构成一个假设空间，由参数 (w, b) 参数化；
  • 所有深度为 3、每层 128 个神经元的神经网络构成另一个假设空间；
  • 所有决策树构成第三个假设空间。

学习，本质上就是从 ℋ 里挑一个 h。挑得好不好，取决于两件事：ℋ 里有没有接近 f 的假设（表达能力），以及我们能否在只有 S 的情况下找到它（搜索能力）。假设空间是学习者的"世界观"，它先天地决定了你最多能学到多好——这是后面"偏差"概念的根源。

3. 损失函数：如何量化"预测错了"#

要从 ℋ 里挑"最好"的 h，得先定义"错多少"。损失函数（loss function） ℓ 给"预测值 h(x) 与真实值 y 之间的差距"打一个非负分数：

ℓ(y, ŷ) ≥ 0，且当 y = ŷ 时通常为 0

ŷ = h(x) 是预测值。常用的损失：

任务 常用损失 定义（单个样本）
回归 平方损失 ℓ(y, ŷ) = (y − ŷ)²
回归 绝对损失 `ℓ(y, ŷ) =
分类 0-1 损失 ℓ(y, ŷ) = ⟦y ≠ ŷ⟧（错为 1，对为 0）
分类 交叉熵损失 ℓ(y, p) = −log p(y)

损失函数的选择本身就是一种价值判断：平方损失认为"误差大一倍，惩罚翻四倍"；绝对损失认为"误差大一倍，惩罚翻一倍"。后面第 2 章我们会看到，这些选择并非随意——它们各自对应着某种概率假设。

4. 期望风险：我们真正想最小化的东西#

有了损失函数，一个假设 h 的"全局表现"就是它在所有可能样本上的平均损失。这叫做期望风险（expected risk）或泛化误差（generalization error）：

L_𝒟(h) = 𝔼_{(x,y)~𝒟}[ ℓ(h(x), y) ]

L_𝒟(h) 是"如果拿无限多真实分布里的样本去考 h，它平均每道题错几分"。这才是学习真正的目标：找一个 h 让 L_𝒟(h) 最小。

但问题来了：我们根本不知道 𝒟，所以 L_𝒟(h) 算不出来。这是一个根本性的困境——目标存在，却不可计算。机器学习的全部历史，某种意义上就是围绕"如何逼近这个不可计算的目标"展开的。

5. 经验风险：用一个可计算的替身#

既然 𝒟 未知，一个朴素而自然的想法是：用训练集 S 上的平均损失去近似期望风险。这个替身叫经验风险（empirical risk）：

L_S(h) = (1/m) · Σᵢ₌₁ᵐ ℓ(h(xᵢ), yᵢ)

由大数定律，当 m 足够大时，L_S(h) 会以概率收敛到 L_𝒟(h)。所以"在训练集上平均损失最小的 h"，通常也会是"在真实分布上损失较小的 h"。

经验风险最小化（Empirical Risk Minimization, ERM） 原则随之诞生：

ĥ_ERM = argmin_{h ∈ ℋ} L_S(h)

这就是"学习"的完整定义：在一个预先圈定的假设空间 ℋ 里，找一个在训练数据上平均损失最小的假设。它由三个零件构成——ℋ（能想到什么）、ℓ（怎么算错）、S（见过什么数据）。

6. 一个隐患：ERM 会过拟合#

ERM 有一个致命软肋：当 ℋ 太大（比如能表达任意复杂函数）时，argmin 会找到一个"在训练集上零误差、却在真实分布上一塌糊涂"的 h——它把训练集的噪声也"背"了下来。这是因为经验风险只是期望风险的近似，两者的差（泛化差距）随 ℋ 的复杂度增大而扩大。

这正是第 4 章偏差-方差分解要定量处理的核心矛盾：ERM 是通向学习的唯一抓手，但 ERM 本身不是学习的全部。理解这一点，是"理论深化"和"调包侠"的分水岭。

二、可运行代码示例#

下面用 NumPy 把这个定义"跑"一遍：造一个真实的线性规律 f(x) = 3x + 2，再人为加一点高斯噪声作为"未知分布"的采样。然后手工构造几个候选假设 h，分别算它们的经验风险，验证"经验风险最小的那个假设，确实最接近真实规律"。

import numpy as np

rng = np.random.default_rng(42)

# 1. 真实规律（我们"假装不知道"的 f）
def f(x):
    return 3.0 * x + 2.0

# 2. 从"未知分布"采样训练集：真实值 + 高斯噪声
m = 100
x = rng.uniform(-5, 5, size=m)
y = f(x) + rng.normal(0.0, 1.0, size=m)   # ε ~ N(0, 1)

def squared_loss(y_true, y_pred):
    """平方损失的经验风险：样本平均"""
    return float(np.mean((y_true - y_pred) ** 2))

# 3. 候选假设空间：一批"斜率-截距"不同的线性函数
candidates = [
    ("h1: w=0, b=0", 0.0, 0.0),
    ("h2: w=3, b=2", 3.0, 2.0),   # 恰好等于真实规律
    ("h3: w=1, b=1", 1.0, 1.0),
    ("h4: w=3, b=5", 3.0, 5.0),
]

for name, w, b in candidates:
    pred = w * x + b
    risk = squared_loss(y, pred)
    print(f"{name:>16s}  经验风险 = {risk:8.4f}")

运行后会看到：h2（就是真实规律 f）的经验风险最小。这不是巧合——当 h = f 时，损失只剩噪声项 ε²，其样本平均最小。"经验风险最小的假设"与"真实规律"高度一致，正是大数定律在起作用。

三、练习#

  1. 把上面的噪声标准差从 1.0 改大到 5.0，再跑一遍。各候选假设的经验风险排名会变吗？为什么噪声越大，"经验风险最小"这个信号越不可靠？
  2. 证明：当训练集只有一个样本 (x₁, y₁)、假设空间是"所有过该点的函数"时，存在无穷多个假设都能让经验风险严格为 0，但它们对 x₁ 之外的点预测完全不同。这说明了 ERM 在什么条件下会失效？
  3. 用 0-1 损失重写上面的代码（分类版）：把 y > f(x) 标为 1、否则标为 0，构造两个阈值分类器并计算它们的经验风险。
  4. 思考：为什么"期望风险"虽然是我们真正想最小化的量，却永远无法直接计算？举一个"经验风险低但期望风险高"的具体例子（提示：训练集太小）。

母原理连接#

本课属于母原理 "一切学习 = 优化"。我们把"学习"这个模糊的动词，还原成了三个可计算的部件——假设空间 ℋ（搜索范围）、损失函数 ℓ（目标）、经验风险最小化（优化过程）。从此以后，任何"学习算法"在你眼里都只是一道优化题：在某个集合里找最小值。第 2 章将告诉你损失函数从哪来（概率），第 3 章告诉你假设空间怎么被约束（贝叶斯），第 4 章告诉你为什么"优化经验风险"不等于"优化期望风险"。而这一切的起点，就是本课这个干净的定义。
