结果与复盘#

上一课你已经能稳定生成图片了。但"能生成"和"生成得好"是两回事。本课是整个课程的收官：如何客观地衡量生成质量、如何诊断并修复常见问题、如何把一次实验变成可复用的经验。这也是一个成熟从业者和"跑通 demo 就停"的初学者之间最大的差别。

一、概念讲解#

1. 客观评估：给"好不好"装一把尺子#

主观的"这张不错"无法比较、无法复现，所以需要客观指标。常用的有三类：

  • FID（Fréchet Inception Distance）：衡量"生成图集合"与"真实图集合"在特征空间里的分布距离。做法是把两批图都送进 Inception 网络取特征，假设特征服从高斯分布，计算两个分布之间的 Fréchet 距离。FID 越低，说明生成图与真实图的分布越接近。它衡量的是"整体像不像真的"，而非单张图质量。
  • CLIP score（图文一致性）：直接用第四章学的 CLIP，计算生成图与其 prompt 的余弦相似度。分数越高，图越贴合文字描述。它是"参考无关"的——不需要真实配对图，只要有 prompt 即可，特别适合文生图场景。
  • 美学/偏好分数：用人工标注训练一个"打分模型"（如 LAION Aesthetics），输出一个"美不美"的分数。它捕捉 FID 和 CLIP score 都拿不准的"构图美感"。

三者互补：FID 看"像不像真实分布"，CLIP score 看"符不符合文字"，美学分看"好不好看"。一个成熟项目至少要同时看其中两个。

2. 常见问题诊断与改进#

症状 常见原因 对策
手部/肢体畸形、多余手指 模型对精细结构建模不足 加负向提示（extra fingers, deformed hand）、提高分辨率、用专门的人像微调模型
画面里的文字乱码 扩散模型天然不擅长生成精确文字 减少文字需求，或把文字用 ControlNet/后期合成上去
主体缺失、构图失衡 prompt 过长或要素冲突 精简并重排 prompt，把最重要主体放句首
颜色过艳/过灰 CFG 过高/过低 回到上一课的 CFG 扫描，取适中值
结果不可复现 未固定 seed 固定 generator 的 seed

进阶修复工具：ControlNet（用边缘、姿态、深度图等额外条件"锁住"构图）、LoRA（低秩适配，用少量数据把模型往特定风格/角色上微调）、放大修复（img2img + upscale）（先低分辨率生成，再放大精修）。

3. 复盘方法论：让每一次生成都留下资产#

  • 实验记录：每次生成都记录 prompt、负向提示、seed、步数、CFG、模型版本。缺了任何一项，结果就无法复现，也无法归因。
  • A/B 对比：一次只改一个变量（例如只改 CFG，其余全固定），对比才有意义；同时改多个参数，你永远不知道是谁起了作用。
  • 成本复盘：统计单张耗时与显存峰值，对照项目规划的预算，判断是否需要换模型或加优化。

4. 全课程回顾#

到这里，你走过的路是这样的：CLIP 对比学习让图文对齐到同一空间（第四章）→ 对齐成果被多模态大模型接进 LLM，实现看图说话、图文统一生成、视频音频扩展（第五章）→ 最后用扩散模型把文本条件变成像素，并学会评估与复盘（第六章）。从"对齐"到"理解"再到"生成"，一条完整的链已经在你手里打通。

二、可运行代码示例#

示例 1：用 CLIP 计算 CLIP score（图文一致性）#

把第四章的 CLIP 直接搬来做评估，一次算多张图的平均分。

from transformers import CLIPProcessor, CLIPModel
from PIL import Image
import torch

model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

# 生成图与其对应的 prompt
items = [
    ("corgi_seed42.png", "a cute corgi wearing a red scarf, cartoon style"),
    ("juice_cfg7.5.png", "a glass of orange juice on a wooden table"),
]

scores = []
for path, prompt in items:
    image = Image.open(path).convert("RGB")
    inputs = processor(text=[prompt], images=image, return_tensors="pt", padding=True)
    with torch.no_grad():
        out = model(**inputs)

    # 归一化后点积 = 余弦相似度, 即该图的 CLIP score
    img_emb = out.image_embeds / out.image_embeds.norm(dim=-1, keepdim=True)
    txt_emb = out.text_embeds / out.text_embeds.norm(dim=-1, keepdim=True)
    score = (img_emb * txt_emb).sum(dim=-1).item()
    scores.append(score)
    print(f"{path:20s} CLIP score = {score:.4f}")

print(f"\n平均 CLIP score = {sum(scores)/len(scores):.4f}")

CLIP score 越高，说明图与文字越一致。把它和你的人工观感对照，你会逐渐校准出"分数多少算合格"的经验阈值。

示例 2：把实验参数落成可复现的记录#

下面用一个字典统一记录每次生成的关键参数，形成"实验日志"，这是复盘的起点。

import json

experiment = {
    "run_id": "exp-001",
    "prompt": "a cute corgi wearing a red scarf, cartoon style",
    "negative_prompt": "low quality, blurry, deformed",
    "model": "runwayml/stable-diffusion-v1-5",
    "seed": 42,
    "num_inference_steps": 30,
    "guidance_scale": 7.5,
    "height": 512,
    "width": 512,
    "clip_score": round(scores[0], 4) if scores else None,  # 接示例 1 的分数
}

with open("experiment_log.json", "w", encoding="utf-8") as f:
    json.dump(experiment, f, ensure_ascii=False, indent=2)
print("实验日志已写入 experiment_log.json")

以后任何人（包括三个月后的你自己）拿到这个 JSON，都能复现同一张图、复算同一个分数——这就是"复盘资产"。

三、练习#

  1. 指标选择：判断以下场景各适合用哪个指标：(a) 比较两个模型的整体画质；(b) 验证"图里是不是真的有一只柯基"；(c) 想知道用户觉得哪张更好看。
  2. 动手实验：把示例 1 里的 prompt 换成一句与图片无关的描述（例如换成 "a bowl of noodles"），CLIP score 会怎样变化？这说明 CLIP score 度量的是什么？
  3. 诊断练习：一张生成的图出现了六根手指，且画面里"欢迎光临"四个字是乱码。请各给出至少一种针对性的改进方案。
  4. 复盘总结：用 300 字以内，写一份你本次文生图项目的复盘：目标达成情况、踩过的坑、下一步最想尝试的一个方向。
