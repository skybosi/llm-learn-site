sklearn 结构与安装#

从这一章开始，我们正式进入 scikit-learn（代码里常写 sklearn）的世界。它是 Python 最流行的传统机器学习库，把几十种算法统一成一套简洁的接口。本课先讲清它的整体结构和安装方法，为后续课时打基础。

一、概念讲解#

1. 什么是 scikit-learn#

scikit-learn 是一个基于 NumPy、SciPy 和 matplotlib 的开源机器学习库，覆盖分类、回归、聚类、降维、模型选择、数据预处理等任务。它的核心设计理念是一致的 API：不管用哪种算法，基本都是"创建对象 → fit() 训练 → predict()/transform() 应用"，学会一个就能举一反三。

2. 模块结构#

scikit-learn 按功能把代码组织成多个子模块，常用的有：

  • sklearn.datasets：示例数据。load_*（小数据，随库打包，如 load_iris、load_diabetes）和 fetch_*（需联网，如 fetch_california_housing），以及 make_*（生成模拟数据，如 make_classification）。
  • sklearn.preprocessing：特征缩放、类别编码等预处理（chapter-3 主角）。
  • sklearn.impute：缺失值填充。
  • sklearn.model_selection：划分数据集、交叉验证、网格搜索。
  • sklearn.linear_model / sklearn.neighbors / sklearn.tree / sklearn.ensemble：各类算法。
  • sklearn.metrics：评估指标（准确率、均方误差、混淆矩阵等）。
  • sklearn.pipeline：把多个步骤串成一条流水线。

3. 安装与版本检查#

用 pip 安装（建议装在虚拟环境里）。scikit-learn 依赖 NumPy 和 SciPy，pip 会自动处理：

pip install -U scikit-learn

安装后，在 Python 里用 import sklearn 并打印 sklearn.__version__ 确认。一个常见坑：包名是 scikit-learn，但导入名是 sklearn，二者不能混用。

二、可运行代码示例#

下面的代码先确认版本，再演示 datasets 模块里不同数据源的用法。

import sklearn
print("scikit-learn 版本：", sklearn.__version__)

from sklearn import datasets

# 1) load_*：打包好的小数据集，无需联网，返回 Bunch 对象
diabetes = datasets.load_diabetes()
print("\nload_diabetes 类型：", type(diabetes))
print("包含的键：", list(diabetes.keys()))
print("特征形状：", diabetes.data.shape, "标签形状：", diabetes.target.shape)
print("特征名：", diabetes.feature_names)

# 2) make_*：生成模拟数据，常用于教学和测试
X, y = datasets.make_classification(
    n_samples=300, n_features=6, n_informative=4, random_state=42
)
print("\nmake_classification 生成的 X 形状：", X.shape, "y 形状：", y.shape)
print("y 里有哪些类别：", sorted(set(y.tolist())))

提示：fetch_* 系列（如 fetch_california_housing）需要联网下载，如果网络受限，可优先使用 load_* 和 make_*。

运行结果里，load_diabetes() 返回的 Bunch 是一个像字典一样可以用 . 访问属性的对象，data 是特征矩阵（NumPy 数组），target 是标签数组，feature_names 是列名列表——这和我们熟悉的 Pandas 数据结构能很方便地互相转换。
