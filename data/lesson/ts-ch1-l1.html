时间序列概念#

你已经学过机器学习，知道怎么把一张表格 (X, y) 喂给模型去拟合。但在很多真实业务里，数据不是"一堆无关样本"，而是按时间先后排成一列的：每天的销量、每分钟的服务器负载、每小时的体温读数。这种数据叫时间序列，它有一条机器学习常规设定里没有的硬约束——观测之间不独立，过去会影响现在。这一课先把时间序列的"长相"和它身上的几类模式讲清楚。

一、概念讲解#

1. 什么是时间序列#

时间序列是同一对象在等间隔时间点上观测得到的一串数值，记作：

y_1, y_2, ..., y_T

下标表示时间顺序，y_t 是第 t 期的观测。这里的"等间隔"很关键：如果间隔一会是一天、一会是一个月，那它更像一堆带时间戳的事件，而不是一条规整的序列，绝大多数经典模型都假设间隔均匀。

和普通表格数据相比，时间序列的核心区别在于次序有意义：

  • 把样本打乱，X 的每行仍然是"一个样本"；但把 y_1..y_T 打乱，序列就完全失去了意义。
  • 普通监督学习常假设样本独立同分布（i.i.d.）；时间序列里 y_t 和 y_{t-1} 几乎总是相关，i.i.d. 假设直接失效。

这就是为什么"学完机器学习还要专门学时间序列"：你手里那套 train_test_split 随机切分、交叉验证的打分方式，在这里会悄悄作弊（第 3 章第 3 课会严格论证为什么不能随机切分）。

2. 四类经典模式#

一条时间序列通常可以看成若干模式叠加或相乘的结果。看懂模式是建模的第一步。

（1）趋势 Trend#

趋势是序列在较长尺度上的整体走向：持续上升、下降，或缓慢变化。它不要求每期都涨，而是"把短期波动抹平后"仍能看出的方向。例如一家公司的年营收随着市场扩张逐年走高，就是上升趋势。

趋势可以是线性的，也可以是非线性的（先快后慢的饱和增长）。要注意：趋势描述的是"长时间尺度的单调或平滑运动"，不等于"每期都在涨"。

（2）季节性 Seasonality#

季节性是固定频率、由日历驱动的周期性波动。它的周期是已知且固定的：

  • 零售在每年 12 月出现销售高峰，周期 = 1 年；
  • 冰淇淋销量夏天高、冬天低，周期 = 1 年；
  • 网站流量工作日高、周末低，周期 = 1 周；
  • 地铁客流早晚高峰，周期 = 1 天。

季节性的根源是日历规律（月份、星期、节假日、作息），所以它是可预测、可重复的：今年 12 月的旺季明年大概率还会来。

（3）周期性 Cycle#

周期性也是"涨上去又跌下来"的波动，但它没有固定频率，由经济或业务景气驱动：

  • 经济扩张与衰退交替的"经济周期"，一次可能 5 年、下一次 8 年；
  • 房地产市场的景气循环，长短不定。

周期性波动的长度会变，不像季节性那样严格按日历重复。因此循环更难预测，很多模型干脆把它归入趋势或残差，或当作长期趋势的一部分处理。

（4）残差 Remainder#

把趋势、季节（和循环）都"拿走"之后剩下的部分，是不可归因的随机波动，也叫不规则分量。理想情况下它像白噪声（无规律），是模型无法再解释的那部分。

一句话记忆：趋势看方向，季节看日历，循环看景气，残差看运气。季节和循环都是"周期波动"，区别只在"频率是否固定、是否由日历驱动"。

3. 加性 vs 乘性：模式怎么组合#

分量之间主要有两种组合方式，第 3 课会展开，这里先建立直觉：

  • 加性模型：y_t = 趋势_t + 季节_t + 残差_t。季节波动的幅度不随水平变化，全年上下波动的"高度"差不多。
  • 乘性模型：y_t = 趋势_t × 季节_t × 残差_t。季节波动幅度随水平同比例放大——销量越大，旺季的绝对增量也越大。

判断加性还是乘性，可以看序列的波动幅度是否随水平增长：如果"水平越高、波动越剧烈"，通常更适合乘性（或先取对数变成加性）。

4. 一个直观例子#

设想某电商平台 3 年的月销售额：整体逐年上涨（趋势），每年 11 月因促销出现尖峰（季节，周期 = 12 个月），中间还夹杂一次持续 14 个月的行业景气回调（循环），其余起伏就是残差。一条真实序列往往是这几种模式的混合体，而预测的本质，就是把这些有规律的部分（趋势、季节）从噪声里分离出来并外推。

二、可运行示例#

用 pandas 生成一条"趋势 + 季节 + 噪声"的合成序列，亲眼看看各分量长什么样。

import numpy as np
import pandas as pd

# 构造 36 个月（3 年）的月度日期索引
idx = pd.date_range("2021-01-01", periods=36, freq="MS")
n = len(idx)

# 1) 趋势：线性上升，每月 +3
trend = 100 + 3 * np.arange(n)

# 2) 季节：周期 12 个月的正弦波动，幅度 15
season = 15 * np.sin(2 * np.pi * np.arange(n) / 12)

# 3) 噪声：正态随机扰动
rng = np.random.default_rng(42)
noise = rng.normal(0, 4, size=n)

# 4) 加性组合成观测值
y = trend + season + noise

df = pd.DataFrame({"y": y, "trend": trend, "season": season}, index=idx)
print(df.head(8).round(1))
print("序列均值 =", round(df["y"].mean(), 2), "，标准差 =", round(df["y"].std(), 2))

运行后你会看到 y 既在整体爬升（趋势），又呈现 12 个月一轮的高低起伏（季节），还叠加了随机抖动（噪声）。

再看一个"乘性"效果：把季节波动做成随水平放大的样子。

# 乘性示意：季节分量是比例，波动幅度随趋势变大
trend2 = 100 + 3 * np.arange(n)
season2 = 1 + 0.12 * np.sin(2 * np.pi * np.arange(n) / 12)  # 季节比例在 0.88~1.12 之间
y_multi = trend2 * season2 + noise

# 观察波动幅度是否随时间变大
early = pd.Series(y_multi[:12]).std()   # 第一年波动
late = pd.Series(y_multi[-12:]).std()   # 第三年波动
print("第一年标准差 =", round(early, 2), "，第三年标准差 =", round(late, 2))

如果第三年的波动幅度明显大于第一年，说明水平越高波动越大，这就是乘性模型的典型信号。
