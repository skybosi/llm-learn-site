正则化方法#

面对过拟合，前面给的药方是"增加数据"或"降低复杂度"。但数据往往拿不到更多，模型又不想一味砍简单。这时正则化（regularization） 提供了一条更精细的路：不直接砍模型的复杂度，而是在损失函数里加一个惩罚项，让模型在"拟合数据"和"保持简单"之间自动妥协。这是机器学习里最优雅、最常用的思想之一。

一、概念讲解#

1. 核心思想：给"复杂"标个价#

模型拟合数据时，会拼命让预测误差变小；如果不加约束，它可能用出一些"大得离谱"的参数去强行贴合噪声。正则化的做法是：在损失函数后面加一项与参数大小有关的惩罚：

新的损失 = 原始损失 + λ · 惩罚项
  • 参数越大，惩罚越重；模型为了减小总损失，不得不把参数压低。
  • λ（在 sklearn 里常写作 alpha 或 C 的倒数）控制惩罚的力度：越大，模型越"保守"、越简单。

于是模型不再是"无脑拟合数据"，而是"在拟合与简单之间找平衡"——这正好降低了方差，缓解过拟合。

2. L1 与 L2：两种最经典的惩罚#

惩罚项取参数向量的 L2 范数（平方和） 或 L1 范数（绝对值和），得到两种正则化：

  • L2 正则化（Ridge / 岭回归）：惩罚 Σ wᵢ²。效果是让所有参数整体变小，但一般不归零，保留所有特征。
  • L1 正则化（Lasso）：惩罚 Σ |wᵢ|。效果更"狠"——会直接把很多不重要的参数压到 0，起到自动特征选择的作用。
  • 弹性网络（ElasticNet）：L1 和 L2 的混合，取两者之长。

3. sklearn 里的正则化"开关"#

  • 线性回归：Ridge(alpha)、Lasso(alpha)、ElasticNet(alpha, l1_ratio)，alpha 越大惩罚越强。
  • 逻辑回归：LogisticRegression(penalty="l2", C)，注意这里 C 是正则化强度的倒数——C 越小，正则化越强。
  • 支持向量机：SVC(C)，同样是 C 越小越强。

4. 力度怎么选#

正则化力度（alpha 或 C）本身也是一个超参数，不该拍脑袋定。正确的做法是用上一章学到的交叉验证 + 网格/随机搜索去挑，我们马上在示例里看到。

二、可运行示例#

示例 1：高维数据上对比无正则、L2、L1

import numpy as np
from sklearn.datasets import make_regression
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

# 50 个特征里只有 10 个真正有用，其余都是噪声特征，容易过拟合
X, y = make_regression(n_samples=200, n_features=50,
                       n_informative=10, noise=30, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42)

# 1) 普通线性回归：无正则化，容易在噪声特征上过拟合
lr = LinearRegression().fit(X_train, y_train)
print("LinearRegression 测试 MSE：",
      round(mean_squared_error(y_test, lr.predict(X_test)), 1))

# 2) Ridge（L2）：系数被整体压小，但不归零
ridge = Ridge(alpha=10).fit(X_train, y_train)
print("Ridge(L2) 测试 MSE：",
      round(mean_squared_error(y_test, ridge.predict(X_test)), 1))

# 3) Lasso（L1）：很多无关特征的系数被直接压成 0
lasso = Lasso(alpha=0.5, max_iter=10000).fit(X_train, y_train)
print("Lasso(L1) 测试 MSE：",
      round(mean_squared_error(y_test, lasso.predict(X_test)), 1))
print("Lasso 非零系数个数：", np.sum(lasso.coef_ != 0))

示例 2：逻辑回归里 C 越小，正则化越强

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0, stratify=y)

# C 是正则化强度的倒数：C 越小 -> 正则化越强 -> 模型越"保守"
for C in [0.01, 0.1, 1, 10]:
    model = LogisticRegression(C=C, max_iter=2000)
    model.fit(X_train, y_train)
    acc = accuracy_score(y_test, model.predict(X_test))
    print(f"C={C:>5} 时测试准确率：{acc:.3f}")

示例 3：用交叉验证自动挑选正则化力度

from sklearn.datasets import load_diabetes
from sklearn.linear_model import Ridge
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.metrics import mean_squared_error

X, y = load_diabetes(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0)

# 把 alpha 当作超参数，交给网格搜索 + 交叉验证去挑
param_grid = {"alpha": [0.01, 0.1, 1, 10, 100]}
gs = GridSearchCV(Ridge(), param_grid, cv=5,
                  scoring="neg_mean_squared_error")
gs.fit(X_train, y_train)

print("最优 alpha：", gs.best_params_)
print("测试 MSE：",
      round(mean_squared_error(y_test, gs.predict(X_test)), 1))

三、练习#

  1. 观察稀疏性：运行示例 1，对比 Ridge 和 Lasso 的系数，数一数 Lasso 有多少个系数是 0，解释为什么 L1 会"自动选特征"而 L2 不会。
  2. 力度方向：说明 Ridge 的 alpha 和 LogisticRegression 的 C 在"正则化力度"上的方向有何不同，为什么容易搞混。
  3. 调力度实验：把示例 2 的 C 继续缩小到 0.001、放大到 1000，观察准确率的变化，判断这个数据集更偏"欠拟合"还是"过拟合"。
  4. 自动选参：把示例 3 的 Ridge 换成 Lasso，同样用 GridSearchCV 搜索 alpha，比较两者最优 alpha 下测试 MSE 的高低。
  5. 思考：正则化为什么能降低方差、缓解过拟合？结合"总误差 ≈ 偏差² + 方差"的公式，说明正则化在压方差的同时，会不会反而增大偏差。

为什么这样做？——理论推导#

从第一性原理出发：惩罚项凭什么长这样#

前面我们"顺手"把惩罚项写成 Σ wᵢ² 或 Σ |wᵢ|，但它们其实不是随意选的。问一句"为什么偏偏是这两种？"——答案藏在贝叶斯视角里：正则化 = 给参数加先验。

第一步：最大后验（MAP）拆成两部分。 贝叶斯公式给出"后验 ∝ 似然 × 先验"：

p(w | D) ∝ p(D | w) · p(w)

取对数求极大，最大后验估计等价于：

w_MAP = argmax_w [ log p(D | w) + log p(w) ]

其中第一项是"拟合数据"（最大似然），第二项是"我对参数的事先信念"（先验）。损失函数里加的惩罚项，本质就是 −log p(w)。

第二步：高斯先验 → L2（岭回归）。 假设每个参数独立地服从均值 0、方差 τ² 的高斯分布——"参数应当小，越极端越不信"：

p(w) = Π_j (1/√(2πτ²)) · exp(−w_j² / (2τ²))

取负对数后，先验项贡献 Σ_j w_j²/(2τ²)。代入 MAP（设噪声也是高斯、方差 σ²，此时似然即平方损失 Σ_i (y_i − w·x_i)²）：

w_MAP = argmin_w [ (1/(2σ²))·Σ_i (y_i − w·x_i)² + (1/(2τ²))·Σ_j w_j² ]

两边同乘 2σ²，令 λ = σ²/τ²，正是：

argmin_w [ Σ_i (y_i − w·x_i)² + λ·Σ_j w_j² ]      ← 岭回归（L2）

第三步：拉普拉斯先验 → L1（Lasso）。 若先验换成拉普拉斯分布（重尾：允许少数参数较大，但多数参数被拉向 0）：

p(w) = Π_j (1/(2b)) · exp(−|w_j| / b)

负对数先验项贡献 Σ_j |w_j|/b，同理归一化后得到：

argmin_w [ Σ_i (y_i − w·x_i)² + λ·Σ_j |w_j| ]      ← Lasso（L1），λ = 2σ²/b

为什么 L1 产生稀疏（参数精确为 0）？ 看两个惩罚项在 w_j → 0 附近的"单位惩罚"：L2 的导数 2w_j 随 w_j 缩小而趋于 0，越接近 0 就越没动力把它压到 0；而 L1 的导数（次梯度）是 sign(w_j)，幅值恒为 λ，与 w_j 大小无关。于是对一个贡献很小的特征，只要它带来的损失下降不足以抵消恒定的 λ，最优解就把 w_j 直接顶到 0。几何上，L1 的约束区域是菱形，尖角正好戳在坐标轴上，损失等高线（椭圆）最先与它相切的位置常在轴上——相切点即最优解，对应某个 w_j = 0；而 L2 的圆是光滑的，切点一般不落在轴上，所以系数只被压小、不归零。

母原理连接#

这段推导把"加惩罚"翻译成了"选先验、算后验"，属于母原理 「概率视角统一」：L1/L2 不是两种人为的技巧，而是同一条公式 w_MAP = argmax [log 似然 + log 先验] 在"高斯先验 / 拉普拉斯先验"两种信念下的自然产物。
