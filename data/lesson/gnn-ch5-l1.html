节点分类#

从这一章起，我们离开"某个具体模型"，站到任务的高度看问题。图上的监督学习主要有两大任务：给节点打标签，和给整张图打标签。本课先攻第一个——节点分类（node classification）：已知部分节点的标签，预测其余节点的标签。引文网络里推断论文主题、社交网络里识别用户身份、商品图里判断物品类别，都是它的典型场景。

一、概念讲解#

1. 任务设定：半监督与直推式#

节点分类最经典、也最容易让人误解的设定是半监督（semi-supervised）：图里只有一小部分节点有标签（训练集），其余节点的标签要么留作验证/测试，要么根本未知。

它的一个重要特性是直推式（transductive）：训练、验证、测试节点共享同一张图。模型在训练时就能"看到"所有节点的特征和连边，只是看不到它们的标签。好处是信息利用充分；风险是如果图结构本身和标签强相关，测试信息可能"泄漏"进训练过程，让评估结果偏乐观。这一点第 3 课评估会专门展开。

2. 通用框架：消息传递 + 分类头#

无论底层用 GCN、SAGE 还是 GAT，节点分类的模型都可以拆成两段：

  1. 编码器（encoder）：堆叠 K 层图卷积，把节点特征 X 逐步"混合"邻居信息，得到每个节点的嵌入 Z = GNN(X, A)。K 通常取 2–3 层（对应聚合 2–3 跳邻居）。
  2. 分类头（decoder）：对每个节点的嵌入做线性变换 + softmax，输出各类别概率：
Z = GNN(X, A)                       # 节点嵌入，Z ∈ R^(N × H)
P = softmax( Z · W_cls + b )        # 每个节点一个类别分布

损失函数用交叉熵，但只在有标签的训练节点上计算：

L = - Σ_{v ∈ V_train} log P_v[ y_v ]

这是半监督的精髓：只有训练节点的标签参与反向传播，但梯度会沿着图结构传遍所有节点（因为它们的嵌入参与了卷积）。

3. 为什么 2–3 层就够：过平滑问题#

一个关键直觉问题：既然"聚合邻居"能带来信息，是不是层数越深越好？答案是否。堆叠过深会引发过平滑（over-smoothing）——每多一层，每个节点都会"看到"更大的邻居范围，最终所有节点的嵌入趋于相同，节点间的差异被抹平，分类器无从下手。

可以这样理解：一层卷积相当于对特征做一次"局部平滑/低通滤波"，层数越多、平滑半径越大，最后逼近"整图一个均值"。因此节点分类通常只用 2–3 层，靠加宽隐藏维而非加深来提升容量。

4. 几个决定成败的工程细节#

  • 自环（self-loop）：聚合邻居时要把节点自己也算进去（Ã = A + I），否则每个节点会"丢掉自己的特征"，层数一多信息就稀释了。PyG 的 GCNConv 默认 add_self_loops=True。
  • 归一化：不同节点的度差异巨大，度数大的节点聚合后范数偏大，需用对称归一化 D^-1/2 Ã D^-1/2 平衡（GCN 已内置）。
  • Dropout：节点分类里对特征做 dropout（而非对边），能显著缓解小训练集上的过拟合。
  • 早停 + 验证集选模型：训练集很小、噪音大，一定要用验证集监控、选最优 checkpoint，避免"训到底反而变差"。

5. 标签传播与"冷启动"#

顺带澄清一个概念误区：半监督节点分类之所以能在"只标了极少数节点"时依然有效，靠的是特征平滑假设——相邻节点倾向同类，卷积让相邻节点的嵌入彼此靠近，于是标签通过"边"从标注节点流向未标注节点。这与经典的标签传播（label propagation）思想一脉相承，但 GNN 额外利用了节点特征，能处理"特征与结构不完全一致"的图，也在新节点到来时比纯标签传播更有泛化能力。

二、可运行示例#

示例：两层 GCN 在 Cora 上做节点分类（完整训练流程）

import torch
import torch.nn.functional as F
from torch_geometric.nn import GCNConv
from torch_geometric.datasets import Planetoid

# 1. 数据：Cora 已内置标准的 训练/验证/测试 掩码
dataset = Planetoid(root='./data/Cora', name='Cora')
data = dataset[0]
print(f'节点数 {data.num_nodes} | 特征维 {dataset.num_features} | 类别数 {dataset.num_classes}')

# 2. 模型：编码器（2 层 GCN）+ 分类头（log_softmax）
class GCN(torch.nn.Module):
    def __init__(self, in_ch, hidden_ch, out_ch):
        super().__init__()
        self.conv1 = GCNConv(in_ch, hidden_ch)   # 默认带自环 + 对称归一化
        self.conv2 = GCNConv(hidden_ch, out_ch)

    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)           # 每个节点输出类别对数概率

model = GCN(dataset.num_features, 16, dataset.num_classes)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

# 3. 训练：损失只在 train_mask 上计算（半监督）
def train():
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()
    return loss.item()

# 4. 评估：三个掩码各自的准确率
@torch.no_grad()
def evaluate():
    model.eval()
    pred = model(data.x, data.edge_index).argmax(dim=1)
    return [(pred[m] == data.y[m]).float().mean().item()
            for m in [data.train_mask, data.val_mask, data.test_mask]]

best_val, best_test = 0.0, 0.0
for epoch in range(200):
    loss = train()
    tr, va, te = evaluate()
    if va > best_val:               # 用验证集挑最优，测试集只报告一次
        best_val, best_test = va, te
    if epoch % 20 == 0:
        print(f'Epoch {epoch:03d} | Loss {loss:.4f} | '
              f'Train {tr:.4f} | Val {va:.4f} | Test {te:.4f}')

print(f'最终：Best Val {best_val:.4f} | 对应 Test {best_test:.4f}')

输出里要注意一个现象：训练集准确率常常能到 1.0（因为 Cora 每类只有 20 个训练节点，模型很快记住它们），真正衡量泛化的是验证集和测试集。最终测试集准确率约 0.81，是节点分类的经典基准线。

练习变体：把 GCNConv 换成 SAGEConv 或 GATConv（第 4 章学过），只改两行 import 和构造，观察准确率变化，体会"任务框架不变、只换编码器"的模块化设计。

三、练习#

  1. 半监督损失：解释为什么损失只在训练节点上计算，但梯度却能"传遍全图"？从计算图（autograd）的角度说明。
  2. 层数实验：把卷积层数从 2 加到 4、6、8，观察测试准确率随层数的变化，并结合"过平滑"解释曲线形状。
  3. 自环的影响：将 GCNConv 的 add_self_loops 设为 False，重跑并对比，说明自环为什么重要。
  4. 特征 vs 结构：把 data.x 换成随机噪声（保持结构不变）再训练，准确率如何？反过来，把 edge_index 换成随机边（保持特征不变）呢？这能帮你判断该任务更依赖特征还是结构。
  5. 前瞻：本课预测的是"每个节点属于哪一类"。如果任务是预测"整张图属于哪一类"（如分子是否有毒），节点嵌入该如何"浓缩"成图表示？带着这个问题进入下一课。
