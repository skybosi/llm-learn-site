时域到频域：STFT、窗长/帧移的时频分辨率权衡#

这一节要解决什么#

上一节把声音变成了一串采样点。但没有任何一个现代声学模型直接吃这串点——它先被切成一帧一帧，每帧做一次 DFT，得到一张"时间 × 频率"的二维图（幅度谱）。这一步叫短时傅里叶变换（STFT）。

STFT 有两个自由参数：窗长 N（等价于时长 Tw​=N/fs​）与帧移 H（等价于帧率 fs​/H）。教科书写着"25 ms 窗、10 ms 帧移"，于是这两个数被当成常数抄了三十年。但它们是一个无解的不等式在两端的妥协点，本节要把它算出来。

具体地说，本节要证明并量化三件事：

  1. 窗长买的是频率分辨率，付的是时间模糊，二者的乘积有下界：σt​σf​≥4π1​。本节的实测是：高斯窗恰好压在下界上（比值 1.000），Hann 窗只差 2.6%（1.026），而矩形窗的乘积是下界的 21.753 倍（表 2）。这是"为什么用 Hann 而不用矩形"的量化答案。
  2. 帧移与分辨率无关，它只决定时间采样密度、计算量与延迟。所以"窗长"和"帧移"是两个可以独立优化的参数，把它们捆在一起（例如固定 H=N/2）会让系统失去一整个自由度。
  3. 对语音而言，存在一个"无解区间"：要分辨 F0​=80 Hz 的谐波结构，Hann 窗的零点间主瓣 4fs​/N 必须小于 80 Hz，即 N≥800（50 ms）；而要分辨相邻音素（时长约 60 ms），窗长不能超过半个音素，即 N≤480（30 ms）。两个要求没有交集。这不是本节算错了，而是 STFT 作为一个固定分辨率变换的根本限制——它也正是后面几章所有"多分辨率前端""可学习前端"存在的原因。

 STFT 的分辨率是一个点，不是一条曲线；所有参数选择都是在把误差挪到哪个任务上 ​

⚠️ 本节代码中的信号都是合成的，代码只用标准库（自带 radix-2 FFT）。所有数字都可以重跑并得到逐字节相同的输出。

一、为什么要分帧：从非平稳到短时平稳#

1.1 语音在两个尺度上同时变化#

语音信号的功率谱随时间变化。变化有两个尺度：

  • 快尺度：基频周期 T0​=1/F0​，对 F0​∈[80,400] Hz 是 2.5–12.5 ms。这是周期性结构，不是"谱内容"的变化；
  • 慢尺度：声道形状（共振峰位置）的变化，与音素时长同量级。一个音素持续 50–200 ms，其中"目标段"（共振峰稳定）约占一半，其余是过渡段。

STFT 的核心假设是短时平稳：在窗长 Tw​ 内，可以把信号当作平稳随机过程，从而"这一帧的频谱"有意义。这个假设成立的条件是

Tw​ ≪ 声道形状的时间尺度 ∼30 ms ⟹ Tw​≲30 ms

代入 fs​=16 kHz，25 ms 对应 N=400 点。这就是 25 ms 的第一重根据：它由"帧内平稳"这个假设决定，与频率分辨率无关。

对第 m 帧：

X(m,k)=n=0∑N−1​x[n+mH]w[n]e−j2πkn/N,k=0,1,…,N−1

二、窗与泄漏：为什么必须加窗#

2.1 泄漏的来历#

矩形截断等价于乘一个矩形窗。矩形窗的 DTFT 是 Dirichlet 核

Wrect​(f)=sin(πf/fs​)sin(πNf/fs​)​

它有一个宽 2 bin 的主瓣和只衰减到 −13.3 dB 的第一旁瓣。一个不在 bin 中心的正弦，其能量会沿这些旁瓣泄漏到整个频带。这就是泄漏。

换窗就是换这个核的形状。四个标准窗的闭式傅里叶级数是（D 为 Dirichlet 核，Δ=1 bin）：

Wrect​WHann​WHamming​WBlackman​​=D(f)=0.5D(f)−0.25[D(f−Δ)+D(f+Δ)]=0.54D(f)−0.23[D(f−Δ)+D(f+Δ)]=0.42D(f)−0.25[D(f−Δ)+D(f+Δ)]+0.04[D(f−2Δ)+D(f+2Δ)]​

Wrect​WHann​WHamming​WBlackman​​=D(f)=0.5D(f)−0.25[D(f−Δ)+D(f+Δ)]=0.54D(f)−0.23[D(f−Δ)+D(f+Δ)]=0.42D(f)−0.25[D(f−Δ)+D(f+Δ)]+0.04[D(f−2Δ)+D(f+2Δ)]​

于是全部指标都能从系数读出来——旁瓣被"用相邻 bin 的副本对消"，系数越负、参与对消的项越多，主瓣越宽、旁瓣越低。表 1 是实测：

  • ENBW（等效噪声带宽）：N∑w2/(∑w)2。矩形 1.000、Hann 1.500、Hamming 1.363、Blackman 1.727。它衡量"这一帧的谱被平均到多宽的等效白噪声带里"——ENBW 越小，谱估计的方差越大。
  • -3 dB 主瓣宽（单位：bin）：矩形 0.91、Hann 1.47、Hamming 1.31、Blackman 1.66。这是实际可分辨频率间隔的下界量级。
  • 零点间主瓣宽：2/4/4/6 bin。注意全部是整数——这正是上面 Dirichlet 级数对消的直接推论：k 项和给出 2k bin 的零点间距。
  • 第一旁瓣：−13.3/−31.5/−44.0/−58.1 dB。每多两项对消，旁瓣再低 12–16 dB。
  • 旁瓣滚降：矩形与 Hamming 约 −6 dB/oct（衰减慢），Hann 与 Blackman 约 −18 dB/oct（衰减快）。滚降比第一旁瓣更重要：一个 −44 dB 但只按 −6 dB/oct 衰减的窗，在 20 bin 之外反而不如 Hann。

实测旁瓣必须用闭式 Dirichlet 核而不是 FFT 网格。 代码里两者都做了：主瓣指标用 32768 点细化网格测，旁瓣用闭式核算。原因是 FFT 在深零点附近的相对误差约 10−15，Blackman 的零点附近幅度低到 −300 dB，用 FFT 网格会量出 −96.5 dB 这样的假旁瓣（正确的第一旁瓣是 −58.1 dB）。这是一条通用的数值经验：测量动态范围超过 150 dB 的量时，先问计算路径本身有没有 10−16 的量级抵消。

2.2 扇形损失：窗的第二个代价#

加窗还有一个副作用：幅度估计有偏。用一个不在 bin 中心的正弦（落在 bin+0.5）估计幅度，得到的值比真值低，这个损失叫扇形损失（scalloping loss）。理论值（只采样 N 点 DFT 栅格）：

矩形 −3.92 dB,Hann −1.42 dB,Hamming −1.78 dB,Blackman −1.10 dB

三、时频不确定性：乘积有下界#

3.1 不等式#

把窗 w(t) 看成能量归一的信号，定义时间与频率的二阶矩展宽

Δt2=∫∣w(t)∣2dt∫t2∣w(t)∣2dt​,Δf2=∫∣W(f)∣2df∫f2∣W(f)∣2df​

则（f 以 Hz 计）

Δt⋅Δf ≥ 4π1​≈0.07958

等号当且仅当 w 是高斯窗。这不是"技术不够好"，是傅里叶变换的数学性质：时域越集中，频域越分散，反之亦然。

这是一个可以直接验证的等式。表 2 用三种不同宽度的高斯窗和 Hann/矩形窗实测：

3.2 把不等式翻译成窗长#

对 Win 长 N、采样率 fs​，代码实测（表 3）给出：

Δf−3dB​≈N1.47fs​​,Δtblur​≈fs​N​ ⟹ Δt⋅Δf≈1.47

1.47 就是 Hann 的 -3 dB 主瓣宽（bin）。也就是说："窗长越长频率越准、时间越糊"这句话可以写成一个常数乘积 1.47——它是 Hann 窗在 STFT 里的"分辨率格"。

四、窗长与帧移各自决定什么#

4.1 窗长：两条互相冲突的要求#

要求 A（分辨谐波）：要看到语音的谐波结构（音高、清浊、韵律），相邻谐波间隔为 F0​，必须让主瓣零点间距小于 F0​：

N4fs​​<F0min​ ⟹ N>F0min​4fs​​=804×16000​=800 点=50 ms

要求 B（分辨音素）：要让一帧不被两个音素同时占据（否则帧内平稳假设破裂，谱被平均），需要窗长不超过半个音素：

Tw​≤2Tphone​​ ⟹ N≤216000×0.06​=480 点=30 ms

两个要求没有交集。 这是本节最重要的一条定量结论。它的后果不是"选哪个"，而是：

  • 任何单一的固定窗长 STFT 都不可能同时做好谐波分析与音素分析；
  • 所以 ASR 的标准做法是 25 ms 窗（偏向要求 B），把基频/音高交给一个独立的、用长窗或自相关的模块（这就是为什么 Kaldi 时代要单独有 pitch 特征，也是为什么今天端到端模型在韵律相关任务上仍然要额外监督）；
  • 反过来，音乐分析（需要分辨半音）会取 46–186 ms 的长窗，因为它不需要分辨音素。

4.2 帧移：与分辨率无关的第二个旋钮#

帧移 H 决定帧率

fr​=Hfs​​

它不改变单帧的频率分辨率（那由 N 决定），只改变：

  • 时间采样密度：帧率越高，时间包络（起止、爆破、韵律）越细；
  • 计算量：每秒帧数 ∝1/H；
  • 算法延迟：最小延迟至少是 N/fs​（必须填满一个窗才能出第一帧）；
  • 输出的数据量：帧率 × 频率点数。

所以 N 与 H 应该分开选。常见的 H=N/4（75% 重叠）或 H=N/2.5（60% 重叠）只是习惯：25 ms/10 ms 是 H=N/2.5。

4.3 重叠与完全重建：COLA 与 WOLA#

如果要在频域做修改后再变回波形（降噪、声码器、语音增强都要做），必须知道重叠相加的归一化条件。定义两个和：

Sw​[n]=m∑​w[n−mH],Sw2​[n]=m∑​w2[n−mH]

  • 分析加窗、合成不加窗时要 Sw​ 为常数（COLA，constant overlap-add）；
  • 分析与合成都加窗时要 Sw2​ 为常数（WOLA 条件）。

五、两条分辨率边界的实测#

上面的不等式是理论。表 4 与表 5 用两个实验直接量出来。

5.1 频率侧：双音分辨#

七、取舍与边界#

(1) 分辨率不是"越高越好"，它是一个二维帕累托前沿。 由 ΔtΔf≥1/(4π)，"同时提高两者"在数学上被禁止。选择窗长就是把误差分配到"频率侧"或"时间侧"。

(2) 固定分辨率是 STFT 的结构性限制，不是参数没调好。 第 4.1 节证明了对 F0min​=80 Hz 与 60 ms 音素这两个约束没有交集。要绕过它只有三条路：多分辨率并行（多个窗长同时算）、把分辨率交给可学习前端、或者换成小波/常数 Q 变换。三条路都在后面的章节出现。

(3) 帧移可以自由优化，但延迟由窗长锁定。 流式系统里"降低延迟"只能靠减小 N，而减小 N 会牺牲频率分辨率。25 ms 窗对应的 25 ms 算法延迟是很多实时应用的硬门槛（这也是为什么端到端流式模型普遍把前端卷积的感受野做到 20–40 ms 这个量级）。

(4) 加窗引入的幅度偏置（扇形损失）与泄漏是一对权衡。 旁瓣越低（Blackman −58.1 dB）主瓣越宽（1.66 bin），时间模糊也越大。−44 dB 的 Hamming 与 −31.5 dB 的 Hann 之间只差一代；再往下压旁瓣的代价（主瓣 6 bin 的 Blackman）通常不值得，除非下游对泄漏极敏感。

(5) 短窗的频率估计是有偏的，不只是方差大。 当窗长小于谐波间隔时，相邻谐波的旁瓣会互相叠加，峰位置会被拉偏，不是简单的"精度差"。所以用短窗做基频估计得到的不是"噪声大的真值"，而是系统偏差——这比随机误差更难处理。

(6) 相位不是可以随便丢的。 STFT 的相位在"重建波形"这个目标下不可或缺。但在"只看谱包络"的任务里它确实可以被丢弃——这是第 3 节要量化的事（本节代码里也做了对照：幅度 + 相位完全重建得到 286.7 dB，相位置零只有 0.2 dB）。

(7) 边界：非平稳性本身有谱。 当窗长与调制频率可比时，STFT 会把"幅度调制"当成"频谱展宽"，二者在单帧里不可分。这就是调制谱（modulation spectrum）分析要单独做的原因，也是为什么语音增强里"帧内幅度变化"是一个专门的误差项。

代码#

下面这段脚本用纯标准库（自带 radix-2 FFT 与逆变换）算出本节的全部数字：窗的六项指标、时频不确定性实测、分辨率账、双音与突发两组分辨实验、扇形损失、COLA/WOLA 与完全重建、以及计算与延迟账。旁瓣指标用闭式 Dirichlet 核求，主瓣用 32768 点细化网格求——两条路径都用是因为 FFT 网格在深零点处被浮点误差淹没（见 2.1 节）。

"""
spk-ch1-l2  时域到频域：DFT / 窗 / STFT / 时频分辨率权衡
仅用标准库（自带 radix-2 FFT）。⚠️ 所有信号都是合成的。
"""
import math
import cmath

FS = 16000.0
TWO_PI = 2.0 * math.pi


# ----------------------------------------------------------------------
# 0. 迭代 radix-2 FFT
# ----------------------------------------------------------------------
def fft(a):
    n = len(a)
    assert n & (n - 1) == 0, "长度必须是 2 的幂"
    a = [complex(v) for v in a]
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j |= bit
        if i < j:
            a[i], a[j] = a[j], a[i]
    length = 2
    while length <= n:
        wl = cmath.exp(-2j * math.pi / length)
        half = length >> 1
        for i in range(0, n, length):
            w = 1 + 0j
            for k in range(i, i + half):
                u = a[k]
                v = a[k + half] * w
                a[k] = u + v
                a[k + half] = u - v
                w *= wl
        length <<= 1
    return a


def mag_spectrum(x, nfft):
    """补零到 nfft 后的幅度谱（只取前半，含直流）。"""
    pad = [0j] * nfft
    for i, v in enumerate(x):
        pad[i] = complex(v)
    spec = fft(pad)
    return [abs(spec[k]) for k in range(nfft // 2 + 1)]


# ----------------------------------------------------------------------
# 1. 窗函数
# ----------------------------------------------------------------------
def window(kind, n):
    w = []
    for i in range(n):
        if kind == "rect":
            v = 1.0
        elif kind == "hann":
            v = 0.5 - 0.5 * math.cos(TWO_PI * i / n)
        elif kind == "hamming":
            v = 0.54 - 0.46 * math.cos(TWO_PI * i / n)
        elif kind == "blackman":
            v = 0.42 - 0.5 * math.cos(TWO_PI * i / n) \
                + 0.08 * math.cos(2 * TWO_PI * i / n)
        else:
            raise ValueError(kind)
        w.append(v)
    return w


def gauss_window(n, sigma):
    return [math.exp(-0.5 * ((i - (n - 1) / 2.0) / sigma) ** 2) for i in range(n)]


def win_metrics(w, nfft):
    n = len(w)
    sw = sum(w)
    sw2 = sum(v * v for v in w)
    enbw = n * sw2 / (sw * sw)
    cg = sw / n
    m = mag_spectrum(w, nfft)
    peak = max(m)
    idx = m.index(peak)                      # 窗的 DTFT 主瓣在直流处
    scale = n / nfft                         # 把细化网格折回「N 点 DFT 的 bin」
    # -3 dB 主瓣宽（单边宽度 ×2）
    thr = peak / math.sqrt(2.0)
    hi = idx
    while hi < len(m) - 1 and m[hi] > thr:
        hi += 1
    w3 = 2.0 * (hi - idx) * scale
    # 主瓣零点到零点宽：从峰值向外走到数值零点，再折成最近的整数 bin
    gate = peak * 1e-6
    k = idx
    while k < len(m) - 2 and m[k + 1] < m[k] and m[k] > gate:
        k += 1
    null_k = k
    nullw = round(2.0 * (null_k - idx) * scale)
    return enbw, cg, w3, nullw


# 窗的闭式傅里叶级数：W(f) = sum_j a_j * D(f - j*fs/N), D 为 Dirichlet 核。
# 用闭式而非 FFT 网格来量旁瓣：FFT 网格在深零点附近被 1e-15 的相对误差淹没。
COEF = {"rect": {0: 1.0},
        "hann": {0: 0.5, 1: -0.25, -1: -0.25},
        "hamming": {0: 0.54, 1: -0.23, -1: -0.23},
        "blackman": {0: 0.42, 1: -0.25, -1: -0.25, 2: 0.04, -2: 0.04}}


def dirichlet(n, f):
    x = math.pi * f / FS
    s = math.sin(x)
    if abs(s) < 1e-12:
        return float(n)
    return abs(math.sin(n * x) / s)


def win_mag(kind, n, f):
    return abs(sum(a * dirichlet(n, f - j * FS / n)
                   for j, a in COEF[kind].items()))


def sidelobe_metrics(kind, n):
    """闭式求第一旁瓣电平与远旁瓣滚降（dB/oct）。"""
    w0 = win_mag(kind, n, 0.0)
    j0 = (len(COEF[kind]) + 1) // 2            # 主瓣第一零点（单位：bin）
    best = max(win_mag(kind, n, (j0 + t / 400.0) * FS / n)
               for t in range(1, 400))
    sl1 = 20.0 * math.log10(best / w0)
    pts = [((m + 0.5) * FS / n, win_mag(kind, n, (m + 0.5) * FS / n))
           for m in range(10, 60)]
    xs = [math.log2(f) for f, _ in pts]
    ys = [20.0 * math.log10(max(v, 1e-30)) for _, v in pts]
    mx, my = sum(xs) / len(xs), sum(ys) / len(ys)
    num = sum((a - mx) * (b - my) for a, b in zip(xs, ys))
    den = sum((a - mx) ** 2 for a in xs)
    return sl1, num / den

# 2. 时频不确定性：实测 sigma_t * sigma_f

def spreads(w):
    n = len(w)
    e = sum(v * v for v in w)
    c = sum(i * v * v for i, v in enumerate(w)) / e
    st2 = sum((i - c) ** 2 * v * v for i, v in enumerate(w)) / e / (FS ** 2)
    half = mag_spectrum(w, NFFT)
    df = FS / NFFT
    h = NFFT // 2
    # 双边功率谱：频率轴带上符号（负频段用 k-NFFT）
    pw = [v * v for v in half] + [half[NFFT - k] ** 2 for k in range(h + 1, NFFT)]
    fr = [k * df for k in range(h + 1)] + [(k - NFFT) * df
                                           for k in range(h + 1, NFFT)]
    e2 = sum(pw)
    c2 = sum(f * v for f, v in zip(fr, pw)) / e2
    sf2 = sum(((f - c2) ** 2) * v for f, v in zip(fr, pw)) / e2
    return math.sqrt(st2), math.sqrt(sf2)

def dip_depth(x, n, f_lo, f_hi):
    """补零细化后在 f_lo..f_hi 找两峰之间的极小，返回 (谷深 dB, 峰1, 峰2)。"""
    w = window("hann", n)
    seg = [x[i] * w[i] for i in range(n)]
    nfft = 16 * n
    m = mag_spectrum(seg, nfft)
    df = FS / nfft
    klo, khi = int(f_lo / df), int(f_hi / df)
    mid = (klo + khi) // 2
    p1 = max((k for k in range(klo, mid)), key=lambda k: m[k])
    p2 = max((k for k in range(mid, khi + 1)), key=lambda k: m[k])
    if p2 < p1:
        p1, p2 = p2, p1
    valley = min(m[k] for k in range(p1 + 1, p2))
    lower = min(m[p1], m[p2])
    return 20.0 * math.log10(max(valley, 1e-30) / lower), p1 * df, p2 * df

# 6. 泄漏与扇形损失

def amp_estimate_error(kind, n, offset, interp=False):
    """单位幅度正弦落在 bin+offset 上，只用 N 点 DFT 栅格值估计幅度，返回误差 dB。"""
    w = window(kind, n)
    sw = sum(w)
    k0 = 32
    f0 = (k0 + offset) * FS / n
    x = [math.sin(TWO_PI * f0 * i / FS) * w[i] for i in range(n)]
    m = mag_spectrum(x, nfft=n)              # 关键：不补零，采样在 N 点栅格上
    k = m.index(max(m))
    if interp and 0 < k < len(m) - 1:
        a = 20.0 * math.log10(max(m[k - 1], 1e-30))
        b = 20.0 * math.log10(max(m[k], 1e-30))
        c = 20.0 * math.log10(max(m[k + 1], 1e-30))
        d = 0.5 * (a - c) / (a - 2.0 * b + c)
        pk = 10.0 ** ((b - 0.25 * (a - c) * d) / 20.0)
    else:
        pk = m[k]
    return 20.0 * math.log10(max(2.0 * pk / sw, 1e-30))


def worst_residual(kind, n):
    worst, at = 0.0, 0.0
    for i in range(1, 20):
        off = i * 0.05
        e = amp_estimate_error(kind, n, off, interp=True)
        if abs(e) > abs(worst):
            worst, at = e, off
    return worst, at

def ifft(a):
    n = len(a)
    return [v.conjugate() / n for v in fft([v.conjugate() for v in a])]


def part_7():
    print()
    print("=" * 82)
    print("表 7  COLA：sum_m w[n-mH] 与 sum_m w^2[n-mH] 的常数性，以及未修改时的重建 SNR")

         + 0.5 * math.sin(TWO_PI * 1310.0 * i / FS) for i in range(n_tot)]

        y2 = [0.0] * (n_tot + 2 * n)

        while pos + n <= n_tot:
            seg = ifft(fft([x[pos + i] * w[i] for i in range(n)]))

                a2[pos + i] += w[i] * w[i]
                y1[pos + i] += seg[i].real                 # 合成不加窗

        m1 = sum(i1) / len(i1)
        m2 = sum(i2) / len(i2)
        e1 = sum((x[i] - y1[i] / m1) ** 2 for i in range(lo, hi))
        e2 = sum((x[i] - y2[i] / m2) ** 2 for i in range(lo, hi))

小结#

  • STFT 有三个独立要素：分帧（时间采样）、加窗（控制泄漏）、DFT（频点采样）。帧移不改变单帧的频率分辨率，只改变时间采样密度、计算量与延迟；延迟由窗长锁定。
  • 窗的六项指标都能从它的 Dirichlet 级数系数推出来：Hann 的 -3 dB 主瓣 1.47 bin、零点间 4 bin、第一旁瓣 −31.5 dB、滚降约 −18 dB/oct、ENBW 1.500；矩形窗对应 0.91/2/−13.3/−6/1.000。
  • 时频不确定性 σt​σf​≥1/(4π)=0.07958 实测：高斯窗恰好取等号（1.000），Hann 只差 2.6%，矩形窗是下界的 21.75 倍。Hann 的"STFT 分辨率格"是 ΔtΔf≈1.47。
  • 扇形损失实测：Hann −1.42 dB、Hamming −1.74 dB、Blackman −1.10 dB、矩形 −3.86 dB；三点抛物线插值后 Hann/Hamming/Blackman 残差在 ±0.5 dB 内，矩形仍有 −2.73 dB。
  • 对 F0min​=80 Hz 与 60 ms 音素，N 的两个约束没有交集（N≥800 与 N≤480）。25 ms/10 ms 是"帧内平稳 + 音素可分"这一侧的妥协点，而 25 ms 窗的 Hann 主瓣 58.8 Hz 大于 F0min​，因此它看不到低音基频的谐波结构。
  • COLA 与 WOLA 不等价：Hann/H=N/2 满足 Sw​≡1 但 Sw2​ 在 0.5–1.0 波动，因此"分析与合成都加窗"时会烂掉（12.6 dB）；H=N/4 时两者都成立（289 dB）。
