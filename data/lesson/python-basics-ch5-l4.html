集合 set 与结构选择#

一、概念讲解#

集合（set）也是一种容器，它最大的特点有两个：元素不重复，以及元素没有顺序。

可以把集合想象成一个装了不同颜色球的袋子：球没有先后顺序，而且同一种球只会出现一次。这个"自动去重"的特性，让它特别适合处理"有哪些不同元素"这一类问题。

1. 创建集合#

集合用一对花括号 {} 表示。注意：空的花括号 {} 创建的是字典，不是集合，创建空集合要用 set()：

fruits = {"苹果", "香蕉", "橙子"}
empty_set = set()        # 空集合
not_a_set = {}           # 这是空字典！

print(type(empty_set))   # <class 'set'>
print(type(not_a_set))   # <class 'dict'>

如果创建时写了重复元素，Python 会自动去掉多余的部分：

nums = {1, 2, 2, 3, 3, 3}
print(nums)              # {1, 2, 3}

2. 增加与删除#

s = {1, 2, 3}

s.add(4)                 # 添加一个元素
print(s)                 # {1, 2, 3, 4}

s.remove(2)              # 删除指定元素（不存在会报错）
s.discard(99)            # 删除指定元素（不存在也不报错）
print(s)                 # {1, 3, 4}

3. 集合运算（交、并、差）#

集合最强大的地方，是支持数学里集合的运算，非常适合做"去重""求共同点""找不同"：

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)   # 并集：{1, 2, 3, 4, 5, 6}
print(a & b)   # 交集：{3, 4}
print(a - b)   # 差集：{1, 2}（在 a 里但不在 b 里）
print(a ^ b)   # 对称差：{1, 2, 5, 6}（只在一个集合里的元素）

4. 经典应用：列表去重#

nums = [1, 2, 2, 3, 4, 4, 4, 5]
unique = list(set(nums))   # 转成集合去重，再转回列表
print(unique)              # [1, 2, 3, 4, 5]（顺序不保证）

提醒：因为集合没有顺序，去重后的顺序可能和原来不一样。如果顺序很重要，就要换别的方法。

二、四种结构如何选择#

学完列表、元组、字典、集合后，很多初学者会困惑：到底该用哪个？可以按下面的思路快速判断：

需求 推荐结构 理由
需要顺序，且内容会变 列表 list 有序、可变，最灵活
需要顺序，但内容固定不变 元组 tuple 不可变，更安全，还能当字典键
需要用"名字"查"值" 字典 dict 键值对，查找快速
只关心"有哪些不同的元素"、去重 集合 set 自动去重，支持集合运算

可运行代码示例#

下面的例子综合使用了四种结构，模拟一个简单场景：统计一段话里出现了哪些不同的单词。

# ---- 场景：统计一篇文章里出现了哪些不同的单词 ----
text = "apple banana apple orange banana apple pear"

# 1. 先用列表存放所有单词（有重复）
words = text.split()
print("原始单词列表：", words)

# 2. 用集合去重，得到"出现了哪些不同的单词"
unique_words = set(words)
print("不同的单词（集合）：", unique_words)

# 3. 用字典统计每个单词出现的次数
word_count = {}
for w in words:
    word_count[w] = word_count.get(w, 0) + 1
print("词频（字典）：", word_count)

# 4. 用元组保存"只读"的固定配置
stop_words = ("a", "an", "the")   # 停用词，固定不变
print("停用词（元组）：", stop_words)

# 5. 集合运算：找出"出现次数超过 1 次的单词"
frequent = {w for w in words if word_count[w] > 1}
print("高频单词（集合）：", frequent)
