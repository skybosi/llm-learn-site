文生图实战#

上一课我们把项目规划好了，环境也通过了 smoke test。本课时正式开跑：用 Stable Diffusion 完成一次有质量的文生图。我们会把第三章学的扩散理论（潜空间、去噪、条件引导、分类器无关引导 CFG）逐一落到代码参数上，让你看清"理论"和"按钮"之间的对应关系。

一、概念讲解#

1. 文生图全流程回顾（一句话版本）#

Stable Diffusion 做文生图，内部是四条链路的接力：

  1. 文本编码：prompt 经 CLIP 文本编码器变成条件向量（第四章的对齐成果在这里直接派上用场）。
  2. 正向采样：从随机噪声 z_T 开始，逐步去噪，得到潜空间里的"干净图像" z_0。每一步，UNet 都预测噪声，而文本条件通过交叉注意力注入，引导去噪方向。
  3. CFG 引导：guidance_scale 控制"无条件去噪"与"有条件去噪"的加权差，值越大越贴合 prompt、但越容易过饱和。
  4. 解码：潜变量 z_0 交给 VAE 解码器，还原成像素图。

2. 关键参数与它们的"理论位置"#

  • num_inference_steps（去噪步数）：对应扩散的离散化步数。默认调度器一般 50 步；25~30 步往往已接近收敛，再多则收益递减、耗时线性增加。
  • guidance_scale（CFG 强度）：默认 7.5。太低 → 图不贴合文字；太高 → 颜色过艳、细节过锐、出现伪影。这是最值得反复调的一个旋钮。
  • generator + seed（随机种子）：噪声 z_T 的来源。固定 seed 可完全复现同一张图，这是调试和 A/B 对比的前提。
  • negative_prompt（负向提示）：告诉模型"不要什么"，例如 "low quality, blurry, deformed"，能有效压掉常见瑕疵。
  • height / width：输出分辨率，须是 8 的倍数（与 VAE 的 8 倍下采样对齐）。

3. 显存不足时的三板斧#

  • fp16：模型用半精度加载，显存几乎减半，精度损失可忽略。
  • attention slicing：把注意力计算切成小块分步算，用时间换显存。
  • CPU offload：把当前不用的模块（如 VAE）暂时放到内存，进一步省显存，代价是变慢。

三者可叠加，按"先 fp16，不够再 slicing，还不够再 offload"的顺序逐级加码。

二、可运行代码示例#

示例 1：一次完整的、可复现的文生图#

from diffusers import StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
)
pipe = pipe.to("cuda")

prompt = "a cute corgi wearing a red scarf, cartoon style, high quality"
negative_prompt = "low quality, blurry, deformed, watermark"

# 固定种子: 同一个 seed 每次生成完全相同的图
seed = 42
generator = torch.Generator(device="cuda").manual_seed(seed)

image = pipe(
    prompt=prompt,
    negative_prompt=negative_prompt,
    num_inference_steps=30,      # 去噪步数
    guidance_scale=7.5,          # CFG 强度
    height=512,
    width=512,
    generator=generator,
).images[0]

image.save(f"corgi_seed{seed}.png")
print(f"已生成 corgi_seed{seed}.png")

把 seed 换成 43 再跑一次，你会得到一张完全不同的图；换回 42，又能逐像素复现刚才那张——这个性质是后续所有对比实验的基础。

示例 2：参数扫描 + 批量生成#

一次把不同 CFG 值都试一遍，直观感受"这个旋钮"的影响。

from diffusers import StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
).to("cuda")

prompt = "a glass of orange juice on a wooden table"
seed = 7

for cfg in [3.0, 7.5, 12.0, 20.0]:
    generator = torch.Generator(device="cuda").manual_seed(seed)  # 同 seed, 只变 CFG
    img = pipe(
        prompt=prompt,
        num_inference_steps=30,
        guidance_scale=cfg,
        generator=generator,
    ).images[0]
    img.save(f"juice_cfg{cfg}.png")
    print(f"guidance_scale={cfg} 完成")

把四张图并排看：CFG 从小到大，你会看到图像从"松散、贴合度一般"逐步变到"贴合文字"，再到"过饱和、发灰发艳"。找到你项目里最舒服的那个值，就是调参的意义。

示例 3：显存优化（fp16 + attention slicing + CPU offload）#

from diffusers import StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
)

# 三板斧: 依次开启
pipe.enable_attention_slicing()   # 切片注意力, 省显存
pipe.enable_model_cpu_offload()   # 不用的模块放到 CPU, 进一步省显存
# 注意: enable_model_cpu_offload 会自动处理设备放置, 无需再 .to("cuda")

image = pipe(
    "a lighthouse at sunset, oil painting style",
    num_inference_steps=25,
    guidance_scale=7.5,
).images[0]
image.save("lighthouse.png")
print("已生成 lighthouse.png")

enable_model_cpu_offload 后不要再手动 .to("cuda")，否则会破坏它的自动显存调度。这套组合能让 SD v1.5 在 4 GB 左右的显卡上也能跑起来。

三、练习#

  1. 参数-理论对应：把 num_inference_steps、guidance_scale、generator/seed、negative_prompt 四个参数，分别对应到扩散流程的哪个环节（加噪/去噪、CFG、噪声来源、条件方向），写一张对照表。
  2. 动手实验：固定 seed，把 guidance_scale 依次设为 1.0、7.5、20.0 各生成一张，描述图像贴合度与画质的变化，并解释 CFG=1.0 时模型在做什么。
  3. 动手实验：保持所有参数不变，只把 num_inference_steps 从 10 逐步加到 50，找出你观察到的"收益递减点"。
  4. 思考题：为什么输出分辨率必须是 8 的倍数？结合 VAE 的 8 倍下采样解释；如果硬要输出 500×500 会怎样？
