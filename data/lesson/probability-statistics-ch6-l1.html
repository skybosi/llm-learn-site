抽样与样本统计量#

前面几章我们默认"已经知道总体分布"。但现实中，我们几乎永远看不到"全部数据"——只能抽取一个样本，再用样本去推断总体。这一课建立"从样本到总体"的第一块基石：样本统计量、无偏估计，以及统计推断的"发动机"——中心极限定理。

一、概念讲解#

1. 总体与样本#

  • 总体（population）：我们真正关心、但通常无法全部观测的对象全体。比如"全国所有人的身高"。
  • 样本（sample）：从总体中抽出来的一小部分观测值。比如"随机调查了 200 个人的身高"。

之所以要抽样，是因为总体往往太大、太贵或根本无法枚举。我们的目标是：用样本去推断总体的特征，这门手艺就叫统计推断。

2. 样本统计量：给样本"总结"一个数#

拿到样本后，我们通常先算几个概括性数字，这些由样本计算出的量叫样本统计量。最常用的两个：

  • 样本均值：x̄ = (1/n) · Σ xᵢ，用来估计总体均值 μ；
  • 样本方差：s² = (1/(n−1)) · Σ (xᵢ − x̄)²，用来估计总体方差 σ²。

注意样本方差的分母是 n − 1，而不是 n。原因在于：我们用 x̄ 代替了未知的 μ，这个"代入"会略微低估数据的离散程度；除以 n − 1 恰好能把这种偏差"补偿"回来，使 s² 成为 σ² 的无偏估计（即多次抽样的 s² 的平均值正好等于 σ²）。

3. 抽样分布与标准误#

统计量本身也是随机变量——换一批样本，算出的 x̄ 就不一样。统计量（比如样本均值）这个随机变量的分布，叫抽样分布。

样本均值的抽样分布有两个关键结论：

  • 它的期望等于总体均值：E[x̄] = μ；
  • 它的标准差叫标准误（standard error）：SE = σ / √n。

SE 告诉我们"样本均值围绕真值波动的幅度"。注意：n 越大，SE 越小，而且是以 √n 的速度缩小——想误差减半，样本量要翻 4 倍。

4. 中心极限定理（CLT）：统计推断的基石#

中心极限定理说的是：无论总体本身是什么形状（只要方差有限），当样本量 n 足够大时，样本均值 x̄ 的抽样分布会近似服从正态分布，且均值为 μ、标准差为 σ/√n。

哪怕总体是严重偏斜的（比如指数分布），只要抽样的样本足够多，这些样本的"平均值"分布仍然会漂亮地趋近钟形。这一结论至关重要：它让我们可以用正态分布的性质去做后面的假设检验和置信区间，而不必知道总体到底是什么分布。

5. 在机器学习中的位置#

  • mini-batch 训练：每次梯度下降只用一个小批量（样本），其梯度是"全体梯度"的一个带噪声估计，噪声幅度同样随批量增大按 √n 规律下降；
  • 模型评估：测试集上的准确率是一个样本统计量，它围绕"真实泛化性能"波动，SE 决定了评估结果的可信度；
  • 数据划分：训练/验证/测试集的随机性，本质上就是抽样，理解抽样分布才能判断"不同次运行的结果差异是否显著"。

二、可运行示例#

下面的代码做两件事：验证样本方差的 n−1 无偏性，以及演示中心极限定理。

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(3)

# ---- 1. 验证 n-1 无偏性：反复抽样，看哪种方差的平均值更接近 σ² ----
mu, sigma = 50.0, 8.0        # 总体 N(50, 8)
n, n_rounds = 10, 20000      # 每次抽 10 个，共抽 20000 轮

var_n = np.empty(n_rounds)      # 除以 n 的方差
var_nm1 = np.empty(n_rounds)    # 除以 n-1 的方差
for i in range(n_rounds):
    s = np.random.normal(mu, sigma, n)
    var_n[i] = ((s - s.mean()) ** 2).sum() / n
    var_nm1[i] = ((s - s.mean()) ** 2).sum() / (n - 1)

print("真实 σ² =", sigma ** 2)
print("除以 n   的方差平均值：", var_n.mean(), "（有偏，偏小）")
print("除以 n-1 的方差平均值：", var_nm1.mean(), "（无偏，接近 σ²）")

# ---- 2. 中心极限定理：从严重偏斜的指数分布抽样 ----
lam = 1.0                      # 指数分布 Exp(1)，均值 1，非常右偏
sample_size = 40               # 每次抽样 40 个
n_means = 10000                # 重复 10000 次
means = np.array([
    np.random.exponential(scale=1 / lam, size=sample_size).mean()
    for _ in range(n_means)
])

print("样本均值的均值：", means.mean(), "（理论值 = 总体均值 =", 1 / lam, "）")
print("样本均值的标准差：", means.std(),
      "（理论值 SE = σ/√n =", (1 / lam) / np.sqrt(sample_size), "）")

# 画样本均值的直方图，叠加理论正态曲线
plt.hist(means, bins=50, density=True, alpha=0.6, label="样本均值直方图")
xs = np.linspace(means.min(), means.max(), 200)
from scipy.stats import norm
plt.plot(xs, norm.pdf(xs, loc=1 / lam, scale=(1 / lam) / np.sqrt(sample_size)),
         "r-", lw=2, label="理论正态曲线")
plt.xlabel("样本均值")
plt.ylabel("概率密度")
plt.title("偏斜总体下，样本均值仍接近正态分布（CLT）")
plt.legend()
plt.show()

预期输出（部分）：

真实 σ² = 64.0
除以 n   的方差平均值： 57.147 （有偏，偏小）
除以 n-1 的方差平均值： 63.496 （无偏，接近 σ²）
样本均值的均值： 1.00084 （理论值 = 总体均值 = 1.0 ）
样本均值的标准差： 0.158467 （理论值 SE = σ/√n = 0.158114 ）

要点：除以 n 的方差系统性偏小（约 57.1 < 64），除以 n−1 后接近真值 64；即便总体是指数分布这样严重右偏的分布，样本均值的直方图仍然和正态曲线贴合得很好——CLT 名不虚传。

三、练习#

  1. 计算：总体标准差 σ = 10，抽取 n = 100 的样本。样本均值的标准误 SE 是多少？若想让 SE 减半，样本量要变成多少？
  2. 改参数：把上面 CLT 代码里的 sample_size 改成 5 和 200 各跑一次，观察直方图与正态曲线的贴合程度如何随 n 变化。
  3. 思考：为什么用 n−1 而不是 n 做分母？尝试用"自由度"的角度解释：样本均值 x̄ 已经"消耗"了一个自由度。
