统计函数#

拿到一批数据，第一步永远是"摸清它的底细"：中心在哪里？散布有多广？有没有异常值？这就是描述性统计要回答的问题。NumPy 把常用的统计量都做成了现成函数，一条命令就能算出来，还能沿着指定的轴（axis）分别计算——这对多列特征组成的二维数据尤其有用。

这一课我们学习均值、中位数、方差、标准差、分位数等核心统计量，并掌握 axis 参数和 NaN 处理的技巧。

一、概念讲解#

1. 描述"中心"：均值 vs 中位数#

  • 均值（mean） np.mean：所有数据的算术平均，最常用，但对异常值敏感——只要混进一个极大的数，均值就会被明显拉偏。
  • 中位数（median） np.median：把数据排序后取正中间那个值，对异常值稳健。描述收入、房价这类"长尾分布"数据时，中位数往往比均值更能代表"典型水平"。

两者一起看，能迅速发现数据的偏斜程度：如果均值明显大于中位数，说明右侧有"大尾巴"（少数极端大值在拉高均值）。

2. 描述"散布"：方差与标准差#

  • 方差（var） np.var：每个数据点偏离均值的距离平方的平均值，衡量"波动多大"。
  • 标准差（std） np.std：方差的平方根，好处是和原始数据同单位，读起来直观。例如"身高的标准差是 8 厘米"。

标准差是衡量风险的经典指标：股票收益率的标准差大，说明波动大、风险高。

3. 分位数与最值#

  • 最小值/最大值 np.min / np.max，以及它们的位置 np.argmin / np.argmax。
  • 分位数（percentile/quantile） np.percentile(a, q)：把排序后的数据切成若干份。q=50 就是中位数，q=25/q=75 是下/上四分位数。四分位距（IQR = 75 分位 − 25 分位）是识别异常值的常用工具。

4. 沿轴计算与 NaN 处理#

二维数组（(样本数, 特征数)）是最常见的数据形态。axis 参数决定"往哪个方向压缩"：

  • axis=0：按列聚合，把每一列（一个特征）的所有样本汇总，结果是"每个特征的统计量"。
  • axis=1：按行聚合，汇总每一行（一条样本）内部，结果是"每条样本的统计量"。

真实数据常带缺失值 np.nan。普通函数遇到 NaN 会"传染"整个结果，此时要用 NaN 安全版本：np.nanmean、np.nanmedian、np.nanstd 等，它们会自动忽略 NaN。

二、可运行示例#

示例 1：基础统计量

import numpy as np

# 模拟 30 天里每天的网站访问量（千次）
visits = np.array([12, 15, 18, 14, 20, 22, 16, 19, 21, 17,
                   14, 13, 25, 18, 20, 19, 16, 15, 21, 22,
                   18, 17, 20, 19, 16, 18, 21, 20, 19, 17])

print("均值 =", np.mean(visits))
print("中位数 =", np.median(visits))
print("标准差 =", np.std(visits))
print("方差 =", np.var(visits))
print("最小值 =", np.min(visits), "，最大值 =", np.max(visits))
print("25/50/75 分位数 =", np.percentile(visits, [25, 50, 75]))

示例 2：异常值如何影响均值与中位数

import numpy as np

normal = np.array([10, 12, 11, 13, 12, 11, 10, 12])
outlier = np.append(normal, 1000)   # 混入一个极端值

print("正常数据的均值 =", np.mean(normal), "，中位数 =", np.median(normal))
print("混入异常值的均值 =", np.mean(outlier), "，中位数 =", np.median(outlier))
# 观察：均值被大幅拉高，而中位数几乎不动

示例 3：沿轴计算（二维特征数据）

import numpy as np

# 4 个样本、3 个特征：每一行是一条样本，每一列是一个特征
data = np.array([[1.0, 100.0, 5.0],
                 [2.0, 200.0, 7.0],
                 [3.0, 300.0, 9.0],
                 [4.0, 400.0, 11.0]])

print("每个特征的均值（axis=0）=", np.mean(data, axis=0))
print("每条样本的均值（axis=1）=", np.mean(data, axis=1))

# 找出每列最大值所在的行号
print("每列最大值的行号 =", np.argmax(data, axis=0))

示例 4：处理缺失值 NaN

import numpy as np

# 有一列存在缺失值（用 np.nan 表示）
scores = np.array([85.0, 90.0, np.nan, 78.0, 92.0])

# 普通 mean 会被 NaN "传染"
print("普通 mean =", np.mean(scores))

# NaN 安全版本：忽略缺失值再算
print("忽略 NaN 的 mean =", np.nanmean(scores))
print("忽略 NaN 的 std =", np.nanstd(scores))

三、练习#

  1. 自己算一遍：对数组 [4, 8, 6, 5, 3, 8, 9, 6] 手算均值、中位数、方差，再用 NumPy 验证。
  2. 异常值实验：生成 100 个均值 50、标准差 10 的正态随机数，分别计算均值和中位数；再人为把其中一个数改成 10000，重算，观察哪个统计量更稳健。
  3. 沿轴辨析：构造一个 (5, 3) 的二维数组，分别用 axis=0 和 axis=1 计算 mean 和 max，并解释每个结果的形状和含义。
  4. 分位数应用：用 np.percentile 计算某组数据的四分位距（IQR = 75 分位 − 25 分位），并据此找出可能的异常值。
  5. NaN 处理：创建一个含若干 np.nan 的二维数组，分别用 np.mean 和 np.nanmean（指定 axis=0）计算，对比结果。
