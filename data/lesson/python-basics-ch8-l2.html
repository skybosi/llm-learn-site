datetime/json/csv#

处理真实数据时，有三个模块几乎天天用：处理"时间"的 datetime、处理"数据交换格式"的 json、处理"表格数据"的 csv。这一课我们分别学会它们最核心的用法。

一、概念讲解#

1. datetime：处理日期和时间#

datetime 模块里有几个常用的类：

类 含义
date 只表示日期（年、月、日）
time 只表示时间（时、分、秒）
datetime 日期 + 时间
timedelta 两个时间之间的差值

最常用的是 datetime 类和 timedelta：

from datetime import datetime, timedelta

now = datetime.now()                 # 当前时间
future = now + timedelta(days=30)    # 30 天之后

和字符串互相转换靠两个方法：

  • strftime(格式)：把时间对象格式化成字符串；
  • strptime(字符串, 格式)：把字符串解析成时间对象。

常见格式符：%Y 四位年份、%m 月份、%d 日期、%H 小时、%M 分钟、%S 秒。

2. json：跨语言的数据格式#

JSON 是一种文本格式，用来在不同程序之间传数据。它的结构和 Python 的字典、列表非常像：

{"name": "小明", "age": 20, "scores": [90, 85, 92]}

json 模块的四个核心函数：

函数 方向 说明
json.dumps(对象) Python → 字符串 把字典/列表转成 JSON 字符串
json.loads(字符串) 字符串 → Python 把 JSON 字符串解析成字典/列表
json.dump(对象, 文件) Python → 文件 直接写入文件
json.load(文件) 文件 → Python 直接从文件读取

提示：中文默认会被转成 \uXXXX 这样的形式，加上 ensure_ascii=False 就能保留可读的中文。

3. csv：处理表格数据#

CSV（逗号分隔值）是表格数据最常见的格式，一行就是一条记录，用逗号分隔各列，很多办公软件都能打开：

姓名,年龄,城市
小明,20,北京
小红,19,上海

csv 模块的常用工具：

  • csv.reader(文件)：逐行读取成列表；
  • csv.writer(文件)：把列表写成一整行；
  • csv.DictReader(文件)：把每行读成字典（以表头为键）；
  • csv.DictWriter(文件, 字段名)：从字典写入行。

用 DictReader/DictWriter 时，表头会作为字典的键，读起来更直观。

二、可运行代码示例#

示例 1：datetime 的格式化与计算#

from datetime import datetime, timedelta

now = datetime.now()
print("现在：", now.strftime("%Y-%m-%d %H:%M:%S"))

# 加上 10 天 2 小时
future = now + timedelta(days=10, hours=2)
print("10天2小时后：", future.strftime("%Y-%m-%d %H:%M:%S"))

# 把字符串解析成时间对象
birthday = datetime.strptime("2000-05-20", "%Y-%m-%d")
print("解析出的日期：", birthday)

# 计算到今天过了多少天
days = (now - birthday).days
print("从生日到今天已经过去", days, "天")

示例 2：json 的字符串转换#

import json

# 字典转 JSON 字符串
data = {"name": "小明", "age": 20, "scores": [90, 85, 92]}
text = json.dumps(data, ensure_ascii=False)
print("JSON 字符串：", text)

# JSON 字符串转回字典
obj = json.loads(text)
print("名字：", obj["name"], "，第二科成绩：", obj["scores"][1])

示例 3：json 的文件读写#

import json

user = {"name": "小明", "age": 20}

# 写入文件
with open("user.json", "w", encoding="utf-8") as f:
    json.dump(user, f, ensure_ascii=False, indent=2)

# 从文件读回
with open("user.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)

print("读回的数据：", loaded)

示例 4：csv 的写入与读取#

import csv

# 先写一个 CSV 文件
with open("students.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "年龄", "城市"])   # 表头
    writer.writerow(["小明", 20, "北京"])
    writer.writerow(["小红", 19, "上海"])

# 再用 DictReader 读出来，表头自动成为键
with open("students.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["姓名"], "来自", row["城市"])

三、练习#

  1. 用 datetime 获取当前时间，分别打印"年-月-日"和"时:分:秒"两种格式。
  2. 把一个包含你个人信息的字典（姓名、年龄、爱好列表）用 json.dump 保存成文件，再用 json.load 读回来打印。
  3. 自己用程序生成一个 5 行数据的 CSV 文件，内容是一张"商品名、价格、数量"的清单，再用 DictReader 读出来，计算所有商品的总价（价格 × 数量再求和）。
