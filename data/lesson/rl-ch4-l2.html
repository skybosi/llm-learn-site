时序差分 TD#

蒙特卡洛必须等 episode 走完才能更新，且只适合分幕任务。时序差分（Temporal Difference，TD）方法更进一步：走一步就能更新，用"下一步的估计值"顶替"未来漫长的不确定"。本课把 TD(0) 的更新公式从 Bellman 方程里推出来，并讲清它相对 MC 的偏差-方差权衡。

一、概念讲解#

1. 先看更新公式#

TD(0) 的更新只有一行：

V(S_t) ← V(S_t) + α [ R_{t+1} + γ V(S_{t+1}) - V(S_t) ]

方括号里是TD 误差（TD error），记作：

δ_t = R_{t+1} + γ V(S_{t+1}) - V(S_t)

和 MC 的 G_t - V(S_t) 对比，唯一区别是目标（target）：MC 用完整真实回报 G_t，TD 用 R_{t+1} + γ V(S_{t+1})——即"真实走出的这一步奖励，加上对下一状态的当前估计"。

2. 推导：从 Bellman 方程到 TD 更新#

TD 不是拍脑袋发明的，它直接长在 Bellman 方程上。状态价值满足：

V_π(s) = E_π[ R_{t+1} + γ V_π(S_{t+1}) | S_t = s ]

这句话的朴素读法是："s 的价值 = 这一步的奖励，加上下一步价值的期望（折扣后）"。注意右边也出现了 V_π——这就是自举（bootstrapping）：用价值估计去估计价值。

现在把"期望"换成"采样"：期望 E[·] 我们无法直接算，但在状态 S_t 实际走一步，得到一个具体样本 R_{t+1} 和具体后继 S_{t+1}，于是上式右边的"期望"被这个采样样本近似：

V_π(s) ≈ R_{t+1} + γ V_π(S_{t+1})

再用随机逼近的思想做增量更新——朝着"采样到的目标"挪一小步 α，就得到 TD(0)：

V(S_t) ← V(S_t) + α [ (R_{t+1} + γ V(S_{t+1})) - V(S_t) ]

所以 TD 的本质是：把 Bellman 期望方程中的期望，用单步采样的"样本目标"替代。MC 则是把 V_π(s) = E[G_t | S_t=s] 中的期望用"整条轨迹的回报样本 G_t"替代——两者替代的对象不同，代价也不同。

3. 偏差-方差：TD 与 MC 的核心分野#

  • MC：目标 G_t 是真实完整回报，E[G_t] = V(s) 严格成立 → 无偏；但 G_t 累积了整条轨迹的所有随机性 → 高方差。
  • TD：目标里含 V(S_{t+1})，而 V(S_{t+1}) 一开始是错的（通常还继承了初始化），所以即使 S_t、R_{t+1} 固定，目标仍可能有偏 → 有偏（偏差随收敛而消失，故是"一致"而非无偏）；但它只用了一步的真实随机性 → 低方差，通常收敛更快。

直觉概括：MC 是"看完整场电影再评分"，稳但慢、信息利用率低；TD 是"看一分钟就猜最终票房，边看边修正"，快但有猜测成分。

4. 统一视角：DP / MC / TD 是一个光谱#

把"更新时往后看多远"当作一个坐标轴：

  • 动态规划（DP）：看一步，但用的是已知模型求出的全概率期望（把所有后继都展开）。
  • TD：看一步，用采样（只走出一条后继）。
  • MC：看到 episode 结束，用采样（整条轨迹）。

三者是"期望展开的广度（bootstrapping 深度）"与"采样展开的长度"的组合：DP = 广而浅，MC = 窄而深，TD = 窄而浅（介于中间）。TD(λ)（可简单提及：用资格迹 eligibility trace 把 1 步到 ∞ 步的回报按 λ 加权平均）则把这条光谱做成一个连续旋钮——λ=0 退化为 TD(0)，λ=1 等价于 MC。

二、可运行代码示例#

继续用上一课的随机游走，把 TD(0)（在线逐步更新）和 MC（走完才更新）放一起对比估计精度。

import numpy as np

N_STATES = 5
START = 2
GAMMA = 1.0
ALPHA = 0.1                     # TD(0) 学习率
TRUE_V = {1: 0.25, 2: 0.5, 3: 0.75}   # 随机游走解析真值

def step(s):
    """走一步，返回 (下一状态, 奖励)。"""
    s_next = s + np.random.choice([-1, 1])
    r = 1.0 if s_next == N_STATES - 1 else 0.0
    return s_next, r

def run_td(n_episodes):
    V = {s: 0.5 for s in range(1, N_STATES - 1)}   # 全部初始化为 0.5
    for _ in range(n_episodes):
        s = START
        while 0 < s < N_STATES - 1:                # 边跑边更新，无需走完
            s_next, r = step(s)
            v_next = V[s_next] if 0 < s_next < N_STATES - 1 else 0.0
            # TD(0)：目标 = r + γ·V(s_next)，自举！
            V[s] += ALPHA * (r + GAMMA * v_next - V[s])
            s = s_next
    return V

def run_mc(n_episodes):
    """首次访问 MC，走完一整条轨迹才更新（见上一课）。"""
    returns = {s: [] for s in range(1, N_STATES - 1)}
    for _ in range(n_episodes):
        states, rewards, s = [START], [], START
        while 0 < s < N_STATES - 1:
            s, r = step(s)
            states.append(s); rewards.append(r)
        G, visited = 0.0, set()
        for t in reversed(range(len(rewards))):
            G = rewards[t] + GAMMA * G
            s = states[t]
            if s not in visited and 0 < s < N_STATES - 1:
                visited.add(s); returns[s].append(G)
    return {s: np.mean(g) for s, g in returns.items()}

def rmse(V):
    return np.sqrt(np.mean([(V[s] - TRUE_V[s]) ** 2 for s in TRUE_V]))

V_td = run_td(1000)
V_mc = run_mc(1000)
print("TD(0) 估计：", {s: round(v, 3) for s, v in V_td.items()}, " RMSE={:.4f}".format(rmse(V_td)))
print("MC    估计：", {s: round(v, 3) for s, v in V_mc.items()}, " RMSE={:.4f}".format(rmse(V_mc)))
print("理论真值：", TRUE_V)

要点：同样 1000 个 episode，TD(0) 每走一步就更新一次，样本（单步转移）远多于 MC，方差更低；但它用常数 α，估计停在"有偏"的位置附近（如上，RMSE 通常略大）。MC 无偏，1000 条轨迹平均后更贴近真值，但方差更高——若减少 episode 数或多次运行，MC 的波动会明显大于 TD。这正是"有偏低方差"与"无偏高方差"的直接体现。

三、练习#

  1. 把 ALPHA 取 0.01、0.1、0.5 各跑一次，观察 TD(0) 收敛速度与最终抖动的变化；α 过大会出现什么现象？
  2. 固定 ALPHA=0.1，改变初始化 V = {s: 0.0 ...} 与 {s: 1.0 ...}，比较收敛到同一真值的轨迹，体会"TD 的有偏来自初始化"这一说法。
  3. 在 step() 里给转移加噪声（例如 10% 概率原地不动），重跑 TD 与 MC，看谁受噪声影响更大。
  4. 思考题：TD(0) 的目标 R_{t+1} + γ V(S_{t+1}) 里，哪一部分是"真实的"、哪一部分是"猜测的"？如果 V(S_{t+1}) 被初始化成 0，为什么说 TD 的估计一开始"有偏"？
