什么是 Python，为什么学它#

欢迎来到 Python 编程基础的第一课。在学习写代码之前，我们先花一点时间弄清楚一件事：Python 到底是什么，它为什么值得你花时间学习。

一、概念讲解#

1. 编程语言是什么#

人和人交流用中文、英语；人和计算机交流，用的是编程语言。计算机其实只能理解一串串的 0 和 1（也就是"机器码"），但直接写 0 和 1 对人类来说太难了。于是人们设计出"更接近人类习惯"的语言，再由一个翻译工具把它变成计算机能懂的东西。Python 就是这样一门语言。

Python 由荷兰程序员 Guido van Rossum（吉多·范罗苏姆）在 1991 年公开发布。它的名字其实来源于他喜欢的一个英国喜剧团体"Monty Python"，而不是蟒蛇——虽然很多地方会用蟒蛇图案作为它的吉祥物。

2. Python 的三个突出特点#

① 读起来像英语，入门友好。 Python 的语法刻意设计得很简洁。同样一件事，用其他语言可能要写好几行符号，用 Python 往往一行就能说清楚。对零基础的人来说，这是最容易上手的选择之一。

② 用途非常广。 Python 不是"只能做一件事"的语言。它可以写网站后端、做数据分析、自动化办公、写爬虫，更是目前人工智能和机器学习领域最主流的语言之一。学会它，等于拿到了一把能开很多扇门的钥匙。

③ 生态丰富。 全世界有海量开发者在使用 Python，并贡献了成千上万个现成的"库"（可以理解为别人已经写好的工具箱）。很多复杂功能，你只要"拿过来用"就行，不用从零造轮子。

3. 一个直观的第一印象#

我们先不看复杂的语法，只感受一下 Python 代码长什么样。下面这行代码会打印一句问候：

print("你好，Python！")

运行后，屏幕上会显示：

你好，Python！

你不需要现在就完全理解它，只需要有个印象：Python 代码很接近我们平时说的话。 从下一课开始，我们会一步步拆开它。

4. 学 Python 需要准备什么#

只需要一台普通的电脑，和一颗愿意动手的心。Python 是免费、开源的，任何人都可以自由下载、使用，甚至查看它的源代码。接下来几课，我们会教你把它装到电脑上，写出自己的第一段程序。

二、可运行代码示例#

下面这段代码会在屏幕上打印几行文字，你可以把它当作"对 Python 说你好"的练习。现在先别急着运行，到第三课配置好环境后，再回来亲手试一次。

# 井号开头的是"注释"，是写给人看的说明，程序会忽略它
# 用 print() 可以在屏幕上输出文字

print("我是 Python，很高兴认识你！")   # 输出一句问候
print("今天是学习编程的第一天")        # 再输出一句
print(1 + 1)                            # Python 还能直接算数，这里会输出 2

预期输出：

我是 Python，很高兴认识你！
今天是学习编程的第一天
2

要点：print() 是 Python 内置的"打印"功能；引号包起来的是文字；没加引号的 1 + 1 会被当作数学运算来算。

三、练习#

  1. 口头描述：用自己的话，向一个完全不懂编程的朋友解释"编程语言是什么"。
  2. 观察：上网找一张 Python 代码截图（任何开源项目都可），试着找出里面有没有你认识的单词，感受一下它的可读性。
  3. 思考：你学 Python 最想用它做什么？写下来，这会成为你坚持学下去的动力。
  4. 预习：访问 Python 官网（python.org），找一找"下载"按钮在哪里，不用下载，只要知道它在哪个页面即可。
