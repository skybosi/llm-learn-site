参数与返回值#

函数不会说话，但能"接收"数据（参数），也能"交回"结果（返回值）。本节课让函数学会输入与输出。

一、概念讲解#

1. 参数：给函数传数据#

定义函数时，在括号里写上"参数名"，函数体就能使用它；调用时，把具体的值传进去，参数名就代表这个值。

def 函数名(参数1, 参数2):
    函数体里使用参数1、参数2

一个函数可以有多个参数，调用时要按顺序一一对应。

2. 关键字参数：按名字传值#

调用时也可以写成 参数名=值 的形式，这样就不必死记参数的顺序，代码也更好读。

3. 默认参数：不传就用默认值#

定义时给参数一个默认值 参数名=默认值。调用时如果没传，就用默认值；传了，就用传进去的值。注意：有默认值的参数要放在没有默认值的参数后面。

4. return：把结果交回去#

return 语句让函数返回一个值，并且函数执行到 return 就立刻结束。调用处可以用一个变量接住返回值。

如果函数没有 return，它会返回一个特殊值 None，表示"没有结果"。

5. 一次返回多个值#

Python 里可以 return a, b，本质上是返回一个元组（tuple）。接收时用多个变量依次接住即可。

二、代码示例#

示例 1：带参数的函数#

def greet(name):
    print(f"你好，{name}！")

greet("小明")
greet("小红")

示例 2：多个参数 + 返回结果#

def add(a, b):
    return a + b          # 把和交回去

result = add(3, 5)        # 用变量接住返回值
print(result)             # 8
print(add(10, 20))        # 也可以直接使用

示例 3：关键字参数与默认参数#

def introduce(name, age=18, city="北京"):
    print(f"{name}，{age} 岁，来自 {city}")

introduce("阿伟")                      # 用默认的 age、city
introduce("小美", 20)                  # 覆盖 age，city 用默认
introduce("老王", city="上海", age=30)  # 关键字参数，顺序随意

示例 4：返回多个值#

def circle_info(r):
    area = 3.14 * r * r
    perimeter = 2 * 3.14 * r
    return area, perimeter    # 一次交回两个值

a, p = circle_info(5)         # 两个变量分别接住
print(f"面积 {a}，周长 {p}")

示例 5：没有 return 时返回 None#

def say_hi():
    print("hi")               # 没有 return

result = say_hi()
print(result)                 # None

三、练习#

  1. 定义一个 max_of_two(a, b) 函数，返回两个数中较大的那个，并测试几组数据。
  2. 定义一个 power(base, exp=2) 函数，返回 base 的 exp 次方，分别测试只传一个参数和传两个参数的情况。
  3. 定义一个函数，接收一个字符串参数，返回它的长度和首字母（两个值），然后调用并打印。
