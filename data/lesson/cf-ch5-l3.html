内联、循环识别与不变量外提#

上一课的三个改写都在单个函数内部。可真实程序由函数组成，而函数边界对优化器是一堵墙：被调函数的体对调用者不可见，常量、类型、别名信息过不去。这一课先讲怎么把墙拆掉（内联），再讲优化收益最集中的地方——循环：怎么用支配关系认出一个自然循环，怎么把循环里"每轮都算但结果不变"的指令搬到循环外，以及为什么"值不变"并不等于"可以随便搬"。

一、概念讲解#

1. 内联的价值主要不在"省一次调用"#

内联（inlining）的第一收益是打开跨过程优化的门：调用点消失后，实参常量、返回值、别名信息都暴露在同一个函数体里，上一课的折叠/CSE/DCE 才有活干；省下的那次 call/ret 反而是次要的。

本课代码第一段就是最小演示：main 原本只有 2 条指令（r = call g(10) 和 return r）。递归内联 g 与 f 后变成 6 条；再跑折叠 + DCE，只剩 2 条，r 直接是 24。没有内联，10 * 2 + 3 + 1 只能陪跑到运行期。

代价同样真实：每个调用点复制一份函数体（代码体积与指令缓存压力）、编译时间、递归需要深度上限。真实编译器因此用代价模型（调用点开销对比体大小、是否只被调用一次、是否有 inline 提示）决定，而不是一个固定阈值。

2. 先要能"认出"循环：支配关系 → 回边 → 自然循环#

LLVM Loop Terminology 的定义很精确：循环是 CFG 节点的一个子集，满足

  1. 子集的诱导子图强连通（里面任意两点互相可达）；
  2. 从子集外进入子集的边全部指向同一个节点，称为 header；
  3. 它是满足前两条的最大子集。

第 2 条的直接推论就是"header 支配循环内所有节点"。识别流程因此非常工程化：先算支配关系（Dom(B) = {B} ∪ ⋂ over P ∈ pred(B) : Dom(P)，从 Dom(entry) = {entry} 迭代到不动点），再找回边（back edge）latch → header（要求 header 支配 latch），最后从 latch 沿前驱反向走、遇 header 即停，走到的节点加 header 就是自然循环。

本课程序实测：B3 → B2 是回边，循环 = {B2, B3}，header = B2。

3. preheader：不变量外提需要"循环外只执行一次"的落点#

外提不能把指令丢进 header（那还是每轮执行一次），也不能丢进某个分支（可能根本不执行）。需要的是 preheader：唯一一个从循环外进入 header、且自己只跳到 header 的前驱块。LLVM 的 LoopSimplify 保证每个循环都有 preheader、单回边、专用出口——这种"规范形态"（canonical form）的意义在于：pass 只需处理一种形状，不必为任意写法各写一套逻辑。本课程序里 B1 就是天然的 preheader。

4. 不变量外提的三个条件#

把一条指令从循环体搬到 preheader，必须同时满足：

  1. 操作数在循环内不变：每个名字要么在循环外定义，要么是已被外提指令的结果。
  2. 无条件执行是安全的（safe to speculate）：搬到"必然执行"的位置后不能引入原来没有的陷阱。除法、可能越界的 load 都是典型反例；LLVM 的 LICM 用 isSafeToSpeculativelyExecute 判这一类。
  3. 结果在循环内只有一个定值，且定义支配所有出口：否则某些出口上这个值还没算出来。在"自然循环 + 单回边 + 无中途退出"的形状下这条自动成立。

本课代码实测：t2 = a * b 被外提；t3 = 100 / c 被拒绝，理由正是第 2 条（循环体一次都不执行时原程序不会出错，搬出去就必然出错）；t4 = s * 2 被拒绝，因为 s 在循环内被改写。

顺带一个组合效应：外提之后 preheader 里的 c = a * b 与新外提的 t2 = a * b 右值相同，上一课的 CSE 可以把它们合成一条。优化的收益经常是组合出来的。

5. 常见坑#

  • 内联递归函数不设界：直接死循环；真实编译器对递归调用点通常直接放弃内联。
  • 把"节点在环里"当成自然循环：不可约控制流里存在没有支配 header 的环，此时不能用自然循环的性质；LLVM 用更一般的 cycle 概念描述，并提供 FixIrreducible 处理。
  • 没有 preheader 就外提：把指令塞进 header 会改变"进入循环的次数"的语义。
  • 把可能陷阱的运算当纯计算搬走：见上面 100 / c 的反例。

二、可运行代码示例#

下面的纯 Python 代码分两部分。第一部分是递归内联器（形参与局部临时名全部换新），演示"内联把跨过程的常量计算暴露给折叠"。第二部分先算支配关系、用回边找自然循环与 preheader，再按上述三个条件做不变量外提，并把每条被拒绝的指令连同理由打印出来——"为什么没外提"和"外提了什么"同样重要。

# ---- 内联 + 自然循环识别 + 循环不变量外提（纯 Python，无第三方依赖）----
BIN = {'add', 'sub', 'mul', 'div'}
OPS = {'add': lambda x, y: x + y, 'sub': lambda x, y: x - y,
       'mul': lambda x, y: x * y, 'div': lambda x, y: x // y}
SAFE_TO_HOIST = {'add', 'sub', 'mul', 'copy', 'cmp'}      # div 可能陷阱 → 不敢无条件执行


def nm(x):
    return ('name', x)


def ct(k):
    return ('const', k)


def op_str(x):
    return str(x[1]) if x else '-'


def fmt(ins):
    op = ins[0]
    if op == 'copy':
        return f'{ins[3]} = {op_str(ins[1])}'
    if op in BIN:
        return f'{ins[3]} = {op_str(ins[1])} {op} {op_str(ins[2])}'
    if op == 'cmp':
        return f'{ins[4]} = {op_str(ins[2])} {ins[1]} {op_str(ins[3])}'
    if op == 'ifgoto':
        return f'if {op_str(ins[1])} goto {ins[2]} else {ins[3]}'
    if op == 'goto':
        return f'goto {ins[1]}'
    if op == 'call':
        return f'{ins[3]} = call {ins[1]}({", ".join(op_str(a) for a in ins[2])})'
    if op == 'return':
        return f'return {op_str(ins[1])}'
    return str(ins)


def def_use(ins):
    op = ins[0]
    if op == 'copy':
        return ins[3], [ins[1]]
    if op in BIN:
        return ins[3], [ins[1], ins[2]]
    if op == 'cmp':
        return ins[4], [ins[2], ins[3]]
    if op == 'call':
        return ins[3], list(ins[2])
    if op in ('ifgoto', 'return'):
        return None, [ins[1]]
    return None, []


# ==================== 第一部分：内联（把跨过程优化变成过程内优化）====================
FUNCS = {                                    # 名字 → (形参, 指令体, 返回值变量)
    'f': (['x'], [('mul', nm('x'), ct(2), 'fx'), ('add', nm('fx'), ct(3), 'fr')], 'fr'),
    'g': (['y'], [('call', 'f', [nm('y')], 'cy'), ('add', nm('cy'), ct(1), 'gr')], 'gr'),
}
MAIN = [('call', 'g', [ct(10)], 'r'), ('return', nm('r'))]
counter = [0]


def fresh(v):
    counter[0] += 1
    return f'{v}.{counter[0]}'


def instantiate(fname, args):
    """把 fname(args) 的体展开成指令序列（形参与局部临时名全部换成新名字）"""
    params, body, ret = FUNCS[fname]
    sub = dict(zip(params, args))
    local, out = {}, []

    def ren(x):
        if x is None or x[0] != 'name':
            return x
        return sub.get(x[1], nm(local[x[1]]) if x[1] in local else x)
    for ins in body:
        op = ins[0]
        if op == 'return':
            continue
        if op == 'call':
            callee, cret = instantiate(ins[1], [ren(a) for a in ins[2]])
            out += callee
            local[ins[3]] = fresh(ins[3])
            out.append(('copy', nm(cret), None, local[ins[3]]))
            continue
        d, _ = def_use(ins)
        local[d] = fresh(d)
        if op == 'copy':
            out.append(('copy', ren(ins[1]), None, local[d]))
        elif op in BIN:
            out.append((op, ren(ins[1]), ren(ins[2]), local[d]))
        else:
            out.append(('cmp', ins[1], ren(ins[2]), ren(ins[3]), local[d]))
    return out, local[ret]


def inline_top(instrs):
    out = []
    for ins in instrs:
        if ins[0] == 'call':
            body, ret = instantiate(ins[1], ins[2])
            out += body + [('copy', nm(ret), None, ins[3])]
        else:
            out.append(ins)
    return out


def fold_and_dce(instrs):
    """过程内常量折叠 + 死代码消除（内联之后才有机会做的事）"""
    state, out, folds = {}, [], 0
    for ins in instrs:
        op = ins[0]
        if op in ('return', 'goto', 'ifgoto'):
            out.append(ins)
            continue
        d, ops = def_use(ins)
        vals = [state.get(x[1]) if x[0] == 'name' else ('C', x[1]) for x in ops]
        if all(v and v[0] == 'C' for v in vals):
            val = vals[0][1] if op == 'copy' else OPS[op](*[v[1] for v in vals])
            state[d] = ('C', val)
            out.append(('copy', ct(val), None, d))
            folds += op != 'copy'
        else:
            state[d] = ('NAC',)
            out.append(ins)
    changed = True
    while changed:                                   # 简单的死代码消除
        used = {x[1] for ins in out for x in def_use(ins)[1] if x and x[0] == 'name'}
        keep = [ins for ins in out if def_use(ins)[0] is None or def_use(ins)[0] in used]
        changed = len(keep) != len(out)
        out = keep
    return out, folds


print('=== 内联：把跨过程的常量计算变成过程内的常量计算 ===')
print('main 原始：')
for ins in MAIN:
    print('   ', fmt(ins))
inlined = inline_top(MAIN)
print(f'main 内联后（{len(inlined)} 条指令，递归展开了 g→f）：')
for ins in inlined:
    print('   ', fmt(ins))
folded, nfold = fold_and_dce(inlined)
print(f'内联 + 折叠 + 死代码消除后（{len(folded)} 条指令，折叠 {nfold} 次）：')
for ins in folded:
    print('   ', fmt(ins))
print('   → 没有内联，这两次乘法加法只能"陪跑"到运行期；内联把它们暴露给了折叠。\n')

# ==================== 第二部分：自然循环识别 + 不变量外提 ====================
LOOP_PROG = {
    'B1': [('mul', nm('a'), nm('b'), 'c'),
           ('copy', ct(0), None, 'i'),
           ('goto', 'B2')],
    'B2': [('cmp', '<', nm('i'), nm('n'), 't1'),
           ('ifgoto', nm('t1'), 'B3', 'B5')],
    'B3': [('mul', nm('a'), nm('b'), 't2'),
           ('div', ct(100), nm('c'), 't3'),
           ('mul', nm('s'), ct(2), 't4'),
           ('add', nm('s'), nm('t2'), 's'),
           ('add', nm('i'), ct(1), 'i'),
           ('goto', 'B2')],
    'B5': [('return', nm('s'))],
}


def succ_of(prog):
    s = {}
    for b, body in prog.items():
        last = body[-1] if body else None
        if last and last[0] == 'goto':
            s[b] = [last[1]]
        elif last and last[0] == 'ifgoto':
            s[b] = [last[2], last[3]]
        else:
            s[b] = []
    return s


def dominators(prog, succ):
    order, entry = list(prog), list(prog)[0]
    pred = {b: [p for p in order if b in succ[p]] for b in order}
    dom = {b: set(order) for b in order}
    dom[entry] = {entry}
    for _ in range(len(order) + 1):
        new = {}
        for b in order:
            if b == entry:
                new[b] = {entry}
            else:
                new[b] = {b} | set.intersection(*[dom[p] for p in pred[b]]) if pred[b] else {b}
        if new == dom:
            break
        dom = new
    return dom, pred


prog, succ = LOOP_PROG, None
succ = succ_of(prog)
dom, pred = dominators(prog, succ)
print('=== 自然循环识别（支配关系 → 回边 → 循环 + preheader）===')
for b in prog:
    print(f'  dom({b}) = {sorted(dom[b])}')
backedges = [(p, b) for b in prog for p in pred[b] if b in dom[p] and p != b or
             (b in dom[p] and b == p)]
backedges = [(p, b) for b in prog for p in pred[b] if b in dom[p]]
print('  回边 back edge：', backedges)
header = backedges[0][1]
loop = {header}
work = [backedges[0][0]]
while work:                                          # 从锁存块反向走，遇到 header 停
    b = work.pop()
    if b in loop:
        continue
    loop.add(b)
    work += [p for p in pred[b] if p != header]
print(f'  自然循环（header={header}）：{sorted(loop)}')
pre = [p for p in pred[header] if p not in loop]
preheader = pre[0] if len(pre) == 1 and succ[pre[0]] == [header] else None
print(f'  preheader：{preheader}'
      f'{"（唯一入口且只跳 header → 可直接外提）" if preheader else "（需先补 preheader）"}')

# ---------- LICM：把循环不变量搬到 preheader 末尾 ----------
in_loop_defs = {def_use(i)[0] for b in loop for i in prog[b] if def_use(i)[0]}
hoisted, refused, moved = set(), [], []
new_pre_body = prog[preheader][:-1]                  # 插在 preheader 的 goto 之前
for b in sorted(loop):
    keep = []
    for ins in prog[b]:
        op, d, ops = ins[0], def_use(ins)[0], def_use(ins)[1]
        if d is None or d in moved:
            keep.append(ins)
            continue
        names = [x[1] for x in ops if x[0] == 'name']
        invariant = all(n not in in_loop_defs or n in hoisted for n in names)
        defs_here = [def_use(i)[0] for i in prog[b] if def_use(i)[0] == d]
        if not invariant:
            refused.append((fmt(ins), '操作数在循环内有定义（非不变量）'))
        elif op not in SAFE_TO_HOIST:
            refused.append((fmt(ins), f'{op} 可能陷阱，不能无条件执行（不能猜测执行）'))
        elif len(defs_here) != 1:
            refused.append((fmt(ins), '循环内该结果有多个定值'))
        else:
            new_pre_body.append(ins)
            hoisted.add(d)
            moved.append(ins)
            continue
        keep.append(ins)
    prog[b] = keep
prog[preheader] = new_pre_body + [prog[preheader][-1]]
print('\n=== LICM 决策 ===')
print(f'  外提到 {preheader} 的指令：')
for ins in moved:
    print('   ', fmt(ins))
print('  拒绝外提的指令与理由：')
for text, why in refused:
    print(f'    {text:<22} ← {why}')
print('\n=== 外提后的程序 ===')
for b in prog:
    for ins in prog[b]:
        print(f'  {b}: {fmt(ins)}')

运行结果：

=== 内联：把跨过程的常量计算变成过程内的常量计算 ===
main 原始：
    r = call g(10)
    return r
main 内联后（6 条指令，递归展开了 g→f）：
    fx.1 = 10 mul 2
    fr.2 = fx.1 add 3
    cy.3 = fr.2
    gr.4 = cy.3 add 1
    r = gr.4
    return r
内联 + 折叠 + 死代码消除后（2 条指令，折叠 3 次）：
    r = 24
    return r
   → 没有内联，这两次乘法加法只能"陪跑"到运行期；内联把它们暴露给了折叠。

=== 自然循环识别（支配关系 → 回边 → 循环 + preheader）===
  dom(B1) = ['B1']
  dom(B2) = ['B1', 'B2']
  dom(B3) = ['B1', 'B2', 'B3']
  dom(B5) = ['B1', 'B2', 'B5']
  回边 back edge： [('B3', 'B2')]
  自然循环（header=B2）：['B2', 'B3']
  preheader：B1（唯一入口且只跳 header → 可直接外提）

=== LICM 决策 ===
  外提到 B1 的指令：
    t2 = a mul b
  拒绝外提的指令与理由：
    t1 = i < n             ← 操作数在循环内有定义（非不变量）
    t3 = 100 div c         ← div 可能陷阱，不能无条件执行（不能猜测执行）
    t4 = s mul 2           ← 操作数在循环内有定义（非不变量）
    s = s add t2           ← 操作数在循环内有定义（非不变量）
    i = i add 1            ← 操作数在循环内有定义（非不变量）

=== 外提后的程序 ===
  B1: c = a mul b
  B1: i = 0
  B1: t2 = a mul b
  B1: goto B2
  B2: t1 = i < n
  B2: if t1 goto B3 else B5
  B3: t3 = 100 div c
  B3: t4 = s mul 2
  B3: s = s add t2
  B3: i = i add 1
  B3: goto B2
  B5: return s

对照输出读三件事：内联 + 折叠把 main 从 6 条压到 2 条（r = 24）；t2 = a * b 落在 B1 末尾（preheader 的 goto 之前）；被拒绝的 5 条里，t3 = 100 div c 的理由是"可能陷阱"，其余 4 条是"操作数在循环内变"。

三、练习#

  1. 实现：给外提加"守卫版"支持——当一条可能陷阱的指令（如 100 / c）也想外提时，不无条件执行，而是生成"提前判断安全性"的守卫，失败则走原循环体（提示：这是 LLVM 处理 speculation 的常见折中）。
  2. 解释：为什么 LLVM 要让 LoopSimplify 先把循环整理成"有 preheader、单回边、专用出口"的规范形态，而不是让每个优化 pass 自己处理任意形状的循环？
  3. 对比/验证：把 t2 = a * b 改成 t2 = a * b * c（c 在 preheader 定义）再跑，确认它仍被外提；然后把 c 改成循环体内定义的变量，观察拒绝理由从"可能陷阱"变成"操作数在循环内变"。
  4. 思考：内联让代码变大、让优化机会变多，平衡该由谁拍板？为什么真实编译器用代价模型而不是"函数体不超过 N 条指令"的硬阈值？
