情感与副语言：标注主观性的判据、表征与跨说话人跨语言泛化#

这一节要解决什么#

前三节的任务都有一份客观标签：转写文本（第 2 章）、说话人身份（第 1 节）、以及由混合与源直接定义的分离目标（第 2 节）。即使对齐未知、说话人未知，标签本身是什么并不含糊。

情感任务打破这一点。给一段语音标"情绪"，两个受过训练的标注者可能给出不同的答案，而且两个都不是错的。这不是标注质量问题，是任务本身的性质：情感是一个感知量，它的"真值"是人群判断的分布，而不是某个客观属性。

这带来三个结构性问题：

  1. 一致性系数不能只看"一致率"。 原始一致率（percentage agreement）会被类别分布的偏斜放大。本节实测：均衡分布下原始一致率 0.4925、Cohen κ=0.3645；严重倾斜（88% 落在第 0 类）下原始一致率 0.7900、κ=0.5055，但用线性加权 κ 看是 0.7216、二次加权 κ 是 0.8881。同一份标注，换个口径读数差 2 倍以上。
  2. 基准率悖论（base-rate paradox）让 κ 本身不可比。 Fleiss κ 在类别均匀时，单标注者错误率 0.10 给出 κ=0.8056；在 88% 倾斜时同一错误率给出 κ=0.5768、错误率 0.25 时 κ=0.2642（均匀时是 0.5493）。κ 的分母 1−pe​ 在倾斜时变小，于是同样的标注质量读出更小的 κ。
  3. 表征的泛化差距是任务的主要瓶颈。 本节用三类合成特征（韵律 6 维 / 谱 16 维 / 自监督 32 维）做消融：跨说话人划分下自监督块从随机划分的 0.4917 掉到 0.4062（−0.0855），而谱块从 0.5583 掉到 0.5125（−0.0458）；说话人中心化（每个测试说话人减去自身均值）把跨说话人准确率抬回去：韵律 0.4188→0.4688、谱 0.5125→0.6062、自监督 0.4062→0.4938、三块拼接 0.9688→0.9875。

 情感任务的“标签”是一个分布；先决定用哪个一致性口径，再谈模型指标 ​

⚠️ 本节代码中的标注、说话人、语言与特征全部是合成的，只用标准库。它们的作用是把"一致性口径"和"泛化差距"变成可核对的算术，不是对任何真实语料库或系统成绩的断言。

一、标注主观性：一致性系数怎么选、怎么读#

1.1 先明确一件事：一致率不是判据#

设 n 个样本、K 个类别、r 个标注者。原始一致率 Po​ 是标注者两两一致的比例。它有一个致命的性质：当某个类别占绝对多数时，两个完全瞎猜的标注者也能拿到很高的一致率。

极端例子：K=5、88% 的样本真值是第 0 类。两个标注者都按"以 0.88 概率说第 0 类、否则均匀乱猜其他类"来标，则

Po​≈0.882+0.122/4≈0.7744+0.0036=0.7780

他们什么都没看，一致率就有 77.8%。 所以必须扣掉"偶然一致"。

1.2 三种口径的公式#

(a) Cohen κ（两个标注者）

κ=1−Pe​Po​−Pe​​,Pe​=k=1∑K​p1​(k)p2​(k)

p1​,p2​ 是两个标注者各自的类别边缘分布。Pe​ 是"在各自边缘分布独立的前提下"的期望一致率。

(b) 加权 κ（序数类别）

情感强度（例如 1∼5）是序数的：标成 4 而真值是 5，比标成 1 而真值是 5 轻得多。无条件 κ 把这两者同等对待。加权 κ 引入权重矩阵 wij​：

κw​=1−∑ij​wij​Eij​∑ij​wij​Oij​​

两种常见权重：

wijlin​=∣i−j∣,wijquad​=(i−j)2

二次权重对"差得远"的惩罚增长得快，因此通常给出更高的 κ（因为它把近似一致算成部分一致）。本节实测（均衡场景）：κ=0.3645、线性加权 0.6507、二次加权 0.8332。报 κ 时必须说明权重，否则三个数可以差 2.3 倍。

(c) Fleiss κ（多个标注者、每人标的样本集相同）

Pˉ=n1​i=1∑n​r(r−1)∑k​nik​(nik​−1)​,Pe​=k∑​pˉ​k2​,κF​=1−Pe​Pˉ−Pe​​

nik​ 是第 i 个样本被判为第 k 类的标注者数，pˉ​k​=nr1​∑i​nik​。

(d) Krippendorff α（序数差平方、允许标注者数不齐）

α=1−De​Do​​,Do​=n1​u∑​i=j∑​mu​−1(xui​−xuj​)2​ / u∑​mu​

其中 mu​ 是第 u 个样本收到的标注数。α 的优点是每个样本的标注数可以不同（真实标注流程里很常见：有的样本没人愿意标）。

1.3 三个口径的数值对照#

本节代码用同一套合成标注算出四种读数：

场景 原始一致率 Cohen κ 线性加权 二次加权
均衡分布 0.4925 0.3645 0.6507 0.8332
严重倾斜（88% 第 0 类） 0.7900 0.5055 0.7216 0.8881

读法：

  • 倾斜场景的原始一致率（0.7900）几乎比均衡场景（0.4925）高一倍，但它的 κ（0.5055）只高 0.14；
  • 在倾斜场景里，Pe​=0.5753——超过一半的"一致"是偶然一致；
  • 二次加权 κ 在两个场景里都很高（0.8332、0.8881），因为大部分分歧只是相邻一档。

这就是"同一份标注可以报出 0.36 或 0.83"的全部机制。

自助法（bootstrap，300 次重采样）给出 κ 的 95% 置信区间：

场景 95% CI 宽度
均衡 [0.3035, 0.4347] 0.1312
倾斜 [0.4167, 0.5901] 0.1735

倾斜场景的区间更宽（0.1735 vs 0.1312）——因为 Pe​ 更接近 1，κ 的分母更小，同样的抽样波动被放大。所以"倾斜数据的 κ 更不可信"有两个理由：系统性地被压低，而且方差更大。

1.4 基准率悖论：Fleiss κ 的两个场景#

同一份标注流程（5 个标注者、200 个样本），只改类别分布：

单标注者错误率 类别均匀：Po​ / Pe​ / κF​ 88% 倾斜：Po​ / Pe​ / κF​
0.10 0.8450 / 0.2028 / 0.8056 0.8755 / 0.7058 / 0.5768
0.25 0.6400 / 0.2013 / 0.5493 0.6425 / 0.5141 / 0.2642
0.45 0.4345 / 0.2028 / 0.2907 —

关键对比：错误率 0.25 时，倾斜场景的原始一致率（0.6425）高于均匀场景（0.6400），但 κF​ 从 0.5493 掉到 0.2642。

这不是 κ 的缺陷，是它的定义在起作用：κ 度量的是"超出偶然一致的那部分一致"，而倾斜场景的偶然一致本来就高。问题是人们拿不同数据集的 κ 互相比较——一个有 88% 第 0 类的情感语料库，κ=0.58 实际上比一个均衡语料库的 κ=0.55 更"好"，但表面上看起来差不多。

判据：报告一致性时必须同时给类别分布与Pe​。只给 κ 是不完整的。

标注者数 α

α 随标注者数略降（因为更多标注者带来更多"至少有一对不一致"的机会），但幅度很小（0.8555→0.8419）。这说明这套标注质量对标注者数不敏感——是一个好的性质，因为它意味着"少标几个人"不会让一致性读数剧烈变化。

1.6 需要多少标注者：多数投票的稳定率#

5 个类别、单标注者可靠度 p（以概率 p 给出正确答案，否则在 5 类里均匀乱猜），2000 次重复：

单标注者 p 3 人多数投票 5 人 7 人
0.40 0.6210 0.7345 0.8095
0.55 0.7765 0.8805 0.9405
0.70 0.8885 0.9565 0.9900
0.85 0.9735 0.9955 0.9995

这张表是可操作的判据：

  • 单标注者 p=0.40 低于随机基线加一点（1/5=0.2），要靠投票救回来代价很大：3 人只有 0.6210，7 人 0.8095；
  • 单标注者 p=0.55 时，5 人投票达到 0.8805 —— 这是一个性价比很高的点；
  • 单标注者 p≥0.70 时，3 人已经够（0.8885），再增加标注者收益递减。

但必须同时看到另一面：如果单标注者之间不是独立错误（例如都受同一个诱导性提问影响），多数投票不会提升。上表的全部前提是"错误独立"。"我们用了 5 个标注者"本身不构成质量保证。

二、表征：韵律、谱、自监督#

2.1 三块特征各自携带什么#

表征块 常见维度 直接编码 主要局限
韵律 4∼10 F0​ 轨迹（均值/范围/斜率）、能量、语速、停顿时长、抖动/微扰 对说话人身份极敏感（F0​ 均值几乎就是性别与个体特征）；对噪声敏感
谱 13∼80 MFCC / LFBE / 谱质心、谱倾斜、谐噪比 混入内容信息；对信道敏感
自监督嵌入 256∼1024 大规模预训练模型的中间层（帧级或句级） 预训练语料决定偏置；维度高、小样本下易过拟合

一个必须说清的结构事实：韵律块的前几个统计量（F0​ 均值、能量均值）同时也是说话人识别最有用的特征。所以在情感任务里，韵律块天然地混入了说话人身份——本节实测的"跨说话人掉分"里，很大一部分就是这块。

2.2 合成实验的构造#

本节代码用高斯生成模型 + 共享协方差的 LDA 判别，构造如下：

  • 四个类别对应四个"情感象限"：(激活,效价)=(+1,0),(+1,+1),(−1,+1),(−1,0)；
  • 韵律 6 维只由激活度这一维生成；谱 16 维只由效价生成；自监督 32 维也只由效价生成（即它与谱块携带同一份信息，但用了 2 倍的维度）；
  • 每维叠加 N(0,1) 噪声，再加一个说话人偏移 N(0,0.62)（与类别无关的通道偏置）；
  • 所有特征都是关于类别的一个仿射函数 + 噪声，所以共享协方差的 LDA 是这个生成模型的贝叶斯最优线性判别器——这是一个保真度很高的合成实验，模型与数据匹配，因此读数反映的是"信息量"与"失配"，不是"优化没调好"。

2.3 主结果：四种划分#

特征 随机划分 跨说话人 跨语言 跨说话人+跨语言
韵律 0.4750 0.4188 0.4500 0.4500
谱 0.5583 0.5125 0.4875 0.4500
自监督 0.4917 0.4062 0.5042 0.5500
韵律+谱 0.9417 0.9125 0.9167 0.8750
全部 0.9750 0.9688 0.9750 0.9750

四个读法：

  1. 单块性能都在随机水平（0.25）到 0.56 之间。因为每一块只携带一个潜在维度，而四个类别需要两个维度才能完全分开——单块在信息量上就不够，这不是模型的问题。
  2. 拼接带来巨大增益：韵律+谱 =0.9417（随机划分），因为两块分别携带激活度与效度正交的两份信息。这是"特征互补性"的直接体现：0.9417−0.5583=0.3834 高于任何单块的边际贡献。
  3. 跨说话人划分一致性地掉分：韵律 −0.0562、谱 −0.0458、自监督 −0.0855。自监督块掉得最多——它维度最高（32 维），因此说话人偏移在里面的投影也最大。
  4. 跨语言与随机划分的差距不大（谱 0.5583→0.4875，0.0708），说明在本例中"语言"与"说话人"是两个不同的混淆源；跨语言样本的说话人偏移量级与训练集相同，所以掉分主要来自分布差异而不是说话人差异。

2.4 说话人中心化：一个几乎免费的修正#

做法：对每个说话人的特征向量，减去该说话人在可用数据上的均值（不需要标签）。这等价于把"说话人偏移"这个与类别无关的加性项消掉。

特征 不中心化 说话人中心化 增益
韵律 0.4188 0.4688 +0.0500
谱 0.5125 0.6062 +0.0938
自监督 0.4062 0.4938 +0.0875
全部 0.9688 0.9875 +0.0188

增益与"该块里说话人偏移占多大比例"成正比：谱与自监督块增益最大（+0.0938、+0.0875），韵律块最小（+0.0500），而三块拼接后增益缩到 +0.0188（已经接近上限 1.0，空间不够）。

必须说清的边界：

  • 说话人中心化需要每个测试说话人的多条语音。如果测试时只有一条语音，中心化无法进行（这是单样本域自适应问题）；
  • 它去掉的是加性偏移。如果说话人差异是乘性的（例如共振峰的缩放）或改变协方差形状，减均值不够，需要更一般的自适应（例如相关对齐、或对说话人做仿射变换）。

2.5 有效维度：为什么"维度高"不等于"信息多"#

特征块 维度 ∥μ∥2 协方差最大特征值 有效维数 每维信噪比
韵律 6 5.9380 1.6346 4.90 0.9897
谱 16 7.5552 2.3308 9.44 0.4722
自监督 32 17.6158 2.8000 15.40 0.5505

（∥μ∥2 是各类别均值向量的平均平方范数；"有效维数" = 协方差迹 / 最大特征值。）

三行的解读：

  • 自监督块的 ∥μ∥2=17.6158 最大（因为 32 维里每一维都带同一份信息，均值向量的范数被维度放大），但它的每维信噪比只有 0.5505，与谱块的 0.4722 同量级——多出来的维度只是把同一份信息重复了 2 倍。
  • 有效维数（协方差迹 / 最大特征值）接近维度本身（4.90/6、9.44/16、15.40/32），说明噪声是各向同性的，没有"低秩结构"可以利用。
  • 这就是为什么拼接三块只比拼接两块好一点点（0.9417→0.9750）：自监督块提供的是与谱块共线的信息，边际贡献主要来自降噪（多份观测平均）。

判据：选表征不能只看维度或"用了哪个预训练模型"，要算每维携带的类别信息（可用类间散度 / 类内散度）和与其他块的共线性。高维嵌入在跨域任务上的额外收益，常常小到被说话人偏移的额外方差抵消。

三、跨语言泛化的两种做法#

3.1 语言做了什么#

语言对情感任务的影响有三条已知的机制路径（此处只描述机制，不给具体语料库数字）：

  1. 韵律的语用差异：同一个 F0​ 变化幅度，在不同语言里可能表示"强调"、"疑问"或"惊讶"；
  2. 副语言词汇的不可译：笑声、叹气、咂嘴在不同文化里的功能不同，而这些正是副语言通道的主要载体；
  3. 说话人差异与语言差异的混淆：一个跨语言测试集里的说话人与训练集说话人不同，所以"跨语言掉分"里混着"跨说话人掉分"。要分开这两者，必须做交叉设计：跨语言但同说话人、同语言但跨说话人，各测一遍。

本节的做法是把"语言"实现为与说话人正交的一个分组变量（20 个说话人、3 种语言、说话人 s 的语言是 smod3），因此跨语言划分与跨说话人划分是两个可以独立操作的维度。实测（谱块）：跨说话人 0.5125、跨语言 0.4875、两者叠加 0.4500。叠加的掉分大于任一单项，说明两者不是同一个混淆源。

3.2 语言无关表征的三条路#

路线 做法 代价
特征层归一化 按语言估计均值/方差并做标准化（需要语言标签或语言识别） 需要目标语言的无标注数据；语言识别错误会引入新的失配
对抗去语言 训练一个"语言判别器"，让特征无法预测语言 语言与情感在真实数据里相关，硬去语言会顺手去掉情感信息
多语言联合训练 在多个语言的语料上共享编码器 采集成本；语言间的标注标准不一致会污染标签

判据：三条路都要用同一套交叉设计评估（跨语言同说话人 / 同语言跨说话人 / 两者叠加），否则无法区分"去掉了语言"和"顺带去掉了情感"。

代码#

下面的脚本只用标准库，数据全部合成。它依次做两部分：A 算 Cohen（三种权重）/ Fleiss / Krippendorff 的口径、自助区间、以及多数投票的稳定率；B 用高斯生成模型 + LDA 做韵律/谱/自监督的消融，并测说话人中心化的增益。

"""第 4 章 第 3 节 · 情感与副语言（纯标准库，数据合成）"""
import math
import random

EPS = 1e-30


# ================= A. 标注一致性 =================
def cohen_kappa(a, b, K=5, weights=None):
    n = len(a)
    O = [[0.0] * K for _ in range(K)]
    for x, y in zip(a, b):
        O[x][y] += 1.0
    ma = [sum(O[i]) / n for i in range(K)]
    mb = [sum(O[i][j] for i in range(K)) / n for j in range(K)]
    if weights is None:
        po = sum(O[i][i] / n for i in range(K))
        pe = sum(ma[i] * mb[i] for i in range(K))
    else:
        wmax = max(weights[i][j] for i in range(K) for j in range(K))
        w = [[weights[i][j] / wmax for j in range(K)] for i in range(K)]
        po = 1.0 - sum(w[i][j] * O[i][j] / n for i in range(K) for j in range(K))
        pe = 1.0 - sum(w[i][j] * ma[i] * mb[j] for i in range(K) for j in range(K))
    return (1.0 - (1.0 - po) / (1.0 - pe)) if (1.0 - pe) > EPS else float("nan"), po, pe


def quad_weights(K):
    return [[float((i - j) ** 2) for j in range(K)] for i in range(K)]


def lin_weights(K):
    return [[float(abs(i - j)) for j in range(K)] for i in range(K)]


def fleiss_kappa(table):
    n_items = len(table)
    n_rat = sum(table[0])
    P = [(sum(v * v for v in row) - n_rat) / (n_rat * (n_rat - 1.0)) for row in table]
    pbar = sum(P) / n_items
    pj = [sum(row[j] for row in table) / (n_items * n_rat) for j in range(len(table[0]))]
    pe = sum(p * p for p in pj)
    return (pbar - pe) / (1.0 - pe), pbar, pe


def krippendorff_alpha_ordinal(data, K=5):
    n_units = len(data)
    counts = [[0.0] * K for _ in range(n_units)]
    for u, row in enumerate(data):
        for v in row:
            counts[u][v] += 1.0
    n_total = sum(len(row) for row in data)
    marg = [sum(counts[u][c] for u in range(n_units)) / n_total for c in range(K)]
    Do = 0.0
    for row in data:
        m = len(row)
        if m < 2:
            continue
        for i in range(m):
            for j in range(m):
                if i != j:
                    Do += (row[i] - row[j]) ** 2 / (m - 1.0)
    Do /= n_total
    De = sum(marg[c] * marg[d] * (c - d) ** 2 for c in range(K) for d in range(K))
    De *= n_total / (n_total - 1.0)
    return 1.0 - Do / De if De > EPS else float("nan")


def bootstrap_ci(pairs, fn, B=500, seed=1):
    rng = random.Random(seed)
    vals = []
    n = len(pairs)
    for _ in range(B):
        samp = [pairs[rng.randrange(n)] for _ in range(n)]
        vals.append(fn([p[0] for p in samp], [p[1] for p in samp]))
    vals.sort()
    return vals[int(0.025 * B)], vals[int(0.975 * B)]

def gen_items(n_per_spk, seed, off_scale=1.0):
    r = random.Random(seed)
    items = []
    for s in range(20):
        for _ in range(n_per_spk):

def slice_feats(v, which):
    out = []
    idx = {"rhy": (0, D_RHY), "spec": (D_RHY, D_RHY + D_SPEC),
           "ssl": (D_RHY + D_SPEC, D_ALL)}
    for name in which:
        a, b = idx[name]
        out.extend(v[a:b])
    return out


def lda_fit(X, y, n_cls, dim):
    cnt = [0] * n_cls
    mu = [[0.0] * dim for _ in range(n_cls)]
    for x, c in zip(X, y):
        cnt[c] += 1
        for k in range(dim):
            mu[c][k] += x[k]
    for c in range(n_cls):
        for k in range(dim):
            mu[c][k] /= max(cnt[c], 1)
    cov = [[0.0] * dim for _ in range(dim)]
    for x, c in zip(X, y):
        for i in range(dim):
            for j in range(dim):
                cov[i][j] += (x[i] - mu[c][i]) * (x[j] - mu[c][j])
    n = len(X)
    for i in range(dim):
        for j in range(dim):
            cov[i][j] /= max(n - n_cls, 1)
        cov[i][i] += 1e-6
    return mu, cov


def solve(A, b):
    n = len(b)
    M = [row[:] + [b[i]] for i, row in enumerate(A)]
    for col in range(n):
        p = max(range(col, n), key=lambda r: abs(M[r][col]))
        M[col], M[p] = M[p], M[col]
        pv = M[col][col]
        for j in range(col, n + 1):
            M[col][j] /= pv
        for r in range(n):
            if r != col and M[r][col] != 0.0:
                f = M[r][col]
                for j in range(col, n + 1):
                    M[r][j] -= f * M[col][j]
    return [M[i][n] for i in range(n)]


def lda_score(x, mu, cov):
    dim = len(x)
    out = []
    for c in range(len(mu)):
        diff = [x[k] - mu[c][k] for k in range(dim)]
        w = solve([row[:] for row in cov], diff)
        out.append(-0.5 * sum(diff[k] * w[k] for k in range(dim)))
    return out


def center_by_speaker(X, rows):
    by = {}
    for x, it in zip(X, rows):
        by.setdefault(it[0], []).append(x)
    mu = {s: [sum(v[k] for v in vs) / len(vs) for k in range(len(vs[0]))] for s, vs in by.items()}
    return [[x[k] - mu[it[0]][k] for k in range(len(x))] for x, it in zip(X, rows)]


def evaluate(which, mode, center=False, n_per_spk=40, seed=101):
    items = gen_items(n_per_spk, seed)
    if mode == "random":
        rng3 = random.Random(5)
        idx = list(range(len(items)))
        rng3.shuffle(idx)
        cut = int(0.7 * len(idx))
        tr = [items[i] for i in idx[:cut]]
        te = [items[i] for i in idx[cut:]]
    elif mode == "speaker":
        tr = [it for it in items if it[0] % 5 != 0]
        te = [it for it in items if it[0] % 5 == 0]
    elif mode == "lang":
        tr = [it for it in items if it[1] != 2]
        te = [it for it in items if it[1] == 2]
    else:
        tr = [it for it in items if it[0] % 5 != 0 and it[1] != 2]
        te = [it for it in items if it[0] % 5 == 0 and it[1] == 2]
    Xtr = [slice_feats(it[3], which) for it in tr]
    Xte = [slice_feats(it[3], which) for it in te]
    ytr = [it[2] for it in tr]
    yte = [it[2] for it in te]
    if center:
        Xtr = center_by_speaker(Xtr, tr)
        Xte = center_by_speaker(Xte, te)
    dim = len(Xtr[0])
    mu, cov = lda_fit(Xtr, ytr, N_CLS, dim)
    pr = [lda_score(x, mu, cov).index(max(lda_score(x, mu, cov))) for x in Xte]
    a = sum(1 for p, t in zip(pr, yte) if p == t) / len(yte)
    fs = []
    for c in range(N_CLS):
        tp = sum(1 for p, t in zip(pr, yte) if p == c and t == c)
        fp = sum(1 for p, t in zip(pr, yte) if p == c and t != c)
        fn = sum(1 for p, t in zip(pr, yte) if p != c and t == c)
        precision = tp / (tp + fp) if tp + fp else 0.0
        recall = tp / (tp + fn) if tp + fn else 0.0
        fs.append(2 * precision * recall / (precision + recall) if precision + recall else 0.0)
    return a, sum(fs) / N_CLS, len(tr), len(te)

小结#

  • 情感标签是感知量，它的"真值"是一个分布。所以第一件事不是选模型，而是选一致性口径：无条件 κ、线性/二次加权 κ、Fleiss κ、Krippendorff α 在同一个数据集上可以差 2.3 倍（0.3645→0.8332）。
  • κ 不可跨数据集直接比较。88% 倾斜时，Pe​ 高达 0.5753∼0.7058，κ 被系统性压低（错误率 0.25 时从 0.5493 掉到 0.2642）且自助区间更宽（0.1735 vs 0.1312）。报 κ 必须同时报类别分布与 Pe​。
  • 标注者数量要按"单标注者可靠度"来定。p=0.55 时 5 人投票到 0.8805 是性价比拐点；p=0.40 时 7 人才到 0.8095。而这一切以错误独立为前提。
  • 表征的泛化差距主要来自说话人偏移，而不是语言。跨说话人划分下三块都掉分（自监督掉得最多，−0.0855），而逐说话人中心化几乎免费地补回来（谱 +0.0938、自监督 +0.0875）。这个操作需要每个测试说话人的多条无标签语音。
  • "维度高"不等于"信息多"。自监督块 32 维、∥μ∥2=17.6158 看似最强，但每维信噪比只有 0.5505，与谱块同量级；拼接第三块带来的增益（0.9417→0.9750）主要来自降噪而非新信息。选表征要算每维信息量与块间共线性。
  • 报告规范：情感读数必须带上——一致性口径与权重、类别分布与 Pe​、标注者数与独立性假设、划分方式（随机/跨说话人/跨语言/叠加）、以及是否做了说话人归一化。少任何一项，"我们的 UAR 更高"都不构成可比较的结论。
