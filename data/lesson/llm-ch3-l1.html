掩码语言模型#

前两章的主角 GPT 是"看着左边猜右边"的自回归模型。BERT 走了另一条路：它把句子里的某些词挖掉，让模型同时看左右两边的上下文把词填回来。这个任务叫掩码语言模型（Masked Language Model，MLM），是 BERT 的核心预训练目标，也是"双向理解"能力的关键来源。本课先讲 MLM 的原理与"80/10/10"掩码技巧，再对比它与 GPT 的因果语言模型，最后亲手实现掩码并用 BERT 填空。

一、概念讲解#

1. 从"猜下一个词"到"填空"#

GPT 的自回归目标（因果语言模型，CLM）是预测下一个 token：

P(x_t | x_1, ..., x_{t-1})   只看左边

BERT 的掩码语言模型（MLM）则是：随机遮住输入里的一部分 token，让模型根据它周围所有 token 预测被遮住的原词：

P(x_t | x_1, ..., x_{t-1}, x_{t+1}, ..., x_n)   左右都看

因为被预测的词处在序列中间、两边都有上下文，模型必须学会"双向"地利用信息。这正是 BERT 能比单向模型更好地"读懂"一句话的原因——理解一个词的含义，往往既要看它前面的词，也要看它后面的词。

2. 掩码怎么做：15% 与 80/10/10#

BERT 的训练流程是：从每个输入序列里随机挑 15% 的 token 作为"预测目标"，但这 15% 不是全部换成 [MASK]，而是按 80/10/10 拆成三种处理：

  • 80% 换成特殊 token [MASK]——让模型真正练习"填空"；
  • 10% 换成随机的一个词——逼模型不能"看到 [MASK] 就抄上下文"，而是要判断这里到底是不是原词；
  • 10% 保持原词不变——让模型在"该不该改"上保持谨慎，同时学到"这个词本身也可能就是答案"。

被挑中的 15% 位置才计算损失，其余位置不参与预测。这个"80/10/10"设计是为了弥合预训练与微调之间的差距：微调阶段输入里没有 [MASK] 这个符号，如果预训练时只见过 [MASK]，模型会对它产生"符号依赖"；混入随机词和原词，能让模型在没见到 [MASK] 时也能正常理解。

3. MLM 与 CLM：两种"语言建模"的分野#

维度 因果语言模型（CLM / GPT） 掩码语言模型（MLM / BERT）
预测目标 下一个 token 被遮住的 token
可见上下文 只看左边 左右都看
架构 仅解码器 仅编码器
擅长 生成、续写 理解、分类、抽取
能否直接生成整句 能（自回归） 不能（一次只补一个空）

一句话概括：GPT 擅长"往下写"，BERT 擅长"看懂"。二者不是谁替代谁，而是同一套 Transformer 骨架走向了"生成"与"理解"两个方向。

4. MLM 的局限与改进#

原始 MLM 有几个公认的缺点：

  1. 每个 batch 只学习 15% 的 token：信息利用率低，需要大量训练步数；
  2. [MASK] 在微调阶段不存在：预训练/微调不一致（80/10/10 只是缓解）；
  3. 按"词片"而非"词"掩码：可能把一个词拆成几片分别遮，导致模型靠"半个词"就能蒙对。

后续工作针对性改进：Whole Word Masking 掩掉整个词而非单个子词片段；RoBERTa 用动态掩码（每次 epoch 重新随机掩码）提升多样性；SpanBERT 改成遮掉连续的一段（span）。这些改进都围绕"让模型更充分地利用双向上下文、学到更难的表示"展开。

二、可运行代码示例#

先手写 80/10/10 掩码，看清每一步在做什么：

import random

def apply_mlm_mask(tokens, mask_token="[MASK]", vocab=("apple", "cat", "the"),
                   mask_prob=0.15, rng=None):
    """对 token 列表做 BERT 式掩码，返回 (掩码后的序列, 需要预测的原词)。"""
    rng = rng or random.Random(0)
    out = tokens[:]
    labels = ["-"] * len(tokens)   # 只有被遮的位置才需要预测，其余记 "-"
    for i, tok in enumerate(tokens):
        if rng.random() >= mask_prob:   # 85% 的位置不动
            continue
        r = rng.random()
        if r < 0.8:                     # 80% 换成 [MASK]
            out[i] = mask_token
        elif r < 0.9:                   # 10% 换成随机词
            out[i] = rng.choice(vocab)
        # 剩下 10% 保持原词不变
        labels[i] = tok                 # 无论哪种处理，模型都要预测原词
    return out, labels

tokens = ["the", "cat", "sat", "on", "the", "mat"]
masked, labels = apply_mlm_mask(tokens)
print("原文  :", tokens)
print("掩码后:", masked)
print("需预测:", labels)

运行几次（换 rng 种子）你会看到：被挑中的位置有的变成 [MASK]，有的被随机词顶替，有的原封不动，但 labels 里都记下了原词——因为模型的最终任务是"预测原词是什么"。

再用真正的 BERT 做一次"填空"：

from transformers import pipeline

# fill-mask 管道内部就是一个在 MLM 目标上预训练好的 BERT
mlm = pipeline("fill-mask", model="bert-base-uncased")
result = mlm("The capital of France is [MASK].")
for item in result:
    print(f"{item['token_str']:>10}  得分 {item['score']:.4f}")

BERT 会给出 Paris 等高分候选。注意它靠的是 [MASK] 左右两边的 "capital of France" 和句号——这就是"双向上下文"在起作用，也是自回归模型（只看左边）做不到的推理方式。

三、练习#

  1. 把 apply_mlm_mask 的 mask_prob 从 0.15 改成 0.5，观察掩码后的序列，解释为什么 BERT 不把比例设得这么高（提示：上下文信息还剩下多少、预测难度如何变化）。
  2. 修改代码，把 vocab 去掉 "cat"，多次运行观察"10% 随机替换"是否还会替换成 "cat"，理解随机替换词的来源。
  3. 用 fill-mask 管道测试 "The [MASK] is barking loudly."，观察模型是否填出 dog，并说明它利用了哪一侧的上下文。
  4. 思考题：为什么 BERT 不能像 GPT 那样逐词生成一整句话？结合"MLM 一次只补一个空、没有自回归的因果链"来解释。
