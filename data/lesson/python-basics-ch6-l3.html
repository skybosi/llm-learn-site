继承与多态#

一、概念讲解#

写程序时经常会遇到"很多类有共同点"的情况。比如猫、狗、鸟都是动物，它们都会叫、都有名字。如果每个类都把"名字""年龄""会叫"这些共同代码抄一遍，既啰嗦又容易出错。

继承（inheritance） 就是来解决这个问题的：让新类"继承"已有类的属性和方法，只需额外写自己不同的地方。

1. 继承的写法#

继承的语法很简单，在类名后面的括号里写上要继承的类：

class Animal:                        # 父类（也叫基类）
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} 发出了声音。")


class Dog(Animal):                   # 子类：继承 Animal
    pass                             # 暂时什么都不加

class Dog(Animal) 里的 Animal 表示"Dog 继承自 Animal"。因为 Dog 里只有 pass，它完全沿用了父类的属性和方法：

d = Dog("旺财")
d.speak()        # 旺财 发出了声音。
print(d.name)    # 旺财

我们把被继承的类叫父类，继承别人的类叫子类。

2. 重写（override）父类方法#

子类可以定义和父类同名的方法，把父类的行为"覆盖"掉，这叫重写：

class Dog(Animal):
    def speak(self):                 # 重写 speak
        print(f"{self.name} 在汪汪叫！")

class Cat(Animal):
    def speak(self):
        print(f"{self.name} 在喵喵叫！")

现在，同样调用 speak，不同对象会表现出不同的行为：

Dog("旺财").speak()   # 旺财 在汪汪叫！
Cat("咪咪").speak()   # 咪咪 在喵喵叫！

3. 用 super() 调用父类#

如果子类的 __init__ 也想保留父类的初始化逻辑，又额外加点自己的东西，可以用 super()：

class Dog(Animal):
    def __init__(self, name, breed):   # 多了一个品种参数
        super().__init__(name)         # 先调用父类的 __init__ 设置 name
        self.breed = breed             # 再设置自己的品种

d = Dog("旺财", "金毛")
print(d.name, d.breed)   # 旺财 金毛

super() 可以理解为"我的父类"。super().__init__(name) 就是"请父类的初始化方法处理 name 这个参数"。

4. 多态#

多态（polymorphism） 是一个听上去吓人、其实很简单的概念：不同的对象，对同一个方法名可以做出不同的反应。

比如我们有一个 make_sound(animal) 函数，它不关心你传进来的是狗还是猫，只管调用 speak，而具体怎么叫由对象自己决定：

def make_sound(animal):
    animal.speak()

make_sound(Dog("旺财"))   # 旺财 在汪汪叫！
make_sound(Cat("咪咪"))   # 咪咪 在喵喵叫！

多态的好处：以后你想加一种"鸟"，只要写一个 Bird 类并实现自己的 speak，make_sound 函数一行都不用改。

二、可运行代码示例#

# ---- 1. 父类 ----
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} 发出了声音。")

    def info(self):
        print(f"我是一只叫 {self.name} 的动物。")


# ---- 2. 子类，各自重写 speak ----
class Dog(Animal):
    def speak(self):
        print(f"{self.name} 在汪汪叫！")

class Cat(Animal):
    def speak(self):
        print(f"{self.name} 在喵喵叫！")

class Bird(Animal):
    def __init__(self, name, can_fly):
        super().__init__(name)      # 复用父类的 name 初始化
        self.can_fly = can_fly      # 新增自己的属性

    def speak(self):
        print(f"{self.name} 在叽叽喳喳！")


# ---- 3. 多态：同一个函数，处理不同对象 ----
def let_speak(animal):
    animal.speak()

animals = [Dog("旺财"), Cat("咪咪"), Bird("小翠", True)]
for a in animals:
    a.info()          # info 未被子类重写，用的是父类的实现
    let_speak(a)      # 多态：各叫各的
    print("---")

# ---- 4. isinstance：判断对象是不是某个类的实例 ----
print(isinstance(animals[0], Dog))       # True
print(isinstance(animals[0], Animal))    # True（子类实例也算父类）
print(isinstance(animals[0], Cat))       # False

三、练习#

  1. 定义一个 Vehicle（交通工具）父类，有 brand 属性和 move 方法；再定义 Car、Bike 两个子类，分别重写 move 方法（例如汽车"在路上行驶"、自行车"慢慢骑行"）。
  2. 定义一个 run_all(vehicles) 函数，接收一个交通工具列表并依次调用它们的 move 方法，体会多态的效果。
  3. 给 Car 的 __init__ 增加一个 seats（座位数）参数，用 super().__init__ 复用父类的初始化逻辑，并打印 brand 和 seats。
  4. 思考题：为什么说"多态让代码更好扩展"？如果现在要新增一种 Ship 交通工具，run_all 函数需要修改吗？为什么？
