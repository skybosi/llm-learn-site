ERM 统一框架#

上一课我们把"学习"定义成了三件事：假设空间、损失函数、经验风险。这一课我们把这三件事拼成一个完整的优化问题，并且搞清楚：为什么说"天下所有监督学习算法，都是同一个公式的不同填法"？我们会看到，线性回归、逻辑回归、SVM 这些看似迥异的算法，其实只是换了 ℋ 和 ℓ 而已——公式没变，变的是零件。

一、概念讲解#

1. ERM 的标准形式#

经验风险最小化可以写成下面这个统一的最优化问题：

minimize_h     L_S(h) = (1/m) · Σᵢ₌₁ᵐ ℓ(h(xᵢ), yᵢ)
subject to     h ∈ ℋ

如果假设空间 ℋ 由参数向量 θ ∈ Θ 参数化（比如 h_θ(x) = wᵀx + b 中的 θ = (w, b)），问题就变成更常见、可直接求解的形式：

minimize_θ     J(θ) = (1/m) · Σᵢ₌₁ᵐ ℓ(h_θ(xᵢ), yᵢ)
subject to     θ ∈ Θ

其中 J(θ) 就是"损失函数（代价函数）"。注意一个术语上的细微差别：ℓ 是单样本的损失，J = (1/m)Σℓ 是全训练集的平均损失。日常口语常把两者都叫"损失函数"，但推导时务必分清。

这个框架的威力在于它的正交性：ℋ（模型长什么样）与 ℓ（怎么算错）可以独立替换、自由组合。于是"发明一个新算法"= "选一个新的 ℋ-ℓ 组合"。

2. 三个零件的角色#

  • 假设空间 ℋ 决定"表达能力"：ℋ 越大，越可能包含接近真实 f 的函数，但搜索也越难、越容易过拟合。ℋ 的大小是"偏差"的根源（第 4 章）。
  • 损失函数 ℓ 决定"优化目标的地形"：ℓ 决定了 J(θ) 是凸是凹、有没有平滑梯度、梯度会不会消失。一个"好"的 ℓ 应当让 J 凸且可导——这样优化既稳又快。
  • 训练集 S 决定"信息上限"：S 是从 𝒟 采样的有限样本，S 越大，经验风险越接近期望风险。数据是唯一能"凭空"降低泛化误差的资源。

3. 从 ERM 到具体算法的"四步走"#

任何监督学习算法，都能按下面四步从 ERM 框架里"生成"出来：

  1. 定假设空间 ℋ：选一类函数（线性？多项式？神经网络？）。
  2. 定损失函数 ℓ：平方损失？0-1 损失？交叉熵？合页损失？
  3. 写经验风险 J(θ) = (1/m)Σℓ：把 ℓ 对训练集求和取平均。
  4. 解最优化：解析解（求导令梯度为 0）或数值解（梯度下降及其变体）。

第 4 步正是把"学习问题"翻译成"优化问题"的桥梁，也是为什么优化理论（凸优化）是机器学习的第一数学支柱。

4. 解析解 vs 数值解：两种求最小值的路线#

当 J(θ) 关于 θ 可导且梯度方程有封闭解时，可以解析求解：令 ∇_θ J(θ) = 0，解出 θ。线性回归的正规方程 w = (XᵀX)⁻¹Xᵀy 就是典型例子——但它的前提是 J 凸且 XᵀX 可逆。

当 J 不可导、非凸、或维度太高无法求逆时，就用数值迭代：从某点出发，沿负梯度方向一步步走：

θ ← θ − α · ∇_θ J(θ)

α 是学习率。梯度下降之所以能work，靠的是一阶泰勒展开：J(θ − αg) ≈ J(θ) − α‖g‖²，当 α 足够小时函数值必然下降。这个"沿负梯度必下降"的直觉，是后面所有优化课的起点。

5. 一个必然的追问：为什么还要正则化？#

ERM 只要求"训练集上损失最小"，但我们的真实目标是"期望风险最小"。当 ℋ 很大时，ERM 的最优解会过拟合。于是人们在经验风险后加一个惩罚项，得到结构风险最小化（Structural Risk Minimization, SRM）：

minimize_θ   J(θ) = (1/m) · Σᵢ ℓ(h_θ(xᵢ), yᵢ) + λ · R(θ)

R(θ) 是正则项（通常是参数的某种范数），λ ≥ 0 控制惩罚强度。SRM 的思想是：不要只看"拟合得多好"，还要看"模型本身多复杂"。第 3 章我们会从贝叶斯视角证明，这个看似拍脑袋加出来的 λR(θ)，其实等价于"对参数施加先验分布"——正则化不是技巧，而是概率论的必然推论。

二、可运行代码示例#

下面用一个统一的 ERM 骨架，分别实现"平方损失 + 线性模型"（线性回归）和"合页损失 + 线性模型"（SVM 的雏形），验证同一个优化流程只需替换 ℓ 就能得到不同算法。

import numpy as np

rng = np.random.default_rng(0)

# 造一个二分类数据集：两类点大致被超平面分开
m = 200
X = rng.normal(0, 1, size=(m, 2))
true_w = np.array([2.0, -1.0])
y = (X @ true_w + rng.normal(0, 0.5, size=m) > 0).astype(float)  # 0/1 标签
y_bin = 2 * y - 1                                # 转成 ±1，方便合页损失

def risk(theta, X, y, loss):
    """统一 ERM 骨架：给定参数和损失，返回经验风险 + 梯度"""
    return loss(theta, X, y)

def squared_regression(theta, X, y):
    """平方损失 + 线性模型（线性回归）"""
    r = X @ theta - y
    return float(np.mean(r ** 2)), 2.0 / len(y) * X.T @ r

def hinge_svm(theta, X, y):
    """合页损失 + 线性模型（SVM 雏形），y 为 ±1"""
    margin = y * (X @ theta)          # 正确且边界大 => margin 大
    loss = np.maximum(0, 1 - margin)
    grad = np.where(margin < 1, -y[:, None] * X, 0.0)
    return float(np.mean(loss)), np.mean(grad, axis=0)

def train(X, y, loss_fn, steps=500, lr=0.05):
    theta = np.zeros(X.shape[1])
    for _ in range(steps):
        val, g = loss_fn(theta, X, y)
        theta = theta - lr * g
    return theta

th_reg = train(X, y,      squared_regression)
th_svm = train(X, y_bin,  hinge_svm)
print("平方损失(回归)求出的 θ =", np.round(th_reg, 4))
print("合页损失(分类)求出的 θ =", np.round(th_svm, 4))

同一个 train 函数、同一条"计算损失 → 算梯度 → 更新参数"的流水线，只把 ℓ 从平方损失换成合页损失，就从"回归器"变成了"分类器"。这就是 ERM 统一框架最直观的体现：骨架恒定，零件可换。

三、练习#

  1. 在 squared_regression 里把平方损失换成绝对损失 |r|，写出它的（次）梯度。绝对损失在 r = 0 处有什么问题？这提示了"不可导损失"为何需要次梯度概念。
  2. 手推：当 ℋ 是一元线性函数、ℓ 是平方损失时，J(w, b) 关于 w 和 b 的梯度各是什么？令它们为 0，解出与正规方程一致的解析解。
  3. 把上面的 steps 改成 5 再运行，观察参数离最优解多远。这说明了数值解"精度受迭代次数限制"的特点，与解析解的区别在哪？
  4. 思考：λ R(θ) 里的 λ 从 0 逐渐增大时，J(θ) 的最优解会朝哪个方向移动？为什么说 λ 是在"拟合"与"简单"之间做权衡？

母原理连接#

本课是母原理 "一切学习 = 优化" 的骨架课。ERM 把千差万别的算法统一成"选 ℋ、选 ℓ、求最小"三件事，并把学习问题干净地翻译成了优化问题。记住这张"三件套"地图，后面第 2 章讲"损失从哪来"、第 3 章讲"正则从哪来"、第 4 章讲"经验最小为何不等于期望最小"，都能在这张地图上找到坐标。
