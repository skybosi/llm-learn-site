DBSCAN 实现与参数#

一、概念讲解#

1.1 上一课的回顾#

上一课我们理解了 DBSCAN 的密度视角：核心点、边界点、噪声点，以及"通过密度可达把密集区域连成任意形状的簇"。这一课聚焦实践中最难、也最关键的一环——如何调好 eps 和 min_samples 这两个参数。

对 K-means 来说，最难的是选 K；对 DBSCAN 来说，最难的是选 eps。DBSCAN 对这两个参数相当敏感：eps 差一点，结果可能天差地别。因此，参数选择不是"随便试"，而是有一套可循的方法。

1.2 参数含义与影响#

  • min_samples：通常可以凭经验先定。一个常用的经验值是 2 * 特征数，或者干脆取较小的值（如 5）。它控制"多密才算密"：值越大，成为核心点的门槛越高，簇越少、噪声越多。一般来说，先固定一个合理的 min_samples，再专心调 eps，是更高效的策略。
  • eps：影响最大。eps 太小，几乎所有点都不够"核心"，结果满盘皆噪声；eps 太大，所有密集区域被连成一个大簇，聚类失去意义。因此 eps 要"恰好"落在数据本身的密度尺度上。

一个直观的理解：min_samples 决定"门槛的高度"，eps 决定"邻域画多大"，两者共同决定一个点够不够格当核心点。

1.3 用 k-距离图选择 eps#

选择 eps 最经典的方法是k-距离图（k-distance plot）：

  1. 对每个样本，计算它到第 k 近邻居的距离（k 通常取 min_samples - 1 或 min_samples）；
  2. 把这些距离从小到大排序，画成一条曲线；
  3. 曲线会先平缓上升，然后在某处突然变陡——陡增之前的那个"拐点"处对应的距离，往往就是合适的 eps。

背后的直觉是：在密集区域内部，点与点之间天然很近，距离增长缓慢；一旦跨出密集区、进入稀疏区，最近邻距离会突然拉大。这个"从密到疏"的转折点，正是该用来当 eps 的尺度。

注意：k-距离图给出的是一个"起点"，实际使用时仍需在拐点附近做微调，并结合簇数与噪声占比是否合理来判断。

1.4 sklearn 的 DBSCAN 关键参数#

sklearn 的 DBSCAN 参数不多，但个个关键：

  • eps：邻域半径，默认 0.5。强烈建议结合数据的尺度手动设定（先标准化再设定），默认值在大多数真实数据上都不合适。
  • min_samples：核心点的最小邻居数，默认 5。
  • metric：距离度量，默认欧氏距离 'euclidean'。
  • algorithm：近邻搜索算法，默认 'auto'，一般无需改动。

使用前的一个必做动作是标准化特征：因为 eps 是一个绝对距离值，若特征量纲差异巨大，同一个 eps 在不同维度上的"含义"会完全不同，聚类结果会被量纲大的特征主导。

二、可运行代码示例#

下面走一遍完整流程：生成数据 → 标准化 → 用 k-距离图找 eps → 训练 DBSCAN → 可视化并分析噪声。

# -*- coding: utf-8 -*-
# 第 2 课：DBSCAN 完整实现与参数选择
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import DBSCAN
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_blobs
from sklearn.neighbors import NearestNeighbors

# 1. 生成数据：三个球形簇 + 一些散落的噪声点
X, _ = make_blobs(n_samples=300, centers=3,
                  cluster_std=0.6, random_state=42)
rng = np.random.RandomState(7)
noise = rng.uniform(low=-10, high=10, size=(20, 2))  # 20 个离群点
X = np.vstack([X, noise])

# 2. 标准化：让 eps 在不同维度上尺度一致
X_scaled = StandardScaler().fit_transform(X)

# 3. 用 k-距离图找 eps（k 取 min_samples-1 = 4）
min_samples = 5
nn = NearestNeighbors(n_neighbors=min_samples)
nn.fit(X_scaled)
distances, _ = nn.kneighbors(X_scaled)
# 每个样本到第 4 近邻居的距离，排序后画图
k_dist = np.sort(distances[:, -1])
plt.figure(figsize=(8, 4))
plt.plot(k_dist)
plt.xlabel("样本（按距离排序）")
plt.ylabel("到第 4 近邻居的距离")
plt.title("k-距离图（用于选择 eps）")
plt.show()

# 4. 根据上图拐点选择 eps（这里取 0.3 作为示例），训练 DBSCAN
db = DBSCAN(eps=0.3, min_samples=min_samples)
labels = db.fit_predict(X_scaled)

# 5. 分析结果
n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise = int(np.sum(labels == -1))
print("簇数（不含噪声）：", n_clusters)
print("噪声点数量：", n_noise)

# 6. 可视化：噪声点用黑色标记
plt.figure(figsize=(6, 5))
plt.scatter(X_scaled[:, 0], X_scaled[:, 1], c=labels, s=20, cmap="viridis")
plt.scatter(X_scaled[labels == -1, 0], X_scaled[labels == -1, 1],
            c="black", s=30, marker="x", label="噪声")
plt.title(f"DBSCAN 聚类结果（eps=0.3, 簇数={n_clusters}, 噪声={n_noise}）")
plt.legend()
plt.show()

输出解读：k-距离图在曲线陡升处给出了 eps 的候选值。选定 eps 后，DBSCAN 不仅正确地找出了 3 个密集簇，还用黑色叉号把 20 个散落噪声点单独标记出来——这是 K-means 和层次聚类默认做不到的（它们会把噪声硬塞进某个簇）。

提示：若拐点不明显，可在候选值附近多试几个 eps，观察"簇数、噪声占比"是否稳定合理，择优而取。

三、练习小节#

  1. 把 eps 固定为 0.3，分别把 min_samples 设为 2、5、10、20，观察簇数和噪声数的变化，解释 min_samples 增大会带来什么趋势。
  2. 反过来，把 min_samples 固定为 5，把 eps 从 0.1 逐步调到 1.0，记录簇数与噪声数的变化，描述"eps 太小 → 合适 → 太大"三个阶段的现象。
  3. 解释为什么 DBSCAN 使用前必须标准化特征；如果跳过标准化，eps 的含义会发生什么偏差？
  4. 用 make_moons 生成月牙数据，手动用 k-距离图选 eps，看 DBSCAN 能否正确分出两个月牙；再用 K-means（K=2）对比。
