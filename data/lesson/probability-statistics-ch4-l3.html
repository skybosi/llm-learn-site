泊松分布与其他常用分布#

这一课补齐概率分布的"常用全家桶"。除了已经学过的伯努利、二项、正态，还有一类描述"单位时间 / 单位空间里发生多少次事件"的泊松分布，以及均匀、指数、几何等在各处露脸的配角。学完这一章，你就拥有一套识别"数据该套哪个分布"的基本直觉。

一、概念讲解#

1. 泊松分布：给"随机事件流"计数#

假设一个客服中心平均每小时接到 λ 个电话，这些电话在时间上随机、彼此独立地到来。那么"一个小时里恰好接到 k 个电话"的概率，就服从泊松分布（Poisson distribution）：

P(X = k) = (λ^k · e^(−λ)) / k!，其中 k = 0, 1, 2, …

泊松分布只有一个参数 λ，它同时等于期望和方差：

  • E[X] = λ
  • Var(X) = λ

一个非常特别的性质：期望 = 方差 = λ。所以如果你发现某份计数数据的均值 ≈ 方差，泊松分布往往是合理的第一选择。

它常用于：网站每小时访问量、一页书上的错别字数、一段时间内的交通事故数、序列模型里"事件到达"的建模。

2. 均匀分布：所有取值等可能#

连续均匀分布 Uniform(a, b) 在区间 [a, b] 上每个点的密度都相同：

f(x) = 1 / (b − a)，当 a ≤ x ≤ b

它的期望是 (a + b) / 2。均匀分布最常见的用途是：随机数生成（random.random() 就是 [0,1) 均匀分布）、以及贝叶斯里表达"我对参数一无所知"的朴素先验。

3. 指数分布：等待下一次事件的时间#

泊松分布描述"事件个数"，而指数分布 Exp(λ) 描述"从此刻到下一次事件发生的等待时间"。它是一个连续分布，PDF 为：

f(x) = λ · e^(−λx)，当 x ≥ 0

它的期望是 1/λ。这正是"事件越频繁（λ 越大），平均等待时间越短"的体现。指数分布具有无记忆性：已经等了多久，不影响还要等多久——就像一台不会老化的设备。

4. 几何分布：第一次成功前失败的次数#

几何分布 Geometric(p) 回答"连续做伯努利试验，直到第一次成功，之前已经失败了多少次"。它的 PMF 是：

P(X = k) = (1 − p)^k · p，其中 k = 0, 1, 2, …

期望为 (1 − p) / p。它经常用来建模"重复尝试直到命中的场景"。

5. 一张关系图：它们如何互相关联#

这些分布并不是孤立的，它们之间有清晰的血缘关系：

  • 伯努利 →（重复 n 次求和）→ 二项；
  • 二项（n 很大、p 很小、np=λ 固定）→ 泊松；
  • 泊松（事件个数）↔ 指数（等待时间）互为镜像；
  • 二项 / 泊松（n 或 λ 很大时）→ 近似正态。

抓住这张图，你就理解了"为什么这些分布会一起出现"。

6. 在机器学习中的位置#

  • 泊松：推荐系统的曝光次数、神经科学中的脉冲发放、计数型回归的似然；
  • 指数 / 几何：生存分析、用户流失建模、强化学习中的"首次到达"；
  • 均匀：随机初始化、蒙特卡洛采样、无信息先验。

二、可运行示例#

下面的代码生成三种分布的样本，验证它们的期望 / 方差，并画出对比图。

import numpy as np
from math import exp, factorial
import matplotlib.pyplot as plt

np.random.seed(0)

# ---- 1. 泊松分布：λ=4，模拟"每小时来电次数" ----
lam = 4
poisson_samples = np.random.poisson(lam=lam, size=20000)
print("泊松：均值", poisson_samples.mean(), "方差", poisson_samples.var(),
      "（两者都应接近 λ =", lam, "）")

# ---- 2. 自己实现泊松 PMF，验证概率和为 1 ----
def poisson_pmf(k, lam):
    """泊松分布 P(X=k) = λ^k * e^{-λ} / k!"""
    return (lam ** k) * exp(-lam) / factorial(k)

ks = np.arange(0, 20)
pmf = np.array([poisson_pmf(k, lam) for k in ks])
print("泊松 PMF 前 20 项之和：", round(pmf.sum(), 6), "（应接近 1）")

# ---- 3. 指数分布：λ=0.5，模拟"等待时间" ----
lam_exp = 0.5
exp_samples = np.random.exponential(scale=1 / lam_exp, size=20000)
print("指数：均值", exp_samples.mean(), "（理论值 1/λ =", 1 / lam_exp, "）")

# ---- 4. 均匀分布 Uniform(2, 6) ----
uni_samples = np.random.uniform(low=2, high=6, size=20000)
print("均匀：均值", uni_samples.mean(), "（理论值 (2+6)/2 = 4.0）")

# ---- 5. 几何分布：p=0.3 ----
p_geo = 0.3
geo_samples = np.random.geometric(p=p_geo, size=20000) - 1  # numpy 是从 1 开始计，减 1 对齐"失败次数"
print("几何：均值", geo_samples.mean(), "（理论值 (1-p)/p =", (1 - p_geo) / p_geo, "）")

# ---- 6. 画泊松与指数对比图 ----
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].hist(poisson_samples, bins=np.arange(0, 16) - 0.5, density=True,
             alpha=0.6, label="模拟直方图")
axes[0].plot(ks, pmf, "o-", color="red", label="理论 PMF")
axes[0].set_title(f"泊松分布 λ={lam}")
axes[0].set_xlabel("事件个数 k")
axes[0].set_ylabel("概率")
axes[0].legend()

axes[1].hist(exp_samples, bins=60, density=True, alpha=0.6)
x = np.linspace(0, 20, 300)
axes[1].plot(x, lam_exp * np.exp(-lam_exp * x), "r-", label="理论 PDF")
axes[1].set_title(f"指数分布 λ={lam_exp}")
axes[1].set_xlabel("等待时间")
axes[1].legend()
plt.tight_layout()
plt.show()

预期输出（部分）：

泊松：均值 3.9864 方差 4.0309 （两者都应接近 λ = 4 ）
泊松 PMF 前 20 项之和： 0.999999 （应接近 1）
指数：均值 2.0263 （理论值 1/λ = 2.0 ）
均匀：均值 4.0036 （理论值 (2+6)/2 = 4.0 ）
几何：均值 2.3138 （理论值 (1-p)/p = 2.3333 ）

要点：所有模拟样本的均值 / 方差都与理论值高度吻合；自己写出的泊松 PMF 累加接近 1，说明公式正确。

三、练习#

  1. 识别分布：下列场景各适合哪个分布？（a）抽 10 张牌中红牌张数；（b）网站每小时访问量；（c）两台服务器故障之间的时间；（d）骰子掷到 6 前掷的次数。
  2. 计算：某路口平均每小时 2 起事故（泊松）。求"一小时恰好 0 起"和"至少 1 起"的概率，用上面的 poisson_pmf 验证。
  3. 验证无记忆性：改写指数分布代码，筛选出"已经等待超过 5"的样本，看看它们"再等超过 5"的比例是否仍等于理论值 e^(−λ·5)。
  4. 思考：泊松分布要求事件"随机独立到来"。现实中哪些计数数据可能违反这个假设？为什么？
