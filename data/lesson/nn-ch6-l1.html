过拟合#

到现在，我们已经能让网络"学会"训练数据了。但学会训练数据 ≠ 学会问题本身。一个经典困境是：模型在训练集上表现越来越好，在没见过的数据上却越来越差——这就是过拟合（overfitting）。它是神经网络（尤其是参数众多的深层网络）最容易犯的毛病，也是第 6 章要集中对付的头号敌人。本课先把它看透，再介绍第一件武器：权重衰减（L1/L2 正则化）。

一、概念讲解#

1. 过拟合与欠拟合#

  • 欠拟合（underfitting）：模型太简单，连训练数据都学不好，训练损失和验证损失都很高。
  • 过拟合（overfitting）：模型太复杂，把训练数据里的噪声和偶然规律也背了下来。训练损失很低，验证损失却很高——两者之间拉开一道明显的"鸿沟"。
  • 恰到好处：模型抓住了数据背后的普遍规律，训练与验证损失都低且接近。

判断标准很简单：训练损失低、验证损失也低 → 好；训练低、验证高 → 过拟合；两者都高 → 欠拟合。

2. 为什么会过拟合：容量与噪声#

网络参数量巨大（"容量"高），而训练数据有限。当模型的"记忆容量"远超数据量时，它就会去记住每一个训练样本的细节，包括噪声。好比一个学生把练习册答案全背下来，却不理解公式——换个新题就露馅。数据越少、模型越大、噪声越多，过拟合越严重。

3. 偏差—方差视角#

过拟合可以理解为高方差：训练集稍微换一批样本，学到的模型就大不相同，说明它"过度贴合"某一批数据。欠拟合则是高偏差：模型假设本身就不对，换多少数据都救不了。好的模型要在偏差与方差之间取得平衡——既不要太简单（高偏差），也不要复杂到记噪声（高方差）。

4. 正则化总览#

正则化（regularization）是所有"抑制过拟合"手段的总称，核心思想是：给模型加约束，限制它的复杂度，逼它只学普遍规律、别去记噪声。常见手段有：

手段 思路 对应课时
权重衰减（L1/L2） 惩罚过大的权重 本课
Dropout 随机丢弃神经元，强制冗余 下一课
批量归一化 / 早停 稳定训练 / 及时停止 第 3 课
数据增强 / 更多数据 从源头增加多样性 后续课程

5. L1 / L2 权重衰减#

权重衰减的做法是：在损失函数里加一项惩罚"权重过大"的正则项：

L₂ 正则：L_total = L_原 + λ · Σ w²    （权重平方和）
L₁ 正则：L_total = L_原 + λ · Σ |w|   （权重绝对值之和）

λ 是正则强度（越大约束越强）。直觉：如果模型要靠"极大的权重"才能记住某个噪声点，那么这一项会狠狠惩罚它，逼模型放弃这种记忆。两者区别：

  • L2：让权重普遍变小但不稀疏，梯度光滑，最常用。
  • L1：让一部分权重恰好变成 0，起到"特征选择"作用，模型更稀疏。

PyTorch 里，L2 权重衰减极其方便——优化器的 weight_decay 参数直接就是 λ，无需手动改损失函数。

二、可运行示例#

下面用一个小数据集 + 大模型，制造一次真实的过拟合，再用 L2 权重衰减缓解它。

import torch
import torch.nn as nn

torch.manual_seed(0)

# —— 构造"小数据 + 噪声"：只有 30 个训练点 ——
x = torch.linspace(-3, 3, 30).view(-1, 1)
y = torch.sin(x) + 0.4 * torch.randn_like(x)   # 明显噪声

# 验证集：同样分布的另一批点，训练时绝不使用
x_val = torch.linspace(-3, 3, 30).view(-1, 1)
y_val = torch.sin(x_val) + 0.4 * torch.randn_like(x_val)

def make_big_net():
    # 一个很大的 MLP，容量远超 30 个点，容易过拟合
    return nn.Sequential(
        nn.Linear(1, 128), nn.Tanh(),
        nn.Linear(128, 128), nn.Tanh(),
        nn.Linear(128, 128), nn.Tanh(),
        nn.Linear(128, 1),
    )

loss_fn = nn.MSELoss()

def train(weight_decay=0.0, epochs=2000):
    net = make_big_net()
    opt = torch.optim.Adam(net.parameters(), lr=0.01,
                           weight_decay=weight_decay)  # weight_decay 即 L2 正则 λ
    for epoch in range(epochs):
        opt.zero_grad()
        loss = loss_fn(net(x), y)
        loss.backward()
        opt.step()
    with torch.no_grad():
        train_loss = loss_fn(net(x), y).item()
        val_loss = loss_fn(net(x_val), y_val).item()
    return train_loss, val_loss

# 不加正则：训练损失极低，验证损失明显更高 -> 过拟合
tr, va = train(weight_decay=0.0)
print(f"[无正则]     训练损失 = {tr:.4f}, 验证损失 = {va:.4f}, 差距 = {va - tr:.4f}")

# 加 L2 权重衰减：验证损失下降，训练-验证差距缩小
tr, va = train(weight_decay=1e-2)
print(f"[L2 λ=1e-2]  训练损失 = {tr:.4f}, 验证损失 = {va:.4f}, 差距 = {va - tr:.4f}")

# 加大正则强度：约束过强，验证损失反而回升（欠拟合苗头）
tr, va = train(weight_decay=1.0)
print(f"[L2 λ=1.0]   训练损失 = {tr:.4f}, 验证损失 = {va:.4f}, 差距 = {va - tr:.4f}")

运行后：无正则时"训练/验证差距"很大（过拟合）；加适度的 L2 后差距明显缩小、验证损失下降；但 λ 过大时模型被约束过头，验证损失又回升。这说明正则强度需要调到一个合适的中间值。

三、练习#

  1. 对比 L1：手动实现 L1 正则——在损失里加 λ * sum(|w|) 项（用 torch.abs(w).sum()），代替 weight_decay 跑一遍，观察收敛后有多少权重接近 0。
  2. 改数据量：把训练点从 30 个增加到 300 个（噪声不变），再跑无正则版本，观察过拟合是否明显缓解，说明"更多数据"为何是最好用的正则化。
  3. 判断三态：分别用"极小模型（1 层 2 个神经元）"和"示例中的大模型"训练，打印训练/验证损失，判断哪个欠拟合、哪个过拟合。
  4. 思考：为什么 L2 正则的梯度形式等价于"每次更新前把权重乘一个略小于 1 的系数"（这就是"权重衰减"名字的由来）？请写出带 L2 项后 ∂L_total/∂w 的表达式。
  5. 前瞻：L2 是"从权重角度"抑制过拟合。下一课要讲的 Dropout 则是"从神经元角度"抑制过拟合。想想这两种视角有什么不同。
