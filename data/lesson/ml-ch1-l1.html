什么是机器学习#

在学完 NumPy 和 Pandas 之后，你已经能用代码加载、清洗、统计和展示数据了。但到目前为止，所有的计算规则（"把面积乘以单价""筛选出价格大于 300 万的房子"）都是你自己手写的。机器学习要回答的问题是：能不能让计算机从数据里自己把规律学出来？

一、概念讲解#

1. 传统编程 vs 机器学习#

传统编程和机器学习解决问题的思路是"倒过来"的：

  • 传统编程：人先想清楚规则（算法），再把规则写成代码，输入数据，得到答案。公式是：数据 + 规则 → 答案。
  • 机器学习：人只给机器一批"数据 + 已知答案"，让机器自己总结出规则，再拿规则去处理没见过的新数据。公式是：数据 + 答案 → 规则。

举一个真实的例子——预测房价。传统做法是：你观察市场，拍脑袋定一个公式，比如"房价 ≈ 面积 × 1.5 + 20"。而机器学习的做法是：收集 1000 条真实成交记录（面积、楼层、房龄、成交价），让算法自动算出一组"最贴合这些数据"的系数，然后用这组系数去预测新房子的价格。当数据规律很复杂（几十个特征、非线性关系）时，人很难手写规则，机器学习就能派上用场。

2. 机器学习的定义#

机器学习是让计算机在没有被显式编程的情况下，通过经验（数据）改进自身表现的方法。它通常包含几个关键概念：

  • 样本（Sample）：数据集里的一行，例如一条成交记录。
  • 特征（Feature）：描述样本的属性，例如面积、房龄、楼层。在 Pandas 里就是某一列。
  • 标签（Label / Target）：我们想预测的那个量，例如房价。监督学习中它是已知的。
  • 模型（Model）：从数据中学到的"规律"的数学表达，例如一条直线的斜率和截距。
  • 训练（Training）：让模型反复观察数据、调整参数以减小误差的过程。

3. 为什么现在机器学习这么普及#

  • 数据多了：互联网、传感器、交易系统每天都在产生海量结构化数据（正好是 Pandas 擅长的表格数据）。
  • 算力便宜了：普通电脑也能训练中小规模模型。
  • 工具成熟了：scikit-learn 这类库把几十种算法统一成"几行代码"的接口，降低了门槛。

一句话总结本课：机器学习的核心不是写规则，而是让模型从"特征 → 标签"的数据里自动学到映射关系。

二、可运行代码示例#

下面这个例子会直观展示"让模型自己学"和"人手工定公式"的区别。我们用一条真实的线性规律（面积 → 房价）加上一点噪声来模拟真实成交数据，然后让 scikit-learn 的 LinearRegression 从数据里把系数学出来。

import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 模拟真实成交数据：面积（平方米）与房价（万元）
# 真实规律是 price = 1.2 * area + 30，再加上随机噪声模拟市场波动
rng = np.random.default_rng(42)
area = np.linspace(40, 150, 30)          # 30 套房子的面积
noise = rng.normal(0, 15, area.shape)    # 噪声，让数据不那么"完美"
price = 1.2 * area + 30 + noise          # 真实成交价

data = pd.DataFrame({"area": area, "price": price})
print("原始数据前 5 行：")
print(data.head())

# 特征 X 是"面积"这一列，标签 y 是"房价"这一列
X = data[["area"]]
y = data["price"]

# 关键一步：我们并没有告诉模型"斜率是 1.2、截距是 30"，
# 而是让模型通过 fit() 自己从数据里学出这两个参数
model = LinearRegression()
model.fit(X, y)

print("\n模型自己学到的斜率（系数）：", round(model.coef_[0], 3))
print("模型自己学到的截距：", round(model.intercept_, 3))
print("（真实值是 斜率 1.2、截距 30，模型学到的结果非常接近）")

# 用学到的规律预测一套 100 平米的房子
new_house = pd.DataFrame({"area": [100]})
predicted_price = model.predict(new_house)
print("\n预测一套 100 平米房子的价格：", round(predicted_price[0], 1), "万元")

运行后你会发现：模型学到的斜率和截距非常接近真实值 1.2 和 30，而对 100 平米房子的预测也接近真实规律给出的 150 万元。这就是"从数据中学习"——你没有写任何 price = 1.2 * area + 30 这样的公式，公式是模型自己找到的。

三、练习#

  1. 概念判断：下列哪种做法属于"机器学习"，哪种属于"传统编程"？
    • (a) 写一段代码，把所有价格大于 300 万、面积大于 100 平的房子筛选出来。
    • (b) 收集 2000 条成交记录，训练一个模型来预测新房子的价格。
  2. 填空：在监督学习里，"面积""房龄"这些用来描述样本的量叫做 ____，而"房价"这种我们想预测的量叫做 ____。
  3. 动手实验：把上面代码中的 np.random.default_rng(42) 改成 np.random.default_rng(7)（换一批随机噪声），重新运行。模型学到的斜率和截距会发生什么变化？为什么每次结果不完全一样？
  4. 思考题：如果真实规律不是直线而是曲线（例如 price = 0.5 * area**2），LinearRegression 还能学得很好吗？你觉得可以怎么改进？
