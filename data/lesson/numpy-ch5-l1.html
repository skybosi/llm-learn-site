随机数生成#

数据科学里有大量场景离不开"随机"：训练神经网络要随机初始化权重、做蒙特卡洛模拟要抽样、交叉验证要随机打乱样本、甚至生成测试数据也要"造"一些符合特定分布的随机数。NumPy 提供了强大且高效的随机数工具，而且用法很统一：先创建一个随机数生成器，再从它身上调用各种分布。

这一课的重点有两个：一是熟悉最常见的几种分布，二是理解随机种子如何让"随机"变得可复现。

一、概念讲解#

1. 伪随机数：用种子控制"随机"#

计算机里的随机数其实是伪随机数——由一个确定的算法（叫随机数生成器，简称 RNG）根据一个初始状态推算出来的。这个初始状态由种子（seed）决定。

关键在于：

  • 同一个种子 → 同一串随机数。因此只要固定种子，整个实验就能完整复现，这是科研和工程的基本要求。
  • 不指定种子时，NumPy 会用系统熵源（如时间、硬件状态）自动初始化，每次结果都不同。

一个经典误区是：以为"随机"就是"每次都不一样、无法控制"。恰恰相反，工程上我们几乎总是主动固定种子，好让结果可复现、可排查。

2. 新的推荐 API：default_rng#

NumPy 提供了两套随机数 API。旧的写法是直接调用 np.random.seed(...) 和 np.random.rand(...) 这类模块级函数；新的、官方推荐的写法是先用 default_rng() 创建一个生成器对象：

rng = np.random.default_rng(42)   # 创建一个种子为 42 的生成器

之后所有随机数都从 rng 这个对象上取。这样做的好处是：生成器可以独立传递、互不干扰，代码更清晰，也更容易并行。本课程统一使用新 API。

3. 最常用的几种分布#

  • 均匀分布 rng.random(size)：在 [0, 1) 区间内等概率取值，是所有连续随机数的"底座"。
  • 标准正态分布 rng.standard_normal(size)：均值 0、标准差 1 的钟形曲线；rng.normal(loc, scale, size) 可以指定均值 loc 和标准差 scale。
  • 整数 rng.integers(low, high, size)：在 [low, high) 内均匀取整数，常用于随机下标或抽样。
  • 随机抽取/打乱 rng.choice、rng.shuffle、rng.permutation：从数组里抽元素、原地打乱、返回乱序副本，数据预处理里天天用到。

size 参数可以是一个整数（一维）或元组（多维形状），比如 size=(3, 4) 会生成一个 3×4 的数组。

二、可运行示例#

示例 1：同一种子生成同一串随机数

import numpy as np

# 用同一个种子创建两个生成器
rng_a = np.random.default_rng(2024)
rng_b = np.random.default_rng(2024)

# 两者生成的序列完全相同
a = rng_a.random(5)
b = rng_b.random(5)
print("生成器 A 的输出 =", a)
print("生成器 B 的输出 =", b)
print("完全相同:", np.array_equal(a, b))

# 不指定种子，每次运行结果都不同（你运行两次试试）
rng_c = np.random.default_rng()
print("无种子生成器的一次输出 =", rng_c.random(3))

示例 2：三种常用分布

import numpy as np

rng = np.random.default_rng(7)

# 均匀分布：[0, 1) 内 4 个数
print("均匀 [0,1) =", rng.random(4))

# 标准正态分布：均值 0、标准差 1，2x3 的矩阵
print("标准正态 =\n", rng.standard_normal((2, 3)))

# 指定均值与标准差的正态分布：均值 100、标准差 15（模拟智商分数）
iq = rng.normal(100, 15, size=5)
print("正态(100,15) =", iq)

# 整数：在 [1, 50) 内抽 6 个整数
print("随机整数 =", rng.integers(1, 50, size=6))

示例 3：随机抽取与打乱

import numpy as np

rng = np.random.default_rng(1)

samples = np.array([10, 20, 30, 40, 50])

# 有放回地随机抽 3 个
print("有放回抽取 =", rng.choice(samples, size=3))

# 无放回抽取（默认 replace=False 只能抽一次，这里显式指定）
print("无放回抽取 =", rng.choice(samples, size=3, replace=False))

# 返回一个乱序副本，原数组不变
shuffled = rng.permutation(samples)
print("乱序副本 =", shuffled)
print("原数组未变 =", samples)

示例 4：模拟一次抛硬币实验

import numpy as np

rng = np.random.default_rng(123)

# 模拟抛 1000 次硬币：1 表示正面，0 表示反面
# 方法：从 [0,2) 中随机取整数，0=反面，1=正面
flips = rng.integers(0, 2, size=1000)

# 统计正面出现的次数与频率
heads = np.count_nonzero(flips == 1)
print(f"正面次数 = {heads}，频率 = {heads / 1000:.3f}")

# 理论上正面频率应接近 0.5，跑多次会围绕 0.5 波动

三、练习#

  1. 复现实验：用 default_rng(42) 生成 10 个标准正态随机数，记下结果；重新运行一遍，确认结果完全一致；再把种子改成 43，观察结果变化。
  2. 形状练习：用 rng.random 分别生成形状为 (5,)、(3, 4)、(2, 3, 2) 的数组，打印各自的 shape。
  3. 模拟骰子：用 rng.integers(1, 7, size=10000) 模拟掷 1 万次六面骰子，统计 1 到 6 每个面出现的次数，观察它们是否大致均匀（各约 1/6）。
  4. 随机抽样：从 np.arange(1, 101) 中无放回地随机抽取 20 个数，模拟"从 100 人中抽 20 人"；确认没有重复。
  5. 思考：为什么机器学习里要固定随机种子？如果训练两次模型、两次都用同一种子，好处是什么？如果忘了设种子，会带来什么麻烦？
