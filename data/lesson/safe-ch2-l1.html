一、SFT 做了什么、没做到什么#

1.1 目标函数#

监督微调（SFT）在示范数据集 Ddemo​={(x(i),y(i))} 上最大化对数似然：

θmax​ E(x,y)∼Ddemo​​[logπθ​(y∣x)] = θmin​ Ex​[交叉熵−y∑​d(y∣x)logπθ​(y∣x)​​]

其中 d(⋅∣x) 是示范在该输入上的经验条件分布。注意这个式子里只有一个符号 d，没有"好"和"坏"。SFT 把示范当作"要复制的对象"，而不是"要超越的下界"。

1.2 下界是数据的熵，不是零#

最优解是 πθ​=d，于是最优交叉熵等于示范分布的熵：

θmin​CE = H(d) = −y∑​d(y∣x)logd(y∣x)

这个恒等式有一个工程后果，被反复低估：只要示范本身不是确定性的，SFT 的损失就不会收敛到零，而且停在哪个值完全由数据决定。 数值算例（合成，⚠️）：4 个候选回答的示范频率 d=(0.55,0.30,0.10,0.05)。

  • 初始均匀分布的 CE=log4=1.386294；
  • 收敛后的 CE=H(d)=1.070047；
  • 模型学到的分布收敛到 π=(0.5484,0.2980,0.0983,0.0554)。

关键读数不在"CE 降了 0.316"，而在第三项：示范里出现频率 0.10 的那个坏回答，模型就忠实地学出 0.10。SFT 没有"知道它坏"的能力——它的目标里没有这个信息。

1.3 为什么"有监督"不够：缺的是偏好的自由度#

同一个示范集可以对应两个完全不同的偏好结构。取偏好 A：最优分布 (0.70,0.20,0.07,0.03)，H(A)=0.862905；偏好 B：(0.20,0.65,0.10,0.05)，H(B)=0.981942。同一个 SFT 模型对两者的交叉熵分别是

CE(πSFT​;A)=0.911929>H(A),CE(πSFT​;B)=1.283815>H(B)

它在两种偏好下都达不到各自的下界，因为它拟合的是 d，而 d 既不等于 A 也不等于 B。这就是 SFT 的结构性缺口：训练目标里没有比较这个操作，所以它无法把"两个都出现过、但一个更好"这件事表达出来。要把这个信息用上，必须换一种数据形式与目标函数：成对比较。

为什么这一步是必须的，而不是可选的：SFT 的梯度是 πθ​−d（对 logits 求导的结果），它的方向只会把概率往示范频率上推。即使你在数据里删掉坏示范，也只是改了 d，没有引入"相对好坏"这一维度。RLHF 的第一步不是换损失，而是换数据形式：从 (x,y) 换成 (x,yw​,yl​)。

二、从打分到偏好：为什么用比较#

2.1 绝对分数不可辨识#

一个自然的替代方案是让人给回答打绝对分 s(x,y)∈{1,…,5}，再训一个回归奖励模型。它有两个问题，都不在"人打得准不准"上，而在尺度上。

第一个问题是平移不可辨识。Bradley-Terry（BT）模型把成对偏好写成

P(yw​≻yl​∣x)=σ(r(x,yw​)−r(x,yl​)),σ(z)=1+e−z1​

数值算例：r=(1.20,0.40)，把两个奖励同时加 c 得到 (4.90,4.10) 或 (−11.30,−12.10)，偏好概率恒为

σ(0.80)=0.689974

这说明奖励的绝对零点（以及任何只依赖 x 的偏置项 c(x)）在成对数据里不可辨识。这不是缺陷，是好事：它意味着你不必去定义"5 分"是什么。

2.2 打分尺度的脆弱性：它才是真正的隐患#

第二个问题更隐蔽：绝对打分的单位是一个无法从数据里检验的建模假设。假设人类心里有一个 1–5 分的量表，但读出来时经过一个单调而非线性的映射（例如把分数平方）。同一份偏好，用两种读出方式算出的 BT 概率是：

真实奖励 (rw​,rl​) σ(rw​−rl​) σ(rw2​−rl2​)
(1.00,0.50) 0.6225 0.6792
(2.00,1.00) 0.7311 0.9526
(4.00,2.00) 0.8808 1.0000

第三行说明问题有多严重：真实奖励差是 2.0，但只要读出被平方，模型就认为"长的必胜"（概率 1.0000，浮点下已饱和）。打分回归把"尺度"变成一个不可检验的自由度，而成对比较只需要差值——差值恰好是唯一被数据约束的量。这就是 RLHF 用偏好而不是打分的第一条理由。

第二条理由是可算的：比较的信噪比随奖励差改善得有多快。用单样本检验把 P(yw​≻yl​) 与 0.5 区分开（α=0.05 双侧、功效 0.80）：

三、RLHF 的目标函数#

3.1 三项在买什么#

RLHF 的第二阶段解的是

πmax​ 让代理奖励变高Ex∼D,y∼π(⋅∣x)​[rϕ​(x,y)]​​ − 别离参考策略太远βKL(π(⋅∣x)​πref​(⋅∣x))​​,β>0

三个对象各司其职，且缺一不可：

  • rϕ​ 是代理奖励，由人类偏好数据经 BT 损失训出的奖励模型给出。它承载"什么更好"的信息，但它只是一个代理——第 5 节会量化它与真实目标的间隙。
  • πref​ 是参考策略（通常是 SFT 模型）。它定义了"从哪儿出发"以及"离哪儿不能太远"。
  • β 是价格：把一 nat 的分布位移折算成多少奖励。β→0 是"不计代价地最大化代理"，β→∞ 是"原地不动"。

3.2 闭式解#

这个问题的解可以精确写出。把目标写成对 y 的求和，用拉格朗日乘子约束 ∑y​π(y)=1，令导数为零，得到

π∗(y∣x)=Z(x)1​πref​(y∣x)exp(βr(x,y)​),Z(x)=y∑​πref​(y∣x)exp(βr(x,y)​)

π∗(y∣x)=Z(x)1​πref​(y∣x)exp(βr(x,y)​),Z(x)=y∑​πref​(y∣x)exp(βr(x,y)​)

这是一个指数倾斜（exponential tilt）：把参考分布的每一项乘以 exp(r/β) 再归一化。数值验证（合成，β=0.5，6 个候选回答）：

  • 在 π∗ 附近按 N(0,0.52) 扰动 logits 随机撒 20000 个策略，最大值是 1.615643，比 J(π∗)=1.615653 低 9.9×10−6——没有抽样点超过闭式解。

3.3 最优值恒等式与"对齐预算"#

把 π∗ 代回目标，得到本节第二个主结论：

J(π∗)=最优正则化收益Eπ∗​[r]−βKL(π∗∥πref​)​​=βlogZ(x)

J(π∗)=最优正则化收益Eπ∗​[r]−βKL(π∗∥πref​)​​=βlogZ(x)

再由 Jensen 不等式 logEπref​​[er/β]≥Eπref​​[r]/β：

βlogZ(x)−Eπref​​[r] ≥ 0

数值算例：J(πref​)=0.925836，J(π∗)=1.615653，两者之差 G=0.689817 就是这次对齐能买到的全部正则化收益。β 一旦定下，这个数就被 Z 锁死了。

为什么这个恒等式重要：它把"对齐能带来多少"从一个叙事变成一个可算的量。它也解释了为什么 RLHF 不能靠"再多训一会儿"无限提升：Z 只依赖 r 与 πref​，与训练步数无关。训得更久只会让 π 更接近 π∗，不会让 π∗ 本身更好。目标函数定下了天花板，优化只决定你有没有摸到它。

3.4 奖励反演：DPO 的全部依据#

把闭式解两边取对数并整理，可以把奖励反过来用策略表示：

r(x,y)=βlogπref​(y∣x)π∗(y∣x)​+βlogZ(x)

r(x,y)=βlogπref​(y∣x)π∗(y∣x)​+βlogZ(x)

数值验证：用上式从 π∗ 与 πref​ 反演的奖励与原始 r 逐项一致（最大误差 1.11×10−16）。

这个式子是第 2 节 DPO 推导的全部依据。但它自带一个限制，必须在这里就标出来：βlogZ(x) 依赖 x。也就是说，隐式奖励只在同一个 prompt 内有定义；跨 prompt 比较两个回答的隐式奖励，等于在比较两个不同的常数偏移。第 2 节会把这条限制算成一个具体的失效情形。

四、KL 约束到底在做什么#

4.1 四个作用#

βKL(π∥πref​) 经常被说成"防止过拟合"或"保持语言质量"。它至少做四件事，其中前两件是可证的：

  1. 固定尺度：没有 KL 项时，奖励可以任意缩放而不改变 BT 似然（§2.1），目标函数对奖励的尺度不敏感。KL 项引入 β 作为唯一的尺度参照，让"奖励单位"有了操作定义。
  2. 限定支撑集：π∗∝πref​er/β 是重加权，不是移动。πref​(y∣x)=0 的地方 π∗(y∣x)=0 恒成立，无论 β 多小、r 多高。数值算例：把参考分布的两个分量置零并重归一化（非零项从 6 降到 4），在 β=0.5 与 β=0.1 下 π∗ 的非零项都恰为 4，被置零的两项值恒为 0.0×100。
  3. 压低模式坍塌的速度：β 越小，π∗ 越集中（§5.3 给出 exp(H) 的曲线）。
  4. 管理对齐税：β 就是能力-安全权衡的旋钮，第 4 节会把它测成一条曲线。

第 2 条是结构性的，不是数值现象。它同时解释了两件事：RLHF 为什么保守（不会跑到参考策略从未覆盖的行为上），以及 DPO 为什么有分布外盲区（第 2 节展开）。

KL(π∥πref​) 与 KL(πref​∥π) 不是同一个量，方向选错得到的策略完全不同：

前者惩罚"π 把质量放到参考认为不可能的地方"；后者惩罚"π 丢掉了参考的某个模态"。RLHF 用的是前者。数值对照（合成）：

五、三类失效模式#

理想目标的分析给出的是"最优解长什么样"，但真实训练会以三种特定方式偏离它。这三类失效模式的可贵之处在于它们都有可算的判据，而不是只能事后归因。

5.1 奖励黑客：代理与真实目标的间隙#

把代理奖励写成真实目标加上一个独立误差：r=r∗+ε，E[r∗]=0，Var(r∗)=1，Var(ε)=σε2​。则

ρ2 ≡ Corr(r,r∗)2=1+σε2​1​,E[r∗∣r=t]=ρ2t

5.2 长度偏置：(b,β,κ) 的赛跑#

奖励模型会学到"更长 = 更好"，这不是因为标注员愚蠢，而是因为长度在偏好数据里确实与胜率正相关。把每个 token 的偏置记为 b，一个回答的代理奖励是

r(x,y)=q(y)+b⋅L(y)

数值算例（合成，⚠️）：b=0.004/token，两个回答真实质量相同 q=0.50，长度 L=120 与 L=260。则

r短​=0.50+0.004×120=0.9800,r长​=0.50+0.004×260=1.5400

Δr=0.5600 ⟹ P(长的更好)=σ(0.56)=0.636453

用 BT 反推出的每 token log-odds 恰为 (1.5400−0.9800)/(260−120)=0.00400，与植入的 b 一致——这就是奖励模型里长度偏置的可测形式：在控制质量后，长度对胜率的每 token 边际贡献。

偏置本身不可怕，它是否导致长度失控取决于策略侧的一个不等式。加长 ΔL 个 token 的净收益是

Δnet​=(b−βκ)ΔL

其中 κ 是每 token 的 KL 代价。取 κ=0.05：

0.05 0.0025 +0.0015 是

0.10 0.0050 −0.0010 否
0.50 0.0250 −0.0210 否

结论：长度偏置不是"奖励模型坏了"，而是 (b,β,κ) 三者的不等式。修法对应三项：去偏 b（改标注指令或加长度特征）、调 β（牺牲优化强度）、改长度归一化（第 2 节的 SimPO 走第三条）。三者都有代价，所以"把长度偏置修掉"从来不是一个单点修复。

六、边界与取舍#

  1. 本节的所有数字都是合成的。 6 个候选回答、b=0.004、σε​=2.0、κ=0.05 都是手写常量，作用是把机制写成可核对的算术。它们不代表任何真实模型或系统的测量结果。
  2. 闭式解只在序列级 KL 下成立。 实际 RLHF 常用逐 token 的 KL 惩罚 ∑t​KL(π(⋅∣x,y<t​)∥πref​(⋅∣x,y<t​))，此时闭式解不再是严格的最优解，而是 per-token 版本的一个近似。第 2 节的 DPO 推导继承同一个理想化。
  3. ρ2 常数模型只解释方向。 §5.1 的模型没有刻画"优化到分布外之后代理误差方差自己变大"这件事，那是外部实验事实。
  4. 奖励模型本身的误差有两类，本节只量化了一类。 代理误差 ε 混了"标注噪声"与"模型泛化误差"两种来源；它们的可约性完全不同（前者靠更多标注，后者靠更好覆盖），本节的 σε​ 是把两者合并后的结果。
  5. PPO 之外还有别的优化器（如 REINFORCE 基线、GRPO 等）。它们的信任域机制不同，但目标函数与本节的分析一致；差异落在"如何维持信任域"而不在"信任域是什么"。
  6. 本节没有回答"β 该取多少"。 那是一个需要第 4 节测量协议才能回答的问题：在不同的 β 下分别测安全指标与能力指标，画出曲线，再按安全阈值选点。

def softmax(xs):
    m = max(xs)

    return [e / s for e in ex]

    return -sum(x * math.log(x) for x in p if x > 0)


def kl(p, q):
    return sum(a * math.log(a / b) for a, b in zip(p, q) if a > 0)

def top_q_stats(sigma_eps, q):
    zq = normal_ppf(1 - q)
    e_r = phi(zq) / q                      # E[r] 取前 q 分位的均值
    rho2 = 1.0 / (1.0 + sigma_eps ** 2)    # r = r* + eps, Var(r*)=1
    e_rstar = rho2 * e_r
    return zq, rho2, e_r, e_rstar

        print("  %8.2f  %6.4f   %12.4f   %7.4f  %8.4f  %9.4f   %8.4f"

小结#

  • SFT 的下界是示范分布的熵 H(d)，不是零。 演示里 d=(0.55,0.30,0.10,0.05) 时 CE 从 1.386294 收敛到 1.070047=H(d)，坏示范被按 0.10 的比例学进去。SFT 的目标里没有"哪个更好"这一项，所以它对两种不同偏好结构给出同一个模型。
  • 用比较而不是打分，是因为差值才是被数据约束的量。 BT 模型下 r→r+c(x) 不改变任何成对概率（P 恒为 0.689974）；而绝对打分的单位是一个不可检验的自由度——同一份打分经过平方读出，成对概率能从 0.6225 变成 0.6792，极端情况下直接饱和到 1.0000。
  • 偏好数据的样本量与奖励差平方反比。 Δr=0.10 需要约 3142 对，Δr=1.00 只要约 34 对。
  • RLHF 的最优解是参考策略的指数重加权：π∗∝πref​er/β，且 J(π∗)=βlogZ≥Eπref​​[r]。数值上 J(πref​)=0.925836、J(π∗)=1.615653，对齐预算 G=0.689817 由 Z 锁死，与训练步数无关。
  • KL 约束做四件事：固定奖励尺度、限定支撑集（πref​=0⇒π∗=0，与 β 无关）、压低模式坍塌速度、管理对齐税。方向必须是 KL(π∥πref​)（mode-seeking）；β=0.05 时两个方向差 23.4 倍。
  • β 的价格曲线是递减的：β=0.05 时每 nat KL 只买到 1.22 的原始奖励，β=1.00 时是 2.61。优化压力加到一定程度，付出去的位移远快于买到的东西。
  • PPO 的裁剪让梯度在两种情形归零（A>0,ρ>1+ϵ 与 A<0,ρ<1−ϵ），从而把单 token 的 KL 预算压到 0.223144 nats（ϵ=0.2）。但裁剪不直接约束 ρ，"PPO 自带 KL 保证"是过度解读。
  • 三类失效模式各有可算判据：奖励黑客是 (1−ρ2)φ(zq​)/q 随优化压力放大（ρ2=0.2、q 从 0.10 到 0.001 时间隙从 1.4040 涨到 2.6937）；长度偏置是 (b,β,κ) 的不等式（b=0.004,κ=0.05 时临界 β=0.08）；模式坍塌是 exp(H) 随 β 下降加上多 epoch 的 m2 漂移（m=16 时 KL 是 m=1 的 256 倍）。
  • 每一条失效都指向一个具体的修法，而每个修法都有代价。 本节没有一条"免费的"改进——这正是第 2、3、4 节要处理的问题：能不能换掉奖励模型？能不能换掉人类反馈？以及，怎么把"更贵/更安全"这件事测成一个可证伪的断言。

下一节：RLHF 的目标函数里，奖励模型是最贵也最脆的一环——它要单独训、单独维护，还会把长度偏置和代理间隙一并带进训练。第 2 节问一个更尖锐的问题：既然 §3.4 已经把奖励写成 r=βlog(π/πref​)+βlogZ，能不能把奖励模型整个删掉，只用策略与参考策略的比值做偏好优化？ DPO 的答案是能，而且推导只有三行。但删掉的东西不会消失，只会换一个地方出现：配分函数 Z(x) 在同一个 prompt 内消掉了，于是隐式奖励跨 prompt 不可比；偏好数据是离线的，于是策略的支撑集被 §4.1 的重加权结构锁死在 πref​ 里、分布外没有梯度；而"奖励是一个 log 比值的和"这件事本身，会让长度重新回来——这次是以每 token log 概率累加的形式。第 2 节把这三点各自的判据算出来，并把 DPO 之后的 IPO/cDPO/KTO/ORPO/SimPO 摆成一张"各修了哪一条"的表。
