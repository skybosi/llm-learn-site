相似度计算#

前两课的 UserCF 和 ItemCF，都悬在一个词上——相似度。但"相似"到底怎么度量？余弦、皮尔逊、Jaccard、调整余弦……它们的区别藏在细微处，选错一个，协同过滤的结果可能面目全非。这一课把这些相似度逐一拆解，并回答一个"知其所以然"的问题：为什么皮尔逊相关系数，恰好就是"中心化之后的余弦相似度"？

一、概念讲解#

1. 余弦相似度（Cosine Similarity）#

把两个用户（或两个物品）的评分看成向量，余弦相似度衡量的是它们的夹角：

cos_sim(a, b) = (a · b) / (‖a‖ · ‖b‖)
  • 结果 ∈ [−1, 1]，1 表示方向完全一致，0 表示正交，−1 表示完全相反；
  • 只关心方向、不关心长度：[1,1] 和 [10,10] 余弦相似度是 1，尽管数值差 10 倍。

这个"尺度不变性"在推荐里有双重含义。好处是：一个用户给所有电影都打 5 分、另一个都打 4 分，只要他们"相对偏好"一致，余弦就认为他们高度相似。坏处也在这：余弦对"打分尺度"完全盲视，有时会把"打分普遍偏高"与"打分普遍偏低"的两个用户当成同好。

2. 皮尔逊相关系数（Pearson Correlation）#

皮尔逊相关系数衡量的是线性相关程度，公式等价于"先各自减去均值、再算余弦"：

pearson(a, b) = cos_sim(a − ā·1, b − b̄·1)

即把每个向量中心化（减掉自己的均值）后求余弦。这一步的精妙在于：中心化后的向量只保留了"相对自己平均水平的偏离"，于是：

  • 一个"什么都打高分"的用户，中心化后高分变成小幅正值、低分变成负值——绝对尺度被抹掉了；
  • 比较的是"哪些物品我更喜欢、哪些更不喜欢"的相对结构。

这直接解决了余弦的尺度盲视问题，是 UserCF/ItemCF 中最常用、最稳健的相似度。

3. 调整余弦相似度（Adjusted Cosine）#

在物品相似度（ItemCF）场景里，中心化该减谁的平均值很微妙。减"物品均值"（所有用户给该物品打分的平均）是错的——那会抹掉"这个物品整体就是更受欢迎"这一重要信息。正确做法是减用户均值（每个用户自己的平均分），再去掉未共同评分的维度，得到：

adjusted_cosine(i, j) = Σ_{u∈U(i,j)} (R[u,i] − r̄_u)(R[u,j] − r̄_u)
                        / (√Σ_u (R[u,i] − r̄_u)² · √Σ_u (R[u,j] − r̄_u)²)

它与普通余弦的区别在于：先把每个用户的评分做中心化，再在共同评分用户上算余弦。这样既消除了"用户打分尺度差异"，又保留了"物品整体热度差异"。

4. Jaccard 相似度（集合视角）#

当反馈是隐式（只有 0/1 交互，没有分数）时，余弦/皮尔逊会退化成"共同交互数"的某种变形，此时更常用集合的 Jaccard：

Jaccard(a, b) = |a ∩ b| / |a ∪ b|

即"共同交互的物品数"除以"两人交互物品的并集数"。它只关心"要不要"（交不交互），不关心"打几分"，是隐式反馈下最朴素的相似度。

5. 一张表选型#

相似度 公式核心 消除尺度差异 适用反馈
余弦 夹角 否（盲视尺度） 显式，尺度较统一
皮尔逊 去中心化后夹角 是（减各自均值） 显式，尺度差异大
调整余弦 去用户均值后夹角 是（减用户均值） ItemCF 显式
Jaccard 交集/并集 — 隐式（0/1）

二、可运行代码示例#

用 NumPy 手写四种相似度，并刻意构造一个"打分尺度不同但口味一致"的场景，直观对比它们的差异。

import numpy as np

def cosine(a, b):
    """余弦相似度：只看方向，对长度（打分尺度）不敏感。"""
    denom = np.linalg.norm(a) * np.linalg.norm(b)
    return float(a @ b / denom) if denom > 0 else 0.0

def pearson(a, b):
    """皮尔逊相关系数：中心化（减各自均值）后再算余弦。"""
    a_c, b_c = a - a.mean(), b - b.mean()
    return cosine(a_c, b_c)

def jaccard(a, b):
    """Jaccard 相似度：把非零项当成"交互过的集合"，算交集/并集。"""
    set_a, set_b = set(np.where(a > 0)[0]), set(np.where(b > 0)[0])
    if not (set_a | set_b):
        return 0.0
    return len(set_a & set_b) / len(set_a | set_b)

# 两位用户：口味结构完全一致，但 A 天生爱打高分、B 天生苛刻
A = np.array([5, 4, 3, 1])   # A：科幻 5、动作 4、爱情 3、喜剧 1（都偏高）
B = np.array([3, 2, 1, 0])   # B：科幻 3、动作 2、爱情 1、喜剧 0（都偏低）
C = np.array([1, 2, 3, 4])   # C：口味完全相反（爱喜剧、烦科幻）

print("A vs B：")
print("  余弦相似度 =", round(cosine(A, B), 3))
print("  皮尔逊相关 =", round(pearson(A, B), 3))   # 结构一致，应为 1 或接近 1
print("  Jaccard    =", round(jaccard(A, B), 3))
print("A vs C：")
print("  余弦相似度 =", round(cosine(A, C), 3))
print("  皮尔逊相关 =", round(pearson(A, C), 3))   # 结构相反，应为负值

观察要点：A 和 B 的相对偏好完全一致（都最喜科幻、最烦喜剧），但绝对分值差了一大截。此时皮尔逊 ≈ 1 而余弦 < 1——皮尔逊正确地识别出"两人口味相同，只是打分尺度不同"；而 A 与 C 的皮尔逊为负，识别出"口味相反"。这正是"为什么皮尔逊在协同过滤里更常用"的直观证据。

为什么这样做？——理论推导#

皮尔逊 = 去中心化余弦的严格证明#

这是本课最重要的"知其所以然"。设两个向量 a = (a₁,…,aₙ)、b = (b₁,…,bₙ)，均值为 ā、b̄。皮尔逊相关系数的标准定义是协方差除以标准差之积：

ρ = Σᵢ (aᵢ − ā)(bᵢ − b̄) / ( √Σᵢ(aᵢ − ā)² · √Σᵢ(bᵢ − b̄)² )

而中心化向量 a_c = a − ā·1、b_c = b − b̄·1 的余弦是：

cos(a_c, b_c) = (a_c · b_c) / (‖a_c‖ ‖b_c‖)
              = Σᵢ (aᵢ − ā)(bᵢ − b̄) / ( √Σᵢ(aᵢ − ā)² · √Σᵢ(bᵢ − b̄)² )

两者逐项相等，证毕。所以"皮尔逊"不是一个独立的新公式，而是"先平移（去均值）再量夹角"这两个原子操作的组合。

为什么去均值能消除"打分尺度"这个混杂变量#

从几何看，余弦对所有向量整体缩放不变，但对平移（加一个常数）敏感。用户打分的"尺度差异"正是一个平移：A 的评分 ≈ B 的评分 + 2。减去各自均值，就是把两个向量都平移到"以自己为原点"的坐标系里，抵消了这个平移。于是剩下的夹角，才纯粹反映"偏好的相对结构"。这正是"中心化"作为去混杂（de-confounding）手段的价值——它和机器学习里"特征标准化/中心化"是同一个动作在不同语境下的应用。

母原理连接： 相似度的选择，本质是在回答"我们想把哪些差异当作信号、把哪些差异当作噪声"。余弦把"长度差异"当噪声、皮尔逊把"平移差异"也当噪声、Jaccard 干脆只保留"要不要"这一个比特。没有绝对最好的相似度，只有与数据假设最匹配的相似度——这本身就是机器学习"先验决定模型"母题的又一次上演。
