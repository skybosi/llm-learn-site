这一节要解决什么#

前三节分别讲了"为什么会脱节""线上怎么测""什么不能变坏"。这一节把三样工具合成一套可执行的动作：当结果与预期不符时，按什么顺序、用哪些检验，把落差定位到具体一层。

先把三种落差定义清楚，因为它们需要的动作完全不同：

现象 常见的第一反应 本章的处理
离线涨、线上不涨 "离线指标不准" 逐层证伪：度量层（代理失效）→ 总体层（权重错位）→ 系统层（链路损耗）→ 策略层（阈值/兜底吸收）
离线涨、线上跌 "是不是实验出错了" 先查实验有效性（分流、污染、偷看），再查代价迁移（收益来自一个未计入目标的量）
离线不涨、线上涨 "数据管道有 bug" 这通常是最有价值的一类：说明离线评测没测到真正的改动机制，要回去改评测集，而不是否定线上结果

归因的核心方法论只有一条：把"落差"写成可分解的恒等式，然后逐项估计符号与量级。不能分解的归因都是故事。本节会给出四层分解的具体式子，以及在每一层上"最便宜的第一个检验"是什么。

一、归因的四层模型与"最便宜的检验"#

把第 1 节的因果链变成四个可检验的层。每一层配一个便宜的证伪动作——先做便宜的，只有它排除掉才做贵的：

层 假设（H1） 最便宜的检验 成本
度量层 离线指标不是线上目标的有效代理 查历史：同类改动中代理与线上结果的符号一致率 几小时（查历史报告）
总体层 评测集分布与线上流量错位，且效果异质 分层重加权：用线上权重重算离线分数 几小时（已有数据）
系统层 链路损耗/降级/下游改写抹平了模型差异 影子回放：同一批请求过完整链路，比对最终输出与模型原始输出 1~2 天（要搭回放）
策略层 阈值/兜底/人工介入吸收了差异 看中间变量：自动化率、兜底率、人工介入率、重排改动率 几分钟（已有埋点）
实验有效性 线上实验本身无效（分流/污染/偷看） 查分流均衡性（AA 检验）、样本比、SRM 检验 几分钟

顺序很重要：从最便宜的层开始，逐层排除。实践中大约一半的"离线涨线上不涨"在第一层或第二层就被解释了，根本不需要搭影子回放。反过来，一上来就怀疑"模型泛化不行"是最贵的路径。

为什么按这个顺序：因为它按"证伪成本"排序，而不是按"可能性"排序。在归因里，先做便宜检验的期望收益永远更高，因为便宜检验常常直接给出答案（比如分层重加权后落差消失 → 结论是总体层问题，与模型能力无关）。

二、度量层：代理指标的符号一致率#

怎么做：翻历史资料，找出过去 N 次"离线有明确变化"的改动，看它们在线上结果上的符号是否一致：

一致率=N#{i: sign(Δoff,i​)=sign(Δon,i​)}​

一致率 0.9 意味着代理可用；0.6 意味着接近抛硬币——此时任何"离线提升"都不构成上线证据。

两个必须注意的点：

  1. 样本量常常很小（历史改动可能只有十几次），因此一致率的不确定性很大。用 Wilson 区间报告：N=12、一致 10 次时，一致率的 95% 区间约是 [0.52,0.95] —— 它甚至不能排除"抛硬币"。结论应当是"代理有效性证据不足"，而不是"代理有效"。
  2. 一致率要分改动类型统计。"离线指标在提示词调优上很准、在换基座模型上完全不准"是很常见的现象。混合统计会把这种结构掩盖掉。

取舍：历史资料通常缺少严格的对照组（很多改动直接全量上线），因此一致率里混着混杂。更强的做法是回溯建立"影子对照"：对每次改动，事后用同期的未受影响流量构造一个对照。这不总是可行，所以要标注一致率的证据等级。

三、总体层：用线上权重重算离线分数#

这一层有一个几乎零成本的分解工具。设评测集被分成 K 层，qk​ 是评测集权重，wk​ 是线上权重，Δ^k​ 是各层的离线效果估计。那么：

Δ^off​=k∑​qk​Δ^k​,Δ^reweighted​=k∑​wk​Δ^k​

重加权后分数变化，且更接近线上结果 → 落差里属于"分布错位"的那部分就是 Δ^off​−Δ^reweighted​。 如果重加权后落差消失，说明模型在各层上都没有问题，问题在你的评测集抽样。

重加权有一个必须处理的技术细节：有限重叠。如果某一层线上权重是 0.30 但评测集里只有 5 个样本，Δ^k​ 的方差会极大，重加权结果会被这一层支配。两个防护：

  • 有效样本量检查：neff​=1/∑k​(wk2​/nk​)。neff​ 太小（比如小于总样本的 20%）时，重加权结论不可信。
  • 截断与合并：把 wk​/qk​ 超过阈值（比如 10）的层合并到相邻层，或对权重做截断。这与第 1 节 IPS 的权重裁剪是同一个取舍。

取舍：层数越多，重加权越"精确"，方差越大。做法是先按少数几个高解释力维度分层（任务类型 × 难度），检查 neff​，再决定是否细分。

四、系统层：影子回放与"损耗账本"#

系统层的落差可以用一个乘性账本表达。设线上最终呈现内容相对"模型原始输出"的保真度为 f，那么：

Δobserved​≈f⋅Δmodel​+Δchain​

其中 Δmodel​ 是模型原始输出的改进，Δchain​ 是链路本身（缓存、降级、下游改写）的变化。做两层测量即可把两者分开：

  1. 影子回放：同一批线上请求分别过"只有模型"和"完整链路"，测量最终输出的差异比例。这会给出 f 的经验值。
  2. 降级率/改写率埋点：链路对输出做了多少次改写（截断、重排、格式化、审核替换）。这些是 Δchain​ 的直接证据。

为什么这是"账本"而不是"诊断"：因为它给出的是比例，可以代入下一次预期。若 f=0.4（模型改进只有 40% 传递到最终展示），那么下次离线涨 3 个点时，合理的线上预期是 1.2 个点，而不是 3 个点。把 f 写进上线预期，能避免大量失望。

五、策略层：中间变量是钥匙#

策略层的判断只需要看中间变量。这些变量通常已有埋点，成本接近零：

中间变量 变化形态 含义
自动化率 / 兜底触发率 大幅变化 阈值与新分数分布不匹配，端到端结果主要由此驱动
人工介入率 变化 人在补偿模型，模型差异被吸收
重排/去重改动率 变化 排序后呈现的差异被抹平或放大
平均输出长度 / token 数 变化 差异可能来自长度而非质量（第 4 章的核心混淆）
拒答率 / 澄清率 变化 模型变得保守，任务完成率可能反而下降

判据：如果中间变量在改动前后基本不变，而端到端结果变了，变化大概率来自模型本身；如果中间变量大幅变化，先解释它们，再谈模型效果。

一个具体的反例：模型升级后置信度整体上移，导致自动化率从 45% 涨到 70%。此时"按时解决率"可能上涨，但上涨来自"更多工单被自动处理"，而不是"每次处理得更好"。如果不看自动化率，你会把这次升级归功于模型能力，并在下一次做出错误的外推。

六、实验有效性：先排除"实验本身错了"#

在怀疑模型之前，先排除实验机制的失效。五个必查项：

（a）样本比例失配（SRM, sample ratio mismatch）：分流应当是 p:p。实际得到 n1​:n2​，用卡方检验：

χ2=np1​(n1​−np1​)2​+np2​(n2​−np2​)2​

p 值极小（比如 <0.001）时，说明分流有 bug（哈希碰撞、日志丢失、触发条件不对称）。SRM 是最常见也最容易修的实验缺陷。 注意用严格阈值（0.001 而非 0.05），因为这个检验会被反复执行，且我们不想因为正常波动停止实验。

（b）AA 检验：在实验开始前或用一个空改动，检查两组在实验前指标上是否可比（p 值应大致均匀分布）。这是对分流机制的直接检验。

（c）偷看次数：查实验日志里实际查看结果的次数。如果远超预注册的次数，结论按第 2 节的结论降权。

（d）污染（contamination）：三种常见污染——缓存键不含实验分组（两组共享缓存）、用户跨组（同一用户被分到两组）、下游共享资源（实验组占用推理资源拖慢对照组）。检查方式：看缓存命中率的组间差异、看用户分组稳定性（同一用户多次请求的分组一致率）。

（e）触发条件不对称：实验组的日志采集只在成功路径上打点，对照组全打点。这会造成"指标差异其实是采集差异"。检查方式是比对两组的曝光量/请求量比例与分流比例是否一致。

七、三种落差的归因树#

把上面的层组装成流程图。每一步都标注了检验方法：

落差类型 1：离线涨、线上不涨

SRM / 分流均衡？ ──异常──> 修实验，结论作废
      │正常
      ▼
中间变量（自动化率/兜底率/人工率）大变？ ──是──> 策略层：重调阈值，而非换模型
      │否
      ▼
线上权重重算离线分数后落差消失？ ──是──> 总体层：改评测集抽样
      │否
      ▼
影子回放：最终输出与模型原始输出差异大（f 低）？ ──是──> 系统层：改链路
      │否
      ▼
代理指标历史一致率低？ ──是──> 度量层：换指标 / 建校准
      │否
      ▼
功效不足（MDE 大于预期效应）？ ──是──> 结论"未知"，加样本或延长实验
      │否
      ▼
诚实结论：效应小于 MDE，或不存在

落差类型 2：离线涨、线上跌

这一类要先怀疑实验，再怀疑代价迁移：

  1. 实验有效性五查（上面一节）。特别是缓存污染与用户跨组——它们最容易造成"看起来有意义但方向错误"的结果。
  2. 代价迁移：检查是否有未被计入目标的量在变差。模型更"敢答"→ 错误答案的代价上升；模型更"长"→ 成本与延迟上升，且用户可能因为信息过载而完成率下降。用第 3 节的护栏表逐条过。
  3. 分布漂移：实验期内的线上流量与实验前不同（比如节假日、促销），若两组流量构成在时间上不对齐，或实验有新奇效应（novelty effect），早期结果会误导。做法：看效应量随时间的曲线是否收敛；新颖效应通常表现为"早期强、逐渐衰减"。
  4. 最后才是模型能力。

落差类型 3：离线不涨、线上涨

这一类最有信息量，因为它说明现有的离线评测没有捕捉到真正的机制。典型情形：

  • 改动实际影响的是对话管理/交互流程（比如更换兜底话术），而不是模型输出质量。离线评测集只评单轮输出，测不到多轮体验。
  • 改动影响的是稳定性（重试后的结果一致性提高），而离线评测只测单次采样。此时要补的指标是方差/一致率，而不是均值。
  • 改动影响的是长尾：离线评测集的题目难度集中在中等，而线上收益来自那 5% 的极端难例。此时要补的是分层报告（第 3 节）。

处理原则：不要因为"离线没测到"就否定线上结果，也不要因此放弃离线评测。正确动作是把线上发现的新机制补进评测集：找到那些因改动而受益/受损的线上样本，抽成新的一层，加入评测集（并标注加入时间与原因）。这就是评测集演进的正常路径。

八、把归因变成纪律：前置检查#

归因做得好不好，取决于评测设计时有没有留下可归因的接口。把下面这张清单前置到评测设计阶段：

  1. 分层标签：评测集每题带层级标签（任务类型/难度/用户价值），并在线上埋点里使用同一套标签。没有这个，总体层归因做不了。
  2. 中间变量埋点：策略层的关键量（自动化率、兜底率、人工介入率、重排改动率）必须在实验前就有埋点。事后补埋点做不了这一段。
  3. 代理指标的历史台账：每次上线都记录"离线变化/线上变化/是否一致"，一年后你就有了一致率的 N。这是最容易被忽略、但收益最长的资产。
  4. 反事实能力：日志里保留少量探索（ε-greedy 或 Thompson 采样），否则 IPS 永远不可用（第 1 节的重叠性）。
  5. 链路保真度测量：把 f（模型改进传递到最终展示的比例）作为常规指标定期测。
  6. MDE 预注册：实验前写下 MDE 与样本量。这样"不显著"才能被正确解释为"效应小于 MDE"。

九、归因报告怎么写#

一份可用的归因报告结构（顺序即执行顺序）：

段落 内容 必须给出的数字
1 结论 落差属于哪一层（或"未能归因"） 各层排除/确认的判据值
2 实验有效性 SRM / AA / 偷看 / 污染 卡方 p 值、两组样本比、查看次数
3 分层 各层效应与权重 Δ^k​、qk​、wk​、neff​
4 重加权 用线上权重重算的离线效应 重算前后分数与置信区间
5 中间变量 策略层的变化 自动化率/兜底率/人工率的组间差
6 链路保真 影子回放结果 f 与改写率
7 功效 本次实验能检出多小的效应 MDE 与观测效应、置信区间
8 动作 下一步要改什么（评测集/链路/阈值/指标） 责任人与验收标准

"未能归因"是合格结论。 当各层检验都不能解释落差时，报告应写明"目前证据不足以归因"，并给出下一步的取证计划（比如加埋点、补一组回放）。编一个解释比承认不知道更贵，因为它会引导团队去修一个不存在的问题。

代码#

⚠️ 以下为合成数据，仅用于展示统计量的行为；代码只用标准库，可直接运行。

import math
import random

rng = random.Random(31)


def phi(x):
    return 0.5 * (1 + math.erf(x / math.sqrt(2)))


# ============================================================
# 1. 实验有效性：SRM 检验（样本比例失配）
# ============================================================
def srm_chi2(n1, n2, p1=0.5):
    n = n1 + n2
    e1, e2 = n * p1, n * (1 - p1)
    chi2 = (n1 - e1) ** 2 / e1 + (n2 - e2) ** 2 / e2
    # df=1 的卡方 p 值：P(chi2_1 > x) = erfc(sqrt(x/2))
    p = math.erfc(math.sqrt(chi2 / 2.0))
    return chi2, p


print("== 1. SRM：分流比例失配检验 ==")
for n1, n2 in [(50000, 50000), (50120, 49880), (51000, 49000), (52000, 48000)]:
    chi2, p = srm_chi2(n1, n2)
    print(f"{n1}/{n2} (偏差 {n1/(n1+n2)-0.5:+.4%}) -> chi2={chi2:7.2f} p={p:.5f} "
          f"{'<- 疑似 SRM（用 0.001 阈值）' if p < 0.001 else ''}")
print("  <- 10 万样本下 2% 的分流偏差就足以被发现；0.001 阈值避免误停")

# ============================================================
# 2. 总体层：组成效应分解 + 线上权重重算
# ============================================================
# 3 个层：评测集权重 q 与线上权重 w 不同；离线效果 Delta_k 异质
q = [0.20, 0.30, 0.50]
w = [0.55, 0.25, 0.20]
delta_k = [+0.02, -0.01, +0.05]

off = sum(qi * di for qi, di in zip(q, delta_k))
reweighted = sum(wi * di for wi, di in zip(w, delta_k))
online = 0.0200                    # 线上真实结果（合成）：量级更接近真实系统
total_gap = off - online

print("\n== 2. 总体层：重加权 ==")
for i in range(3):
    print(f"层{i+1}: q={q[i]:.2f} w={w[i]:.2f} Delta={delta_k[i]:+.3f} "
          f"权重比 w/q={w[i]/q[i]:.2f}")
print(f"离线加权效果       = {off:+.4f}")
print(f"用线上权重重算     = {reweighted:+.4f}")
print(f"线上真实结果       = {online:+.4f}")
print(f"总落差（离线 - 线上）= {total_gap:+.4f}")
print(f"分布错位解释的落差 = {off - reweighted:+.4f} "
      f"({(off - reweighted) / total_gap:.0%} of 总落差)")
print(f"剩余落差（系统/策略层）= {reweighted - online:+.4f}")
print("  <- 分布错位解释了落差的绝大部分；剩余 = 系统层 + 策略层的偏移")

# ============================================================
# 3. 加权重算的有效样本量：防止某一层主导
# ============================================================
def n_eff(w, n_k):
    return 1.0 / sum(wi ** 2 / ni for wi, ni in zip(w, n_k))


print("\n== 3. 重加权的有效样本量 ==")
for n_k in ([500, 500, 500], [1500, 100, 100], [1800, 50, 20]):
    ne = n_eff(w, n_k)
    print(f"各层样本 {n_k} -> n_eff={ne:7.1f} (占名义 {sum(n_k)} 的 {ne/sum(n_k):.0%})")
print("  <- 与线上权重最大（0.55）的层1 样本太少时，重算结果被它支配")
print("     判据：n_eff/名义样本 < 20% 时，重加权结论不可信")

# ============================================================
# 4. 度量层：代理指标的历史符号一致率 + Wilson 区间
# ============================================================
def wilson(k, n, z=1.959963985):
    if n == 0:
        return 0.0, 0.0
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return max(0.0, c - h), min(1.0, c + h)


print("\n== 4. 代理指标符号一致率（含不确定性） ==")
for k, n in [(12, 12), (10, 12), (8, 12), (9, 10), (45, 50)]:
    lo, hi = wilson(k, n)
    band = "证据不足（区间含 0.5）" if lo < 0.5 else "代理可用"
    print(f"{k}/{n} = {k/n:.2f}  95% CI [{lo:.2f}, {hi:.2f}]  {band}")
print("  <- 只有 12 次历史改动时，10/12 的 95% 区间下界只有 0.55：")
print("     它不能再排除'抛硬币'级别的代理有效性，只够支撑'初步可用'")

# ============================================================
# 5. 系统层：链路保真度 f = 模型改进传递到最终展示的比例
# ============================================================
print("\n== 5. 系统层：链路保真度 ==")
delta_model = 0.030          # 模型原始输出的改进（离线测得）
for f in (1.00, 0.70, 0.40, 0.15):
    delta_chain = -0.002     # 链路自身的漂移（合成）
    obs = f * delta_model + delta_chain
    print(f"保真度 f={f:.2f} -> 预期线上效果 {obs:+.4f} "
          f"(若按模型改进外推会预期 {delta_model:+.4f}，高估 {delta_model/obs:.1f}x)")
print("  <- f 必须定期实测；把预期写成 f * 离线改进，而不是 离线改进")

# ============================================================
# 6. 策略层：中间变量归因
# ============================================================
print("\n== 6. 策略层：阈值与新分数分布不匹配 ==")
# 合成：模型升级后置信度整体上移 0.06，阈值固定 0.90
for shift, tag, seed in ((0.0, "升级前", 77), (0.06, "升级后", 77)):
    r = random.Random(seed)            # 同一随机种子 -> 分数分布整体平移
    auto = 0
    for _ in range(20000):
        conf = min(1.0, max(0.0, r.gauss(0.86 + shift, 0.07)))
        if conf > 0.90:
            auto += 1
    print(f"{tag}: 置信度均值 {0.86 + shift:.2f} -> 自动化率 ≈ {auto/20000:.1%}")
print("  <- 自动化率从 28% 跳到 61%，'按时解决率'的上涨主要来自这里")
print("     若不看中间变量，会把它误归因为'模型能力提升'")

# ============================================================
# 7. 功效核算：这个实验能检出多大的效应（MDE）
# ============================================================
def mde(p, n_per_arm, alpha=0.05, power=0.80):
    z_a, z_b = 1.959963985, 0.841621234
    return math.sqrt(2 * p * (1 - p) * (z_a + z_b) ** 2 / n_per_arm)


print("\n== 7. 功效核算：不显著到底是'没效应'还是'测不出' ==")
for n in (5000, 20000, 100000):
    m = mde(0.10, n)
    print(f"每组 {n:6d} -> MDE = {m:.4f}（相对 {m/0.10:.1%}）")
print("  若离线预期提升 0.5 个百分点（相对 5%），每组 20000 的 MDE 是 0.84 个百分点（相对 8.4%）：")
print("  -> 该实验从一开始就不可能检出预期效应，'不显著'不构成任何证据")

代码里七个值得注意的点：

  • 第 1 段说明 SRM 是最便宜的检查：10 万样本下 2% 的分流偏差就会给出极小的 p 值（10−4 量级以下）。用 0.001 而不是 0.05 作阈值，是因为这个检验会被反复执行，而因为正常波动误停实验的代价高于多跑一天。
  • 第 2 段是一次完整的落差分解：离线测得 +2.60 个点、线上实测 +2.00 个点，总落差 0.60 个点。用线上权重重算得到 +1.85：分布错位一项就解释了 0.75 个点（超过总落差），剩余的 −0.15 说明系统/策略层还有一点反向偏移。先做这一步的意义在于它把"模型不行"这个昂贵假设排除了——落差的量级被一个不涉及模型的抽样问题解释掉了。
  • 第 3 段给出重加权的防线：各层样本是 [1800,50,20] 时 neff​ 只有名义样本的 7%，重算被层 1 支配。这解释了为什么"用线上权重重算离线分数"这件事有时会给出荒谬结果——不是方法错，是重叠性不足。
  • 第 4 段是本节最实用的一个数字：10/12 的一致率（0.83）看起来很好，但 95% 区间是 [0.55,0.95] —— 下界只比抛硬币高一点。只有累积到 45/50（区间 [0.79,0.96]）才谈得上"代理已被验证"。"离线指标到底有没有用"在只有十几次改动历史时没有答案——正确动作是继续记录台账，而不是急着下结论。
  • 第 5 段给出系统层的预期公式：保真度 f=0.4 时，离线涨 3 个点只应预期线上涨 1.0 个点（还要扣链路漂移）。把 f 写进预期，能消除大部分"落差"叙事。
  • 第 6 段是策略层的典型事故：阈值固定而分数分布整体上移，自动化率从 28% 跳到 56%，端到端指标的上涨主要来自这里。如果不看中间变量，团队会得出"模型能力提升带动业务指标"的错误外推。
  • 第 7 段是最容易被忽略的结论：每组 2 万样本、基线 0.10 时 MDE 是 0.84 个百分点（相对 8.4%），而离线预期只有 0.5 个百分点（相对 5%）—— 这个实验设计从一开始就不可能检出目标效应。"不显著"在这里不携带任何关于"有没有效应"的信息。每次报告"不显著"之前都要先报 MDE。

练习#

  1. 分层重算：某评测集的离线提升是 +2.4 个点。按任务类型分三层：简单（占评测集 40%、效果 +1 点）、中等（40%、+2 点）、困难（20%、+6 点）。线上流量权重是 20% / 40% / 40%。 （a）用线上权重重算离线提升，与 +2.4 相差多少？ （b）如果线上实测只有 +0.6，这个重算解释了总落差的多少？ （c）假设"困难"层在评测集里只有 12 个样本，算出 neff​ 并判断重算是否可信。

  2. SRM 与污染：某实验对照组 25,000 人、实验组 24,600 人。 （a）算 SRM 卡方与 p 值（用 p 值在 df=1 下的近似公式），按 0.001 阈值判断是否异常； （b）假定分流正常，那么剩下的 1.6% 差异最可能来自什么？列出三种机制并给出对应的检查方法； （c）说明"缓存键不含实验分组"会造成什么现象（提示：对照组的指标被实验组污染，效应量被低估）以及如何检测。

  3. 归因树实操：你面对"离线 +3 点、线上 0 点"，且团队里有三种说法：（A）模型过拟合评测集；（B）线上流量不一样；（C）改动没真正生效（灰度配置漏了）。 （a）按本节的"最便宜检验优先"原则，给出你的检查顺序（至少 5 步），每步写出判据； （b）哪一步能在 1 小时内完成？哪一步最贵？ （c）如果所有检验都排除了，你的结论怎么写？

  4. 保真度外推：你测出链路保真度 f=0.55，链路自身漂移 −0.003。下一次离线评测显示 +4 个点。 （a）写出你对外宣布的线上预期值与它的不确定性来源； （b）如果实际线上只涨 0.5 个点，落差里有多少属于"保真度已解释"、多少属于新的未知； （c）f 可能随请求类型变化（长请求更容易被截断）。这会让"全局 f"产生什么偏差？

  5. 中间变量反例（开放题）：某团队把模型升级后"按时解决率"从 61% 涨到 68%，准备写进季度总结。你查到自动化率从 45% 涨到 72%、而"被自动处理的工单的解决率"从 61% 降到 58%。 （a）用混合分解写出 68% 的来源（提示：加权平均 + 组成效应）； （b）这次升级的净效果是正还是负？需要什么额外数据才能判断？ （c）如果你要在下一次升级中避免这种情况，会改哪两处设计？

  6. 前置检查：为"给客服工单自动生成回复草稿"这个功能，写一份评测设计前置清单，要求覆盖本节第八条的六项。对每一项写出：具体做法、缺失时的后果、验收标准。

小结#

  • 归因的顺序由成本决定，不由可能性决定：实验有效性（分钟级）→ 策略层中间变量（分钟级）→ 总体层重加权（小时级）→ 度量层历史一致率（小时级）→ 系统层影子回放（天级）→ 最后才是"模型不行"。
  • 每一层都有可分解的式子：总体层用 ∑wk​Δk​ 重算（并检查 neff​）；系统层用乘性账本 Δobs​=f⋅Δmodel​+Δchain​；策略层看中间变量的变化；度量层用符号一致率 + Wilson 区间。
  • 有效样本量是重加权的第一道门槛：neff​/名义样本<20% 时，重加权结果不可信（与第 1 节 IPS 的权重裁剪同源）。
  • "离线涨、线上跌"要先怀疑实验，再怀疑代价迁移，最后才是模型。生产环境里，缓存污染、用户跨组、采集不对称三类缺陷造成的错向结论比模型问题更常见。
  • "离线不涨、线上涨"是最有价值的信号：它说明现有评测集没捕捉到真实机制（多轮交互、稳定性、长尾）。正确动作是把线上发现的机制补成评测集的新一层。
  • 未归因是合格结论：证据不足时写明"未能归因"并给出取证计划，比编一个解释便宜得多。
  • 可归因性是设计出来的：分层标签、中间变量埋点、代理一致性台账、日志探索、保真度测量、MDE 预注册——这六项必须在评测设计阶段前置，事后补不了。
