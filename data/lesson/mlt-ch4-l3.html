过拟合与欠拟合的数学解释#

"过拟合""欠拟合"是机器学习里最常挂在嘴边的两个词，但大多数人只是凭图说话，说不出它们的数学定义。有了上一课的偏差-方差分解，这两个词终于可以被精确定义，并且和第 1 章的 ERM、第 3 章的正则化全部串起来。这一课，我们把整门课的四章收束成一个完整的因果链条。

一、概念讲解#

1. 用偏差和方差精确定义两个词#

把上一课的分解式作为"总纲"：

期望误差 = Bias² + Variance + σ²

由此，两个词有了数学定义：

  • 欠拟合（Underfitting）：Bias² 主导误差。模型假设空间太小，平均而言就贴不近真实函数——再多的训练数据、再稳的拟合，都救不了它。特征是：训练误差和测试误差都高。
  • 过拟合（Overfitting）：Variance 主导误差。模型假设空间太大，把训练集的噪声也"背"了下来——换一批数据，模型就换一副面孔。特征是：训练误差很低，但测试误差很高，两者之间有巨大鸿沟。

一句话记住：欠拟合是"能力不足"，过拟合是"记住太多"。

2. 三条曲线的形状：容量-误差图#

把"模型容量（复杂度）"放在横轴，误差放在纵轴，会得到机器学习里最重要的一幅图：

  • 训练误差：随容量增加单调下降。容量越大，模型越能贴合训练集，极限时可以零误差。
  • 测试误差：呈 U 形。容量太小时（左端）偏差大 → 测试误差高（欠拟合）；容量太大时（右端）方差大 → 测试误差又升高（过拟合）；中间某点是最优容量，测试误差最小。

U 形曲线的最低点，就是"偏差-方差权衡"的最优点。调参（选阶数、选深度、选 λ）的本质，就是在找这条 U 形曲线的最低点。

3. 泛化差距：为什么 ERM 会"说谎"#

训练误差与测试误差之间的差，叫泛化差距（generalization gap）。它在数学上可以这样看：ERM 最小化的是经验风险 L_S(h)，而我们要的是期望风险 L_𝒟(h)。学习理论（如 PAC 学习、VC 维、Rademacher 复杂度）的核心结论是：

L_𝒟(ĥ) ≤ L_S(ĥ) + 复杂度惩罚项（随 |ℋ| 增大、随样本量 m 减小）

也就是说，泛化差距随假设空间变大而变大、随数据变多而变小。这正是第 1 章结尾埋下的那个隐患的定量版本：ERM 只保证"训练集上最优"，不保证"真实分布上最优"；假设空间越大，这个保证越弱。

4. 与前面三章的因果闭环#

现在可以把四章串成一条完整的因果链：

  1. 第 1 章（ERM）：学习 = 在 ℋ 里最小化经验风险。ℋ 太小 → 偏差大（欠拟合）；ℋ 太大 → 方差大（过拟合）。
  2. 第 2 章（MLE/损失）：损失函数来自概率假设（高斯→MSE，伯努利→交叉熵）。损失选对了，偏差才可能降下来。
  3. 第 3 章（贝叶斯/正则）：正则 = 先验。正则化主动牺牲一点偏差、换取方差的下降，把模型从 U 形曲线右端拉回最低点附近。
  4. 第 4 章（偏差-方差）：这条恒等式是前 3 章的"总账本"，它精确量化了"多大算大、多小算小"。

一句话总结全课：ERM 负责"拟合"，概率负责"定损失"，先验负责"控复杂度"，偏差-方差分解负责"算总账"。

5. 怎么修：对准三个分量的药方#

知道了误差的三个来源，就能对症下药：

症状 诊断（哪项大） 药方
欠拟合 Bias² 大 增大模型容量（更高阶、更深、更多特征），减少正则 λ
过拟合 Variance 大 增加训练数据，增强正则 λ（L1/L2），提前停止，集成/平均
数据脏 Noise 大 清理数据、更好的特征、换更准确的标注（模型无能为力）

特别注意："加数据"只降方差，不降偏差（上一课练习 4）；"加大模型"只降偏差，可能升方差。没有一个动作能同时解决所有问题——这正是"权衡"二字的含义。

6. 一点现代补充：双重下降#

近年研究发现，U 形曲线在深度网络 + 超参数化时会出现一个反直觉现象：越过"过拟合区间"后，继续增大模型，测试误差可能再次下降（double descent）。这提醒我们，经典偏差-方差分解是理解泛化的第一近似，但不是全部真相。不过，对于绝大多数传统模型和入门理解，U 形曲线与偏差-方差权衡仍是正确且深刻的起点。

二、可运行代码示例#

在一个真实数据集上，画出"训练误差 vs 测试误差 vs 多项式阶数"的曲线，亲手看见那条 U 形曲线：低阶时两者都高（欠拟合），中间最优，高阶时训练误差趋零而测试误差飙升（过拟合）。

import numpy as np

rng = np.random.default_rng(31)

def f(x):
    return np.sin(x)

# 训练集与测试集（测试集用来估计"期望误差"）
x_train = rng.uniform(-3, 3, size=50)
y_train = f(x_train) + rng.normal(0, 0.4, size=50)
x_test  = np.linspace(-3, 3, 200)
y_test  = f(x_test)

def fit_and_error(K):
    A = np.vander(x_train, K + 1, increasing=True)
    w = np.linalg.lstsq(A, y_train, rcond=None)[0]
    pred_train = np.vander(x_train, K + 1, increasing=True) @ w
    pred_test  = np.vander(x_test,  K + 1, increasing=True) @ w
    err_train = float(np.mean((pred_train - y_train) ** 2))
    err_test  = float(np.mean((pred_test  - y_test)  ** 2))
    return err_train, err_test

print(f"{'阶数 K':>6} | {'训练误差':>10} | {'测试误差':>10}")
for K in [0, 1, 2, 3, 5, 8, 12, 18]:
    e_tr, e_te = fit_and_error(K)
    print(f"{K:>6} | {e_tr:>10.4f} | {e_te:>10.4f}")

运行结果会呈现教科书式的 U 形：K=0~1 训练、测试误差都高（欠拟合）；K=3~5 测试误差最低（最优）；K=12~18 训练误差趋近 0，但测试误差再次升高（过拟合）。这张表，就是偏差-方差权衡在真实数据上的投影。

三、练习#

  1. 用偏差-方差分解的语言，重新表述"欠拟合"和"过拟合"，并分别说明它们在训练误差/测试误差上的特征。
  2. 解释 U 形曲线两端：为什么左端测试误差高（关联 Bias²）、右端测试误差也高（关联 Variance），而训练误差却一路单调下降？
  3. 结合第 3 章：增大正则系数 λ，在偏差-方差坐标系里是往哪个方向移动？为什么它能治过拟合、却可能加重欠拟合？
  4. 思考：把训练样本量从 50 加到 5000，上面的 U 形曲线会怎样变化（右端是否还翘起来）？为什么"数据变多"只压制方差、不压制偏差？

母原理连接#

本课是全课程四章的收束点，把三条母原理拧成一股绳："一切学习=优化"（ERM 的过拟合风险）、"概率视角统一"（偏差-方差分解是期望运算的产物，正则来自先验）、"信息论视角"（交叉熵与模型分布逼近真实分布的 KL 散度，也受制于数据量）。四章走完，你得到的不是十几个零散算法的调用方法，而是一套统一的思维方式：任何学习问题，都可以先问"假设空间、损失、先验、偏差-方差"四个问题，从而直达本质。这就是"母原理"的意义——算法会过时，母原理不会。
