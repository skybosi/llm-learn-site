K-means 实现#

一、概念讲解#

1.1 上一课的回顾#

上一课我们弄清了 K-means 的数学原理：给定簇数 K，反复做"分配"和"更新"两步，最小化簇内误差平方和（inertia）。这一课我们把原理落到工程上——用 scikit-learn 完整地实现一次聚类，并理解每个关键参数背后的含义。

在动手之前，有一个容易被忽视但至关重要的环节：数据预处理。K-means 依赖距离，而距离对特征的量纲非常敏感。假如一份数据同时包含"年龄（几十到一百）"和"年收入（几万到几十万）"两个特征，收入在距离计算里会完全压过年龄。因此，在做 K-means 之前通常要先对特征做标准化，让每个特征都处在可比的尺度上。这也是"原理"和"工程实现"之间最重要的差距之一。

1.2 sklearn 的 KMeans 关键参数#

sklearn 的 KMeans 类把 K-means 的各种变体统一封装了起来，最常用的参数有：

  • n_clusters：簇数 K，必填的核心超参数，默认 8。
  • init：初始中心的选择方式。默认是 'k-means++'，它会优先选择彼此距离较远的样本作为初始中心，从而降低"初始点选得差导致结果差"的概率；也可设为 'random' 使用纯随机初始化。
  • n_init：用不同的随机初始化重复运行算法的次数，最后保留惯性最小的那次结果。默认值是 'auto'（新版本中约等于 10 次），这是对抗"局部最优"最实用的手段。
  • max_iter：单次运行的最大迭代次数，默认 300。
  • random_state：随机种子，固定后结果可复现。
  • tol：判定收敛的阈值，当中心移动量小于该值时提前停止。

理解这些参数的关键在于它们分别对应算法的哪一环：init 和 n_init 管"起点"，max_iter 和 tol 管"终点（何时停）"，n_clusters 管"目标"。

1.3 一个完整实现的标准流程#

工程上实现一次 K-means，通常按以下顺序推进：

  1. 加载 / 生成数据，观察特征取值范围；
  2. 标准化特征（常用 StandardScaler），消除量纲影响；
  3. 选择 K（本课先用已知的簇数，第 3 课再讲如何科学地选）；
  4. 训练模型，检查聚类中心、标签与惯性；
  5. 可视化 / 解读结果，判断划分是否合理。

下面用 make_blobs 生成已知分组的人工数据，走一遍完整流程。make_blobs 会按指定的中心生成若干各向同性的高斯簇，非常适合用来验证聚类算法。

二、可运行代码示例#

# -*- coding: utf-8 -*-
# 第 2 课：K-means 完整实现流程
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_blobs

# 1. 生成人工数据集：3 个簇，共 300 个样本
#    centers=3 表示 3 个中心；cluster_std 控制每个簇的离散程度
X, y_true = make_blobs(n_samples=300, centers=3,
                       cluster_std=0.8, random_state=42)
print("数据形状：", X.shape)   # (300, 2)

# 2. 标准化：让每个特征的均值为 0、标准差为 1
#    对 make_blobs 这种量纲一致的数据影响不大，但真实数据上几乎必做
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 3. 训练 K-means
#    init='k-means++' 让初始中心彼此分散；n_init=10 跑 10 次取最优
kmeans = KMeans(n_clusters=3, init="k-means++",
                n_init=10, max_iter=300, random_state=42)
kmeans.fit(X_scaled)

# 4. 查看结果
print("聚类中心（标准化坐标系）：")
print(kmeans.cluster_centers_)
print("惯性（inertia）：", kmeans.inertia_)
print("迭代次数：", kmeans.n_iter_)

# 5. 可视化：左图是真实分组，右图是 K-means 的划分
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].scatter(X_scaled[:, 0], X_scaled[:, 1], c=y_true, s=20, cmap="viridis")
axes[0].set_title("真实分组（真值）")
axes[1].scatter(X_scaled[:, 0], X_scaled[:, 1], c=kmeans.labels_, s=20, cmap="viridis")
# 把聚类中心用红色星号标出来
axes[1].scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1],
                marker="*", s=200, c="red", edgecolor="black")
axes[1].set_title("K-means 聚类结果")
plt.tight_layout()
plt.show()

输出解读：右侧图中三种颜色分别对应三个簇，红色星号是学到的聚类中心。可以看到，对于这种球形且分离良好的数据，K-means 能几乎完美地还原出真实分组。

注意：聚类得到的标签编号（0、1、2）与真实标签（0、1、2）的对应关系是随机的，簇的"编号"本身没有语义，对比时不要直接按编号相等来判断对错。

三、练习小节#

  1. 把 init 改为 'random' 并把 n_init 设为 1，多运行几次，观察结果是否稳定；再改回 'k-means++' 和 n_init=10，体会这两个参数的作用。
  2. 修改 make_blobs 的 cluster_std（例如改成 2.0），让簇之间重叠更严重，观察聚类结果如何变差，思考为什么会这样。
  3. 为什么说"数据标准化"在真实数据上几乎必做？请构造一个两特征量纲相差悬殊的小例子（例如特征一取值 01，特征二取值 010000），对比标准化前后的聚类结果。
  4. 自己动手：用纯 NumPy 实现一个最简版 K-means（随机初始化、硬分配、均值更新，迭代固定次数），并和 sklearn 的 inertia_ 对照。
