为什么需要激活#

前面每一课我们都反复强调一句话："没有非线性激活，再深的网络也只是线性变换。"这一课就正面回答这个问题：激活函数到底起了什么作用？为什么少了它，MLP 就名存实亡？ 我们会用一个简洁的数学论证和一个可运行的实验，把"激活 = 非线性 = 深度网络的生命线"这条道理讲透。

一、概念讲解#

1. 全连接层的本质：线性变换#

回顾 MLP 的每一层：

z = W·a + b

这本质上是一个线性（仿射）变换——输出是输入的线性组合再平移。线性变换有几个"要命"的性质：

  • 它的图像是一条直线（或高维平面），无法表达弯曲；
  • 两个线性变换的复合，仍然是一个线性变换。

第二点尤其关键。假设两层网络都没有激活函数：

第 1 层：h = W₁x + b₁
第 2 层：ŷ = W₂h + b₂ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)

把 W₂W₁ 记作 W'、W₂b₁ + b₂ 记作 b'，整个两层网络就塌缩成了：

ŷ = W'x + b'

一层、两层、一百层线性层，叠在一起永远等价于"一个线性层"。 这就是为什么"堆层数"本身毫无意义——堆的只是矩阵连乘。无论你加多少层，只要中间没有非线性，模型能表达的函数类始终只是线性函数，跟线性回归没有本质区别。

2. 激活函数打破"塌缩"#

现在把非线性激活 f 插进两层之间：

ŷ = W₂ · f(W₁x + b₁) + b₂

因为 f 不是线性的，f(W₁x + b₁) 无法再被"提出来"合并成一个矩阵，两层不再等价于一层。正是这一步"破坏线性"，让网络获得了表达弯曲决策边界、复杂函数的能力——也是上一章"万能逼近定理"成立的前提。

所以激活函数的真正身份，是给网络注入非线性。它是 MLP 区别于"一堆线性回归叠在一起"的分水岭。

3. 一个直觉：非线性是"弯折"的力量#

把网络想象成一台"折纸机"：

  • 只有线性变换时，它只能做平移、旋转、缩放——无论操作多少次，输入空间始终是"平"的，两类数据若被直线无法分开，就永远分不开；
  • 加入激活函数后，每一步都相当于把空间弯折一下。多次弯折叠加，原本搅在一起的两类点，就可能被"掰"成可以被一条直线（输出层的线性分界）分开的样子。

这就是为什么有了隐藏层非线性，XOR 这种"原始空间线性不可分"的问题能被解决：网络把输入空间弯成了一个新的表示空间，在新空间里两类点变得线性可分。

4. 顺带纠正两个常见误区#

  • "激活函数让输出非负/归一化"：那只是某些激活函数的副带效果，不是它的根本使命。根本使命是非线性；
  • "输出层一定要激活"：不一定。回归任务输出层常不用激活（要连续值）；分类任务输出层用 Sigmoid/Softmax，是为了把输出解释成概率。隐藏层的非线性才是"必须"的，输出层的激活是"按任务选"的。

5. 什么函数能当激活#

理论上，只要满足"非线性、几乎处处可导（方便反向传播）"的函数都能当激活。于是诞生了 Sigmoid、Tanh、ReLU、Leaky ReLU、GELU 等一大类选择——它们的区别、优缺点与选择策略，正是本课后面两节的主题。

二、可运行代码示例#

示例 1：用 NumPy 证明"多层线性 = 一层线性"

我们随机生成三个线性层，验证"依次套三层"与"把三个矩阵乘成一个"结果完全一致。

import numpy as np

rng = np.random.default_rng(42)

# 三个"线性层"的权重与偏置
W1 = rng.normal(size=(3, 4)); b1 = rng.normal(size=(3,))
W2 = rng.normal(size=(5, 3)); b2 = rng.normal(size=(5,))
W3 = rng.normal(size=(2, 5)); b3 = rng.normal(size=(2,))

x = rng.normal(size=(4,))   # 输入

# 方法 A：一层一层地算（模拟三层线性网络）
h1 = W1 @ x + b1
h2 = W2 @ h1 + b2
y_stack = W3 @ h2 + b3

# 方法 B：先把三层合并成一个线性层，再一次性算
W = W3 @ W2 @ W1
b = W3 @ W2 @ b1 + W3 @ b2 + b3
y_merged = W @ x + b

print("逐层计算：", y_stack)
print("合并计算：", y_merged)
print("两者最大误差：", np.max(np.abs(y_stack - y_merged)))

运行后你会看到 两者最大误差 几乎为 0（只差浮点精度）。这证明：没有激活函数，叠多少层都白搭，最终仍是一个线性变换。

示例 2：线性网络 vs 带激活的网络，在 XOR 上见分晓

用 PyTorch 对比"纯线性多层"与"加了 ReLU"的两种网络，看谁学得会 XOR。

import torch
import torch.nn as nn

X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = torch.tensor([[0.], [1.], [1.], [0.]])

def train(model, name):
    criterion = nn.MSELoss()
    optimizer = torch.optim.SGD(model.parameters(), lr=0.5)
    for epoch in range(4000):
        optimizer.zero_grad()
        loss = criterion(model(X), y)
        loss.backward()
        optimizer.step()
    print(f"{name:10s} 最终损失 = {loss.item():.4f}")

# 网络 A：多层但全是线性（没有激活）——理论上等价于一个线性层
linear_net = nn.Sequential(nn.Linear(2, 4), nn.Linear(4, 4), nn.Linear(4, 1))
train(linear_net, "纯线性网络")

# 网络 B：同样多层，但隐藏层加了 ReLU 非线性
relu_net = nn.Sequential(nn.Linear(2, 4), nn.ReLU(), nn.Linear(4, 4), nn.ReLU(), nn.Linear(4, 1))
train(relu_net, "带 ReLU 网络")

# 打印两类网络的预测结果
with torch.no_grad():
    print("纯线性网络预测：", linear_net(X).round().flatten().numpy())
    print("带 ReLU 网络预测：", relu_net(X).round().flatten().numpy())

运行结果非常鲜明：纯线性网络即使堆了三层、练了 4000 轮，损失也降不到 0，四个样本的预测依然错乱（它本质上只是在学一条直线）；而带 ReLU 的网络能轻松把损失压到接近 0，预测接近 [0, 1, 1, 0]。同一个结构，差别全在有没有激活函数——这就是"非线性"的全部意义。

三、练习#

  1. 复现证明：运行示例 1，确认"逐层计算"与"合并计算"几乎相等，用自己的话说明为什么多层线性会塌缩成一层。
  2. 数学推导：把公式 ŷ = W₂(W₁x + b₁) + b₂ 一步步展开，写出合并后的 W' 与 b'，验证它仍是线性变换。
  3. 对比实验：运行示例 2，观察纯线性网络与带 ReLU 网络的损失和预测差异；再试试把 ReLU 换成 Sigmoid，看是否同样能学会 XOR。
  4. 误区自查：判断对错并解释——"只要网络有足够多层，即使不用激活函数也能表达非线性函数。"
