方差与标准差#

期望告诉我们随机变量"平均在哪"，但它完全没告诉我们"有多散"。两个随机变量可以有相同的期望，但一个取值老老实实挤在中心附近，另一个却忽大忽小。方差就是衡量这种"离散程度"的指标——在机器学习里，它既是数据预处理的基石，也是理解"模型风险/波动"的钥匙。

一、概念讲解#

1. 方差的定义#

随机变量 X 的方差定义为离差平方的期望：

Var(X) = E[ (X − E[X])² ]

直观上，它把"每个取值偏离中心多远"先平方（避免正负抵消），再求平均。方差越大，说明取值越分散；方差为 0 意味着 X 恒等于一个常数（毫无随机性）。

按定义展开并利用期望的线性性质，能得到一个更便于手算的公式：

Var(X) = E[X²] − (E[X])²

2. 标准差：把单位"拉回"原尺度#

方差的单位是原单位的平方（身高的方差单位是 cm²），不够直观。因此常取其算术平方根，得到标准差：

σ = √Var(X)

标准差的单位和原数据一致，可以直接和均值放在一起说："身高 170 ± 6 cm"。符号 σ（小写 sigma）和 σ² 分别表示标准差和方差。

3. 常用性质#

  • 加常数不变：Var(X + c) = Var(X)。整体平移不改变分散程度。
  • 乘常数放大平方：Var(aX) = a² · Var(X)。放大 a 倍，方差放大 a² 倍。
  • 独立变量之和：若 X、Y 独立，则 Var(X + Y) = Var(X) + Var(Y)。这是"独立则方差可加"的重要结论。

4. 机器学习视角：标准化与风险#

  • 特征标准化（Z-score）：把每个特征减去均值再除以标准差，z = (x − μ) / σ，得到均值为 0、方差为 1 的特征。这能消除不同特征量纲的影响，让梯度下降更快、更稳，是训练前的常规操作。
  • 方差即风险：在金融和决策论里，方差常被当作"风险/不确定度"的度量。一个预测器若在训练集上损失很小、但换一批数据损失波动巨大，我们说它"高方差"（过拟合的典型特征）。理解方差，才能理解机器学习里著名的"偏差-方差权衡"。

二、可运行示例#

示例 1：手算骰子点数的方差#

# 骰子点数 X 的方差：E[X^2] - (E[X])^2
values = list(range(1, 7))
p = 1 / 6

e_x = sum(k * p for k in values)         # 3.5
e_x2 = sum(k * k * p for k in values)    # E[X^2]
var = e_x2 - e_x ** 2
print(f"E[X] = {e_x}")
print(f"E[X^2] = {e_x2}")
print(f"Var(X) = {var:.4f}")
print(f"标准差 σ = {var ** 0.5:.4f}")

示例 2：用样本估计方差与标准差#

import statistics

# 身高样本（cm）
heights = [162, 170, 168, 175, 158, 172, 165, 180, 169, 171]

mean = statistics.mean(heights)
# 样本方差默认用 n-1 做分母（无偏估计），总体方差用 pvariance
var = statistics.variance(heights)
std = statistics.stdev(heights)

print(f"均值 = {mean:.2f} cm")
print(f"样本方差 = {var:.2f} cm²")
print(f"标准差 = {std:.2f} cm")

示例 3：特征标准化（Z-score）#

import statistics

# 两组量纲差异很大的特征
age = [22, 25, 30, 28, 35, 40, 24, 33]
income = [3000, 5000, 8000, 6500, 12000, 20000, 4500, 9000]


def standardize(data):
    """Z-score 标准化：减去均值再除以标准差。"""
    m = statistics.mean(data)
    s = statistics.stdev(data)
    return [(x - m) / s for x in data], m, s


age_z, age_m, age_s = standardize(age)
income_z, income_m, income_s = standardize(income)

print("标准化后的年龄：", [round(x, 2) for x in age_z])
print("标准化后的收入：", [round(x, 2) for x in income_z])

# 验证：标准化后均值接近 0，样本方差接近 1
print(f"年龄标准化后均值 = {statistics.mean(age_z):.2e}")
print(f"收入标准化后方差 = {statistics.variance(income_z):.2f}")
