自定义样式#

默认的 Matplotlib 图能看，但离"好看、专业"还差一口气：边框多余、字体偏小、颜色发灰。这一课把散落在各处的"美化"技巧收拢起来，教你系统化地自定义一张图的颜色、线型、边框、刻度、字体，并最终把它们固化成可复用的"样式"。

一、概念讲解#

1. 一张图有哪些可自定义的元素#

一张 Matplotlib 图由很多"零件"组成，常见可定制项包括：

  • 颜色与线型：color、linestyle、linewidth、marker。
  • 坐标轴边框（spines）：图四周的四条边线，可以隐藏或移位。
  • 刻度（ticks）与刻度标签（tick labels）：决定坐标轴上标什么数字、字体多大、朝里还是朝外。
  • 文字：标题、轴标签、图例、注释的字体大小与样式。
  • 画布本身：figsize、分辨率 dpi、留白。

2. 中文字体的坑#

Matplotlib 默认字体不含中文字符，中文标签会显示成方框"□□□"。解决办法是在脚本开头设置：

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

第一行指定中文字体（按优先级依次尝试），第二行让负号 "-" 能正常显示。字体名需与你系统里实际安装的字体匹配。

3. 全局样式：rcParams 与 style sheet#

与其每张图重复写一堆 color=、fontsize=，不如把常用设置固化：

  • rcParams：一个全局配置字典，plt.rcParams['font.size'] = 12 会让之后所有图的字号都变成 12。
  • 样式表（style sheet）：plt.style.use('ggplot') 或 'seaborn-v0_8' 一键套用整套现成风格；plt.style.available 可查看全部可选样式。你也可以把自己喜欢的参数存成 .mplstyle 文件反复使用。

4. 保存与导出#

用 fig.savefig('out.png', dpi=300, bbox_inches='tight') 保存图片。dpi=300 适合印刷或报告插图；bbox_inches='tight' 会自动裁掉多余白边，避免导出后四周留白过大。

二、可运行代码示例#

示例 1：把一个"默认图"改造成"成品图"#

下面先画默认样式，再逐一加上自定义，对比前后的差别：

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

x = np.linspace(0, 10, 100)
y = np.sin(x) * np.exp(-0.1 * x)     # 一个衰减的正弦波

fig, ax = plt.subplots(figsize=(8, 5))

# 1. 画主曲线：指定颜色、线宽、线型，并加标签
ax.plot(x, y, color='#1f77b4', linewidth=2.2, linestyle='-', label='衰减正弦波')

# 2. 加一条 y=0 的参考虚线
ax.axhline(0, color='gray', linewidth=0.8, linestyle='--')

# 3. 精简边框：只保留左边和底边，并把它们移到原点位置
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.spines['bottom'].set_position(('data', 0))   # 底边移到 y=0 处
ax.spines['left'].set_position(('data', 0))     # 左边移到 x=0 处

# 4. 自定义刻度：把 x 轴刻度放到 0 到 10 每隔 2 一个，并去掉多余刻度标签
ax.set_xticks(np.arange(0, 11, 2))
ax.set_yticks([-1, -0.5, 0.5, 1])
ax.tick_params(axis='both', labelsize=10, direction='inout')

# 5. 文字：标题、轴标签、图例
ax.set_title('衰减的正弦波', fontsize=15, pad=15)
ax.set_xlabel('时间 t', fontsize=12)
ax.set_ylabel('幅值', fontsize=12)
ax.legend(loc='upper right', frameon=False)     # 无边框图例

fig.tight_layout()
plt.show()
# fig.savefig('damped_sine.png', dpi=300, bbox_inches='tight')   # 需要时取消注释

要点：spines[...].set_position(('data', 0)) 把坐标轴移到数据原点，做出"数学坐标轴"的效果；tick_params 的 direction='inout' 让刻度线朝内外双向延伸。

示例 2：用样式表一键切换风格#

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)

# 打印所有可用的内置样式名（可选）
# print(plt.style.available)

plt.style.use('ggplot')            # 一键套用 ggplot 风格
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, y, linewidth=2)
ax.set_title('ggplot 风格下的正弦曲线')
plt.show()

plt.style.use('default')           # 恢复默认样式

要点：plt.style.use 只影响它之后创建的图，不会改动之前画好的图；用完记得 plt.style.use('default') 恢复，避免影响后续代码。

三、练习#

  1. 动手改造：把第一课里画的那张 2×2 子图，统一换成 plt.style.use('seaborn-v0_8') 风格，再手动调整标题字号为 14、去掉所有子图的上边框和右边框。
  2. 字体设置：在你的环境里找到一款已安装的中文字体名（如"微软雅黑"），把它写进 rcParams['font.sans-serif']，验证中文标签不再显示方框。
  3. 导出对比：用 savefig 分别以 dpi=72 和 dpi=300 保存同一张图，比较两张图的文件大小和清晰度。
  4. 思考：为什么"隐藏多余的边框和刻度"通常能让图更清爽？有没有哪些场景是必须保留上边框/右边框的？
