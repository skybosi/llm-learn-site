文本分类应用#

朴素贝叶斯最经典的战场是文本分类——垃圾邮件过滤、新闻主题归类、情感分析都离不开它。本课把前面学的知识串成一条完整流水线：从原始文本到词频矩阵，再到朴素贝叶斯分类，最后用指标评估。

一、概念讲解#

1. 文本怎么变成数字：向量化#

机器学习模型吃的是数字矩阵，而文本是字符串。第一步要向量化（vectorization）：

  • CountVectorizer：把每篇文档转成"每个词出现次数"的计数向量（词袋模型，bag-of-words）；
  • TfidfVectorizer：在计数基础上加权，用 TF-IDF 让"常见词（如'的''了'）"降权、"稀有而关键词"升权。

向量化的结果是高维稀疏矩阵：词汇表可能有几万列，但每篇文档只有少数词出现（大部分是 0）。这正是朴素贝叶斯的主场——它处理稀疏计数又快又稳。

2. 为什么朴素贝叶斯适合文本#

  • 高维稀疏数据上，独立性假设虽不严格成立，但近似得不错；
  • 训练只需一遍统计词频，文本量大也扛得住；
  • 天然输出每个类别的概率，方便做阈值控制（如垃圾邮件拦截）。

3. 完整流水线（Pipeline）#

一条标准流水线把"向量化 + 分类器"封装成一个对象：Pipeline([("vec", TfidfVectorizer()), ("clf", MultinomialNB())])。这样训练、预测、交叉验证、调参都能一步到位，也避免"在测试集上泄露词表统计"这类低级错误。

4. 中文文本的额外一步：分词#

英文天然按空格分词；中文没有空格，需要先分词（如用 jieba 分词），或退而求其次按"字"切分（character n-gram）。CountVectorizer(analyzer="char_wb", ngram_range=(2,3)) 就能按中文字符 n-gram 提取特征，省去外部分词工具，在中文短文本上效果不错。

5. 评估：准确率之外要看报告#

文本类别往往不平衡（正常邮件远多于垃圾邮件）。除了准确率，要看混淆矩阵（哪些类别互相混淆）和分类报告（每类的精确率/召回率/F1），才能判断模型是否真的可用。

二、可运行代码示例#

from sklearn.datasets import fetch_20newsgroups
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline
from sklearn.metrics import classification_report, confusion_matrix

# 1. 取 20 Newsgroups 的两个主题做二分类（含训练/测试切分）
categories = ["rec.sport.baseball", "sci.space"]
train = fetch_20newsgroups(subset="train", categories=categories, random_state=42)
test = fetch_20newsgroups(subset="test", categories=categories, random_state=42)

# 2. 搭流水线：TF-IDF 向量化 + 多项式朴素贝叶斯
pipe = Pipeline([
    ("vec", TfidfVectorizer(stop_words="english")),  # 去英文停用词
    ("clf", MultinomialNB()),
])
pipe.fit(train.data, train.target)

# 3. 预测并评估
pred = pipe.predict(test.data)
print("测试准确率：{:.3f}".format(pipe.score(test.data, test.target)))
print("\n分类报告：\n", classification_report(
    test.target, pred, target_names=categories))
print("混淆矩阵：\n", confusion_matrix(test.target, pred))

# 4. 对新文本做预测，并查看概率
new_texts = [
    "The pitcher threw a fastball in the ninth inning",
    "The rocket was launched into orbit around the earth",
]
probs = pipe.predict_proba(new_texts)
for text, p in zip(new_texts, probs):
    print("\n文本：", text)
    print("各类概率：", dict(zip(categories, p.round(3))))

要点：TfidfVectorizer 负责把文档变成加权词频矩阵，MultinomialNB 在其上分类，二者被 Pipeline 封装成一个整体；predict_proba 直接给出文档属于各主题的概率，正是朴素贝叶斯的"概率基因"在起作用。

三、练习#

  1. 把 TfidfVectorizer 换成 CountVectorizer，对比准确率；再试试给 MultinomialNB 调 alpha（如 0.1、1、5），看平滑强度的影响。
  2. 增加第三个主题（如 talk.politics.guns），改成三分类，观察混淆矩阵里哪些类别最容易互相混淆。
  3. 自己构造一批中文短文本（两类主题，各 5 条左右），用 CountVectorizer(analyzer="char_wb", ngram_range=(2, 3)) + MultinomialNB 做分类，验证中文按字 n-gram 是否可行。
  4. 思考题：为什么对文本分类，"词袋模型"丢掉了词序却仍然有效？朴素贝叶斯的独立性假设在文本上大致成立的原因是什么？
