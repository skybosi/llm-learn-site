数学期望#

如果只能用一个数字概括一个随机变量，你会选什么？大多数人的答案是"平均"。数学期望就是概率意义上的"平均"——它把随机变量的所有可能取值按概率加权求和，给出一个代表性的中心值。在机器学习里，期望是最核心的算子之一：损失函数、风险、预测的"平均好坏"，本质上都是期望。

一、概念讲解#

1. 期望的定义#

离散随机变量 X 的期望定义为：

E[X] = Σₖ k · P(X = k)

即"每个取值 × 它的概率"全部加起来。连续随机变量的定义类似，把求和换成积分：

E[X] = ∫ x · f(x) dx

注意，期望不一定等于任何一个可能的取值：掷骰子点数的期望是 3.5，但骰子永远不会掷出 3.5。期望是"长期平均"，不是"最可能的值"。

2. 期望就是长期平均#

为什么加权平均能代表"长期平均"？假设骰子掷了 6000 次，由频率解释，每个点数大约各出现 1000 次，于是平均点数 ≈ (1×1000 + 2×1000 + … + 6×1000)/6000 = (1+2+…+6)/6 = 3.5。这正好是期望。所以期望可以理解为：把试验重复无穷多次，结果的算术平均会收敛到期望（这是大数定律的严格表述）。

3. 期望的线性性质#

期望最强大、用得最多的性质是线性：对任意随机变量 X、Y 和常数 a、b，

E[aX + b] = a·E[X] + b E[X + Y] = E[X] + E[Y]

第二条对任意 X、Y 都成立，即使它们不独立！这让"求和后的期望"可以拆成"期望的和"，极大简化计算。也正因如此，样本均值（把一堆观测加起来再平均）天然就是总体期望的无偏估计。

4. 机器学习视角：期望风险与损失函数#

监督学习的核心是找一个模型，让它在"新数据上"的平均损失尽量小。这个"平均损失"正是期望风险：

R(θ) = E[ L(y, ŷ(x; θ)) ]

其中 L 是损失函数（衡量预测 ŷ 与真实 y 的差距），期望是对数据分布 (x, y) 取的。实践中我们拿不到真实分布，只能用训练集上的经验均值去逼近这个期望——训练时不断下降的那个"平均 loss"，本质上就是在估计期望风险。所以"为什么优化损失能学到东西"，答案就藏在期望的定义里。

二、可运行示例#

示例 1：骰子点数的期望#

# 理论计算：E[X] = Σ k * P(X=k) = (1+2+3+4+5+6)/6 = 3.5
values = list(range(1, 7))
p = 1 / 6
expected = sum(k * p for k in values)
print(f"骰子点数的期望 E[X] = {expected}")

# 用样本均值逼近：样本越多越接近 3.5
import random

random.seed(0)
for n in [100, 1000, 100000]:
    rolls = [random.randint(1, 6) for _ in range(n)]
    mean = sum(rolls) / n
    print(f"掷 {n:>6} 次的样本均值 = {mean:.4f}")

示例 2：验证期望的线性性质#

import random

random.seed(1)


def die():
    return random.randint(1, 6)


# X = 骰子点数，验证 E[2X + 3] = 2*E[X] + 3
n = 200000
xs = [die() for _ in range(n)]
transformed = [2 * x + 3 for x in xs]

e_x = sum(xs) / n
e_trans = sum(transformed) / n
print(f"E[X] 的样本估计 = {e_x:.4f}")
print(f"E[2X+3] 的样本估计 = {e_trans:.4f}")
print(f"2*E[X]+3 的理论值 = {2 * 3.5 + 3}")

示例 3：损失函数（MSE）的经验期望#

import random

random.seed(2)

# 假设真实值 y 围绕 0 波动，模型预测恒为 0，看平方损失的平均（即期望的估计）
ys = [random.gauss(0.0, 1.0) for _ in range(50000)]


def mse(y_true, y_pred):
    """均方误差：各样本平方损失的平均值。"""
    return sum((t - p) ** 2 for t, p in zip(y_true, y_pred)) / len(y_true)


# 预测恒为 0
preds = [0.0] * len(ys)
loss = mse(ys, preds)
print(f"预测恒为 0 时的 MSE = {loss:.4f}")
print("提示：标准正态的方差为 1，MSE 会接近 E[(y-0)^2] = 1。")
