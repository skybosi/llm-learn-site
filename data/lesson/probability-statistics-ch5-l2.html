先验、后验与似然#

MLE 只依赖"当前这批数据"来估计参数。但现实中，我们往往在拿到数据之前就已经对参数有一些判断（比如"硬币大概率是均匀的"）。贝叶斯推断的独特之处，就是把这种"先验认知"和数据结合起来，用贝叶斯公式更新出"后验认知"。这一课讲清三个核心概念：先验、似然、后验。

一、概念讲解#

1. 三个角色各是什么#

回顾贝叶斯公式（本课程 chapter-1 已学过）：

P(θ | D) = P(D | θ) · P(θ) / P(D)

现在把 θ 看作"要估计的参数"，把 D 看作"观测到的数据"，三个量各有身份：

  • 先验 P(θ)：在看到数据之前，我们对参数 θ 的已有信念。比如"我认为这枚硬币 80% 是均匀的"。
  • 似然 P(D | θ)：在参数为 θ 时，观察到数据 D 的可能性。这正是上一课的主角。
  • 后验 P(θ | D)：看完数据之后，我们对 θ 的更新后的信念。它是先验被数据"修正"后的结果。

分母 P(D) 是与 θ 无关的归一化常数，所以贝叶斯推断的核心关系可以浓缩成一句话：

后验 ∝ 似然 × 先验

2. 用抛硬币把整个过程走一遍#

设硬币正面概率为 θ，先验认为 θ 很可能在 0.5 附近。现在抛了 n 次，观察到 k 次正面：

  • 先验：Beta(α, β) 分布（稍后解释）；
  • 似然：P(k | θ) ∝ θ^k · (1 − θ)^(n − k)，这是二项分布的核；
  • 后验：把两者相乘再归一化。

关键结论是：如果先验取 Beta 分布、似然取二项分布，那么后验仍然是 Beta 分布。这种"先验和后验同属一族"的性质叫共轭，Beta 就是二项似然的共轭先验。它的参数更新极其干净：

先验 Beta(α, β) → 观察到 (n, k) → 后验 Beta(α + k, β + n − k)

换句话说：每看到一次正面，就把 α 加 1；每看到一次反面，就把 β 加 1。α 和 β 可以理解为"先验里已经假设见过的正面数和反面数"。

3. 先验如何被数据逐渐"拉"过去#

贝叶斯更新的美妙之处在于：先验很强时，需要很多数据才能把它掰过来；先验很弱时，几笔数据就能主导后验。而无论先验多强，当数据量 n 越来越大，后验都会收敛到真实的 θ 附近——先验的影响被"稀释"了。这正是贝叶斯方法与 MLE 在大样本下殊途同归的原因。

4. 贝叶斯推断 vs 频率派：两种世界观#

  • 频率派（MLE）：参数 θ 是一个未知但固定的值，用数据去"猜"它，给出一个点估计。
  • 贝叶斯派：参数 θ 本身也是随机变量，有分布；我们不是在猜一个数，而是在维护一整个"关于 θ 的信念分布"，并随数据不断更新。

理解这个区别，是读懂很多现代机器学习方法（贝叶斯神经网络、概率编程、变分推断）的前提。

5. 在机器学习中的位置#

  • 朴素贝叶斯分类器：直接用贝叶斯公式更新类别概率；
  • 贝叶斯优化：用先验 + 观测来维护目标函数的后验，指导超参数搜索；
  • 正则化：下一课你会看到，MAP 估计里的先验，正好对应机器学习里的正则化项。

二、可运行示例#

下面的代码用 Beta-二项共轭，完整演示"先验 → 观察数据 → 后验"的更新过程，并画出三条曲线。

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import beta as beta_dist

np.random.seed(0)
# 真实正面概率 0.7，我们逐步"观察"抛硬币结果
theta_true = 0.7
data = np.random.binomial(1, theta_true, size=60)  # 60 次抛硬币

# 先验 Beta(α=2, β=2)：弱先验，略微倾向 0.5 附近
a, b = 2, 2
grid = np.linspace(0, 1, 400)
plt.figure(figsize=(10, 4))
plt.plot(grid, beta_dist.pdf(grid, a, b), label="先验 Beta(2,2)", lw=2)

# 逐步更新：每观察 20 次，就更新一次后验
for t in [20, 40, 60]:
    k = data[:t].sum()          # 前 t 次中的正面数
    a_post = a + k              # 后验 α = 先验 α + 正面数
    b_post = b + (t - k)        # 后验 β = 先验 β + 反面数
    plt.plot(grid, beta_dist.pdf(grid, a_post, b_post),
             label=f"观察 {t} 次后的后验 Beta({a_post},{b_post})", lw=2)

plt.axvline(theta_true, color="gray", ls="--", label=f"真实 θ={theta_true}")
plt.xlabel("θ")
plt.ylabel("概率密度")
plt.title("先验随观察数据逐步更新为后验")
plt.legend()
plt.show()

# 最终后验的均值与最大后验（MAP）点
a_final, b_final = a + data.sum(), b + (len(data) - data.sum())
print("最终后验 Beta({},{})".format(a_final, b_final))
print("后验均值：", a_final / (a_final + b_final), "（真实值", theta_true, "）")

预期输出（部分）：

最终后验 Beta(47,17)
后验均值： 0.734375 （真实值 0.7 ）

要点：先验曲线比较"宽"（不确定），随着观察次数增加，后验曲线越来越"窄"（确定），中心逐渐向真实值 0.7 靠拢；最终后验均值 0.734 已经相当接近真实值。

三、练习#

  1. 手算更新：先验 Beta(1,1)（即 [0,1] 均匀分布），抛 5 次硬币出现 4 次正面。写出后验分布及其均值。
  2. 改先验：把先验改成 Beta(20, 20)（很强烈地相信硬币均匀），再跑一遍代码，观察"前 20 次观察"对后验的影响是否变小了。
  3. 思考：为什么说 Beta 的 α、β 可以理解为"先验假想的正面 / 反面计数"？结合 α=2, β=2 说明它相当于"先验见过几次"。
  4. 联系机器学习：朴素贝叶斯分类器把"类别"当作 θ、"特征"当作 D。请用"后验 ∝ 似然 × 先验"解释它如何预测一个新样本的类别。
