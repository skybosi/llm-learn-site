重排的训练数据从哪来：标注、弱监督、蒸馏与难负样本#

这一节要解决什么#

前三节把重排器当成了一个给定的函数：它读入 (q,d)，输出一个分数，我们讨论它的表达能力（第 1 节）、它的质量-延迟前沿（第 2 节）、以及它和融合怎么配合（第 3 节）。但那个函数不是天上掉下来的 —— 它是用某一份数据训练出来的，而那份数据的构造方式，直接决定了它的上限和它的系统性偏差。

这一节要回答一个常被跳过的问题：

你的重排器的训练标签是怎么来的？这份标签把什么偏差一起教给了模型？

真实项目里标签只有三种来源，每种都有代价，也都有可测的偏差：

① 人工标注   贵、准、慢        → 偏差：标注指南不一致、标注者的"相关"定义漂移、长文档被草读
② 弱监督     便宜、量大、脏    → 偏差：位置偏置（点击）、把未标注当负例（假负样本）
③ 蒸馏       便宜、可规模化    → 偏差：把教师的错误与校准一起学走；软标签才保住教师的"暗知识"
        +
   负样本挖掘 决定模型把边界画在哪  → 偏差：挖得越狠，假负样本的伤害越大
        +
   数据集划分 决定离线指标可信吗    → 偏差：同一文档/同一查询跨 split → 离线虚高、线上崩

一句话结论先放在这里：

重排器的离线分数不是"模型能力"的度量，而是"模型 × 数据构造"的联合度量。 在 §4.3 的表四里，同一个模型族在同一个测试集上，只因为多了一个泄漏特征，聚合 nDCG 从 0.224 抬到 0.530 —— 而真实泛化（干净子集）从 0.391 掉到 0.078。指标变好和系统变好，在这里是两件方向相反的事。

本节要回答四个问题：

  1. 三种标签来源的边际收益在哪里饱和？ "再多标 500 条"什么时候不再值得？
  2. 弱监督的位置偏置是怎么被学进去的？逆倾向加权（IPS）在修什么，代价是什么？
  3. 蒸馏的三种监督信号各传递了多少信息？软标签为什么比硬标签值钱 —— 而且要诚实地说清"在什么条件下并不值钱"。
  4. 难负样本挖得越狠越好吗？拐点由哪个可测的量决定？哪三种泄漏最容易把离线指标变成谎言？

一、三种标签来源：成本、质量与它们各自的病#

1.1 三种来源的对照#

来源 每条成本量级 规模能力 主要偏差 适用阶段
人工标注（grade 0–3） 高（分钟级/条） 102∼104 指南不一致、标注者漂移 校准集、门禁集、不可替代的黄金集
点击 / 行为日志 极低（本来就产生） 106∼109 位置偏置、只覆盖被展示过的候选 冷启动、大规模预训练
教师模型蒸馏 低（一次前向/对） 105∼108 教师的错误、校准误差、领域盲区 有强模型可用时的主力
难负样本挖掘 低 同上 假负样本、分布偏移 与上面任一配合

这里有一个必须说清的分工：三种来源不是替代关系，而是分工关系。它们各自解决的病不同：

  • 人工标注解决校准（"什么叫相关"的定义权）—— 所以它必须留一小份，作为永远不参与训练的门禁集；
  • 弱监督解决规模（覆盖长尾查询与长尾文档）；
  • 蒸馏解决成本（把参数量大 10 倍的教师压进可上线的小模型，这正是第 2 节"质量-延迟前沿"里把强档能力压进弱档的那一步）。

常见的错误是做成了替代关系：用点击日志训完，就再也不维护人工黄金集。结果是模型的相关性定义完全由"用户点了什么"决定 —— 而用户只点被展示的东西。

1.2 标注预算的边际收益：为什么它很快饱和#

设标注量为 n，指标（例如 nDCG@10）的经验曲线几乎总是幂律饱和的形式：

nDCG(n) ≈ nDCG∞​−cn−α,α∈[0.1,0.4]

对它求导，得到第 n 条标注的边际收益：

∂n∂nDCG​ = cαn−α−1 ∝ n−(1+α)

这个式子的工程含义很硬：边际收益按 n−(1+α) 衰减，也就是比 1/n 还快。 把标注量翻倍，收益只增加 2−α 倍（α=0.2 时是 13%）。

把两边换成钱，就得到一条可执行的判据。令：

  • clab​：单条标注成本；
  • V：指标每提升 1 个点对应的业务价值（可从第 5 章第 4 节的成本-质量前沿里读出）。

则继续标注值得做的条件是：

cαn−α−1⋅1 点V​ > clab​

为什么这个判据比"感觉还需要标注"有用：它把"标注够不够"变成了三个可测的量（c、α、V）。在实践中 α 通常由前 200~500 条标注就把 α 估出来 —— 因为模型的收益主要来自覆盖新查询类型，而不是来自"把同一类查询再多标 100 条"。当新增标注已经不再引入新的查询类型时，α 就已经接近它的下限，此时正确的动作是转向蒸馏或难负样本，而不是继续买标注。

边界：幂律饱和的前提是"标注的分布不变"。如果新增的 n 覆盖了此前完全缺失的查询类型（长尾、多语言、表格类），曲线会重新变陡。所以判据要按查询类型分层算，而不是在总体上算一条曲线 —— 总体的 α 会把新类型的增益平均掉。

二、弱监督：位置偏置如何被学进去，IPS 在修什么#

2.1 位置偏置的生成模型#

点击日志最经典的生成模型是检验模型（Examination Model，也叫 Position-Based Model）：用户先"看到"某个位置，看到之后才决定点不点。

P(c=1∣q,d,pos) = 相关性rel(q,d)​​⋅被检验概率pe​(pos)​​

其中 pe​ 随位置单调下降（第 1 位最高）。这个等式是整个弱监督问题的源头：它说明"点击"不是"相关"的无偏观测，而是相关性与曝光机会的乘积。

一个常用的参数化是 pe​(pos)=(pos+1)−η，η≈1 时首位与第 20 位的曝光率相差 20 倍。

2.2 朴素训练在优化什么：一个偏差项#

朴素做法是把点击当标签，最小化

R^naive​(θ)=m1​i∑​ℓ(fθ​(qi​,di​),ci​)

对它取期望，代入检验模型：

E[R^naive​] = m1​i∑​ E[ℓ(fθ​,ci​)] = m1​i∑​ℓ(fθ​,reli​)

偏差来自两处，都必须分开看：

  1. 缩放偏差：所有正例都被乘上了 pe​(pos)，深位置的点击被系统性低估 → 模型对"排在后面但相关"的文档学不足。
  2. 混淆偏差（真正致命的那一处）：日志策略决定谁排在哪。如果日志策略用的是某个与相关性相关、但不等于相关性的量（文档长度、历史热度、上一版模型的分数），那么"位置"就成了那个量的代理。模型会把"这个特征导致被点击"学进去 —— 而它学到的是"被展示"，不是"相关"。

第二处偏差在表一里是可读的：对比 oracle 与 朴素点击训练 的 w_qual 一列，0.038 → 0.747。quality 是日志策略用的有噪代理，条件在 (sim, lex) 下不含任何额外信息；理想模型应给它接近 0 的权重，而朴素训练给了它 0.747 —— 接近 w_sim 与 w_lex 的量级。结果 nDCG@10 从 0.995 掉到 0.809。

2.3 逆倾向加权的推导（只有两行，但必须写对）#

给每条观测乘上权重 wi​=1/pe​(posi​)，再取期望：

E[pe​(posi​)ci​​ ​ q,d,pos]=pe​(pos)rel(q,d)⋅pe​(pos)​=rel(q,d)

因此加权目标

R^IPS​(θ)=m1​i∑​pe​(posi​)ci​​ℓ(fθ​(qi​,di​),ci​)

在期望意义下等于我们真正想要的理想风险 R⋆=m1​∑i​ℓ(fθ​,reli​)。这就是 IPS 的全部内容：它不改变损失函数，只改变每条样本的权重，把"曝光机会"这一项除回去。

三个必须一起说清的边界：

  1. pe​ 必须已知或估计得准。 实践中 pe​ 要么来自随机化实验（随机打散一部分流量，直接测各位置的点击率），要么来自一个倾向模型。倾向模型本身的误差会直接变成偏差，而它无法用更多数据消除 —— 这是 IPS 最容易被忽略的风险。
  2. 方差爆炸。 当 pe​(pos)→0（深位置），1/pe​ 会非常巨大，少数几条观测主导整个梯度。IPS 是无偏的，但不是低方差的。
  3. 未检验样本不是负例。 没被看到 ≠ 不相关。把未检验样本当负例是另一个独立偏差，IPS 修不了它；正确做法是把它们从损失里剔除（权重 0）或用交换实验构造反事实。

2.4 截断：一个有偏但可用的折中#

定义截断权重 wi​=min(1/pe​(posi​),C)，C 是上限（例如 5 或 10）。截断引入偏差（深位置的正例被相对低估），但换来方差下降。表一实测：

方案 w_qual nDCG@10
朴素点击训练 0.747 0.809
IPS（不截断） 0.546 0.838
IPS（截断 5） 0.583 0.833
IPS（截断 10） 0.545 0.840

读数：IPS 把 w_qual 从 0.747 压到 0.545（方向正确），nDCG 从 0.809 抬到 0.838~0.840。但即使截断到 10，w_qual 仍显著大于 oracle 的 0.038 —— 这是"无偏低方差不可兼得"的直接体现：1/pe​ 这个估计量本身的方差让有限样本的拟合仍然偏离。所以工程上不能把 IPS 当成修复位置偏置的银弹，它只是把偏差压到一个可接受量级；最后的校准仍然要靠人工黄金集。

三、蒸馏：三种监督信号，以及软标签值钱的确切条件#

3.1 三种监督信号#

信号 每条样本携带 对齐的优化目标 代价
硬标签（0/1 或按阈值二值化） ≤1 bit pointwise 分类 最低
软标签（教师的概率/分数） 教师的完整后验（含置信度） pointwise 回归 低
listwise（查询内归一化后的分布） 同一查询内所有候选的相对关系 直接对齐排序指标 需同一查询的完整候选列表

3.2 软标签值钱的确切条件（这里必须诚实）#

教科书里"软标签比硬标签好"的标准论证是暗知识：教师的输出分布含有类别间的相似性结构，硬标签（one-hot）把它抹掉了。这个论证在分类任务上成立。但在我们这里的排序场景，必须把话说准，否则会得出错误的工程结论：

在无限样本 + 正确模型类的极限下，硬标签与软标签会收敛到同一个预测器 —— 因为 logistic 回归对硬标签的极小化点也是 E[y∣x]，而软标签的目标本身就是 E[教师输出∣x]。两者的差别不在极限，在有限样本与目标错配上。

具体到两个机制，都可以测：

  1. 有限样本下的标签噪声。 硬标签是"对教师的连续判断做了一次伯努利采样"。当教师带着学生看不见的信息 z 时，条件在学生的特征上，这个 1 bit 的采样在决策边界附近方差很大；软标签给出的是 E[教师输出∣学生特征]，方差小得多。样本越少、教师独有信息越多，这个差距越大。
  2. 目标错配。 点式硬标签对齐的是"分类边界"，而指标（nDCG）关心的是查询内的相对次序。listwise 蒸馏直接对齐后者，因此在中大样本下通常最好。

表三把第 1 个机制做成了可扫描的量：学生只有 sim/lex 两个特征，教师额外看见一个隐特征 z（强度 β）。只用 16 个查询训练（样本饥饿，正是机制 1 会显形的区间）：

教师独有信息 β 硬标签 软标签 listwise 软 − 硬
0.0 1.000 1.000 1.000 0.000
0.4 1.000 1.000 1.000 0.000
0.8 0.998 0.999 0.999 0.001
1.6 0.982 0.997 0.998 0.015
3.2 0.949 0.991 0.989 0.042

逐行读：

  • β=0 时三者完全相等（1.000）—— 教师没有超出学生的信息时，蒸馏不创造任何价值。这直接否掉了"用大模型蒸馏一定有用"的说法。
  • 差距随 β 单调拉开（0.000 → 0.042）—— 这正是机制 1 的形状：教师独有信息越多，硬标签那一次伯努利采样的噪声越大。
  • β=3.2 时 listwise（0.989）略低于软标签（0.991）—— 这是样本太少（16 个查询）时 listwise 的查询内归一化放大了方差，是机制 2 的反向边界。

工程结论：蒸馏的收益 ≈f(教师超出学生的信息量, 标注样本量)。如果教师和学生的特征/领域几乎一样（β≈0），蒸馏只是在复制一个更贵的自己 —— 此时把算力花在难负样本或人工校准上收益更大。

3.3 忠实度判据：学生有没有学"歪"#

蒸馏必须配三个可测判据，否则你不知道学生学到的是教师的能力还是教师的病：

判据 定义 判读
一致率 学生与教师 Top-k 集合的 Jaccard 低 → 学生没学到排序能力（不是"学到了新东西"）
校准偏差 学生在黄金集上的分数分布 vs 教师 系统性平移/压缩 → 蒸馏目标（温度、损失）设错
分层一致率 按查询类型（单跳/多跳/聚合）分层算一致率 某类显著低 → 教师在该类也不可靠，蒸馏把盲区放大了

特别要盯住第三行：教师在自己的盲区上会给出自信但错误的分数，而软标签会把这个自信一起教给学生。这也是软标签唯一的真实风险 —— 它不是"更多的信息"，而是"教师认为的信息"，两者在教师出错时不相等。

四、难负样本：硬度谱与假负样本风险#

4.1 硬度谱#

硬度指一个负样本在打分上离正样本有多近。常见的三种定义：

  • 随机负样本：从语料随机抽 —— 最易；
  • 批内负样本：同一 batch 里其他查询的正例 —— 中等（这是第 1 章第 3 节讨论过的采样偏差来源）；
  • 挖掘负样本：用当前模型/教师找出分数最高但未被标注为正的候选 —— 最难。

为什么难负样本有用（机制，不是经验）：排序损失（pairwise logistic / softmax）的梯度大小由 ∣fθ​(q,d−)−fθ​(q,d+)∣ 决定。易负样本的分数远低于正样本，梯度接近 0，几乎不贡献学习信号；难负样本把边界处的梯度放大，让有限的计算步数花在真正决定 Top-k 排序的区域。这也解释了为什么难负样本的收益与候选池的头部直接相关 —— 而头部正是指标（nDCG@10）唯一看见的部分。

4.2 挖得越狠越危险：假负样本#

假负样本＝被当作负例、其实是相关的候选。它们的来源有三类，都要分开处理：

  1. 未标注但相关：人工只标了 Top-k，k 之外的候选默认是负例 —— 而它们可能相关；
  2. 标注者漏标：长文档、多跳证据、需要领域知识的正例被漏掉；
  3. 版本过时：第 2 章第 4 节的墓碑在这里有一个直接后果 —— 旧版本号相同的文档在索引里可能仍可被检索到，它与新版本内容相关但不完全一致，很自然地落在"高相似度但未被标注为正"的区间里，于是被挖成难负样本。

为什么它比"噪声"更坏：普通标签噪声是对称的，而假负样本是系统性地把正样本往低分压，且恰好集中在决策边界附近（因为能被挖成"难负样本"的前提就是它们的分数高）。它同时做两件坏事：把边界推高（造成漏召）、把正样本的表示压向负例（造成表示塌缩）。

逐行读（这张表里每一列都在讲一件事）：

  • 低硬度端（τ≤0）nDCG 在 0.83~0.91 徘徊：易负样本给出的分离方向不够准（w_lex/w_sim 只有 0.4 左右，即模型几乎只用了 sim），但不出灾难。这解释了为什么"只用随机负样本"是一个能跑通、却始终差一截的基线。
  • 峰值在 τ=0.4（nDCG 0.998）：负样本正好落在决策边界下方，模型被迫用上 lex（比值 1.22 ≈ 真值权重比 1.2）—— 难负样本的价值不是"更难"，而是"迫使模型用上正确的特征"。
  • τ=0.8 出现 w_lex/w_sim = 16.31 的畸变：该区间的负样本在 sim 上已经与正例不可分，模型只能把全部权重压到 lex 上 —— 这是过拟合到噪声维度的典型信号，nDCG 掉到 0.718。这个列（特征权重比）比 nDCG 更早报警：nDCG 还有 0.718 时，权重比已经畸变到 16。
  • 假负率 0.58 之后崩溃（0.246 → 0.081）：此时区间里超过一半是"其实是正例"的候选，损失函数的主要工作是把正例压下去，边界被整体推高。

4.3 拐点判据与处置#

不要用"感觉挖够了"来决定硬度。 用这三个量：

判据 定义 处置
假负率估计 在挖出的负样本里抽样 100 条人工判 > 0.15 → 必须过滤或降硬度
特征权重分布 训练后看各特征权重的相对量级 某个特征权重畸变（>5× 其他） → 硬度过头
分层 nDCG 按"黄金文档原始名次"分桶（1–10 / 11–50 / 50+） 只有低名次桶涨 → 挖到的是噪声

四种可组合的处置：

  1. 交叉批负样本：用同一 batch 内其他查询的正例当负例 —— 假负率被稀释（同一批里"恰巧相关"的概率极低）；
  2. 教师过滤：用一个独立的（最好是人工校准过的）cross-encoder 给挖出的负样本打分，把分数超过阈值的剔除 —— 这是最直接的去噪，代价是一次额外的前向；
  3. 硬度混合：例如 50% 随机 + 50% 挖掘。目的不是"兼顾"，而是让损失里始终有一个可靠的低硬度成分，防止边界被假负样本单独推走；
  4. 标签平滑 / 软标签：把"负例"从 0 改成 ϵ（例如 0.1）。注意这只降低伤害，不消除偏差 —— 它承认"负例可能是正例"，但同时削弱了所有真负例的信号。

五、数据集工程：三种泄漏，以及它们为什么让离线指标变成谎言#

5.1 文档级泄漏：兄弟块跨 split#

机制：一份长文档被切成 chunk A 与 chunk B，A 落在训练集、B 落在测试集。对重排器来说，同一篇文档的另一个 chunk 是近乎完美的答案线索（它们在语义上几乎等价）。如果任何特征带有"文档级"信息（文档热度、文档整体与训练集的相似度、一个不小心把 doc_id 编码进去的稠密特征、甚至只是近重复文档的词汇重叠），那么测试集上"与训练集近重复"的题会被轻松做对 —— 而这不是模型学会了泛化，是它见过答案。

表四给出了这个效应的完整形状。泄漏特征定义为"该候选与训练侧相关文档的最大余弦 > 0.9"（一个很朴素、很多系统里都会存在的近重复判定）：

特征集 污染集（leaked） 干净集（clean） 聚合（50/50） 虚高 wleak​
cos + 泄漏特征 0.983 0.078 0.530 0.906 3.433
只用 cos（去泄漏） 0.056 0.391 0.224 −0.335 —

逐行读：

  • 含泄漏特征时，聚合指标（0.530）看起来比去泄漏（0.224）好一倍以上。 如果只看聚合数字，结论会是"这个特征非常有价值"。
  • 但把测试集按污染/干净分层，真相立刻反转：污染集 0.983（靠记忆），干净集只有 0.078 —— 比随机好不了多少。去泄漏后干净集反而升到 0.391。
  • 机制在 wleak​=3.433 这个权重上：模型把泄漏特征当成了最强信号，于是任何"训练集里没见过"的题都被它排到后面。泄漏不只是让指标虚高，它主动破坏了模型对分布外查询的排序能力。
  • 污染集的 0.983 有一个特别值得注意的性质：它是在同主题、换方面的查询上取得的（问的是同一篇文档的另一个方面，cos 对不上但证据是同一份）。这正是真实业务里最常见的泄漏形态 —— 不是重复的题，而是同一份资料的另一个问题。

5.2 版本泄漏：墓碑的直接后果#

第 2 章第 4 节的墓碑机制在训练数据里有两处后果，必须分开处理：

  1. 旧版本成为假负样本：同一 doc_id 的新旧版本在检索时都可能被召回，而标注只标了新版本 → 旧版本被挖成难负样本（§4.2 的第 3 类来源）。
  2. 旧版本成为"捷径"：如果训练集里留着旧版本的正例，模型会学到"与旧版本措辞相同 = 相关"，而线上用户问的是更新后的问题。

判据（可自动跑）：

① 同一 doc_id 在索引里存在 >1 个活跃版本的比例
   目标：0（除保留期内的显式多版本需求）
② 训练集里的版本时间戳集合 vs 线上活跃版本集合的差集大小
   目标：差集为空；否则必须重建训练集
③ 挖出的难负样本里，与某个正例同 doc_id 的比例
   目标：0（这类样本一律剔除，不要靠"降硬度"回避）

5.3 查询级泄漏与时间泄漏#

  • 查询级泄漏：同一查询的改写、同一意图的不同表述、或者同一会话里的连续问题，被分到 train 与 test 两侧。这会让测试集变成"训练集的重述"，收益被高估。判据：对查询做归一化（小写 + 去标点）后的 n-gram/MinHash 近重复检测，跨 split 的重复率目标为 0；对语义改写，用查询向量做近重复检测，阈值需要人工看一批样本确定。
  • 时间泄漏：用未来的文档训练、用过去的查询测试（或反过来）。对时效型语料（新闻、政策、价格），这等于把答案提前给了模型。判据：split 的时间边界必须早于测试查询的时间戳（按时间切分，而不是随机切分）。

5.4 泄漏检测的执行顺序（为什么是这个顺序）#

① 内容寻址 chunk_id 去重（最便宜、最彻底：同一内容天然同 id）
② 按 doc_id 做文档级隔离（同一文档的所有 chunk 只进一个 split）
③ 按时间切分（时效型语料）
④ 查询近重复检测（字符级 → 语义级）
⑤ 分层报告：leaked / clean 两个子集的指标必须分别给

顺序不能颠倒：前四步都是"构造上消除"，第五步是"测量上暴露"。只做第五步不做前四步，得到的是"我知道自己被污染了多少"，而不是"我没被污染"。 而第 ⑤ 步是唯一能防止 §5.1 那种"聚合数字很好看"的机制 —— 任何单一的聚合离线指标，都必须配一份分层报告才可信。

代码：重排训练数据的四个可测问题#

下面的脚本把本节四个机制全部做成可运行的对照实验。⚠️ 全部为合成数据：它不模拟任何真实语料，只模拟"标签生成过程"本身 —— 因为本节要讲的正是这个过程。

"""
重排器训练数据的四个可测问题（全部为合成数据 ⚠️）：只依赖 numpy。
  表一 位置偏置：朴素点击训练 vs 逆倾向加权（IPS）
  表二 难负样本硬度：收益饱和与假负样本率的加速
  表三 蒸馏：硬标签 / 软标签 / listwise 三种监督信号（分级 nDCG）
  表四 文档级近重复泄漏：聚合指标被"见过的题"抬高
"""
import numpy as np


def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))


def ndcg_at(order, gain, k=10):
    """分级 nDCG@k：gain 为逐候选增益（非负实数）。"""
    order = np.asarray(order)[:k]
    g = np.asarray(gain)[order]
    dcg = float(np.sum(g / np.log2(np.arange(2, len(g) + 2))))
    ideal = np.sort(np.asarray(gain))[::-1][:k]
    idcg = float(np.sum(ideal / np.log2(np.arange(2, len(ideal) + 2))))
    return dcg / idcg if idcg > 0 else 0.0


def make_data(n_q=600, n_d=40, seed=0):
    """每查询 n_d 个候选；三个可观测特征 sim / lex / quality，真值由 sim 与 lex 决定。"""
    rng = np.random.default_rng(seed)
    sim = rng.normal(0, 1, (n_q, n_d))
    lex = 0.2 * sim + rng.normal(0, 1, (n_q, n_d))      # 与 sim 弱相关 -> 单靠 sim 排不好
    truth = sim + 1.2 * lex
    thr = np.quantile(truth, 0.75, axis=1, keepdims=True)
    rel = (truth > thr).astype(float)
    # 分级增益：只在相关档内分三级（软标签能恢复这部分序，硬标签不能）
    gain = np.clip(truth - thr, 0, None)
    gain = gain / (gain.max(axis=1, keepdims=True) + 1e-9) * 3.0
    # quality 是日志策略用的**有噪代理**，条件在 (sim,lex) 下不含额外信息
    quality = truth + rng.normal(0, 1.5, (n_q, n_d))
    return dict(sim=sim, lex=lex, quality=quality, truth=truth, rel=rel,
                gain=gain, n_q=n_q, n_d=n_d)


def feats(d, idx=None, use_quality=True):
    cols = [d["sim"], d["lex"]]
    if use_quality:
        cols.append(d["quality"])
    cols.append(np.ones_like(d["sim"]))
    X = np.stack(cols, axis=-1)
    return X if idx is None else X[idx]


def fit_soft_logreg(X, y, w=None, iters=1500, lr=0.6, l2=1e-3):
    if w is None:
        w = np.ones(len(y))
    w = w / (w.mean() + 1e-12)
    th = np.zeros(X.shape[1])
    for _ in range(iters):
        p = sigmoid(X @ th)
        th -= lr * ((X * ((p - y) * w)[:, None]).mean(axis=0) + l2 * th)
    return th


def eval_theta(d, th, idx, use_quality=True, graded=False):
    out = []
    for i in idx:
        s = feats(d, i, use_quality) @ th
        g = d["gain"][i] if graded else d["rel"][i]
        out.append(ndcg_at(np.argsort(-s), g))
    return float(np.mean(out))


# ====================================================== 表一：位置偏置 + IPS
def clicks_from_policy(d, eta=1.0, seed=1):
    rng = np.random.default_rng(seed)
    n_q, n_d = d["n_q"], d["n_d"]
    order = np.argsort(-d["quality"], axis=1)
    pos = np.empty_like(order)
    pos[np.arange(n_q)[:, None], order] = np.arange(n_d)[None, :]
    prop = 1.0 / (1.0 + pos) ** eta
    examined = rng.random((n_q, n_d)) < prop
    return ((d["rel"] > 0) & examined).astype(float), pos, prop


def table_position_bias(d):
    click, pos, prop = clicks_from_policy(d)
    tr, te = np.arange(0, d["n_q"], 2), np.arange(1, d["n_q"], 2)
    Xtr, ytr = feats(d, tr).reshape(-1, 4), click[tr].reshape(-1)
    w_prop = prop[tr].reshape(-1)
    rows = [("真实排序（按 truth）", np.array([1.0, 1.2, 0.0, 0.0]), True)]
    rows.append(("oracle（真值标签）",
                 fit_soft_logreg(Xtr, d["rel"][tr].reshape(-1)), True))
    rows.append(("朴素点击训练", fit_soft_logreg(Xtr, ytr), True))
    rows.append(("IPS（不截断）",
                 fit_soft_logreg(Xtr, ytr, w=1.0 / np.maximum(w_prop, 1e-3)), True))
    for cap in (5.0, 10.0):
        rows.append((f"IPS（截断 {cap:.0f}）",
                     fit_soft_logreg(Xtr, ytr,
                                     w=np.minimum(1.0 / np.maximum(w_prop, 1e-3), cap)),
                     True))
    print("=" * 88)
    print("表一：位置偏置下训练目标的偏离（特征 = sim / lex / quality，测试半集，nDCG@10）")
    print("=" * 88)
    print(f"{'训练方案':<22}{'w_sim':>8}{'w_lex':>8}{'w_qual':>9}{'w_bias':>9}{'nDCG@10':>10}")
    for name, th, _ in rows:
        print(f"{name:<22}{th[0]:>8.3f}{th[1]:>8.3f}{th[2]:>9.3f}{th[3]:>9.3f}"
              f"{eval_theta(d, th, te):>10.3f}")


# ====================================================== 表二：负样本硬度
def mine(d, tau, delta=0.6, pos_rate=0.35, seed=2):
    rng = np.random.default_rng(seed)
    labeled_pos = (d["rel"] > 0) & (rng.random((d["n_q"], d["n_d"])) < pos_rate)
    band = (d["sim"] >= tau) & (d["sim"] < tau + delta)
    return labeled_pos, band & ~labeled_pos


def table_hardness(d):
    tr, te = np.arange(0, d["n_q"], 2), np.arange(1, d["n_q"], 2)
    print()
    print("=" * 88)
    print("表二：负样本硬度扫描（带宽 Δ=0.6，正例标注率 0.35，无 quality 特征）")
    print("=" * 88)
    print(f"{'硬度下界 tau':>13}{'负样本数':>10}{'其中真相关':>12}{'假负率':>9}"
          f"{'w_lex/w_sim':>13}{'nDCG@10':>10}")
    for tau in (-1.5, -1.0, -0.5, 0.0, 0.4, 0.8, 1.2, 1.6):
        lp, neg = mine(d, tau)
        X = np.concatenate([feats(d, use_quality=False)[lp],
                            feats(d, use_quality=False)[neg]], axis=0)
        y = np.concatenate([np.ones(lp.sum()), np.zeros(neg.sum())])
        th = fit_soft_logreg(X, y)
        r = d["rel"][neg]
        print(f"{tau:>13.1f}{int(neg.sum()):>10d}{int(r.sum()):>12d}{r.mean():>9.3f}"
              f"{abs(th[1] / (th[0] + 1e-9)):>13.2f}"
              f"{eval_theta(d, th, te, use_quality=False):>10.3f}")


# ====================================================== 表三：蒸馏
def listwise_fit(d, t, idx, iters=400, lr=0.5, l2=1e-3):
    Xs = [feats(d, i, use_quality=False) for i in idx]
    tgt = []
    for i in idx:
        e = np.exp(t[i] - t[i].max())
        tgt.append(e / e.sum())
    th = np.zeros(3)
    for _ in range(iters):
        g = np.zeros(3)
        for X, tg in zip(Xs, tgt):
            s = X @ th
            e = np.exp(s - s.max())
            g += X.T @ (e / e.sum() - tg)
        th -= lr * (g / len(Xs) + l2 * th)
    return th


def table_distill(d, n_train_q=16, seed=1000):
    """
    教师比学生多看见一个隐特征 z（学生只有 sim/lex）：
    硬标签把这份"看不见的信息"压成 1 bit，软标签保留它对置信度的连续影响。
    """
    tr = np.arange(0, n_train_q * 2, 2)              # 只用 16 个查询训练
    te = np.arange(1, d["n_q"], 2)
    rng = np.random.default_rng(seed)
    z = rng.normal(0, 1, d["truth"].shape)           # 教师独有特征
    print()
    print("=" * 88)
    print(f"表三：蒸馏的监督信号价值（学生只有 sim/lex；训练仅 {len(tr)} 个查询；分级 nDCG@10）")
    print("=" * 88)
    print(f"{'教师独有信息 beta':>17}{'硬标签':>10}{'软标签':>10}{'listwise':>11}"
          f"{'软-硬':>9}")
    for beta in (0.0, 0.4, 0.8, 1.6, 3.2):
        t = d["truth"] + beta * z
        # 硬标签：阈值化 -> 把 z 的作用压成 1 bit
        y_hard = (t > np.percentile(t, 75)).astype(float)
        X = feats(d, tr, use_quality=False).reshape(-1, 3)
        hard = eval_theta(d, fit_soft_logreg(X, y_hard[tr].reshape(-1)),
                          te, use_quality=False, graded=True)
        soft = eval_theta(d, fit_soft_logreg(X, sigmoid(t)[tr].reshape(-1)),
                          te, use_quality=False, graded=True)
        lst = eval_theta(d, listwise_fit(d, t, tr), te,
                         use_quality=False, graded=True)
        print(f"{beta:>17.1f}{hard:>10.3f}{soft:>10.3f}{lst:>11.3f}"
              f"{soft - hard:>9.3f}")


# ====================================================== 表四：泄漏
def table_leakage(seed=7, n_topic=16, n_doc=1200, n_qtr=300, n_qte=120, dim=64,
                  n_train_topic=12, n_neg=12):
    """
    泄漏机制：同一篇文档的两个 chunk 落在 train / test 两侧。
    · 训练题：问的是某个方面，黄金块 = 该文档的 chunk A。
    · 污染的测试题(leaked)：问的是**同一文档的另一个方面**，黄金块 = chunk B（A 的兄弟块）。
      两句问句的向量不同（cos 对不上），但证据是同一篇文档 —— 这就是泄漏能"喂"给模型的东西。
    · 干净的测试题(clean)：主题在训练集里从未出现过，没有兄弟块在训练侧。
    泄漏特征 leakf[d] = 候选与训练侧相关文档的最大余弦（很多系统里的"文档级/热度特征"）。
    """
    rng = np.random.default_rng(seed)
    topics = rng.normal(0, 1, (n_topic, dim))
    dtopic = rng.integers(0, n_topic, n_doc)
    emb = topics[dtopic] + 0.5 * rng.normal(0, 1, (n_doc, dim))
    emb /= np.linalg.norm(emb, axis=1, keepdims=True)

    def pick(topic):
        return int(rng.choice(np.where(dtopic == topic)[0]))

    def qvec(v, s=0.8):
        q = v + s * rng.normal(0, 1, dim)
        return q / np.linalg.norm(q)

    # ---- 训练侧
    gold_tr = np.array([pick(int(rng.integers(0, n_train_topic))) for _ in range(n_qtr)])
    train_gold = np.unique(gold_tr)
    sib = emb[train_gold] + 0.05 * rng.normal(0, 1, (len(train_gold), dim))
    sib /= np.linalg.norm(sib, axis=1, keepdims=True)
    all_emb = np.vstack([emb, sib])
    n_all = len(all_emb)
    sib_of = {int(g): len(emb) + k for k, g in enumerate(train_gold)}
    # 近重复判定（阈值 0.9）：只有"训练侧出现过同一篇文档"才亮
    leakf = ((all_emb @ emb[train_gold].T).max(axis=1) > 0.9).astype(float)
    gold_set = set(int(g) for g in train_gold)
    print(f"（leakf 亮起比例：兄弟块 {leakf[[sib_of[int(g)] for g in train_gold]].mean():.3f}"
          f" / 训练黄金块 {leakf[train_gold].mean():.3f}"
          f" / 其他文档 {leakf[[i for i in range(n_all) if i not in sib_of.values() and i not in gold_set]].mean():.3f}）")

    # ---- 训练样本：正例 = chunk A，负例 = 随机块
    Xs, ys = [], []
    for g in gold_tr:
        g = int(g)
        negs = [int(x) for x in rng.choice(n_all, n_neg * 8)
                if int(x) not in gold_set and int(x) != sib_of.get(g, -1)][:n_neg]
        pool = [g] + negs
        q = qvec(emb[g])
        F = np.stack([all_emb[pool] @ q, leakf[pool], np.ones(len(pool))], axis=1)
        Xs.append(F)
        ys.append(np.array([1.0] + [0.0] * len(negs)))
    X, y = np.concatenate(Xs), np.concatenate(ys)

    # ---- 测试题
    leaked, clean = [], []
    for k in range(n_qte):
        t = int(rng.integers(0, n_train_topic))        # leaked：同主题、换方面
        same = [int(x) for x in train_gold if dtopic[x] == t]
        g = int(same[rng.integers(0, len(same))])
        q = qvec(topics[t], s=1.0)
        # 干扰项全部来自同一主题（cos 都很高，靠 cos 分不出黄金块）
        cand = [int(x) for x in np.where(dtopic == t)[0] if int(x) not in gold_set]
        pool = [sib_of[g]] + [c for c in rng.permutation(cand)][:39]
        leaked.append((q, pool, sib_of[g]))
        t2 = int(rng.integers(n_train_topic, n_topic))  # clean：未出现过的主题
        g2 = pick(t2)
        q2 = qvec(emb[g2])
        pool2 = [g2] + [int(x) for x in rng.choice(n_all, 200)
                        if int(x) not in gold_set][:39]
        clean.append((q2, pool2, g2))

    print("=" * 88)
    print("表四：兄弟块跨 split 的泄漏（污染测试集 vs 干净测试集，40 候选，nDCG@10）")
    print("=" * 88)
    print(f"{'特征集':<24}{'污染集(leaked)':>16}{'干净集(clean)':>15}"
          f"{'聚合(50/50)':>13}{'虚高':>9}{'w_leak':>9}")
    for tag, use_leak in (("cos + 泄漏特征", True), ("只用 cos（去泄漏）", False)):
        w = fit_soft_logreg(X if use_leak else X[:, [0, 2]], y, iters=1200)
        acc = {}
        for name, items in (("leaked", leaked), ("clean", clean)):
            vs = []
            for q, pool, gold in items:
                F = np.stack([all_emb[pool] @ q, leakf[pool]] if use_leak else
                             [all_emb[pool] @ q], axis=-1)
                s = F @ w[:-1] + w[-1]
                rel = (np.array(pool)[np.argsort(-s)] == gold).astype(float)
                vs.append(ndcg_at(np.arange(len(pool)), rel))
            acc[name] = float(np.mean(vs))
        agg = 0.5 * (acc["leaked"] + acc["clean"])
        print(f"{tag:<24}{acc['leaked']:>16.3f}{acc['clean']:>15.3f}{agg:>13.3f}"
              f"{acc['leaked'] - acc['clean']:>9.3f}"
              f"{(w[1] if use_leak else float('nan')):>9.3f}")

小结#

  • 离线分数度量的是"模型 × 数据构造"的联合效果，不是模型能力。 训练数据的构造方式决定了模型的上限与它的系统性偏差；偏差不会在评估时自己消失，只会以"离线好、线上差"的形式回收。
  • 三种标签来源是分工不是替代：人工标注解决"什么叫相关"（必须留一份不参与训练的黄金集），弱监督解决规模，蒸馏解决成本。把它们做成替代关系，是相关性定义失控的起点。
  • 标注预算的边际收益按 n−(1+α) 衰减（α≈0.1∼0.4），比 1/n 还快。判据是 cαn−α−1V>clab​，且必须按查询类型分层算 —— 新增类型会让曲线重新变陡。
  • 位置偏置的生成模型是 P(c=1)=rel⋅pe​(pos)；朴素训练学到的是两处偏差：缩放偏差与混淆偏差。IPS 用 1/pe​ 加权，两行推导即可证明无偏，但代价是方差爆炸与依赖 pe​ 的正确性。本节实测：w_qual 0.747（朴素）→ 0.545（IPS 截断 10），nDCG 0.809 → 0.840，而 oracle 是 0.038 / 0.995 —— IPS 把偏差压到可接受量级，不能替代人工校准。
  • 软标签值钱的确切条件是"教师带有学生看不见的信息 + 样本有限"。无限样本 + 正确模型类下，硬标签与软标签收敛到同一预测器（都估计 E[y∣x]）。本节实测：β=0 时三者完全相同（1.000），β=3.2 且仅 16 个训练查询时，硬标签 0.949、软标签 0.991、listwise 0.989 —— "用大模型蒸馏一定有用"是错的，要先用 β 测出教师到底多知道什么。 软标签的唯一真实风险是把教师的自信错误一起教走，必须用分层一致率盯住。
  • 难负样本的价值来自"迫使模型用上正确的特征"，不是来自"更难"。本节实测的 U 型：峰值在假负率 0.299（nDCG 0.998，特征权重比 1.22 ≈ 真值 1.2），崩溃在 0.58 之后（0.246 → 0.081）。特征权重比 nDCG 更早报警（τ=0.8 时权重比已畸变到 16.31，nDCG 还有 0.718）。处置手段四种：交叉批负样本、教师过滤、硬度混合、标签平滑，其中只有前两种真正去偏。
  • 泄漏的三种形态与顺序：文档级（兄弟块跨 split，最隐蔽也最普遍）、版本（墓碑的直接后果）、查询级与时间级。检测必须"先构造上消除（内容寻址去重 → 按文档隔离 → 按时间切 → 查询近重复），再测量上暴露（分层报告 leaked/clean）"。任何单一聚合离线指标都必须配一份分层报告才可信 —— 因为本节实测里，聚合 0.530 的配置在干净集上只有 0.078，而去泄漏的配置聚合只有 0.224、干净集却有 0.391。
  • 一句话：重排器的质量上限由"标签里有多少信息"决定，而它的系统性失效由"标签里混进了什么"决定。前者靠标注与蒸馏的边际收益算，后者靠三个可测量（假负率、特征权重分布、分层指标）盯。
