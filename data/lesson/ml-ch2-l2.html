fit-transform-predict#

fit、transform、predict 是 scikit-learn 里最核心的三个方法。几乎所有对象都遵循这套约定，理解它们是读懂任何 sklearn 代码的关键。本课把这三者以及背后的两类对象——变换器（Transformer）和估计器（Estimator）——彻底讲清楚。

一、概念讲解#

1. 两类对象#

scikit-learn 的对象大致分两类，区别在于 fit 之后"产出"什么：

  • 变换器（Transformer）：fit 学习的是数据本身的统计量（如均值、标准差、每个类别的取值），随后 transform 把数据变换成新形式。典型代表：StandardScaler（标准化）、OneHotEncoder（独热编码）。它输出的是"变换后的特征"，形状通常还是样本数 × 特征数。
  • 估计器（Estimator）：fit 学习的是从特征到标签的映射参数，随后 predict 输出预测结果（类别或数值）。典型代表：KNeighborsClassifier、LinearRegression。它输出的是"预测标签"。

2. 三个方法的含义#

  • fit(X[, y])：学习。根据训练数据计算并保存内部参数/统计量。有监督模型需要同时传特征 X 和标签 y；无监督或变换器通常只传 X。
  • transform(X)：变换。用 fit 学到的统计量，把新数据转换成新的特征表示。只有变换器有这个方法。
  • predict(X)：预测。用 fit 学到的参数，对新数据输出标签。只有（有监督的）估计器有这个方法。
  • fit_transform(X)：fit 之后立刻 transform 的简写，等价于两步连做。注意：它应当只用于训练集。

3. 最重要的坑：训练集和测试集要分开处理#

对变换器来说，正确的顺序是：

  1. 在训练集上 fit（或 fit_transform），学习统计量；
  2. 在测试集上只调用 transform，复用训练集学到的统计量。

如果对测试集也调用 fit_transform，等于让模型"偷看"了测试集的统计信息（比如测试集的均值），会造成数据泄漏，让评估结果虚高、不可信。

二、可运行代码示例#

下面用一个分类任务，把变换器和估计器串起来演示。

from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

# 生成一个二分类数据集
X, y = make_classification(n_samples=500, n_features=8, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# ---- 变换器：StandardScaler ----
scaler = StandardScaler()
scaler.fit(X_train)                       # 1. 只在训练集上学习均值与标准差
print("学到的均值（前 3 个特征）：", scaler.mean_[:3].round(3))
print("学到的标准差（前 3 个特征）：", scaler.scale_[:3].round(3))

X_train_scaled = scaler.transform(X_train)   # 2. 训练集：用学到的统计量变换
X_test_scaled = scaler.transform(X_test)     # 3. 测试集：只 transform，不 fit
print("\n标准化后训练集均值（应接近 0）：", X_train_scaled[:, 0].mean().round(6))

# fit_transform 等价于 fit 后紧跟 transform（仅对训练集）
X_train_scaled_2 = scaler.fit_transform(X_train)
print("fit_transform 与分开调用是否一致：",
      (X_train_scaled == X_train_scaled_2).all())

# ---- 估计器：LogisticRegression ----
clf = LogisticRegression()
clf.fit(X_train_scaled, y_train)             # fit 学习分类边界
y_pred = clf.predict(X_test_scaled)          # predict 输出预测类别
y_prob = clf.predict_proba(X_test_scaled)    # predict_proba 输出概率

print("\n测试集前 5 个预测类别：", y_pred[:5])
print("前 3 个样本属于两个类别的概率：\n", y_prob[:3].round(3))
print("训练集准确率：", round(clf.score(X_train_scaled, y_train), 3))
print("测试集准确率：", round(clf.score(X_test_scaled, y_test), 3))

关键观察：

  • scaler.mean_、scaler.scale_ 里保存的就是 fit 学到的统计量；带下划线后缀的属性都是"从数据学出来的"，是 sklearn 的命名约定。
  • clf.score() 是 predict 后自动算准确率的快捷方法，内部等价于"预测 + 对比标签"。
  • 若把 scaler.fit_transform(X_test) 用在测试集上，标准化会基于测试集自己的均值做，这就是典型的数据泄漏错误。

三、练习#

  1. 填空：StandardScaler 属于 ____（变换器/估计器），它的 fit 学到的是 ____ 和 ____；LogisticRegression 属于 ____，它的 fit 学到的是分类边界的 ____。
  2. 判断对错：对测试集调用 fit_transform 是安全且推荐的做法。（请说明理由）
  3. 动手实验：把代码里 X_test_scaled = scaler.transform(X_test) 改成 X_test_scaled = scaler.fit_transform(X_test)，重新运行并对比测试集准确率。观察这种"泄漏"会让结果变好还是变差？为什么它仍然是错误做法？
  4. 思考题：fit_transform(X_train) 和先 fit(X_train) 再 transform(X_train) 结果是否总是一样？如果某个变换器没有 fit 学习量（例如只需要 transform 的纯函数变换），会发生什么？
