其他降维方法#

PCA 好用，但它是个线性方法：只能沿着直线方向去找方差最大的投影。真实数据常常躺在一条弯弯曲曲的"流形"上，或者干脆是稀疏的文本矩阵，这时 PCA 就力不从心了。这一课介绍另外几类常用降维工具——非线性流形学习的代表 t-SNE 与 UMAP，以及面向稀疏数据的 TruncatedSVD，帮你根据数据特点选对方法。

一、概念讲解#

1. PCA 的短板：线性假设#

PCA 的本质是"旋转坐标轴再截断"，它假设数据的主要变化沿直线方向发生。可很多数据的结构不是直的：比如一堆人脸照片按"转头角度"排列，在像素空间里其实是一条弯曲的弧线。PCA 会把这条弧线硬压到平面上，破坏样本之间的局部邻接关系，视觉上显得乱作一团。非线性降维方法就是为了处理这类"弯结构"而生。

2. t-SNE：把"邻居关系"保留下来#

t-SNE（t-distributed Stochastic Neighbor Embedding）不关心全局的直线方差，而是试图让"在高维空间里相近的点，降维后依然相近"。它把高维和低维的点都看作概率分布，用 KL 散度衡量两者的差异并迭代优化。

t-SNE 的几个特点要记住：

  • 用于可视化，而不是通用的降维预处理。它输出的坐标没有线性意义，也不适合直接喂给下游模型做训练；
  • 有两个关键超参数：perplexity（大致理解为"每个点关注多少邻居"）和学习率，结果对它们比较敏感；
  • 带有随机性，同一次运行可能得到不同布局，通常需要设 random_state 复现；
  • 计算量较大，数据量很大时会比较慢。

3. UMAP：更快、更保全局#

UMAP（Uniform Manifold Approximation and Projection）和 t-SNE 目标类似，也是非线性流形学习，但它通常跑得更快，而且在保留全局结构、处理大规模数据上表现更好，因此近年来在单细胞、推荐系统等领域很流行。UMAP 不在 scikit-learn 里，需要单独安装 umap-learn 库，接口风格与 sklearn 一致。

4. TruncatedSVD：为稀疏数据准备的"PCA"#

当数据是稀疏矩阵（大量元素为 0，常见于文本的 TF-IDF 表示）时，标准 PCA 需要先中心化，而中心化会把稀疏矩阵"填满"，内存瞬间爆炸。TruncatedSVD（截断奇异值分解）不需要中心化，可以直接在稀疏矩阵上做分解，常被当作"文本版 PCA"。它同样提供 explained_variance_ratio_ 等属性。

二、可运行代码示例#

示例 1：PCA 与 t-SNE 在同一数据上的对比#

用手写数字对比线性与非线性方法的可视化效果：

from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

digits = load_digits()
X, y = digits.data, digits.target

pca2 = PCA(n_components=2, random_state=42).fit_transform(X)
tsne2 = TSNE(n_components=2, perplexity=30, random_state=42, init='pca').fit_transform(X)

fig, axes = plt.subplots(1, 2, figsize=(13, 5.5))
axes[0].scatter(pca2[:, 0], pca2[:, 1], c=y, cmap='tab10', alpha=0.6, s=15)
axes[0].set_title('PCA（线性）')
axes[1].scatter(tsne2[:, 0], tsne2[:, 1], c=y, cmap='tab10', alpha=0.6, s=15)
axes[1].set_title('t-SNE（非线性）')
for ax in axes:
    ax.set_xticks([]); ax.set_yticks([])
plt.show()

要点：t-SNE 通常能把不同数字"抱"得更紧、簇与簇之间分得更开。init='pca' 用 PCA 结果作为初始点，能让 t-SNE 更稳定。数据量较大时这段代码可能要运行几秒到几十秒。

示例 2：TruncatedSVD 处理稀疏文本矩阵#

用一个极小的文档集演示稀疏矩阵上的降维：

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import TruncatedSVD

docs = [
    "机器学习 降维 主成分 分析",
    "主成分 分析 方差 投影",
    "聚类 客户 分群 无监督",
    "图像 压缩 聚类 颜色",
]
vec = TfidfVectorizer()
X_tfidf = vec.fit_transform(docs)      # 稀疏矩阵，多数元素为 0
print("TF-IDF 矩阵形状:", X_tfidf.shape)

svd = TruncatedSVD(n_components=2, random_state=42)
X_svd = svd.fit_transform(X_tfidf)
print("降维后的坐标:\n", X_svd.round(3))
print("解释方差比例:", svd.explained_variance_ratio_.round(3))

要点：TfidfVectorizer 输出的是 scipy 稀疏矩阵，TruncatedSVD 可以直接在其上 fit_transform，不必先把稀疏矩阵稠密化。X_svd 每行就是一篇文档在"潜语义"空间里的二维坐标。
