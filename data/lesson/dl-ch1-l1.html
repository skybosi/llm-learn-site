卷积操作#

卷积（Convolution）是卷积神经网络名字的由来，也是它区别于普通全连接网络的核心。学完 PyTorch 后你已经会用张量和自动求导，这一课要回答的问题很直接：一张图片是怎么被一个"滑动的小窗口"扫描、变成特征图的？ 我们会先讲清卷积为什么适合图像，再拆解卷积核、步长、填充这几个关键参数，最后用 torch.nn.Conv2d 亲手算一遍并验证输出尺寸。

一、概念讲解#

1. 为什么图像不能用全连接层硬接#

一张 224×224 的彩色图片有 224 × 224 × 3 ≈ 15 万 个像素。如果第一个隐藏层有 1000 个神经元，光这一层的权重就是 15 万 × 1000 ≈ 1.5 亿 个参数，既吃内存又容易过拟合。更关键的是，把图片拉成一维向量，等于抹掉了像素之间的空间关系——相邻像素才构成边缘、纹理，而全连接层并不天然知道"谁和谁挨着"。

卷积的思路是局部连接 + 权重共享：每个神经元只盯着输入的一小片区域（感受野），并且同一个"模式检测器"在整张图上滑来滑去、复用同一组权重。这样参数数量骤减，也天然契合"边缘、角点等局部特征在图中任何位置都可能出现"的直觉。

2. 卷积运算的本质：滑动窗口 + 点积求和#

一个卷积核（kernel / filter）是一小张权重矩阵，比如 3×3。它从输入的左上角开始，与覆盖到的 3×3 区域逐元素相乘再求和，得到输出特征图上的一个值；然后窗口向右滑动一个像素，再算下一个值，直到扫完整张图。

输出值 = Σ (输入窗口 ⊙ 卷积核) + 偏置

其中 ⊙ 表示逐元素相乘。一个卷积核负责提取一种模式（比如"竖直边缘"），卷积后的整张输出就叫做特征图（feature map）。卷积层通常有多个卷积核，于是输出有多张特征图、多通道。

3. 关键参数：kernel_size、stride、padding#

torch.nn.Conv2d 的构造参数里，最常调的是这四个：

  • kernel_size（卷积核尺寸）：如 3 表示 3×3。核越大，一次看到的区域越大，参数也越多。
  • stride（步长）：窗口每次移动几个像素。步长 2 会让输出尺寸减半，常用来替代池化做降采样。
  • padding（填充）：在输入四周补一圈 0，让输出尺寸可控。padding=1 配 3×3 卷积能保持宽高不变，是经典组合。
  • dilation（空洞率）：让卷积核的元素之间留出空隙，从而在不增加参数的前提下扩大感受野，语义分割里常用。

输出尺寸由下面的公式决定（高宽同理）：

输出高 = floor((输入高 − 卷积核高 + 2×padding) / stride) + 1

比如输入 32×32、3×3 卷积、padding=1、stride=1，输出仍是 32×32；把 stride 改成 2，输出就变成 16×16。

4. 多通道卷积：核的数量决定输出通道#

彩色图片有 RGB 三个通道。此时卷积核的通道数必须等于输入通道数：一个 3×3 卷积核实际是 C_in × 3 × 3 的三维权重，它对所有输入通道加权求和，得到一张单通道特征图。要得到多张特征图，就准备多个这样的卷积核：

输出通道数 = 卷积核个数

于是 nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3) 意味着有 64 个 3×3×3 的卷积核，输出 64 张特征图。

5. 卷积的三大特性#

  1. 稀疏连接：每个输出只依赖输入的一小块区域，而非全部像素；
  2. 参数共享：同一卷积核在整张图上复用，一个边缘检测器各处通用；
  3. 平移等变：图像里的物体平移一段，特征图里的响应也相应平移，卷积天然能"认出"移动后的同一模式。

这三点加在一起，让卷积既省参数又贴合图像的本质。

二、可运行代码示例#

下面用 nn.Conv2d 对一个 5×5 的单通道输入做一次卷积，并手动核对手算结果，把"滑动窗口 + 点积求和"看个清楚。

import torch
import torch.nn as nn

# 构造 1 张 5x5 的"图片"（batch=1, 通道=1, 高=5, 宽=5）
x = torch.arange(1, 26, dtype=torch.float32).reshape(1, 1, 5, 5)
print("输入形状:", x.shape)          # torch.Size([1, 1, 5, 5])

# 一个 3x3 卷积核，输出 1 个通道，不填充、步长为 1
conv = nn.Conv2d(in_channels=1, out_channels=1, kernel_size=3,
                 stride=1, padding=0, bias=False)

# 手动设定卷积核为"竖直边缘检测器"：左正右负
with torch.no_grad():
    conv.weight.copy_(torch.tensor([[[[ 1., 0., -1.],
                                      [ 1., 0., -1.],
                                      [ 1., 0., -1.]]]]))

y = conv(x)
print("输出形状:", y.shape)          # torch.Size([1, 1, 3, 3])
print("输出特征图:\n", y[0, 0])

# 手算输出左上角元素：输入左上 3x3 区域与核逐元素相乘求和
window = x[0, 0, :3, :3]
manual = (window * conv.weight[0, 0]).sum()
print("手算左上角:", manual.item(), " 与网络一致:", torch.allclose(y[0, 0, 0, 0], manual))

运行后输出形状是 3×3（由公式 (5−3+0)/1+1=3 得出），左上角元素与你手算的窗口点积完全一致。这个"竖直边缘检测器"在左右亮度突变处会输出较大绝对值，正是图像边缘提取的雏形。

再看步长与填充对输出尺寸的影响：

x = torch.randn(1, 1, 32, 32)               # 32x32 输入

# 3x3 卷积 + 填充 1：保持尺寸不变（same 卷积）
same = nn.Conv2d(1, 8, kernel_size=3, padding=1, stride=1)
print("padding=1, stride=1 输出:", same(x).shape)   # [1, 8, 32, 32]

# 3x3 卷积 + 步长 2：尺寸减半（替代池化的降采样）
half = nn.Conv2d(1, 8, kernel_size=3, padding=1, stride=2)
print("padding=1, stride=2 输出:", half(x).shape)   # [1, 8, 16, 16]
