作用域与 lambda#

为什么函数里的变量外面用不了？lambda 又是什么？本节课解开这两个常见的困惑。

一、概念讲解#

1. 作用域：变量有"势力范围"#

变量的"作用域"指它在代码的哪些地方能被访问到。Python 里最常见的是两种：

  • 局部变量：定义在函数内部的变量，只能在这个函数里使用，函数结束就被清理；
  • 全局变量：定义在函数外部（最顶层）的变量，整个文件里都能读。

2. 名字查找顺序（LEGB，先记个印象）#

函数里用到某个名字时，Python 按"局部 → 外层函数 → 全局 → 内置"的顺序去找。所以如果函数里定义了和全局同名的变量，函数内用的是局部那个，不会影响外面的全局变量。

3. 想在函数里修改全局变量：global#

在函数内给一个全局变量重新赋值，需要用 global 关键字声明一下，告诉 Python"我要改的是全局那个"。不过实际编程中应尽量少用全局变量，让函数"自给自足"会更清晰、更少出 bug。

4. lambda：一行写个小函数#

lambda 可以用来写一个没有名字、只有一行表达式的小函数：

lambda 参数: 表达式

它适合临时需要一个简单函数的地方，比如排序、过滤、map 等场景。复杂的逻辑还是用 def 更合适，因为 lambda 写不了多行语句。

二、代码示例#

示例 1：局部变量外面拿不到#

def demo():
    message = "我在函数里"   # 局部变量
    print(message)

demo()
# print(message)   # 取消注释会报 NameError，因为 message 只在函数里可见

示例 2：函数内读全局变量#

count = 10          # 全局变量

def show():
    print(count)    # 函数里可以直接读

show()              # 10

示例 3：函数内赋值不会改到全局#

num = 5

def change():
    num = 99        # 这是新建的局部变量，和全局 num 无关
    print("函数内：", num)

change()                # 函数内：99
print("函数外：", num)  # 函数外：5

示例 4：用 global 修改全局变量#

score = 60

def pass_exam():
    global score    # 声明要改全局 score
    score = 90

pass_exam()
print(score)        # 90

示例 5：lambda 的基本用法#

double = lambda x: x * 2     # 相当于 def double(x): return x * 2
print(double(5))             # 10

add = lambda a, b: a + b
print(add(3, 7))             # 10

示例 6：lambda 用在 sorted 里#

students = [("阿伟", 88), ("小美", 95), ("老王", 76)]

# 按分数（每项的第 2 个元素）从高到低排序
ranked = sorted(students, key=lambda s: s[1], reverse=True)
print(ranked)

三、练习#

  1. 写一个函数，在函数内定义一个局部变量并打印；然后在函数外尝试打印它，观察报错信息，再把那行注释掉。
  2. 定义一个全局变量 total = 0，写一个函数用 global 把它改成 100，调用后打印验证。
  3. 用 lambda 写一个返回两个数乘积的函数，赋给变量 mul，并测试几组数据。
