pyplot 基础#

上一课我们认识了 Figure、Axes、Axis 等组成部分。这一课正式学习最常用的绘图入口 matplotlib.pyplot（通常简写为 plt），以及它提供的两种编程风格。

一、概念讲解#

1. pyplot 是什么#

matplotlib.pyplot 是 Matplotlib 提供的一层命令式接口，它模仿 MATLAB 的绘图方式：你调用 plt.plot()、plt.title() 等函数，pyplot 在背后维护一个"当前图"（current figure）和"当前坐标轴"（current axes），把你的命令作用上去。它的优点是对快速探索非常友好，一行就能出图。

2. 两种编程风格#

风格 A：pyplot 状态机风格（stateful / implicit）

不显式创建对象，直接调用 plt.* 函数，pyplot 自动管理"当前图"：

import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [1, 4, 9])   # 作用在"当前"Axes 上
plt.title("隐式接口")
plt.show()

这种方式适合脚本和交互式探索，但一旦图变复杂（多个子图、需要精确控制），状态就难以追踪。

风格 B：面向对象风格（object-oriented / explicit）

先用 plt.subplots() 显式拿到 fig 和 ax，之后全部通过 ax.* 方法操作：

import matplotlib.pyplot as plt
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 4, 9])
ax.set_title("显式接口")
plt.show()

本课程后续统一推荐面向对象风格，因为它目标明确、不易出错，也更接近 Matplotlib 官方建议。

3. 最常用的 plot 参数#

ax.plot(x, y, ...) 是折线/点图的基础函数，几个高频参数：

参数 含义 示例取值
color / c 颜色 "steelblue"、"#1f77b4"
linestyle / ls 线型 "-"、"--"、":"、"-."
linewidth / lw 线宽 2、2.5
marker 数据点标记 "o"、"s"、"^"、"*"
markersize 标记大小 6
markevery 每隔几个点画一个标记 25
label 图例标签 "sin(x)"

4. 保存与显示#

  • plt.show()：在交互环境（如 Jupyter、GUI）中显示窗口。
  • fig.savefig("文件名.png", dpi=150)：把图保存为文件，dpi 控制分辨率。在无图形界面的脚本或服务器环境中，通常用 savefig 代替 show。

二、可运行代码示例#

下面用面向对象接口绘制正弦与余弦两条曲线，演示 plot 的常用参数、图例与保存。

import numpy as np
import matplotlib.pyplot as plt

# 中文与负号配置（放在绘图之前）
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False

x = np.linspace(0, 2 * np.pi, 200)
y_sin = np.sin(x)
y_cos = np.cos(x)

# 面向对象接口：显式拿到 fig 与 ax
fig, ax = plt.subplots(figsize=(8, 4.5))

# 常用参数：color 颜色、linestyle 线型、linewidth 线宽、marker 标记、label 标签
ax.plot(x, y_sin, color="#1f77b4", linestyle="-", linewidth=2,
        marker="o", markevery=25, label="sin(x)")
ax.plot(x, y_cos, color="#ff7f0e", linestyle="--", linewidth=2,
        marker="s", markevery=25, label="cos(x)")

ax.set_title("pyplot / 面向对象接口绘制示例")
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.legend()

# 保存到当前工作目录，再显示
fig.savefig("pyplot_demo.png", dpi=150)
plt.show()

试着改动 color、linestyle、marker 的取值，观察效果变化。

三、练习#

  1. 用状态机风格（plt.plot + plt.title 等）重画上面的正弦曲线，体会两种风格的差异。
  2. 用面向对象接口绘制 y1 = x 与 y2 = x**2（x 取 0 到 10），分别使用 "-" 与 "--" 线型，添加图例。
  3. 把练习 2 的图用 fig.savefig("ex2.png", dpi=200) 保存，并说明 dpi 的作用。
