常见误区#

学完怎么"画得对、画得美"，这一课反过来看"画得错"。有些误区不是语法错误，而是会让读者误解数据的视觉陷阱。识别这些误区，既是保护读者，也是保护你自己在报告里的可信度。

一、概念讲解#

1. 截断的坐标轴（最隐蔽的陷阱）#

为了让差异"看起来更大"，有人把 y 轴从一个大数开始（比如从 50 而不是 0）。这在柱状图上尤其危险——柱子的高度代表数量，若基线不是 0，两根柱子的高度差会被成倍放大。规则是：柱状图（以及用面积表示大小的图）的数值轴必须从 0 开始；只有折线图这种"看趋势/斜率"的图，才允许截断，且必须明确标注截断记号。

2. 用饼图装太多类别#

饼图靠"扇形角度"表达占比，但当类别超过 5~6 个，或各扇形大小相近时，人眼几乎无法比较。此时应改用横向条形图——按数值排序后，一眼就能看出谁大谁小。

3. 滥用 3D 和装饰#

3D 饼图、3D 柱状图、花哨的阴影和渐变色，往往只会扭曲比例、增加噪声，很少真正帮助理解。3D 饼图还会让靠近读者的扇形显得更大。除非数据本身是三维的，否则优先用 2D。

4. 用双轴制造"虚假相关"#

上一课讲过双轴，但双轴可以被恶意（或无意）地用来"对齐"两条本无关系的曲线——通过各自缩放 y 轴范围，让两条曲线看起来同步。看图时要警惕：双轴图里的两条曲线是否真的可比？

二、可运行代码示例#

示例 1：柱状图基线必须从 0 开始#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

groups = ['A', 'B']
values = [80, 85]     # 两组差距其实只有 5

fig, axs = plt.subplots(1, 2, figsize=(10, 4.5))

# 左：错误示范——y 轴从 70 开始，5 的差距被放大到"看起来像两倍"
axs[0].bar(groups, values, color=['tab:blue', 'tab:orange'])
axs[0].set_ylim(70, 90)
axs[0].set_title('错误：y 轴从 70 开始（误导）')

# 右：正确示范——y 轴从 0 开始，真实差距一目了然
axs[1].bar(groups, values, color=['tab:blue', 'tab:orange'])
axs[1].set_ylim(0, 100)
axs[1].set_title('正确：y 轴从 0 开始')

fig.suptitle('柱状图基线对比', fontsize=14)
fig.tight_layout()
plt.show()

要点：同一个数据（80 vs 85），左图看起来 A 只有 B 的一半多一点，右图才是真实观感。柱状图里，柱子的"长度"就是信息本身，砍掉基线等于篡改信息。

示例 2：饼图 vs 横向条形图#

import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

# 八个市场份额接近的品类，用饼图几乎无法比较
labels = ['品类A', '品类B', '品类C', '品类D', '品类E', '品类F', '品类G', '品类H']
shares = [13, 13, 13, 12, 12, 12, 12, 13]

fig, axs = plt.subplots(1, 2, figsize=(11, 4.5))

# 左：饼图（八块大小几乎一样，难比较）
axs[0].pie(shares, labels=labels, autopct='%d%%')
axs[0].set_title('饼图：八类占比难比较')

# 右：横向条形图（按数值排序，清晰）
order = sorted(range(len(shares)), key=lambda i: shares[i])   # 按数值升序排序的下标
sorted_labels = [labels[i] for i in order]
sorted_shares = [shares[i] for i in order]
axs[1].barh(sorted_labels, sorted_shares, color='tab:cyan')
axs[1].set_xlim(0, 20)
axs[1].set_title('横向条形图：排序后一目了然')

fig.tight_layout()
plt.show()

要点：饼图适合"少数几个、差距明显"的占比；类别一多或占比接近，就换成排序后的横向条形图。barh 是水平条形图，sorted 配合 key=lambda 按数值排序。

三、练习#

  1. 动手验证：把示例 1 中的 set_ylim(70, 90) 改成 set_ylim(0, 90)，再改成 set_ylim(75, 86)，感受基线位置对"视觉差距"的影响，并写一句话总结。
  2. 改造反例：画一张带 explode 的饼图模拟 3D 效果，再把它改造成一张 2D 横向条形图，对比哪种更易读。
  3. 找茬：上网找 2 张你认为是"误导性图表"的新闻图或广告图（可搜"misleading charts"），分析它们用了哪种误区（截断轴、滥用 3D、双轴、饼图过多等）。
  4. 思考：如果一张折线图必须用截断的 y 轴（比如数值都集中在 90~100 之间），你该怎么做，才能既不误导、又看清变化？
