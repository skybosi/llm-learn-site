综合实战#

这是《NumPy 科学计算》的最后一课。前面九课积攒的武器——数组操作、广播、线性代数、随机数、统计、向量化——现在要合在一起，打一场完整的实战。

我们选取三个数据科学里最经典的场景：移动平均（信号平滑）、线性回归（拟合直线）、距离矩阵（相似度分析）。每个场景都遵循同一条主线：明确问题 → 设计向量化解法 → 用 NumPy 实现 → 验证结果。你会在写代码的过程中，体会到"向量化思维"如何让几十行的循环浓缩成两三行，却更快更清晰。

一、概念讲解#

1. 场景一：移动平均，平滑噪声#

时间序列数据（股价、气温、传感器读数）常夹杂噪声，让趋势难以辨认。移动平均是最朴素的平滑手段：把每个点替换成"以它为中心、前后若干个点的平均值"。噪声在平均过程中相互抵消，趋势便浮现出来。

朴素做法是"每个位置都套一个内层循环求平均"，是 O(N·window) 的双重循环。但借助 卷积思想，可以用 np.convolve 或巧妙的 cumsum 一次完成，把复杂度降到 O(N)。

2. 场景二：线性回归，用正规方程解出拟合直线#

给定一堆 (x, y) 散点，线性回归要找一条直线 y = kx + b，使所有点到直线的竖直距离平方和最小。这个最优的 k 和 b 有闭式解（正规方程）：

θ = (XᵀX)⁻¹ Xᵀy

其中 X 是"加了一列 1"的设计矩阵（第一列全是 1 对应截距 b，第二列是 x 对应斜率 k），θ = [b, k]。用前面学过的 np.linalg.solve 或矩阵运算，几行就能解出来——不需要任何循环。

3. 场景三：距离矩阵，一次算出所有点对的距离#

在聚类、最近邻搜索、推荐系统里，经常需要"任意两点之间的距离"。朴素做法是双重循环逐个算，复杂度 O(N²)。但利用上一章学过的平方展开技巧：

‖a - b‖² = ‖a‖² - 2·(a·b) + ‖b‖²

可以用广播 + 一次矩阵乘法，把整张距离矩阵"一次到位"地算出来。这既是向量化的典范，也是前面"性能对比"结论的绝佳印证。

二、可运行示例#

示例 1：移动平均平滑股价

import numpy as np

# 生成一条带噪声的"价格"序列：真实趋势 + 随机噪声
rng = np.random.default_rng(2024)
t = np.arange(50)
trend = 50 + 0.5 * t                        # 缓慢上升的趋势
noise = rng.normal(0, 3, size=50)           # 噪声
price = trend + noise                       # 观测到的价格

window = 5
# 用卷积实现移动平均：核是一排相等的 1/window
kernel = np.ones(window) / window
# mode='valid' 表示只输出"核完整覆盖"的部分
smooth = np.convolve(price, kernel, mode='valid')

print("原始价格前 8 个 =", np.round(price[:8], 1))
print("平滑后前 4 个 =", np.round(smooth[:4], 1))

# 平滑后噪声应明显变小：比较两者的标准差
print("原始标准差 =", np.round(price.std(), 2),
      "，平滑后标准差 =", np.round(smooth.std(), 2))

示例 2：线性回归拟合直线（正规方程）

import numpy as np

# 模拟数据：y = 3x + 5 附近散布的点
rng = np.random.default_rng(1)
x = np.linspace(0, 10, 30)
y = 3 * x + 5 + rng.normal(0, 2, size=30)   # 真斜率 3、截距 5，加噪声

# 构建设计矩阵 X：第一列全是 1（对应截距），第二列是 x（对应斜率）
X = np.column_stack([np.ones_like(x), x])

# 正规方程解：θ = (XᵀX)⁻¹ Xᵀy
theta = np.linalg.solve(X.T @ X, X.T @ y)
b, k = theta
print(f"拟合结果：截距 b ≈ {b:.2f}，斜率 k ≈ {k:.2f}")

# 用拟合的直线做预测，并计算均方误差（MSE）
y_pred = X @ theta
mse = np.mean((y - y_pred) ** 2)
print(f"均方误差 MSE = {mse:.2f}")

示例 3：向量化计算距离矩阵

import numpy as np

# 10 个二维点
rng = np.random.default_rng(5)
points = rng.random((10, 2))

# 平方展开公式：d² = |a|² - 2 a·b + |b|²
sq = np.sum(points ** 2, axis=1)            # 每个点的模长平方
# 广播相加得到 10x10 矩阵
dist_sq = sq[:, None] - 2 * (points @ points.T) + sq[None, :]
# 数值误差可能导致极小负数，先截断再开方
dist = np.sqrt(np.maximum(dist_sq, 0))

print("距离矩阵形状 =", dist.shape)
print("对角线上（自身到自身）应全为 0：", np.allclose(np.diag(dist), 0))
print("矩阵是否对称 =", np.allclose(dist, dist.T))

# 找出距离最近的一对点（排除对角线）
i, j = np.unravel_index(np.argmax(dist), dist.shape)
print(f"距离最远的一对点是第 {i} 和 {j} 号点，距离 {dist[i, j]:.3f}")

示例 4：把三件事串起来（迷你流水线）

import numpy as np

# 一份模拟的"每日订单量"数据：趋势 + 噪声
rng = np.random.default_rng(9)
days = np.arange(60)
orders = 100 + 2 * days + rng.normal(0, 15, size=60)

# 1) 平滑：7 天移动平均
kernel = np.ones(7) / 7
orders_smooth = np.convolve(orders, kernel, mode='valid')

# 2) 统计：平滑前后的均值与标准差
print("平滑前 均值=%.1f 标准差=%.1f" % (orders.mean(), orders.std()))
print("平滑后 均值=%.1f 标准差=%.1f" % (orders_smooth.mean(), orders_smooth.std()))

# 3) 回归：用前 40 天拟合增长趋势，预测第 60 天
x_train = days[:40]
y_train = orders[:40]
X = np.column_stack([np.ones_like(x_train), x_train])
theta = np.linalg.solve(X.T @ X, X.T @ y_train)
pred_day60 = theta[0] + theta[1] * 59
print(f"预测第 60 天订单量 ≈ {pred_day60:.1f}，实际值 = {orders[59]:.1f}")

  3. 距离矩阵扩展：把示例 3 的点集改成 100 个三维点，计算距离矩阵，找出距离最近的一对点，并验证矩阵的对称性与对角线为 0 这两个性质。
