CNN 结构#

单个卷积、池化只是零件，把它们按一定顺序拼起来，才是一台能工作的机器。这一课我们把前面两课的积木组装成一个完整的卷积神经网络，讲清楚每个模块各司何职，并学会统计一个网络有多少参数、每层输出是什么形状——这是读懂任何 CNN 论文结构图的基本功。

一、概念讲解#

1. 一个典型 CNN 的骨架#

绝大多数分类用 CNN 都由几类模块按顺序堆叠而成：

输入图片 → [卷积 + 激活 + 池化] × N → 展平 → 全连接层 → 输出类别
  • 卷积层（Conv）：提取局部特征，参数少、共享权重；
  • 激活函数（ReLU）：引入非线性，否则多层卷积叠起来仍等价于一个线性变换；
  • 池化层（Pool）：下采样，压缩尺寸、扩大感受野；
  • 全连接层（FC）：在特征被压平后做最终分类决策。

从整体看，CNN 遵循一条清晰的分工：前面的卷积层负责把像素逐步抽象成语义特征，后面的全连接层负责根据这些特征做判断。

2. 每个模块的角色再放大#

  • 激活函数 ReLU：ReLU(x) = max(0, x)，计算快、梯度不会像 sigmoid 那样在两端消失，是卷积层之后最常用的选择。PyTorch 里用 nn.ReLU(inplace=True)。
  • 批量归一化 BatchNorm：对每个通道的输出做归一化，让各层输入的分布更稳定，从而可以用更大的学习率、训练更稳更快，现代网络几乎标配 nn.BatchNorm2d。
  • Dropout：训练时随机把一部分神经元输出置 0，强迫网络不依赖个别神经元，是全连接层上常用的防过拟合手段 nn.Dropout(p)。
  • 展平 Flatten：把 (C, H, W) 的多维特征图拉成一维向量，才能交给全连接层。

3. 感受野：一个神经元"看"到多大#

感受野（receptive field） 指输出特征图上某个神经元，对应到原始输入上的区域大小。每叠一层卷积或池化，感受野都会变大。直观理解：第一层神经元只看到 3×3 的像素；第二层神经元看到的 3×3，实际覆盖原图 5×5；越深越"视野开阔"。这也是深层 CNN 能捕捉全局结构的原因。

4. 参数数量怎么算#

读结构时，一眼估出参数量是重要技能：

  • 卷积层参数：kernel_h × kernel_w × in_channels × out_channels + out_channels（最后的 out_channels 是偏置）。
  • 全连接层参数：in_features × out_features + out_features。
  • 池化层、激活层、Flatten、Dropout：0 参数。

一个 3×3、in=64, out=128 的卷积层参数量是 3×3×64×128 + 128 = 73856；而一个把 4096 维接 1000 维的全连接层参数高达 400 多万——这解释了为什么现代网络倾向于用全局平均池化替代大号全连接层。

二、可运行代码示例#

下面搭一个手写数字（MNIST 风格，单通道 28×28 输入）的 CNN，用 nn.Sequential 串起各模块，并逐层打印输出形状与参数量。

import torch
import torch.nn as nn

class TinyCNN(nn.Module):
    """一个麻雀虽小五脏俱全的 CNN：卷积 + ReLU + 池化，再接全连接分类。"""
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3, padding=1),  # 28x28 -> 16x28x28
            nn.ReLU(inplace=True),
            nn.MaxPool2d(2),                             # -> 16x14x14
            nn.Conv2d(16, 32, kernel_size=3, padding=1), # -> 32x14x14
            nn.ReLU(inplace=True),
            nn.MaxPool2d(2),                             # -> 32x7x7
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),                                # -> 32*7*7 = 1568
            nn.Linear(32 * 7 * 7, 128),
            nn.ReLU(inplace=True),
            nn.Dropout(0.5),
            nn.Linear(128, num_classes),
        )

    def forward(self, x):
        x = self.features(x)      # 特征提取
        x = self.classifier(x)    # 分类决策
        return x

net = TinyCNN()
print(net)

# 打印每一层输出形状（借助 features 顺序前向即可）
x = torch.randn(1, 1, 28, 28)
for name, layer in net.features.named_children():
    x = layer(x)
    print(f"{name:12s} -> 输出形状 {tuple(x.shape)}")
x = x.flatten(1)
print(f"{'Flatten':12s} -> 输出形状 {tuple(x.shape)}")

# 统计总参数量
total = sum(p.numel() for p in net.parameters())
print("总参数量:", total)

# 单独看第一个卷积层的参数形状与数量
first_conv = net.features[0]
w = first_conv.weight
print("第一层卷积核形状:", tuple(w.shape))   # (16, 1, 3, 3)
print("第一层参数量:", w.numel() + first_conv.bias.numel())  # 16*1*3*3 + 16 = 160

运行后你会看到特征图从 28×28 一路缩小到 7×7，通道数从 1 涨到 32——空间尺寸变小、通道数变多，这正是 CNN 前向过程的典型规律。

三、练习#

  1. 给 TinyCNN 的 features 再加一个 nn.Conv2d(32, 64, 3, padding=1) 和一个 nn.MaxPool2d(2)，算出此时 Flatten 前的形状，并相应修改 classifier 的输入维度。
  2. 手算第一层卷积 nn.Conv2d(1, 16, 3, padding=1) 的参数量，与代码打印的 160 对比，写出公式。
  3. 把 nn.Dropout(0.5) 放到 net.train() 和 net.eval() 两种模式下各前向一次，说明 Dropout 在训练和评估时行为有何不同。
  4. 思考：如果把所有 nn.ReLU 去掉，这个网络退化成什么？为什么说"多层线性变换叠加仍是线性"？
