训练测试集划分#

在前几章里，我们已经能走通"读数据 → 预处理 → 训练模型 → 预测"的完整流程。但有一个关键问题被暂时搁置了：模型到底好不好，我们凭什么下结论？

如果拿训练时用过的那批数据去"考试"，模型几乎总是高分——因为它已经"背过"这些题的答案了。真正的挑战在于：面对从没见过的新数据时，模型还能不能答对？这种能力叫泛化能力（generalization）。本课讲的"训练集 / 测试集划分"，就是衡量泛化能力的第一步，也是最基础的一步。

一、概念讲解#

1. 为什么不能在同一批数据上既训练又评估#

想象一个学生在考试前把试卷原题全背了下来，考场上遇到一模一样的题自然满分，但这不能说明他真正掌握了知识。模型也一样：

  • 模型在训练数据上的表现叫训练误差（或训练得分），它衡量的是"记忆能力"。
  • 模型在没见过的新数据上的表现叫泛化误差（或测试得分），它才衡量"学习能力"。

如果不把数据分开，我们只能得到训练误差，会高估模型的真实水平，甚至把"过拟合"（第 6 章会细讲）当成好成绩。

2. 划分的基本原则#

最常用的做法是：把整份数据按一定比例随机切成两块——

  • 训练集（train set）：用来让模型学习参数，通常占大头（70%～80%）。
  • 测试集（test set）：学习完成后才拿出来评分，模型在训练阶段完全不碰它。

三个要点必须记牢：

  1. 先划分，再做预处理。标准化（StandardScaler）之类的操作必须只用训练集来拟合，再套用到测试集。否则测试集的信息会"泄漏"到训练过程中，测试得分就失真了。
  2. 固定随机种子（random_state）。随机划分每次结果都不同，固定种子才能让结果可复现，也方便和别人对齐结论。
  3. 测试集只能用于"最终验收"，不能反复调参、反复看它的分数。否则测试集也会慢慢"被模型偷看到"，失去独立评估的意义（第 5 章的交叉验证就是为此准备的）。

3. train_test_split 的核心参数#

scikit-learn 的 train_test_split 是这件事的标准工具，几个参数要会：

参数 作用
test_size 测试集占比（0～1 之间的小数）或绝对样本数
train_size 训练集占比，与 test_size 二选一即可
random_state 随机种子，固定后划分结果可复现
shuffle 是否先打乱再划分，默认 True
stratify 传入标签 y，按类别比例分层抽样，保证每块里的类别比例与整体一致

最后一项 stratify 对类别不平衡的数据尤其重要，我们马上在示例里看到它的价值。

二、可运行示例#

示例 1：最基本的划分

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

# 加载鸢尾花数据集（150 条样本，3 个类别，4 个特征）
X, y = load_iris(return_X_y=True)

# 按 70%/30% 划分训练集与测试集
# random_state 固定随机种子，保证每次运行切出的样本完全相同
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

print("训练集样本数：", X_train.shape[0])
print("测试集样本数：", X_test.shape[0])
print("特征维度：", X_train.shape[1])

示例 2：stratify 在类别不平衡时的作用

import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

# 生成类别严重不平衡的二分类数据：0 类占 90%，1 类只占 10%
X, y = make_classification(
    n_samples=1000, n_features=10,
    weights=[0.9, 0.1], random_state=0)

# 不加 stratify：随机切分可能让测试集里 1 类的比例偏离 10%，极端时甚至一个 1 类都没有
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0)
print("不加 stratify，测试集中 1 类的比例：", round(np.mean(y_test == 1), 3))

# 加 stratify：按 y 的类别比例分层抽样，两块数据的类别比例都贴近原始分布
X_train_s, X_test_s, y_train_s, y_test_s = train_test_split(
    X, y, test_size=0.2, random_state=0, stratify=y)
print("加 stratify，测试集中 1 类的比例：", round(np.mean(y_test_s == 1), 3))

示例 3：完整流程——先划分，再做预处理，最后评估

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

X, y = load_iris(return_X_y=True)

# 第一步：先划分（在一切预处理之前！）
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

# 第二步：标准化只用训练集拟合，再套用到测试集，避免信息泄漏
scaler = StandardScaler()
scaler.fit(X_train)                         # 只用训练集计算均值和标准差
X_train_scaled = scaler.transform(X_train)  # 训练集标准化
X_test_scaled = scaler.transform(X_test)    # 测试集用同一套参数标准化

# 第三步：只在训练集上学习
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train_scaled, y_train)

# 第四步：分别在训练集、测试集上打分，对比两者差距
train_acc = model.score(X_train_scaled, y_train)
test_acc = model.score(X_test_scaled, y_test)
print("训练集准确率：", round(train_acc, 3))
print("测试集准确率：", round(test_acc, 3))

三、练习#

  1. 改比例：把 test_size 分别改成 0.1、0.3、0.5，观察训练集与测试集的准确率如何变化，思考测试集太小会带来什么问题。
  2. 理解 random_state：把 random_state 去掉运行 3 次，比较每次的测试准确率是否相同；再设回 42，说明它的作用。
  3. 找 bug：下面的代码哪里违反了"先划分再预处理"的原则？指出并改写：
    scaler = StandardScaler().fit(X)      # 先对整个 X 做了标准化
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)
  4. 分层思考：为什么在"欺诈检测"（欺诈样本只占 0.1%）这类任务里，stratify 几乎是必须的？
  5. 前瞻：当数据量很小（比如只有 100 条），一次随机的 7:3 划分可能导致测试集只有 30 条、结果波动很大。想一想有没有更稳的评估办法（提示：下一章要讲交叉验证）。
