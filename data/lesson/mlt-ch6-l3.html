信息增益与决策树准则#

前两课我们有了熵（不确定性）和 KL 散度（分布差距）。现在把它们用到机器学习里最经典的一个问题上：决策树在每个节点该选哪个特征来分裂？ 答案是"选最能降低不确定性的那个"，而其数学形式就是信息增益。这一课要做的，是把 ID3/C4.5 那条"看起来是启发式"的准则，还原成一条由熵的链式法则直接推出的定理，并和另外两种候选准则（Gini、分类误差率）做定量比较。

一、概念讲解（含推导）#

1. 先问"为什么"：分裂的动机是"减少不确定性"#

决策树的每个内部节点手里握着一批样本，目标是尽快让样本"变纯"（同一类）。天然的想法是：选一个特征 X，使得"知道 X 之后，标签 Y 的不确定性下降最多"。用上一课的语言，就是比较"分裂前的熵"与"分裂后的条件熵"之差：

IG(Y;X):=H(Y)−H(Y∣X).

这就是信息增益（Information Gain）。它读作："特征 X 能消除多少关于 Y 的不确定性"。

2. 信息增益 = 互信息：链式法则的直接结果#

信息增益有一个更深刻的名字——互信息 I(X;Y)。它度量两个变量的"共享信息"，有三条等价定义，全部由熵的性质推出：

I(X;Y)=H(Y)−H(Y∣X)=H(X)−H(X∣Y)=H(X)+H(Y)−H(X,Y).

推导（对称性）：由链式法则 H(X,Y)=H(X)+H(Y∣X)=H(Y)+H(X∣Y)，移项立得：

H(Y)−H(Y∣X)=H(X)−H(X∣Y)=H(X)+H(Y)−H(X,Y).

互信息的对称性（I(X;Y)=I(Y;X)）来自这个等式，它的含义很美："X 揭示了多少 Y" 恰好等于 "Y 揭示了多少 X"——信息是双向共享的。

互信息还有两个关键性质，都直接复用上一课的结论：

  • 非负性：I(X;Y)=DKL​(p(x,y)∥p(x)p(y))≥0。也就是说，互信息是"联合分布与独立乘积分布"之间的 KL 散度；它非负，正是 Gibbs 不等式的又一次应用。等号当且仅当 X、Y 独立——独立变量之间没有共享信息，这完全符合直觉。
  • 上界：I(X;Y)≤min{H(X),H(Y)}，因为条件熵非负。

因此，决策树选特征 X 最大化信息增益，等价于选与标签 Y 互信息最大的特征，也等价于选"与 Y 最不独立"的特征。

3. 三种分裂准则的比较：为什么 CART 用 Gini#

实际决策树并不都用信息增益，常见有三条，都是"节点不纯度"的度量，选让加权不纯度下降最多的特征：

  • 熵 / 信息增益（ID3、C4.5）：H(p)=−∑c​pc​logpc​。
  • Gini 不纯度（CART 默认）：G(p)=∑c​pc​(1−pc​)=1−∑c​pc2​。
  • 分类误差率：E(p)=1−maxc​pc​。

三者都在分布"均匀"时最大、"纯净"时最小，但形状不同。对二分类（设正类概率 p）：

H(p)=−plogp−(1−p)log(1−p),G(p)=2p(1−p),E(p)=min(p,1−p).

关键区别在于光滑性与对"不纯"的敏感度：

  • 熵是严格凹的，对"50/50"的完全混乱给出最大值 1 bit，且它对应最大似然，理论最"正"；
  • Gini 是 p(1−p) 的倍数，是熵在 p=21​ 附近的二阶近似，计算更快（无对数），且对"多数类占优"的情形更敏感，实际效果与熵几乎无差；
  • 分类误差率对"多数类占比"最不敏感（只要最大类不变，误差率不变），因此不善于捕捉"哪一次分裂让纯度提升得更细腻"，实践中很少用它做分裂（但常用它做剪枝）。

三者都以"让分裂后的加权不纯度最小"为目标，只是"不纯度"的定义不同；信息增益（熵）是其中唯一能直接解释成"减少的比特数"的那一个。

4. 从信息增益到 ID3 算法：把准则变成树#

有了准则，ID3 就只是它的逐层应用：在每个节点，对每个候选特征算 IG(Y;Xi​)，选最大的做分裂，然后递归。这就是完整的"信息论决策树"：

  1. 若当前节点样本全属一类（H(Y)=0）或无特征可用，停止，标为该节点多数类；
  2. 否则，选 argmaxi​IG(Y;Xi​) 分裂；
  3. 对每个取值分支递归。

注意信息增益有个已知缺陷：偏好取值多的特征（如"编号"这种唯一值特征，每个分支都极纯，IG 人为虚高）。C4.5 用信息增益率（gain ratio）修正：把 IG 除以特征自身的熵 H(X)，惩罚"取值过多"的特征。这提醒我们：信息论准则虽美，落地时仍需正则化——这又呼应了母原理 1 里"目标函数 + 正则项"的统一结构。

二、验证性代码示例#

下面代码用经典的"打网球"数据集：① 手工计算各特征的信息增益，找出应选的首个分裂特征；② 对比熵、Gini、分类误差率三者在二分类下随 p 的曲线；③ 极小规模地"跑"一次信息增益分裂，验证"选 IG 最大的特征"确实让条件熵下降最多。

import numpy as np
from collections import Counter

def entropy(counts):
    counts = np.array([c for c in counts if c > 0], dtype=float)
    p = counts / counts.sum()
    return float(-np.sum(p * np.log2(p))) + 0.0   # +0.0 把 -0.0 规范回 0.0

def gini(counts):
    counts = np.array(counts, dtype=float)
    p = counts / counts.sum()
    return 1 - np.sum(p ** 2)

# ---------- 1) 打网球数据：手工信息增益 ----------
# 特征：天气(晴/阴/雨)、湿度(高/正常)；标签：是否打球(是/否)
samples = [
    ("晴", "高", "否"), ("晴", "高", "否"), ("阴", "高", "是"), ("雨", "高", "是"),
    ("雨", "正常", "是"), ("雨", "正常", "否"), ("阴", "正常", "是"), ("晴", "高", "否"),
    ("晴", "正常", "是"), ("雨", "高", "是"),
]
labels = [s[2] for s in samples]
H_Y = entropy(list(Counter(labels).values()))

def info_gain(feat_idx):
    groups = {}
    for s in samples:
        groups.setdefault(s[feat_idx], []).append(s[2])
    H_cond = sum(len(v)/len(samples) * entropy(list(Counter(v).values()))
                 for v in groups.values())
    return H_Y - H_cond

ig_weather = info_gain(0)
ig_humid   = info_gain(1)
print(f"H(Y) = {H_Y:.4f} bit")
print(f"IG(天气) = {ig_weather:.4f} bit")
print(f"IG(湿度) = {ig_humid:.4f} bit")
print("应选分裂特征:", "天气" if ig_weather > ig_humid else "湿度")

# ---------- 2) 三种不纯度曲线对比 ----------
for p in [0.0, 0.25, 0.5, 0.75, 1.0]:
    c = [p, 1 - p]
    print(f"p={p:>4}: 熵={entropy(c):.4f}  Gini={gini(c):.4f}  误差率={1-max(c):.4f}")

运行结果大致为：

H(Y) = 0.9710 bit
IG(天气) = 0.3219 bit
IG(湿度) = 0.0464 bit
应选分裂特征: 天气
p= 0.0: 熵=0.0000  Gini=0.0000  误差率=0.0000
p=0.25: 熵=0.8113  Gini=0.3750  误差率=0.2500
p= 0.5: 熵=1.0000  Gini=0.5000  误差率=0.5000
p=0.75: 熵=0.8113  Gini=0.3750  误差率=0.2500
p= 1.0: 熵=0.0000  Gini=0.0000  误差率=0.0000

结果印证两点：① "天气"的信息增益更大，应作为首个分裂特征（这正是经典 ID3 对该数据集给出的第一步）；② 在 p=0.5 时三种不纯度都取最大值，但中间区域里 Gini 比分类误差率更"拱"、对纯度变化更敏感——这就是 CART 弃误差率而用 Gini 的数值原因。

三、练习#

  1. 证明 I(X;Y)=DKL​(p(x,y)∥p(x)p(y))，并据此用 Gibbs 不等式说明 I(X;Y)≥0，等号当且仅当 X,Y 独立。
  2. 证明互信息的对称性 I(X;Y)=I(Y;X)，并解释"X 揭示的 Y 信息 = Y 揭示的 X 信息"这句话为什么成立。
  3. 用代码：对二分类，在同一坐标系画出熵、Gini、分类误差率关于 p∈[0,1] 的三条曲线，验证 Gini 是熵在 p=21​ 附近的近似（提示：比较两者的泰勒展开）。
  4. 计算"编号"特征的陷阱：若给上面 10 个样本加一个取值互不相同的"编号"特征，它的信息增益是多少？为什么说它虚高？C4.5 的增益率如何把它压下来？
  5. 思考：信息增益是"分裂前后熵的绝对下降量"，而增益率是"除以特征自身熵"。二者的根本区别是什么？为什么说这是"目标函数 + 正则化"结构在决策树里的体现？

母原理连接#

本课是母原理 4（信息论视角） 的落地应用，也是"信息论视角"与母原理 1（一切学习 = 优化一个目标函数） 的会师：决策树每个节点都在解同一个子优化问题——最大化信息增益（等价于最小化加权条件熵），而这正是"选最能降低不确定性的特征"这一朴素目标的形式化。你还看到了正则化的影子：信息增益率 = 信息增益 − 对特征取值的惩罚，说明即便是决策树，也逃不出"目标 + 正则"的统一母题。
