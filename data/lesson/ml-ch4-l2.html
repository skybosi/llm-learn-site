评估指标#

上一课我们把数据切成了训练集和测试集，但切完之后，"得分"到底该怎么算？一个"好"字太笼统，我们需要量化的指标来客观描述模型的表现。

不同任务需要不同的尺子：分类任务看"分对了几分"，回归任务看"预测值和真实值差多远"。本课把分类、回归两大类里最常用的指标一次讲清，并重点点出一个新手最容易踩的坑——准确率在类别不平衡时会骗人。

一、概念讲解#

1. 分类指标：从准确率到精确率、召回率、F1#

准确率（accuracy） 是最直观的：预测正确的样本占总样本的比例。但在"99% 是正常人、1% 是患者"的疾病筛查里，一个模型只要把所有人都判成"正常人"，准确率就有 99%，却一个患者都抓不到——这种"高准确率"毫无价值。

于是我们需要从"阳性（positive）"这个角度重新衡量。约定把关心的那一类（比如"患病"）叫阳性：

  • 精确率（precision）：预测为阳性的样本里，真正是阳性的比例。回答"预测为阳性，有多少是真阳性？"
  • 召回率（recall）：真正的阳性样本里，被成功预测出来的比例。回答"所有真阳性，被抓到了几个？"
  • F1 分数（F1-score）：精确率和召回率的调和平均，把两者合成一个数。当两者此消彼长时，F1 用来找平衡点。

精确率和召回率往往此消彼长：把判定标准放宽，能抓到更多真阳性（召回率↑），但也会把更多正常人误判成阳性（精确率↓）。

2. 回归指标：预测值离真实值有多远#

回归任务是预测一个连续数值（房价、温度、销量），指标围绕"误差"展开：

  • MAE（平均绝对误差）：误差绝对值的平均，直观、单位与目标一致，对异常值不敏感。
  • MSE（均方误差）：误差平方的平均，会放大较大的误差，数学性质好、处处可导。
  • RMSE（均方根误差）：MSE 开根号，单位回到与目标一致，更常被拿来"读"。
  • R²（决定系数）：衡量模型解释了目标变量多少方差，越接近 1 越好；等于 0 意味着不比"拿平均值瞎猜"强。

3. 怎么选指标#

一句话：先看任务在乎什么。

  • 分类且类别平衡：准确率就够用。
  • 分类且类别不平衡：精确率 / 召回率 / F1，尤其要明确"抓阳性"和"别误报"哪个更要紧。
  • 回归：MAE 直观、RMSE 常用，R² 用来横向比较不同模型。

二、可运行示例#

示例 1：类别不平衡时，准确率 vs 精确率 / 召回率 / F1

from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (accuracy_score, precision_score,
                             recall_score, f1_score, classification_report)

# 构造类别不平衡数据：1 类（阳性）只占 5%
X, y = make_classification(
    n_samples=2000, n_features=10, weights=[0.95, 0.05],
    flip_y=0.05, random_state=0)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# 逐个指标查看：准确率很高，但召回率可能低得可怜
print("准确率 accuracy：", round(accuracy_score(y_test, y_pred), 3))
print("精确率 precision：", round(precision_score(y_test, y_pred), 3))
print("召回率 recall：", round(recall_score(y_test, y_pred), 3))
print("F1 分数：", round(f1_score(y_test, y_pred), 3))

# classification_report 一次性给出每个类别的 precision / recall / f1
print("\n完整报告：")
print(classification_report(y_test, y_pred))

示例 2：回归指标 MAE / MSE / RMSE / R²

import numpy as np
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

X, y = load_diabetes(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0)

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

mae = mean_absolute_error(y_test, y_pred)
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)

print("MAE ：", round(mae, 2))
print("MSE ：", round(mse, 2))
print("RMSE：", round(rmse, 2))
print("R²  ：", round(r2, 3))

三、练习#

  1. 手动验证：用 classification_report 打印出的 precision、recall，对照下一课混淆矩阵的公式，反推出这个测试集里 TP、FP、FN、TN 各是多少。
  2. 比较单位：把示例 2 的 MAE 和 RMSE 放在一起看，为什么 RMSE 通常比 MAE 大？什么情况下两者差距会拉得很大？
  3. 场景决策：分别判断下面场景最该看哪个指标：① 垃圾邮件过滤（漏掉垃圾邮件可接受，但误杀正常邮件很糟糕）；② 癌症筛查（宁可多召回，不能漏诊）；③ 房价预测。
  4. 调包实验：把示例 1 的 LogisticRegression 换成 DummyClassifier(strategy="most_frequent")，观察它的准确率与召回率，理解"偷懒模型"为什么准确率好看却没用。
  5. 思考：F1 为什么用调和平均而不是普通的算术平均？提示：若精确率=1、召回率=0，算术平均是 0.5，调和平均是多少？
