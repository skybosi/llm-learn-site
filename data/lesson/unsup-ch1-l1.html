K-means 聚类原理#

一、概念讲解#

1.1 聚类问题是什么#

在监督学习中，每一份训练样本都带着正确答案——标签。而聚类面对的是另一种局面：数据只有特征、没有标签，我们要靠自己从数据本身挖掘出"天然的分组"。这种"无标签却要发现结构"的任务，就是无监督学习中最经典的一类问题。

聚类要回答的核心问题是：如何把一批样本划分成若干组，让同一组内的样本彼此相似，不同组之间的样本差异明显？ 这里的"相似"通常用距离来度量——距离近的样本更像是一伙的。

K-means 是聚类算法里最朴素、最常用的一种。它的名字里的 K 表示我们要把数据分成 K 个簇（cluster），而"means"指的是每个簇用其成员的均值来代表。整个算法本质上是"猜中心 → 分样本 → 再算中心"这样不断来回的过程，最终让每个样本都稳定地属于某个簇。

1.2 算法的直观直觉#

想象桌上散落着一堆彩色的点，你想把它们分成 3 堆。一个自然的做法是：

  1. 先随便在桌上放 3 个"临时中心点"；
  2. 把每个点划给离它最近的那个中心；
  3. 对每一堆，重新计算这堆点的"重心"，把临时中心移到重心处；
  4. 因为中心动了，有些点可能该换堆了，于是回到第 2 步再来一遍。

如此反复，直到中心不再明显移动为止。这就是 K-means 的全部思想：反复执行"分配"和"更新"两步，直到收敛。

1.3 形式化定义#

给定数据集 {x1​,x2​,…,xn​}，K-means 的目标是把样本划分成 K 个互不重叠的簇 C1​,C2​,…,CK​，使得簇内误差平方和（也常被称作"惯性"，inertia）最小：

inertia=k=1∑K​x∈Ck​∑​∥x−μk​∥2

其中 μk​ 是第 k 个簇的中心（簇内所有样本的均值）。这个式子的含义很清楚：把每个样本到它所属簇中心的距离平方加起来，这个总和越小，说明簇内部越"紧凑"，聚类效果越好。

可以这样理解这个优化目标：K-means 是在最小化"每个点离自己的代表点有多远"的总代价。正因为用的是均值作为代表，K-means 天然适合那些大致呈球形、大小相近、密度均匀的数据；对于细长条、月牙形或者大小悬殊的簇，它往往会力不从心——这一点我们会在后面看到具体表现。

1.4 算法步骤#

把上面的直觉写成确定的流程，K-means 的标准步骤如下：

  1. 初始化：选定簇数 K，并初始化 K 个中心点 μ1​,…,μK​（最常用的做法是随机选 K 个样本作为初始中心，sklearn 里也提供更聪明的初始化方式）。
  2. 分配（Assignment）：对每个样本 xi​，计算它到 K 个中心的距离，把它划给距离最近的那个簇：

Ck​={xi​:∥xi​−μk​∥≤∥xi​−μj​∥, ∀j=k}

  1. 更新（Update）：对每个簇，用簇内所有样本的均值重新计算中心：

μk​=∣Ck​∣1​x∈Ck​∑​x

  1. 判断收敛：若中心位置变化很小（或达到最大迭代次数），停止；否则回到第 2 步。

第 2 步保证"给定中心，分配是最优的"，第 3 步保证"给定分配，中心是最优的"，两者交替进行，每一步都让惯性不增。因此惯性会单调下降，算法最终收敛到某个局部最小值。

1.5 两个必须知道的性质#

一是对初始中心敏感。 不同的初始中心可能导致完全不同的结果，算法可能收敛到不同的局部最优。sklearn 用 n_init 参数控制"用不同初始中心跑多次、取最好结果"的次数，就是为了缓解这个问题。

二是 K 需要事先指定。 K-means 不会自己"发现"该分成几类，K 是一个必须由你给定的超参数。如何科学地选择 K，正是本章第 3 课要解决的核心问题。

二、可运行代码示例#

下面用 sklearn 内置的 iris 数据集，体验一次完整的 K-means 聚类流程。

# -*- coding: utf-8 -*-
# 第 1 课：K-means 聚类原理演示
import numpy as np
from sklearn.cluster import KMeans
from sklearn.datasets import load_iris

# 1. 加载 iris 数据集（150 个样本，4 个特征，真实有 3 类花）
iris = load_iris()
X = iris.data          # 特征矩阵，形状 (150, 4)
y_true = iris.target   # 真实标签，仅用于对照，聚类时不会使用

# 2. 创建 K-means 模型，指定分成 3 个簇
#    random_state 固定随机种子，保证每次运行结果一致
kmeans = KMeans(n_clusters=3, random_state=42)

# 3. 训练：内部反复执行"分配 -> 更新"直到收敛
kmeans.fit(X)

# 4. 查看结果
print("聚类中心（3 个簇，每个是 4 维均值向量）：")
print(kmeans.cluster_centers_)
print("\n每个样本被分配的簇标签（前 20 个）：")
print(kmeans.labels_[:20])
print("\n簇内误差平方和（惯性）：", kmeans.inertia_)
print("迭代次数：", kmeans.n_iter_)

# 5. 对训练数据做预测（返回每个样本的簇标签，与 labels_ 一致）
pred = kmeans.predict(X[:5])
print("\n前 5 个样本的预测簇标签：", pred)

输出解读：cluster_centers_ 给出了 3 个簇各自的 4 维均值向量，这正对应"每个簇用均值代表"的思想；inertia_ 就是上一节定义的簇内误差平方和，数值越小表示簇越紧凑；n_iter_ 告诉我们算法迭代了几次才收敛。

提示：运行环境需安装 scikit-learn，可通过 pip install scikit-learn 安装。
