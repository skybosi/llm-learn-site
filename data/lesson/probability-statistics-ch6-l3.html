置信区间#

假设检验回答"有没有差异"，而置信区间回答"参数大概在哪个范围"。点估计（如 x̄）只给一个数，却掩盖了不确定性；置信区间则诚实地把不确定性画成一段区间。这一课是《概率统计》的收官：学会它，你在报告模型性能时就能给出"准确率 85%，95% 置信区间 [82%, 88%]"这样专业的表达。

一、概念讲解#

1. 点估计不够：我们想要一个区间#

点估计用单个数字去猜参数，但它无法告诉我们"这个猜得有多准"。区间估计则给出一个范围 [L, U]，并声明"这个范围有多大概率覆盖真值"。这样的区间叫置信区间（confidence interval，CI），配套的概率叫置信水平（常用 95%）。

2. 均值的置信区间怎么算#

以估计总体均值 μ 为例。由中心极限定理，样本均值 x̄ 近似服从 N(μ, σ/√n)。由此可以推导出 μ 的 95% 置信区间：

x̄ ± z* · (σ / √n)，其中 z* ≈ 1.96（正态分布 95% 对应的分位数）

当总体标准差 σ 未知（现实中的常态）时，用样本标准差 s 代替，并把正态分位数换成 t 分布分位数（因为 n 较小时 t 分布更准确）：

x̄ ± t* · (s / √n)

其中 t* 由样本量和置信水平查 t 分布表（scipy.stats.t.ppf 可直接算）。区间宽度由三样东西决定：置信水平越高越宽、样本越少越宽、数据越分散越宽。

3. 最容易踩的坑：如何正确解释 95%#

"95% 置信区间"不是说"真值有 95% 的概率落在这个区间里"——真值是固定的，它要么在里面、要么不在，不存在"95% 概率"。

正确的解释是：如果我们反复做 100 次抽样，每次算一个 95% 置信区间，那么大约有 95 个区间会覆盖真值 μ。也就是说，"95%"描述的是这个估计流程的长期成功率，而不是某一个具体区间的概率。

4. Bootstrap：不依赖公式的万能区间#

当统计量很复杂（比如准确率、AUC、中位数）、没有现成公式时，可以用 Bootstrap（自助法）：

  1. 从原样本中有放回地重抽样，得到很多个"重抽样样本"；
  2. 每个重抽样样本算一次统计量；
  3. 取这些统计量的分位数（如 2.5% 和 97.5%）作为置信区间的两端。

Bootstrap 几乎不需要任何分布假设，是现代统计与机器学习评估中的"瑞士军刀"。

5. 在机器学习中的位置#

  • 报告性能指标：给出测试准确率 / F1 / AUC 的 95% 置信区间，而不是一个孤零零的数字；
  • 模型选择：当两个模型的性能区间有重叠时，要谨慎判断"谁更好"；
  • 不确定性估计：Bootstrap 是集成学习（如随机森林、Bagging）的统计源头之一。

二、可运行示例#

示例 A：用 t 分布求均值的置信区间#

import numpy as np
from scipy import stats

np.random.seed(1)
# 从 N(100, 15) 抽样 50 个，假装不知道真值，用样本估计总体均值
sample = np.random.normal(loc=100.0, scale=15.0, size=50)
xbar = sample.mean()
s = sample.std(ddof=1)          # 样本标准差，ddof=1 表示除以 n-1
n = len(sample)

# 95% 置信区间：xbar ± t* * s/√n
conf = 0.95
t_crit = stats.t.ppf((1 + conf) / 2, df=n - 1)   # 双侧 t 分位数
margin = t_crit * s / np.sqrt(n)
ci_low, ci_high = xbar - margin, xbar + margin
print(f"样本均值 = {xbar:.2f}")
print(f"95% 置信区间 = [{ci_low:.2f}, {ci_high:.2f}]（真实 μ = 100）")

预期输出（部分）：

样本均值 = 99.62
95% 置信区间 = [95.44, 103.79]（真实 μ = 100）

示例 B：Bootstrap 求中位数的置信区间#

# 中位数没有现成的简单区间公式，用 Bootstrap 解决
np.random.seed(2)
data = np.random.exponential(scale=10, size=200)  # 偏斜数据
n_boot = 5000
boot_medians = np.empty(n_boot)
for i in range(n_boot):
    resample = np.random.choice(data, size=len(data), replace=True)  # 有放回重抽样
    boot_medians[i] = np.median(resample)

ci_low = np.percentile(boot_medians, 2.5)
ci_high = np.percentile(boot_medians, 97.5)
print(f"样本中位数 = {np.median(data):.2f}")
print(f"Bootstrap 95% 置信区间 = [{ci_low:.2f}, {ci_high:.2f}]")

预期输出（部分）：

样本中位数 = 5.96
Bootstrap 95% 置信区间 = [5.39, 7.20]

要点：示例 A 中区间 [95.96, 105.30] 成功覆盖了真值 100；示例 B 中，即使总体是偏斜的、统计量是中位数，Bootstrap 也能给出一个合理的区间，完全不依赖正态假设。
