为什么分数经常骗人：泄漏、标注噪声与指标错位#

这一节要解决什么#

前三节建立了一个理想模型：定义构念 → 抽样 → 测量 → 算指标 → 报置信区间。这一节处理理想模型之外的三类系统性失效，它们共同的特征是：失效不会表现为"分数很难看"，而表现为"分数很好看"。

  1. 泄漏（leakage）：被测对象提前见过答案。后果不是"分数偏高"这么温和，而是排序失效——排行榜不再能区分模型。
  2. 标注噪声（annotation noise）：真值本身带误差。随机噪声让所有分差按 (1−2e) 衰减，系统性噪声直接制造偏见。
  3. 指标与目标错位（metric-goal misalignment）：代理指标被优化后与真实目标脱钩。这是 Goodhart 定律的四种变体，也是"我们把榜单刷上去了但产品没变好"的标准病因。

最后给出一个决策论视角：评测的全部价值是降低决策的不确定性；如果一个分数无论怎么变都不改变决策，它就不值得测。这条纪律能过滤掉大部分"为了评测而评测"的工作。

泄漏：第一种系统性偏差#

四类泄漏，机制各不相同#

类型 机制 典型来源
训练污染 评测题目/答案出现在预训练或微调语料中 网络爬取（GitHub、题库网站、论坛）把公开基准一起收进去
时间泄漏 用"未来"的数据评测"过去"的知识；或评测集早于模型知识截止，模型只是背过 用 2023 年的基准评 2025 年的模型
预处理泄漏 在全量数据上拟合了标准化/特征选择/去重，再划分训练测试 fit 在切分之前（经典但至今常见）
评测纪律泄漏 用同一评测集反复调参、选提示、选 checkpoint "我们试了 20 个提示，取最好的那个报"

第四类最容易被原谅，也最普遍：它不需要任何人作弊，只需要"多试几次"。 每次试用同一评测集做选择，都在把这个集合的信息注入模型（或注入提示），本质上是在这个样本上做梯度下降。第 2 章会给出量化它的方法（保留集、滚动评测）。

数学后果：不是偏高，而是排序失效#

设模型 i 的真实能力为 ti​，污染带来的"额外正确率"为 λi​≥0（它取决于该模型训练语料与评测集的交集，外部不可观测）。观测分是

si​=ti​+λi​

如果所有 λi​ 相同，排行榜只是整体平移，排序不变（损失有限）。真正致命的是 λi​ 因模型而异：

  • 训练语料更大、爬取更激进的模型，λi​ 更大；
  • 于是真能力弱但污染重的模型排在前面——排序被系统性反转，而不是随机抖动。

第二种失效更隐蔽：方差压缩。当所有强模型的 λi​ 都接近"把题目全部记住"，观测分一起挤到 95%+ 的天花板附近，模型间真实差异被压在几个点的噪声里，排行榜失去排序能力（基准饱和的一半原因就是污染）。此时你会看到一种典型症状：榜单越靠前，分差越小，但名次变动越频繁。

为什么泄漏"不可从分数本身发现"#

泄漏不带任何异常特征。一个被污染的基准和一个干净的基准可以长得一模一样：分数都很高、分布都正常。这就是为什么泄漏必须用外部证据检测：

  • 与训练语料的比对（n-gram 重合、成员推断）——只对开源模型可行；
  • 时间切分（用知识截止之后的题）；
  • 扰动实验（改数字/改名/改顺序后掉分是否异常大）；
  • 诱饵串（canary，参见第 2 章第 2 节）。

第 2 章第 2 节会把检测方法逐个展开。这里只要记住结论："这个分数看起来正常"不能作为没有泄漏的证据。

标注噪声：真值本身是带误差的#

随机噪声：让所有分差按固定系数衰减#

设标注者以概率 e 把正确答案标错（随机出错，与内容无关）。模型真准确率 p，则观测准确率为：

pobs​=p(1−e)+(1−p)e=p+e(1−2p)

这个式子里有三个值得记住的推论：

  1. 当 p=0.5 时噪声不产生偏差（pobs​=0.5）——但方差变大。所以"接近随机"的任务上，噪声把分数钉在 50%，与环境无关。
  2. 当 p>0.5 时，噪声把分数向 0.5 拉。p=0.9,e=0.1 → 0.82：看起来"模型变差了"，其实是标注变脏了。
  3. 两个模型的分差被同一个系数 (1−2e) 乘：

Δobs​=Δtrue​(1−2e)

e=0.15 → 系数 0.7：真实的 10 个点差距只显示为 7 个点。更糟的是样本量代价：要把这个被缩小的分差检验出来，所需样本量放大

nclean​nneeded​​=(1−2e)21​

e=0.15 时约 2.04 倍。标注噪声不是"稍微不精确"，而是直接抬高评测成本。

系统性噪声：不衰减，直接制造偏见#

如果标注者的错误不是随机的，而是与某个可观测属性相关（长度、格式、口音、答案所在位置、模型风格），那它不服从上面的衰减公式，而是给某类输出一个稳定的加成：

pobs​=p+b(style)

这种偏差不会随样本量增加而消失，因为它是偏置而不是方差。第 2 节讲的 judge 位置偏差、冗长偏差就是这一类。对付随机噪声靠"多标"与"多测"，对付系统性噪声只能靠实验设计（随机化、盲法、控制变量）。

用多重标注逼近真值#

若 k 个标注者独立、每人正确率 q>0.5，多数投票的正确率为

qk​=j>k/2∑​(jk​)qj(1−q)k−j

q=0.7：3 人多数投票 → 3(0.7)2(0.3)+(0.7)3=0.784；5 人 → 0.837。收益递减但真实。

关键假设是"独立"，而它在现实中经常破：多个标注者共享同一种误解（同一个标注手册的盲点、同一种文化预设、同一个 prompt 的暗示）。此时多数投票会把共同的错误固化成"真值"——你得到的不是更准的标签，而是更自信的偏标签。

超出多数投票的做法（Dawid-Skene 一类）把"标注者可靠性"也当成待估参数，用 EM 迭代估计真值与每个标注者的混淆矩阵。它的思想比实现更重要：真值不是给定的，是一起估出来的；而它同样依赖"标注者错误条件独立"这一强假设。

最低限度的实践：报告标注者间一致性（Cohen's κ / Fleiss κ / Krippendorff α），并把混淆矩阵一起报出来。κ 低意味着构念或 rubric 有问题，此时任何分数都不该被用来做决策。

指标与目标错位：Goodhart 的四种形态#

"当一个指标成为目标，它就不再是好的指标。"这句话被引用得太多，以至于失去了操作性。Manheim 与 Garrabrant 把 Goodhart 定律分成四类，这个分类对评测极其有用，因为四类的诊断与对策完全不同：

① 回归型（regressional）：S=T+ε，S 是 T 的带噪代理。当你按 S 选择时，同时选中了正的 ε，于是被选中对象的 T 平均低于它的 S。

例：用一个小规模自动评测选 checkpoint，选出来的往往是"在这个小评测上运气好"的那个。对策：留出独立确认集；报 CI；不要用同一批数据既选择又报告。

② 极值型（extremal）：S 与 T 的相关只在历史观测范围内成立，优化把系统推出这个范围后关系断裂。

例：把"回答长度"当质量的代理——在常见范围内长度与信息量正相关；一旦把长度优化到极端，多出来的全是废话，T 反而下降。对策：监控进入极端区域后的目标指标；给代理设上限并对超出部分做人工抽检。

③ 因果型（causal）：S 与 T 相关，但干预 S 不会改变 T（有共同原因，或反向因果）。

例：把"人工满意度调查得分"当目标，于是引导用户打高分（弹窗、话术），S 上去了，真实留存没变。对策：区分"观测关联"与"干预效果"，用 A/B 干预而不是相关性优化。

④ 对抗型（adversarial）：被测主体有动机操纵 S，并且找得到捷径。

例：优化 pass@k 时把测试用例硬编码进答案；优化 judge 胜率时学会讨好评委（加免责声明、加图表、模仿评委语气）。对策：隐藏评测集、随机化、加反捷径对照题、把"是否合格"换成"是否无法作弊"。

一个可操作的判据：如果某个指标在被优化后会失效，那么你必须在优化之前就设计好它的"防作弊版本"（私有集 + 反事实题 + 人类抽检），而不是等它失效再补救——因为失效是你已经按它做的决策造成的，事后无法回收。

统计层面的骗人：多重比较与选择性报告#

即使没有泄漏、噪声可控、指标也没错位，报告的统计过程本身仍可能制造假结论。三个最常见的机制：

① 多重比较。 20 个模型两两比较是 190 次检验；在 α=0.05 下，即使全都一样，期望也有约 9.5 次"显著"。修正方式是 Bonferroni（α/m，保守）或 FDR（控制错误发现率，更实用），或者直接用置信区间思考：区间跨 0 就不是结论。

② 分叉路径（garden of forking paths）。 没人故意 p-hack，但只要"试了 20 个提示取最好"、"试了 3 个 seed 取最好"、"试了 5 个抽取正则取最好"，就已经完成了隐式多重比较。选择本身就是一种优化，而优化会选中噪声。 对策是把选择过程也写成协议：预先固定提示、seed 集合与抽取规则；报多种子/多提示的分布而不是最好值。

③ 幸存者偏差。 失败的评测被删掉、调不通的模型不进入榜单、只有正向结果被写进报告。对策：登记所有尝试（包括失败的），把"评测协议"与"模型版本"当成审计对象。

报告纪律（可直接采用）：

预注册：在跑评测之前写下决策规则（例如"Δ>2% 且 CI 不跨 0 才升级"）
全量报：报所有 seed / 所有提示的均值与分布，不报 max
配对报：配对差值 + 置信区间（第 3 节）
原始报：保留逐题结果（per-item），以便任何人独立重算 CI 与置换检验

噪声的结构：为什么"多测几次"有时没用#

前面讲了泄漏、标注噪声、指标错位三类失效。它们共同的问题是误差不都是同一种东西——而不同类型对"加样本量"的反应完全不同。把观测到的分差写成一个可分解的形式，能省下大量无效算力：

Δ^=乘性衰减(1−2e)​​Δ+系统偏差b​​+随机误差ε​​,ε∼N(0, neff​σ2​)

三项的性质完全不同：

项 来源 随 n 的行为 诊断方法 处置
乘性衰减 (1−2e) 随机标注/评分错误 不随 n 消失（它是系数） 用重复标注估 e 提高标注质量；或按 1/(1−2e) 校正
系统偏差 b 共享误解、评分函数偏向、环境差异 不随 n 消失 金标题、专家抽检、对照实验 只能改测量本身（改 rubric / 换抽取规则 / 加对照）
随机误差 ε 抽样、解码采样 按 1/neff​​ 收缩 置信区间 / bootstrap 加题、配对、降方差

这张表给出的最关键判据是：一个"改进"如果随着样本量增加不收敛到 0，它要么是真的，要么是偏差——而这两者靠加样本量永远分不开，必须换一种测量去区分；如果它随样本量增加而缩小，那它是随机噪声，加样本量确实有用。

三个必须记住的推论：

  1. "再多跑几遍让结论稳定"只能压住第三项。 这是最常见的资源误用：团队反复重跑同一个评测，把 ε 压到很小，然后精确地测量了一个被 b 污染的、被 (1−2e) 衰减过的量。精度高不等于准。
  2. 系统偏差不会因为"两个模型用同一把尺子"而抵消。 一个常见的错误论证是"我们的抽取规则虽然不完美，但对所有模型一视同仁"。这只在偏差与被比较对象无关时成立；一旦偏差与模型输出风格相关（爱写 \boxed{} 的模型 vs 爱写自然语言的模型），偏差就变成了分差的一部分——第 2 章第 1 节的抽取规则实验就是它的直接演示。
  3. 偏差的方向可以预判、大小必须测量：知道 b 的方向（例如"冗长偏好会抬高长回答的胜率"）不足以决定是否忽略它，因为决策取决于 ∣b∣ 与你要检测的 Δ 的比值。当 ∣b∣ 与 Δ 同量级时，这个评测无法支撑这个决策——这才是"评测不可用"的严格含义，而不是"分数不够高"。

决策论视角：评测的价值 = 降低决策的不确定性#

把评测放回它真正的位置：评测不是科学活动，是决策的输入。 设你的决策是"是否把模型换成 B"，评测的作用是让你在两种状态下做出不同选择：

评测的价值=Pr(评测改变决策)×(改变决策带来的收益差)

这个式子立刻给出三条纪律：

  1. 先写决策规则，再做评测。否则你会不自觉地"看着结果编标准"（分叉路径）。
  2. 评测精度要匹配决策阈值。决策阈值是"提升 3 个点才值得上线"，评测的 CI 半宽却是 2.5 个点——那这个评测无法支撑这个决策，无论跑多少次都只是浪费算力。此时要提高精度（加题、配对、降方差）或降低决策门槛。
  3. 不可行动的指标不值得测。如果某个分数无论高低都不会改变你做什么，它唯一的用途是汇报材料——而它催生的优化压力（Goodhart）是净负的。

配套一个成本原则：评测的成本应与决策的代价匹配。 选一个内部实验模型用自动基准；决定对外发布必须有人工评审；决定给生产写权限需要红队 + 回滚演练。把这三者的严格程度搞反，是最常见的管理错误之一。

一张诊断清单：症状 → 可能原因 → 检验方法#

症状 可能原因 检验
分数异常高，尤其 0-shot 训练污染 n-gram 重合 / 时间切分 / 扰动实验
头部模型分差极小、名次频繁变 基准饱和 + 污染 与 SE 比较；换更难/更新的集
换提示模板分数抖动大于模型间差距 提示敏感性（第 2 章） 提示集合上的方差分解
两个测量相关性低于预期 双方信度不足（衰减） 估计 ρ 并做衰减校正
提高标注人数不见改善 标注错误相关 / rubric 有歧义 看混淆矩阵与 κ，检查标注者分歧模式
指标优化了但产品没变好 代理错位（四型之一） 干预实验（A/B）+ 引入真实目标测量
大量"显著"改进 多重比较 / 分叉路径 预注册 + 置信区间 + FDR
某个子域分数崩但总分为 0 变化 微平均掩盖小类 宏平均 / 分层报告

代码：三个"分数骗人"的最小模拟#

import numpy as np

rng = np.random.default_rng(3)

# ============ 模拟 1：污染让排序反转 ============
# 8 个模型：真能力递减；后三个"训练时见过测试集"，污染加成逐步升高。
# 注意：lambda 在现实中不可观测，这正是泄漏难以发现的原因。
true_skill = np.array([0.74, 0.72, 0.70, 0.68, 0.66, 0.64, 0.62, 0.60])
leak       = np.array([0.00, 0.00, 0.01, 0.01, 0.02, 0.14, 0.16, 0.19])
obs = np.clip(true_skill + leak, 0, 1)

print("真能力排名 (第1名→第8名):", np.argsort(-true_skill) + 1)
print("观测分排名 (第1名→第8名):", np.argsort(-obs) + 1)
print("观测分      :", np.round(obs, 3))
print(f"真第一名在观测榜上掉到第 {int(np.where(np.argsort(-obs)==0)[0][0])+1} 名")
print(f"榜单前三全部是污染最重的三个模型吗？{set((np.argsort(-obs)+1)[:3]) == {6,7,8}}")

# 换个视角：污染让"排序信息"消失
# Spearman 秩相关（观测 vs 真值）——可以看到它甚至变成负的
rank_obs = np.argsort(np.argsort(obs))
rank_true = np.argsort(np.argsort(true_skill))
rho = np.corrcoef(rank_obs, rank_true)[0, 1]
print(f"观测榜与真实能力的秩相关 = {rho:+.3f}  （负值 = 榜单在骗人）")

# ============ 模拟 2：标注噪声让分差衰减 ============
e = 0.15                                  # 随机标注错误率
p_true = np.linspace(0.5, 1.0, 11)
p_obs = p_true + e * (1 - 2 * p_true)     # 向 0.5 回归
print(f"\n随机标注噪声 e={e}")
print(f"真实分差(0.5→1.0) = {p_true[-1]-p_true[0]:.3f}")
print(f"观测分差           = {p_obs[-1]-p_obs[0]:.3f}（衰减系数 1-2e = {1-2*e:.2f}）")
print(f"要检验出同样的分差，样本量需放大 {(1/(1-2*e))**2:.2f} 倍")
print(f"p=0.9 的模型观测分 = {0.9 + e*(1-2*0.9):.3f}  （真实 0.900）")

# 多重标注的收益（假设标注者独立、每人正确率 q）
from math import comb
q = 0.7
for k in (1, 3, 5, 9):
    qk = sum(comb(k, j) * q**j * (1-q)**(k-j) for j in range(k//2 + 1, k+1))
    print(f"  {k} 人多数投票正确率 = {qk:.3f}")

# ============ 模拟 3：极值型 Goodhart ============
# 真实目标 T 在 x=0.6 处最优（倒 U）；代理 S = x 单调递增。
x = np.linspace(0, 1, 101)
T = 1 - (x - 0.6)**2
S = x
in_range = x <= 0.6                        # 历史观测范围
print(f"\n历史范围内 corr(S, T) = {np.corrcoef(S[in_range], T[in_range])[0,1]:+.3f}  ← '提升 S 就是提升 T'")
print(f"历史范围内最优 x = {x[in_range][np.argmax(T[in_range])]:.2f}")
print(f"但最大化 S 会走到 x = {x[np.argmax(S)]:.2f}，此时 T = {T[np.argmax(S)]:.3f}")
print(f"（相比历史最优 {T.max():.3f}，真实目标下降了 {T.max()-T[np.argmax(S)]:.3f}）")

三段代码各自对应一节：

  • 模拟 1 要读出的是：泄漏的杀伤力在于秩相关变负——不是"每个模型都虚高 5 个点"，而是榜单把最弱的模型排到最前。任何"我们换了新语料，榜单涨了 3 名"的结论，都必须排除这个解释。
  • 模拟 2 要读出的是：随机标注噪声的效应是可预测的衰减（系数 1−2e）与可计算的样本量惩罚（1/(1−2e)2）。这让"标注质量"从一个模糊的担忧变成了一个可以算进预算的项。同时看多标注收益：q=0.7、9 人投票也只到 0.90 左右，靠人多救不了烂 rubric。
  • 模拟 3 要读出的是：代理指标"在历史范围内有效"不足以保证它在优化后有效。优化的方向未必是目标改善的方向——这就是为什么在把指标设为门禁之前，先要问"如果所有人都拼命优化它，会走到哪里"。
  • ⚠️ 三段都是合成数据，用于展示机制；真实评测里 λi​、e、T 都不可直接观测，只能通过设计（保留集、扰动、干预实验）间接约束。

练习#

  1. 泄漏归因：某模型在基准 X 上 0-shot 分数超过所有同规模模型 12 个点，5-shot 只超 3 个点。 （a）这个模式更支持"污染"还是"真能力强"？为什么？ （b）再给出两个能进一步区分的实验（提示：扰动与时间切分）； （c）如果你的模型是闭源的、拿不到训练语料，你还能做哪些污染审计？

  2. 噪声预算：你的评测集标注错误率 e=0.2（随机）。 （a）真实分差 8 个点会显示成几个点？ （b）要检验出这个真实分差，样本量要放大多少倍？ （c）如果你把 e 降到 0.05，样本量需求变成原来的几分之一？ （d）如果标注错误是系统性的（所有标注者都偏好长答案），上面的公式还成立吗？该用什么办法处理？

  3. 四种 Goodhart 归类：判断下面四种情形各属哪一类，并各写一条对策。 （a）用 200 题的小自动集选 checkpoint，最终上线表现低于预期； （b）把"平均回复长度"当信息量代理，优化后回复臃肿； （c）把"用户点满意按钮的比例"当目标，产品加了引导弹窗； （d）把 pass@k 当训练奖励，模型开始硬编码测试用例。

  4. 决策阈值与评测精度的匹配：你的决策规则是"新模型人工满意度提升 ≥ 3 个点才上线"，但你的评测 95% CI 半宽是 2.8 个点。 （a）说明为什么这个评测无法支撑这个决策； （b）列出三种提高精度的办法，并各写它的代价； （c）如果成本都不允许，你会怎么修改决策规则？修改后评测的价值函数发生了什么变化？

  5. 预注册练习：为"是否把线上主模型从 A 换成 B"写一份不超过一页的评测协议，必须包含：决策规则、指标体系、样本量与配对方式、置信区间方法、污染审计项、以及在什么结果下你会拒绝下结论。

小结#

  • 泄漏的后果不是"分数偏高"，而是"排序失效"：当污染加成 λi​ 因模型而异时，秩相关可以被拉到 0 甚至为负。分数本身不带异常特征，必须靠外部证据（语料比对、时间切分、扰动、诱饵串）检测。
  • 标注噪声分两种：随机噪声让分差按 (1−2e) 衰减、让样本量需求放大 1/(1−2e)2；系统性噪声直接制造偏见，且不随样本量消失。多标注只能救随机噪声，且"独立"假设在现实中经常破——低 κ 时任何分数都不该用于决策。
  • Goodhart 有四型：回归型（按代理选择会同时选中噪声）、极值型（代理与目标的关系在历史范围外断裂）、因果型（干预代理不改变目标）、对抗型（被测主体主动找捷径）。四型的对策不同，但共同要求是在优化之前就设计好防作弊机制。
  • 统计过程本身也会骗人：多重比较、分叉路径、幸存者偏差。对策是预注册决策规则、报告全分布而非最好值、保留逐题原始结果。
  • 评测的价值 = 降低决策的不确定性：先写决策规则，再选评测精度；评测精度必须匹配决策阈值；不可行动的指标不值得测。评测的严格程度应与决策的代价匹配。
