花式索引#

基础索引一次取一个或一段连续元素，布尔掩码按条件筛选。但还有一种需求：按任意给定的下标列表，一次性取出多个元素，比如"取第 0、3、7 号样本"，或"把样本按某个随机顺序重新排列"。这种用整数数组作为索引的方式，就是花式索引（fancy indexing）。

一、概念讲解#

1. 什么是花式索引#

花式索引是指：用整数数组（或列表）作为索引，按其中的下标值去原数组里"点名"取元素。它和切片最大的区别是——花式索引返回的是拷贝，而不是视图，修改结果不会影响原数组。

a = np.array([10, 20, 30, 40, 50])
a[[0, 2, 4]]   # 取出第 0、2、4 个元素 -> [10, 30, 50]

2. 一维与多维#

  • 一维数组：a[[i1, i2, ...]]，下标可重复、可乱序，结果按给定顺序排列；
  • 二维数组：X[[r1, r2, ...]] 按行下标取若干行；X[[r1, r2], [c1, c2]] 则是"逐对配对"取元素 (r1,c1)、(r2,c2)，而不是取一个子矩阵（子矩阵要用 np.ix_ 或切片组合）。

3. 数据科学中的典型用法#

  • 随机抽样/打乱样本：用随机排列的下标数组重排样本，训练时 shuffle 数据集；
  • 按得分排序后取 top-k 样本：先用 np.argsort 得到排序下标，再花式索引取前 k 个；
  • 重排类别标签顺序、重采样 等。

4. 相关函数#

  • np.take(a, indices)：功能类似花式索引，可指定 axis，沿某轴取元素；
  • np.argsort(a)：返回"排序后每个元素应有的下标"，常和花式索引搭配使用。

二、可运行代码示例#

示例 1：一维花式索引#

import numpy as np

a = np.array([10, 20, 30, 40, 50])

idx = [0, 2, 4]
print("a[[0,2,4]]:", a[idx])      # [10 30 50]

# 下标可以重复、乱序
print("a[[4, 0, 0]]:", a[[4, 0, 0]])  # [50 10 10]

# 花式索引返回拷贝：修改不影响原数组
selected = a[[0, 1]]
selected[0] = 999
print("a unchanged:", a)

示例 2：二维数组按行取样本#

import numpy as np

X = np.arange(20).reshape(5, 4)
print("X:\n", X)

# 取第 0、3、1 行（顺序由下标数组决定）
rows = X[[0, 3, 1]]
print("rows 0,3,1:\n", rows)

# 逐对配对：取 (0,2)、(3,1)、(1,3) 三个元素
pairs = X[[0, 3, 1], [2, 1, 3]]
print("paired elements:", pairs)

示例 3：随机打乱样本（shuffle）#

import numpy as np

rng = np.random.default_rng(42)   # 固定种子，保证结果可复现

X = np.arange(20).reshape(5, 4)
perm = rng.permutation(X.shape[0])  # 生成随机排列的下标
print("permutation:", perm)

shuffled = X[perm]                # 用花式索引按新顺序取行
print("shuffled X:\n", shuffled)

示例 4：argsort 取 top-k#

import numpy as np

scores = np.array([0.62, 0.95, 0.31, 0.88, 0.44])

order = np.argsort(scores)[::-1]   # 从高到低的下标
print("order (high to low):", order)

top2 = scores[order[:2]]           # 取前 2 个最高分
print("top-2 scores:", top2)

# 用 np.take 沿轴取行
X = np.arange(20).reshape(5, 4)
taken = np.take(X, [4, 0], axis=0)
print("np.take rows 4,0:\n", taken)

三、练习#

  1. 对 np.arange(10)，用花式索引取出下标为 [9, 7, 5, 3, 1] 的元素，并验证它是拷贝（修改后原数组不变）。
  2. 创建一个 (6, 3) 的特征矩阵，用花式索引按 [5, 0, 2, 2] 的行顺序取出样本，观察重复行。
  3. 用 rng.permutation 生成一个随机排列，对一个样本矩阵做 shuffle，并说明为什么这比用循环交换更简洁。
  4. 思考：X[[0, 1], [2, 3]] 返回的是几个元素？如果想像切片那样取一个 2x2 子块，应该怎么写（提示：查 np.ix_）？
