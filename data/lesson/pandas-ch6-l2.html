merge#

上一课的 concat 只是"硬拼"，不关心行与行的对应。可更多时候，我们需要的是按某个键把两张表对齐：比如一张表存订单，一张表存商品信息，想通过"商品编号"把两张表关联起来。pd.merge() 做的正是这件事，它就像 SQL 里的 JOIN。

一、概念讲解#

1. 什么是 merge#

merge 会拿两张表里同名的列（键）做匹配：键值相同的行被拼到一起，形成一张更宽的表。

pd.merge(左表, 右表, on="键列")

默认使用两张表共有的列名作为合并键。若两张表的键列名不同，则分别用 left_on 和 right_on 指定。

2. 四种连接方式：how#

how 参数决定"两边匹配不上时怎么办"，这是 merge 里最需要理解的概念：

how 含义 结果
inner（默认） 内连接 只保留两边都匹配的行
left 左连接 保留左表全部行，右表匹配不上的补 NaN
right 右连接 保留右表全部行，左表匹配不上的补 NaN
outer 外连接 两边所有行都保留，匹配不上的补 NaN

3. 多列合并键#

有时单一列不足以唯一确定一行（比如"地区 + 品类"才唯一），可以传一个列表：

pd.merge(df1, df2, on=["地区", "品类"])

只有两列都相同的行才会被合并。

4. 重名列的区分：suffixes#

当两张表除了键列，还有同名的其他列时，结果里会出现两个同名列。可以用 suffixes 给它们加上不同的后缀加以区分：

pd.merge(df1, df2, on="商品", suffixes=("_左", "_右"))

5. merge / join / concat 怎么选#

  • 按键匹配两列数据：merge；
  • 纯粹上下/左右拼接：concat；
  • 用索引做键（一个按列、一个按索引）：join（DataFrame 的方法，本质是 merge 的索引版本）。

二、可运行代码示例#

import pandas as pd

# 订单表：记录了每个订单卖出的商品
orders = pd.DataFrame({
    "商品": ["手机", "耳机", "键盘", "鼠标"],
    "销量": [120, 430, 210, 300],
})

# 商品表：记录了商品的价格与所属品类
products = pd.DataFrame({
    "商品": ["手机", "耳机", "键盘", "台灯"],
    "价格": [3200, 430, 210, 120],
    "品类": ["数码", "数码", "数码", "家居"],
})
print("订单表：\n", orders)
print("商品表：\n", products)

示例 1：内连接（inner）#

# 只保留两张表都有的商品（鼠标和台灯被丢弃）
inner = pd.merge(orders, products, on="商品", how="inner")
print(inner)

示例 2：左连接（left）#

# 保留订单表全部行；鼠标在商品表里没有，价格和品类补 NaN
left = pd.merge(orders, products, on="商品", how="left")
print(left)

示例 3：外连接与后缀#

# 外连接：两边所有商品都保留，匹配不上的补 NaN
outer = pd.merge(orders, products, on="商品", how="outer")
print(outer)

# 两张表都有"销量"列时，用 suffixes 区分
o2 = pd.DataFrame({"商品": ["手机"], "销量": [120]})
p2 = pd.DataFrame({"商品": ["手机"], "销量": [99]})
print(pd.merge(o2, p2, on="商品", suffixes=("_订单", "_库存")))

三、练习#

  1. 用上面的 orders 和 products，分别尝试 how="right" 和 how="outer"，观察结果里哪些行被保留、哪些位置出现了 NaN。
  2. 把 products 表的键列改名为 商品名，然后用 left_on / right_on 完成左连接。
  3. 构造两张需要"两列才能唯一确定"的表，用 on=["A", "B"] 做多键合并，并解释为什么需要两列作键。
