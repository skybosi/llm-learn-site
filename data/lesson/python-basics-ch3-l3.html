while 循环与 break/continue#

for 适合"已知次数"的重复，while 适合"满足条件就继续"的重复。本节课学习 while 循环，以及能提前控制循环的 break 和 continue。

一、概念讲解#

1. while：只要条件成立就一直循环#

while 条件:
    循环体

每次执行循环体之前，程序都会先检查 条件 是否为真；为真就执行一遍，然后回来再检查，直到条件变成假才退出。

用 while 时，一定要保证循环条件有机会变成假，否则程序会陷入"死循环"，永远停不下来。

2. 循环的三个要素#

一个健康的 while 循环通常包含三件事：

  1. 循环开始前，给条件里用到的变量一个初始值；
  2. 循环体里，做真正的工作；
  3. 循环体里，更新变量，让条件最终能变成假。

3. break：立刻结束整个循环#

break 一执行，循环立即终止，直接跳到循环之后的代码。它常用于"找到目标就收工"的场景。

4. continue：跳过本次，进入下一次#

continue 不会结束循环，而是跳过本次循环剩下的代码，直接回到条件判断、开始下一轮。

5. while 的 else（可选）#

while ... else 里的 else 只在循环正常结束（条件变假、没有 break）时执行；如果循环是被 break 打断的，else 就不会执行。这个小技巧常用来判断"有没有提前退出"。

二、代码示例#

示例 1：数到 5#

count = 1              # ① 初始值
while count <= 5:      # ② 条件
    print(count)
    count += 1         # ③ 更新，让 count 最终超过 5

示例 2：break 提前退出#

# 从 1 一直找，找到第一个能被 7 整除的数就停
n = 1
while True:            # 条件永远为真，靠 break 退出
    if n % 7 == 0:
        print(f"找到：{n}")
        break         # 立即结束循环
    n += 1

示例 3：continue 跳过偶数#

i = 0
while i < 10:
    i += 1
    if i % 2 == 0:
        continue      # 偶数跳过，不打印
    print(i)          # 只打印 1,3,5,7,9

示例 4：else 判断是否提前退出#

secret = 42
tries = 0
guess = 0
while guess != secret and tries < 5:
    guess = int(input("猜一个数字："))
    tries += 1
else:
    if guess == secret:
        print("猜对了！")
    else:
        print("次数用完了。")

三、练习#

  1. 用 while 循环计算 1 到 100 的和（写完后对比一下，它和 for 写法有什么不同）。
  2. 写一个程序，让用户不断输入数字，输入 0 时用 break 退出，并打印所有输入数字的和。
  3. 打印 1 到 20 中所有不是 3 的倍数的数字（提示：用 continue 跳过 3 的倍数）。
