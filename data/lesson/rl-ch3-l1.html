策略评估#

从这一章起，我们进入动态规划（Dynamic Programming, DP）——求解 MDP 的第一类算法。DP 家族有三兄弟：策略评估（policy evaluation）、策略迭代（policy iteration）、价值迭代（value iteration）。本课先讲老大"策略评估"，它回答的是一个"预测"问题：给定一个策略 π，精确求出它的价值函数 v_π。 第 2 章我们已经能用"解线性方程组"一次求出 v_π，但本课要讲的方法——迭代策略评估——用"反复套用贝尔曼方程"逼近 v_π，它虽然在网格世界里显得笨拙，却是理解后续一切算法（包括无模型的蒙特卡洛与 TD）的母模板。

一、概念讲解#

1. 动态规划的适用前提#

"动态规划"这个词借自 1950 年代 Bellman 本人的工作。用在 MDP 上，它有一个严格的适用前提——环境模型已知：p(s', r | s, a) 完全给定，状态集和动作集都是有限的。满足这个前提，就能"闭门造车"式地精确计算，无需与环境真实交互。这也是它和第 4 章（蒙特卡洛、TD 等免模型方法）的根本分界。此外，DP 还有一条实用性的局限：维度灾难——状态数随问题规模指数爆炸时，逐状态更新变得不可承受。但作为理论基石和方法母版，DP 必须先吃透。

2. 策略评估（预测）：目标与思路#

策略评估也叫预测（prediction）：给定 MDP 和策略 π，计算 v_π(s) 对所有 s 的值。第 2 章我们得到两条路：

  • 直接解方程组：v_π = (I − γP^π)^{-1} r^π，一次到位，但要求矩阵求逆，状态一多就不可行；
  • 迭代逼近：把贝尔曼方程 v_π(s) = Σ_a π(a|s) Σ_{s',r} p(s',r|s,a)[r + γ v_π(s')] 当成更新规则，从任意初始值出发，反复更新直到不动点。

本课讲的就是第二条。它绕开了"求逆"这个大工程，代价是要迭代很多轮——但对大状态空间，这正是唯一可行的路。

3. 迭代策略评估：把方程变成更新规则#

迭代策略评估的更新规则是：取贝尔曼方程的右边作为"新的估计"，反复扫描：

v_{k+1}(s) = Σ_a π(a|s) · Σ_{s', r} p(s', r | s, a) · [ r + γ · v_k(s') ]

从 v_0 = 0（或任意值）起步，逐状态代入。它为什么是对的？因为贝尔曼方程的不动点就是 v_π：若某次更新前后 v_{k+1} = v_k，那么这个 v 恰好满足贝尔曼方程，而贝尔曼方程的解唯一，所以 v = v_π。换句话说，我们是在用"反复代入"去逼近那个唯一不动点。

实现上有两种扫描方式：

  • 双数组（同步）：每轮用上一轮的完整 v_k 计算整个 v_{k+1}，互不干扰，最贴合数学定义；
  • 就地更新（in-place）：边算边覆盖，用到的 v_k(s') 可能是本轮刚更新过的新值。它收敛得更快（因为新信息立刻被利用），也是实践中常用的写法。

终止条件通常取"本轮最大变化量"小于阈值 θ：

max_s | v_{k+1}(s) − v_k(s) | < θ

当它满足时，就认为 v 已足够接近 v_π。

4. 为什么一定收敛：压缩映射论证#

"反复更新就会逼近 v_π"这句话不能只靠直觉，要给出理由。把迭代规则写成一个算子 T^π（贝尔曼策略算子）：

(T^π v)(s) = Σ_a π(a|s) Σ_{s', r} p(s', r | s, a) [ r + γ v(s') ]

那么迭代就是 v_{k+1} = T^π v_k。核心结论：T^π 是一个 γ-压缩映射。对任意两个价值向量 u、v，考察它们在某个状态 s 处的差：

| (T^π u)(s) − (T^π v)(s) |
  = | Σ_a π(a|s) Σ_{s',r} p(s',r|s,a) · γ · ( u(s') − v(s') ) |
  ≤ γ · Σ_a π(a|s) Σ_{s',r} p(s',r|s,a) · | u(s') − v(s') |
  ≤ γ · max_{s'} | u(s') − v(s') |
  = γ · ‖u − v‖_∞

第一行用到 T^π 里"即时奖励 r"在相减时抵消，只剩 γ(u(s')−v(s'))；第二行用了三角不等式；第三行用 Σ_{s',r} p(s',r|s,a) = 1 把加权平均放大成"逐点最大值"。于是：

‖T^π u − T^π v‖_∞ ≤ γ · ‖u − v‖_∞

当 γ < 1 时，每应用一次 T^π，两个候选解的距离就至少缩小 γ 倍。反复应用，差距以几何级数收敛到 0。由 Banach 不动点定理，T^π 有唯一不动点（就是 v_π），且从任何起点迭代都收敛到它。这就是迭代策略评估收敛的完整理由——你不需要背下证明，但要能说出这条逻辑链："即时项相消 → 加权平均被逐点最大压制 → γ-压缩 → 唯一不动点 → 迭代收敛"。

5. 就地更新为什么也收敛且更快#

第 3 节说就地更新收敛更快，直觉是：一个状态 s 更新后，同一轮里后续状态 s' 读到它的新值时，相当于提前用上了一部分下一轮的信息。这在数学上仍可用"异步价值迭代收敛定理"保证收敛（条件宽松：每个状态被无限频繁地访问即可）。对确定性网格世界这种"有向无环"的任务，就地更新甚至可能一轮就到位。实践中记住结论：就地更新正确且更快，是默认选择。

二、可运行代码示例#

在经典的 4×4 网格世界上，对"等概率随机策略"做迭代策略评估：每走一步得 −1 分，左上角 (0,0) 和右下角 (3,3) 是终止状态（价值固定为 0），越界动作弹回原地。

import numpy as np

N = 4                         # 4x4 网格
nS, nA = N * N, 4
GAMMA = 1.0                   # 情节任务，不折扣
TERMINAL = {0, 15}            # 左上 (0,0) 与右下 (3,3) 为终止状态

ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]   # 上、下、左、右

def step(s, a):
    """确定性转移：越界弹回原地；每步奖励 -1。"""
    r, c = divmod(s, N)
    dr, dc = ACTIONS[a]
    nr, nc = r + dr, c + dc
    ns = (nr * N + nc) if (0 <= nr < N and 0 <= nc < N) else s
    return ns, -1.0

def print_grid(v):
    """把 16 维价值向量按 4x4 打印。"""
    for row in v.reshape(N, N):
        print("  " + " ".join(f"{x:6.2f}" for x in row))

# 等概率随机策略：每个动作概率 1/4
pi = np.full((nS, nA), 0.25)

def policy_evaluation(pi, theta=1e-4):
    """就地更新的迭代策略评估，返回 v_π 与每轮 delta 历史。"""
    v = np.zeros(nS)
    deltas = []
    while True:
        delta = 0.0
        for s in range(nS):
            if s in TERMINAL:            # 终止状态价值恒为 0，不更新
                continue
            old = v[s]
            # v(s) = Σ_a π(a|s) Σ_{s'} p(s'|s,a)[ r + γ v(s') ]
            new_v = 0.0
            for a in range(nA):
                ns, r = step(s, a)
                new_v += pi[s, a] * (r + GAMMA * v[ns])
            v[s] = new_v                 # 就地覆盖
            delta = max(delta, abs(old - v[s]))
        deltas.append(delta)
        if delta < theta:
            break
    return v, deltas

v, deltas = policy_evaluation(pi)
print("每轮最大变化量 delta（前 6 轮）：")
print("  " + " ".join(f"{d:.3f}" for d in deltas[:6]))
print(f"共 {len(deltas)} 轮收敛")
print("\n等概率随机策略下的 v_π：")
print_grid(v)

运行后你会看到 delta 从大到小单调下降（例如 1.898 → 1.725 → 1.472 → 1.406 → … 一路收敛到 θ 以下），最终的价值函数大致是：

    0.00  -14.00  -20.00  -22.00
  -14.00  -18.00  -20.00  -20.00
  -20.00  -20.00  -18.00  -14.00
  -22.00  -20.00  -14.00    0.00

读这张表：两个终止状态价值为 0；离终止状态越近，价值越大（负得越少）；网格越靠中心，负得越多——因为这些格子"到任何出口都要走更多步、扣更多分"。价值函数的对称性（上下、左右镜像对称）也印证了"等概率策略 + 对称环境 → 对称价值"这一直觉。注意 v_π 在这里等于"从该格出发、按随机策略走到终止状态的期望步数的负数"，所以越接近目标、数值越接近 0。

三、练习#

  1. 把 GAMMA 改成 0.9，重跑策略评估。价值整体向 0 靠近了吗？为什么折扣会让"远处的惩罚"变小？（提示：回想第 1 章的 R_max/(1−γ) 与 γ^k 的衰减。）
  2. 把 theta 从 1e-4 改大到 1.0，观察收敛轮数如何减少、以及最终价值与精确解的偏差如何增大，说明 θ 是"精度 vs 速度"的旋钮。
  3. 把代码改成双数组（同步）更新：每轮先把 v_next 全部算完、再一次性赋给 v。对比它和就地更新在收敛轮数上的差别，验证"就地更快"。
  4. 思考：为什么"即时奖励 r"在压缩映射证明里会相消？这对"收敛速率只由 γ 决定、与奖励大小无关"意味着什么？
