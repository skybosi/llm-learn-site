协方差与相关性#

方差衡量的是单个随机变量的分散程度。但机器学习里我们更常问的是：两个变量之间有没有关系？ 身高和体重是不是一起涨？广告投入和销量是不是正相关？协方差和相关系数就是回答这类问题的工具，它们是相关性分析、协方差矩阵乃至主成分分析（PCA）的数学基础。

一、概念讲解#

1. 协方差的定义#

两个随机变量 X、Y 的协方差定义为：

Cov(X, Y) = E[ (X − E[X]) · (Y − E[Y]) ]

它的含义是：把 X 的偏离和 Y 的偏离乘起来，再取期望。如果 X 偏大时 Y 往往也偏大（两者"同涨同跌"），乘积多为正，协方差就为正；若 X 偏大时 Y 往往偏小（"此消彼长"），协方差为负；若两者毫无关系，正负抵消，协方差接近 0。

展开后同样有手算公式：

Cov(X, Y) = E[XY] − E[X]·E[Y]

特别地，Cov(X, X) = Var(X)——协方差是方差的推广。

2. 相关系数：把协方差"标准化"#

协方差的大小受量纲影响，不好直接比较。皮尔逊相关系数把它标准化到 [−1, 1] 之间：

ρ = Cov(X, Y) / (σₓ · σ_y)

  • ρ = 1：完全正线性相关（点在一条上升直线上）；
  • ρ = −1：完全负线性相关；
  • ρ = 0：无线性相关。

相关系数只衡量线性关系的强弱。ρ = 0 只说明"没有线性关系"，X 和 Y 仍可能存在强烈的非线性关系（比如 Y = X² 在对称区间上相关系数就是 0）。这是使用相关系数时最要记住的一点。

3. 独立 ⇒ 不相关，反之不成立#

若 X、Y 独立，则 E[XY] = E[X]·E[Y]，于是 Cov(X, Y) = 0，即独立一定不相关。但反过来，不相关不一定独立：相关系数为 0 只排除线性关系，变量之间仍可能存在其他依赖。经典的"Y = X²"就是一个不相关但不独立的例子。

4. 机器学习视角：协方差矩阵与 PCA#

把多个特征两两之间的协方差排成一张表，就得到协方差矩阵 Σ，其中第 i 行第 j 列是 Cov(Xᵢ, Xⱼ)。对角线是各特征的方差，非对角是两两协方差。

协方差矩阵在机器学习里地位极高：

  • 相关性分析：特征之间高度相关意味着信息冗余，可能要做特征选择或降维；
  • 主成分分析（PCA）：对协方差矩阵做特征分解，找到方差最大的方向，把高维数据投影到低维，是最常用的降维/去相关方法；
  • 多元正态分布：完全由均值向量和协方差矩阵决定，是很多生成模型和高斯过程的基础。

二、可运行示例#

示例 1：手算协方差与相关系数#

def mean(xs):
    return sum(xs) / len(xs)


def covariance(xs, ys):
    """样本协方差：离差乘积的平均（这里用 n 作分母，便于教学）。"""
    mx, my = mean(xs), mean(ys)
    return sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / len(xs)


def correlation(xs, ys):
    """皮尔逊相关系数：协方差除以两个标准差。"""
    sx = (sum((x - mean(xs)) ** 2 for x in xs) / len(xs)) ** 0.5
    sy = (sum((y - mean(ys)) ** 2 for y in ys) / len(ys)) ** 0.5
    return covariance(xs, ys) / (sx * sy)


# 身高与体重：明显的正相关
height = [160, 165, 170, 175, 180, 185]
weight = [55, 60, 63, 70, 78, 85]

print(f"Cov(身高, 体重) = {covariance(height, weight):.2f}")
print(f"相关系数 ρ = {correlation(height, weight):.4f}")

示例 2：三种关系的数据对比#

本示例沿用示例 1 中定义的 correlation 函数，请先运行示例 1。

import random

random.seed(0)

# 构造三组数据：正相关、负相关、几乎不相关
n = 200
x = [random.gauss(0, 1) for _ in range(n)]
y_pos = [xi * 1.0 + random.gauss(0, 0.3) for xi in x]   # 正相关
y_neg = [xi * -1.0 + random.gauss(0, 0.3) for xi in x]  # 负相关
y_ind = [random.gauss(0, 1) for _ in range(n)]          # 独立噪声


def corr(xs, ys):
    return correlation(xs, ys)


print(f"正相关样本的 ρ = {corr(x, y_pos):.4f}")
print(f"负相关样本的 ρ = {corr(x, y_neg):.4f}")
print(f"独立样本的 ρ = {corr(x, y_ind):.4f}")

示例 3：非线性关系下相关系数会"失效"#

本示例沿用示例 1 中定义的 correlation 函数，请先运行示例 1。

import random

random.seed(1)

# Y = X^2，X 在对称区间 [-1, 1] 均匀取值：有明显关系，但线性相关系数≈0
xs = [random.uniform(-1, 1) for _ in range(100000)]
ys = [xi ** 2 for xi in xs]

print(f"Y = X^2 的相关系数 ρ = {correlation(xs, ys):.4f}")
print("结论：ρ≈0 只表示无线性关系，X 和 Y 仍强相关（二次关系）。")
