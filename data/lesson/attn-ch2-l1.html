自注意力#

第一章的注意力是编码器与解码器之间的：Query 来自解码器，Key/Value 来自编码器。现在换一个视角——如果一条序列自己对自己做注意力，让每个词都能直接"看见"序列里的其它词，会得到什么？这就是自注意力（self-attention），Transformer 最核心的构件。它让每个位置的表示都融合了全序列的信息，而且完全并行，一举解决了 RNN 的顺序瓶颈。

一、概念讲解#

1. 从"两段之间"到"一段之内"#

回顾普通注意力：解码器每生成一步，用 Query 去编码器那串 Key/Value 里找信息。这里 Query 和 Key/Value 来自两个不同的序列，方向是"从生成端看输入端"。

自注意力则把这种"查找"用在一段序列内部：序列中的每个位置都既当 Query，也当 Key，也当 Value。第 i 个词的新表示，是它（作为 Query）与所有位置（作为 Key）比对出权重后，对全体位置（作为 Value）加权求和的结果。一句话说：每个词都问一句"其它词和我有多相关"，然后把它们按相关度融合进自己的表示里。

2. 为什么它能取代 RNN#

RNN 处理序列是一步一步的：第 i 个词的表示要等第 i-1 个算完才能算，信息从前往后逐步传递，相隔很远的两个词要经过很多步才能"见面"，既慢又容易在长距离上衰减。

自注意力让任意两个位置直接相连：计算第 i 个词时，它与第 j 个词的相关性是一次点积，无论 i 和 j 隔多远，路径长度都是 1。于是：

  • 长距离依赖不再衰减，词与词之间是"一步直达"；
  • 并行计算：所有位置可以同时算，因为彼此没有先后依赖（这正是 Transformer 能大规模并行训练的根本原因）。

3. 注意力矩阵：一张"两两关系"热力图#

自注意力中间会得到一张形状为 (序列长度, 序列长度) 的权重矩阵。第 i 行第 j 列的元素，表示"第 i 个词在多大程度上关注第 j 个词"。每一行是一个概率分布（和为 1）。

这张矩阵非常直观：对角线上往往权重较高（词与自己最相关），而句法上有关联的词对（如"动词—宾语"）会在对应位置亮起。可视化自注意力，就等于在观察"模型在读这句话时，眼睛在哪些词之间来回跳"。

4. 一个关键性质：置换不变性#

自注意力本身不含位置信息——把序列里的词打乱顺序，只要词集合不变，每个词的输出（不考虑位置编码）只是按新顺序排列，内容不变。因为注意力权重只由 Query 与 Key 的内容决定，与它们在第几位无关。

这意味着纯自注意力无法区分"我 爱 你"和"你 爱 我"。要让它感知顺序，必须额外注入位置信息（位置编码），这正是第四章"为什么需要位置"要讲的主题。现在先记住这个结论，它是理解 Transformer 为什么需要位置编码的钥匙。

二、可运行代码示例#

下面实现一个最朴素的自注意力（Q=K=V=x，还没加可学习投影），观察注意力矩阵的形状与性质。

import torch
import torch.nn.functional as F

torch.manual_seed(0)

# 一个 4 词句子，每个词 6 维向量（真实模型里来自嵌入层，这里用随机数代替）
x = torch.randn(4, 6)          # (序列长度, 维度)

# 自注意力：Q、K、V 都来自 x 本身
d = x.size(1)
scores = x @ x.T / (d ** 0.5)   # (4,4)：第 i 行第 j 列 = 词 i 与词 j 的相关性
weights = F.softmax(scores, dim=-1)   # 每行归一化成一个"关注分布"
out = weights @ x               # 每个词的新表示 = 全体词的加权和

print("注意力矩阵（每行和为 1）:")
print(weights)
print("每行之和:", weights.sum(dim=-1))   # 应为 1.0
print("输出形状:", out.shape)            # (4,6)，与输入一致

# 第 0 个词"看"其它词的权重
print("第 0 个词对其它词的关注:", weights[0])

# 验证置换不变性：把句子顺序打乱，输出只是按新顺序排列
idx = torch.tensor([2, 0, 3, 1])
x_perm = x[idx]
out_perm = F.softmax(x_perm @ x_perm.T / (d ** 0.5), dim=-1) @ x_perm
print("打乱后输出与按新顺序排列一致:", torch.allclose(out_perm, out[idx], atol=1e-6))

运行后注意：

  • 注意力矩阵是 4×4，每一行都是一个概率分布，代表"第 i 个词把注意力分配给了哪些词"；
  • out 与输入 x 形状相同（4×6），但每一行已经是全句信息的融合结果；
  • 最后一行验证了置换不变性：把输入按 [2,0,3,1] 重排，输出只是原来输出按同样顺序重排，内容不变。这印证了"自注意力感知不到位置"的结论。

三、练习#

  1. 把 x 改成 10×6（10 个词），重新运行，观察注意力矩阵变成 10×10；挑一个词打印它权重最大的前三个位置，看看它最"关注"谁。
  2. 构造一个"重复词"的句子（比如让 x[0] 和 x[2] 完全相同），观察注意力矩阵第 0 行和第 2 行是否相同，解释为什么（自注意力只看内容不看位置）。
  3. 把 softmax 的 dim 从 -1 改成 0，看看每列之和变成什么、每行还是否为 1，从而理解"对行归一化"（每个查询对自己的关注分布）的含义。
  4. 思考：RNN 里信息从位置 1 传到位置 10 要走 9 步，而自注意力里这两者之间的"路径长度"是多少？这个差异为什么让 Transformer 能更好地处理长序列？
