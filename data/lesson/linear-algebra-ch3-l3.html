高斯消元求解实践#

这是本章、也是本课程第一阶段（向量 → 矩阵 → 方程组）的收官课。我们把高斯消元升级成一个更健壮、能处理边界情况的完整实现，并把它应用到真实任务上：用最小二乘拟合一条直线。到这里，你会看到前面所有知识（向量、矩阵乘法、转置、逆矩阵、消元）是如何串成一条完整的链的。

一、概念讲解#

1. 为什么需要"健壮"的消元#

上一课的实现能解"方阵、唯一解"的方程，但现实会抛出各种难题：

  • 主元为 0 或接近 0：直接除以它会得到无穷大或巨大误差，所以要"选主元"（部分主元法，pivoting）；
  • 方程组无解或有无穷多解：阶梯形最后会出现"全 0 行"，需要能识别并给出提示，而不是崩溃；
  • 样本数远大于特征数：这时 A 不是方阵，Ax = b 通常无精确解，只能求最小二乘近似解。

2. 部分主元法（partial pivoting）#

每一列消元前，先找出该列绝对值最大的元素，把那一行交换到当前行，再以此为基准去消下面的行。为什么选最大的？

  • 除数越大，factor = M[row,col]/M[col,col] 的绝对值越小，计算越稳定；
  • 除以一个接近 0 的小数会把浮点误差放大成千上万倍，选大主元能显著减少这种误差。

3. 从"解方程"到"最小二乘"#

当 A 是 m×n（m 条样本，n 个特征，且 m > n）时，正规方程是：

Aᵀ A x = Aᵀ b

注意 Aᵀ A 是一个 n×n 的方阵。我们只要求解这个新的方阵方程组，就得到了最小二乘解。因此，高斯消元 + 正规方程 = 最小二乘求解器。这就是线性回归拟合直线/曲线的完整数学原理。

二、可运行示例#

下面实现一个完整的最小二乘线性回归求解器，分两步：① 构造正规方程；② 用带主元选择的高斯消元求解。

import numpy as np

def solve_linear(A, b):
    """用带部分主元的高斯消元解 Ax = b，返回解向量 x。"""
    A = A.astype(float)
    b = b.astype(float)
    n = A.shape[0]
    # 增广矩阵
    M = np.column_stack([A, b])

    # 前向消元
    for col in range(n):
        # 部分主元法：选绝对值最大的行交换上来
        pivot = col + np.argmax(np.abs(M[col:, col]))
        if abs(M[pivot, col]) < 1e-12:
            raise ValueError("矩阵不可逆，无法求唯一解")
        M[[col, pivot]] = M[[pivot, col]]
        for row in range(col + 1, n):
            factor = M[row, col] / M[col, col]
            M[row, col:] -= factor * M[col, col:]

    # 回代
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (M[i, -1] - np.dot(M[i, i + 1:n], x[i + 1:n])) / M[i, i]
    return x


def least_squares(X, y):
    """用正规方程 + 高斯消元求最小二乘解。X: m×n，y: m。"""
    # 正规方程：Xᵀ X w = Xᵀ y
    A = X.T @ X            # n×n 方阵
    b = X.T @ y            # n 维向量
    return solve_linear(A, b)


# ---- 实验：拟合直线 y = 3x + 5，但加入随机噪声 ----
np.random.seed(0)
m = 50                                  # 50 条样本
x_true = np.linspace(0, 10, m)          # 自变量
y_true = 3 * x_true + 5                 # 真实关系
noise = np.random.normal(0, 2, m)       # 高斯噪声
y_obs = y_true + noise                  # 带噪声的观测值

# 构建设计矩阵：第一列是 1（截距），第二列是 x（斜率）
X = np.column_stack([np.ones(m), x_true])

w = least_squares(X, y_obs)
print("拟合得到的权重 w =", w)          # 应接近 [5, 3]（截距≈5，斜率≈3）

# 与 NumPy 官方最小二乘对比
w_ref = np.linalg.lstsq(X, y_obs, rcond=None)[0]
print("NumPy lstsq 结果  =", w_ref)

# 预测并简单评估
y_pred = X @ w
mse = np.mean((y_pred - y_obs) ** 2)
print("均方误差 MSE =", round(mse, 3))

预期输出（大意，数值因随机种子固定而可复现）：

拟合得到的权重 w = [5.07639286 2.99685139]
NumPy lstsq 结果  = [5.07639286 2.99685139]
均方误差 MSE = 3.012

要点：我们手写的 least_squares 结果和 NumPy 官方 lstsq 几乎一致，说明"正规方程 + 高斯消元"确实是正确的最小二乘实现；截距 5.08、斜率 2.997 都贴近真实值 5 和 3，误差来自我们故意加入的噪声。

三、练习#

  1. 运行示例，把噪声的标准差从 2 改大到 10，再改小到 0.1，观察拟合权重和 MSE 如何变化，解释原因。
  2. 改用"二次曲线"（在 X 中加一列 x²）做拟合，观察是否能逼近一条抛物线，并说说这和多项式回归的关系。
  3. 把 solve_linear 里的"部分主元法"删掉（固定用当前行做主元），构造一个第 1 个主元为 0 的方程组，观察会发生什么。
  4. 总结：用一段话写出"向量 → 矩阵乘法 → 转置/逆 → 线性方程组 → 高斯消元"这条知识链，以及它如何一步步支撑起一个线性回归模型。
