DQN#

把上一课的"线性函数逼近"换成神经网络，就是深度 Q 网络（Deep Q-Network，DQN，DeepMind 2015 首次用它在 Atari 游戏上达到人类水平）。但把 Q-learning 直接塞进深度网络会不稳定甚至发散——死三角里的三个条件它全占了。DQN 的两大杀手锏经验回放与目标网络正是为此而生。本课讲清这两招"为什么管用"，并给出可跑的完整实现。

一、概念讲解#

1. 从线性到深度：用网络输出 Q#

线性逼近 Q̂(s,a) = θᵀφ(s,a) 的表达力受制于人工特征 φ。DQN 用一个神经网络 Q(s, ·; θ) 直接吃进原始观测（或简单特征），输出每个动作的 Q 值——一个输入、|A| 个输出，于是"选动作"就是 argmax，max_a' Q(s',a'; θ) 就是输出向量的最大值，天然契合 Q-learning 的更新式。

2. 为什么不稳定：三个互相关联的病根#

直接把深度网络接上 Q-learning，会同时踩中几个坑：

  1. 样本强相关：轨迹里相邻时刻的状态高度相关，而神经网络训练（SGD）默认"样本独立同分布"。相关样本会让梯度一路"抱团"、震荡。
  2. 数据浪费：在线 RL 的每条转移用一次就扔，样本效率极低。
  3. 目标在动：Q-learning 的目标 r + γ max Q(s',a'; θ) 里也带着 θ。网络一边追目标、目标一边被自己改，"追自己尾巴"，极易发散。

3. 杀手锏一：经验回放（experience replay）#

把每次交互的转移 (s, a, r, s', done) 存进一个回放缓冲区（replay buffer）；训练时随机抽一小批（minibatch）来更新。这一招同时治两病：

  • 打破相关性：随机抽样把"时间上相邻"变成"独立同分布"的近似，SGD 的假设重新成立；
  • 提高利用率：每条转移被反复抽取使用多次，数据效率成倍提升。

4. 杀手锏二：目标网络（target network）#

把"用于计算目标的网络"和"正在被训练的网络"拆成两个：一个 Q 网络（参数 θ，负责产生当前估计、被梯度更新），一个 目标网络（参数 θ⁻，只负责算目标、不参与反向传播）。损失函数：

L(θ) = E_{replay} [ ( r + γ max_{a'} Q(s', a'; θ⁻) - Q(s, a; θ) )² ]

θ⁻ 每隔若干回合才从 θ 硬拷贝一次（其余时间冻结）。冻结期间目标近似不变，回归目标"稳住了"，Q-learning 就从"追移动靶"变成了"打固定靶"，大幅缓解发散。这其实是对死三角里"自举 + off-policy + 函数逼近"组合的直接对冲：用半静态目标换取稳定。

5. 完整流程与后续#

DQN 的训练循环 = ε-greedy 采集 + 回放抽样 + 用目标网络算 TD 目标 + 梯度下降 + 周期同步 θ⁻ → θ。它让深度网络 + Q-learning 第一次真正稳定，成为深度 RL 的里程碑。它的后继（Double DQN 修 max 的过估计、Dueling DQN 拆分 V 与优势、Rainbow 集大成、以及把"选动作"与"评估"解耦的 actor-critic 家族）都在它的骨架上发展，后面章节会逐步遇到。

二、可运行代码示例#

自包含的 CartPole 环境 + PyTorch 最小 DQN（含经验回放与目标网络）。

import random
from collections import deque
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F

# ---- 自包含 CartPole 环境（离散动作，简化倒立摆物理） ----
GRAVITY, MASS_CART, MASS_POLE = 9.8, 1.0, 0.1
LENGTH, FORCE, DT = 0.5, 10.0, 0.02

class CartPole:
    def reset(self):
        # 状态 = [小车位置 x, 速度 x_dot, 摆角 theta, 角速度 theta_dot]
        self.state = np.array([0.0, 0.0, 0.05 * (np.random.rand() - 0.5), 0.0])
        return self.state.copy()

    def step(self, action):
        x, x_dot, theta, theta_dot = self.state
        force = FORCE if action == 1 else -FORCE       # 0 左推 / 1 右推
        total = MASS_CART + MASS_POLE
        cos_t, sin_t = np.cos(theta), np.sin(theta)
        # 经典倒立摆动力学，做一次欧拉积分
        temp = (force + MASS_POLE * LENGTH * theta_dot**2 * sin_t) / total
        theta_acc = (GRAVITY * sin_t - cos_t * temp) / (LENGTH * (4/3 - MASS_POLE * cos_t**2 / total))
        x_acc = temp - MASS_POLE * LENGTH * theta_acc * cos_t / total
        x, x_dot = x + DT * x_dot, x_dot + DT * x_acc
        theta, theta_dot = theta + DT * theta_dot, theta_dot + DT * theta_acc
        self.state = np.array([x, x_dot, theta, theta_dot])
        done = abs(x) > 2.4 or abs(theta) > 0.2095       # 出界或倒杆
        return self.state.copy(), 1.0, done

# ---- Q 网络：输入状态，输出每个动作的 Q 值 ----
class QNet(nn.Module):
    def __init__(self, obs_dim, n_actions):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, 64), nn.ReLU(),
            nn.Linear(64, 64), nn.ReLU(),
            nn.Linear(64, n_actions),
        )
    def forward(self, x):
        return self.net(x)

# ---- 经验回放缓冲区 ----
class ReplayBuffer:
    def __init__(self, capacity=10000):
        self.buf = deque(maxlen=capacity)
    def push(self, s, a, r, sn, d):
        self.buf.append((s, a, r, sn, d))
    def sample(self, batch):
        idx = random.sample(range(len(self.buf)), batch)
        s, a, r, sn, d = zip(*[self.buf[i] for i in idx])
        return (torch.tensor(np.array(s), dtype=torch.float32),
                torch.tensor(a, dtype=torch.long),
                torch.tensor(r, dtype=torch.float32),
                torch.tensor(np.array(sn), dtype=torch.float32),
                torch.tensor(d, dtype=torch.float32))
    def __len__(self):
        return len(self.buf)

# ---- 训练 DQN ----
env, n_actions = CartPole(), 2
q_net, target_net = QNet(4, n_actions), QNet(4, n_actions)
target_net.load_state_dict(q_net.state_dict())     # 初始同步目标网络
opt = torch.optim.Adam(q_net.parameters(), lr=1e-3)
replay = ReplayBuffer()

GAMMA, BATCH, SYNC_EVERY = 0.99, 64, 20
EPS, EPS_MIN, EPS_DECAY = 1.0, 0.01, 0.995
scores = []

for ep in range(200):
    s, total, done, steps = env.reset(), 0.0, False, 0
    while not done and steps < 500:        # 500 步上限，与 gym CartPole 一致
        # ε-greedy 选动作
        if np.random.rand() < EPS:
            a = np.random.randint(n_actions)
        else:
            a = int(torch.argmax(q_net(torch.tensor(s, dtype=torch.float32))))
        s_next, r, done = env.step(a)
        replay.push(s, a, r, s_next, done)
        s = s_next
        total += r
        steps += 1

        # 从回放缓冲区抽批更新
        if len(replay) >= BATCH:
            sb, ab, rb, snb, db = replay.sample(BATCH)
            q = q_net(sb).gather(1, ab.unsqueeze(1)).squeeze(1)   # Q(s,a;θ)
            with torch.no_grad():
                q_next = target_net(snb).max(1)[0]                # max_a Q(s',a;θ⁻)
                target = rb + GAMMA * q_next * (1 - db)           # 终止态无后继
            loss = F.mse_loss(q, target)
            opt.zero_grad(); loss.backward(); opt.step()

    EPS = max(EPS_MIN, EPS * EPS_DECAY)
    if ep % SYNC_EVERY == 0:
        target_net.load_state_dict(q_net.state_dict())           # 周期同步 θ⁻ ← θ
    scores.append(total)
    if (ep + 1) % 20 == 0:
        print("回合 {:3d}  近20回合平均得分 {:.1f}".format(ep + 1, np.mean(scores[-20:])))

print("训练完成，最后一回合得分：{:.0f}".format(scores[-1]))

要点：target_net 用 torch.no_grad() 出目标、不反向传播，靠 SYNC_EVERY 周期硬拷贝；(1 - db) 把终止态的后继价值清零，等价于"终止后 max Q = 0"。运行后近 20 回合平均得分应稳步爬升（CartPole 满分为 500）。

三、练习#

  1. 删掉目标网络，把目标直接改成 q_net(snb).max(1)[0]（自举自身），观察得分是否震荡或发散；体会"追自己尾巴"。
  2. 把回放缓冲区容量从 10000 减到 256，或把 BATCH 从 64 改成 8，对比稳定性与样本效率。
  3. 把 SYNC_EVERY 改成 5、200，观察"同步太频繁"与"同步太稀疏"各自的坏处。
  4. 思考题：经验回放打破了时序相关性，但也让训练变成 off-policy（缓冲区里混着旧策略的数据）。为什么说这正是"死三角"的组合之一，而目标网络是对它的对冲？
