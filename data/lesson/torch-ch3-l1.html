nn.Module#

前两章我们搞懂了张量与自动微分。但从零手写每个前向、每个 backward()、每个参数更新，很快就会变成灾难。torch.nn 就是来收拾这一切的，而它的地基是 nn.Module——所有网络层、所有模型，乃至整个损失函数，都继承自它。本课讲清 nn.Module 的三个职责：组织参数、定义前向、递归管理子模块。

一、概念讲解#

1. nn.Module 是什么#

nn.Module 是所有神经网络组件的基类。你写的模型是它，nn.Linear、nn.Conv2d 也是它。继承它并做两件事，就是一个合法模型：

  1. 在 __init__ 里用 super().__init__() 初始化，然后把子层注册为属性；
  2. 实现 forward(self, x)，定义数据如何流过这些子层。

只要把子层赋值给 self.xxx，nn.Module 就能自动"感知"它们：收集它们的参数、递归管理它们的状态（如训练/评估模式）、把它们一起搬上 GPU。

2. 关键机制：自动参数收集#

nn.Module 会递归扫描所有子模块，把所有 nn.Parameter（第 3 课详述）汇总起来。于是：

  • model.parameters()：返回全部可学习参数（给优化器用）；
  • model.named_parameters()：带名字的参数（调试、精细控制用）；
  • model.state_dict()：参数名 → 张量的字典（保存/加载模型用）。

这省掉了"手动维护一张参数表"的繁重劳动——你只管定义结构，参数管理由框架接管。图 3-1 展示了一个模块树如何被递归汇总。

3. 调用 model(x) 到底发生了什么#

model(x) 会触发 __call__，而 nn.Module.__call__ 内部做了若干统一的前后处理（例如钩子），再调用你写的 forward。所以：

  • 请实现 forward，而不是 __call__；
  • 调用时用 model(x)，不要直接 model.forward(x)（会绕过框架的后处理逻辑）。

4. 为什么不用 nn.Sequential 时也要继承 nn.Module#

nn.Sequential 只是 nn.Module 的一个便捷子类，适合"一条直线"的简单堆叠。一旦模型有分支、跳跃连接、共享权重或自定义逻辑，就必须继承 nn.Module 手写 forward。继承 nn.Module 是通用解，Sequential 是它的特例。

二、可运行代码示例#

import torch
import torch.nn as nn

# ---- 1. 自定义一个两层 MLP ----
class Net(nn.Module):
    def __init__(self, in_dim, hidden, out_dim):
        super().__init__()                  # 必须调用父类初始化
        self.fc1 = nn.Linear(in_dim, hidden)   # 子层注册为属性
        self.fc2 = nn.Linear(hidden, out_dim)
        self.act = nn.ReLU()

    def forward(self, x):                   # 只定义前向，反向由 autograd 处理
        x = self.fc1(x)
        x = self.act(x)
        x = self.fc2(x)
        return x

net = Net(in_dim=4, hidden=8, out_dim=1)
print(net)                                  # 打印出模块树结构
print("参数总数:", sum(p.numel() for p in net.parameters()))

# ---- 2. 前向调用：直接 net(x)，不要 net.forward(x) ----
x = torch.randn(2, 4)                       # 2 个样本，4 维特征
out = net(x)
print("\n输出形状:", out.shape)             # torch.Size([2, 1])

# ---- 3. 参数汇总 ----
print("\nnamed_parameters:")
for name, p in net.named_parameters():
    print("  ", name, p.shape)

# ---- 4. 训练/评估模式切换 ----
net.train()                                 # 训练模式（Dropout、BN 生效）
net.eval()                                  # 评估模式（Dropout、BN 行为改变）

# ---- 5. Sequential：直线堆叠的快捷方式 ----
seq = nn.Sequential(
    nn.Linear(4, 8),
    nn.ReLU(),
    nn.Linear(8, 1),
)
print("\nSequential 输出形状:", seq(x).shape)   # torch.Size([2, 1])

运行要点：print(net) 会列出 Net 内部的两个 Linear 和一个 ReLU；sum(p.numel() for p in net.parameters()) 应等于 4*8+8 + 8*1+1 = 49。
