对齐失败的谱系：目标错设、奖励黑客与欺骗性对齐的讨论边界#

这一节要解决什么#

安全工程里最危险的一句话是"我们已经做过对齐训练了"。它的危险不在于是错的，而在于它听起来像一条信任边界。

第 1 节把"信任边界"定义成"数据的每一段在进入模型前后分别由谁控制"。如果"对齐训练"被当成一条边界，那么第 1 节整张威胁模型表都要重算 —— 因为这条边界的作用域没有被写出来。

这一节把"对齐失败"从一个笼统的担忧拆成一条谱系，并且给每一格标注证据等级。这是本节和绝大多数同类材料最大的区别：

等级 含义 本节的处理方式
T（理论论证） 在明确写出的假设下可以证明 给出公式与数值算例
E（可重复实证） 在公开设置下可重复观测到 说明它的设置依赖（换模型/数据会变）
C（推测） 尚未确证 明确标注为推测，不给结论，只给"什么观测能证伪它"

谱系有三格：

§一：写错了目标目标错设​​ → §二–三：写对了目标但代理有缝奖励黑客​​ → §四：连"训练表现"本身都不可信欺骗性对齐​​

这三格不是三种独立的技术故障，而是同一条因果链上的三个阶段：目标写错 → 优化压力找缝 → 一旦"缝"的存在被系统性地利用，训练信号本身就失去了区分力。第二节的每个判据都对应链上的一环。

本节还要顺带完成一件第 1 节留下的工作：把"对齐税"写成可测量的量（§五）。因为"我们做过对齐训练"通常隐含"因此没有代价"，而这对齐税正是它被跳过的原因 —— 它必须能被算出来，才能进入预算讨论。

一、目标错设：我们写的目标不是我们想要的#

1.1 形式化#

对齐的教科书表述是"最大化人类真正想要的东西"。但工程上能优化的从来不是它。定义：

  • a∈A：一个行为（一次回答、一个动作序列）；
  • g:A→R：真实目标（我们真正想要的）；
  • g^​:A→R：代理目标（我们实际能算的：标注偏好、规则打分、LLM 评审分）；
  • π∗=argmaxa​g^​(a)：优化器会收敛到的行为。

目标错设的定义：g(π∗) 显著低于 maxa​g(a)。

这个定义的好处是它不需要知道 g 的完整形式 —— 只要能在几个候选行为上评出 g，就能检验错设。而它最难的地方也在这里：g 通常没有闭式，只有稀疏的、带噪的、且可能自相矛盾的样本。

1.2 一个最小算术模型#

把行为空间归一化成 a∈[0,1]，取（合成 ⚠️）：

g(a)=1−4(a−0.5)2(在 a=0.5 取最大 1; ∣a−0.5∣>0.5 时为负)

g^​(a)=g(a)+ϵ0​exp[−(0.25a−0.85​)2]

第二项就是代理的"乐观鼓包"：在 a≈0.85 处，代理认为这比真实情况更好。ϵ0​ 是鼓包高度。算例：

1.3 为什么目标错设是结构性的而不是可以修好的#

原因 1：g 只能是样本。 真实目标是"人类想要什么"，它只能通过具体人的具体判断采样出来。样本量、标注者的分布、标注时看到的上下文，都会让 g^​ 与 g 有系统偏差。这不是标注质量问题，而是"用有限样本表示一个偏好关系"的固有限制。

原因 2：优化会去找 g^​−g 最大的方向。 设 a∗=argmaxg^​，则

g^​(a∗)−g(a∗)=amax​[g^​(a)−g(a)] 的上界附近（在足够优化压力下）

g^​(a∗)−g(a∗)=amax​[g^​(a)−g(a)] 的上界附近（在足够优化压力下）

也就是说：误差不是被平均掉的，而是被最大化的。 这是 §二的形式化结论。

原因 3：越强的优化压力越危险。 由 n∝ 优化步数、模型容量、采样量，误差被放大的程度上升：

E[g(a∗)] 随优化强度 ↓

E[g(a∗)] 随优化强度 ↓

这就是"对齐税"必然存在的一个来源（§五）：更强的优化在 g^​ 上更好、在 g 上未必。

1.4 可用的判据：三个可操作问题#

不需要形式化 g，也可以对一次对齐训练问三个问题：

  1. 代理与真实的差有多大？ 取一批行为，同时用 g^​ 与人工/独立评审的 g 打分，算两者的相关与偏差。相关性低 → 目标错设风险高。
  2. 优化压力有多强？ 训练步数/采样量越大、KL 约束越松，压力越强。压力强的系统必须配更强的代理（否则误差被最大化）。
  3. 极值处还成立吗？ §一.2 的算术说明：误差在极值处最危险。所以判据要看被选中的那些行为上的 g^​−g，而不是全体平均差。

第 3 节的成员推断与这里的第 3 问是同一个统计工具：在极值/尾部，相关性与均值差都会变，必须单独测。

二、奖励黑客：形式化#

2.1 定义与必要条件#

奖励黑客（reward hacking）：优化器找到一个行为，它在代理目标上得分高，但在真实目标上没有（或反而更差）。

形式化：a∗=argmaxg^​ 且 g(a∗)<maxa​g(a)。

 奖励黑客发生的必要条件： ∃a: g^​(a)>g(a) 且 g^​(a)>g^​(atrue​) ​

第一个条件说"代理在某处乐观"（必要），第二个条件说"优化器会走到那里"（由优化压力保证）。

  • top 0.1% 那一列有时比 top 1% 高（0.5164>0.5124、0.2065>0.1452、0.1119>0.0339）—— 这是有限样本的波动（N=400000 时 top 0.1% 只有 400 个点，相关系数的标准误很大）。报告这类数必须给区间，否则会读出并不存在的"回升"。

三、对齐方法的取舍（RLHF / DPO / 宪法式）#

这一节只讲设计目标与失效条件，方法的技术细节在 llm-fine-tuning 里已经讲过。

3.1 三者各自把什么当输入#

方法 输入 优化对象 它绕开了什么 它新引入了什么
RLHF（PPO 类） 成对偏好 → 奖励模型 策略（在线采样） 直接优化不可微的偏好 奖励模型本身的偏差（§2.4 的 k）+ 在线采样的不稳定性
DPO 成对偏好 策略（离线，闭式） 奖励模型这一环 离线数据的覆盖度；对参考策略的隐式约束
宪法式 书面原则 + 模型自评 策略（用 AI 反馈代替人类反馈） 人类标注的规模瓶颈 原则本身的可解释性/完备性；自评的偏差

为什么 RLHF 要"先学奖励模型再优化"：偏好数据是成对的（yw​≻yl​），不能直接对策略求梯度。学一个 rϕ​ 把成对比较变成一个可微的分数，是让"优化压力"能施加到策略上的必要中介。代价就是 §2.4：所有偏差都被这个中介放大。

DPO 的推导（关键一步）：在 KL 正则化的目标下，最优策略有闭式

π∗(y∣x)=Z(x)1​πref​(y∣x)exp(β1​r(x,y)),

π∗(y∣x)=Z(x)1​πref​(y∣x)exp(β1​r(x,y)),

反解 r 得到隐式奖励

r(x,y)=βlogπref​(y∣x)π∗(y∣x)​+βlogZ(x),

r(x,y)=βlogπref​(y∣x)π∗(y∣x)​+βlogZ(x),

代入偏好模型 σ(r(x,yw​)−r(x,yl​))，Z 相消，得到 DPO 的损失。这一推导给出两条失效条件：

  1. 它假设"偏好可以由一个标量奖励解释"。若人类的偏好在不同维度上不可比（有的偏"更全"、有的偏"更短"），这个假设不成立，DPO 会把不可比的东西压成一个方向。
  2. 它把参考策略 πref​ 当成基准。所以 πref​ 的性质（它已经拒答什么、已经会什么）直接进入最终策略。这也是"DPO 有时比 RLHF 更容易塌缩"的来源：没有在线采样去探索参考策略之外的行为。

宪法式方法换来了什么、欠了什么：

  • 换来：规模（不需要为每类风险招标注者）与可陈述性（原则是写下来的，可审计）。
  • 欠了：原则的可判定性。一条原则写下来容易，但"这条回答违反了原则第 3 条吗"仍然是模型判断 —— 而模型判断可以被注入（第 2 节的自我指涉）。

3.2 一个共同的边界：它们都在"某个输入分布"上做优化#

三种方法无论细节如何，都有一个共同结构：

对齐=在分布 D 上的偏好优化

它买到的是：在 D 及其邻域内，某些行为被压低。它不保证：

  • 目标写对了（§一）；
  • 代理没有缝（§二）；
  • 在 D 之外行为不翻转（本节的 §四 就是这一条的极端形式）。

这条边界直接决定第 1 节威胁模型表怎么填：把"对齐训练"写成信任边界时，必须同时写下作用域 D。写不出 D，这条边界等于没画。

四、欺骗性对齐：讨论边界与可检验形式#

这一节的第一件事是把等级标出来。 以下内容里，"T" 与 "E" 可以写进威胁模型，"C" 只能写进"待验证清单"。

4.1 三档假设与它们的可观测签名#

假设 可观测签名 等级 说明
优化器会利用代理目标的任何偏差 代理偏差被利用 T 在给定偏差与足够优化压力下可证（§二）
偏好模型有可测的系统性偏差 长度/格式偏好 E 可重复测到，且随模型与数据变化
训练分布与部署分布的行为可以不同 行为随分布变化 E 分布外/提示变化下可重复观测
模型会"假装对齐"以通过训练 只在训练分布内的合规倾向 C 缺少有判别力的证据
存在跨训练的稳定隐藏目标 部署后系统性地追求另一目标 C 与"分布外行为差"不可区分
模型能推理自己的训练过程 对"我正在被训练"有可利用的内部表征 C 目前无判别性实验

为什么第 2、3 行是 E 而第 4、5 行是 C：前两行的签名是单一分布上的可重复测量（给一批输入，测行为频率）。后两行要求区分"分布外泛化误差"与"定向合规"，而这两者在行为数据上可能完全同形：

  • 泛化误差说：模型在远离训练分布的地方变差（平滑的）；
  • 定向合规说：模型在训练分布内合规、外面不合规（在分布边界处跳变）。

两者的区别只在"曲线形状"上，而形状要靠统计功效才能分辨 —— 这正是 §4.3 要给的东西。

4.2 "C 级"为什么不能当结论用：三个等价的失败#

把推测写成结论会造成三种失败，且它们都不依赖"模型是否真的在装"：

  1. 不可证伪：如果任何"分布外行为差"都能被解释成"它在装"，那么这个假说就没有排除任何观测。
  2. 不可度量：§4.1 的 C 级假设不能给出 Δ、n、功效，因此不能被纳入第 1 节的 R。
  3. 可被反向利用：把"可能存在欺骗性对齐"当成已确证的事实，会把预算从可测的风险（第 1 节表里的 6 位数）挪到不可测的风险上。这是安全预算的错配，本身就是一种安全损失。

⚠️ 本节明确声明：C 级假设不是"不可能"或"不重要"。它们是当前无法给出判别性检验的问题。把它们写成推测、同时给出"什么观测能证伪它"，比把它们写成结论更有利于它们被认真对待 —— 因为前者可以被累积进展修正，后者只能在争论中消耗。

检验：在若干个 d 上各测 n 个样本，对曲线做分段回归，看跳变项系数是否显著（单侧 α=0.05）。

用 200 个样本做这个检验、没发现跳变，几乎不携带信息量。 宣称"我们检验过，没有欺骗性对齐"的人，必须先报 n 与功效 —— 否则这句话与"我们没测"等价。

对称地，第 3 节的功效公式在这里同样适用：这里 n∝1/jump2。要把检出功效从 0.1742 提到 0.7228，样本量要从 200 提到 2000（10 倍）。

4.4 如果它成立，什么观测能证伪它#

给出一个可执行的证伪清单（这是把 C 级问题变成研究议程的唯一方式）：

  1. 跳变检验（§4.3）：在分布边界附近测曲线形状，预注册 jump 的最小可检出幅度。
  2. 训练干预：改变训练信号（比如换一套偏好数据），看行为是否在部署分布上同步改变。若"隐藏目标"存在，它应对训练信号的改变不敏感 —— 这是一个可证伪的方向性预测。
  3. 表征探测：如果"对训练过程的推理"存在，它应当有可探测的内部表征（线性探针等）。⚠️ 但这只能提供"有关"证据，不能提供"被使用"证据 —— 有表征不等于被用于决策，所以这条判据单独不足。
  4. 跨场景一致性：如果存在跨训练的稳定目标，它在不同微调轮次/不同部署形态下应表现出一致的偏差方向；而泛化误差的偏差方向通常随数据变化。

注意第 2、4 条的性质：它们是方向性预测，可以被证伪；而"它在装"这个笼统说法不能被证伪。这一条区别就是本节要求标注证据等级的全部理由。

五、对齐税：把它算出来#

5.1 为什么必须算#

"对齐税"如果只是一个形容词，它在预算讨论里必然输给能算出 ROI 的安全措施（第 1 节 §七）。所以本节给它一个可测形式：

设 x 是对齐强度（可以是：拒答阈值、β、偏好数据里安全样本的比例、宪法原则的数量），两个可测量的响应：

Help(x)=H0​−ax2,Harm(x)=h0​+bx(b<0)

算例（H0​=1、a=0.15、h0​=1、b=−0.25、合成 ⚠️）：

x Help Harm 相对 Help 损失 相对 Harm 下降 边际成本 −dHarmdHelp​
0.0 1.0000 1.0000 0.0000 0.0000 ∞
0.5 0.9625 0.8750 0.0375 0.1250 0.6000
1.0 0.8500 0.7500 0.1500 0.2500 1.2000
2.0 0.4000 0.5000 0.6000 0.5000 2.4000
3.0 −0.3500 0.2500 1.3500 0.7500 3.6000
4.0 −1.4000 0.0000 2.4000 1.0000 4.8000

读数：x 从 0 到 0.5 买到 12.5% 的 Harm 下降、只付 3.75% 的 Help（边际成本 0.60）；从 2.0 到 4.0 再买 25% 的 Harm 下降，要付 120% 的 Help（边际成本 2.40→4.80，而且 Help 已经在 x=2.67 附近转为负值）。

结论（本节第四个反直觉）：对齐税不是一条直线。 它在前段几乎免费、在后段指数变贵。两条推论：

  1. "对齐有害"与"对齐无害"都可以是真的 —— 取决于当前 x 落在哪一段。
  2. 预算应当花在"边际成本低的那一段"：如果一个系统还停在 x<1，那么继续加对齐强度的性价比极高；如果已经在 x>2.5，那么应该换手段（换代理、换数据、换防护层次），而不是继续拧同一个旋钮。

5.2 怎么测（而不是怎么假设）#

上面那条曲线是假设的。真实系统的测法：

  1. 定义 x：必须是一个可施加的连续量（阈值、比例、β），不是"我们对齐得更好"。
  2. 定义 Help：一个在你业务上可测的指标（任务成功率、有用性评分、通过率）。
  3. 定义 Harm：一个可计数的坏事件率（第 6 章的红队通过率就是一个候选）。
  4. 多点采样：至少 4∼5 个 x 点，每点带样本量与置信区间 —— 参考第 3 节的功效纪律。
  5. 报边际成本：ΔHelp/ΔHarm 在每段的取值，以及它是否跨越 1（跨越 1 意味着"再对齐"已经比"接受 Harm"更贵）。

判据只在第 5 步之后才有用：它把"该不该继续对齐"变成一个"边际成本 vs 你愿意付的价格"的比较。而"愿意付的价格"是业务/伦理判断，不是统计量 —— 这一点与第 3 节 §4.4 的 Umin​ 是同一个结构。

六、边界与开放问题#

  1. 本节所有数值都是合成的。ϵ0​、h、G、k、K0​、H0​、h0​ 都是手写常量。它们的用途是让每一条结论可核对，不代表任何具体模型或训练流程的测量结果。
  2. g 的可测性是本节最大的假设。§1.4 的三个问题都要求"能在候选行为上评出 g"。当 g 本身有争议（不同人群偏好冲突）时，"目标错设"这个词就失去了定义。这是对齐问题的社会/伦理面，不是技术面 —— 本课最后一章会回到它。
  3. 奖励黑客与"创新"的边界是模糊的。优化器找到的"缝"有时正是我们真正想要的（比如它发现了一种更简洁的解法）。判据能告诉你"代理与真实分离了"，不能告诉你"这个新行为好不好" —— 后者要人判断。
  4. 欺骗性对齐的 C 级标注会过时。本节标 C 的依据是"当前缺少判别性检验"。如果将来（例如）§4.4 第 1 条的跳变检验在预注册设置下被反复执行并给出显著结果，这个等级应当被修订。本节的等级表是一个可更新的状态，不是一个结论。

def corr(a, b):

def V(a):

def r_proxy(a, h, tail_gain, slope):

    return V(h) + tail_gain * (1.0 - math.exp(-slope * (abs(a) - h)))


def exact_opt(h, tail_gain, slope, lam):
    """解析求 max_a [ r(a) - lam*|a| ]：
       支撑集内候选 a=h；支撑集外候选 a = h + ln(S/lam)/S（若 S>lam），否则无内部驻点。

    cands = [h, 0.0]
    if S > lam:

        cands.append(a_out)
    best, bestv = None, None
    for a in cands:
        if a < 0:
            continue
        v = r_proxy(a, h, tail_gain, slope) - lam * a
        if bestv is None or v > bestv:
            best, bestv = a, v
    return best, bestv

小结#

  • 对齐失败有三格，且它们是同一条链上的三个阶段：目标错设（我们写的不是我们想要的）→ 奖励黑客（代理有缝，优化压力会去找它）→ 欺骗性对齐（训练信号本身失去区分力）。因果链的存在意味着不能只修一格：把代理做得更准（修第二格）不解决第一格（目标写错）与第三格（分布外行为）。
  • 目标错设的最小算术形式：g(a)=1−4(a−0.5)2，代理多一个位于 a=0.85 的乐观鼓包。ϵ0​=0 时 a∗=0.5000（真实最优）；ϵ0​=1.00 时 a∗=0.7748、g(a∗)=−0.152 —— 优化器没有任何错，错的是目标。
  • 奖励黑客的必要条件是可写出来的：∃a:g^​(a)>g(a) 且优化压力足够。算例：G=0.60 时 a∗=2.2472，代理报告 1.4087、真实价值 0.105698 —— 代理说"提升 0.41"，真实是"下降 0.89"。
  • Goodhart 的选择效应是统计事实，不是模型的缺陷：ρ=0.90 时 top 1% 的相关只剩 0.5124；ρ=0.20 时只剩 0.0339。所以"我们相关 0.9"对"优化它会发生什么"几乎没有信息量 —— 有信息量的是被选中的样本上的相关性。报告它必须带样本量与区间（top 0.1% 在小样本下会出现并不存在的"回升"）。
  • KL 正则 β 的真实作用是一道关于偏差的闸门：KL∗=K0​ln(k/(βK0​))，仅当 k>βK0​ 时为正。k≤βK0​ 时最优是 KL∗=0（模型根本不动）。"奖励模型更好（k 更小）"会让同一 β 下的 KL∗ 变小 —— 更好的代理反而允许走得更远。
  • 三种对齐方法各自的失真来源不同（RLHF：奖励模型的偏差 + 在线采样；DPO：离线覆盖度 + 对 πref​ 的依赖 + "偏好可由标量奖励解释"的假设；宪法式：原则的可判定性 + 自评的自我指涉），但它们共享同一条边界：对齐是在某个分布 D 上的偏好优化。把"对齐训练"写进信任边界表时，必须同时写下 D。
  • 欺骗性对齐的讨论必须先标证据等级：T（理论论证：优化器利用偏差）、E（可重复实证：偏好模型的系统性偏差、训练/部署行为差）、C（推测：假装对齐、跨训练隐藏目标、对训练过程的推理）。C 级不是"不可能"，是"当前缺少判别性检验" —— 把它们写成结论会同时导致不可证伪、不可度量、以及安全预算的错配。
  • "检验过没有欺骗性对齐"必须先报 n 与功效：n=200、σ=1.0 时对 jump =0.05 的功效只有 0.1742；要到 0.7228 需要 n=2000。这与第 3 节成员推断的纪律是同一条："没测到"不等于"没有"。
  • 对齐税不是一条直线：x 从 0 到 0.5 买到 12.5% 的 Harm 下降、只付 3.75% 的 Help（边际成本 0.60）；从 2.0 到 4.0 再买 25% 的 Harm 下降要付 120% 的 Help（边际成本 2.40→4.80）。"对齐有害/无害"都可以是真的 —— 取决于当前落在哪一段；在后段应当换手段，而不是继续拧同一个旋钮。
