实现#

理解了贝叶斯公式与"朴素"假设后，本课落到 scikit-learn 的实现。朴素贝叶斯的"朴素"只决定了"特征独立"这一步，但特征本身是什么分布还要单独假设——据此 scikit-learn 提供了几个不同的变体，各有所长。

一、概念讲解#

1. 三个常用变体#

类名 特征假设 适用数据 关键参数
GaussianNB 每个特征在各类下服从高斯分布 连续特征（身高、温度、图像像素均值） var_smoothing
MultinomialNB 特征为计数（如词频） 文本分类、词频向量 alpha
BernoulliNB 特征为二值（出现/不出现） 只关心"是否出现"的文本 alpha、binarize

另有 ComplementNB（MultinomialNB 的改进版，处理类别不平衡更稳）和 CategoricalNB（类别型特征）。日常最常用的就是 GaussianNB 与 MultinomialNB 两个。

2. GaussianNB：给连续特征套高斯#

它假设在每一类内部，每个特征都近似服从一个正态分布，训练时对每个"类别 × 特征"估计一组均值和方差，预测时把新样本代入对应的高斯概率密度，再按朴素贝叶斯连乘。var_smoothing 是加在方差上的一个小量，防止方差为 0 导致除零。

3. MultinomialNB：给计数特征套多项分布#

文本常被表示成"每个词出现多少次"的计数向量。MultinomialNB 假设这些计数服从多项分布，训练时统计"每个词在各类里出现的总次数"，配合拉普拉斯平滑（alpha）估计条件概率。它极其适合高维稀疏的词频矩阵。

4. BernoulliNB：只关心"出现与否"#

有时我们只想知道某个词"有没有出现"，不在乎次数。BernoulliNB 把特征二值化后处理，适合特征本身就是 0/1 的场景（如"是否包含某关键词"）。

5. 为什么朴素贝叶斯又快又省#

它没有迭代优化过程，训练只需一遍计数统计，复杂度随样本量线性增长；预测也是若干次查表和连乘。相比随机森林、SVM、梯度提升，它训练极快、内存占用小，还天然输出概率，非常适合做快速基线和在线学习。

二、可运行代码示例#

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB, MultinomialNB, BernoulliNB
import numpy as np

# 1. 连续特征数据：用高斯朴素贝叶斯
X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

gnb = GaussianNB()
gnb.fit(X_train, y_train)
print("GaussianNB 测试准确率：{:.3f}".format(gnb.score(X_test, y_test)))
print("各类先验概率 class_prior_：", np.round(gnb.class_prior_, 3))

# 2. 计数特征数据：手工构造一个小的词频矩阵（3 条文本 × 4 个词）
#    词依次为 [机器学习, 天气, 电影, 股票]
X_count = np.array([
    [2, 0, 0, 1],   # 文本 1
    [0, 1, 1, 0],   # 文本 2
    [1, 0, 0, 2],   # 文本 3
    [0, 0, 2, 0],   # 文本 4
])
y_count = np.array([0, 1, 0, 1])  # 两类主题

mnb = MultinomialNB(alpha=1.0)  # alpha 即拉普拉斯平滑系数
mnb.fit(X_count, y_count)
print("\nMultinomialNB 对词频矩阵的预测：", mnb.predict(X_count))

# 3. 观察 alpha（平滑强度）对训练分数的影响
for alpha in [0.01, 1.0, 10.0]:
    m = MultinomialNB(alpha=alpha)
    m.fit(X_count, y_count)
    print("alpha={:<6} 训练准确率：{:.3f}".format(
        alpha, m.score(X_count, y_count)))

# 4. 二值特征：BernoulliNB 只关心"出现与否"
X_bin = (X_count > 0).astype(int)  # 把计数转成 0/1
bnb = BernoulliNB()
bnb.fit(X_bin, y_count)
print("\nBernoulliNB 对二值化特征的预测：", bnb.predict(X_bin))

要点：GaussianNB 处理连续特征直接可用；MultinomialNB 面向词频这类计数；BernoulliNB 面向 0/1 特征。三者 API 一致，都是 fit → predict/predict_proba，切换成本极低。

三、练习#

  2. 把上面 X_count 词频矩阵整体乘以 10（保持比例不变），观察 MultinomialNB 的预测是否改变；再讨论：朴素贝叶斯对"计数缩放"敏不敏感？
  3. 给 MultinomialNB 设置 class_prior（如 [0.8, 0.2]），预测结果会发生什么变化？这体现了先验概率的什么作用？
  4. 思考题：为什么 GaussianNB 不适合直接用于高维稀疏的词频矩阵？（提示：高斯分布假设与"大量零值"的数据形态是否匹配。）
