优化器#

上一课定义了损失函数，反向传播算出了梯度。最后一步是：沿着梯度的反方向，把参数更新掉。这个"怎么更新"的策略，就是优化器（optimizer）。从最简单的 SGD，到带动量的 Momentum，再到如今默认首选的 Adam，优化器的演进就是一部"让训练更快、更稳"的历史。本课讲清它们各自的思想和适用场景。

一、概念讲解#

1. SGD：最朴素的梯度下降#

随机梯度下降（Stochastic Gradient Descent）每次用一小批（mini-batch）样本算出梯度 g，然后沿反方向走一小步：

θ ← θ − η·g

它简单、稳定、好实现，但有两大缺点：一是方向抖动大（每个 batch 的梯度都带噪声，步子在陡峭方向上来回震荡）；二是在"狭长山谷"里走得慢（扁平的损失曲面让它只能小步挪动，否则会震荡发散）。

2. Momentum：给下降加"惯性"#

动量法把参数更新想象成滚下山的小球，不仅看当前梯度，还叠加上一时刻的速度：

v ← β·v + g       （β 常用 0.9，累积历史梯度）
θ ← θ − η·v

好处：历史方向一致的维度，速度会累积放大，越走越快；方向抖动的维度，正负互相抵消，走得稳。于是小球能更快穿过平坦区，又不易在陡坡上震荡。

3. 自适应学习率：AdaGrad 与 RMSProp#

SGD 对所有参数用同一个学习率 η，但不同参数"需要的步子大小"往往不同。自适应方法给每个参数单独分配学习率：

  • AdaGrad：累积历史梯度平方和，用它来缩小学习率——θ ← θ − η·g / √(Σg² + ε)。问题：Σg² 只增不减，学习率最终会衰减到 0，训练过早停滞。
  • RMSProp：把"累积求和"改成"指数滑动平均"E[g²] = ρ·E[g²] + (1−ρ)·g²，从而只记住近期梯度，避免了 AdaGrad 的无限衰减，是更实用的选择。

4. Adam：动量 + 自适应 = 默认之选#

Adam（Adaptive Moment Estimation）把动量和自适应学习率结合起来，同时维护梯度的一阶矩 m（类似动量）和二阶矩 v（类似 RMSProp）：

m ← β₁·m + (1−β₁)·g
v ← β₂·v + (1−β₂)·g²
m̂ ← m / (1−β₁ᵗ)      （偏差修正，前几步更准）
v̂ ← v / (1−β₂ᵗ)
θ ← θ − η·m̂ / (√v̂ + ε)

因为 m̂ 提供稳定的方向、√v̂ 提供自适应的步长，Adam 对学习率不那么敏感、收敛快，成为绝大多数任务"开箱即用"的默认优化器。默认超参 η=0.001, β₁=0.9, β₂=0.999, ε=1e-8。

5. 如何选择#

场景 推荐
大多数任务、不想调参 Adam（或其变体 AdamW）
需要极致泛化、有调参预算（如大模型预训练） SGD + Momentum + 学习率调度
梯度极稀疏（如词嵌入） AdaGrad / Adam
目标函数震荡剧烈 RMSProp

二、可运行示例#

示例 1：NumPy 手写 SGD / Momentum / Adam，对比收敛速度

在"狭长山谷"函数 f(w₁,w₂) = 0.05·w₁² + w₂² 上，从 (10, 10) 出发，比较三种优化器谁先到达谷底。

import numpy as np

# 目标函数：扁长的椭圆谷，w1 方向平缓、w2 方向陡峭
def f(w):
    return 0.05 * w[0]**2 + w[1]**2

def grad(w):
    return np.array([0.1 * w[0], 2.0 * w[1]])   # 解析梯度

def run(optimizer, lr, steps=300):
    w = np.array([10.0, 10.0])
    # 优化器内部状态
    v = np.zeros(2)          # 动量 / SGD 无
    m = np.zeros(2); vv = np.zeros(2)   # Adam 的一阶、二阶矩
    history = [f(w)]
    for t in range(1, steps + 1):
        g = grad(w)
        if optimizer == "sgd":
            w = w - lr * g
        elif optimizer == "momentum":
            v = 0.9 * v + g          # 累积动量
            w = w - lr * v
        elif optimizer == "adam":
            m = 0.9 * m + 0.1 * g
            vv = 0.999 * vv + 0.001 * g * g
            m_hat = m / (1 - 0.9 ** t)        # 偏差修正
            v_hat = vv / (1 - 0.999 ** t)
            w = w - lr * m_hat / (np.sqrt(v_hat) + 1e-8)
        history.append(f(w))
    return history

for name, lr in [("SGD", 0.1), ("Momentum", 0.1), ("Adam", 0.1)]:
    hist = run(name.lower(), lr)
    # 找到首次使损失低于 1e-6 的步数（找不到就用总步数）
    steps = next((i for i, v in enumerate(hist) if v < 1e-6), len(hist))
    print(f"{name:8s} 最终损失 = {hist[-1]:.3e}, 收敛到 1e-6 所需步数 = {steps}")

结果会显示：Adam 几步内就逼近谷底，Momentum 次之，SGD 最慢——这正是动量与自适应学习率带来的加速。

示例 2：用 PyTorch 内置优化器做同一件事

import torch

w = torch.tensor([10.0, 10.0], requires_grad=True)
# 对比两个优化器：SGD（带动量）与 Adam
opt_sgd = torch.optim.SGD([w], lr=0.1, momentum=0.9)
opt_adam = torch.optim.Adam([w], lr=0.1)

for name, opt in [("SGD+Momentum", opt_sgd), ("Adam", opt_adam)]:
    with torch.no_grad():
        w.copy_(torch.tensor([10.0, 10.0]))   # 重置起点
    for _ in range(200):
        opt.zero_grad()
        loss = 0.05 * w[0]**2 + w[1]**2
        loss.backward()
        opt.step()
    print(f"{name:12s} 最终损失 = {loss.item():.3e}")

三、练习#

  1. 调超参观察：把示例 1 里 Momentum 的 β 从 0.9 改成 0.5 和 0.99，观察收敛步数变化，解释为什么 β 过大或过小都不好。
  2. 手推更新：设当前梯度 g=2、上一时刻动量 v=1.5、β=0.9、η=0.1，用 Momentum 的公式手算出这一步参数实际移动了多少。
  3. 加一段 AdaGrad：在示例 1 中补一个 ada 分支，实现 G += g²; w -= lr*g/(sqrt(G)+1e-8)，对比它在长步数（如 5000 步）后是否出现"学习率衰减到 0、停滞不前"的现象。
  4. 思考：为什么 Adam 要做"偏差修正"（除以 1−βᵗ）？想一想在训练最初的几步，m、v 被初始化为 0 时会发生什么。
  5. 查资料：AdamW 和 Adam 有什么区别？为什么现在很多大模型用 AdamW（提示：权重衰减与 L2 正则的关系，第 6 章会涉及）？
