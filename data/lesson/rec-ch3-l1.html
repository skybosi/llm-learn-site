矩阵分解原理#

协同过滤用"邻域"做预测：找相似用户/相似物品，加权平均。但邻域方法有一个天花板——它只能"就近取材"，当矩阵极度稀疏、共同评分极少时，相似度估计就会失准。矩阵分解（Matrix Factorization, MF） 换了一条更宏大的思路：与其在原始的、稀疏的矩阵里数共同评分，不如假设整个矩阵背后有一个低维结构，并把这个结构显式地学出来。这一课从第一性原理讲清矩阵分解为什么成立、优化目标怎么写、以及它和线性代数里 SVD 的血缘关系。

一、概念讲解#

1. 从"数共同评分"到"低秩假设"#

评分矩阵 R 的形状是 m×n（用户 × 物品），绝大多数元素缺失。矩阵分解的核心假设是低秩（low-rank）：

每个用户可以用一个 k 维隐向量 p_u 描述，每个物品可以用一个 k 维隐向量 q_i 描述，k 很小（远小于 m、n）；用户对物品的评分，就是这两个向量做内积。

R̂[u, i] = p_uᵀ q_i

写成矩阵形式就是：

R ≈ P Qᵀ ， 其中 P ∈ R^{m×k}，Q ∈ R^{n×k}

这个假设的威力在于参数共享：原来要估计 m×n 个未知数，现在只需要估计 (m+n)×k 个参数。当 k 远小于 m、n 时，参数数量急剧下降——用少量参数去拟合大量观测，本身就是一种极强的正则化，天然缓解稀疏与过拟合。

2. 优化目标：只在观测值上拟合#

评分矩阵有缺失值，我们不能像完整 SVD 那样对全矩阵求分解，而是只对观测到的那些 (u, i) 拟合。于是损失函数是观测值上的平方误差，再加一个 L2 正则化抑制过拟合：

J = Σ_{(u,i) ∈ Ω} (R[u,i] − p_uᵀ q_i)² + λ ( Σ_u ‖p_u‖² + Σ_i ‖q_i‖² )
  • Ω 是"所有已知评分的 (u, i) 集合"；
  • 第一项让预测贴近真实评分，第二项让隐向量别太大（防过拟合，原理同机器学习课的正则化）；
  • λ 是正则化强度。

这本质上就是机器学习课里"平方损失 + L2 正则化"的套路，只不过这里的"特征" p_u 和 q_i 本身也是要学的参数，而不是预先给定的输入——这是矩阵分解与普通回归最本质的区别。

3. 梯度下降求解：SGD 每一步都在"追残差"#

对单个观测 (u, i)，记残差 e_ui = R[u,i] − p_uᵀ q_i。分别对 p_u、q_i 求梯度：

∂J/∂p_u = −2 e_ui · q_i + 2λ p_u
∂J/∂q_i = −2 e_ui · p_u + 2λ q_i

于是随机梯度下降（SGD）的更新规则是：

p_u ← p_u + η ( e_ui · q_i − λ p_u )
q_i ← q_i + η ( e_ui · p_u − λ q_i )

直觉很清晰：当预测偏低（残差为正）时，把 p_u 朝 q_i 方向挪一点、把 q_i 朝 p_u 方向挪一点，让内积变大、逼近真实值；反之亦然。每个观测样本都这样"追残差"一小步，反复扫多轮就收敛了。

4. 为什么这能抓住"相似度"抓不到的结构#

回到第 2 章"相似度为什么有效"的讨论：协同过滤用相似度做局部平滑，矩阵分解则更进一步——它把每个用户/物品压缩成一个低维向量，让"相似"不再是"数共同评分"，而是"两个向量在隐空间里靠近"。好处有二：

  1. 泛化更强：两个物品即使没有共同用户，只要它们的隐向量接近，也能被判定相似——这是邻域方法做不到的。
  2. 更省存储：只需存 (m+n)k 个参数，而不是 m×m 或 n×n 的相似度矩阵。

代价是可解释性下降：隐向量的每一维是什么含义，往往说不清——这个"隐语义"的解读放到本章第 3 课。

二、可运行代码示例#

用 NumPy 从零实现一个 SGD 矩阵分解，在 5×4 的小评分矩阵上把缺失值补出来。

import numpy as np

# 用户-物品评分矩阵：0 表示未评分
R = np.array([
    [5, 3, 0, 1],
    [4, 0, 0, 1],
    [1, 1, 0, 5],
    [0, 0, 0, 4],
    [0, 1, 5, 4],
], dtype=float)

n_users, n_items = R.shape
k = 3            # 隐因子数
lr = 0.01        # 学习率
lam = 0.02       # L2 正则化系数
steps = 2000     # 迭代轮数

rng = np.random.default_rng(0)
P = rng.normal(0, 0.1, (n_users, k))   # 用户隐向量矩阵（随机初始化）
Q = rng.normal(0, 0.1, (n_items, k))   # 物品隐向量矩阵（随机初始化）

# 所有已知评分的 (用户, 物品) 对
pairs = [(u, i) for u in range(n_users) for i in range(n_items) if R[u, i] > 0]

for step in range(steps):
    for u, i in pairs:
        err = R[u, i] - P[u] @ Q[i]     # 残差：真实值 − 预测值
        pu = P[u].copy()                # 先暂存，避免更新 Q 时用到已变的 P[u]
        P[u] += lr * (err * Q[i] - lam * P[u])
        Q[i] += lr * (err * pu   - lam * Q[i])

R_hat = P @ Q.T                        # 补全后的完整评分矩阵
print("补全后的评分矩阵 R̂：\n", np.round(R_hat, 2))
print("\n真实评分（用于对照）：\n", R)

观察要点：迭代结束后，R_hat 里原本为 0 的位置被填上了"合理"的预测值，而原本有评分的位置则被尽量复现（存在小误差，来自正则化与迭代精度）。试着增大 k（比如 4）会拟合得更贴训练值但可能过拟合，减小 λ 同理——这正是机器学习课"偏差-方差"权衡在推荐里的重演。

三、练习#

  1. 把 k 分别设为 1、2、4，观察训练集上误差与"缺失值预测"的变化，解释为什么 k 太大容易过拟合（参考"低秩假设"）。
  2. 把 λ 设为 0（去掉正则化），观察迭代后期是否出现隐向量数值爆炸或过拟合迹象；再设成 1.0，观察是否欠拟合（预测都逼近均值）。
  3. 手写验证一条梯度：对单个样本 (u, i)，用数值梯度（(J(p_u+ε) − J(p_u−ε)) / 2ε）近似 ∂J/∂p_u，与解析式 −2e·q_i + 2λp_u 对比，确认更新公式正确。

为什么这样做？——理论推导#

从 SVD 的角度理解矩阵分解#

这是本课要"知其所以然"的核心，也是任务里点名的重点。线性代数课学过奇异值分解（SVD）：任何 m×n 实矩阵 R 都能分解为 R = U Σ Vᵀ，其中 Σ 的对角线是奇异值（从大到小排列）。而截断 SVD（Truncated SVD） 只保留前 k 个最大的奇异值及其对应的左右奇异向量，得到秩 k 的近似矩阵 R_k。Eckart–Young 定理保证：在所有秩不超过 k 的矩阵里，R_k 是 Frobenius 范数下对 R 的最佳近似。

这似乎意味着"推荐 = 对评分矩阵做截断 SVD"。但有个致命障碍：评分矩阵有缺失值，而标准 SVD 要求矩阵完整。硬要做，只能先把缺失值用均值/0 填充——这会引入大量虚假的"0 分"，严重污染分解结果。

于是矩阵分解换了个做法：放弃"全矩阵精确分解"，改成"只在观测值上最小化误差"。把截断 SVD 的目标 min ‖R − P Qᵀ‖_F²（对全矩阵）改成对观测子集：

min_{P,Q} Σ_{(u,i) ∈ Ω} (R[u,i] − p_uᵀ q_i)² + λ(‖P‖² + ‖Q‖²)

这时的 P、Q 不再是 SVD 里的正交矩阵，而是普通参数矩阵，但它们扮演的角色完全对应：P 对应 U_k（用户侧的低维表示），Q 对应 V_k（物品侧的低维表示），k 对应"保留多少个奇异方向"。所以可以这样一句话概括：

矩阵分解 = 把"完整矩阵上的截断 SVD（最佳低秩近似）"，改造成"稀疏观测矩阵上、带正则化的最佳低秩近似"。

SVD 给出了"低秩逼近为何合理"的理论背书（Eckart–Young 最优性），矩阵分解则解决了"SVD 在缺失值面前无能为力"的工程困境。二者一脉相承。

母原理连接： 从"完整矩阵 SVD"到"稀疏矩阵分解"的改造，本质是把一个约束优化问题（精确分解、含正交约束）松弛成一个无约束的经验风险最小化问题（平方损失 + 正则化）——这正是机器学习里"把难题转化为可优化的损失函数"这一核心母题的绝佳范例。
