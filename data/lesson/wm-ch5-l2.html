模型预测控制式 Agent：视界、重规划频率与延迟预算#

这一节要解决什么#

上一节说清了模型能提供什么。这一节把它装进一个闭环，回答工程上最先撞到的三个问题：

  1. 每次决策看多远（视界 H）？
  2. 多久重新想一次（重规划间隔 R）？
  3. 每次决策能花多少算力（延迟预算 M）？

这三个量不是三个可以各自调的旋钮，它们被一条 硬约束 绑在一起：

每次决策的模型步数预算M​​ ≥ 候选样本数N​​×视界H​​ × (每次 rollout 的常数),

而性能同时受两边挤压：H 太小则看不到后果（短视），H 太大则把模型误差也一起看进去（被反噬）。本节的交付就是一个把两边都算出来的最优视界判据。

① 开环执行长计划是灾难的放大器，而每步重规划基本免疫。 本课表 A：模型有结构误差（不知道阻力与侧风）时，开环执行 36 步的末端距离是 2.60 格、进入容差带的步数是 0.0%；同样预算下每步重规划（R=1、H=36）是 0.07 格、26.4%。同一个模型、同一个规划器，只改了"多久重规划一次"。 ② 视界不是越长越好，最优视界可以被算出来。 表 B：随着模型变准（eps=0→1），实测最优视界从 12 单调升到 16；而模型误差随视界按幂律长（表 C：err(t)≈ε1​tα，α=1.45∼1.67）。把两者合起来得到 H⋆=min{(Δ/ε1​)1/α, M/(2d)}——表 D 里这个判据给出的 8.3 与 11.6，实测最优视界分别是 8 与 12。 ③ 在固定算力下，把预算从"重规划频率"挪到"每次采样数"常常更划算。 表 E：总预算 6.4×105 模型步固定，R=1（N=400）代价 315.0，R=2（N=800）代价 313.9 —— 重规划慢一倍、采样多一倍，反而略好；但 R≥4 之后计划过期，代价迅速涨到 338.7、433.4。

一、把 Agent 写成闭环：模型在回路里的哪一格#

先给本节讨论的对象一个明确的、不依赖 LLM 的定义。一个以世界模型为决策底座的 Agent 是这样运转的：

① 状态估计   从观测维护一个"足以预测未来"的状态 s（第 2 章）
② 想象       在 (P̂, R̂) 里采样 N 条长度为 H 的候选动作序列
③ 打分       用模型算每条序列的期望回报 Ĵ（必要时加悲观/风险项）
④ 选择       取 argmax，但只执行这条序列的**前 R 步**
⑤ 执行       在真实环境里走 R 步，观测、更新状态
⑥ 回到 ①     —— 这一步就是"闭环"

与"一次规划、开环执行"相比，差别只在第 ④ 步的那个 R 和第 ⑥ 步。但就是这一步，决定了模型误差会不会被累积。

三个量因此各司其职：

符号 含义 变大的后果
H 想象的长度（看多远） 视野更宽，但把模型在远处的误差也纳入打分
R 承诺的长度（执行几步） 省算力，但计划过期、偏差累积
N 每次想象采多少条 搜索更充分，但延迟线性增长（N⋅H）
M 每次决策允许的模型步数 上界约束：N⋅H≲M

为什么这套结构值得单独讲：因为它是"模型"与"决策"之间唯一不能省略的接口。没有 R=1 的重规划，"闭环"只是修辞；没有 M 的约束，"想得更久"就是免费的。后面第 3 章（分层）与第 4 节（误差利用）讨论的所有机制，都是在这三个量的夹缝里做文章。

二、视界：开环执行是灾难的放大器#

本课的任务是一个连续的 2D "停靠"问题：5×5 的盒子里，从 8 个起点走到 (4.4,4.4) 并停稳。真值动力学有阻力 μ=0.15 与常值侧风；Agent 的模型是"真值 × eps"——eps=1 表示完全正确，eps=0 表示既不知道阻力也不知道风。代价函数是 ∥p−g∥2+0.5∥v∥2+0.01∥a∥2，其中速度项让"提前刹车"成为必须——这一项是让"长视界有价值"的关键设计：没有它，短视界贪心就能把位置推过去。

四条读法：

  1. 开环 vs 闭环的差距随 H 单调拉开。 eps=0 时，H=12 的三项指标是 0.16 / 16.0%（MPC）与 1.31 / 0.0%（开环）；到 H=36 是 0.07 / 26.4% 与 2.60 / 0.0%。开环的容差占比在整张表里始终是 0.0%——它从来没有真正停稳过。
  2. 开环的失败不是"模型不好"能解释的。 eps=1（真值模型）的开环在 H=36 也只有 0.14 / 16.6%，仍然远差于 MPC。误差源是"承诺"，不是"模型"。 只要环境里有任何未被模型捕捉的扰动（本课是常值侧风），一次承诺越长，偏差越久得不到修正。
  3. MPC 的最优视界随模型质量移动：eps=0 的最优在 H=12（0.16 / 16.0%），之后开始变差（H=36 掉回 0.53 / 0.0%）；eps=1 的最优在 H=16，并且在 H≥12 之后基本平坦。模型越差，能安全使用的视界越短。
  4. 短视界也有硬伤：H≤3 时两种模型都无法停靠（容差 0.0%）。原因是"刹车"必须提前规划——这正是速度项的设计目的。"视界越短越鲁棒"是错的；正确说法是"视界要够用，但不要超过模型的可信长度"。

可复用判据：如果你在系统里看到"模型自评很好，但闭环收益随规划视界下降"，先不要加大模型——检查你的执行方式是开环还是闭环。表 A 里开环与闭环用的是同一个模型。

三、误差 × 视界：把"可信视界"算出来#

要做取舍，先得有一个"模型能信多久"的定量刻画。做法很直接：从同一个状态出发，喂同一条动作序列，分别用模型和真值推进，量位置的差。

err(t)=​p^​t​−pt​​,logerr(t)=logε1​+αlogt.

三条读法：

  1. 误差按幂律长，指数 α≈1.5∼1.7（超线性但亚二次）。它的来源可以直接解释：eps=0 的模型漏掉了"每步损失 15% 速度"和"每步增加 0.035 侧向速度"，两个常值偏差各贡献位置误差的一个多项式项。指数接近 2 意味着：把视界翻倍，误差大约翻三倍。
  2. α 随模型变好而下降（1.67→1.45），因为剩下的误差更接近随机游走而不是常值偏差。这条对判据很重要：不能把 α 当成常数，必须在自己系统上量一次。
  3. 误差界 Hϵ​ 是可以直接算的：给一个容差 Δ（这里取终端位置误差 0.2 格），解 ε1​Hα=Δ 得到

Hϵ​=(ε1​Δ​)1/α.

用它检验：eps=0 时 Hϵ​=11.6，而表 A/B 测出的最优视界是 H⋆=12；eps=0.25 时 Hϵ​=15.2，实测 12；eps=0.5 时 21.9，实测 16；eps=0.75 时 39.8，实测 16。

怎么读这个偏差：Hϵ​ 是一个上界代理——它回答"模型在哪一步之后不再可信"，而实测最优视界总是不大于它（11.6 vs 12 属于网格步长 4 的范围内）。eps 越大时差距越大，因为此时限制最优视界的已经不是误差，而是搜索预算（下一节）。用 Hϵ​ 当上限、再用小步长回退扫描定精确值，是最省事的工程做法。

四、延迟预算：算力界与误差界取 min#

"看多远"还受另一个约束：每次决策能跑多少次模型前向。把一次决策的模型步数记为 M（一次 rollout 长度 H 的成本记作 H，因为它要推进 H 步），则

N=⌊HM​⌋.

而搜索本身有一个"最低采样数"要求：本课的规划器把动作序列参数化成 K=min(H,6) 段（搜索维度 d=2K），N 太小就变成了"在 d 维空间里抽 N 个点"，直接退化成噪声。这条给出算力界：

HB​=cdM​,c≈2 （每维最少样本数）, d=2min(H,6).

表 D 把两个界放在一起验证（eps=0，误差界 Hϵ​=11.6）：

 H⋆=min{Hϵ​: 模型可信多久(Δ/ε1​)1/α​​, HB​: 采样够不够M/(cd)​​} ​

三条使用规则：

  1. 先量 ε1​ 与 α：拿一批真实的 (s,a,s′)，用"同状态同动作、模型与真值各推一步"的方式测 ε1​；沿轨迹测多步得到 α。这一步比调 H 便宜得多，却直接决定 H 的上限。
  2. Δ 要按任务的终端精度要求取，不能拍。本课容差带是 0.3 格，但判据用的是更严的 0.2：因为 0.3 是"进了就算"的松弛阈值，而规划需要在终端附近有分辨力。
  3. Δ 与 α 都是环境的函数，不是超参。换环境必须重测——这也是 α 必须实测、不能抄的原因。

五、重规划频率：R 是"承诺长度"的旋钮#

R 的语义是：这条计划我信几步。 R=H 就是完全开环（第二节已经量过），R=1 是完全闭环。

四条读法：

  1. R=1 不是必然最优。 R=2 在同等预算下把 N 从 400 提到 800，代价反而略低（313.9 vs 315.0）。这说明"每步重规划"这个直觉里，混着一半是"采样更充分"的收益。 当搜索本身是瓶颈时（本课 N=400 在 d=12 维里并不充分），把算力挪给采样更划算。
  2. R≥4 迅速变差：代价 338.7（R=4）、433.4（R=8），且只花了 52%、28% 的预算——也就是说即使把省下的算力全丢掉，性能也不划算。计划过期是硬伤，不能靠加采样补救。
  3. R=8 时模型质量几乎不救场：eps=1（真值模型）也只有 0.46 格末端距离。承诺长度是环境扰动与执行噪声的函数，与模型精度基本无关。
  4. R 的合理量级由"扰动在一个重规划周期内能累积多少"决定。 本课侧风恒定、动力学平滑，R=2 还能接受；如果执行器有随机延迟或环境突变，R=1 才是唯一可接受的选择。

可复用判据：先做一次"R 扫描 × 固定总算力"的对照（表 E 的形状），再看曲线在哪个 R 开始翘起——那个拐点之前的最后一个 R 就是你的 R⋆。不要先验地取 R=1：它会浪费一半算力在本可以用采样的地方。

六、取舍与边界#

你会遇到的症状 大概率原因 先改什么 依据
闭环收益随规划视界下降 模型误差被视界放大 缩短 H 到 Hϵ​ 以内；或加大 R 的频率 表 A/B：eps=0 最优 H=12，H=36 掉回 0.53
开环执行表现差、模型自评却很好 承诺太长，扰动无法修正 把 R 降到 1∼2 表 A：开环容差占比全程 0.0%
加大算力没有收益 已越过误差界，瓶颈在模型不在搜索 去改模型，或缩短 H 把算力换给 N 表 D：M≥800 后最优 H 恒定在 12
采样很少时表现像随机 搜索维度 d 下的样本量不足 加 N 或减少动作参数化维度 K 表 D：M=200、N=25 时最优 H 被压到 8
每次决策延迟超标 N⋅H 超预算 先降 H（保 N），再降 R 的调用次数 约束 N≤M/H

三条边界：

  1. 本节的所有结论都以"规划器能把 H 用起来"为前提。 本课的规划器是 CEM + 分段常值参数化（K=min(H,6)），这是一个刻意的设计决策：搜索维度与 H 解耦，否则 H 一变大搜索就崩，量出来的"最优视界"其实是"搜索能力的最优视界"。换成随机 shooting，长视界会有完全不同的曲线。
  2. ε1​、α、c 都是环境相关的常数。本课的值只用来演示判据的形状；换到你的系统，这三个数必须自己量（各不超过几十行代码）。
  3. H⋆ 是"每步决策"的量，不是全局超参。 在不同状态区域（远离目标 vs 临近目标）模型误差率不同，H 理论上应该自适应。本课为了把结论讲清用了固定 H；工程上按状态分档（例如"ε1​ 在线估计"）是自然的下一步。

代码：视界、重规划频率与延迟预算的三张对照表#

下面的代码不调用任何 API，只依赖 numpy。它实现一个 CEM 规划器（分段常值参数化，返回最优精英样本而不是精英均值）与一个带阻力/侧风的 2D 停靠任务，然后：

  • 表 A：视界扫描，闭环 MPC（R=1）vs 开环执行（R=H），两种模型质量；
  • 表 B：误差 × 视界，给出每个 eps 的实测最优视界；
  • 表 C：误差随视界的增长与幂律拟合，算出误差界 Hϵ​；
  • 表 D：延迟预算 M 下的视界选择，对照"算力界"与判据 min(Hϵ​,HB​)；
  • 表 E：总算力固定时，重规划间隔 R 与每次采样数 N 的分配。

每一处注释写的是设计决策，不是实现细节。

⚠️ 环境与全部数据为本代码合成，不代表任何真实系统。

"""WM ch5-l2 演示：模型预测控制式 Agent —— 视界、重规划频率与延迟预算
连续 2D 点质量「停靠」任务（阻力 + 侧风 + 速度惩罚）与全部数据为合成（⚠️ 不代表任何真实系统）。
只依赖 numpy。
"""
import numpy as np

DT, MU, WIND, T, BOX, TOL = 0.1, 0.15, np.array([0.0, 0.35]), 50, 5.0, 0.30
GOAL = np.array([4.4, 4.4])
STARTS = np.array([[0.5, 0.5], [0.8, 1.2], [1.2, 0.6], [0.6, 2.4], [2.2, 0.7],
                   [0.4, 3.6], [3.2, 0.5], [1.6, 1.6]])


def step_true(p, v, a):
    """真值动力学：阻力 + 常值侧风；撞边界则该方向速度归零。"""
    v = (1 - MU) * v + a * DT + WIND * DT
    p = p + v * DT
    for k in range(2):
        if p[k] < 0 or p[k] > BOX:
            p[k] = np.clip(p[k], 0, BOX); v[k] = 0.0
    return p, v


def step_cost(p, v, a):
    """停靠代价：离目标要近、速度要小、动作要小。速度项让「提前刹车」成为必须。"""
    return float(((p - GOAL) ** 2).sum() + 0.5 * (v ** 2).sum() + 0.01 * (a ** 2).sum())


def rollout(p, v, A, eps):
    """模型版批量 rollout。eps=1 与真值一致；eps=0 是「既不知道阻力、也不知道风」的模型。"""
    N, H, _ = A.shape
    P = np.repeat(p[None], N, 0); V = np.repeat(v[None], N, 0); C = np.zeros(N)
    for t in range(H):
        V = (1 - eps * MU) * V + A[:, t] * DT + eps * WIND * DT
        P = np.clip(P + V * DT, 0, BOX)
        C += ((P - GOAL) ** 2).sum(1) + 0.5 * (V ** 2).sum(1) + 0.01 * (A[:, t] ** 2).sum(1)
    return C, P, V


def expand(coef, H, K):
    """K 段分段常值动作 → 长度 H 的序列：让搜索维度与视界解耦。"""
    return coef[:, np.minimum(np.arange(H) * K // H, K - 1), :]


def cem(p, v, eps, H, r, N=200, iters=4, elite=0.15):
    """CEM：粗采样后向精英集收紧。设计决策：返回最优精英样本，不是精英均值。"""
    K = min(H, 6); mean = np.zeros((K, 2)); std = np.ones((K, 2)) * 1.5; bc, bcoef = 1e18, mean.copy()
    for _ in range(iters):
        coef = np.clip(r.normal(mean, std, size=(N, K, 2)), -2, 2)
        C, P, V = rollout(p, v, np.clip(expand(coef, H, K), -2, 2), eps)
        idx = np.argsort(C)[:max(4, int(N * elite))]
        mean, std = coef[idx].mean(0), coef[idx].std(0) + 0.05
        if C[idx[0]] < bc:
            bc, bcoef = C[idx[0]], coef[idx[0]]
    return np.clip(expand(bcoef[None], H, K)[0], -2, 2)


def run(eps, H, R_replan, N=200, iters=4, seeds=2):
    """R_replan=1 → 逐步重规划（MPC）；R_replan=H → 一次规划、开环执行 H 步。"""
    cost, dist, tail, frac, calls = [], [], [], [], []
    for sd in range(seeds):
        r = np.random.default_rng(sd); tc = td = tt = tf = tk = 0.0
        for s0 in STARTS:
            p, v = s0.copy(), np.zeros(2); c = 0.0; k = 0; good = 0.0; d10 = []
            while k < T:
                pl = cem(p, v, eps, H, r, N, iters); tk += N * iters * H
                for j in range(min(R_replan, H, T - k)):
                    a = pl[j]
                    c += step_cost(p, v, a)
                    p, v = step_true(p, v, a); k += 1
                    d10.append(float(np.linalg.norm(p - GOAL)))
                    good += 1.0 if d10[-1] <= TOL else 0.0
            tc += c; td += d10[-1]; tt += float(np.mean(d10[-10:])); tf += good / T
        cost.append(tc / len(STARTS)); dist.append(td / len(STARTS))
        tail.append(tt / len(STARTS)); frac.append(tf / len(STARTS)); calls.append(tk / len(STARTS))
    m = lambda z: float(np.mean(z))
    return m(cost), m(dist), m(tail), m(frac), m(calls)

def growth(eps, H=40, reps=40):
    """同一个动作序列下，模型预测位置与真值的偏差 —— 完全向量化。"""
    r = np.random.default_rng(5)
    P = np.repeat(STARTS.astype(float), reps, 0); V = np.zeros_like(P)
    Pm, Vm = P.copy(), V.copy()
    A = np.clip(r.uniform(-2, 2, size=(len(P), H, 2)), -2, 2); E = np.zeros(H)
    for t in range(H):
        a = A[:, t]
        V = (1 - MU) * V + a * DT + WIND * DT; P = np.clip(P + V * DT, 0, BOX)
        Vm = (1 - eps * MU) * Vm + a * DT + eps * WIND * DT; Pm = np.clip(Pm + Vm * DT, 0, BOX)
        E[t] = np.linalg.norm(Pm - P, axis=1).mean()
    return E

这段代码想让你看到的五件事：

  1. 开环与闭环的差距是量级级别的。 表 A：模型有结构误差时，开环执行 36 步的容差带占比是 0.0%、末端 2.60 格；每步重规划的同一预算下是 26.4%、0.07 格。"多久重规划一次"比"模型多准"更能决定成败。
  2. 模型质量决定"能用多长的视界"。 表 B：eps =0→1 时实测最优视界从 12 升到 16；表 C 的误差幂律（α=1.45∼1.67）解释了为什么。
  3. 最优视界可以算出来。 表 D：判据 min(Hϵ​,HB​) 给出 8.3 与 11.6，实测最优视界是 8 与 12。这是本节的核心交付。
  4. R=1 不是免费的。 表 E：固定预算下 R=2（N 翻倍）比 R=1 略好（313.9 vs 315.0），而 R≥4 迅速崩坏（338.7、433.4）。
  5. 把模型换成真值的收益，远小于把开环改成闭环的收益。 表 A：eps=0 的 MPC 最好值是 0.16 格（H=12），eps=1 是 0.05 格（H=16），差 0.11 格；而同样从 eps=0 出发，只把"开环执行"改成"每步重规划"，末端距离从 2.60 格降到 0.07 格，差 2.5 格。先修闭环结构，再修模型。

⚠️ 诚实说明这个实验的边界：任务是低维连续控制（4 维状态、2 维动作），动力学线性、扰动是常值侧风，规划器是 CEM + 6 段参数化。α 的幂律形式来自常值偏差这一特定误差结构；若你的模型误差主要是随机噪声或混沌放大，err(t) 的形状会不同（前者接近 t​，后者接近指数），Hϵ​ 的公式要换成对应的形式。本节证明的是"最优视界由误差界与算力界共同决定"这一结构，以及两个界各自的量法。

练习#

  1. 把判据搬到自己的任务上。 任选一个你能跑起来的仿真环境（gym 里的 MuJoCo、一个棋盘游戏、或自己写的小车），量出 ε1​ 与 α，用 Hϵ​=(Δ/ε1​)1/α 预测最优视界，再用扫描验证。要求报告"预测 vs 实测"的偏差，并解释偏差来源。
  2. 让 H 自适应。 本课的 H⋆ 是常数。设计一个在线方案：用滑动窗口估计 ε1​（模型一步预测误差），实时给出 H。给出窗口长度、更新频率、以及"估计抖动导致 H 抖动"的抑制手段。
  3. 找出 R 的拐点规律。 在表 E 的框架下，改变侧风强度（例如 0.35→0.1,0.7）与动作噪声，重跑 R 扫描。给出"R⋆ 与扰动强度"的经验关系，并说明它为什么与模型精度弱相关。
  4. 算力该怎么加。 固定 M，把预算在 (N,H) 上重新分配，画出"性能 vs M"的曲线。指出在哪个 M 之后继续加算力不再有收益，并给出"该改模型"的判据。
  5. 把开环做得公平一点。 第二节说"开环会垮"，但开环也可以每隔若干步用真实观测做一次偏差校正（feedback linearization 式）。设计这个变体，重跑表 A，给出"校正频率"与"承诺长度"的组合边界。
  6. 延迟的真实来源。 本课用"模型步数"当算力单位。请把它换算成真实延迟（前向次数 × 单次前向耗时 + 状态估计耗时 + 通信耗时），并说明在哪一类系统里"状态估计"会成为主导项。

小结#

  • 把 Agent 写成闭环：状态估计 → 在模型里想象 N 条长 H 的序列 → 打分 → 只执行前 R 步 → 观测 → 回到起点。R 就是"承诺长度"，也是模型误差能否被修正的开关。
  • 开环执行长计划是灾难的放大器，而它与模型质量几乎无关。 表 A：eps=0 开环在 H=36 时容差带占比 0.0%、末端 2.60 格；eps=1 开环也只有 16.6%。同一个模型改成 R=1 就是 26.4% / 0.07。
  • 视界有最优值，且可以算：模型误差按 err(t)≈ε1​tα 增长（本课 α=1.45∼1.67），误差界 Hϵ​=(Δ/ε1​)1/α。
  • 延迟预算给出第二个界：N=⌊M/H⌋，而搜索需要 N≳cd，于是 HB​=M/(cd)。最优视界是两界取 min：表 D 判据给 8.3/11.6，实测 8/12。
  • R 是拿算力换鲁棒性的旋钮：固定总算力下 R=2（N 翻倍）略优于 R=1（313.9 vs 315.0），而 R≥4 迅速崩坏（338.7、433.4），且省下的算力也补不回来。
  • 先修结构，再修模型：表 A 里"开环→每步重规划"把末端距离从 2.60 格降到 0.07 格（2.5 格），而"有误差模型→真值模型"只从 0.16 格降到 0.05 格（0.11 格）。只有结构对了，提升模型质量才谈得上回报。
  • 下一节把这套闭环拉长：当任务需要几十步才能完成时，任何"够用的视界"都会超过 Hϵ​。届时的解法不是把 H 开大，而是换时间尺度——用粗尺度的子目标/选项把长任务拆成若干段短视界任务。

下一节（wm-ch5-l3）：分层与想象。我们会用一个"两个房间、只有一扇门"的任务量出：平铺规划需要 H≥16 才能看到门后的目标，而"粗尺度子目标 + 低层 h=3"用同样的预算就能达到 100% 成功率；然后讨论想象的时间尺度（选项长度 D）与误差预算该怎么分配。
