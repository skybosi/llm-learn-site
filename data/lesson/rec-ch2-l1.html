UserCF：基于用户的协同过滤#

协同过滤最古老、最直观的形态，就是基于用户的协同过滤（User-based Collaborative Filtering, UserCF）。它的思想一句话就能说清：要找 u 对物品 i 的未知评分，先找一群和 u 口味最像的人，看他们给 i 打了多少分，再按相似度加权平均。这一课把这个直觉翻译成精确的公式，并手写一遍完整的 NumPy 实现。

一、概念讲解#

1. 核心思想：借别人的眼睛看自己#

UserCF 不需要任何物品的内容信息，只依赖"用户 × 物品"的评分矩阵 R。它基于一个朴素假设：如果用户 u 和 v 过去对同一批物品的打分高度一致，那么未来面对一个新物品时，他们的打分也会高度一致。于是，u 对 i 的未知评分，可以由"与 u 相似的用户"在 i 上的已知评分来估计。

2. 算法三步走#

  1. 算相似度：对每对用户 (u, v)，用他们在共同评分过的物品上的打分算相似度 sim(u, v)（余弦或皮尔逊，下一课详解）。
  2. 找邻居：对目标用户 u，按相似度降序取前 K 个邻居（且邻居必须给物品 i 打过分）。
  3. 加权预测：用这些邻居的评分加权平均，得到 R̂[u, i]。

3. 预测公式与推导#

记邻居集合为 N(u, i) = { v : v 给 i 打过分，且 v 是 u 的 top-K 相似用户 }，预测公式为：

R̂[u, i] = Σ_{v ∈ N(u,i)} sim(u, v) · R[v, i] / Σ_{v ∈ N(u,i)} |sim(u, v)|

为什么是相似度加权平均而不是简单平均？因为"相似度"衡量的是"这个邻居有多可信"：口味越接近 u 的人，他的评分越有参考价值，理应获得更大的话语权。分母取 |sim|（绝对值）是为了在相似度有正有负时，权重保持非负且归一化，避免正负抵消产生异常。

一个常见的偏差修正版本是减掉用户均值：

R̂[u, i] = r̄_u + Σ_{v} sim(u,v) · (R[v,i] − r̄_v) / Σ_{v} |sim(u,v)|

其中 r̄_u、r̄_v 是用户的历史平均分。它解决了一个实际问题：有的人天生爱打高分（平均 4.8），有的人天生苛刻（平均 2.5）——直接用原始分会把"打分尺度"的差异误当成"口味"的差异，减掉各自的均值后，比较的才是"相对自己平均水平的偏离"，更公平。这个去均值思想在下一课"相似度计算"里会再次遇到。

4. UserCF 的强项与软肋#

  • 强项：结果可解释（"因为和你口味相似的小李也喜欢它"）；能发现跨品类的惊喜（你喜欢科幻小说，但口味相似的你却发现他还爱某个爵士乐手）。
  • 软肋：
    • 稀疏性敏感：用户共同评分少时，相似度估计不可靠；
    • 计算代价高：用户数远大于物品数时，两两用户算相似度代价大，且用户行为实时变化，相似度要频繁重算；
    • 新用户冷启动：新用户没有评分，找不到相似邻居。

这些软肋，恰好是下一课 ItemCF 诞生的动机之一。

二、可运行代码示例#

用 NumPy 从零实现一个 UserCF，包括"算用户相似度"和"加权预测评分"两部分。

import numpy as np

# 用户-物品评分矩阵：0 表示未评分，评分范围 1~5
R = np.array([
    [5, 3, 0, 1],   # 用户 0
    [4, 0, 0, 1],   # 用户 1
    [1, 1, 0, 5],   # 用户 2
    [1, 0, 0, 4],   # 用户 3
    [0, 1, 5, 4],   # 用户 4
], dtype=float)

def cosine_sim(a, b):
    """两个用户之间的余弦相似度，只统计两人共同评分过的物品。"""
    mask = (a > 0) & (b > 0)          # 共同评分过的位置
    if mask.sum() == 0:
        return 0.0                    # 没有共同评分，无法判断相似
    a, b = a[mask], b[mask]
    denom = np.linalg.norm(a) * np.linalg.norm(b)
    return float(a @ b / denom) if denom > 0 else 0.0

# 1) 计算完整的用户-用户相似度矩阵
n_users, n_items = R.shape
sim = np.zeros((n_users, n_users))
for u in range(n_users):
    for v in range(n_users):
        sim[u, v] = 1.0 if u == v else cosine_sim(R[u], R[v])
print("用户相似度矩阵：\n", np.round(sim, 3))

def predict(R, sim, user, item, k=2):
    """用与 user 最相似的 k 个邻居（须评过 item）加权平均，预测评分。"""
    # 给 item 打过分的用户（排除 user 自己）
    neighbors = [v for v in np.where(R[:, item] > 0)[0] if v != user]
    if not neighbors:
        return float(R[:, item][R[:, item] > 0].mean())   # 无邻居时退回物品均值
    top_k = sorted(neighbors, key=lambda v: -sim[user, v])[:k]
    num = sum(sim[user, v] * R[v, item] for v in top_k)   # 相似度加权分子
    den = sum(abs(sim[user, v]) for v in top_k)           # 权重归一化分母
    return float(num / den) if den > 0 else float(R[:, item][R[:, item] > 0].mean())

# 2) 预测：用户 0 对物品 2（原本未知）的评分
print("预测 用户0 对 物品2 的评分 =", round(predict(R, sim, user=0, item=2, k=2), 3))

# 3) 给用户 0 生成推荐：对所有未评分物品打分并排序
def recommend(R, sim, user, k=2, top_n=2):
    unrated = [i for i in range(n_items) if R[user, i] == 0]
    scores = [(i, predict(R, sim, user, i, k)) for i in unrated]
    scores.sort(key=lambda x: -x[1])
    return [(i, round(s, 3)) for i, s in scores[:top_n]]

print("给用户 0 的推荐（物品, 预测分）：", recommend(R, sim, user=0, k=2))

观察要点：用户 0 与用户 1 在共同物品（物品 0、3）上打分接近，相似度较高；预测"用户 0 对物品 2"时，会主要参考与他相似、且评过物品 2 的邻居的评分，而不是全体用户的均值。这正是"借相似用户的眼睛"的落地。

三、练习#

  1. 把 k 从 2 改成 1，观察预测值变化；解释"邻居太少"会让预测变得多么不稳定（对噪声敏感）。
  2. 实现均值修正版 UserCF：在 predict 里先算出每个用户的历史平均分 r̄_v，用 R̂ = r̄_u + Σ sim·(R[v,i] − r̄_v) / Σ|sim| 预测，对比与原版结果的差异。
  3. 构造一个"打分尺度"差异明显的矩阵：用户 A 全打 5 分、用户 B 全打 3 分但排序完全一致，比较"原始分余弦"和"减均值后的皮尔逊"两种相似度，解释为什么后者更能反映"口味一致"。
  4. 思考：UserCF 对新物品是"冷启动友好"还是"冷启动不友好"？结合"物品只要有用户评过分就能被邻居带出来"这一性质说明，并与上一课"内容推荐对新物品友好"做对比。

为什么这样做？——理论推导#

相似度加权平均 = 条件期望的邻域估计#

预测公式 Σ sim·R / Σ|sim| 看似是随手写的加权平均，实则是在估计一个条件期望。设目标用户 u 的"真实偏好函数"对物品 i 的取值是 f_u(i)。我们观测不到 f_u，但观测到了其他用户 v 的 R[v, i]。UserCF 的关键假设是：R[v, i] 作为 f_u(i) 的一个"带噪观测"，其噪声方差与 1/sim(u, v) 成正比——即越相似的用户，他的评分越能代表 u。

在这个假设下，用最小化加权误差来估计 f_u(i)：

argmin_{ŷ} Σ_v sim(u, v) · (ŷ − R[v, i])²

对 ŷ 求导令其为 0，解出的最优估计恰好就是相似度加权平均 Σ sim·R / Σ sim。所以加权平均不是经验法则，而是"相似度 = 信任度"这个统计假设下的加权最小二乘闭式解。

去均值 = 消除评分尺度这个混杂变量#

再看均值修正版。用户打分的绝对值混合了两个东西：口味（相对偏好） 和 打分尺度（普遍偏高/偏低）。我们用 R[v,i] − r̄_v 只保留"相对自己平均水平的偏离"，相当于在估计前先做了一次中心化，把"尺度"这个混杂变量剥离出去。这与回归里"先对变量中心化再算相关"是同一个操作——中心化后，皮尔逊相关系数其实就是"中心化向量的余弦相似度"（下一课会严格证明）。

母原理连接： UserCF 的三个步骤——相似度、邻域、加权——合起来就是非参数统计里的 K 近邻回归（K-Nearest Neighbors Regression）：不假设 f_u 有固定形式，而是"用附近样本的加权平均就地估计"。推荐系统的协同过滤，和机器学习课的 KNN，是同一母原理在"用户-物品矩阵"这个特定载体上的两个名字。
