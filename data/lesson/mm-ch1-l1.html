生成模型分类#

你已经在 LLM 课程里见过"预测下一个 token"的生成式目标，也见过判别式的分类头。这一课把"生成模型"这个概念讲清楚：它到底和判别模型差在哪、按什么维度分类、主流三大家族（VAE / GAN / 归一化流）各自怎么构造、又各有什么软肋。理解这张地图，是后面学扩散模型的前置——扩散模型本质上就是"流的近亲 + 变分下界的另一种用法"。

一、概念讲解#

1. 判别式 vs 生成式：学的是两种不同的东西#

给定数据 x 与标签 y，判别模型学的是条件分布 P(y|x)——给你一张图，回答"它是猫还是狗"。它只需要找到一条把两类分开的决策边界，边界的"另一边"长什么样，它毫不关心。

生成模型学的是联合分布 P(x)（无监督）或 P(x,y)（有监督）——它要理解"数据本身是怎么来的"，于是既能给任意样本打分（密度估计），也能造出新样本（采样）。造样本这件事，判别模型做不到：它连 x 的边缘分布都没建模。

用一句话记：判别式划界线，生成式造数据。

2. 按"似然是否显式"分类#

生成模型的第一种分类法，看它是否显式定义了数据似然 P(x)：

  • 显式密度模型：直接写出 P(x) 或它的变分下界，可以逐点计算概率。又分两小类：
    • 可精确计算的：如自回归模型（P(x) = ∏ P(x_t | x_<t)，用链式法则把联合分布拆成一串条件分布，LLM 就是它的代表）、归一化流（Flow）（用可逆变换 + 变量替换公式精确算密度）。
    • 只能近似计算的：变分自编码器（VAE）——真似然 P(x) = ∫ P(x|z)P(z) dz 积分难算，于是最大化它的证据下界（ELBO）。
  • 隐式密度模型：生成对抗网络（GAN）——不写出任何密度，直接让生成器与判别器对抗，隐式地逼近数据分布。GAN 能采样、不能算概率。

第二种分类法看采样方式：VAE/GAN 用神经网络一步映射（从潜变量到数据），Flow 靠可逆变换，自回归靠逐 token 采样，而后面要讲的扩散模型靠"多步去噪"。

3. VAE：把生成变成"编码—解码 + 约束"#

VAE 的核心直觉是给隐变量 z 一个先验，再学一个从 z 到数据 x 的生成器。但直接最大化 log P(x) 遇到一个硬骨头：边际似然 P(x) = ∫ P(x|z)P(z) dz 要对隐变量积分，不可解。

于是引入编码器 q(z|x)（近似后验），推导出证据下界 ELBO（下一课详细推导）：

log P(x)  ≥  E_{q(z|x)}[ log P(x|z) ]  -  KL( q(z|x) ‖ P(z) )
                └── 重构项（要还原 x）──┘    └── 正则项（z 靠近先验）──┘

直观理解：重构项逼生成器"能造回原图"，KL 项逼编码器的输出服从标准正态，这样测试时直接抽 z ~ N(0,I) 就能生成。代价是 KL 项会"抹平"分布，导致 VAE 样本偏模糊——这是它最被诟病的缺点。

4. GAN：用"警察抓小偷"隐式逼近分布#

GAN 完全不碰似然，而是玩一个极小极大博弈：

min_G max_D  E_{x~真实}[ log D(x) ] + E_{z~噪声}[ log(1 - D(G(z))) ]

判别器 D 努力分辨真假，生成器 G 努力骗过 D。训练到均衡时，G 生成的分布理论上与真实分布重合。GAN 的优势是样本锐利、质量高；代价是训练极不稳定（模式坍塌、判别器过强、梯度消失），而且没有显式似然，无法直接评估 P(x)。

5. 归一化流：用可逆变换"精确"算密度#

Flow 的思路最"硬核"：用一个可逆神经网络 f 把简单分布（如标准正态）逐步变换成复杂数据分布。由变量替换公式（下一课推导），数据密度可以精确写出来：

log P(x) = log P_Z(f^{-1}(x)) + log | det J_{f^{-1}}(x) |

只要 f 可逆、雅可比行列式好算，就能既精确算密度、又能双向采样。代价是"可逆 + 行列式可算"这两个约束把网络结构卡得很死（典型做法如仿射耦合层、加性耦合层），表达力受限。

6. 三者各有软肋，扩散模型来补位#

方法 显式似然 采样质量 训练稳定性 主要短板
VAE 变分下界 模糊 稳 KL 项压平分布
GAN 无 锐利 不稳 模式坍塌、难收敛
Flow 精确 一般 稳 可逆约束太强
扩散模型 变分下界 高 稳 采样慢（多步）

扩散模型恰好补上这个空位：训练稳定（像 VAE 那样有清晰目标）、样本质量高（超过 GAN）、似然有下界可优化，唯一代价是采样要多步迭代。下一课先用"似然视角 + 采样视角"把生成模型的两个通用语言统一起来，为扩散模型的数学打底。

二、可运行代码示例#

用一个 2D 玩具任务亲手感受三种方法的"味道"。先跑一个迷你 GAN，让生成器学会画一个圆环：

import torch
import torch.nn as nn
import matplotlib.pyplot as plt

torch.manual_seed(0)

# —— 真实数据：二维圆环上的点，带一点噪声 ——
def real_samples(n):
    theta = torch.rand(n) * 2 * torch.pi
    r = 1.0 + 0.05 * torch.randn(n)
    return torch.stack([r * torch.cos(theta), r * torch.sin(theta)], dim=1)

# —— 判别器：输出一个 logit，越大越"像真的" ——
D = nn.Sequential(nn.Linear(2, 64), nn.ReLU(), nn.Linear(64, 1))
# —— 生成器：把 2 维噪声映射成 2 维点 ——
G = nn.Sequential(nn.Linear(2, 64), nn.ReLU(), nn.Linear(64, 2))

opt_D = torch.optim.Adam(D.parameters(), lr=1e-3)
opt_G = torch.optim.Adam(G.parameters(), lr=1e-3)
bce = nn.BCEWithLogitsLoss()   # 内部自带 sigmoid，适合二分类 logit

for step in range(2000):
    # 1) 训判别器：真样本尽量判 1，假样本尽量判 0
    x = real_samples(128)
    fake = G(torch.randn(128, 2)).detach()   # detach：此步不更新生成器
    loss_D = bce(D(x), torch.ones(128, 1)) + bce(D(fake), torch.zeros(128, 1))
    opt_D.zero_grad(); loss_D.backward(); opt_D.step()

    # 2) 训生成器：目标是"骗过判别器"，把假样本判成 1
    fake = G(torch.randn(128, 2))
    loss_G = bce(D(fake), torch.ones(128, 1))
    opt_G.zero_grad(); loss_G.backward(); opt_G.step()

    if step % 500 == 0:
        print(f"step {step}: loss_D={loss_D.item():.3f}, loss_G={loss_G.item():.3f}")

# 训练完，采样 500 个点画出来，观察是否"长"成了圆环
with torch.no_grad():
    samples = G(torch.randn(500, 2))
plt.scatter(samples[:, 0], samples[:, 1], s=4, label="生成样本")
plt.gca().set_aspect("equal")
plt.legend(); plt.show()

再看三种方法的损失函数各长什么样（这是它们的本质区别）：

# —— VAE：最大化 ELBO，等价于最小化 (重构误差 + KL 正则) ——
recon = ((x - x_hat) ** 2).sum()                          # 重构项：还原原图
kl = -0.5 * (1 + log_var - mu ** 2 - log_var.exp()).sum() # KL(q(z|x)‖N(0,I))
loss_vae = recon + kl

# —— Flow：最大化精确对数似然（变量替换公式），等价于最小化负对数似然 ——
log_p = base_log_prob(z) + log_det_jacobian   # 基分布概率 + log|det J|
loss_flow = -log_p.mean()

# —— GAN：没有显式似然，只有"真假对抗"的极小极大目标 ——
loss_gan = -(torch.log(D(G(z)))).mean()       # 生成器视角（非饱和形式）

运行后你会发现：GAN 只关心"像不像真的"，从不算概率；VAE 的损失里显式出现"概率下界"；Flow 的损失里显式出现"精确概率"。这就是"隐式 vs 显式 vs 变分近似"三种哲学在代码里的落点。

三、练习#

  1. 运行迷你 GAN，把 real_samples 改成"两个高斯团"（月牙/双峰数据），观察生成器能否学到多峰分布；反复跑几次，记录是否出现模式坍塌（生成器只画出一个团）。
  2. 在 VAE 损失里把 KL 项系数从 1 调到 0.1、再调到 10，分别说明重构项与正则项谁占上风、对"样本模糊度/多样性"有什么影响。
  3. 用一段话解释：为什么 GAN"没有显式似然"既是优点（表达力强）又是缺点（无法做密度估计、难评估训练进度）？
  4. 手推变量替换公式 P_X(x) = P_Z(f^{-1}(x)) |det J_{f^{-1}}(x)| 的一维版本，并说明"可逆"为什么是 Flow 的硬约束。
  5. 思考题：扩散模型被归为"显式密度（变分下界）"模型，但它采样又是多步迭代——它和 Flow、VAE 各有什么亲缘关系？带着这个问题进入第 2、3 课。
