流程控制综合练习#

把 if、for、while 组合起来，才能真正解决现实问题。本节课通过几个综合例子，帮你把前面三课的知识串起来。

一、概念讲解：怎么把流程控制"组装"起来#

写程序时，我们很少单独用一个 if 或一个循环，更多是把它们组合在一起：

  • 循环里放判断：一边遍历，一边筛选或分类；
  • 判断里放循环：满足条件时才启动一段重复工作；
  • 循环里套循环：处理二维结构（表格、乘法表）；
  • 用 break/continue 精细控制循环走向。

动手前先想清楚三件事，可以少踩很多坑：

  1. 要重复做什么——决定用 for 还是 while；
  2. 每一步要不要判断——决定哪里放 if；
  3. 什么时候停下来——决定是否需要 break。

二、代码示例#

示例 1：分类统计 1 到 30 的奇偶个数#

odd = 0
even = 0
for i in range(1, 31):
    if i % 2 == 0:
        even += 1
    else:
        odd += 1
print(f"奇数有 {odd} 个，偶数有 {even} 个")

示例 2：猜数字小游戏#

import random

target = random.randint(1, 100)   # 随机生成 1~100 的目标数字
while True:
    guess = int(input("猜一个 1~100 的数字："))
    if guess == target:
        print("恭喜，猜对了！")
        break                      # 猜对就结束
    elif guess > target:
        print("大了，再猜小一点")
    else:
        print("小了，再猜大一点")

示例 3：打印直角三角形#

n = 5
for i in range(1, n + 1):   # 第 i 行打印 i 个 *
    print("*" * i)

示例 4：判断一个数是否为质数#

质数：大于 1，且只能被 1 和它自己整除。

num = 29
if num < 2:
    print("不是质数")
else:
    for i in range(2, num):
        if num % i == 0:
            print(f"{num} 不是质数，能被 {i} 整除")
            break
    else:   # for 正常走完、没执行 break，说明没找到因数
        print(f"{num} 是质数")

三、练习#

  1. 统计 1 到 100 中能被 3 或 5 整除的数字一共有多少个。
  2. 写一个程序，输出 1 到 50 中所有质数（可参考示例 4 的思路）。
  3. 用双重循环打印完整的"九九乘法表"（共 9 行）。
  4. 模拟一个简单的 ATM 菜单：输入 1 显示"查询余额"，输入 2 显示"取款"，输入 3 显示"退出"并用 break 结束循环，其他输入提示"无效选项"。
