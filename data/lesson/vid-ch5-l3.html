开放问题与判断力：长时一致性、评测标准、算力门槛与一张决策表#

这一节要解决什么#

前四节把能算的都算了：接口的 bit、动作通道的台阶、可预测视界、规划预算。本节处理剩下的事——哪些问题目前没有答案，以及在给定预算下怎么做一个可辩护的判断。

这两个问题必须一起回答，因为开放问题的存在方式决定了判断力的形式：

如果长时一致性有一个"正确答案"，那判断力就是去查那个答案；如果它没有，判断力就是知道自己的结论依赖哪几个未验证的假设，并把它们写出来。

本节的全部结论如下：

  1. 长时一致性的"开放"在于递推参数不可先验知道，而在于"可检测"与"存在"是两件事。 一阶递推 εk​=λεk−1​+ρ 的越线步数从 λ=0.98 的"永不越线"（极限 0.200000 恰压在阈值上）到 λ=1.05 的 16 步；而检测门槛 δmin​=1.962​σ/n​=0.006930（σ=0.02,n=64）划出"测不出"与"没有"的界线（表 1）。"测不出差异"永远不能推出"没有漂移"。
  2. 长时一致性的真正开放点有三条，都是结构性的：① λ 与 ρ 依赖于模型、数据、任务三者的交互，目前没有从第一性原理预测它们的方法；② "一致性"的口径有四个互不蕴含的版本（第 3 章第 1 节），选哪个口径会改变结论；③ 长时一致性与内容多样性存在张力——最"一致"的生成是静止画面。本节给这三条各自的可测代理量，并明确标注哪些是 C 级推测。
  3. 评测标准的开放点在于"分辨能力"与"值得换"是两件事。 分辨一个真实差异所需样本 N=((zα​+zβ​)σ/Δmin​)2：Δmin​=10 时 N=25（α=0.05、功率 0.8、σ=20），Δmin​=20 时 N=7（表 2）。同一份评测里 Δmin​ 是固定的：想让 Δmin​ 减半，N 要涨 4 倍。 而"值不值得换"由业务阈值决定——本节能做的只是把前者算清楚，让后者不再含糊。
  4. 算力门槛的本质是"证据条数"。 C=6ND 把数据量换成卡时：N=6×1010、D=108 时 C=6.0×1019，1024 卡一遍 3.73 天、128 卡 29.8 天；把"复现两遍"写进 90 天工期约束，可行卡数下界是 2C/(η86400Dmax​)：D=108 时下界 110 卡（表 3）。门槛不是"能不能训"，是"能不能做出可复现的对比"。
  5. 数据版权上，本课只做技术与流程的可观测项，不做法律判断。 来源分层、许可/同意状态登记、去重报告、删除请求链路、合成内容标记——这些都是可核查的事实；而合法性、合理使用范围、期限这类判断必须按司法辖区逐案取得专业意见，本课不写法条、不给数字、不下结论（表 4）。
  6. 判断力的可执行形式是一张决策表。 全课五章的判据收成 18 行：现象 → 该看的量（含判据）→ 该动的旋钮 → 代价 → 出处（表 5）。用法只有一条：先找到现象、当场算出那个量；只有当它越过门槛时才去动旋钮，并接受那一行的代价。

主线一句话：面对一个视频系统，判断力的形式不是"知道更多方法"，而是"知道眼下这个现象该看哪个量、这个量越过哪个门槛才值得动、动了要付什么代价"——以及诚实地标注哪一步是推测。

一、开放问题（一）：长时一致性#

1.1 可算的部分：递推、越线步数与可检测门槛#

  5. 两条判据合起来：报告"长时一致性改进"时必须同时给 (a) 实测 λ 或 ρ 的变化，(b) 评测的 δmin​。只给"第 k 步的误差"而不给这两项的报告，无法区分"真改进了"与"这次没测出来"。

1.2 真正开放的三条（附 C 级推测标注）#

开放点 A：λ 与 ρ 能不能被预测？

  • 为什么难：λ 是模型、数据分布、任务容忍度的交互量，不是模型属性。同一个模型换任务（例如从"人脸说话"换到"流体模拟"）λ 会变；同一任务换分辨率 λ 也会变。目前没有从第一性原理出发预测 λ 的方法，只能实测。
  • 当前近似手段：短序列外推（用 k≤32 的误差拟合 λ，再外推 k=512）。代价：外推误差随 k 指数放大；第 4 章第 1 节在另一组参数上算过，忽略 ρ、只按 λ 估重锚周期会把周期高估 5.8098 倍——同一个错误在本节的递推里同样存在，而这里没有重锚可依赖。
  • 可测判据：把实测 λ 与"用前 1/4 序列拟合的 λ"对比，若差异 >10%，说明模型族（一阶线性递推）不成立，此时所有基于该模型的 K∗ 预测都不可信。
  • C 级推测：是否所有视频生成任务都存在一个"与分辨率无关的 λ"？ 目前证据不足。若成立，它会是很有价值的报告项；若不成立，跨论文比较长时一致性就缺少共同尺度。

开放点 B：四个一致性口径能否收敛到一个？

  • 为什么难：四个口径互不蕴含（第 3 章第 1 节），它们测的是不同的失效（像素抖、语义跳、拓扑错、物理违例），而且用不同的口径排序会得到不同的结论（第 3 章第 4 节表 3 的三个反例）。
  • 当前近似手段：报四个口径 + 一个预先声明的主口径。代价：报告成本翻倍，且四个数之间的"加权总分"不可解释（本课明确建议不要合成单一标量）。
  • 可测判据：口径之间的秩相关。如果在你的任务集上四个口径的 Spearman 相关都 >0.9，说明它们在你的场景里冗余，可以只报一个；如果 <0.5，它们测的是不同东西，必须并列报。
  • C 级推测：是否存在一个"充分的口径集合"（有限个口径能蕴含其余口径）？本课倾向于没有，因为一致性本质上是任务的属性。

开放点 C：一致性与多样性是不是一定冲突？

  • 为什么难：最"一致"的生成是常量输出（静止画面或同一张脸），它在所有一致性口径上满分。所以任何一个只测一致性的指标都能被"退化解"刷满。
  • 当前近似手段：把一致性与多样性/条件遵循一起报（第 3 章第 4 节的四轴），用"一致性 @ 固定多样性"的方式比较。代价：需要联合采样，评测成本上升；且"多样性"本身也有多个定义（pairwise 距离、模式覆盖率、条件熵）。
  • 可测判据：构造一个退化解基线（例如把首帧复制 T 次），要求所有报告的模型在一致性上显著优于该基线（用 δmin​ 判断显著）。这个基线必须出现在每一份长时一致性报告里——它是最便宜也最有效的防伪手段。
  • C 级推测：一致性与多样性能不能通过更好的表征解耦？ 这是一个实证问题；本课不给结论。

二、开放问题（二）：评测标准#

2.1 分辨能力：N 与 Δmin​ 的兑换#

  1. Δmin​ 由 N 决定，不由"仪器"决定：N=7 时能分辨的最小差异是 18.795983；N=25 时是 9.945899。所以"我们观测到 +10 的提升"这句话，在 N=7 的评测里根本没有被分辨出来。

  4. "显著"与"值得换"必须分开报：本表只算前者。后者需要一个业务阈值（换一次模型的成本），而那个阈值不该由评测方单方面设定。

2.2 评测标准的三个开放点#

开放点 D：基准与真实用途的错位。

  • 为什么难：公开基准为了可比性必须固定分布、分辨率、时长、指标；而真实用途的分布是漂移的。两者的差距无法用基准内部的数字衡量。
  • 当前近似手段：在基准之外加一个"自建压力集"（分布外、长尾、失败样例）。代价：不可与公开成绩直接比较；且自建集本身会被反复使用而污染（第 4 章第 4 节的泄漏率公式适用于它）。
  • 可测判据：基准分数与自建集分数的秩相关。若相关低（例如 <0.5），说明基准的选择在该场景下失去指导意义。这个量必须报。

开放点 E：评测集污染。

  • 为什么难：视频数据的近重复检测比文本难（同一场景的不同机位、不同剪辑、不同字幕）。第 4 章第 4 节的近重复泄漏率 1−(1−f)v−1（v=50 时 0.999982）说明：只要测试集里的场景在训练集里出现过，泄漏几乎是必然的。
  • 当前近似手段：场景级切分（按视频 id / 拍摄批次 / 地理时间聚类），而不是帧级随机切分。代价：测试集的有效多样性由场景数 U 决定（U=200,f=0.2⇒40 个有效测试场景），误差棒会变大好几倍。
  • 可测判据：报 (t,C,期望假阳性) 三元组（64 位哈希在 t=6 时对撞概率 4.5145×10−12，C=106 时只有 2.257252 对）。缺这个三元组的污染声明不可核验。

开放点 F：自动指标与人评的关系。

  • 为什么难：第 3 章第 4 节已经量化过：噪声尺度超过真值差中位数（0.581434）时，自动指标与人评的排序相关会掉到接近零甚至负值（Pearson +1.000000→−0.125630）。
  • 当前近似手段：报"相关系数 + 样本量 + 前 k 命中率"三件套。代价：人评成本高、可复现性差（人评本身有偏）。
  • 可测判据：前 k 命中率（k 个模型里自动指标选出的前 k 是否命中人评的前 k）。随机基线是 k2/M；命中数低于它的自动指标不能用。
  • C 级推测："人评能否被一个校准良好的自动指标完全替代"？ 本课倾向于不能，因为人评捕捉的是"意图一致性"与"可用性"，而这两者不由像素统计量决定。这是一个立场，不是结论。

3.2 算力门槛的两个开放点#

开放点 G：训练与推理的算力能不能互换？

  • 为什么难：视频模型的成本结构里，训练侧是 O(ND)、推理侧是 O(T2)（T 是生成帧数）。两者的瓶颈不同（前者是算力与通信，后者是显存带宽与 KV）。
  • 当前近似手段：用更多推理算力换更少的训练（测试时搜索、更多采样、更好的解码）。代价：推理成本随帧数平方增长，长视频上这个交换会失效（第 4 章第 2 节的 Amdahl 归因：真实加速远小于连乘）。
  • 可测判据：单位质量的边际成本 d(质量)/d(FLOPs) 在两侧的比值。若推理侧的边际收益已经降到训练侧的 1/10 以下，继续加推理算力是亏的。

开放点 H：数据量与模型规模的最优配比是否与语言模型一致？

  • 为什么难：语言模型的缩放律是在离散 token 上、以"下一个 token 的似然"为目标得到的；视频的目标是连续高维分布，且评测不收敛到一个标量（第 2 节的开放点 B）。配比律的推导前提不成立。
  • 当前近似手段：按语言模型的配比外推、再按算力截断。代价：这个外推没有可验证的依据，一旦视频的缩放行为不同（例如数据质量维度更多），结论会偏。
  • C 级推测：视频侧存在与语言侧同形的缩放律——本课认为这是一个未被验证的假设，而不是结论。凡是引用"按缩放律应当用 X 倍数据"的论证，都要把它的前提（同形、同评测、同数据质量曲线）写明。

4.2 与接口的耦合（本节唯一的技术结论）#

版权与同意状态直接限制接口的两侧：

  • 条件侧：如果一个实体（人脸、品牌、地点）的来源不可清，那么它不能出现在结构化条件里——即使它在像素上被模糊了，"以该实体为条件"本身就是使用。
  • 增强侧：如果生成数据的训练来源不可清，那么把它当训练数据回喂（第 1 节的增强管道）会把风险沿管道放大：一个不可清的来源 → 一个生成模型 → 一个下游理解模型。

判据（可执行）：给每个数据来源打一个状态标签（可清 / 需评估 / 未知 / 排除），并让接口契约（第 1 节 §3.2 的六字段）里的"量的语义"字段引用这个标签。这样"来源状态"就变成了一个结构化的接口字段，而不是一段免责声明。

一个开放点：

开放点 I：合成数据的"内容"如何标记与追溯？

  • 为什么难：合成内容与真实内容的区别在像素上是渐近的（尤其经过压缩、二次编辑后）；而"生成"这个事实只存在于生产环节的元数据里，一旦脱离元数据就不可恢复。
  • 当前近似手段：把来源与编辑历史编码进可验证元数据的内容凭证机制，以及流水线级的来源登记。代价：需要全链路支持；二次编辑可能破坏凭证；不同平台与工具的支持度不一。
  • C 级推测："内容凭证"会不会成为视频生成的事实标准？ 本课不给预测。可以确定的只有一条：在不支持凭证的管道里，"这是合成的"这件事无法从内容本身恢复——所以技术上的做法只能是"在生产环节留下结构化记录"，而不是"在像素里找痕迹"。

六、全课收束#

全课收束：这门课从一个加法开始——视频只比图像多一维，但这一维同时引爆了存储、采样与计算三笔账，于是"很多张图"必须变成"一条时空 token 序列"，四代表示就是这条转换路上的四次结构性换手（第 1 章）。接着把这条序列接到四个任务上：识别、定位、问答、跟踪与分割，每个任务的指标都自带口径，口径不写清成绩就不可比（第 2 章）。然后反过来做生成：多出来的是误差轴、噪声调度的维度与条件通道的信息上限，三者共同决定"能生成多长、能控多准"（第 3 章）。把长度与效率推到工程极限时，瓶颈会在算力、显存、延迟、功耗之间迁移，而评测本身也会骗人——所以两者都要在动手前算（第 4 章）。最后这一章把两条方向相反的问题收在一起：理解与生成之间的接口要按 bit 与时序精度办契约，视频模型与世界模型之间的界线要按动作通道与干预问句来划，而真正没有答案的问题（长时一致性、评测标准、算力门槛、数据来源）必须连同它们的可测代理量一起写出来。这门课不提供"最佳配置"，它提供的是把配置写成不等式的方法，以及在哪些条件下这个不等式会失效。

"""第 5 章 第 3 节 数值脚本（正文表 1~表 5）。"""
import math
import unicodedata


def dwidth(s):
    return sum(2 if unicodedata.east_asian_width(ch) in ("W", "F") else 1
               for ch in s)


def pad(s, w, align=">"):
    gap = max(0, w - dwidth(s))
    if align == ">":
        return " " * gap + s
    if align == "<":
        return s + " " * gap
    left = gap // 2
    return " " * left + s + " " * (gap - left)


def row(cells, widths, aligns=None):
    aligns = aligns or [">"] * len(cells)
    return " | ".join(pad(c, w, a) for c, w, a in zip(cells, widths, aligns))


def rule(widths):
    return "-+-".join("-" * w for w in widths)


F = lambda x: f"{x:.6f}"
E = lambda x: f"{x:.4e}"


def z_alpha(a):
    """标准正态上分位：用 erfc 做二分求 P(Z>z)=a（区间 [-10,10]）。"""
    lo, hi = -10.0, 10.0
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        tail = 0.5 * math.erfc(mid / math.sqrt(2.0))
        if tail > a:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)

# 长时一致性：漂移的闭式、翻倍时间与可检测性
def table1():
    print("表 1  长时一致性的可算判据：漂移递推、越线步数与可检测性")
    print("构造：一阶递推 eps_k = lam*eps_k-1 + rho，eps_0=0.05、rho=0.004；")
    print("      判为「不一致」的阈值 delta=0.20；检测噪声 sd=0.02、n=64 次重复。")
    eps0, rho, delta = 0.05, 0.004, 0.20
    n, sd = 64, 0.02

              widths))

    for lam in (0.980, 0.995, 1.000, 1.005, 1.010, 1.020, 1.050):
        eps = eps0
        Kstar = None
        for k in range(1, 20001):
            eps = lam * eps + rho
            if Kstar is None and eps > delta:
                Kstar = k
        eps100 = eps0
        for _ in range(100):
            eps100 = lam * eps100 + rho
        einf = rho / (1.0 - lam) if lam < 1.0 else float("inf")
        det = "是" if delta > dmin else "否"
        print(row([F(lam), str(Kstar) if Kstar else "inf", F(eps100),
                   F(einf) if einf != float("inf") else "inf", F(dmin), det],
                  widths))
    print()
    print("  读法：lam 只差 0.01（1.00 -> 1.01），越线步数从")

# 评测标准：需要多少样本才能分辨一个真实提升
def table2():
    print("表 2  评测标准的功率账：分辨真实提升需要多少样本")
    print("构造：重复测量 sd=20、Alpha=0.05、功率 1-beta=0.80；")
    print("      N 由 N=((z_a+z_b)*sd/D_min)^2 反解，D_min=最小可分辨差异。")
    widths = [10, 12, 12, 12, 14, 16]
    print(row(["D_true", "D_min=10", "D_min=20", "N(80%)", "P_漏判", "结论"],
              widths))
    print(rule(widths))
    za, zb = z_alpha(0.05), z_alpha(0.20)
    for Dtrue in (10.0, 20.0, 50.0, 100.0):
        for Dmin in (10.0, 20.0):
            N = math.ceil(((za + zb) * 20.0 / Dmin) ** 2)
            dmin = (za + zb) * 20.0 / math.sqrt(N)
            # 真实差异 Dtrue 被检出的概率：P(Z > z_a - Dtrue/dmin*z_b 近似)
            power = 1.0 - 0.5 * (1.0 + math.erf((za - Dtrue / 20.0 * math.sqrt(N))
                                                / math.sqrt(2.0)))
            print(row([F(Dtrue), F(Dmin), str(N), F(dmin), F(1 - power),
                       "可分辨" if dmin <= Dtrue else "不可分辨"], widths))
    print()
    print(f"  z_(0.05)={F(za)}、z_(0.20)={F(zb)}：N = ((z_a+z_b)*sd/D_min)^2。")
    print("  三条判据：")
    print("  1) 报告只写「提升 Delta」，不写「能分辨的最小差异 D_min」与 N，")
    print("     那么这个提升在统计上是一个未定义的量。")
    print("  2) 同一份评测里 D_min 是固定的：想让 D_min 减半，N 要涨 4 倍。")
    print("  3) 「显著」与「值得换」是两件事：D_min 由 N 决定，而值不值得换")
    print("     由业务阈值决定——本表只负责把前者算清楚。")
    return

小结#

  • 长时一致性：递推 εk​=λεk−1​+ρ 的三档分界（λ=0.98 永不越线、1.00 时 K∗=38、1.05 时 16 步）；可检测门槛 δmin​=1.962​σ/n​=0.006930。"测不出差异"不能推出"没有漂移"。 三个开放点：λ 不可先验预测、四个口径不收敛、一致性与多样性有张力——各有可测代理量与C 级推测标注。
  • 评测标准：N=((zα​+zβ​)σ/Δmin​)2，σ=20 时 Δmin​=10⇒N=25、Δmin​=20⇒N=7；漏判概率可算（0.626265）。精度按 N2 换；"显著"与"值得换"必须分开报。 三个开放点：基准与用途错位、评测集污染（报 (t,C,期望假阳性)）、自动指标与人评（报前 k 命中）。
  • 算力门槛：C=6ND；N=6×1010,D=108 时 C=6.0×1019，1024 卡一遍 3.73 天、两遍下界 110 卡。预算买的是证据条数，不是正确性；MFU 是隐藏旋钮（0.35→0.25 等于卡打 7 折）。两个开放点：训练/推理算力可否互换、视频缩放律是否与语言同形（后者明确标为未验证假设）。
  • 数据来源与版权：只做可观测项与流程项（来源分层、许可/同意登记、去重报告、删除链路、合成标记）。本课不写法条、不给数字、不做合法性判断；条件是接口的六字段之一（"量的语义"引用来源状态标签）。开放点：合成内容的标记与追溯（C2PA 类凭证；不给预测）。
  • 决策表（18 行）：现象 → 该看的量（含判据）→ 该动的旋钮 → 代价 → 出处，跨 ch1–ch5。用法三步：先算量、越过门槛才动、接受该行的代价。 跨章关系不是并列清单：ch1 的量决定 ch4 的旋钮，ch2 的口径决定 ch3 的评测，ch3 的量决定 ch5 的门槛。
