标注与可读性#

一张图的价值，取决于读者能不能快速看懂它。好的标注能替作者"开口说话"：告诉读者这张图在讲什么、关键点在哪里、异常值为何值得注意。这一课讲如何用标题、轴标签、图例、注释和数据标签，把一张"能看的图"变成一张"好读的图"。

一、概念讲解#

1. 标注的三个层次#

标注不是越满越好，而是分层次的：

  • 基础层（必须）：标题（讲清主题）、x/y 轴标签（讲清单位与变量）、图例（讲清系列含义）。没有这一层，图基本不合格。
  • 强调层（按需）：用 annotate 或箭头，把读者的目光引向某个关键数据点（峰值、拐点、异常值）。
  • 辅助层（锦上添花）：网格线、参考线（如平均线）、数据标签（在柱顶标数值）。

2. annotate：带箭头的注释#

ax.annotate(text, xy, xytext, arrowprops) 是最常用的注释工具：

  • text：注释文字。
  • xy：箭头指向的数据点坐标（被解释的点）。
  • xytext：注释文字摆放的坐标。
  • arrowprops：箭头样式字典，如 dict(arrowstyle='->', color='red')。

3. 可读性：留白、字号与网格#

  • 字号：标题 > 轴标签 > 刻度标签，层级要分明；正文 1012 号、标题 1416 号是常用区间。
  • 留白：fig.tight_layout() 或 constrained_layout 自动处理子图重叠；不要让文字和曲线挤在一起。
  • 网格线：ax.grid(True, alpha=0.3) 加淡色网格，帮助读者对齐数值，但网格要淡、别喧宾夺主。

二、可运行代码示例#

示例 1：标注一张"增长曲线"的关键点#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

# 模拟某产品 12 个月的累计用户数（万人）
month = np.arange(1, 13)
users = [1.0, 1.6, 2.3, 3.1, 4.0, 5.2, 7.0, 9.5, 12.0, 15.5, 19.0, 24.0]

fig, ax = plt.subplots(figsize=(9, 5.5))

# 基础层：曲线、标题、轴标签、网格
ax.plot(month, users, marker='o', color='tab:blue', label='累计用户数')
ax.set_title('某产品全年累计用户增长', fontsize=15)
ax.set_xlabel('月份')
ax.set_ylabel('累计用户数（万人）')
ax.grid(True, alpha=0.3)

# 强调层：标注增长最快的拐点（第 8 个月，斜率最大）
peak_month = 8
ax.annotate(
    '第 8 个月增长最快',
    xy=(peak_month, users[peak_month - 1]),          # 箭头指向的数据点
    xytext=(peak_month + 1.5, users[peak_month - 1] - 5),  # 文字摆放位置
    arrowprops=dict(arrowstyle='->', color='tab:red'),
    fontsize=11,
    color='tab:red',
)

# 辅助层：给每个数据点标上数值
for m, u in zip(month, users):
    ax.text(m, u + 0.6, f'{u:.1f}', ha='center', fontsize=9)

ax.legend(loc='upper left')
fig.tight_layout()
plt.show()

要点：xy 是"箭头指向谁"，xytext 是"文字放在哪"，两者是两组独立的坐标；arrowprops 里 arrowstyle='->' 指定箭头样式；ax.text 的 ha='center' 让数值标签在数据点正上方居中。

示例 2：加平均参考线#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

rng = np.random.default_rng(3)
scores = rng.normal(70, 12, 60)         # 60 名学生成绩，均值 70、标准差 12
avg = scores.mean()

fig, ax = plt.subplots(figsize=(8, 5))
ax.hist(scores, bins=12, color='tab:cyan', edgecolor='white', label='成绩分布')

# 画平均线并标注
ax.axvline(avg, color='tab:red', linestyle='--', linewidth=1.5)
ax.text(avg + 0.5, 10, f'平均分 {avg:.1f}', color='tab:red', fontsize=11)

ax.set_title('成绩分布与平均分', fontsize=14)
ax.set_xlabel('成绩')
ax.set_ylabel('人数')
ax.legend()
fig.tight_layout()
plt.show()

要点：axvline 画竖直参考线，axhline 画水平参考线；参考线用虚线、与数据线区分颜色，并配文字说明它代表什么。

三、练习#

  1. 动手练习：给"示例 1"的曲线再加一条注释，标注"第 1 个月起点"，文字放在起点下方，箭头指向起点。
  2. 数据标签：把一张柱状图改造为"每根柱子顶部标注数值"，注意调整数值标签的垂直偏移，避免和柱子重叠。
  3. 读图自测：随便找一张你自己之前画的图，遮住标题和图例后给一个不懂数据的朋友看，问他"这张图在讲什么"；根据他的反馈，判断你的基础层标注是否到位。
  4. 思考：什么时候"数据标签"是多余的、甚至会伤害可读性？在折线图、柱状图、散点图上，数据标签的适用性有什么不同？
