梯度计算#

上一课我们见到了 .backward() 的"魔法"，但它有不少细节需要掌握才能真正用于训练：梯度会累加、对非标量求导要传一个方向向量、以及如何临时关闭梯度。这些不是边角料——训练循环里天天都要跟它们打交道。本课逐个讲透，并给出对应的正确写法。

一、概念讲解#

1. 梯度是累加的#

调用一次 backward()，得到的梯度会加到 .grad 上，而不是覆盖。原因：某些场景需要在同一个图上对多个损失分别反向（例如多任务学习的多个损失相加后一次反向，或某些需要多次反向的算法），PyTorch 选择了"累加"这一更灵活的默认行为。

后果是：每个训练 step 开始前必须清零梯度，否则上一次的梯度会污染本次更新。清零方式：

  • 对某个张量：w.grad.zero_()；
  • 对整个模型（第 3 章会大量使用）：optimizer.zero_grad()。

2. 对非标量求导需要"方向向量"#

backward() 只能对一个标量（0 维）直接调用。若输出是向量/矩阵（例如 y 形状 (3,)），直接 y.backward() 会报错。此时要传入与 y 同形状的 gradient 参数，表示"沿这个方向加权求和"：

  • 标量输出：loss.backward()，等价于乘以 1。
  • 非标量输出：y.backward(torch.ones_like(y))，等于把各分量导数按权重相加。

这在"雅可比向量积"语境下很自然：反向传播本质是计算雅可比矩阵与一个向量的乘积，而不是直接计算整个雅可比。

3. 保留计算图：retain_graph#

默认 backward() 跑完后会释放计算图（释放中间结果的缓存），因此对同一个输出调用两次 backward() 会报错。若确实需要再次反向，第一次调用时加 retain_graph=True。多数训练场景不需要它，只在"要对同一前向多次求导"（如某些对抗训练、二阶方法）时才用。

4. 临时关闭梯度：no_grad 与 detach#

  • torch.no_grad() 上下文：在其内部所有运算都不构建计算图、不追踪梯度。推理、评估、手工更新参数时用它，省内存、提速。
  • .detach()：从当前计算图里"摘出"一个张量的副本（共享数据，但不再携带梯度历史）。常用于把需要梯度的张量转成纯数值使用。

二、可运行代码示例#

import torch

# ---- 1. 梯度累加与清零 ----
w = torch.tensor(2.0, requires_grad=True)
loss = w ** 2                    # L = w^2, dL/dw = 2w = 4
loss.backward()
print("第一次 backward 后 w.grad =", w.grad)   # 4.0

loss.backward()                  # 再来一次：梯度累加
print("第二次 backward 后 w.grad =", w.grad)   # 8.0（4 被加了两次）

w.grad.zero_()                   # 清零
loss.backward()
print("清零后   backward 后 w.grad =", w.grad)   # 4.0

# ---- 2. 非标量求导：传入方向向量 ----
x = torch.tensor(2.0, requires_grad=True)
y = x ** torch.tensor([1.0, 2.0, 3.0])   # y = [x, x^2, x^3]，形状 (3,)
# 各分量导数 = [1, 2x, 3x^2] = [1, 4, 12]
y.backward(torch.ones(3))                 # 用全 1 方向：求和 = 1+4+12
print("\n非标量 backward(ones) 后 x.grad =", x.grad)   # 17.0

# ---- 3. 临时关闭梯度 ----
z = torch.tensor(3.0, requires_grad=True)
with torch.no_grad():
    q = z * z                    # no_grad 内不建图
print("\nno_grad 内结果 requires_grad =", q.requires_grad)  # False
print("q.grad_fn =", q.grad_fn)  # None

# ---- 4. detach：摘出纯数值 ----
p = torch.tensor(2.0, requires_grad=True)
r = p ** 2
r_detached = r.detach()          # 数值相同，但不再追踪梯度
print("\nr =", r, "| r_detached.requires_grad =", r_detached.requires_grad)  # False

运行要点：第一次 backward 后 w.grad=4，第二次直接 backward 会变成 8（累加）；x.grad=17 对应非标量加权的链式结果。

三、练习#

  1. 写一个两行的"训练步"骨架：定义 w（需要梯度）、算损失、反向、清零梯度，并说明清零放在反向之后的意义。
  2. 设 x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)，y = (x ** 2).sum()。y 是标量吗？直接 y.backward() 能得到什么？x.grad 应是多少？
  3. 对一个非标量输出 y = x ** 2（x 形状 (3,)），直接 y.backward() 会怎样？改用 torch.ones_like(y) 后结果如何，解释其数学含义。
  4. 什么场景下需要 retain_graph=True？为什么默认释放计算图对显存友好？
