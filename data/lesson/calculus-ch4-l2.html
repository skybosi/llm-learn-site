计算图#

计算图把一串复杂的公式画成一张"流程图"：每个节点是一步简单运算，边是数据流向。有了它，求导这件事就能被拆成一个个独立的小零件。

一、概念讲解#

1. 什么是计算图#

计算图（computation graph）是一种用图来表示算式的方式：

  • 节点（node）：代表一个数值，它既可以是输入，也可以是某步运算的结果；
  • 边（edge）：代表数据从哪个节点流向哪个节点；
  • 运算：描述父节点是如何由子节点"组合"出来的。

例如 f = (a + b) * c 可以画成三层：输入节点 a、b、c，中间节点 u = a + b，输出节点 f = u * c。这是一个有向无环图（DAG），数据只能沿箭头方向前进。

2. 前向传播：从输入算到输出#

沿着计算图从输入节点一路算到输出节点，就叫前向传播（forward pass）。它做的事和普通的"按公式代入求值"完全一样，只是把中间每一步都单独存下来了。

3. 局部偏导数：每个节点只管自己#

计算图求导的妙处在于"局部性"：每个节点只关心它自己的这一步运算对每个输入的偏导，而不需要知道整个公式长什么样。比如：

  • 对节点 u = a + b：∂u/∂a = 1，∂u/∂b = 1；
  • 对节点 f = u * c：∂f/∂u = c，∂f/∂c = u。

这些就叫做局部梯度。整条复杂的链式法则，最终就是由这些局部梯度"拼接"而成的。

4. 为什么需要计算图#

  • 它把"整条公式"拆成了"一个个简单运算"，每个局部梯度都非常好算；
  • 中间值被保存下来，反向传播时可以复用，避免重复计算；
  • 深度学习的框架（如 PyTorch 的 autograd）正是用计算图来自动求导的。

二、可运行示例#

示例 1：手动展开一张计算图#

把 f = (a + b) * c 的前向值手写出来，并在注释里列出每个节点的局部梯度。

a, b, c = 2.0, 3.0, 4.0

u = a + b        # 节点 u = a + b，局部梯度 ∂u/∂a = 1, ∂u/∂b = 1
f = u * c        # 节点 f = u * c，局部梯度 ∂f/∂u = c, ∂f/∂c = u

print("u =", u, ", f =", f)
print("f 对 u 的局部梯度 =", c)
print("f 对 c 的局部梯度 =", u)
print("u 对 a、b 的局部梯度 = 1, 1")

示例 2：用 Node 类记录"值 + 局部梯度"#

写一个最小的 Node 类，让每个节点既存数值，也存它对自己子节点的局部梯度。

class Node:
    """计算图节点：存数值、子节点、运算名，以及本节点对各子节点的局部梯度。"""
    def __init__(self, value, children=(), op="", local_grads=None):
        self.value = value                    # 本节点的数值
        self.children = tuple(children)       # 产生本节点的子节点
        self.op = op                          # 运算名，便于阅读
        self.local_grads = local_grads or []  # 与 children 一一对应的局部梯度

def add(a, b):
    # z = a + b，两个局部梯度都是 1
    return Node(a.value + b.value, (a, b), "+", [1.0, 1.0])

def mul(a, b):
    # z = a * b，∂z/∂a = b，∂z/∂b = a
    return Node(a.value * b.value, (a, b), "*", [b.value, a.value])

x = Node(2.0, op="x")
y = Node(3.0, op="y")
c = Node(4.0, op="c")

u = add(x, y)     # u = x + y
f = mul(u, c)     # f = u * c

print("f 的值 =", f.value)
print("f 对 u 的局部梯度 =", f.local_grads[0])  # 应为 c = 4
print("f 对 c 的局部梯度 =", f.local_grads[1])  # 应为 u = 5
print("u 对 x 的局部梯度 =", u.local_grads[0])  # 应为 1

示例 3：单神经元的前向计算图#

把上一课的 sigmoid 神经元展开成一张计算图，打印每个中间节点的值，并写出各节点"这一步"的局部偏导。

import math

# 单神经元：x1,x2 -> 加权和 z -> sigmoid 激活 a -> 平方损失 L
x1, x2 = 0.6, 0.3
w1, w2 = 0.5, -0.4
b = 0.1
y_true = 1.0

# 前向传播，逐节点求值
z = w1 * x1 + w2 * x2 + b
a = 1.0 / (1.0 + math.exp(-z))
L = (a - y_true) ** 2

print("节点值：z =", round(z, 4), ", a =", round(a, 4), ", L =", round(L, 4))

# 每个节点只负责"自己这一步"的局部偏导（链式法则的零件）：
dL_da = 2 * (a - y_true)     # L=(a-y)^2 对 a 求导
da_dz = a * (1 - a)          # sigmoid 对 z 求导
print("局部梯度：dL/da =", round(dL_da, 4), ", da/dz =", round(da_dz, 4))
print("局部梯度：dz/dw1 =", x1, ", dz/dw2 =", x2, ", dz/db = 1")

三、练习#

  1. 画出 f = (a * b) + (a * c) 的计算图，标出每个节点，并写出每个节点的局部梯度。
  2. 在示例 2 的基础上，给 Node 增加一个 square 运算（z = a²），并补上它的局部梯度 ∂z/∂a = 2a。
  3. 修改示例 3 的参数 w1，观察 z、a、L 以及各个局部梯度会如何变化，试着解释它们之间的连锁关系。
