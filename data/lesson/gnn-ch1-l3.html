图机器学习任务#

有了图的表示，接下来问一个更实际的问题：在图数据上，我们到底要预测什么？图机器学习任务可以按"预测对象"分成三大类——节点级、边级、图级。这三类任务贯穿全书：节点分类是 GCN 最经典的练兵场，链路预测是推荐系统的底层模型，图分类则是药物发现的核心。这一课把它们统一到"学一个能利用图结构的函数"这个框架下，并顺带说清两个绕不开的概念：直推（transductive）与归纳（inductive）。

一、概念讲解#

1. 节点级任务：给节点打标签#

节点分类：给定图中部分节点的标签，预测其余未标注节点的标签。典型例子：

  • 论文引用网络 Cora：已知部分论文的学科，预测其余论文的学科；
  • 社交网络：已知部分用户是否"水军"，找出其余水军。

节点级任务的核心直觉是：一个节点的标签，和它邻居的标签高度相关（物以类聚）。所以只看节点自身特征往往不够，必须把邻居信息聚合进来——这直接引出了消息传递机制。

2. 边级任务：预测关系#

链路预测（link prediction）：给定图中已有的边，判断两个节点之间是否应该存在（或未来会出现）一条边。典型例子：

  • 社交平台的"可能认识的人"推荐；
  • 知识图谱补全：预测"实体 A 和实体 B 是否存在某关系"；
  • 药物靶点相互作用预测。

链路预测通常的做法是：先把两个节点各自用 GNN 编码成向量，再对两个向量做一个打分函数（内积、拼接后接 MLP 等），分数高就认为有边。它其实和推荐系统里的"用户-物品打分"是同构的。

3. 图级任务：给整张图打标签#

图分类 / 图回归：给定一整张图，输出一个标签或数值。典型例子：

  • 分子性质预测：输入分子图，输出是否有毒、溶解度多少；
  • 蛋白质结构分类；
  • 程序依赖图上的代码缺陷检测。

图级任务需要把整张图压缩成一个向量。做法是先用 GNN 得到每个节点的向量，再用一个读出（readout）函数（求和、平均、取最大值，或更复杂的层次池化）把节点向量聚合成图向量。读出函数的设计是图级任务的关键一环。

4. 直推 vs 归纳#

这两个词描述的是"模型能不能推广到没见过的节点/图"：

  • 直推（transductive）：训练时就能看到整张图（包括测试节点的特征和连边，只是不知道它们的标签）。模型学的是"在这张固定的图上如何传播标签"。早期 GCN 的论文就在这种设定下做实验——测试节点虽没标签，但它们和训练节点同处一张图，图结构全程可见。
  • 归纳（inductive）：测试时要面对全新的图或全新的节点，训练时完全没见过。比如训练时用社交网络 A，上线后要处理社交网络 B。归纳能力更贴近真实生产，也是 GraphSAGE 这类方法的重要卖点（第四章会专门讲）。

理解这个区别，才能读懂论文里的实验设定：很多早期方法在直推设定下表现很好，但一到归纳设定就失效，因为它们的参数"记住"了训练图的具体结构。

5. 为什么 GNN 适合这些任务：置换不变性#

图任务有一个特殊约束：节点的编号是人为赋予的，交换两个节点的编号，图本身没有任何变化。因此一个合理的图模型，其输出不应该依赖节点编号的顺序——这叫置换不变性（permutation invariance）。图级任务的输出必须置换不变，而节点级任务要求"节点置换后，每个节点的输出跟着节点一起置换"——这叫置换等变性（permutation equivariance）。GNN 的消息传递天然满足这两个性质，这是它区别于"把节点随机排列后塞进 MLP"的关键优势。下一章我们会看到这种性质是如何从"对邻居集合做对称聚合"自然涌现的。

二、可运行代码示例#

我们用 NumPy 搭一个"两个社区"的小图，直观体会为什么只看节点特征不够、必须用图结构。节点 0–4 属于社区 A，5–9 属于社区 B；社区内部全连接，社区之间只有一条"桥"。我们给节点构造带有强噪声的特征，然后对比"只用原始特征分类"和"先做一次邻居特征平均再分类"两种方案的准确率。

import numpy as np

# 1) 构造两社区图：0-4 为 A，5-9 为 B
n = 10
labels = np.array([0] * 5 + [1] * 5)

edges = []
for i in range(5):
    for j in range(i + 1, 5):
        edges.append((i, j))
for i in range(5, 10):
    for j in range(i + 1, 10):
        edges.append((i, j))
edges.append((2, 7))          # 两社区之间唯一的一条"桥"

A = np.zeros((n, n))
for u, v in edges:
    A[u, v] = A[v, u] = 1.0

# 2) 节点特征：社区 A 整体右移、社区 B 整体左移，再叠加强噪声
rng = np.random.default_rng(42)
X = rng.normal(size=(n, 2))
X[:5] += 1.0
X[5:] -= 1.0
X += rng.normal(scale=2.0, size=(n, 2))   # 噪声很大，单看特征几乎分不清

# 3) 方案一：只用原始特征做线性分类（最小二乘拟合标签）
def linear_fit_classify(features):
    Xb = np.hstack([features, np.ones((n, 1))])   # 加偏置列
    W = np.linalg.lstsq(Xb, labels, rcond=None)[0]
    pred = (Xb @ W > 0.5).astype(int)
    return (pred == labels).mean()

acc_raw = linear_fit_classify(X)
print("只用原始特征分类的准确率：", acc_raw)

# 4) 方案二：先做一次邻居特征平均（消息传递的雏形），再分类
D_inv = np.diag(1.0 / A.sum(axis=1))   # 度数归一化
X_agg = D_inv @ A @ X                   # 每个节点 = 邻居特征的均值
acc_agg = linear_fit_classify(X_agg)
print("邻居聚合后再分类的准确率：", acc_agg)

运行后你会发现，在特征噪声很大的情况下，"邻居聚合"这一步显著提升了准确率。原因很直观：虽然单个节点的特征因噪声而不可靠，但一群邻居的特征取平均后噪声被摊薄了，而且同社区节点互相聚合会放大共同模式。这就是图结构的威力，也是下一章要系统化学习的消息传递思想的一个"预告片"。

三、练习#

  1. 把上面的噪声强度从 scale=2.0 改成 0.5，两种方案的准确率差距会怎么变？解释为什么噪声越小，图结构的增益越小。
  2. 把"桥"边 (2, 7) 改成 3 条社区间边（如 (1,6)、(3,8)、(4,9)），重新实验，观察聚合方案准确率的变化，并说明社区间边增多为何会让分类变难。
  3. 为链路预测写一个最朴素的基线：对任意两个节点，用它们特征的余弦相似度作为"是否有边"的分数，评估它能否区分"社区内节点对"和"社区间节点对"。
  4. 思考：图级任务里，如果直接把所有节点特征求和作为图向量，这个操作满足置换不变性吗？平均和取最大值呢？
