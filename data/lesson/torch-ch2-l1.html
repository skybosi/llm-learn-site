自动微分原理#

训练神经网络靠的是梯度下降，而梯度下降要算"损失对每个参数的偏导数"。手推公式、数值差分、符号求导都有各自的局限。PyTorch 的核心竞争力之一，就是自动微分（autograd）——你只需写前向计算的普通代码，反向的梯度它自动帮你算好。本课讲原理：自动微分和数值微分、符号微分差在哪，以及它如何做到"像写前向一样拿到梯度"。

一、概念讲解#

1. 求导的三条路#

设损失 L(w)=(wx−y)2，要算 dL/dw。有三种方式：

  • 数值微分：用差分 hL(w+h)−L(w)​ 近似。实现简单，但有截断误差和舍入误差，且每个参数都要额外跑一次前向，参数多了就慢到不可用。
  • 符号微分：对表达式做代数求导，得到精确的导函数。但表达式爆炸增长（"表达式膨胀"），且遇到分支、循环、if 等控制流就失效。
  • 自动微分：不是"近似"，也不是"对整条公式求导"。它把前向计算拆成一张由基本运算节点组成的图，再用链式法则从输出往回逐步传播，得到与符号求导同样精确的梯度。图 2-1 对比了三者的思路。

自动微分的精度是机器精度的量级，且每个节点只需 O(1) 的局部导数计算，总代价与前向计算同量级。

2. 自动微分的基本流程#

PyTorch 的自动微分只需要两步：

  1. 把"要求梯度的输入"标记为 requires_grad=True；
  2. 正常写前向计算，最后调用 loss.backward()。

之后，每个被标记张量的 .grad 里就存好了梯度。这一切背后，PyTorch 在每一步运算时都悄悄记录"这个结果是由谁、经什么算子算出来的"，构成一张动态计算图（第 3 课详述），backward() 就是在这张图上反向走一遍链式法则。

3. 叶子张量与 requires_grad#

  • 叶子张量（leaf tensor）：直接由用户创建、不依赖其他张量的张量。只有叶子的 .grad 会被填充。
  • requires_grad=True：表示"我需要这个张量的梯度"。它开启后，凡是参与这个张量的运算结果也会自动带上梯度需求（requires_grad 会向后代传播）。

对比记忆：x 是叶子、y = x ** 2 是中间结果（非叶子）。y.backward() 之后，x.grad 有值，而 y.grad 是 None。

4. 为什么不直接给你所有梯度#

  • 只对叶子存梯度，避免为海量中间结果占用内存；
  • 中间结果在反向传播后默认被释放，这是 PyTorch 控制显存的关键设计（下一课会讲 retain_graph）。

二、可运行代码示例#

import torch

# ---- 最小例子：y = x^2，求 dy/dx ----
x = torch.tensor(2.0, requires_grad=True)   # 标记：要 x 的梯度
y = x ** 2                                  # 前向计算
y.backward()                                # 反向：链式法则
print("x.grad =", x.grad)                   # 2*2 = 4.0

# ---- 复合函数：L = (w*x - y)^2 ----
w = torch.tensor(1.0, requires_grad=True)
xx = torch.tensor(2.0, requires_grad=True)
yy = torch.tensor(5.0)                      # 目标值，不要求梯度

loss = (w * xx - yy) ** 2                   # L = (2w - 5)^2
loss.backward()
# dL/dw = 2*(w*x - y)*x = 2*(2-5)*2 = -12
print("\nloss =", loss.item())
print("w.grad =", w.grad)                   # -12.0
print("xx.grad =", xx.grad)                 # dL/dx = 2*(w*x-y)*w = -6.0

# ---- requires_grad 的向后传播 ----
a = torch.tensor(1.0)                       # 未标记
b = torch.tensor(2.0, requires_grad=True)
c = a * b                                   # c 参与过带梯度的 b
print("\nc.requires_grad =", c.requires_grad)   # True：梯度需求会传播

# ---- 中间结果不是叶子，.grad 为 None ----
print("y.is_leaf =", y.is_leaf)             # False（y 是 x 算出来的）
print("x.is_leaf =", x.is_leaf)             # True
print("y.grad =", y.grad)                   # None：默认不存非叶子梯度

验证要点：x.grad 应为 4.0；复合例子里 w.grad 应为 -12.0；c.requires_grad 为 True 说明"梯度需求"会自动向后代传播。

三、练习#

  1. 设 x = torch.tensor(3.0, requires_grad=True)，计算 y = x**3 + 2*x 并对 y 求导，手算 dy/dx，再与 x.grad 对比。
  2. 把上面复合例子中的 yy 改成 requires_grad=True 再跑一遍，观察 yy.grad 是多少，解释为什么它是"对目标的梯度"。
  3. 判断题：a = torch.tensor(1.0)（未标记）与 b = torch.tensor(2.0, requires_grad=True) 相加得到 c，那么 c.backward() 能成功，且 a.grad 会被填充。这句话哪里错了？
  4. 思考：为什么 PyTorch 选择"只保存叶子张量的梯度"而不是保存所有中间结果的梯度？这对训练大模型的内存有什么意义？
