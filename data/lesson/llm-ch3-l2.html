BERT 架构#

上一课讲了 BERT"做什么"（填空），这一课讲 BERT"长什么样"。BERT 是仅编码器（encoder-only）的 Transformer：堆叠多层双向自注意力，靠 [CLS]、[SEP] 两个特殊 token 组织输入，用"词嵌入 + 分段嵌入 + 位置嵌入"三者相加作为输入表示。我们会逐一拆解这些零件，对照 BERT_base / BERT_large 的参数，并亲手跑一遍前向，把论文里的框图变成可观测的张量。

一、概念讲解#

1. 整体结构：双向的编码器堆栈#

BERT 复用原始 Transformer 的编码器部分，去掉了解码器与交叉注意力，所以每个位置都能同时看到整句的所有位置（双向、无因果掩码）。数据流如下：

输入表示（词 + 分段 + 位置嵌入之和）
   → 堆叠 N 个编码器块（多头自注意力 + 前馈，残差 + LayerNorm）
   → 每个位置输出一个上下文表示
   → [CLS] 位置的表示常被当作"整句"的摘要，供下游任务使用

和 GPT 的一个关键差别是归一化位置：BERT 沿用原始 Transformer 的 post-LN（子层之后归一化），而 GPT-2 之后改用 pre-LN。另一个差别是注意力没有因果掩码，因此能双向理解——这是它能做"填空"（MLM）的结构基础。

2. 输入表示：三种嵌入相加#

BERT 的每个输入 token 被表示成三个嵌入逐元素相加：

输入向量 = 词嵌入(token) + 分段嵌入(segment) + 位置嵌入(position)
  • 词嵌入（Token Embeddings）：由 WordPiece 子词算法得到的词表（约 3 万个 token）查表而来；
  • 分段嵌入（Segment Embeddings）：标记 token 属于"第一句"还是"第二句"（值为 0/1），用于支持下一句预测这类双句任务；
  • 位置嵌入（Position Embeddings）：可学习的绝对位置编码（BERT 不用正弦函数），最多 512 个位置。

三者相加后，再过一层 LayerNorm 与 Dropout，得到送入编码器的向量。这里"分段嵌入"是 BERT 区别于 GPT 的显著点——GPT 是单句自回归，不需要区分两个句子。

3. 两个特殊 token：[CLS] 与 [SEP]#

BERT 的每个输入序列都被包裹上两个特殊符号：

  • [CLS]（classification）：放在句首。经过编码后，[CLS] 位置的输出向量被训练成"整句语义的聚合表示"，分类任务就直接在它上面接一个线性头；
  • [SEP]（separator）：放在句尾，以及两个句子之间，用来分隔句 A 与句 B。

于是输入格式通常是 [CLS] 句A [SEP] 句B [SEP]。这是 BERT 支持"单句任务 + 双句任务"的关键设计。

4. 编码器块与 BERT_base / BERT_large#

每个编码器块和标准 Transformer 编码器一致：多头自注意力 + 前馈网络，各带残差连接与 LayerNorm（post-LN）。前馈网络的中间维度是 4 × hidden_size，激活用 GELU。

BERT 发布时给了两个规格：

规格 参数量 层数 隐藏维 注意力头数 总参数
BERT_base 约 1.1 亿 12 768 12 110M
BERT_large 约 3.4 亿 24 1024 16 340M

base 适合快速实验与微调，large 精度更高但更吃资源。两者的结构完全相同，只是宽度与深度不同——又一次印证了"架构复用、规模调节"的设计哲学。

5. 输出：每个位置的表示 + [CLS] 聚合#

编码完成后，BERT 输出每个位置的上下文表示 last_hidden_state（形状 [batch, 长度, hidden]）。此外还额外输出一个 pooler_output：把 [CLS] 位置的表示过一个线性层 + tanh，作为"整句级"的聚合向量。下游任务按需取用：

  • token 级任务（如命名实体识别、问答）用每个位置的表示；
  • 句子级任务（如情感分类、句子对判断）用 [CLS] 的表示。

二、可运行代码示例#

先用 Hugging Face 读 BERT 的配置，把参数表变成可打印的数字。

from transformers import BertConfig, BertModel

cfg = BertConfig.from_pretrained("bert-base-uncased")
print("隐藏维 hidden_size        =", cfg.hidden_size)
print("层数 num_hidden_layers     =", cfg.num_hidden_layers)
print("注意力头 num_attention_heads=", cfg.num_attention_heads)
print("词表 vocab_size            =", cfg.vocab_size)
print("最大位置 max_position_embeddings =", cfg.max_position_embeddings)

model = BertModel.from_pretrained("bert-base-uncased")
params = sum(p.numel() for p in model.parameters())
print("总参数量 =", f"{params/1e6:.1f}M")

# 三种嵌入都在 model.embeddings 里，逐项看清
print("\n嵌入模块结构:")
print(model.embeddings)

你会看到 embeddings 里依次是 word_embeddings、position_embeddings、token_type_embeddings（即分段嵌入）以及 LayerNorm/Dropout——正是"三种嵌入相加"的具象化。

再跑一次前向，看 [CLS] 与 [SEP] 如何出现、两种输出各是什么形状：

import torch
from transformers import BertTokenizer

tok = BertTokenizer.from_pretrained("bert-base-uncased")
text = "Hello, my dog is cute"
inputs = tok(text, return_tensors="pt")

print("input_ids       :", inputs["input_ids"].tolist())
print("token_type_ids  :", inputs["token_type_ids"].tolist())  # 单句全为 0
print("解码回 token    :", tok.convert_ids_to_tokens(inputs["input_ids"][0]))

with torch.no_grad():
    out = model(**inputs)
print("\nlast_hidden_state 形状:", out.last_hidden_state.shape)  # [1, T, 768]
print("pooler_output      形状:", out.pooler_output.shape)       # [1, 768]

input_ids 里开头的 101 是 [CLS]、结尾的 102 是 [SEP]。last_hidden_state 的每一行是对应 token 的上下文表示，而 pooler_output 是 [CLS] 表示经过线性 + tanh 后的"整句摘要"。

三、练习#

  1. 用 BertConfig 实例化 bert-large-uncased，打印它的 hidden_size / num_hidden_layers / num_attention_heads，对照上表验证 base 与 large 的差异。
  2. 输入两个句子 ("Hello", "my dog is cute")（作为 pair），观察 token_type_ids 的变化，指出哪些 token 属于"第二句"，并说明 [SEP] 出现了几次。
  3. 在 model.embeddings 上分别打印 word_embeddings、position_embeddings、token_type_embeddings 三个权重的形状，解释为什么前两者形状相同、第三个形状不同（提示：分段只有 0/1 两种）。
  4. 思考题：BERT 为什么用 [CLS] 位置的输出作为"整句表示"，而不是把所有位置求平均？结合"这个位置被专门训练来聚合句子信息"来回答。
