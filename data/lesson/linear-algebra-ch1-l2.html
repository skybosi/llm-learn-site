向量的加减与数乘#

上一课我们知道向量是一串有序数字，也是带方向的箭头。这一课我们学习向量的三种基本运算：加法、减法、数乘。它们是线性代数里最"底层"的动作，后面几乎所有更复杂的运算（点积、矩阵乘法、线性方程组）都由它们组合而成。在机器学习里，它们还对应着"特征缩放、平移、组合"等非常实际的操作。

一、概念讲解#

1. 向量加法：逐个分量相加#

两个维度相同的向量相加，规则很简单：把对应位置的分量相加，得到一个新向量。

例如：

(1, 2) + (3, 4) = (1+3, 2+4) = (4, 6)

从几何上看，向量加法是"首尾相连"：先沿着第一个向量走，再沿着第二个向量走，最终到达的位置就是和向量。画出来也像一个平行四边形的对角线，所以也叫平行四边形法则。

必须注意：只有维度相同的向量才能相加。一个 3 维向量和一个 4 维向量相加，在数学上没有定义，在 NumPy 里也会直接报错。

2. 向量减法：加上"相反方向"的向量#

减法本质上是加法的逆运算：u - v 等于 u + (-v)，其中 -v 是 v 的相反向量（每个分量取负号）。

(4, 6) - (3, 4) = (4-3, 6-4) = (1, 2)

从几何上看，u - v 得到的箭头正好从 v 的终点指向 u 的终点，表示"从 v 到 u 的位移"。这个概念后面计算两个样本之间的"差距"时很有用。

3. 数乘：把向量按比例缩放#

数乘是用一个普通数字（称为标量）去乘向量的每一个分量：

2 × (1, 2) = (2×1, 2×2) = (2, 4)

从几何上看，数乘会拉伸或压缩向量：乘以大于 1 的数会拉长，乘以 0 到 1 之间的数会缩短，乘以负数还会把方向反过来。

4. 线性组合：加减与数乘的"总装"#

把加法和数乘结合起来，就得到线性组合：给定向量 v 和 w，表达式

a·v + b·w

就是 v 和 w 的一个线性组合，其中 a、b 是标量（也叫系数）。线性组合是贯穿整门课的"灵魂概念"，后面你会反复遇到它：矩阵乘法本质是列向量的线性组合，线性方程组的解也是线性组合。

5. 机器学习中的应用：特征缩放#

向量运算在数据预处理里无处不在。比如"标准化"（standardization）就要用到减法和数乘：

x_new = (x - mean) / std

其中 mean 是特征的均值（一个标量或向量），std 是标准差。减去均值相当于向量减法（把数据中心平移到原点），除以标准差相当于数乘（把数据统一到相近的尺度）。这样做的目的是让不同量纲的特征（比如"面积"和"房间数"）在数值上可比，否则数值大的特征会"欺负"数值小的特征，影响模型训练。

二、可运行示例#

下面用 NumPy 演示向量的加减与数乘，并完成一次真实的特征标准化。

import numpy as np

# 两个同维度（3 维）的房价特征向量
house_a = np.array([120.0, 3.0, 5.0])   # 面积、房间数、房龄
house_b = np.array([90.0, 2.0, 10.0])

# 1) 加法：对应分量相加
add = house_a + house_b
print("加法 house_a + house_b =", add)   # [210.  5. 15.]

# 2) 减法：对应分量相减（得到两套房子的差距）
diff = house_a - house_b
print("减法 house_a - house_b =", diff)  # [ 30.   1.  -5.]

# 3) 数乘：所有分量统一缩放
scaled = 2.5 * house_a
print("数乘 2.5 * house_a =", scaled)    # [300.   7.5  12.5]

# 4) 线性组合：0.5*house_a + 0.5*house_b 相当于"取平均"
mid = 0.5 * house_a + 0.5 * house_b
print("线性组合（两套房的平均）=", mid)   # [105.   2.5   7.5]

# 5) 特征标准化：对"面积"这一列数据做 (x - 均值) / 标准差
areas = np.array([120.0, 90.0, 150.0, 80.0, 110.0])  # 5 套房子的面积
mean = areas.mean()        # 均值
std = areas.std()          # 标准差
areas_norm = (areas - mean) / std
print("原始面积：", areas)
print("标准化后：", areas_norm)
print("标准化后均值≈", areas_norm.mean(), "标准差≈", areas_norm.std())

预期输出（大意）：

加法 house_a + house_b = [210.   5.  15.]
减法 house_a - house_b = [ 30.   1.  -5.]
数乘 2.5 * house_a = [300.   7.5  12.5]
线性组合（两套房的平均）= [105.   2.5   7.5]
原始面积： [120.  90. 150.  80. 110.]
标准化后： [ 0.404   -0.809   1.617  -1.213   0.    ]
标准化后均值≈ 0.0 标准差≈ 1.0

要点：+、-、* 对 NumPy 数组都是逐分量运算，这正是向量运算的定义；* 两边若都是数组则是"逐分量相乘"（不是点积，点积下一课讲），只有一边是标量时才叫数乘。

三、练习#

  1. 用手算验证：(2, 5) + (3, -1) 和 3 × (2, 5) - (0, 5) 分别等于多少？再用 NumPy 验证你的答案。
  2. 用 np.array 创建两个你感兴趣的三维向量（比如两个城市的气温、湿度、风速），分别求它们的和、差，以及 1.5 × 第一个向量。
  3. 仿照示例，对 areas 之外自己造的一组数据做标准化，并验证结果均值接近 0、标准差接近 1。
  4. 思考：如果两个向量维度不同（一个 3 维、一个 4 维），NumPy 相加会怎样？动手试一下，把报错信息读一读，理解"维度必须一致"这条规则。
