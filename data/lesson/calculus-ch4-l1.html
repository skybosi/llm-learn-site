多元链式法则#

链式法则是"导数版的分工协作"：当函数一层套一层时，总变化率等于每一层变化率的乘积。它是后面反向传播算法的数学根基。

一、概念讲解#

1. 先回忆单变量链式法则#

如果 y = f(u)，而 u = g(x)，那么 y 对 x 的导数可以拆成两段：

dy/dx = dy/du · du/dx

读法是："y 随 x 变化" = "y 随 u 变化" 乘以 "u 随 x 变化"。它告诉我们，套娃式的函数可以一层一层地求导，再把结果乘起来。

2. 多元链式法则：多了一个"求和"#

到了多元函数，情况略有不同：一个中间变量可能有多条路径影响最终结果，每条路径都要算一遍再相加。

最典型的情形是：z = f(x, y)，而 x = x(t)、y = y(t) 都只是单个自变量 t 的函数。此时 z 对 t 的全导数是：

dz/dt = (∂z/∂x)·(dx/dt) + (∂z/∂y)·(dy/dt)

直观理解：t 变化会同时推动 x 和 y 变化，这两条"影响线路"都要计入，所以是两个乘积相加。这个"每条路径相乘、路径之间相加"的规则，正是反向传播的全部内容。

3. 为什么它对机器学习重要#

神经网络的损失函数，本质上是"参数 → 预测 → 损失"的多层复合函数。以单个神经元为例：

z = w·x + b        （线性加权）
a = sigmoid(z)     （激活函数）
L = (a - y)²       （平方损失）

损失 L 对权重 w 的导数，需要把三段乘起来：

dL/dw = dL/da · da/dz · dz/dw

这就是链式法则最直接的应用。搞懂这一条式子，你就抓住了深度学习"训练"背后的数学动作：求损失对每个参数的偏导，然后让参数沿负方向挪动。

二、可运行示例#

示例 1：数值验证多元链式法则#

设 z = x² + y²，且 x = t、y = t²。用链式法则和直接求导两种方式各算一遍 dz/dt，看结果是否一致。

def dz_dt_chain(t):
    """用多元链式法则求 dz/dt。"""
    x = t
    y = t ** 2
    dz_dx = 2 * x      # ∂z/∂x
    dz_dy = 2 * y      # ∂z/∂y
    dx_dt = 1.0        # x = t 对 t 求导
    dy_dt = 2 * t      # y = t² 对 t 求导
    # 两条路径相乘后相加
    return dz_dx * dx_dt + dz_dy * dy_dt

def dz_dt_direct(t):
    """先把 x、y 代入 z 再直接求导：z = t² + t⁴，dz/dt = 2t + 4t³。"""
    return 2 * t + 4 * t ** 3

for t in [1.0, 2.0, 3.0]:
    print(f"t={t}: 链式法则={dz_dt_chain(t):.4f}, 直接求导={dz_dt_direct(t):.4f}")

示例 2：损失对权重求导 + 数值差分验证#

手写单个 sigmoid 神经元，用链式法则求 dL/dw，再用数值差分（给 w 一个极小扰动）做交叉验证。

import math

def sigmoid(z):
    # sigmoid 激活函数：把任意实数映射到 (0, 1) 之间
    return 1.0 / (1.0 + math.exp(-z))

def forward_and_grad(w, x, b, y_true):
    # 前向计算：线性加权 -> 激活 -> 平方损失
    z = w * x + b
    a = sigmoid(z)
    L = (a - y_true) ** 2

    # 反向求导：用链式法则把三段导数相乘
    dL_da = 2.0 * (a - y_true)   # L = (a-y)² 对 a 求导
    da_dz = a * (1.0 - a)        # sigmoid 的导数 s(1-s)
    dz_dw = x                    # z = w*x + b 对 w 求导
    dL_dw = dL_da * da_dz * dz_dw
    return L, dL_dw

x, b, y_true = 0.5, 0.1, 1.0
w = 1.0
L, dL_dw = forward_and_grad(w, x, b, y_true)
print("损失 L =", round(L, 6))
print("链式法则得到的 dL/dw =", round(dL_dw, 6))

# 数值差分验证：用 (f(w+h) - f(w-h)) / 2h 近似导数
eps = 1e-6
L_plus, _ = forward_and_grad(w + eps, x, b, y_true)
L_minus, _ = forward_and_grad(w - eps, x, b, y_true)
numerical = (L_plus - L_minus) / (2 * eps)
print("数值差分 dL/dw ≈", round(numerical, 6))

示例 3：双参数损失的手写梯度#

对 L = (w1·x1 + w2·x2 - y)² 求 ∂L/∂w1 和 ∂L/∂w2，分别用"链式法则"和"直接展开"两种方式实现并对照。

def grad_chain(w1, w2, x1, x2, y):
    # 引入中间变量 s = w1*x1 + w2*x2 - y
    s = w1 * x1 + w2 * x2 - y
    dL_ds = 2 * s          # L = s² 对 s 求导
    dL_dw1 = dL_ds * x1    # ds/dw1 = x1
    dL_dw2 = dL_ds * x2    # ds/dw2 = x2
    return dL_dw1, dL_dw2

def grad_direct(w1, w2, x1, x2, y):
    # 直接展开求偏导：∂L/∂w1 = 2s·x1，∂L/∂w2 = 2s·x2
    s = w1 * x1 + w2 * x2 - y
    return 2 * s * x1, 2 * s * x2

w1, w2, x1, x2, y = 0.5, -0.4, 0.6, 0.3, 1.0
print("链式法则:", grad_chain(w1, w2, x1, x2, y))
print("直接展开:", grad_direct(w1, w2, x1, x2, y))
