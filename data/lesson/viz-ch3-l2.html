箱线图#

直方图展示分布的完整形状，而箱线图用几个关键统计量把分布"压缩"成一张紧凑的图，特别适合多组数据之间的快速对比和发现离群点。

一、概念讲解#

1. 箱线图展示的五数概括#

箱线图基于分位数，用五个数刻画分布：

  • 最小值（去离群点后的下边缘）
  • 下四分位数 Q1（25% 分位）
  • 中位数 Q2（50% 分位）
  • 上四分位数 Q3（75% 分位）
  • 最大值（去离群点后的上边缘）

箱体（box）覆盖 Q1 到 Q3 的范围，箱体中间一条线标出中位数，箱体两侧伸出"须"（whiskers）延伸到非离群的数据范围。

2. 四分位距与离群点判定#

  • 四分位距 IQR = Q3 − Q1，衡量中间 50% 数据的离散程度。
  • 须通常延伸到 Q1 − 1.5×IQR 到 Q3 + 1.5×IQR 范围内最远的实际数据点。
  • 超出这个范围的点被判定为离群点（outlier），单独画成小点。这就是箱线图能一眼看出异常值的原因。

3. 基础用法：ax.boxplot#

ax.boxplot(data) 接收一个列表，其中每个元素是一组一维数据，每个元素会画成一个箱子，非常适合"多组对比"。

参数 含义
labels 每组箱子的标签
vert True 垂直、False 水平
patch_artist 是否填充箱体颜色
showfliers 是否显示离群点
boxprops / medianprops 箱体 / 中位线的样式字典

二、可运行代码示例#

下面模拟四个班级的考试成绩，用一张箱线图对比它们的分布与离群点。

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False

rng = np.random.default_rng(1)

# 四个班级的成绩，各有不同的均值与标准差
data = [
    rng.normal(72, 8, 100),    # 一班
    rng.normal(78, 6, 100),    # 二班
    rng.normal(65, 12, 100),   # 三班（更分散，更易出现离群点）
    rng.normal(70, 9, 100),    # 四班
]
labels = ["一班", "二班", "三班", "四班"]

fig, ax = plt.subplots(figsize=(8, 5))

ax.boxplot(data, labels=labels, patch_artist=True,
           boxprops=dict(facecolor="#cfe0f3"),       # 箱体填充色
           medianprops=dict(color="crimson", linewidth=2))

ax.set_ylabel("成绩")
ax.set_title("箱线图：四个班级成绩分布")
ax.grid(axis="y", linestyle=":", alpha=0.6)

plt.show()

观察：三班的箱体更"长"（IQR 更大）、须也更长，说明成绩更分散；若有点落在须之外，就是离群点。

三、练习#

  1. 用 np.percentile(data[0], [0, 25, 50, 75, 100]) 计算一班的五数概括，并与图中箱体的位置对应起来。
  2. 给第二组数据人为加入一个极端值（如 data[1] = np.append(data[1], 200)），重画箱线图，观察离群点如何被标出。
  3. 把 vert=False 改成水平箱线图，并说明在类别标签很长时水平布局的优势。
