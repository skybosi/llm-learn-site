缺失值处理#

一、概念讲解#

第 1 章我们只是"初识"了缺失值，本课系统地解决它。缺失值处理是数据清洗的第一步，核心就一句话：先摸清缺失的规模和分布，再决定"删"还是"填"。

1. 先检测#

  • df.isnull() / df.notnull()：返回同形状的布尔 DataFrame。
  • df.isnull().sum()：统计每列的缺失个数，是快速定位"哪列最脏"的关键。
  • 配合 df.isnull().mean() 还能得到每列的缺失比例。

2. 删除：dropna#

df.dropna() 默认删除任何包含缺失值的行，常用参数：

  • axis=1：改为删除含缺失的列。
  • how="all"：只有整行全是缺失才删除（默认 how="any" 是有任一缺失就删）。
  • thresh=n：一行里至少保留 n 个非缺失值，否则删除。
  • subset=[...]：只在指定列上判断缺失，其他列的缺失不影响。

删除适合"缺失很少、丢掉不影响整体"的情况；缺失太多时盲目删除会损失大量样本。

3. 填充：fillna 与插值#

  • df.fillna(值)：用常数、字典（按列指定）、或整列统计量（如均值、中位数）填充。
  • df.ffill() / df.bfill()：前向/后向填充，用相邻有效值顺延，适合时间序列。
  • df.interpolate()：线性插值，在两个有效值之间按趋势估出中间值，适合平滑变化的数据。

4. 怎么选#

  • 缺失比例极小且是随机缺失 → 删。
  • 缺失有规律、可用相邻值或统计量合理估计 → 填。
  • 关键列缺失且无法合理估计 → 考虑标记为新类别或单独分析，而不是硬填。

二、可运行代码示例#

import pandas as pd
import numpy as np

df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五", "赵六"],
    "年龄": [25, np.nan, 22, 30],
    "工资": [8000, 9000, np.nan, 12000],
})
print("原始数据：\n", df)

# 1. 检测缺失
print("\n每列缺失个数：\n", df.isnull().sum())
print("每列缺失比例：\n", df.isnull().mean())

# 2. 删除
print("\n删除含缺失的行（默认 any）：\n", df.dropna())
print("\n删除含缺失的列（axis=1）：\n", df.dropna(axis=1))
print("\n至少保留 3 个非缺失值（thresh=3）：\n", df.dropna(thresh=3))
print("\n仅看'工资'列的缺失（subset）：\n", df.dropna(subset=["工资"]))

# 3. 填充
print("\n年龄用均值填充：\n", df["年龄"].fillna(df["年龄"].mean()))
print("\n按列分别填充：\n", df.fillna({"年龄": 0, "工资": 5000}))
print("\n前向填充 ffill：\n", df.ffill())
print("\n后向填充 bfill：\n", df.bfill())
print("\n工资线性插值：\n", df["工资"].interpolate())

运行后注意对比：dropna() 默认把"张三"以外的行几乎删光（因为只有第一行完全无缺失），而 thresh=3 和 subset 让删除更克制；填充则完整保留了所有行。

三、练习#

  1. 创建一个 5 行 3 列的 DataFrame，人为制造若干 NaN，用 isnull().sum() 找出缺失最多的列。
  2. 对上面的数据分别执行 dropna()、dropna(thresh=2)、dropna(subset=[指定列])，比较三种删除结果保留了多少行。
  3. 对某列含 NaN 的数值数据，分别用 fillna(均值)、ffill()、interpolate() 填充，说明三种方法各适合什么场景。
