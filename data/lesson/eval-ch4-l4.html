这一节要解决什么#

前两节把 judge 拆完了，这一节讲另一台仪器：人。

人的优势是"判得准"（在多数任务上仍是唯一的地面真值），劣势是三条硬约束：贵、慢、不稳定。本课程对人工评审的立场是：它不是一个"更贵的选项"，而是一种需要工程化的生产活动——有流程、有质检、有成本模型、有版本治理。把它当成"找几个同事看一下"的团队，通常会在三个月后发现自己有一堆无法复现、无法比较的评分。

本节的组织是"先算账，再讲流程，最后讲坑"：

  1. 三类标注者：众包、领域专家、真实用户。它们在成本、质量、生态效度上各有不可替代的位置，选错类型会让整个评测失效。
  2. 流程七步：采样 → 指南 → 试标校准 → 正式标注（含冗余）→ 仲裁 → 质检 → 归档。
  3. 成本模型：把"每条有效标签的成本"算出来——它包含指南与培训的摊销、冗余倍数、仲裁成本、以及质检成本。只看"每条多少钱"的团队会低估 2~3 倍。
  4. 标注质量：金题、注意力检查、漂移监控、标注者效应（宽严不一）的度量与校正。
  5. 五个必须提前定的事：这是第 2 章讲过的，但人工评审把它们放大了——尤其是"意见不一致该怎么算"。
  6. 隐私与合规：不可跳过。

最后给出一个判据：什么任务上"贵的那种标注者"真的值得？ 答案不是"重要的任务"，而是"判断需要任务外的知识、且错误代价高"的任务。

一、三类标注者：位置不同，不能互相替代#

类型 单位成本 判定质量 生态效度 最适合 最不适合
众包标注者 最低 中低（受训练与激励影响大） 低（不代表真实用户） 客观可判定的任务（事实核对、格式合规、明显有害） 主观质量、领域判断
领域专家 高（10~50×） 高 中（专家偏好 ≠ 用户偏好） 专业正确性、合规、安全、需要外部知识的判断 大规模（成本不允许）、用户体验类
真实用户 中（需要触达与激励） 中 最高 满意度、可读性、愿不愿意用、格式偏好 专业正确性（用户无法判断对错）

为什么必须区分：因为三者在不同的构念上有效。第 1 章区分过"能力 / 行为 / 偏好"三层提问：

  • "这个回答事实正确吗" → 能力层 → 领域专家（众包会漏掉微妙错误，用户根本不知道）。
  • "用户会不会采纳" → 行为层 → 真实用户（专家可能更喜欢一个用户根本不会用的答案）。
  • "哪个回答更好" → 偏好层 → 取决于"谁"的偏好：产品的目标是用户偏好，合规的目标是专家偏好。这两者经常冲突，而且必须在评测设计阶段决定以谁为准。

判据（贵的那种是否值得）：把任务按两维切开——(a) 判断是否需要任务外知识；(b) 错误代价是否高。

错误代价低 错误代价高
不需任务外知识 众包（便宜够用） 众包 + 专家抽查（冗余）
需要任务外知识 专家（小样本） 专家 + 双评 + 仲裁（不可省）

右上与左下两格是常见的浪费：用专家去判"格式是否规范"（左下，浪费钱），或让众包判"医疗建议是否正确"（右上，危险）。

二、流程七步#

① 采样。与第 2 章的自建评测集一致：分层 + 配额 + 边界样本过采样。人工评审特有的要求是控制单次任务的规模：一次给标注者 200 条、每条要看 1000 字，质量会在后半段崩塌。拆成每批 20~40 条、带强制休息，比一次给完更便宜（返工少）。

② 标注指南（rubric + 锚点示例）。三个要求（第 2 章已给，这里强调人工版）：

  • 可判定：每个类别有明确的判定边界，不只是正向定义，还要有反例（"什么不算"）。
  • 最小可判定差异：相邻类别之间的差别是标注者能稳定区分的，不是理论差别。
  • 锚点示例：每类给 2~3 个已定论的例子，尤其是边界例子。

一份好的指南应该能让两个受训标注者在 80% 的样本上独立达成一致。如果试标一致率不到 70%，指南不够用；继续标注只会制造返工。

③ 试标校准（calibration round）。30~50 条，全员标，然后开会对齐分歧。这一步的成本是"便宜的一次会议"，收益是"避免几百条的返工"。必须做的事：把分歧逐条讨论到"大家同意这个类别该怎么判"，并把结论写回指南（指南要版本化）。

④ 正式标注（含冗余）。冗余策略：

策略 说明 适用
单标 每条 1 人 客观任务、成本敏感
双标（100%） 每条 2 人 主观任务、需要一致性估计
部分双标（20~30%） 一部分双标用于估一致性 大规模 + 需要质检信号
三标 + 多数投票 每条 3 人 高价值、易分歧

注意：部分双标的估计精度取决于重叠比例。重叠 20% 时，κ 的点估计噪声很大（第 3 节的 bootstrap 区间会很宽）。做法是把重叠集中在一个随机子集上（而不是"随便挑"），并把这个子集当校准样本单独报告。

⑤ 仲裁。分歧样本由高级标注者/专家定。两个必须写清的规则：

  • 谁是仲裁者：仲裁者必须比标注者更强（领域知识或流程权威），否则只是多一个人投票。
  • 仲裁结果去哪：仲裁结果应该写回指南（作为新的锚点例子）。只裁决不沉淀，等于同样的分歧下个月还会出现。

⑥ 质检。四件工具（下一节展开）：金题、注意力检查、一致性监控、漂移监控。

⑦ 归档。原始标注 + 仲裁 + 指南版本 + 标注者 ID（匿名化）+ 时间戳。没有原始标注的评测无法复审，也无法重算一致性。

三、成本模型：每条有效标签的真实成本#

设：

  • ch​：标注者每小时成本（含平台抽成/税费）
  • t：每条平均耗时（分钟）
  • r：冗余倍数（双标 = 2）
  • o：重叠比例（用于一致性估计的样本占比，也常等于冗余覆盖）
  • p：仲裁率（分歧样本占非冗余判定的比例）
  • ta​：仲裁每条耗时（通常 2~3× 标注时间）
  • H：指南编写 + 试标 + 培训的一次性投入（小时）
  • q：质检覆盖率（金题占比 + 抽查占比）
  • N：正式标注的样本量

单条有效标签的成本：

Clabel​=60ch​​[r⋅t+p⋅ta​⋅r+q⋅tcheck​]+Nch​H​

这个式子有三个反直觉的含义：

  1. 一次性投入 H/N 在大项目上可以忽略、在小项目上主导。 N=200、H=10 人时时，摊销是 3 人分的成本；若每条只要 1 分钟，那 H 是标注成本的 90%。这解释了为什么"小规模人工评审"的单条成本总是高得离谱——它不是标注贵，是准备贵。
  2. 仲裁成本可能超过标注成本。 若 p=0.3、ta​=3t，仲裁项是 0.9t，接近单次标注的 t。降低仲裁率的最有效手段不是加钱，是改指南。
  3. 冗余降低"有效标签"成本的方式是提高可用率。 双标看起来成本 ×2，但如果它把"需要返工的比例"从 30% 降到 5%，实际成本可能只增加 30%。算账时要算"每条有效标签"，不是"每条标注"。

一个具体算例（本节代码会算出来）：ch​=60 元/时、t=2 分钟、双标、p=0.25、ta​=5 分钟、q=0.1、tcheck​=1 分钟、H=12 人时、N=500：

  • 标注：2×2=4 分钟
  • 仲裁：0.25×5×2=2.5 分钟
  • 质检：0.1×1=0.1 分钟
  • 合计 6.6 分钟/条 → 6.6 元/条，再加 H/N 摊销约 1.44 元 → 约 8 元/条
  • 对照："找人看一下"的直觉估价是 2 分钟 × 2 元/分钟 = 4 元/条，低估一半。

四、标注质量：四件工具#

（a）金题（gold items）。混入已知正确答案的样本，测量"与真相的一致"，而不是"彼此的一致"。金题的关键设计约束是：不能被认出来。 如果金题都很简单或都很怪，标注者会学会识别并特别认真——你测的是他们的警觉性，不是日常质量。

做法：金题占 5%~10%，难度与普通样本相当，混在批次内随机位置。报告"金题准确率"作为标注者质量的常规指标。

（b）注意力检查（attention checks）。与金题的区别：注意力检查测"有没有认真读"（比如同一内容重复出现两次，前后判定应该一致；或指令里要求某条按特定方式标）。风险：检查本身会改变行为——过度使用会让标注者变得"求稳"（倾向选择默认类别），引入系统性偏差。

（c）一致性监控。分两个层次：

  • 批内一致性：同一批里的重叠样本的 κ。
  • 标注者两两一致性矩阵：找出"离群标注者"（与其他人一致率显著低的人）。做法：对每个标注者算他与其他人的平均一致率，低于阈值（比如全体均值 - 2 个标准差）的进入复核。

（d）漂移监控。时间序列视角：标注者的判定分布（比如各类别占比）、平均耗时、金题准确率随时间的变化。

  • 判定分布漂移：如果一个标注者的"合格"率从 70% 涨到 88%，他可能变宽了。
  • 耗时漂移：平均耗时突然下降 40%，通常意味着开始敷衍。
  • 金题准确率漂移：最直接的信号。

标注者效应（宽严不一）的校正：如果多个标注者评同一批样本，可以用一个简单模型把"样本真实难度"与"标注者宽严"分开：

logitPr(yij​=1)=θi​+βj​

其中 θi​ 是样本 i 的难度参数、βj​ 是标注者 j 的偏移。βj​ 显著偏离 0 说明宽严差异。可以直接用 β^​j​ 校正，但要在报告中说明——校正后的分数与未校正的不能混用（这与第 3 节的校准映射同类）。

五、五个必须提前定的事（人工版）#

第 2 章给过通用版本，人工评审让它变得更尖锐：

  1. 分歧怎么算：平局？多数投票？仲裁定？必须在开始标注前写进指南。 事后改规则会让已标数据失去可比性。
  2. 类别不平衡怎么处理：如果 90% 是"合格"，就不要用"标注者之间的一致率"做质检——用金题与分层抽样（第 3 节讲过一致率的陷阱）。
  3. 主观性边界：哪一部分是"客观可判定"（应该高一致）、哪一部分是"主观偏好"（低一致是正常的）。把两者混在一起算全局 κ，会让"任务本身主观"被误读成"标注质量差"。
  4. 返工规则：什么情况下要求某标注者重标（金题低于阈值？漂移？）？返工的数据怎么处理（覆盖还是追加）？追加会引入选择偏差（只重标"看起来不对"的部分）。
  5. 隐私与合规：进入人工评审的数据可能包含个人信息、用户隐私、商业机密。
    • 最小化：只给标注者判定所需的最少内容（能脱敏就脱敏）。
    • 去标识化：移除姓名、联系方式、账号 ID；注意上下文里的间接标识（工单号、订单号、罕见事件描述）。
    • 保密与权限：签署保密协议、限制导出、禁止转录到公开工具（尤其是"把数据贴进对外的聊天模型里帮忙标"这类操作）。
    • 留存与删除：明确保留期与删除流程。这一条在很多团队里是"事后才发现违法"的典型。

六、常见失败模式#

失败 现象 根因 处置
指南不可判定 试标一致率 < 70% 类别定义重叠、缺少反例 改指南 + 补锚点，重跑试标
标注者互不相同 两两一致性差异大 培训不足/激励不当 建两两矩阵，剔除离群者并重训
主观与客观混算 全局 κ 很低，但分项不低 把偏好层与能力层混在一起 分层报告 κ
冗余不产生信息 双标一致率异常高（>0.95） 两人商量着标 / 共享账号 / 看到同一批顺序 独立标注隔离、随机顺序、检查 IP/时间戳
漂移未被发现 后半批的质量下降 无监控 引入时间维度监控 + 强制休息 + 分小批
数据无法复审 半年后无法复现结论 只存聚合结果，不存原始标注 归档要求（第 7 步）
专家更贵但没更准 专家与用户偏好差异巨大 构念选错（要偏好却找了专家） 回到第 1 步：这份评测要改变哪个决策？

七、判据汇总#

什么时候可以用众包：任务是"任何受过基础训练的人都能稳定判断"的（格式合规、明显有害、事实可核查），且错误代价中等偏低；同时你有金题与抽样复核。

什么时候必须用专家：判断需要任务外知识（专业正确性、合规边界、安全影响），或错误代价高（法律、医疗、资金）。并且必须注意：专家一致率通常也不高（专业判断本身有分歧），所以专家评审不能要求高 κ——更好的做法是让专家给出"理由 + 置信度"，把分歧作为信息保留下来，而不是强求一致性。

什么时候必须用真实用户：当构念是"偏好/行为"时（满意度、采纳意愿、可读性）。专家在这里是错误的地面真值。

一条通用纪律：人工评审的结论必须带着"谁标的、标了多少、一致性多少、不一致怎么处置"一起报告。 只报一个平均分的人工评审，本质上和只报一个平均分的 judge 一样不可信——而且更贵。

import math
import random
import statistics

rng = random.Random(419)


# ============================================================
# 1. 成本模型：每条"有效标签"的成本
# ============================================================
def cost_per_label(c_hour, t_min, redundancy, p_arb, t_arb, q_check,
                   t_check, H_hours, N):
    per_min = c_hour / 60.0
    annot = redundancy * t_min
    arb = p_arb * t_arb * redundancy
    check = q_check * t_check
    per_label = per_min * (annot + arb + check)
    amortized = c_hour * H_hours / N
    return per_label + amortized, dict(标注=per_min * annot,
                                      仲裁=per_min * arb,
                                      质检=per_min * check,
                                      一次性摊销=amortized)


print("== 1. 人工评审的成本结构（合成参数） ==")
base = dict(c_hour=60.0, t_min=2.0, redundancy=2, p_arb=0.25, t_arb=5.0,
            q_check=0.10, t_check=1.0, H_hours=12.0, N=500)
total, parts = cost_per_label(**base)
for k, v in parts.items():
    print(f"  {k:6s} {v:6.2f} 元/条  ({v/total:5.1%})")
print(f"合计 {total:.2f} 元/条")
naive = 60 / 60 * 2
print(f"直觉估价（只看标注工时）{naive:.2f} 元/条 -> 低估 {total/naive:.1f} 倍")

print("\n  敏感性分析（其他条件不变）：")
for key, vals in [("redundancy", [1, 2, 3]), ("p_arb", [0.10, 0.25, 0.40]),
                  ("N", [100, 500, 2000])]:
    row = []
    for v in vals:
        cfg = dict(base)
        cfg[key] = v
        row.append(f"{key}={v}: {cost_per_label(**cfg)[0]:.2f}")
    print("   " + " | ".join(row))
print("  <- 单标最便宜但拿不到一致性证据；仲裁率的杠杆比冗余更大；")
print("     N 从 500 降到 100 时摊销翻 5 倍（小项目的人工评审天然昂贵）")


# ============================================================
# 2. 冗余与"有效标签"：双标换来的是可用率
# ============================================================
def effective_cost(n_items, redundancy, c_hour, t_min, rework_rate):
    # rework_rate：需要返工的比例（返工再花一遍 redundancy*t_min）
    per_min = c_hour / 60.0
    cost = n_items * (redundancy * t_min + rework_rate * redundancy * t_min) * per_min
    valid = n_items * (1 - rework_rate)
    return cost / valid, cost


print("\n== 2. 冗余 vs 返工率：每条有效标签成本 ==")
for red, rework in [(1, 0.30), (2, 0.05), (2, 0.15), (3, 0.03)]:
    cpl, tot = effective_cost(500, red, 60.0, 2.0, rework)
    print(f"冗余 {red} 人 / 返工率 {rework:.0%} -> 有效成本 {cpl:.2f} 元/条 "
          f"(总投入 {tot:.0f} 元)")
print("  <- 双标看似翻倍，但把返工从 30% 压到 5% 后，有效成本只涨约 24%")


# ============================================================
# 3. 标注者效应：宽严不一（theta_i + beta_j 模型）
# ============================================================
def fit_rasch(responses, n_iter=200, lr=0.4):
    # responses: list of (item_id, rater_id, y)，拟合 logit P(y=1)=theta_i+beta_j
    items = sorted({r[0] for r in responses})
    raters = sorted({r[1] for r in responses})
    ii = {v: k for k, v in enumerate(items)}
    jj = {v: k for k, v in enumerate(raters)}
    theta = [0.0] * len(items)
    beta = [0.0] * len(raters)
    for _ in range(n_iter):
        gt = [0.0] * len(items)
        gb = [0.0] * len(raters)
        for (it, rt, y) in responses:
            z = theta[ii[it]] + beta[jj[rt]]
            p = 1 / (1 + math.exp(-max(-20.0, min(20.0, z))))
            e = y - p
            gt[ii[it]] += e
            gb[jj[rt]] += e
        for k in range(len(items)):
            theta[k] += lr * gt[k] / max(1, len(raters))
        for k in range(len(raters)):
            beta[k] += lr * gb[k] / max(1, len(items))
        m = statistics.mean(beta)
        beta = [b - m for b in beta]              # 中心化，避免不可识别
    return theta, beta, items, raters


r = random.Random(11)
true_theta = {i: r.gauss(0, 1.0) for i in range(60)}
rater_beta = {0: -0.9, 1: -0.2, 2: 0.4, 3: 1.1}   # 标注者 3 明显更"宽"
responses = []
for it in true_theta:
    for rt in rater_beta:
        if r.random() < 0.75:                     # 25% 缺失（部分重叠）
            z = true_theta[it] + rater_beta[rt]
            p = 1 / (1 + math.exp(-z))
            responses.append((it, rt, 1 if r.random() < p else 0))
theta_hat, beta_hat, items_, raters_ = fit_rasch(responses)

print("\n== 3. 标注者宽严（拟合 vs 真实） ==")
for k, rt in enumerate(raters_):
    print(f"  标注者 {rt}: 真实 beta={rater_beta[rt]:+.2f}  拟合 beta={beta_hat[k]:+.2f}")
print("  <- beta 偏离 0 说明宽严不一；可直接用于校正")
print("     注意：校正后的分数与未校正的不能混用（与 judge 校准同类纪律）")

# 若忽略标注者效应，会得到什么错误结论
naive_pass = sum(y for (_, _, y) in responses) / len(responses)
adj = 0.0
for (it, rt, y) in responses:
    z = theta_hat[items_.index(it)]
    adj += 1 / (1 + math.exp(-z))
adj /= len(responses)
print(f"  朴素通过率 {naive_pass:.3f} vs 校正宽严后的期望通过率 {adj:.3f} "
      f"(差 {adj - naive_pass:+.3f})")


# ============================================================
# 4. 漂移监控：判定分布与金题准确率
# ============================================================
print("\n== 4. 漂移监控（合成：同一标注者跨 10 批） ==")
r = random.Random(13)
for rater_name, drift in (("A（稳定）", 0.0), ("B（逐渐变宽）", 0.012)):
    rows = []
    for batch in range(1, 11):
        gold_acc = 0.92 - drift * batch + r.gauss(0, 0.015)
        pass_rate = min(1.0, 0.60 + (drift * 4) * batch + r.gauss(0, 0.01))
        rows.append((batch, gold_acc, pass_rate))
    print(f"  {rater_name}: " + " ".join(f"B{b}:{g:.2f}/{p:.2f}"
                                         for b, g, p in rows))
print("  （格式：批号:金题准确率/通过率）")
print("  <- 金题准确率下降 + 通过率上升 = 典型'变宽'漂移；")
print("     这个模式在只看总平均分时完全看不见")


# ============================================================
# 5. 注意力检查的副作用：迫使标注者"求稳"
# ============================================================
def simulate_attention_checks(n_items, check_ratio, default_bias, seed):
    # check_ratio：被抽查比例；default_bias：为通过检查而倾向默认类别的强度
    r = random.Random(seed)
    labels = []
    for _ in range(n_items):
        truth = 1 if r.random() < 0.5 else 0
        is_check = r.random() < check_ratio
        p_default = 1.0 if is_check else 0.5      # 被抽查时"求稳"选默认类别
        bias = default_bias
        if r.random() < bias:
            labels.append(1)                       # 求稳：直接选默认类别
        else:
            labels.append(truth if r.random() < 0.75 else 1 - truth)
    return sum(labels) / len(labels), 0.0


print("\n== 5. 注意力检查的副作用（合成） ==")
for ratio, bias in [(0.0, 0.0), (0.10, 0.0), (0.10, 0.25), (0.30, 0.25)]:
    rate1, _ = simulate_attention_checks(2000, ratio, bias, seed=3)
    print(f"  抽查比例 {ratio:.0%}, 求稳强度 {bias:.2f} -> 类别 1 占比 {rate1:.3f}")
print("  <- 抽查本身会让'默认类别'占比上升：质检手段会在被测对象上留下痕迹")
print("     做法：抽查比例控制在 10% 左右，并在分析时把抽查样本单独标记")


# ============================================================
# 6. 标注者两两一致性：找出离群者
# ============================================================
print("\n== 6. 标注者离群检测（合成） ==")
r = random.Random(17)
n_items = 300
truth = [1 if r.random() < 0.5 else 0 for _ in range(n_items)]
raters = {0: 0.85, 1: 0.82, 2: 0.80, 3: 0.55}   # 3 号是"敷衍"的标注者
labels = {}
for rt, acc in raters.items():
    labels[rt] = [t if r.random() < acc else 1 - t for t in truth]


def agree(x, y):
    return sum(1 for a, b in zip(x, y) if a == b) / len(x)


ids = sorted(raters)
print("  两两一致率矩阵：")
print("      " + "".join(f"{j:>7}" for j in ids))
for i in ids:
    row = "".join("   --  " if i == j else f"{agree(labels[i], labels[j]):7.3f}"
                  for j in ids)
    print(f"  {i}: {row}")
for i in ids:
    others = [agree(labels[i], labels[j]) for j in ids if j != i]
    print(f"  标注者 {i}: 平均与他人一致率 {statistics.mean(others):.3f}")
print("  <- 3 号明显离群（0.54 vs 其余 0.63~0.66）")
print("     阈值可用'全体均值 - 2 个标准差'，但复核前先看他的金题准确率")

代码里六个值得注意的点：

  • 第 1 段把成本结构摊开：标注只占约六成，仲裁约占三成八，一次性摊销在小项目上占两成以上。"每条 2 分钟 × 1 元/分钟 = 2 元"的直觉估价低估了约 4 倍（本例合计约 8 元/条）。敏感性分析还显示：N 从 500 降到 100 时摊销项翻 5 倍——小规模人工评审的昂贵不是因为标注，而是因为准备。
  • 第 2 段给出冗余的正确算法：要算"每条有效标签"的成本，而不是"每条标注"的成本。双标把返工率从 30% 压到 5% 时，有效成本只从 3.43 涨到 4.25（约 +24%），而不是翻倍。这也说明：判断冗余是否值得，要先估返工率。
  • 第 3 段是标注者效应的标准处理：用 logitPr(y=1)=θi​+βj​ 把"样本难度"与"标注者宽严"分开。本例中标注者 3 的真实 β=+1.1（明显更宽），拟合值 +1.71 —— 排序完全正确，但幅度被高估了约 55%：这是最简单的交替梯度法在只有 75% 重叠数据上的已知缺陷（尺度的识别不干净），生产实现应当用边缘极大似然（MML）或带正则的联合估计。关键结论不变：忽略标注者效应，通过率估计会偏，而偏差与模型质量毫无关系。
  • 第 4 段给出漂移的可观测形态：金题准确率下降 + 类别占比上升是"标注者变宽"的特征模式；只看总平均分完全看不见（总平均分可能还上升了）。这就是为什么质检指标要分标注者、分批次看时间序列。
  • 第 5 段说明质检手段会改变被测对象（观察者效应）：随着"求稳"强度上升，"默认类别"的占比被推离 0.5（0.498 → 0.625 量级）。这是为什么抽查比例不宜过高，以及为什么抽查样本应在分析时单独标记。
  • 第 6 段的离群检测是人工评审的基本卫生：两两一致率矩阵里，标注者 3 的平均一致率（0.54）明显低于其他三人（0.63~0.66）。但要注意先看金题准确率再定性——"更严格"的标注者与"敷衍"的标注者表现不同：前者与他人一致率低但金题准，后者两者都低。

小结#

  • 三类标注者不可互换：众包（便宜、客观任务）、领域专家（需任务外知识、错误代价高）、真实用户（偏好/行为层，生态效度最高）。贵的那种值得的条件是"需要任务外知识 + 错误代价高"，不是"任务重要"。
  • 流程七步缺一不可：采样（小批次、控制规模）→ 指南（可判定、最小可判定差异、锚点示例）→ 试标校准（一致率 < 70% 就改指南）→ 正式标注（冗余策略）→ 仲裁（结果写回指南）→ 质检（金题/注意力/一致性/漂移）→ 归档（原始标注 + 指南版本 + 匿名 ID）。
  • 成本要算"每条有效标签"：C≈60ch​​(rt+pta​r+qtcheck​)+Nch​H​。直觉估价通常低估 2~4 倍；小项目被一次性投入主导；仲裁项的杠杆常大于冗余项。
  • 质检四件工具都有副作用：金题要"不可识别"；注意力检查比例过高会迫使标注者求稳（观察者效应）；一致性监控要分主观/客观层；漂移监控要看"金题准确率 + 类别占比"的时间序列。
  • 标注者效应必须建模：logitPr(y=1)=θi​+βj​ 分离样本难度与宽严偏移。忽略它造成的通过率偏差可以到 10 个点以上，而且与模型质量无关。
  • 人工评审的结论必须带上下文：谁标的、标了多少、一致性多少、分歧怎么处置、金题准确率多少。只报平均分的人工评审和只报平均分的 judge 一样不可信，而且更贵。
  • 隐私与合规不可跳过：最小化、去标识化（含间接标识）、权限与保密、留存与删除。"把数据贴进公开工具帮忙标"是必须被流程禁止的操作。
