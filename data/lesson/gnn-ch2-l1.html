邻居聚合思想#

第一章已经埋下伏笔：节点分类时，"先对邻居特征取平均再分类"比"只看节点自身特征"更准。这一课把这个朴素的直觉上升为一套正式的学习范式——邻居聚合（neighborhood aggregation）。它是所有图神经网络（GCN、GraphSAGE、GAT 等）共同的骨架。理解它为什么有效、它怎么一步步展开成感受野，是进入 GNN 世界的第一道门。

一、概念讲解#

1. 核心假设：物以类聚#

邻居聚合之所以有效，背后有一条经验性假设——同质性（homophily）：相连的节点倾向于相似。社交网络里朋友之间有相似兴趣，论文引用网络里互相引用的论文主题相近，分子里相连的原子处于相近的化学环境。既然邻居"像自己"，那把邻居的信息借过来，就能补足甚至修正自身信息——尤其是当自身特征有噪声或缺失时（第一章的例子正是如此）。

当然，同质性不是放之四海皆准的：欺诈检测网络里，骗子反而更爱连向"正常用户"（异质性）。这时简单聚合会帮倒忙，需要更精细的设计（负权重、注意力、更深的变换）。但作为入门，先理解同质性假设下的聚合逻辑就足够了。

2. 迭代聚合：从局部到全局#

邻居聚合的核心是一套迭代公式。设节点 v 在第 k 层的表示向量为 h_v^(k)，初始时 h_v^(0) 就是节点特征 x_v。每一层做两件事：

  1. 聚合（aggregate）：把 v 的所有邻居的上一轮表示收集起来，用一个"对称函数"合并成一个向量；
  2. 结合（combine）：把聚合结果和 v 自己上一轮的表示合起来，经过变换，得到这一轮的新表示。

写成公式（均值聚合的简化版）：

h_v^(k) = σ( W^(k) · MEAN( { h_u^(k−1) : u ∈ N(v) ∪ {v} } ) )

其中 σ 是非线性激活，W^(k) 是可学习的权重矩阵。这就是 GCN 一层做的事情，也是几乎所有 GNN 层的共同模板——聚合邻居、变换特征、迭代多层。

3. 感受野随层数扩大#

这个迭代过程有一个漂亮的几何解释：k 层之后，节点 v 的表示包含了它 k 跳以内所有邻居的信息。

  • 第 1 层后，v 看到了自己的 1 跳邻居；
  • 第 2 层后，v 的邻居们各自也聚合了它们的邻居，于是 v 间接看到了 2 跳邻居；
  • 以此类推，k 层对应 k 跳感受野。

这就像 CNN 里卷积核的感受野随层数扩大、RNN 里隐状态沿时间步越记越远。所以层的数量决定了每个节点"能看到多远"，这是设计 GNN 深度时要权衡的关键因素。

4. 为什么不能无限加深：过度平滑#

既然多层能看得更远，那是不是越深越好？不是。因为每做一次聚合，相邻节点的表示就被"拉近"一点。层数过多时，整张图里所有节点的表示会趋于同一个值，节点之间不再有区分度——这叫过度平滑（over-smoothing）。这也是为什么实践中 GNN 通常只堆 2~4 层，而不是像 ResNet 那样几十上百层。理解"感受野扩大"与"过度平滑"这对矛盾，是设计 GNN 的核心直觉之一。

二、可运行代码示例#

下面用 NumPy 手写"邻居均值聚合"的迭代过程，直观感受两件事：① 特征如何一层层被"抹平"；② 每个节点在每一层"看得到"哪些节点。

import numpy as np

# 1) 一条链式图：0 - 1 - 2 - 3 - 4 - 5
n = 6
A = np.zeros((n, n))
for i in range(n - 1):
    A[i, i + 1] = A[i + 1, i] = 1.0

# 2) 加自环 + 行归一化，得到"传播矩阵" S
A_tilde = A + np.eye(n)              # 加自环，保留自身信息
D_tilde_inv = np.diag(1.0 / A_tilde.sum(axis=1))
S = D_tilde_inv @ A_tilde            # S @ H 就是"邻居均值（含自身）"

# 3) 初始特征：每个节点用 1 维特征 = 自己的编号
H = np.arange(n, dtype=float).reshape(-1, 1)
print("初始特征 H^0：", H.ravel())

# 4) 迭代聚合 3 层，观察特征如何被"抹平"
for k in range(1, 4):
    H = S @ H
    print(f"第 {k} 层后 H^{k}：", np.round(H.ravel(), 3))

# 5) 感受野演示：节点 2 在第 k 层"看得到"哪些节点
#    第 k 层之后，节点 i 的表示会依赖距离 <= k 的节点
for k in range(1, 4):
    seen = [j for j in range(n) if abs(j - 2) <= k]
    print(f"节点 2 在第 {k} 层后的感受野：{seen}")

运行后你能看到两个现象：① 初始特征 [0,1,2,3,4,5] 每聚合一次，相邻节点的差距就缩小一点，三次之后整条链趋于平滑——这正是"过度平滑"的雏形；② 节点 2 的感受野从 {1,2,3} 一步步扩大到 {0,1,2,3,4,5}，层数与跳数一一对应。

三、练习#

  1. 把传播矩阵 S 改成不带自环的纯邻居平均（D^{-1} A），运行 3 层，观察节点自身特征在传播中"丢失"的现象，说明为什么通常要加自环。
  2. 把图从"链"改成"两个社区各 3 个节点 + 一条桥"，初始特征随机，迭代 2 层后计算"社区内部节点表示的差异"和"社区间节点表示的差异"，验证同质性假设下聚合能让同类更聚拢。
  3. 手工推导：在一维链 0-1-2 上，节点 1 经过两层均值聚合后，它的表示由哪些节点的初始特征组成？各自的权重是多少？
  4. 思考：过度平滑的本质是什么？如果给每层的聚合结果加一个"跳跃连接"（把 h_v^(k−1) 直接加到 h_v^(k) 上），能否缓解过度平滑？为什么？
