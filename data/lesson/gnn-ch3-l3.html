GCN 实现#

公式已经到手：H^{(l+1)} = σ( D̃^{−1/2} Ã D̃^{−1/2} H^{(l)} W^{(l)} )。这一课把它变成能跑的代码，完成一个经典的半监督节点分类任务。我们用 PyTorch 从零实现两层 GCN（不依赖 PyG），在一个人工构造的"两社区"图上训练，完整走一遍"构造归一化传播算子 → 定义 GCN 层 → 训练 → 评估"的闭环，最后再对照 PyG 的 GCNConv 说明两者如何对应。

一、概念讲解#

1. 半监督节点分类的设定#

GCN 论文最经典的实验是在 Cora 等引文网络上做半监督节点分类：

  • 输入：整张图（所有节点的特征 + 所有边）都可见；
  • 标签：只有一小部分节点有标签（训练集），其余节点作为验证/测试集；
  • 目标：让标签信息"顺着边传播"到未标注节点。

这就是第一章说的直推（transductive）设定。训练时损失只在有标签的节点上计算，但梯度会通过共享的传播算子流回所有节点——这正是 GCN 能"用少量标签训好整张图"的关键：图结构本身就是一条信息传播的高速公路。

2. 两层 GCN 的结构#

标准配置是两层：

Z = softmax( S · ReLU( S · X · W⁽⁰⁾ ) · W⁽¹⁾ )

  • 第一层：S X W⁽⁰⁾ 把 d 维输入映射到 hidden 维，过 ReLU；
  • 第二层：S H⁽¹⁾ W⁽¹⁾ 把 hidden 维映射到类别数 C；
  • 最后接 softmax 得到分类概率。

为什么恰好两层？论文发现：一层只能看 1 跳邻居，信息不足；三层及以上会过度平滑，精度下降。两层是"感受野"与"平滑度"之间的甜点。

3. 传播算子的两种实现#

实现 GCN 的关键是构造传播算子 S = D̃^{−1/2} Ã D̃^{−1/2}，有两种思路：

  • 稠密实现：直接构造 n×n 的矩阵 A、D̃，再矩阵相乘。简单直观，但 n 大时内存是 O(n²)，只能用于小图/教学。
  • 稀疏实现：借助 edge_index 和 torch_sparse（或 PyG 内部的 spmm），只在非零元素上做乘法，内存 O(|E|)。真实框架都用这一种。

本课用稠密实现讲清原理，PyG 的 GCNConv 底层则是高效的稀疏版本。

4. 与 PyG 的对应关系#

PyG 里一行 GCNConv(in_channels, out_channels) 就封装了全部逻辑：它在 forward 里先由 edge_index 算出归一化系数，再执行 S @ X @ W + b。你手写的 GCNLayer 和它的差异只在"传播算子怎么算、用不用稀疏矩阵"，数学上完全一致。看懂本课代码，再看 PyG 源码就不会陌生。

二、可运行代码示例#

下面用纯 PyTorch 实现两层 GCN，在一个 17 节点的两社区图上做半监督节点分类。整段代码可直接运行，不依赖 PyG。

import random
import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)
random.seed(0)

# 1) 构造两社区图：社区 A = 0..8，社区 B = 9..16，社区间有少量"桥"边
n = 17
labels = torch.tensor([0] * 9 + [1] * 8)

edges = set()
def add(u, v):
    if u > v:
        u, v = v, u
    edges.add((u, v))
for _ in range(40):                     # 社区 A 内部连边
    a, b = random.randrange(9), random.randrange(9)
    if a != b:
        add(a, b)
for _ in range(40):                     # 社区 B 内部连边
    a, b = random.randrange(9, 17), random.randrange(9, 17)
    if a != b:
        add(a, b)
for _ in range(8):                      # 社区间的桥边
    add(random.randrange(9), random.randrange(9, 17))

edge_index = torch.tensor(
    [[u for u, v in edges] + [v for u, v in edges],
     [v for u, v in edges] + [u for u, v in edges]])

# 2) 构造归一化传播算子 S = D̃^{-1/2} Ã D̃^{-1/2}
def normalize_adjacency(edge_index, n):
    A = torch.zeros(n, n)
    A[edge_index[0], edge_index[1]] = 1.0
    A_hat = A + torch.eye(n)                 # 加自环
    deg_inv_sqrt = A_hat.sum(dim=1).pow(-0.5)
    D_inv_sqrt = torch.diag(deg_inv_sqrt)
    return D_inv_sqrt @ A_hat @ D_inv_sqrt   # 对称归一化

S = normalize_adjacency(edge_index, n)

# 节点特征用 one-hot（无属性图的常见做法）
X = torch.eye(n)

# 3) 两层 GCN 模型
class GCN(nn.Module):
    def __init__(self, in_dim, hidden, out_dim, S):
        super().__init__()
        self.S = S
        self.fc1 = nn.Linear(in_dim, hidden)
        self.fc2 = nn.Linear(hidden, out_dim)
    def forward(self, X):
        H = self.S @ F.relu(self.fc1(X))     # 第一层传播
        return self.S @ self.fc2(H)          # 第二层传播

model = GCN(n, 8, 2, S)
opt = torch.optim.Adam(model.parameters(), lr=0.02)
loss_fn = nn.CrossEntropyLoss()

# 4) 半监督设定：每个社区只标注前 4 个节点，其余作为测试
train_mask = torch.zeros(n, dtype=torch.bool)
train_mask[:4] = True
train_mask[9:13] = True
test_mask = ~train_mask

# 5) 训练
for epoch in range(400):
    model.train()
    logits = model(X)
    loss = loss_fn(logits[train_mask], labels[train_mask])
    opt.zero_grad()
    loss.backward()
    opt.step()
    if epoch % 80 == 0:
        print(f"epoch {epoch:3d} | loss = {loss.item():.4f}")

# 6) 评估：只统计测试节点的准确率
model.eval()
with torch.no_grad():
    pred = model(X).argmax(dim=1)
acc = (pred[test_mask] == labels[test_mask]).float().mean()
print("测试节点准确率：", round(acc.item(), 3))
print("预测标签：", pred.tolist())
print("真实标签：", labels.tolist())

运行后损失会快速下降，测试节点准确率通常能达到 1.0（或接近）。关键观察：每个社区只标注了 4 个节点，其余节点全靠"标签顺着边传播"被正确分类——这正是半监督图学习的威力。你可以把桥边数量加多、或减少标注节点，观察准确率如何随"社区分界模糊程度"和"标注稀疏程度"变化。

三、练习#

  1. 把 GCN 层数从 2 层加到 5 层（注意中间层都要过 ReLU），重新训练，观察准确率和损失的变化，结合"过度平滑"解释现象。
  2. 把节点特征从 one-hot 换成随机向量 torch.randn(n, 4)，重训，对比准确率。思考：为什么 one-hot 在这个无属性图上更有效？
  3. 参照 GCNConv 的接口，把自己实现的 GCN 重构成一个 GCNLayer(in_dim, out_dim) 类，forward(self, X, edge_index) 内部实时计算 S，使它能处理不同的图。
  4. 用 PyG 复现本课任务：from torch_geometric.nn import GCNConv，把 Data(x=X, edge_index=edge_index, y=labels) 传入两层 GCNConv，对比结果与手写版是否一致。
