函数基础#

微积分研究的对象是函数。在学导数、极限之前，我们先花一课把"函数"这个地基打牢——而且你会发现，你在 Python 里早就天天和函数打交道了。机器学习里最核心的一句话是：模型就是一个函数。理解函数，就是理解 AI 在"算"什么。

一、概念讲解#

1. 函数是什么：一台"输入—输出"机器#

把函数想象成一台自动售货机：你投进去一枚硬币（输入），它吐出一罐饮料（输出）。只要投的是同一个币，吐出来的永远是同一罐饮料，结果确定且唯一。这就是函数的本质：

函数是一种规则，它给每个输入，都对应唯一一个输出。

数学上写作 y = f(x)：x 是输入（自变量），y 是输出（因变量），f 就是那套"规则"。

在 Python 里，这就是你熟悉的 def：

def f(x):
    """一台最朴素的'函数机器'：输入一个数，输出它的平方。"""
    return x * x

f 是规则，x 是输入，f(3) 返回 9。和数学里的 f(3) = 9 完全是一回事。

2. 定义域与值域#

函数不是对所有输入都有意义：

  • 定义域：所有"可以投进去"的输入组成的集合。
  • 值域：所有"可能吐出来"的输出组成的集合。

例如 f(x) = 1 / x，当 x = 0 时没有意义（分母不能为 0），所以定义域是"所有非零实数"。再如 f(x) = x²，输出永远大于等于 0，值域就是 [0, +∞)。

在机器学习里，定义域/值域常对应"输入特征的取值范围"和"输出预测的取值范围"，想清楚它们能帮你避免很多 bug。

3. 函数为什么是 AI 的基石#

一个最简单的线性回归模型：

预测房价 = 权重 × 面积 + 偏置

这本质上是一个函数 price = f(area)。输入是"面积"，输出是"房价"，而 权重 和 偏置 是决定这台"机器"具体长什么样的参数。所谓"训练模型"，就是不断调整这两个参数，让这个函数的输出越来越接近真实房价。整门课，我们都在围绕"怎么调参数让函数更好用"展开。

4. 常见函数速览#

类型 例子 特点
一次函数 y = 2x + 1 直线，均匀变化
二次函数 y = x² 抛物线，有最低点
指数函数 y = eˣ 增长越来越快
对数函数 y = ln(x) 增长越来越慢

这些你都会在微积分里反复见到，现在混个脸熟即可。

二、可运行示例#

下面我们用 Python 亲手搭一台"函数机器"，并给它画张图。

import math

# 1) 定义几个函数
def linear(x):
    """一次函数：y = 2x + 1"""
    return 2 * x + 1

def quadratic(x):
    """二次函数：y = x^2"""
    return x * x

def sigmoid(x):
    """Sigmoid 函数：机器学习里最常见的激活函数之一"""
    return 1 / (1 + math.exp(-x))

# 2) 函数机器：给定函数和输入，输出结果
def apply(f, x):
    """把函数 f 作用在输入 x 上，返回 f(x)。"""
    return f(x)

# 3) 逐个试试
print("linear(3)   =", apply(linear, 3))     # 2*3+1 = 7
print("quadratic(5)=", apply(quadratic, 5))   # 5*5 = 25
print("sigmoid(0)  =", apply(sigmoid, 0))     # 1/(1+1) = 0.5

# 4) 手动生成一张数值表，体会"函数 = 输入到输出的映射"
print("\n--- quadratic 在 x=0..5 的取值表 ---")
for x in range(6):
    print(f"x = {x}, quadratic(x) = {apply(quadratic, x)}")

运行后你会得到：

linear(3)   = 7
quadratic(5)= 25
sigmoid(0)  = 0.5

--- quadratic 在 x=0..5 的取值表 ---
x = 0, quadratic(x) = 0
x = 1, quadratic(x) = 1
x = 2, quadratic(x) = 4
x = 3, quadratic(x) = 9
x = 4, quadratic(x) = 16
x = 5, quadratic(x) = 25

注意到没？quadratic 的输出从 0、1、4 一路涨到 25，增长得越来越快——这正是二次函数的特征。而 sigmoid(0) = 0.5 这个结果，在你学神经网络时会天天见到。

三、练习#

  1. 定义一个 cube(x)，计算 x³，并打印 x = 1..5 的取值表，观察增长比 quadratic 更快还是更慢。
  2. 定义 f(x) = 1/x，试着打印 f(0)，观察会发生什么；再想想它的定义域里"缺"了哪个点。
  3. 定义一个"线性回归"函数 price(area, w, b) = w * area + b。固定 w=3000, b=20000，分别计算 area 为 50、80、100（平方米）时的房价，体会"模型 = 函数 + 参数"。
  4. 想一想：f(x) = x² 和 g(x) = x² + 3 是不是同一个函数？它们画出来的图是什么关系？
