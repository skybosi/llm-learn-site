PyG 入门#

前五章我们在"纸面"上把 GCN、SAGE、GAT、图分类都推了一遍，代码片段都是拿来即用的示意。从本章开始进入实战：用 PyTorch Geometric（PyG） 这套最主流的图神经网络库，把理论落成可运行的完整工程。本课先搭好环境、吃透它的核心数据结构 Data，再写出第一个"从零到训练"的完整脚本。

一、概念讲解#

1. PyG 是什么，为什么用它#

PyG（torch_geometric）是构建在 PyTorch 之上的图深度学习库，官方定位是"几何深度学习扩展库"。它解决了一个关键问题：图的规模、结构、稀疏性各不相同，直接用 PyTorch 的张量很难统一表达。PyG 提供了：

  • 统一的数据抽象：Data、Dataset、Batch、DataLoader，把各种图塞进同一套 API。
  • 现成的卷积算子：GCNConv、SAGEConv、GATConv、GINConv 等，一行调用。
  • 丰富的内置数据集：Cora、PubMed、MUTAG、OGB 等，一行下载。
  • 消息传递框架：MessagePassing 基类，让你用几行代码自定义新的图卷积。

它与 DGL（Deep Graph Library）是两大主流选择；PyG 的优势是与 PyTorch 生态无缝衔接、社区活跃、论文复现多，是国内学习与科研的默认入口之一。

pip install torch_scatter torch_sparse torch_cluster

import torch

print(torch.__version__)

如果 import torch_geometric 成功，环境就绪。注意：不同 PyG 大版本之间 API 有变化（例如 DataLoader 从 torch_geometric.data 迁到了 torch_geometric.loader），遇到报错先核对版本对应关系。

3. 核心数据结构：Data#

PyG 用单个 Data 对象表示一张图。它本质上是一个"带属性的字典"，最常用的字段：

字段 含义 形状
x 节点特征矩阵 [num_nodes, num_node_features]
edge_index 边的索引（COO 格式） [2, num_edges]
edge_attr 边特征（可选） [num_edges, num_edge_features]
y 标签（节点或图） 视任务而定

其中 edge_index 是 PyG 最关键的约定：它不是邻接矩阵，而是两行索引。第 0 行是源节点、第 1 行是目标节点，每一列是一条边。例如 edge_index = [[0,1,2], [1,2,0]] 表示三条有向边 0→1, 1→2, 2→0。若是无向图，需要双向写入每条边（或使用 to_undirected() 转换）。

Data 还有便捷工具：data.num_nodes、data.num_edges、data.has_self_loops()、data.is_undirected()，以及切片、按节点/边过滤等操作。

4. 手工构造一个 Data 并跑一次 GCN#

理解了 Data，就能手工把任意图"塞进" PyG。下面构造一个 3 节点的小图，验证 GCNConv 的前向输出形状，感受消息传递在库内部是如何自动发生的。

import torch
from torch_geometric.data import Data
from torch_geometric.nn import GCNConv

# 手工构造 3 节点图：每个节点 2 维特征
x = torch.tensor([[1., 2.],
                  [3., 4.],
                  [5., 6.]], dtype=torch.float)

# 无向边（双向写）：0-1、1-2
edge_index = torch.tensor([[0, 1, 1, 2],
                           [1, 0, 2, 1]], dtype=torch.long)

data = Data(x=x, edge_index=edge_index)
print(data)  # Data(x=[3, 2], edge_index=[2, 4])

# 一层 GCN：2 维输入 → 4 维输出
conv = GCNConv(2, 4)
out = conv(data.x, data.edge_index)
print(out.shape)  # torch.Size([3, 4])，每个节点都得到新嵌入

这里的关键是：GCNConv.forward(x, edge_index) 内部自动完成了"邻居查找 → 归一化 → 聚合 → 线性变换"，你不需要手写任何稀疏矩阵乘法。

二、可运行示例#

示例：第一个完整训练脚本——Karate 空手道俱乐部（半监督节点分类）

KarateClub 是内置的经典小图（34 个节点，分成 2 个社区），适合作为"hello world"跑通全流程。

import torch
import torch.nn.functional as F
from torch_geometric.nn import GCNConv
from torch_geometric.datasets import KarateClub

# 1. 数据：只有 34 个节点，边表示成员社交关系，标签是社区归属（2 类）
dataset = KarateClub()
data = dataset[0]
print(f'节点 {data.num_nodes} | 边 {data.num_edges} | 特征维 {data.num_features}')

# 2. 模型：两层 GCN + log_softmax
class GCN(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = GCNConv(dataset.num_features, 16)
        self.conv2 = GCNConv(16, dataset.num_classes)
    def forward(self, x, edge_index):
        x = F.relu(self.conv1(x, edge_index))
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)

model = GCN()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# 3. 半监督：只用前 4 个节点的标签训练（掩码）
train_mask = torch.zeros(data.num_nodes, dtype=torch.bool)
train_mask[:4] = True

def train():
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.nll_loss(out[train_mask], data.y[train_mask])
    loss.backward()
    optimizer.step()
    return loss.item()

@torch.no_grad()
def test():
    model.eval()
    pred = model(data.x, data.edge_index).argmax(dim=1)
    acc = (pred == data.y).float().mean().item()
    return acc

for epoch in range(100):
    loss = train()
    if epoch % 10 == 0:
        print(f'Epoch {epoch:03d} | Loss {loss:.4f} | 全图 Acc {test():.4f}')

这个例子麻雀虽小五脏俱全：Data 载入 → 定义模型 → 定义掩码 → 训练循环 → 评估。它和前几章 Cora 例子的结构完全一致，只是换了更小的数据集便于一眼看清全貌。跑通它，你就掌握了 PyG 的基本工作流。

三、练习#

  1. 环境自检：在自己的环境里执行 import torch_geometric 并打印版本，记录 torch 与 torch_geometric 的版本组合。
  2. 手工造图：构造一个 5 节点、含自环和重复边的 Data，分别用 data.has_self_loops()、data.num_edges 验证，再用 to_undirected() 把它变成无向图。
  3. 理解 edge_index：把手工例子的 edge_index 打印出来，画出对应的图，确认第 0 行是源、第 1 行是目标这一约定。
  4. 掩码实验：把 Karate 例子的训练掩码从 4 个节点改成 8 个、20 个，观察全图准确率随标签数量如何变化，体会半监督学习的效果。
  5. 前瞻：KarateClub() 是一个内置数据集。下一课我们要弄清 PyG 如何统一管理几十个这样的数据集、以及如何加载自己的数据。
