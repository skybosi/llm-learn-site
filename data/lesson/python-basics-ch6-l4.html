魔法方法与简单实战#

一、概念讲解#

"魔法方法"（magic methods，也叫特殊方法）是 Python 里一类名字前后都有两个下划线的方法，比如我们已经见过的 __init__。它们由 Python 在特定时刻自动调用，你通常不需要直接去调用它们。

魔法方法的作用是：让自定义的类能像 Python 内置类型一样好用。比如让你的对象能打印得好看、能比较大小、能相加、能被 len() 计算长度等。

1. 让打印更好看：str 与 repr#

默认情况下，直接 print(对象) 会得到一串看不懂的地址。实现 __str__ 后，print 就会显示我们想要的文字：

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"Point({self.x}, {self.y})"

p = Point(3, 5)
print(p)          # Point(3, 5)

__str__ 面向用户，负责可读性；__repr__ 面向开发者，通常返回一个"能看出对象如何构造"的字符串。两者可以写成一样，也可以不同。简单起见，初学时实现 __str__ 就足够日常使用。

2. 支持 len()：len#

实现 __len__ 后，你的对象就能用 len() 来测量：

class Playlist:
    def __init__(self):
        self.songs = []

    def add(self, song):
        self.songs.append(song)

    def __len__(self):
        return len(self.songs)

p = Playlist()
p.add("晴天")
p.add("稻香")
print(len(p))     # 2

3. 支持比较：eq 与 lt#

实现 __eq__ 可以让对象用 == 判断"相等"，实现 __lt__ 可以让对象用 < 比较大小：

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __eq__(self, other):
        return self.age == other.age

    def __lt__(self, other):
        return self.age < other.age

a = Person("小明", 20)
b = Person("小红", 22)
print(a == b)     # False
print(a < b)      # True

4. 支持相加：add#

实现 __add__ 后，对象之间就能用 + 号运算：

class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __str__(self):
        return f"({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)    # (4, 6)

二、简单实战：一个待办事项（Todo）类#

下面用一个完整的小例子，把本课和前面几课的知识串起来，模拟一个"待办事项清单"。

class Todo:
    def __init__(self, title, done=False):
        self.title = title      # 事项内容
        self.done = done        # 是否完成

    def finish(self):
        """标记为已完成"""
        self.done = True

    def __str__(self):
        # 根据完成状态返回不同文字，让打印更直观
        mark = "✓" if self.done else "○"
        return f"{mark} {self.title}"


class TodoList:
    def __init__(self):
        self.items = []         # 用一个列表保存所有事项

    def add(self, title):
        """添加一个待办"""
        self.items.append(Todo(title))

    def finish(self, index):
        """完成指定序号的事项"""
        if 0 <= index < len(self.items):
            self.items[index].finish()
        else:
            print("序号超出范围")

    def __len__(self):
        # 魔法方法：让 len() 直接返回事项数量
        return len(self.items)

    def show(self):
        print(f"共 {len(self)} 件事：")
        for i, item in enumerate(self.items):
            print(f"  [{i}] {item}")


# ---- 使用 ----
mylist = TodoList()
mylist.add("背 20 个单词")
mylist.add("做一道 Python 练习")
mylist.add("跑步 30 分钟")

mylist.show()
# 共 3 件事：
#   [0] ○ 背 20 个单词
#   [1] ○ 做一道 Python 练习
#   [2] ○ 跑步 30 分钟

mylist.finish(1)      # 完成第 1 件事
mylist.show()
# 共 3 件事：
#   [0] ○ 背 20 个单词
#   [1] ✓ 做一道 Python 练习
#   [2] ○ 跑步 30 分钟

print("事项总数：", len(mylist))   # 事项总数： 3
