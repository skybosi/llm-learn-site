训练流程#

前四章已经备齐了所有零件：张量、自动微分、模型、数据加载。现在把它们组装成一台能"自动变聪明"的机器——训练循环。无论多复杂的神经网络，训练的本质都是同一个四步循环，理解这四步，你就理解了深度学习"学习"二字的全部含义。

一、概念讲解#

1. 训练 = 反复执行四步#

一个 batch 的训练由四步构成：

  1. 前向传播（forward）：把输入送进模型，算出预测 output = model(x)；
  2. 计算损失（loss）：用损失函数衡量"预测和真实差多远" loss = criterion(output, y)；
  3. 反向传播（backward）：调用 loss.backward()，自动算出每个参数对损失的梯度；
  4. 更新参数（step）：优化器 optimizer.step() 沿梯度反方向微调参数，让损失变小。

这四步被包进一个 for 循环，反复跑很多轮（epoch），模型的损失就会一路下降，参数越调越好。

2. 三样"训练前必先备好"的东西#

进入循环前，必须先准备三样：

  • 模型 model = Net()；
  • 损失函数 criterion = nn.CrossEntropyLoss()（分类）或 nn.MSELoss()（回归）；
  • 优化器 optimizer = torch.optim.SGD(model.parameters(), lr=0.01)，它持有"用哪个学习率、怎么更新参数"的规则。

3. 一个极其容易踩的坑：忘记清零梯度#

loss.backward() 会累加梯度到参数的 .grad 上，而不是覆盖。所以每次更新前必须 optimizer.zero_grad()，否则上一个 batch 的梯度会混进下一个 batch，让模型越训越歪。正确顺序是：

optimizer.zero_grad()   # 1) 清空旧梯度
loss.backward()         # 2) 计算新梯度
optimizer.step()        # 3) 更新参数

4. 两种训练模式：train 与 eval#

模型里有些层在训练和评估时行为不同，最典型的是 Dropout 和 BatchNorm。因此：

  • 训练前调用 model.train()；
  • 评估/推理前调用 model.eval()。

漏掉 model.eval() 会让 Dropout 在测试时仍然随机丢弃神经元，导致评估结果失真。

二、可运行代码示例#

下面用一个线性模型拟合上一章的抛物线数据，跑一个完整但精简的训练循环，并打印损失下降的过程。代码只用 CPU，几分钟内就能跑完。

import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader


# 1) 数据：y = 2x^2 - 3x + 1 的带噪声样本
class ParabolaDataset(Dataset):
    def __init__(self, n=500, noise=0.3):
        super().__init__()
        self.x = torch.linspace(-2, 2, steps=n).unsqueeze(1)
        self.y = 2 * self.x ** 2 - 3 * self.x + 1
        self.y = self.y + noise * torch.randn_like(self.y)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, index):
        return self.x[index], self.y[index]


loader = DataLoader(ParabolaDataset(n=500), batch_size=32, shuffle=True)

# 2) 模型：一个隐藏层，用 ReLU 激活，能拟合非线性曲线
model = nn.Sequential(
    nn.Linear(1, 16),
    nn.ReLU(),
    nn.Linear(16, 1),
)

# 3) 损失函数（回归用均方误差）与优化器（SGD）
criterion = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)

# 4) 训练循环：epoch 是"看完整轮数据"，内层 for 是"逐个 batch"
model.train()   # 进入训练模式
for epoch in range(1, 21):
    total_loss = 0.0
    for x_batch, y_batch in loader:
        optimizer.zero_grad()          # ① 清空上一 batch 的梯度
        pred = model(x_batch)          # ② 前向传播
        loss = criterion(pred, y_batch)  # ③ 计算损失
        loss.backward()                # ④ 反向传播，求梯度
        optimizer.step()               # ⑤ 用梯度更新参数

        total_loss += loss.item() * x_batch.size(0)

    avg_loss = total_loss / len(loader.dataset)
    if epoch % 5 == 0 or epoch == 1:
        print(f"epoch {epoch:2d}  平均损失 = {avg_loss:.4f}")

运行后你会看到类似：

epoch  1  平均损失 = 8.2310
epoch  5  平均损失 = 1.9744
epoch 10  平均损失 = 0.9218
epoch 15  平均损失 = 0.4513
epoch 20  平均损失 = 0.2401

损失从 8 一路降到 0.24，说明模型正一步步逼近真实的抛物线。注意 total_loss += loss.item() * x_batch.size(0) 这一步：因为最后一个 batch 可能不满，用"损失乘以样本数"来加权平均，才能得到正确的全体样本平均损失。

三、练习#

  1. 把优化器换成 torch.optim.Adam(model.parameters(), lr=0.01)，同样跑 20 个 epoch，对比损失下降速度。
  2. 把学习率改成 lr=1.0，观察损失是否发散（inf 或 nan），体会学习率过大导致"跳过头"的现象。
  3. 故意删掉 optimizer.zero_grad() 这一行再跑，观察损失曲线是否异常，解释为什么梯度会累加。
  4. 在循环里加一行，每个 epoch 打印 model[0].weight.grad 的绝对值均值，观察梯度随训练的变化趋势。
