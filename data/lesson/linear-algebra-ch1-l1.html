向量的概念与表示#

学完 Python 基础之后，我们正式开始学习机器学习最核心的数学工具——线性代数。这门课的第一站是向量（vector）。你可能会问：向量不是高中几何里那个"带箭头的线段"吗？它跟 AI 有什么关系？

答案是：在机器学习里，向量是最基础的数据容器。一条样本、一张图片、一句话，最终都会被表示成一个向量。这一课我们先弄清楚"向量到底是什么"，以及如何用 Python 表示它。

一、概念讲解#

1. 什么是向量#

数学上，向量可以有两种互补的理解方式：

  • 几何视角：向量是一个有方向和大小的量，通常画成一根箭头。箭头的指向是方向，箭头的长度是大小（也叫模长）。
  • 分量视角（更贴近编程）：向量是一串有序排列的数字。例如 (3, 4) 就是一个二维向量，它由两个"分量"组成。

这两种视角是同一件事的两面：把 (3, 4) 画在坐标平面上，就是一根从原点出发、向右走 3 格再向上走 4 格的箭头。

向量有几个常用记号：黑体小写字母 v，或者带箭头的 v⃗。在程序里，我们直接用变量名（如 v）来表示它。

2. 机器学习中的向量：表示"一条样本"#

在 AI 领域，向量最重要的用途是表示样本的特征。举个例子，我们要训练一个模型预测房价，每条房源数据可能包含：

  • 面积（平方米）
  • 房间数
  • 房龄（年）

那么一套"120 平方米、3 间房、房龄 5 年"的房子，就可以写成一个三维向量：

(120, 3, 5)

其中第 1 个分量是面积，第 2 个是房间数，第 3 个是房龄。分量顺序一旦定下来，就必须始终一致——如果第一条样本的第 1 位是面积，那么所有样本的第 1 位都必须是面积。

类似地：

  • 一张 28×28 的灰度图片，把 784 个像素的灰度值排成一列，就得到一个 784 维向量；
  • 一句话经过"词向量"技术处理后，也可以变成一个固定长度的向量；
  • 一个用户的行为（点击、购买、评分……）可以编码成向量，用来做推荐。

一句话总结：向量 = 一组按固定顺序排列的数字，用来描述一个对象。 向量的长度（分量的个数）叫做维度（dimension）。

3. 向量的两种写法：行向量与列向量#

向量写成一横排叫行向量，写成一竖列叫列向量。同一个向量 (3, 4) 可以写成：

行向量： [3  4]
列向量：  [3]
         [4]

在机器学习公式里，习惯上把"样本特征向量"写成列向量，记作 x。不过在代码里我们通常用一维数组表示它，不严格区分横竖，需要时再用 .reshape() 调整。

二、可运行示例#

在 Python 里，最常用的数值计算库是 NumPy。它提供了一个专门的数组类型 ndarray，向量就是其中"一维数组"这一特例。下面我们用 NumPy 表示一条房价样本，并做几个基本操作。

import numpy as np

# 用 np.array 创建一个三维特征向量
# 顺序约定：第 0 位=面积，第 1 位=房间数，第 2 位=房龄
house = np.array([120.0, 3.0, 5.0])

print("特征向量 house =", house)
print("向量维度（分量个数）=", house.shape[0])   # shape 是 (3,)，shape[0] 即 3

# 通过下标访问每一个分量（注意：Python 下标从 0 开始）
area = house[0]     # 第 0 个分量：面积
rooms = house[1]    # 第 1 个分量：房间数
age = house[2]      # 第 2 个分量：房龄
print(f"面积={area}，房间数={rooms}，房龄={age}")

# 把行向量转成列向量（3 行 1 列），供后面矩阵乘法使用
column_vec = house.reshape(3, 1)
print("列向量形状 =", column_vec.shape)          # 输出 (3, 1)
print(column_vec)

预期输出（大意）：

特征向量 house = [120.   3.   5.]
向量维度（分量个数）= 3
面积=120.0，房间数=3.0，房龄=5.0
列向量形状 = (3, 1)
[[120.]
 [  3.]
 [  5.]]

再来看一个"多个样本"的例子。我们用向量表示三名用户对某部电影的评分，维度是 4（对应 4 个不同方面）：

import numpy as np

# 每个向量表示一个用户的评分，4 个分量分别对应：剧情、画面、演技、音乐
user_a = np.array([9, 8, 7, 9])   # 用户 A 的打分
user_b = np.array([6, 7, 8, 6])   # 用户 B 的打分
user_c = np.array([8, 6, 9, 7])   # 用户 C 的打分

print("用户 A 的评分向量：", user_a)
print("第 3 个维度（音乐）的分数：", user_a[3])   # 下标 3 对应第 4 个分量

要点：np.array([...]) 中的数字必须是同一类型（这里都是整数）；整个数组的维度由 shape 表示，(3,) 表示"有 3 个分量的一维数组"。

三、练习#

  2. 口头解释：向一个没学过线性代数的朋友，用"一套房子的三个属性"这个例子，解释什么是向量、什么是分量、什么是维度。
  3. 观察数据：找一份你感兴趣的公开数据集（如鸢尾花数据 Iris），看看每条样本由哪些特征组成；写出其中一条样本的向量表示，并说明每个分量的含义。
  4. 思考：为什么说"分量顺序一旦定下来就不能乱"？如果把面积和房龄的位置调换，会带来什么问题？
