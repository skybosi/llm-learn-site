保存与加载#

辛辛苦苦训练几小时甚至几天的模型，如果关掉程序就消失，那真是前功尽弃。这一课讲模型持久化：怎么把训练好的参数存到磁盘、怎么重新读回来，以及"保存权重"和"保存整个模型"两种方式的区别——这是把模型交付上线的第一步。

一、概念讲解#

1. 模型的"灵魂"：state_dict#

PyTorch 的 nn.Module 里，真正决定模型行为的不是代码结构，而是每一层的参数（权重和偏置）。这些参数集中存放在一个叫 state_dict 的有序字典里：键是参数名（如 net.0.weight），值是对应的张量。

model = nn.Linear(2, 3)
print(model.state_dict().keys())
# odict_keys(['weight', 'bias'])

因此，保存模型的核心就是保存这个 state_dict。结构（几层、多大）由你手里的代码定义，参数由文件保存，两者配合才能完整还原一个模型。

2. 两种保存方式，选哪个#

（1）只存权重（推荐）：torch.save(model.state_dict(), "model.pt")

  • 优点：文件小、灵活、跨环境兼容性好；
  • 缺点：加载前必须先重建模型结构，再 load_state_dict。
model = MLP()                             # 先重建完全相同的结构
model.load_state_dict(torch.load("model.pt"))

（2）存整个模型：torch.save(model, "model.pt")

  • 优点：一行就能连结构带参数一起存、一起读；
  • 缺点：文件大、绑定具体代码路径，跨版本或跨机器时容易出兼容问题。

实战中，推荐只存 state_dict，这也是 PyTorch 官方文档建议的方式。

3. 从"训练脚本"到"推理脚本"#

保存之后要能用于推理，两个脚本必须保持模型结构一致。保存时存 state_dict，推理时先写同样的模型类、再加载权重。这提醒我们：模型结构代码要像"钥匙"一样妥善保管，丢了结构，权重文件就是一堆看不懂的数字。

二、可运行代码示例#

完整演示"训练 → 保存权重 → 另开一个'新环境'重建模型 → 加载 → 推理"的闭环。为了让代码在无 GPU 环境也能跑，全程用 CPU。

import torch
import torch.nn as nn


# ---------- 1) 定义一个模型结构 ----------
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Flatten(),
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10),
        )

    def forward(self, x):
        return self.net(x)


# ---------- 2) 假装"训练"：随便更新几步，让参数有意义 ----------
model = MLP()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
x = torch.randn(16, 1, 28, 28)   # 16 张 28x28 的伪图片
y = torch.randint(0, 10, (16,))  # 随机标签
for _ in range(3):
    optimizer.zero_grad()
    loss = nn.functional.cross_entropy(model(x), y)
    loss.backward()
    optimizer.step()

# ---------- 3) 只保存权重（推荐做法） ----------
torch.save(model.state_dict(), "mlp_weights.pt")
print("已保存 state_dict 到 mlp_weights.pt")

# ---------- 4) 模拟"另开一个程序"：重建结构 + 加载权重 ----------
model2 = MLP()                                   # 必须先重建同样的结构
model2.load_state_dict(torch.load("mlp_weights.pt"))
model2.eval()

# 验证两个模型参数一致、输出一致
with torch.no_grad():
    out1 = model(x)
    out2 = model2(x)
print("\n两个模型输出是否完全一致：", torch.allclose(out1, out2))

# ---------- 5) 用加载好的模型做一次"推理" ----------
with torch.no_grad():
    logits = model2(x[:1])          # 只预测第一张
    pred = logits.argmax(dim=1)
print("第一张图的预测类别：", pred.item())

运行后你会看到类似：

已保存 state_dict 到 mlp_weights.pt
两个模型输出是否完全一致： True
第一张图的预测类别： 3

关键在 torch.allclose(out1, out2) 返回 True：说明"保存权重 → 重建结构 → 加载权重"之后，新模型和原模型行为完全一致。这就是把训练成果持久化、交给推理服务的完整链路。

三、练习#

  1. 改用 torch.save(model, "mlp_full.pt") 保存整个模型，再用 torch.load 直接加载（无需重建结构），验证输出是否一致，并对比两个文件的大小。
  2. 保存 state_dict 后，故意把 model2 的结构改掉一层（比如隐藏层从 128 改成 64），再 load_state_dict，观察会报什么错，理解"结构必须一致"。
  3. 用 torch.load 读回 mlp_weights.pt，打印这个 state_dict 里每个键对应的张量形状，说说每一层参数的形状为什么是那样。
  4. 想一想：如果只想保存"训练中间状态"以便断点续训，除了权重还需要保存哪些东西（提示：优化器状态、epoch 数）？
