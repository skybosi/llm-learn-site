LSTM#

上一章我们看到，普通 RNN 的梯度在长序列上会指数级消失，导致"记不住很久以前的信息"。长短期记忆网络（Long Short-Term Memory, LSTM）就是为了解决这个问题而设计的：它给网络装上了"门"，让重要信息可以沿着一条几乎不受干扰的通道，跨越很多个时间步传递下去。这一课我们拆开 LSTM 的三个门，看清它是怎么做到"记得久、忘得对"的。

一、概念讲解#

1. 核心创新：细胞状态这条"传送带"#

LSTM 比 RNN 多了一条贯穿始终的通道，叫做细胞状态（cell state），记作 cₜ。你可以把它想象成一条在时间轴上滑动的传送带：信息搭上传送带后，可以几乎原封不动地一直往前传，很少被改动。

普通 RNN 里，隐藏状态每步都要经过一次 tanh 和权重连乘，信息被反复"揉搓"，早期内容很快就面目全非。而 LSTM 的细胞状态上，每一步只做线性的、可选择的加减——该保留的原样保留，该删除的删掉，该新增的加上。线性运算的梯度不像 tanh 连乘那样容易衰减，这正是它能缓解梯度消失的关键。

2. 三个门：遗忘、输入、输出#

LSTM 每一步用三个"门"来控制细胞状态。每个门本质上是一个输出 0~1 的 sigmoid 层，0 表示"完全拦住"，1 表示"完全放行"，中间值表示"放一部分"：

  • 遗忘门 fₜ：决定丢掉哪些旧信息。它看当前输入 xₜ 和上一刻隐藏状态 hₜ₋₁，对细胞状态的每个维度输出一个 0~1 的系数，乘到旧状态 cₜ₋₁ 上，把不需要的内容"擦掉"。
  • 输入门 iₜ：决定写入哪些新信息。它同时配合一个候选值 c̃ₜ（由 tanh 生成的新信息候选），门控系数决定"候选值里哪些真的存进细胞状态"。
  • 输出门 oₜ：决定输出什么。它从更新后的细胞状态 cₜ 里挑出要暴露给外界的部分，形成这一时刻的隐藏状态 hₜ。

整个过程可以写成五步（这里 σ 是 sigmoid，⊙ 是逐元素相乘）：

fₜ = σ(W_f · [hₜ₋₁, xₜ] + b_f)     # 遗忘门
iₜ = σ(W_i · [hₜ₋₁, xₜ] + b_i)     # 输入门
c̃ₜ = tanh(W_c · [hₜ₋₁, xₜ] + b_c)  # 候选新信息
cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ          # 更新细胞状态
oₜ = σ(W_o · [hₜ₋₁, xₜ] + b_o)     # 输出门
hₜ = oₜ ⊙ tanh(cₜ)                 # 当前隐藏状态

3. 用直觉读一遍公式#

拿"读句子判断情绪"来体会：模型读到"这个电影很无聊"——

  • 读到"很无聊"时，遗忘门会放大对应"负面"维度的保留系数，同时把之前"中性"的旧信息删掉；
  • 输入门把"无聊→负面"这个新信息写进细胞状态；
  • 输出门在最后一步把"负面情绪"作为隐藏状态交给分类层。

于是，"无聊"这个早期（或中期）信号可以被细胞状态稳稳地携带到句末，不再被长距离连乘稀释掉。门让网络学会了"选择性记忆"，而这正是普通 RNN 做不到的。

4. 与 RNN 的两点区别#

  1. 多了细胞状态：RNN 只有一个状态 hₜ，LSTM 有两个——cₜ（长期记忆）和 hₜ（对外输出，短期"工作记忆"）。
  2. 参数更多：每个门都有一组权重，LSTM 的参数量大约是同样隐藏尺寸 RNN 的 4 倍。这也意味着它更吃显存、更慢，但换来了更强的长期记忆能力。

二、可运行代码示例#

torch.nn.LSTM 把三个门和细胞状态都封装好了。下面用它做一次前向传播，重点看清它的输入输出形状（多了一个 c），并手动验证"隐藏状态是输出门对细胞状态的调制"这一关系。

import torch
import torch.nn as nn

batch, seq_len, input_size, hidden_size = 2, 5, 4, 6

# 输入：默认 batch_first=False，形状为 (seq_len, batch, input_size)
x = torch.randn(seq_len, batch, input_size)

# 初始隐藏状态 h0 与细胞状态 c0，形状都是 (num_layers, batch, hidden_size)
h0 = torch.zeros(1, batch, hidden_size)
c0 = torch.zeros(1, batch, hidden_size)

lstm = nn.LSTM(input_size=input_size, hidden_size=hidden_size, num_layers=1)

# output: (seq_len, batch, hidden_size) 每一时间步的隐藏状态
# (hn, cn): 最后一个时间步的隐藏状态与细胞状态
output, (hn, cn) = lstm(x, (h0, c0))

print("output 形状：", output.shape)   # (5, 2, 6)
print("hn 形状：", hn.shape)           # (1, 2, 6)
print("cn 形状：", cn.shape)           # (1, 2, 6)

# 单层时，最后一时间步的输出 == 最终隐藏状态 hn[0]
print("output[-1] == hn[0]：", torch.allclose(output[-1], hn[0], atol=1e-6))

# —— 观察：LSTM 参数量约为同尺寸 RNN 的 4 倍 ——
rnn = nn.RNN(input_size, hidden_size)
lstm_params = sum(p.numel() for p in lstm.parameters())
rnn_params = sum(p.numel() for p in rnn.parameters())
print(f"LSTM 参数量 {lstm_params} / RNN 参数量 {rnn_params} ≈ {lstm_params / rnn_params:.2f}")

# —— 堆叠两层，看形状如何变化 ——
lstm2 = nn.LSTM(input_size, hidden_size, num_layers=2)
h0_2 = torch.zeros(2, batch, hidden_size)
c0_2 = torch.zeros(2, batch, hidden_size)
output2, (hn2, cn2) = lstm2(x, (h0_2, c0_2))
print("两层 LSTM 的 output 形状：", output2.shape)   # (5, 2, 6)
print("两层 LSTM 的 hn/cn 形状：", hn2.shape, cn2.shape)   # (2, 2, 6)

运行后你会发现：output 每个时间步都输出一个隐藏状态，而 hn、cn 只保留最后一步的最终记忆；换成 2 层后，hn/cn 的第 0 维变成层数。理解这套形状约定，是后面用 LSTM 搭文本分类、序列生成的地基。

三、练习#

  2. 用 nn.LSTMCell 手动实现上面的单层 LSTM 前向传播：循环调用 cell，把每个时间步的 (h, c) 存下来，与 nn.LSTM 的输出比对是否一致。
  3. 思考：为什么细胞状态 cₜ 用线性加减更新（fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ）能缓解梯度消失，而普通 RNN 的 hₜ = tanh(...) 不行？结合梯度连乘来解释。
