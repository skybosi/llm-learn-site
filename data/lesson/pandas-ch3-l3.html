数据来源概览#

一、概念讲解#

前两课学了 CSV、Excel、JSON 三种最常见的来源，但 Pandas 的读写能力远不止于此。本课把主要数据来源串成一张地图，让你知道"遇到什么格式该用什么函数"，以及不同格式各自适合什么场景。

1. 文本 / 表格类#

格式 读 写 适用场景
CSV read_csv to_csv 通用表格交换，最常用
Excel read_excel to_excel 与人协作、多工作表
JSON read_json to_json Web 接口、程序间交换
HTML read_html to_html 抓取网页中的表格

read_html 会扫描 HTML 里的 <table> 标签并返回 DataFrame 列表，适合快速抓取维基百科等网页上的表格。

2. 数据库类#

read_sql(sql, 连接) 可以直接把 SQL 查询结果读成 DataFrame，to_sql 则把 DataFrame 写入数据库表。生产环境的数据大多住在数据库里，这条通道让 Pandas 能无缝衔接"数据库取数 → 内存分析"。

3. 高性能二进制类#

  • Parquet（read_parquet / to_parquet）：列式存储，压缩率高、读取快，是大数据生态（如 Spark）的标配格式。
  • Feather（read_feather / to_feather）：为数据帧设计的轻量二进制格式，读写极快，适合本地缓存中间结果。

两者通常需要 pyarrow 依赖。

4. 剪贴板#

read_clipboard() 直接读取系统剪贴板里的表格，to_clipboard() 把 DataFrame 复制到剪贴板，是"从 Excel 随手粘一段数据进来"的偷懒利器。

5. 选型建议#

  • 与人交换、通用存档 → CSV（或 Excel）；
  • Web/API 数据 → JSON；
  • 大规模、反复读取 → Parquet；
  • 结构化业务数据 → 数据库 + read_sql。

二、可运行代码示例#

import pandas as pd
import sqlite3

# 1. SQL：内存 SQLite 数据库（无需安装数据库软件）
conn = sqlite3.connect(":memory:")
pd.DataFrame({"id": [1, 2, 3], "姓名": ["张三", "李四", "王五"]}).to_sql(
    "users", conn, index=False
)
df = pd.read_sql("SELECT * FROM users WHERE id >= 2", conn)
print("read_sql 结果：\n", df)
conn.close()

# 2. HTML：从字符串中抓取表格
html_text = """
<table>
  <tr><th>城市</th><th>人口(万)</th></tr>
  <tr><td>北京</td><td>2189</td></tr>
  <tr><td>上海</td><td>2487</td></tr>
</table>
"""
tables = pd.read_html(html_text)
print("\nread_html 抓到的表格：\n", tables[0])

# 3. Parquet / Feather：需要 pyarrow，示例见注释
# df.to_parquet("data.parquet")        # 写出列式存储
# df2 = pd.read_parquet("data.parquet")  # 读回
# df.to_feather("data.feather")        # 本地缓存中间结果

# 4. 剪贴板（需要系统剪贴板中有表格数据）
# df_clip = pd.read_clipboard()
print("\n提示：Parquet/Feather 需 pip install pyarrow；剪贴板需先复制一段表格。")

第 1 步用了 Python 自带的 sqlite3 建了一个内存数据库，完整演示了"写入表 → 查询 → 读成 DataFrame"的闭环，没有安装任何数据库软件也能跑通。

  2. 用 read_html 抓取一段包含两行表头的 HTML 表格（可自行构造字符串），观察返回的 DataFrame 列表。
