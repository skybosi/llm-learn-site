前馈与残差#

上一课的编码器块里，除了注意力还有一个我们一笔带过的部件：前馈网络（FFN）。以及每个子层外面套着的那句 x + sublayer(x)——残差连接。这两个"配角"其实撑起了 Transformer 的半壁江山：一个负责在每个位置做深度非线性变换，一个负责让几十层深的大模型能被训练起来。这一课把它们讲透。

一、概念讲解#

1. 前馈网络：每个位置独立的"感知机"#

注意力负责让位置之间交换信息，但它本身（除去投影）基本是线性的加权求和。要让每个位置拥有更丰富的表示能力，需要加非线性。前馈网络干的就是这件事：

FFN(x) = W₂ · ReLU(W₁ · x + b₁) + b₂

它由两层线性变换夹一个 ReLU 组成，中间维度 d_ff 通常放大到 d_model 的 4 倍（论文取 d_ff = 2048, d_model = 512）。放大再缩回，给了模型足够的"思考空间"去组合特征。

关键在于"位置独立"：同一个 FFN 对每个位置分别、独立地作用（对同一位置的所有特征做变换，但不同位置之间不交互），参数在所有位置共享。这就像对序列的每个位置各打一针"同样的激活剂"，位置间的信息流动仍完全由注意力负责。

2. 为什么需要残差连接#

Transformer 可以堆得很深（论文 6 层，后来的模型动辄几十层）。深层网络有个老大难：梯度消失/爆炸。信息经过几十层变换，反向传播时梯度连乘，很容易衰减到接近 0，前面的层几乎学不动。

残差连接的写法是：

输出 = x + sublayer(x)

它给信息开了一条直通高速公路：x 不经过 sublayer，原样加到输出上。反向传播时，梯度沿着这条直路原样回传（对 x 的导数是 1），不会被连续的非线性变换"磨没"。于是即使子层学得不好、梯度很小，输入支路仍能把梯度完整送回前面——深层网络因此可以被稳定训练。

3. "先残差，再归一化"的顺序#

每个子层的完整形式是：

x = LayerNorm(x + sublayer(x))

即先做残差相加，再做层归一化。残差保证梯度畅通，层归一化（下一课详讲）保证每层的数值尺度稳定。两者配合，构成了 Transformer 块的基本骨架，也成了后来几乎所有大模型（BERT、GPT）的标准配方。

4. 残差的直观理解#

可以把每个子层看成"在已有表示上做一次修正"：sublayer(x) 输出的是对 x 的增量，残差连接把增量加回原值。如果这个修正没有用，网络可以让 sublayer 输出接近 0，从而保持 x 不变——这让网络"学不坏"：最差也只是维持原样，不会因为多加一层而把已经学好的表示搅乱。

这也是为什么 Transformer 能叠得很深而不崩：每一层都有"啥也不改、原地踏步"的退路。

二、可运行代码示例#

下面实现论文里的位置前馈网络，验证其形状与参数量，并用一个标量小例子直观展示残差连接对梯度的保护作用。

import torch
import torch.nn as nn

torch.manual_seed(0)

class PositionwiseFFN(nn.Module):
    """论文里的前馈网络：两层线性 + ReLU，中间放大到 4 倍。"""
    def __init__(self, d_model, d_ff):
        super().__init__()
        self.linear1 = nn.Linear(d_model, d_ff)
        self.linear2 = nn.Linear(d_ff, d_model)

    def forward(self, x):
        return self.linear2(torch.relu(self.linear1(x)))

d_model, d_ff = 16, 64
ffn = PositionwiseFFN(d_model, d_ff)

x = torch.randn(2, 5, d_model)       # (batch, seq, d_model)，每个位置独立过同一套 FFN
y = ffn(x)
print("FFN 输出形状:", y.shape)       # (2, 5, 16)，与输入一致

# 参数量：d_model*d_ff + d_ff + d_ff*d_model + d_model
print("FFN 参数量:", sum(p.numel() for p in ffn.parameters()))

# 残差连接：x + sublayer(x)，形状不变
residual = x + y
print("残差输出形状:", residual.shape)

# 残差对梯度的保护：用一个标量演示"直通支路"如何把梯度原样回传
a = torch.tensor(1.0, requires_grad=True)
f = nn.Linear(1, 1, bias=False)
with torch.no_grad():
    f.weight.fill_(0.01)             # 故意让子层权重很小，梯度很弱

out = a + f(a.unsqueeze(0)).squeeze(0)   # 残差：输入直接 + 子层变换
out.backward()
print("残差连接下 a 的梯度:", a.grad.item())   # 至少包含直连支路贡献的 1.0

# 对比：没有残差时，梯度会被小权重"磨小"
a2 = torch.tensor(1.0, requires_grad=True)
out2 = f(a2.unsqueeze(0)).squeeze(0)       # 没有直连支路
out2.backward()
print("无残差时 a2 的梯度:", a2.grad.item())  # 只有 0.01，明显更小

运行后重点看最后两行：

  • 有残差时，a 的梯度是 1.0（直通支路）加上子层那点小贡献，约为 1.01；
  • 无残差时，a2 的梯度只有 0.01，被小权重直接"吃"掉了。

这就是残差连接的核心价值：无论子层学成什么样，输入支路都能保证一条畅通的梯度通路。在几十层的 Transformer 里，这条通路是训练不崩的关键。

三、练习#

  1. 把 d_ff 从 64 改成 16（等于 d_model），观察参数量减少、输出形状不变，思考"放大 4 倍"这个设计是否必要，能否用更小的 d_ff 换来近似的效果。
  2. 把 PositionwiseFFN 里的 relu 换成 gelu（F.gelu），观察输出分布的变化；查询资料了解为什么后来的很多 Transformer 变体改用 GELU。
  3. 打印 residual 与 x 的差的范数（(residual - x).norm()），验证"残差输出 = 输入 + 子层增量"；再把子层换成"恒等映射"（直接返回 x），看看会变成什么样。
  4. 思考：残差连接的直通支路为什么要求"输入和子层输出同维度"？如果 sublayer 改变了维度，还能直接相加吗？这如何限制了 Transformer 块的设计？
