用 PyTorch 实现 Transformer#

前面几课分别讲清了位置编码、掩码注意力和交叉注意力。这一课把它们拼装成一个完整的 Transformer。我们会从零写起：多头注意力、前馈网络、编码器层、解码器层，再到把它们叠起来的完整模型。全部用 PyTorch 的 nn.Module 手工实现，而不是直接调 nn.Transformer——因为只有亲手写过一遍，你才真正清楚每一处 Q、K、V 的来源和每一层残差、归一化的位置。代码统一采用 batch_first=True 的 (batch, seq_len, d_model) 形状，读起来更直观。

一、概念讲解#

1. 完整结构回顾#

一个标准的 Transformer 由这些积木组成：

  • 输入嵌入 + 位置编码：把 token id 变成 d_model 维向量，再叠加位置信息（第 4 章）。
  • N 层编码器：每层 = 多头自注意力（双向） + 前馈网络，各配残差连接与 LayerNorm。
  • N 层解码器：每层 = 因果自注意力 + 交叉注意力 + 前馈网络，同样各配残差与 LayerNorm。
  • 输出投影：把 d_model 维的最终表示映射回词表大小，得到每个位置的 logits。

2. 残差连接与 LayerNorm 的摆放#

每个子层（注意力或前馈）都被"残差 + 归一化"包裹。这里有个实现细节值得注意：归一化放在子层前还是后。

  • 原论文用的是 Post-LN：x = LayerNorm(x + Sublayer(x))。
  • 现在更主流的是 Pre-LN：x = x + Sublayer(LayerNorm(x))。

Pre-LN 训练更稳定、对学习率不那么敏感，所以现代实现（包括 PyTorch 的默认 norm_first=True 之外的自定义版本）大多用它。本课代码采用 Pre-LN，并保留残差连接，你可以在练习里改成 Post-LN 对比。

3. 多头注意力：把 Q、K、V 拆成 h 份#

多头注意力的本质是"把一个大空间拆成 h 个小空间分别做注意力，再拼回来"。实现上就是四步：投影 → 拆分 → 独立计算 → 拼接投影。

Q = x @ W_q;  K = x @ W_k;  V = x @ W_v      # 投影到 d_model 维
把每个都 view 成 (batch, heads, seq, d_k)      # d_k = d_model / heads
scores = Q @ K^T / sqrt(d_k)                  # 各头独立算注意力
拼接各头输出，再过 W_o                          # 还原回 d_model 维

这段代码是后面第 3 课"可视化注意力"的根基：只要把中间的注意力权重返回出来，就能画热力图。

4. 为什么还要写一个 Seq2Seq 包装层#

Transformer 核心类只处理已经嵌入好的 d_model 维向量。真正做任务时，输入是 token id，输出要是词表上的概率。所以再包一层 Seq2SeqTransformer：负责 token 嵌入、调用核心 Transformer、最后投影回词表。这样"编码器—解码器骨架"和"具体任务"就解耦了。

二、可运行代码示例#

下面从零实现，代码较长，但每段都标了中文注释。可以整段复制运行。

import math
import torch
import torch.nn as nn
import torch.nn.functional as F

# ---------- 1. 多头注意力 ----------
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0, "d_model 必须能被头数整除"
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, q, k, v, mask=None, return_attn=False):
        # q/k/v: (batch, seq, d_model)；mask 为加性掩码（0 保留，-inf 屏蔽）
        b = q.size(0)
        # 投影后按头拆分：(batch, seq, heads, d_k) -> (batch, heads, seq, d_k)
        q = self.W_q(q).view(b, -1, self.n_heads, self.d_k).transpose(1, 2)
        k = self.W_k(k).view(b, -1, self.n_heads, self.d_k).transpose(1, 2)
        v = self.W_v(v).view(b, -1, self.n_heads, self.d_k).transpose(1, 2)

        scores = q @ k.transpose(-2, -1) / math.sqrt(self.d_k)   # (batch, heads, t, s)
        if mask is not None:
            scores = scores + mask          # 加性掩码：-inf 处 softmax 后归零
        attn = F.softmax(scores, dim=-1)    # 每行是一个关注分布
        out = attn @ v                      # (batch, heads, t, d_k)
        out = out.transpose(1, 2).contiguous().view(b, -1, self.n_heads * self.d_k)
        out = self.W_o(out)
        return (out, attn) if return_attn else out

# ---------- 2. 前馈网络 ----------
class FeedForward(nn.Module):
    def __init__(self, d_model, dim_ff):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d_model, dim_ff),
            nn.ReLU(),
            nn.Linear(dim_ff, d_model),
        )
    def forward(self, x):
        return self.net(x)

# ---------- 3. 编码器层 ----------
class EncoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, dim_ff):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, n_heads)
        self.ff = FeedForward(d_model, dim_ff)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)

    def forward(self, x, mask=None):
        # Pre-LN：先归一化再进子层，最后加残差
        a = self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x), mask)
        x = x + a
        x = x + self.ff(self.norm2(x))
        return x

# ---------- 4. 解码器层 ----------
class DecoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, dim_ff):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, n_heads)   # 因果自注意力
        self.cross_attn = MultiHeadAttention(d_model, n_heads)  # 交叉注意力
        self.ff = FeedForward(d_model, dim_ff)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)

    def forward(self, x, memory, tgt_mask=None, memory_mask=None):
        # 1) 因果自注意力：Q=K=V 都来自目标序列自己
        a = self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x), tgt_mask)
        x = x + a
        # 2) 交叉注意力：Q 来自目标序列，K/V 来自编码器输出 memory
        a = self.cross_attn(self.norm2(x), memory, memory, memory_mask)
        x = x + a
        # 3) 前馈网络
        x = x + self.ff(self.norm3(x))
        return x

# ---------- 5. 位置编码（正弦，来自第 4 章） ----------
class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(max_len).unsqueeze(1).float()
        div = torch.exp(torch.arange(0, d_model, 2).float()
                        * (-math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(position * div)
        pe[:, 1::2] = torch.cos(position * div)
        self.register_buffer("pe", pe.unsqueeze(0))   # (1, max_len, d_model)

    def forward(self, x):
        # x: (batch, seq, d_model)，取前 seq 个位置逐元素相加
        return x + self.pe[:, :x.size(1)]

# ---------- 6. 完整 Transformer ----------
class Transformer(nn.Module):
    def __init__(self, d_model, n_heads, n_layers, dim_ff, max_len=5000):
        super().__init__()
        self.pos_enc = PositionalEncoding(d_model, max_len)
        self.encoder = nn.ModuleList(
            [EncoderLayer(d_model, n_heads, dim_ff) for _ in range(n_layers)])
        self.decoder = nn.ModuleList(
            [DecoderLayer(d_model, n_heads, dim_ff) for _ in range(n_layers)])
        self.norm = nn.LayerNorm(d_model)

    def forward(self, src, tgt, tgt_mask=None, src_mask=None):
        # src/tgt: 已嵌入的 (batch, seq, d_model)
        src = self.pos_enc(src)
        tgt = self.pos_enc(tgt)
        for layer in self.encoder:
            src = layer(src, src_mask)
        memory = self.norm(src)               # 编码器最终输出，供解码器交叉注意力使用
        for layer in self.decoder:
            tgt = layer(tgt, memory, tgt_mask, src_mask)
        return self.norm(tgt)

# ---------- 7. Seq2Seq 包装层 ----------
class Seq2SeqTransformer(nn.Module):
    def __init__(self, vocab_size, d_model=128, n_heads=8, n_layers=3, dim_ff=512):
        super().__init__()
        self.d_model = d_model
        self.embed = nn.Embedding(vocab_size, d_model)
        self.transformer = Transformer(d_model, n_heads, n_layers, dim_ff)
        self.proj = nn.Linear(d_model, vocab_size)

    def forward(self, src, tgt, tgt_mask=None, src_mask=None):
        # 原论文在嵌入后乘 sqrt(d_model)，缓解嵌入与位置编码的尺度差异
        src_emb = self.embed(src) * math.sqrt(self.d_model)
        tgt_emb = self.embed(tgt) * math.sqrt(self.d_model)
        out = self.transformer(src_emb, tgt_emb, tgt_mask, src_mask)
        return self.proj(out)

现在构造一个随机输入，跑一次完整前向，验证形状并统计参数量。

torch.manual_seed(0)
VOCAB = 100
model = Seq2SeqTransformer(vocab_size=VOCAB, d_model=32, n_heads=4, n_layers=2, dim_ff=64)

src = torch.randint(0, VOCAB, (2, 6))   # batch=2，源序列长度 6
tgt = torch.randint(0, VOCAB, (2, 5))   # batch=2，目标序列长度 5

# 解码器自注意力的因果掩码：(5, 5) 下三角为 0、上三角为 -inf
tgt_mask = torch.triu(torch.full((5, 5), float("-inf")), diagonal=1)

out = model(src, tgt, tgt_mask=tgt_mask)
print("输出形状:", out.shape)            # torch.Size([2, 5, 100]) = (batch, tgt_len, vocab)

total = sum(p.numel() for p in model.parameters())
print("总参数量:", total)                # 小模型，约几十万量级

输出形状 (2, 5, 100) 说明：2 条样本、5 个目标位置，每个位置给 100 个词的 logits。这个模型就是第 2、3 课要拿去训练和可视化的完整骨架。若想验证正确性，可以把同样配置的 nn.Transformer 跑一遍，前向输出的形状应该完全一致。

三、练习#

  1. 把 n_layers 从 2 改成 4、n_heads 改成 8，重新统计参数量，解释哪些参数随层数线性增长、哪些随头数不变（提示：多头注意力的总投影参数与头数无关）。
  2. 把 Pre-LN 改成 Post-LN（x = LayerNorm(x + Sublayer(x))），用同一组随机输入训练几步，观察两种写法下 loss 曲线的稳定性差异。
  3. 给 Seq2SeqTransformer 增加权重共享（把 embed 与 proj 的权重绑定），重新统计参数量，说明省掉了哪一部分参数，以及共享的前提（嵌入维必须等于模型维）。
  4. 用 torch.nn.Transformer 复现同样的 (2, 6) -> (2, 5) 前向，把它的输出与你自己模型的输出做形状对比，并指出两者在"mask 传入方式"上的 API 差异。
