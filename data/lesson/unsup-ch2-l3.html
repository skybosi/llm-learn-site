树状图#

一、概念讲解#

1.1 树状图是什么#

层次聚类最独特、最有价值的产出，是一张树状图（dendrogram）。它把"谁先和谁合并、以多高的距离合并"这一完整历史，画成一棵倒挂的树：

  • 叶子：底部的每一个节点代表一个原始样本；
  • 枝干的合并点（分叉）：表示某两个簇在某个"合并高度（距离）"处合成一个簇；
  • 垂直高度：合并点越高，说明被合并的两个簇离得越远，也就是"越不情愿"合并。

因此，树状图的纵轴是距离，横轴是样本（或样本分组）。合并点越低，说明两个对象越相似、越早被合并；合并点越高，说明它们差异越大、越晚才被捏到一起。

1.2 从树状图选择簇数#

树状图的一大妙用，就是直观地决定簇数。方法非常简单：在图上画一条水平线，这条线会把树"拦腰切断"，线以上有多少个垂直的枝干，就得到多少个簇。

  • 水平线画得越低，切得越"细"，簇数越多；
  • 水平线画得越高，切得越"粗"，簇数越少。

如何选线的高度？经验法则是：把线画在"树枝最长的那段空隙"处。观察图中相邻合并点之间的垂直间距，间距最大的那段（说明再往上合并需要跨越很大的距离，合并变得"勉强"）往往就是最自然的分界。在这段空隙里切一刀，得到的簇数通常最合理。这与第 1 章的肘部法则在精神上是相通的——都是寻找"收益骤减"的临界点。

1.3 sklearn 与 scipy 的分工#

这里有一个实践要点：sklearn 的 AgglomerativeClustering 本身不提供绘制树状图的接口，它只负责计算聚类标签。要画树状图，通常需要借助 SciPy 的层次聚类模块：

  • scipy.cluster.hierarchy.linkage：执行凝聚式层次聚类，返回合并过程的记录矩阵（linkage matrix）；
  • scipy.cluster.hierarchy.dendrogram：根据合并矩阵绘制树状图；
  • scipy.cluster.hierarchy.fcluster：按"高度阈值"或"簇数"从合并矩阵切出扁平标签。

所以完整的"画树状图"流程是：用 linkage 得到合并历史 → 用 dendrogram 画图 → 看图选高度 → 用 fcluster（或 sklearn 的 n_clusters）切出最终簇。sklearn 与 scipy 各司其职，配合使用。

二、可运行代码示例#

下面用 SciPy 对 iris 数据画树状图，并演示"按水平线切出簇"的完整过程。

# -*- coding: utf-8 -*-
# 第 3 课：绘制树状图并据此选择簇数
import numpy as np
import matplotlib.pyplot as plt
from scipy.cluster.hierarchy import linkage, dendrogram, fcluster
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler

# 1. 加载 iris 数据并标准化
X = StandardScaler().fit_transform(load_iris().data)

# 2. 用 Ward 方法执行凝聚式层次聚类
#    method='ward' 对应 sklearn 的 linkage='ward'
Z = linkage(X, method="ward")
print("合并矩阵形状：", Z.shape)  # (n-1, 4)，每行记录一次合并

# 3. 绘制树状图
#    truncate_mode='level', p=5 只显示顶部的 5 层，避免叶子过多看不清
plt.figure(figsize=(10, 5))
dendrogram(Z, truncate_mode="level", p=5)
plt.axhline(y=15, color="red", linestyle="--", label="切割高度 y=15")
plt.title("iris 数据的层次聚类树状图")
plt.xlabel("样本（分组后）")
plt.ylabel("合并距离")
plt.legend()
plt.show()

# 4. 按簇数切分：直接切成 3 簇（iris 已知有 3 类）
labels = fcluster(Z, t=3, criterion="maxclust")
print("按 3 簇切割后各簇样本数：",
      dict(zip(*np.unique(labels, return_counts=True))))

# 5. 对比：按高度阈值切割
labels_by_height = fcluster(Z, t=15, criterion="distance")
print("按高度 15 切割得到的簇数：", len(np.unique(labels_by_height)))

输出解读：linkage 返回的合并矩阵 Z 有 n-1 行，每一行记录了"第几步把哪两个簇合并成了哪个新簇、合并距离是多少"。dendrogram 据此画出倒挂的树。红色虚线 y=15 会把树拦腰切断，虚线以上的枝干数量就是该高度下的簇数。

提示：truncate_mode="level" 会折叠掉过密的底层分支，适合样本量大时的展示；想看全部叶子细节，可去掉该参数（数据量小时用）。

三、练习小节#

  1. 观察输出的树状图，找到相邻合并点之间"垂直间距最大"的一段，说说为什么应该在这段空隙里画切割线。
  2. 把切割高度分别改为 5、15、25，记录每种高度切出的簇数，解释簇数随高度变化的规律。
  3. 用 fcluster 按高度 15 切割后，把结果与 iris 的真实标签（3 类）对照，估算一下聚类的"纯度"（如每簇中占比最高的真实类别的比例）。
  4. 为什么 sklearn 的 AgglomerativeClustering 不直接提供画树状图的功能，而要借助 scipy？这反映了两个库怎样的分工？
