梯度下降算法#

知道了"最低点在哪里"还不够，更要紧的是"怎么走到那里"。梯度下降就是机器学习最常用的下山法：每走一步，都朝着当前最陡的下坡方向挪一点。

一、概念讲解#

1. 为什么需要梯度下降#

理论上，找极小点可以令梯度为零然后解方程。但真实的损失函数动辄有上百万个参数，解析求解根本不现实。梯度下降则是一种迭代逼近的方法：不追求一步到位，而是沿着正确的方向一步步靠近最低点。

2. 负梯度方向是最速下降方向#

梯度 ∇f 指向函数值上升最快的方向。那么反过来，负梯度 -∇f 就是下降最快的方向。因此每一步的更新规则是：

θ ← θ - η · ∇f(θ)

其中 η 是学习率（步长），θ 泛指所有待更新的参数。

3. 更新公式的三种"口味"#

根据每一步用多少数据来估计梯度，梯度下降分为三种：

  • 批量梯度下降（BGD）：每一步用全部样本算梯度，最稳但最慢；
  • 随机梯度下降（SGD）：每一步只用 1 个样本，快但噪声大、波动明显；
  • 小批量梯度下降（Mini-batch GD）：每次取一小批（如 32 个）样本，平衡了稳定与速度，是深度学习里最常用的形式。

4. 落到损失函数上#

对平方损失 L = (ŷ - y)²，其中 ŷ = w·x + b，上一章已用链式法则求出：

∂L/∂w = 2(ŷ - y)·x
∂L/∂b = 2(ŷ - y)

把它们代入更新公式，反复迭代，就能"训"出合适的 w 和 b——这正是最小二乘回归的迭代版本。

二、可运行示例#

示例 1：一维梯度下降#

对 f(x) = (x-3)²，从 x = 0 出发，沿负梯度方向迭代。

def f(x):
    return (x - 3) ** 2

def df(x):
    return 2 * (x - 3)   # f'(x)

x = 0.0
lr = 0.1
for step in range(30):
    x = x - lr * df(x)   # 更新：往负梯度方向挪一步
    print(f"step {step:2d}: x = {x:.4f}, f(x) = {f(x):.4f}")

示例 2：二维梯度下降#

对 f(x, y) = (x-1)² + (y-2)² 做二维梯度下降，观察它逼近 (1, 2)。

def f(x, y):
    return (x - 1) ** 2 + (y - 2) ** 2

def grad(x, y):
    return 2 * (x - 1), 2 * (y - 2)   # (∂f/∂x, ∂f/∂y)

x, y = 0.0, 0.0
lr = 0.1
for step in range(50):
    gx, gy = grad(x, y)
    x -= lr * gx
    y -= lr * gy
    if step % 5 == 0:
        print(f"step {step:2d}: (x, y) = ({x:.4f}, {y:.4f}), f = {f(x, y):.4f}")

示例 3：梯度下降训练一个线性神经元#

用批量梯度下降拟合直线 y = 2x + 1。这正是"手写一个最简单的神经网络训练"。

# 训练数据：由 y = 2x + 1 生成
data = [(0, 1), (1, 3), (2, 5), (3, 7)]

w, b = 0.0, 0.0          # 待学习参数，初始随便设
lr = 0.05                # 学习率

for epoch in range(200):
    gw, gb, loss = 0.0, 0.0, 0.0
    # 批量梯度下降：对全部样本累加梯度
    for x, y in data:
        pred = w * x + b
        err = pred - y
        loss += err ** 2
        gw += 2 * err * x   # ∂L/∂w 的累加
        gb += 2 * err       # ∂L/∂b 的累加
    n = len(data)
    w -= lr * gw / n        # 更新参数
    b -= lr * gb / n
    if epoch % 20 == 0:
        print(f"epoch {epoch:3d}: loss = {loss/n:.4f}, w = {w:.3f}, b = {b:.3f}")

print(f"训练结束：w = {w:.3f}, b = {b:.3f}（目标 w=2, b=1）")

三、练习#

  1. 把示例 1 的学习率改成 0.01 和 1.1，分别运行，观察收敛速度与是否发散。
  2. 修改示例 3 的初始 w、b 和训练数据（例如拟合 y = -x + 2），看算法能否逼近正确参数。
  3. 解释"批量 / 随机 / 小批量"三种梯度下降各自的优缺点，以及为什么小批量在实践中最常用。
