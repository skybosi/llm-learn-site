第一个程序与基本语法约定#

环境已经装好了。这一课，我们要写下并运行自己的第一个 Python 程序，同时了解几条最基本的语法约定——它们会贯穿你之后写的每一行代码。

一、概念讲解#

1. 两种运行方式#

Python 有两种最常用的运行方式：

  • 交互模式：在命令行输入 python 进入 >>> 提示符，写一行、立刻出结果。适合临时试验和快速计算。
  • 脚本模式：把代码写进一个以 .py 结尾的文件，再一次性运行整个文件。这是写正式程序的常用方式。

2. 用脚本模式写第一个程序#

打开 IDLE（或任何文本编辑器），新建文件，输入：

print("Hello, World!")

保存为 hello.py，然后运行它（在 IDLE 中按 F5，或命令行输入 python hello.py），屏幕上就会出现：

Hello, World!

恭喜，这就是你写的第一个程序。"Hello, World!" 是全世界程序员学习新语言时的传统第一句——用来确认环境一切正常。

3. 四条基本语法约定#

① 缩进表示代码块的归属。 Python 用空格缩进（通常是 4 个空格）来表示"哪些代码属于同一块"。例如 if、for 后面的语句要缩进。缩进错了，程序会报错。这一点和其他语言用大括号 {} 完全不同，要特别注意。

② 区分大小写。 print 和 Print、PRINT 是三个不同的名字。写错大小写会报 NameError（名字错误）。

③ 注释用 # 开头。 # 后面的内容是人看的说明，程序会忽略它。写注释是好习惯，方便以后自己和别人看懂代码。

④ 一条语句通常占一行。 Python 一般一行写一条语句，行尾不需要加分号（这点比很多语言省事）。如果要在一行放多条语句，中间用分号 ; 隔开，但新手不推荐。

4. 出错时不要慌#

写程序一定会遇到报错。报错信息里通常写着是什么错和在第几行。例如：

NameError: name 'prnt' is not defined

意思是：prnt 这个名字没定义（很可能是 print 拼错了）。学会读报错信息，是进步最快的技能之一。

二、可运行代码示例#

把下面这段代码保存为 first_program.py 再运行，观察每一行输出的结果。

# 第一个脚本程序：演示几条基本语法

print("你好，这是第一个程序！")     # print 输出文字
print(2024 + 1)                      # 直接计算并输出结果

# 下面用缩进演示"代码块"的概念
name = "小明"                        # 定义一个变量（下一章会细讲）
if name == "小明":                   # 如果 name 等于"小明"
    print("欢迎你，" + name)         # 这行缩进了，属于 if 的代码块

# 这行没有缩进，不属于 if，所以无论条件如何都会执行
print("程序结束")

预期输出：

你好，这是第一个程序！
2025
欢迎你，小明
程序结束

要点：if 后面的 print 缩进了 4 个空格，所以它属于 if；最后一行顶格写，不属于 if。试着把 name 改成 "小红"，观察输出有什么变化。

三、练习#

  1. 运行第一个程序：新建 hello.py，写入 print("Hello, World!")，分别用交互模式和脚本模式各运行一次。
  2. 写注释：给上面的程序加上至少两行中文注释，说明每段代码在做什么。
  3. 体验缩进：把示例代码中 print("欢迎你，" + name) 前面的缩进删掉再运行，观察报错或结果变化，理解缩进的重要性。
  4. 故意制造一个错误：把 print 改成 prnt 再运行，读一读报错信息，试着理解它在告诉你什么。
  5. 输出多行：写一个程序，用三次 print 分别输出你的名字、你今天的心情、你学 Python 的目标。
