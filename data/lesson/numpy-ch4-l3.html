特征值与 SVD#

这是线性代数运算的最后一课，也是"含金量"最高的一课。特征值分解与奇异值分解（SVD）是两把"数学手术刀"，能把一个矩阵拆解成几个结构更简单的矩阵，从而看清它最本质的信息。主成分分析（PCA）、推荐系统、图像压缩、数据降噪，背后几乎都站着这两样工具。

好消息是：在 NumPy 里调用它们只需要一行代码。难点不在调用，而在理解分解结果的每一块代表什么。

一、概念讲解#

1. 特征值与特征向量#

对于一个方阵 A，如果存在一个非零向量 v 和一个标量 λ，满足：

A v = λ v

那么 v 就叫做 A 的特征向量，λ 叫做对应的特征值。

这个式子的意思是：矩阵 A 作用在 v 上，效果仅仅是把 v 拉伸（或压缩、翻转）了 λ 倍，方向保持不变。因此特征向量刻画了矩阵变换的"主轴"方向，特征值刻画了沿这些主轴拉伸的倍数。

特征值分解的价值：把一个复杂的矩阵变换，拆解成"旋转到主轴方向 → 沿各轴独立缩放 → 再转回来"三步。哪个特征值大，说明那个方向的信息越"强"——这正是 PCA 降维"保留大方差方向"的数学来源。

在 NumPy 里：

  • np.linalg.eig(A)：返回 (特征值数组, 特征向量矩阵)，每列是一个特征向量。适用于一般方阵，结果可能是复数。
  • np.linalg.eigh(A)：专门给对称矩阵（或厄米矩阵）用，返回的必定是实数，且更快、更稳。做协方差矩阵分解时优先用它。

2. 奇异值分解 SVD：适用于任意矩阵#

特征值分解有个局限：只能用于方阵。而现实数据几乎都是"非方阵"——比如一张 1000×800 的图像、一个"用户数 × 物品数"的评分表。SVD 打破了这一限制，任何形状的矩阵都能分解成三块：

A = U · Σ · Vᵀ
  • U：左奇异向量矩阵，列向量是 A 的"输出方向"主轴；
  • Σ：对角矩阵（对角线上是奇异值，从大到小排列，其余为 0），奇异值衡量每个主轴方向的"能量/强度"；
  • Vᵀ：右奇异向量矩阵的转置，行向量是 A 的"输入方向"主轴。

奇异值 σ 与特征值的关系：对 AᵀA 做特征值分解，特征值的平方根就是 A 的奇异值。

3. SVD 为什么这么重要：低秩近似与压缩#

SVD 最实用的性质是低秩近似：奇异值从大到小排列，往往前几个奇异值就携带了矩阵绝大部分"能量"，后面很多奇异值接近 0、贡献微乎其微。于是我们可以只保留前 k 个最大的奇异值（以及对应的 U、V 列），得到一个对 A 的近似：

A ≈ U[:, :k] · Σ[:k, :k] · V[:k, :]ᵀ

当 k 远小于原始维度时，存储量大幅下降——这就是图像压缩、数据降维、去噪的核心原理。k 越小，压缩越狠，但信息损失也越多，这是一个可调节的"保真度旋钮"。

二、可运行示例#

示例 1：特征值与特征向量

import numpy as np

A = np.array([[4, 1],
              [2, 3]])

# eig 返回 (特征值, 特征向量矩阵)，特征向量按列存放
eigenvalues, eigenvectors = np.linalg.eig(A)
print("特征值 =", eigenvalues)
print("特征向量矩阵（每列一个向量）=\n", eigenvectors)

# 验证 Av = λv：取第一个特征向量
v = eigenvectors[:, 0]
lam = eigenvalues[0]
print("A @ v =", A @ v)
print("λ * v =", lam * v)

示例 2：对称矩阵用 eigh，结果是实数

import numpy as np

# 对称矩阵（常用于协方差矩阵）
S = np.array([[3, 1],
              [1, 2]])

evals, evecs = np.linalg.eigh(S)
print("特征值（实数，升序）=", evals)
print("特征向量 =\n", evecs)

# 验证：S 与"evecs @ diag(evals) @ evecs.T" 相等
S_recon = evecs @ np.diag(evals) @ evecs.T
print("重构 S 是否等于原矩阵:", np.allclose(S, S_recon))

示例 3：对非方阵做 SVD

import numpy as np

# 一个 3x2 的非方阵
A = np.array([[1, 0],
              [0, 1],
              [1, 1]])

# svd 返回 (U, s, Vt)，注意 s 是一维奇异值数组，Vt 是 V 的转置
U, s, Vt = np.linalg.svd(A)
print("U 形状 =", U.shape)
print("奇异值 =", s)
print("Vt 形状 =", Vt.shape)

# 把 s 扩展成对角矩阵 Σ，再重构 A
Sigma = np.zeros((3, 2))
np.fill_diagonal(Sigma, s)
A_recon = U @ Sigma @ Vt
print("重构 A 是否等于原矩阵:", np.allclose(A, A_recon))

示例 4：用 SVD 做图像的低秩压缩

import numpy as np

# 造一个 6x5 的"图像"矩阵，数值随便取，模拟像素灰度
rng = np.random.default_rng(42)
image = rng.integers(0, 255, size=(6, 5)).astype(float)

# 完整 SVD
U, s, Vt = np.linalg.svd(image, full_matrices=False)

# 只保留前 k 个奇异值做近似
k = 2
image_approx = (U[:, :k] * s[:k]) @ Vt[:k, :]

print("原矩阵（保留 2 位小数）=\n", np.round(image, 2))
print("低秩近似（k=2）=\n", np.round(image_approx, 2))

# 用全部奇异值就能完整还原
print("k 取满时是否完整还原:", np.allclose(
    (U * s) @ Vt, image))

三、练习#

  1. 特征值验证：对矩阵 [[2, 1], [1, 2]] 求特征值与特征向量，逐一验证 A v = λ v 对每个特征对成立。
  2. 对称 vs 一般：分别用 eig 和 eigh 计算上面的对称矩阵，观察特征值是否一致、顺序有何不同。
  3. SVD 重构：随机生成一个 5×4 矩阵，做 SVD 后用 U @ Σ @ Vt 重构，检查是否与原矩阵相等；再用 k=1、2、3 做低秩近似，观察近似误差如何随 k 变小。
  4. 奇异值衰减：对一个 10×10 的随机矩阵做 SVD，打印奇异值数组，观察它是否从大到小排列、衰减速度如何。思考：这说明了什么？
