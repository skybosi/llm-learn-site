CSV 读写#

一、概念讲解#

前面几章的数据都是手工写死在代码里的，而真实的分析工作从"读文件"开始。CSV（Comma-Separated Values，逗号分隔值）是数据分析领域最通用的表格交换格式：几乎任何系统（Excel、数据库、网页导出）都能导出 CSV，它本质就是一个纯文本文件，用分隔符把一行行记录拆成字段。

1. 读取：read_csv#

pd.read_csv("文件.csv") 是入口，但它有不少参数值得掌握：

  • sep：字段分隔符，默认是逗号，但很多系统用制表符（\t）或竖线（|）。
  • header：表头所在行，默认第 0 行；没有表头时可设 header=None。
  • index_col：把某一列设为行索引。
  • encoding：文件编码。中文数据最常见的坑就在这里——Windows 上很多 CSV 是 GBK 编码，直接用默认 UTF-8 读取会乱码。
  • skiprows / nrows：跳过前面若干行 / 只读前若干行，适合快速预览大文件。
  • usecols：只读指定的列，减少内存占用。
  • dtype：指定列类型，避免数字被误读成字符串。

2. 写出：to_csv#

df.to_csv("输出.csv", index=False) 把 DataFrame 写回文件。两个高频参数：

  • index：是否把行索引也写进文件。默认 True，但通常应设 False，否则会多出一列没用的序号。
  • encoding：写出时的编码。想用 Excel 直接双击打开不乱码，常用 utf-8-sig（带 BOM 的 UTF-8）。

3. 编码问题的应对#

遇到中文乱码，先试 encoding="utf-8"，不行再试 encoding="gbk" 或 "gb18030"。读入后先 head() 看一眼，确认中文正常再继续。

二、可运行代码示例#

import pandas as pd
from io import StringIO   # 用内存字符串模拟 CSV 文件，方便直接运行

# 1. 最基本的读取
csv_text = """姓名,年龄,城市
张三,25,北京
李四,30,上海
王五,22,广州
"""
df = pd.read_csv(StringIO(csv_text))
print("基本读取：\n", df)

# 2. 自定义分隔符（竖线）
csv_pipe = "编号|成绩\n1|88\n2|79\n"
df2 = pd.read_csv(StringIO(csv_pipe), sep="|")
print("\n竖线分隔符：\n", df2)

# 3. 指定某一列为行索引
df3 = pd.read_csv(StringIO(csv_text), index_col="姓名")
print("\n姓名作索引：\n", df3)

# 4. 只读前 2 行 / 跳过 1 行
print("\n只读前 2 行：\n", pd.read_csv(StringIO(csv_text), nrows=2))

# 5. 写出到 CSV（写进内存字符串观察内容）
buf = StringIO()
df.to_csv(buf, index=False, encoding="utf-8-sig")
print("\nto_csv 写出内容：\n", buf.getvalue())

# 6. 真实文件场景：读取 GBK 编码、写出带 BOM 的 UTF-8
# df = pd.read_csv("销售数据.csv", encoding="gbk")          # Windows 常见 GBK 文件
# df.to_csv("清洗后.csv", index=False, encoding="utf-8-sig") # Excel 打开不乱码

示例用 StringIO 把 CSV 内容放在内存里，这样无需真实文件就能跑通；真实使用时把 StringIO(csv_text) 换成文件路径即可，其余参数完全一致。

三、练习#

  1. 用 pd.read_csv 读取一个用制表符分隔的数据（可用 StringIO 模拟），指定 sep="\t"，观察结果。
  2. 写一个 DataFrame 到 CSV：先 index=True、再 index=False，对比两次写出的文件内容，说明 index 参数的作用。
  3. 用一个"没有表头"的 CSV 数据（第一行就是数据），尝试 header=None 读取，再用 names=["列A", "列B"] 给它补上列名。
