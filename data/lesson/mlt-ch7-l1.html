什么是泛化#

到目前为止，我们一直默认"让训练误差最小"就是学习的目标。但仔细一想就有个漏洞：训练数据只是一次抽样，模型在训练集上表现好，凭什么在没见过的数据上也表现好？ 这个"在未见数据上表现好"的能力，就是泛化（generalization）。它是机器学习区别于"死记硬背"的根本，也是本章（乃至整个学习理论）要精确刻画的对象。这一课先把"泛化"这个词变成可以写在纸上的量，并给出它和过拟合、偏差-方差的关系。

一、概念讲解（含推导）#

1. 先问"为什么"：我们真正关心的是哪个误差？#

假设数据来自某个未知的联合分布 (x,y)∼P，我们用带参数的假设 hθ​ 去预测。真正该最小化的，是在整个分布上的期望损失——称为期望风险（expected risk）：

R(θ)=E(x,y)∼P​[ℓ(hθ​(x),y)].

但我们永远拿不到整个分布，手里只有 m 个独立同分布样本 {(xi​,yi​)}。于是我们退而求其次，最小化经验风险（empirical risk）：

R^(θ)=m1​i=1∑m​ℓ(hθ​(xi​),yi​).

泛化误差（generalization error） 就是两者之差：

Gen(θ)=R(θ)−R^(θ).

一句话：经验风险最小化（ERM）是我们能做的，期望风险才是我们想要的，泛化误差就是"能做的"和"想要的"之间的缺口。 学习理论的中心问题，就是问：在什么条件下、用多少样本，这个缺口能被压到任意小？

2. 泛化误差的直观：样本只是"抽样快照"#

泛化误差为什么不为零？因为 R^ 是 R 的一个抽样估计。大数定律保证 R^→R（当 m→∞），但对有限样本，估计总有波动。模型越"灵活"（能拟合的函数越多），它就越能专门去拟合这 m 个点的随机噪声，让 R^ 被压得比 R 低——这就是过拟合。于是有了那条著名的"经验风险 vs 模型复杂度"的 U 形曲线：

  • 欠拟合（左边）：模型太简单，R^ 和 R 都高——模型没学到结构。
  • 过拟合（右边）：模型太复杂，R^ 很低但 R 很高——模型把噪声也背下来了。
  • 最佳点（谷底）：R^ 与 R 的差距被复杂度惩罚所抵消。

3. 泛化误差的分解：偏差、方差与噪声#

在 chapter-4 我们做过偏差-方差分解，这里用它给泛化误差一个结构。以平方损失为例，设目标函数 f(x)=E[Y∣X=x]、噪声 ϵ（Var=σ2）。对一个"固定数据集训练出的模型" f^​，其期望测试误差可分解为：

E[(Y−f^​(x))2]=偏差2(f(x)−E[f^​(x)])2​​+方差E[(f^​(x)−E[f^​(x)])2]​​+不可约噪声σ2​​.

三项的含义：

  • 偏差²：模型族的"平均水平"离真实有多远——模型太简单导致欠拟合。
  • 方差：换一组训练数据，模型预测会抖多厉害——模型太灵活导致过拟合。
  • 噪声 σ2：即便知道真实 f 也无法消除的固有误差。

泛化误差（测试误差 − 训练误差的期望）大体对应"方差 + 噪声"那部分在测试集上的体现：过拟合 = 高方差。降低方差的手段（更多样本、正则化、集成）就是在"收紧泛化误差"，而代价往往是抬高一点偏差——这就是"偏差-方差权衡"。

4. 为什么"训练误差低"不等于"泛化好"：一个思想实验#

设想一个最极端的"模型"：查表函数——它把训练集的每个 (xi​,yi​) 原样背下来，遇到新样本就随便猜。它的训练误差是 0，但测试误差与瞎猜无异。这说明：训练误差度量的是"记忆"，泛化度量的是"预测"，两者在模型自由度过大时彻底脱钩。

更精确地说，泛化误差的上界（后面两课会严格证明）大致长这样：

泛化误差≲m模型复杂度​​.

它同时告诉我们两件事：① 样本越多，泛化越好（m 在分母）；② 模型越复杂，泛化越差（复杂度在分子）。这条上界是整个泛化理论的核心直觉，也是"为什么要有正则化、为什么大模型需要海量数据"的理论注脚。

5. 从"经验风险最小化"到"结构风险最小化"#

既然直接最小化 R^ 会过拟合，自然的修正是给复杂度一个惩罚，转而最小化：

R^(θ)+λ⋅penalty(θ).

这就是结构风险最小化（SRM），也是母原理 1 中"目标函数 + 正则项"的统一框架在泛化视角下的重新登场：L1/L2 正则、早停、dropout、数据增强，本质上都是在用显式或隐式的方式压低"模型复杂度/样本数"这个比值，从而收紧泛化误差上界。

二、验证性代码示例#

下面代码用多项式回归验证泛化的核心现象：① 训练误差随阶数单调下降，但测试误差呈 U 形；② 把噪声水平调高，过拟合（高方差）更明显；③ 增加样本量能显著缩小训练-测试差距。

import numpy as np

rng = np.random.default_rng(0)

def make_data(n, noise=0.5):
    x = rng.uniform(-3, 3, n)
    y = np.sin(x) + noise * rng.standard_normal(n)   # 真实 f=sin(x) + 噪声
    return x, y

def poly_fit(x, y, deg):
    """最小二乘拟合 deg 次多项式，返回测试集上的预测（用于验证推导，不教 API）"""
    X = np.vander(x, deg + 1, increasing=True)       # 范德蒙德矩阵
    w, *_ = np.linalg.lstsq(X, y, rcond=None)
    return w

def predict(w, x):
    X = np.vander(x, len(w), increasing=True)
    return X @ w

x_tr, y_tr = make_data(30)
x_te, y_te = make_data(200, noise=0.5)

print("阶数 | 训练MSE | 测试MSE | 差距")
for deg in range(0, 13):
    w = poly_fit(x_tr, y_tr, deg)
    tr = np.mean((predict(w, x_tr) - y_tr) ** 2)
    te = np.mean((predict(w, x_te) - y_te) ** 2)
    print(f"{deg:>3} | {tr:7.4f} | {te:7.4f} | {te-tr:+7.4f}")

# 对比：更多样本能否缩小差距
x_tr2, y_tr2 = make_data(300)
w9  = poly_fit(x_tr,  y_tr,  9)
w9b = poly_fit(x_tr2, y_tr2, 9)
te9  = np.mean((predict(w9,  x_te) - y_te) ** 2)
te9b = np.mean((predict(w9b, x_te) - y_te) ** 2)
print(f"\n9阶多项式：m=30 测试MSE={te9:.4f}  vs  m=300 测试MSE={te9b:.4f}")

母原理连接#

本课是母原理 1（一切学习 = 优化） 与母原理 2（概率视角统一一切） 的衔接处，它点破了母原理 1 的一个隐藏前提：我们优化的从来不是"真实的期望风险"，而是它的抽样估计。泛化误差就是"估计"与"真相"之间的缺口，而它的结构（偏差/方差/噪声）与上界（复杂度/m​）全部来自概率语言。记住这条主线：学习 = 优化经验风险，而泛化 = 保证经验风险逼近期望风险——前者是母原理 1，后者是本章要形式化的理论。
