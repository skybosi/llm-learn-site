通用函数 ufunc#

前面我们用 +、* 等运算符做了逐元素运算，也用 np.sqrt、np.exp 这样的函数处理数组。它们背后其实是同一类东西：ufunc（universal function，通用函数）。ufunc 是 NumPy 里一种特殊的函数对象，专为"对数组逐元素运算"而设计，不仅速度快，还带有一系列额外能力，比如指定输出位置、逐元素累积等。

一、概念讲解#

1. 什么是 ufunc#

ufunc 的核心行为是：对输入数组的每一个元素，执行同一个标量函数，返回一个形状相同的数组。它天然支持广播，所以也能处理不同形状的输入。

2. 常见 ufunc 分类#

一元 ufunc（单个输入）：

函数 作用
np.sqrt 平方根
np.exp / np.log 指数 / 自然对数
np.log10 / np.log2 以 10 / 2 为底的对数
np.abs / np.fabs 绝对值
np.sin / np.cos / np.tan 三角函数
np.sign 符号函数（正 1、负 -1、零 0）

二元 ufunc（两个输入）：

函数 作用 等价运算符
np.add 相加 +
np.subtract 相减 -
np.multiply 相乘 *
np.divide 相除 /
np.power 幂 **
np.maximum / np.minimum 逐元素取较大/较小值 无

3. ufunc 的三个进阶能力#

  • out= 参数：把结果直接写入指定的数组，避免额外分配内存；
  • reduce 方法：沿某个轴反复应用二元 ufunc，把多个元素"归约"成一个（如 np.add.reduce 就是求和）；
  • accumulate 方法：保留每一步的中间结果（如累加得到前缀和）。

4. 数据科学中的典型用法#

  • 用 np.exp 实现 softmax 中的指数部分；
  • 用 np.log1p 处理接近 0 的数值、避免精度损失（log1p(x) = log(1 + x)）；
  • 用 np.maximum(x, 0) 实现 ReLU 激活函数。

二、可运行代码示例#

示例 1：一元 ufunc#

import numpy as np

x = np.array([1.0, 2.0, 4.0, 8.0])

print("sqrt:", np.sqrt(x))
print("exp:", np.exp(x))
print("log:", np.log(x))
print("log2:", np.log2(x))

angles = np.linspace(0, np.pi, 5)
print("sin of angles:", np.sin(angles))

# 用 np.log1p 精确计算 log(1 + 1e-10)
tiny = 1e-10
print("log1p(tiny):", np.log1p(tiny))

示例 2：二元 ufunc 与 out 参数#

import numpy as np

a = np.array([1, 2, 3, 4])
b = np.array([10, 20, 30, 40])

print("np.add:", np.add(a, b))       # 等价于 a + b
print("np.multiply:", np.multiply(a, b))  # 等价于 a * b

# 逐元素取较大值：常用于裁剪
c = np.array([1, 9, 3, 7])
print("maximum(a, c):", np.maximum(a, c))

# 用 out 参数复用缓冲区
buf = np.empty(4, dtype=np.int64)
np.add(a, b, out=buf)
print("out buffer:", buf)

示例 3：reduce 与 accumulate#

import numpy as np

v = np.array([1, 2, 3, 4, 5])

# reduce：把整个数组归约成一个值
total = np.add.reduce(v)
product = np.multiply.reduce(v)
print("add.reduce:", total)       # 1+2+3+4+5 = 15
print("multiply.reduce:", product)  # 5! = 120

# accumulate：保留每一步中间结果（前缀和 / 累乘）
cumsum = np.add.accumulate(v)
cumprod = np.multiply.accumulate(v)
print("add.accumulate:", cumsum)
print("multiply.accumulate:", cumprod)

示例 4：数据科学小例子——ReLU 与 softmax 的指数部分#

import numpy as np

# ReLU 激活：max(0, x)
logits = np.array([-2.0, -0.5, 0.0, 1.0, 3.0])
relu = np.maximum(logits, 0.0)
print("ReLU:", relu)

# softmax 的指数与归一化（数值稳定版本：先减最大值）
exp_scores = np.exp(logits - logits.max())
softmax = exp_scores / exp_scores.sum()
print("softmax:", softmax)
print("softmax sum:", softmax.sum())  # 应约等于 1
