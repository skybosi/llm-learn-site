常见激活函数#

上一课我们搞清了激活函数的使命是"注入非线性"。但"非线性"的函数千千万，该用哪个？这一课逐个拆解深度学习里最常用的几种：Sigmoid、Tanh、ReLU，以及它的改进版 Leaky ReLU，顺带提一下现代网络爱用的 GELU/Swish 和输出层专用的 Softmax。重点是记住每个函数的公式、形状、导数、优缺点——这是下一课"怎么选"的依据。

一、概念讲解#

1. Sigmoid：把输出压到 0 和 1 之间#

σ(z) = 1 / (1 + e^(-z))      取值范围：(0, 1)
σ'(z) = σ(z)(1 − σ(z))

Sigmoid 把所有输入光滑地压到 (0, 1) 之间，天然适合解释成"概率"，因此在二分类输出层上长期是标配。但它有三个毛病：

  • 饱和：当 z 很大或很小时，曲线变得非常平，导数 σ'(z) 趋近于 0。反向传播时梯度会被连乘得越来越小，导致梯度消失，深网络训练不动；
  • 输出不以 0 为中心：输出恒为正，导致下一层权重更新时梯度"同号"，优化路径呈锯齿状、收敛变慢；
  • 指数运算较慢：e^(-z) 计算代价比 ReLU 高。

因此今天 Sigmoid 主要留在输出层做二分类概率，几乎不再用作隐藏层激活。

2. Tanh：把 Sigmoid 拉成"零中心"#

tanh(z) = (e^z − e^(-z)) / (e^z + e^(-z))      取值范围：(−1, 1)
tanh'(z) = 1 − tanh²(z)

Tanh 是 Sigmoid 的"平移缩放版"：形状同样是 S 形，但输出范围变成 (−1, 1)，以 0 为中心，这解决了 Sigmoid"非零中心"的毛病。不过它依然会饱和，z 远离 0 时导数同样趋近 0，梯度消失问题依旧存在。所以 Tanh 现在也主要出现在一些循环网络（如 RNN/LSTM 内部）里，普通 MLP 的隐藏层已被 ReLU 取代。

3. ReLU：简单粗暴的现代默认值#

ReLU(z) = max(0, z)
ReLU'(z) = 1 (z > 0)，0 (z < 0)

ReLU（Rectified Linear Unit）在 z > 0 时直接输出 z（导数恒为 1），z < 0 时输出 0。它的优点极其突出：

  • 正区间不饱和：z > 0 时梯度恒为 1，反向传播时梯度不会连乘衰减，有效缓解梯度消失；
  • 计算极快：就是一个 max 操作，没有指数运算；
  • 天然稀疏：负输入一律输出 0，很多神经元"不激活"，网络更稀疏、更高效。

代价是它有一个著名缺陷——死亡 ReLU（dead ReLU）：一旦某个神经元的输入恒为负，它的梯度永远是 0，权重再也更新不动，这个神经元就"死"了，再也救不回来。这通常由学习率过大或偏置初始化不当触发。

4. Leaky ReLU 等变体：给负区间留一条缝#

Leaky ReLU(z) = max(α·z, z)    （α 是一个小斜率，如 0.01）

Leaky ReLU 把负区间从"硬 0"改成"一个很小的斜率 α·z"，这样 z < 0 时梯度不再是 0，避免了神经元彻底死亡。它只是把 ReLU 的缺点补掉一点点，训练更稳，但多数任务上收益有限。当 α 也被当作可学习参数时，就是 PReLU。此外还有负区间更光滑的 ELU、以及 ReLU 的平滑版 GELU/Swish（现代 Transformer 大模型里的常客）。

5. Softmax：输出层的"多分类"专用#

Softmax 严格说不是隐藏层激活，而是输出层把一串数变成"和为 1 的概率分布"的操作：

softmax(z)ᵢ = e^(zᵢ) / Σⱼ e^(zⱼ)

做 k 分类时，输出层放 k 个神经元，接 Softmax 得到 k 个概率。注意：PyTorch 里通常不单独写 Softmax，而是把它并进损失函数（如 CrossEntropyLoss 内部自带 softmax + 负对数似然），数值更稳——这个细节下一课会用到。

二、可运行代码示例#

示例 1：在 NumPy 里实现并对比三种激活

先自己写出 Sigmoid、Tanh、ReLU，再在几个关键点上观察它们的输出。

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def tanh(z):
    return np.tanh(z)          # NumPy 自带

def relu(z):
    return np.maximum(0, z)

z = np.array([-3., -1., 0., 1., 3.])
print("z        :", z)
print("sigmoid  :", sigmoid(z))
print("tanh     :", tanh(z))
print("relu     :", relu(z))

# 打印导数值，体会"饱和区"
def sigmoid_grad(z):
    s = sigmoid(z)
    return s * (1 - s)

print("\nz        :", z)
print("sigmoid 导数:", sigmoid_grad(z))   # 两端趋近 0 → 饱和
print("tanh 导数   :", 1 - tanh(z) ** 2)   # 两端趋近 0 → 饱和
print("relu 导数   :", (z > 0).astype(float))  # 正区间恒 1，负区间 0

观察输出：Sigmoid 把值压到 (0,1)、Tanh 压到 (−1,1)、ReLU 把负数清零；再看导数，Sigmoid/Tanh 在 z=±3 处导数已接近 0（饱和），而 ReLU 在正区间的导数恒为 1。

示例 2：用 PyTorch 演示"死亡 ReLU"

把 ReLU 神经元的输入偏置设成一个很大的负数，观察它的输出和梯度都变成 0——这就是"死神经元"。

import torch
import torch.nn as nn

# 单个 ReLU 神经元：输入 1 维，输出 1 维
linear = nn.Linear(1, 1)
relu = nn.ReLU()

# 故意把偏置设成很大的负数，权重也设成让输入常为负
with torch.no_grad():
    linear.weight.fill_(-1.0)
    linear.bias.fill_(-10.0)

x = torch.tensor([[1.0]])          # 输入
z = linear(x)                      # z = -1 * 1 - 10 = -11 < 0
a = relu(z)                        # ReLU 输出 0
a.backward()                       # 反向传播

print("z =", z.item(), "→ 输出 a =", a.item())
print("权重梯度 =", linear.weight.grad.item())   # 梯度为 0，权重不再更新
print("偏置梯度 =", linear.bias.grad.item())

运行后 输出 a = 0、权重梯度 = 0、偏置梯度 = 0：因为输入落在 ReLU 的负区间，梯度被"掐断"，这个神经元从此收不到任何更新信号——如果长期如此，它就成了"死神经元"。这就是使用 ReLU 时要留意（配合合理学习率与初始化）的原因，也是 Leaky ReLU 想解决的痛点。

三、练习#

  1. 手算导数：分别写出 Sigmoid、Tanh、ReLU 的导数公式，并计算它们在 z = 0 和 z = 5 处的导数值。
  2. 饱和观察：运行示例 1，比较 z = ±3 与 z = 0 处 Sigmoid 的导数大小，解释"为什么饱和会导致梯度消失"。
  3. 复现死神经元：运行示例 2，确认输出与梯度都为 0；再把 bias 改成 1.0，重跑观察梯度是否恢复非零，说说"死亡"发生的条件。
  4. 换激活实验：把上一课示例 2 里 XOR 网络的 ReLU 换成 Sigmoid、再换成 Tanh，观察收敛速度差异，说说 Sigmoid/Tanh 在较深网络里为何不如 ReLU 好训。
  5. 思考：为什么 Sigmoid 现在几乎只用于"二分类输出层"，而不再用于隐藏层？请从饱和、零中心、计算量三个角度作答。
