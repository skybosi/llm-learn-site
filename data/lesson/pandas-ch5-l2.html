排序#

筛选帮我们"选出要看的数据"，排序则帮我们"把数据按顺序摆好"。找出销量最高的前十件商品、把订单按时间从新到旧排列、看哪个地区金额最高——这些都要用到排序。Pandas 里排序的核心方法是 sort_values()，这一课我们就把它用熟。

一、概念讲解#

1. 按值排序：sort_values()#

sort_values() 按某一列或多列的值给行重新排列，最常用的参数是 by：

df.sort_values("金额")

默认是升序（从小到大）。要降序就加 ascending=False：

df.sort_values("金额", ascending=False)

2. 按多列排序#

by 可以传一个列名的列表，排序时先按第一列排，第一列相同时再按第二列排，依次类推。不同列还能各自指定升降序：

df.sort_values(["地区", "金额"], ascending=[True, False])

这句的意思是：地区按升序，同一地区内部金额按降序——"按地区分组，组内金额从高到低"。

3. 缺失值的位置：na_position#

排序时如果有缺失值，默认会被放到最后。可以用 na_position="first" 让它们排到最前面：

df.sort_values("金额", na_position="first")

4. 是改原表还是返回新表？#

sort_values() 默认返回一个新的 DataFrame，原来的 df 不变。若想就地修改，加 inplace=True。日常分析建议用返回值（可链式继续操作），少用 inplace，代码更清晰。

5. 按索引排序：sort_index()#

除了按值，还能按行索引或列名的顺序排序，用 sort_index()。当索引被打乱（比如某些合并操作之后）时，用它把顺序整理回来很实用。

6. 快速取"最大/最小的 N 行"#

想知道"金额最高的 3 笔订单"，可以直接用：

  • nlargest(n, "列")：该列值最大的 n 行；
  • nsmallest(n, "列")：该列值最小的 n 行。

它们和"先排序再取前 n 行"结果一致，但写法更简洁、意图更明确。

二、可运行代码示例#

import pandas as pd

df = pd.DataFrame({
    "商品": ["手机", "耳机", "键盘", "台灯", "T恤", "口红"],
    "品类": ["数码", "数码", "数码", "家居", "服饰", "美妆"],
    "销量": [120, 430, 210, 340, 560, 180],
    "金额": [9600, 12900, 6300, 8500, 9800, 7200],
})
print(df)

示例 1：单列排序#

# 销量从高到低
print(df.sort_values("销量", ascending=False))

示例 2：多列排序（组内降序）#

# 先按品类升序，同品类内按销量降序
print(df.sort_values(["品类", "销量"], ascending=[True, False]))

示例 3：nlargest 与 sort_index#

# 金额最高的 3 件商品
print(df.nlargest(3, "金额"))

# 把索引按升序整理回来
shuffled = df.sample(frac=1, random_state=1)   # 先随机打乱顺序
print(shuffled.sort_index())

三、练习#

  1. 把 df 按"金额"从小到大排列，输出结果。
  2. 用一条 sort_values() 实现：先按"品类"降序、同品类内按"金额"升序排列。
  3. 分别用 sort_values().head(2) 和 nsmallest(2, "金额") 找出金额最低的两件商品，确认两者结果相同；再尝试给 df 加一列含缺失值的数据，观察 na_position 的作用。
