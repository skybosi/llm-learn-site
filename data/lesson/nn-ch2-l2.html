前向传播#

上一课我们把 MLP 的结构搭好了：一堆全连接层，每层做"矩阵乘 + 偏置 + 激活"。那么给定一个输入，网络是怎么一步步算出最终输出的？这个过程就是前向传播（forward propagation）——数据从输入层出发，逐层变换，最终流到输出层。它是整个神经网络计算的"主干道"，反向传播（下一章讲）只是沿着这条主干道把梯度倒着推回去。这一课我们把前向传播的每一步掰开揉碎，再用 NumPy 和 PyTorch 各实现一遍。

一、概念讲解#

1. 统一记号：一层就是一个函数#

用上标 (l) 表示层号（l = 1, 2, …, L）。第 l 层的计算可以写成两小步：

z^(l) = W^(l) · a^(l−1) + b^(l)     # ① 线性变换
a^(l) = f(z^(l))                    # ② 非线性激活

其中：

  • a^(l−1) 是上一层的输出（对第 1 层而言就是原始输入 a^(0) = x）；
  • W^(l)、b^(l) 是第 l 层的权重矩阵与偏置向量；
  • f 是激活函数，a^(l) 是第 l 层的输出，会作为下一层的输入。

前向传播就是把这个公式从 l=1 到 l=L 依次执行，最后 a^(L) 就是网络的输出 ŷ。整个网络其实就是一个层层嵌套的函数：

ŷ = f( W^(L) · f( W^(L−1) · … f( W^(1)·x + b^(1) ) … ) + b^(L) )

2. 单神经元视角：先算 z，再算 a#

把镜头拉近到一个神经元：它接收上一层所有神经元的输出，先线性加权求和得到 z，再过激活函数得到 a。这一"先 z 后 a"的两步，是后面理解"反向传播"时最关键的记忆点——因为链式法则要分别对这两步求导。

3. 整层视角：数据在层间"流动"#

从层的角度看，前向传播就是一批向量在层间流动、被反复变换：

输入 x (m维) ──▶ 隐藏层1 ──▶ 隐藏层2 ──▶ … ──▶ 输出 ŷ (k维)
              (线性+激活)   (线性+激活)
  • 维度变化：每经过一个全连接层，向量维度从"该层输入维度"变成"该层输出维度"（由 W^(l) 的形状决定）；
  • 信息逐渐抽象：越靠近输出，表示越"任务相关"。这也呼应了上一章的"表征学习"——每一层都在把输入改写成更利于判断的形式。

4. 批处理：把向量换成矩阵#

实际训练不会一个样本一个样本地算，而是一次算一批（batch）。这时把上面的向量换成矩阵，维度多出一维"样本数"：

  • 输入 X 形状为 (m, d)：m 个样本、每个 d 维；
  • 线性变换写成 Z = X·Wᵀ + b（PyTorch 内部即如此），其中 W 形状 (n, d)，输出 Z 形状 (m, n)。

公式不变，只是"向量运算"升级为"矩阵运算"。好处是可以充分利用 GPU 的并行能力，一次处理成百上千个样本。

5. 手算一个小例子#

用一个最小的 2 → 2 → 1 网络感受一下。假设：

W^(1) = [[1, 1], [1, 1]]，b^(1) = [0, -1]，激活 f 用 ReLU
W^(2) = [[1, -2]]，       b^(2) = [0]，    输出层不用激活
输入 x = [1, 2]

一步步算：

z^(1) = W^(1)·x + b^(1) = [3, 3] + [0, -1] = [3, 2]
a^(1) = ReLU([3, 2]) = [3, 2]
z^(2) = W^(2)·a^(1) + b^(2) = [1·3 + (-2)·2] = [-1]
ŷ = a^(2) = -1

看，前向传播没有玄学，就是矩阵乘、加法、套激活三步的机械重复。真正的难点在"怎么调 W、b"，而那正是反向传播的任务。

二、可运行代码示例#

示例 1：NumPy 手写一个 2 → 3 → 1 MLP 的完整前向传播

我们用固定权重，把上面的手工计算流程完整跑一遍，并打印每一层的中间结果。

import numpy as np

def relu(z):
    """ReLU 激活：max(0, z)，逐元素"""
    return np.maximum(0, z)

# 固定权重与偏置（权当"已经学好的参数"）
W1 = np.array([[1., 1.], [1., 1.], [-1., 1.]])   # (3, 2)
b1 = np.array([0., -1., 0.])                     # (3,)
W2 = np.array([[1., -2., 1.]])                   # (1, 3)
b2 = np.array([0.])                              # (1,)

def forward(x):
    """前向传播：返回各层中间结果，方便观察"""
    z1 = W1 @ x + b1          # 第 1 层线性
    a1 = relu(z1)             # 第 1 层激活
    z2 = W2 @ a1 + b2         # 第 2 层线性
    a2 = z2                   # 输出层不做激活（回归场景）
    return z1, a1, z2, a2

x = np.array([1., 2.])        # 一个输入样本
z1, a1, z2, y_hat = forward(x)

print("输入 x        =", x)
print("z1 = W1·x+b1  =", z1)
print("a1 = ReLU(z1) =", a1)
print("z2 = W2·a1+b2 =", z2)
print("输出 ŷ        =", y_hat)

对照上文的记号：z1/a1 是第 1 层的"线性/激活"两步，z2/a2 是第 2 层。运行后你能清楚地看到数据从 [1,2] 一路变成标量输出 [-1] 的全过程。

示例 2：PyTorch 里一次跑一批样本

同一个网络，换成 PyTorch 并输入一批 3 个样本，体会"批处理"下维度的变化。

import torch
import torch.nn as nn

# 与示例 1 等价的 MLP：2 -> 3 -> 1
model = nn.Sequential(
    nn.Linear(2, 3),
    nn.ReLU(),
    nn.Linear(3, 1),
)

# 手动把示例 1 的权重填进去，保证结果一致
with torch.no_grad():
    model[0].weight.copy_(torch.tensor([[1., 1.], [1., 1.], [-1., 1.]]))
    model[0].bias.copy_(torch.tensor([0., -1., 0.]))
    model[2].weight.copy_(torch.tensor([[1., -2., 1.]]))
    model[2].bias.copy_(torch.tensor([0.]))

# 一批 3 个样本：第 1 个就是示例 1 的 [1,2]，后面两个任意
X = torch.tensor([[1., 2.],
                  [0., 1.],
                  [2., 0.]])

out = model(X)   # 前向传播，一次性算完 3 个样本
print("输入形状：", tuple(X.shape))
print("输出形状：", tuple(out.shape))
print("输出值：\n", out.detach().numpy())

你会看到输出形状是 (3, 1)——每个样本对应一个标量输出，第 1 行的值与示例 1 的 -1 完全一致。同一个前向传播，一次算一个样本是向量运算，一次算一批样本就是矩阵运算，本质完全相同。

三、练习#

  1. 手算：把上面 2 → 2 → 1 的小例子里 W^(1) 改成 [[1,0],[0,1]]、b^(1) 全 0、W^(2) 改成 [[1,1]]，输入 x=[3,4]，手写出 z^(1)、a^(1)、z^(2)、ŷ 各是多少。
  2. 改激活：在示例 1 里把 ReLU 换成 Sigmoid（1/(1+exp(-z))），重算并观察 a1 的变化，说说两者对负值输出的处理差异。
  3. 加一层：给示例 1 的 2 → 3 → 1 网络中间再加一层 3 → 2，写出新的 forward 函数（需要多一组 W、b 和多一次 ReLU）。
  4. 批处理对照：在示例 2 里把输入改成 torch.randn(100, 2)，确认输出形状是 (100, 1)，解释为什么权重形状不随样本数变化。
  5. 思考：前向传播每一步都是确定性计算，没有任何"学习"发生。那么"学习"究竟发生在哪个环节？它和下一课要讲的"万能逼近"、以及再往后的"反向传播"是什么关系？
