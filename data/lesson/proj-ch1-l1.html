项目规划（结构化数据端到端预测）#

这是"AI 实战项目"课程的第一个项目：结构化数据端到端预测。你已经学完机器学习基础（数据预处理、sklearn、正则化、树模型、评估指标），本课不再重复原理，而是带你从零规划一个"能写进简历、能在面试里展开讲"的完整项目——把一张 Kaggle 原始表格，做到一份可复现、可展示、可对答的模型报告。

一、目标与步骤#

1. 项目目标：选一个"能讲故事"的问题#

本项目给你两个候选题目，先看清它们的差异再决定主打哪一个：

维度 房价预测（回归） 信用卡欺诈检测（分类）
任务类型 回归，预测连续价格 二分类，识别极少数欺诈交易
数据难点 缺失值多、特征含义杂（房屋属性） 类别严重不平衡（欺诈占比 <1%）
核心指标 RMSE / R² / MAE AUC-PR、AUC-ROC、召回率@固定假阳率
面试亮点 特征工程扎实、缺失值处理 不平衡处理、业务阈值、成本敏感
难度与话题度 中等，适合打底 较高，最能体现"工程判断"

建议：把信用卡欺诈检测作为主打项目（它天然涉及"不平衡学习 + 业务权衡"，最能体现你不是只会调 API），把房价预测作为回归能力的补充练习。本课两条路线都给出规划，第 2 课以欺诈检测为主线写代码骨架，并在末尾附房价回归的变体。

2. 明确验收标准（先定目标，再动手）#

动手前先写下"什么算做完、什么算做得好"，避免无限调参：

欺诈检测（分类）

  • 主指标：AUC-PR（Precision-Recall 曲线下面积），因为正类极稀，用 Accuracy 毫无意义（全预测"非欺诈"也能 99.8%）。
  • 辅助指标：AUC-ROC、召回率（Recall）在假阳率约 0.1% 时的值，以及"每笔误拦交易的成本"换算。
  • 验收线（自定、可写进报告）：AUC-ROC ≥ 0.97，AUC-PR ≥ 0.75，并给出一个业务可用的分类阈值。

房价预测（回归）

  • 主指标：RMSE（与目标同单位，好解释）和 R²。
  • 辅助指标：MAE、对数目标下的 RMSLE。
  • 验收线：交叉验证 RMSE 进入该竞赛公开排行榜前 10% 量级（约 <0.13 对数价格），并分析 Top 特征。

4. 工具与选型#

环节 选型 理由
数据处理 pandas + numpy 表格数据的标准组合
基线/线性模型 scikit-learn（LogisticRegression / Ridge） 快速建立可解释基线
树模型主力 XGBoost + LightGBM 结构化数据 SOTA 常客，面试高频
调参 Optuna 比 GridSearch 快，且是简历加分项
可解释性 SHAP 回答"模型为什么这么判"
实验管理 本地目录 + joblib 保存 轻量即可，不必上 MLflow

pip install pandas numpy scikit-learn xgboost lightgbm optuna shap matplotlib

5. 里程碑与时间规划#

把项目拆成 6 个可交付节点，每步都有产出物：

步骤 产出物 大约耗时

二、代码骨架（本节先搭框架）#

先不写算法，把"工程骨架"立起来：项目目录、环境、数据读取、划分工具函数。第 2 课会在它的基础上填充特征工程与模型对比。

# 项目目录建议（保持可复现、可讲解）：
# fraud-project/
# ├── data/creditcard.csv          # 原始数据
# ├── notebooks/01_eda.ipynb       # 探索性分析
# ├── src/
# │   ├── data.py                  # 数据读取与划分
# │   ├── features.py              # 特征工程
# │   ├── models.py                # 模型对比与调优
# │   └── evaluate.py              # 评估与阈值
# └── reports/                     # 图表与总结

import pandas as pd
import numpy as np

# 1) 读取欺诈数据
df = pd.read_csv("data/creditcard.csv")
print("形状:", df.shape)
print("正类占比:", df["Class"].mean())          # 预期约 0.0017，即 0.17%
print("缺失值数量:", df.isna().sum().sum())     # 该数据集通常无缺失
print(df["Amount"].describe())                  # 金额尺度差异大，需缩放

# 2) 时间维度观察：是否按交易时间排序、有无周期性
df["Time"] = pd.to_datetime(df["Time"], unit="s")
print("时间范围:", df["Time"].min(), "->", df["Time"].max())

# 3) 无泄漏划分：欺诈场景按时间切分更贴近真实（用历史预测未来）
#    而非随机切分——随机切分会让"未来数据"泄漏进训练集，虚高指标。
df = df.sort_values("Time")
split_idx = int(len(df) * 0.8)
train_df, val_df = df.iloc[:split_idx], df.iloc[split_idx:]
print(f"训练集 {len(train_df)} 行, 验证集 {len(val_df)} 行")
print("验证集正类占比:", val_df["Class"].mean())

关键点：这一段已经包含本项目最重要的一个"工程判断"——按时间划分而不是随机划分。面试时主动说出这一点，远比"我用了 XGBoost"更值钱。

三、验收与复盘（规划视角）#

本课的验收不是跑出分数，而是"规划是否闭环"：

  1. 能否一句话讲清项目：尝试在 30 秒内说明"我做了什么、为什么选这个指标、最终做到了什么"。讲不清，说明规划还没到位。
  2. 指标是否先于模型确定：确认你已经在上文第 2 节写下了验收线，而不是"先跑模型再看什么好看"。
  3. 数据是否已落到本地：完成 data/creditcard.csv（或 train.csv）的下载与读取，运行骨架代码能打印出形状与占比。
  4. 简历一句话初稿：写下项目名的英文标题，例如 "Credit Card Fraud Detection — end-to-end tabular ML with XGBoost/LightGBM (AUC-PR 0.78)"，后续每课回来补全数字。

复盘提示：如果你两个题目都犹豫，先只做欺诈检测主路径；房价预测留在学完回归变体后作为第二个项目。贪多会稀释每个项目的深度，而"深度"才是简历与面试的分水岭。
