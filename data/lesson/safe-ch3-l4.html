量化安全评测协议：区间、样本量、配对与"安全-能力"的相互影响#

这一节要解决什么#

第 3 节给每项防护标了 εeff​。这一节处理一个更靠前的问题：那个 ε 是怎么测出来的，以及它带着多大的不确定度。

安全评测里最常见的四句话，每一句都缺一个数：

原话 缺的数 本节把它改写成
"攻击成功率 5%" 样本量与区间 phat​ 的 Clopper-Pearson 区间，n 与 k 必须一起报
"这一版比上一版更安全" 最小可检测效应 配对设计的 MDE 与样本量（§二、§三）
"我们试了 20 次都没攻破" 零成功的上界 U=1−0.051/n=0.139108
"我们把这个变体的成功率降到了 5%" 选择效应 从 M 个变体里挑最大值，报告必须按 max 读（§五）

本节的核心结论是一个纪律：安全量必须报成区间，样本量与判定器版本必须一起报，且"没测到"永远不等于"没有"——这与第 1 章成员推断（n≥(z1−α​+z1−β​)2σ2/(LΔ)2）、第 1 章第 4 节（n=200 对 jump =0.05 的功效只有 0.1742）的纪律是同一条。

具体地，本节会算出：

  • n=20 观察到 1 次成功，精确 95% 区间是 [0.0013,0.2487] —— 宽度 0.2475，点估计 0.05 几乎不携带信息。
  • "一次都没攻破"要 n≥298.07 才能把成功率上界压到 0.01，n=20 时上界仍是 0.139108。
  • 要检出"攻击成功率从 0.10 降到 0.05"，独立两组各需 434.4 条；配对设计在两版结果相关时才省样本（c=0.80、基线 0.30→0.25 时从 1250.7 省到 543.1，2.30 倍），正交时不省（1250.7→1253.5）。
  • n=200 的配对实验、先验不一致率 π=0.10 时，最小可检测效应是 0.0626（6.26 个百分点）——小于它的差异测不出来，报告里"没差别"必须带上这个数。
  • M=20 个真实成功率全是 0.05 的变体里挑最大值，平均报出 0.1572（高估 3.14 倍），它的 95% 上界平均 0.3510。
  • 2×2 能力-安全设计的交互：只沿对角线测，会得到"安全档低时 guard 代价大"或"高安全档更贵"两个相反结论，而两者都来自同一个合成系统。

1.1 安全量与能力量在统计上有什么不同#

两者都是"通过率"，但有一个结构差异必须先在协议里写明：

能力评测 安全评测
目标量 通过率 q（越大越好） 违规率 p（越小越好）
关注区 中间（0.3∼0.9） 尾部（p 很小）
主要误差 抽样误差 抽样误差 + 判定器误差 + 选择效应
样本量的驱动 分辨两个模型的差距 把上界压到可接受水平（与点估计无关）
典型报告 分数 + 区间 上界 + 判定器错分率 + 样本量

尾部这一行是关键：能力评测在 p≈0.5 附近做，区间宽度按 1/n​ 收缩；安全评测常常要回答"p 是不是小于 0.01"，此时区间宽度按 1/n 收缩（零成功时更是只有 1−0.051/n 可用）。这意味着同样的精度要求，安全评测需要的样本量可以比能力评测多一个数量级——这是安全评测预算常常被低估的算术原因。

1.2 三层结论：点估计、区间、可检验假设#

任何一次安全实验的输出都可以停在三个层次上，报告必须声明自己停在哪一层：

  1. 点估计：phat​=k/n。最少信息，只在 n 很大时可用。
  2. 区间：[pL​,pU​]（Clopper-Pearson / Wilson）。可以对决策说话。
  3. 可检验假设：与对照版本比较，报效应量与 p 值/MDE。这是唯一能支撑"更安全了"这个断言的层次，也是 §二–§五 的内容。

为什么必须声明层次：混用会产生"用点估计做第 3 层结论"的典型错误——"我们的成功率从 0.05 降到 0.04"（两个点估计差 0.01，可能是噪声）被当成"更安全了"的证据。

一、攻击成功率的区间估计#

1.1 三种区间，各自什么时候用#

设 K∼Binomial(n,p)。

Wald 区间（±zphat​(1−phat​)/n​）：最常被随手使用，但 k=0 或 k=n 时退化（宽度 0），且小样本覆盖率差。

Wilson 得分区间：对 Wald 的修正，在 k 接近 0 或 n 时仍给非退化区间：

1+nz2​phat​+2nz2​±znphat​(1−phat​)​+4n2z2​​​

Clopper-Pearson 精确区间：由 Beta 分位数给出，覆盖率不低于名义水平（保守）：

pL​=Bα/2​(k,n−k+1),pU​=B1−α/2​(k+1,n−k)

约定 k=0⇒pL​=0，k=n⇒pU​=1。本节代码实现了 B 分位数（正则化不完全 Beta + 二分），并在 §五 用蒙特卡洛核对覆盖率。

要 U≤0.001，需要 2994.23 ⇒ 2995 次。上界按 1/n 收缩：把 0.01 压到 0.001 要 10 倍样本，而把点估计精度提高一倍只要 4 倍样本。这就是"我们测了 20 次都没攻破"这句话的真实含量：U=0.139108。

1.4 区间不能修复判定器#

第 1 节已经说明 pobs​=pSe+(1−p)(1−Sp)。区间是围绕 k/n 算的，而 k 来自判定器；所以：

  • 若判定器误报率 1−Sp 与攻击率同量级（第 1 节算例：p=0.002 时假阳性占比 0.9421），那么再窄的区间也只是把 pobs​ 估准了，而不是把 p 估准了。
  • 正确的做法：先用阴性对照估 1−Sp，再看"观测率减掉假阳性基线"是否为正值，并给出该差值的区间；若观测率与假阳性基线不可区分，结论只能是"未检出"，不能是"违规率低于某值"。

二、样本量：独立两组 vs 配对#

2.1 独立两组（各 n 条，两组用例不同）#

要检出 p1​ 与 p2​ 的差异，α=0.05、功效 0.80：

nindep​=(p1​−p2​)2(z1−α/2​2pˉ​(1−pˉ​)​+z1−β​p1​(1−p1​)+p2​(1−p2​)​)2​,pˉ​=2p1​+p2​​

p1​ p2​ 每组 n
0.100 0.050 434.4
0.200 0.100 199.0
0.500 0.250 57.7

读数三条：

  1. p 越小越贵。 同样是"减半"，0.10→0.05 要 434.4 条，0.50→0.25 只要 57.7 条（7.5 倍）。
  2. 绝对差越小越贵。 0.10→0.08（2 个百分点的绝对差）要 3212.9 条，是 0.10→0.05 的 7.4 倍。这解释了为什么"把成功率从 5% 压到 3%"的验证成本远高于"从 50% 压到 25%"。
  3. 公式假设两组独立（不同的用例）。如果两组用例相同，就应该用配对设计（§3.2），而它不总是更省。

2.2 配对（同一批用例跑两个版本）#

配对实验的 2×2 表：

新版违规 新版不违规
旧版违规 p11​ p10​
旧版不违规 p01​ p00​

McNemar 只看不一致对：b（旧违规、新不违规）与 c（旧不违规、新违规），统计量 (b−c)2/(b+c)∼χ12​。样本量（对数）：

npairs​ ≈ δ2(z1−α/2​D​+z1−β​D−δ2​)2​,D=p10​+p01​,δ=p10​−p01​

注意：D 与 δ 不是自由参数——它们由两个边缘违规率与两版结果的相关性共同决定。

读数（本节的第二个反直觉）：配对的收益完全来自"两版结果的相关性"，不来自"配对"这个动作本身。

  • 正交（几乎不相关）时，npairs​/nunpaired​≈1.00，配对白干；
  • 相关性强（c=0.80）时，0.30→0.25 的配置只需独立设计的 0.434 倍样本（省 2.30 倍），0.10→0.05 省 1.73 倍。

为什么：D=p10​+p01​ 是不一致率，McNemar 的检验力只跟它有关。两版结果越相关（同一次攻击在两版上同时成功或同时失败），不一致率 D 越小，而 δ 不变，于是 δ/D​ 变大、需要的对数变少。正交时不一致率最大，配对的信息优势归零。

协议含义："我们用同一批用例做了配对实验"本身不是优点；要报的是 p10​、p01​ 与 D，并说明为什么认为两版结果相关（同模型家族、同提示框架、同一批用例难度相似）。如果 D 大到接近 p0​+p1​−2p11​ 的正交值，就应当承认这个实验的配对设计没有带来效率。

还有一条必须写进协议的代价：配对要求同一用例在两个版本上都可判定；不可判定的用例对（例如新版拒绝了整个任务）必须整对丢弃，所以实际可用对数 = 计划对数 × 可判定率。可判定率 0.8 时，计划 679 对才能得到 543 对。

三、最小可检测效应：给"没差别"配一个数#

3.1 公式与表的读法#

固定 n、π=D（不一致率），配对实验能检出的最小 δ（功效 0.80、α=0.05）满足：

δMDE​:1−Φ(z1−α/2​−π​δn​​)=0.80

π n=50 n=200 n=1000 n=5000
0.04 0.0792 0.0396 0.0177 0.0079
0.10 0.1253 0.0626 0.0280 0.0125
0.20 0.1772 0.0886 0.0396 0.0177

读数：

  1. π=0.10、n=200 时 MDE =0.0626，也就是 6.26 个百分点的成功率差。小于它的差异测不出来——所以"新版与旧版没有显著差异"这句话必须补上"本实验能检出的最小差异是 6.26 个百分点"。
  2. 同样 n，π 从 0.04 涨到 0.20，MDE 从 0.0396 涨到 0.0886（2.24 倍）。 不一致率越高越钝——这与 §2.3 的结论一致（相关性强 → π 小 → 更灵敏）。
  3. n 从 200 涨到 1000（5 倍），MDE 从 0.0626 降到 0.0280（2.24 倍），约等于 5​=2.236——MDE 按 1/n​ 收缩。

3.2 "没差别"的三种合法说法与一种非法说法#

说法 合法性
"未检出显著差异（n=200，MDE =0.0626）" ✓ 正确
"差异小于 6.26 个百分点时本实验无法检出" ✓ 正确
"两版在等价界 [−Δ,Δ] 内（TOST，Δ=0.05）" ✓ 正确，但需要预先设定 Δ
"两版一样安全" ✗ 非法：没有等价性检验，也没有 MDE

等价性检验（TOST）的样本量比"检出差异"更大，因为要同时排除两个方向。协议里应当预先声明用哪一种：想证明"没变差"就用 TOST，想证明"变好了"就用单侧检验，两者的样本量差一倍以上（单侧 vs 双侧）。

四、安全评测与能力评测的相互影响#

4.1 为什么必须做 2×2 而不是"两个独立实验"#

安全与能力共享同一根轴：加 guard（拒答、过滤、审批）会降低违规率，也会降低能力分。问题在于这个交换率不是常数。 一个可核对的四元组设计：

版本 安全档 guard 能力分 违规率
A B0（低） 关 0.80 0.10
A B0（低） 开 0.70 0.20
B B3（高） 关 0.92 0.05
B B3（高） 开 0.86 0.15

（合成 ⚠️：能力分为合成分数，违规率为合成估计）

主效应与交互：

  • guard 换来的能力提升：A 档 0.10、B 档 0.06；
  • guard 换来的违规上升：A 档 0.10、B 档 0.10；
  • 边际替代率（每 1 个百分点违规上升换多少能力分）：A 档 1.0000、B 档 0.6000。

读数（本节第三个反直觉）：

  1. 只看 A 的对角线（B0/关 → B0/开）会得到"guard 的能力代价是 0.10"；只看 B 会得到 0.06。两个结论都来自同一个系统，差异来自"当前落在安全-能力曲线的哪一段"——这与第 1 章第 4 节"对齐税不是一条直线"是同一个结论。
  2. 把 A、B 两档的数据画进同一张"安全-能力"散点图会得到一条不存在的曲线：四个点里有两个方向相反的 2 个样本，任何单调拟合都在拟合不同的机制。
  3. 正确的报告形态是：先报 (pviol​,cap) 的四元组与交互项（能力代价之差 0.10−0.06=0.04），再报主效应。交互项不显著时才能报"平均代价"。

4.2 两个评测共用一个样本时的纪律#

安全和能力评测常常共用同一批 prompt。这带来三个必须处理的问题：

  1. 判定器不同（能力看正确性，安全看违规），两个判定器可能相关：一个会被长回答迷惑的判定器，可能同时高估能力与漏掉违规。
  2. 上下文污染：能力评测的 prompt 进入上下文后改变安全评测的表现（多轮效应，第 1 章 ϕ(t)）。
  3. 多重比较：一份 prompt 集合上做 M 个判定 → 族错误率（§五）。

协议写法：把"共用 prompt 集合"作为一条显式声明，并给出两个判定器在同一子集上的一致性（例如 Cohen's κ 或简单一致率），以及不一致样本的数目。判据：若两个判定器在共用子集上的不一致率超过 5%，则不能把两个评测的数字放在同一个表格里比较。

五、多重比较与选择效应#

5.1 族错误率#

M 个独立判定、每个用 α=0.05，至少一次假阳性的概率：

FWER=1−(1−α)M

M 20 120 500
FWER 0.641514 0.997878 1.000000
Bonferroni 阈值 α/M 2.5000×10−3 4.1667×10−4 1.0000×10−4

读数：M=120 条用例各判一次，几乎必然出现至少一次假阳性（0.997878）。 红队报告里"我们发现了 1 个攻击"在 M=120 且判定器有 1% 假阳性时，期望假阳性数是 1.2——这条发现可能完全是假的。这就是阴性对照集必须存在的原因（第 1 节 §4.3）。

校正的取舍：

  • Bonferroni（α/M）：控制 FWER，保守，M 大时功效损失严重；
  • Benjamini-Hochberg（控制 FDR）：在 M 大时更有功效，但允许"报告出的发现里有一定比例的假阳性"，需要报告该比例的目标值；
  • 不校正：只能用于预注册的单一假设（这时 M=1）。

判据：报告里写出 M 是多少、"发现"是否从多个候选中挑出来的（若是，见 §5.2），以及用的哪一种校正。

5.2 选择效应：从 M 个变体里挑最好的那个#

红队里最常见的操作是"跑 M 个攻击变体，报最好的那个"。设所有变体的真实成功率都是 p=0.05，每个变体采 n 次，取最大值。蒙特卡洛（2000 次重复）：

n M E[maxphat​] 实测 解析近似 p+2p(1−p)lnM/n​
20 5 0.1092 0.1374
20 20 0.1573 0.1693
20 100 0.2039 0.1979
100 5 0.0766 0.0891
100 20 0.0944 0.1033
100 100 0.1111 0.1161

读数：n=20、M=20 时，挑出来的最好变体平均报出 0.1573——而真实值是 0.05，高估 3.14 倍。 这个偏置叫最大值偏置（winner's curse），它不需要任何模型缺陷就能产生：它是"从 20 个样本里挑最大"这个动作的数学后果。

解析近似的误差：M=5,n=20 时它给 0.1374 而实测 0.1092（高估），M=100,n=20 时给 0.1979 而实测 0.2039（低估）——近似式在 lnM 较小时不准，报告里不应用它替代实测。

5.3 选择之后，区间也要重算#

即使给挑出来的变体配上 Clopper-Pearson 区间，那个区间也不是"该变体真实成功率"的区间——因为它没有把选择这一步算进去。蒙特卡洛（每个变体 n=20，真实 p=0.05，2000 次重复）：

读数：M=20 时挑出的变体平均报出 0.1572（真实 0.05，高估 3.14 倍），它的 95% 上界平均 0.3510。 把 0.1572 当成"该变体的真实成功率"是最常见的报告错误。

正确的三种处理：

  1. 预注册：先定一个变体，只测它，M=1（代价是失去探索）；
  2. 分裂样本：在一半变体上挑，在另一半上验证（最推荐：报告里给出"挑选集 0.1572 / 验证集 x"两个数）；
  3. 校正区间：用保留样本或 Bonferroni 型校正把选择算进去（复杂，且通常仍不如分裂样本直观）。

判据：任何"我们找到了成功率最高的变体"的结论，必须回答"它在未参与挑选的样本上成功率是多少"。没有这个数，报告里的数字是选择过程的产物而不是系统的属性。

七、边界与开放问题#

  1. 本节所有公式假设"每条用例的成功是独立同分布伯努利"。 真实红队用例高度相关（同一批模板、同一个模型家族），有效样本量小于名义样本量。修正方向：用簇（cluster）层次报样本量（例如"40 个模板 ×5 个变体"），并在协议里声明簇数。
  2. "违规"的定义往往是复合的。 一条输出可能同时构成"越狱"与"泄漏"，把它算成两次判定会让 M 与 p 都虚高。协议必须声明判定是否互斥。
  3. 判定器误差与抽样误差不可分离时的处理：若阴性对照集不足以把 1−Sp 估到目标精度，那么真正的 p 上界要同时含两部分不确定性（抽样的 + 判定器的）。本节的区间只给前者，报告里必须写明这一层没算进去。
  4. 等价性检验的方向性：TOST 需要预先声明等价界 Δ；事后挑 Δ 会让检验失去意义（这是 §5.2 选择效应的另一种形态）。
  5. 能力-安全交互项本身也需要样本量。 交互项的方差约是主效应方差的 4 倍（2×2 设计的经典结果），所以"交互不显著"在小样本下几乎必然——报告交互项时必须给它的 MDE。
  6. 本节数值的合成性：区间、样本量、MDE、FWER、选择效应偏置都是解析计算或固定种子的蒙特卡洛（random.Random(20261122)），它们是可复算的算术，不代表任何真实系统。核对项：§五的 Clopper-Pearson 覆盖率实测 0.9868（名义 0.95，离散分布导致保守）、McNemar 功效解析 0.9424 vs 实测 0.9500。

def qnorm(p):
    """标准正态分位数（Acklam 有理逼近，绝对误差 < 1.15e-9）。"""
    a = [-3.969683028665376e+01, 2.209460984245205e+02, -2.759285104469687e+02,
         1.383577518672690e+02, -3.066479806614716e+01, 2.506628277459239e+00]
    b = [-5.447609879822406e+01, 1.615858368580409e+02, -1.556989798598866e+02,
         6.680131188771972e+01, -1.328068155288572e+01]
    c = [-7.784894002430293e-03, -3.223964580411365e-01, -2.400758277161838e+00,
         -2.549732539343734e+00, 4.374664141464968e+00, 2.938163982698783e+00]
    d = [7.784695709041462e-03, 3.224671290700398e-01, 2.445134137142996e+00,
         3.754408661907416e+00]
    plow, phigh = 0.02425, 1 - 0.02425
    if p < plow:
        q = math.sqrt(-2 * math.log(p))
        return (((((c[0] * q + c[1]) * q + c[2]) * q + c[3]) * q + c[4]) * q + c[5]) / \
               ((((d[0] * q + d[1]) * q + d[2]) * q + d[3]) * q + 1)
    if p > phigh:
        q = math.sqrt(-2 * math.log(1 - p))
        return -(((((c[0] * q + c[1]) * q + c[2]) * q + c[3]) * q + c[4]) * q + c[5]) / \
                ((((d[0] * q + d[1]) * q + d[2]) * q + d[3]) * q + 1)
    q = p - 0.5
    r = q * q
    return (((((a[0] * r + a[1]) * r + a[2]) * r + a[3]) * r + a[4]) * r + a[5]) * q / \
           (((((b[0] * r + b[1]) * r + b[2]) * r + b[3]) * r + b[4]) * r + 1)


def qnorm_cdf(z):
    return 0.5 * (1.0 + math.erf(z / math.sqrt(2.0)))


def betacf(a, b, x, itmax=400, eps=3e-16):
    qab, qap, qam = a + b, a + 1.0, a - 1.0
    c = 1.0
    d = 1.0 - qab * x / qap
    if abs(d) < 1e-300:
        d = 1e-300
    d = 1.0 / d
    h = d
    for m in range(1, itmax + 1):
        m2 = 2 * m
        aa = m * (b - m) * x / ((qam + m2) * (a + m2))
        d = 1.0 + aa * d
        if abs(d) < 1e-300:
            d = 1e-300
        c = 1.0 + aa / c
        if abs(c) < 1e-300:
            c = 1e-300
        d = 1.0 / d
        h *= d * c
        aa = -(a + m) * (qab + m) * x / ((a + m2) * (qap + m2))
        d = 1.0 + aa * d
        if abs(d) < 1e-300:
            d = 1e-300
        c = 1.0 + aa / c
        if abs(c) < 1e-300:
            c = 1e-300
        d = 1.0 / d
        de = d * c
        h *= de
        if abs(de - 1.0) < eps:
            break
    return h


def betai(a, b, x):
    """正则化不完全 Beta 函数 I_x(a,b)。"""
    if x <= 0.0:
        return 0.0
    if x >= 1.0:
        return 1.0
    lbeta = math.lgamma(a + b) - math.lgamma(a) - math.lgamma(b)
    front = math.exp(lbeta + a * math.log(x) + b * math.log(1.0 - x))
    if x < (a + 1.0) / (a + b + 2.0):
        return front * betacf(a, b, x) / a
    return 1.0 - front * betacf(b, a, 1.0 - x) / b


def qbeta(p, a, b, lo=0.0, hi=1.0):
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        if betai(a, b, mid) < p:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)


def cp_interval(k, n, alpha=0.05):
    lo = 0.0 if k == 0 else qbeta(alpha / 2, k, n - k + 1)
    hi = 1.0 if k == n else qbeta(1 - alpha / 2, k + 1, n - k)
    return lo, hi


def cp_upper(k, n, alpha=0.05):
    """单侧上界：P(p > U | k) < alpha。k=0 时 U = 1-alpha^(1/n)。"""
    if k == 0:
        return 1.0 - alpha ** (1.0 / n)
    return qbeta(1 - alpha, k + 1, n - k)


def wilson(k, n, z=1.959964):
    ph = k / n
    d = 1 + z * z / n
    c = ph + z * z / (2 * n)
    h = z * math.sqrt(ph * (1 - ph) / n + z * z / (4 * n * n))
    return ((c - h) / d, (c + h) / d)

小结#

  • 安全量必须报成区间，且必须带 n、k、判定器版本。 n=20,k=1 的 Clopper-Pearson 区间是 [0.0013,0.2487]（宽度 0.2475）——点估计 0.05 几乎不携带信息；n 从 20 涨到 4000（200 倍），宽度从 0.2475 收到 0.0138（17.98 倍，∝1/n​）。安全报告取 CP（覆盖率不低于名义），能力评测可用 Wilson。
  • 零成功不是零。 U=1−α1/n：n=20⇒0.139108、n=100⇒0.029513、n=300⇒0.009936。要 U≤0.01 需 n≥298.07，要 U≤0.001 需 2994.23 次。上界按 1/n 收缩，压一个数量级要十倍样本。
  • 区间修不了判定器。 pobs​=pSe+(1−p)(1−Sp)：p=0.002 时报出的事件 0.9421 是假阳性。区间只能把 pobs​ 估准；要谈 p，必须先用阴性对照估 1−Sp。
  • 独立两组：p 越小越贵、绝对差越小越贵。 0.10→0.05 各需 434.4；0.50→0.25 只要 57.7；0.10→0.08 要 3212.9（7.4 倍）。
  • 配对的收益来自相关性，不来自"配对"。 正交上界情形 npairs​/nunpaired​=1.002∼1.006（白干）；潜在相关 c=0.80 时 0.30→0.25 从 1250.7 降到 543.1（省 2.30 倍）、0.10→0.05 从 434.4 降到 251.2（省 1.73 倍）。McNemar 只看不一致对，所以报告必须给 p10​,p01​,D；且可判定率决定实际可用对数（0.8 时计划 679 对换 543 对）。
  • "没差别"必须配 MDE。 π=0.10 时 n=50/200/1000/5000 的 MDE 是 0.1253/0.0626/0.0280/0.0125；同样 n 下 π 从 0.04 到 0.20，MDE 从 0.0396 涨到 0.0886（2.24 倍）。MDE 按 1/n​ 收缩（n 涨 5 倍，MDE 降 2.24 倍）。"两版一样安全"在没有等价性检验时是非法结论。
  • 安全与能力必须做 2×2。 合成四元组里 guard 的能力代价在 A 档是 0.10、B 档是 0.06，违规上升都是 0.10；边际替代率 1.0000 vs 0.6000。只看一条对角线会得到相反的结论；报告要先报四元组与交互项，交互不显著才能报平均代价。交互项方差约是主效应的 4 倍，所以小样本下"交互不显著"几乎必然。
  • 多重比较：M=20/120/500 的 FWER 是 0.641514/0.997878/1.000000。 M=120、判定器假阳性 1% 时期望假阳性 1.2 条——"我们发现了 1 个攻击"可能完全是假的。Bonferroni 保 FWER 但丧失功效，BH 控 FDR 但需报告目标比例；预注册单一假设时无需校正。
  • 选择效应不需要任何模型缺陷就能产生。 n=20、M=20 时挑出的变体平均报出 0.1573（真实 0.05，高估 3.15 倍），其 95% 上界平均 0.3510。处理办法按推荐度排序：分裂样本 > 预注册 > 校正区间；判据是"它在未参与挑选的样本上成功率是多少"。
  • 取舍：本节的区间只含抽样误差，不含判定器误差；用例相关会让有效样本量小于名义样本量（应用簇口径与 design effect 1+(mˉ−1)ρ）；等价性界必须预先声明；全部数值为解析或固定种子蒙特卡洛（random.Random(20261122)），核对项：CP 覆盖率实测 0.9868（名义 0.95，离散导致保守）、McNemar 功效解析 0.9424 vs 实测 0.9500。
