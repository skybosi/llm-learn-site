数据与隐私泄露：记忆化、成员推断的统计功效、上下文与去标识化的可逆性#

这一节要解决什么#

第 2 节讲的是"怎么被打进去"。这一节讲打进去能带走什么 —— 也就是第 1 节威胁模型表里 E（利用因子）与 c（单次损失）的取值依据。

关于 LLM 隐私，公开讨论里最常见的四句话是：

  1. "模型会背下训练数据。"
  2. "可以做成员推断，判断某条数据在不在训练集里。"
  3. "上下文和工具链会泄露别的用户的数据。"
  4. "把姓名去掉就匿名了。"

这四句话都指向真实的问题，但作为判据都不合格：它们没有给出可测量的量，也没有给出失效条件。本节把每一句改写成一个带公式的断言，并且明确它在什么参数下成立、在什么参数下不成立：

原话 改写后的可算断言 本节位置
"模型会背数据" 逐字复现概率 1−(1−p)k；给定曝光次数 k，p 是多少？ §一
"可以做成员推断" 功效公式 n≥(z1−α​+z1−β​)2σ2/(LΔ)2：在 L、Δ、σ 给定的条件下要多少条样本？ §二
"缓存会串味" 撞桶概率 1−e−M(M−1)/2B 与期望读到次数 M(M−1)pread​/2B §三
"去掉姓名就匿名" 准标识符空间的碰撞概率、唯一率与 k-匿名；要多少比特才够？ §四

本节的核心判据是第二行，因为它把一句最容易说空的话（"能做成员推断"）变成了一个可以算样本量的统计问题：结论不是"能"或"不能"，而是"在长度 L 的片段上、给定似然差 Δ 与噪声 σ、要 n 条样本"。下面的算例里会出现一个具体结果：同一份数据、同一个模型，LΔ=0.287 nats 时 AUC 只有 0.6605，而逐条目 5% 假阳性下的检出率只有 0.1525 —— 说"能做成员推断"的人如果不给这两个数，他说的其实不是任何具体结论。

一、记忆化：一个概率，不是开关#

1.1 先建立操作判据#

"模型记住了训练数据"这句话最含糊的地方是它把逐字复现与能力泛化混在一起。可操作的判据是：

记忆 ≡ 在合适的前缀下，模型生成的续写与训练语料中的某一段 逐字相同 （长度超过某个阈值）

为什么需要"长度阈值"：任何模型都会产出训练集中常见的短串（"the"、"的"、常见短语）。这些不构成隐私问题。判据必须要求匹配长度足够长，使得"偶然重合"的概率可忽略 —— 这与 §四的碰撞概率是同一个工具（见 §1.4）。

1.2 曝光—复现模型#

设一个串在训练集中出现 k 次（曝光次数），单次曝光导致模型"记住"它的概率是 p。若各次曝光独立，则至少一次被记住的概率是：

 Prepro​(k)=1−(1−p)k ​

1.3 这个模型的三个边界#

边界 1：独立性假设通常不成立。 同一串的多次出现往往来自同一来源（同一网页的不同镜像），这时它们对模型的贡献高度相关，实际 Prepro​ 低于公式。去重算法正是靠"识别重复来源"起作用的。因此公式给的是上界，不是点估计。

边界 2：p 不是一个数，它随串的性质变化。 高困惑度的串（随机数字、唯一标识符）比自然语言更容易被逐字记住 —— 因为自然语言的续写可以由很多条路径产生，而随机串只有一条。⚠️ 本节不给 p 的经验值（不同模型/数据/长度下差异很大，网上流传的具体数字往往缺少可比的口径）。

边界 3：k-匿名与记忆的关系。 若限制"训练集中每个串最多出现 k−1 次"，那么由公式，复现概率上界是 1−(1−p)k−1。取 k=3、p=0.01：1−(1−0.01)2=0.019900. 这是"k-匿名作为记忆缓解"的算术含义：它不把概率变成 0，它把概率压到 1−(1−p)k−1。

1.4 逐字复现与"偶然重合"的分界#

即使模型生成一段长文本，也要问"它是不是本来就该被生成出来"。给定基线语料的字符分布，一段长 m 的串偶然出现的概率粗略是 ∏i​pi​（用实际词频）。取一个互补的判据：

偶然重合约等于  exp(m⋅Hchar​)−1

其中 Hchar​ 是字符级熵。读数：Hchar​=3 bit 时，m=40 字符的偶然重合概率约 2−120 —— 所以"匹配长度 ≥40 字符"是一个足够强的操作门槛，不需要更复杂的统计。 ⚠️ 这个估算假设字符近似独立，对高度结构化的文本（如代码模板）会低估偶然重合率，因此结构化文本上的阈值应更高。

二、成员推断：把"能不能做"变成"要多少样本"#

2.1 判据是什么#

成员推断（membership inference, MIA）问的是：给定一条记录 x 与一个模型 f，判断 x 在不在这份训练集里。 标准做法是似然比：

Λ(x)=logpf​(x∣member)−logpf​(x∣non-member)

实践中往往用可算的代理：模型在 x 上的平均对数似然 s(x)=L1​∑i​logpf​(xi​∣x<i​)，把它当分数，阈值取在非成员分数的某个分位（比如 95%）上。

为什么这个分数有信息量：模型在训练中见过 x，则 x 的 token 序列在模型下的概率通常（不是必然）被抬高。但这个"通常"就是全部争议所在 —— 它依赖正则化、数据量、重复次数、序列长度。所以判据必须带功效，不能只说"有信号"。

2.2 功效公式#

设分数在成员与非成员上的均值差为

E[s∣member]−E[s∣non-member]=Δ(每 token 的 nats 差),

整条序列（长 L）的分数差是 LΔ，非成员分数的标准差是 σ。用单侧 z 检验，显著性 α、功效 1−β 所需样本量：

 n ≥ (LΔ)2(z1−α​+z1−β​)2σ2​ ​

取 α=0.05, 1−β=0.80：z1−α​=1.6449、z1−β​=0.8416，于是 (z1−α​+z1−β​)2=6.1834。

算例（合成 ⚠️）：

三条立刻可读的结论：

  1. n∝1/(LΔ)2：样本量对"每 token 效应"是平方反比。Δ 减半 → 需要 4 倍样本；Δ 减到 1/10 → 需要 100 倍。
  2. n∝σ2：噪声翻倍 → 样本量翻两番。σ 由"逐序列对数似然的波动"决定，而这个波动随序列长度增长（更多 token 更多方差）—— 所以 L 的收益不是无限的：L 涨，LΔ 涨，σ 往往也在涨。
  3. L 与 Δ 在公式里以乘积出现：把序列长度从 64 拉到 256（4 倍），等价于把每 token 效应从 0.05 提到 0.20。

反向用法（最小可检出效应）：固定样本量 n 与 σ=8.0：

读数：手上有 200 条样本、在 L=64 的片段上，你只能检出每 token ≥0.022 nats 的泄漏。 如果真实的 Δ 是 0.005，你的实验测不出来不等于没有 —— 这是隐私评估里最常见的错误结论。

TPR=1−Φ(σ1.6449σ−LΔ​)=1−Φ(1.6449−σLΔ​)

读数：第三行说"Δ 只有 0.02 nats/token 时，逐条判定的检出率只有 6.88%" —— 这时 AUC 可能仍有 0.58 左右（分辨力存在），但逐条判定几乎无效。AUC 与 FPR-约束下的检出率是两个不同的量，把前者当后者是本节要纠正的第二个错误。

还有一个容易被忽略的抽样问题：阈值是从非成员样本估出来的。若手边只有 20 条非成员样本，阈值的相对标准误约

20​1​≈22.4%,

即 95% 分位阈值自身的标准误约为它均值的 22.4%（200 条时降到 1/200​=7.07%）。用 20 条样本估的阈值去宣称"检出率 10%"，这个 10% 没有任何意义 —— 阈值的误差比效应还大。

AUC≈Φ(σ2​LΔ​),

要让 AUC 到 0.68（即 z≈0.4661）需要 σLΔ​≈0.66，按 σ=0.477 反解需要 LΔ≈0.315、n≈4.75 —— 但实测要 13∼30 条。差距来自：分数不服从正态（对数似然是求和，尾部行为不同）、以及 LΔ 是用有限样本估出来的（估出来的效应本身带噪声，会系统性高估可检出性）。结论：功效公式给下界，实际实验要多留 2~6 倍样本。

2.6 成员推断不能证明什么#

边界 1（不能证明"某条数据被记住了"）。 MIA 是集合级陈述："这条记录更像来自训练集"。它不说明模型能生成它 —— 记忆化（§一）与可推断性是两个不同的量，可以一个高一个低。

边界 2（分布偏移会污染结论）。 如果成员与非成员来自不同分布（这在真实里几乎必然：训练数据是从某个来源抽的，评估数据是另抽的），那么 MIA 的 AUC 里混着"分布差异"而不是"训练痕迹"。这就是所谓"影子模型"方法要解决的问题：必须让参照模型在同分布上训练，才能把差异归因到"见过/没见过"。

边界 3（去重会大幅削弱它）。 由 §1.2，k 次曝光把记忆概率推到 1−(1−p)k；反过来，把 k 压到 1 会把 MIA 的优势压回最低。所以真实系统的 MIA 攻击效果高度依赖去重程度，跨系统的 AUC 数字不可比。

边界 4（Δ 是"每 token"的量，必须连同 L 报）。 本节所有结论都以 (L,Δ,σ) 三元组为条件。只报"我们测到 Δ=0.005"而不报 L 与 n，等于没报。

三、上下文与工具链泄露#

3.1 与训练数据泄露的区别#

前两节讲的是参数记忆（信息进入权重）。上下文与工具链讲的是运行期记忆：信息进入 KV 缓存、语义缓存、日志、遥测、向量库。区别是关键的：

维度 参数记忆 运行期记忆
是否经过"记忆—复现"这一关 是（要 k 次曝光 + 采样命中） 否（原样存下来，读到就能看）
缓解手段 去重 / 差分隐私 / 更少参数 隔离 / 分桶 / TTL / 加密 / 审计
触发条件 前缀 + 采样 命中同一个键 / 桶 / 缓存行
时间尺度 训练周期 毫秒级（缓存命中）

一句话：参数记忆是概率的，运行期记忆的默认状态是"原样留存"，需要刻意的隔离才变成概率的。

3.2 缓存与前缀共享的撞桶算术#

设缓存按前缀哈希分桶，共 B 个桶，一轮里有 M 次请求。把 M 个请求投入 B 个桶，至少有一对落在同一桶的概率（生日问题）：

Pcollide​=1−exp(−2BM(M−1)​)

期望的跨会话读取事件数（每对撞桶以 pread​ 的概率真的读到对方内容）：

E[Nread​]≈2BM(M−1)pread​​

算例（合成 ⚠️，pread​=0.35）：

M B=103（概率 / 期望次数） B=104 B=105
100 0.992917 / 1.73 0.390429 / 0.17 0.048295 / 0.02
1000 1.000000 / 174.82 1.000000 / 17.48 0.993228 / 1.75
10000 1.000000 / 17498.25 1.000000 / 1749.83 1.000000 / 174.98

读数（本节第三个反直觉）：在 M=1000、B=103 或 104 这两档上，"至少一次撞桶"的概率早已饱和到 1.0 —— 这个指标没有分辨力。有分辨力的是期望次数：B 从 105 降到 104，期望读到次数从 1.75 涨到 17.48 次（10 倍）。 所以：

"我们的缓存是隔离的"这句话必须带分桶数。 隔离不是布尔量，它是 B 的函数：把 B 减 10 倍，泄漏期望涨 10 倍。

取 B 的条件：如果要让期望读到次数不超过 1 次/轮，则

B ≥ 2M(M−1)pread​​.

M=1000、pread​=0.35 时 B≥1.75×105。这是一个可以直接写进设计文档的数。

3.3 语义缓存与"相似即命中"#

比前缀哈希更危险的一类设计是语义缓存：用嵌入相似度判断"这两个问题是不是同一个"，命中就复用答案。它的泄漏机理与哈希不同：

  • 哈希桶：撞桶是偶然（生日问题），概率随 B 下降；
  • 语义缓存：命中是设计目的，相似度阈值 τ 越低，跨用户命中的概率越高，而且命中率与泄漏率同向变化。

语义缓存的取舍： ↑命中率 ⇒ ↑跨用户复用 ⇒ ↑泄漏

判据：对每一对不同的用户问题算相似度，取一个阈值 τ，则

P(跨用户命中)=Pr[sim(qa​,qb​)>τ ​ 用户不同].

这个概率必须实测（用一个真实的问句分布），不能由"阈值设成 0.95 应该很安全"推断 —— 嵌入空间里不同用户问同一件事的相似度可以很高。缓解不是调阈值，而是把用户维度并进缓存键（即 B 的分子里加一个用户/租户维度）。

3.4 工具链：泄露发生在"返回"与"日志"#

工具链的泄漏有三条常见路径：

  1. 工具返回的内容被原样拼进上下文：一次越权查询的结果就留在上下文里（第 2 节的 pread​），如果这个上下文被缓存或落盘，它就跑到了下一个会话。
  2. 日志与遥测：为了可观测性，很多系统会把完整的 prompt 与响应写日志。这是运行期泄漏最常见的路径，而它通常不在威胁模型里。 审计判据：日志里有没有原文？保留期多长？谁能读？
  3. 错误信息：异常堆栈里带查询语句与参数（第 1 节的"运维凭据"通路的常见入口）。

对第 1 节威胁模型表的回填：每条工具通路上要加一列"输出到哪里"（只进上下文 / 进缓存 / 进日志 / 进向量库）。这一列决定了这条通路的 N 是"一次"还是"每次日志被读" —— 差着数量级。

四、去标识化的可逆性#

4.1 "删掉姓名"为什么在算术上等于没做#

去标识化的目标不是"没有姓名"，而是没有人（或没有外部数据）能把一条记录重新对到一个人。这要求准标识符（quasi-identifier, QI）组合的空间足够大：

  • 准标识符 = 邮编 + 出生日期 + 性别 + 职业 + …… 这些字段本身不唯一，但组合起来可能唯一。

把 n 条记录投入 N 个准标识符格子，碰撞概率（存在两条记录共享同一格子）：

Pcollide​=1−exp(−2Nn(n−1)​)

算例（合成 ⚠️）：

样本量 n N=103 N=104 N=105 N=106 N=109
100 0.992917 0.390429 0.048295 0.004938 0.000005
1000 1.000000 1.000000 0.993228 0.393166 0.000499
10000 1.000000 1.000000 1.000000 1.000000 0.048766
100000 1.000000 1.000000 1.000000 1.000000 0.993262

要让 n=10000 时碰撞概率 <0.01，需要

N ≥ 2(−ln(1−0.01))n(n−1)​=4,974,460,628 个格子,

即准标识符空间的熵

H=log2​N ≥ 32.21 bit.

读数：32 bit 是什么概念？ 一个 (5 位邮编 + 出生日期 + 性别) 的组合大概只有 105∼106 量级（17∼20 bit），远不够。"删掉姓名"把 H 从"完全可识别"降到 17∼20 bit，仍然远低于 32 bit 的门槛。 这就是"去标识化在算术上等于没做"的准确含义。

4.2 k-匿名：把门槛说成一个可核对的数#

k-匿名要求"每个准标识符组合下至少 k 条记录"。在均匀假设下，格子人数服从 Poisson(λ)、λ=n/N，于是

P(格子人数≥k)=1−i=0∑k−1​i!e−λλi​

算例（n=10000）：

N λ P(≥2) P(≥3) P(≥5)
103 10.0000 0.999501 0.997231 0.970747
104 1.0000 0.264241 0.080301 0.003660
105 0.1000 0.004679 0.000155 0.000000

读数：N=105（H≈16.6 bit）时 P(≥3)=0.000155。 也就是说："我们达到了 k=3"这句话基本上等价于"我们的准标识符熵足够小" —— 这两句话是同一件事的两种说法，可以互相换算。这是本节给出的最有用的换算之一：审计时不必争论"k 取多少"，可以直接比熵。

4.3 去匿名化的查询账本#

外部数据源存在时，每次查询都能把候选集合缩小。设每次查询的有效收缩因子 reff​，则 k 次查询后候选数为 n0​/reffk​，唯一识别需要

k=lnreff​lnn0​​.

算例（n0​=104）：reff​=2.0 → k=13.3 次；reff​=1.5 → k=22.7 次；reff​=1.2 → k=50.5 次。

读数：reff​ 从 2.0 掉到 1.2，所需查询从 13.3 涨到 50.5 次（3.8 倍）。 关键在 reff​ 的取值：reff​ 不是字段数，而是每次查询带来的实际信息量。 如果两次查询高度相关（同一数据源的两个相关字段），第二次的 reff​ 接近 1 —— 于是"我用了 5 个独立来源"这种说法必须换成"这 5 次查询的总信息量是多少 bit"。

这条也是"差分隐私为什么以比特计价"的原因：可识别性由信息量决定，不由字段数、不由流程数。差分隐私的预算 ε 正是把"泄露多少比特"写成一个可加的账本。

4.4 取舍与边界#

手段 它做什么 代价 失效条件
删除直接标识符 去掉姓名/身份证号 几乎为零 准标识符组合仍可唯一
泛化（邮编截断、年龄分箱） 降低 H 增速 有用性损失（分析精度） 泛化过粗后仍可与外部数据连接
k-匿名 保证每格 ≥k 同上；且不防"同质攻击" 同格内敏感属性相同则泄露
差分隐私 给泄露一个可加预算 ε 精度损失随 1/ε 组合（多次查询）会累积；ε 的取法本身是价值判断
合成数据 不发布任何真实记录 分布保真度与隐私的取舍 生成模型可能复现训练记录（回到 §一）

取舍的一般形式：去标识化要在"链接风险"与"有用性"之间选点，而这个点不能由技术单方面定：

min 由 H 决定Plink​​​s.t.有用性U(data)​​ ≥ Umin​.

这条约束里的 Umin​ 是业务/伦理判断，不是统计量。 本课最后一章会回到"哪些量不该被折进一个目标函数"。

五、边界与开放问题#

  1. 本节的 p、Δ、σ、pread​ 全是合成值。 真实系统上必须实测，且要连同 (L,n) 一起报。
  2. 多模态与结构化数据的判据不同。 图像/音频的"记忆"判据不是逐字匹配（没有"字"），需要基于感知相似度或嵌入距离的阈值；结构化表格的准标识符理论更成熟（这是统计披露控制的领域），但字段间的相关性会显著降低有效 H。⚠️ 后者所需的联合熵在实践中很难估准。
  3. 本节没有覆盖"模型权重本身的泄漏"。 从权重里反推训练样本（权重反演）是独立的一类通路，E 与 c 都不同，本节只把它记进第 1 节的资产表（"模型权重"那一行）。
  4. "聚合/统计查询"的隐私成本是另一种账本。 当系统允许"给我满足条件的记录数"这类查询时，多次查询会组合出个体信息，这属于差分隐私的组合定理范畴，本节只给出直觉（§4.3）。

# -*- coding: utf-8 -*-
"""⚠️ 合成数据：数据与隐私泄露的四个可算量。纯标准库。

块 0 记忆化：曝光次数 k 与逐字复现概率（1-(1-p)^k）的对照表；
块 1 成员推断的功效公式：n >= (z_{1-a}+z_{1-b})^2 * sigma^2 / (L*Delta)^2，含数值算例；
块 2 似然比判别：用非成员分位数定阈值，再看成员检出率与漏检率；
块 3 真实似然差：一阶马尔可夫计数模型 + 少量「成员过程」进入训练集，
     比较成员/非成员的对数似然、AUC（含 bootstrap 区间）与功效公式预测的所需样本量；
块 4 去标识化：准标识符空间 N、样本量 n 下的碰撞概率、唯一率与 k-匿名；
块 5 KV 缓存/前缀共享的跨会话泄露：桶数、请求数、至少一次撞桶的概率；
块 6 去匿名化的查询账本：要达到唯一识别需要多少次外部查询。
"""
import bisect
import math
import random
from statistics import NormalDist

ND = NormalDist()
RNG = random.Random(20260924)


# ============================================================================
# 0. 记忆化：不是「记住/没记住」的开关，而是曝光次数的函数
# ============================================================================
print("=== 0. 记忆化：曝光次数 k 与逐字复现概率（合成 ⚠️）===")
print("  模型：P(复现) = 1 - (1-p)^k，k = 该串在训练集里的出现次数，p = 单次记忆概率")


def p_repro(p, k):
    return 1.0 - (1.0 - p) ** k


for p in (0.001, 0.01, 0.05):
    row = ["%.6f" % p_repro(p, k) for k in (1, 2, 3, 5, 10, 50)]
    print("  p=%.3f  k=1,2,3,5,10,50 -> %s" % (p, "  ".join(row)))

print()
print("  反解：要复现概率达到 q，需要多少曝光次数 k = ln(1-q)/ln(1-p)")
for q in (0.01, 0.10, 0.50):
    row = []
    for p in (0.001, 0.01, 0.05):
        k = math.log(1 - q) / math.log(1 - p)
        row.append("p=%.3f -> k=%8.2f" % (p, k))
    print("  q=%.2f  %s" % (q, " ｜ ".join(row)))
print("  读数：q=0.50 时，p 从 0.05 掉到 0.001，所需曝光 k 涨 %.1f 倍 —— 训练侧去重的收益是超线性的"
      % ((math.log(0.5) / math.log(1 - 0.001)) / (math.log(0.5) / math.log(1 - 0.05))))

# ============================================================================
# 1. 成员推断的功效：需要多少条样本才能分清成员与非成员
# ============================================================================
print()
print("=== 1. 成员推断的统计功效（合成 ⚠️）===")
print("  设逐序列对数似然 s_i 在成员/非成员上的均值差 = L*Delta，标准差 = sigma")
print("  单侧 z 检验功效公式：n >= (z_{1-a} + z_{1-b})^2 * sigma^2 / (L*Delta)^2")


def n_required(L, Delta, sigma, alpha=0.05, power=0.80):
    za = ND.inv_cdf(1 - alpha)
    zb = ND.inv_cdf(power)
    return (za + zb) ** 2 * sigma ** 2 / (L * Delta) ** 2


print("  显著性 a=0.05，功效 1-b=0.80 ｜ z_{1-a}=%.4f, z_{0.80}=%.4f"
      % (ND.inv_cdf(0.95), ND.inv_cdf(0.80)))
print()
print("  L     Delta      sigma    所需样本数 n")
for L in (16, 64, 256):
    for Delta in (0.05, 0.10, 0.49):
        for sigma in (2.0, 8.0):
            n = n_required(L, Delta, sigma)
            print("  %5d  %6.3f  %8.1f   %14s" % (L, Delta, sigma, "{:,.1f}".format(n)))

print()
print("  最小可检出效应：固定 n 与 sigma=8.0 时 MDE = (z_{1-a}+z_{1-b})*sigma/(sqrt(n)*L)")
for L in (64, 256):
    for n in (200, 2000, 20000):
        mde = (ND.inv_cdf(0.95) + ND.inv_cdf(0.80)) * 8.0 / (math.sqrt(n) * L)
        print("  L=%4d  n=%6d -> MDE=%8.5f nats/token" % (L, n, mde))

# ============================================================================
# 2. 似然比判别：用非成员分位数定阈值，看成员检出率
# ============================================================================
print()
print("=== 2. 似然比检验：阈值取非成员的 95% 分位 ===")
for sigma, Delta, L in ((2.0, 0.10, 64), (8.0, 0.05, 64), (8.0, 0.02, 64)):
    mu_d = L * Delta
    zeta = ND.inv_cdf(0.95) * sigma
    tpr = 1 - ND.cdf((zeta - mu_d) / sigma)
    print("  sigma=%4.1f Delta=%.3f L=%d -> L*Delta=%.3f, 阈值 zeta=%.3f, 检出率=%.4f, 漏检率=%.4f"
          % (sigma, Delta, L, mu_d, zeta, tpr, 1 - tpr))
    need = (ND.inv_cdf(0.95) + ND.inv_cdf(0.80)) * sigma
    print("      想让检出率到 0.80：需要 L*Delta >= %.3f（当前 %.3f，差 %.2f 倍）"
          % (need, mu_d, need / mu_d))
    for n_non in (20, 200):
        rel = ND.inv_cdf(0.95) / math.sqrt(n_non)
        print("      若非成员只有 %3d 条，阈值估计的相对标准误约 %.1f%%" % (n_non, 100 * rel))

# ============================================================================
# 3. 真实似然差：一阶马尔可夫 + 少量「成员过程」进入训练集
# ============================================================================
print()
print("=== 3. 真实似然差：一阶马尔可夫模型上的成员推断（合成 ⚠️）===")
V = 128
K = 16                       # 前 K 个 token 构成「群内」；后 V-K 个是「群外」
BASE_N = 63000
L_SEQ = 64
EPS = (0.90, 0.10)           # 成员过程的两套发射概率
IN_TOK = list(range(K))
OUT_TOK = list(range(K, V))


def member_seq(rng, L):
    """成员过程：状态在每位交替，偶数位发射 in 的概率 = EPS[0]，奇数位 = EPS[1]。"""
    s = []
    for i in range(L):
        p = EPS[0] if (i % 2 == 0) else EPS[1]
        s.append(rng.randrange(K) if rng.random() < p else rng.randrange(K, V))
    return s


def nonmember_seq(rng, L):
    """非成员：每位独立、群内/群外各 50%，群内群外都均匀。"""
    return [rng.randrange(K) if rng.random() < 0.5 else rng.randrange(K, V) for _ in range(L)]


def gen_training(rng, n_base, n_mem):
    seqs = [[rng.randrange(V) for _ in range(L_SEQ)] for _ in range(n_base)]
    seqs += [member_seq(rng, L_SEQ) for _ in range(n_mem)]
    return seqs


def fit_markov(seqs, alpha=1.0):
    cnt = [[alpha] * V for _ in range(V)]
    first = [alpha] * V
    for s in seqs:
        first[s[0]] += 1
        for i in range(1, len(s)):
            cnt[s[i - 1]][s[i]] += 1
    P = [[cnt[i][j] / sum(cnt[i]) for j in range(V)] for i in range(V)]
    tot = sum(first)
    P0 = [v / tot for v in first]
    return P, P0


def seq_logprob(P, P0, s):
    tot = math.log(P0[s[0]])
    for i in range(1, len(s)):
        tot += math.log(P[s[i - 1]][s[i]])
    return tot


def auc_fast(mem, non):
    ns = sorted(non)
    c = 0
    for a in mem:
        lo = bisect.bisect_left(ns, a)
        hi = bisect.bisect_right(ns, a)
        c += lo + 0.5 * (hi - lo)
    return c / (len(mem) * len(non))


def mean(xs):
    return sum(xs) / len(xs)


def sd(xs):
    mu = mean(xs)
    return math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


print("  词表 V=%d；成员过程的群内集合大小 K=%d，发射概率 EPS=(%.2f, %.2f)"
      % (V, K, EPS[0], EPS[1]))
print("  基座训练集 %d 条（均匀随机），另混入 n_mem 条成员过程样本；序列长 L=%d"
      % (BASE_N, L_SEQ))
print("  评估集用独立种子重新抽样（不是训练集里的那几条）")
print()
print("  n_mem   gam=n_mem/BASE   实测每token Delta   sigma    L*Delta   功效公式 n   实测 AUC")
rows = []
for n_mem in (40000, 12000, 4000, 1200):
    P, P0 = fit_markov(gen_training(random.Random(11), BASE_N, n_mem))
    r_eval = random.Random(31337)
    MEM_EVAL = [member_seq(r_eval, L_SEQ) for _ in range(400)]
    NON_EVAL = [nonmember_seq(r_eval, L_SEQ) for _ in range(400)]
    s_mem = [seq_logprob(P, P0, s) for s in MEM_EVAL]
    s_non = [seq_logprob(P, P0, s) for s in NON_EVAL]
    L = L_SEQ - 1
    d = (mean(s_mem) - mean(s_non)) / L
    sig = sd(s_non)
    a = auc_fast(s_mem, s_non)
    rows.append((n_mem, d, sig, a, s_mem, s_non))
    print("  %6d  %14.5f   %16.6f   %6.3f   %8.3f   %11.1f   %8.4f"
          % (n_mem, n_mem / float(BASE_N), d, sig, L * d, n_required(L, d, sig), a))

print()
print("  取 n_mem=1200 的那一组看细节（最接近「难打的成员推断」）：")
n_mem, d, sig, a, s_mem, s_non = rows[-1]
L = L_SEQ - 1
print("  成员   平均对数似然 = %9.4f （每 token %.6f）" % (mean(s_mem), mean(s_mem) / L))
print("  非成员 平均对数似然 = %9.4f （每 token %.6f）" % (mean(s_non), mean(s_non) / L))
print("  逐序列标准差：成员 %.4f ｜ 非成员 %.4f" % (sd(s_mem), sd(s_non)))
print("  群内/群外各半时的每 token 对数似然基准 = %.6f"
      % (0.5 * math.log(0.5 / K) + 0.5 * math.log(0.5 / (V - K))))
bs = []
for _ in range(200):
    x = [s_mem[RNG.randrange(len(s_mem))] for _ in range(len(s_mem))]
    y = [s_non[RNG.randrange(len(s_non))] for _ in range(len(s_non))]
    bs.append(auc_fast(x, y))
bs.sort()
print("  AUC=%.4f，bootstrap 90%% 区间 = [%.4f, %.4f]"
      % (a, bs[int(0.05 * len(bs))], bs[int(0.95 * len(bs))]))
s_non_sorted = sorted(s_non)
zeta = s_non_sorted[int(0.95 * len(s_non_sorted))]
tpr = sum(1 for s in s_mem if s > zeta) / len(s_mem)
print("  阈值取非成员 95%% 分位 = %.4f -> 成员检出率 = %.4f（假阳性 5%%）" % (zeta, tpr))
print()
print("  功效公式的自我检验：用 n_mem=1200 那组，按不同样本量各抽一次，看实测 AUC 与预测是否对得上")
P, P0 = fit_markov(gen_training(random.Random(11), BASE_N, 1200))
for n_try in (50, 100, 400, 1600):
    r2 = random.Random(555)
    x = [seq_logprob(P, P0, s) for s in (member_seq(r2, L_SEQ) for _ in range(n_try))]
    y = [seq_logprob(P, P0, s) for s in (nonmember_seq(r2, L_SEQ) for _ in range(n_try))]
    print("    n_try=%5d -> 实测 AUC=%.4f（由这组数据重新估出的功效所需 n=%.1f）"
          % (n_try, auc_fast(x, y), n_required(L_SEQ - 1, (mean(x) - mean(y)) / (L_SEQ - 1), sd(y))))
print("  读数：Delta 由「成员过程进入训练集的条数」决定，所需样本量按 1/Delta^2 上涨 ——")
print("        「成员推断能不能做」不是二值结论，而由 (L, Delta, sigma) 三个量共同决定")

# 4. 去标识化：准标识符空间的碰撞与唯一率
# ============================================================================
print()
print("=== 4. 去标识化的可逆性：碰撞概率、唯一率、k-匿名（合成 ⚠️）===")
print("  模型：n 条记录落在 N 个准标识符格子里，碰撞概率 ~ 1-exp(-n(n-1)/(2N))")


def collision_p(n, N):
    return 1.0 - math.exp(-n * (n - 1) / (2.0 * N))


print("  样本量 n   N=1e3     N=1e4     N=1e5      N=1e6      N=1e9")
for n in (100, 1000, 10000, 100000):
    row = ["%.6f" % collision_p(n, N) for N in (1e3, 1e4, 1e5, 1e6, 1e9)]
    print("  %8d  %s" % (n, "  ".join(row)))
print()
n = 10000.0
N_need = n * (n - 1) / (2.0 * (-math.log(1 - 0.01)))
print("  想让碰撞概率 < 0.01（n=10000）：N >= %s 个格子，即熵 H >= log2(N) = %.2f bit"
      % ("{:,.0f}".format(N_need), math.log2(N_need)))
print()
print("  k-匿名：同一准标识符组合下至少 k 条记录（格子人数 ~ Poisson(lam)，lam = n/N）")
for N in (1e3, 1e4, 1e5):
    lam = 10000.0 / N
    p_k2 = 1 - sum(math.exp(-lam) * lam ** i / math.factorial(i) for i in range(2))

小结#

  • 记忆化是一个概率，不是开关：Prepro​(k)=1−(1−p)k。算例 p=0.05,k=50 时 0.923055；q=0.50 时把 p 从 0.05 压到 0.001 需要 51.3 倍的曝光差距 —— 去重的收益是超线性的（边际概率 p(1−p)k−1 指数衰减）。k-匿名的算术含义就是 Prepro​≤1−(1−p)k−1。
  • 逐字复现与偶然重合的分界可以定：Hchar​=3 bit、匹配 40 字符时偶然重合约 2−120 —— "匹配长度 ≥40 字符"是足够强的操作门槛（结构化文本要更高）。
  • 成员推断的判据是功效，不是"能不能"：n≥(z1−α​+z1−β​)2σ2/(LΔ)2，α=0.05、功效 0.80 时系数是 6.1834。n∝1/(LΔ)2，且 (L,Δ,σ) 必须一起报。
  • 固定样本量时能检出的效应有下界：σ=8、L=64、n=200 时 MDE =0.02198 nats/token。测不出来不等于没有 —— 这是隐私评估里最常见的错误结论。
  • AUC 与逐条检出率是两个量：实测算例里 AUC =0.6605，而假阳性 5% 下的检出率只有 0.1525。只报 AUC 的评估不完整。阈值本身也有抽样误差：20 条非成员样本时阈值标准误是自身的 22.4%（200 条时 7.07%）。
  • 曝光量决定可推断性：nmem​ 从 40000 降到 1200（33 倍），Δ 从 0.134652 掉到 0.004553，AUC 从 0.9946 掉到 0.6605。
  • 功效公式给下界，实测要多留 2∼6 倍样本：AUC 0.68 的近似公式说 n≈4.75，实测要 13∼30 条（分数非正态 + 效应本身带噪声）。
  • 成员推断不能证明"某条被记住了"：它是集合级陈述；分布偏移会污染结论（这就是影子模型的作用）；去重会大幅削弱它；所以跨系统的 AUC 数字不可比。
  • 运行期记忆与参数记忆机制不同：前者默认"原样留存"，靠隔离才变成概率的。撞桶概率 1−e−M(M−1)/2B，期望泄漏次数 ≈M(M−1)pread​/2B。"至少一次"在 M 大时饱和到 1.0、没有分辨力，有分辨力的是期望次数（M=1000 时 B 从 105 降到 103：1.75→174.82 次）。"我们的缓存是隔离的"必须带分桶数 B。
  • "删掉姓名"在算术上等于没做：n=10000 时想让碰撞概率 <0.01 需要 H=log2​N≥32.21 bit，而(5 位邮编+出生日期+性别)通常只给到 17∼20 bit。k-匿名与熵可以互相换算（N=105、H≈16.6 bit 时 P(≥3)=0.000155）。
  • 去匿名化由信息量决定，不由字段数决定：k=lnn0​/lnreff​；reff​ 从 2.0 掉到 1.2，所需查询从 13.3 涨到 50.5 次。差分隐私以比特计价正是因为这一点。
  • 取舍：去标识化在"链接风险"与"有用性"之间选点，而 Umin​ 是价值判断不是统计量（与第 4 节的"愿意付的价格"同构）。

下一节：第 3 节讲的是"数据侧的失败"。第 4 节转向训练侧的失败：为什么"我们做过对齐训练了"不能当成一条信任边界。它会给出对齐失败的谱系 —— 目标错设（我们写的目标不是我们想要的）、奖励黑客（形式化：代理奖励与真实目标的相关系数 <1 时，在代理上取极值会使真实目标的期望下降，本节给出可复算的例子）、以及欺骗性对齐；后者会逐条标注证据等级：哪些是在明确假设下的理论论证、哪些有可重复的实证迹象、哪些目前属于推测、不应当写成结论，并给出"如果它成立，什么观测能证伪它"的检验设计。
