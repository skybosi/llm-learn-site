类别编码#

现实数据里充满了文字型类别：房型"一室/两室/三室"、朝向"东/南/西/北"、学历"高中/本科/硕士"。机器学习模型只认数字，所以必须先把这些类别转成数值——这就是类别编码。本课讲清有序类别和无序类别的不同编码方法，以及如何用 ColumnTransformer 一次处理多列。

一、概念讲解#

1. 两种类别，两种编码#

  • 有序类别（Ordinal）：类别之间存在天然的大小顺序，例如"低楼层 < 中楼层 < 高楼层"、学历高低。适合用 OrdinalEncoder 转成递增整数。
  • 无序类别（Nominal）：类别之间没有顺序，例如"朝向""城市""颜色"。如果直接编成 0、1、2，模型会误以为"西(3) > 南(1)"，引入虚假的顺序关系。适合用 OneHotEncoder 独热编码。

2. 独热编码（One-Hot Encoding）#

把一列有 k 个取值的类别，展开成 k 列 0/1：每个样本在其所属类别那一列标 1，其余标 0。例如"朝向=南"变成 [南=1, 北=0, 东=0, 西=0]。优点是消除了虚假顺序，缺点是类别多时特征维度会膨胀。

3. 常用工具对比#

  • OrdinalEncoder：编码特征列的有序类别。
  • OneHotEncoder：编码特征列的无序类别，可与 ColumnTransformer 搭配处理多列。
  • LabelEncoder：只用来编码目标标签 y（把类别名转成 0/1/2），不适合当特征编码器用（它同样会引入虚假顺序，且一次只能处理一列）。
  • Pandas 的 pd.get_dummies：也能做独热编码，简单直接；但它是"一次性"的，无法保存"训练时见过哪些类别"，预测新数据时容易漏类别，工程上更推荐用 OneHotEncoder（可 fit 后复用）。

二、可运行代码示例#

用一份带多个类别列的房价数据，演示各种编码方式。

import pandas as pd
from sklearn.preprocessing import OrdinalEncoder, OneHotEncoder, LabelEncoder
from sklearn.compose import ColumnTransformer

df = pd.DataFrame({
    "户型": ["一室", "三室", "两室", "三室", "两室"],
    "朝向": ["南", "北", "南", "东", "西"],
    "楼层": ["高", "低", "中", "高", "中"],
    "价格": [300, 520, 420, 480, 400],
})
print("原始数据：\n", df)

# ---- 1. 有序类别：楼层 低<中<高，用 OrdinalEncoder 指定顺序 ----
enc_ord = OrdinalEncoder(categories=[["低", "中", "高"]])
df["楼层编码"] = enc_ord.fit_transform(df[["楼层"]])
print("\n楼层有序编码结果：\n", df[["楼层", "楼层编码"]])

# ---- 2. 无序类别：朝向，用 OneHotEncoder ----
enc_one = OneHotEncoder(sparse_output=False)
oh = enc_one.fit_transform(df[["朝向"]])
print("\n朝向独热编码的类别：", enc_one.categories_)
print("独热编码矩阵（5 行 × 4 列）：\n", oh.astype(int))

# ---- 3. 用 ColumnTransformer 一次处理多个不同类型的列 ----
ct = ColumnTransformer([
    ("户型_onehot", OneHotEncoder(sparse_output=False), ["户型"]),
    ("朝向_onehot", OneHotEncoder(sparse_output=False), ["朝向"]),
    ("楼层_ordinal", OrdinalEncoder(categories=[["低", "中", "高"]]), ["楼层"]),
])
X_encoded = ct.fit_transform(df)
print("\n组合编码后的特征矩阵：\n", X_encoded.astype(int))
print("组合后的列名：", ct.get_feature_names_out().tolist())

# ---- 4. 目标编码：LabelEncoder 只用于标签 y ----
le = LabelEncoder()
y = le.fit_transform(["便宜", "贵", "中等", "贵", "中等"])
print("\n目标编码结果：", y, "对应类别：", le.classes_.tolist())

要点回顾：

  • 楼层用了 OrdinalEncoder(categories=...) 手动指定顺序，避免它按字母序（低、中、高恰好也是这个序）或出现顺序误判。
  • ColumnTransformer 让"数值列原样保留、无序列独热、有序列序数编码"可以一次性完成，是实战中最常用的写法。
  • OneHotEncoder(sparse_output=False) 输出普通数组方便打印；默认输出稀疏矩阵以节省内存。

三、练习#

  1. 选择编码方式：以下列分别该用有序编码还是独热编码？
    • (a) 学历（高中/本科/硕士/博士）
    • (b) 所在城市（北京/上海/广州/深圳）
    • (c) 用户性别（男/女/其他）
  2. 填空：OneHotEncoder 把有 k 个取值的类别列展开成 ____ 列；LabelEncoder 的正确用途是编码 ____。
  3. 动手实验：用 pd.get_dummies(df[["朝向"]]) 和 OneHotEncoder 分别处理"朝向"，对比结果。再思考：如果新来一条"朝向=东北"的样本，两者的表现有何不同？
  4. 思考题：为什么给"城市"这类无序类别直接用 OrdinalEncoder 编成 0、1、2 是危险的？模型会因此产生什么错误假设？
