图卷积思想#

第二章我们从"邻居聚合"的空间域角度搭起了 GNN 的骨架。但 GCN（Graph Convolutional Network）这个名字里还带着"卷积"二字——它其实有一条独立的、来自信号处理的谱域（spectral）血统。这一课走一遍谱方法的完整逻辑：把"定义在图上的信号"做傅里叶变换、在频域上滤波、再反变换回来。你会看到，看似神秘的图卷积，起点不过是第一章见过的一个等式：xᵀ L x = Σ (x_u − x_v)²。理解了这条血统，下一课的 GCN 公式推导就是水到渠成。

一、概念讲解#

1. 图信号与平滑度#

把定义在所有节点上的一个实数值，看作一个图信号（graph signal） x ∈ Rⁿ（n 为节点数）。比如 x 可以是"每个节点的温度"、"每个用户的风险分"。第一章我们已经证明过一个核心等式：

xᵀ L x = Σ_{(u,v)∈E} (x_u − x_v)²

左边用拉普拉斯矩阵 L 表示，右边是所有相连节点之间取值差的平方和。这个量衡量了图信号有多"颠簸"：如果相邻节点取值都很接近，它就小（信号平滑）；如果相邻节点跳变剧烈，它就大（信号粗糙）。

2. 拉普拉斯矩阵的特征分解：图的"频率"#

既然 L 是一个实对称半正定矩阵，它可以特征分解：

L = U Λ Uᵀ

其中 U 的列是正交的特征向量，Λ 是对角矩阵，对角线是特征值 λ₁ ≤ λ₂ ≤ … ≤ λₙ（非负）。这些特征值和特征向量，就是图上"频率"与"基函数"的推广：

  • 特征值越小，对应特征向量越平滑。最小的特征值 λ₁ = 0，对应的特征向量是"常数向量"（所有节点取值相同，完全平滑）；特征值越大，对应的特征向量沿边振荡越剧烈。
  • 换句话说，Uᵀ x 就是在图的"频域"上分解信号：把 x 投影到各个特征向量上，得到的系数 x̂ = Uᵀ x 就是信号在"低频、中频、高频"上的分量。

这完全类比普通傅里叶变换：时域信号投影到不同频率的正弦/余弦基上。只是这里的"基"不再是正弦波，而是拉普拉斯矩阵的特征向量。

3. 图傅里叶变换与图卷积#

有了频域分解，就可以定义图傅里叶变换（Graph Fourier Transform）：

x̂ = Uᵀ x（正变换），x = U x̂（逆变换）

回忆卷积定理：普通卷积 = 傅里叶变换 → 频域逐点相乘 → 反变换。把同样的套路搬到图上，图卷积定义为一个"频谱滤波器" g_θ：

x * g_θ = U g_θ(Λ) Uᵀ x

其中 g_θ(Λ) 是对角矩阵，对角线是滤波器在各频率上的响应 g_θ(λ_i)。学习图卷积，就是学习这个频谱滤波器 g_θ 的形状——想保留低频、滤掉高频，就把 g_θ 在低频处置大、高频处置小。GCN 本质上就是一种特定参数化的频谱滤波器。

4. 朴素谱卷积的三大缺陷#

直接按 U g_θ(Λ) Uᵀ x 做卷积，理论漂亮但工程上寸步难行：

  1. 计算昂贵：特征分解是 O(n³)，大图（百万节点）根本算不动；
  2. 参数不共享：g_θ(Λ) 有 n 个自由参数（每个频率一个），既难学又易过拟合；
  3. 非局部：频谱滤波天然是"全局"的，一个节点要聚合所有其他节点的信息，失去局部性（而局部性恰恰是 CNN 和邻居聚合高效的关键）。

下一课会看到 Kipf & Welling 如何用切比雪夫多项式逼近，一口气解决这三个问题，把谱方法"翻译"成我们熟悉的邻居聚合形式。这正是 GCN 论文最精彩的地方。

二、可运行代码示例#

下面用 NumPy 在一条小链图上做特征分解，验证"特征值越小、特征向量越平滑"这一关键直觉，并演示一次"低通滤波"。

import numpy as np

# 1) 路径图 0-1-2-3（4 个节点）
n = 4
A = np.zeros((n, n))
for i in range(n - 1):
    A[i, i + 1] = A[i + 1, i] = 1.0

D = np.diag(A.sum(axis=1))
L = D - A
print("拉普拉斯矩阵 L：\n", L)

# 2) 特征分解（L 对称，用 eigh 得到升序特征值）
w, U = np.linalg.eigh(L)
print("特征值（升序）：", np.round(w, 3))
print("特征向量（每列是一个基函数）：\n", np.round(U, 3))

# 3) 观察：特征值越小，对应特征向量越"平滑"
#    平滑度可以用 x^T L x = Σ (x_u - x_v)^2 衡量
for i in range(n):
    vec = U[:, i]
    smoothness = vec @ L @ vec
    print(f"特征向量 u_{i}（λ={w[i]:.3f}）的平滑度 x^T L x = {smoothness:.3f}")

# 4) 图傅里叶变换：把一个图信号投影到频域
x = np.array([0.2, 0.8, 0.9, 1.5])
x_hat = U.T @ x
print("信号 x 的图傅里叶系数 x̂ =", np.round(x_hat, 3))

# 5) 低通滤波：只保留前两个（最平滑的）频率分量，再反变换
x_hat_low = x_hat.copy()
x_hat_low[2:] = 0.0                 # 砍掉高频分量
x_low = U @ x_hat_low
print("低通滤波后的信号：", np.round(x_low, 3))
print("原始信号：        ", x)

运行后你会看到：特征值从 0 递增，对应特征向量的平滑度（xᵀ L x）也严格递增——第一个特征向量（λ=0）是常数向量，平滑度为 0；最后一个振荡最剧烈。第 5 步做了个"低通滤波"，把高频分量清零后，重建的信号明显更平滑、相邻节点更接近——这正好对应下一课 GCN 的传播算子在做的事。

三、练习#

  1. 把图从"路径图"换成"4 个节点的完全图"（任意两点都相连），重新做特征分解，观察特征值分布有什么变化，并解释为什么完全图的"频谱"更退化。
  2. 手工验证 λ₁ = 0 对应的特征向量是常数向量：证明对任意图，L · 1 = 0（其中 1 是全 1 向量），说明"常数信号"永远是拉普拉斯矩阵的零特征值特征向量。
  3. 在代码里把滤波器改成高通（把前两个低频分量清零、保留高频），重建信号，观察输出信号是否更"颠簸"，并与低通结果对比。
  4. 思考：为什么谱方法里特征分解是 O(n³) 会成为瓶颈？如果图的节点数 n = 10⁶，直接做 U g_θ(Λ) Uᵀ x 在时间和内存上分别会出什么问题？
