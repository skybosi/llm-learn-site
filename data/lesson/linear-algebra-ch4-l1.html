向量空间与子空间#

前面三章我们认识了向量、矩阵和线性方程组。这一章开始，我们把视野抬高一点：不再纠结于一个个具体的向量，而是研究"由向量组成的集合"本身。为什么这件事对 AI 很重要？因为机器学习里的很多核心问题，本质上就是在问"某个东西是否落在某个空间里"——一张图片是不是某种手写数字，一个解是否真的存在。

一、概念讲解#

1. 什么是向量空间#

一个向量空间（vector space），通俗地说，就是一个"对加法和数乘都封闭"的向量集合。这里的"封闭"是指：在这个集合里随便挑两个向量相加，结果还在集合里；随便拿一个数去乘集合里的向量，结果也还在集合里。再加上"零向量也在里面"这个前提，这个集合就构成一个向量空间。

我们用最熟悉的例子理解它：全体二维实数向量构成的集合 R2（平面）就是一个向量空间。任意两个平面向量相加仍是平面向量，任意一个平面向量放大或缩小后仍在平面上，零向量也在这个平面上。

更严格地说，向量空间需要满足若干条运算规则（加法交换律、结合律、数乘分配律等），但对我们学习 AI 来说，抓住"对加法和数乘封闭 + 包含零向量"这个核心就足够了。

2. 子空间：空间里套着的小空间#

如果向量空间 V 的某个非空子集 W，它自己也是一个向量空间（对同样的加法和数乘封闭），我们就说 W 是 V 的子空间（subspace）。

判断一个子集是不是子空间，只需要检查三件事：

  1. 零向量在不在里面；
  2. 加法封闭：u,w∈W，则 u+w∈W；
  3. 数乘封闭：w∈W、c 是任意实数，则 cw∈W。

一个很直观的例子：在三维空间 R3 中，过原点的任何一条直线、任何一个平面，都是 R3 的子空间；而不过原点的直线或平面不是子空间——因为它们不包含零向量，随便一验证就会发现"数乘封闭"也保不住。

3. 两个最重要的子空间：列空间与零空间#

对一个 m×n 矩阵 A，有两个子空间在机器学习中反复出现：

  • 列空间（column space） Col(A)：A 所有列向量的所有线性组合构成的集合。它刻画了"Ax=b 什么时候有解"——b 有解当且仅当 b 落在 Col(A) 里。
  • 零空间（null space） Nul(A)：满足 Ax=0 的所有 x 的集合。它刻画了"齐次方程有多少非零解"，也就是矩阵"丢失信息"的程度。

这组概念在 AI 里很实用：比如把训练数据排成矩阵，列空间告诉这些特征到底能覆盖多大范围的输出，零空间则暗示数据里有没有冗余的、对预测无贡献的方向。

二、可运行代码示例#

import numpy as np

# ---- 例 1：验证"过原点的直线"是子空间 ----
# 在 R^3 中取过原点的直线 L = { t * v }，v = [2, 1, 3]
v = np.array([2.0, 1.0, 3.0])

u = 1.5 * v     # L 中的一个向量
w = -0.5 * v    # L 中的另一个向量

s = u + w       # 加法结果
print("u =", u)
print("w =", w)
print("u + w =", s)
print("s 与 v 的比值 =", s / v)   # 三个分量相同 → s 仍在 L 上（加法封闭）

# ---- 例 2：不过原点的直线不是子空间 ----
p = np.array([1.0, 0.0, 0.0])    # 偏移量，使直线不过原点
print("t=0 时得到", p, "而不是零向量 → 不含零向量，不是子空间")

# ---- 例 3：矩阵的列空间与零空间 ----
A = np.array([
    [1.0, 2.0],
    [3.0, 6.0],   # 第 2 行 = 第 1 行 × 3，两列线性相关
    [2.0, 4.0],
])

r = np.linalg.matrix_rank(A)
print("A 的秩 =", r)              # 1，列空间是 1 维的

# 零空间：满足 A x = 0 的所有 x（用 SVD 取最小奇异值对应的右奇异向量）
_, _, Vt = np.linalg.svd(A)
null_vec = Vt[-1]                  # 对应零奇异值 → 张成零空间
print("零空间基向量 ≈", null_vec)
print("验证 A @ null_vec ≈ 0：", A @ null_vec)

要点：例 1 中 s / v 三个分量相等，说明 s 与 v 共线，加法没有"跑出"直线，这就是加法和数乘封闭的直观体现。
