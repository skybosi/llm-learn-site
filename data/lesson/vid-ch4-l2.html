效率工程：稀疏采样、token 裁剪与合并、时序降采样、混合精度与显存优化#

这一节要解决什么#

上一节把长视频的可行性讲清了：分块、滑窗、记忆、检索，四类机制各自修一种结构性缺陷。但每一样都在花钱，而工程上真正被问到的问题是更小的一层：

给定一个必须在 X 毫秒/Y 瓦/Z 显存里跑完的视频模型，先砍哪一刀、能砍到多少、砍掉的那部分到底是什么？"更快"不是一个答案——答案是"用多少信息损失换多少倍收益"，而这两个数都必须是可算的。

这一节把六项手段逐项写成一对数：收益（显存/带宽/FLOPs 的倍数）与信息损失（一个可测量的量），并给出每一项的适用边界（一个不等式）。全部结论如下：

  1. 稀疏采样是唯一一项"超线性"的收益，也是唯一一项会改变信号本身的。 token 数按 1/s 降、KV 按 1/s 降，而注意力对数按 1/s2 降——s=8 时是 1/8、1/64、1/8（表 1）。代价是混叠：25 Hz 的轮辐在 30 fps 下就已经变成 5.000000 Hz 且方向反转；降采样到 s=8 时变成 1.250000 Hz。降采样不会让快运动变慢，它会让快运动变成另一个频率的运动。
  2. 稀疏采样的信息损失有一个与模型无关的天花板。 时间分辨率 Δ=s/f 时，长度 τ 的事件最多只能做到 IoUmax​=(τ−Δ)/(τ+Δ)；要求 ≥θ 需 s≤fτ(1−θ)/(1+θ)。θ=0.5 时就是 s≤fτ/3：τ=0.5 s 要求 s≤5，s=8 时上界只有 0.304348——纯量化就已经判死（表 1、表 4）。
  3. 裁剪买"覆盖"，合并买"分辨率"，两者不可互换。 随机裁剪保留比例 a 时，G 个有用 token 中被保留的个数服从 Bin(G,a)：a=0.5 时"保住一半证据"的概率只有 0.539795，而收益是 4 倍注意力加速（表 2）。合并 m 个 token 时收益是 1/m2，但每组损失最多 log2​m bit 身份、位置精度退化到 1/m（m=8：3 bit/组、1/8 bin、注意力省 64 倍）（表 3）。
  4. 裁剪的收益完全由注意力谱决定。 若注意力服从 Zipf(α)，保留前 10% 的 key 在 α=3 时保住 0.999961 的注意力质量，在 α=1 时只剩 0.693429（表 2）。"剪一半不掉点"这句话必须附带一张注意力质量曲线，否则不可证伪。
  5. 时序降采样同样有量化天花板，而且它比采样更常被忽略。 对特征做 stride σ 的降采样，Δ=σ/f：τ=1 s 时 σ≤10（每秒至少 3 个 bin），τ=0.2 s 时 σ≤2（表 4）。"每秒 1 个 bin 够用"只在事件长于 3 秒时成立。
  6. 混合精度的三笔账必须分开算：显存/带宽是 2× 或 4×，数值上是 u=2−(m+1)，累加上必须 fp32。 bf16 的 u=3.9062×10−3，n=106 项求和的最坏误差界是 3.9062×103（毫无意义），随机界 3.9062；fp16 在 key 数 >65504 时累加必然溢出（上限 65504）——这是长上下文默认 bf16 的直接原因。fp8 的 u=6.25×10−2 在 p=0.5 上造成 0.015625 的概率扰动（表 5）。
  7. 显存优化里只有激活重计算是零信息损失的。 每 k 层存一个检查点，激活 ∼A(L/k+k)，最优 k∗=L​，最小值 2L​A：L=28 时 10.5830A vs 28A（省 2.645751 倍），代价是算力 ×1.3333（3→4 个单位）（表 6）。它把"存下来"换成"再算一遍"，数值上除归约顺序外逐位相同。
  8. 单项收益是乘法，总收益是加法（分式）。 把四项手段依次加进一份"注意力 0.50/稠密 0.25/显存流量 0.20/固定 0.05"的时间预算：真实累计加速 3.4949×，而各因子直接连乘是 123.4192×——相差 0.028318 倍。固定开销 0.05 决定了绝对上限 20×（表 8）。

在动手之前先立规矩：任何一项效率手段都必须写成一对数 + 一个不等式。

(收益, 信息损失, 适用边界)

二、稀疏采样：唯一超线性的收益#

2.1 收益为什么是 1/s2 而不是 1/s#

设原始帧率 f，采样间隔 s（每 s 帧取一帧）。token 数与帧数成正比，所以

N(s)=sN(1)​,注意力对数=N(1)2N(s)2​=s21​,KV=s1​

表 1 的读数：

s token 比 注意力对数比 KV 比
2 0.500000 0.250000 0.500000
4 0.250000 0.062500 0.250000
8 0.125000 0.015625 0.125000
16 0.062500 0.003906 0.062500

这是全部效率手段里唯一一项在二次项上超线性的（1/s2 是二次的倒数，而裁剪/合并给的是 a2、1/m2，本质上同一件事——但只有采样同时把"输入的物理帧数"降下来，因此同时省带宽与解码）。它也是唯一一项改变了输入信号本身的手段：后面五项都是在"已经采下来的帧"上做文章，只有这一项决定"哪些帧根本没被看到"。

第 1 章的采样定理账在这一节第一次被真正用上。采样率 fs​=f/s，一个真实频率 fsig​ 的信号会被折叠到

fapp​=k∈Z≥0​min​∣fsig​−kfs​∣

而且折叠的次数 k 决定方向是否反转：k 为奇数时方向反转，k 为偶数时方向保持。表 1 用 fsig​=25 Hz 算了一遍：

注意 s=1 与 s=2 给出同一个表观频率 5.000000 Hz，但方向相反。 这是最容易骗过肉眼的一类错误：从帧序列上看"转得一样快"，但一个是正转、一个是反转，任何基于运动方向的下游任务（动作方向、手势、装配顺序）会得到系统性错误而不是随机噪声。误差是系统性的这一点很重要——它不会被平均掉。

空间混叠的对应式：图案周期 P px、速度 v px/s、采样间隔 Δt=s/f 秒，位移 vΔt>P/2 即混叠，因此

vmax​=2sfP​

P=10 px、f=30 时：s=1⇒150.000000 px/s，s=4⇒37.500000，s=8⇒18.750000 px/s。可测速度上限与 s 成反比——这是"降采样会让快速动作消失"的准确说法。

2.4 取舍/边界#

  • s 的选择是"事件时长分布"的函数，不是常数。 若任务里最短事件是 τmin​，则 s≤fτmin​/3 是硬约束；如果这个约束把 s 压到 1（不能降采样），说明任务本身与降采样不兼容，应该改去降空间分辨率或降 token 数（§3、§4）。
  • 多尺度采样是标准解法：先按 scoarse​ 粗扫定位候选区间，再在候选区间内用 s=1 细看。这把"全局 s"换成"局部 s"，代价是要多一遍粗扫（粗扫本身很便宜，因为它就是 §4 的检索式结构）。
  • 不要用"帧差很小"来论证降采样无损：混叠可以把高速运动映射成低速运动（25 Hz → 5 Hz），帧差看起来"刚好合适"，实际上信息已经被折叠掉了。

三、token 裁剪与合并：一个是"丢覆盖"，一个是"丢分辨率"#

这两项经常被合称"token 压缩"，但它们的失败模式完全不同，必须分开。

3.1 裁剪：收益 a2，损失由二项尾概率精确给出#

3.2 收益由注意力谱决定，不由"剪枝算法"决定#

上述是随机剪枝。真实剪枝是按分数剪的，于是收益取决于注意力质量的集中度。用 Zipf(α) 当模型：pi​∝i−α，保留前 a 比例的 key 能保住的注意力质量为

mass(a)=HN(α)​H⌊aN⌋(α)​​,Hn(α)​=i=1∑n​i−α

表 2 后半段（N=1024）：

1.0 0.693429 0.839731 0.907758
1.5 0.947033 0.979776 0.989858

α=3（极度集中）时保留 10% 就保住 0.999961；α=1（缓降）时保留 10% 只剩 0.693429。同一个"剪掉 90%"的动作，在两个谱上一个几乎无损、一个丢掉三成。

为什么这样设计（或者说：这条结论的用法）：因为它把"剪枝不掉点"从一句结论变成了一条可检验的预测：先测你的注意力谱（对若干层若干头拟合 α），再按上式算出保留 a 的预期质量，最后才决定剪多少。凡是没有这张曲线的剪枝报告，都无法区分"方法好"与"这个模型的注意力本来就集中"。

3.3 合并：收益 1/m2，损失是 log2​m bit 身份 + 位置精度#

把 m 个 token 压成 1 个：token 数 ×1/m、注意力 ×1/m2、KV ×1/m。

信息损失的上界：如果这 m 个 token 代表 m 个可区分实体（m 元均匀集合），合并成一个向量后最多保留 1 个身份，即每组损失

ΔI≤log2​m bit,总损失≤mN​log2​m bit

四、时序降采样：量化误差给出的 tIoU 天花板#

时序降采样（对特征沿时间轴做 stride σ 的池化/丢弃）与稀疏采样的收益结构完全一样（token ×1/σ、注意力 ×1/σ2、KV ×1/σ），唯一的差别是它发生在编码之后：已经采下来的帧仍然要过一遍骨干，所以省不掉输入带宽，只省下游的注意力与 KV。这个差别决定了选择顺序：

优先降采样输入（省骨干） ≻ 降采样特征（只省注意力）

信息损失的式子是同一个，只是 Δ=σ/f：

IoUmax​(τ,σ)=τ+σ/fτ−σ/f​,σ≤3fτ​ (θ=0.5)

取舍/边界：降采样与"下采样后做插值恢复"不是一回事。线性插值能把边界误差从 Δ 降到约 Δ/2（σ 上限放宽到 2fτ/3），代价是引入插值偏差，且插值不能恢复被混叠掉的高频。所以只有在"事件时长分布已知且下限远大于 Δ"时，插值才是免费的。

fp8 在 p=0.5 上造成 0.015625（1.56 个百分点）的概率扰动。 对"预测下一个词"这类任务，1.56 个百分点通常无所谓；但对"在 1024 个候选片段里选一个"这类任务，它已经与真实差异同阶，因为 top-1 的分界往往就落在这个量级上。所以 fp8 的适用边界是任务指标的分辨率，不是硬件的支持矩阵。

注意"相对误差"这一列是常数 3.9062×10−3——但这是相对"取值范围"的。 如果某个 channel 里有一个大值把范围撑开，其它小值的绝对误差会跟着变大而相对误差变差（因为小值的量级远小于范围）。所以 per-channel（甚至 per-token）归一化是 KV 量化的前提，而不是可选项。

激活重计算：唯一零信息损失的交换#

每 k 层存一个检查点，激活显存 ≈A(L/k+k)（检查点本身 L/k 份，重算时的峰值 ∼k 份），算力从 3 个单位（1 前向 +2 反向）涨到 4（多一次重算前向）——+33.33%。最小化

为什么它是唯一零损失的一项：它不改变任何张量的数值（除了浮点归约顺序），只改变"这些张量是活在显存里还是被重新算一次"。所以它应该排在所有有损手段之前：先把免费的 L​ 拿到手，再谈要不要剪 token。

六、收益的可算归因：Amdahl#

单项收益都是倍数，所以很容易把它们乘起来。这是错的。 把基线时间按去向拆开，设

T0​=注意力二次项0.50​​+稠密投影+MLP0.25​​+显存流量0.20​​+固定开销0.05​​

逐项施加（每一次只作用在它自己的那份上）：

0 基线 1.000000 1.0000×

真实累计 3.4949×；把各因子直接连乘是 123.4192×；两者相差 0.028318 倍。

两条必须记住的推论：

上限=ffix​1​=0.051​=20×

即使其余部分全部归零，也超不过 20×。而 ffix​=0.05 已经是很乐观的假设（长视频里 IO/解码/调度通常远大于 5%）。

为什么这样设计：因为 Amdahl 让"优化谁"变成一个可以排序的问题——当前剩余时间最大的那一项，才是下一刀的落点。表 8 里第 3 阶段之后剩余最大的已经是 0.20→0.10 的显存流量与 0.05 的固定开销，此时再剪 token 的边际收益已经很小。

练习#

  1. 采样间隔反解。 给定任务里最短事件 τmin​=0.3 s、θ=0.5，求 s 的上限；若必须用 s=4，反解"最坏情况"下仍能过 θ 的最小 τ。再设计一个两阶段采样方案（粗扫 sc​ + 细看 sf​=1），给出粗扫的召回下界公式。
  2. 混叠方向。 用 f=25 fps、fsig​=7 Hz 重算表 1 的折叠 k、表观频率与方向；说明为什么"换一个帧率"能改变方向判断（这与第 1 章"24 fps 拍 25 Hz"是同一件事的两个方向）。
  3. 剪枝与注意力谱。 用 Zipf(α) 计算 α=2、N=4096 时保留 a=0.05,0.1,0.2 的注意力质量；再算同一 a 下随机裁剪的期望质量（期望 = a），说明两者的差距随 α 如何变化。
  4. 合并损失与任务。 对 m=4,16,64 计算总身份损失 mN​log2​m（N=65536）。构造一个"损失很大但任务不受影响"的任务和一个"损失很小但任务崩掉"的任务，各写清判据。
  5. 时序降采样与插值。 在表 4 的模型下，若允许线性插值使边界误差降到 Δ/2，重算 σ 上限与 τ=0.5 s 的 IoU 表；说明插值不能修哪一类错误（提示：混叠）。
  6. 累加精度。 对 n=4096，分别用 bf16 与 fp16 算最坏界与随机界；再回答"softmax 分母用 fp16 累加、n=4096 时相对误差最坏是多少"，并判断它是否能解释"fp16 长序列训练不稳定"。
  7. 重计算的整数化与反解。 对 L=64，求 k∗ 与最优显存；列出 k=4,8,16 的实际显存与节省倍数；再反解"若显存预算只有 12A，k 最大可以取多少（或必须多小）"。
  8. Amdahl 反解。 沿用表 8 的基线分配，若只允许施加一项手段且总加速目标为 2.5×，哪一项能达到？若要求 4×，需要同时施加哪几项、并且固定开销最多能占多少？

小结#

  • 效率必须写成一对数 + 一个不等式：(收益,信息损失,边界)。缺任何一项，"优化"都无法进决策。
  • 稀疏采样是唯一超线性的收益（注意力 1/s2、KV 与 token 1/s，s=8 时 1/64 与 1/8），也是唯一改变信号的：25 Hz 在 30 fps 下就变成 5.000000 Hz 且方向反转，s=8 时变 1.250000 Hz。可测速度上限 vmax​=fP/(2s)。
  • 稀疏采样与降采样的信息损失有硬天花板：IoUmax​=(τ−Δ)/(τ+Δ)，θ=0.5 即 s≤fτ/3；s=8 时 0.5 秒事件的 IoU 上界只有 0.304348<0.5——与模型无关。
  • 裁剪丢覆盖、合并丢分辨率：裁剪收益 a2，损失由二项尾概率精确给出（a=0.5 时 Pkeep​=0.539795；要 0.99 需 a∗=0.609668，收益降到 2.6904×）；合并收益 1/m2，每组 ≤log2​m bit（m=8：3 bit、1/8 bin、注意力 64×）。
  • 剪枝收益由注意力谱决定：Zipf(α) 下保留 10% 在 α=3 保住 0.999961、在 α=1 只剩 0.693429。没有注意力质量曲线的剪枝报告不可证伪。
  • 时序降采样按 σ≤fτ/3 定：τ=1 s 时 σ≤10，即每秒 3 个 bin；优先降输入（省骨干）而非降特征（只省注意力）。
  • 混合精度分五笔账：显存/带宽 2× 或 4×；u=2−(m+1)（bf16 3.9062×10−3、fp16 4.8828×10−4、fp8 6.2500×10−2）；归约必须 fp32（n=106 时 bf16 最坏界 3.9062×103）；fp16 在 key 数 >65504 时必然溢出；fp8 在 p=0.5 造成 0.015625 的概率扰动；KV int8 必须先 per-channel 归一化。
  • 激活重计算是唯一零信息损失的交换：k∗=L​、显存 2L​A（L=28 省 2.645751 倍），算力 +33.33%；k=1 是负收益（29A）。
  • Amdahl 是总收益的判据：真实 3.4949× vs 连乘 123.4192×（差 0.028318 倍）；固定开销 0.05 决定上限 20×。下一刀要落在剩余时间最大的那一项上。
