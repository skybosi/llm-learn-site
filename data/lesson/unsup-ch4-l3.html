降维可视化#

人眼只能直接"看懂"二维或三维的图。当一份数据有几十上百个特征时，我们没法把它的结构画出来看。PCA 这时就派上了用场：把高维数据压到 2 维或 3 维，再用散点图呈现，从而"看见"高维空间里肉眼不可见的分群结构。这一课讲如何用 PCA 做降维可视化，并学会读懂主成分本身的含义，同时认清它的局限。

一、概念讲解#

1. 把高维"压扁"来看#

降维可视化的基本思路是：用 PCA 找到最能代表数据差异的前两个（或前三个）主成分，把每个样本投影成平面上的一个点。如果不同类别的样本在投影后仍能大致分开，就说明数据里确实存在可以用主成分刻画的结构；如果它们混成一团，可能意味着线性方向无法区分这些类别（这时往往要借助第 5 章的非线性方法）。

2. 怎么读主成分的含义#

每个主成分是原始特征的线性组合，组合系数就存在 components_ 里。第 i 个主成分上、第 j 个特征的系数常被称作载荷（loading）。系数绝对值越大，说明该特征对这个主成分的贡献越大；正负号表示方向（正相关还是负相关）。通过看哪些特征的载荷大，我们可以给每个主成分"起名字"，例如"这个主成分主要代表的是酒精浓度与颜色深浅的对比"。

3. 二维与三维#

降到 2 维最直观，也最常用；降到 3 维能保留更多方差，但需要交互式旋转才能看清。选择时，先看前两个主成分的累计解释方差是否够高——如果前两维加起来只有很小一部分方差，那么这张 2D 散点图可能带有误导性，要谨慎解读。

4. PCA 可视化的局限#

PCA 是线性方法，它只能沿着"直线方向"去保留方差。如果数据的真实结构是一条弯弯绕绕的流形（比如瑞士卷形状），PCA 会把它强行"压平"，可能破坏原本的局部邻接关系。这种情况下，2D 图看起来乱，不代表数据真的没有结构——这正是后面 t-SNE、UMAP 等方法登场的原因。

二、可运行代码示例#

示例 1：手写数字降到 2 维并着色#

手写数字每张是 64 维像素，直接用 PCA 压到 2 维，按真实数字着色：

from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

digits = load_digits()
X, y = digits.data, digits.target          # (1797, 64)

pca = PCA(n_components=2)
X2 = pca.fit_transform(X)

fig, ax = plt.subplots(figsize=(9, 7))
sc = ax.scatter(X2[:, 0], X2[:, 1], c=y, cmap='tab10', alpha=0.7, s=20)
ax.set_xlabel('第一主成分')
ax.set_ylabel('第二主成分')
ax.set_title('手写数字（64 维）降到 2 维后的分布')
plt.colorbar(sc, ticks=range(10), label='数字')
plt.show()

print("前两个主成分累计解释方差:", pca.explained_variance_ratio_.sum().round(3))

要点：你能看到某些数字（如 0、1、6）各自抱团，而另一些（如 4、7、9）互相交叠——这说明像素空间中这些字形本身就有一定相似性。图上聚得越开，说明这部分差异被线性主成分很好地抓住了。

示例 2：降到 3 维看立体结构#

用葡萄酒数据降成 3 维，画立体散点：

from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

X, y = load_wine(return_X_y=True)
X_scaled = StandardScaler().fit_transform(X)

pca3 = PCA(n_components=3)
X3 = pca3.fit_transform(X_scaled)

fig = plt.figure(figsize=(9, 7))
ax = fig.add_subplot(111, projection='3d')
sc = ax.scatter(X3[:, 0], X3[:, 1], X3[:, 2], c=y, cmap='viridis', alpha=0.7)
ax.set_xlabel('PC1'); ax.set_ylabel('PC2'); ax.set_zlabel('PC3')
ax.set_title('葡萄酒数据降到 3 维')
plt.colorbar(sc, label='类别')
plt.show()

print("前三个主成分累计解释方差:", pca3.explained_variance_ratio_.sum().round(3))

要点：加一维通常会保留更多方差、类别分得更开，但代价是需要在图上旋转视角才能看清。可以拖动这张图从不同角度观察三个类别的相对位置。

示例 3：用载荷解读主成分#

看看葡萄酒数据的第一个主成分主要由哪些原始特征构成：

import numpy as np
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

wine = load_wine()
X, feature_names = wine.data, wine.feature_names
X_scaled = StandardScaler().fit_transform(X)

pca = PCA(n_components=2)
pca.fit(X_scaled)

loadings = pca.components_.T          # 形状 (n_features, 2)，每行是一个特征的载荷
for pc in range(2):
    idx = np.argsort(np.abs(loadings[:, pc]))[::-1][:3]
    top = [(feature_names[i], round(loadings[i, pc], 3)) for i in idx]
    print(f"第 {pc+1} 主成分贡献最大的三个特征:", top)

要点：载荷绝对值最大的特征就是这个主成分的"主要成分"。结合业务知识，你可以给主成分起一个通俗名字，例如"酒精浓度主导的方向"，这能让降维结果更容易向别人解释。

三、练习#

  1. 二维对比：分别用 load_wine 和 load_digits 做 PCA(n_components=2) 可视化，比较两张图里"类别分离程度"的差异，并联系各自的前两维累计解释方差解释原因。
  2. 三维升级：把示例 1 的手写数字改成降到 3 维并绘制 3D 散点，看看哪些数字在第三维上分得更开了。
  3. 载荷解读：对 load_wine，分别打印第一、第二主成分贡献最大的三个特征名及其载荷，试着用一句话描述每个主成分"代表什么"。
  4. 思考：如果前两个主成分的累计解释方差只有 20%，这张 2D 散点图还值得相信吗？你会怎么办？
