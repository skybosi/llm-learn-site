对比可视化#

趋势图回答"随时间怎么变"，对比图回答的是"谁多谁少、谁高谁低"。对比是数据分析里最频繁的问题：不同产品的销量、不同地区的营收、不同方案的效率。这一课讲清楚三种对比——单组排序对比、分组对比、占比对比，各该用什么图。

一、概念讲解#

1. 单组排序对比：柱状图 / 横向条形图#

一组类别、每个类别一个数值时，用柱状图或横向条形图。类别很多、名称很长时用横向条形图（barh），并按数值排序，让大小关系一眼可见。

2. 分组对比：并排柱状图#

两组及以上类别（如"今年 vs 去年"各品类销量）需要并排分组柱状图。关键是用 x 位置偏移把各组柱子排开，并用图例区分组别。

3. 占比对比：堆叠柱状图 / 百分比堆叠#

要同时看"总量"和"构成"时，用堆叠柱状图（bottom= 参数把柱子一层层摞起来）。若要突出"构成比例"而非总量，用百分比堆叠（每根柱子高度归一化为 100%）。

二、可运行代码示例#

示例 1：分组柱状图（今年 vs 去年）#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

categories = ['Q1', 'Q2', 'Q3', 'Q4']
last_year = [80, 92, 100, 120]   # 去年各季度营收（万元）
this_year = [95, 105, 118, 150]  # 今年各季度营收（万元）

x = np.arange(len(categories))       # 类别位置 [0, 1, 2, 3]
width = 0.35                          # 每组柱子的宽度

fig, ax = plt.subplots(figsize=(8, 5))

# 两组柱子并排：去年在左（x - width/2），今年在右（x + width/2）
ax.bar(x - width / 2, last_year, width, label='去年', color='tab:gray')
ax.bar(x + width / 2, this_year, width, label='今年', color='tab:blue')

ax.set_xticks(x)                      # 把刻度放回类别正中间
ax.set_xticklabels(categories)
ax.set_ylabel('营收（万元）')
ax.set_title('各季度营收：今年 vs 去年')
ax.legend()
fig.tight_layout()
plt.show()

要点：分组柱状图的精髓是用 x - width/2 和 x + width/2 把两组柱子错开，再用 set_xticks(x) 把类别标签放回中央。柱子宽度和组间间距要协调，避免重叠或过疏。

示例 2：堆叠柱状图（看总量 + 构成）#

import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

categories = ['1 月', '2 月', '3 月', '4 月']
online = [40, 55, 60, 70]      # 线上销售额
offline = [60, 50, 65, 55]     # 线下销售额

fig, ax = plt.subplots(figsize=(8, 5))

# 先画底层（线下），再画上层（线上），bottom 指定上层从哪开始摞
ax.bar(categories, offline, label='线下', color='tab:orange')
ax.bar(categories, online, bottom=offline, label='线上', color='tab:blue')

ax.set_ylabel('销售额（万元）')
ax.set_title('线上线下销售额构成（堆叠）')
ax.legend()
fig.tight_layout()
plt.show()

要点：堆叠柱状图的 bottom=offline 表示"线上柱子的底部从线下柱子的顶部开始"。要突出构成比例时，可以把每组数值先换算成百分比再做堆叠。

示例 3：横向条形图（类别多、名称长）#

import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

# 十个城市的营收（万元），名称较长
cities = ['北京', '上海', '广州', '深圳', '杭州', '成都', '武汉', '南京', '重庆', '西安']
revenue = [98, 92, 66, 71, 55, 48, 44, 40, 38, 30]

# 按数值升序排序，让最大的一根在最上面
order = sorted(range(len(revenue)), key=lambda i: revenue[i])
sorted_cities = [cities[i] for i in order]
sorted_revenue = [revenue[i] for i in order]

fig, ax = plt.subplots(figsize=(8, 6))
ax.barh(sorted_cities, sorted_revenue, color='tab:cyan')
ax.set_xlabel('营收（万元）')
ax.set_title('十城市营收排名（横向条形图）')

# 给每根条形标数值
for i, v in enumerate(sorted_revenue):
    ax.text(v + 1, i, str(v), va='center', fontsize=10)

fig.tight_layout()
plt.show()

要点：barh 的 y 轴是类别、x 轴是数值；升序排序后最大的类别排在最上面，符合阅读习惯。va='center' 让数值标签在每根条形的垂直居中位置。

三、练习#

  1. 动手练习：用 bar 画一张"三个地区（华北/华东/华南）今年与去年销售额"的分组柱状图，三组柱子并排、用不同颜色区分年份。
  2. 百分比堆叠：把示例 2 的线上/线下销售额先各自除以当月总量、再乘 100，画成百分比堆叠柱状图，观察和"绝对量堆叠"的差异。
  3. 排序：把示例 1 的四个季度按"今年营收"降序重排，重画分组柱状图，看排序后是否更易读。
  4. 思考：什么时候堆叠柱状图会失效（例如某个月的线上/线下比例差异很大，或类别很多时）？这时该换成什么图？
