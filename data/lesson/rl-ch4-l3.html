SARSA 与 Q-learning#

前面两课都在估计状态价值 V(s)。要"选动作"还得靠动作价值 Q(s,a)。本课讲控制（control）阶段的两个核心算法：SARSA 和 Q-learning。它们长得几乎一样，只差一处"下一步取什么 Q"，但这一处差别背后是on-policy 与 off-policy 的分水岭——必须彻底讲清。

一、概念讲解#

1. 从 V 到 Q：动作价值函数#

定义 Q_π(s,a)：在状态 s 执行动作 a、之后一直按策略 π 行动，所能得到的期望回报。它满足Bellman 期望方程：

Q_π(s,a) = E[ R_{t+1} + γ Q_π(S_{t+1}, A_{t+1}) | S_t=s, A_t=a ]

其中 A_{t+1} ~ π(·|S_{t+1})。同样把期望换成采样，得到一条增量更新——这就是 SARSA：

Q(S_t,A_t) ← Q(S_t,A_t) + α [ R_{t+1} + γ Q(S_{t+1}, A_{t+1}) - Q(S_t,A_t) ]

它名字的来历正是更新用到的五元组：(S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1})，即 S-A-R-S-A。关键在于：更新里的 A_{t+1} 是智能体下一步实际要做的动作（从当前策略采样出来的）。

2. Q-learning：把"下一步"换成最优#

Q-learning 的更新只有末尾不同——它不看"下一步实际做什么"，而直接取"下一状态里价值最高的那个动作"：

Q(S_t,A_t) ← Q(S_t,A_t) + α [ R_{t+1} + γ max_a Q(S_{t+1}, a) - Q(S_t,A_t) ]

它来自 Bellman 最优方程：

Q*(s,a) = E[ R_{t+1} + γ max_{a'} Q*(S_{t+1}, a') | S_t=s, A_t=a ]

即"最优 Q 值 = 这一步奖励 + 下一状态最优 Q 值的折扣期望"。用采样逼近它，就得到 Q-learning 的 max 形式。注意：这里的 max 是直接朝最优值去够，和"下一步实际走哪个动作"无关。

3. on-policy vs off-policy：一字之差的本质#

这是 RL 里最容易混的两个词，钉死定义：

  • 行为策略（behavior policy）b：真正产生数据（与环境交互、得到 R、S'）的策略。
  • 目标策略（target policy）π：我们真正想学习、想改进的策略。

据此：

  • on-policy：行为策略 = 目标策略。学的东西 = 走的东西。SARSA 属于此类——它评估/改进的，正是那个"用 ε-greedy 在探索"的策略本身；因此 SARSA 学出来的最优是"在探索（ε）约束下"的最优，会自觉给"危险动作"留出安全余量。
  • off-policy：行为策略 ≠ 目标策略。学一套、走另一套。Q-learning 属于此类——它用 ε-greedy 的 b 采样数据，但目标 max_a Q 指向的是贪婪最优策略 π*（完全不含探索）。所以 Q-learning 学的是"纯最优"，哪怕这个最优贴着危险边缘。

一句话记忆：SARSA 是"我按自己（可能探索）的做法去学"，Q-learning 是"我按数据学、但目标永远是满分答案"。

4. 悬崖行走（Cliff Walking）：行为差异的教科书案例#

Sutton 的经典例子最能体现这一差异。4×12 网格，起点左下、终点右下，底行除两端外全是悬崖：掉下去 -100 并弹回起点，普通一步 -1。

  • Q-learning：max 让它"眼里只有最短路径"，学到贴着悬崖边缘一路冲过去（约 13 步，理论最短）。
  • SARSA：因为数据里 A_{t+1} 含 ε 概率的随机探索，靠近悬崖时"手一抖就可能掉崖"，于是它把"掉崖风险"也算进 Q 值，学到远离悬崖、多绕几步的稳妥路径（约 15 步）。

结果很有意思：若训练时 ε 固定为 0.1，SARSA 的每回合平均奖励反而更高——因为 Q-learning 的"最优路径"在探索下频繁掉崖被罚。"最优"不一定"最稳"，这正是指标（在线性能 vs 理论最优）不同的体现。

二、可运行代码示例#

手写悬崖行走，跑通 SARSA 与 Q-learning 并打印两者学到的路径。

import numpy as np

np.random.seed(0)                                # 固定随机种子，结果可复现
ROWS, COLS = 4, 12
START, GOAL = (3, 0), (3, 11)
CLIFF = [(3, c) for c in range(1, 11)]          # 底行除两端外全是悬崖
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]     # 上、下、左、右
EPSILON, ALPHA, GAMMA = 0.1, 0.1, 1.0

def step(s, a):
    r = max(0, min(ROWS - 1, s[0] + ACTIONS[a][0]))   # 越界则留在原地
    c = max(0, min(COLS - 1, s[1] + ACTIONS[a][1]))
    s_next = (r, c)
    if s_next in CLIFF:                    # 掉下悬崖：重罚并弹回起点
        return START, -100.0
    return s_next, -1.0                    # 普通一步 -1

def eps_greedy(Q, s):
    if np.random.rand() < EPSILON:
        return np.random.randint(len(ACTIONS))
    return np.argmax(Q[s[0], s[1]])

def run(agent, n_episodes=500):
    Q = np.zeros((ROWS, COLS, len(ACTIONS)))
    rewards = []
    for _ in range(n_episodes):
        s, total = START, 0.0
        a = eps_greedy(Q, s)
        while s != GOAL:
            s_next, r = step(s, a)
            total += r
            if agent == "sarsa":
                a_next = eps_greedy(Q, s_next)                    # 行为策略采样 a'
                Q[s[0], s[1], a] += ALPHA * (r + GAMMA * Q[s_next[0], s_next[1], a_next]
                                              - Q[s[0], s[1], a])
                a = a_next
            else:  # q-learning
                best = np.max(Q[s_next[0], s_next[1]])            # 目标直接取 max
                Q[s[0], s[1], a] += ALPHA * (r + GAMMA * best - Q[s[0], s[1], a])
                a = eps_greedy(Q, s_next)
            s = s_next
        rewards.append(total)
    return Q, rewards

def greedy_path(Q):
    s, path, seen = START, [START], set()
    while s != GOAL and s not in seen:
        seen.add(s)
        s, _ = step(s, np.argmax(Q[s[0], s[1]]))
        path.append(s)
    return path

Q_sarsa, r_sarsa = run("sarsa")
Q_ql, r_ql = run("q-learning")
print("SARSA     平均奖励(末100回合)：{:.1f}，步数：{}".format(np.mean(r_sarsa[-100:]), len(greedy_path(Q_sarsa)) - 1))
print("Q-learning 平均奖励(末100回合)：{:.1f}，步数：{}".format(np.mean(r_ql[-100:]), len(greedy_path(Q_ql)) - 1))
print("SARSA     贪婪路径：", greedy_path(Q_sarsa))
print("Q-learning 贪婪路径：", greedy_path(Q_ql))

要点：greedy_path 输出的是"学完后按贪婪动作走"的路径——Q-learning 是贴着底行悬崖的 13 步最短路径，SARSA 是远离悬崖、约 15 步的稳妥路径；而 平均奖励 一项，在 ε=0.1 的探索下 SARSA 明显更高（约 -23 对 -60），直观印证了"最优 ≠ 最稳"。

三、练习#

  1. 把 EPSILON 从 0.1 改成 0.0（纯贪婪）再跑，此时 Q-learning 与 SARSA 学到的路径还有差别吗？为什么？
  2. 固定 ε=0.1，把 ALPHA 调到 0.05、0.9，观察两种算法平均奖励的稳定程度，解释过大学习率导致的震荡。
  3. 把悬崖惩罚从 -100 改成 -5，观察 SARSA 是否更"敢"靠近悬崖；改成 -1000，观察 Q-learning 是否也被逼得绕远。
  4. 思考题：Q-learning 是 off-policy，它的"目标策略"是什么？"行为策略"又是什么？在更新式里，哪个量来自目标策略、哪个量来自行为策略？
