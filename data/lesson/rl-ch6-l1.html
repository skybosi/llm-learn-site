策略梯度定理#

前几章走的是"值函数"路线：先估计 Q 或 V，再从中导出（贪婪）策略。策略梯度（policy gradient）方法换一条路：把策略 π 直接参数化，沿"让期望回报变大"的方向去更新参数，一步到位地优化策略本身。本课把这条路的理论基础——策略梯度定理完整推出来，并说明它最关键的副产品：梯度里没有模型。

一、概念讲解#

1. 参数化策略与目标#

设策略是一个以 θ 为参数的函数 π(a|s; θ)，输出在状态 s 下各动作的概率（常用 softmax 对离散动作、高斯分布对连续动作）。我们希望找到让某个目标最大的 θ。最自然的目标是从初始状态出发的期望回报：

J(θ) = V^{π_θ}(s_0) = E_{π_θ}[ G_0 ]

策略梯度方法的任务，就是计算 ∇_θ J(θ)，然后做梯度上升：θ ← θ + α ∇_θ J(θ)。

2. 似然比技巧（likelihood ratio trick）#

直接对 π 求梯度不好处理，但有个恒等式能把"策略的梯度"变成"对数策略的梯度"：

∇_θ π(a|s; θ) = π(a|s; θ) · ∇_θ log π(a|s; θ)

因为 ∇log f = ∇f / f，两边乘回 f 即得。这一手看似平凡，却能把期望的梯度改写成"对当前采样动作的加权平均"的形式——权重正是 log π 的梯度，这正是所有策略梯度算法的计算核心。可以验证：对 softmax 策略 π(a|s) ∝ exp(θᵀφ(s,a))，有

∇_θ log π(a|s) = φ(s,a) - Σ_{a'} π(a'|s) φ(s,a')

即"该动作的特征，减去所有动作的平均特征"——学过分类交叉熵的同学会觉得很眼熟。

3. 策略梯度定理（完整推导）#

目标： 推出 ∇_θ J(θ) 的显式表达式。从 V^{π_θ}(s) 开始展开：

∇ V(s) = ∇ Σ_a π(a|s) Q(s,a)
       = Σ_a [ ∇π(a|s) · Q(s,a) + π(a|s) · ∇Q(s,a) ]      (乘积法则)

第一项用似然比技巧改写；第二项里出现了 ∇Q(s,a)，它是否含模型？继续展开：

Q(s,a) = Σ_{s',r} p(s',r|s,a) [ r + γ V(s') ]
∇Q(s,a) = γ Σ_{s'} p(s'|s,a) ∇V(s')

注意：p（转移概率）和 r 都不依赖 θ，所以梯度只落在 V(s') 上。于是：

∇ V(s) = Σ_a π(a|s) ∇log π(a|s) Q(s,a) + γ Σ_{s'} P(s→s') ∇V(s')

第二项是"下一状态价值的梯度"按一步转移概率的加权。把它反复代入自身（对 ∇V(s') 再展开），就得到一个从 s_0 出发、沿所有可能路径逐层展开的无穷级数。合并同类项后，每个状态 s 前面的系数，恰好是它被访问到的折扣概率 d_π(s) = Σ_{t≥0} γᵗ P(S_t = s | s_0, π)。最终得到：

∇_θ J(θ) = Σ_s d_π(s) Σ_a π(a|s) ∇_θ log π(a|s) · Q^π(s,a)
         = E_{π_θ}[ ∇_θ log π(A|S) · Q^π(S, A) ]          (S ~ d_π, A ~ π)

这就是策略梯度定理。它最了不起的一点是：最终表达式里没有任何模型量 p(s'|s,a)——转移概率在推导中互相抵消/被吸收进了采样分布 d_π。这意味着我们不需要环境模型，只需"按当前策略跑，采样出 (S, A) 并知道它们的 Q 值"，就能估计出真实梯度。

4. 定理的直觉：加权方向#

把定理读成人话：∇J(θ) 等于"对每个采样到的动作，用它的 Q 值当权重，去加权 ∇log π(a|s)"。而 ∇log π 指向"让这个动作更可能发生"的参数方向。所以整件事就是：

  • 某个动作的 Q(s,a) 高 → 给它正权重 → 更新让它的概率升；
  • Q(s,a) 低 → 负权重 → 概率降。

参数就沿着"把概率从差动作挪到好动作"的方向移动。这是策略梯度与值函数方法最本质的差别：前者直接优化概率分布，后者先找最优值再反推动作。

5. 还差最后一块：Q 从哪来#

定理给的是"如果知道 Q^π 该怎么做"，但 Q^π 本身也是未知的。围绕"如何估计定理里的 Q^π"这个缺口，分化出了整个策略梯度家族：

  • 用整条轨迹的真实回报 G_t 代替 → REINFORCE（下一课）；
  • 用一个可学习的价值函数（critic）去近似 → Actor-Critic（本课之后）；
  • 用 G_t 减一个只依赖状态的 baseline 降方差 → 进阶技巧。

这正是后面两课要填的坑。

二、可运行代码示例#

用 NumPy 验证两件事：似然比技巧的正确性，以及"沿 ∇log π 加权"确实能提升高奖励动作的概率。

import numpy as np

# softmax 策略：π(a|s) ∝ exp(θᵀφ(s,a))，features 每行是一个动作的特征向量
def softmax_policy(theta, features):
    z = np.exp(features @ theta)          # (n_actions,)
    return z / z.sum()

# 解析梯度：∇log π(a|s) = φ(s,a) - Σ_a' π(a'|s) φ(s,a')   （对每个 a 一行）
def grad_log_pi(theta, features):
    pi = softmax_policy(theta, features)  # (n_actions,)
    return features - pi @ features       # (n_actions, d)

# 数值梯度（中心差分），用来校验解析式
def numerical_grad(theta, features, a, eps=1e-6):
    g = np.zeros_like(theta)
    for i in range(len(theta)):
        tp, tm = theta.copy(), theta.copy()
        tp[i] += eps; tm[i] -= eps
        g[i] = (np.log(softmax_policy(tp, features)[a])
                - np.log(softmax_policy(tm, features)[a])) / (2 * eps)
    return g

np.random.seed(0)
d, n_actions = 3, 4
theta = np.random.randn(d)
features = np.random.randn(n_actions, d)
a = 1
print("解析 ∇log π(a|s)：", np.round(grad_log_pi(theta, features)[a], 4))
print("数值 ∇log π(a|s)：", np.round(numerical_grad(theta, features, a), 4))

# 用策略梯度上升：θ ← θ + α·r·∇log π(a|s)，观察动作 a 的概率是否上升
r, alpha = 5.0, 0.5
p_before = softmax_policy(theta, features)[a]
theta_new = theta + alpha * r * grad_log_pi(theta, features)[a]
p_after = softmax_policy(theta_new, features)[a]
print("动作 {} 的概率：{:.4f} -> {:.4f}（奖励为正，概率上升）".format(a, p_before, p_after))

要点：解析梯度与数值梯度几乎一致，验证了 ∇π = π∇log π 及 softmax 的梯度公式；最后一段演示了策略梯度上升的一步更新——正奖励的动作概率被抬升。

三、练习#

  1. 把上面的 features 换成全零矩阵（所有动作特征相同），∇log π 会变成什么样？此时策略梯度还能区分动作吗？
  2. 手工推出 softmax 策略的 ∇log π = φ(s,a) - E_{a'~π}[φ(s,a')]，并用代码在随机点上验证。
  3. 对连续动作，策略常用高斯 π(a|s) = N(μ_θ(s), σ²)。试写出 ∇log π 关于 μ 与 σ 的表达式（提示：log N 展开后分别求导）。
  4. 思考题：策略梯度定理的最终表达式里为什么没有转移概率 p(s'|s,a)？它在推导的哪一步"消失"了？
