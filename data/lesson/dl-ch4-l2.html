RNN 结构#

上一课我们学会了把序列变成张量。但普通的全连接网络和 CNN 都假设"输入之间彼此独立、且长度固定"，处理不了序列。循环神经网络（Recurrent Neural Network, RNN）正是为序列而生的：它按时间步逐个读取输入，并把"读过的内容"压缩成一个隐藏状态，一路传递下去。这一课我们拆开 RNN 的内部结构，看看这个"记忆"到底是怎么实现的。

一、概念讲解#

1. 核心思想：用循环共享权重#

RNN 最巧的地方是——它对每个时间步执行同一个运算，只是输入和上一刻的记忆在变化。用一句话概括：

每一时刻的输出，由"当前输入"和"上一时刻的隐藏状态"共同决定。

数学上，RNN 在每个时间步 t 做两件事：

hₜ = tanh(Wₓₕ · xₜ + Wₕₕ · hₜ₋₁ + bₕ)
yₜ = Wₕᵧ · hₜ + bᵧ
  • xₜ：第 t 步的输入（比如第 t 个词的词向量）；
  • hₜ：第 t 步的隐藏状态，也就是网络此刻的"记忆"；
  • Wₓₕ、Wₕₕ、Wₕᵧ：三组所有时间步共享的权重矩阵；
  • tanh：非线性激活，把状态值压到 (-1, 1) 之间。

关键在于 Wₕₕ——它负责把"上一步的记忆"带到"这一步"。因为 Wₕₕ 在每一步都复用，RNN 才能用一套参数处理任意长度的序列，参数量不会随序列变长而增长。这正是它与"为每个位置单独设参数"的全连接网络的本质区别。

2. 展开视图：一条共享权重的链#

把上面的递推公式沿时间轴"摊开"，RNN 就变成一条首尾相连的链：每一步都是同一个"细胞（cell）"，输入 xₜ 和上一步传来的 hₜ₋₁，输出 hₜ 并把它传给下一步。这条链的长度等于序列长度。

理解"共享权重"很重要：它不是"很多个不同的神经元串起来"，而是"同一个细胞被反复调用"。就像同一条流水线，原材料（输入）一个个过，机器（权重）不变，但机器内部的状态（隐藏状态）不断更新。

初始隐藏状态 h₀ 通常初始化为全零，表示"还没读到任何东西时的空白记忆"。

3. 三种经典用法#

同一个 RNN，通过"在哪些时间步取输出"，可以适配不同任务：

  • 多对一（many-to-one）：读完整条序列，只在最后一步输出一个结果。典型任务：文本分类、情感分析（读完整句话，判断是好评还是差评）。
  • 一对多（one-to-many）：给一个初始输入，然后连续输出一个序列。典型任务：图像描述、音乐生成（给一张图，逐词输出一句描述）。
  • 多对多（many-to-many）：每读一步就输出一步。又分两类：输入输出等长（序列标注，如给每个词标词性）和不等长（机器翻译，如英文逐词进去、中文逐词出来，属于 encoder-decoder）。

4. 一个具体算例的直觉#

假设我们要判断"这个电影很好看"是正面还是负面（多对一）。RNN 逐词读入"这个 / 电影 / 很 / 好看"，隐藏状态一路更新：

  • 读到"这个"：状态里有了"在说某样东西"；
  • 读到"好看"：状态被强烈更新为"正面情绪"；
  • 读完最后一步，把最终的 h₄ 接一个全连接层 + softmax，输出"正面"的概率。

你能看出，RNN 不需要一次性看到整句话——它是边读边更新记忆，最后用记忆做判断。这也意味着，越靠后的词对最终状态影响越大，这是它的特点，也是它的短板（后面讲）。

二、可运行代码示例#

PyTorch 里 torch.nn.RNN 已经帮你封装好了整条循环链。下面我们既用封装好的 nn.RNN，也手动写一个单步的 RNNCell 递推，验证两者结果一致——亲手看清"记忆是怎么一步步传下去的"。

import torch
import torch.nn as nn

# 参数设定
batch, seq_len, input_size, hidden_size = 2, 5, 4, 3

# 造一个随机输入：形状 (seq_len, batch, input_size)
x = torch.randn(seq_len, batch, input_size)

# 初始隐藏状态 h0：全零，形状 (1, batch, hidden_size)
# 1 表示 1 层 RNN
h0 = torch.zeros(1, batch, hidden_size)

# —— 方式一：用封装好的 nn.RNN ——
rnn = nn.RNN(input_size=input_size, hidden_size=hidden_size, num_layers=1)
output, hn = rnn(x, h0)
print("nn.RNN 输出形状：", output.shape)   # (seq_len, batch, hidden_size)
print("nn.RNN 最终隐藏状态形状：", hn.shape)  # (1, batch, hidden_size)

# —— 方式二：手动用 RNNCell 逐步递推，验证公式 h_t = tanh(W_ih x + W_hh h + b) ——
cell = nn.RNNCell(input_size=input_size, hidden_size=hidden_size)
# 手动把 nn.RNN 的权重复制给 cell，保证两者参数一致
cell.weight_ih.data = rnn.weight_ih_l0.data
cell.weight_hh.data = rnn.weight_hh_l0.data
cell.bias_ih.data = rnn.bias_ih_l0.data
cell.bias_hh.data = rnn.bias_hh_l0.data

h = h0[0]                 # 取出第 0 层的初始状态，形状 (batch, hidden_size)
manual_outputs = []
for t in range(seq_len):
    h = cell(x[t], h)     # 输入当前步 x[t] 和上一步状态 h，得到新状态
    manual_outputs.append(h)

manual_output = torch.stack(manual_outputs, dim=0)   # 拼回 (seq_len, batch, hidden_size)
print("两种方式的输出是否一致：", torch.allclose(output, manual_output, atol=1e-6))

# —— 观察：最后一步的输出等于最终的隐藏状态（单层且无额外变换时）——
print("output 最后一步 == hn[0]：", torch.allclose(output[-1], hn[0], atol=1e-6))

运行后，两个 allclose 都会打印 True。这说明 nn.RNN 内部干的事，就是循环调用同一个 cell，把隐藏状态一步步往后传。以后堆多层、换 LSTM/GRU，都只是这个"细胞"和"记忆传递方式"的变化。

三、练习#

  1. 把 hidden_size 从 3 改成 6，观察输出形状怎么变；再把 num_layers 改成 2，观察 output 和 hn 的形状分别变成什么。
  2. 解释：为什么 hn 的形状是 (num_layers, batch, hidden_size)，而 output 是 (seq_len, batch, hidden_size)？两者各自保存了什么信息？
  3. 手动实现一个多对一的文本分类小模型：用 nn.RNN 读入序列，只取 output[-1]（最后一步），接一个 nn.Linear 做二分类，打印模型结构。
  4. 思考：如果把初始隐藏状态 h0 换成随机值而不是全零，训练时会发生什么？这提示我们在 batch 之间应该怎样处理隐藏状态？
