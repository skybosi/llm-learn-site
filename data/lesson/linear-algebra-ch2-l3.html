转置与逆矩阵#

这一课学习矩阵的两个"变形与逆操作"：转置（transpose） 和逆矩阵（inverse）。转置几乎天天在代码里出现（让两个矩阵形状"对上"），逆矩阵则是"解方程"和"求解析解"的关键工具，在最小二乘、线性回归的正规方程里直接登场。

一、概念讲解#

1. 转置：行变列、列变行#

把矩阵 A 的行和列互换，得到的新矩阵叫 A 的转置，记作 Aᵀ（读作"A 转置"）。

A = [ 1  2  3 ]       Aᵀ = [ 1  4 ]
    [ 4  5  6 ]            [ 2  5 ]
                           [ 3  6 ]

A 是 2×3，转置后 Aᵀ 就是 3×2。规律：Aᵀ 的第 i 行第 j 列元素，等于 A 的第 j 行第 i 列元素。

转置的用途非常实际——调整形状让乘法成立：

  • 向量 x 默认是行向量（形状 (n,)），要参与 xᵀ · x（求平方和）或 Xᵀ · X（正规方程里的关键项）时，往往需要先转置或 reshape。
  • 深度学习里，反向传播（backpropagation）大量使用 Wᵀ，把误差从后一层"传回"前一层。

2. 逆矩阵：乘法的"撤销键"#

普通数字里，3 × (1/3) = 1，1/3 是 3 的"倒数"。矩阵也有类似概念：对于方阵 A（行数=列数），如果存在另一个方阵 A⁻¹，使得

A · A⁻¹ = A⁻¹ · A = I

其中 I 是单位矩阵（对角线上全 1、其余全 0），那么 A⁻¹ 就叫 A 的逆矩阵。它相当于"撤销" A 的作用。

不是所有方阵都有逆矩阵：

  • 有逆矩阵的方阵叫可逆或非奇异；
  • 没有逆矩阵的方阵叫不可逆或奇异，它的行列式（一个标量指标）为 0。

可以直觉地理解：如果矩阵 A 把两个不同的向量"压缩"成了同一个向量（丢失了信息），那么这个变换就无法撤销，A 也就不可逆。

3. 机器学习中的应用：正规方程#

线性回归可以直接求"解析解"，公式是：

w = (Xᵀ X)⁻¹ Xᵀ y

其中 X 是特征矩阵、y 是真实标签向量、w 是要求的权重向量。这个式子叫正规方程（normal equation），它同时用到了转置和逆矩阵。虽然现代深度学习更常用梯度下降，但理解正规方程能帮你把"矩阵运算"和"机器学习求解"串起来。

4. 逆矩阵的几个性质#

  • (A·B)⁻¹ = B⁻¹ · A⁻¹（注意顺序反转）；
  • (A⁻¹)⁻¹ = A；
  • (Aᵀ)⁻¹ = (A⁻¹)ᵀ；
  • 单位矩阵的逆是它自己。

二、可运行示例#

下面用 NumPy 演示转置、逆矩阵，并用正规方程解一个线性回归问题。

import numpy as np

# 1) 转置：.T 属性
A = np.array([
    [1, 2, 3],
    [4, 5, 6],
])
print("A =")
print(A)
print("A 的形状 =", A.shape)          # (2, 3)
print("A 的转置 A.T =")
print(A.T)
print("A.T 的形状 =", A.T.shape)      # (3, 2)

# 2) 逆矩阵：np.linalg.inv（只对方阵有效）
M = np.array([
    [4, 7],
    [2, 6],
])
M_inv = np.linalg.inv(M)
print("M 的逆矩阵 M_inv =")
print(M_inv)
# 验证：M @ M_inv 应等于单位矩阵
print("M @ M_inv =")
print(M @ M_inv)

# 3) 正规方程解线性回归：w = (Xᵀ X)⁻¹ Xᵀ y
# 已知 3 条样本：y = 2*面积 + 1（近似线性关系），求解权重 w
X = np.array([
    [1, 80],    # 每行：截距项 1 和特征"面积"
    [1, 100],
    [1, 120],
])
y = np.array([170, 210, 250])   # 对应的房价

# 按公式分步计算
w = np.linalg.inv(X.T @ X) @ X.T @ y
print("正规方程求得的权重 w =", w)   # 应接近 [10, 2]（截距≈10，斜率≈2）

预期输出（大意）：

A =
[[1 2 3]
 [4 5 6]]
A 的形状 = (2, 3)
A 的转置 A.T =
[[1 4]
 [2 5]
 [3 6]]
A.T 的形状 = (3, 2)
M 的逆矩阵 M_inv =
[[ 0.6 -0.7]
 [-0.2  0.4]]
M @ M_inv =
[[1. 0.]
 [0. 1.]]
正规方程求得的权重 w = [10.  2.]

要点：.T 是转置最简洁的写法；np.linalg.inv 只能对可逆方阵用，遇到奇异矩阵会报错；正规方程里 X.T @ X 得到的是一个方阵，这正是"必须可逆"才能求 (Xᵀ X)⁻¹ 的原因——实际中常用 np.linalg.solve 直接解，避免显式求逆。

三、练习#

  1. 手动写出 [[1,2,3],[4,5,6]] 的转置，再用 .T 验证。
  2. 用 np.linalg.inv 求 [[3,1],[1,2]] 的逆，并验证 M @ M_inv 是单位矩阵。
  3. 把示例中的样本数据换成你自己的三组"面积→房价"数据，用正规方程求出权重，并预测一套 110 平方米房子的房价。
  4. 思考：为什么"显式求逆"在数据量很大时不如 np.linalg.solve 高效？查一查相关资料，用一句话回答。
