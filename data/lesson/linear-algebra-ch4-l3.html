秩与线性相关性#

一个矩阵到底"装了多少独立的信息"？这是本章收尾要回答的问题，答案是：秩（rank）。秩是一把尺子，量出矩阵的列（或行）里有多少个真正线性无关的方向，也直接决定了线性方程组的解是唯一、无穷多还是不存在。在 AI 里，秩还是"低秩近似""数据压缩"这些概念的地基。

一、概念讲解#

1. 线性相关的严格说法#

一组向量 {v1​,…,vk​} 线性相关，是指存在不全为零的系数使

c1​v1​+⋯+ck​vk​=0

成立。反之，只有当所有系数都必须为零时该等式才成立，就称它们线性无关。直观讲：线性无关的一组向量，谁也不能被"别人"拼出来，每个都贡献了一个全新的方向。

2. 秩的定义#

矩阵的秩，定义为它的列空间维数，也就是线性无关的列向量的最大个数。一个重要的结论是：列秩 = 行秩——"按列数"和"按行数"得到的独立方向个数总是相等的。所以秩也常被说成"矩阵中线性无关的行或列的最大个数"。

对 m×n 的矩阵 A，秩满足 0≤rank(A)≤min(m,n)。当 rank(A)=min(m,n) 时，称矩阵满秩（full rank），意味着它把信息"装得最满"。

3. 秩与线性方程组的解#

秩直接回答了 Ax=b 的解的形态（这里以方阵为例最直观）：

  • 满秩 → 系数矩阵可逆 → 唯一解；
  • 秩亏（不满秩）→ 要么无解（b 不在列空间内），要么无穷多解（零空间非平凡）。

更一般地，秩-零度定理（rank-nullity theorem）给出了一个漂亮的关系：

rank(A)+dimNul(A)=n

意思是：矩阵把 n 维输入"用掉了"秩那么多维度的信息，剩下的 n−rank 维就是被"压成零"的方向（零空间）。这解释了为什么不满秩的矩阵会丢失信息。

4. 秩在 AI 里的意义#

  • 数据冗余检测：特征矩阵的秩远小于特征数，说明大量特征是重复的，可以降维。
  • 低秩近似：真实数据（图像、评分表）往往"近似低秩"，用较少的秩去逼近它，就是后面 SVD 的核心思想。
  • 推荐系统：用户-物品评分矩阵常被假设为低秩，隐含"少数几个偏好维度就能解释大部分评分"。

二、可运行代码示例#

import numpy as np

# ---- 例 1：观察线性相关列与秩 ----
A = np.array([
    [1.0, 2.0, 3.0],
    [2.0, 4.0, 6.0],   # 第 2 列 = 第 1 列 × 2，相关
    [1.0, 1.0, 1.0],
])
print("A 的秩 =", np.linalg.matrix_rank(A))   # 2（只有 2 个独立方向）

# ---- 例 2：用秩判断方程组的解 ----
B = np.array([[2.0, 1.0],
              [1.0, 3.0]])
print("B 秩 =", np.linalg.matrix_rank(B), "（满秩 → 唯一解）")
x = np.linalg.solve(B, np.array([4.0, 5.0]))
print("唯一解 x =", x)

C = np.array([[1.0, 2.0],
              [2.0, 4.0]])   # 秩亏：第 2 行 = 第 1 行 × 2
print("C 秩 =", np.linalg.matrix_rank(C), "（秩亏 → 唯一性被破坏）")

# ---- 例 3：秩越低，越容易被低秩近似（为 SVD 铺路） ----
np.random.seed(0)
U_true = np.random.randn(6, 2)
V_true = np.random.randn(2, 4)
M = U_true @ V_true + 0.01 * np.random.randn(6, 4)   # 秩 2 结构 + 小噪声
print("M 的数值秩 =", np.linalg.matrix_rank(M))

U, s, Vt = np.linalg.svd(M)
M2 = U[:, :2] @ np.diag(s[:2]) @ Vt[:2, :]           # 只保留前 2 个方向
print("秩 2 近似的误差 =", np.linalg.norm(M - M2))    # 误差很小

要点：例 3 中矩阵 M 本质只有 2 个独立方向，用前 2 个奇异值重构几乎无损——这就是"低秩近似"：用更少的参数还原主要信息。
