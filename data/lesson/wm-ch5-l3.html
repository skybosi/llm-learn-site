分层与想象：长时任务里的子目标、选项与误差预算#

这一节要解决什么#

上一节给出了最优视界公式 H⋆=min{Hϵ​, M/(cd)}。现在让它面对一个尴尬的事实：真实任务往往比 Hϵ​ 长。

本课的任务就是最小的一种：9×9 的两个房间，中间一堵墙只有一扇门。起点全在左房间，目标在右房间的角落，从起点到目标的真实最短路约 13∼20 步。而第 2 节告诉我们，模型的可信视界大致是十几步——你需要的视界和你敢用的视界几乎一样长。

这一节要回答三件事：

  1. 当"看得更远"不是选项时，Agent 该怎么办？
  2. 分层的那一层"粗尺度想象"到底在算什么、代价是多少？
  3. 想象的时间尺度（选项长度 D）与低层视界 h，预算该怎么分？

① 分层买到的不是"更强的模型"，而是"更短的必要视界"。 本课表 A：平铺规划需要每次做 16 次想象（h=16）才能达到 100% 成功率，h≤6 时是 0.0%、h=8 时 10.0%；而"低层 h=3 + 粗尺度子目标"用同样的 100% 完成任务，平均步数 15.7（平铺 15.6）。把"必须看 16 步"变成"只看 3 步"。 ② 粗尺度想象是另一笔账，而且它比细尺度想象便宜。 表 A 的两行按代码结构折算：平铺 h=16 每次决策 16×292=4672 次模型查询；分层 h=3 是 876 次 + 一次性 5329 次几何检查 + 每步 73 次候选扫描——整段 16 步的总账约 2.1×104 vs 7.5×104，约 3.6 倍便宜。 ③ 分配规则是两条不等式，而且第二条是硬约束。 表 C 的实测格点给出：低层视界必须能"看穿"选项长度，h≳D−1（D=2 时 h≥1；D=4 时 h≥3；D=6 时 h≥5）；同时选项长度不能超过模型可信视界 D≲Hϵ​——一旦模型出错（表 B/C 的"幻门"），最优 D 立刻收缩到 2。

一、为什么"看得更远"不是解法#

先把问题摆正。这个任务的信息结构是拓扑性的：在左房间里，无论朝哪个方向走，"离目标的曼哈顿距离"这个信号都会把你带到墙上——目标在墙的另一侧，而在墙附近局部信号是平的。

平铺 Agent 的实现方式很朴素：每次决策时在模型上做 h 次 Bellman 更新，得到 h 步截断的最短代价 Vh​(⋅→目标)，然后按它贪心走一步、再重算。h 就是"每次做几次想象"。

平铺：Vh​ h 次 Bellman ​目标,每步重算，走 argamin​EP​[Vh​].

实测（表 A）：h=2,3,4,6 全部 0.0%；h=8 是 10.0%；h=12 是 93.3%；h≥16 才是 100%。

为什么门槛正好在 12∼16：Bellman 更新每一步只把信息往外推一格。起点到门的距离约 4∼8 步，门到目标约 8∼10 步，所以只有当 h 超过整条路径的长度，"目标"这条路的信息才会传到起点附近。h 小于它时，Vh​ 在所有候选动作上都是同一个大常数（"看不到目标"），argmin 就退化成任意选择。

这就是长时任务的本质困难：需要的视界等于任务长度，而模型的可信视界（第 2 节）通常小于它。把 h 开大到 16 不是"更努力"，而是把一个已经被误差污染的量当成决策依据。

一个必须说清的边界：本课的任务只有 73 个状态，所以"全收敛值迭代"是可行的，它也正是表 B 里那行 平铺 h=200（100% 成功）。换句话说，在一个小状态空间里，"无限视界规划"是分层的最强对照组。分层的价值出现在全收敛不可行的时候：状态连续/高维、或者每次决策的时间预算只够做几次想象。本课后面所有对照都建立在这个前提下——我们比较的是"有限想象预算怎么花"，不是"要不要做全局规划"。

二、分层：粗尺度想象 + 短视界执行#

分层的结构与上一节的闭环完全兼容，只是把"想象"拆成两层、放在两个时间尺度上：

粗尺度（每 K_hi 步或子目标达成时执行一次）
  ① 从模型里读出"哪些格子是墙"：四个动作都走不动的格子 → 墙
  ② 在"模型认为可走"的格子上建粗图：两点有边 ⟺ 曼哈顿距离 ≤ D 且折线通畅
  ③ 在这张小图上做最短路（跳数）→ 每个格子的粗代价 V_hi
  ④ 选子目标 g = argmin_g [ 曼哈顿距离(s,g) + D · V_hi(g) ]，要求 V_hi(g) < V_hi(s)（严格下坡）

细尺度（每一步执行）
  ⑤ 在模型上做 h 次 Bellman 更新得到 V_h(·→g)，按它贪心走一步
  ⑥ 若 |s−g| 已达成或超过期限 D+2+grace 仍未到达 → 丢弃 g（失败剪枝），回到 ①

三个部件各自对应一个明确的问题：

部件 回答什么问题 代价 出错时会发生什么
墙图（①） 哪些地方过不去 从模型的 P 直接读，O(S⋅A) 幻门/丢门 → 全局路线错（表 B）
粗图 + 最短路（②③） 长程上"该往哪个方向" O(∣W∣2) 次几何检查，每回合一次 粗代价排序错 → 子目标选错
低层截断值（⑤） 眼前这几步怎么走 O(h⋅S⋅A) 每步 执行抖动、撞墙
失败剪枝（⑥） 子目标到不了怎么办 一个期限计数器 没有它，幻门会把 Agent 永久卡住（表 B）

为什么这样设计是对的：长程决策需要的"视野"其实是一个拓扑量（往哪个方向、要不要绕），而短程决策需要的是几何量（这几步怎么落脚）。把两者放在同一层，就等于要求"精细的执行"也具备"全局的视野"——这正是平铺方案被迫把 h 开到 16 的原因。

实测（表 A 下半）：

方法 成功率 平均步数
分层，低层 h=3，选项长度 D=2 100.0% 15.7
分层，低层 h=3，D=3 100.0% 15.7
分层，低层 h=3，D=4 80.0% 27.0
分层，低层 h=3，D=6 63.3% 38.6
平铺 h=16（对照） 100.0% 15.6

同样的成绩，h 从 16 降到 3。 而 D 太大反而变差——理由见第四节。

2.1 想象账本#

分层不是免费的。把两层的模型查询次数都算出来（S=81、∣W∣=73）：

做法 每次决策的模型查询 一段 16 步回合的总量
平铺 h=16 16×S×4=4672 4672×16≈7.5×104
分层 h=3 3×S×4=876，加每步 73 次候选扫描 (876+73)×16+732≈2.1×104

约 3.6 倍便宜，而且这个比值随任务长度增长（平铺的成本是 O(h⋅T)，分层的粗尺度部分是一次性的 O(∣W∣2)）。

可复用判据：判断"该不该分层"，看这两件事——①任务长度是否超过模型可信视界（Tpath​>Hϵ​）；②粗尺度结构是否可枚举（是否存在一张远小于状态空间的"路标/子目标"图）。两个都是"是"，分层就是划算的；只有 ① 成立而 ② 不成立（例如精细操作里的连续位姿），需要的是别的抽象方式，不是本文这套。

三、误差预算怎么分：h≳D−1 与 D≲Hϵ​#

表 C 是本节的核心交付：在"模型正确"与"模型有 20% 幻门"两种情形下，扫描（选项长度 D，低层视界 h）。

模型正确时：

D\h h=1 h=2 h=3 h=5 h=8
2 100.0% 100.0% 100.0% 100.0% 100.0%
3 36.7% 100.0% 100.0% 100.0% 86.7%
4 26.7% 30.0% 86.7% 86.7% 73.3%
6 3.3% 16.7% 73.3% 90.0% 93.3%

模型有 20% 幻门时：

D\h h=1 h=2 h=3 h=5 h=8
2 53.3% 53.3% 53.3% 53.3% 53.3%
3 16.7% 53.3% 53.3% 53.3% 43.3%
4 23.3% 20.0% 46.7% 46.7% 50.0%
6 0.0% 6.7% 23.3% 53.3% 53.3%

两条规则直接从格点里读出来：

规则一（时间尺度匹配）：h≳D−1。 模型正确时，D=2 在 h=1 就能工作；D=3 需要 h≥2；D=4 需要 h≥3；D=6 需要 h≥5。原因：低层的 Vh​ 每做一次 Bellman 更新才把子目标的信息往外推一格，而低层需要在整个选项跨度上都有梯度。选项长度 D 超过 h+1 时，低层在选项的后半段是"盲走"。

规则二（可信性约束）：D≲Hϵ​。 幻门出现后，D=2 的那一行完全不随 h 变化（53.3% 横穿整行），而 D=6 一行从 0.0% 爬升到 53.3%，D=3 在 h≥2 时也稳定在 53.3%。含义：粗尺度模型一旦错了，加多少细尺度算力都补不回来——细尺度能修正"怎么走"，修正不了"往哪走"。D 越小，粗尺度错误的影响半径越小，失败剪枝能救回的比例越高。

可复用判据：两层预算的分配写成三条不等式，全部可用一次小规模扫描标定： h ≥ D−1（低层要能看穿选项）,D ≤ Hϵ​ （选项不能超过模型可信视界）,N⋅h ≤ M （延迟预算）. 第一条决定下层，第二条决定上层，第三条把两者绑在同一个预算里。当模型质量下降时，先缩 D（而不是先加 h）：表 C 里 D=2 那一行是全表唯一在两种模型下都稳定可用的配置。

四、粗尺度模型比细尺度模型更容易错#

这是一个容易被忽略的结构性事实：粗尺度模型是对细尺度模型的抽象，而抽象会引入细尺度上没有的误差。

本课的抽象是"墙图"：它把动力学的连续细节压成"这里能不能过去"的 0/1 判断。抽象带来的典型错误有两类：

  • 幻门（把墙看成通道）：于是粗图里出现捷径，Agent 朝一堵墙走过去；
  • 丢门（把通道看成墙）：于是粗图里没有路，Agent 直接放弃。

表 B 注入的是幻门，而且刻意挑"看起来更近"的那半堵墙（下方几格），使幻门路线在模型里严格优于真门路线。注入方式是把洞口两侧的转移都改成确定性的直通——注入到动力学模型本身，因此平铺与分层看到的是同一个错模型：

幻门比例 eps 平铺 h=200（全收敛） 平铺 h=4 分层 D=2 分层 D=4 分层 D=6
0.0 100.0% 0.0% 100.0% 90.0% 66.7%
0.1 100.0% 0.0% 100.0% 90.0% 66.7%
0.2 20.0% 0.0% 53.3% 46.7% 16.7%
0.4 20.0% 0.0% 53.3% 53.3% 16.7%
0.6 20.0% 0.0% 53.3% 53.3% 16.7%

四条读法：

  1. 全收敛的平铺规划最脆：eps 从 0.1 到 0.2 就掉了 80 个百分点（100%→20%）。因为它把整条路线一次性押在幻门上，一旦撞墙，值函数仍然告诉它"往那边走"——它没有任何机制发现这个计划是错的。
  2. 分层靠"失败剪枝"救回一半（53.3%）。机制：低层在期限（D+2+4 步）内没到达子目标，就把该子目标加入黑名单，高层改选下一个下坡候选。这是一条纯粹工程性的补救，但它把"永久卡死"变成了"多花几步"。
  3. D 越小越能救：D=2 的 53.3%、D=6 的 16.7%。因为小选项让"错误的影响半径"只有 2 格，剪枝能快速穷尽幻门附近的候选；D=6 的选项一次押注六个格，剪枝的代价太大。
  4. 它救不回来全部：53.3% 意味着近一半的起点仍然失败。原因是幻门路线在粗图里严格更短，剪掉一个子目标后，剩下的下坡候选仍是同一条幻门路线上的格子，剪枝需要"烧掉"很多步预算。这是分层 + 失败检测的能力上界，不是参数没调好。

可复用判据：如果你的系统里有"粗尺度抽象"（地图、路标、技能/选项、子任务），请务必做到两件事——①抽象层必须带失败检测与剪枝（否则错误不可恢复）；②抽象的具体程度要有旋钮（本课的 D），并且在模型质量下降时能自动调小。第 4 节会从另一个角度给出同一结论：粗尺度模型一旦错，误差会沿着规划器诱导分布被系统性放大。

五、高层多久重想一次#

Khi​ 是"高层多久重选子目标"。它与第 2 节的 R 是同一类旋钮，但作用在不同的时间尺度上。

Khi​ eps=0 成功率 / 平均步数 eps=0.2 成功率 / 平均步数
1（每步重想） 86.7% / 23.0 46.7% / 40.2
2 96.7% / 17.3 60.0% / 33.4
4 96.7% / 17.9 60.0% / 34.0
8 96.7% / 18.4 60.0% / 34.6
16 96.7% / 19.0 60.0% / 34.8

Khi​=1 反而更差（86.7% vs 96.7%；46.7% vs 60.0%），而且平均步数多 5∼7 步。原因和高层的"下坡规则"有关：子目标集合本身包含当前格附近的所有下坡候选，每步重选会让子目标在几个相邻候选之间抖动，低层的 Vh​(⋅→g) 跟着换，动作变得不连贯。

Khi​ 从 2 到 16 几乎是平的（96.7%，步数只涨 1.7）。这说明高层决策的时间尺度不敏感——只要别每步重想。这与低层 h 的敏感形成了对照：粗糙的决策可以慢慢改，精细的执行必须每步对齐。

可复用判据：把重规划频率与抽象层级绑定——越抽象的决定，重想得越慢（本课 Khi​≥2；极端是"一个选项执行完再重选"）。如果发现高层决策抖动，先增加 Khi​ 或给子目标加迟滞，而不是去调低层的 h。

六、取舍与边界#

你的处境 建议 依据
任务长度 > 模型可信视界 引入分层：粗尺度子目标 + 短视界执行 表 A：h 从 16 降到 3 保住 100%
低层总是"盲走"、到不了子目标 增大 h（至少 h≥D−1）或缩短 D 表 C 规则一
粗尺度模型不可信（幻门/丢门） 缩短 D，并必须加失败剪枝与黑名单 表 B/C 规则二
高层子目标抖动 增大 Khi​ 或加迟滞 表 D：Khi​=1 反而更差
想象预算被粗尺度吃掉 粗尺度只算一次、只在状态变化大时重算 §2.1 账本：粗尺度是一次性 O(∣W∣2)

三条边界：

  1. 分层的收益以"存在可枚举的粗结构"为前提。 本课的门、房间是几何上自然的路标；换到精细操作或连续位姿任务，粗结构需要自己学出来（这正是 options / skill discovery 的问题），代价与风险都更高。
  2. 失败剪枝是必要条件，不是充分条件。 表 B 里它只救回 53.3%；要救回更多，需要更强的机制（例如把"可疑通道"显式标成需要验证的假设，用真实交互去验证一次——这就回到主动探索的范畴）。
  3. "h≳D−1"与"D≲Hϵ​"是经验不等式，常数来自本课的离散网格与 1 步/格的信息传播速度。连续状态下的对应形式需要重新标定，但两条不等式的结构（下层要够深、上层要够短）是通用的。

代码：平铺 vs 分层，以及想象预算的两层分配#

下面的代码不调用任何 API，只依赖 numpy。它构造一个 9×9 的双房间网格（第 4 列是墙，只有 (4,4) 是门），用 6000 条随机游走数据学一个计数模型，然后比较：

  • 表 A：平铺规划（每次做 h 次 Bellman 更新）vs 分层（粗尺度子目标 + 低层 h）；
  • 表 B：模型"幻门"比例 eps 下的鲁棒性，对照组含"全收敛平铺"（h=200）；
  • 表 C：(D,h) 网格，两种模型质量下各自的最优区域；
  • 表 D：高层重想间隔 Khi​ 的影响。

一个必须点明的实现细节：horizon_value 必须从 +∞ 初始化、每次更新 V←min(V,1+mina​EP​[V])。如果图省事从"到目标的曼哈顿距离"这种上界出发做 min 迭代，整个值函数会塌到 0（本课在调试时真踩了这个坑：V 全为 0，于是 Agent 永远执行第 0 号动作）。最短路的 Bellman 迭代只能从 ∞ 出发。

每一处注释写的是设计决策，不是实现细节。

⚠️ 环境与全部数据为本代码合成，不代表任何真实环境。

"""WM ch5-l3 演示：分层与想象 —— 短视界 + 粗尺度子目标 vs 长视界平铺规划
9x9 双房间网格（中间一堵墙，只有一个门）与全部数据为合成（⚠️ 不代表任何真实环境），只依赖 numpy。
"""
import numpy as np

N, GAMMA = 9, 0.95
S = N * N
WALL = np.zeros(S, bool)
for r in range(N):
    for c in range(N):
        if c == 4 and r != 4:
            WALL[r * N + c] = True
FREE = np.array([s for s in range(S) if not WALL[s]])
GOAL = 8 * N + 8
LEFT = np.array([s for s in FREE if s % N <= 3])
MOVES = np.array([-N, N, -1, 1])
T_EP, DOOR = 60, 4 * N + 4


def step_env(s, a, r):
    """真值动力学：90% 按意图走，10% 打滑到垂直方向；撞墙或出界则原地不动。"""
    a = a if r.random() < 0.9 else ((a + 1) % 4 if r.random() < 0.5 else (a + 3) % 4)
    t = s + MOVES[a]
    if t < 0 or t >= S or abs(t % N - s % N) > 1 or WALL[t]:
        return s
    return t


def dist_to(g):
    return (np.abs(np.arange(S) // N - g // N) + np.abs(np.arange(S) % N - g % N)).astype(float)


def collect(n, r):
    """随机游走采数据（不用任何策略先验），用于学一个转移模型。"""
    D, s = [], int(r.choice(LEFT))
    while len(D) < n:
        a = int(r.integers(0, 4)); s2 = step_env(s, a, r); D.append((s, a, s2)); s = s2
    return np.array(D, dtype=int)


def learn_model(D):
    """计数 + 「原地不动」保守先验：零样本的 (s,a) 认为走不动。"""
    Nc = np.zeros((S, 4, S)); cnt = np.zeros((S, 4))
    for s, a, s2 in D:
        Nc[s, a, s2] += 1; cnt[s, a] += 1
    prior = np.zeros((S, 4, S))
    prior[np.arange(S)[:, None], np.arange(4)[None, :], np.arange(S)[:, None]] = 0.1
    return (Nc + prior) / (cnt[..., None] + 0.1)


def corrupt(P, eps, r):
    """把 eps 比例的墙格改成「可以穿过去」的通道 —— 注入到动力学模型本身，两个 Agent 都会看到。"""
    Pc = P.copy(); walls = np.array([w for w in np.where(WALL)[0] if w // N > 4])   # 只腐蚀「绕过去更近」的那半堵墙
    k = int(round(eps * len(walls)))
    for s_ in (r.choice(walls, size=k, replace=False) if k else []):
        for a in range(4):
            t = int(s_ + MOVES[a])
            if 0 <= t < S and abs(t % N - s_ % N) <= 1 and not WALL[t]:
                Pc[s_, a, :] = 0.0; Pc[s_, a, t] = 1.0      # 模型以为这堵墙有个洞
                Pc[t, a ^ 1, :] = 0.0; Pc[t, a ^ 1, s_] = 1.0   # 反向也要通，否则洞进不去
    return Pc


def wall_map_of(P, eps=0.0, r=None):
    """从模型读出「哪些格是墙」：四个动作都走不动 → 墙。再按 eps 注入幻门（粗尺度模型出错）。"""
    wm = (P[np.arange(S)[:, None], np.arange(4)[None, :], np.arange(S)[:, None]] > 0.5).all(1)
    if eps > 0:
        idx = np.where(wm)[0]
        k = int(round(eps * len(idx)))
        if k:
            for s in r.choice(idx, size=k, replace=False):
                wm[s] = False
    return wm


def horizon_value(P, g, sweeps, BIG=1e6):
    """模型上的 h 步截断最短代价：g 处为 0，其余初始为 ∞，做 h 次 Bellman 更新。
    ⚠️ 这里必须从 ∞ 出发 —— 从「曼哈顿距离」这种上界出发做 min 迭代会塌到 0（见正文）。"""
    V = np.full(S, BIG); V[g] = 0.0
    for _ in range(sweeps):
        V = np.minimum(V, 1.0 + np.einsum('sap,p->sa', P, V).min(1))
    return V


def flat_episode(P, s0, h, r, T=T_EP):
    """平铺 Agent：每走一步都重做 h 次想象，按 V_h(·→GOAL) 贪心。"""
    s = int(s0)
    for t in range(T):
        if s == GOAL:
            return t
        V = horizon_value(P, GOAL, h)
        s = step_env(s, int(np.argmin(np.einsum('ap,p->a', P[s], V))), r)
    return T


def los_clear(i, j, wm):
    """在「模型认为的墙」下，i→j 的折线（先竖后横）是否通畅。"""
    r0, c0, r1, c1 = i // N, i % N, j // N, j % N
    for k in range(1, max(abs(r1 - r0), abs(c1 - c0))):
        rr = r0 + int(np.sign(r1 - r0)) * min(k, abs(r1 - r0))
        cc = c0 + int(np.sign(c1 - c0)) * min(k, abs(c1 - c0))
        if wm[rr * N + cc]:
            return False
    return True


def abstract_vh(wm, D_):
    """粗尺度图：节点=模型认为可走的格；两点有边当且仅当曼哈顿距离 ≤ D_ 且折线通畅。
    值 = 跳数（每跳最多 D_ 格）→ 高层用它做长程判断，代价只有 |W|² 次几何检查。"""
    F = np.array([s for s in range(S) if not wm[s]])
    n = len(F); Vh = np.full(n, 1e9); pos = {int(s): i for i, s in enumerate(F)}
    Vh[pos[GOAL]] = 0
    nbr = [[] for _ in range(n)]
    for i in range(n):
        for j in range(i + 1, n):
            if abs(int(F[i]) // N - int(F[j]) // N) + abs(int(F[i]) % N - int(F[j]) % N) <= D_ \
               and los_clear(int(F[i]), int(F[j]), wm):
                nbr[i].append(j); nbr[j].append(i)
    for _ in range(n):
        upd = False
        for i in range(n):
            for j in nbr[i]:
                if Vh[j] + 1 < Vh[i]:
                    Vh[i] = Vh[j] + 1; upd = True
        if not upd:
            break
    return F, pos, Vh


def hier_episode(P, s0, h, D_, wm, K_hi=1, r=None, T=T_EP, grace=4):
    """分层 Agent：高层在粗尺度图上选子目标（长程、便宜），低层用 h 步截断值执行（短程、精确）。"""
    F, pos, Vh = abstract_vh(wm, D_)
    s = int(s0); sub, sub_age, sub_t0 = None, 10 ** 9, 0; banned = set()
    for t in range(T):
        if s == GOAL:
            return t
        if sub is None or s == sub or sub_age >= K_hi:
            cand = [int(g) for g in F if int(g) != s and int(g) not in banned
                    and Vh[pos[int(g)]] < Vh[pos[s]]                      # 必须在粗尺度上严格下坡
                    and abs(int(g) // N - s // N) + abs(int(g) % N - s % N) <= D_
                    and los_clear(s, int(g), wm)]
            if not cand:
                banned.clear()
                cand = [int(g) for g in F if Vh[pos[int(g)]] < Vh[pos[s]]] or [GOAL]
            sub = min(cand, key=lambda g: (abs(g // N - s // N) + abs(g % N - s % N) + D_ * Vh[pos[g]],
                                           -(abs(g // N - s // N) + abs(g % N - s % N))))
            sub_age = 0; sub_t0 = t
        V = horizon_value(P, sub, h)
        s = step_env(s, int(np.argmin(np.einsum('ap,p->a', P[s], V))), r)
        sub_age += 1
        if t - sub_t0 > D_ + 2 + grace and s != sub:      # 选项失败检测 → 剪枝
            banned.add(sub); sub = None
    return T

这段代码想让你看到的五件事：

  1. 平铺的必要视界等于任务长度。 表 A：h≤6 时 0.0%，h=8 时 10.0%，h=12 时 93.3%，h≥16 才 100%。这不是模型不好，是"信息每步只能推一格"。
  2. 分层把必要视界从 16 降到 3，成绩完全一样（100%、平均 15.7 步 vs 15.6 步）。
  3. 选项长度与低层视界必须匹配：h≥D−1（表 C 左上角的空白与右下角的 h≥5 一起给出这条规则）；模型出错时唯一稳的配置是 D=2（整行 53.3% 不随 h 变）。
  4. 粗尺度错误无法靠细尺度算力弥补。 表 B：全收敛平铺从 100% 掉到 20.0%，分层 D=2 靠失败剪枝保住 53.3%，而纯加 h 对 D=6 那一列没有任何用处（16.7%）。
  5. 高层决策的时间尺度不敏感，但不能每步重想。 表 D：Khi​=1 反而更差（86.7% / 46.7%），Khi​≥2 后基本平坦。

⚠️ 诚实说明这个实验的边界：状态空间只有 73 格，所以"全收敛值迭代"这个对照组是可行的——分层在这里是为了演示机制，不是因为 73 个状态管不过来。真实的高维/连续任务里，粗尺度结构通常不能像本课的"墙图"那样直接从模型读出，而要额外学习；此时本课的两条不等式仍然成立，但标定常数与失败模式都会变。另外，"幻门"是人为注入的抽象层错误（注入到动力学模型本身），它模拟的是"模型对某处通行性判断错误"这一类系统性偏差，不是随机噪声。

  1. 标定两条不等式。 在表 C 的框架下，把门下移到不同位置（例如 (6,4)）、把房间改成 3 个，重跑 (D,h) 网格。给出 h≥D−1 这条规则的常数如何随几何变化，并解释原因。
  2. 把"丢门"补上。 表 B 只注入了幻门。请注入"丢门"（真通道被看成墙），重跑表 B。说明两种错误对平铺/分层的杀伤方式为何不同，以及失败剪枝在哪种下失效。
  3. 粗尺度多便宜才算便宜。 §2.1 的账本按"模型查询次数"计。请改成真实延迟（包含建图与最短路的耗时），说明在什么规模下粗尺度的 O(∣W∣2) 会重新变成瓶颈，以及那时该怎么做。
  4. 让 D 自适应。 设计一个在线方案：用失败剪枝的触发率作为信号，自动调小 D。给出更新规则、迟滞与恢复条件（注意：D 缩了之后要好回去，否则会永久保守）。

小结#

  • 长时任务的核心矛盾：需要的视界等于任务长度，而模型的可信视界通常更短。把 h 开大不是解法——表 A 里 h≤6 时 0.0% 成功率，正是因为"看不到目标"时值函数在所有动作上都是同一个大常数。
  • 分层的机制是"换时间尺度"，不是"更强的模型"：粗尺度（墙图 + 路标图最短路）决定往哪走，细尺度（h 次 Bellman 更新）决定这几步怎么走。同样的 100% 成绩，h 从 16 降到 3，总模型查询约便宜 3.6 倍。
  • 两层预算由三条不等式约束：h≥D−1（低层要能看穿选项）、D≤Hϵ​（选项不能超过模型可信视界，Hϵ​ 来自第 2 节的判据）、N⋅h≤M（延迟预算）。
  • 粗尺度模型更容易错，而且错了就补不回来：表 B 全收敛平铺从 100% 掉到 20.0%；分层 D=2 靠失败剪枝保住 53.3%；加 h 对 D=6 完全没有作用（16.7%）。
  • 失败剪枝是必要条件：没有它，Agent 会永久卡在幻门前；有了它，D=2 那一行在全表两种模型下都稳定可用（53.3% 横穿）。
  • 高层重想的频率不敏感，但不能每步重想：Khi​=1 反而更差（86.7% vs 96.7%），Khi​≥2 后基本平坦。
  • 下一节回到误差本身：这一节反复出现"模型错了会怎样"，但一直没有正面回答"怎么知道它错了"。下一节给出可检测的信号与工程缓解清单——包括一条反直觉的实测：搜索得越狠，越会精确地撞上模型的正向误差。
