似然视角与采样#

上一课把生成模型分成了三大家族。这一课深入两个贯穿所有生成模型的通用语言：似然视角（怎么训练、怎么给数据打分）和采样视角（怎么从学到的分布里"抽"出新样本）。搞懂这两个视角——尤其最大似然、KL 散度、ELBO、重参数化技巧这四个工具——扩散模型的训练目标和采样循环你就能一眼看懂，因为它们全是这套语言的延续。

一、概念讲解#

1. 似然视角：训练生成模型 = 最大化数据概率#

生成模型的基本训练原则是最大似然估计（MLE）：给一批真实数据 {x_i}，找一个参数 θ 使这批数据"出现得最可能"：

θ* = argmax_θ  ∏_i P_θ(x_i)   ⟺   θ* = argmax_θ  Σ_i log P_θ(x_i)

取对数是为了三件事：乘积变求和（数值更稳）、凸性更好优化、与 KL 散度挂钩。最后这一点最关键：

(1/N) Σ_i log P_θ(x_i)  =  - KL( P_data ‖ P_θ ) + const

也就是说，最大化对数似然，等价于最小化真实数据分布与模型分布之间的 KL 散度。这是似然视角的"世界观"：把"模型分布尽量贴合数据分布"这个模糊目标，翻译成了可优化、可微的数值。

2. 两个拦路虎：归一化常数与边际积分#

直接最大化 log P_θ(x) 会遇到两个难题：

  • 配分函数难算：能量模型里 P_θ(x) = exp(-E_θ(x)) / Z_θ，分母 Z_θ = ∫ exp(-E_θ(x)) dx 是归一化常数，高维下无法求。这就是能量模型、玻尔兹曼机长期难以训练的原因。
  • 隐变量难积分：VAE 里 P_θ(x) = ∫ P_θ(x|z) P(z) dz，要对隐变量 z 做全空间积分，同样不可解。

3. 变分下界 ELBO：用"近似后验"绕开积分#

VAE 的对策是引入一个变分分布 q(z|x) 去近似真实后验 P(z|x)，再对 log P(x) 做一个巧妙的分解：

log P(x) = E_{q(z|x)}[ log P(x) ]                     # log P(x) 与 z 无关，可放进期望
         = E_q[ log P(x, z) - log P(z|x) ]
         = E_q[ log P(x, z) - log q(z|x) ] + KL( q(z|x) ‖ P(z|x) )
         =     ELBO(θ, φ)                          + KL( q ‖ P(z|x) )

因为 KL 散度恒非负，所以 log P(x) ≥ ELBO。证据（evidence）的下界由此得名。再展开 ELBO：

ELBO = E_{q(z|x)}[ log P_θ(x|z) ] - KL( q_φ(z|x) ‖ P(z) )
        └── 重构项：逼生成器还原 x ──┘   └── 正则项：逼 z 靠近先验 ──┘

最大化 ELBO 时：重构项让"编码—解码"能还原数据，正则项让编码器输出别乱跑、贴近标准正态先验。当 q(z|x) 恰好等于真实后验时 KL 项归零，ELBO 精确等于 log P(x)——这是下界"紧"的时刻。

4. 采样视角：从分布里"抽"样本，且要可导#

训练得到分布之后，怎么采样？如果模型是"高斯+变换"结构，最优雅的做法是重参数化技巧（reparameterization trick）。普通采样 z ~ N(μ, σ²) 是随机操作，梯度流不回 μ、σ；重参数化把它拆成"确定性变换 + 固定噪声"：

z = μ + σ · ε,   ε ~ N(0, I)

ε 是标准正态噪声、与参数无关，于是梯度能顺畅地流回 μ 和 σ，采样动作变得可微。这是 VAE 能被端到端训练的技术关键，也是扩散模型"加噪/去噪"里反复出现的手势。

5. 两个视角的分工#

把两个视角合起来看，生成模型的"标准套路"是：

  1. 训练阶段用似然视角：最大化 ELBO 或精确似然（或隐式地做对抗），让分布贴合数据；
  2. 生成阶段用采样视角：从易采样的基分布（如标准正态）抽 ε，再过网络变换成样本；
  3. 评价阶段又回到似然视角：用对数似然、FID、Inception Score 等度量生成质量。

扩散模型会把这个套路发挥到极致：它的前向过程是"把数据一步步变噪声"（重参数化的叠加），反向过程是"一步步把噪声变回数据"（可微采样），训练目标则是"让去噪网络最大化变分下界"。下一课先补上"为什么需要生成模型"的动机，随后就进入扩散模型正文。

二、可运行代码示例#

先看似然视角的最小实现：用 MLE 从样本估计高斯分布的均值和方差，并算出对数似然。

import torch

torch.manual_seed(0)
true_mu, true_sigma = 3.0, 2.0
data = torch.normal(true_mu, true_sigma, (10000,))   # 从真实分布采样

# —— MLE 估计：高斯均值和方差的闭式解 ——
mu_hat = data.mean()                        # 均值估计 = 样本均值
var_hat = data.var(unbiased=False)          # MLE 方差 = 除以 N（无偏则除以 N-1）
sigma_hat = var_hat.sqrt()

print(f"真实参数: mu={true_mu}, sigma={true_sigma}")
print(f"MLE 估计: mu={mu_hat:.3f}, sigma={sigma_hat:.3f}")

# —— 对数似然：MLE 真正在最大化的目标 ——
log_p = -0.5 * (torch.log(2 * torch.pi * var_hat) + (data - mu_hat) ** 2 / var_hat)
print(f"平均对数似然: {log_p.mean():.3f}")

再看采样视角 + 重参数化技巧：如何让"从高斯采样"这件事可导。

import torch

# —— 编码器输出均值和对数方差（真实场景由网络预测） ——
mu = torch.tensor([0.0], requires_grad=True)
log_var = torch.tensor([0.0], requires_grad=True)

# —— 普通采样：随机操作，梯度流不回 mu/log_var ——
z_naive = torch.normal(mu, (0.5 * log_var).exp())

# —— 重参数化：确定性变换 + 固定噪声，梯度可回传 ——
eps = torch.randn_like(mu)                  # 从标准正态采样，与参数无关
z = mu + eps * (0.5 * log_var).exp()        # z ~ N(mu, sigma^2)，且对 mu/log_var 可导

# 验证梯度能流回参数
z.sum().backward()
print(f"d z / d mu   = {mu.grad.item():.3f}")         # 应为 1
print(f"d z / d log_var = {log_var.grad.item():.3f}") # 非零：说明 sigma 参与计算

运行后注意 mu.grad 恰好等于 1、log_var.grad 非零——这证明重参数化后的采样确实对分布参数可导。而 z_naive 那条路，梯度会被 torch.normal 这个随机节点"截断"。这十几行代码，就是 VAE 和扩散模型能够被梯度下降训练的技术根基。

三、练习#

  1. 把 MLE 代码里的样本量从 10000 改成 10、100、1000，观察估计的 mu_hat 随样本量如何波动，体会"最大似然估计的一致性"。
  2. 把 var_hat 换成 data.var(unbiased=True)，说明无偏方差与 MLE 方差差在哪（除以 N-1 vs N），哪个才是"最大化对数似然"的闭式解。
  3. 手推 log P(x) = ELBO + KL(q(z|x)‖P(z|x)) 这行分解，写清每一步用到了什么（期望定义、对数性质、KL 定义），并说明为什么 KL 项恒非负。
  4. 在重参数化代码里把 z 的表达式改成 z = mu + eps * (0.5*log_var).exp() * 0，观察 log_var.grad 是否变成 0，解释其含义（σ=0 时对数方差不参与采样）。
  5. 思考题：为什么"训练用似然、生成用采样、评价又回到似然"这个循环里，最难的一环往往是"采样要可导"？想想 GAN 为什么可以绕开它、扩散模型又为什么必须正面解决它。
