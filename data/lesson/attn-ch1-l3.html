注意力权重#

打分函数给出了一串"谁相关"的原始分数，但分数还不能直接拿来加权——它可能是负数、可能之和不为 1，不构成一个"关注比例"。这一课完成注意力的最后一步：把打分 softmax 归一化成权重，再用权重对 Value 加权求和，得到上下文向量。我们还会讨论温度、掩码，以及"软注意力 vs 硬注意力"的区别。

一、概念讲解#

1. 从分数到权重：softmax 归一化#

打分得到的分数 scores 只是相对大小，不满足权重的基本要求。注意力权重应当满足两条：

  1. 非负：关注比例不能是负数；
  2. 和为 1：所有位置的关注加在一起等于 100%，这样才能解释成"注意力分布"。

softmax 恰好同时满足这两点：

α_i = exp(score_i) / Σ_j exp(score_j)

于是 α_i ∈ [0, 1] 且 Σ α_i = 1。分数越高，α 越大；但所有位置的 α 共享同一个归一化分母，彼此"此消彼长"——这就是注意力的竞争本质：对某个位置的关注增加，必然挤占对其它位置的关注。

2. 加权求和：Value 的"软混合"#

有了权重，上下文向量就是对 Value 做加权平均：

context = Σ_i α_i · v_i

这里的 Value v_i 是每个位置真正承载的内容。注意一个容易混淆的点：打分用到的是 Key，加权用到的却是 Value。Key 决定"我该看谁"（权重从 Key 与 Query 的比对而来），Value 决定"看到了之后取什么"。二者在一般注意力里是两套向量，各自独立。

3. 温度：控制权重的"软硬"#

在 softmax 里引入温度参数 T：

α_i = exp(score_i / T) / Σ_j exp(score_j / T)
  • T 越小，分布越"尖锐"，几乎把全部权重压给最高分，趋近于硬注意力（只挑一个位置）；
  • T 越大，分布越"平坦"，各位置权重趋同，接近"平均池化"。

温度是调试注意力的一个旋钮：训练早期可以用较高温度让模型多看几个候选，后期降温聚焦。

4. 掩码：屏蔽不该看的位置#

真实的序列是变长的，<pad> 位置本身没有信息，不应被关注；解码器生成时也不能偷看未来的词。这两类"不该看"的位置，用掩码处理：把它们的分数置为 -inf，softmax 后这些位置的权重就变成精确的 0，其余位置重新归一化。这是注意力在实践中几乎必配的一步。

5. 软注意力 vs 硬注意力#

  • 软注意力（soft attention）：权重是连续的、处处可导，整个"打分→归一化→加权"都可微，能端到端反向传播。我们（以及 Transformer）用的都是它。
  • 硬注意力（hard attention）：直接抽一个位置（如 argmax 或采样），只看它。好处是省计算，坏处是不可微，训练要用强化学习或 Gumbel-Softmax 之类的技巧，麻烦得多。

因此实际系统几乎清一色软注意力，硬注意力更多出现在"需要显式选择"的少数场景。

二、可运行代码示例#

下面把上一课的打分接到 softmax 与加权求和，串成一次完整的注意力前向，并演示温度与掩码对权重的影响。

import torch
import torch.nn.functional as F

torch.manual_seed(0)

d = 8
q = torch.randn(d)                       # 查询
keys = torch.randn(4, d)                 # 4 个键
values = torch.randn(4, d)               # 4 个值

# 1) 打分（缩放点积）
scores = keys @ q / (d ** 0.5)

# 2) softmax 归一化：非负、和为 1
weights = F.softmax(scores, dim=0)
print("注意力权重:", weights)
print("权重之和:", weights.sum().item())   # 应为 1.0

# 3) 加权求和：Value 按权重混合成 context
context = (weights.unsqueeze(1) * values).sum(dim=0)
print("上下文向量形状:", context.shape)    # (d,)

# 4) 温度：T 越小越"硬"，越大越"平"
for T in [0.5, 1.0, 2.0]:
    w = F.softmax(scores / T, dim=0)
    print(f"温度 {T} 的权重:", w)

# 5) 掩码：屏蔽第 3 个位置（索引 2），softmax 后它权重为 0
mask = torch.tensor([True, True, False, True])
masked_scores = scores.masked_fill(~mask, float("-inf"))
masked_weights = F.softmax(masked_scores, dim=0)
print("掩码后权重（第 3 项应为 0）:", masked_weights)
print("掩码后权重之和:", masked_weights.sum().item())   # 仍为 1.0

运行后重点观察：

  • weights 全部非负、之和为 1，是一个标准的概率分布；
  • 温度 0.5 时最大值被放大、最小值被压得更小，2.0 时各权重明显"拉平"；
  • 掩码把被屏蔽项的权重精确归 0，其余三项重新归一化，之和仍是 1。

这三条正是"注意力权重"的核心性质，也是你在后面所有代码里会反复看到的行为。

三、练习#

  1. 把 values 改成和 keys 完全相同（values = keys），重跑一遍，体会"Key 负责算权重、Value 负责被加权"这层分工在代码里是如何体现的。
  2. 手动构造一个极端分数，比如 scores = torch.tensor([100.0, 1.0, 1.0, 1.0])，观察 softmax 后的分布；再除以一个大温度试试，理解"高分被饱和"的现象。
  3. 用 torch.multinomial 按 weights 做一次采样（重复 1000 次），统计各位置被选中的频率，比较它与 weights 是否接近，从而理解"权重"也可以解释成"被选中的概率"。
  4. 思考：掩码用 -inf 而非一个很大的负数（如 -1e9）有什么好处？如果分数本身可能超过 1e9 的量级，用固定负数会出什么问题？
