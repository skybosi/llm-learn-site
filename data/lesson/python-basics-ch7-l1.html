文件读写#

程序运行的时候，变量都保存在内存里。可只要程序一结束，这些数据就消失了。想要让数据"留下来"，下次再打开程序还能用，就要把它们写到文件里。这一课我们学习 Python 里最基础、也最常用的一类操作：把文件读进来、把内容写出去。

一、概念讲解#

1. 为什么需要文件#

  • 保存用户的成绩、订单、配置、日志等信息；
  • 读取别人准备好的数据（比如一份 CSV 表格）；
  • 在不同程序之间交换数据。

文件本质上就是磁盘上的一串字节。Python 用一套统一的接口来读写它们，无论文件是文本还是图片，思路都一样。

2. 打开文件的三个步骤#

读写文件的标准流程是固定的三步：

  1. 打开文件，拿到一个"文件对象"；
  2. 通过文件对象读或写；
  3. 关闭文件，释放系统资源。

对应到 Python，最常用的函数是内置的 open()。

3. open() 函数与打开模式#

open() 的基本用法是：

文件对象 = open("文件路径", "模式", encoding="编码")
  • 第一个参数是文件路径，例如 "data.txt"；
  • 第二个参数是打开模式，告诉 Python 你想读还是想写；
  • 第三个参数 encoding 指定字符编码，处理中文文本时强烈建议写上 encoding="utf-8"，否则在部分系统上可能乱码。

常用的模式：

模式 含义 文件不存在时
"r" 只读（默认） 报错
"w" 只写，会覆盖原有内容 自动创建
"a" 追加，在末尾继续写 自动创建
"x" 新建并写入，文件已存在则报错 报错

还有两个可以附加的字母："b" 表示二进制模式（如图片），"+" 表示同时读写。例如 "rb" 就是"以二进制方式只读"。

4. 读取文件#

打开文件后，有三种常见的读取方式：

  • read()：一次性把整个文件内容读成一个字符串；
  • readline()：每次读一行；
  • readlines()：把每一行读成一个字符串，放进一个列表返回。

5. 写入文件#

  • write(字符串)：把一段字符串写入文件；
  • writelines(列表)：把列表里的多个字符串依次写入。

需要留意：write() 不会自动帮你在末尾加换行符，需要换行时记得自己在字符串里加上 "\n"。

6. 别忘了关闭文件#

用完文件要调用 close()。如果不关闭，一方面占用系统资源，另一方面写入的内容可能还没真正落到磁盘上。下一课我们会学习 with 语句，它可以帮我们自动关闭文件，更省心。

二、可运行代码示例#

示例 1：写入并再次读取#

# 1. 用 "w" 模式打开（或创建）文件，注意 encoding 指定 utf-8
f = open("diary.txt", "w", encoding="utf-8")

# 2. 写入两行内容，换行符 \n 需要自己加
f.write("今天学会了文件读写\n")
f.write("明天继续加油\n")

# 3. 关闭文件，确保内容真正保存
f.close()

# 4. 再用 "r" 模式打开同一个文件，把内容读出来
f = open("diary.txt", "r", encoding="utf-8")
content = f.read()          # 一次性读出全部内容
print(content)
f.close()

运行后控制台会打印：

今天学会了文件读写
明天继续加油

示例 2：逐行读取#

f = open("diary.txt", "r", encoding="utf-8")

# 用 for 循环直接遍历文件对象，每次拿到一行（包含末尾的换行符）
for line in f:
    # strip() 去掉行首行尾的空白字符（包括换行符）
    print("这一行是：", line.strip())

f.close()

示例 3：追加内容#

# "a" 模式不会覆盖原来的内容，而是在末尾接着写
f = open("diary.txt", "a", encoding="utf-8")
f.write("追加的一行：今天也进步了一点\n")
f.close()

# 读出来验证一下
f = open("diary.txt", "r", encoding="utf-8")
print(f.read())
f.close()

三、练习#

  1. 写一个程序，让用户输入三句喜欢的话，把它们保存到 favorite.txt 文件里，每句占一行。
  2. 重新打开 favorite.txt，用 readlines() 读出来，统计一共有多少行，并打印出每一行。
  3. 尝试分别用 "w" 和 "a" 模式往同一个文件写两句话，观察最终文件里是"只有最后一次写的内容"还是"两次写的内容都在"，并解释原因。
