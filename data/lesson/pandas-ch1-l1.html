Series 创建#

一、概念讲解#

NumPy 的 ndarray 是一个"只有位置、没有名字"的数组，访问第 3 个元素只能用数字下标 arr[2]。但在真实数据分析里，一列数据往往天然带有标签：销售数据带月份、成绩带学生姓名、股价带交易日。Pandas 的 Series 就是为解决这个问题而设计的：它是一维的带标签数组（labeled array），每个元素既可以通过位置找到，也可以通过标签找到。

一个 Series 包含三个核心组成部分：

  1. values：存放数据的一维数组，底层就是 NumPy 的 ndarray。
  2. index：索引标签序列。默认是 0, 1, 2, ... 的整数位置，但你可以把它换成月份、姓名等任何有意义的标签。
  3. name 与 dtype：name 是这一列数据的名字（相当于表格里的"列名"），dtype 描述存储的数值类型。

可以这样理解：Series 把 NumPy 数组的"无标签值"升级成了"带标签的值"，从而让"按名字取数"成为可能。这是从数组思维迈向表格思维的第一步。

创建 Series 最常见的来源有四种：

  • 列表 / 元组：pd.Series([1, 2, 3])，最直接的写法。
  • 字典：pd.Series({"a": 1, "b": 2})，字典的键自动成为索引。
  • NumPy 数组：pd.Series(np.array([...]))，复用已有的数值计算成果。
  • 标量：pd.Series(5, index=["x", "y"])，同一个值广播到所有标签，常用于初始化占位。

无论哪种方式，都可以通过 index= 显式指定标签，通过 dtype= 指定类型，通过 name= 给这一列起名。

二、可运行代码示例#

import pandas as pd
import numpy as np

# 1. 从列表创建，索引默认为 0,1,2...
s1 = pd.Series([12, 8, 15, 20])
print("默认整数索引：\n", s1)

# 2. 指定自定义标签索引：把水果名作为索引
prices = pd.Series(
    [12.5, 8.0, 15.3],
    index=["苹果", "香蕉", "橙子"],
    name="水果价格",
)
print("\n带标签与名字的 Series：\n", prices)

# 3. 从字典创建：键自动成为索引
sales = {"一月": 120, "二月": 95, "三月": 140}
s_sales = pd.Series(sales)
print("\n从字典创建：\n", s_sales)

# 4. 从 NumPy 数组创建，并指定标签和类型
arr = np.array([1.0, 2.0, 3.0])
s_arr = pd.Series(arr, index=["a", "b", "c"], dtype="float64")
print("\n从 ndarray 创建：\n", s_arr)

# 5. 从标量创建：一个值广播到所有标签
s_scalar = pd.Series(5, index=["x", "y", "z"])
print("\n标量广播：\n", s_scalar)

# 6. 查看一个 Series 的核心属性
print("\n索引 index：", prices.index)
print("值 values：", prices.values)
print("类型 dtype：", prices.dtype)
print("名字 name：", prices.name)

运行后你会看到：字典的键、index= 传入的标签，最终都变成了 Series 左侧那一列标签；而 values 仍然是熟悉的 NumPy 数组。

三、练习#

  1. 用列表 [31, 28, 31, 30] 创建一个 Series，索引设为 ["一月", "二月", "三月", "四月"]，并给这一列命名为 "天数"，打印它的 index 和 name。
  2. 用字典 {"北京": 2189, "上海": 2487, "广州": 1867} 创建 Series，观察字典键是否变成了索引；再用 index= 传入一个更长的标签列表 ["北京", "上海", "广州", "深圳"]，看看缺失标签的位置会出现什么。
  3. 思考题：Series 与一维 NumPy 数组相比，多出来的"标签索引"在真实表格数据中有什么实际意义？（提示：想想按学生姓名查成绩，而不是按第几行查成绩。）
