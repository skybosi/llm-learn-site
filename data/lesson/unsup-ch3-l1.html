DBSCAN 密度聚类原理#

一、概念讲解#

1.1 从"距离"到"密度"的视角转变#

K-means 和层次聚类（尤其是 Ward 准则）有一个共同的隐含假设：簇大致是球形、大小相近的。一旦数据里出现月牙形、环形，或者大小悬殊、彼此缠绕的簇，它们就很容易出错。

DBSCAN（Density-Based Spatial Clustering of Applications with Noise）换了一个完全不同的视角：不假设簇的形状，而是看"哪里样本密集、哪里稀疏"。它的基本信念是——一个簇，就是被低密度区域隔开的一片高密度区域。密度高的地方连成一片，就是一个簇；密度低、孤零零的点，就是噪声。正因为这个视角，DBSCAN 能发现任意形状的簇，并且天然具备识别离群点的能力。

1.2 两个核心参数与三类点#

DBSCAN 的整个算法只由两个参数驱动：

  • eps（ε）：邻域半径。以某个样本为圆心、半径 ε 的圆形区域就是它的"邻域"。
  • min_samples：一个样本要成为"核心点"，其 ε 邻域内至少要有多少个样本（通常含自身）。

基于这两个参数，DBSCAN 把所有样本分成三类：

  1. 核心点（core point）：ε 邻域内样本数 ≥ min_samples 的点。它是"密度中心"，周围足够热闹。
  2. 边界点（border point）：本身不是核心点（邻域内样本数不足），但它落在某个核心点的 ε 邻域内。它属于某个簇，但位于簇的边缘。
  3. 噪声点（noise point）：既不是核心点，也不在任何核心点的邻域内。它不属于任何簇，被标记为离群点（sklearn 里标签为 -1）。

1.3 密度可达与簇的定义#

有了核心点，DBSCAN 通过三个递进的概念来"生长"出簇：

  • 直接密度可达（directly density-reachable）：若点 q 落在核心点 p 的 ε 邻域内，则称 q 从 p 直接密度可达。
  • 密度可达（density-reachable）：若存在一串点 p1​,p2​,…,pm​，其中 p1​=p、pm​=q，且每个 pi+1​ 都从 pi​ 直接密度可达，则称 q 从 p 密度可达。可以理解为"从核心点出发，一步步沿着密集区域能走到 q"。
  • 密度相连（density-connected）：若存在点 o，使 p 和 q 都从 o 密度可达，则称 p 与 q 密度相连。

一个簇，就是所有"密度相连"的点的最大集合。噪声点不与任何点密度相连，所以自成一体地被排除在外。这套定义的精妙之处在于：它不要求簇内任意两点都互相很近，只要求"能通过一串密集的点连起来"，因此月牙、环形这类形状也能被完整地识别成一个簇。

1.4 算法步骤#

DBSCAN 的整体流程如下：

  1. 遍历所有样本，根据 eps 和 min_samples 标记出哪些是核心点；
  2. 随机挑一个尚未访问的核心点，把它作为种子，新建一个簇；
  3. 不断把"从该簇核心点密度可达"的点吸收进来，直到簇不再扩张；
  4. 若还有未访问的核心点，回到第 2 步，开启下一个簇；
  5. 最后，从未被任何簇吸收的点被标记为噪声（-1）。

这个过程很像"从高密度核心向外扩张、直到撞上低密度区域为止"，因此也叫基于密度的区域生长。

二、可运行代码示例#

先用 sklearn 的 DBSCAN 在月牙形数据上做一次聚类，直观感受"任意形状"的优势。

# -*- coding: utf-8 -*-
# 第 1 课：DBSCAN 密度聚类原理最小示例
import numpy as np
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

# 1. 生成月牙形数据（两个互相缠绕的半圆，K-means 处理这类数据会失败）
X, y_true = make_moons(n_samples=300, noise=0.08, random_state=42)

# 2. 创建 DBSCAN 模型
#    eps=0.25：邻域半径；min_samples=5：核心点至少要有 5 个邻居
db = DBSCAN(eps=0.25, min_samples=5)

# 3. 训练并查看标签（-1 表示噪声点）
labels = db.fit_predict(X)
print("前 20 个样本的标签：", labels[:20])
print("簇的数量（不含噪声）：", len(set(labels)) - (1 if -1 in labels else 0))
print("被标记为噪声的样本数：", int(np.sum(labels == -1)))

# 4. 查看核心点标记（core_sample_indices_ 给出核心点在原数据中的下标）
print("核心点数量：", db.core_sample_indices_.shape[0])

输出解读：labels 里除了 0、1 两个簇标签外，还可能出现 -1，那些就是被判定为噪声的点。core_sample_indices_ 记录了哪些样本是核心点，这是 DBSCAN 特有的输出——它把"密度骨架"直接暴露了出来，便于你理解簇是如何生长的。

提示：运行环境需安装 scikit-learn，可通过 pip install scikit-learn 安装。
