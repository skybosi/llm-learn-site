多元函数的极值条件#

训练模型本质上是在"找损失函数的最低点"。这一课我们先用严格的数学条件判断：一个点到底是不是极小值、极大值，还是另有玄机的鞍点。

一、概念讲解#

1. 必要条件：梯度为零（驻点）#

对可微的多元函数 f(x, y)，如果它在某点是局部极值（极大或极小），那么该点的梯度必须为零向量：

∇f = (∂f/∂x, ∂f/∂y) = (0, 0)

满足这一条件的点叫驻点（stationary point）。但注意：梯度为零只是"必要条件"，不保证一定是极值——还可能是什么都不是的鞍点。

2. 充分条件：看黑塞矩阵#

要判断驻点的"性质"，要看二阶信息——黑塞矩阵（Hessian），它由所有二阶偏导组成：

H = [[ f_xx, f_xy ],
     [ f_yx, f_yy ]]

在驻点处，判断规则是：

  • 若 H 正定（所有特征值 > 0）：该点是局部极小点；
  • 若 H 负定（所有特征值 < 0）：该点是局部极大点；
  • 若 H 的特征值有正有负（不定）：该点是鞍点（saddle point），沿某些方向上升、沿另一些方向下降。

对 2×2 对称矩阵，可以只看行列式与 f_xx 的符号快速判断：f_xx > 0 且 det(H) > 0 时为极小点。

3. 凸函数：极小点就是全局最低点#

如果 f 是凸函数（黑塞矩阵处处半正定），那么它的任何局部极小点都是全局极小点，梯度下降也就不会卡在错误的低点。这解释了为什么很多损失函数（如平方损失、交叉熵）被设计成凸的。

4. 对机器学习的意义#

  • 损失函数往往维度极高，直接"解方程 ∇f = 0"不现实；
  • 但极小值的条件告诉我们：最优参数处梯度为零，这为下一课的"沿梯度反方向走"提供了方向依据；
  • 神经网络损失通常非凸，存在大量鞍点和局部极小，这也是后续要面对的挑战。

二、可运行示例#

示例 1：凸函数的极小点判定#

对 f(x, y) = x² + y²，先找驻点，再用黑塞矩阵判断它是极小点。

def grad(x, y):
    # ∇f = (2x, 2y)
    return 2 * x, 2 * y

def hessian():
    # 二阶偏导：f_xx=2, f_xy=0, f_yx=0, f_yy=2
    return [[2, 0], [0, 2]]

x0, y0 = 0.0, 0.0
gx, gy = grad(x0, y0)
print("驻点处的梯度 =", gx, gy, "（都为零，是驻点）")

H = hessian()
det = H[0][0] * H[1][1] - H[0][1] * H[1][0]
print("f_xx =", H[0][0], "，det(H) =", det)
# f_xx > 0 且 det > 0 => 黑塞矩阵正定 => 局部极小点
print("判定：黑塞矩阵正定，是极小点。")

示例 2：鞍点的判定#

对 f(x, y) = x² - y²，(0, 0) 处梯度为零，但它是典型的"马鞍面"。

def grad(x, y):
    # ∇f = (2x, -2y)
    return 2 * x, -2 * y

def hessian():
    # H = [[2, 0], [0, -2]]
    return [[2, 0], [0, -2]]

print("梯度 =", grad(0.0, 0.0), "（是驻点）")
H = hessian()
# 特征值就是对角元 2 与 -2，一正一负 => 不定 => 鞍点
print("特征值：2 和 -2（一正一负）=> 黑塞矩阵不定，是鞍点。")

# 数值感受：沿 x 方向 f 上升，沿 y 方向 f 下降
print("f(0.1, 0) =", 0.1 ** 2, "（沿 x 方向上升）")
print("f(0, 0.1) =", -(0.1 ** 2), "（沿 y 方向下降）")

示例 3：网格搜索验证全局极小点#

对 f(x, y) = (x-1)² + 2(y-3)² + 4 做一次粗网格搜索，数值上逼近极小点，印证解析判断（理论极点在 (1, 3)，最小值 4）。

def f(x, y):
    return (x - 1) ** 2 + 2 * (y - 3) ** 2 + 4

best = None
for i in range(-50, 51):
    for j in range(-50, 51):
        x = i / 10.0
        y = j / 10.0
        v = f(x, y)
        if best is None or v < best[2]:
            best = (x, y, v)

print("网格搜索找到的极小点 ≈", best)   # 应在 (1, 3) 附近，值接近 4

三、练习#

  1. 求 f(x, y) = x² + xy + y² 的驻点，写出黑塞矩阵并判断它是极小点、极大点还是鞍点。
  2. 说明为什么"梯度为零"只是极值的必要条件而非充分条件，并举一个反例。
  3. 修改示例 3 的函数为 f(x, y) = (x-2)² + (y+1)²，先解析判断极值位置，再用网格搜索验证。
