所有机器学习都能套进 ERM#

前两课我们搭好了 ERM 的框架。这一课做一次"大阅兵"：把从线性回归到神经网络、从 K 均值到强化学习的一长串算法，逐一装进 minimize_θ (1/m)Σℓ 这个模板里。你会发现，没有任何算法能逃出这个框架——它们只是三件套（假设空间、损失、正则）填了不同的值。做完这一步，"机器学习不过是换零件"的母原理就彻底立住了。

一、概念讲解#

1. 线性回归：ERM 的最简实例#

  • 假设空间：ℋ = { h_w(x) = wᵀx + b }，仿射函数族。
  • 损失：平方损失 ℓ(y, ŷ) = (y − ŷ)²。
  • 经验风险：J(w) = (1/m)Σᵢ (wᵀxᵢ + b − yᵢ)²，即均方误差 MSE。
  • 求解：J 是凸二次函数，可解析（正规方程）或梯度下降。

线性回归是 ERM 的"基准案例"：假设空间最小、损失最平滑、目标最凸。第 2 章我们会证明，选平方损失并非随意——它等价于"假设误差服从高斯分布后做最大似然"。

2. 逻辑回归：换个损失，同一套骨架#

  • 假设空间：线性函数的 sigmoid 压缩，h_w(x) = σ(wᵀx + b)，σ(z) = 1/(1+e⁻ᶻ)，输出是"正类概率"。
  • 损失：交叉熵（对数损失）ℓ(y, p) = −[y log p + (1−y) log(1−p)]。
  • 经验风险：J(w) = −(1/m)Σᵢ [yᵢ log pᵢ + (1−yᵢ) log(1−pᵢ)]。
  • 求解：J 凸，无解析解，用梯度下降（梯度恰好是"预测概率 − 真实标签"的漂亮形式）。

注意：逻辑回归和线性回归的假设空间同源（都是线性参数化），差别只在"损失 + 一个输出端的非线性"。第 2 章第 3 课会从伯努利分布 + 最大似然推出这个交叉熵。

3. 支持向量机 SVM：ERM + 正则的最经典组合#

SVM 不是"另一个框架"，而是 ERM 加上正则、再换一个损失的产物：

minimize_w   (1/m)Σᵢ max(0, 1 − yᵢ(wᵀxᵢ + b))  +  λ‖w‖²
  • 损失：合页损失 max(0, 1 − yᵢ(wᵀxᵢ + b))，只惩罚"分类不够自信"的样本，正确且超出边界的样本损失为 0。
  • 正则：λ‖w‖²（L2），对应第 3 章的高斯先验。
  • 假设空间：线性（可用核函数推广到非线性）。

对比逻辑回归：两者假设空间相同，只差在损失——逻辑回归用平滑的交叉熵，SVM 用"平顶"的合页损失。一个损失函数的选择，就造就了两个不同学派。

4. 决策树：0-1 损失太难，改用"贪心代理"#

决策树想直接最小化 0-1 损失（分类错误数），但 0-1 损失非凸、不可导、组合爆炸，直接优化是 NP 难的。于是决策树走了一条贪心 + 代理损失的路：

  • 每次分裂选择能最大程度降低不纯度（基尼指数、熵、或回归方差）的特征阈值；
  • 这个"不纯度下降"本质上是 0-1 损失的一个可计算的代理（surrogate）；
  • 整棵树生长结束，相当于一个近似的 ERM 解。

结论：决策树不是"非 ERM"，而是"用代理损失 + 贪心策略逼近 ERM"——因为它无法精确解 ERM，只能妥协。

5. K 近邻 KNN：假设空间是"整张数据表"#

KNN 没有显式训练参数，但它依然在 ERM 框架内：

  • 假设空间：由训练集本身定义——h(x) 取 x 的 K 个最近邻的标签多数投票（或均值）。
  • 损失：预测时隐含地最小化"与近邻的差异"；可视为在"局部"做 ERM。
  • 代价：假设空间完全由数据决定，没有可学习的参数，因此"训练"等于"记忆"，推理时才计算。

KNN 揭示了一个深层道理："非参数方法"并不是没有假设空间，而是把假设空间直接钉在了数据上，代价是推理开销大、且对噪声敏感。

6. 神经网络：分层参数化 + 梯度下降的 ERM#

神经网络是把假设空间"叠高"的产物：

  • 假设空间：h_θ(x) = W_L·φ(W_{L−1}·φ(…φ(W₁x)…))，多层仿射变换 + 非线性激活 φ 复合而成，θ 是所有权重。
  • 损失：回归用 MSE，分类用交叉熵——与线性模型完全相同的损失。
  • 经验风险：J(θ) = (1/m)Σᵢ ℓ(h_θ(xᵢ), yᵢ)，仍是样本平均。
  • 求解：J 非凸，用反向传播算梯度 + 随机梯度下降。

看到关键了吗？神经网络与线性回归的区别只在假设空间 ℋ 的表达能力——损失、经验风险的形式一模一样。所谓"深度学习革命"，本质是用一个巨大且可微的 ℋ，配合可扩展的梯度下降，去解同一个 ERM 问题。

7. 无监督：K 均值与 PCA 也能套进去#

无监督学习没有标签 y，但可以把"重构误差"当作损失：

  • K 均值：minimize_{μ₁,…,μ_K} Σᵢ min_k ‖xᵢ − μ_k‖²——即"每个点到其最近质心的平方距离之和"最小，这正是 ERM（损失 = 到最近质心的距离，参数 = K 个质心）。
  • PCA：minimize_{U: UᵀU=I} Σᵢ ‖xᵢ − UUᵀxᵢ‖²——在"正交子空间"假设空间里最小化重构误差，是 ERM 在降维上的体现。

所以"监督/无监督"的区别不在框架，而在损失怎么定义：有标签就用预测误差，无标签就用重构误差。

8. 一张总表：所有算法 = 三件套的填法#

算法 假设空间 ℋ 损失 ℓ 正则/备注
线性回归 仿射函数 平方损失 无（可加 L2）
逻辑回归 sigmoid(仿射) 交叉熵 可加 L1/L2
SVM 仿射（可核化） 合页损失 L2（必带）
决策树 轴平行分段常数 0-1 损失（贪心代理） 剪枝/深度限制
KNN 由数据定义的近邻函数 局部多数/均值 K 的选择
神经网络 多层复合非线性 MSE / 交叉熵 各种正则
K 均值 K 个质心 到最近质心距离² K 的选择
PCA 正交子空间 重构误差² 子空间维度

这张表就是本章的结论："机器学习算法"这个词，可以被"(ℋ, ℓ, R, 优化器) 四元组"完全取代。

二、可运行代码示例#

用同一套"梯度下降解 ERM"的代码，同时拟合线性回归和逻辑回归，直观展示"换损失 + 换输出变换 = 换算法"。

import numpy as np

rng = np.random.default_rng(1)
m = 300
X = np.c_[np.ones(m), rng.normal(0, 1, size=m)]   # 第 0 列是截距项

# —— 回归任务：y = 3x + 2 + 噪声 ——
y_reg = 3.0 * X[:, 1] + 2.0 + rng.normal(0, 1, size=m)

def train(X, y, grad_fn, steps=2000, lr=0.01):
    theta = np.zeros(X.shape[1])
    for _ in range(steps):
        theta = theta - lr * grad_fn(theta, X, y)
    return theta

# 线性回归：平方损失梯度
def grad_mse(theta, X, y):
    r = X @ theta - y
    return (2.0 / len(y)) * X.T @ r

# 逻辑回归：交叉熵梯度
def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def grad_ce(theta, X, y):
    p = sigmoid(X @ theta)
    return (1.0 / len(y)) * X.T @ (p - y)   # 漂亮：梯度 = 概率误差

th_reg = train(X, y_reg, grad_mse)
print("线性回归 θ =", np.round(th_reg, 4))

# —— 分类任务：用同样的 X，标签 = x>0 ——
y_cls = (X[:, 1] > 0).astype(float)
th_cls = train(X, y_cls, grad_ce)
print("逻辑回归 θ =", np.round(th_cls, 4))
print("逻辑回归预测准确率 =", np.mean((sigmoid(X @ th_cls) > 0.5) == y_cls))

同一份 train 骨架、同一个 θ ← θ − α∇J，只替换了梯度函数 grad_fn，就分别解出了线性回归和逻辑回归。这就是"所有算法都能套进 ERM"的最直接证据：优化的骨架只有一个，算法的个性全在 ∇J 里。

三、练习#

  1. 上表里哪个算法的"经验风险"不能被写成 (1/m)Σᵢℓ 的求和形式？（提示：KNN 的损失与近邻有关）这说明 ERM 框架对非参数方法是一种"精神上的统一"，而非字面上的求和。请解释。
  2. 写出 K 均值的目标函数，并证明"固定质心更新分配"与"固定分配更新质心"两步都不会让目标函数增大（EM/坐标下降的一步）。
  3. 逻辑回归的梯度 ∇J = (1/m)Xᵀ(p − y) 为什么在 p ≈ y 时趋近于 0？从几何上解释"预测得越准，梯度越小"。
  4. 思考：既然神经网络和线性回归是同一个 ERM 框架，为什么神经网络能学出线性回归学不出的东西？答案应落在三件套的哪个零件上？

母原理连接#

本课是母原理 "一切学习 = 优化" 的收官课。我们证明了从 K 均值到深度网络的每一个算法，都能被压缩成一个四元组 (ℋ, ℓ, R, 优化器)。从此你再看任何新算法，第一反应应该是："它的 ℋ 是什么？ℓ 是什么？正则是什么？"——而不是去记 API。带着这个"拆解一切算法"的视角进入第 2 章，我们追问下一个母问题：损失函数 ℓ 凭什么这么选？ 答案藏在概率论里。
