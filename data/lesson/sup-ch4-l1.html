决策树原理与信息增益#

决策树是最接近人类"问答式"推理的算法：它像玩"二十个问题"一样，一步步提问，把数据不断切分，直到每个小格子里"纯净"为止。它既能分类也能回归，还是随机森林、梯度提升树这些"集成学习明星"的基石。这一课我们从树的结构讲起，重点搞懂信息熵、信息增益与基尼指数这三个决定"怎么提问"的核心概念。

一、概念讲解#

1. 树的结构：根、内部节点与叶子#

一棵决策树由三种节点组成：

  • 根节点：整份数据的起点，含全部样本；
  • 内部节点：一个"提问"（对某个特征做阈值判断），把数据分成两路（或多路）；
  • 叶子节点：停止划分，给出最终预测——分类树里是类别，回归树里是数值。

一次判断形如"花萼长度 ≤ 5.4 cm？"，满足走左子树、不满足走右子树。整棵树就是一连串 if-else 规则，因此天然可解释：把一条样本从根走到叶子，沿途的判断就是它的"决策理由"。

2. 怎么选"最好的问题"：不纯度#

构建树的核心是：在每个节点，选哪个特征、哪个阈值来切分，能让数据"分得最干净"？ 这需要一个衡量"脏乱程度"的指标，统称不纯度（Impurity）。两类样本混在一起，不纯度高；全部同一类，不纯度为零。切分的目标，就是让切完后子节点的加权不纯度尽可能低。

3. 信息熵与信息增益（ID3 / C4.5 的思路）#

信息熵（Entropy）衡量一个集合的混乱程度。设第 i 类样本占比为 pᵢ，熵定义为：

Entropy = −Σ pᵢ · log₂(pᵢ)
  • 全是同一类（p=1）：熵为 0，最纯净；
  • 各类均匀混合：熵最大（二分类各占一半时，熵 = 1 bit）。

信息增益（Information Gain） = 划分前的熵 − 划分后各子节点熵的加权平均。增益越大，说明这次划分让数据"变纯"得越多，就越值得选。这是 ID3 算法的选择标准。它的一个缺点是偏好取值多的特征（比如"ID 号"这种几乎每行一个值的特征，能把数据切得极细、增益虚高），于是 C4.5 改用信息增益比（增益除以特征的"固有信息"）来修正这个偏差。

4. 基尼指数（CART 的思路）#

sklearn 的决策树默认用 CART 算法，它选择的是基尼指数（Gini Impurity）：

Gini = 1 − Σ pᵢ²

基尼指数同样在"纯"时为 0、在"均匀混合"时最大。与熵相比，基尼指数计算更快（没有对数），且更倾向产生"更平衡"的切分。两者在多数情况下选出的分裂点差别不大，但基尼是 sklearn 的默认 criterion。此外，CART 只能做二叉分裂，而 ID3/C4.5 可以做多叉。

5. 回归树：用方差代替不纯度#

分类树看"类别纯不纯"，回归树看"目标值散不散"。CART 回归树用均方误差（MSE）作为切分标准：选一个特征和阈值，让切分后两个子节点的目标值方差加权和最小。叶子节点的预测值，就是落到该叶子的样本目标值的平均值。

二、可运行代码示例#

下面用 numpy 手写"信息熵"与"信息增益"的计算，并用一个经典的二分类小例子演示如何挑选分裂特征。

import numpy as np

def entropy(labels):
    """计算类别标签数组的香农熵（单位：bit）。"""
    _, counts = np.unique(labels, return_counts=True)
    p = counts / counts.sum()          # 各类占比
    p = p[p > 0]                       # 去掉 0，避免 log(0)
    return float(-np.sum(p * np.log2(p)))

def info_gain(parent, left, right):
    """信息增益 = 父节点熵 − 左右子节点熵的加权平均（样本不丢时）。"""
    n_parent = len(parent)
    gain = entropy(parent)
    gain -= (len(left) / n_parent) * entropy(left)
    gain -= (len(right) / n_parent) * entropy(right)
    return gain

# 构造一个"是否外出打球"风格的二分类小数据
# 标签：0=不去, 1=去；两个候选特征分别给出不同切分
labels_all = np.array([0, 0, 1, 1, 1, 0, 1, 1, 0, 1])

# 特征 A（天气）切分结果：左子集 4 个、右子集 6 个
left_A  = np.array([0, 0, 0, 1])
right_A = np.array([1, 1, 1, 0, 1, 1])
# 特征 B（湿度）切分结果：左子集 5 个、右子集 5 个
left_B  = np.array([0, 0, 1, 1, 1])
right_B = np.array([0, 1, 0, 1, 1])

print("父节点熵          =", round(entropy(labels_all), 3))
print("特征 A 的信息增益 =", round(info_gain(labels_all, left_A, right_A), 3))
print("特征 B 的信息增益 =", round(info_gain(labels_all, left_B, right_B), 3))
print("应选择：", "特征 A" if info_gain(labels_all, left_A, right_A) >
      info_gain(labels_all, left_B, right_B) else "特征 B")

再补一个基尼指数对照：

def gini(labels):
    """基尼不纯度 = 1 − Σpᵢ²。"""
    _, counts = np.unique(labels, return_counts=True)
    p = counts / counts.sum()
    return float(1 - np.sum(p ** 2))

print("\n父节点基尼指数 =", round(gini(labels_all), 3))
print("纯集合的熵与基尼 =", round(entropy(np.array([1, 1, 1])), 3),
      round(gini(np.array([1, 1, 1])), 3))

观察要点：父节点的熵/基尼都大于 0（有 6 个 1、4 个 0，混合）；纯集合（全是 1）的熵与基尼都恰好为 0；信息增益更大的那个特征会被选中作为分裂依据。这就是决策树"在每一步选最好的问题"的完整机制。

  2. 修改上面的 info_gain 函数，实现信息增益比（增益 ÷ 特征的固有信息），体会它如何抑制"取值过多"的特征。
  3. 在 [0, 0.5, 1] 三个占比上分别计算熵和基尼指数，感受两者数值范围与变化趋势的异同。
  4. 思考：如果某个特征的取值是"身份证号"（每个样本都不同），它的信息增益会怎样？为什么 C4.5 要用增益比来修正它？

为什么这样做？——理论推导#

从熵的不确定性推出信息增益准则#

先问"为什么"。 决策树每一步都在问"哪个问题最能分清数据"，可"最能分清"该如何量化？我们缺两样东西：(1) 一把测量"混乱/不确定"的尺子；(2) 一个用这把尺子比较"提问前后"的准则。前者是熵，后者是信息增益。

熵为什么长成 −Σ pᵢ log₂ pᵢ？ 从第一性原理看，我们给"不确定性"定三条公理，并要求存在唯一一把尺子满足它们：

  1. 连续：类别占比微调，不确定性只微变；
  2. 对称且极大在均匀处：各类换个名字不确定性不变；占比越均匀，不确定性越大；
  3. 可加（合成法则）：先"按大类分、再按小类分"的两步不确定性之和，等于"一步直接分"的总不确定性。

信息论证明：同时满足这三条的函数，唯一形式就是

H(p₁, …, p_k) = −Σ pᵢ · log₂ pᵢ

（底取 2 单位是 bit；取 e 是 nat，取 10 是 hartley。）它的直觉是"平均意外程度"：−log₂ pᵢ 是"看到第 i 类"这件事带来的惊讶量（概率越小越惊讶），H 是这份惊讶的期望。于是"全同类"时 H=0（毫不意外），"均匀混合"时 H 最大（最不确定）。

信息增益 = 不确定性的减少量。 划分前父节点不确定性为 H(parent)；按某特征切成若干子节点后，用样本占比 nⱼ/n 加权平均各子节点熵，得到划分后的期望不确定性：

H_after = Σⱼ (nⱼ / n) · H(childⱼ)

两者之差就是这次划分"消除掉了多少不确定性"：

Gain = H(parent) − H_after = H(parent) − Σⱼ (nⱼ/n) · H(childⱼ)

为什么这个式子度量的是"不确定性减少"？ 关键一步是熵的凹性（Jensen 不等式）：因为各子节点的类别占比按样本数加权平均后，恰好回到父节点的类别占比，即 Σⱼ (nⱼ/n)·p(childⱼ) = p(parent)，所以

Σⱼ (nⱼ/n) · H(childⱼ) ≤ H( Σⱼ (nⱼ/n)·p(childⱼ) ) = H(parent)

即"熵的加权平均 ≤ 加权平均后的熵"。取反后，信息增益恒为非负，且当且仅当"子节点与父节点的类别分布完全一致"时等于 0（这次划分没提供任何信息）。增益越大，说明这次提问把"不知道是哪个类"的不确定消除得越多——于是选最大增益，就是选"信息量最大"的那个问题。

母原理连接： 熵把"不确定性"翻译成可以加减的数字，信息增益则把它变成"提问前 − 提问后"的差额——这正是信息论的核心量互信息（mutual information）：一次划分的增益，等于"答案"与"标签"这两个随机变量之间的互信息。决策树贪心地最大化互信息，就是在一步步问出"关于标签最值钱的问题"。
