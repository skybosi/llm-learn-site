欠拟合与过拟合#

调参调了半天，模型在训练集上分数很高，一上测试集就现原形——这是机器学习里最经典、也最核心的现象之一：过拟合（overfitting）。与之相对的还有欠拟合（underfitting）。搞懂这两者，是掌握后面"偏差-方差权衡"和"正则化"的前提，也是从"会调包"走向"会建模"的分水岭。

一、概念讲解#

1. 三种状态：欠拟合、恰好、过拟合#

用一句话概括：

  • 欠拟合（underfitting）：模型太"简单"，连训练数据本身的规律都没学够，训练集和测试集表现都差。就像用一条直线去拟合一条抛物线。
  • 恰好（good fit）：模型复杂度适中，抓到了数据背后的真实规律，训练集和测试集表现都较好且接近。
  • 过拟合（overfitting）：模型太"复杂"，把训练数据里的噪声也当成规律背了下来，训练集表现很好、测试集表现明显变差。就像考试前把例题连同印刷错误一起背了。

2. 怎么判断：看"训练-测试差距"#

最实用的信号就是训练得分与测试得分之间的差距：

  • 两者都很低 → 欠拟合（模型太弱）。
  • 训练高、测试低、差距大 → 过拟合（模型记性好、迁移差）。
  • 两者都高且接近 → 状态良好。

3. 学习曲线：更精细的诊断工具#

学习曲线（learning curve） 把"训练集大小"作为横轴，画出训练得分和验证得分的变化：

  • 若两条曲线最终都很低且贴在一起 → 欠拟合，加数据也没用，需要换更复杂的模型。
  • 若训练得分高、验证得分低，中间隔着一道明显的缝 → 过拟合，增加训练数据或降低复杂度会有效果。

4. 常见成因与对策#

状态 常见成因 对策
欠拟合 模型太简单、特征太少、训练不足 换更强模型、增加特征、提高复杂度
过拟合 模型太复杂、数据太少、噪声太多 增加数据、降低复杂度、正则化（下一课）、交叉验证

二、可运行示例#

示例 1：多项式回归直观感受三种状态

import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.metrics import mean_squared_error

# 生成一条真实二次曲线并叠加噪声
np.random.seed(0)
X = np.linspace(-3, 3, 60).reshape(-1, 1)
y = 0.5 * X.ravel()**2 + X.ravel() + 2 + np.random.normal(0, 1, X.shape[0])

# 用 1 / 2 / 12 次多项式分别拟合，观察欠拟合、恰好、过拟合
degrees = [1, 2, 12]
plt.figure(figsize=(12, 4))
for i, d in enumerate(degrees, 1):
    model = make_pipeline(PolynomialFeatures(d), LinearRegression())
    model.fit(X, y)
    mse = mean_squared_error(y, model.predict(X))

    plt.subplot(1, 3, i)
    plt.scatter(X, y, s=15)
    xs = np.linspace(-3.3, 3.3, 200).reshape(-1, 1)
    plt.plot(xs, model.predict(xs), color="red")
    plt.title(f"{d} 次多项式\nMSE={mse:.2f}")
plt.tight_layout()
plt.show()

示例 2：学习曲线揭示过拟合

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification
from sklearn.model_selection import learning_curve
from sklearn.tree import DecisionTreeClassifier

X, y = make_classification(n_samples=600, n_features=20,
                           n_informative=5, random_state=0)

# max_depth=None 的决策树几乎不限制复杂度，很容易过拟合
model = DecisionTreeClassifier(max_depth=None, random_state=0)

train_sizes, train_scores, test_scores = learning_curve(
    model, X, y, cv=5, train_sizes=np.linspace(0.1, 1.0, 10))

train_mean = train_scores.mean(axis=1)
test_mean = test_scores.mean(axis=1)

plt.plot(train_sizes, train_mean, "o-", label="训练得分")
plt.plot(train_sizes, test_mean, "o-", label="验证得分")
plt.xlabel("训练样本数")
plt.ylabel("准确率")
plt.legend()
plt.title("学习曲线：训练与验证之间的大缝隙就是过拟合")
plt.show()

示例 3：用训练/测试差距量化过拟合

from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeRegressor
from sklearn.metrics import mean_squared_error

X, y = load_diabetes(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0)

# 一棵"放任生长"的深树 vs 一棵限制深度的浅树
for depth in [3, None]:
    model = DecisionTreeRegressor(max_depth=depth, random_state=0)
    model.fit(X_train, y_train)
    train_mse = mean_squared_error(y_train, model.predict(X_train))
    test_mse = mean_squared_error(y_test, model.predict(X_test))
    print(f"max_depth={depth}: 训练MSE={train_mse:.0f}, "
          f"测试MSE={test_mse:.0f}, 差距={test_mse - train_mse:.0f}")
