最大后验估计（MAP）#

MLE 只看数据，完全无视我们先前的判断；完整的贝叶斯推断又要维护一整个后验分布，有时计算太贵。最大后验估计（Maximum A Posteriori，简称 MAP）是两者的折中：它把"先验"请回来参与决策，但只输出一个点估计。更重要的是，MAP 会揭示一个惊人的联系——机器学习里的正则化，本质就是先验。

一、概念讲解#

1. 定义：在后验上取最大值#

后验分布 ∝ 似然 × 先验。MAP 就是找让后验概率密度最大的那个参数：

θ̂_MAP = argmax_θ P(θ | D) = argmax_θ P(D | θ) · P(θ)

对比一下三个估计量：

  • MLE：θ̂ = argmax P(D | θ)，只看似然；
  • MAP：θ̂ = argmax P(D | θ) · P(θ)，似然 × 先验；
  • 后验均值（完整贝叶斯）：θ̄ = E[θ | D]，用整个后验分布。

MAP 比 MLE 多乘了一项先验 P(θ)。这一项的作用是：当我们对某个参数取值有偏好时，把估计往偏好的方向"拉"一点。

2. 抛硬币的 MAP：一个具体例子#

先验取 Beta(α, β)，似然为二项，后验是 Beta(α + k, β + n − k)。Beta(a, b) 的众数（最大值点）在 (a − 1) / (a + b − 2)（当 a, b > 1 时）。因此：

θ̂_MAP = (α + k − 1) / (α + β + n − 2)

把它和 MLE 的 θ̂_MLE = k / n 对比：当 n 很大时，(α−1) 和 (α+β−2) 这些先验项相对 n 越来越小，MAP 逐渐趋近 MLE；当 n 很小时，先验项主导，把估计拉向先验的众数附近。这正是"先验在数据少时起作用、数据多时退场"的定量体现。

3. 先验 = 正则化：机器学习最重要的联想之一#

把 MAP 的目标取对数（并去掉无关常数），得到：

θ̂_MAP = argmax [ log P(D | θ) + log P(θ) ]

第一项是似然（对应"拟合数据"），第二项 log P(θ) 是"先验惩罚"（对应"约束参数"）。下面两个结论几乎贯穿所有机器学习教材：

  • 高斯先验 → L2 正则：若先验 P(θ) 是均值为 0 的正态分布，那么 log P(θ) ∝ −‖θ‖²，正是岭回归 / 权重衰减里的 L2 惩罚项。
  • 拉普拉斯先验 → L1 正则：若先验是拉普拉斯分布，log P(θ) ∝ −‖θ‖₁，正是LASSO里的 L1 惩罚项，它会鼓励参数稀疏（很多权重变成 0）。

所以"给损失函数加正则项"这件事，站在贝叶斯角度看，就是"给参数加了一个先验假设"。MLE + 正则化 ≈ MAP。

4. MAP 的优缺点#

  • 优点：比 MLE 更稳健（小样本时不被极端数据带偏）；计算量远小于完整贝叶斯推断；直接对应正则化。
  • 缺点：仍然只是一个点估计，丢失了后验分布携带的"不确定性"信息；并且它对参数的坐标变换不敏感的特性不如完整贝叶斯方法。

5. 在机器学习中的位置#

  • 带 L2 正则的逻辑回归 / 线性回归：MAP 的直接应用；
  • 主题模型（LDA）、矩阵分解（PMF）：常用 MAP 来求主题分布或隐因子；
  • 稀疏学习（LASSO）：拉普拉斯先验下的 MAP。

二、可运行示例#

下面的代码对比 MLE 与 MAP：在小样本下看先验如何"拉住"估计，在大样本下看两者如何趋同。

import numpy as np
from scipy.stats import beta as beta_dist

# 假设真实正面概率 0.7，我们只观察到少量数据
theta_true = 0.7

def mle(n, k):
    """二项似然的 MLE：p = k / n"""
    return k / n

def map_estimate(alpha, beta, n, k):
    """Beta 先验下的 MAP：众数公式 (alpha+k-1)/(alpha+beta+n-2)"""
    return (alpha + k - 1) / (alpha + beta + n - 2)

# 先验：Beta(3, 3)，先验众数在 (3-1)/(3+3-2) = 0.5，即"先验认为硬币接近均匀"
alpha, beta = 3, 3
print("先验众数（先验最相信的 θ）：", (alpha - 1) / (alpha + beta - 2))

# 场景 1：小样本 n=5，只出现 4 次正面（数据极端偏 0.8）
n, k = 5, 4
print(f"\n小样本 n={n}, k={k}:")
print("  MLE =", mle(n, k))
print("  MAP =", round(map_estimate(alpha, beta, n, k), 4), "（被先验拉向 0.5）")

# 场景 2：大样本 n=1000，出现 700 次正面
n, k = 1000, 700
print(f"\n大样本 n={n}, k={k}:")
print("  MLE =", mle(n, k))
print("  MAP =", round(map_estimate(alpha, beta, n, k), 6), "（几乎与 MLE 相同）")

# 画出后验分布，标出 MAP 与后验均值的位置
import matplotlib.pyplot as plt
grid = np.linspace(0, 1, 500)
a_post, b_post = alpha + k, beta + (n - k)
pdf = beta_dist.pdf(grid, a_post, b_post)
plt.plot(grid, pdf, label=f"后验 Beta({a_post},{b_post})")
plt.axvline(map_estimate(alpha, beta, n, k), color="red", ls="--",
            label="MAP（后验众数）")
plt.axvline(a_post / (a_post + b_post), color="green", ls=":",
            label="后验均值")
plt.axvline(mle(n, k), color="blue", ls="-.", label="MLE")
plt.xlabel("θ")
plt.ylabel("概率密度")
plt.legend()
plt.title("大样本下 MAP ≈ MLE ≈ 后验均值")
plt.show()

预期输出（部分）：

先验众数（先验最相信的 θ）： 0.5

小样本 n=5, k=4:
  MLE = 0.8
  MAP = 0.6667 （被先验拉向 0.5）

大样本 n=1000, k=700:
  MLE = 0.7
  MAP = 0.699203 （几乎与 MLE 相同）

要点：小样本时 MLE 给出了 0.8（被极端数据带偏），MAP 把它拉回到 0.667；大样本时两者几乎重合在 0.7 附近——先验的影响被大量数据"淹没"。

三、练习#

  1. 推导：验证 Beta(α,β) 的众数公式是 (α−1)/(α+β−2)，并说明为什么要求 α, β > 1。
  2. 改先验：把先验改成 Beta(30, 30)（极强地相信均匀），重跑小样本场景，观察 MAP 被拉向 0.5 的程度。
  3. 正则化联想：写出均值为 0、方差为 σ₀² 的高斯先验的对数，证明 log P(θ) 与 −‖θ‖² 成正比（即对应 L2 正则）。
  4. 思考：既然完整贝叶斯保留了不确定性，为什么工程上还常用 MAP？举一个你理解的理由。
