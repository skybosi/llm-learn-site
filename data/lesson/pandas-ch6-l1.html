concat#

现实里的数据经常是"拆散的"：每个月一个文件、每个地区一张表。分析前要做的第一步，往往是把它们拼回一整张表。pd.concat() 就是最直接的拼接工具——不做任何匹配，只是把若干 DataFrame 简单地首尾相接或左右并排。

一、概念讲解#

1. concat 是"简单拼接"，不是"匹配"#

concat 和下一课的 merge 分工不同：

  • concat：按位置拼接，把几张结构相同的表叠起来或并起来，不关心"哪一行和哪一行对应"；
  • merge：按键匹配，根据某一列的取值把两张表对齐，像数据库 JOIN。

记住这个区别，选择工具时就不会犹豫：结构相同、单纯叠加用 concat；需要按某列对应关系合并用 merge。

2. 纵向拼接：axis=0#

axis=0 是默认值，表示沿行方向拼接——把后面的表接在前面的表下面，行数增加：

pd.concat([df1, df2])              # 默认 axis=0，上下拼接
pd.concat([df1, df2], axis=0)      # 等价写法

拼接后，两张表的列会自动对齐：共有的列保留，某张表独有的列会补上缺失值。

3. 横向拼接：axis=1#

axis=1 表示沿列方向拼接——把两张表左右并排，列数增加：

pd.concat([df1, df2], axis=1)

横向拼接默认按索引对齐，所以通常要先保证两张表的索引顺序一致，否则会错位。

4. 重置索引：ignore_index#

纵向拼接后，两边的行索引会原样保留，可能出现重复索引（比如两张表都是从 0 开始编号）。加 ignore_index=True 就会忽略旧索引，重新从 0 连续编号：

pd.concat([df1, df2], ignore_index=True)

5. 多级索引标记来源：keys#

一次拼多张表时，往往想区分"每一行来自哪张表"。传 keys 参数会给结果加上一层来源标签：

pd.concat([df1, df2], keys=["一月", "二月"])

结果会变成多级索引，外层是"一月/二月"，内层是原来的索引，方便追踪数据来源。

6. 控制交集还是并集：join#

join 参数决定拼接时对"列"（axis=0 时）的取舍：

  • join="outer"（默认）：保留所有列，缺的补 NaN；
  • join="inner"：只保留所有表都有的列。

二、可运行代码示例#

import pandas as pd

df1 = pd.DataFrame({
    "商品": ["手机", "耳机"],
    "销量": [120, 430],
})
df2 = pd.DataFrame({
    "商品": ["键盘", "台灯"],
    "销量": [210, 340],
})
df3 = pd.DataFrame({
    "商品": ["手机", "耳机", "键盘", "台灯"],
    "金额": [9600, 12900, 6300, 8500],
})

示例 1：纵向拼接（axis=0）#

# 把 df1 和 df2 上下接起来，并重新编号
merged = pd.concat([df1, df2], ignore_index=True)
print(merged)

示例 2：用 keys 标记来源#

# 用 keys 记录每行来自哪一段
with_keys = pd.concat([df1, df2], keys=["第一批", "第二批"])
print(with_keys)

示例 3：横向拼接（axis=1）#

# 左右并排，按索引对齐
side_by_side = pd.concat([df1, df3], axis=1)
print(side_by_side)

三、练习#

  1. 创建两张结构相同、各含 3 行的 DataFrame（列名都叫 城市 和 人口），用 concat 纵向拼接，比较加与不加 ignore_index=True 时索引的差异。
  2. 给上一步的拼接加上 keys=["城市A", "城市B"]，观察多级索引的结构，并尝试用 .loc["城市A"] 取出第一段数据。
  3. 造一张"列数不同"的表（多一列 省份）和原表纵向拼接，观察结果里缺失值是如何自动补上的，并说明 join="inner" 会怎样改变结果。
