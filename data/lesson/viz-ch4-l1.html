subplot 布局#

前面几章我们已经会用 plt.plot、plt.bar 等函数画出单张图。但一份真正有用的分析，往往需要把多张相关的图放在一起对照观察：比如同时看"趋势"和"分布"，或者把训练数据、预测结果、误差并排展示。这一课就来讲清 Matplotlib 里最常用的多子图布局工具：subplot 与 subplots。

一、概念讲解#

1. 什么是子图#

"子图（subplot）"指的是画在同一张画布上的多张独立小图。每一张子图都有自己的坐标系、坐标轴和数据，但它们共享同一个"画布"（Figure）。这样做的好处是：眼睛可以在同一屏内来回对比，而不用在多个窗口之间切换。

一个子图布局由三个要素决定：

  • 画布 Figure：最外层的大容器，所有子图都画在它上面。
  • 网格（rows × cols）：把画布想象成"表格"，几行几列决定了能放多少张图。
  • 位置 index：每张子图占哪一个格子，编号从 1 开始，按"先从左到右、再从上到下"的顺序数。

2. 两种创建方式：plt.subplot 与 plt.subplots#

Matplotlib 提供了两套创建子图的方式，各有适用场景：

  • plt.subplot(nrows, ncols, index)：函数式写法，一次创建一个子图，之后所有绘图命令都作用在"当前"子图上。适合脚本里顺序地一张张画。
  • plt.subplots(nrows, ncols)：面向对象写法，一次返回画布对象 fig 和一个由"坐标轴对象"组成的数组 axs。之后用 axs[行, 列] 精确指定要在哪张图上画。这是官方更推荐的写法，控制更精细、不容易出错。

两种写法的本质一样，都是在同一个网格里"占位"。对复杂项目，建议直接养成用 plt.subplots 的习惯。

3. 共享坐标轴：sharex 与 sharey#

当多张子图展示的是同一组数据的不同侧面时，让它们共享 x 轴或 y 轴，既能省去重复的刻度，又方便对齐比较。用 plt.subplots 时加参数 sharex=True 或 sharey=True 即可；共享后，只有边缘的子图会显示刻度标签。

4. 更灵活的 GridSpec#

subplot 的网格是"规整的等分"；如果你想让某些图占两列、某些图跨两行，就要用到 GridSpec。它允许你自定义每个格子的大小和跨度，实现"拼贴画"式的布局。我们会在本章第三课的综合练习里用到它。

二、可运行代码示例#

示例 1：用 plt.subplots 画 2×2 布局#

下面在一个画布里画出四张不同类型的图，展示同一批数据的四个视角：

import numpy as np
import matplotlib.pyplot as plt

# 让图表支持中文显示（没有中文字体的环境可删掉这两行）
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False   # 让负号正常显示

# 生成示例数据
x = np.linspace(0, 2 * np.pi, 100)      # 0 到 2π 共 100 个点
y1 = np.sin(x)                          # 正弦
y2 = np.cos(x)                          # 余弦
data = np.random.default_rng(42).normal(0, 1, 500)   # 500 个正态随机数

# 创建 2 行 2 列的子图，并拿到每个坐标轴对象
fig, axs = plt.subplots(2, 2, figsize=(10, 8))

# 左上：折线图（正弦与余弦）
axs[0, 0].plot(x, y1, label='sin')
axs[0, 0].plot(x, y2, label='cos')
axs[0, 0].set_title('折线图')
axs[0, 0].legend()

# 右上：散点图（余弦为横轴、正弦为纵轴）
axs[0, 1].scatter(y2, y1, s=10, alpha=0.6)
axs[0, 1].set_title('散点图')

# 左下：柱状图（各区间频数）
bins = 20
counts, edges = np.histogram(data, bins=bins)
axs[1, 0].bar(edges[:-1], counts, width=np.diff(edges), align='edge')
axs[1, 0].set_title('柱状图（频数分布）')

# 右下：直方图（同样的数据，用 hist 一步到位）
axs[1, 1].hist(data, bins=bins)
axs[1, 1].set_title('直方图')

fig.suptitle('同一批数据的四个视角', fontsize=16)   # 整张画布的大标题
fig.tight_layout(rect=[0, 0, 1, 0.95])              # 压缩布局，给大标题留空间
plt.show()

要点：axs[0, 0] 里的两个下标分别对应行和列，都是从 0 开始；fig.suptitle 给整张画布加标题，tight_layout 自动消除子图之间的重叠。

示例 2：用 GridSpec 让一张图跨两列#

import numpy as np
import matplotlib.pyplot as plt
import matplotlib.gridspec as gridspec

x = np.linspace(0, 10, 100)
y = np.sin(x)

fig = plt.figure(figsize=(9, 4))
gs = gridspec.GridSpec(1, 3, figure=fig)   # 1 行 3 列的网格

# 第一张图横跨前两列（占 2/3 宽度）
ax1 = fig.add_subplot(gs[0, :2])
ax1.plot(x, y, color='tab:blue')
ax1.set_title('大图（横跨两列）')

# 第二张图占第 3 列（1/3 宽度）
ax2 = fig.add_subplot(gs[0, 2])
ax2.plot(x, y ** 2, color='tab:red')
ax2.set_title('小图（占一列）')

fig.tight_layout()
plt.show()

要点：gs[0, :2] 表示"第 0 行、第 0 到第 1 列"（Python 切片不包含右边界），即横跨两列。用切片就能实现任意跨度。

三、练习#

  1. 动手练习：用 plt.subplots(2, 3) 创建 2 行 3 列的布局，在前两行各画一张图，把最后一格留空（不画任何内容），观察留空格子的效果。
  2. 共享坐标轴：创建 plt.subplots(2, 1, sharex=True)，在两行分别画 sin(x) 和 sin(2x)，确认只有下面一行显示了 x 轴刻度。
  3. GridSpec 挑战：设计一个"左大右小"的布局——左边一张大图占整个画布 2/3 高度，右边上下叠放两张小图。
  4. 思考：什么情况下你会选择"多子图"而不是"画多张单独的图"？多子图相比多张独立图，有什么代价？
