损失函数#

反向传播算出了"损失对每个参数的梯度"，那么损失本身该怎么定义？损失函数（loss function）就是衡量"模型预测与真实答案差多远"的那把尺子。尺子选得对不对，直接决定网络学不学得动、学得好不好。本课讲神经网络里最常用的两类损失：回归用的均方误差（MSE），和分类用的交叉熵（cross-entropy），并解释"为什么分类不该用 MSE"这个经典问题。

一、概念讲解#

1. 回归：均方误差（MSE）#

回归任务要预测连续数值（房价、温度、销量）。最常用的损失是均方误差：

MSE = (1/n) · Σ (ŷᵢ − yᵢ)²

它对"大误差"惩罚特别重（平方放大），所以对少数离群点很敏感。直觉上合理：预测差 10 比差 1 要"严重得多"，理应被狠狠扣分。

2. 分类：交叉熵（Cross-Entropy）#

分类任务要输出"属于每个类别的概率"。此时我们不再直接比较"数值差多少"，而是比较两个概率分布的差异：真实分布（one-hot，正确类别概率为 1）与预测分布。交叉熵度量这两个分布的差距：

二分类：L = −[ y·log(ŷ) + (1−y)·log(1−ŷ) ]
多分类：L = −Σ_k y_k · log(ŷ_k)

其中 ŷ_k 是模型预测样本属于第 k 类的概率，y_k 是真实标签（one-hot）。因为真实标签里只有正确类别那一项是 1，所以多分类的交叉熵实际只留下一项：L = −log(ŷ_正确类别)。也就是说，模型给"正确答案"的概率越高，损失越小；给错了概率接近 0，−log(0) 就趋向无穷，损失极大。

3. 为什么分类不用 MSE？——梯度饱和问题#

这是深度学习里的经典坑。假设二分类，输出经过 sigmoid：ŷ = σ(z)。可以算出两种损失对 z 的梯度：

MSE：      ∂L/∂z = (ŷ − y) · ŷ(1 − ŷ)
交叉熵：   ∂L/∂z = ŷ − y

注意 MSE 的梯度里多了个 ŷ(1−ŷ)。当模型错得离谱时（比如正确答案是 1，模型却输出 ŷ≈0），sigmoid 恰好处于饱和区，ŷ(1−ŷ)≈0，梯度几乎为 0——模型错得越厉害，反而越学不动，训练极慢。而交叉熵的梯度就是简洁的 ŷ − y，错得越多、梯度越大，学得越快。这就是分类任务几乎都用交叉熵的原因。

4. 从 logits 到概率：softmax + 交叉熵#

多分类时，网络最后一层输出的原始分数叫 logits（未归一化）。要把它们变成概率，用 softmax：

ŷ_k = exp(z_k) / Σ_j exp(z_j)

把 softmax 与交叉熵连起来看，有一个极其漂亮的结论：交叉熵对 logits 的梯度 = softmax 概率 − one-hot 标签，即 ∂L/∂z_k = ŷ_k − y_k。这条简洁的梯度，是"softmax + 交叉熵"成为分类标配的深层原因。

工程提示：PyTorch 里做分类，不要手动"先 softmax 再算 NLLLoss"（数值不稳定），而应直接用 nn.CrossEntropyLoss，它内部已包含 softmax 并做了数值稳定处理；二分类同理，推荐 nn.BCEWithLogitsLoss 而不是先 sigmoid。

二、可运行示例#

import torch
import torch.nn as nn

torch.manual_seed(0)

# —— 1. 回归：均方误差 ——
y_true = torch.tensor([1.0, 2.0, 3.0])     # 三个真实值
y_pred = torch.tensor([1.2, 1.8, 3.5])     # 模型预测
mse_loss = nn.MSELoss()
print("MSE =", mse_loss(y_pred, y_true).item())

# —— 2. 二分类：BCEWithLogitsLoss（内部自带 sigmoid）——
# 真实标签：前两个是负类(0)，后两个是正类(1)
labels = torch.tensor([0.0, 0.0, 1.0, 1.0])
logits = torch.tensor([-2.0, 0.1, 1.5, 3.0])   # 未经 sigmoid 的原始分数
bce = nn.BCEWithLogitsLoss()
print("二分类交叉熵 =", bce(logits, labels).item())

# —— 3. 多分类：CrossEntropyLoss（内部自带 softmax）——
# 4 个样本、3 个类别；真实标签分别是类别 0、1、2、1
logits_mc = torch.randn(4, 3)
targets_mc = torch.tensor([0, 1, 2, 1])
ce = nn.CrossEntropyLoss()
print("多分类交叉熵 =", ce(logits_mc, targets_mc).item())

# —— 4. 手算多分类交叉熵，验证公式 ——
# softmax 把 logits 变成概率
def softmax(z):
    e = torch.exp(z - z.max())          # 减去最大值，防止数值溢出
    return e / e.sum(dim=-1, keepdim=True)

probs = softmax(logits_mc)              # (4,3) 每个样本的概率分布
# 取"正确类别"那一项的对数的相反数，再对样本求平均
manual_ce = -torch.log(probs[range(4), targets_mc]).mean()
print("手算交叉熵 =", manual_ce.item())

# —— 5. 对比 MSE 与交叉熵在"错得离谱"时的梯度 ——
# 二分类单样本：正确答案是 1，但模型 logit 很小 -> 预测概率接近 0
z = torch.tensor(-5.0, requires_grad=True)   # 模型输出（远小于 0）
y = torch.tensor(1.0)

# 交叉熵（带 sigmoid）对 z 的梯度
p = torch.sigmoid(z)
loss_ce = -(y * torch.log(p) + (1 - y) * torch.log(1 - p))
loss_ce.backward(retain_graph=True)
print("交叉熵梯度 ∂L/∂z =", z.grad.item())
z.grad.zero_()

# MSE 对 z 的梯度
p = torch.sigmoid(z)
loss_mse = (p - y) ** 2
loss_mse.backward()
print("MSE 梯度 ∂L/∂z =", z.grad.item())

运行后可以看到：模型错得离谱时，交叉熵的梯度仍很大（约 0.99），而 MSE 的梯度几乎为 0（约 0.007）。这就是分类用交叉熵、不用 MSE 的根本原因。

三、练习#

  1. 手推梯度：证明二分类交叉熵 L = −[y·log σ(z) + (1−y)·log(1−σ(z))] 对 z 的导数是 σ(z) − y。再证明 MSE L = (σ(z) − y)² 对 z 的导数是 2(σ(z)−y)σ(z)(1−σ(z))，并说明那个额外的 σ(1−σ) 因子为什么会"拖累"训练。
  2. 改数据试运行：把示例 5 里的 z 改成 +5.0（模型已经很有信心地答对），再分别打印两种损失的梯度，观察它们是否都变小。
  3. 多分类手算：对示例 3 的 logits，把某个样本的 logits 手动改大改小，观察它对应的交叉熵和 softmax 概率如何变化，验证"正确类概率越高、损失越小"。
  4. 思考：为什么 nn.CrossEntropyLoss 的标签参数 targets_mc 直接传类别整数（而不是 one-hot 向量）？这样做有什么好处？
  5. 拓展：查一查"类别不平衡"时交叉熵的缺陷（少数类样本几乎不起作用），想一想可以怎么改进（提示：weight 参数 / Focal Loss）。
