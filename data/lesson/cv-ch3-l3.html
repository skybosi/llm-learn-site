对比与选择#

学到这里，你已经完整走过检测、分割、实例分割、关键点四条技术线。这一课做一次收束：把这四个任务并排放在一起比较，把"两阶段 vs 一阶段""backbone / FPN / head"这些反复出现的组件串成一张网，最后落到一个工程师真正要回答的问题——面对一个实际需求，我该选哪个任务、哪个模型？

这一课不引入新算法，而是把前面所有"知其所以然"的知识，转化成"会做选择"的判断力。

一、概念讲解#

1. 四任务全景对比#

维度 目标检测 语义分割 实例分割 关键点检测
输出粒度 框 + 类别 每像素类别 框 + 每物体掩码 点坐标（+ 热图）
是否区分个体 是 否 是 是（点归属到人）
核心指标 mAP@IoU mIoU mAP + 掩码质量 OKS / PCK
标注成本 中 高（逐像素） 高 中高
代表模型 Faster R-CNN / YOLO FCN / U-Net Mask R-CNN HRNet / OpenPose

看清这张表，很多选择就自然浮现：要"画边界"就别用检测；要"分个体"就别用语义分割；标注预算有限就别轻易上实例分割。

2. 两条贯穿始终的张力线#

回顾全部内容，其实一直在围绕两组张力做折中：

  • 速度 vs 精度：一阶段（YOLO）快、两阶段（Faster R-CNN / Mask R-CNN）准，这是检测/实例分割的主线；
  • 大感受野 vs 高分辨率：下采样拿到语义（"是什么"），上采样拿回空间（"在哪里"），这是分割/关键点的主线。

所有网络组件，本质上都是在给这两组张力找平衡点：

  • backbone（骨干）：负责语义提取，越强越准、也越慢（ResNet → 更强网络）；
  • FPN（特征金字塔）：让不同尺度的物体在"合适的分辨率层级"被检测，是平衡"尺度差异"的关键；
  • head（任务头）：把共享特征翻译成任务要的输出（框、掩码、热图、坐标），决定了网络"擅长什么任务"。

3. 选型决策的四个问题#

拿到一个需求，按顺序问四个问题，基本就能锁定方案：

  1. 要什么粒度的输出？ 框 → 检测；像素类别 → 语义分割；个体掩码 → 实例分割；关键位置 → 关键点。
  2. 实时性要求多高？ 移动端/实时 → 一阶段（YOLO 系列）；离线/高精度 → 两阶段（Faster R-CNN、Mask R-CNN）。
  3. 目标尺度与密集程度如何？ 小目标、密集场景 → 加 FPN、多尺度，或选两阶段；大目标、稀疏 → 一阶段足够。
  4. 能负担多少标注？ 预算低 → 检测或关键点，或先做弱监督/半监督；预算充足且要精细边界 → 分割/实例分割。

4. 工程落地的三个常见坑#

  • 指标与业务目标脱节：论文比 mAP，业务可能更在意"漏检率"或"某一类的召回"。先把业务诉求翻译成指标，再选模型；
  • 无视部署约束：端侧算力、内存、功耗比 mAP 更重要，通常要量化、剪枝、蒸馏或换轻量 backbone；
  • 数据与预训练不匹配：COCO 预训练模型迁移到医疗、遥感、工业场景，域差距大，通常需要在小数据上微调，而非直接推理。

5. 下一步：视觉 Transformer 时代的到来#

我们学到的卷积检测/分割范式，是过去十年的主流。但 ViT / DETR / Swin / Mask2Former 等 Transformer 系方法正在改写规则——它们把图像切成 patch 当 token 处理，用注意力替代手工设计的多尺度结构，在检测、分割上持续刷新精度。下一章"视觉 Transformer"就从这个转折点开始，它是你从"卷积范式"走向"注意力范式"的桥。

二、可运行代码示例#

用 torchvision 的统一接口，把检测、实例分割、关键点三个预训练模型并排跑一遍，对比它们的输出结构差异与单次推理耗时——这正是"选型"时要做的事。

import time
import torch
from torchvision.models.detection import (
    fasterrcnn_resnet50_fpn, FasterRCNN_ResNet50_FPN_Weights,
    maskrcnn_resnet50_fpn, MaskRCNN_ResNet50_FPN_Weights,
    keypointrcnn_resnet50_fpn, KeypointRCNN_ResNet50_FPN_Weights,
)
from torchvision.models.segmentation import fcn_resnet50, FCN_ResNet50_Weights

def bench(build, img):
    model = build().eval()
    with torch.no_grad():
        t0 = time.time()
        out = model([img])
        dt = time.time() - t0
    return dt, out

img = torch.rand(3, 640, 640)

# 目标检测
dt, out = bench(lambda: fasterrcnn_resnet50_fpn(weights=FasterRCNN_ResNet50_FPN_Weights.DEFAULT), img)
print(f"[检测] Faster R-CNN  耗时 {dt*1000:.0f} ms，输出键：{list(out[0].keys())}")

# 实例分割（输出里多了 masks）
dt, out = bench(lambda: maskrcnn_resnet50_fpn(weights=MaskRCNN_ResNet50_FPN_Weights.DEFAULT), img)
print(f"[实例分割] Mask R-CNN 耗时 {dt*1000:.0f} ms，输出键：{list(out[0].keys())}")

# 关键点检测（输出里多了 keypoints）
dt, out = bench(lambda: keypointrcnn_resnet50_fpn(weights=KeypointRCNN_ResNet50_FPN_Weights.DEFAULT), img)
print(f"[关键点] Keypoint R-CNN 耗时 {dt*1000:.0f} ms，输出键：{list(out[0].keys())}")

# 语义分割（不同的接口：返回字典，键为 out/aux）
seg = fcn_resnet50(weights=FCN_ResNet50_Weights.DEFAULT).eval()
with torch.no_grad():
    t0 = time.time()
    out = seg(img.unsqueeze(0))
    dt = time.time() - t0
print(f"[语义分割] FCN 耗时 {dt*1000:.0f} ms，输出键：{list(out.keys())}，逐像素输出形状：{tuple(out['out'].shape)}")

注意输出结构里藏着任务差异：检测只有 boxes/labels/scores；实例分割多出 masks；关键点检测多出 keypoints/keypoint_scores；语义分割干脆换了个接口，返回逐像素类别图而不是框列表。同一张图、同一种骨干，任务不同，输出形态与耗时完全不同——这就是选型要面对的直观现实。
