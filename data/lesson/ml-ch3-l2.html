特征缩放标准化#

现实数据里，不同特征常常差着好几个数量级：身高 170 厘米、年收入 20 万、房子面积 90 平。如果直接把这样的数据喂给模型，量级大的特征会"霸凌"量级小的特征。本课讲清楚为什么要缩放以及 sklearn 里几种常用的缩放器。

一、概念讲解#

1. 为什么要缩放#

很多模型的数学核心是计算样本间的距离（如 K 近邻、KMeans）或基于梯度/正则化优化（如逻辑回归、支持向量机）。如果特征量纲差异巨大：

  • 对距离型模型：距离几乎完全由"大数值特征"主导，小数值特征被忽略。
  • 对梯度型模型：不同特征的梯度尺度不一，收敛变慢，甚至震荡。

缩放把所有特征拉到相近的量级，让每个特征"公平地"参与计算。

2. 三种常用缩放器#

  • StandardScaler（标准化）：把每列变成"均值 0、标准差 1"，公式 z = (x - mean) / std。它不把数据限制在某个固定区间，且对异常值敏感。最常用，是大多数算法的默认首选。
  • MinMaxScaler（归一化/最小-最大缩放）：把每列线性缩放到 [0, 1]，公式 (x - min) / (max - min)。适合需要非负、有界输出的场景（如神经网络、某些图像处理），但对异常值非常敏感。
  • RobustScaler（稳健缩放）：用中位数和四分位距（IQR）代替均值和标准差，公式 (x - median) / IQR。对异常值鲁棒，适合数据里混有离群点的情况。

3. 两个要点#

  • 缩放器是变换器，同样遵守"训练集 fit_transform、测试集 transform"的约定。
  • 缩放会改变特征的实际数值和单位，因此解释模型时（如看系数）要注意特征已被变换过。树模型（决策树、随机森林）本身不依赖距离，通常可以不缩放。

二、可运行代码示例#

我们用一个特征量纲差异极大的葡萄酒数据集，直观对比"缩放前后"对 KNN 分类的影响。

import pandas as pd
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

# 葡萄酒数据集：13 个理化指标（酒精含量约 13，镁约 100，脯氨酸约 700，量纲差异大）
wine = load_wine()
X, y = wine.data, wine.target
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# 先看看各特征的量纲差异有多大
df = pd.DataFrame(X, columns=wine.feature_names)
print("缩放前各特征均值：", df.mean().round(1).to_list())

knn = KNeighborsClassifier(n_neighbors=5)

# ---- 未缩放：直接训练 ----
knn.fit(X_train, y_train)
print("\n未缩放 KNN 准确率：", round(accuracy_score(y_test, knn.predict(X_test)), 3))

# ---- StandardScaler：均值 0、标准差 1 ----
ss = StandardScaler()
X_train_s = ss.fit_transform(X_train)
X_test_s = ss.transform(X_test)
knn.fit(X_train_s, y_train)
print("StandardScaler 后 KNN 准确率：",
      round(accuracy_score(y_test, knn.predict(X_test_s)), 3))
print("标准化后训练集第 1 列均值（应≈0）：", round(X_train_s[:, 0].mean(), 6))
print("标准化后训练集第 1 列标准差（应≈1）：", round(X_train_s[:, 0].std(), 6))

# ---- MinMaxScaler：缩放到 [0, 1] ----
mm = MinMaxScaler()
X_train_m = mm.fit_transform(X_train)
X_test_m = mm.transform(X_test)
knn.fit(X_train_m, y_train)
print("MinMaxScaler 后 KNN 准确率：",
      round(accuracy_score(y_test, knn.predict(X_test_m)), 3))

# ---- RobustScaler：用中位数和四分位距，抗异常值 ----
rb = RobustScaler()
X_train_r = rb.fit_transform(X_train)
X_test_r = rb.transform(X_test)
knn.fit(X_train_r, y_train)
print("RobustScaler 后 KNN 准确率：",
      round(accuracy_score(y_test, knn.predict(X_test_r)), 3))

运行后，未缩放的 KNN 准确率通常明显低于缩放后，这直观地说明了"量纲不统一会损害距离型模型"。三种缩放器效果相近时，日常开发优先选 StandardScaler 即可。

三、练习#

  1. 填空：StandardScaler 把每列变换成均值为 ____、标准差为 ____；MinMaxScaler 把每列变换到区间 ____。
  2. 判断：随机森林、决策树这类树模型对特征缩放不敏感，因此不一定需要缩放。这句话对吗？为什么？
  3. 动手实验：在 load_wine 数据里人为注入一个离群点（例如把某行第一个特征改成原来的 100 倍），分别用 StandardScaler 和 RobustScaler 缩放后再跑 KNN，观察哪个更稳定。
  4. 思考题：为什么说 MinMaxScaler 对异常值特别敏感？如果某列本来在 [0, 100]，突然出现一个 10000 的异常值，MinMaxScaler 会把正常值挤到哪里去？
