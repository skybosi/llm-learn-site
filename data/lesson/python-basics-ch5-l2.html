元组 tuple#

一、概念讲解#

元组（tuple）和列表很像，也是一个有序的、可以存放多个元素的容器。区别只有关键的一点：元组一旦创建，就不能修改——不能增、删、改里面的元素。我们把这种特性称为"不可变"（immutable）。

可以这样理解：列表像一张可以反复涂改的草稿纸，元组则像一份打印出来的合同，写上去就定死了。

1. 创建元组#

元组用一对圆括号 () 表示，元素之间用逗号分隔：

point = (3, 5)              # 表示一个坐标
days = ("周一", "周二", "周三")

要特别小心一个坑：只有一个元素的元组，必须在元素后面加一个逗号，否则 Python 会把它当成普通括号里的值，而不是元组：

a = (10)      # 这是整数 10，不是元组
b = (10,)     # 这才是只有一个元素的元组

print(type(a))  # <class 'int'>
print(type(b))  # <class 'tuple'>

2. 访问元素#

和列表一样，元组也支持索引和切片，只是不能修改：

days = ("周一", "周二", "周三", "周四", "周五")
print(days[0])      # 周一
print(days[-1])     # 周五
print(days[1:3])    # ('周二', '周三')

如果你尝试修改元组，Python 会直接报错：

days[0] = "周日"   # TypeError: 'tuple' object does not support item assignment

3. 打包与解包#

元组有一个非常方便的用法叫"解包"（unpacking），可以把元组里的元素一次性分配给多个变量：

point = (3, 5)
x, y = point        # 同时给 x 和 y 赋值
print(x)  # 3
print(y)  # 5

反过来，把多个值直接写在一起，Python 也会自动把它们打包成元组：

coords = 10, 20     # 相当于 coords = (10, 20)
print(coords)       # (10, 20)

4. 什么时候用元组#

  • 数据在程序运行期间不应该被意外修改时（例如固定的配置、坐标、日期）。
  • 函数需要返回多个值时，Python 内部就是用元组来打包返回结果的。
  • 元组可以作为字典的键，而列表不行（因为元组不可变，天然适合当"身份证号"）。

二、可运行代码示例#

# ---- 1. 创建与访问 ----
profile = ("小明", 20, "北京")   # 姓名、年龄、城市
print("档案：", profile)
print("姓名：", profile[0])
print("年龄：", profile[1])

# ---- 2. 解包 ----
name, age, city = profile
print(f"{name} 今年 {age} 岁，住在 {city}")

# ---- 3. 遍历元组 ----
week = ("周一", "周二", "周三", "周四", "周五")
for day in week:
    print("工作日：", day)

# ---- 4. 元组不可变，但可以做"组合" ----
a = (1, 2)
b = (3, 4)
combined = a + b        # 拼接成新元组，原来的 a、b 不变
print("拼接结果：", combined)
print("重复：", a * 3)   # 重复三次

# ---- 5. 常用方法 ----
nums = (3, 1, 2, 1, 5)
print("元素个数：", len(nums))
print("1 出现了几次：", nums.count(1))
print("2 的索引：", nums.index(2))

# ---- 6. 元组作为字典的键 ----
routes = {}
routes[("北京", "上海")] = "高铁 4.5 小时"
print(routes[("北京", "上海")])
