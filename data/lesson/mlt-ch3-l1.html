贝叶斯与最大后验 MAP#

第 2 章告诉我们损失函数从"数据生成假设"来（MLE）。但 MLE 有一个盲区：它只信数据，完全不理会"参数本身哪个取值更合理"。贝叶斯学派补上了这一环——给参数也安一个概率分布（先验），再综合数据得到后验。这一课讲清楚贝叶斯估计，以及它最常用的点估计版本 MAP（最大后验）。你会发现一个惊人的事实：MAP 就是"正则化的 MLE"，而正则项就是先验的对数。这为后两课"从先验推出岭回归/Lasso"埋下伏笔。

一、概念讲解#

1. 频率派 vs 贝叶斯派：参数是不是随机变量#

  • 频率派（MLE）：参数 θ 是一个固定但未知的常数，数据 x 是随机变量。目标是找到那个最可能产生数据的 θ。
  • 贝叶斯派：把 θ 也当作随机变量，我们对它有一个"先验信念" P(θ)。观测到数据后，用贝叶斯公式更新这个信念。

贝叶斯公式是唯一的运算规则：

P(θ | x) = P(x | θ) · P(θ) / P(x)

读作：

后验 ∝ 似然 × 先验

P(x) = ∫ P(x|θ)P(θ)dθ 是归一化常数（证据）。先验 P(θ) 编码"见到数据之前，我们认为哪些 θ 更可能"，这是频率派完全放弃、而贝叶斯派抓住不放的信息。

2. 三种用后验做决策的方式#

拿到后验 P(θ|x) 之后，有三种用法：

  • 完全贝叶斯（后验预测）：不挑单个 θ，而是对所有 θ 按后验加权积分：P(x_new | x) = ∫ P(x_new|θ) P(θ|x) dθ。理论上最优，但积分通常不可解。
  • MAP（最大后验）：取后验最大的那个点：θ̂_MAP = argmax_θ P(θ|x)。它把"分布"压缩成"一个点"，牺牲了不确定性，换来了可计算性。
  • 后验采样 / 贝叶斯平均：从后验里采样或做变分近似，介于两者之间。

机器学习的正则化，几乎都来自 MAP。所以这一课聚焦 MAP。

3. MAP 的推导：后验最大化 = 似然 + 先验#

取后验最大：

θ̂_MAP = argmax_θ P(θ|x)
       = argmax_θ [ P(x|θ) · P(θ) ]          （分母 P(x) 与 θ 无关）
       = argmax_θ [ log P(x|θ) + log P(θ) ]  （取对数，单调变换）
       = argmin_θ [ −log P(x|θ) − log P(θ) ]

写成经验风险的样子（假设 i.i.d.）：

θ̂_MAP = argmin_θ (1/m)Σᵢ [−log P(xᵢ|θ)]  +  (1/m)·[−log P(θ)]
       = argmin_θ 经验风险  +  正则项

这就是 MAP 的核心结论：与 MLE 相比，MAP 只是多了一项 −log P(θ)。这一项只依赖参数、不依赖数据，正是第 1 章 SRM 里那个"拍脑袋加进去"的正则项 λR(θ)。于是：

MLE + 先验  =  MAP
似然 + 先验  =  经验风险 + 正则项

正则化从来不是工程补丁，而是"给参数安了先验"之后的必然结果。

4. 例：硬币问题，MLE vs MAP#

掷硬币 m 次得 k 次正面。MLE 给出 θ̂ = k/m。若 m 很小（比如 3 次全反面），MLE 会断言 θ̂ = 0——"硬币永远不可能出正面"，这显然是过拟合。贝叶斯派给 θ 一个 Beta 先验 Beta(α, β)：

P(θ) ∝ θ^{α−1} (1−θ)^{β−1}

后验仍为 Beta（Beta 是伯努利的共轭先验）：P(θ|x) = Beta(α+k, β+m−k)。其 MAP 为：

θ̂_MAP = (k + α − 1) / (m + α + β − 2)

当 α=β=1（均匀先验）时，MAP 退化为 MLE k/m；当 α,β > 1 时，MAP 把估计往"先验中心"拉了一点。3 次全反面时，取 α=β=2 得 θ̂ = (0+1)/(3+2) = 0.2——先验避免了"零概率"这个过拟合结论。这正是正则化"把极端估计往温和处拉"的微观机理。

5. 先验的三个作用#

  1. 编码领域知识：把"参数大致在哪个范围"的事先判断写进模型；
  2. 对抗过拟合：小样本时，先验起平滑作用，防止参数被噪声牵着走；
  3. 可解释性：正则项不再是黑箱，它有一个概率故事（后两课展开）。

代价是：先验选得不好，会引入系统性偏差（把估计往错误方向拉）。所以贝叶斯不是免费午餐，它是"用偏差换方差"的显式工具（第 4 章）。

二、可运行代码示例#

用手算验证硬币问题的 MLE 与 MAP：固定一个真实的 θ*，模拟"小样本"（3 次、10 次）与"大样本"（1000 次），对比 θ̂_MLE = k/m 与 θ̂_MAP = (k+α−1)/(m+α+β−2)，观察先验在小样本时如何拉近估计、大样本时又如何被数据淹没。

import numpy as np

rng = np.random.default_rng(11)
theta_true = 0.2
alpha, beta = 2.0, 2.0        # Beta(2,2) 先验，中心在 0.5

def estimate(m):
    flips = rng.random(m) < theta_true
    k = int(flips.sum())
    mle = k / m
    map_ = (k + alpha - 1) / (m + alpha + beta - 2)
    return k, mle, map_

print(f"真实 θ* = {theta_true}\n")
print(f"{'样本量 m':>8} | {'k':>4} | {'MLE':>8} | {'MAP(先验拉向0.5)':>16}")
for m in [3, 10, 100, 1000]:
    k, mle, map_ = estimate(m)
    print(f"{m:>8} | {k:>4} | {mle:>8.4f} | {map_:>16.4f}")

运行后你会看到清晰的趋势：m=3 时 MLE 可能给出 0 或 0.33 这类极端值，而 MAP 被先验拉向 0.5 附近；随着 m 增大，MLE 和 MAP 越来越接近真实值 0.2。先验在小样本时"发言权"大，在大样本时被数据"投票"淹没——这就是正则化强度随数据量相对变化的本质。

三、练习#

  1. 从贝叶斯公式出发，逐步推导 θ̂_MAP = argmin_θ [−log P(x|θ) − log P(θ)]，说明每一步（约掉分母、取对数、变号）为何合法。
  2. 证明 Beta 分布是伯努利分布的共轭先验：若先验 Beta(α,β)、似然 Binom(k;m,θ)，则后验为 Beta(α+k, β+m−k)。
  3. 当先验取均匀分布 Beta(1,1) 时，验证 MAP 退化为 MLE；当 α,β → ∞（先验极度集中）时，MAP 会怎样？这对应正则化里的什么情形（λ→∞）？
  4. 思考：MAP 只取后验的"最高点"，会丢失什么信息？举一个"后验双峰、MAP 只取一峰"的例子，说明为什么完全贝叶斯在不确定性强时优于 MAP。

母原理连接#

本课属于母原理 "概率视角统一"，并给出了正则化的概率根基。核心一句：MAP = MLE + 先验，正则项 = 先验的负对数。这条等式把第 1 章"优化视角的正则项"与本章"概率视角的先验"焊在了一起——从此正则化不再是玄学调参，而是"你在声明自己相信参数服从什么分布"。后两课把这个等式具体化：高斯先验 → 岭回归，拉普拉斯先验 → Lasso。
