完整预测流程#

规划做好了，这一课我们把一个预测项目从头到尾跑通：从原始数据，到训练集、验证集、测试集，到模型训练、调参、最终在测试集上做一次"只许用一次"的评估，最后把预测还原成业务可读的结果。这是一条标准化流水线，掌握了它，任何预测任务都能照葫芦画瓢地走完。我们用一个 LSTM 多变量模型作例子，但流水线的每一步与模型无关——换成 Transformer 或 Informer 只需替换中间的模型模块。

一、概念讲解#

1. 流水线的六步骨架#

一个完整的预测项目，无论用什么模型，都逃不过这六步：

  1. 加载与清洗：读入数据、处理缺失与异常、对齐时间戳；
  2. 特征工程：构造协变量、周期特征、滞后特征；
  3. 划分与标准化：按时间顺序切 train/val/test，用训练集统计量做标准化；
  4. 建窗口样本：把序列切成 (输入窗口, 输出窗口) 的监督学习样本；
  5. 训练与验证：在训练集上优化，在验证集上选超参、做早停；
  6. 测试与还原：在测试集上评估一次，逆标准化还原真实量纲。

其中最关键、最容易被做错的是第 3、4 步——时序的切分和窗口构造必须严格避免未来信息泄露。

2. 标准化的正确姿势#

标准化（z-score）必须只用训练集的均值和方差，然后用同一组统计量去标准化验证集和测试集。因为验证集、测试集模拟的是"未来"，未来数据的统计量在真实部署时是拿不到的。如果用全量数据算均值方差，等于偷偷告诉了模型未来的信息。预测后，还要用训练集那组统计量逆标准化，把预测值还原回原始量纲。

3. 窗口构造：监督学习的视角#

窗口构造是把时序问题转成监督学习的关键一步。用输入窗口长度 in_len 和输出窗口长度 out_len，在序列上滑动，每个窗口产生一条样本：输入 [x_t, ..., x_{t+in_len-1}]，标签 [x_{t+in_len}, ..., x_{t+in_len+out_len-1}]。注意窗口只能在训练段内部滑动，绝不能滑过训练/验证的边界——否则训练样本里就混进了验证集的信息。

4. 验证与早停：防止过拟合#

训练时每过几个 epoch 就在验证集上算一次 loss。验证 loss 不降反升且持续若干轮，就早停并回滚到验证 loss 最优的权重。这防止模型把训练集的噪声也背下来。验证集是"调参的裁判"，测试集是"最终验收的裁判"，两者要严格隔离——测试集只在最后一刻用一次，反复在测试集上调参等于把测试集也变成了验证集。

5. 最终产出：还原 + 可视化 + 指标#

在测试集上跑出预测后，先逆标准化，再和真实值画对比图，计算 MAE/RMSE 等指标。图和指标都要看：图能暴露"指标看着还行、但相位整体错位"这类系统性问题，指标能给出可比较的量化结论。二者结合，才算一个完整的交付。

二、可运行代码示例#

下面把六步完整走一遍。数据沿用上一课的日销量（趋势 + 周周期 + 噪声），模型用 LSTM，输入过去 14 天预测未来 7 天。每一步都标了序号，与骨架一一对应。

import numpy as np
import pandas as pd
import torch
import torch.nn as nn
from sklearn.metrics import mean_absolute_error, mean_squared_error

torch.manual_seed(0)
np.random.seed(0)

# ① 加载与清洗：构造一份"日销量"，含周周期
dates = pd.date_range("2022-01-01", periods=730, freq="D")
t = np.arange(730)
sales = 0.05 * t + 8 * np.sin(t * 2 * np.pi / 7) + np.random.randn(730) * 2
sales[200] = 80                                   # 异常值
sales[400:405] = np.nan                           # 缺失
df = pd.DataFrame({"date": dates, "sales": sales})
df["sales"] = df["sales"].ffill()                 # 简单前向填充

# ② 特征工程：加"星期几"作为协变量（周期特征，未来可知）
df["dow"] = df["date"].dt.dayofweek.values / 6.0  # 归一化到 [0,1]
values = df[["sales", "dow"]].values.astype(np.float32)   # (730, 2)

# ③ 划分与标准化：先按时间切分，再用"训练集"统计量标准化
n = len(values)
tr_end, va_end = int(n * 0.7), int(n * 0.85)
train_raw, val_raw, test_raw = values[:tr_end], values[tr_end:va_end], values[va_end:]
mu, sigma = train_raw.mean(axis=0), train_raw.std(axis=0) + 1e-6
train = (train_raw - mu) / sigma
val = (val_raw - mu) / sigma
test = (test_raw - mu) / sigma

# ④ 建窗口样本：输入 in_len 步，输出 out_len 步（只预测 sales，第 0 列）
IN_LEN, OUT_LEN = 14, 7
def make_dataset(seg):
    X, y = [], []
    for i in range(len(seg) - IN_LEN - OUT_LEN):
        X.append(seg[i:i + IN_LEN])                    # (in_len, 2)
        y.append(seg[i + IN_LEN:i + IN_LEN + OUT_LEN, 0])  # (out_len,)
    return (torch.tensor(X), torch.tensor(y))

X_tr, y_tr = make_dataset(train)
X_va, y_va = make_dataset(val)
X_te, y_te = make_dataset(test)
print("样本数  训练/验证/测试:", X_tr.shape[0], X_va.shape[0], X_te.shape[0])

# ⑤ 训练与验证：LSTM 多步预测 + 早停
class ForecastLSTM(nn.Module):
    def __init__(self, in_feat=2, hidden=32, out_len=7):
        super().__init__()
        self.lstm = nn.LSTM(in_feat, hidden, batch_first=True)
        self.fc = nn.Linear(hidden, out_len)
    def forward(self, x):
        out, (h, c) = self.lstm(x)
        return self.fc(h[-1])                          # 最后一步隐藏状态 → 未来 7 步

model = ForecastLSTM()
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

best_va, best_state, patience = float("inf"), None, 0
for epoch in range(2000):
    model.train()
    optimizer.zero_grad()
    loss = criterion(model(X_tr), y_tr)
    loss.backward()
    optimizer.step()
    # 验证 + 早停
    model.eval()
    with torch.no_grad():
        va_loss = criterion(model(X_va), y_va).item()
    if va_loss < best_va:
        best_va, patience, best_state = va_loss, 0, model.state_dict()
    else:
        patience += 1
        if patience >= 30:
            print(f"早停于 epoch {epoch+1}，验证 loss={best_va:.4f}")
            break

model.load_state_dict(best_state)

# ⑥ 测试与还原：测试集只评估这一次
model.eval()
with torch.no_grad():
    pred = model(X_te).numpy()                          # (n_test, 7)
# 逆标准化：只还原第 0 列（sales）
pred_sales = pred * sigma[0] + mu[0]
true_sales = y_te.numpy() * sigma[0] + mu[0]
mae = mean_absolute_error(true_sales, pred_sales)
rmse = np.sqrt(mean_squared_error(true_sales, pred_sales))
print(f"测试集  MAE={mae:.3f}  RMSE={rmse:.3f}")
print("首个测试样本：真实未来7天 vs 预测7天")
print("真实:", np.round(true_sales[0], 1))
print("预测:", np.round(pred_sales[0], 1))

走完这六步，你就拥有了一个可复用的预测流水线。几个必须记住的细节：

  • 标准化的 mu/sigma 只来自训练集，验证/测试用同一组，预测后再逆标准化——三处必须严格配对；
  • 窗口在各自段内滑动，训练样本与验证样本不重叠，杜绝边界泄露；
  • 测试集在全程只被调用了一次（最后一步），早停和调参全靠验证集，这是"测试集只许用一次"的纪律。

三、练习#

  1. 把 LSTM 换成你在第五章学的 Transformer 编码器（只替换模型类），其余流水线不动，跑一遍并比较 MAE。体会"流水线与模型解耦"的设计价值。
  2. 去掉 dow 协变量（只保留 sales 一列）重跑，观察周周期是否更难学到。这说明了特征工程对精度的贡献。
  3. 把 IN_LEN 从 14 改成 7 和 28，观察验证 loss 变化。输入窗口长度如何影响模型"看到多少历史"与"过拟合风险"？
  4. 写一段代码，检查训练样本与验证样本在时间轴上是否重叠。如果重叠，会怎样污染评估？你如何修正？
