算法选择：消息大小、拓扑与数值确定性#

前两课把账本与用途对齐了，但"该选哪个"不能靠背结论：算法选错可以差几倍；更隐蔽的是，换算法、换消息大小甚至换并行度都会改变浮点加法的顺序，让两次本该相同的训练出现位级差异。这一课把选择收敛成三条判据：消息大小、拓扑（跨机带宽是否共享）、数值（求和顺序是否固定），并全部用可打印的模型算出来。

一、概念讲解#

1. 判据一：消息大小——解交叉点，而不是记口诀#

把两个算法的 α-β 代价写成直线，交点就是换算法的点：

Tring​=2(p−1)α+p2(p−1)​⋅βs​,Ttree​=2⌈lgp⌉α+2⌈lgp⌉⋅βs​

两边相等解出 s∗=2⌈lgp⌉−p2(p−1)​(2(p−1)−2⌈lgp⌉)αβ​。用示例参数 p=8、α=5 μs、β=300 GB/s 代入得 2.69 MiB：比它小的消息该用步数少的算法，比它大的该用 ring。注意 ring 与 butterfly 的带宽斜率相同（都是 p2(p−1)​s/β），所以均匀模型下二者没有有限交叉点——butterfly 在账面上全面占优，直到你把拓扑写进模型。

Thakur 等人在 MPICH 里的实测结论也提示了这一点：≤ 32 B 时递归倍增最好，≤ 1 KB 时二项树最好，更长时环算法在部分尺寸与进程数下更好——换算法的阈值随规模与机器滑动。

2. 判据二：拓扑——把"跨机带宽是否共享"写进模型#

α-β 模型默认"每张卡有自己独立的 β"，而真实机器的跨机路径是共享资源：4 个节点各自一张 NIC，跨机字节要排队。加上这条约束，模型立刻变脸：

消息 s ring butterfly 谁快（示例参数、跨机汇总 100 GB/s）
4 KiB 600.3 μs 100.3 μs butterfly（延迟主导）
1 MiB 678.6 μs 273.0 μs butterfly
16 MiB 1858.3 μs 4067.5 μs ring（大消息塞满跨机通道）
256 MiB 20732.7 μs 64780.1 μs ring

交叉点在 3.33 MiB 附近。原因是 butterfly 末尾几步每 rank 要发 s/2 且伙伴在距离 p/2 处：一步之内全体跨机字节数是 ring 单步的很多倍，全挤在共享通道上排队。

这也正是 NCCL 的行为：NCCL_ALGO 默认 unset 时"由 NCCL 根据节点拓扑与架构自动选择可用算法"；历史上（2.4 引入、2.5 移除）的 NCCL_TREE_THRESHOLD，文档定义就是"小于该尺寸时用树算法而不是环"；NVIDIA 的双二叉树博客也写了"当树拿不到更大带宽时 NCCL 会自动切回 ring"。所以正确做法不是手选算法，而是先量自己的 α/β 与拓扑（nvidia-smi topo -m、nccl-tests），让库去选，只在怀疑启发式选错时用 NCCL_ALGO 强制对比。

3. 判据三：数值确定性——浮点加法不满足结合律#

归约顺序取决于算法（ring / 树 / butterfly 各不相同）与并行度（p 一变，归约树就变）。float32 下这些差异是真实可测的位级差异。实测（16 份 float32、各 20 万元素，同一个逐元素和）：

累加顺序 与 float64 参考的最大绝对误差 与"顺序累加"位不同的元素
顺序累加（rank 0→15） 3.487e-06 0 / 200000
两两配对（树形） 1.431e-06 133106 / 200000
ring 环序 3.658e-06 141683 / 200000

只改参与归约的份数（16 → 8 / 4 / 2），位不同的元素分别有 123341 / 126177 / 118373 个。两点结论：① 换算法、换并行度必然改变末尾几位，当 bug 查白费力气；② 树形累加反而更接近精确值（1.4e-6 vs 3.5e-6）——先合并小量级更稳。

PyTorch 文档在 SDPA 那节把同一件事写得很直白："不同后端之间的位级匹配不保证，因为每个后端按不同的顺序做浮点累加，而浮点加法不满足结合律"。要可复现就得固定求和顺序：固定 NCCL_ALGO / NCCL_PROTO（文档明确劝退随意设 NCCL_PROTO）、固定 world size 与分桶，必要时开 torch.use_deterministic_algorithms(True)（确定实现更慢）。

4. 常见坑#

  • 把位级差异当 bug 查，或以为"同一个和"天然逐位一致。
  • 用不同 world size 续训后逐位对比 loss——先想清楚你要"统计等价"还是"位级一致"。
  • 只在单机测 α/β 就外推到多机：跨机 β 与 bisection 会让结论反转（上面的 3.33 MiB）。
  • 拿链路标称带宽当有效带宽（有效带宽低于标称是常态）；把同步等待、慢节点也归成"算法不好"（第 3、4 章展开）。

5. 一张决策清单#

场景 选择 理由
小消息（几 MiB 以下）、跨机多 tree / butterfly 延迟项 O(logp)
大消息、跨机带宽共享 ring 只走邻居链路，单步跨机字节少
同一节点内（NVLink 域） butterfly / tree 常占优 步数少、远距离步代价低
需要位级复现 固定算法、协议、world size、分桶 求和顺序固定
低精度累加 优先树形（两两配对）顺序 部分和量级增长慢

阈值都要用实测 α/β 重算：2.69 / 3.33 MiB 只是示例参数下的结果。

二、可运行代码示例#

第一段：把步数、每步消息、是否跨机记成账，再用两个模型（每卡独立链路 / 跨机带宽共享）算时间，并解出交叉点。第二段：位级确定性实验。

# ===== 示例 1：把通信记成账（步数 / 每步消息 / 是否跨节点），再套 α-β 模型比时间 =====
import math
import numpy as np

N_ELEM = 4096          # 模拟用的小缓冲区：只用来数"每步发多少"，字节数按比例缩放到真实 s
ITEM = 8               # float64


def sim_ring(P, g):
    """ring：每步每 rank 发 s/P，邻居关系决定是否跨节点。"""
    m = N_ELEM * ITEM // P
    steps = []
    for _ in range(2 * (P - 1)):
        b, c = [], []
        for r in range(P):
            nb = (r + 1) % P
            b.append(m); c.append((r // g) != (nb // g))
        steps.append((b, c))
    return steps


def sim_tree(P, g):
    """二项树：归约 lg P 步 + 广播 lg P 步，每步发送整个缓冲区。"""
    lg = int(math.log2(P))
    steps = []
    for k in range(lg):                                   # 归约
        b, c = [0] * P, [False] * P
        for r in range(P):
            if (r >> k) & 1:
                b[r] = N_ELEM * ITEM
                c[r] = (r // g) != ((r ^ (1 << k)) // g)
        steps.append((b, c))
    for k in reversed(range(lg)):                         # 广播
        b, c = [0] * P, [False] * P
        for r in range(P):
            if (r >> k) & 1:
                p = r ^ (1 << k)
                b[p] = N_ELEM * ITEM
                c[p] = (p // g) != (r // g)
        steps.append((b, c))
    return steps


def sim_butterfly(P, g):
    """递归折半 reduce-scatter + 递归倍增 allgather。"""
    m = N_ELEM * ITEM // P
    held = [set(range(P)) for _ in range(P)]
    steps = []
    mask = P // 2
    while mask >= 1:
        b, c = [0] * P, [False] * P
        for r in range(P):
            gv = [x for x in held[r] if (x & mask) != (r & mask)]
            b[r] = len(gv) * m
            c[r] = (r // g) != ((r ^ mask) // g)
        for r in range(P):
            held[r] = {x for x in held[r] if (x & mask) == (r & mask)}
        steps.append((b, c)); mask //= 2
    mask = 1
    while mask < P:
        b, c = [0] * P, [False] * P
        sends = []
        for r in range(P):
            gv = [x for x in held[r] if (x & mask) == (r & mask)]
            sends.append(gv); b[r] = len(gv) * m
            c[r] = (r // g) != ((r ^ mask) // g)
        for r in range(P):
            held[r] = held[r] | set(sends[r ^ mask])
        steps.append((b, c)); mask *= 2
    return steps


def t_total(steps, s, alpha_l, beta_l, alpha_n, beta_n):
    """每步取"最慢那个 rank"的 α + 字节/β；跨节点的消息按跨机 β 计价。返回 μs。"""
    scale = s / (N_ELEM * ITEM)
    tot = 0.0
    for b, c in steps:
        worst = 0.0
        for nb, cross in zip(b, c):
            if nb == 0:
                continue
            a, be = (alpha_n, beta_n) if cross else (alpha_l, beta_l)
            worst = max(worst, a + nb * scale / (be * 1e9) * 1e6)
        tot += worst
    return tot


def t_bisection(steps, s, alpha_l, beta_l, alpha_n, beta_n, beta_bis):
    """再叠一条约束：跨机总带宽被所有节点共享（bisection），整步的跨机字节数一起排队。"""
    scale = s / (N_ELEM * ITEM)
    tot = 0.0
    for b, c in steps:
        worst = 0.0
        cross_bytes = 0.0
        for nb, cross in zip(b, c):
            if nb == 0:
                continue
            a, be = (alpha_n, beta_n) if cross else (alpha_l, beta_l)
            worst = max(worst, a + nb * scale / (be * 1e9) * 1e6)
            if cross:
                cross_bytes += nb * scale
        tot += max(worst, cross_bytes / (beta_bis * 1e9) * 1e6)
    return tot


P, g = 16, 4                       # 16 个 rank，每节点 4 卡 → 4 节点
algos = {"ring": sim_ring(P, g), "tree": sim_tree(P, g), "butterfly": sim_butterfly(P, g)}
print(f"P = {P}，每节点 {g} 卡（共 {P//g} 节点）")
for k, st in algos.items():
    msgs = sum(len(b) for b, _ in st)
    cross = sum(sum(c) for _, c in st)
    print(f"  {k:<10} 步数 {len(st):2d} | 跨节点消息 {cross:3d}/{msgs} | "
          f"每步消息/s 最大 {max(max(b) for b, _ in st)/(N_ELEM*ITEM):.3f}")

# 示例参数：节点内 ≈NVLink 级、跨节点 ≈NIC 级（一律标注为示例值，请用实测替换）
A_L, B_L, A_N, B_N = 5.0, 300.0, 20.0, 25.0
B_BIS = 4 * 25.0                   # 4 个节点的跨机带宽汇总，示例值
print(f"\nα/β 示例参数：节点内 {A_L} μs / {B_L} GB/s，跨节点 {A_N} μs / {B_N} GB/s，"
      f"跨机汇总 {B_BIS} GB/s")
print(f"{'消息 s':>10} {'ring':>10} {'tree':>10} {'butterfly':>10}   最快")
for kb in (4, 64, 1024, 16384, 262144):
    s = kb * 1024
    t = {k: t_total(st, s, A_L, B_L, A_N, B_N) for k, st in algos.items()}
    row = "".join(f"{t[k]:>10.1f}" for k in ("ring", "tree", "butterfly"))
    print(f"{kb:>7} KiB{row}   {min(t, key=t.get)}")

print(f"\n加上跨机汇总带宽约束（{B_BIS:.0f} GB/s，跨机字节一起排队）：")
print(f"{'消息 s':>10} {'ring':>10} {'butterfly':>10}   最快")
for kb in (4, 64, 1024, 16384, 262144):
    s = kb * 1024
    tr = t_bisection(algos["ring"], s, A_L, B_L, A_N, B_N, B_BIS)
    tb = t_bisection(algos["butterfly"], s, A_L, B_L, A_N, B_N, B_BIS)
    print(f"{kb:>7} KiB{tr:>10.1f}{tb:>10.1f}   {'ring' if tr < tb else 'butterfly'}")

s_swap = 4 * 2**20                 # 演示用：4 MiB
def swap_size(lo=1024.0, hi=float(1 << 34)):
    f = lambda s: t_bisection(algos["butterfly"], s, A_L, B_L, A_N, B_N, B_BIS) - \
                  t_bisection(algos["ring"], s, A_L, B_L, A_N, B_N, B_BIS)
    sign_lo = 1 if f(lo) > 0 else -1
    for _ in range(100):
        mid = (lo + hi) / 2
        if (1 if f(mid) > 0 else -1) == sign_lo:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2


print(f"\n交叉点：≤ {swap_size()/2**20:.2f} MiB 时 butterfly 更快，"
      f"更大时 ring 更快（跨机带宽被共享的拓扑）")

# ===== 示例 2：均匀 β 下直接解交叉点（解析式 + 数值） =====
def crossover_uniform(a_slow, b_slow, a_fast, b_fast, alpha_us, beta_gbs):
    """T = A·α + B·s/β。两条直线的斜率差为 0 时没有有限交叉点，返回 None。"""
    if b_fast <= b_slow:
        return None
    return (a_slow - a_fast) * (alpha_us * 1e-6) * (beta_gbs * 1e9) / (b_fast - b_slow)


p_, lg_ = 8, 3
ring_a, ring_b = 2 * (p_ - 1), 2 * (p_ - 1) / p_       # 14·α + 1.75·s/β
tree_a, tree_b = 2 * lg_, 2 * lg_                      # 6·α + 6·s/β
bfly_a, bfly_b = 2 * lg_, 2 * (p_ - 1) / p_            # 6·α + 1.75·s/β
print("\n均匀 β 下的解析交叉点（P=8、α=5 μs、β=300 GB/s 示例参数）：")
print(f"  ring = {ring_a}α + {ring_b:.2f}s/β ；tree = {tree_a}α + {tree_b:.2f}s/β ；"

第二段把"求和顺序"变成可观测量：

# ===== 示例 4：同一份数据的同一个和，换加法顺序 / 换并行度 → 位不再相同 =====
import numpy as np

rng = np.random.default_rng(0)
P, n = 16, 200_000
parts = [rng.standard_normal(n).astype(np.float32) for _ in range(P)]
ref = np.sum([p.astype(np.float64) for p in parts], axis=0)      # float64 参考


def seq_sum(ps):
    acc = np.zeros_like(ps[0])
    for p in ps:
        acc = acc + p
    return acc


def pairwise_sum(ps):
    cur = list(ps)
    while len(cur) > 1:
        nxt = []
        for i in range(0, len(cur), 2):
            nxt.append(cur[i] + cur[i + 1] if i + 1 < len(cur) else cur[i])
        cur = nxt
    return cur[0]


def ring_sum(ps):
    """ring reduce-scatter 的累加顺序：块 c 由 rank c 依次加上 rank c-1、c-2……（绕环 P-1 次）。"""
    P = len(ps)
    n = ps[0].size
    m = n // P
    out = np.zeros(n, dtype=np.float32)
    for c in range(P):
        acc = ps[c].reshape(P, m)[c].copy()
        for k in range(1, P):
            acc = acc + ps[(c - k) % P].reshape(P, m)[c]
        out.reshape(P, m)[c] = acc
    return out


def grouped_sum(ps, groups):
    """先按 groups 组各自顺序求和，再对组结果顺序求和：模拟"换一个并行度/换一棵归约树"。"""
    step = len(ps) // groups
    partials = [seq_sum(ps[i * step:(i + 1) * step]) for i in range(groups)]
    return seq_sum(partials)


base = seq_sum(parts)
print(f"P = {P} 份 float32（每份 {n} 个元素），同一个逐元素和：")
for name, r in (("顺序累加", base), ("两两配对（树形）", pairwise_sum(parts)),
                ("ring 环序", ring_sum(parts))):
    diff = np.abs(r.astype(np.float64) - ref)
    bits_diff = int(np.count_nonzero(r.view(np.int32) != base.view(np.int32)))
    print(f"  {name:<14} 与 float64 参考最大绝对误差 {diff.max():.3e} | "
          f"与顺序累加位不同的元素 {bits_diff}/{n}")

print("\n同一份数据、同一份 float64 参考，只换参与归约的份数：")
for groups in (16, 8, 4, 2):
    r = grouped_sum(parts, groups)
    bits_diff = int(np.count_nonzero(r.view(np.int32) != base.view(np.int32)))
    d = np.abs(r.astype(np.float64) - ref).max()
    print(f"  {groups:>2} 份归约 → 与 16 份结果位不同的元素 {bits_diff:>6}/{n}"
          f" | 与 float64 参考最大绝对误差 {d:.3e}")

print("\n自检：同一个顺序跑两遍，结果是否逐位相同？",
      bool(np.array_equal(ring_sum(parts).view(np.int32), ring_sum(parts).view(np.int32))))
print("float32 eps =", np.finfo(np.float32).eps, "；1 个 ulp 的量级就是上面那些误差的来源")
