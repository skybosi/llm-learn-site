正弦位置编码#

上一课我们确认了"位置盲"的问题，也知道了解法的大方向：给每个位置准备一个向量，加在 token embedding 上。这一课讲原论文给出的第一种具体方案——正弦位置编码（sinusoidal positional encoding）。它不需要任何可训练参数，直接用三角函数算出来。看似简单的公式背后藏着两个精妙的设计：一是用不同频率的波形给每个维度"染色"，让向量唯一且有序；二是 sin/cos 的三角恒等式让"相对位置"可以被线性表示出来，这让模型学到"隔了两个位置"比"隔了五个位置"更近，成为可能。

一、概念讲解#

1. 公式长什么样#

原论文给出的定义是，对位置 pos 和维度 i（i 从 0 到 d_model−1）：

PE(pos, 2i)     = sin(pos / 10000^(2i / d_model))
PE(pos, 2i+1)   = cos(pos / 10000^(2i / d_model))

逐项拆开看：

  • 偶数维度用 sin，奇数维度用 cos：同一频率的一对 sin/cos 放在相邻的两个维度上。
  • 10000^(2i / d_model) 是频率的分母：i 越大，分母越大，频率越低。于是低维度变化快（高频、波长短），高维度变化慢（低频、波长长）。整个向量像一个"从高频到低频排列的波形集合"。
  • pos 是位置序号：位置越靠后，波形走得更远，数值随之变化。

这样每个位置 pos 都能得到一个独一无二的 d_model 维向量，并且相邻位置的向量变化是平滑、连续的。

2. 为什么选 sin/cos：相对位置可线性表示#

这是正弦编码最漂亮的一点。回忆两个三角恒等式：

sin(a + b) = sin(a)cos(b) + cos(a)sin(b)
cos(a + b) = cos(a)cos(b) − sin(a)sin(b)

把 a = pos·ω、b = k·ω 代进去（ω 是某个维度的角频率），会得到：位置 pos + k 的正弦值，等于位置 pos 的 sin 与 cos 值乘上一组只依赖 k 的系数再相加。也就是说：

PE(pos + k) = M_k · PE(pos)

其中 M_k 是一个旋转矩阵，只由偏移量 k 决定，与绝对位置 pos 无关。于是两个位置向量的点积 PE(pos) · PE(pos + k) 也就只依赖相对距离 k。这给模型提供了一个天然的"相对位置"信号：它可以通过学习 Query/Key 的线性变换，去挖掘"离我 k 步的那个 token"这种关系，而不必记住绝对坐标。

3. 为什么不用"one-hot 位置"或"纯学出来的位置"#

在正弦编码出现之前，最朴素的思路是把位置序号做 one-hot 或直接归一化成一个小数。这些做法的问题在于：

  • one-hot 维度爆炸且无结构：位置 1 和位置 2 的两个 one-hot 向量内积恒为 0，模型看不出"1 和 2 很近、1 和 100 很远"。
  • 归一化小数信息太少：pos / max_len 只给一个标量，且对不同长度序列的尺度不一致，难以外推。

正弦编码用"多个频率"同时编码位置，既把位置展开成一个丰富的向量，又天然带出了"距离"概念，而且不需要任何参数、序列多长都能算。第 3 课会看到，可学习位置编码虽然更灵活，但也失去了这些"免费"的性质。

4. 一个直觉：把位置画成"条纹"#

如果把正弦位置编码矩阵画成热力图（横轴是 d_model 的各个维度，纵轴是位置 pos），会看到一组清晰的竖直条纹：左边（低频维度）是宽条纹，右边（高频维度）是细密条纹。不同的条纹组合，就唯一地标记了一个位置——这就像给每个位置发了一组"条形码"。条纹的粗细由频率决定，而频率沿维度轴从慢到快变化，正是公式里 10000^(2i/d_model) 的作用。

二、可运行代码示例#

先用 PyTorch 把正弦位置编码实现出来，并验证它的形状与数值范围。

import math
import torch
import torch.nn as nn

def sinusoidal_pe(max_len, d_model):
    """返回 (max_len, d_model) 的正弦位置编码矩阵"""
    pe = torch.zeros(max_len, d_model)
    position = torch.arange(max_len).unsqueeze(1).float()   # (max_len, 1)

    # 10000^(2i/d_model) 的等价写法：exp(-log(10000) * 2i / d_model)
    div = torch.exp(torch.arange(0, d_model, 2).float()
                    * (-math.log(10000.0) / d_model))        # 每个偶数维度的频率系数

    pe[:, 0::2] = torch.sin(position * div)   # 偶数维度填 sin
    pe[:, 1::2] = torch.cos(position * div)   # 奇数维度填 cos
    return pe

pe = sinusoidal_pe(max_len=64, d_model=16)
print("形状:", pe.shape)          # torch.Size([64, 16])
print("数值范围约:", pe.min().item(), "到", pe.max().item())  # 约 -1 到 1

# 不同位置一定得到不同的向量（唯一性）
print("位置 0 与位置 1 的向量是否相等:", torch.allclose(pe[0], pe[1]))
print("位置 0 与位置 63 的向量是否相等:", torch.allclose(pe[0], pe[63]))

接着验证那条关键的"相对位置"性质：对固定的偏移 k，PE(pos)·PE(pos+k) 应该几乎不随绝对位置 pos 变化。

def dot(pos_a, pos_b):
    return (pe[pos_a] * pe[pos_b]).sum().item()

for k in [1, 2, 4, 8]:
    vals = [dot(p, p + k) for p in range(64 - k)]
    spread = max(vals) - min(vals)
    print(f"偏移 k={k:>2}: 点积均值={sum(vals)/len(vals):.4f}, 随位置波动幅度={spread:.4f}")

运行后可以看到：固定 k 时，点积在不同绝对位置上几乎恒定（波动幅度远小于点积本身的量级），而不同 k 之间的点积差异明显。这正是"编码的是相对距离，而非绝对位置"的数值证据。想让这幅图更直观，可以把矩阵画出来：

import matplotlib.pyplot as plt

plt.figure(figsize=(8, 4))
plt.imshow(pe.numpy(), aspect="auto", cmap="viridis")
plt.xlabel("维度 (0 ~ d_model-1)")
plt.ylabel("位置 pos")
plt.colorbar(label="PE 值")
plt.title("正弦位置编码：低频宽条纹 → 高频细条纹")
plt.show()

三、练习#

  1. 把 d_model 从 16 改成 128，重新画热力图，观察条纹数量、粗细如何变化；再解释为什么"高维度变化慢、低维度变化快"。
  2. 验证三角恒等式：任选一个位置 pos 和偏移 k，用 sin(a+b)、cos(a+b) 的展开式，手动由 pe[pos] 重建 pe[pos+k] 的某一对 sin/cos 维度，确认误差接近 0。
  3. 为什么 10000 这个基数会出现在公式里？把它改成 100 或 1000000，观察热力图和"相对位置性质"（点积波动）会怎么变化。
  4. 思考：正弦编码不依赖训练数据，可以无限外推到任意长的序列。但长序列里低频维度的值会怎样变化？这会给极长序列带来什么潜在问题？
