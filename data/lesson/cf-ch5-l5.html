优化的正确性：如何证明一个 pass 没改语义#

前四课给了你一堆"看起来显然成立"的改写。现在把它们推倒重问：凭什么说改写之后程序没变？ 这个问题没有廉价答案：x / 2 换成 x >> 1 看起来天经地义，x + 1 > x 看起来恒真，删掉"没人用"的除法看起来纯赚。本课用一个 60 行的 TAC 解释器加差分测试把其中几条抓出反例，再把"每个 pass 要证的义务"写成一张表，最后解释它与未定义行为（UB）的关系。

一、概念讲解#

1. "没改语义"的准确含义#

优化改写的目标不是"代码变短"，而是观察等价（observational equivalence）：对每一个输入，两个程序的可观察行为相同。可观察行为包括返回的值、副作用（写内存、I/O）与是否陷阱/是否终止（除零、越界、死循环）。

要证明"两个程序的行为集合完全相等"通常不现实，工程上做的是 refinement：新程序允许的行为集合 ⊆ 旧程序允许的行为集合（不许产生原来没有的结果，也不许丢掉原来的陷阱）。

2. 三把锤子：证明、翻译验证、测试#

  • 局部证明：为改写规则写出前提（右值相同、无使用、无副作用），再证前提成立时观察不变。
  • 翻译验证（translation validation）：编译后让验证器自动证原 IR 与优化后 IR 等价。
  • 差分测试：同一输入跑两个版本比较可观察结果，配合随机程序生成器扩大覆盖面；只能证伪。

前两者是证明，第三者只能证伪：测试通过不代表正确，失败一定不正确。

3. 差分测试的三个实现要点#

  1. 参考语义要写死：解释器约定 32 位回绕、除法向零取整、除零抛陷阱——语义不确定，比较就没有意义。
  2. 两个版本都要能陷阱，并把它当结果比较：只比返回值会漏掉"原程序崩、优化后不崩"的错误。
  3. 输入池要含边界值：0、±1、2^31-1、-2^31、负数——小范围随机数碰不到边界。

本课实测：200 个随机程序 × 10 组输入 = 2000 次比较，0 处不一致（其中 431 次两边都陷阱、结果一致）；被检验的优化器一共折叠 344 次、CSE 4 次、删除 714 条——测试有效性取决于"优化确实改了东西"。

4. 三个反例：为什么"显然成立"经常不成立#

改写 直觉 反例（本课抓到） 真正的语义原因
x / 2 → x >> 1 除以 2 就是右移 x = -3：原式 -1 除法向零取整、右移向下取整
x + 1 > x → 恒真 加一当然变大 x = 2147483647：原式 0 补码回绕后 x + 1 反而更小
删掉没人用的 100 / y 结果没人用 y = 0 时原程序陷阱 陷阱也是可观察行为

5. 每个 pass 的"证明义务"表#

写 pass 之前先把这张表填了，评审也按它检查：

pass 要证明的 最容易错的地方
常量折叠 算出来的值 == 运行期算的值 溢出/回绕、除零陷阱不能折掉
公共子表达式 两次右值在改写点同值，且其间操作数未被重定义 可用表达式是 Must；跨块还要支配关系
死代码消除 结果无人使用，且无副作用、不陷阱 除/移位/调用不能因"没人用"就删
不变量外提 每次迭代值相同，且无条件执行安全 可能陷阱要留守卫，且需 preheader
强度削减 代数等价 + 不改变溢出/取整行为 有符号除法不能用右移代替

工程原则：改写必须比分析结论更保守，且"为什么这么改"要写进 pass 文档。

6. 为什么这事和未定义行为绑在一起#

回到那个尖锐的问题：x + 1 > x → true 这个改写，编译器错没错？答案取决于语言语义——C 里有符号溢出是未定义行为（UB），编译器有权假设它不发生，所以 x = 2147483647 这个反例本来就不是合法程序。这也解释了经典困惑"为什么 -O2 下程序炸了、-O0 下好好的"：是 UB 被优化暴露，不是编译器 bug。

LLVM 把 UB 做成显式的 IR 语义：nsw/nuw 标记与 poison、undef 值都写在语言参考手册与 UB 手册里；Alive 系列工具能形式化验证 peephole 优化，正因为它们验证的是IR 层面写死的语义。

本机 clang 实测（见下方 bash 块）：同一个 (x+1) > x 程序，-O0 对 x = 2147483647 输出 0、-O1 输出 1。合法性边界由 UB 规则划定，不由直觉划定。

二、可运行代码示例#

下面这段纯 Python 有三样东西：固定了语义的 TAC 解释器（32 位回绕、向零取整、陷阱可见）、"尽量正确"的过程内优化器（折叠 + CSE + 复制传播 + 带陷阱保护的 DCE）、差分测试驱动。最后它把两个故意写错的 pass 塞进管线，看检查器能否自动抓到反例。

# ---- 语义保持的验证：解释器 + 差分测试 + 两个"看起来对"的错误 pass（纯 Python）----
import random

BIN = {'add', 'sub', 'mul', 'div', 'shr'}
CMPS = {'>': lambda x, y: x > y, '<': lambda x, y: x < y, '>=': lambda x, y: x >= y,
        '<=': lambda x, y: x <= y, '==': lambda x, y: x == y, '!=': lambda x, y: x != y}


def nm(x):
    return ('name', x)


def ct(k):
    return ('const', k)


def def_use(ins):
    op = ins[0]
    if op == 'copy':
        return ins[3], [ins[1]]
    if op in BIN:
        return ins[3], [ins[1], ins[2]]
    if op == 'cmp':
        return ins[4], [ins[2], ins[3]]
    if op == 'return':
        return None, [ins[1]]
    return None, []


def fmt(ins):
    op = ins[0]
    s = lambda x: str(x[1]) if x else '-'
    if op == 'copy':
        return f'{ins[3]} = {s(ins[1])}'
    if op in BIN:
        return f'{ins[3]} = {s(ins[1])} {op} {s(ins[2])}'
    if op == 'cmp':
        return f'{ins[4]} = {s(ins[2])} {ins[1]} {s(ins[3])}'
    if op == 'return':
        return f'return {s(ins[1])}'
    return str(ins)


class Trap(Exception):
    pass


def wrap32(v):
    return ((v + 2 ** 31) % 2 ** 32) - 2 ** 31


def trunc_div(a, b):
    if b == 0:
        raise Trap('除零')
    q = abs(a) // abs(b)
    return q if (a < 0) == (b < 0) else -q


# ---------------- 参考语义：一个 TAC 解释器（32 位回绕 + 向零取整的除法）----------------
def run(instrs, env):
    env = dict(env)
    for ins in instrs:
        op = ins[0]
        if op == 'return':
            return env[ins[1][1]]
        d, ops = def_use(ins)
        vals = [env[x[1]] if x[0] == 'name' else x[1] for x in ops]
        if op == 'add':
            v = wrap32(vals[0] + vals[1])
        elif op == 'sub':
            v = wrap32(vals[0] - vals[1])
        elif op == 'mul':
            v = wrap32(vals[0] * vals[1])
        elif op == 'div':
            v = wrap32(trunc_div(vals[0], vals[1]))       # 向零取整，除零 = 陷阱
        elif op == 'shr':
            if vals[1] < 0 or vals[1] > 31:
                raise Trap('移位量非法')
            v = vals[0] >> vals[1]                        # 算术右移 = 向下取整
        elif op == 'cmp':
            v = int(CMPS[ins[1]](vals[0], vals[1]))
        else:
            v = vals[0]
        env[d] = v
    raise Trap('控制流走到了终点却没有 return')


# ---------------- 一个"尽量正确"的过程内优化器：折叠 + CSE/复制传播 + DCE ----------------
def optimize(instrs):
    state, alias, vn, out = {}, {}, {}, []
    folds = cse = 0
    for ins in instrs:
        op = ins[0]
        if op == 'return':
            out.append(ins)
            continue
        d, ops = def_use(ins)
        known = [('C', state[x[1]]) if x[0] == 'name' and x[1] in state else
                 (x if x[0] == 'const' else None) for x in ops]
        ok = all(k is not None for k in known)
        # (1) 常量折叠（除法要额外确认除数非 0）
        if ok and op in ('add', 'sub', 'mul', 'div', 'shr', 'cmp'):
            a, b = known[0][1], known[1][1]
            try:
                if op == 'add':
                    v = wrap32(a + b)
                elif op == 'sub':
                    v = wrap32(a - b)
                elif op == 'mul':
                    v = wrap32(a * b)
                elif op == 'div':
                    v = wrap32(trunc_div(a, b))
                elif op == 'shr':
                    if b < 0 or b > 31:
                        raise Trap('移位量非法')
                    v = a >> b
                else:
                    v = int(CMPS[ins[1]](a, b))
                out.append(('copy', ct(v), None, d))
                state[d] = v
                folds += 1
                continue
            except Trap:
                pass                                       # 会陷阱的表达式不能折叠掉
        if op == 'copy' and ok:
            state[d] = known[0][1]
            out.append(('copy', ct(known[0][1]), None, d))
            continue
        # (2) 把操作数里已知常量的名字换成常量字面量
        newops = [ct(known[i][1]) if known[i] and known[i][0] == 'C' else ops[i]
                  for i in range(len(ops))]
        for k in [k for k in vn if any(isinstance(x, tuple) and x == nm(d) for x in k[1:])]:
            del vn[k]                                      # d 被重定义 → 相关右值失效
        key = ('copy', newops[0]) if op == 'copy' else (
            (op, newops[0], newops[1]) if op in BIN else (op, ins[1], newops[0], newops[1]))
        if key in vn and vn[key] != d:                     # (3) 公共子表达式
            out.append(('copy', nm(vn[key]), None, d))
            cse += 1
            state.pop(d, None)
            continue
        vn[key] = d
        state.pop(d, None)
        if op == 'copy':
            out.append(('copy', newops[0], None, d))
        elif op in BIN:
            out.append((op, newops[0], newops[1], d))
        else:
            out.append(('cmp', ins[1], newops[0], newops[1], d))
    # 复制传播
    alias = {}
    for i, ins in enumerate(out):
        if ins[0] == 'copy' and ins[1] and ins[1][0] == 'name':
            src = alias.get(ins[1][1], ins[1][1])
            alias[ins[3]] = src
            out[i] = ('copy', nm(src), None, ins[3])
    def sub(x):
        return nm(alias[x[1]]) if x and x[0] == 'name' and x[1] in alias else x
    out = [(('copy', sub(i[1]), None, i[3]) if i[0] == 'copy' else
            ((i[0], sub(i[1]), sub(i[2]), i[3]) if i[0] in BIN else
             (('cmp', i[1], sub(i[2]), sub(i[3]), i[4]) if i[0] == 'cmp' else i)))
           for i in out]
    # (4) 死代码消除：只删"不会陷阱"的指令（除/移位可能陷阱，不能因结果没人用就删）
    dropped = 0
    changed = True
    while changed:
        used = {x[1] for i in out for x in def_use(i)[1] if x and x[0] == 'name'}
        keep = []
        for i in out:
            d, ops = def_use(i)
            safe = i[0] in ('copy', 'add', 'sub', 'mul', 'cmp') or (
                i[0] in ('div', 'shr') and ops[1][0] == 'const' and ops[1][1] > 0)
            if d is not None and d not in used and safe:
                dropped += 1
                continue
            keep.append(i)
        changed, out = len(keep) != len(out), keep
    return out, (folds, cse, dropped)


# ---------------- 差分测试：同一程序 + 同一输入，比较两个版本的可观察结果 ----------------
INPUTS = [(0, 1), (1, 2), (-3, 2), (7, -4), (123, 456), (-1, -1),
          (2 ** 31 - 1, 1), (-2 ** 31, 1), (1023, 3), (5, 0)]


def observe(instrs, env):
    try:
        return ('值', run(instrs, env))
    except Trap as e:
        return ('陷阱', str(e))


def gen_program(rng):
    instrs, names = [], ['x', 'y']
    for k in range(rng.randint(4, 7)):
        d = f't{k}'
        op = rng.choice(['add', 'sub', 'mul', 'div', 'shr'])

        def operand():
            r = rng.random()
            if r < 0.35:
                return ct(rng.choice([1, 2, 3]))
            if r < 0.5:
                return ct(rng.choice([0, 1, -1, 4]))
            return nm(rng.choice(names))
        a1, a2 = operand(), operand()
        if op in ('div', 'shr') and a2[0] == 'const' and a2[1] <= 0:
            a2 = ct(2)
        instrs.append((op, a1, a2, d))
        names.append(d)
    instrs.append(('return', nm(rng.choice(names))))
    return instrs


print('=== 差分测试：一个"证据驱动"的正确性检查 ===')
mismatch = bad_opt1 = bad_opt2 = 0
traps, tot = 0, [0, 0, 0]
for seed in range(200):
    prog = gen_program(random.Random(seed))
    opt, (f, c, dr) = optimize(prog)
    for i in range(3):
        tot[i] += (f, c, dr)[i]
    for env in INPUTS:
        a, b = observe(prog, dict(zip(['x', 'y'], env))), observe(opt, dict(zip(['x', 'y'], env)))
        if a[0] == '陷阱' and b[0] == '陷阱':
            traps += 1
        if a != b:
            mismatch += 1
print(f'  200 个随机程序 × {len(INPUTS)} 组输入 = {200 * len(INPUTS)} 次比较；'
      f'两侧结果不一致 {mismatch} 处（其中两侧都陷阱、结果一致的有 {traps} 次）')
print(f'  被检验的优化器确实做了事：折叠 {tot[0]} 次、CSE {tot[1]} 次、删除 {tot[2]} 条')

print('\n  现在把两个"看起来显然成立"的改写塞进管线，看检查器能不能抓住：')
NO_SHIFT = [( 'div', nm('x'), ct(2), 't0'), ('return', nm('t0'))]
WITH_SHIFT = [('shr', nm('x'), ct(1), 't0'), ('return', nm('t0'))]
for env in INPUTS:
    e = {'x': env[0], 'y': env[1]}
    a, b = observe(NO_SHIFT, e), observe(WITH_SHIFT, e)
    if a != b:
        print(f'  ✗ 「x / 2 ⇒ x >> 1」在 x={env[0]} 上不等价：原式 {a[1]}，改写后 {b[1]}'
              f'（向零取整 vs 向下取整）')
        bad_opt1 += 1
NO_OVF = [('add', nm('x'), ct(1), 't0'), ('cmp', '>', nm('t0'), nm('x'), 't1'),
          ('return', nm('t1'))]
ASSUME_NO_OVF = [('copy', ct(1), None, 't1'), ('return', nm('t1'))]
for env in INPUTS:
    a, b = observe(NO_OVF, {'x': env[0], 'y': env[1]}), observe(ASSUME_NO_OVF, {'x': env[0]})
    if a != b:
        print(f'  ✗ 「x + 1 > x ⇒ 恒真」在 x={env[0]} 上不等价：原式 {a[1]}，改写后 {b[1]}'
              f'（32 位回绕后 x+1 比 x 小）')
        bad_opt2 += 1
print(f'  → 两个错误 pass 各被抓住 {bad_opt1} / {bad_opt2} 个反例；'
      f'这是"测试能证伪、不能证真"的典型场景')

print('\n=== 每个 pass 的证明义务（写 pass 前先想清这一栏）===')

三、练习#

  1. 实现：给差分测试加一条"副作用"通道——记录每次 store 的地址与值，再测"把 A[i] = x 提到循环外"的错误改写，看它能否被抓住。
  2. 解释：为什么 refinement 比"行为集合相等"更适合做优化正确性的标准？举一个优化减少行为的例子（把陷阱路径变安全），说明它算不算合法优化。
  3. 对比/验证：把输入池换成只含 [0, 1, 2] 再跑——两个错误 pass 还能被抓到吗？由此说明"覆盖面"为什么比"随机次数"更重要。
  4. 思考：翻译验证与"把 pass 本身证明一次"各有什么代价？为什么两条路都要（提示：pass 组合后新出现的改写机会，局部证明并不覆盖）？
