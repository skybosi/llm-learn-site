完整流程示例#

前两课我们认识了 sklearn 的结构和 fit/transform/predict 约定。这一课把它们拼成一个端到端的完整项目：从加载数据、用 Pandas 做探索，到划分、缩放、训练、评估，最后再用 Pipeline 和交叉验证把流程"包装"得更规范。

一、概念讲解#

一个标准的 sklearn 分类项目，代码层面通常按这个顺序展开：

  1. 加载数据：用 load_* 得到特征矩阵和标签。
  2. Pandas 探索：把数据转成 DataFrame，看形状、类别分布、缺失值——这一步沿用你已掌握的 Pandas 技能。
  3. 划分：train_test_split 切出训练集和测试集，分类任务建议加 stratify 保持类别比例。
  4. 预处理：在训练集上 fit_transform，测试集上 transform。
  5. 训练：选一个分类器 fit。
  6. 评估：用 accuracy_score、confusion_matrix、classification_report 看效果。
  7. （进阶）交叉验证 + Pipeline：用 Pipeline 把预处理和模型合并，cross_val_score 做多折验证，得到更稳定的性能估计。

评估指标里，混淆矩阵能告诉我们模型在每一类上对错多少：它是一个 2×2（二分类）的表格，记录"真阳性（TP）、假阳性（FP）、真阴性（TN）、假阴性（FN）"。只看准确率有时会掩盖问题——例如 100 个样本里 95 个是负类，全预测成负类准确率也有 95%，但正类一个都没识别出来。

二、可运行代码示例#

我们用乳腺癌诊断数据集（load_breast_cancer，二分类：良性/恶性）走完整流程。

import pandas as pd
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

# 1. 加载数据，并转成 Pandas DataFrame 便于探索
data = load_breast_cancer()
df = pd.DataFrame(data.data, columns=data.feature_names)
df["target"] = data.target
print("数据形状：", df.shape)
print("类别分布：\n", df["target"].value_counts())
print("缺失值总数：", df.isna().sum().sum())

# 2. 分离特征与标签
X = df.drop(columns="target")
y = df["target"]

# 3. 划分训练集 / 测试集（stratify 保持类别比例）
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)

# 4. 预处理：标准化（训练集 fit_transform，测试集只 transform）
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# 5. 训练模型
model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

# 6. 预测并评估
y_pred = model.predict(X_test)
print("\n准确率：", round(accuracy_score(y_test, y_pred), 3))
print("混淆矩阵：\n", confusion_matrix(y_test, y_pred))
print("分类报告：\n", classification_report(y_test, y_pred, target_names=data.target_names))

# 7. 进阶：用 Pipeline + 交叉验证，避免手动缩放时出错、得到更稳定的估计
pipe = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
cv_scores = cross_val_score(pipe, X, y, cv=5)
print("5 折交叉验证准确率：", cv_scores.round(3), "均值：", round(cv_scores.mean(), 3))

观察输出：

  • confusion_matrix 的两行两列对应"良性/恶性"的真实值与预测值，对角线是预测对的个数。
  • classification_report 给出精确率、召回率、F1 等更细致的指标，比只看准确率更有参考价值。
  • make_pipeline(StandardScaler(), LogisticRegression()) 把"缩放 + 模型"打包成一个对象，cross_val_score 会在每一折里自动、正确地先缩放再训练，从根上避免了泄漏。

三、练习#

  1. 填空：分类任务里建议给 train_test_split 加 stratify=y，其作用是 ____。
  2. 读图：假设混淆矩阵为 [[80, 5], [8, 7]]（行=真实值，列=预测值），请写出 TP、FP、FN、TN 分别是多少，并算出准确率。
  3. 动手实验：把 LogisticRegression 换成 KNeighborsClassifier（需先 from sklearn.neighbors import KNeighborsClassifier），对比准确率和混淆矩阵有什么变化。提示：KNN 对特征缩放很敏感，这也是我们提前标准化的原因之一。
  4. 思考题：make_pipeline 与手动"先 scaler、再 model"相比有什么好处？在 cross_val_score 的场景下，为什么手动写法容易出错？
