散点图#

散点图把两个变量之间的关系画成一个个点，适合观察相关性、聚类和离群点。它还能借助颜色和大小编码第三个、第四个变量，是探索数据的有力工具。

一、概念讲解#

1. 散点图适合什么场景#

当你有两个连续变量，想回答"它们之间有没有关系、是什么关系"时，散点图几乎是首选：

  • 身高与体重是否正相关？
  • 广告投入与销量是否相关？
  • 数据里是否存在明显聚成几簇的群体？

每个数据点由一对 (x, y) 确定，点的聚集与走向直接反映两变量的关系。

2. 基础用法：ax.scatter#

ax.scatter(x, y) 在 (x, y) 位置画散点。与 ax.plot(x, y, "o") 相比，scatter 更强大：它能为每个点单独设置颜色、大小，因此常用于用颜色/大小编码额外信息。

3. 用颜色与大小编码更多变量#

参数 含义 示例
c 点的颜色（或数值序列，配合 cmap） c=age
cmap 颜色映射（把数值映射到色带） cmap="viridis"
s 点的大小（面积，可传数值序列） s=sizes
alpha 透明度（0~1，密集时避免互相遮挡） alpha=0.6
edgecolors 点边缘颜色 edgecolors="white"
marker 点的形状 marker="o"

当 c 传入数值数组时，应配合 cmap 与 fig.colorbar(...) 添加颜色条，说明颜色与数值的对应关系。

二、可运行代码示例#

下面生成 300 个人的身高、体重与年龄，用散点图展示身高—体重关系，并用颜色表示年龄、用大小表示"偏离标准体重的程度"。

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False

rng = np.random.default_rng(42)
n = 300

height = rng.normal(170, 8, n)                    # 身高（cm）
weight = 0.6 * height + rng.normal(0, 6, n)       # 体重（kg），与身高相关
age = rng.integers(18, 60, n)                     # 年龄，用作颜色

fig, ax = plt.subplots(figsize=(8, 5.5))

# c=age 颜色映射年龄；s 控制点大小；cmap 指定色带
sc = ax.scatter(height, weight,
                c=age,
                s=np.abs(weight - 60) * 3 + 20,   # 偏离 60kg 越多点越大
                alpha=0.6,
                cmap="viridis",
                edgecolors="white", linewidths=0.4)

ax.set_xlabel("身高（cm）")
ax.set_ylabel("体重（kg）")
ax.set_title("散点图：身高—体重关系，颜色表示年龄")

# 颜色条说明颜色与年龄的对应关系
cbar = fig.colorbar(sc, ax=ax)
cbar.set_label("年龄")

plt.show()

观察：点整体沿右上方向分布，说明身高与体重正相关；颜色深浅显示年龄信息。

三、练习#

  1. 生成两组二维数据 rng.normal(0, 1, (100, 2)) 与 rng.normal(4, 1, (100, 2))，用不同颜色把它们画在同一张散点图上，观察是否能看出两个簇。
  2. 用 np.linspace(0, 10, 100) 生成 x，y = x + noise，画出散点并设置 alpha=0.5，说明透明度在点密集时的作用。
  3. 把示例中 cmap 换成 "plasma" 再运行一次，观察色带变化，并尝试用 s 传入一个固定数值让所有点大小一致。
