1. README 结构（照此模板，替换成你的项目）#

# 知识库助手（AI Knowledge Assistant）

## 一句话简介
基于 RAG 的私有知识库问答助手：上传文档即可自然语言提问，
回答带引用来源，可本地或云端部署。

## 为什么做（需求）
- 用户：需要快速在大量资料里找到答案的人（如备考/新员工）
- 痛点：资料分散、检索靠翻页，找不到原文依据
- 成功指标：50 个评测问题上引用命中率 ≥ 80%、回答延迟 ≤ 3s

## 技术选型与理由
| 环节 | 方案 | 为什么 |
| --- | --- | --- |
| 解析 | PyMuPDF | 轻量、离线、抽取快 |
| 切块 | 512 字符 + 重叠 64 | 平衡检索精度与上下文 |
| Embedding | BGE-small-zh | 中文友好、本地可跑 |
| 向量库 | Chroma | 本地持久化、零运维 |
| 生成 | Qwen2.5-7B + vLLM(AWQ) | 复用 P10 部署、可控成本 |
| 服务 | FastAPI | 轻量、异步、易容器化 |

## 怎么跑
1. 准备文档到 data/，安装依赖
2. python src/ingest.py  # 入库
3. 启动 vLLM 生成服务（P10）
4. uvicorn src.serve:app --port 9000
5. 打开 web/index.html 提问

- v1：块 512，命中率 72% → v2：块 256+重叠 128，命中率 85%
- v2：换 bge-m3 embedding，命中率 +3%，延迟 +40ms

3. 成本 / 性能数据（复用 P10 算账法）#

把产品运行的真实数据填进表，这是"毕业项目"区别于"课程作业"的关键：

指标 数值（示例，替换为实测）
生成模型显存（AWQ 7B） ~9 GB（一张 24 GB 卡）
平均检索延迟 ~120 ms
平均生成延迟（200 token） ~2.2 s
单次请求成本 检索 ~0（本地 CPU）+ 生成约 0.007 元
月度常驻成本（云，单卡） GPU 小时单价 × 24 × 30 
# cost.py —— 估算产品单次请求成本与月度成本（示例数值）
retrieval_ms = 120
gen_ms_per_1k = 1100            # 生成每 1K token 约 1.1s（AWQ 7B 示例）
avg_out_tokens = 200
gpu_hour_price = 1.2            # 示例单价（元）

gen_cost = avg_out_tokens / 1e6 * (
    gpu_hour_price / (1000 / gen_ms_per_1k * 3600 / 1e6)
)  # 等价于：按吞吐折算每 token 成本再乘输出量
monthly = gpu_hour_price * 24 * 30
print(f"单次请求生成成本 ≈ {gen_cost:.4f} 元（检索本地≈0）")
print(f"月度常驻成本 ≈ {monthly:.0f} 元（按 24h×30 天，未计弹性/spot）")

结论一句话："检索几乎免费，成本集中在生成模型；单次问答生成成本约 0.007 元，月度常驻约 860 元——若用弹性实例/闲时缩容还能再降。"

三、面试话术与毕业总结#

1. 面试话术（"从头讲讲你这个项目"）#

这是毕业项目最常被问的问题，用五步闭环串起来讲，3 分钟版本：

  1. 需求："我想解决'在大量私有资料里快速找到带依据的答案'这个问题，目标用户是备考/新员工，成功指标是引用命中率 ≥ 80%、回答延迟 ≤ 3 秒。"
  2. 数据："我用 PyMuPDF 解析文档，按 512 字符 + 重叠 64 切块，用 BGE 中文 embedding 向量化后存进 Chroma。"
  3. 模型："检索用 embedding 相似度召回 top-4，生成复用我之前部署的 Qwen2.5-7B AWQ 服务，把检索到的段落拼进 prompt，并要求只依据资料回答、标注来源。"
  4. 部署："用 FastAPI 把 RAG 包成 /ask 接口，Docker 容器化，前端是极简网页，接口同样可对接小程序。"
  5. 上线与效果："本地和云都跑通了；评测 50 题引用命中率 85%，平均延迟约 2.3 秒，单次请求成本约 0.007 元。"

高频追问，这样接：

  • "技术选型为什么这么定？" —— "每层都按'可控 + 可解释 + 成本低'选：Chroma 本地持久化零运维，BGE 中文效果好且免费，生成复用 AWQ 量化卡成本。用自写检索而不用 LangChain，是为了少黑盒、更好讲清原理。"
  • "怎么防止模型胡编？" —— "系统提示词强制'资料没有就明说'、温度降到 0.1，并且来源在检索阶段就带出，生成只能引用不能编。"
  • "如果上线后效果不好，你怎么优化？" —— 讲迭代记录：调切块大小、换更强 embedding、加 rerank、扩充文档，每一步都有命中率的变化支撑。
