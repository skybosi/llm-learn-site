张量与 NumPy#

深度学习工程里，数据常常先经过 NumPy / pandas 做预处理，再进入 PyTorch 训练。因此"张量 ↔ NumPy 数组"的互转是每天都要用到的技能。本课讲清三件事：怎么互转、转换是共享内存还是复制、以及转换中的类型细节。理解"共享内存"是本章的关键——它决定了你在一边改数据时，另一边会不会被悄悄影响。

一、概念讲解#

1. 两条互转路径#

  • NumPy → 张量：torch.from_numpy(arr) 或 torch.tensor(arr)。
  • 张量 → NumPy：tensor.numpy()（要求张量在 CPU 上且为浮点/整型，不能是 requires_grad=True 的叶子张量）。

两条路径都能完成转换，但行为差异很大，核心区别就在"是否共享内存"。

2. torch.from_numpy 与 torch.tensor 的本质区别#

  • torch.from_numpy(arr)：共享内存。它不复制数据，只新建一个"指向同一块内存"的张量。改张量会同步改 NumPy 数组，反之亦然。
  • torch.tensor(arr)：深拷贝。复制出一份独立数据，改任何一边都不影响另一边。

共享内存的优点是零拷贝、省时间省内存；代价是"一改两变"，不注意会埋下难以排查的 bug。图 1-5 用"两个把手握同一块数据"来比喻这层关系。

3. dtype 与设备约束#

  • 数据类型要一致：NumPy 的 float64 对应 torch.float64，float32 对应 torch.float32，int64 对应 torch.int64。如果 NumPy 数组是 float64，from_numpy 得到的张量也是 float64——而 PyTorch 训练默认 float32，必要时用 .float() 转换。
  • tensor.numpy() 不能用在 GPU 张量上，需先 .cpu()；也不能用在需要梯度的张量上，需先 .detach()。

4. 为什么要在意这些#

  • 性能：大数据上用 from_numpy 避免一次拷贝，预处理流水线更快。
  • 正确性：若误以为 from_numpy 是复制，之后"只改 NumPy 不动张量"的假设会失效。
  • 习惯：tensor.numpy() 常用来把训练结果导出给 Matplotlib 绘图或保存为 .npy。

二、可运行代码示例#

import torch
import numpy as np

# ---- 1. NumPy -> 张量（共享内存）----
arr = np.array([[1.0, 2.0], [3.0, 4.0]], dtype=np.float32)
t = torch.from_numpy(arr)          # 共享同一块内存
print("原始 arr =\n", arr)

t[0, 0] = 99.0                     # 只改张量
print("\n改张量后 arr =\n", arr)   # arr 也跟着变了！证明共享内存

arr[1, 1] = -7.0                   # 只改 NumPy
print("改 NumPy 后 t =\n", t)      # 张量也跟着变

# ---- 2. NumPy -> 张量（复制）----
t2 = torch.tensor(arr)             # 深拷贝，独立数据
t2[0, 0] = 0.0
print("\ntorch.tensor 复制后，改 t2 后 arr =\n", arr)  # arr 不变

# ---- 3. 张量 -> NumPy ----
x = torch.arange(6, dtype=torch.float32).reshape(2, 3)
nd = x.numpy()
print("\n张量转 NumPy：", type(nd), nd.shape)   # <class 'numpy.ndarray'> (2, 3)

# ---- 4. dtype 对照 ----
a64 = np.array([1, 2, 3], dtype=np.float64)
print("\nfloat64 NumPy -> 张量 dtype:", torch.from_numpy(a64).dtype)  # torch.float64
print("转回 float32:", torch.from_numpy(a64).float().dtype)           # torch.float32

运行后重点确认两处：t[0,0]=99 之后 arr 的第一行第一个元素也变成 99（共享内存）；而 torch.tensor(arr) 得到的 t2 无论怎么改，arr 都不受影响（复制）。

三、练习#

  1. 创建 arr = np.zeros((3, 3))，用 torch.from_numpy 得到 t，对 t 做原地 t.add_(5)，打印 arr，说明结果并解释原因。
  2. 分别用 torch.from_numpy(arr) 和 torch.tensor(arr) 从同一个 arr 建两个张量，修改其中一个，验证哪个会"连带"改掉 arr。
  3. 把上一课创建的形状 (4, 5) 张量转成 NumPy 数组后，用 np.save 保存成 .npy，再 np.load 读回来、用 torch.from_numpy 转回张量，确认形状与数值一致。
  4. 尝试对 x = torch.tensor([1.0], requires_grad=True) 调用 x.numpy()，观察报错信息，然后用正确的方法（先 detach）拿到 NumPy 数组。
