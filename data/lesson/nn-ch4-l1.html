链式法则回顾#

前面三章，我们已经搭好了多层感知机、跑通了前向传播，也认识了各种激活函数。但到目前为止，网络里的权重还只是"随机猜"出来的——我们还不知道该怎么更新它们，让预测误差一步步变小。答案就藏在反向传播（backpropagation）里，而反向传播的数学根基，是微积分里的链式法则（chain rule）。

本课先不急着讲完整的反向传播，而是把链式法则这条"传送带"单独拎出来讲清楚：它如何把输出端的误差，一层一层"倒着传"回最前面的权重。只有把这条法则吃透，下一课的反向传播算法才会水到渠成。

一、概念讲解#

1. 一元复合函数的链式法则#

先回忆最简单的情形。设 y = f(u)，u = g(x)，那么 y 实际上是 x 的复合函数 y = f(g(x))。它的导数怎么求？答案是"外层先求导、再乘内层导数"：

dy/dx = dy/du · du/dx

用一句话记：沿着一层层函数往下剥，把每一层的导数乘起来。举个具体例子：y = (x² + 1)³，令 u = x² + 1，则 y = u³：

dy/du = 3u²        （外层：三次方的导数）
du/dx = 2x         （内层：x²+1 的导数）
dy/dx = 3u² · 2x = 6x(x² + 1)²

2. 多元情形与"局部导数"的视角#

神经网络里没有这么简单的单变量函数。前向传播里，一个神经元 a = σ(w·x + b) 同时依赖权重向量 w、偏置 b、输入 x，下一层又依赖这一层。这时我们关心的是损失对某个权重的偏导数。

链式法则在多元下依然成立，只是写法从"相乘"变成"把沿途所有局部导数相乘"。这里的关键思想是：每个计算节点只负责算好自己的"局部导数"，把上游传来的梯度乘上局部导数，再继续传给下游。这就是反向传播的雏形。

3. 用"计算图"拆解复合关系#

把复杂函数画成计算图（computation graph），链式法则就会变得一目了然。图中每个节点是一个中间变量，每条边是一次运算。求 L 对图中任意节点的梯度，只需从 L 出发，沿着图反向走，把经过的每条边上的局部导数连乘即可。

  • 前向：从输入节点出发，按箭头方向算出所有中间值，直到损失 L。
  • 反向：从 L 出发，逆着箭头，用链式法则累积每个节点的梯度。

例如一个小网络：z = w·x + b，a = sigmoid(z)，L = (a - y)²。要求 ∂L/∂w，就是：

∂L/∂w = ∂L/∂a · ∂a/∂z · ∂z/∂w
      = 2(a-y) · a(1-a) · x

这三个因子，正好对应损失层、激活层、线性层各自的"局部导数"。反向传播的本质，就是把这条链上的因子逐个算出来并乘上去。

4. 为什么对神经网络如此重要#

一个深层网络里，损失 L 到第一层权重之间有几十上百次"连乘"。如果不用链式法则逐层传递，而想靠暴力枚举每一个权重的变化来求梯度，计算量会爆炸。链式法则让我们只需一次前向、一次反向，就能同时得到损失对所有参数的梯度——这是深度学习能训练成千上万个参数的根本原因。

二、可运行示例#

示例 1：一元复合函数，手算 + 数值验证

import numpy as np

# f(x) = (x^2 + 1)^3
# 令 u = x^2 + 1，则 f = u^3
# 由链式法则：f'(x) = 3u^2 * 2x = 6x(x^2 + 1)^2
def f(x):
    return (x**2 + 1) ** 3

def f_prime(x):
    return 6 * x * (x**2 + 1) ** 2

x = 2.0
# 用中心差分算数值梯度，验证解析结果是否一致
h = 1e-5
num_grad = (f(x + h) - f(x - h)) / (2 * h)

print("解析梯度 f'(2) =", f_prime(x))
print("数值梯度        =", num_grad)
print("两者之差        =", abs(f_prime(x) - num_grad))

示例 2：一个小网络的梯度，逐因子相乘

import numpy as np

# 一个单神经元：z = w*x + b，a = sigmoid(z)，L = (a - y)^2
# 目标是求 dL/dw，用链式法则逐因子相乘
x, w, b, y = 1.5, 0.8, 0.1, 1.0

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

# —— 前向：算出所有中间值 ——
z = w * x + b
a = sigmoid(z)
L = (a - y) ** 2

# —— 反向：逐层求局部导数并连乘 ——
dL_da = 2 * (a - y)        # 损失层的局部导数
da_dz = a * (1 - a)        # sigmoid 的导数
dz_dw = x                  # 线性层的局部导数

dL_dw = dL_da * da_dz * dz_dw   # 链式法则连乘
print("链式法则求得的 dL/dw =", dL_dw)

# 数值梯度验证：给 w 加一个极小扰动，看 L 的变化率
eps = 1e-6
z_plus = (w + eps) * x + b
L_plus = (sigmoid(z_plus) - y) ** 2
z_minus = (w - eps) * x + b
L_minus = (sigmoid(z_minus) - y) ** 2
num_grad = (L_plus - L_minus) / (2 * eps)
print("数值梯度求得的 dL/dw =", num_grad)

示例 3：用 PyTorch 自动求导对照

import torch

# PyTorch 的 autograd 内部正是靠链式法则在计算图上反向传递梯度
w = torch.tensor(0.8, requires_grad=True)
x = torch.tensor(1.5)
b = torch.tensor(0.1)
y = torch.tensor(1.0)

a = torch.sigmoid(w * x + b)   # 前向
L = (a - y) ** 2               # 平方损失
L.backward()                   # 反向：自动沿计算图求导

print("PyTorch 自动求导 dL/dw =", w.grad.item())
# 与示例 2 手算结果一致，说明链式法则理解正确

三个示例都算出同一个 dL/dw，说明：链式法则、数值差分、自动微分三条路殊途同归。而自动微分框架（PyTorch 等）做的事情，就是把示例 2 里"手写局部导数再连乘"的过程自动化。
