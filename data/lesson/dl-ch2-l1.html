LeNet/AlexNet#

理解了 CNN 的零件与结构后，我们进入"经典架构"单元，从两个开山之作看起：LeNet-5 用不到六万参数让机器认出手写数字，AlexNet 则用八层网络引爆了 2012 年的 ImageNet 竞赛。它们年代不同、规模悬殊，却共享同一套"卷积提取特征、全连接做分类"的设计哲学。这一课我们逐层拆解两座里程碑，看看深度网络第一次被"点燃"时踩对了哪些关键点。

一、概念讲解#

1. LeNet-5：CNN 的起点#

LeNet-5 由 Yann LeCun 团队在 1998 年提出，用于识别手写数字（如银行支票）。它只有 7 层，却已经包含了今天几乎所有 CNN 的零件：

输入 32×32（灰度） → C1 卷积(6 核 5×5) → S2 池化(2×2)
→ C3 卷积(16 核 5×5) → S4 池化(2×2)
→ C5 卷积(120 核 5×5) → F6 全连接(84) → 输出(10)

几个要点：

  1. 交替堆叠：卷积与池化成对出现，先提特征、再降采样，尺寸从 32 一路缩到 1；
  2. 激活函数：当年用的是 tanh / sigmoid，如今我们复现时通常换成 ReLU；
  3. 平均池化：LeNet 用的是平均池化，且池化后还会乘一个可训练系数再加偏置，现代复现一般简化为标准 AvgPool2d；
  4. 最后一层用 RBF 而非 softmax：这是历史实现细节，现代复现直接换成线性层 + 交叉熵即可。

2. AlexNet：深度学习爆发的导火索#

2012 年，AlexNet 在 ImageNet（1000 类、120 万张训练图）上把 top-5 错误率从约 26% 一举压到 15.3%，领先亚军一大截，学界从此转向深度学习。它的结构与 LeNet 一脉相承，但更深更宽，并引入了几项关键工程手段：

  1. ReLU：替代饱和的 tanh，缓解梯度消失，训练快得多；
  2. Dropout：在最后两个大号全连接层随机丢弃神经元，抑制过拟合；
  3. 数据增强：随机裁剪、水平翻转，人为扩充训练集；
  4. 局部响应归一化（LRN）：对相邻通道做竞争性归一化（今天多数被 BatchNorm 取代）；
  5. 双 GPU 并行：把网络拆成两半放在两块 GPU 上，解决当时显存不足的问题。

AlexNet 的骨架：输入 227×227 → 5 个卷积层（含池化）+ 3 个全连接层。前两层卷积核较大（11×11、5×5）以快速压缩尺寸，后三层用 3×3 精修特征；全连接层尺寸高达 4096 维，参数量主要集中在这里（约 6000 万）。

3. LeNet 与 AlexNet 的对比#

维度 LeNet-5 AlexNet
年代 1998 2012
输入 32×32 灰度 227×227 RGB
深度 约 5~7 层 8 层（5 卷积 + 3 全连接）
激活 tanh / sigmoid ReLU
正则化 — Dropout + 数据增强
参数规模 约 6 万 约 6000 万

这条对比线揭示了一个趋势：更深的网络 + 更有效的正则化 + 更大的数据，是性能跃迁的三驾马车，也是下一课 VGG、ResNet 继续发力的方向。

4. 复现时的"现代化改造"#

在 PyTorch 里复现经典网络时，我们通常做三处无害改造：把激活函数统一成 ReLU、把 LRN 换成 BatchNorm、把平均池化后的可训练缩放省略。这样做既保留原始骨架的教学价值，又能让网络在今天的数据上稳定训练。

二、可运行代码示例#

下面用 PyTorch 复现一个简化版 LeNet-5 和一个简化版 AlexNet（针对 MNIST 的 28×28 输入做了尺寸适配），打印结构并跑一次前向。

import torch
import torch.nn as nn

class LeNet5(nn.Module):
    """简化版 LeNet-5：卷积-池化交替，激活换成 ReLU，末端全连接分类。"""
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 6, kernel_size=5),          # 28x28 -> 6x24x24
            nn.ReLU(inplace=True),
            nn.AvgPool2d(kernel_size=2),             # -> 6x12x12
            nn.Conv2d(6, 16, kernel_size=5),         # -> 16x8x8
            nn.ReLU(inplace=True),
            nn.AvgPool2d(kernel_size=2),             # -> 16x4x4
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(16 * 4 * 4, 120),
            nn.ReLU(inplace=True),
            nn.Linear(120, 84),
            nn.ReLU(inplace=True),
            nn.Linear(84, num_classes),
        )

    def forward(self, x):
        return self.classifier(self.features(x))

class AlexNetMini(nn.Module):
    """简化版 AlexNet：大核起步 + 3x3 精修 + 大号全连接，尺寸适配 MNIST。"""
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=5, padding=2),   # 28x28 -> 32x28x28
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2),                  # -> 32x14x14
            nn.Conv2d(32, 64, kernel_size=3, padding=1),  # -> 64x14x14
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2),                  # -> 64x7x7
            nn.Conv2d(64, 128, kernel_size=3, padding=1), # -> 128x7x7
            nn.ReLU(inplace=True),
            nn.Conv2d(128, 128, kernel_size=3, padding=1),# -> 128x7x7
            nn.ReLU(inplace=True),
        )
        self.classifier = nn.Sequential(
            nn.Dropout(0.5),
            nn.Linear(128 * 7 * 7, 1024),
            nn.ReLU(inplace=True),
            nn.Dropout(0.5),
            nn.Linear(1024, num_classes),
        )

    def forward(self, x):
        return self.classifier(self.features(x).flatten(1))

for name, net in [("LeNet5", LeNet5()), ("AlexNetMini", AlexNetMini())]:
    x = torch.randn(1, 1, 28, 28)
    y = net(x)
    params = sum(p.numel() for p in net.parameters())
    print(f"{name}: 输出 {tuple(y.shape)}, 参数量 {params:,}")

运行后会看到，LeNet5 只有几万参数，AlexNetMini 则有数百万——大头都来自后面那几层全连接，这正是 AlexNet 参数臃肿、后来被全局平均池化取代的痛点所在。

三、练习#

  1. 打印 LeNet5 每一层输出形状，说明为什么 Flatten 前的特征图是 16×4×4，而不是别的尺寸。
  2. 把 LeNet5 里的 nn.AvgPool2d(2) 全部换成 nn.MaxPool2d(2)，重新训练（或直接前向），体会两种池化在"手写数字"这类任务上的细微差别。
  3. 给 AlexNetMini 的卷积层之间插入 nn.BatchNorm2d，统计参数量变化，说明 BatchNorm 新增的参数是哪两个（γ 与 β）。
  4. 思考：为什么 AlexNet 前两层用 11×11、5×5 的大卷积核，而后三层却只用 3×3？大核和小核各自有什么优缺点？
