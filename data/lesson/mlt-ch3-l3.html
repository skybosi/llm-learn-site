从拉普拉斯先验推出 Lasso#

上一课我们证明"高斯先验 → 岭回归（L2）"。这一课换一个先验——拉普拉斯分布——看看同样的 MAP 公式会变出什么。结果会让我们看到机器学习里最迷人的一个现象：L1 正则（Lasso）会自动把一部分权重精确压成 0，产生稀疏解。而这一切的根源，竟然只是拉普拉斯先验在 0 点"尖"了一下。

一、概念讲解#

1. 拉普拉斯先验：0 点上的一个尖峰#

给权重向量 w 的每个分量安一个独立的拉普拉斯分布（零均值、尺度参数 b）：

p(wⱼ) = (1/2b) · exp( −|wⱼ| / b )

对比上一课的高斯密度 exp(−wⱼ²/2τ²)：

  • 高斯：wⱼ=0 处是平滑的峰，两侧以 e^{−w²} 的速率衰减，没有尖角；
  • 拉普拉斯：wⱼ=0 处有一个尖尖的峰（导数不连续），两侧以 e^{−|w|} 的速率衰减，在 0 点聚集了更集中的概率质量。

这个"尖峰"意味着：拉普拉斯先验强烈地相信"很多权重恰好就是 0"，只有少数权重显著非零。这正是"稀疏"这个先验信念的概率表达。

2. 写出后验，推出 Lasso#

与上一课完全平行的推导。噪声仍假设高斯 y|X,w ~ N(Xw, σ²I)，先验换成拉普拉斯。后验取负对数：

−log P(w|X,y) = −log P(y|X,w) − log P(w) + 常数
              = (1/2σ²)‖y − Xw‖² + (1/b)Σⱼ |wⱼ| + 常数

先验的负对数 −log P(w) = Σⱼ |wⱼ|/b + 常数，恰好给出各权重绝对值之和——即 L1 范数 ‖w‖₁。整理（乘 2σ² 不变最小值点）：

J(w) = ‖y − Xw‖² + λ·Σⱼ |wⱼ|,      其中 λ = 2σ²/b
     = ‖y − Xw‖² + λ‖w‖₁

这就是 Lasso（Least Absolute Shrinkage and Selection Operator） 的目标函数。结论：

拉普拉斯先验 + MAP  ⟹  Lasso（L1 正则 λ‖w‖₁）

与上一课并列成一张对称的图景：

先验 负对数先验 正则项 算法 效果
高斯 e^{−w²} w² L2 ‖w‖² 岭回归 收缩、不稀疏
拉普拉斯 `e^{− w }` ` w

3. 为什么 L1 产生稀疏？（几何直觉）#

这是本课最需要"知其所以然"的一点。比较两种惩罚对"把某个 wⱼ 压到精确 0"的态度：

  • L2 惩罚 wⱼ² 的边际收益在 0 附近几乎为 0：wⱼ² 在 wⱼ≈0 处是平的（导数 2wⱼ→0），意味着"从 0.001 再压到 0"几乎不省惩罚，却可能损失拟合，所以 L2 懒得把权重归零。
  • L1 惩罚 |wⱼ| 的边际收益恒定：|wⱼ| 在 wⱼ≠0 处导数恒为 ±1，"从 0.001 压到 0"仍能省 0.001·λ 的惩罚。所以只要"归零"带来的拟合损失足够小，L1 就果断把权重归零。

几何上更直观：L2 的约束域是圆球（光滑），L1 的约束域是菱形（有尖角）。损失等高线（椭圆）向外扩张，第一次与约束域相切的位置：

  • 与圆球相切，切点几乎总在圆面上（坐标都不为 0）；
  • 与菱形相切，切点极容易落在菱形的角上（某个坐标恰好为 0）。

4. 解析解：软阈值算子#

L1 不可导（在 0 点），没有普通梯度，但可用次梯度或软阈值（soft-thresholding）得到解析解。特别地，当设计矩阵正交（XᵀX = I）时，Lasso 的解可以逐个坐标写出：

ŵⱼ_lasso = sign(ŵⱼ_ols) · max( |ŵⱼ_ols| − λ/2, 0 )

这叫软阈值算子。它的行为一目了然：

  • 若普通最小二乘解 |ŵⱼ_ols| > λ/2：把它朝 0 收缩 λ/2；
  • 若 |ŵⱼ_ols| ≤ λ/2：直接归零。

对比岭回归在同一正交情形下的解 ŵⱼ_ridge = ŵⱼ_ols / (1+λ)：它只是按比例缩小，永远不会等于 0。两者差别，就是"稀疏"与"不稀疏"的差别，其根源就是我们反复强调的那一点——先验在 0 点尖不尖。

5. 稀疏的意义#

Lasso 的稀疏性有实际价值：

  • 特征选择：权重为 0 的特征被自动剔除，模型更小、更可解释；
  • 抗噪声：把不重要的噪声特征归零，等效于降维；
  • 可读性：非零权重就是"真正有用的那几维"，符合"少数关键因素"的物理直觉。

但代价是：L1 不可导，优化需用坐标下降、近端梯度等专门算法；且当特征强相关时，Lasso 可能"随机挑一个"而丢弃另一个，不如岭回归稳定。

二、可运行代码示例#

手工实现软阈值算子，验证"正交设计下 Lasso 精确归零、岭回归只收缩"这一理论结论；再用一个简单循环做 Lasso 的坐标下降，观察随 λ 增大权重逐个归零的过程。

import numpy as np

rng = np.random.default_rng(17)
d = 6
# 正交设计：随机旋转矩阵的列（列两两正交、单位长度）
Q, _ = np.linalg.qr(rng.normal(0, 1, size=(d, d)))
X = Q  # XᵀX = I
w_true = np.array([1.5, -0.8, 0.0, 0.0, 0.0, 0.0])   # 真实只有前两个非零
y = X @ w_true + rng.normal(0, 0.3, size=d)

w_ols = X.T @ y          # 正交情形下 OLS = Xᵀy

def soft_threshold(w_ols, lam):
    return np.sign(w_ols) * np.maximum(np.abs(w_ols) - lam / 2, 0.0)

print(f"{'λ':>5} | {'岭回归(收缩不归零)':>22} | {'Lasso(软阈值,可归零)':>22}")
for lam in [0.0, 0.3, 0.8, 1.6, 3.0]:
    w_ridge = w_ols / (1 + lam)
    w_lasso = soft_threshold(w_ols, lam)
    print(f"{lam:>5.1f} | {np.round(w_ridge, 3)!s:>22} | {np.round(w_lasso, 3)!s:>22}")

观察两列：岭回归的所有坐标都在缩小，但没有一个是精确 0；Lasso 在 λ 超过某个阈值后，把原本接近 0 的坐标精确压成 0，只留下真正重要的两个。稀疏性在软阈值算子 max(|·|−λ/2, 0) 里被"一刀切"出来，与理论推导严丝合缝。

三、练习#

  1. 从拉普拉斯密度 p(w) = (1/2b)e^{−|w|/b} 出发，逐行推导 −log P(w) = ‖w‖₁/b + 常数，并解释最大化后验为何等价于最小化 ‖y−Xw‖² + λ‖w‖₁（给出 λ = 2σ²/b）。
  2. 用"菱形 vs 圆球"的几何图解释稀疏性：为什么椭圆等高线更容易与 L1 菱形的角相切（得到 0 坐标），而 L2 圆球切点几乎不在坐标轴上？
  3. 推导软阈值算子：在 XᵀX = I 时，Lasso 的单坐标目标 (wⱼ−ŵⱼ_ols)² + λ|wⱼ| 的最小值是什么？验证软阈值公式 sign(ŵ)·max(|ŵ|−λ/2,0)。
  4. 思考：如果两个特征高度相关，Lasso 会"随机"保留其中一个、丢弃另一个，而岭回归会同时保留两者（各分一半权重）。从"稀疏 vs 稳定"的权衡角度，说明何时该选 Lasso、何时该选岭回归。

母原理连接#

本课属于母原理 "概率视角统一"，完成了"正则项 = 先验负对数"的第二个、也是最具戏剧性的实例。核心结论：L1 正则 = 拉普拉斯先验，而拉普拉斯先验在 0 点的"尖峰"正是稀疏性的全部来源。把本课与上一课并排看，你收获的是一条统一的母原理——先验的形状，决定了正则化的行为：平滑的先验（高斯）给出温和的收缩，尖锐的先验（拉普拉斯）给出果断的归零。选正则，就是选先验。
