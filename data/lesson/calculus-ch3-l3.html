梯度向量#

上一课我们分别求了 ∂z/∂x 和 ∂z/∂y——但它们各说各话。这一课把它们打包成一个向量，就得到机器学习里真正的"主角"：梯度。梯度会告诉你：站在曲面上，往哪个方向走，函数上升（或下降）得最快。

一、概念讲解#

1. 梯度：所有偏导组成的向量#

函数 z = f(x, y) 的梯度，就是把两个偏导按顺序放进一个向量：

∇f = ( ∂f/∂x , ∂f/∂y )

读作"nabla f"。它其实是一个"箭头"：既有方向（指向哪个方向），又有大小（变化有多陡）。输入有几个变量，梯度就有几个分量——n 元函数的梯度是一个 n 维向量。

2. 梯度的方向：最陡的方向#

这是梯度最神奇也最重要的性质：

梯度指向函数"上升最快"的方向；它的反方向就是"下降最快"的方向。

想象你站在一座山上，四面八方都是坡。梯度指向的那条路，是上坡最陡的一条；背对梯度走，就是下坡最陡的一条。梯度的大小，则告诉你这条坡有多陡。

3. 梯度下降：背对梯度，一步步下山#

既然反梯度方向下降最快，那么"找最小值"就有了明确策略：

新参数 = 旧参数 − 学习率 × 梯度

每一步都朝反梯度方向迈一小步，就像蒙着眼、但每一步都挑最陡的下坡走，最终会滑到谷底。这就是梯度下降（Gradient Descent），是训练几乎所有现代神经网络的基石。

对 f(x, y) = x² + y² 来说，梯度 ∇f = (2x, 2y)，从点 (x, y) 出发，反梯度方向就是 (−2x, −2y)——恰好指向原点（最小值点）。这就是为什么梯度下降对它特别有效。

二、可运行示例#

示例一：计算梯度并验证"最陡"性质#

def grad_f(x, y):
    """f(x,y)=x^2+y^2 的梯度 ∇f = (2x, 2y)。"""
    return (2 * x, 2 * y)

x, y = 3.0, 4.0
gx, gy = grad_f(x, y)
print(f"在点 ({x}, {y}) 处，梯度 ∇f = ({gx}, {gy})")
print(f"梯度大小（坡的陡峭程度） = {(gx**2 + gy**2) ** 0.5:.2f}")
print("梯度指向 (6, 8)，即远离原点的方向（上升最快）；")
print("反梯度指向 (-6, -8)，即朝向原点（下降最快）。")

示例二：完整的梯度下降#

我们用梯度下降，从起点 (3, 4) 一路走到 f(x,y)=x²+y² 的最小值 (0, 0)。

def f(x, y):
    return x * x + y * y

def grad_f(x, y):
    return (2 * x, 2 * y)

def gradient_descent(f, grad_f, start, alpha=0.1, steps=20):
    """从 start 出发，沿反梯度方向迭代 steps 步。"""
    x, y = start
    history = [(x, y, f(x, y))]
    for _ in range(steps):
        gx, gy = grad_f(x, y)
        x = x - alpha * gx    # 参数更新：−学习率 × 梯度
        y = y - alpha * gy
        history.append((x, y, f(x, y)))
    return history

history = gradient_descent(f, grad_f, start=(3.0, 4.0))

print("梯度下降过程（每 5 步打印一次）：")
for i in range(0, len(history), 5):
    x, y, val = history[i]
    print(f"  第 {i:2d} 步：位置=({x:7.4f}, {y:7.4f})  损失={val:9.4f}")

print(f"\n最终：位置≈({history[-1][0]:.6f}, {history[-1][1]:.6f})，损失≈{history[-1][2]:.6f}")

运行结果（节选）：

梯度下降过程（每 5 步打印一次）：
  第  0 步：位置=( 3.0000,  4.0000)  损失= 25.0000
  第  5 步：位置=( 0.9830,  1.3107)  损失=  2.6844
  第 10 步：位置=( 0.3221,  0.4295)  损失=  0.2882
  第 15 步：位置=( 0.1056,  0.1407)  损失=  0.0310
  第 20 步：位置=( 0.0346,  0.0461)  损失=  0.0033

最终：位置≈(0.034572, 0.046096)，损失≈0.003321

损失从 25 一路降到 0.003，位置从 (3,4) 逼近 (0,0)——梯度下降成功了！这就是深度学习每次训练背后的数学动作。

示例三：梯度下降拟合线性回归#

把"损失函数的梯度"串起来，做一次真实的参数拟合：

data = [(1, 2), (2, 4), (3, 6)]   # 真实关系 y = 2x

def mse(w, b):
    total = sum((w * x + b - y) ** 2 for x, y in data)
    return total / len(data)

def mse_grad(w, b):
    """MSE 对 w、b 的梯度（偏导的向量）。"""
    gw = sum(2 * (w * x + b - y) * x for x, y in data) / len(data)
    gb = sum(2 * (w * x + b - y) for x, y in data) / len(data)
    return gw, gb

w, b = 0.0, 0.0
alpha = 0.1
for step in range(50):
    gw, gb = mse_grad(w, b)
    w -= alpha * gw
    b -= alpha * gb
    if step % 10 == 0:
        print(f"第 {step:2d} 步：w={w:6.3f}, b={b:6.3f}, MSE={mse(w, b):.4f}")

print(f"\n拟合结果：w={w:.4f}, b={b:.4f}（真实为 w=2, b=0）")

运行后你会看到 w 逼近 2、b 逼近 0、MSE 逼近 0——模型"学会"了数据背后的规律 y=2x。

三、练习#

  1. 把示例二的起点改成 (1, 1) 和 (10, 10)，观察梯度下降最终是否都收敛到 (0, 0)，收敛步数有何不同。
  2. 把学习率 alpha 改成 1.0 和 0.01，观察 f(x,y)=x²+y² 的梯度下降分别会发生什么（提示：alpha=1 可能来回震荡）。
  3. 求 f(x, y) = x² + 3y² 的梯度 ∇f，实现它的梯度下降，观察下降路径更"偏向"哪个轴，并解释原因。
  4. 在示例三里，把数据改成 [(1, 3), (2, 5), (3, 7)]，重新跑梯度下降，验证能否拟合出 y = 2x + 1。
