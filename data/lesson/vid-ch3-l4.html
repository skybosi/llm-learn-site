可控生成与评测：条件控制、指标边界与可复现协议#

这一节要解决什么#

前三节把视频生成拆成了三笔账：时间维的误差轴（第 1 节）、噪声调度与隐空间（第 2 节）、漂移机制与显存（第 3 节）。但它们都默认了一件没有验证的事——"生成得好"是一个定义清楚的量。这一节先不假设它是，而是把它拆开：

  1. 控制的每一种条件都有一个 bit 数，而 bit 数决定控制上限。 20 秒视频的内容熵约 3.9322 Mbit；文本条件（77 token @ 3 bit）只有 231 bit（0.005875%）、首帧 65,536 bit（约束 1/60 的时间轴，即 1.666667%）、逐帧深度 983,040 bit（25.000000%）（表 1）。"文字控制不住细节"首先是信息量问题；引导只能把已有信息放大成梯度，不产生新 bit（第 1 节式 21）。
  2. 分布距离是估计量，不是测量值。 FVD 的最小可分辨差异随样本量按 1/N​ 收缩：δmin​(N)=1.962​σFVD​/N​，σFVD​=20 时 N=64/256/1024 给出 6.929646/3.464823/1.732412（表 2）。跨论文比较 FVD 而不报 N、d 与特征提取器，等于用三把不同的尺子量同一件东西。
  3. 小样本 + 高维会给出系统性偏正的 FVD。 两段特征来自完全相同的分布（真值 FVD =0）时，n=8/32/128/1024 的估计是 6.306530/1.550772/0.420299/0.030777；固定 n=32 改维度 d，20 次重复的平均偏差（每维）从 0.102619（d=2）涨到 0.287562（d=16）（表 4）。"真值 0 也会被估成正数" 是 Fréchet 距离里 Tr(Σ1​Σ2​)1/2 项在 n≪d 时不可估的直接后果。
  4. 像素/分布相似与"生成得好"可以互相矛盾。 同一批样本上的三个反例（表 3）：静止图的像素 MSE 只有 0.010000 却时间一致性 0.000000、综合观感 0.05；高频闪烁的 MSE（0.004000）比强模糊（0.012000）小 3 倍，但时间一致性差 15 倍。没有一致性就没有条件遵循，而没有多样性就没有"生成"——四个轴压不成一个标量。
  5. 自动指标与人评的一致性是必须报告的统计量。 在 12 个模型上，当自动指标的噪声从 0 涨到 2.0 时 Pearson 从 +1.000000 掉到 −0.125630、Spearman 从 +1.000000 掉到 −0.244755、真值前三命中从 3/3 掉到 1/3（表 5）。"趋势一致"不是证据；"ρ=0.71，N=12"才是。

本节的主线：可控性与可评测性都是"信息量 + 统计量"的问题——条件给多少 bit 决定能控多少，样本量给多少决定能分辨多少；把这两件事写成报告卡，视频生成才从演示变成工程。

一、四类条件通道：能控什么、代价在哪#

1.1 把条件写成 bit 数#

沿用第 1 节的记账口径：20 秒视频的潜码是 4×64×64×60 个分量，按每分量 4 bit 有效熵计，内容熵约 3.9322 Mbit。表 1：

条件类型 通道 bit 数 占内容熵 可约束自由度 每秒条件成本
文本：77 token @ 3 bit 231 bit 0.005875% 全局 1 组 —
首帧：1 张 512 潜图 @ 4 bit 65,536 bit 1.666667% 1 个潜帧 —
尾帧：1 张 512 潜图 @ 4 bit 65,536 bit 1.666667% 1 个潜帧 —
首尾帧同时给 131,072 bit 3.333333% 2 个潜帧 —
姿态：17 关节 @ 8 bit × 480 帧 65,280 bit 1.660156% 逐帧骨架 3,264 bit/s
深度：16×16 @ 8 bit × 480 帧 983,040 bit 25.000000% 逐帧几何 49,152 bit/s
光流：32×32 @ 8 bit × 480 帧 3,932,160 bit 100.000000% 逐帧运动 196,608 bit/s

三类条件的性质完全不同：

  • 文本是"全局主题"，231 bit 对逐帧细节几乎没有约束（58.7463 ppm）。
  • 首/尾帧是"锚点"：65,536 bit 只约束 1 个潜帧（1/60 的时间轴），但约束强度极高——第 3 节的关键帧锚定正是用它把漂移"清零"。
  • 逐帧几何条件（深度/光流）是"密集条件"：bit 数高，但必须由用户或另一个模型提供，最后两列就是它的价格。

这条结论对工程的含义：选条件类型时，第一个问题不是"哪个条件效果好"，而是"这个条件的信息量够不够约束我关心的自由度"。想让模型控制"人物左手的姿势"，给文本是在要求它从 231 bit 里推出一个 104 bit 量级的细节——这不是模型能力问题，是通道容量问题。

1.2 首尾帧控制：一个可以算清楚的例子#

首尾帧条件是视频生成里最常用的可控方案（给定首帧与尾帧，生成中间过程）。它的账可以直接算：

  • 两端锚点共 131,072 bit，相当于给时间轴两端各加一个硬约束；
  • 中间 T−2 帧完全没有条件，它们全部由插值/先验决定；
  • 因此"中段是否合理"取决于模型对运动的先验，而不是条件——这在评测上表现为：首尾帧条件能显著提升首尾一致性与条件遵循，但对中段时间一致性几乎无影响（因为它是插值问题的自由部分）。

（式 1）如果把中段也锚定（每 K 帧一个锚点），成本按第 3 节表 5 增长：K=8 时锚点信息量占总内容熵 12.5%，换来平均漂移从 4.833899 降到 0.763398。这就是"可控性"与"条件成本"的直接兑换率。

1.3 引导与信息量：为什么"加引导"不能突破上限#

第 1 节给了分类器无关引导的一致性/多样性交换：ϵ^=ϵuncond​+w(ϵcond​−ϵuncond​)，一致性 ≈1−e−(w−1)、相对多样性 ≈1/w（第 1 节式 21）。

本节要补的是它的信息论解释：引导做的是"把条件方向的梯度放大"，它需要两次前向（无条件 + 有条件），算力 ×2，但它不引入新的条件 bit。因此：

H(输出∣条件) ≥ H(输出)−≤条件 bit 数I(条件;输出)​​ ⟹ 可控细节的上限=条件 bit 数.

H(输出∣条件) ≥ H(输出)−≤条件 bit 数I(条件;输出)​​ ⟹ 可控细节的上限=条件 bit 数.

（式 2）这条不等式的实用价值在于：当你发现"文本控制不住"时，正确的下一步是换条件通道（加深、加姿态、加首尾帧），而不是把 w 从 3 加到 15——后者只会把多样性换掉（1/w），不会增加可控的自由度。表 1 与第 1 节表 6 是同一张账，本节把它扩展到了"条件成本"这一列。

二、评测难题：分布距离的适用边界#

2.1 FVD 是估计量：1/N​ 与最小可分辨差异#

FVD 类指标在两段特征分布之间算 Fréchet 距离：

FVD=∥μ1​−μ2​∥2+Tr(Σ1​+Σ2​−2(Σ1​Σ2​)1/2).

（式 3）它是用有限样本估计出来的量。把单次估计的抽样标准差记为 σFVD​，N 段样本的标准误是 σFVD​/N​，于是两个模型比较时的最小可分辨差异：

δmin​(N)=1.962​N​σFVD​​.

（式 4）表 2（σFVD​=20）：

N 段 SE(N) 95% CI 半宽 δmin​(N) 相对 N=64
16 5.000000 9.800000 13.859293 2.000000
64 2.500000 4.900000 6.929646 1.000000
256 1.250000 2.450000 3.464823 0.500000
1,024 0.625000 1.225000 1.732412 0.250000
4,096 0.312500 0.612500 0.866206 0.125000
16,384 0.156250 0.306250 0.433103 0.062500

三条读数：

  1. N=256 时 δmin​=3.464823：两个模型的 FVD 差小于它就不能声称有差。
  2. 要把 δmin​ 压到一半，N 要乘 4（64→256）——精度是拿样本量平方换的。
  3. 想从 δmin​=20 压到 5（4 倍），N 要涨 16 倍。

边界：这张表假设 σFVD​ 与 N 无关、且两段样本独立。真实评测里这两条都会破：不同模型生成的样本量常不同、特征提取器常不同（σ 与偏差都变），这时数字之间根本不可比。

2.2 小样本偏差：真值 0 也会被估成非 0#

式 3 的第三项 Tr((Σ1​Σ2​)1/2) 需要估计两个 d×d 协方差矩阵。当 n≲d 时，样本协方差是奇异的，这一项不可估，Fréchet 距离出现系统性偏正。表 4 的构造：两段特征都来自完全相同的 8 维高斯（均值 0、Σij​=0.4∣i−j∣，真值 FVD =0）：

n 样本 估计 FVD d d/n 偏差因子

16 2.898130 8 0.500000 0.362266
32 1.550772 8 0.250000 0.193846
64 0.532838 8 0.125000 0.066605
128 0.420299 8 0.062500 0.052537
256 0.224588 8 0.031250 0.028073
1,024 0.030777 8 0.007812 0.003847

固定 n=32、改维度 d（20 次重复取平均，把趋势从单次抽样的涨落里分出来）：

d n 平均估计 FVD 每维平均偏差
2 32 0.205238 0.102619
4 32 0.505500 0.126375

两个可操作判据：

  1. 要么让 n≫d（d=2048 时 n≥104 量级），要么固定同 n、同 d、同提取器再比较。三者缺一，数字不可比。
  2. 报 FVD 时必须同时报 n 与 d，并给出按式 4 算出的 δmin​。只报"我们的 FVD 是 120"是半个数字。

2.3 为什么不能只看像素/分布相似：三个可算的反例#

表 3 在同一批样本上给四种"生成结果"的四个轴打分：

生成结果 像素 MSE 时间一致性 条件遵循 多样性 综合观感
真值视频 0.000000 0.000000 0.00 0.00 1.00
静止图（复制同一帧） 0.010000 0.000000 0.90 0.02 0.05
强模糊（保留运动骨架） 0.012000 0.004000 0.35 0.30 0.90
高频闪烁（细节锐利、帧间抖动） 0.004000 0.060000 0.05 0.95 0.45

三个反例：

  1. 静止图的像素 MSE 只有 0.010000，但时间一致性 0.000000、综合观感 0.05（最低）。任何只看像素/分布相似的指标都会把它排在"强模糊"或"高频闪烁"之上。
  2. 强模糊的 MSE（0.012000）比高频闪烁（0.004000）大 3 倍，但时间一致性（0.004000 对 0.060000）好 15 倍、观感高得多。像素误差与时间一致性的排序可以完全相反。
  3. 多样性与前三列正交：静止图 0.02、闪烁 0.45，而它们的条件遵循是 0.90 与 0.05。没有一致性就没有条件遵循，而没有多样性就没有"生成"。

（式 5）由此得到评测协议的第一条硬规则：

报告卡 ⊇ {视觉质量, 时间一致性, 条件遵循, 多样性}.

任何一个标量总分都会把上面三种失效混在一起——"总分 82 分"这种数字在视频生成里没有可操作性。

三、可复现评测协议#

3.1 七个必填字段与它们各自防住的失效#

协议字段 它防住的失效
固定 prompt 集（含随机种子与模板） 提示换一批，分数就换一批
样本量 N 与置信区间（δmin​ 随 N 报） 小样本差异被当成方法差异
特征提取器与 d（含是否用预训练权重） 换提取器就换了一把尺子
四个口径分别报告（质量/一致性/条件遵循/多样性） 标量总分掩盖失效类型
参考基线（同 n、同 d、同提取器复跑） 跨论文数字直接相比
人评对齐检查（相关性 + 样本量） 自动指标与人评脱钩
失败样例清单（至少 10 例，含随机抽样的） 只看均值看不到系统性失效

（表 6 上半）这份清单的每一条都对应一个具体的失效，不是形式主义：固定 prompt 集防的是"提示敏感"；报 δmin​ 防的是"把 0.5 的差当成方法改进"；固定提取器防的是"跨论文比较"；四口径防的是"用总分掩盖失效类型"；人评相关性防的是"自动指标自娱自乐"；失败样例清单防的是"均值掩盖长尾"。

3.2 一页报告卡#

把清单落成可执行的一页（表 6 下半）：

报告卡字段 示例值（构造） 备注
prompt 集 固定 256 条 公开 seeds 与模板
N（段） 256 δmin​=3.464102
特征提取器 I3D-like, d=2048 固定权重与预处理
视觉质量 见正文口径 单列，不合并
时间一致性 0.027（抖动口径） 必须写口径

这张卡的设计原则是"缺项即视为未报告"：任何一项缺失，读者都无法判断数字的可比性。注意"时间一致性"那一行的备注是"必须写口径"——第 1 节表 3 已经证明四个口径互不蕴含，只写"一致性 0.027"是不完整的。

3.3 人评对齐：相关性必须带样本量#

表 5 的构造：12 个模型，真值质量固定，自动指标 = 真值 + 噪声 × 尺度：

噪声尺度 Pearson r Spearman ρ 真值前 3 命中 真值差中位数
0.00 +1.000000 +1.000000 3/3 0.581434
0.25 +0.875137 +0.846154 2/3 0.581434
0.50 +0.574972 +0.468531 2/3 0.581434
1.00 +0.148174 −0.027972 1/3 0.581434
2.00 −0.125630 −0.244755 1/3 0.581434

读法：噪声尺度到 0.5 时 Pearson 还有 +0.574972，看起来"相关"，但真值前 3 命中已经掉到 2/3——相关系数对"顶部几名"不敏感，而工程决策往往只看顶部几名。所以报告卡里"人评相关性"这一项应该同时给相关系数与前 k 命中率。

（式 6）另一条可算的判据在最后一列：相邻模型的真值差中位数是 0.581434。当自动指标的噪声标准差超过这个中位数时，排序就已经不可靠了。这条判据把"我的指标够不够准"变成一个可以直接算的问题。

3.4 本节的三条边界#

  1. 条件通道的 bit 数决定控制上限（表 1、式 2）：文本 231 bit（0.005875%）、首帧 65,536 bit（约束 1/60 时间轴）、逐帧深度 983,040 bit（25.000000%）。引导只放大已有信息，算力 ×2 换来的是一致性/多样性交换，不是新的可控自由度。
  2. 分布距离是估计量（式 4）：δmin​ 按 1/N​ 收缩（N=64/256/1024→6.929646/3.464823/1.732412），且小 n/大 d 时有正向偏差（真值 0 估成 6.306530，n=8,d=8）。不比 n、不比 d、不比提取器的数字之间没有可比性。
  3. 评测必须多口径（表 3、式 5）：四个轴可以互相矛盾（静止图 MSE 小但一致性为 0；闪烁 MSE 最小但一致性最差），标量总分掩盖失效类型。报告卡缺项即视为未报告。

代码#

下面的脚本重算本节六张表的每一个数字：四类条件通道的信息量与代价、FVD 的 δmin​ 与样本量表、四口径互相矛盾的构造反例、Fréchet 距离的小样本偏差（含纯标准库实现的 Jacobi 特征分解与矩阵平方根）、自动指标与人评的排序一致性、以及协议七字段与报告卡。合成数据均标在注释里，随机数来自固定种子的自写 LCG，同一份代码每次运行输出逐字节相同。

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""第 3 章 第 4 节 数值脚本（正文表 1~表 6）。"""
import math
import unicodedata


def dwidth(s):
    return sum(2 if unicodedata.east_asian_width(ch) in ("W", "F") else 1
               for ch in s)


def pad(s, w, align=">"):
    gap = max(0, w - dwidth(s))
    if align == ">":
        return " " * gap + s
    if align == "<":
        return s + " " * gap
    left = gap // 2
    return " " * left + s + " " * (gap - left)


def row(cells, widths, aligns=None):
    aligns = aligns or [">"] * len(cells)
    return " | ".join(pad(c, w, a) for c, w, a in zip(cells, widths, aligns))


def rule(t, w=112):
    print("=" * w)
    print(t)
    print("=" * w)


class LCG:
    def __init__(self, seed=20260923):
        self.s = seed & 0xFFFFFFFFFFFFFFFF

    def u(self):
        self.s = (6364136223846793005 * self.s + 1442695040888963407) \
            & 0xFFFFFFFFFFFFFFFF
        return (self.s >> 11) / float(1 << 53)

    def n(self):
        u1 = max(self.u(), 1e-12)
        u2 = self.u()
        return math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)

    def uni(self):
        return self.u()

rule("表 1  四类条件通道：信息量、约束自由度与代价")

T = 480                     # 20 s @ 24 fps
N_SIDE = 4096               # 空间位置数（64x64）
N_LAT = 60                  # 潜帧数
LAT_ELEMS = 4 * N_SIDE * N_LAT
EFF_BIT = 4.0
LAT_ENTROPY = LAT_ELEMS * EFF_BIT
print(f"参照量：{T} 帧（20 s @ 24 fps）的潜码 = 4*{N_SIDE:,}*{N_LAT} = "
      f"{LAT_ELEMS:,} 个分量，")
print(f"  按每分量有效熵 {EFF_BIT:.1f} bit 计，内容熵 = {LAT_ENTROPY / 1e6:,.4f} Mbit。")
print()
widths = [30, 14, 16, 18, 18]
print(row(["条件类型", "通道 bit 数", "占内容熵", "可约束自由度", "每秒条件成本"],
          widths))
print("-" * 112)
CONDS = (
    ("文本：77 token @ 3 bit", 77 * 3, "全局 1 组", 0.0),
    ("首帧：1 张 512 潜图 @ 4 bit", N_SIDE * EFF_BIT, "1 个潜帧", 0.0),
    ("尾帧：1 张 512 潜图 @ 4 bit", N_SIDE * EFF_BIT, "1 个潜帧", 0.0),
    ("首尾帧同时给", 2 * N_SIDE * EFF_BIT, "2 个潜帧", 0.0),
    ("姿态：17 关节 @ 8 bit x 480 帧", 17 * 8 * T, "逐帧骨架", 17 * 8 * 24),
    ("深度：16x16 @ 8 bit x 480 帧", 16 * 16 * 8 * T, "逐帧几何", 16 * 16 * 8 * 24),
    ("光流：32x32 @ 8 bit x 480 帧", 32 * 32 * 8 * T, "逐帧运动", 32 * 32 * 8 * 24),
)
for name, bits, dof, per_sec in CONDS:

               f"{per_sec:,} bit/s" if per_sec else "-"], widths))
print()

D_FEAT = 8


def make_cov(d, rho):
    return [[rho ** abs(i - j) for j in range(d)] for i in range(d)]


def chol(A):
    n = len(A)
    L = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(i + 1):
            s = sum(L[i][k] * L[j][k] for k in range(j))
            if i == j:
                L[i][j] = math.sqrt(max(1e-18, A[i][i] - s))
            else:
                L[i][j] = (A[i][j] - s) / L[j][j]
    return L


def matmul(A, B):
    n, m, p = len(A), len(B), len(B[0])
    return [[sum(A[i][k] * B[k][j] for k in range(m)) for j in range(p)]
            for i in range(n)]


def transpose(A):
    return [list(r) for r in zip(*A)]


def jacobi_eig(A, iters=200):
    """对称矩阵的 Jacobi 特征分解（纯标准库），返回 (特征值, 特征向量)。"""
    n = len(A)
    a = [r[:] for r in A]
    V = [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]
    for _ in range(iters):
        off = math.sqrt(sum(a[i][j] ** 2 for i in range(n)
                            for j in range(n) if i != j))
        if off < 1e-14:
            break
        for p in range(n - 1):
            for q in range(p + 1, n):
                if abs(a[p][q]) < 1e-18:
                    continue
                theta = 0.5 * math.atan2(2 * a[p][q], a[q][q] - a[p][p])
                c, s = math.cos(theta), math.sin(theta)
                for k in range(n):
                    apk, aqk = a[p][k], a[q][k]
                    a[p][k] = c * apk - s * aqk
                    a[q][k] = s * apk + c * aqk
                for k in range(n):
                    akp, akq = a[k][p], a[k][q]
                    a[k][p] = c * akp - s * akq
                    a[k][q] = s * akp + c * akq
                for k in range(n):
                    vkp, vkq = V[k][p], V[k][q]
                    V[k][p] = c * vkp - s * vkq
                    V[k][q] = s * vkp + c * vkq
    return [a[i][i] for i in range(n)], V


def sqrt_psd(A):
    """对称半正定矩阵的平方根（用于计算 Tr((Sigma1 Sigma2)^{1/2})）。"""
    w, V = jacobi_eig(A)
    w = [max(0.0, x) for x in w]
    sw = [math.sqrt(x) for x in w]
    n = len(A)
    return [[sum(V[i][k] * sw[k] * V[j][k] for k in range(n)) for j in range(n)]
            for i in range(n)]


def frechet(mu1, S1, mu2, S2):
    d = len(mu1)
    dm = sum((a - b) ** 2 for a, b in zip(mu1, mu2))
    prod = matmul(S1, S2)
    tr = sum(sqrt_psd(prod)[i][i] for i in range(d))
    return dm + sum(S1[i][i] for i in range(d)) + \
        sum(S2[i][i] for i in range(d)) - 2 * tr

    S = [[sum((x[i] - m[i]) * (x[j] - m[j]) for x in xs) / n
          for j in range(d)] for i in range(d)]
    return m, S

def rank(v):
    order = sorted(range(len(v)), key=lambda i: v[i])
    rk = [0.0] * len(v)
    for pos, i in enumerate(order):
        rk[i] = float(pos)
    return rk


def pearson(a, b):
    n = len(a)
    ma, mb = sum(a) / n, sum(b) / n
    num = sum((x - ma) * (y - mb) for x, y in zip(a, b))
    da = math.sqrt(sum((x - ma) ** 2 for x in a))
    db = math.sqrt(sum((y - mb) ** 2 for y in b))
    return num / (da * db)


def topk_hits(a, b, k=3):
    ia = sorted(range(len(a)), key=lambda i: a[i])[:k]
    ib = sorted(range(len(b)), key=lambda i: b[i])[:k]
    return len(set(ia) & set(ib))

  delta_min(N) = 1.96 * sqrt(2) * SE(N)

          64 |         2.500000 |             4.900000 |             6.929646 |           1.000000
         256 |         1.250000 |             2.450000 |             3.464823 |           0.500000
       1,024 |         0.625000 |             1.225000 |             1.732412 |           0.250000

  · N=256 时 delta_min = 3.464823：两个模型的 FVD
    差小于这个数就不能声称有差。
  · N=64 时 delta_min = 6.929646；要把它压到一半，按 1/sqrt(N) 需要把 N 乘 4（64 -> 256）。
  · 想把 delta_min 从 20 压到 5（4 倍），N 需要涨 16 倍。

的 SE 与偏差都不同，**数字之间根本不可比** —— 这是本节最常被忽略的一句。

这张表的三个反例（都能在同一批样本上复算）：
  1) **静止图**的像素 MSE 只有 0.010000，但时间一致性 0.000000、条件遵循
     0.900000 —— 任何只看「像素/分布相似」的指标都会把它排在模糊或闪烁
     之上，而人的综合观感是 0.05（最低）。
  2) **强模糊**的 MSE（0.012000）比高频闪烁（0.004000）大 3 倍，但它的
     时间一致性（0.004000）比闪烁（0.060000）好 15 倍、观感高得多。
     这说明「像素误差」与「时间一致性」的排序可以**完全相反**。
  3) **多样性**这一列与前三列正交：静止图的多样性 0.02、闪烁 0.45，
     而它们的条件遵循分别是 0.90 与 0.05。**没有一致性就没有条件遵循，
     而没有多样性就没有「生成」** —— 四个轴无法压成一个标量。

由此得到评测协议的第一条硬规则：**报告卡必须至少给四个数**
（视觉质量 / 时间一致性 / 条件遵循 / 多样性），任何一个标量总分都会把
上面三种失效混在一起。

练习#

  1. 条件的信息量。 用表 1 的口径：设你希望模型控制"人物右手在每帧的三维位置"（3 个数、各 8 bit、480 帧）。算出通道 bit 数与占内容熵的比例。回答：如果只给文本条件（231 bit），模型要"猜"多少 bit？这解释了哪一类失败？
  2. δmin​ 的花费。 用式 4：设 σFVD​=35，你要在 95% 置信下分辨 FVD 差 2.0。求所需 N。回答：如果换成把特征维度从 d=2048 降到 d=512（假设 σ 同步降到 1/2），N 可以降到多少？
  3. 小样本偏差的外推。 表 4 给出 n=8 时真值 0 被估成 6.306530。用 d/n 这个自变量，拟合"估计 FVD 随 n 下降"的经验幂律（取 n=8∼1024 六点，log-log）。回答：据此估计 n=4096 时的偏差，并与 n=1024 的 0.030777 对照，说明为什么"把 n 翻倍"在 d/n 很小时收益有限。
  4. 反对称指标。 表 3 里"静止图"的 MSE 是 0.010000、"高频闪烁"是 0.004000。构造一个只由这两项组成（再加时间一致性）的加权指标族 S=αMSE+β(1−TC)，求 α/β 的取值区间使得"闪烁"排在"静止图"之前（即 Sflash​<Sstill​）。回答：这个区间是否非空？如果非空，为什么实际评测里仍然不应该用单一 S？
  5. 排序一致性的样本量。 在表 5 的构造里，k=3、模型数 =12。若噪声尺度取 0.5，前 3 命中的期望命中数是多少（用随机置换的基线 k2/M 对比）？回答：要让"前 3 命中"成为一个有统计意义的证据，需要多少个人评模型？给出你的推导。

小结#

  • 四类条件的信息量（表 1）：文本 231 bit（0.005875%）、首帧/尾帧各 65,536 bit（1.666667%）、首尾帧 131,072 bit、姿态 65,280 bit（1.660156%）、深度 983,040 bit（25.000000%）、光流 3,932,160 bit（100.000000%）。逐帧条件每秒成本 3,264∼196,608 bit/s——控制的每一 bit 都是从标注/前处理借来的。
  • 控制上限由条件 bit 数封顶（式 2）：H(输出∣条件)≥H(输出)−I(条件;输出)，引导（算力 ×2）只放大已有信息。
  • δmin​(N)=1.962​σFVD​/N​（式 4）：σ=20 时 N=16/64/256/1024/16384 给 13.859293/6.929646/3.464823/1.732412/0.433103。精度按 N2 换。
  • 小样本偏正（表 4）：真值 FVD =0 时，n=8/16/32/64/128/256/1024 的估计是 6.306530/2.898130/1.550772/0.532838/0.420299/0.224588/0.030777；固定 n=32、d:2→16 的每维平均偏差 0.102619→0.287562。判据：n≫d，或固定 n/d/提取器。
  • 像素/分布相似与质量可以矛盾（表 3）：静止图 MSE 0.010000 但一致性 0.000000、观感 0.05；高频闪烁 MSE 0.004000（比强模糊小 3 倍）但一致性差 15 倍。四个轴压不成一个标量（式 5）。
  • 自动指标与人评（表 5）：噪声 0→2.0 时 Pearson +1.000000→−0.125630、Spearman +1.000000→−0.244755、真值前 3 命中 3/3→1/3。报告必须给相关系数 + 样本量 + 前 k 命中率；噪声超过真值差中位数（0.581434）时排序不可靠（式 6）。
  • 协议七字段（表 6）：固定 prompt 集 / N 与 δmin​ / 提取器与 d / 四口径 / 同条件基线 / 人评对齐 / 失败样例清单。缺项即视为未报告。
