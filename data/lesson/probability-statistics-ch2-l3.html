分布函数与概率密度#

上一课我们分别用 PMF 和 PDF 描述了离散与连续随机变量。这一课引入一个"统一"的工具——累积分布函数（CDF）。无论离散还是连续，它都能完整刻画一个随机变量的概率规律，而且它天然地回答了机器学习里最常问的问题："取值不超过某个阈值的概率有多大？"

一、概念讲解#

1. 累积分布函数（CDF）的定义#

随机变量 X 的累积分布函数定义为：

F(x) = P(X ≤ x)

也就是"X 的取值不超过 x"的概率。它对离散和连续变量都成立，而且随 x 增大单调不减，且满足 F(−∞) = 0、F(+∞) = 1。

CDF 的三个关键性质：

  1. 单调不减：x 越大，F(x) 不会变小；
  2. 右连续：F(x) 在每个点从右边连续；
  3. 两端极限：x 趋于负无穷时 F(x)→0，趋于正无穷时 F(x)→1。

2. CDF 与 PMF / PDF 的关系#

  • 离散情形：F(x) = Σ_{k≤x} P(X = k)，即把不超过 x 的所有质量累加起来。F(x) 是一条"阶梯状"上升的曲线，在取值点处跳一下，跳跃的高度就是那个点的概率。
  • 连续情形：F(x) = ∫_{−∞}^{x} f(t) dt，即密度曲线从负无穷到 x 的面积。反过来，密度就是 CDF 的导数：f(x) = F′(x)。

所以 PMF 是"每个点的概率"，PDF 是"密度的瞬时值"，而 CDF 是"累积起来的概率"。三者是同一信息的三种写法。

3. 用 CDF 算区间概率#

CDF 最大的便利是能直接做减法算区间概率：

P(a < X ≤ b) = F(b) − F(a)

对连续变量，端点取不取等号无所谓（单点概率为 0）；对离散变量则要注意端点是否包含。

4. 分位数：CDF 的反函数#

给定概率 p，满足 F(x) = p 的那个 x 叫p 分位数（quantile）。中位数就是 0.5 分位数；在机器学习里，"95 分位数"常用来描述"95% 的样本不超过这个值"。分位数是 CDF 的"反着用"：CDF 从值求概率，分位数从概率求值。统计里的箱线图、置信区间、归一化分位数变换都依赖它。

5. 机器学习视角：CDF 的实用价值#

  • 阈值决策：模型输出一个分数，我们要选一个阈值，让"误报率不超过 5%"，这等价于在 CDF 上找 95 分位数。
  • 异常检测：一个样本值落在 CDF 的极端尾部（比如超过 99.9 分位数），就很可能是异常。
  • 经验 CDF（ECDF）：没有理论分布时，直接用样本画出的阶梯状 CDF，是探索性数据分析（EDA）的常用工具。

二、可运行示例#

示例 1：离散分布的 CDF 手算#

# 掷一颗公平骰子，X 为点数。计算 F(x) = P(X ≤ x)
pmf = {k: 1 / 6 for k in range(1, 7)}


def cdf(pmf, x):
    """离散分布：把不超过 x 的取值概率累加。"""
    return sum(p for k, p in pmf.items() if k <= x)


for x in [0, 1, 2, 3, 4, 5, 6, 7]:
    print(f"F({x}) = P(X ≤ {x}) = {cdf(pmf, x):.4f}")

示例 2：用样本构造经验 CDF#

import random

random.seed(0)

# 抽取 1000 个样本，构造经验 CDF：P(X ≤ x) ≈ 不超过 x 的样本占比
samples = [random.gauss(0.0, 1.0) for _ in range(1000)]


def ecdf(samples, x):
    """经验累积分布函数：用样本中小于等于 x 的比例估计 F(x)。"""
    return sum(1 for s in samples if s <= x) / len(samples)


for x in [-2.0, -1.0, 0.0, 1.0, 2.0]:
    print(f"经验 F({x}) ≈ {ecdf(samples, x):.4f}")

示例 3：正态分布 CDF 与区间概率#

import math


def normal_cdf(x, mu=0.0, sigma=1.0):
    """标准正态分布的 CDF，借助 math.erf（误差函数）计算。"""
    return 0.5 * (1 + math.erf((x - mu) / (sigma * math.sqrt(2))))


# 标准正态下，约 68% 落在 [-1, 1]，95% 落在 [-1.96, 1.96]
p_68 = normal_cdf(1.0) - normal_cdf(-1.0)
p_95 = normal_cdf(1.96) - normal_cdf(-1.96)
print(f"P(-1 ≤ X ≤ 1) ≈ {p_68:.4f}（经验法则约 0.68）")
print(f"P(-1.96 ≤ X ≤ 1.96) ≈ {p_95:.4f}（约 0.95）")
