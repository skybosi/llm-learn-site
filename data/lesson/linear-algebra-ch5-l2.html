特征分解#

上一课我们找到了矩阵的"主轴"——特征向量。这一课把所有这些主轴拼起来，把矩阵本身"拆散"成最清晰的形式：特征分解（eigendecomposition）。它能把矩阵的幂、矩阵函数变成极简单的运算，更是 PCA（主成分分析）的直接来源。

一、概念讲解#

1. 特征分解的形式#

如果一个 n×n 方阵 A 有 n 个线性无关的特征向量，把它们按列排成矩阵 Q，把对应特征值排成对角矩阵 Λ，就有

A=QΛQ−1

其中 Λ=diag(λ1​,…,λn​)。这就是特征分解：A 被写成"换基 → 缩放 → 换回"三个动作。

2. 对称矩阵的优雅形式#

当 A 是对称矩阵（A=AT）时，性质格外好：特征值都是实数，且可以选出一组互相正交的单位特征向量，于是 Q 是正交矩阵，满足 Q−1=QT。此时特征分解变成

A=QΛQT

这正是机器学习里最常见的形态，因为协方差矩阵、核矩阵、很多 Hessian 矩阵都是对称的。

3. 它为什么有用#

  • 矩阵幂：Ak=QΛkQT，对角矩阵的幂只需对每个对角元素求幂，复杂度大幅下降。
  • 几何解读：A 的效果等于"旋转到主轴坐标 → 沿各轴独立缩放 → 旋转回来"。
  • PCA 的来源：对数据协方差矩阵做特征分解，最大特征值对应的特征向量就是第一主成分方向。

4. 可对角化的条件#

并不是所有矩阵都能写成 A=QΛQ−1。只有当矩阵有 n 个线性无关的特征向量时才可以（称为可对角化）。对称矩阵一定可对角化；但某些矩阵（比如若尔当块）特征向量不足 n 个，就不可对角化。好在 AI 里遇到的绝大多数对称矩阵都没这个问题。

二、可运行代码示例#

import numpy as np

# ---- 例 1：对称矩阵的特征分解 A = Q Λ Q^T ----
A = np.array([[2.0, 1.0],
              [1.0, 2.0]])
eigvals, Q = np.linalg.eigh(A)      # eigh 专用于对称矩阵，返回升序特征值
Lambda = np.diag(eigvals)
A_recon = Q @ Lambda @ Q.T
print("特征值（升序）=", eigvals)
print("重构 A =\n", A_recon)
print("与原始 A 相等：", np.allclose(A, A_recon))

# ---- 例 2：用特征分解快速求矩阵的高次幂 ----
k = 10
A_pow = Q @ np.diag(eigvals ** k) @ Q.T
print("A^10 =\n", A_pow)
print("与直接矩阵乘方一致：",
      np.allclose(A_pow, np.linalg.matrix_power(A, k)))

# ---- 例 3：特征分解是 PCA 的核心 ----
np.random.seed(0)
n = 200
x = np.random.randn(n)
y = 2.5 * x + 0.6 * np.random.randn(n)   # y 与 x 强相关 → 数据沿斜向延展
X = np.column_stack([x, y])
Xc = X - X.mean(axis=0)                   # 数据中心化
Cov = (Xc.T @ Xc) / (n - 1)               # 协方差矩阵
vals, Q = np.linalg.eigh(Cov)             # 升序
print("协方差矩阵特征值（升序）=", vals)
print("方差最大的主方向 =", Q[:, -1])      # 数据"散得最开"的方向

要点：例 3 中 Q[:, -1] 对应最大特征值，就是数据延伸的斜向主方向。沿这个方向投影，能保留最大的方差——这就是 PCA 选第一主成分的完整逻辑。
