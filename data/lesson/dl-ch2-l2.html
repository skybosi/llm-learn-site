VGG/ResNet#

AlexNet 证明了"更深"有用，但更深的网络该怎么设计？VGG 给出的答案是"规整地深"——只用 3×3 卷积反复堆叠；ResNet 更进一步，用残差连接打破了"网络越深越难训练"的魔咒，把深度推到上百层。这一课是经典架构的核心，理解 ResNet 的 shortcut，等于拿到读懂现代骨干网络的钥匙。

一、概念讲解#

1. VGG：用最朴素的方式变深#

VGG（2014）的设计哲学极其简单：只堆 3×3 卷积和 2×2 池化，全网络结构高度统一。它按深度分为 VGG-16、VGG-19 等版本，其中 VGG-16 有 13 个卷积层 + 3 个全连接层。

为什么要坚持 3×3 小卷积？关键在感受野的等价性：

两个 3×3 卷积堆叠 ≈ 一个 5×5 卷积的感受野
三个 3×3 卷积堆叠 ≈ 一个 7×7 卷积的感受野

但参数却省得多：一个 5×5 卷积有 25 个权重，两个 3×3 卷积只有 18 个；而且中间多了一层非线性，表达力反而更强。所以 VGG 用"小而多"的卷积，在同样感受野下换取更少的参数和更强的拟合能力。

VGG 的代价是全连接层太重：末端两个 4096 维全连接层贡献了绝大部分参数（约 1.38 亿），又慢又占内存，这正是后来被改进的地方。

2. 退化问题：为什么网络不能无脑加深#

直觉上，网络越深拟合能力越强，但实验发现：当深度超过某个阈值，训练误差反而上升，而且这不是过拟合（连训练集都变差了）。这被称为退化问题（degradation）。

原因之一是深层网络的梯度在反向传播中不断连乘，容易消失或爆炸，优化变得困难——即使加了 BatchNorm，几十层以后依然难以训练。ResNet 就是冲着这个问题来的。

3. ResNet：让网络学习"残差"#

ResNet（2015）的核心是一个大胆的改动——残差连接（shortcut / skip connection）。与其让若干层直接去学目标映射 H(x)，不如让它们去学残差 F(x) = H(x) − x，再通过捷径把输入 x 原样加回来：

输出 = F(x) + x

这里的 F(x) 通常是"卷积 → BN → ReLU → 卷积 → BN"这样两层的组合，+ x 则是把输入直接跳过这两层加到输出上。这个"绕道"的加法看似简单，却带来两个决定性好处：

  1. 梯度高速公路：反向传播时，梯度可以通过 shortcut 直接流回浅层，不易消失；
  2. 降低学习难度：当 F(x) 学到 0 时，整个块退化为恒等映射 x，网络"至少不会变差"，于是加深网络有了安全底线。

因此 ResNet 能堆到 50、101 甚至 152 层，并在 2015 年 ImageNet 上把错误率进一步压到 3.57%（超过人类水平）。

4. 基本块与瓶颈块#

ResNet 有两个常用积木：

  • BasicBlock：两个 3×3 卷积，通道数不变，用于 ResNet-18/34 这类较浅网络；
  • Bottleneck（瓶颈块）：先用 1×1 卷积降通道、中间 3×3 卷积、再用 1×1 升回通道，用于 ResNet-50/101/152，能在深度很大时控制参数量。

无论哪种块，只要输入输出尺寸或通道不一致，shortcut 就不能原样相加，需要加一个 1×1 卷积（或下采样卷积）把 x 变换到匹配的维度。

二、可运行代码示例#

下面实现 VGG 风格的卷积块与 ResNet 的 BasicBlock、Bottleneck，体会两种"变深"思路的差别。

import torch
import torch.nn as nn

def vgg_block(in_c, out_c, num_convs):
    """VGG 风格：num_convs 个 3x3 卷积 + 一个 2x2 池化。"""
    layers = []
    for _ in range(num_convs):
        layers.append(nn.Conv2d(in_c, out_c, kernel_size=3, padding=1))
        layers.append(nn.ReLU(inplace=True))
        in_c = out_c
    layers.append(nn.MaxPool2d(kernel_size=2))
    return nn.Sequential(*layers)

class BasicBlock(nn.Module):
    """ResNet 基本块：两个 3x3 卷积 + 残差连接。"""
    expansion = 1
    def __init__(self, in_c, out_c, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_c, out_c, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_c)
        self.conv2 = nn.Conv2d(out_c, out_c, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_c)
        # 当尺寸或通道变化时，shortcut 需要 1x1 卷积对齐
        self.shortcut = nn.Sequential()
        if stride != 1 or in_c != out_c:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_c, out_c, 1, stride, bias=False),
                nn.BatchNorm2d(out_c),
            )

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)      # 残差连接：F(x) + x
        return torch.relu(out)

class Bottleneck(nn.Module):
    """ResNet 瓶颈块：1x1 降维 -> 3x3 -> 1x1 升维。"""
    expansion = 4
    def __init__(self, in_c, mid_c, stride=1):
        super().__init__()
        out_c = mid_c * self.expansion
        self.conv1 = nn.Conv2d(in_c, mid_c, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(mid_c)
        self.conv2 = nn.Conv2d(mid_c, mid_c, 3, stride, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(mid_c)
        self.conv3 = nn.Conv2d(mid_c, out_c, 1, bias=False)
        self.bn3 = nn.BatchNorm2d(out_c)
        self.shortcut = nn.Sequential()
        if stride != 1 or in_c != out_c:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_c, out_c, 1, stride, bias=False),
                nn.BatchNorm2d(out_c),
            )

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = torch.relu(self.bn2(self.conv2(out)))
        out = self.bn3(self.conv3(out))
        out += self.shortcut(x)
        return torch.relu(out)

# 验证前向
x = torch.randn(2, 64, 32, 32)
block = BasicBlock(64, 64)
print("BasicBlock 输出:", tuple(block(x).shape))      # [2, 64, 32, 32]

bn = Bottleneck(64, 64)
print("Bottleneck 输出:", tuple(bn(x).shape))         # [2, 256, 32, 32]（expansion=4）

这段代码揭示了 ResNet 最精妙的一行：out += self.shortcut(x)。它把"学映射"改成了"学残差"，配合 BatchNorm，让上百层的网络也能稳定训练。

三、练习#

  1. 用两层 3×3 卷积和一个 5×5 卷积分别对一张图做卷积，对比两者的参数量，验证 VGG"两个 3×3 等价一个 5×5 感受野但参数更少"的说法。
  2. 构造一个 BasicBlock(32, 64, stride=2) 并前向，打印输出形状，说明此时 shortcut 为什么不能直接用 x 相加。
  3. 手算 Bottleneck(64, 64) 三个卷积层的参数量之和，解释瓶颈块为何比两个 3×3（通道 256）的普通块更省参数。
  4. 思考：如果去掉残差连接（out += self.shortcut(x) 这一行），这个 BasicBlock 退化成什么？结合"退化问题"谈谈 shortcut 的必要性。
