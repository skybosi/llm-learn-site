最优贝尔曼方程#

上一课我们学会了对任意给定策略 π 求价值函数 v_π。但强化学习的最终目标不是"评价某个策略"，而是"找到最好的那个策略"。这一课我们把这个"最好"精确化：定义最优价值函数 v_* 与 q_*，写出它们满足的贝尔曼最优方程（Bellman optimality equation），并讲清三个关键点——最优方程为什么是"非线性"的、为什么"对 q_ 贪心"就是最优策略、以及最优价值函数为什么唯一存在*。这是第 3 章动态规划（策略迭代、价值迭代）的直接理论依据。

一、概念讲解#

1. 策略的偏序：什么叫"一个策略比另一个好"#

要谈"最优"，先得能比较两个策略。定义策略间的偏序关系 π ≥ π'：

π ≥ π'  ⟺  v_π(s) ≥ v_π'(s)  对所有 s ∈ S 都成立

即：策略 π 不劣于 π'，当且仅当它在每一个状态上的价值都不更低。 说它是"偏序"而非"全序"，是因为可能存在两个策略互有胜负（在 s1 上 π 好、在 s2 上 π' 好），此时两者不可比较。但关键结论是：在这个偏序下，至少存在一个"不比任何策略差"的最优策略（有限 MDP 里策略只有有限多个，取"价值逐点最大"的那个即可）。这个最优策略记作 π_*，它可能不止一个（可以并列最优），但它们共享同一个价值函数。

2. 最优价值函数：逐点取最大#

基于偏序，定义两个最优价值函数：

v_*(s) = max_π v_π(s)          （在所有策略上取最大）
q_*(s, a) = max_π q_π(s, a)

v_*(s) 是"从状态 s 出发，在最优策略下能拿到的最大期望回报"；q_*(s, a) 是"先在 s 选 a，之后按最优策略走，能拿到的最大期望回报"。注意 v_* 是对策略取最大，不是对动作取最大——这是一个容易被读错的地方。由定义，最优策略 π_* 就是处处达到这个最大值的策略：v_{π_*}(s) = v_*(s) 对所有 s 成立。

3. 最优方程：把 max 塞进贝尔曼方程#

上一课的贝尔曼方程对某个固定 π 成立。对最优价值函数，直觉是"在每一步都选最好的动作"，于是把求和前的 π(a|s) 换成 max_a，得到贝尔曼最优方程：

v_*(s) = max_a  Σ_{s', r} p(s', r | s, a) · [ r + γ · v_*(s') ]

对称地，动作价值的最优方程：

q_*(s, a) = Σ_{s', r} p(s', r | s, a) · [ r + γ · max_{a'} q_*(s', a') ]

读作：最优状态价值 = 在所有动作里，选那个让"即时奖励 + 折扣后的最优后续价值"最大的动作。 结构依然是"即时项 + 未来项"，但那个 Σ_a π(a|s) 被 max_a 取代了。另外两个价值函数之间还有一条简单而重要的桥：

v_*(s) = max_a q_*(s, a)

——最优状态价值，就是从 s 出发所有动作里最好的那个动作价值。

4. 为什么最优方程是非线性的：max 不是线性算子#

对比上一课的贝尔曼方程（对 π 是线性方程组），贝尔曼最优方程是非线性的。原因只有一个：max 不是线性算子。线性算子满足 T(αx + βy) = αT(x) + βT(y)，但 max_a(α x_a + β y_a) ≠ α max_a x_a + β max_a y_a。于是"最优方程"不能像"策略方程"那样直接移项、用 (I − γP)^{-1} 一次解出来——它必须靠迭代（第 3 章的价值迭代）去逼近。这是"最优版"与"策略版"之间最本质的差异，也是理解动态规划两条算法差异的钥匙。

5. 对 q_* 贪心，就是最优策略#

一个自然的问题是：知道了 q_*(s, a)，怎么得到最优策略？答案是——在每个状态贪心地选 q_* 最大的动作：

π_*(s) = argmax_a q_*(s, a)

为什么"贪心"在这里反而是全局最优？直觉：q_*(s, a) 的定义本身就是"选 a 之后按最优策略走到底"的最大期望回报。所以比较 q_*(s, ·) 就是在比较"选不同第一步动作的完整最优未来"，贪心选最大的那个，自然全局最优。关键前提是"之后按最优策略走"——因为 q_* 里已经内嵌了最优的后续选择，所以眼前的贪心不会损害长远。这解释了为什么强化学习里"贪心"和"最优"能统一：只要价值函数是最优的，对它的贪心就是最优策略。反之，若只对 v_π（某个非最优策略）贪心，只能得到"不比 π 差"的策略——这正是第 3 章策略改进定理的内容。

6. 存在性与唯一性（压缩映射的直觉）#

贝尔曼最优方程是否有解？解唯一吗？答案：在有限 MDP 且 γ < 1 时，v_* 唯一存在。 严格证明依赖压缩映射定理（Banach 不动点定理），这里给出直觉：定义"最优贝尔曼算子" T：

(T v)(s) = max_a Σ_{s', r} p(s', r | s, a) [ r + γ v(s') ]

可以证明 T 是一个γ-压缩映射：对任意两个价值向量 u、v，有

‖T u − T v‖_∞ ≤ γ ‖u − v‖_∞

因为 γ < 1，每次应用 T 都把"两个候选解的差距"缩小至少 γ 倍。由 Banach 不动点定理，T 有唯一不动点 v = T v——这个不动点正是贝尔曼最优方程的解 v_*。而迭代 v_{k+1} = T v_k 必收敛到它。这就是第 3 章价值迭代收敛的理论保证。你不需要背证明，但要记住这个逻辑链：max 让方程非线性 → 不能直接解 → 但算子仍是压缩的 → 所以迭代收敛且解唯一。

二、可运行代码示例#

用三状态链式 MDP，实现一次价值迭代（贝尔曼最优算子的反复应用），把最优价值 v_* 求出来，再从 q_* 贪心导出最优策略，并验证"贪心确为最优"。

import numpy as np

# 三状态链式 MDP（同前两课）
nS, nA = 3, 2
P = np.zeros((nA, nS, nS))        # P[a, s, s'] = p(s'|s,a)
R = np.zeros((nA, nS))            # R[a, s] = r(s,a)
P[0, 0, 1] = 1.0
P[1, 0, 0] = 1.0
P[0, 1, 0] = 0.5; P[0, 1, 2] = 0.5
P[1, 1, 2] = 1.0
P[0, 2, 2] = 1.0; P[1, 2, 2] = 1.0
R[1, 1] = 1.0
GAMMA = 0.9

# ---- 价值迭代：反复应用最优贝尔曼算子 T ----
v = np.zeros(nS)
for k in range(200):
    # 先算所有 (s,a) 的 q 值
    q = np.zeros((nS, nA))
    for s in range(nS):
        for a in range(nA):
            q[s, a] = sum(P[a, s, s2] * (R[a, s] + GAMMA * v[s2])
                          for s2 in range(nS))
    v_next = q.max(axis=1)        # v_*(s) = max_a q_*(s,a)
    if np.max(np.abs(v_next - v)) < 1e-10:
        print(f"价值迭代在 k={k} 收敛")
        break
    v = v_next

print("最优状态价值 v_* =", np.round(v, 4))

# ---- 从 q_* 贪心导出最优策略 ----
q_star = np.zeros((nS, nA))
for s in range(nS):
    for a in range(nA):
        q_star[s, a] = sum(P[a, s, s2] * (R[a, s] + GAMMA * v[s2])
                           for s2 in range(nS))
policy = q_star.argmax(axis=1)
print("最优动作价值 q_* =\n", np.round(q_star, 4))
print("贪心策略 π_*(s) =", policy)   # 0=选a0, 1=选a1

# ---- 验证：穷举所有确定性策略，确认没有比贪心更好的 ----
best = -np.inf
for a0 in range(nA):
    for a1 in range(nA):
        for a2 in range(nA):
            pi = {0: a0, 1: a1, 2: a2}
            P_pi = np.array([P[pi[s], s] for s in range(nS)])
            r_pi = np.array([R[pi[s], s] for s in range(nS)])
            v_pi = np.linalg.solve(np.eye(nS) - GAMMA * P_pi, r_pi)
            best = max(best, v_pi[0])   # 比较"从 s0 出发"的价值
print(f"\n穷举 2^3 个确定性策略，s0 处最大价值 = {best:.4f}")

运行结果大致是：

价值迭代在 k=2 收敛
最优状态价值 v_* = [0.9 1.  0. ]
最优动作价值 q_* =
 [[0.9   0.81 ]
  [0.405 1.   ]
  [0.    0.   ]]
贪心策略 π_*(s) = [0 1 0]
穷举 2^3 个确定性策略，s0 处最大价值 = 0.9000

读三件事：① v_*(s0)=0.9, v_*(s1)=1.0，与最优策略"在 s0 选 a0 去 s1、在 s1 选 a1 拿 1 分"完全吻合；② q_*(s1, a1)=1.0 而 q_*(s1, a0)=0.405，贪心选 a1 正确；③ 穷举所有确定性策略，s0 处最大价值正是 0.9，证明了这个贪心策略确为全局最优——"对 q_* 贪心即最优"得到了数值验证。

三、练习#

  1. 把 γ 改成 0.5，重跑价值迭代。v_*(s0) 从 0.9 变成多少？为什么它恰好等于 γ·1 = 0.5？
  2. 手推：为什么 v_*(s) = max_a q_*(s, a)？从 v_* 和 q_* 的定义各写一行，说明这个等式如何从"对策略取最大"退化为"对动作取最大"。
  3. 在 s1 的动作里，q_*(s1, a0) 为什么是 0.405 而不是 0？提示：a0 从 s1 有 0.5 概率回到 s0，而 v_*(s0)=0.9，故 0.5 × 0.9 × 0.9 = 0.405。
  4. 思考：为什么贝尔曼最优方程不能像上一课的贝尔曼方程那样，用 (I − γP)^{-1} 一次解出？请用"max 不是线性算子"解释，并说明这为何迫使我们改用迭代法（第 3 章价值迭代）。
