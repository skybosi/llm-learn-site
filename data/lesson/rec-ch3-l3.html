隐语义模型#

矩阵分解里的隐向量 p_u、q_i 到底"隐"了什么？隐语义模型（Latent Factor Model, LFM） 就是对这个问题的回答：那 k 个维度，是算法自己从数据里学出来的隐藏属性——不是"科幻""动作"这种人工标注，而是"某个说不清名字、但确实在决定用户偏好"的潜在因子。这一课把隐因子的含义、偏置项、以及 LFM 的局限与延伸讲透，作为本章收尾。

一、概念讲解#

1. 从"显式特征"到"隐式因子"#

回忆第 1 章的基于内容推荐：物品特征是人手工定义的（科幻、动作、爱情……），这叫显式特征。隐语义模型的革命在于：不预设任何特征，让算法从评分行为里反推出一组"因子"。

以电影为例，算法可能学出这样的隐因子：某一维大致对应"科幻程度"，另一维大致对应"轻松/严肃"。于是：

  • 用户向量 p_u = [0.8, −0.3] 表示"爱科幻、偏好严肃"；
  • 物品向量 q_i = [0.9, −0.5] 表示"科幻、偏严肃"；
  • 内积 p_uᵀ q_i = 0.8×0.9 + (−0.3)×(−0.5) = 0.87 表示"这个用户会喜欢这部电影"。

注意：这些"科幻""严肃"的名字是我们事后贴的标签，算法本身只知道"这是第 3 维"。隐因子不必对应人类能理解的概念——这既是它的强大（能捕捉人想不到的结构），也是它的代价（不可解释）。

2. 完整版预测公式：别忘了"偏置项"#

原始公式 R̂ = p_uᵀ q_i 有一个问题：它假设"没偏好就预测 0 分"，但现实中即使一个用户和物品毫无关联，物品本身也可能"整体偏高分"。于是 LFM 的完整形式加入偏置项（bias）：

R̂[u, i] = μ + b_u + b_i + p_uᵀ q_i
  • μ：全局平均分（所有观测评分的均值）；
  • b_u：用户偏置（这个人打分普遍偏高/偏低）；
  • b_i：物品偏置（这部电影普遍被高估/低估）；
  • p_uᵀ q_i：剩下的、真正个性化的交互部分。

直觉：先看"平均大家都打几分"（μ），再看"这个用户爱不爱给高分"（b_u）、"这个物品本身质量如何"（b_i），最后才是"这个用户与这个物品之间独特的化学反应"（内积项）。加了偏置后，预测更准，且把"整体水平"与"个性化匹配"清晰地分开。

3. 学习目标：四项一起学#

带上偏置项，优化目标变为：

J = Σ_{(u,i) ∈ Ω} ( R[u,i] − μ − b_u − b_i − p_uᵀ q_i )²
    + λ ( Σ_u b_u² + Σ_i b_i² + Σ_u ‖p_u‖² + Σ_i ‖q_i‖² )

对 b_u、b_i 求导可得（残差记 e_ui）：

b_u ← b_u + η ( e_ui − λ b_u )
b_i ← b_i + η ( e_ui − λ b_i )

而 p_u、q_i 的更新与第 1 课完全相同。四条规则都用 SGD 交替更新即可。

4. LFM 的局限与延伸#

  • 不可解释：隐因子维度难以命名，难以向用户解释"为什么推荐"；
  • 冷启动依旧：新用户/新物品没有观测，隐向量学不到（需靠内容特征或先验补救）；
  • 只能建模"内积"关系：内积是线性的，可能不足以表达复杂的用户-物品交互（这也催生了后面用神经网络替代内积的 NCF 等模型）。

但瑕不掩瑜：LFM 是协同过滤之后最重要的推荐范式，也是"把推荐问题嵌入到低维向量空间"这一现代思路（如双塔模型、图嵌入）的思想起点。

二、可运行代码示例#

在上一课 SGD 矩阵分解基础上，加上偏置项 μ + b_u + b_i，用 NumPy 手写完整版 LFM。

import numpy as np

R = np.array([
    [5, 3, 0, 1],
    [4, 0, 0, 1],
    [1, 1, 0, 5],
    [0, 0, 0, 4],
    [0, 1, 5, 4],
], dtype=float)

n_users, n_items = R.shape
k = 3
lr = 0.01
lam = 0.02
steps = 3000

# 偏置项与隐向量的初始化
mu = R[R > 0].mean()                 # 全局平均分
bu = np.zeros(n_users)               # 用户偏置
bi = np.zeros(n_items)               # 物品偏置
rng = np.random.default_rng(0)
P = rng.normal(0, 0.1, (n_users, k))
Q = rng.normal(0, 0.1, (n_items, k))

pairs = [(u, i) for u in range(n_users) for i in range(n_items) if R[u, i] > 0]

for step in range(steps):
    for u, i in pairs:
        pred = mu + bu[u] + bi[i] + P[u] @ Q[i]   # 完整预测：偏置 + 内积
        err = R[u, i] - pred                      # 残差
        bu[u] += lr * (err - lam * bu[u])         # 更新用户偏置
        bi[i] += lr * (err - lam * bi[i])         # 更新物品偏置
        pu = P[u].copy()
        P[u] += lr * (err * Q[i] - lam * P[u])    # 更新用户隐向量
        Q[i] += lr * (err * pu   - lam * Q[i])    # 更新物品隐向量

def predict(u, i):
    return mu + bu[u] + bi[i] + P[u] @ Q[i]

print("全局均值 μ =", round(mu, 3))
print("用户偏置 b_u：", np.round(bu, 3))
print("物品偏置 b_i：", np.round(bi, 3))
print("预测 用户0-物品2 =", round(predict(0, 2), 3))
print("补全矩阵 R̂：\n", np.round(P @ Q.T + mu + bu[:, None] + bi[None, :], 2))

观察要点：bu、bi 会各自学出"谁爱打高分、哪部片整体更受欢迎"；内积项 P@Qᵀ 则专注捕捉"偏置解释不了的那部分个性化"。对比第 1 课无偏置版本，带偏置的模型在训练集上的拟合误差通常更低——因为"整体高低"被偏置项吸收走了，隐向量不必再为它分心。

三、练习#

  1. 运行后打印"只看偏置"的预测 μ + b_u + b_i（去掉内积项），对比"完整预测"，观察内积项带来了多少修正，说明偏置项承担了哪部分解释。
  2. 把 k 设为 1，训练后打印 P、Q 各列，尝试为这唯一的隐因子"贴标签"（结合哪些物品/用户得分高），体会"隐因子可近似解读但难精确命名"。
  3. 实现一个"冻结偏置"的版本：把 bu、bi 固定为 0，其余不变，对比与完整版的训练误差，量化偏置项的价值。
  4. 思考：LFM 为什么对新物品冷启动无能为力？如果必须用 LFM 推荐一个新物品，可以借用哪些"内容特征"或"先验"来初始化它的隐向量 q_new？结合第 1 章混合推荐的思想回答。

为什么这样做？——理论推导#

偏置项来自"均值分解"#

μ + b_u + b_i 这套偏置结构，不是拍脑袋拼出来的，它来自一个朴素但深刻的统计观察：一个评分可以被分解成"全局水平 + 用户偏移 + 物品偏移 + 交互项"。这正对应回归分析里的"双向固定效应（two-way fixed effects）"模型：假设观测 R[u,i] = μ + α_u + β_i + ε_ui，其中 α_u、β_i 是用户、物品的固定效应，ε_ui 是残余的交互噪声。用最大似然去估计 μ、α_u、β_i，当损失是平方误差时，闭式解正是"全局均值 + 用户均值偏移 + 物品均值偏移"——与 LFM 的偏置项同构。LFM 只是进一步把残余的 ε_ui 也用低秩结构 p_uᵀ q_i 去建模。

为什么隐因子"学得出来"#

隐因子能被 SGD 学出来，靠的是"共享参数 + 观测信号回流"：用户 u 的向量 p_u 会同时被 u 评过的所有物品的观测所更新；物品 i 的向量 q_i 也会被评过它的所有用户的观测所更新。于是"谁和谁一起被喜欢"这种全局共现信息，会通过梯度在 P、Q 之间反复回流，最终把用户和物品"摆放"到一个能让内积解释观测的隐空间里。这与第 2 章 ItemCF"共现反推隐藏属性"是同一个思想，只是从"显式算相似度"升级成了"端到端学向量"。

母原理连接： 隐语义模型 = 矩阵分解 + 隐因子 + 偏置项，它把"推荐"完整地翻译成了机器学习语言：定义模型（μ+b_u+b_i+pᵀq）→ 定义损失（观测平方误差 + L2）→ 梯度优化。到这里，你已经能从"为什么这样做"一路推回到"模型、损失、优化"这三件套，这正是本课程"知其所以然"的最终落点。
