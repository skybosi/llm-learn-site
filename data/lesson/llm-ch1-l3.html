缩放定律#

前两课我们反复提到一个词——"规模"。这一课把它讲透：模型的能力到底是怎么随规模变化的？答案是缩放定律（Scaling Laws）：在很大范围内，语言模型的性能（损失）随参数、数据、算力的增长，以一条可预测的规律下降。掌握了这条规律，你就能理解为什么 GPT-3 要造 1750 亿参数、为什么后来的模型反而"变小变聪明"，以及那些"突然出现"的能力从何而来。

一、概念讲解#

1. 一条经验规律：损失随规模呈幂律下降#

OpenAI 在 2020 年系统训练了不同尺寸的语言模型，发现一个稳定现象：测试损失 L 与模型参数量 N、训练数据量 D、算力 C 之间，近似满足幂律（power law）关系：

L(N) ≈ (N_c / N)^α    L(D) ≈ (D_c / D)^β

其中 α、β 是正的幂指数，N_c、D_c 是常数。翻译成大白话：参数量或数据量每扩大 10 倍，损失就按固定比例下降，而且这个下降趋势跨越好几个数量级都保持稳定。因为损失取对数后是一条直线，所以"再加多少算力能换来多少收益"是可以提前估算的——这正是各家实验室敢砸钱训练超大模型的原因。

这条规律还有两个重要推论：

  1. 大模型更"省数据"：达到同一性能，大模型所需的训练步数更少（样本效率更高）；
  2. 边际收益递减：幂律意味着越往后，要再降一点损失，需要付出的规模增长越大。

2. Kaplan 定律：先固定数据，猛堆参数#

OpenAI 的 Kaplan 等人（2020）在"固定算力预算"的前提下给出的建议是：优先增大模型参数量，数据量只要"够用"即可。这条结论一度成为行业默认，直接催生了 GPT-3 这样的"超大参数、相对没那么大语料"的模型。但它后来被发现并不最优——因为它在固定算力的约束下比较，而没有让数据与参数同步放大。

3. Chinchilla 定律：数据与参数要同步增长#

DeepMind 的 Hoffmann 等人（2022）做了一个更全面的实验，结论反转：在给定算力预算下，模型参数量和训练 token 数应该大致同步放大，最优配比大约是：

每个参数约配 20 个训练 token（D ≈ 20 × N）

也就是说，一个 700 亿参数的模型，最理想的训练数据量大约是 1.4 万亿 token。这解释了为什么后来的 LLaMA（65B 却用 1.4T token 训练） 能以远小于 GPT-3 的参数量，达到相当甚至更好的效果——它把"省下来的参数预算"换成了更多数据。Chinchilla 定律让行业从"一味堆参数"转向"参数与数据平衡"，也直接改变了新模型的训练策略。

4. 涌现能力：量变积累出质变#

缩放定律解释的是损失平滑下降，但模型的实际能力有时不是平滑出现的。Google 的 Wei 等人（2022）发现，很多能力（多步推理、指令跟随、上下文学习等）在模型规模小于某个阈值时几乎测不出来，一旦跨过阈值就突然跳升。这类现象被称为涌现能力（emergent abilities）。

它有两层含义：

  1. 能力不是被"显式教"进去的，而是规模大到一定程度自然出现的；
  2. 因为出现是"跳变"的，小规模实验无法预测某个能力何时出现，只能靠足够大的规模去"触发"。

这解释了为什么 GPT-2 做 few-shot 一般般，而 GPT-3 突然就能做——阈值被跨过了。涌现能力与缩放定律共同回答了一个根本问题："大"为什么值得。

5. 缩放定律给工程实践的三个启示#

  1. 先算账再训练：用缩放定律估算"要达到目标损失需要多少算力、多少数据"，避免盲目堆料或数据不足；
  2. 参数与数据要匹配：大模型配大数据，别让 1750 亿参数只吃几百亿 token；
  3. 能力不可小模型预测：小规模验证只对"损失"可靠，对"能力是否涌现"未必可靠——关键能力必须在足够大的规模上验证。

二、可运行代码示例#

缩放定律是幂律，我们用 NumPy 亲手"拟合"一条损失-规模曲线，并画出 Chinchilla 最优配比，直观感受"对数坐标下是一条直线"。

import numpy as np
import matplotlib.pyplot as plt

# 1) 模拟一组"（参数量, 测试损失）"观测点（噪声很小，接近幂律）
N = np.logspace(6, 10, 30)            # 参数量从 10^6 到 10^10
alpha = 0.076                          # 幂指数：越大，规模收益越大
true_loss = 8.0 * N ** (-alpha)       # L = C * N^(-alpha)
noise = np.random.default_rng(0).normal(1.0, 0.02, size=N.shape)
loss = true_loss * noise

# 2) 在双对数坐标下，幂律变成一条直线：log L = log C - alpha * log N
logN, logL = np.log10(N), np.log10(loss)
k, b = np.polyfit(logN, logL, 1)       # 一次拟合，斜率即 -alpha
print(f"拟合斜率 k = {k:.4f}（理论值 -alpha = {-alpha}）")

# 3) 画出原始曲线与拟合直线
plt.figure(figsize=(9, 5))
plt.subplot(1, 2, 1)
plt.plot(N, loss, 'o', ms=4, label='观测损失')
plt.plot(N, 10**(k * logN + b), '-', label='拟合幂律')
plt.xscale('log'); plt.yscale('log')
plt.xlabel('参数量 N'); plt.ylabel('测试损失 L')
plt.title('双对数坐标下的幂律'); plt.legend(); plt.grid(True, which='both')

# 4) Chinchilla 定律：D ≈ 20 * N，画出参数与数据的最优配比线
plt.subplot(1, 2, 2)
N_grid = np.logspace(7, 11, 100)
D_grid = 20 * N_grid                    # 每个参数约 20 个 token
plt.plot(N_grid, D_grid, '-', label='D = 20 × N（Chinchilla）')
plt.fill_between(N_grid, 5 * N_grid, 80 * N_grid, alpha=0.15,
                 label='数据偏少/偏多区域')
plt.xscale('log'); plt.yscale('log')
plt.xlabel('参数量 N'); plt.ylabel('训练 token 数 D')
plt.title('参数与数据的最优配比'); plt.legend(); plt.grid(True, which='both')
plt.tight_layout()
plt.savefig('scaling_law_demo.png', dpi=120)
print("已保存图表到 scaling_law_demo.png")

运行后，第一张图在双对数坐标下几乎是一条直线，斜率 k ≈ -0.076，正是幂指数 α 的相反数——这就是缩放定律"可预测"的数学来源。第二张图展示了 Chinchilla 定律：给定参数量，数据量应落在 D ≈ 20N 这条线附近，偏左（数据不够）或偏右（数据冗余）都浪费预算。

三、练习#

  1. 把上面代码里的 alpha 改成 0.05 和 0.1，重新拟合，观察斜率与"规模收益"的关系：alpha 越大，加倍参数带来的损失下降是越多还是越少？
  2. 写一个函数 loss_after_scale(C, alpha)，计算"把参数量翻 10 倍，损失变为原来的多少倍"，并用它说明为什么越往后收益越递减。
  3. 已知某模型有 700 亿参数，按 Chinchilla 定律估算它最理想的训练 token 数，并查一查 LLaMA-65B 实际的训练 token 数（约 1.4T），对比是否吻合。
  4. 思考题：为什么"涌现能力"让实验室无法仅靠小模型实验来预测大模型的表现？这给"训练前评估 ROI"带来了什么困难？
