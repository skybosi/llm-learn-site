梯度消失与爆炸#

反向传播让深层网络"可训练"，但也埋下一个隐患：梯度要穿过几十上百层，每层都乘一个局部导数。如果这些局部导数普遍偏小，梯度会指数级衰减，越靠近输入层越微弱，几乎等于没更新——这叫梯度消失（vanishing gradient）；反过来，如果局部导数普遍偏大，梯度会指数级膨胀，参数更新一步就飞出合理范围，损失变成 NaN——这叫梯度爆炸（exploding gradient）。它们是训练深层网络最常见的两大"拦路虎"。

一、概念讲解#

1. 连乘带来的指数效应#

设网络有 L 层，第 l 层向上一层回传梯度时，大致都要乘一个因子 λₗ（由权重和激活函数导数共同决定）。那么第 1 层收到的梯度大概是：

∂L/∂W₁ ≈ ∂L/∂W_L · λ_L · λ_{L-1} · … · λ₂

这是连乘，不是相加。哪怕每个 λₗ 只是"略小于 1"的 0.8，乘 50 次之后也只剩 0.8⁵⁰ ≈ 0.000014——几乎归零。同理，每个 λₗ 略大于 1（比如 1.5），乘 50 次就变成 1.5⁵⁰ ≈ 6.4×10⁸——爆炸。这就是"指数级"的含义：深层网络里，梯度对层数极其敏感。

2. 梯度消失：sigmoid 的"饱和区"#

经典罪魁祸首是 sigmoid（以及 tanh）的饱和。sigmoid 的导数 σ′(z) = σ(z)(1−σ(z)) 最大值只有 0.25，而且当 z 很大或很小时，σ(z) 贴近 0 或 1，导数几乎为 0：

σ′(-10) ≈ 0.000045   （神经元"熄火"，梯度几乎传不出去）
σ′(0)   = 0.25       （导数最大值，也只有 0.25）

在深层网络中，每一层 sigmoid 都把梯度"打一次折"，折到第 1 层就所剩无几。结果：靠近输入的前几层学不动，网络退化成"只有最后几层在工作"。

3. 梯度爆炸：权重初始值过大#

如果初始化时权重给得太大，线性层会让 z 很大，而某些激活（如 ReLU）的导数是 1，不会衰减；此时梯度在回传时反复乘上较大的权重，就会越乘越大，最终超过浮点数表示范围，损失直接变成 inf 或 NaN。

4. 症状与应对#

现象 可能原因
损失在训练初期就卡住不下降 梯度消失，前几层没更新
损失在训练中突然变成 NaN 梯度爆炸，参数飞了
权重更新量普遍趋近 0 梯度消失
权重、梯度出现极大数值 梯度爆炸

常见对策（后续章节会逐一展开）：

  • 用 ReLU / Leaky ReLU 等不易饱和的激活函数（缓解消失）；
  • 合理初始化权重，如 Xavier/He 初始化（控制各层方差，防爆炸/消失）；
  • 用梯度裁剪（gradient clipping）把过大的梯度截断（专治爆炸）；
  • 用批量归一化（BatchNorm）和 残差连接（ResNet） 让深层网络也能稳定训练。

二、可运行示例#

下面用 PyTorch 直观观察梯度在深层网络中的变化：对比 sigmoid 深层网络（梯度消失）与 ReLU 深层网络，以及大权重初始化（梯度爆炸）。

import torch
import torch.nn as nn

torch.manual_seed(0)

# 构造一个 12 层全连接网络，每层隐藏 64 个神经元
def make_net(activation, weight_scale=1.0):
    layers = []
    for _ in range(12):
        linear = nn.Linear(64, 64)
        # 手动缩放权重，模拟不同的初始化尺度
        with torch.no_grad():
            linear.weight *= weight_scale
        layers.append(linear)
        layers.append(activation)
    return nn.Sequential(*layers)

x = torch.randn(64)          # 一个随机输入
target = torch.randn(64)     # 随机目标

# —— 场景 1：sigmoid 网络（默认初始化）——
net_sigmoid = make_net(nn.Sigmoid())
loss = ((net_sigmoid(x) - target) ** 2).sum()
loss.backward()
# 取出第一层权重的梯度，看它有多大
g_first = net_sigmoid[0].weight.grad.norm().item()
print(f"[sigmoid] 损失 = {loss.item():.3f}, 第一层梯度范数 = {g_first:.3e}")

# —— 场景 2：ReLU 网络（同样结构，仅换激活函数）——
net_relu = make_net(nn.ReLU())
loss = ((net_relu(x) - target) ** 2).sum()
loss.backward()
g_first = net_relu[0].weight.grad.norm().item()
print(f"[ReLU]    损失 = {loss.item():.3f}, 第一层梯度范数 = {g_first:.3e}")

运行结果里，sigmoid 网络第一层的梯度范数通常远小于 ReLU 网络（甚至差几个数量级）——这就是梯度消失的直接证据：同样的结构，激活函数一变，最前面的层"收到的信号"天差地别。

再看梯度爆炸：把初始权重放大几十倍。

# 场景 3：权重初始值过大（放大 30 倍），模拟梯度爆炸
net_big = make_net(nn.ReLU(), weight_scale=30.0)
loss = ((net_big(x) - target) ** 2).sum()
loss.backward()
g_first = net_big[0].weight.grad.norm().item()
print(f"[ReLU+大权重] 损失 = {loss.item():.3f}, 第一层梯度范数 = {g_first:.3e}")

权重放大后，第一层梯度范数可能达到 1e15 甚至更大；再做一步参数更新，损失就会溢出成 inf 或 NaN。

梯度裁剪演示（防爆炸的常用手段）：

# 场景 4：用梯度裁剪把过大的梯度截断到阈值以内
net_clip = make_net(nn.ReLU(), weight_scale=30.0)
loss = ((net_clip(x) - target) ** 2).sum()
loss.backward()
# 把所有参数的梯度范数统一裁剪到 1.0，防止更新步子过大
torch.nn.utils.clip_grad_norm_(net_clip.parameters(), max_norm=1.0)
g_first = net_clip[0].weight.grad.norm().item()
print(f"[ReLU+大权重+裁剪] 第一层梯度范数 = {g_first:.3e}")

裁剪后梯度范数被压到合理范围，参数更新不会再"飞出去"。

为什么这样做？——理论推导#

梯度消失/爆炸的数学根源：连乘 Jacobian 的特征值#

第 1 步：把整段回传写成"连乘 Jacobian"。

从反向传播的递推 δ^{(l)} = (W^{(l+1)})ᵀ δ^{(l+1)} ⊙ σ′(z^{(l)}) 出发。把逐元素乘 σ′(z^{(l)}) 写成对角矩阵 D^{(l)} = diag(σ′(z^{(l)}))，递推变为线性映射：

δ^{(l)} = D^{(l)} (W^{(l+1)})ᵀ δ^{(l+1)}

沿 l = L−1, …, 1 一路展开，第 1 层的误差信号是：

δ^{(1)} = D^{(1)}(W^{(2)})ᵀ · D^{(2)}(W^{(3)})ᵀ · … · D^{(L-1)}(W^{(L)})ᵀ · δ^{(L)}

这就是"深层梯度 = 连乘 Jacobian 矩阵"的精确形式：每个因子 J^{(l)} := D^{(l)}(W^{(l+1)})ᵀ 是第 l 层对第 l+1 层误差信号的雅可比。梯度回传 = 一连串矩阵乘法作用于初始误差向量。

第 2 步：为什么"连乘"会指数放大/缩小——范数与谱半径。

矩阵乘向量最多把向量放大 ‖J‖₂（谱范数 = 最大奇异值）倍。谱范数满足次乘性 ‖J₁J₂…J_k‖₂ ≤ ‖J₁‖₂‖J₂‖₂…‖J_k‖₂，于是：

  • 若所有 ‖J^{(l)}‖₂ ≤ μ < 1，则 ‖δ^{(1)}‖₂ ≤ μ^{L-1}‖δ^{(L)}‖₂ → 0（指数消失）；
  • 若所有 ‖J^{(l)}‖₂ ≥ ρ > 1，误差信号以 ρ^{L-1} 的速度指数放大（爆炸）。

更本质的是谱半径（最大特征值绝对值）：连乘矩阵 M = J₁…J_k 的特征值等于各因子特征值的（广义）乘积，只要主导特征值 |λ| < 1，M 的幂趋于零矩阵；|λ| > 1 则发散。这就是"特征值 <1 连乘→消失，>1→爆炸"的数学根源——梯度沿深度方向是一个线性迭代，其长期行为完全由谱性质决定。

第 3 步：三种"缓解"手段各自击中哪一环。

  • ReLU：σ′ ∈ {0,1}，使 D^{(l)} 的元素不再恒小于 1（Sigmoid 的 σ′ ≤ 0.25 意味着 ‖D‖₂ 必然 < 0.25，注定消失）。ReLU 让激活区神经元局部导数为 1，J 的谱范数不再被激活项强制压低（代价是死区神经元导数恒 0）。
  • 残差连接：a^{(l)} = σ(z^{(l)}) + a^{(l-1)} 使反向路径多出恒等捷径，∂a^{(l)}/∂a^{(l-1)} = I + (主路径项)。即使主路径雅可比范数很小，I 这一项也保证整体范数下限为 1，梯度不再被迫连乘衰减。
  • 归一化/初始化：消失/爆炸本质是各层 ‖J‖₂ 系统性偏离 1。He/Xavier 初始化精确控制 W 的方差，使每层前向/反向谱范数都约等于 1；BatchNorm 把激活强制到零均值单位方差，把 ‖D‖₂ 稳定在 1 附近。二者共同目的：让连乘的每个因子都落在"既不衰减也不放大"的临界区 μ≈1。

母原理连接：梯度消失/爆炸不是"调参技巧问题"，而是动力系统中"稳定性"问题的投影——沿深度方向，误差信号服从线性迭代 δ^{(l)} = J^{(l)}δ^{(l+1)}，长期行为由连乘算子的谱性质（Lyapunov 指数）决定：谱半径 <1 收缩（梯度归零）、>1 扩张（发散）、≈1 才"临界稳定"。这与复利、细菌繁殖、连锁反应等一切指数过程共享同一母原理：乘积的长期行为由每个因子的对数平均值决定，深层网络只是把"时间"换成了"深度"。
