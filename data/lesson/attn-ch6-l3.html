可视化注意力#

注意力权重是 Transformer 最"可解释"的一扇窗：它明明白白地告诉我们，每个位置在生成时"看了谁、看了多重"。这一课回到第 2 课的序列反转任务，用 nn.MultiheadAttention 把三处注意力权重都抓出来，画成热力图，看它们各自呈现出什么结构。你会亲眼看到：编码器自注意力是双向的、解码器自注意力被因果掩码切成下三角、而交叉注意力形成一条漂亮的反对角线——那是模型在"对着源序列找对应位置"。最后我们也要给注意力泼一盆冷水：它好读，但不等于因果解释。

一、概念讲解#

1. 三张热力图，三种结构#

反转任务里，源序列长度 L=5、目标序列（含 BOS/EOS）长度 6。训练收敛后，取出同一个样本的三处注意力：

  • 编码器自注意力（5 × 5）：每个源位置对全体源位置的关注。双向，没有掩码，通常比较分散，或对数值相同的 token 有偏好。
  • 解码器自注意力（6 × 6）：每个目标位置对已生成前缀的关注。因果掩码把它严格压成下三角——右上角整片为 0。
  • 交叉注意力（6 × 5，行=目标、列=源）：目标位置 i 要输出源序列倒数第 i 个 token，所以它必须关注源位置 L−1−i，权重于是沿反对角线排列。

2. 如何拿到注意力权重#

nn.MultiheadAttention 的 forward 有个 need_weights 参数：

  • need_weights=False（默认）：只返回 (attn_output)，快、省内存。
  • need_weights=True：额外返回 (attn_output, attn_output_weights)，权重形状为 (batch, tgt_len, src_len)（默认对多头取平均）。

想看每个头各自的注意力，再加 average_attn_weights=False，权重形状就变成 (batch, n_heads, tgt_len, src_len)。本课先用"对头取平均"的版本画整体，你可以自行改成逐头绘制。

3. 注意力 ≠ 解释（重要提醒）#

热力图好看、也好讲，但要克制地读。多篇研究（如 Jain & Wallace 的 Attention is not Explanation）指出：注意力权重高的位置，未必是模型做决策真正依赖的位置；扰动注意力有时并不改变输出。注意力更准确的定位是"模型计算时关注了什么"，而不是"是什么原因导致了这个输出"的因果结论。可视化它的价值在于调试与直觉，而不是充当严格的可解释性证明。

二、可运行代码示例#

先搭一个会"吐注意力"的小模型：单层编码器 + 单层解码器，都基于 nn.MultiheadAttention，在 forward 里把三处权重一并返回。

import math
import torch
import torch.nn as nn

torch.manual_seed(0)
VOCAB, BOS, EOS = 12, 0, 1

class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=100):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        pos = torch.arange(max_len).unsqueeze(1).float()
        div = torch.exp(torch.arange(0, d_model, 2).float()
                        * (-math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(pos * div)
        pe[:, 1::2] = torch.cos(pos * div)
        self.register_buffer("pe", pe.unsqueeze(0))
    def forward(self, x):
        return x + self.pe[:, :x.size(1)]

def ff(d_model):
    return nn.Sequential(nn.Linear(d_model, 4 * d_model), nn.ReLU(),
                         nn.Linear(4 * d_model, d_model))

class EncLayer(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.ff = ff(d_model)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
    def forward(self, x):
        h = self.norm1(x)
        a, w = self.attn(h, h, h, need_weights=True)   # 双向自注意力
        x = x + a
        return x + self.ff(self.norm2(x)), w

class DecLayer(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.cross_attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.ff = ff(d_model)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
    def forward(self, x, memory, tgt_mask):
        h = self.norm1(x)
        a1, w_self = self.self_attn(h, h, h, attn_mask=tgt_mask, need_weights=True)
        x = x + a1
        h = self.norm2(x)
        a2, w_cross = self.cross_attn(h, memory, memory, need_weights=True)
        x = x + a2
        return x + self.ff(self.norm3(x)), w_self, w_cross

class AttnReverser(nn.Module):
    def __init__(self, vocab, d_model=16, n_heads=2):
        super().__init__()
        self.d_model = d_model
        self.embed = nn.Embedding(vocab, d_model)
        self.pos = PositionalEncoding(d_model)
        self.encoder = EncLayer(d_model, n_heads)
        self.decoder = DecLayer(d_model, n_heads)
        self.proj = nn.Linear(d_model, vocab)
    def forward(self, src, tgt, tgt_mask):
        src_emb = self.pos(self.embed(src) * math.sqrt(self.d_model))
        memory, w_enc = self.encoder(src_emb)
        tgt_emb = self.pos(self.embed(tgt) * math.sqrt(self.d_model))
        out, w_self, w_cross = self.decoder(tgt_emb, memory, tgt_mask)
        return self.proj(out), w_enc, w_self, w_cross

训练这个小模型（数据与第 2 课完全相同）：

def make_batch(b, L):
    src = torch.randint(2, VOCAB, (b, L))
    rev = src.flip(1)
    dec_in = torch.cat([torch.full((b, 1), BOS), rev], dim=1)
    dec_out = torch.cat([rev, torch.full((b, 1), EOS)], dim=1)
    return src, dec_in, dec_out

model = AttnReverser(VOCAB)
opt = torch.optim.Adam(model.parameters(), lr=2e-3)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(1, 201):
    src, dec_in, dec_out = make_batch(32, 5)
    tgt_mask = nn.Transformer.generate_square_subsequent_mask(dec_in.size(1))
    logits, *_ = model(src, dec_in, tgt_mask)
    loss = loss_fn(logits.reshape(-1, VOCAB), dec_out.reshape(-1))
    opt.zero_grad(); loss.backward(); opt.step()
    if epoch % 50 == 0:
        print(f"epoch {epoch:>3}  loss {loss.item():.4f}")

训练好后，取一条样本，把三处注意力权重抓出来画热力图：

import matplotlib.pyplot as plt

model.eval()
src = torch.randint(2, VOCAB, (1, 5))            # 源序列长度 5
rev = src.flip(1)
dec_in = torch.cat([torch.full((1, 1), BOS), rev], dim=1)
tgt_mask = nn.Transformer.generate_square_subsequent_mask(dec_in.size(1))

with torch.no_grad():
    _, w_enc, w_self, w_cross = model(src, dec_in, tgt_mask)

w_enc, w_self, w_cross = w_enc[0], w_self[0], w_cross[0]  # 去掉 batch 维
print("三处权重形状:", w_enc.shape, w_self.shape, w_cross.shape)  # (5,5) (6,6) (6,5)

fig, axes = plt.subplots(1, 3, figsize=(15, 4.5))
im0 = axes[0].imshow(w_enc.numpy(), cmap="viridis", vmin=0, vmax=1)
axes[0].set_title("编码器自注意力（双向）")
axes[0].set_xlabel("源位置"); axes[0].set_ylabel("源位置")

im1 = axes[1].imshow(w_self.numpy(), cmap="viridis", vmin=0, vmax=1)
axes[1].set_title("解码器自注意力（因果，下三角）")
axes[1].set_xlabel("目标位置"); axes[1].set_ylabel("目标位置")

im2 = axes[2].imshow(w_cross.numpy(), cmap="viridis", vmin=0, vmax=1)
axes[2].set_title("交叉注意力（反对角线）")
axes[2].set_xlabel("源位置"); axes[2].set_ylabel("目标位置")

for ax, im in zip(axes, [im0, im1, im2]):
    fig.colorbar(im, ax=ax, fraction=0.046, pad=0.04)
plt.tight_layout()
plt.show()

print("源序列:", src.tolist()[0])
print("交叉注意力各行最关注的源位置:", w_cross.argmax(dim=-1).tolist())

看点：解码器自注意力严格下三角；交叉注意力里，目标位置 i（i=0..4）最关注的源位置应约等于 4−i，形成反对角线；最后一行（预测 <eos>）的关注则较为分散。想看每个头的行为，把 need_weights=True 改成 need_weights=True, average_attn_weights=False，权重会变成 (batch, heads, t, s)，再逐头画即可。

三、练习#

  1. 分别打印 w_cross 每一行 argmax 得到的源位置，与理论反对角线 [4,3,2,1,0,...] 对比，解释一致或不一致的原因。
  2. 改成 average_attn_weights=False，把 2 个头的交叉注意力各画一张，观察不同头是否学到了不同的对齐模式。
  3. 换一个样本（或换一组随机种子），确认反对角线模式是否稳定出现；若某条样本失败，尝试分析原因。
  4. 阅读 Jain & Wallace 的《Attention is not Explanation》，用一段话总结"注意力高≠重要"的论据，并说明可视化注意力更适合用来做什么。
