图的组成结构#

在动手画任何图表之前，先理解 Matplotlib 是如何"组织"一幅图的。这一步能帮你从"照着例子抄"进阶到"清楚自己每一步在改什么"，也为后续使用面向对象接口画图打下基础。

一、概念讲解#

1. Figure：整张画布#

Figure 是图的最外层容器，可以理解为一张画布。一张画布上可以放多个子图（subplot），每个子图是一套独立的坐标系。调用 plt.figure() 或 plt.subplots() 时，返回的就是 Figure 对象。

2. Axes：真正的"图"#

Axes（注意拼写带 es，发音近似"ax-ease"）才是我们通常所说的"一张图"。它包含一个坐标系、一组坐标轴（Axis），以及画在其中的数据（线条、散点、柱体等）。一个 Figure 可以包含一个或多个 Axes。

初学者最容易混淆的点：Axes ≠ 坐标轴。坐标轴（x 轴、y 轴）对应的对象叫 Axis，而 Axes 是承载整张图的绘图区域。一句话记忆：Figure 是画布，Axes 是图，Axis 是轴。

3. 一张图的关键组成部分#

以一张常见的折线图为例，从内到外可以看到以下元素，它们各自对应一个对象：

元素 作用 常用设置方法
数据线 / 数据点 实际展示的数据 ax.plot() 等绘图函数
标题（title） 说明图的主题 ax.set_title()
x / y 轴标签（xlabel / ylabel） 说明坐标轴含义 ax.set_xlabel() / ax.set_ylabel()
刻度（ticks） 轴上的定位标记 ax.set_xticks()
刻度标签（tick labels） 刻度旁的数字或文字 ax.set_xticklabels()
边框（spines） 坐标系四周的框线 ax.spines[...]
图例（legend） 说明各数据系列 ax.legend()

4. 一切都是 Artist#

在 Matplotlib 内部，图上的每一个可见元素——线条、文字、刻度、图例——都是 Artist 对象，它们组成一棵树：Figure 是根，下面挂 Axes，Axes 下再挂 Line2D、Text、Axis 等。理解了这层"容器 — 元素"的层级关系，你就掌握了 Matplotlib 面向对象接口的核心心智模型。

二、可运行代码示例#

下面的示例显式创建 Figure 与 Axes，再逐个设置图的各个组成部分，帮助你对照上面的概念逐一对应。

import numpy as np
import matplotlib.pyplot as plt

# 中文显示说明：Windows 可用 SimHei / Microsoft YaHei，macOS 可用 PingFang SC
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False  # 解决负号显示为方块的问题

# 生成数据（沿用 NumPy 知识）
x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)

# 1. 创建画布与子图：fig 是 Figure，ax 是 Axes
fig, ax = plt.subplots(figsize=(8, 4.5))

# 2. 在 Axes 上绘制数据
ax.plot(x, y, color="steelblue", linewidth=2, label="sin(x)")

# 3. 逐个设置图的各组成部分
ax.set_title("正弦曲线", fontsize=14)                 # 标题
ax.set_xlabel("角度（弧度）")                          # x 轴标签
ax.set_ylabel("取值")                                  # y 轴标签
ax.set_xticks(np.linspace(0, 2 * np.pi, 5))            # 指定刻度位置
ax.set_xticklabels(["0", "π/2", "π", "3π/2", "2π"])    # 刻度标签
ax.legend(loc="upper right")                           # 图例

# 4. 显示（脚本中也可改用 fig.savefig("output.png") 保存）
plt.show()

运行后，请逐行注释掉某个 set_* 调用再运行，观察图的变化，从而记住每个元素对应的对象。

三、练习#

  1. 用 fig, ax = plt.subplots() 创建画布，绘制 y = x**2（x 取 -5 到 5），并为其添加标题、坐标轴标签与网格（ax.grid(True)）。
  2. 使用 ax.set_xticks() 和 ax.set_xticklabels()，把 x 轴刻度标签改成 ["左", "中", "右"] 这样的自定义文字。
  3. 思考题：plt.plot() 与 ax.plot() 有什么联系？提示——当图中只有一个 Axes 时，plt.plot() 会作用于"当前"Axes。
