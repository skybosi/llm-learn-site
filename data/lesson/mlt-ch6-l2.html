交叉熵与 KL 散度#

上一课我们有了熵：它度量"一个分布自身的不确定性"。但机器学习里更常问的是另一个问题：我的模型预测分布 q，和真实分布 p 差多远？ 答案就是 KL 散度，以及它派生的交叉熵。这一课要做的，是把"交叉熵损失"从一句"大家都这么用"的口诀，还原成一条可以一步步推出来的定理：最小化交叉熵 = 最小化 KL 散度 = 最大化似然。这条链一旦打通，损失函数就不再是背下来的。

一、概念讲解（含推导）#

1. 先问"为什么"：如何度量两个分布的差距？#

直觉上，如果真实分布是 p，你却用 q 去编码它，会付出额外的代价。上一课我们知道，最优编码下每个符号的平均码长是熵 H(p)=−∑p(x)logp(x)。如果你误以为分布是 q，就会给事件 x 分配码长 −logq(x)，于是真实分布 p 下的平均码长变成

H(p,q):=−x∑​p(x)logq(x).

这就是交叉熵。显然 H(p,q)≥H(p)——用错了编码，平均码长只会更长。两者之差，就是"因误用 q 而多付出的代价"，记为

DKL​(p∥q):=x∑​p(x)logq(x)p(x)​=H(p,q)−H(p).

这就是 KL 散度（Kullback–Leibler divergence）。它度量"用 q 近似 p 的信息损失"。

2. KL 散度非负：Gibbs 不等式#

命题：DKL​(p∥q)≥0，等号当且仅当 p=q（几乎处处）。

证明（两种方法，都只用琴生不等式或 logt≤t−1）：

法一（对数上界）：对 t>0 有 lnt≤t−1（等号仅 t=1）。于是

−DKL​(p∥q)=x∑​p(x)lnp(x)q(x)​≤x∑​p(x)(p(x)q(x)​−1)=x∑​q(x)−x∑​p(x)=0.

所以 DKL​≥0。等号成立当且仅当对所有 x 都有 q(x)/p(x)=1，即 p=q。∎

法二（琴生不等式）：−ln 是凸函数，故

−DKL​(p∥q)=x∑​p(x)lnp(x)q(x)​≤ln(x∑​p(x)p(x)q(x)​)=ln(x∑​q(x))=ln1=0.

两条路殊途同归。这条非负性说明：KL 散度是一个"合法的距离"（半度量）的下界保证——但注意它不是真正的距离，因为不对称：一般 DKL​(p∥q)=DKL​(q∥p)。

3. KL 散度的不对称：两种"错"不一样贵#

不对称是 KL 散度最重要的特性。看一个极端例子：p=(1,0)（确定性事件），q=(0.5,0.5)。

  • DKL​(p∥q)=1⋅log0.51​+0=1 bit；
  • DKL​(q∥p)=0.5⋅log10.5​+0.5⋅log00.5​=∞。

直觉：p∥q 问的是"用 q 去近似 p 亏多少"——亏一点；q∥p 问的是"用 p 去近似 q 亏多少"——p 认为某事件概率为 0，而 q 里它真会发生，于是"亏到无穷"。这就是为什么在机器学习里我们固定用真实分布 p 作被除数、让模型分布 q 作除数：DKL​(p∥q) 是"让模型去匹配数据"的正向代价，它惩罚"模型对真实出现的事件给出过低概率"，而不会为"模型给无关事件分配概率"付出无穷代价。

4. 核心等价链：交叉熵 = KL = 最大似然#

把上面三者连起来：

H(p,q)=与 q 无关H(p)​​+DKL​(p∥q).

因为 H(p) 与模型参数无关，关于 q 最小化交叉熵，等价于最小化 KL 散度：

argqmin​H(p,q)=argqmin​DKL​(p∥q)=p.

再由 Gibbs 不等式，最小值在 q=p 处取到。现在看最大似然：设数据集 {x(i)}i=1m​ 独立同分布采样自真实分布 p，用经验分布 p^​(x)=m1​∑i​1[x(i)=x] 近似 p。模型 qθ​ 的对数似然是

i=1∑m​logqθ​(x(i))=mx∑​p^​(x)logqθ​(x)=−mH(p^​,qθ​).

因此

最大化对数似然⟺最小化交叉熵 H(p^​,qθ​)⟺最小化 DKL​(p^​∥qθ​)​

这就是"交叉熵损失"的完整由来：它不是什么经验配方，而是"在真实（经验）分布下、用模型分布去编码所付出的平均代价"，其最小值恰好在"模型分布 = 数据分布"处，且这一最小化过程与最大似然估计完全等价。chapter-2 从最大似然推出过逻辑回归的交叉熵，本课从信息论一端独立地走到了同一个终点——两条路在此汇合，正是"概率视角"与"信息论视角"统一的最好证据。

5. 交叉熵的梯度：为何它比 MSE 更适合分类#

对分类任务，输出是概率向量 q=softmax(z)，真实标签是 one-hot y（即 p=p^​ 退化到单点）。交叉熵为 L=−∑c​yc​logqc​=−logqtrue​。它对 logits 的梯度有一个极其干净的形式（这是推导出来的结果）：

∂zc​∂L​=qc​−yc​.

即"预测概率 − 真实标签"。这个形式有两个巨大优点：① 当预测很错时（qtrue​ 接近 0），梯度接近 −1，不会饱和，学习依然有信号；② 与之对照，若用 MSE 配 sigmoid/softmax，梯度里会乘上 σ′(z)=q(1−q)，当输出接近 0 或 1 时梯度消失。因此交叉熵 + softmax 是分类任务的"天作之合"——这不是巧合，而是"最大化似然"与"消除饱和"在数学上的一致。

二、验证性代码示例#

下面代码验证四条结论：① Gibbs 不等式 DKL​≥0，且 p=q 时取 0；② KL 的不对称性（含"无穷"的情形）；③ 最小化交叉熵等价于逼近真实分布（数值优化）；④ softmax + 交叉熵的梯度公式 q−y。

import numpy as np

def kl(p, q):
    p = np.asarray(p, float); q = np.asarray(q, float)
    m = p > 0
    return np.sum(p[m] * np.log(p[m] / q[m]))   # 自然对数（nat）

# ---------- 1) Gibbs 不等式：D_KL >= 0，p=q 时 = 0 ----------
p = np.array([0.7, 0.2, 0.1])
print(f"D_KL(p||p) = {kl(p, p):.4f} （应=0）")
print(f"D_KL(p||q) = {kl(p, [0.3, 0.4, 0.3]):.4f} （应>0）")

# ---------- 2) 不对称性，含无穷 ----------
p0 = np.array([1.0, 0.0]); q0 = np.array([0.5, 0.5])
print("\nD_KL([1,0]||[.5,.5]) =", f"{kl(p0, q0):.4f}")
print("D_KL([.5,.5]||[1,0]) =", kl(q0, p0), "（发散 -> inf）")

# ---------- 3) 最小化交叉熵 = 逼近真实分布 ----------
def softmax(z):
    e = np.exp(z - z.max())
    return e / e.sum()

target = np.array([1.0, 0.0, 0.0])      # 真实分布（one-hot）
z = np.zeros(3)                          # 初始 logits
for _ in range(1000):                    # 朴素梯度下降，lr=0.5
    q = softmax(z)
    z = z - 0.5 * (q - target)           # 直接用推导出的梯度 q - y
print("\n优化后的 q =", np.round(softmax(z), 5), "（应逼近 [1,0,0]）")

# ---------- 4) 数值验证梯度公式 dL/dz = q - y ----------
eps = 1e-6
z2 = np.array([0.2, -0.5, 0.8]); y2 = np.array([0.0, 1.0, 0.0])
q2 = softmax(z2)
g_analytic = q2 - y2
g_numeric = np.zeros(3)
for c in range(3):
    zp = z2.copy(); zp[c] += eps
    zm = z2.copy(); zm[c] -= eps
    Lp = -np.log(softmax(zp)[1]); Lm = -np.log(softmax(zm)[1])   # 交叉熵 = -log q_true
    g_numeric[c] = (Lp - Lm) / (2 * eps)
print("\n解析梯度 q-y :", np.round(g_analytic, 5))
print("数值梯度      :", np.round(g_numeric, 5))

运行结果大致为：

D_KL(p||p) = 0.0000 （应=0）
D_KL(p||q) = 0.3446 （应>0）

D_KL([1,0]||[.5,.5]) = 0.6931
D_KL([.5,.5]||[1,0]) = inf （发散 -> inf）

优化后的 q = [9.9866e-01 6.7000e-04 6.7000e-04] （应逼近 [1,0,0]）

解析梯度 q-y : [ 0.30132 -0.85037  0.54905]
数值梯度      : [ 0.30132 -0.85037  0.54905]

第 3 组展示"最小化交叉熵 = 让模型分布逼近真实分布"；第 4 组里解析梯度与数值差分完全一致，坐实了 q−y 这个干净形式。

三、练习#

  1. 用 lnt≤t−1 完整写出 Gibbs 不等式的证明，并指出等号成立条件为什么是 p=q。
  2. 证明 DKL​(p∥q) 关于 p 是凸的（提示：它关于 (p,q) 联合凸）。据此说明"固定 q 最小化 DKL​(p∥q)"是个凸优化问题。
  3. 设 p 是两点分布 Bernoulli(0.8)，q 是 Bernoulli(t)。求 DKL​(p∥q) 作为 t 的显式表达式，并证明它在 t=0.8 处取最小值 0。
  4. 从 softmax 定义出发，推导交叉熵对 logits 的梯度 ∂L/∂zc​=qc​−yc​（用链式法则，注意 qc​ 对 zc′​ 的依赖）。
  5. 思考：为什么分类任务中交叉熵比 MSE 更合适？具体计算：当真实标签为类别 1、模型输出 q1​ 很小时，MSE 梯度和交叉熵梯度各是什么量级？谁会让学习"停摆"？

母原理连接#

本课是母原理 2（概率视角统一一切） 与母原理 4（信息论视角） 的交汇点，也是全课程"损失函数从哪来"这一问题的最终答案之一：交叉熵损失 = KL 散度 = 负对数似然，三者在数学上等价，分别从"编码代价""分布差距""概率似然"三个角度指向同一个优化目标。这解释了为什么逻辑回归、softmax 分类、以及后面 LLM 的自回归训练，全都"不约而同"地最小化交叉熵——因为它们在做同一件事：让模型分布逼近数据分布。
