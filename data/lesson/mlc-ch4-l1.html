常量折叠、代数化简与算子消除#

第 3 课教会我们"怎么改图"——在 Relay、MLIR、StableHLO 这类图 IR 上写一个 pass。但 pass 不是目的，改什么才划算才是。真实模型里有一类节点从编译那一刻起就注定可以删掉：权重形状推导出的常量、x + 0、x * 1、以及被折叠结果孤立出来的死子图。它们不改变任何数值，却占着执行计划和显存。这一课把这三类改写拆开讲清，并给出一个能逐条核对的 40 行 pass 管线。

一、概念讲解#

1. 常量折叠 = 在图 IR 上做一遍常量传播#

常量折叠（constant folding）指"当某个节点的全部输入在编译期已知，就直接算出结果、把节点换成常量"。TVM Relay 把它实现为一个独立 pass（常量折叠 pass，官方文档的 pass 基础设施一节描述了这类 pass 如何注册与串联）；MLIR 侧则是 arith 等 dialect 的 canonicalizer/folder 机制。

关键在于它不是"扫一遍就能完"，而是要迭代到不动点：five = 2+3 折成 5 之后，c = five*five 才第一次具备可折叠条件。真实编译器把这件事交给"重写到不动点"的驱动逻辑，本课的程序用一个 while 显式写出来——实测在 12 节点图上只需要 2 轮。

2. 代数化简：哪些恒等式在浮点下也成立#

代数化简（algebraic simplification）是一组模式改写：x+0→x、x*1→x、x-0→x、x/1→x、÷常数→×倒数。它们成立的前提各不相同：

改写 整数下 浮点下 备注
x+0 → x 成立 成立 但 -0.0 + 0.0 = +0.0，strict 语义要保号
x*1 → x 成立 成立 NaN/Inf 也成立
x*0 → 0 成立 条件成立 NaN/Inf 上应为 NaN，见第 4 课
(x+y)-y → x 成立 不成立 消去律在有限精度下失效
÷c → ×(1/c) 仅整除时 不成立（位不一致） 只有在数值契约允许时才做

真实的简化不是"能换就换"，而是每条规则带着自己的前置条件：÷c→×(1/c) 要求 c≠0 且契约允许非位一致；x*0→0 要求能证明 x 有限。TVM Relay 有一个专门的化简 pass（SimplifyExpr），它的规则集就是这种"带守卫的改写"的集合。

3. 算子消除：常量折叠的副产品#

折叠会生产孤儿子图：c 被折成常量后，two、three、five 不再有读者。这一步叫死节点消除（dead node elimination），也叫 DCE。做法是从每个输出反向求活跃集合——与第 3 课数据流分析里的"活跃变量"是同一件事，只是作用在整张图上。

DCE 的价值常被低估：折叠本身并不减少节点数（本课实测 12→12），真正把节点数降下来的是紧接着的 DCE（12→8）。顺序错了会白干：先 DCE 再折叠，孤儿要等下一轮才被清掉。

4. pass 的次序与不动点#

四个 pass 的排列顺序有硬道理：

  1. 先折叠、再化简：化简 x+0 需要知道 0 是常量；如果常量还在图里以"未折叠的节点"形式存在，化简判定就要多写一套"这个节点其实是常量"的逻辑。
  2. 化简后要再折叠一次：÷c 换成 ×0.04 之后，如果 x 也是常量，这一层新出现的乘法又能折。
  3. DCE 放最后：它清的是前三个 pass 制造的垃圾。

5. 常见坑#

  • 折叠用了宿主精度：在 float64 里算 float32 表达式再降回去，结果可能差 1 个 ULP。折叠必须在目标 dtype 上做（第 4 课有实测）。
  • 拿"等价"当"位一致"：÷25 → ×0.04 在多数硬件上不保证位一致；是否允许取决于数值契约。
  • 漏掉常量语义的边界：/0、x*0、-0.0 三处是折叠器最常翻车的地方。
  • 忘记 identity 节点的代价：化简产生的"直接复用"节点如果不做别名消除，执行时仍可能退化成一次拷贝。

二、可运行代码示例#

下面这段纯 Python（无第三方依赖）实现四步 pass 管线：常量折叠 → 代数化简 → 常量除法改写 → 死节点消除。图用第 3 课的节点表表示，identity 表示"直接复用输入"。每步都打印改了哪条规则，最后做优化前后逐元素对拍。

# ---- 第 1 课示例：常量折叠 + 代数化简 + 死节点消除（纯 Python，无第三方依赖）----
# 图表示沿用第 3 课的节点表：节点 = (op, [输入名], attrs, 输出名)，表顺序即拓扑序

def graph_before():
    N = lambda op, deps, nm, **at: (op, deps, at | {'name': nm}, nm)
    return [
        N('const', [], 'two',   value=2.0),
        N('const', [], 'three', value=3.0),
        N('const', [], 'zero',  value=0.0),
        N('const', [], 'one',   value=1.0),
        N('add',  ['two', 'three'], 'five'),     # 2+3 → 5（常量折叠）
        N('mul',  ['five', 'five'], 'c'),        # 5*5 → 25（同一 pass 里要再触发一轮）
        N('mul',  ['x', 'w'], 't1'),             # 真实计算从这里开始
        N('add',  ['t1', 'zero'], 't2'),         # +0 → 恒等（代数化简）
        N('mul',  ['t2', 'one'], 't3'),          # ×1 → 恒等
        N('div',  ['t3', 'c'], 'y1'),            # ÷25：折叠后常量在分母上，可换成 ×0.04
        N('relu', ['t1'], 't4'),
        N('mul',  ['t4', 'zero'], 'y2'),         # ×0：本课不做（第 4 课讲它何时不合法）
    ]

EXTERNAL = {'x': [1.0, 2.0, 3.0], 'w': [2.0, 0.0, -1.0]}

def binop(op, a, b):
    f = {'add': lambda u, v: u + v, 'sub': lambda u, v: u - v,
         'mul': lambda u, v: u * v, 'div': lambda u, v: u / v}[op]
    if isinstance(a, list) and isinstance(b, list): return [f(u, v) for u, v in zip(a, b)]
    if isinstance(a, list): return [f(u, b) for u in a]
    if isinstance(b, list): return [f(a, v) for v in b]
    return f(a, b)

def run(nodes, inputs):
    """解释执行：外部输入 + const 节点提供初值，identity 直接复用输入。"""
    env = dict(inputs)
    for op, deps, at, nm in nodes:
        if op == 'const':      env[nm] = at['value']
        elif op == 'identity': env[nm] = env[deps[0]]
        elif op in ('add', 'sub', 'mul', 'div'): env[nm] = binop(op, env[deps[0]], env[deps[1]])
        elif op == 'relu':     env[nm] = [max(u, 0.0) for u in env[deps[0]]]
        else: raise ValueError(op)
    return env

# ---------------- pass 1：常量折叠（一个常量会解锁下游，必须迭代到不动点）----------------
def fold(nodes, const):
    cur, log, rounds = list(nodes), [], 0
    while True:
        rounds += 1; changed = False; nxt = []
        for op, deps, at, nm in cur:
            if op == 'const':
                const[nm] = at['value']; nxt.append((op, deps, at, nm)); continue
            # 只折叠"输入全是标量常量"的算术节点；含张量的常量运算留给后端常量算
            if op in ('add', 'sub', 'mul', 'div') and all(d in const for d in deps):
                a, b = const[deps[0]], const[deps[1]]
                if op == 'div' and b == 0:                      # 先挡住非法折叠
                    log.append((nm, f'{a!r} div {b!r} → 分母为 0，不折叠'))
                    nxt.append((op, deps, at, nm)); continue
                v = binop(op, a, b)
                log.append((nm, f'{a!r} {op} {b!r} = {v!r}'))
                const[nm] = v; changed = True
                nxt.append(('const', [], {'value': v, 'name': nm, 'from': nm}, nm)); continue
            nxt.append((op, deps, at, nm))
        cur = nxt
        if not changed: break
    return cur, log, rounds

# ---------------- pass 2：代数化简（只留浮点下成立的恒等式）----------------
IDENT = {('add', 'zero'), ('sub', 'zero'), ('mul', 'one'), ('div', 'one')}
def simplify(nodes, const):
    cur, log = [], []
    for op, deps, at, nm in nodes:
        hit = None
        if len(deps) == 2 and op in ('add', 'sub', 'mul', 'div'):
            for d in deps:
                if (op, d) in IDENT and d in const:
                    hit = deps[1] if deps[0] == d else deps[0]; break
        if hit:
            log.append((nm, f'{op}({deps[0]}, {deps[1]}) → 直接复用 {hit}'))
            cur.append(('identity', [hit], {'name': nm}, nm))
        else:
            cur.append((op, deps, at, nm))
    return cur, log

# ---------------- pass 3：常量除法改写（÷常数 → ×倒数，判定在后端）----------------
def div_to_mul(nodes, const):
    cur, log = [], []
    for op, deps, at, nm in nodes:
        if op == 'div' and deps[1] in const and const[deps[1]] not in (0, 0.0):
            r = 1.0 / const[deps[1]]
            log.append((nm, f'÷{const[deps[1]]} → ×{r!r}'))
            cur.append(('const', [], {'value': r, 'name': '_recip_' + nm}, '_recip_' + nm))
            cur.append(('mul', [deps[0], '_recip_' + nm], {'name': nm}, nm))
            continue
        cur.append((op, deps, at, nm))
    return cur, log

# ---------------- pass 4：死节点消除（从输出反向求活跃集合）----------------
def dce(nodes, outputs):
    byname = {nm: deps for op, deps, at, nm in nodes}
    live = set(outputs)
    for nm in [n for _, _, _, n in nodes][::-1]:
        if nm in live: live.update(byname[nm])
    kept = [t for t in nodes if t[3] in live]
    return kept, [t[3] for t in nodes if t[3] not in live]

def show(nodes):
    return ' → '.join(f'{nm}:{op}({",".join(deps)})' for op, deps, at, nm in nodes)

if __name__ == '__main__':
    g0 = graph_before()
    print('=== 原始图（12 个节点，前 4 个是 const）===')
    print(' ', show(g0))

    const = {}
    g1, log1, rounds = fold(g0, const)
    print(f'\n=== pass 1 常量折叠：迭代 {rounds} 轮达到不动点 ===')
    for nm, msg in log1: print(f'  {nm:<6} {msg}')

    g2, log2 = simplify(g1, const)
    print('\n=== pass 2 代数化简（先折叠后化简：常量在 map 里看得见）===')
    for nm, msg in log2: print(f'  {nm:<6} +0 / ×1 命中：{msg}')

    g3, log3 = div_to_mul(g2, const)
    print('\n=== pass 3 常量除法改写（÷常数 换 ×倒数；第 2 课的布局改写同属这一类属性改写）===')
    for nm, msg in log3: print(f'  {nm:<6} {msg}')

    g4, gone = dce(g3, ['y1', 'y2'])
    print(f'\n=== pass 4 死节点消除：已无读者 {gone}（{len(gone)} 个）===')
    print(f'\n节点数：{len(g0)} → {len(g1)} → {len(g2)} → {len(g3)} → {len(g4)}')

    rb, ra = run(g0, EXTERNAL), run(g4, EXTERNAL)
    print('\n=== 优化前后逐元素对拍（必须完全一致）===')
    print(f'  y1: 前 {rb["y1"]}  后 {ra["y1"]}  {"一致" if rb["y1"] == ra["y1"] else "不一致 ← bug"}')
    print(f'  y2: 前 {rb["y2"]}  后 {ra["y2"]}  {"一致" if rb["y2"] == ra["y2"] else "不一致 ← bug"}')
    print(f'  折叠出的常量：' + ', '.join(f'{k}={v!r}' for k, v in const.items() if k in ('five', 'c')))

    print('\n=== 为什么"等价变换"不总是等价：浮点不是实数域 ===')
    x, z = 1.0, 1e16
    print(f'  (x+z)-z = {(x + z) - z!r}  而 x = {x!r}  → "(x+z)-z → x" 这条改写在这里不成立')
    y = 1e16
    print(f'  (x+y)-y = {(x + y) - y!r}  而 x = {x!r}  → 同样的改写，换一组数就不成立')
    print(f'  nan*0.0 = {float("nan") * 0.0}   inf*0.0 = {float("inf") * 0.0}'
          f'   → "x*0→0" 的前提是 x 有限')
    print('  本课演示的都是"能折叠"的情形；判定标准与反例清单在第 4 课。')

实际运行结果（Python 3.14，无第三方依赖）：

=== 原始图（12 个节点，前 4 个是 const）===
  two:const() → three:const() → zero:const() → one:const() → five:add(two,three) → c:mul(five,five) → t1:mul(x,w) → t2:add(t1,zero) → t3:mul(t2,one) → y1:div(t3,c) → t4:relu(t1) → y2:mul(t4,zero)

=== pass 1 常量折叠：迭代 2 轮达到不动点 ===
  five   2.0 add 3.0 = 5.0
  c      5.0 mul 5.0 = 25.0

=== pass 2 代数化简（先折叠后化简：常量在 map 里看得见）===
  t2     +0 / ×1 命中：add(t1, zero) → 直接复用 t1
  t3     +0 / ×1 命中：mul(t2, one) → 直接复用 t2

=== pass 3 常量除法改写（÷常数 换 ×倒数；第 2 课的布局改写同属这一类属性改写）===
  y1     ÷25.0 → ×0.04

=== pass 4 死节点消除：已无读者 ['two', 'three', 'one', 'five', 'c']（5 个）===

节点数：12 → 12 → 12 → 13 → 8

=== 优化前后逐元素对拍（必须完全一致）===
  y1: 前 [0.08, 0.0, -0.12]  后 [0.08, 0.0, -0.12]  一致
  y2: 前 [0.0, 0.0, 0.0]  后 [0.0, 0.0, 0.0]  一致
  折叠出的常量：five=5.0, c=25.0

=== 为什么"等价变换"不总是等价：浮点不是实数域 ===
  (x+z)-z = 0.0  而 x = 1.0  → "(x+z)-z → x" 这条改写在这里不成立
  (x+y)-y = 0.0  而 x = 1.0  → 同样的改写，换一组数就不成立
  nan*0.0 = nan   inf*0.0 = nan   → "x*0→0" 的前提是 x 有限
  本课演示的都是"能折叠"的情形；判定标准与反例清单在第 4 课。

四处可核对的结论：折叠必须迭代（第 1 轮折出 five，第 2 轮才折出 c，第 3 轮确认不再变化）；折叠本身不减节点（12→12），把节点数降下来的是 DCE（12→8，删掉 5 个孤儿）；化简依赖折叠结果（zero/one 先作为常量节点存在，+0/×1 才判得出来）；改写前后逐元素一致（y1、y2 完全相同），这就是"正确性验收"的最小形式——真实编译器要跑的是整个测试集。

三、练习#

  1. 实现：给 fold 加一条"广播折叠"——当输入是"标量常量 + 常量列表"时也折叠（例如 t = x_const_list + 0.0）。提示：先想清楚结果该是列表还是标量，以及这一步为什么在真实编译器里常交给后端常量算。
  2. 解释：为什么 pass 3 把 _recip_y1 常量节点插在 mul 之前是必须的？如果插在后面，run 会报什么错，这暴露了图 IR 的哪条不变式？
  3. 对比/验证：把 simplify 的规则集扩展到 x-0→x 和 x/1→x，重跑程序并对照节点数变化；再故意加一条 x*0→0，用 x = [float('nan'), 1.0] 做输入，观察逐元素对拍是否失效。
  4. 思考：本课的 DCE 从 ['y1','y2'] 出发。如果模型有多个输出（例如训练时还要输出 loss），DCE 的根集合该取什么？取漏一个会发生什么——是编译错误，还是更难发现的运行时错误？
