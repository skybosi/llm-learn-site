从感知机说起#

神经网络的一切，都要从一个只有"一个神经元"的模型讲起：感知机（Perceptron）。它诞生于 1958 年，是心理学家 Frank Rosenblatt 提出的第一个能"自己学习"的模型，也是后来所有深度网络共同的祖先。理解感知机，你就拿到了神经网络的地基——后面要学的多层感知机、深度学习，本质上都是在它的"加权求和 + 非线性"骨架上不断加层、换激活、换优化器。这一课我们从感知机的结构、学习规则讲起，并亲手用 NumPy 实现一个。

一、概念讲解#

1. 感知机长什么样：一个会做决策的"门卫"#

感知机解决的是二分类问题：给定一个输入向量 x = [x₁, x₂, …, xₙ]，判断它属于"正类"还是"负类"。它的计算分两步：

第一步：加权求和   z = w₁x₁ + w₂x₂ + … + wₙxₙ + b
第二步：阶跃判断   ŷ = 1  (若 z ≥ 0)，否则 ŷ = 0
  • w = [w₁, …, wₙ] 是权重，表示每个输入特征的重要性；
  • b 是偏置，相当于一个"门槛"，决定决策边界离原点多远；
  • 第二步的"阶跃判断"叫激活函数，这里用的是阶跃函数（step function），把连续的 z 硬掰成 0 或 1。

可以把它想成一个门卫：门卫把来访者的各项信息（特征）分别打分、加权加起来，得到一个总分 z；总分超过门槛（z ≥ 0）就放行（输出 1），否则拒绝（输出 0）。它要学的，就是"每一项该打多少分"（权重 w）和"门槛设在多高"（偏置 b）。

2. 几何含义：一条把空间切成两半的直线#

z = wᵀx + b = 0 在二维平面里是一条直线，在高维空间里是一个超平面。感知机的分类，就是把空间用这条直线切成两半：

  • 直线一边的点 z > 0，判为正类；
  • 另一边 z < 0，判为负类。

因此感知机只能解决"线性可分"的问题——即存在一条直线（超平面）能把两类样本完全分开。像逻辑与（AND）、逻辑或（OR）这类问题都可以用一条直线分开；但异或（XOR）问题不行：它的四个点无法用任何一条直线把 (0,0)/(1,1) 和 (0,1)/(1,0) 分开。

这一条看似不起眼的限制，后来直接引发了神经网络史上的第一次"寒冬"——1969 年 Minsky 和 Papert 在《感知机》一书里严厉指出单层感知机连 XOR 都学不会，让整个领域沉寂了十几年。而走出这个死胡同的钥匙，恰恰是"多加一层"——这就是下一课要讲的神经网络。

3. 感知机怎么学：错误驱动的更新规则#

感知机的学习规则极其朴素——只在犯错的时候改参数。对每个训练样本 (x, y)：

预测 ŷ = step(wᵀx + b)
若预测正确：不改
若预测错误：w ← w + η·(y − ŷ)·x
            b ← b + η·(y − ŷ)
  • η 是学习率，控制每次改正的步长；
  • (y − ŷ) 是"真实标签减去预测标签"，取值只能是 +1 或 -1，代表"该往哪边修"。

直觉是这样的：当预测错误时，我们把权重往"能让这个样本变正确"的方向挪一点。如果负样本被误判成正样本（y=0, ŷ=1，即 y−ŷ=−1），就把权重沿 x 的反方向拉；反之沿 x 正方向推。只要数据线性可分，感知机收敛定理保证：这个朴素算法一定能在有限步内找到一条把两类分开的直线。 但若数据不可分，它会永远震荡下去——这也是它的软肋。

4. 从感知机到现代网络：三步走#

把上面这套流程抽象出来，你会看到它与今天深度学习训练流程一模一样：

  1. 前向计算：输入 → 加权求和 → 激活 → 输出预测；
  2. 算误差：预测与真实标签的差距（感知机用 y − ŷ，深度网络用更光滑的损失函数）；
  3. 更新参数：沿让误差变小的方向调权重（感知机用规则直接更新，深度网络用梯度下降 + 反向传播）。

感知机把"模型长什么样、怎么衡量好坏、怎么改参数"这三件事都发明了出来。后续课程要做的，只是把阶跃激活换成可导的激活函数、把单层换成多层、把简单规则换成梯度反向传播——骨架没变，变的是规模与工具。

二、可运行代码示例#

下面用纯 NumPy 从零实现一个感知机，让它学会 AND 逻辑门。AND 是线性可分的，正好适合单层感知机。

import numpy as np

# 训练数据：AND 逻辑门（线性可分）
# 每一行是 [x1, x2]，标签是 x1 AND x2
X = np.array([[0, 0],
              [0, 1],
              [1, 0],
              [1, 1]])
y = np.array([0, 0, 0, 1])   # 只有 (1,1) 输出 1

class Perceptron:
    def __init__(self, lr=0.1):
        self.lr = lr

    def step(self, z):
        """阶跃激活函数：z >= 0 输出 1，否则 0"""
        return (z >= 0).astype(int)

    def fit(self, X, y, epochs=20):
        n_samples, n_features = X.shape
        # 权重与偏置都初始化为 0
        self.w = np.zeros(n_features)
        self.b = 0.0
        for epoch in range(epochs):
            errors = 0
            for xi, yi in zip(X, y):
                z = np.dot(self.w, xi) + self.b      # 加权求和
                y_pred = self.step(z)                # 阶跃判断
                update = self.lr * (yi - y_pred)     # 仅在犯错时非零
                self.w += update * xi                # 更新权重
                self.b += update                     # 更新偏置
                errors += int(yi != y_pred)
            print(f"第 {epoch:2d} 轮：分类错误数 = {errors}，w = {self.w}，b = {self.b:.1f}")
            if errors == 0:
                print("已完全正确，提前停止训练。")
                break

    def predict(self, X):
        return self.step(X @ self.w + self.b)

# 训练并验证
model = Perceptron(lr=0.1)
model.fit(X, y, epochs=20)
print("预测结果：", model.predict(X))
print("期望结果：", y)

运行后你会看到：前几轮模型在 (0,1)、(1,0) 上犯错，权重被不断修正；几轮之后错误数归零，预测与期望完全一致。最终学到的决策边界是 w₁x₁ + w₂x₂ + b = 0 这样一条把 (1,1) 单独切到一边的直线。

再来验证它学不会 XOR：把上面的 X、y 换成 XOR 数据（y = [0,1,1,0]），重新跑训练。你会观察到错误数永远无法归零，权重在几组值之间来回震荡——这正是单层感知机"线性不可分"局限的直接体现。

三、练习#

  1. 读懂更新规则：假设当前 w=[0,0], b=0，样本是 x=[1,1], y=1，学习率 η=0.1。手算一次更新后的 w 和 b，说明为什么权重朝 x 的方向移动。
  2. 实现 OR 门：把训练数据换成 OR 逻辑门（y=[0,1,1,1]），运行代码确认感知机能学会，并思考 OR 的决策边界大概是什么样。
  3. 验证 XOR 失败：换成 XOR 数据跑一遍，记录每一轮错误数，观察震荡现象，解释为什么"犯错才改"的规则在不可分数据上会不停打转。
  4. 学习率实验：把 lr 改成 0.01 和 1.0，对比收敛轮数。学习率过小和过大各有什么后果？
  5. 思考：感知机的输出是离散的 0/1，这给"用梯度下降训练多层网络"带来了什么麻烦？提示：阶跃函数在 z=0 处不可导、其它地方导数为 0，梯度会变成什么样？
