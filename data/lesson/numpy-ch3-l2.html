布尔掩码#

上一课我们用整数下标和切片取数据，但数据科学里更常见的需求是按条件筛选：找出所有缺失值、筛选成绩及格的学生、定位价格异常的样本。这类"选出满足条件的元素"的操作，靠的就是布尔掩码（boolean mask）。

一、概念讲解#

1. 什么是布尔掩码#

对一个数组施加比较运算，会得到一个形状相同的布尔数组（元素为 True/False）。把这个布尔数组当作索引放进方括号里，NumPy 就会只返回对应位置为 True 的元素。

mask = scores >= 60   # 布尔数组
passed = scores[mask] # 只取出 mask 为 True 的元素

2. 组合多个条件#

用位运算符组合条件（不要用 and/or，它们只作用于单个布尔值，对数组会报错）：

运算符 含义
& 与（同时满足）
` `
~ 非（取反）

多个条件各自都要加括号，否则会因运算优先级而出错，例如 (x > 0) & (x < 10)。

3. 布尔掩码的常用配套#

  • np.where(condition, a, b)：条件为真取 a 的值，否则取 b 的值，常用来做"条件替换"；
  • np.where(condition)：只给条件时，返回满足条件的元素的下标；
  • 布尔数组的 .sum() 统计 True 个数，.any()/.all() 判断是否存在/是否全部满足；
  • 布尔掩码常用于处理缺失值（配合 np.nan 判断）和异常值过滤。

4. 数据科学中的典型用法#

  • 筛选某列特征满足阈值的所有样本行；
  • 统计满足条件的样本数量；
  • 把异常值（如负值）替换成 0 或均值；
  • 配合 np.isnan 找出缺失值。

二、可运行代码示例#

示例 1：基本布尔索引#

import numpy as np

scores = np.array([72, 91, 58, 84, 66, 95])

passed = scores[scores >= 60]   # 取出及格的分数
print("passed scores:", passed)

count = (scores >= 60).sum()    # 及格人数
print("pass count:", count)

print("any >= 90:", (scores >= 90).any())   # 是否存在 90 分以上
print("all >= 60:", (scores >= 60).all())   # 是否全部及格

示例 2：组合条件筛选样本行#

import numpy as np

# 特征矩阵：第 0 列年龄，第 1 列收入（千元），第 2 列城市编号
people = np.array([
    [25, 12, 1],
    [34, 30, 2],
    [18, 5, 1],
    [42, 50, 3],
    [29, 20, 2],
])

# 筛选：年龄在 20~40 之间 且 收入大于 15 的样本
age = people[:, 0]
income = people[:, 1]
mask = (age >= 20) & (age <= 40) & (income > 15)
selected = people[mask]

print("mask:", mask)
print("selected rows:\n", selected)

示例 3：用 np.where 做条件替换#

import numpy as np

values = np.array([-3, -1, 0, 2, 7, 10])

# 三参数形式：负值替换成 0，其余保留原值
clipped = np.where(values < 0, 0, values)
print("replace negatives with 0:", clipped)

# 单参数形式：返回满足条件的下标
idx = np.where(values > 0)
print("indices where > 0:", idx[0])
print("values at those indices:", values[idx])

示例 4：处理缺失值（NaN）#

import numpy as np

data = np.array([1.0, np.nan, 3.0, np.nan, 5.0])

is_missing = np.isnan(data)            # 缺失值掩码
print("missing mask:", is_missing)
print("missing count:", is_missing.sum())

# 用非缺失值的均值填充缺失值
mean_valid = data[~is_missing].mean()
filled = np.where(is_missing, mean_valid, data)
print("filled:", filled)
