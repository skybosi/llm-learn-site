数据增强#

一个模型在训练集上表现好、在新数据上表现差，最常见的病因就是过拟合——它把训练集里"特定图片长什么样"也死记下来了。数据增强（Data Augmentation）是缓解过拟合最便宜的良药：不增加真实数据，而是对现有样本做随机变换，让模型每个 epoch 看到的都是"略有不同"的样本，逼它去学真正通用的特征，而不是死记某一帧。

一、概念讲解#

1. 增强的本质：制造"合理的变体"#

以图像分类为例，一张猫的照片，无论左右翻转、轻微旋转、裁剪掉一部分，都还是一只猫。数据增强就是把这些"不影响标签的变换"随机地施加到训练样本上：

  • 几何变换：随机水平翻转、随机裁剪、旋转、缩放；
  • 颜色变换：调整亮度、对比度、饱和度、色调；
  • 归一化：把像素缩放到固定均值和方差（严格说这是"预处理"，不是增强，但常一起放进变换流水线）。

关键在于：只在训练集上做增强，验证集和测试集只做确定性的预处理（比如 Resize + 归一化），这样才能公平地评估真实表现。

2. 在 PyTorch 里怎么做：transforms#

torchvision.transforms 提供了一系列可组合的变换。用 transforms.Compose 把它们串成一条流水线，图片从左到右依次经过每一步：

from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(p=0.5),   # 50% 概率水平翻转
    transforms.RandomRotation(15),            # 在 [-15°, 15°] 内随机旋转
    transforms.ToTensor(),                    # PIL 图像 -> 张量，像素归一到 [0,1]
    transforms.Normalize((0.5,), (0.5,)),     # 标准化到均值 0.5、方差 0.5
])

transforms 可以直接传给 torchvision.datasets 的 transform= 参数，也可以在自己写的 Dataset.__getitem__ 里手动调用。上一课说过，__getitem__ 每次取样本时都会执行一次，因此随机变换每个 epoch 都会重新随机——这就是"同一张图每次看起来不一样"的原因。

3. 增强放在哪里执行#

推荐把增强写进 Dataset 的 transform，而不是训练循环里。好处是：

  1. 逻辑内聚：数据和它的预处理绑在一起；
  2. 复用简单：训练、验证、推理各自用不同的 transform 即可；
  3. 配合 DataLoader 多线程：增强在 worker 里并行完成，不拖慢主循环。

二、可运行代码示例#

下面用一个内置数据集 FashionMNIST 演示完整流程：定义训练/验证两套 transform，包装成 DataLoader，再用一个迷你 CNN 各跑一步前向，观察增强后的输入形状不变（变换只改内容，不改尺寸）。

import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms


# 1) 训练集：随机增强 + 归一化
train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(p=0.5),   # 服装图左右翻转后仍是同类
    transforms.RandomRotation(10),            # 随机旋转 ±10 度
    transforms.ToTensor(),                    # (1, 28, 28) 且像素归一到 [0,1]
    transforms.Normalize((0.5,), (0.5,)),     # 标准化：让像素大致落在 [-1, 1]
])

# 2) 验证集：不做增强，只做确定性预处理
val_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,)),
])

# 3) 加载数据（首次会自动下载）
train_set = datasets.FashionMNIST(root="./data", train=True, download=True, transform=train_transform)
val_set = datasets.FashionMNIST(root="./data", train=False, download=True, transform=val_transform)

train_loader = DataLoader(train_set, batch_size=64, shuffle=True)
val_loader = DataLoader(val_set, batch_size=64, shuffle=False)

# 4) 一个能接收 28x28 灰度图的迷你 CNN
class MiniCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 8, kernel_size=3),   # 28x28 -> 26x26
            nn.ReLU(),
            nn.Flatten(),
            nn.Linear(8 * 26 * 26, 10),       # 输出 10 类
        )

    def forward(self, x):
        return self.net(x)


model = MiniCNN()

# 5) 各取一个 batch 做前向，验证形状一致
train_x, train_y = next(iter(train_loader))
val_x, val_y = next(iter(val_loader))

print("训练 batch 输入形状：", train_x.shape)   # torch.Size([64, 1, 28, 28])
print("验证 batch 输入形状：", val_x.shape)     # torch.Size([64, 1, 28, 28])

out_train = model(train_x)
out_val = model(val_x)
print("训练 batch 输出形状：", out_train.shape)  # torch.Size([64, 10])
print("验证 batch 输出形状：", out_val.shape)    # torch.Size([64, 10])

# 6) 直观感受增强：对同一张图做多次训练变换，像素统计会不同
raw = train_set.data[0].float() / 255.0   # 原始第 0 张图（未增强的张量）
print("\n原始图像素均值：", round(raw.mean().item(), 4))

means = []
for _ in range(5):
    img, _ = train_set[0]   # 每次都重新经过 train_transform
    means.append(round(img.mean().item(), 4))
print("同一样本经 5 次增强后的像素均值：", means)  # 每次不同，说明增强在随机生效

运行后你会看到类似：

训练 batch 输入形状： torch.Size([64, 1, 28, 28])
验证 batch 输入形状： torch.Size([64, 1, 28, 28])
训练 batch 输出形状： torch.Size([64, 10])
验证 batch 输出形状： torch.Size([64, 10])
原始图像素均值： 0.0...
同一样本经 5 次增强后的像素均值： [0.0115, -0.0312, 0.0047, -0.0171, 0.0216]

最后那行最能说明问题：同一张图、同一个下标，每次取出来经过随机翻转/旋转后数值都不一样。模型因此被迫学会"翻转过的衬衫还是衬衫"，泛化能力自然更强。

三、练习#

  1. 在 train_transform 里加入 transforms.RandomCrop(28, padding=4)（先填充再裁剪），观察训练输入形状是否仍是 (64, 1, 28, 28)。
  2. 用 transforms.ColorJitter(brightness=0.3, contrast=0.3) 替换旋转，重新跑第 6 步，观察像素均值的变化幅度。
  3. 把训练用的 Normalize 参数改成 (0.5,), (0.2,)，思考这对输入数值范围有什么影响，为什么验证集要用和训练集一致的归一化参数？
  4. 想一想：如果对验证集也做随机增强，评估出来的准确率是"偏高"还是"偏低"？为什么数据增强通常只在训练阶段开启？
