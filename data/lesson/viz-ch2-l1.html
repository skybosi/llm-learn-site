折线图#

折线图是最常见的基础图表之一，擅长展示数据随某个有序变量（尤其是时间）变化的趋势。从这一章开始，我们逐一学习几种基础图表。

一、概念讲解#

1. 折线图适合什么场景#

折线图的核心价值在于展示趋势与变化：横轴通常是有序的量（时间、序号、连续的数值），纵轴是观测值，用线段把相邻点连起来，让"上升、下降、波动"一目了然。典型场景包括：

  • 时间序列：股价、气温、销售额随日期的变化。
  • 函数曲线：绘制数学函数或模型输出。
  • 多序列对比：在同一坐标系里画多条线，比较不同组的变化趋势。

2. 用 ax.plot 画折线图#

ax.plot(x, y) 把 (x, y) 点按顺序用线段连接。要点：

  • x 与 y 是等长的一维数组（可直接用 NumPy 数组）。
  • 若只传一个数组 ax.plot(y)，则横轴自动取 0, 1, 2, ... 的索引。
  • 多次调用 ax.plot 会在同一个 Axes 上叠加多条折线，配合 label 参数和 ax.legend() 区分各序列。

3. 让折线图更易读的常用元素#

  • 网格：ax.grid(True) 或 ax.grid(True, linestyle=":", alpha=0.6)，方便对照读数。
  • 数据点标记：marker="o"、markersize=4 在线上标出采样点。
  • 线型区分：多条线时用实线、虚线、不同颜色区分。
  • 图例：label + ax.legend() 说明每条线代表什么。

二、可运行代码示例#

下面模拟 30 天的"日均气温"与"日销售额"两条序列，用折线图对比它们的趋势。

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False

rng = np.random.default_rng(42)

# 模拟 30 天的数据：基础趋势 + 噪声
days = np.arange(1, 31)
temperature = 20 + 8 * np.sin(days / 30 * 2 * np.pi) + rng.normal(0, 1, 30)
sales = 100 + 20 * np.sin(days / 30 * 2 * np.pi - 1) + rng.normal(0, 5, 30)

fig, ax = plt.subplots(figsize=(9, 4.5))

# 两条折线：不同颜色、线型与标记，label 供图例使用
ax.plot(days, temperature, color="#4c72b0", marker="o", markersize=4,
        linestyle="-", linewidth=2, label="日均气温（℃）")
ax.plot(days, sales, color="#dd8452", marker="s", markersize=4,
        linestyle="--", linewidth=2, label="日销售额（万元）")

ax.set_title("折线图：30 天趋势对比")
ax.set_xlabel("第几天")
ax.set_ylabel("数值")
ax.grid(True, linestyle=":", alpha=0.6)   # 淡色点线网格
ax.legend()

plt.show()

观察两条折线如何用颜色、线型和标记被清晰区分。

三、练习#

  1. 用 ax.plot(y)（只传一个数组）绘制 np.array([3, 1, 4, 1, 5, 9])，观察横轴的默认取值。
  2. 生成 50 个点：x = np.linspace(0, 10, 50)，绘制 y1 = np.sin(x) 与 y2 = np.cos(x) 两条折线，分别使用实线与点划线（"-."），并添加图例与网格。
  3. 在练习 2 的基础上，把某一条线的 linewidth 改为 3、另一条改为 1，说明线宽对视觉层次的影响。
