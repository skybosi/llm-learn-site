两者对比#

前两课我们分别拆解了 GraphSAGE 和 GAT。现在把它们放到一起对照，回答一个工程上最实际的问题：拿到一个图任务，我该选哪一个？ 本课从机制、能力、成本三个层面做系统对比，并给出一个可操作的选型指南。

一、概念讲解#

1. 先回到同一个"母题"：消息传递#

在纠结差异之前，先确认两者的共性——它们和 GCN 一样，都属于消息传递（message passing）框架。每一层都做两件事：

  1. 聚合（Aggregate）：把邻居的信息汇总成一个向量。
  2. 更新（Update）：用聚合结果更新中心节点自己的表示。

写成统一形式：

m_v = AGGREGATE( { h_u : u ∈ N(v) } )       # 邻居消息汇总
h_v' = UPDATE( h_v, m_v )                    # 结合自身，更新表示

GCN、GraphSAGE、GAT 的差别，全部落在"AGGREGATE 里邻居权重如何确定"这一点上。抓住这条主线，对比就一目了然：

  • GCN：权重 = 1/sqrt(d_v · d_u)，固定，只由度数决定。
  • GraphSAGE：权重 = 均值/池化里的固定规则（等权平均，或最大池化取最强特征），可学习的是聚合函数形态。
  • GAT：权重 = 注意力系数 α_ij，逐边可学习、依赖内容。

2. 维度一：直推式 vs 归纳式#

这是 GraphSAGE 最核心的卖点。

  • GCN：直推式。参数无法直接"从特征生成嵌入"，对训练图之外的新节点无能为力。
  • GraphSAGE：归纳式。学到的是聚合函数，新节点只要有特征就能套用，天然支持动态图、跨图迁移。
  • GAT：部分归纳。权重 W 和 a 也是"从特征到嵌入"的函数，理论上能处理新节点；但原版 GAT 的 softmax 仍限定在给定邻接结构上（只对已知邻居做 mask）。若去掉这个 mask、改成对全图/全序列做注意力，就退化成类似 Transformer 的全局注意力，可完全归纳。所以 GAT 的归纳能力介于 GCN 和 GraphSAGE 之间，取决于实现方式。

3. 维度二：权重是否"聪明"#

  • GraphSAGE：均值聚合对邻居等权，隐含假设"所有邻居贡献相同"；池化聚合稍微聪明一点（能挑出最强特征），但仍不区分邻居与中心节点的相关性。
  • GAT：权重 α_ij 由两端特征共同决定，能主动放大相关邻居、抑制噪音邻居，还能学出非对称的有向关系。在"邻居质量参差不齐"的图上（异质图、含噪图），GAT 的优势最明显。
  • 代价是：注意力要对每条边算一次打分，计算量更大；而且 softmax 的"赌注"集中性可能让训练略不稳定，常需多头来缓解。

4. 维度三：可扩展性与成本#

  • GraphSAGE：靠邻居采样把每层计算量约束到常数，支持超大图的小批量训练，是三者中可扩展性最好的。
  • GAT：对每个节点的全部邻居做注意力（除非额外引入采样），遇到高度数节点成本高；且注意力涉及成对的矩阵运算，显存开销大于 GraphSAGE。
  • GCN：整图一次性前向，小图很快，但全图放不进内存时同样需要采样变体。

5. 维度四：表达力与鲁棒性#

  • 表达力：GAT 通过学习边权重，理论上能表达"哪些邻居更重要"，表达力上限更高；GraphSAGE 通过池化/拼接也有不错的表达力。
  • 鲁棒性：GraphSAGE 的采样自带正则化，训练较稳；GAT 对注意力初始化较敏感，且有"静态注意力"的隐患（前一课讲的 GATv2 修正）。
  • 可解释性：GAT 的注意力权重可直接可视化，解释性最好；GraphSAGE 的聚合过程相对黑盒。

6. 一张表总结 + 选型指南#

对比维度 GCN GraphSAGE GAT
邻居权重来源 度数固定 等权 / 池化（可学聚合函数） 注意力（逐边可学、内容相关）
归纳能力 无（直推式） 强（归纳式） 中等（取决于是否放开结构 mask）
可扩展性 小图快、大图需采样 采样，最好 全邻居注意力，成本高
表达力 基础 较好 高（可学边权）
训练稳定性 稳定 稳定 需多头、初始化敏感
可解释性 低 低 高（注意力可解释）

选型建议：

  • 图规模巨大、要处理新节点/新图、追求可扩展 → GraphSAGE。
  • 邻居质量参差、需要区分邻居重要性、图规模中等、看重可解释 → GAT（不稳就换 GATv2）。
  • 快速基线、小图基准对比 → GCN。
  • 实际工程中，三者常作为同一套消息传递框架下的不同卷积层混用：主干用 GraphSAGE 保证可扩展，关键层换 GAT 增强表达力，完全可行。

二、可运行示例#

示例：同一个 Cora 任务，分别跑 GCN / SAGE / GAT，对比测试准确率

import torch
import torch.nn.functional as F
from torch_geometric.nn import GCNConv, SAGEConv, GATConv
from torch_geometric.datasets import Planetoid

dataset = Planetoid(root='./data/Cora', name='Cora')
data = dataset[0]
in_ch, out_ch = dataset.num_features, dataset.num_classes

# 三个模型结构完全一致：两层卷积 + ReLU + dropout + log_softmax
def make_model(conv_type):
    class Net(torch.nn.Module):
        def __init__(self):
            super().__init__()
            if conv_type == 'gcn':
                self.c1, self.c2 = GCNConv(in_ch, 16), GCNConv(16, out_ch)
            elif conv_type == 'sage':
                self.c1, self.c2 = SAGEConv(in_ch, 16), SAGEConv(16, out_ch)
            else:  # gat
                self.c1 = GATConv(in_ch, 8, heads=8, dropout=0.6)
                self.c2 = GATConv(8 * 8, out_ch, heads=1, concat=False, dropout=0.6)
        def forward(self, x, ei):
            x = self.c1(x, ei)
            x = F.relu(x)
            x = F.dropout(x, p=0.5, training=self.training)
            x = self.c2(x, ei)
            return F.log_softmax(x, dim=1)
    return Net()

def run(conv_type, epochs=200):
    model = make_model(conv_type)
    opt = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)
    best_val = 0.0; best_test = 0.0
    for epoch in range(epochs):
        model.train(); opt.zero_grad()
        out = model(data.x, data.edge_index)
        loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
        loss.backward(); opt.step()
        # 用验证集选最优，测试集只做最终报告
        model.eval()
        pred = model(data.x, data.edge_index).argmax(dim=1)
        val = (pred[data.val_mask] == data.y[data.val_mask]).float().mean().item()
        test = (pred[data.test_mask] == data.y[data.test_mask]).float().mean().item()
        if val > best_val:
            best_val, best_test = val, test
    print(f'{conv_type.upper():>5} | Best Val {best_val:.4f} | Test {best_test:.4f}')
    return best_test

for c in ['gcn', 'sage', 'gat']:
    run(c)

典型结果三者都落在 0.79–0.83 区间，差异不大——这本身就是一个重要结论：在 Cora 这类同质、干净的引文图上，三种聚合方式的差距被任务难度掩盖；模型之间的真正分水岭，要到"新节点泛化""异质邻居""超大图"这些场景里才拉开。建议读者把这段代码改到 CiteSeer、PubMed 上各跑一遍，感受差异。

三、练习#

  1. 填空对照：不看讲义，把 GCN / GraphSAGE / GAT 三者的"邻居权重来源"和"归纳能力"两行填出来，并与 6. 节的表格核对。
  2. 改动实验：把示例里的 dropout 从 0.5 改成 0，观察 GAT 相对 GCN/SAGE 的过拟合程度，解释注意力模型为何更依赖正则化。
  3. 混搭尝试：把模型第一层改成 SAGEConv、第二层用 GATConv，跑一遍，看看准确率与纯 SAGE、纯 GAT 相比如何，思考"混搭"的合理性。
  4. 归纳性验证：仿照第 1 课的方法，把 10% 的节点从训练图中隐藏，训练后用三者分别给隐藏节点预测。哪些模型能直接预测？哪些需要重训？结果说明了什么？
  5. 综述阅读：找一篇消息传递框架（Message Passing Neural Network）的综述或论文，把 GCN/SAGE/GAT 统一写成"聚合 + 更新"的形式，比较各自对这两个函数的具体选择。
