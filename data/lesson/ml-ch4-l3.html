混淆矩阵#

上一课我们提到精确率、召回率这些指标，但它们背后到底是怎么算出来的？本课介绍的混淆矩阵（confusion matrix）就是这一切的"账本"：它把模型"预测对了多少、错在哪"一次性摊开，是所有分类指标的源头。

一、概念讲解#

1. 四个格子：TP / FP / FN / TN#

对于二分类问题，每个样本都有"真实标签"和"预测标签"两个维度，两两交叉就得到 4 种结果：

预测为阳性 预测为阴性
真实为阳性 TP（真阳性） FN（假阴性）
真实为阴性 FP（假阳性） TN（真阴性）

记忆口诀：首字母看"对不对"，第二字母看"判成了啥"。

  • TP（True Positive）：真的阳性，被判成了阳性 ✅
  • TN（True Negative）：真的阴性，被判成了阴性 ✅
  • FP（False Positive）：其实是阴性，被误判成阳性 ❌（"误报"）
  • FN（False Negative）：其实是阳性，被漏判成阴性 ❌（"漏报"）

FP 对应统计学里的第一类错误（弃真），FN 对应第二类错误（取伪）。在疾病筛查里，FN（漏诊）通常比 FP（误报）后果更严重。

2. 从混淆矩阵推导所有指标#

只要拿到这四个数，上一课的分类指标都能算出来：

准确率 accuracy = (TP + TN) / (TP + TN + FP + FN)   # 所有样本里判对的比例
精确率 precision = TP / (TP + FP)                    # 预测阳性里有多少是真阳性
召回率 recall    = TP / (TP + FN)                    # 真阳性里被抓到了多少
F1              = 2 * precision * recall / (precision + recall)

看懂了这张表，指标之间"此消彼长"的关系就一目了然：放宽判定标准，TP 和 FP 都会变多，于是召回率↑、精确率↓。

3. 多分类的混淆矩阵#

超过两个类别时，混淆矩阵就是一个 N×N 的方阵：第 i 行第 j 列表示"真实是第 i 类、却被预测成第 j 类"的样本数。对角线上的格子全是判对的，非对角线全是各类别之间的"串门"错误。

二、可运行示例#

示例 1：计算并读懂二分类混淆矩阵

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import confusion_matrix

# 乳腺癌数据集：标签 0=恶性、1=良性（这里把 1 当作"阳性"来演示）
X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0, stratify=y)

model = RandomForestClassifier(n_estimators=100, random_state=0)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# confusion_matrix 返回的二维数组，行=真实标签，列=预测标签
cm = confusion_matrix(y_test, y_pred)
print("混淆矩阵（行=真实，列=预测）：")
print(cm)

# 拆出四个格子（顺序为 TN, FP, FN, TP）
tn, fp, fn, tp = cm.ravel()
print("\n真阳性 TP =", tp)
print("假阳性 FP =", fp)
print("假阴性 FN =", fn)
print("真阴性 TN =", tn)

# 用公式手动推导各指标，与上一课的指标函数互相印证
total = tp + tn + fp + fn
print("\n准确率 =", round((tp + tn) / total, 3))
print("精确率 =", round(tp / (tp + fp), 3))
print("召回率 =", round(tp / (tp + fn), 3))

示例 2：把混淆矩阵画出来

import matplotlib.pyplot as plt
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0, stratify=y)

model = RandomForestClassifier(n_estimators=100, random_state=0)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# ConfusionMatrixDisplay 把混淆矩阵渲染成热力图，数字一眼可读
disp = ConfusionMatrixDisplay(
    confusion_matrix=confusion_matrix(y_test, y_pred),
    display_labels=["恶性", "良性"])
disp.plot(cmap="Blues")
plt.title("乳腺癌诊断混淆矩阵")
plt.show()
