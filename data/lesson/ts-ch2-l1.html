ARIMA#

ARIMA 是经典时间序列建模的"集大成者"：把自回归（AR）、差分（I）、移动平均（MA）三个构件拼在一起，用一组简洁的参数描述一条序列的依赖结构。这一课不满足于"调包跑通"，而是把每个构件的数学含义、平稳条件，以及"为什么差分能让序列平稳"讲透。

一、概念讲解#

1. 三块积木：AR、I、MA#

ARIMA 的名字就是这三块的缩写：AR（AutoRegressive，自回归）、I（Integrated，差分）、MA（Moving Average，移动平均）。先从最基础的一阶情形推导。

（1）AR(1)：用过去解释现在#

AR(1) 模型假设"当前值 = 常数 + 上一期的一部分 + 随机扰动"：

y_t = c + φ₁·y_{t-1} + ε_t，其中 ε_t ~ 白噪声(0, σ²)

参数 φ₁ 度量"过去的惯性"：φ₁ 越接近 1，序列越"黏"，今天和昨天越像。关键问题是：什么样的 φ₁ 让序列平稳？

把模型反复代入自身：

y_t = c + φ₁(c + φ₁ y_{t-2} + ε_{t-1}) + ε_t
    = c(1 + φ₁ + φ₁² + ...) + (ε_t + φ₁ ε_{t-1} + φ₁² ε_{t-2} + ...)

当 |φ₁| < 1 时，几何级数收敛，y_t 可以写成"无限个过去白噪声的加权和"，且权重 φ₁^k 指数衰减。由此能算出平稳分布的两个数字特征：

  • 均值：两边取期望，E[y_t] = c + φ₁ E[y_{t-1}]，平稳时 E[y_t] = E[y_{t-1}] = μ，解得 μ = c / (1 − φ₁)；
  • 方差：两边取方差，Var(y_t) = φ₁² Var(y_{t-1}) + σ²，平稳时方差相等，解得 γ₀ = σ² / (1 − φ₁²)。

结论：|φ₁| < 1 是 AR(1) 平稳的充要条件。φ₁ = 1 时方差公式分母为 0，序列退化成随机游走（非平稳）；|φ₁| > 1 则序列爆炸。这就是第 1 章"单位根"的完整数学来源。

ACF/PACF 特征：AR(1) 的 ACF 是 ρ(h) = φ₁^h，指数衰减（拖尾）；而 PACF 在滞后 1 之后截尾为 0（因为只隔 1 期的直接依赖已被完全捕捉）。推广到 AR(p)，规律是：ACF 拖尾、PACF 在 p 阶后截尾。

（2）MA(q)：用过去的冲击解释现在#

MA(q) 模型换了个视角，用"历史白噪声冲击"的加权和来描述当前值：

y_t = c + ε_t + θ₁ ε_{t-1} + ... + θ_q ε_{t-q}

注意 MA 里的 θ 作用在不可观测的冲击 ε上，而不是可观测的 y 上，这点与 AR 根本不同。MA(1) 的 ACF 是：ρ(1) = θ₁/(1+θ₁²)，ρ(h) = 0（h>1）——即 ACF 在 q 阶后截尾、PACF 拖尾，恰好与 AR 相反。这一"对偶"关系是后面识别阶数的重要抓手。

MA 还有一个对称性：θ₁ 和 1/θ₁ 会产生相同的 ACF，两者不可区分。为保证参数唯一可估计，要求模型可逆（|θ| < 1），此时 MA 也能写成无限阶 AR 的形式。可逆性与 AR 的平稳性是一组对偶概念。

（3）ARMA(p,q) 与差分 I#

把两者合并就是 ARMA(p,q)：

y_t = c + φ₁ y_{t-1} + ... + φ_p y_{t-p} + ε_t + θ₁ ε_{t-1} + ... + θ_q ε_{t-q}

用后移算子 B y_t = y_{t-1} 可写成紧凑形式：φ(B) y_t = θ(B) ε_t。ARMA 描述的是一个平稳序列的短期依赖结构；现实序列往往不平稳，于是引入差分：

y'_t = y_t − y_{t-1} = (1 − B) y_t

对序列做 d 次差分，若结果平稳，就称原序列是 d 阶单整（integrated of order d）。把这 d 次差分当作预处理，再对差分后的平稳序列套 ARMA，就得到 ARIMA(p,d,q)。多数业务序列 d = 0 或 d = 1 就够了；d=2 较少见，过度差分反而会引入人为的负自相关。

（4）季节性 ARIMA（SARIMA）#

当序列带季节（如月度数据周期 m=12），可在常规项之外再叠一组"季节差分 + 季节 AR/MA"，记为 SARIMA(p,d,q)(P,D,Q)m，其中大写 P,D,Q 是季节阶数、m 是季节周期。季节差分 (1 − B^m) y_t = y_t − y_{t-m} 去掉的是"今年 1 月与去年 1 月"之间的季节步长差异。

2. 为什么 ARIMA 值得"知其所以然"#

  • 三块积木各有可解释的物理含义：AR 是"惯性/均值回归"，I 是"去漂移"，MA 是"消化短期冲击"；
  • 平稳条件、可逆条件背后是特征根是否落在单位圆内这一统一判据——理解了它，你就明白 ADF 检验到底在检验什么；
  • ACF/PACF 的"截尾/拖尾"规律是手工识别阶数的依据，而自动定阶工具（第 3 课的 AIC 搜索）只是把这些规则自动化。

二、可运行示例#

用 statsmodels 拟合一个 ARIMA，看看参数估计与预测。

import numpy as np
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA

# 1) 先生成一条已知参数的 ARIMA(1,1,1) 序列，便于验证
rng = np.random.default_rng(11)
T = 200
e = rng.normal(0, 1, size=T)
y = np.zeros(T)
for t in range(2, T):
    # 差分后是 ARMA(1,1)：z_t = 0.6*z_{t-1} + e_t + 0.3*e_{t-1}
    z = 0.6 * (y[t-1] - y[t-2]) + e[t] + 0.3 * e[t-1]
    y[t] = y[t-1] + z  # 相当于再做一次积分(差分还原)

series = pd.Series(y)

# 2) 拟合 ARIMA(1,1,1)
model = ARIMA(series, order=(1, 1, 1))
fit = model.fit()
print(fit.summary())

# 3) 用拟合模型做 10 步预测（含 80% 预测区间）
forecast = fit.get_forecast(steps=10)
mean = forecast.predicted_mean
ci = forecast.conf_int(alpha=0.2)  # 80% 置信区间
print("\n未来 10 期预测均值：", np.round(mean.values, 2))
print("80% 预测区间下界：", np.round(ci.iloc[:, 0].values, 2))
print("80% 预测区间上界：", np.round(ci.iloc[:, 1].values, 2))

# 4) 打印估计的 AR/MA 系数，对比真实值 0.6 / 0.3
print("\n估计的 AR 系数：", np.round(fit.arparams, 3))
print("估计的 MA 系数：", np.round(fit.maparams, 3))

运行后，估计出的 AR 系数应接近 0.6、MA 系数接近 0.3——这验证了模型能从数据里"找回"真实参数。注意 summary() 里会给出 AIC、BIC 等信息准则，它们正是下一课选模型的依据。

三、练习#

  1. 把上面生成序列时的 d 改成 0（即直接生成平稳 ARMA），再用 ARIMA(series, order=(1,0,1)) 拟合，观察估计系数是否仍接近真实值。
  2. 分别拟合 order=(1,0,0)、(0,0,1)、(1,0,1) 三个模型到同一条数据，比较它们的 AIC，看哪个更小，并解释 AIC 越小代表什么。
  3. 手写推导：证明 AR(1) 平稳时 E[y_t] = c/(1−φ₁)，并说明为什么 φ₁ = 1 时均值公式失效。
  4. 思考：为什么说对平稳序列再做一次差分（d=1 其实不需要）会"过度差分"？它会怎样破坏 ACF 的形状？
