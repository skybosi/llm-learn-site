标注指南与一致性：把主观判断变成可复现的判据#

这一节要解决什么#

前三章处理的对象都有一个共同的隐含前提：标签已经在数据里了。第 1 章讲标签噪声如何改变模型行为，第 2 章讲清洗与去重，第 3 章讲配比与评测协议 —— 它们都在"给定标签"之后开始工作。这一章回到标签的源头：标签是谁产生的，以及它为什么会长成那个样子。

标注是数据管线里唯一由人参与的环节，因此它的失效模式和前面所有环节都不同。爬虫会失败并报错，解析器会崩溃，去重会给出可核对的数量；而标注不会。它产出的是一串看起来完全正常的数字，里面的错误系统、可复现、并且恰好会被"标注一致性"这个指标掩盖。一个团队可以拿到 κ=0.94 的一致性报告，同时它的正类召回只有 0.68 —— 本节的代码会实测出这两个数出现在同一份数据上。

所以这一节回答四个问题，每一个都给可计算的判据：

  1. 一份标注指南怎么写，才算"可判定"？ 可判定的标准不是"写得详细"，而是第三方能不能在不追问的情况下重放出同一个结论。这一条把"主观描述"和"判据"分开，也决定了指南必须以判例而不仅是定义为核心。
  2. 一致性怎么度量？ 从 po​ 到 Cohen κ、Fleiss κ、Krippendorff α，它们回答的是不同的问题，要求不同的数据结构，并且在不同的地方骗人。
  3. 一致性怎么提升？ 提升的正确动作是补判据，不是删掉有分歧的样本。本节代码量化这两条路线的差别，以及"分歧"作为判据缺口检测器的查准率与查全率 —— 后者只有 0.554，因为分歧检不出"一致地错"。
  4. 验收门槛怎么定？ "κ≥0.8"这种绝对门槛不可迁移；门槛应当从下游可容忍的噪声率反推，而反推需要额外声明一件事：κ 到噪声率的映射不唯一。

结论先放在这里：

一致性指标测的是"可复现性"，不是"有效性"。 两个标注者可以完全一致地错。因此一致性只是标注质量的必要条件，必须与外部效标（金标样本、下游评测）一起看；而"提高一致性"这个动作本身也有两种截然不同的做法 —— 补判据（提高可复现性）与删分歧样本（只是抬高这个数字）。

一、标注任务的形态，以及判据的结构#

1.1 先分清形态：判据的最小单位不一样#

不同标注任务的"一个决策"大小不同，指南的写法、一致性的算法、以及失败方式都随之改变。先把形态列清，后面才不至于拿分类任务的 κ 去套序列标注。

形态 一个决策是什么 判据的最小单位 合适的一致性度量 典型失效
二分类 / 多分类 整条样本一个标签 标签定义 + 边界条件 Cohen κ（2 人）/ Fleiss κ（多人） 类别定义重叠、稀有类被并类
序数 / 评分 整条样本一个等级 等级锚点 + 相邻等级的判例 加权 κ / 序数 α 等级锚点漂移（同一分数不同人理解不同）
序列标注 / 抽取 每个 span 的边界与类型 边界规则（含标点、含修饰语）+ 嵌套规则 按 span 对齐后算 α；边界一致性单独报 边界粒度不一致被"类型一致"掩盖
偏好 / 排序 一对（或一组）样本的相对关系 判据维度 + 平局规则 α（序数）+ 配对一致率 平局处理不一致、维度混用
生成 + 核验 一段文本是否满足若干条可核验断言 断言列表（每条可自动或人工判定） 逐断言一致率（不是整体 κ） 整体打分把"错一处"与"错五处"混为一谈

这张表最重要的一列是第四列。给序列标注报一个整体的 Fleiss κ 是常见的做法，也是常见的错误：它把"边界偏一个词"和"类型判错"混在一个数字里，而这两件事的修法完全不同（前者靠边界规则与判例，后者靠类型定义）。判据的最小单位决定了度量的最小单位。

1.2 可判定判据：标准是"能被重放"，不是"写得详细"#

给判据下一个可操作的定义：

一条判据是可判定的（decidable），当且仅当：对任意两个标注者、任意一条样本，只要他们都读了这条判据，就会得出同一个标签；如果得不出，判据必须给出下一步动作（弃权、升级、或"按第 k 条判例处理"）。

注意这个定义不要求判据"正确"，只要求它封闭：任何输入都有确定的出口。一条判据是否可判定，可以用一个便宜的实验测出来 —— 让两个没参与编写的人（关键：没参与编写）各标同一批 80 条样本，然后逐条问"你为什么这么标"。凡是被迫回答"感觉"或"我记得当时说的是"的条目，都是判据缺口。

把主观描述改写成可判定判据，是这个环节唯一的硬功夫。改写不是措辞问题，而是把一个判断分解成可观察的条件：

主观描述（不可判定） 为什么不可判定 改写成可判定判据
"这条评论是负面的" 没有给"负面"的载体（整体？某个方面？） "当评论中至少出现一个针对商品/服务的否定评价对象，且该对象的极性词属于词表 V（见附录）时，标负面"
"文本质量高" 质量是结果，不是可观察属性 拆成三条独立断言：语法是否可解析、是否含事实性错误、是否含被禁内容；每条独立标
"这条与上一条重复" 重复的粒度与阈值未定 "正文 shingle（k=5）的 Jaccard ≥0.8 → 重复；0.5∼0.8 → 标为灰区并升级"（阈值由第 2 章第 2 节的 PR 曲线定）
"答案是错的" 谁的标准算对 "答案与参考答案在数值上不一致 → 错；表述不同但数值一致 → 对；参考答案本身可疑 → 弃权"
"这段代码有 bug" bug 的定义未定 "f(输入)=期望输出 → bug；仅风格问题 → 否；输入未定义 → 弃权"

改写后的判据有一个共同特征：它们可以被写成 if 语句，或者可以指出一个能写成 if 语句的附录（词表、阈值、参考答案）。这不是巧合 —— 可判定性就是"可以被机械重放"，而机械重放的最小形式就是判定程序。

1.3 判据的四件套，以及"弃权"为什么必须存在#

一份完整的指南包含四部分，缺任何一部分都会在标注现场变成口头约定：

  1. 内涵定义：这个标签是什么。作用是让标注者建立原型。
  2. 边界与优先级：多个标签同时适用时谁赢。作用是消除顺序依赖（否则两人标注顺序不同 → 结果不同）。优先级表必须显式给出，因为它是判据里最容易被隐式假设的部分。
  3. 判例：正例、难负例（看起来像正例但不是）、以及灰区裁决。作用是覆盖定义的边界。难负例比正例重要得多 —— 正例是判据的用法演示，难负例才是判据的区分力所在。
  4. 弃权与升级路径：什么情况下不标，交给谁。这一条最常被漏掉，代价最大。

为什么弃权必须存在：如果判据不允许弃权，标注者面对没被覆盖的样本只有两个选择 —— 猜，或者按字面执行。前者注入随机噪声，后者注入系统性错误。第 1 章已经量化过这两种噪声的差别：随机噪声只让决策面线性压缩（排序不变），系统性错误可以让排序反转。允许弃权把"判据没覆盖"从一个隐藏错误变成一个可观测的数据点（弃权率与弃权样本的分布），这正是第 1 章"最贵的错误是静默错误"在标注环节的具体落法。

工程上还要给弃权定一个预算：弃权率过高说明判据不合格（不是标注者不合格），应当返回去改判据；经验上把弃权率控制在 2%∼5% 是比较健康的量级（低于此说明判据过宽、标注者在硬猜；高于此说明判据覆盖不足）。

1.4 指南版本必须绑到数据版本上#

承接第 2 章第 4 节的结论（内容指纹 + 管线版本 + 参数 = 数据版本），标注数据多出一个版本维度：指南版本。两批标签如果出自不同的指南版本，它们的一致性是不可比的，而且它们的混合会重新引入第 1 章讲过的"标注指南漂移"型噪声。

最小做法是把指南的摘要哈希写进每条标注记录的元数据：

record = {sample_id, annotator_id, label, guideline_hash, ts, abstained}

guideline_hash 的作用不是审计，而是筛选：任何时候你都可以问"我的训练集里混了几个指南版本"，并据此把老版本的数据重新标注、降权或丢弃。没有这一列，这个问题无法回答 —— 又一处静默错误。

二、一致性：从 po​ 到 κ 到 α#

2.1 观察一致率为什么不够：机会一致的基线#

设两名标注者在一批 n 个样本上的观察一致率为

po​=n1​i=1∑n​1[yi(1)​=yi(2)​]

po​ 有一个致命缺陷：它没有扣除"碰巧一致"。若两人各自以概率 p1​,p2​ 标正类，那么在完全独立（即没有任何共同判据）的零假设下，期望一致率是

pe​=p1​p2​+(1−p1​)(1−p2​)

Cohen κ 就是扣掉这个基线之后的相对一致率：

κ=1−pe​po​−pe​​

三个量的分工必须记牢：po​ 是事实（两人到底有多少条一样），pe​ 是基线（如果他们在瞎标，会有多少条一样），κ 是相对于基线的富余比例。报告里只给 κ 是不合格的 —— 因为 κ 是前两个量的商的函数，而不同的 (po​,pe​) 组合可以得到同一个 κ。

场景 po​ pe​ κ 这个 κ 说明什么
均衡二分类，两人很一致 0.90 0.50 0.80 判据可用
稀有类（正类 1%），两人原始一致 0.95 0.93 0.26 判据可能没问题，是基线太高
均衡二分类，两人几乎一致地错 0.97 0.50 0.94 判据不可用，但 κ 很高
三分类，两类实际是同一类 0.85 0.70 0.50 是标签体系的问题，不是标注者的问题

第三行与第四行分别对应本节代码的 C 段与练习 2 —— 它们说明 κ 必须与外部效标、与混淆矩阵一起读。

2.2 多标注者与缺失：Fleiss κ 与 Krippendorff α#

当标注者多于两人，或者存在缺失（不是每个标注者都标了每条），Cohen κ 就用不了。两个常用推广：

Fleiss κ：要求每个受试者被同样多的标注者标注，且无缺失。记第 i 个受试者被判为第 k 类的次数为 nik​，标注者数为 m：

Pi​=m(m−1)∑k​nik2​−m​,Pˉ=N1​i∑​Pi​,pk​=Nm1​i∑​nik​

κF​=1−∑k​pk2​Pˉ−∑k​pk2​​

Krippendorff α：允许缺失、允许不同受试者的标注者数不同、并允许不同的测量尺度。它的计算核心是巧合矩阵（coincidence matrix）ock​：

ock​=u∑​mu​−1nuc​nuk​​ (c=k),occ​=u∑​mu​−1nuc​(nuc​−1)​

α=1−De​Do​​,Do​=n1​c,k∑​ock​δ2(c,k),De​=n(n−1)1​c,k∑​nc​nk​δ2(c,k)

其中 nc​=∑k​ock​，n=∑c,k​ock​，δ2 是尺度相关的差异函数：名义尺度取 1[c=k]；序数尺度取 (∑g=ck​ng​−2nc​+nk​​)2；区间尺度取 (c−k)2。

三个必须说清的点：

  • De​ 的分母是 n(n−1) 而不是 n2，因为期望不一致是"从 n 个值里不放回地抽两个"的概率。这个 n/(n−1) 的差别就是 α 与 Scott's π（两名标注者情形下等于 Fleiss κ）的全部差别，它随 n 收敛 —— 本节代码 A 段把这条收敛性跑了出来（n=100 时差 0.0017，n=2×105 时差 0.00000）。
  • α 的序数差异函数用的是边缘计数，不是类别编号的算术差。所以"差一格"的严重程度由数据里该类别的频率决定 —— 这是一个建模假设，必须写清楚，因为在长尾类别上它会把"罕见类被误判"惩罚得极重。
  • α 的上界是 1，下界不是 0 而是 −1（理论上可以更负，取决于类别数与边缘）。出现负值说明系统性的反向不一致（比如两人的标签映射搞反了）—— 这与第 1 章第 1 节的"标注反转"是同一类事故，值得当作报警信号。

2.3 五个陷阱#

陷阱 1：prevalence 悖论。 在对称错误模型下，po​ 与正类比例 π 无关（因为"都对"与"都错"是仅有的两种一致情形），而 pe​ 随 π 剧烈变化。于是同样的标注质量在稀有类上得到低得多的 κ。本节代码 B 段实测：固定 po​=0.95，π 从 0.5 降到 0.01 时 κ 从 0.900 掉到 0.263。结论：κ 不能跨数据集、跨类别比较；要比较必须同时报 po​、pe​ 与混淆矩阵。

陷阱 2：一致性 = 有效性。 代码 C 段构造了一个反例：30% 的正类采用"否定式表达"，指南没写清楚，于是两个标注者用同一个错误判据把它们都标成负类。结果是

量 值
Cohen κ（两人之间） 0.9397
原始一致率 po​ 0.9720
对金标准的准确率 0.8230
正类召回 0.6805

κ 看起来很好，正类召回只有 0.68。没有金标样本时，"一致地错"与"一致地对"在数据上不可区分。 所以任何标注项目都必须保留一批外部锚点：金标题（有权威答案）、陷阱题（已知正确答案的边界样本）、以及最关键的一类 —— 由指南作者之外的人独立判定的抽样。

陷阱 3：把 κ 当连续量做算术。 κ 是比值，它的置信区间不随 κ 线性变化，且在 κ 接近 1 时强烈不对称。规则：不要对 κ 做平均（要平均就平均混淆矩阵），不要报告 κ 的点估计而不报区间。代码 E 段实测：600 个双层标注单元给出的 bootstrap 95% 区间仍有 ±0.06 的宽度；200 个单元时宽度近 0.20。用 κ 做验收门槛时，区间比点估计重要。

陷阱 4：加权的语义被忽略。 序数任务的加权 κ 里，线性权重把"差一格"的代价设成"差两格"的一半，二次权重设成四分之一。这不是技术细节，而是价值判断：二次权重在 1–5 分评分上，实际上是在说"4 分被标成 2 分"比"4 分被标成 3 分"严重四倍。写下权重时应当同时写下这个判断的依据，否则它是又一个隐性假设。

陷阱 5：用 α/κ 掩盖结构。 一个整体的 α=0.75 可能来自"所有类别都一般"，也可能来自"四个类别里三个 0.95、一个 0.2"。这两种情况的修法完全不同。必须按类别、按标注者、按时间段分别算一遍。

情形 用哪个 理由
2 名标注者、无缺失、名义尺度 Cohen κ 每人的边缘不同，κ 允许这种差异

最后一行值得强调：当任务可以分解成若干条可核验断言时，不要对整体打分算 κ。 逐断言一致率（以及"两人一致认为某条断言通过/不通过/不适用"的三值一致率）能直接指向判据的哪一条有问题，而整体 κ 只能告诉你"有问题"。

三、一致性怎么提升：分歧是信号，不是垃圾#

3.1 分歧分析闭环#

提升一致性的标准动作是一个闭环，四步：

① 聚合分歧      找出所有"标注者不一致"的样本（按分歧的严重程度排序）
② 聚类分歧      用文本/特征相似度把分歧样本聚成簇（常见：5~20 个簇）
③ 定位缺口      每个簇对应一条判据缺口（"这种情况指南没说"）
④ 补判据 + 复标 在指南里加判例（而不是加形容词），重标相关样本，再测 α/κ

这个闭环有一个必须被量化的前提：分歧是不是好的缺口检测器？ 代码 D 段把它测了出来。数据里有三种样本：70% 判据清晰、20% 落在指南没写的灰区、10% 是"否定式表达"（三人共享同一个错误判据）。以"三人不完全一致"作为缺口信号，结果是

指标 值 含义
查准率 0.767 被判为分歧的样本里，约 77% 确实是判据缺口
查全率 0.554 判据缺口里只有约 55% 会被分歧暴露出来

查全率只有 0.554 的原因正是陷阱 2：那 10% "一致地错"的样本没有任何分歧，分歧分析对它们是盲的。所以闭环必须补一条并行通道：独立锚点抽检（金标题 + 由外部人员判定的随机样本），专门用来抓"一致地错"。

3.2 提升路径的五层与它们的成本#

一致性提升有五个层级，成本从低到高，收益从大到小，但顺序不能颠倒：

层级 动作 成本 典型收益 什么时候不适用
1. 任务设计 把复合判断拆成原子判断；允许弃权 低 高（消除"一题多解"） 任务本身要求整体判断（如文风）
2. 判据与判例 补边界条件、优先级、难负例 低 高 判据已经饱和（分歧集中在主观量上）
3. 标注者 培训、认证考核、黄金集即时反馈 中 中 判据本身有缺口时，培训只是在强化错误
4. 流程 多人复核、仲裁、抽检 高 中（主要提升有效性而非一致性） 预算极紧；或分歧是合法信号
5. 建模 把分歧当软标签/当噪声率估计，而不是当垃圾 中 中（不改变原始质量，但改变损失函数） 需要重复标注作为前提

第 3 层有一个反直觉的顺序问题：先修判据，再培训标注者。 如果判据有缺口，培训会把标注者训练成一致地错——κ 上升，有效性下降。这是"κ 提升不等于数据变好"的最常见实现。

第 5 层值得单独说明：分歧本身携带信息。同一条样本被三人标成"1/1/0"，这个 0 不是噪声，而是"该样本确实落在边界上"的证据。可用的做法有三种：按多数投票但记录分歧度作为样本级元数据；用 Dawid-Skene 类的模型估计每个标注者的混淆矩阵并反推真标签；或者直接保留分歧、在训练时按分歧度降权。三者的共同前提是必须有重复标注。

3.3 "删掉分歧样本"为什么是错的（但要量化错多少）#

最省事的做法是把有分歧的样本整批丢掉，于是 κ 立刻变好看。代码 D 段把两条路线放在一起：

路线 α 全一致率 正类比例 hard 样本占比
第 1 轮（原始） 0.7017 0.7783 0.4983 0.3067
第 2 轮：补判据后复标 0.7867 0.8400 0.4983 0.3067
对照：删掉有分歧的 133 个单元 1.0000 1.0000 0.4989 0.1756

删样本路线的 α 是 1.0（因为留下来的全是三人一致的样本，这不是"变好"，这是定义），而它的真实代价是：hard 样本占比从 0.3067 掉到 0.1756，也就是说被删掉的恰好是模型最需要的那部分数据。更糟的是，这个副作用在正类比例上完全看不出来（0.4983→0.4989）—— 它是一处典型的静默损失。

判据：κ / α 上升本身不能作为目标。 补判据提升的是"这类样本以后能被一致地判定"；删样本提升的只是"这个数字"。区分方法很简单：问一句"被删掉/被改判的样本，以后还会不会是问题？"补判据的答案是"不会"，删样本的答案是"会，只是这次看不见"。

3.4 验收门槛怎么定#

"κ≥0.8"是业界流传的经验值，但它不可迁移，原因是第 2.3 节的陷阱 1 与陷阱 2：同样的 κ 在不同 prevalence 与不同有效性下意味着完全不同的数据质量。

可操作的定法是反推，三步：

  1. 先定下游可容忍的噪声率 εmax​。 这来自第 1 章第 1 节的机制：在对称噪声下，最优决策面被线性压缩，阈值化准确率的损失大致是 ε 的量级放大系数（取决于类别重叠），而 AUC 几乎不变。所以"能容忍多少 ε"取决于你的决策是否依赖阈值。
  2. 估 κ→ε 的映射。 这个映射不唯一：它取决于错误是随机的还是系统的、是否与特征相关。所以必须做一个小实验：在 200 条上人工注入已知噪声率，测 κ 怎么变（本节练习 5）。
  3. 写下区间而不是点。 门槛形如"κ≥0.75，且 95% 区间下界 ≥0.65，且正类召回 ≥0.85（用金标题测）"。

第 3 步里那个"且"很重要：κ 必须与至少一个有效性指标联合验收，否则陷阱 2 会一直开着。

四、取舍与边界#

取舍 一端 另一端 怎么选
判据粒度 定义驱动（写得多） 判例驱动（写边界） 优先判例；定义只负责建立原型
判据严格度 宽（判据覆盖少 → 弃权多） 严（硬判 → 系统性错误多） 让弃权率落在 2%∼5% 并监控其分布
标注人数 1 人（便宜，无法度量一致性） ≥3 人（能算一致性，成本×3） 先双标 200 条估 κ，再决定全量策略
分歧处置 多数投票（简单） 建模（Dawid-Skene） 先记录分歧度，等它在下游显现出作用再建模
一致性指标 κ（可跨人比） α（能吃缺失、多尺度） 有缺失或多于两人时直接用 α
验收门槛 绝对门槛（≥0.8） 从下游反推 必须反推；绝对门槛只在同类任务的同一数据上可比

三条边界：

  1. 一致性不能替代有效性，反之亦然。 前者是必要条件，后者需要外部锚点。缺少金标样本的项目，κ 再高也不能证明数据可用 —— 这一点在主观任务（风格、有用性、安全性）上尤其危险，因为这类任务天然存在合法分歧，其 κ 的上限本来就不高（常见 0.4∼0.7），此时追求高 κ 会强迫标注者放弃真实判断。
  2. 一致性提升有收益递减，且成本在流程层跳变。 从"没指南"到"有判据+判例"通常能一次提升 0.1∼0.2；从"有判例"到"多人复核+仲裁"只能再提 0.02∼0.05，而成本翻倍。先把判据写完，再考虑加人。
  3. 标注数据必须携带元数据。 至少四列：标注者 id、指南哈希、时间戳、是否弃权。缺少任何一列，第 1 章的"标注指南漂移"、第 2 章的"可复现"、以及本节的"按切片算一致性"都无法执行。

代码#

一段代码，五段，全部用合成数据（⚠️ 除 A 段的小例子是手算可核对的）：A 段先用手工可核对的小样本 + 三条可验证的恒等式对拍实现；B 段量化 prevalence 如何让 κ 崩塌；C 段构造"κ 高但正类召回低"的反例；D 段跑"分歧聚类 → 补指南 → 复标"的闭环，并把它与"删分歧样本"的代价对照；E 段给出 κ 的 bootstrap 区间与所需双层标注量。纯标准库，固定种子，可复现。

# -*- coding: utf-8 -*-
"""⚠️ 全部数据为合成数据（除 A 段的文献对拍数据集）。标注一致性：Cohen κ /
Fleiss κ / Krippendorff α 的分工与陷阱，以及"分歧聚类 → 补指南"的闭环。
纯标准库，固定种子，可复现。
"""
import math, random, statistics

# ---------------------------------------------------------------- 一致性度量

def cohen_kappa(a, b):
    """两名标注者的名义尺度 κ。返回 (kappa, po, pe)。"""
    n = len(a)
    po = sum(1 for x, y in zip(a, b) if x == y) / n
    pa, pb = sum(a) / n, sum(b) / n
    pe = pa * pb + (1 - pa) * (1 - pb)
    return (po - pe) / (1 - pe), po, pe


def fleiss_kappa(rows):
    """rows: 每个受试者的各类别计数，长度 N × K，每行和必须相等（无缺失）。"""
    N, K = len(rows), len(rows[0])
    m = sum(rows[0])
    P = [(sum(c * c for c in row) - m) / (m * (m - 1)) for row in rows]
    pbar = sum(P) / N
    p = [sum(row[k] for row in rows) / (N * m) for k in range(K)]
    return (pbar - sum(x * x for x in p)) / (1 - sum(x * x for x in p))


def krippendorff_alpha(units, level="nominal"):
    """units: 每个受试者一个列表，None 表示该标注者未标。支持缺失。
    level ∈ {nominal, ordinal, interval}。"""
    cats = sorted({c for u in units for c in u if c is not None})
    idx = {c: i for i, c in enumerate(cats)}
    K = len(cats)
    o = [[0.0] * K for _ in range(K)]
    for u in units:
        vals = [v for v in u if v is not None]
        m = len(vals)
        if m < 2:
            continue
        for i in range(m):
            for j in range(m):
                if i != j:
                    o[idx[vals[i]]][idx[vals[j]]] += 1.0 / (m - 1)
    n = sum(sum(r) for r in o)
    nc = [sum(o[i]) for i in range(K)]

    def d2(i, j):
        if level == "nominal":
            return 0.0 if i == j else 1.0
        if level == "interval":
            return float((cats[i] - cats[j]) ** 2)
        lo, hi = min(i, j), max(i, j)                      # ordinal
        s = sum(nc[g] for g in range(lo, hi + 1)) - (nc[lo] + nc[hi]) / 2.0
        return s * s

    Do = sum(o[i][j] * d2(i, j) for i in range(K) for j in range(K)) / n
    De = sum(nc[i] * nc[j] * d2(i, j) for i in range(K) for j in range(K)) / (n * (n - 1))
    return 1.0 - Do / De


def boot_ci(fn, data, B=400, seed=0):
    """对"受试者"做 bootstrap，返回 κ/α 的 95% 百分位区间。"""
    rng = random.Random(seed)
    n = len(data)
    out = []
    for _ in range(B):
        s = [data[rng.randrange(n)] for _ in range(n)]
        try:
            out.append(fn(s))
        except ZeroDivisionError:
            pass
    out.sort()
    return out[int(0.025 * len(out))], out[int(0.975 * len(out))]


# ------------------------------------- A. 手工可核对的小例子 + 恒等式对拍
print("=== A. 先手工核对一遍，再用恒等式验实现 ===")
tiny_a = [1, 1, 0, 0, 1, 0, 1, 1]
tiny_b = [1, 0, 0, 0, 1, 1, 1, 0]
kt, pot, pet = cohen_kappa(tiny_a, tiny_b)
n11 = sum(1 for x, y in zip(tiny_a, tiny_b) if x == 1 and y == 1)
n00 = sum(1 for x, y in zip(tiny_a, tiny_b) if x == 0 and y == 0)
print("  两名标注者 × 8 个单元：一致 %d 格（1-1 有 %d，0-0 有 %d），原始一致率 p_o = %.4f"
      % (n11 + n00, n11, n00, pot))
print("  边缘：标注者 A 的正类比例 %.4f，B 的 %.4f → p_e = p_A·p_B+(1-p_A)(1-p_B) = %.4f"
      % (sum(tiny_a) / 8, sum(tiny_b) / 8, pet))
print("  Cohen κ = (p_o-p_e)/(1-p_e) = (%.4f-%.4f)/(1-%.4f) = %.4f" % (pot, pet, pet, kt))

# 恒等式 1（可手算）：Fleiss κ（两名标注者、无缺失）= Scott's π，用的是"平均边缘"
tiny_rows = [[sum(1 for v in (tiny_a[i], tiny_b[i]) if v == c) for c in (0, 1)]
             for i in range(len(tiny_a))]
pbar = (sum(tiny_a) / 8 + sum(tiny_b) / 8) / 2
pi_scott = (pot - (pbar ** 2 + (1 - pbar) ** 2)) / (1 - (pbar ** 2 + (1 - pbar) ** 2))
print("  Scott's π（手算：边缘取两标注者的平均 %.4f）= %.4f；Fleiss κ = %.4f，差 %.1e"
      % (pbar, pi_scott, fleiss_kappa(tiny_rows), abs(pi_scott - fleiss_kappa(tiny_rows))))

# 恒等式 2（不是恒等式！）：α 与 κ 只差一个有限样本校正 n/(n-1)，随 n 收敛
print("  同一份数据上 α(nominal) = %.4f ≠ Fleiss κ = %.4f —— 差别是有限样本校正，会随 n 消失："
      % (krippendorff_alpha([[tiny_a[i], tiny_b[i]] for i in range(8)], "nominal"),
         fleiss_kappa(tiny_rows)))
rng0 = random.Random(5)
print("    %-9s %-10s %-10s %-10s" % ("n", "Fleiss κ", "α(nominal)", "｜差｜"))
for nn in (100, 1000, 10000, 200000):
    xa, xb = [], []
    for _ in range(nn):
        y = 1 if rng0.random() < 0.5 else 0
        xa.append(y if rng0.random() > 0.10 else 1 - y)
        xb.append(y if rng0.random() > 0.10 else 1 - y)
    rws = [[sum(1 for v in (xa[i], xb[i]) if v == c) for c in (0, 1)] for i in range(nn)]
    f, a_ = fleiss_kappa(rws), krippendorff_alpha([[xa[i], xb[i]] for i in range(nn)], "nominal")
    print("    %-9d %-10.4f %-10.4f %.5f" % (nn, f, a_, abs(f - a_)))

# 缺失：α 能用满全部单元，Fleiss κ / Cohen κ 必须整行丢弃
miss = [[1, 1], [2, 2], [3, None], [3, 3], [2, 1], [1, None], [4, 4]]
mc = [u for u in miss if None not in u]
mr = [[sum(1 for v in u if v == c) for c in (1, 2, 3, 4)] for u in mc]
print("  含缺失的数据：α(nominal) = %.4f（用满 %d 个单元）；Fleiss κ = %.4f（只剩 %d 个单元）"
      % (krippendorff_alpha(miss, "nominal"), len(miss), fleiss_kappa(mr), len(mc)))
print("  → 对拍过的三条：Fleiss κ ≡ Scott π（可手算）、α 与 κ 的差随 n 收敛、α 能吃缺失。")

# ------------------------------------------- B. prevalence 陷阱：p_o 固定，κ 崩
print("\n=== B. 原始一致率固定 95%，κ 随正类比例 (prevalence) 崩塌 ===")
TARGET_PO = 0.95
eps = (2 - math.sqrt(4 - 8 * (1 - TARGET_PO))) / 4      # 1-2ε+2ε² = 0.95
print("  对称错误率 ε = %.5f（由 (1-ε)² + ε² = %.2f 反解，故 p_o 与 π 无关）"
      % (eps, TARGET_PO))
print("  %-10s %-10s %-10s %-10s %s" % ("prevalence", "p_o", "p_e", "κ", "按 Landis-Koch 的档位"))
rng = random.Random(11)
def band(k):
    return ("几乎完全" if k >= 0.8 else "高度" if k >= 0.6 else
            "中等" if k >= 0.4 else "一般" if k >= 0.2 else "差")
for pi in (0.5, 0.2, 0.1, 0.05, 0.02, 0.01):
    pa = pi * (1 - eps) + (1 - pi) * eps
    pe = pa * pa + (1 - pa) ** 2
    k = (TARGET_PO - pe) / (1 - pe)
    # 经验模拟核对
    n = 40000
    A, B = [], []
    for _ in range(n):
        y = 1 if rng.random() < pi else 0
        A.append(y if rng.random() > eps else 1 - y)
        B.append(y if rng.random() > eps else 1 - y)
    ke, poe, _ = cohen_kappa(A, B)
    print("  %-10.2f %-10.4f %-10.4f %-10.4f %s（模拟 %.4f）"
          % (pi, poe, pe, k, band(k), ke))
print("  → 同样「95% 的原始一致率」，在 1% 正类上 κ 只有 0.26。跨数据集比较 κ 是无效的。")

# ------------------------------------- C. 高 κ ≠ 高准确率（大家一起错）
print("\n=== C. 反例：κ 接近 1，但相对金标准的准确率并不高 ===")
rng = random.Random(23)
N = 1000
latent, gold, a1, a2 = [], [], [], []
for _ in range(N):
    y = 1 if rng.random() < 0.5 else 0
    # 30% 的正类是"否定式表达"，指南没写清楚，两个标注者都按同一个错误判据标成 0
    trap = (y == 1 and rng.random() < 0.30)
    g = y
    lab = 0 if trap else y
    if rng.random() < 0.02:            # 2% 随机手误
        lab = 1 - lab
    latent.append(trap); gold.append(g); a1.append(lab)
    a2.append(lab if rng.random() > 0.03 else 1 - lab)
k, po, pe = cohen_kappa(a1, a2)
acc = sum(1 for g, p in zip(gold, a1) if g == p) / N
print("  Cohen κ(两人) = %.4f  原始一致率 = %.4f  对金标准准确率 = %.4f" % (k, po, acc))
print("  两人各自对金标准准确率 = %.4f / %.4f"
      % (sum(1 for g, p in zip(gold, a1) if g == p) / N,
         sum(1 for g, p in zip(gold, a2) if g == p) / N))
print("  正类上的召回（金标准正类被标成正的比例）= %.4f"
      % (sum(1 for g, p in zip(gold, a1) if g == 1 and p == 1) /
         max(1, sum(1 for g in gold if g == 1))))
print("  → κ 只测「可复现」，不测「有效」。没有金标样本时，一致地错与一致地对无法区分。")

# ------------------------- D. 分歧聚类 → 补指南 → 复标：κ 提升的闭环与代价
print("\n=== D. 指南缺口闭环：从分歧里找缺口，而不是从分歧里删样本 ===")
rng = random.Random(37)
NU, ANNO = 600, 3
kind, ytrue, ratings = [], [], []
for _ in range(NU):
    r = rng.random()
    k_ = "clear" if r < 0.70 else ("gray" if r < 0.90 else "negation")
    y = 1 if rng.random() < 0.5 else 0
    kind.append(k_); ytrue.append(y)
    row = []
    for _a in range(ANNO):
        if k_ == "clear":
            v = y if rng.random() > 0.03 else 1 - y
        elif k_ == "gray":
            v = y if rng.random() > 0.50 else 1 - y
        else:
            v = 0                          # 三人共享同一个错误判据
        row.append(v)
    ratings.append(row)

def alpha_of(rs):
    return krippendorff_alpha(rs, "nominal")

def agree_rate(rs):
    return sum(1 for r in rs if len(set(r)) == 1) / len(rs)

a0 = alpha_of(ratings)
disagree = [i for i, r in enumerate(ratings) if len(set(r)) > 1]
hit = [i for i in disagree if kind[i] in ("gray", "negation")]
prec = len(hit) / max(1, len(disagree))
rec = len(hit) / max(1, sum(1 for k_ in kind if k_ in ("gray", "negation")))
print("  第 1 轮：α = %.4f  全一致率 = %.4f  有分歧单元 = %d/%d"
      % (a0, agree_rate(ratings), len(disagree), NU))
print("  「用分歧找缺口」的查准率 = %.3f  查全率 = %.3f（真缺口 = gray + negation）"
      % (prec, rec))

# 路线①：补指南（对 gray 与 negation 都给出可判定判据）后复标
r2 = []
for i in range(NU):
    y = ytrue[i]; row = []
    for _a in range(ANNO):
        if kind[i] == "clear":
            v = y if rng.random() > 0.03 else 1 - y
        elif kind[i] == "gray":
            v = y if rng.random() > 0.12 else 1 - y        # 判据落地后大幅改善
        else:
            v = y if rng.random() > 0.15 else 1 - y
        row.append(v)
    r2.append(row)
a1_ = alpha_of(r2)
# 路线②：把有分歧的单元整批删掉（不做指南改进）
keep = [i for i, r in enumerate(ratings) if len(set(r)) == 1]
a2_ = alpha_of([ratings[i] for i in keep])
pos_all, pos_kept = sum(ytrue) / NU, sum(ytrue[i] for i in keep) / len(keep)
hard_all = sum(1 for k_ in kind if k_ in ("gray", "negation")) / NU
hard_kept = sum(1 for i in keep if kind[i] in ("gray", "negation")) / len(keep)
gray_all = sum(1 for k_ in kind if k_ == "gray") / NU
gray_kept = sum(1 for i in keep if kind[i] == "gray") / len(keep)
print("  第 2 轮（补指南后复标）：α = %.4f   全一致率 = %.4f" % (a1_, agree_rate(r2)))
print("  对照（不补指南，直接删掉有分歧的 %d 个单元）：α = %.4f" % (NU - len(keep), a2_))
print("  两条路线的副作用在哪个统计量上可见：")
print("    正类比例      %.4f → %.4f（删样本）   —— 几乎不变，查不出问题"
      % (pos_all, pos_kept))
print("    hard 样本占比 %.4f → %.4f（删样本）   ← 被删掉的正是最难的那部分"
      % (hard_all, hard_kept))
print("    其中 gray 桶 %.4f → %.4f" % (gray_all, gray_kept))
print("  → κ/α 上升本身不是目标：补指南提升的是判据的可复现性，删样本提升的只是这个数字。")

# ------------------------------------------ E. κ 的置信区间与所需双层标注量
print("\n=== E. κ 的不确定度：双层标注样本量 n 与 95% 区间的宽度 ===")
base = ratings
print("  %-8s %-10s %s" % ("n", "κ 点估计", "bootstrap 95% 区间（宽度）"))
for n in (50, 100, 200, 600):
    sub = [list(zip(*base))[0][:n], list(zip(*base))[1][:n]]
    pairs = list(zip(sub[0], sub[1]))
    kk = cohen_kappa(sub[0], sub[1])[0]
    lo, hi = boot_ci(lambda s: cohen_kappa([p[0] for p in s], [p[1] for p in s])[0],
                     pairs, B=300, seed=n)
    print("  %-8d %-10.4f [%.4f, %.4f]  宽度 %.4f" % (n, kk, lo, hi, hi - lo))
print("  → 600 个双层标注单元才把区间压到约 ±0.06；用 κ 当验收门槛必须带区间，且写清 n。")

实际输出（Python 3.14.5 / 纯标准库，固定种子）：

九处实现决策的理由：

  • A 段先做"手工可核对"再谈指标：κ 与 α 的差别极易被记成"两个差不多的数"。用 8 个单元的小例子把 po​、pe​、κ 一步一步打出来，读者才能自己验证后面的实现没有写反。
  • A 段用 Scott's π 做恒等式而不是拿 α 去对：两名标注者、无缺失、名义尺度下 Fleiss κ 恰好等于 Scott's π（因为 m=2 时 Pi​ 退化成"是否一致"的示性函数），这个恒等式可以手算验证。而 α 与 κ 不是恒等，只差一个 n/(n−1) 的有限样本校正 —— 代码把这条收敛性单独打了一张表（差 0.0017→0.00000）。把"近似"说成"恒等"是这一节最容易犯的错。
  • B 段的 ε 是从目标 po​ 反解的：ε=(2−4−8(1−po​)​)/4 解自 (1−ε)2+ε2=po​。这样做的好处是 π 变化时 po​ 精确不变，把"κ 随 prevalence 变化"这个效应孤立出来，而不是混进采样噪声。
  • B 段同时给解析值与模拟值：解析列用理论 pe​，模拟列用 40000 条样本重算。两者差在 0.01 量级（蒙特卡洛噪声），这个一致性本身是对实现的第二个检查。
  • C 段的陷阱是"共享判据"而不是"随机噪声"：随机噪声会同时压低 κ 与准确率，测不出"一致性掩盖有效性"这件事。只有让两人用同一个错误判据（否定式表达一律标负），才能造出 κ=0.94 与召回 0.68 并存的局面。
  • C 段报"正类召回"而不只报准确率：30% 的正类被系统性标错时，整体准确率只掉到 0.8230（因为负类占一半且全对），而召回掉到 0.6805 —— 后者才是这个缺陷的量级。
  • D 段的"删样本"路线故意保留 α=1.0：这不是为了好看，而是结论本身 —— 删到只剩全一致样本时 α 必然是 1，所以"α 升到 1"这件事不携带任何关于数据质量的信息。
  • D 段用正类比例与 hard 占比两个统计量做对照：正类比例几乎不动（0.4983→0.4989），hard 占比腰斩（0.3067→0.1756）。"哪个统计量能看见副作用"本身就是本节要教的东西。
  • E 段用 bootstrap 而不是解析方差：κ 的解析方差在 κ 接近 1 或类别极不平衡时近似很差；bootstrap 直接对"受试者"重采样，与后续的配对设计（第 3 章第 3 节）也更一致。代价是需要重算几百次，对小样本（n≤600）完全可接受。
  • ⚠️ 本段代码是教学实现：合成数据、二分类、标注者之间条件独立。真实标注里标注者的错误是相关的（同一份培训、同一种误读），相关错误会让 κ 高估数据质量 —— 代码 C 段就是这个现象的一个极端例子。α 的实现（巧合矩阵 + 序数差异函数）与真实工具一致，可以直接拿去对拍。

小结#

  • 标注的可判定性是第一位的。判据可判定 ⟺ 第三方能在不追问的情况下重放同一个结论 ⟺ 能被写成 if 语句或指向能写成 if 语句的附录。判例（尤其难负例）比定义重要；优先级表与弃权条件必须显式写出。
  • 一致性有三个概念层次：po​（事实）、pe​（基线）、κ（相对富余）。只报 κ 不合格；跨数据集比 κ 无效。
  • α 是唯一能直接吃缺失与多尺度的度量。它的 De​ 用 n(n−1) 做分母，与 Scott's π（两人无缺失时等于 Fleiss κ）只差一个随 n 收敛的校正 —— 代码实测 n=100 差 0.0017，n=2×105 差 0.00000。
  • prevalence 悖论是硬约束：固定 po​=0.95，正类比例从 0.5 降到 0.01 时 κ 从 0.900 崩到 0.263。同样质量的标注在稀有类上会得到难看得多的 κ。
  • 一致性 = 有效性：代码 C 段的 κ=0.9397 与正类召回 0.6805 并存。必须保留外部锚点（金标题、陷阱题、外部人员抽样），否则"一致地错"不可见。
  • 分歧是缺口检测器，但有盲区：查准率 0.767，查全率只有 0.554 —— 因为分歧对"一致地错"完全盲目。所以闭环要两条腿：分歧聚类 + 独立锚点抽检。
  • 提升一致性的正确顺序是判据 → 判例 → 培训 → 流程 → 建模。顺序颠倒（先培训后修判据）会制造"一致地错"，κ 上升而数据变差。
  • κ 上升不能作为目标：删分歧样本能把 α 抬到 1.0，代价是 hard 样本占比从 0.3067 掉到 0.1756，而正类比例（0.4983→0.4989）完全看不出这个损失。
  • κ 的不确定度不可忽略：600 个双层标注单元给出的 95% 区间宽度仍有 ±0.06；200 个单元时近 0.20。门槛必须带区间，且验收必须"κ 且 某个有效性指标"。
  • 验收门槛从下游反推，不从文献抄。三步：定可容忍噪声率 εmax​ → 用小样本实验估 κ→ε 的（非唯一）映射 → 写成"点估计 + 区间下界 + 效标"的三段式。

下一节：主动学习与抽样：不确定性、多样性与代表性的取舍 —— 指南与一致性解决的是"标得准"，但标注预算是有限的，所以还有一个更前置的问题：标哪些。下一节把"用最少标注拿到最大收益"写成可计算的采集准则，并给出主动学习什么时候有效、什么时候反而有害的可测条件（代码实测：在噪声与"难"重合时，不确定性抽样能省 53% 标注，但边界偏移误差从 0.349 恶化到 0.667，最终准确率反而更低）。
