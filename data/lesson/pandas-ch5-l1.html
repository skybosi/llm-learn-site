筛选与查询#

清洗干净的数据，通常还是"一整张表"。真正开始分析时，我们几乎总是先问一个问题：我只要其中满足某些条件的那些行——比如"华东地区、金额大于 100 的订单"。从 DataFrame 里按条件挑出想要的子集，就是筛选与查询，也是数据分析中使用频率最高的操作之一。

一、概念讲解#

1. 筛选的本质：布尔掩码#

Pandas 里筛选数据，靠的是一种非常统一的思想——布尔掩码（Boolean Mask）。

先看一个简单的比较运算：

df["金额"] > 100

这一句的返回值不是数字，而是一个和原 DataFrame 行数一样长的 Series，里面每个元素要么是 True（满足条件）要么是 False（不满足）。这个由真/假组成的 Series，就叫布尔掩码。

把它放进方括号里，Pandas 就只保留掩码为 True 的那些行：

df[df["金额"] > 100]   # 只保留金额大于 100 的行

整个筛选过程可以概括为三步：写出条件 → 得到布尔序列 → 用它当"筛子"过滤行。

2. 多条件组合：& | ~#

现实中很少只用一个条件。多个条件之间用以下符号连接，注意必须用括号把每个条件包起来，否则会因运算符优先级而出错：

符号 含义 例子
& 与（同时满足） (df["地区"] == "华东") & (df["金额"] > 100)
` ` 或（满足其一）
~ 非（取反） ~(df["状态"] == "已取消")

小陷阱：不要用 Python 的 and / or 连接条件，它们不能对整列做逐元素的逻辑运算，会直接报错。

3. 用 .loc[] 按标签或条件筛选#

.loc[] 既能按标签选，也能接受一个布尔序列。它的基本形式是 .loc[行, 列]：

df.loc[df["金额"] > 100, ["订单号", "金额"]]   # 筛选行，同时只保留两列

逗号左边是行条件（布尔掩码），右边是要保留的列。这样"筛行 + 选列"一步完成，非常常用。

4. 用 .query() 写出更易读的条件#

当条件很长时，用 & | ~ 写会越来越难读。.query() 允许我们把条件写成字符串，像查数据库一样：

df.query("金额 > 100 and 地区 == '华东'")

.query() 里可以用 and / or / not 这些更自然的词，也支持引用外部变量（加 @ 前缀），适合条件多、逻辑复杂的场景。

5. 三个好用的"条件函数"#

除了手写比较，还有几个现成的方法能快速表达常见条件：

  • isin(列表)：值在给定列表里；
  • between(a, b)：数值落在 [a, b] 区间内；
  • str.contains("子串")：字符串列包含某个片段（配合 .str 访问器）。

二、可运行代码示例#

先准备一份小的订单数据：

import pandas as pd

# 构造一份示例订单表
df = pd.DataFrame({
    "订单号": ["A01", "A02", "A03", "A04", "A05", "A06"],
    "地区":   ["华东", "华北", "华东", "华南", "华北", "华东"],
    "品类":   ["数码", "家居", "数码", "服饰", "美妆", "家居"],
    "金额":   [320, 88, 450, 199, 75, 260],
    "状态":   ["已完成", "已完成", "已取消", "已完成", "已完成", "待发货"],
})
print(df)

示例 1：单条件布尔筛选#

# 只看金额大于 100 的订单
big = df[df["金额"] > 100]
print(big)

示例 2：多条件组合 + 选列#

# 华东地区 且 金额大于 200，只保留订单号和金额两列
result = df.loc[(df["地区"] == "华东") & (df["金额"] > 200), ["订单号", "金额"]]
print(result)

示例 3：用 query 和条件函数#

# 1) query 写法：华东或华南地区，且状态不是"已取消"
q = df.query("地区 in ['华东', '华南'] and 状态 != '已取消'")
print(q)

# 2) 金额落在 100 到 300 之间
b = df[df["金额"].between(100, 300)]
print(b)

# 3) 品类属于指定列表
i = df[df["品类"].isin(["数码", "家居"])]
print(i)

三、练习#

  1. 在上面这份 df 里，筛选出"华北地区 且 金额小于 100"的所有行。
  2. 分别用 & | ~ 和 .query() 两种写法，实现"金额大于等于 200 或 状态为待发货"的筛选，比较两种写法哪个更易读。
  3. 找出"品类为数码、但状态不是已完成"的订单，并只输出"订单号"和"状态"两列。思考：这个需求用 & 和 ~ 各该怎么写？
