列表 list#

一、概念讲解#

列表（list）是 Python 中最常用的数据结构之一。你可以把它想象成一个"有编号的储物柜"：柜子里的每个格子都放着一件物品，物品之间互不影响，而且你可以随时取出、更换或增减格子里的东西。

列表有三个重要特点：

  1. 有序：元素按照你放入的先后顺序排列，每个位置都有固定编号。
  2. 可变：创建之后，你还可以增、删、改里面的元素。
  3. 可混合：同一个列表里可以同时存放整数、字符串、甚至另一个列表等不同类型的元素。

1. 创建列表#

列表用一对方括号 [] 表示，元素之间用逗号分隔：

# 空列表
empty = []

# 存放几个数字
scores = [90, 85, 72, 66]

# 混合类型
mix = [1, "hello", 3.14, True]

2. 索引与切片#

每个元素都有一个"门牌号"，称为索引（index）。索引从 0 开始，也就是说第一个元素的索引是 0，第二个是 1，以此类推。Python 还支持负数索引：-1 表示最后一个元素，-2 表示倒数第二个。

fruits = ["苹果", "香蕉", "橙子", "葡萄"]

print(fruits[0])   # 苹果
print(fruits[-1])  # 葡萄

切片（slice）可以一次取出多个元素，语法是 列表[起点:终点]。注意：终点位置的元素不包含在内。

nums = [10, 20, 30, 40, 50]

print(nums[1:3])   # [20, 30]，取索引 1 和 2，不含索引 3
print(nums[:2])    # [10, 20]，省略起点表示从头开始
print(nums[2:])    # [30, 40, 50]，省略终点表示一直到末尾

3. 修改元素#

因为列表可变，所以你可以直接通过索引给某个位置赋新值：

fruits = ["苹果", "香蕉", "橙子"]
fruits[1] = "西瓜"
print(fruits)  # ['苹果', '西瓜', '橙子']

二、可运行代码示例#

下面的代码涵盖了列表最常用的操作，建议你在自己的 Python 环境里完整运行一遍，观察输出结果。

# ---- 1. 创建与访问 ----
shopping = ["牛奶", "面包", "鸡蛋"]
print("购物清单：", shopping)
print("第一项：", shopping[0])
print("最后一项：", shopping[-1])
print("一共有几项：", len(shopping))

# ---- 2. 增加元素 ----
shopping.append("苹果")        # 在末尾追加一个元素
print("追加后：", shopping)

shopping.insert(1, "咖啡")     # 在索引 1 的位置插入
print("插入后：", shopping)

shopping.extend(["盐", "糖"])  # 把另一个列表的元素拼接到末尾
print("扩展后：", shopping)

# ---- 3. 删除元素 ----
shopping.remove("面包")        # 按值删除（删除第一个匹配的元素）
print("删除面包后：", shopping)

last = shopping.pop()          # 弹出并返回最后一个元素
print("弹出的元素：", last)
print("弹出后：", shopping)

del shopping[0]                # 按索引删除
print("按索引删除后：", shopping)

# ---- 4. 查找与统计 ----
scores = [88, 92, 88, 75, 88]
print("88 出现了几次：", scores.count(88))
print("92 的索引是：", scores.index(92))

# ---- 5. 排序与反转 ----
nums = [5, 1, 8, 3]
nums.sort()                    # 从小到大排序（原地修改）
print("升序：", nums)
nums.sort(reverse=True)        # 从大到小排序
print("降序：", nums)
nums.reverse()                 # 反转顺序
print("反转：", nums)

# ---- 6. 遍历列表 ----
for item in shopping:
    print("我要买：", item)

# ---- 7. 列表推导式（快速生成新列表）----
squares = [n * n for n in range(1, 6)]
print("1 到 5 的平方：", squares)
