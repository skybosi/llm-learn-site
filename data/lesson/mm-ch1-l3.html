为什么需要生成模型#

前面两课讲了生成模型"是什么"和"怎么学"。这一课回答一个更根本的问题：花这么大代价去学 P(x)、去造数据，到底图什么？ 我们从"判别式做不到的事"说起，铺开生成模型的真实应用版图，最后落到一个结论——扩散模型是当下把"高质量 + 可控 + 稳定"三者同时做好的最强者，这正是本课程后面两章的主角。

一、概念讲解#

1. 判别式的天花板：只能"判"，不能"造"#

判别模型 P(y|x) 的所有能力都锁定在"输入 → 标签"这条单向通道里。它回答不了这些问题：

  • 补全：一张照片被挡住一半，缺失的那半该长什么样？
  • 反推：给定一个模糊的低分辨率图，清晰版应该是什么？
  • 生成：没有输入，凭空造一张"不存在的猫"。

这些任务的共同点，是需要一个关于"数据本身长什么样"的完整先验，而不仅仅是"这条边界怎么画"。学 P(x)，就是把这种先验装进模型。

2. 真实价值：生成模型在干什么活#

生成模型的用途远不止"画图"，按"是最终产品还是中间件"分两大类：

作为最终产品（造内容）：

  • 图像/视频生成：文生图（Stable Diffusion、Midjourney）、文生视频、风格迁移；
  • 图像编辑与修复：inpainting（补残缺）、超分辨率（放大变清晰）、老照片上色；
  • 跨模态生成：文生图、文生语音、图生文，乃至多模态对齐（本课程第 4 章）。

作为中间件（服务别的任务）：

  • 数据增强：训练样本不够时，用生成模型造更多样本（尤其医疗影像、长尾类别）；
  • 表征学习与预训练：为了"造得好"而被迫学到的内部表示，可以迁移到分类、检测、分割——"先学会画，再学会认"；
  • 科学发现：分子结构、蛋白质构象、药物分子的逆向设计；
  • 世界模型：让智能体在"想象"中推演环境，是具身智能与机器人研究的前沿方向。

3. 为什么"现在"才爆发#

生成模型并不年轻（VAE 2013、GAN 2014、扩散模型的雏形 2015 年就出现了），但真正可用是近几年的事，三个因素叠加：

  1. 算力：训练/采样都需要大规模并行，GPU 集群把它变成可能；
  2. 数据：图文对、网页、视频等海量语料，让模型有东西可学；
  3. 架构与优化：Transformer 的通用骨架、更稳的训练技巧（谱归一化、更好调度等）让模型"训得动"。

4. 生成质量的三难：扩散模型的破局点#

历史上没有一个方法能同时拿到三样东西：

  • VAE：稳，但样本模糊（KL 项压平分布）；
  • GAN：锐利，但不稳、易模式坍塌，且无似然；
  • Flow：精确似然，但可逆约束压低了表达力。

扩散模型（DDPM / Stable Diffusion）破局的原因，可以提前剧透三句话：

  1. 训练目标极简且稳定：就是"预测噪声"，一个均方误差，没有 GAN 的对抗博弈，也没有 Flow 的可逆约束；
  2. 似然有下界可优化：它的训练目标是变分下界的简化形式（第 2 章第 3 课完整推导）；
  3. 多步采样换来质量：把"一步生成"拆成几百步小步的"逐步去噪"，每一步都容易学，合起来却能得到高质量样本。

它的代价只有一个：采样慢。于是有了第 3 章的"文生图 + 采样加速"——把扩散搬到潜空间（Stable Diffusion）并压缩采样步数，让它真正落地成产品。

二、可运行代码示例#

用 Hugging Face diffusers 亲手生成第一张图，直观感受"生成模型能造内容"。注意：首次运行会联网下载数 GB 权重，建议在 GPU 环境执行（CPU 也能跑，只是慢）。

from diffusers import DiffusionPipeline
import torch

# —— 加载一个预训练的文生图模型（首次运行自动下载权重） ——
pipe = DiffusionPipeline.from_pretrained(
    "stabilityai/stable-diffusion-2-1-base",
    torch_dtype=torch.float16,           # 半精度，省显存
)
pipe.to("cuda")                           # 没有 GPU 就改成 pipe.to("cpu")

# —— 输入一句自然语言，输出一张图像 ——
prompt = "a serene lake at sunset, oil painting, highly detailed"
image = pipe(prompt, num_inference_steps=25).images[0]
image.save("sunset.png")
print("已生成 sunset.png，打开文件查看图像")

这一段代码背后藏着一整条生成管线（第 3 章拆解）：文本 → 文本编码器 → 潜空间去噪 → 解码成图像。你现在只需建立两个直觉：

  1. 一句话就能造出一张从未存在的图，这是判别模型给不了的能力；
  2. 那个 num_inference_steps=25 就是扩散模型的"多步采样"，它正是"质量高但采样慢"这一权衡在代码里的显式体现。

三、练习#

  1. 在 diffusers 示例里把 prompt 换成"a glass of red wine on a table, studio light"，对比生成结果，体会文本条件如何控制生成内容（第 3 章深入）。
  2. 把 num_inference_steps 从 25 改成 5 和 50，观察图像质量与耗时如何随步数变化，说说"多步采样"为何既是优点也是成本。
  3. 思考题：判别模型能否通过"枚举所有像素组合 + 分类打分"来间接生成图像？为什么这条路走不通（提示：组合爆炸、P(x) 的维度）？
  4. 列出三个"生成模型作为中间件"的真实场景（例如医学图像增强），并说明每个场景里生成模型提供了判别模型给不了的价值。
  5. 写作题：用一段话论证"学习 P(x) 是获得智能的必要条件之一"，可以联系 LLM 的"预测下一个 token"（本质也是学 P(x)）。
