偏差-方差分解的完整推导#

上一课我们定义了偏差、方差、噪声三个概念。这一课证明机器学习里最漂亮的一个恒等式：期望泛化误差 = 偏差² + 方差 + 噪声。这不是经验规律，而是一个由数学严格推出的恒等式。我们一步一步推，每一步都不跳过，最终你会发现：推导过程本身，就是对"模型为什么失败"的最深刻解释。

一、概念讲解#

1. 记号与假设#

固定一个测试点 x，真实标签为 y，真实函数值为 f(x) = 𝔼[y | x]（即给定 x 时 y 的条件期望）。噪声定义为观测相对真实函数的偏差：

ε = y − f(x),  且 𝔼[ε] = 0,  Var(ε) = σ²

设模型 ĥ_D 是在随机训练集 D 上训练的，ĥ_D(x) 是它在 x 处的预测。为简洁，记：

ŷ = ĥ_D(x),    ŷ̄ = 𝔼_D[ŷ] = 𝔼_D[ĥ_D(x)]

ŷ̄ 是"所有训练集对应的预测的平均"。注意 ŷ 是随机变量（随 D 变），ŷ̄ 是常数。

2. 我们分解的量：期望平方误差#

我们关心的是期望预测误差——在随机训练集 D 与随机噪声 ε 的共同作用下，(y − ŷ)² 的平均值：

𝔼[ (y − ŷ)² ]

这里 𝔼 同时对 D（影响 ŷ）和 ε（影响 y）取期望。它是"换一个训练集、换一次观测，平均错多少"的严格刻画。我们的目标，就是把它拆成三块。

3. 第一步：加一项减一项，注入 ŷ̄#

经典技巧：往括号里"加 ŷ̄ 再减 ŷ̄"：

y − ŷ = y − ŷ̄ + ŷ̄ − ŷ = (y − ŷ̄) − (ŷ − ŷ̄)

于是：

(y − ŷ)² = [ (y − ŷ̄) − (ŷ − ŷ̄) ]²
         = (y − ŷ̄)² + (ŷ − ŷ̄)² − 2(y − ŷ̄)(ŷ − ŷ̄)

对两边取期望，得到三项：

𝔼[(y−ŷ)²] = 𝔼[(y−ŷ̄)²] + 𝔼[(ŷ−ŷ̄)²] − 2·𝔼[(y−ŷ̄)(ŷ−ŷ̄)]

下面逐项处理。

4. 第二步：交叉项为 0#

看交叉项 𝔼[(y − ŷ̄)(ŷ − ŷ̄)]。利用 y = f(x) + ε，拆开：

(y − ŷ̄)(ŷ − ŷ̄) = (f(x) + ε − ŷ̄)(ŷ − ŷ̄)
                  = (f(x) − ŷ̄)(ŷ − ŷ̄) + ε(ŷ − ŷ̄)

第一项：(f(x) − ŷ̄) 是常数（f(x)、ŷ̄ 都不随机），提出到期望外：

𝔼[(f(x) − ŷ̄)(ŷ − ŷ̄)] = (f(x) − ŷ̄) · 𝔼[ŷ − ŷ̄] = (f(x) − ŷ̄) · (ŷ̄ − ŷ̄) = 0

关键一步：𝔼[ŷ − ŷ̄] = 0，因为 ŷ̄ 就是 ŷ 的期望。

第二项：ε 与 ŷ 独立（噪声来自测试点的新观测，训练集 D 来自历史数据，二者独立），所以：

𝔼[ε(ŷ − ŷ̄)] = 𝔼[ε] · 𝔼[ŷ − ŷ̄] = 0 · 0 = 0

交叉项整体为 0。"加一项减一项"之后，那个交叉项之所以消失，靠的是 ŷ̄ 恰好是 ŷ 的期望——这是整个证明的枢纽。

5. 第三步：识别三个分量#

剩下两项分别识别：

  • 第一项 𝔼[(y − ŷ̄)²]：把 y = f(x) + ε 代入并展开：
𝔼[(y − ŷ̄)²] = 𝔼[ (f(x) − ŷ̄ + ε)² ]
             = (f(x) − ŷ̄)² + 𝔼[ε²] + 2(f(x) − ŷ̄)𝔼[ε]
             = (f(x) − ŷ̄)² + σ²

其中 (f(x) − ŷ̄)² = (𝔼[ŷ] − f(x))² 正是偏差平方 Bias²，σ² 是噪声。

  • 第二项 𝔼[(ŷ − ŷ̄)²]：直接就是方差 Variance。

6. 汇合：偏差-方差分解#

把上面全部拼起来，得到最终的恒等式：

𝔼[ (y − ŷ)² ] = ( 𝔼[ŷ] − f(x) )²  +  𝔼[ (ŷ − 𝔼[ŷ])² ]  +  σ²
              =  Bias²               +  Variance           +  Noise

这就是偏差-方差分解（Bias-Variance Decomposition）。对每个测试点 x 成立；再对 x 按输入分布取平均，就得到总体期望误差的分解：

总体误差 = 𝔼_x[Bias²(x)] + 𝔼_x[Variance(x)] + σ²

7. 这个恒等式说了什么#

逐项解读：

  • Bias² ≥ 0：模型类"平均而言"离真实函数多远。它由假设空间 ℋ 的表达能力决定，训练再多也无法消灭——除非换一个更大的 ℋ。
  • Variance ≥ 0：模型对训练集随机性的敏感度。由 ℋ 的复杂度与训练集大小共同决定，样本越多、正则越强，方差越小。
  • Noise = σ²：数据的固有随机性，与模型无关，任何算法都无法消减。

最关键的含义是权衡（trade-off）：Bias² 和 Variance 通常无法同时变小——模型一变复杂，偏差降、方差升，总误差走出一条 U 形曲线（下一课细讲）。"调参"的本质，就是在偏差与方差之间找到那个使总和最小的平衡点。

8. 一个易错点：前提条件#

这个分解式成立，前提是平方损失、以及我们用的是 f(x) = 𝔼[y|x]（回归设定）。对 0-1 损失（分类），"偏差² + 方差 + 噪声"的干净分解不再严格成立（有各种推广版本），但"偏差-方差权衡"的直觉依然成立。所以这个分解是理解泛化的最佳起点，但不是唯一终点。

二、可运行代码示例#

用代码验证这个恒等式：用蒙特卡洛方法，直接估计 𝔼[(y−ŷ)²]，再分别估计 Bias²、Variance、σ²，看三者之和是否等于前者。

import numpy as np

rng = np.random.default_rng(29)

def f(x):
    return np.sin(x)

x_test = 0.7
sigma = 0.3                       # 噪声标准差，σ² 已知
K = 5                             # 多项式阶数
N_trials = 2000

preds = np.empty(N_trials)
y_obs = np.empty(N_trials)
for t in range(N_trials):
    x = rng.uniform(-3, 3, size=40)
    y = f(x) + rng.normal(0, sigma, size=40)
    A = np.vander(x, K + 1, increasing=True)
    w = np.linalg.lstsq(A, y, rcond=None)[0]
    preds[t] = np.vander(np.array([x_test]), K + 1, increasing=True) @ w
    y_obs[t] = f(x_test) + rng.normal(0, sigma)   # 独立采样测试标签

# 蒙特卡洛估计三项 + 总和
total = float(np.mean((y_obs - preds) ** 2))
bias2 = float((preds.mean() - f(x_test)) ** 2)
var   = float(preds.var())
noise = sigma ** 2

print(f"直接估计的期望误差  𝔼[(y−ŷ)²] = {total:.6f}")
print(f"偏差²                Bias²     = {bias2:.6f}")
print(f"方差                Variance   = {var:.6f}")
print(f"噪声                σ²        = {noise:.6f}")
print(f"三者之和 = {bias2 + var + noise:.6f}")
print(f"吻合：{np.isclose(total, bias2 + var + noise, atol=1e-2)}")

输出会显示 𝔼[(y−ŷ)²] ≈ Bias² + Variance + σ²。蒙特卡洛的数值实验，与上一节逐行推导出的恒等式精确吻合——这不是"近似成立"，而是数学恒等式在有限采样下的统计表现。

三、练习#

  1. 把推导里的每一步都写一遍，特别是"交叉项为 0"那一步：说明为什么 𝔼[ŷ − ŷ̄] = 0，以及为什么 ε 与 ŷ 独立这两个条件缺一不可。
  2. 为什么分解式里的噪声项恰好是 σ²，而不是别的？推导 𝔼[(y − ŷ̄)²] 时，2(f(x)−ŷ̄)𝔼[ε] 这一项为何消失？
  3. 若把损失从平方损失换成绝对损失 |y − ŷ|，这个干净的三项分解还严格成立吗？为什么？（提示：中位数 vs 均值的性质）
  4. 思考：Variance 项在训练集大小 m → ∞ 时会怎样？Bias² 项呢？由此说明"增加数据"能解决哪类问题、不能解决哪类问题。

母原理连接#

本课是母原理 "概率视角统一" 的核心定理课。偏差-方差分解把"模型好不好"这个模糊问题，严格拆成了三个可计算的期望——它证明：泛化误差的全部秘密，就藏在"对随机训练集取期望"这个动作里。同时，它也为第 1 章"优化经验风险 ≠ 优化期望风险"提供了精确的数学解释：ERM 优化的是经验风险，而偏差-方差分解刻画的是期望风险的结构。下一课，我们用这条恒等式，一次性讲透"过拟合"与"欠拟合"。
