属性与方法#

一、概念讲解#

上一课我们知道了类是一张"图纸"，对象是"实物"。这一课深入看看图纸里到底装了什么：属性和方法。

  • 属性（attribute）：对象身上保存的数据，比如狗的名字、年龄。
  • 方法（method）：对象能做的事情，比如狗会叫、学生会自我介绍。

在类里面，方法其实就是"定义在类里的函数"，而属性就是"绑定在对象上的变量"。

1. 实例属性 vs 类属性#

属性分成两种：实例属性和类属性，这是初学者最容易混淆的地方。

  • 实例属性：属于每一个具体的对象，通常写在 __init__ 里，用 self.xxx 定义。每个对象可以有不同的值。
  • 类属性：属于整个类，直接写在类里面（方法外面），所有对象共享同一个值。
class Dog:
    species = "犬科"        # 类属性：所有狗共享

    def __init__(self, name):
        self.name = name    # 实例属性：每条狗不同

访问时两者写法一样，都用"点"：

d1 = Dog("旺财")
d2 = Dog("小黑")

print(d1.name, d1.species)   # 旺财 犬科
print(d2.name, d2.species)   # 小黑 犬科

它们的区别在于"改的时候"：

  • 修改实例属性，只影响这一个对象。
  • 修改类属性，会影响所有对象（以及后续新建的对象）。
d1 = Dog("旺财")
d2 = Dog("小黑")

d1.name = "旺财二号"      # 只改 d1 自己的名字
print(d1.name, d2.name)  # 旺财二号 小黑

Dog.species = "哺乳动物"  # 改类属性，所有对象都受影响
print(d1.species, d2.species)   # 哺乳动物 哺乳动物

2. 在方法里访问属性#

方法里通过 self.属性名 来访问和修改属性。这样对象才能"记住"自己的状态：

class Counter:
    def __init__(self):
        self.count = 0

    def add_one(self):
        self.count += 1     # 修改自己的属性

    def show(self):
        print("当前计数：", self.count)

c = Counter()
c.add_one()
c.add_one()
c.show()        # 当前计数： 2

3. 私有属性和命名约定#

Python 没有"真正私有"的属性，但有一套约定来提醒别人"这个属性别随便动"：

  • 名字前面加一个下划线 _name：表示"约定俗成请勿直接访问"，是一种礼貌提醒。
  • 名字前面加两个下划线 __name：Python 会把它改名（称为 name mangling），让它更难被外部直接访问，主要用来避免子类里的命名冲突。
class BankAccount:
    def __init__(self, balance):
        self._balance = balance   # 约定：请通过方法操作，别直接改

    def deposit(self, amount):
        if amount > 0:
            self._balance += amount

    def show(self):
        print("余额：", self._balance)

acc = BankAccount(100)
acc.deposit(50)
acc.show()        # 余额： 150

初学者先记住一点：属性通过方法去修改，比直接改更安全，因为你可以在方法里加校验（比如上面的"金额必须大于 0"）。

4. 给对象动态加属性#

Python 很灵活，允许给一个对象在创建之后再新增属性，但同一个类的不同对象可能因此"长得不一样"，容易出错，所以建议把属性都写在 __init__ 里统一初始化：

class Student:
    def __init__(self, name):
        self.name = name

s = Student("小明")
s.age = 18          # 动态新增，能运行，但不推荐
print(s.name, s.age)

二、可运行代码示例#

# ---- 1. 类属性与实例属性 ----
class Student:
    school = "未来小学"            # 类属性：全校共享

    def __init__(self, name, grade):
        self.name = name          # 实例属性
        self.grade = grade        # 实例属性

    def introduce(self):
        # 方法里访问自己的实例属性 + 类的类属性
        print(f"我是 {self.name}，来自 {self.school}，读 {self.grade} 年级。")


s1 = Student("小明", 3)
s2 = Student("小红", 5)

s1.introduce()
s2.introduce()

# ---- 2. 修改类属性 ----
Student.school = "新未来小学"       # 改一次，全校都变
s1.introduce()
s2.introduce()

# ---- 3. 方法修改属性 + 校验 ----
class Wallet:
    def __init__(self):
        self._money = 0           # 用下划线表示"请通过方法访问"

    def earn(self, amount):
        if amount > 0:
            self._money += amount
            print(f"赚到 {amount} 元")
        else:
            print("金额必须大于 0")

    def spend(self, amount):
        if 0 < amount <= self._money:
            self._money -= amount
            print(f"花掉 {amount} 元")
        else:
            print("余额不足或金额无效")

    def show(self):
        print("钱包余额：", self._money)

w = Wallet()
w.earn(100)
w.spend(30)
w.spend(999)     # 触发校验，不会扣钱
w.show()

三、练习#

  1. 定义一个 Circle 类：类属性 shape = "圆形"，实例属性 radius（半径），再写一个 area 方法返回面积（面积 = 3.14 × 半径的平方）。
  2. 创建两个半径不同的圆对象，打印它们的形状和面积，验证类属性是共享的。
  3. 定义一个 Account 类，用下划线开头保存余额，提供 deposit 和 withdraw 两个方法，withdraw 时要判断余额是否足够，不足则打印提示。
  4. 思考题：实例属性和类属性最大的区别是什么？如果两个对象都各自修改了自己的实例属性，会互相影响吗？为什么？
