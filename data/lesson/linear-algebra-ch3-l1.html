线性方程组的矩阵表示#

前两章我们分别学习了向量和矩阵，这一章把它们合起来解决一个经典问题：解线性方程组。你中学就解过 2x + 3y = 8 这样的方程，但机器学习里动辄成千上万个变量、成千上万个方程，必须用矩阵来统一处理。这一课先把"方程组"翻译成"矩阵语言"。

一、概念讲解#

1. 什么是线性方程组#

线性方程组就是一组"未知数只出现一次方、不相互乘除"的方程。比如：

2x + 3y = 8
4x -  y = 2

这就是一个含 2 个未知数、2 个方程的线性方程组。我们的目标是找到一组 (x, y)，让两个方程同时成立。

2. 写成矩阵形式：Ax = b#

任何线性方程组都能压缩成一句话：

A x = b

其中：

  • A 是系数矩阵：把所有未知数前面的系数按方程、按未知数排列成矩阵；
  • x 是未知数向量：把所有未知数排成一个列向量；
  • b 是常数向量：把每个方程等号右边的常数排成一个列向量。

上面的例子写成矩阵形式就是：

[ 2  3 ] [ x ]   [ 8 ]
[ 4 -1 ] [ y ] = [ 2 ]

即 A = [[2,3],[4,-1]]，x = [[x],[y]]，b = [[8],[2]]。

3. 增广矩阵：把 A 和 b 拼在一起#

解方程时经常把 A 和 b 拼成一个增广矩阵 [A | b]，在 A 右边加一列竖线，竖线右边放 b：

[ 2  3 | 8 ]
[ 4 -1 | 2 ]

后面做高斯消元时，我们对这个增广矩阵做行变换，就能同时"照顾"到 A 和 b。

4. 解的三种情况#

一个线性方程组可能有三种结局：

  • 唯一解：恰好一组 x 满足所有方程（最常见的"良态"情形）；
  • 无解：方程之间互相矛盾（比如 x+y=1 和 x+y=2 同时要求，不可能）；
  • 无穷多解：方程不够多，约束不了所有未知数（比如只有一个方程 x+y=1，却有两个未知数）。

判断哪种情况，正是后面高斯消元要解决的问题。

5. 机器学习中的应用：从"精确解"到"最小二乘"#

现实数据几乎永远有噪声，方程个数（样本数）和未知数个数（特征数）往往不匹配，所以通常不存在让所有方程都精确成立的解。这时我们不求 Ax = b 的精确解，而是求"误差平方和最小"的近似解：

minimize  ‖Ax - b‖²

这就是最小二乘。线性回归、曲线拟合都在解这个问题。上一章的正规方程 w = (XᵀX)⁻¹Xᵀy 就是它的解析解。

二、可运行示例#

下面用 NumPy 把方程组翻译成矩阵，并直接调用求解器得到答案。

import numpy as np

# 方程组：
#   2x + 3y = 8
#   4x -  y = 2
A = np.array([
    [2.0, 3.0],
    [4.0, -1.0],
])
b = np.array([8.0, 2.0])

# 1) 增广矩阵：把 A 和 b 横向拼接（np.column_stack 或 np.hstack）
aug = np.column_stack([A, b])
print("增广矩阵 [A | b] =")
print(aug)

# 2) 直接求解 Ax = b（底层用的正是高斯消元一类方法）
x = np.linalg.solve(A, b)
print("方程组的解 x, y =", x)   # 应为 [1, 2]

# 3) 验证：A @ x 应等于 b
print("验证 A @ x =", A @ x)

# 4) 现实场景：样本数 > 未知数，用最小二乘求近似解
# 5 条样本，拟合 y = 2*面积 + 1（带一点噪声）
X = np.array([
    [1, 80],
    [1, 95],
    [1, 110],
    [1, 125],
    [1, 140],
])
y = np.array([163, 190, 221, 248, 279])   # 大致符合 2x+1，但有噪声

# np.linalg.lstsq 返回最小二乘解
w, residuals, rank, sv = np.linalg.lstsq(X, y, rcond=None)
print("最小二乘权重 w =", w)   # 应接近 [1, 2]

预期输出（大意）：

增广矩阵 [A | b] =
[[ 2.  3.  8.]
 [ 4. -1.  2.]]
方程组的解 x, y = [1. 2.]
验证 A @ x = [8. 2.]
最小二乘权重 w = [0.99999999 2.        ]

要点：np.linalg.solve 只适用于"方阵且唯一解"的情形；当样本数多于未知数（现实常态）时，用 np.linalg.lstsq 求最小二乘近似解；np.column_stack([A, b]) 是把两个数组按列拼接成增广矩阵的常用写法。

三、练习#

  1. 把方程组 x + y + z = 6、2x - y + z = 3、x + 2y - z = 2 写成 Ax = b 的形式，并用 np.linalg.solve 求解。
  2. 用 np.column_stack 构造上面方程组的增广矩阵，并说明每一列分别代表什么。
  3. 用 np.linalg.lstsq 对你自己的 5 组"面积→房价"数据做最小二乘拟合，解释得到的两条权重分别是什么含义。
  4. 思考：为什么现实数据中"无解"比"有唯一解"更常见？结合噪声和数据量谈谈你的理解。
