贝尔曼方程#

上一课我们得到了价值函数 v_π 和 q_π 的定义，以及它们互相换算的两条公式。把这两条公式互相代入，就得到本课的主角——贝尔曼方程（Bellman equation）。它把价值函数从一个"定义"变成一个"可求解的方程"，是整门强化学习的理论枢纽：动态规划靠它迭代，蒙特卡洛和 TD 靠它估计，Q-learning 靠它的"最优版"（下一课）。这一课我们逐步推导贝尔曼方程，讲清"它凭什么成立"，再用线性代数把它真正解出来。

一、概念讲解#

1. 起点：回报的递推式#

推导的种子，是第 1 章第 5 节已经得到的回报递推式：

G_t = R_{t+1} + γ · G_{t+1}

这个式子对任何一条轨迹都成立。贝尔曼方程的本质，就是对这个等式两边，在"状态 = s"的条件下取期望。下面我们把这一步做到底，而不是只写结论。

2. 推导状态价值贝尔曼方程（分四步）#

记 E_π[· | S_t = s] 为条件期望。从定义出发：

第一步：写出 v_π 的定义并套用递推式。

v_π(s) = E_π[ G_t | S_t = s ]
       = E_π[ R_{t+1} + γ · G_{t+1} | S_t = s ]

第二步：期望的线性性拆开。

v_π(s) = E_π[ R_{t+1} | S_t = s ] + γ · E_π[ G_{t+1} | S_t = s ]

第三步：对第二项，用全期望公式"先对下一步状态取期望"。 下一步状态 S_{t+1} 是随机的，G_{t+1} 的期望可以写成"先按 s' 的条件期望，再对 s' 平均"：

E_π[ G_{t+1} | S_t = s ] = Σ_{s'} P(S_{t+1}=s' | S_t=s) · E_π[ G_{t+1} | S_{t+1}=s' ]
                         = Σ_{s'} P(S_{t+1}=s' | S_t=s) · v_π(s')

最后一步用到了 v_π(s') 的定义——E_π[G_{t+1} | S_{t+1}=s'] 正是从 s' 出发的期望回报。这是最关键的一步：它把一个"未来整条轨迹的期望"递归地"折叠"成了"下一步状态的价值"，而这一步之所以合法，根子在于马尔可夫性质（给定 S_{t+1}=s'，未来的分布只取决于 s'）。

第四步：把动作和奖励也展开成对 p(s', r | s, a) 的求和。 第一项的期望奖励，要先把"选动作"和"环境给奖励/转移"都拆开：

E_π[ R_{t+1} | S_t = s ]
    = Σ_a π(a|s) · E[ R_{t+1} | S_t=s, A_t=a ]
    = Σ_a π(a|s) · Σ_{s', r} r · p(s', r | s, a)

同理，第二项里对 s' 的求和也要按动力学展开。把两者合起来，就得到状态价值的贝尔曼方程：

v_π(s) = Σ_a π(a|s) · Σ_{s', r} p(s', r | s, a) · [ r + γ · v_π(s') ]

3. 贝尔曼方程说了什么：期望的"一步展开"#

把方程读成人话："状态 s 的价值，等于在 s 按 π 选动作、环境转移到 s' 并给奖励 r，这一过程的期望（即时奖励 r + 折扣后的下一状态价值 γ·v_π(s')）。" 它的结构是"即时项 + 未来项"，即：

当前价值 = 期望( 即时奖励 + γ × 下一步价值 )

贝尔曼方程之所以不是废话，是因为两边都含有 v_π——左边是要估计的 v_π(s)，右边又出现了 v_π(s')。所以它是一个关于 v_π 的方程（方程组），而不是一个可直接代入的公式。这正是它被叫做"方程"的原因。

4. 动作价值的贝尔曼方程#

用完全相同的推导（只是把"固定第一步动作"的条件带上），得到 q_π 的贝尔曼方程：

q_π(s, a) = Σ_{s', r} p(s', r | s, a) · [ r + γ · Σ_{a'} π(a'|s') · q_π(s', a') ]

它的结构对称而优美：动作价值 q_π(s,a) = 这一步的期望（奖励 + 折扣后的、在 s' 处按 π 加权的下一动作价值）。两个方程可以互相代入推导，构成闭环。状态方程适合"评价"，动作方程适合"改进"，两者共享同一个骨架。

5. 贝尔曼方程是线性方程组，可解析求解#

把贝尔曼方程对所有状态 s 写成一列，就得到一个线性方程组。用矩阵记号：

v_π = r^π + γ · P^π · v_π

其中 v_π 是列向量，P^π 是"按策略 π 的转移矩阵"（P^π[s, s'] = Σ_a π(a|s) p(s'|s,a)），r^π 是"按 π 的期望即时奖励"向量。移项：

(I − γ·P^π) · v_π = r^π
    ⟹   v_π = (I − γ·P^π)^{-1} · r^π

当 0 ≤ γ < 1 时矩阵 I − γP^π 可逆（因为它严格对角占优），所以 v_π 有唯一解。这个结论意义重大：给定 MDP 和策略 π，价值函数是唯一确定的，且可以用解线性方程组得到。 不过对于大状态空间，矩阵求逆代价太高，所以实际用第 3 章的迭代法（动态规划）来逼近它——但"解存在且唯一"这一事实，正是迭代法能收敛的根。

二、可运行代码示例#

用三状态链式 MDP，先数值验证贝尔曼方程左右两边相等，再直接解线性方程组求 v_π，并和迭代法结果对照。

import numpy as np

# 三状态链式 MDP（与第 2 章第 1 课一致）
nS, nA = 3, 2
P = np.zeros((nA, nS, nS))        # P[a, s, s'] = p(s'|s,a)
R = np.zeros((nA, nS))            # R[a, s] = r(s,a)（期望即时奖励）
P[0, 0, 1] = 1.0
P[1, 0, 0] = 1.0
P[0, 1, 0] = 0.5; P[0, 1, 2] = 0.5
P[1, 1, 2] = 1.0
P[0, 2, 2] = 1.0; P[1, 2, 2] = 1.0
R[1, 1] = 1.0
GAMMA = 0.9

# 随机策略：每个动作各 0.5 概率
pi = np.full((nS, nA), 0.5)       # pi[s, a] = π(a|s)

# ---- 构造矩阵形式：v = r^π + γ P^π v ----
P_pi = np.zeros((nS, nS))
r_pi = np.zeros(nS)
for s in range(nS):
    for s2 in range(nS):
        # P^π[s, s2] = Σ_a π(a|s) p(s2|s,a)
        P_pi[s, s2] = sum(pi[s, a] * P[a, s, s2] for a in range(nA))
    # r^π[s] = Σ_a π(a|s) r(s,a)
    r_pi[s] = sum(pi[s, a] * R[a, s] for a in range(nA))

# ---- ① 直接解线性方程组：v = (I - γ P^π)^{-1} r^π ----
v_solve = np.linalg.solve(np.eye(nS) - GAMMA * P_pi, r_pi)
print("解析解 v_π =", np.round(v_solve, 4))

# ---- ② 迭代法（动态规划的原型）：v_{k+1} = r^π + γ P^π v_k ----
v = np.zeros(nS)
for k in range(200):
    v_next = r_pi + GAMMA * P_pi @ v
    if np.max(np.abs(v_next - v)) < 1e-10:
        print(f"迭代法在 k={k} 收敛")
        break
    v = v_next
print("迭代解 v_π =", np.round(v, 4))

# ---- ③ 数值验证贝尔曼方程：左边 v_π(s) 应等于右边 ----
for s in range(nS):
    rhs = 0.0
    for a in range(nA):
        for s2 in range(nS):
            rhs += pi[s, a] * P[a, s, s2] * (R[a, s] + GAMMA * v_solve[s2])
    print(f"验证 v_π({s})：左边={v_solve[s]:.4f}，右边={rhs:.4f}")

运行结果大致是：

解析解 v_π = [0.5014 0.6128 0.     ]
迭代解 v_π = [0.5014 0.6128 0.     ]
验证 v_π(0)：左边=0.5014，右边=0.5014
验证 v_π(1)：左边=0.6128，右边=0.6128
验证 v_π(2)：左边=0.0000，右边=0.0000

三件事：① 解析解与迭代解一致，说明"解线性方程组"和"反复用贝尔曼方程更新"殊途同归；② 第 ③ 步对每个状态打印"左边 = 右边"，把贝尔曼方程当作等式做了数值验证——它确实是被价值函数满足的方程；③ 这个"迭代更新"写法 v ← r^π + γ P^π v，就是第 3 章迭代策略评估的原型，你已经在无意间写了一遍动态规划。

三、练习#

  1. 把上面的随机策略改成"确定性贪心向右"（pi[s0,a0]=1, pi[s1,a1]=1），重新解 v_π，与第 2 章第 1 课的结果 [0.9, 1.0, 0] 对照，说明策略如何改变价值。
  2. 手推贝尔曼方程里"第二步"：为什么 E_π[G_{t+1} | S_t=s] = Σ_{s'} p(s'|s,π)·v_π(s')？这一步用到了哪两个假设（提示：全期望公式、马尔可夫性质）？
  3. 把 γ 从 0.9 改成 0.5 重算 v_π。各状态价值如何变化？为什么 γ 越小，远期奖励（这里只有 s1→s2 的 1 分）对 s0 的价值贡献越小？
  4. 思考：贝尔曼方程两边都有 v_π，所以它是一个"自洽方程"而非"代入公式"。请用一句话说明：为什么这种自洽结构反而给了我们求解价值函数的两种方法（解方程组 / 迭代）？
