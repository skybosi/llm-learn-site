数据漂移与概念漂移：可判定的区分判据#

这一节要解决什么#

第 2 章把"该不该发"和"坏了怎么退"都做成了可算的东西。但它留了一个敞开的接口：那套判据全部是在离线数据上算的。上线之后，模型的输入分布会变、输入与标签的关系会变、上游的 schema 会变，而这些变化不会自己报告自己。

先看一个每天都会发生的场景：

周二 09:00 上线新版本
周三 10:00 业务方说："最近回答好像不太对"
周四 14:00 数据同学翻开监控：
   拒答率       0.012  →  0.013     （在阈值内）
   检索命中率   0.71   →  0.70      （在阈值内）
   平均延迟     820ms  →  815ms     （正常）
   输入 token 长度 p95   1.9k → 2.4k  （涨了 26%，但"这是业务在变"）
周五 18:00 还在争论：是模型坏了，还是业务变了？

两天时间，卡在一个问题上："漂移"这个词到底指什么？ 它至少指三件不同的事，而这三件事的处置方式完全不同：

说法 分布上发生了什么 正确处置
"输入分布变了" P(X) 变，P(y∣X) 不变 重新校准 / 阈值迁移 / 重加权；不用重训
"输入和标签的关系变了" P(y∣X) 变 必须重训；重加权救不了
"正例比例变了" P(y) 变，P(X∣y) 不变 先验校正 + 重训阈值；也不一定要重训

如果团队只会说"漂移了"，那么唯一可用的动作就是把模型重训一遍 —— 于是每次指标抖动都触发一次昂贵且不可控的重训，而真正需要重训的概念漂移可能混在噪声里被忽略。

所以本节要回答一个非常具体的问题：

给定线上的一批数据，怎么判定它属于上面哪一种？判据必须能算、能给出数值、能说"我判不出来"。

四个子问题：

  1. 这三种漂移在数学上如何区分？ —— 它们对应联合分布的三种不同分解，而且"不可识别"这句话有精确的边界：在没有因果结构的纯观测数据上，标签漂移与概念漂移确实不可分离；但一旦承认"采样机制"与"输入→标签的机制"是两个可以分开干预的东西，判据就出现了（§二）。
  2. 有哪些现成的统计量，各自在哪里失效？ —— PSI 在二值列上结构性失明（不是"弱"，是"错"）；KS 的临界值随 n 缩小，所以它只能用来报警不能用来下结论；MMD 能看见逐列看不见的依赖结构漂移（§三、§四）。
  3. 判据长什么样？ —— 本节给出两条：加权误差与源误差的相容性，以及源最优决策在重加权后是否仍最优。两条都只需要输入的密度比，不需要新标签（§五）。
  4. 没有标签怎么办？ —— 标签漂移可以用 BBS 从预测率反推先验；但它的分辨率被分类器的 TPR−FPR 放大，这个放大倍数决定了什么时候该先修模型而不是先查漂移（§七）。

一句话给本节定调：

"漂移"不是一个现象，而是一组断言。每个断言都必须能被单独检验，都要有它的统计量和它的失效条件。 判不出类型时，正确输出是"未判定"，而不是"漂移了，重训吧"。

一、先把词拆开：三种漂移对应的三个分解#

联合分布有两种经典分解，它们分别对应一组"哪一项变了"的问题：

P(X,y)=输入分布P(X)​​⋅条件分布P(y∣X)​​=先验P(y)​​⋅类条件分布P(X∣y)​​

于是"漂移"这个词可以被拆成三个可分别陈述的断言：

名称 断言 在哪个分解里看得见 典型原因
数据漂移（协变量漂移） Pnew​(X)=Pold​(X)，而 P(y∣X) 不变 前一个分解的第一项 流量构成变化、上游字段单位/量纲变化、季节与促销
概念漂移 Pnew​(y∣X)=Pold​(y∣X) 前一个分解的第二项 用户偏好变了、作弊策略变了、业务规则改了
标签漂移 Pnew​(y)=Pold​(y)，而 P(X∣y) 不变 后一个分解的第一项 正例率变化（退订潮、大促、渠道结构变化）

三者不是互斥的。现实里最常见的是叠加：流量构成变了（数据漂移），同时在新的流量里用户偏好也变了（概念漂移）。这正是第一节要处理的困难 —— "指标掉了"这一个观测，对应的是三种成因的任意组合。

1.1 为什么不能用"哪个统计量"来命名漂移#

一个流传很广的错误做法是：用 KS 检验 P(X)，用 PSI 看特征，用准确率看 P(y∣X)，然后把"KS 显著"叫作数据漂移、"准确率下降"叫作概念漂移。这混淆了"检验什么"和"怎么检验"：

  • 统计量检验的对象永远是某个分布，而不是某种漂移。同一个 KS 统计量，用在输入列上是数据漂移的证据，用在残差 y−p^​(X) 上是概念漂移的证据；
  • 反过来，同一个漂移类型可以用很多统计量检验（均值检验、KS、MMD、分类器两样本检验）。选哪个是功效与假设的问题，不是定义的问题。

所以正确的组织方式是：先写清楚零假设（哪个分布在变），再选统计量。本节的判据顺序也是这样安排：

§三 §四，只需输入H0​:P(X) 是否变了​​→§五，需要输入+少量标签H0​:P(y∣X) 是否变了​​→§七，只需预测输出H0​:P(y) 是否变了​​

1.2 一个必须先澄清的"不可识别"边界#

有一句常被引用的话："仅从 P(X,y) 无法区分数据漂移与概念漂移"。这句话是对的，但必须说清它成立的边界，否则会得出"所以没法区分"这个错误结论。

为什么在纯观测上不可识别：给定两个联合分布 Pold​ 与 Pnew​，我们可以把它们各自分解：

Pnew​(X,y)=Pnew​(X)⋅Pnew​(y∣X)=Pnew​(y)⋅Pnew​(X∣y)

"P(X) 变了但 P(y∣X) 没变，只是重加权恰好造成了一样的联合分布"与"P(y∣X) 真的变了"，在只观测到两个联合分布的样本时给出完全相同的似然。任何只看 P(X,y) 的检验都不可能区分这两种解释 —— 这不是统计功效不够，是信息不够。

边界在哪里：只要引入一个额外假设 —— 数据生成过程有两个可以分别干预的机制：

X∼P(X∣采样机制),y∼P(y∣X, 输入→标签机制)

那么两类干预在因果图上就是两个不同的节点：

干预 结果 对应漂移
do(采样)：只改采样/流量构成 P(X) 变，P(y∣do(X)) 不变 数据漂移
do(机制)：只改输入→标签的机制 P(y∣do(X)) 变（P(X) 可不变） 概念漂移

这就是不变性原理（invariance / invariant prediction）：跨环境稳定的不是 P(X)，也不是 P(y)，而是 P(y∣do(X)) 这一项。于是"概念漂移"有了一个不依赖具体分布的判据：

 若存在重加权 w(X) 使得 Pnew​(y∣X) 与该权重下的旧条件分布一致，则只是数据漂移；否则概念漂移 ​

注意这句话的可操作性：它说的不是"比较两个条件分布"（那需要知道 P(y∣X) 的函数形式），而是"看旧的最优决策在新分布下还是不是最优的"。§五 会把它变成两条真正能跑的检验。

1.3 "只看边际的监控"的盲区：一个反例#

在往下走之前，先确立一个贯穿全节的立场：逐列/逐边际的监控有结构性盲区。

构造：一个二变量输入 (x1​,x2​)，旧环境中两者独立，新环境中 x2​=0.85x1​+1−0.852​⋅ε。两个变量的边际分布完全没变（都还是标准正态），但联合分布已经面目全非。

这时：

  • 逐列 KS：x1​ 与 x2​ 的 KS 分别是多少？
  • 联合判据（MMD）能不能看出来？

代码里的实测（§四 的 [6]）给出答案：逐列 KS 两条都是 0.0000 与 0.0700（临界 0.0785，都不显著），而 MMD² = 0.04118，200 次置换里 0 次达到这个值（p≈0.000）。

这个反例说明："每个特征都正常"与"输入分布正常"是两句不同的话。任何只做逐列检验的监控体系，对"依赖结构变了"这一类漂移是全盲的 —— 而这一类漂移对模型的影响可以非常大（线性模型下它意味着决策面完全跑偏）。

二、为什么这样设计：把"漂移"写成带标准误的差值#

现在回答一个设计问题：判据为什么不写成"指标下降超过 10% 就报警"？

因为那是一个没有单位、没有误差量、也没有对照的阈值。"下降 10%"至少混进了三样东西：

  1. 抽样波动：线上每小时的样本量不同，同一份分布下"下降 10%"可能只是噪声；
  2. 输入分布变化的影响：输入变了，模型的表现当然会变，但这不说明模型坏了；
  3. 条件分布变化的影响：这才是真正需要重训的信号。

要分开这三样，判据必须写成"一个带标准误的差值"，并且这个差值必须是在扣除输入分布变化之后剩余的部分。这就是重要性加权的用途。

2.1 重要性加权：把目标域"搬回"源分布#

设源分布密度 p0​(x)、目标分布密度 p1​(x)。定义密度比

w(x)=p0​(x)p1​(x)​

那么在目标数据上对任意函数 f 有恒等式

Ep1​​[f(X)]=∫f(x)p1​(x)dx=∫f(x)w(x)p0​(x)dx=Ep0​​[w(X)f(X)]

反过来，如果我们在目标数据上按 w 加权，就得到源分布下的期望：

Ep0​​[f(X)]=Ep1​​[w(X)f(X)​]⟺∑i​wi​∑i​wi​f(xi​)​  目标样本 ​ Ep0​​[f]

最后那个式子是自归一化的重要性加权估计量（把权重归一化，省掉对 p0​,p1​ 归一化常数的依赖）。本节代码里的 weighted_error 用的就是它：

R^w​=∑i=1n​wi​∑i=1n​wi​L(xi​,yi​)​,L∈{0,1} 是 0-1 损失

这条式子的用途是诊断，不是训练：如果模型在目标域上的误差下降，仅仅是因为"输入搬到了模型擅长的区域"，那么加权之后误差应当回到源水平；如果加权之后误差仍然比源水平差一大截，那误差里就含有与输入分布无关的成分 —— 也就是条件分布变了。

2.2 两条判据，以及它们各自的标准误#

判据 ①（误差相容性）：设源误差为 R0​（在源数据上测得的同一个模型的误差），目标域上的加权误差为 R^w​。若

∣R^w​−R0​∣≤max(3SE(R^w​), εabs​)

则判"条件分布在采样误差内相容"。其中

SE(R^w​)=wˉn​sd(wi​Li​)​

εabs​ 是一个绝对下限（本节代码取 0.005）。它存在的原因很实际：当数值恰好接近 0 时，SE 也会接近 0，于是"3 个标准误"变成一个极小的窗口，抽样噪声会被当成信号。加绝对下限等价于承认"小于半个百分点的误差差，我们不关心"。

判据 ②（决策最优性）：把目标数据按 w 搬回源分布，重新求 0-1 风险最小的阈值 t^w​。若源域上重训出的最优阈值 t0​ 仍在 t^w​ 的邻域内（本节代码用 ∣tw​−t0​∣≤0.02），则判"源最优决策在新输入分布下仍最优"，即条件分布没变。

判据 ② 比判据 ① 更贴身，原因是三条：

  1. 它不依赖模型是否校准。模型自己在源域上可能就不是最优的（欠校准），但 ① 拿它当基线，于是把校准误差也算进了"相容性"。② 只问"源最优的决策还最优吗"；
  2. 它的量纲是决策阈值，不是误差率。阈值位移比误差率差值更容易解释、更容易设定"多大算大"；
  3. 它对小漂移更敏感。本节算例中，C 场景下误差差只有 0.0016（3.1 个标准误，勉强），但阈值位移是 0.300 —— 一目了然。

代价：判据 ② 需要一个可参数化的决策族（阈值、分位数、或者一个可重训的小模型）。对"输出是一段文本"的生成任务，没有单一阈值，这时只能用判据 ①，或者把判据 ② 改成"在某个人工标注的评分代理上求最优分位点"。

2.3 权重的代价：有效样本量#

重要性加权的估计精度不是由 n 决定的，而是由有效样本量决定的：

ESS=1+CV(w)2n​,CV(w)=E[w]sd(w)​

如果 w 的变异系数是 0.5，有效样本量就掉到 n/1.25≈0.8n；如果 CV 是 5，ESS 掉到 n/26。这是"漂移越大、加权诊断越不可用"的定量形式：漂移越大，p1​/p0​ 越极端，CV 越大，同一条判据的误差越大。

所以加权诊断有一个适用半径：它只在两个分布重叠良好的地方工作。本节算例中，C 场景的最大权重是 6.363、ESS 是 170345/200000（85%），还很好用；D 场景的最大权重 12.250、ESS 是 155475（78%），已经开始退化；若把均值位移再加大一两倍，ESS 会掉到几千，这条判据就该被放弃。

三、怎么做（一）：列类型决定判据#

有了"检验哪个分布"的框架，接下来是"用什么统计量"。这里最容易犯的错误是拿一个统计量套所有列。三个具体结论。

3.1 连续列：KS 只能报警，不能下结论#

两样本 Kolmogorov–Smirnov 统计量：

Dn,m​=xsup​​F^1​(x)−F^2​(x)​

在原假设 F1​=F2​ 下，D 的分布与分布形式无关（这是 KS 最大的优点），临界值的渐近形式是

Dcrit​≈n​1.36​(α=0.05, n=m)

注意 n 出现在分母上：n=1000 时临界值 0.0430，n=100000 时 0.0043 —— 缩小了 10 倍。这意味着同一份"0.2σ 的均值漂移"，在 n 大时必然显著。本节代码实测：

n 临界值 KS（同分布基线） KS（漂移 0.2σ） 判定
1000 0.0430 0.0480 0.1260 显著
10000 0.0136 0.0129 0.0712 显著
100000 0.0043 0.0049 0.0786 显著

三条读数：

  • 基线那一列也在临界值附近摆动（0.0480 就超过了 0.0430）—— 这是渐近临界值在有限样本下的实际水平（真实 α 略高于 5%），所以 KS 的"显著"必须当告警用、不当结论用；
  • 漂移那一列随 n 单调上升（0.1260 → 0.0786 是巧合，但都在临界值之上很远）。这印证了"大样本下 p 值必然显著"这条规律；
  • 显著 ≠ 重要。KS 的零假设是"两个分布完全相同"，它里面没有一个业务后果。要问"这个漂移伤不伤模型"，必须换一个零假设：§五 的加权误差就是那个零假设。

3.2 二值列：占比 z 检验，不要用 KS#

二值列（比如"检索未命中"标记）的全部信息在占比 p=Pr(X=1) 上。比较两个占比的标准做法是两样本比例 z 检验：

z=n0​p^​0​(1−p^​0​)​+n1​p^​1​(1−p^​1​)​​p^​1​−p^​0​​

本节算例：旧占比 0.0399、新占比 0.0546、n=20000，得 z=6.95、p=3.54×10−12 —— 毫不含糊。

同一列如果用 KS：实测 D=0.0147，而连续临界值是 0.0096。表面上看"1.5 倍临界值，也算显著"，但这个数完全取决于并列（ties）怎么处理：

  • 按"经验 CDF 只在观测值处跳"实现，跳的幅度是 Δp=0.0147，于是 D≈∣p^​1​−p^​0​∣；
  • 按"合并排序、逐个样本推进"实现，D 会被推到接近 1；
  • 连续情形的临界值 1.36/n​ 对离散分布不成立（KS 的分布无关性依赖连续性）。

所以结论不是"KS 太弱"，而是：二值列上 KS 的结论会随实现而飘，这个统计量在这里不适用。

3.3 PSI 在二值列上不是"弱判据"，是"错判据"#

PSI（population stability index）的通用形式是对箱比较：

PSI=b=1∑B​(pb​−qb​)lnqb​pb​​,pb​,qb​ 是两个分布在箱 b 里的占比

它的常用门槛是 <0.10 通过、>0.25 阻断。现在把它套到二值列上。

假设占比从 p0​ 变到 p1​，列只有两个取值，于是只有两个非空箱，PSI 精确地等于

PSI(p0​→p1​)=(p1​−p0​)lnp0​p1​​+((1−p1​)−(1−p0​))ln1−p0​1−p1​​

本节算例（p0​=0.0399→p1​=0.0546，相对变化 +37%）：

分箱方式 PSI
分 10 箱（9 个空箱，空箱对空箱贡献 1⋅ln1=0） 0.00487
正确分 2 箱 0.00487
同样幅度的漂移落在连续列（10 分位箱） 0.03392

0.00487 这个数离 0.10 的门槛差 20 倍。 用解析式可以看出这不是运气：两箱 PSI 满足

PSI≤∣Δp∣⋅​ln1−p0​p0​​​

算例里 ∣Δp∣=0.0147、∣ln(p0​/(1−p0​))∣=3.19，上界 0.04691。换句话说：在 p0​≈0.04 这种常见的小占比列上，两箱 PSI 的取值天花板就在 0.05 附近，0.10 的门槛永远不可能被触发。 相对变化 37% 在 PSI 里只值 0.005。

三条推论：

  1. PSI 的 0.10/0.25 门槛是"每箱至少有足够样本、且箱数较多"前提下才成立的经验值，套到低基数/二值列上立刻失效；
  2. 二值列要用占比 z 检验或卡方，它们对"占比变化"有正确的量纲；
  3. 给每一列写判据时必须先写下它的类型（连续 / 计数 / 二值 / 类别），判据随类型变 —— 这就是 ch2-l1 里"schema 全绿、模型必然变差"在监控侧的对应物。

四、怎么做（二）：从逐列到联合#

逐列检验还有第二个盲区（§1.3 的反例）：依赖结构的变化。补上它需要联合分布的检验。

4.1 MMD：两样本检验的"核"版本#

最大均值差异（MMD）把"两个分布是否相同"变成一个均值的比较。若 k(⋅,⋅) 是特征映射 ϕ 对应的核，定义

MMD2(P,Q)=​EP​[ϕ(X)]−EQ​[ϕ(Y)]​2

它的无偏估计只用样本两两核值：

MMD2=n(n−1)1​i=j∑​k(xi​,xj​)+m(m−1)1​i=j∑​k(yi​,yj​)−nm2​i,j∑​k(xi​,yj​)

关键性质：当且仅当 P=Q 时 MMD2=0（当核是特征核时）。所以它不需要指定"哪一项变了"，能同时抓住边际变化与依赖结构变化。

显著性用置换检验：把两组样本混起来反复随机对半分，看观测到的 MMD2 在置换分布里的位置。本节代码实测：

  • 逐列 KS：x1​=0.0000、x2​=0.0700，临界值 0.0785 —— 都不显著；
  • MMD2=0.04118；
  • 200 次置换中 0 次达到或超过观测值，p≈0.000。

4.2 MMD 的工程代价与替代#

MMD2 的朴素实现是 O(n2)，n=104 就是 108 次核计算 —— 在监控里不可行。三条替代路线：

方案 复杂度 代价
随机特征近似（RFF） O(nD)，D 取 100~1000 引入近似误差；D 要随 n 调
在降维后的表示上算（如嵌入向量的前 10 个主成分） 便宜 降维本身可能把要检测的方向丢掉
只对分片做联合检验（比如按业务线分组，组内做 MMD） 便宜 覆盖不到跨分片的漂移

工程上的实用组合是：逐列判据做第一层（便宜、可解释、覆盖大多数事故）+ 一个降维后的联合判据做第二层（覆盖依赖结构）+ 一个分类器两样本检验做第三层（最强功效，但需要一个模型）。三层不是冗余：它们的失效条件不同。

五、怎么做（三）：两条判据的完整流程与实测#

把前面拼起来，得到一个可执行的判定流程：

输入：源数据 D0（含标签）、目标数据 D1（可含少量标签，可完全没有）
① 若 D0 与 D1 的输入列类型已知：
     - 连续列 -> KS/均值检验（作为告警）
     - 二值/类别列 -> 占比 z 检验 / 卡方
     - 联合 -> MMD 置换检验
   目的：判断 P(X) 是否变了（不判断"哪种漂移"）
② 估计密度比 w(x) = p1(x)/p0(x)
     有标签：可用分类器估计（两样本分类，输出概率比）
     无标签：若假设"只是均值/尺度漂移"，可用高斯/指数族假设给闭式 w
③ 计算加权误差 R̂_w 与它的标准误；与源误差 R0 比较（判据①）
④ 在加权风险下重训阈值 t_w；与源域最优阈值 t0 比较（判据②）
⑤ 输出三态：只有 P(X) 变 / 条件分布也变了 / 证据不足

本节代码实现了 ②③④ 的全部步骤，并在四个受控场景上验证。场景设计（每个数字都能解析验证）：

  • 源域 X∼N(0,1)，真值规则 y=1[x>0.30]，t0​ = 在源域上重训出的最优阈值 =0.300；
  • 目标域 X∼N(a,1)，真值 y=1[x>b]。a=0 是数据漂移，b=0.30 是概念漂移，两者可以同时开；
  • 重要性权重用高斯闭式：w(x)=p0​(x)p1​(x)​=exp(−2(x−a)2​+2x2​)。

五条读数：

  2. C 行证明"误差更低"也可能是概念漂移。它的新误差 0.0597 与 B 行相同（甚至比某些情形更低），但加权误差高 0.0016（3.1 个标准误），而决定性信号是阈值被顶到 0.600（位移 0.300）。如果只看"指标有没有变差"，这一行会被完全漏掉。
  3. A 行是 B 行的对照组：同一组设计参数、换一批随机数、位移同为 0.000，给出"同一情景重复测一次"的波动量级 —— 大约 0.0004。判据的窗口（max(3SE, 0.005)）比这个大一个量级，所以不会误报。
  4. D 行的权重开始变尖：最大权重 12.250、ESS 掉到 155475（78%），判据仍然可用；但要意识到这正是适用半径的边缘 —— 漂移再大，CV(w) 会继续涨，ESS 会按 1/(1+CV2) 迅速塌缩。
  5. 判据 ② 的阈值位移是"定性的量"：0.300 和 0.400 这两个位移值不需要任何标准误就足以说服人。这也是为什么生产上优先实现判据 ②：它的读数抗噪、可解释、容易定门槛。

5.1 密度比怎么来：三种可得性#

判据 ②③④ 都依赖 w(x)。生产上有三条来源，成本与适用范围各不相同：

方法 需要什么 优点 失效条件
参数假设（高斯/指数族闭式） 只假设分布族 + 均值/尺度 便宜、稳定、无超参 假设错则 w 错，且不报错
判别式估计（训练"源 vs 目标"分类器，用输出概率比） 一份源样本 + 一份目标样本 灵活、能抓复杂漂移 分类器过拟合时会低估漂移；需要正则
域适配模型（KLIEP / 核均值匹配） 同上 + 核超参 直接优化权重质量 超参敏感、离线开销大

本节代码用第一条（闭式高斯），因为它让每一个数字都能手算验证 —— 这是教学代码应有的性质。生产系统里更常见的是第二条：两样本分类器的输出概率比就是 w 的估计。这也解释了为什么"训练一个'区分新旧数据'的分类器"是漂移检测里最常见的起点：它同时给出 w、给出"两个分布有多可分"（AUC），还可以用特征重要性告诉你"哪几个特征在贡献漂移"。

六、边界与取舍#

这一节给出的判据有明确的适用边界。把它们列清楚，比反复强调"要注意"更有用。

6.1 判据救不了的四类情形#

情形 为什么失效 替代动作
分布几乎不重叠 CV(w) 爆炸、ESS 掉到几十，加权估计没有意义 放弃加权路径，直接看"目标域上重训 + 与源水平对照"
需要检测的是多变量交互，而输入维度很高 密度比的估计误差随维度指数增长（维数灾难） 降维到任务相关的低维表示后再估 w；或只监控下游可观测指标
输出是开放式文本 没有单一的"最优阈值"或 0-1 损失 用代理指标（人工评分抽样、LLM 评审、用户反馈）上的分布判据
漂移是突发的（几分钟内切换） 本节判据是"两批样本比较"，需要一个稳定的参照批次 用 ch3-l3/l4 的序贯检测与变更事件对齐（把变更事件写进时间线）

6.2 两条判据的取舍#

判据 ①（误差相容） 判据 ②（阈值/决策最优性）
需要的额外假设 几乎没有（只要 w 与 0-1 或可分解损失） 决策族可参数化
对模型失校准的敏感性 高（把校准误差算进基线） 无
对小漂移的敏感性 低（误差率差值往往在小数第三位） 高（阈值位移是一阶量）
稀有事件的功效 差（正例太少，标准误大） 视决策族而定，通常更好
实现成本 低 中（需要重训/重估决策）
适合的场景 连续输出、有校准需求 阈值决策、排序截断、分档

实践建议：两条都算，以判据 ② 为主判据、判据 ① 为交叉验证。当两者不一致时（本节 C 行就出现了这种情况：① 刚好卡在边界、② 明确），以 ② 为准，并把 ① 的边界情况记下来作为"需要更多样本"的信号。

6.3 标签延迟：判据的时效边界#

概念漂移的判据需要标签，而标签往往延迟到达。设标签以速率 λ（单位时间到达比例）到达、平均延迟 D，则在漂移发生后的第 t 时间单位，仍缺标签的样本比例约为

fmissing​(t)≈e−λt

（泊松到达假设下的标准结论。）于是基于标签的判据有一个固有的"盲窗"：在 t≪1/λ 期间，任何标签依赖的判据都失效，只能靠无标签的判据 ① ② 与代理指标撑着。

数值例子：λ=0.08/小时（约 12.5 小时到达一半标签）、事件发生在 12 小时前，则 fmissing​=e−0.08×12=e−0.96≈0.383 —— 38% 的样本还没标签。这段时间里，判据 ②（无标签）是唯一可用的概念漂移信号。这从数量上说明了为什么"无标签的决策最优性检验"值得优先实现。

6.4 一个必须记住的结论#

三种漂移的处置动作不同，而它们的可判定性也不同：

只需输入，当天可算P(X) 可判定​​≻只需预测率，当天可算P(y) 可判定​​≻需要标签或强假设，慢P(y∣X) 可判定​​

监控体系的设计应当顺着这个顺序铺：最便宜、最快的判据先跑，把昂贵的判据留给"已经被怀疑"的时间窗。这也正是 ch3-l4 的排查路径要解决的问题。

"""
mlops-ch3-l1：数据漂移 vs 概念漂移的七个可运行实验。

① 基础函数自检：正态 CDF / 分位数 / 分箱统计
② KS 统计量与它的临界值随 n 缩小（显著 != 重要）
③ 二值列的判据：占比 z 检验 vs KS（列类型决定判据）
④ PSI 在二值列上结构性地看不见漂移（空箱 + 只有两个箱）
⑤ 四个实验：纯数据漂移 / 纯概念漂移 / 两者叠加 / 加权诊断量
⑥ MMD（置换检验）：只看边际会漏掉依赖结构的漂移
⑦ 标签漂移：BBS（黑箱移位估计）与加权准确率诊断量

运行：python3 /tmp/mlops_ch3_l1.py
⚠️ 全部为合成数据（random，固定种子），目的是让每个数字可复算。
"""
from __future__ import annotations

import math
import random
from bisect import bisect_left


# ==================================================================== 基础函数
def norm_cdf(x: float) -> float:
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))


def norm_ppf(p: float) -> float:
    """标准正态分位数：二分。不引入近似公式自身的误差（与 ch1-l4 同源）。"""
    lo, hi = -40.0, 40.0
    for _ in range(200):
        mid = (lo + hi) / 2.0
        if norm_cdf(mid) < p:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2.0


def mean(xs) -> float:
    return sum(xs) / len(xs)


def stdev(xs) -> float:
    m = mean(xs)
    return math.sqrt(sum((x - m) ** 2 for x in xs) / (len(xs) - 1))


def cdf_at(sorted_xs, v: float) -> float:
    """经验 CDF（<= v 的比例），用二分，纯标准库。"""
    return bisect_left(sorted_xs, v) / len(sorted_xs)


def ks_stat(a, b) -> float:
    """两样本 KS：在合并后的各观测点上比较经验 CDF。"""
    sa, sb = sorted(a), sorted(b)
    return max(abs(cdf_at(sa, v) - cdf_at(sb, v)) for v in set(sa) | set(sb))


def bin_counts(xs, edges, low, high):
    counts = [0] * (len(edges) + 1)
    for x in xs:
        if x <= edges[0]:
            counts[0] += 1
        elif x > edges[-1]:
            counts[-1] += 1
        else:
            i = 1
            while i < len(edges) and x > edges[i]:
                i += 1
            counts[i] += 1
    return counts


def psi(base, new, edges, low=-10.0, high=10.0) -> float:
    """PSI。空箱一律跳过 —— 这既是它的保护，也是它掩盖漂移的方式。"""
    a, b = bin_counts(base, edges, low, high), bin_counts(new, edges, low, high)
    na, nb = sum(a), sum(b)
    total = 0.0
    for ca, cb in zip(a, b):
        pa, pb = ca / na, cb / nb
        if pa > 0 and pb > 0:
            total += (pb - pa) * math.log(pb / pa)
    return total


def mmd2(xs, ys, kscale: float, seed: int = 7) -> float:
    """MMD^2 的无偏估计（高斯核）。O(n^2) 仅用于教学；生产用随机特征近似。"""

    def k(u, v):
        d = (u[0] - v[0]) ** 2 + (u[1] - v[1]) ** 2
        return math.exp(-d / (2.0 * kscale * kscale))

    def cross(a, b, skip_same):
        s = 0.0
        for i, u in enumerate(a):
            for j, v in enumerate(b):
                if skip_same and i == j:
                    continue
                s += k(u, v)
        return s

    n, m = len(xs), len(ys)
    return (cross(xs, xs, True) / (n * (n - 1))
            + cross(ys, ys, True) / (m * (m - 1))
            - 2.0 * cross(xs, ys, False) / (n * m))


def weighted_error(xs, ys, pred, w):
    """自归一化重要性加权误差：sum(w·L)/sum(w)。

    返回 (估计值, 标准误, 权重变异系数, 有效样本量, 最大权重)。
    """
    terms = [ww * (1.0 if pred(x) != y else 0.0) for x, y, ww in zip(xs, ys, w)]
    n = len(terms)
    m = mean(terms)
    se = stdev(terms) / (mean(w) * math.sqrt(n))
    cv = stdev(w) / mean(w)
    ess = n / (1.0 + cv * cv)
    return m / mean(w), se, cv, ess, max(w)

def weighted_argmin(xs, ys, w, lo=-3.0, hi=3.0, step=0.005):
    """网格上求加权 0-1 风险的最小值集，返回 (区间中点, 最小风险, 区间宽度)。

    O(n log n + G)：先按 x 排序建两张前缀和，于是每个候选阈值只需四则运算。
    直接把网格扫描写成 O(n·G) 也可以，但 2×10^5 样本上会慢到不可接受。
    """
    order = sorted(range(len(xs)), key=lambda i: xs[i])
    sxs = [xs[i] for i in order]
    sw = [w[i] for i in order]
    sy = [ys[i] for i in order]
    n = len(sxs)
    cum_w = [0.0] * (n + 1)
    cum_1 = [0.0] * (n + 1)          # 真值为 1 的累计权重
    for i in range(n):
        cum_w[i + 1] = cum_w[i] + sw[i]
        cum_1[i + 1] = cum_1[i] + (sw[i] if sy[i] == 1 else 0.0)
    tot = cum_w[n]
    grid = [lo + step * k for k in range(int((hi - lo) / step) + 1)]
    j = 0
    cand = []
    for t in grid:
        while j < n and sxs[j] <= t:
            j += 1
        left1 = cum_1[j]                       # 左侧（预测 0）里真值为 1 的权重
        right0 = (cum_w[n] - cum_w[j]) - (cum_1[n] - cum_1[j])   # 右侧（预测 1）里真值为 0 的权重
        cand.append((t, (left1 + right0) / tot))
    best = min(r for _, r in cand)
    argmin = [t for t, r in cand if r <= best + 1e-12]
    return (argmin[0] + argmin[-1]) / 2.0, best, argmin[-1] - argmin[0]

7.1 "标签漂移"这一段单独说明：BBS 的推导与它的条件数#

[7] 那一段实现了黑箱移位估计（black-box shift estimation, BBS）。推导只有三行。

设先验 ρ=Pr(y=1)，r=Pr(y^​=1) 是预测正例率，TPR,FPR 是既定分类器的两个率。条件 P(X∣y) 不变意味着模型在新数据上的 TPR、FPR 不变（它们只依赖类条件分布）。由全概率公式：

r=ρ⋅TPR+(1−ρ)⋅FPR

解出 ρ：

 ρ^​=TPR−FPRr−FPR​ ​

实测：TPR=0.8930、FPR=0.1023、线上预测率 r=0.2623。

估计量 估计值 偏差 标准误
直接拿预测率当初验 0.2623 0.0623 —
BBS：(r−FPR)/(TPR−FPR) 0.2024 0.0024 0.00124

真值是 0.2000，BBS 把它从 0.0623 的偏差压到 0.0024。

这个式子最值得记住的是它的分母。由 r 的标准误传播到 ρ^​：

SE(ρ^​)=TPR−FPRSE(r)​=TPR−FPRr(1−r)/n​​

1/(TPR−FPR) 是一个乘在标准误上的放大倍数（"条件数"）。实测它等于 1.265 —— 这个分类器足够强，所以 BBS 好用。但把它换成一个接近随机的分类器（比如 TPR=0.55,FPR=0.50），条件数变成 20 —— 同样 n 下标准误涨 16 倍，BBS 的结果就是噪声。

工程推论（本节最重要的一条顺序结论）：

当 BBS 的条件数很大时，正确的动作是先提升模型分辨率（或换一个与标签更相关的代理），而不是继续在漂移归因上投入。 归因工具的分辨率上限，是由被监控模型本身的分辨率决定的。

小结#

  • "漂移"要拆成三个可分别检验的断言：P(X) 变（数据漂移）、P(y∣X) 变（概念漂移）、P(y) 变（标签漂移）。三者的处置动作不同（校准 / 重训 / 先验校正），所以"漂移了"这句话在工程上没有用。
  • 不可识别有精确边界：只凭 P(X,y) 无法分离"重加权"与"条件分布变化"；但只要承认采样机制与输入→标签机制是两个可分别干预的节点，判据就出现了 —— 跨域稳定的是 P(y∣do(X))（不变性原理）。
  • 判据要写成带标准误的差值：加权误差 R^w​=∑wi​Li​/∑wi​ 与源误差的相容性（判据 ①，阈值 max(3SE,0.005)），以及"源最优决策在重加权后是否仍最优"（判据 ②，阈值位移 ≤0.02）。实测：B 场景误差差 −0.0017（−3.5 个 SE）、位移 0.000 → 只有 P(X) 变；C 场景位移 0.300 → 概念漂移。
  • 判据 ② 更贴身：它不依赖模型校准，量纲是决策阈值（一阶量，比误差率的小数第三位显眼得多）。实测 C 场景的误差差只有 0.0016（3.1 个 SE，勉强），而阈值位移是 0.300 —— 一目了然。
  • 权重的代价是有效样本量：ESS=n/(1+CV(w)2)。实测 D 场景最大权重 12.250、ESS 掉到 155475/200000（78%）—— 漂移越大这条判据越先失效，这就是它的适用半径。
  • 判据必须与列类型匹配：二值列用占比 z 检验（实测 z=6.95、p=3.54×10−12），不要用 KS（同一列 D=0.0147，结论随并列处理方式而飘）；PSI 在二值列上结构性失明：占比相对变化 +37% 的 PSI 只有 0.00487，而上界是 0.04691 —— 0.10 的门槛永远不可能触发。
  • 显著 ≠ 重要：KS 的临界值是 1.36/n​，n=1000 时 0.0430、n=100000 时 0.0043；一个 0.2σ 的均值漂移在小样本上就已显著，而它对模型的实际影响可能完全可忽略。KS 只配做告警。
  • 逐列监控有结构性盲区：构造"边际全不变、只改相关系数"的漂移（0.00 → 0.85），逐列 KS 是 0.0000/0.0700（都不显著），而 MMD² =0.04118、置换检验 p≈0.000。联合判据不是锦上添花，是补盲。
  • 标签漂移可以用预测率反推：ρ^​=(r−FPR)/(TPR−FPR)，实测把偏差从 0.0623 压到 0.0024。但 SE(ρ^​)=SE(r)/(TPR−FPR) —— 条件数 1/(TPR−FPR) 决定归因的分辨率（本节 1.265 好用；换成近随机分类器就是 20，归因结果全是噪声）。
  • 判不出来时要敢说"未判定"：本节所有判据都给了明确的失效条件（分布不重叠、高维、开放式输出、突发漂移）。把"未判定"当输出，比把"漂移了，重训吧"当输出安全得多。
