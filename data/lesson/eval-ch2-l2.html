基准饱和与数据污染：污染到底怎么检测#

这一节要解决什么#

一个公开基准的生命周期通常是：刚发布时很有区分度 → 分数逐年上升 → 头部挤在一起 → 名次靠噪声决定 → 榜单失去意义。 这个过程的两个驱动力是饱和（题目难度相对当前模型太低）与污染（题目/答案进了训练语料）。它们经常同时发生，而且症状相似：分数都很高。

这一节要做两件事：

  1. 把"饱和"变成一个可以算的量：用项目反应理论的题目信息量 I(θ)=a2P(1−P) 说明为什么题目难度偏离能力越远，信息量越低；给出"可排序区间"的判据（分差 vs 标准误）。
  2. 把"污染检测"讲成一套方法学：时间切分、n-gram 重合、诱饵串、扰动不变性、成员推断（Min-K% Prob）、生成式变体、训练侧审计——每一种方法的假设、能证明什么、不能证明什么，以及它们的误报来源。

这一节的立场很明确：污染无法被"彻底排除"，只能被"持续约束"。 因此真正的问题不是"有没有污染"，而是"在一个已知会被污染的世界里，如何做出仍然可靠的比较"。

饱和：方差被压缩之后，排行榜还剩多少信息#

现象与后果#

饱和的第一层后果是区分度消失：当所有模型落在 90%94%，模型间真实差异（通常只有 13 个点）被抽样噪声（第 1 章：SE=p(1−p)/n​）覆盖。第 1 名与第 5 名的差距可能小于 2 个标准误——此时"第 1 名更强"这个说法不可证伪。

第二层后果更隐蔽：饱和会让人误判进步速度。 从 60% 提到 65% 与从 94% 提到 95% 不是同一种进步。要看这有多不同，需要把分数映射回能力。

用信息量把饱和算出来#

对 2PL 模型，题目 j 在能力 θ 处提供的信息量是

Ij​(θ)=aj2​Pj​(θ)(1−Pj​(θ)),Pj​(θ)=1+e−aj​(θ−bj​)1​

它关于 P 的形状是一个倒抛物线，在 P=0.5 处最大，在 P→0 或 P→1 处趋近于 0。整份评测的总信息量是各题之和，而能力估计的标准误满足

SE(θ^)≈∑j​Ij​(θ)​1​

这条式子直接给出了"饱和为什么致命"的算术：

题的通过率 P P(1−P) 相对信息量（P=0.5 为 1）
0.50 0.250 1.00
0.80 0.160 0.64
0.90 0.090 0.36
0.95 0.0475 0.19
0.99 0.0099 0.04

从 P=0.5 移到 P=0.95，单题信息量掉到 19%⇒SE(θ^) 放大 1/0.19​≈2.3 倍

换句话说：一份 1000 题、通过率 50% 的评测，在饱和到 95% 之后，其能力分辨力只相当于原来 190 题。 而模型之间的能力差并没有变大——所以"榜单越靠前越乱"不是错觉，是信息量的必然。

同时，分数尺度本身也被压缩了。由 dθdP​=aP(1−P)，同样的能力差 Δθ 在 P=0.95 处产生的分数差只有在 P=0.5 处的约 1/5。这带来一个容易搞反的解读：饱和基准上的 1 个点分差，对应的能力差比未饱和基准上的 1 个点更大——但它的测量噪声占比也更高。 两者相抵，净效果是"分差不可解释"，所以正确做法不是"更仔细地看小数点"，而是换更难的题。

饱和的两种成因要分开#

分数高可能是能力真的强，也可能是题目被污染。两者在总分上长得一样，但在项目层面的模式不同：

现象 更支持 怎么区分
分数均匀上升，跨多个基准一致 能力提升 换新基准后仍高
某基准异常高、其它基准正常 污染（该基准进了语料） 扰动实验、n-gram 比对
0-shot 突然接近 few-shot 污染 时间切分、成员推断
难题正确率异常高、简单题不高 污染（难题本来稀有，被"记住"的信号更亮） 逐题分析 + 语料比对

最后一条值得展开：污染在"稀有题"上的信号最强。一道常见题的正确率提升可以被能力提升解释；一道全世界只有基准数据集中出现过的问题被答对，几乎只有两种解释——记住，或者运气。所以污染审计应该优先看低通过率题目的答对率，而不是看平均分。

污染：定义、分层与传播路径#

四层污染#

层次 定义 后果
输入污染 题干出现在训练语料 模型"见过题"，可能在推理前就知道方向
标签污染 题干 + 标准答案一起出现 最严重：可以直接输出答案
模板污染 评测使用的提示模板/系统提示出现在语料 模型对特定模板过拟合，换模板即掉分
测试集过拟合 反复用同一测试集调参、选 checkpoint、选提示 不需要任何语料泄漏，全靠"多试几次"实现

前三层是"数据泄漏"，第四层是"纪律泄漏"。第四层最普遍且最容易被忽视，因为它是评测方的行为而非模型方的行为：一个团队在同一个测试集上试 200 个提示，取最好的报出去，本质上已经完成了对测试集的拟合（第 1 章第 4 节的"分叉路径"）。

传播路径#

公开基准发布（网页/arXiv/代码仓库）
   ├→ 网络爬取（题库站、GitHub、论坛提问）→ 预训练语料
   ├→ 开源数据集聚合（HF datasets 等）→ 微调/SFT 语料（最常见）
   ├→ 蒸馏/合成数据（用强模型在基准上生成答案）→ 训练语料
   └→ 评测方自己的调参循环 → 测试集过拟合

其中最危险的是第二条：SFT 语料经常由"公开数据集的混合"构成，而基准数据集本身就在里面。很多污染并非有意，而是数据集管理不善的副产品。

污染检测的六类方法#

以下六类方法可以组合使用。每一类都只能提供"证据"，不能提供"证明"——这是本节最重要的元认知。

方法一：时间切分（temporal split）#

做法：只使用模型知识截止日期之后发布的题目（或数据），例如按月份滚动更新的"live"基准。

能证明什么：如果模型在截止日期之后的题上表现显著低于截止之前，是一个有力的污染信号（尽管也可由分布差异解释）。

边界：

  • 需要知道（或可靠推断）训练数据的截止日期；闭源模型通常只给一个粗略日期；
  • 截止日期之后的数据不保证没被收（部分训练管线会持续更新数据）；
  • 新题更少、更偏、难度分布可能不同——不能直接和旧基准的分数比。

方法二：n-gram / 子串重合#

做法：把评测题目的文本切成 n-gram（常用 n=13 或更长，短于 8 会大量误报），与（可见的）训练语料比对，统计重合比例：

overlap(x)=#{n-gram∈x}#{n-gram∈x:n-gram∈corpus}​

也可用最长公共子串（LCS）长度作为补充。

能证明什么：有重合 = 确实存在泄漏路径（这是硬证据）；无重合 ≠ 没泄漏（模型可能只记住了语义，或以改写形式收录）。

边界：

  • 需要训练语料 → 对闭源模型根本不可用；
  • 改写、翻译、格式转换可以规避精确 n-gram 匹配；
  • 阈值的选择影响很大：太高漏报，太低把"常识短语"也算成泄漏（因此通常要排除高频 n-gram）。

方法三：诱饵串（canary / decoy）#

做法：在基准数据文件中嵌入一段不自然、唯一的字符串（BIG-bench 的 canary GUID 是业内最常被引用的一例），并配合一句明确的声明"本数据不应出现在训练语料中"。然后测试模型能否逐字复现这段诱饵。

能证明什么：能复现 → 该数据（至少该文件）在训练语料中。

边界：

  • 它是泄漏探测器，不是防泄漏机制。没有任何机制能阻止爬虫收录一个公开文件；
  • 模型可能见过但复现不出来（采样、格式）；
  • 需要设计得足够"不自然"以免模型靠语言模型先验猜出（GUID 类字符串满足这一点）。

方法四：扰动不变性（perturbation invariance）#

做法：对同一道题做不改变解题结构的扰动，比较扰动前后的正确率：

扰动 不改变什么 改变了什么
替换人名/地名/单位 数学结构 表面实体
替换关键数字（保持可解） 题型与解法 具体计算
加入无关从句 解题所需信息 上下文噪声
打乱选项顺序 正确选项内容 位置

判据：定义扰动敏感度

PS=Accorig​Accorig​−Accpert​​

原始分高 + 扰动掉分大 = 记忆/模式匹配的强信号；原始分中等 + 扰动稳定 = 更可能是真推理。

边界（必须警惕）：

  • 扰动可能把题目变成分布外样本。原生表现本来就脆弱的模型（例如对措辞敏感的小模型）也会掉分，这与污染无关；
  • 因此扰动实验需要对照组：拿一个肯定不可能见过该基准的模型（自训小模型 / 时间切分模型）做同样扰动，比较两组的掉分幅度；
  • 关键数字的替换会改变难度，需要重新校准难度分布（否则掉分可能是"变难了"）。

方法五：成员推断（membership inference）与 Min-K% Prob#

思路：如果一段文本在训练集里，模型对它的"意外程度"应该更低。最常用于 LLM 的具体做法是 Min-K% Prob：不看平均对数似然（那会被常见词主导），而看最"意外"的那 k% token 的平均对数似然。

设文本 token 序列为 x=(x1​,…,xT​)，逐 token 对数似然为 ℓt​=logp(xt​∣x<t​)。取 ℓ 最小的 k%（最意外的那些 token）构成集合 MinK%(x)，定义：

MinK%(x)=∣MinK%(x)∣1​t∈MinK%(x)∑​ℓt​

判定规则：MinK%(x)>τ → 判为"成员"（见过的文本），阈值 τ 用一组已知成员/非成员校准。

为什么有效：记忆的痕迹藏在"本来不该能预测对"的 token 上。平均似然会被大量高频虚词拉高，看不出差别；只看最意外的 token，才暴露"它居然预测对了"。

边界（四条都很关键）：

  1. 需要逐 token 对数概率 → 纯 API 的黑盒模型拿不到（有些 API 不返回 logprobs）；
  2. 域偏移是最大的混淆：如果评测题目的文体与校准集不同（比如都是数学符号），Min-K% 分数会整体偏移，阈值失效；
  3. 长文本平均会稀释信号：只对可疑片段（题干 + 答案）打分，不要对整页打分；
  4. 改写即失效：如果语料收录的是改写版，Min-K% 检测不到原题。

方法六：生成式变体与模板实例化#

做法：不直接用公开题，而是用它生成同构的新题：固定解题模板，随机化实体、数字、场景，生成大规模变体（GSM-Symbolic 类工作的思路）。然后比较：同一模板下的多个实例之间，模型表现是否稳定。

能证明什么：同模板实例间的方差很大，说明原题的高分部分来自"拟合了那个具体实例"而不是掌握了解法——这是污染与模式匹配的强信号。反过来，一个真解题的模型应该在同一模板的实例间表现稳定。

边界：

  • 生成变体本身要保证"同构且唯一可解"（否则你在测出题器的 bug）；
  • 模板化会牺牲自然性，可能引入与真实任务不同的难度特征；
  • 需要人工抽查一部分变体的正确性。

补充：训练侧审计（由模型方执行）#

上面六类是评测方能做的。模型方还应做：训练语料与已知基准的去重（精确 + 近似，如 MinHash/SimHash）、canary 移除、数据血缘记录、以及在模型卡里报告"污染审计结果"。但这类自报信息不可验证——因此评测方不应把它当作免除自己审计的理由。

检出之后怎么办#

检出污染后，有四条务实路径：

  1. 分层报告：把可疑子集（n-gram 重合高的题）单独标出，同时报"全体"与"剔除可疑子集后"的分数。两者差距就是污染的量化上界。
  2. 换私有保留集：把一部分题完全不公开、不进入任何可爬取渠道，只在关键决策点使用（"一次开箱"）。这是唯一能结构性降低污染风险的常规手段。
  3. 转向相对比较 + 滚动刷新：既然绝对分数不可比，就比较同批次、同协议下的相对差异，并定期换题（第 4 节展开冻结 vs 滚动的取舍）。
  4. 报告污染审计：把用了哪些检测方法、结果如何、结论的不确定性写进评测报告。不报告审计的评测报告，其分数应被默认打折。

取舍：污染检测的成本与"够用"标准#

方法 需要什么 成本 证据强度 最适合的场景
时间切分 数据日期 低 中 持续评测（滚动基准）
n-gram 重合 训练语料 中 强（有重合时） 开源自训模型
诱饵串 能改数据 低 强（能复现时） 自建基准
扰动不变性 出题能力 中 中 通用、最实用
Min-K% Prob logprobs + 校准集 中 中 有 API logprobs 时
生成式变体 模板 + 生成预算 高 中强 高危基准的深度审计
训练侧审计 语料访问权 高 强（但不可验证） 模型方自证

"够用"的标准：如果你要在两个模型之间下一个会影响产品的结论，至少应做扰动不变性 + 一个时间/私有集交叉验证。只有 n-gram 或只有 leaderboard 分数，都不足以支撑决策。

代码：三种污染探针的最小实现#

import numpy as np

rng = np.random.default_rng(5)

# ============ 探针 1：n-gram 重合（有重合 = 硬证据） ============
def ngrams(tokens, n):
    return {tuple(tokens[i:i+n]) for i in range(len(tokens) - n + 1)}

def overlap_ratio(item_tokens, corpus_ngram_set, n=13):
    grams = ngrams(item_tokens, n)
    if not grams:
        return 0.0, 0
    hit = sum(g in corpus_ngram_set for g in grams)
    return hit / len(grams), len(grams)

# 造一个"训练语料"：其中混进了 3 道评测题（模拟数据集聚合导致的泄漏）
corpus = ("the quick brown fox jumps over the lazy dog " * 50).split()
leaked = ["a train leaves the station at 9 am traveling 60 km per hour "
          "and another leaves at 10 am traveling 80 km per hour"] * 3
for s in leaked:
    corpus += s.split()
corpus_grams = ngrams(corpus, 13)

eval_items = {
    "被污染的题": leaked[0].split(),
    "干净的同题型": ("a bus departs the central terminal at seven in the morning "
                 "moving at forty five kilometers per hour along the coastal road").split(),
}
for name, toks in eval_items.items():
    r, m = overlap_ratio(toks, corpus_grams)
    print(f"[n-gram] {name}: 13-gram 重合率 = {r:.2f} ({m} 个 n-gram)")
print("→ 有重合是硬证据；重合率为 0 不能证明干净（改写即可规避）\n")

# ============ 探针 2：扰动不变性 ============
# 两个模型：一个靠记忆、一个靠推理。原题分与扰动后分（示意值，可用真实评测替换）
models = {
    "记忆型": (0.86, 0.41),   # (原题, 关键数字替换后)
    "推理型": (0.62, 0.60),
    "对照小模型": (0.30, 0.28),
}
print("[扰动] 原题 -> 替换关键数字后")
for name, (orig, pert) in models.items():
    ps = (orig - pert) / orig
    print(f"  {name:6s}: {orig:.2f} -> {pert:.2f}  扰动敏感度 PS = {ps:+.2f}")
print("→ 记忆型原题高但 PS 极大；对照组的 PS 才是'扰动本身造成的难度'基线\n")

# ============ 探针 3：Min-K% Prob ============
def min_k_score(logprobs, k=0.2):
    """logprobs: 每个 token 的 log p。取最意外的 k% token 求均值；越高越像见过。"""
    lp = np.sort(np.asarray(logprobs))       # 升序：最意外在前
    m = max(1, int(len(lp) * k))
    return float(lp[:m].mean())

n_tok, n_items = 80, 150
# 合成：成员文本的"最意外 token"对数似然略高（模型对它们不那么意外）
# 注意两组均值只差 0.35 —— 刻意让分布重叠，避免造出"完美可分"的假象
member = np.array([rng.normal(-2.20, 0.9, n_tok) for _ in range(n_items)])
nonmem = np.array([rng.normal(-2.55, 0.9, n_tok) for _ in range(n_items)])
s_mem = np.array([min_k_score(x) for x in member])
s_non = np.array([min_k_score(x) for x in nonmem])

thr = (s_mem.mean() + s_non.mean()) / 2
tpr = (s_mem > thr).mean()
fpr = (s_non > thr).mean()
# 简易 AUC：正样本得分高于负样本的概率
auc = np.mean(s_mem[:, None] > s_non[None, :])
print(f"[Min-K%] 成员均值={s_mem.mean():+.2f} 非成员均值={s_non.mean():+.2f}")
print(f"阈值={thr:+.2f} → 召回(TPR)={tpr:.2f} 误报(FPR)={fpr:.2f} AUC={auc:.3f}")
print("→ 阈值必须在'与你评测同域'的校准集上定；域一变，阈值就失效")
print("→ 注意：这里的高 AUC 是合成数据造的，真实场景远没有这么干净")

三个探针各自的用途与局限：

  • n-gram 重合是唯一能给出硬证据的方法（有重合就实锤），但只在能拿到训练语料时有意义。重合率为 0 绝不能作为"干净"的结论——代码里那行注释就是这个意思。
  • 扰动不变性是最实用的方法：不需要语料、不需要 logprobs，只需要出题能力。关键是必须有对照组（代码里的"对照小模型"），否则你分不清掉分是记忆还是"题目被扰动变难了"。
  • Min-K% Prob 的价值在于它能对黑盒但有 logprobs 的模型做检测；它的软肋是阈值依赖分布：代码里即便人为让两组分布重叠，AUC 也有 0.93，但代价是 TPR 0.85 的同时 FPR 高达 0.17——在真实决策里这个误报率往往不可接受。任何成员推断结果都必须与目标域校准集、以及 TPR/FPR 一起报告，而不是只报一个 AUC。
  • ⚠️ 三段都是合成演示，不构成任何真实模型的污染结论。

练习#

  1. 信息量计算：一份 800 题的评测，头部模型平均通过率 0.93。 （a）用 Ij​=aj2​P(1−P)（假设所有 aj​=1.2）计算总信息量与 SE(θ^) 的近似值； （b）如果额外加入 200 道"当前模型通过率 0.5、区分度 1.2"的新题，SE(θ^) 变成多少？ （c）用这个计算解释：为什么"给饱和基准加新题"比"再加 200 道简单题"有用得多。

  2. 设计一份污染审计方案：你的目标是比较两个闭源模型（只能通过 API 调用，其中一个 API 提供 logprobs）。给出你会做的三种检测、各自的预期结果形态、以及"如果三种结果相互矛盾"时你的结论怎么写。

  3. 扰动实验的对照设计：你要用"替换关键数字"来测某模型是否背过 GSM8K。 （a）写出实验组与对照组（对照组应该包含什么模型或什么题型？）； （b）如果扰动后的题目难度整体上升，你怎么把"难度效应"与"记忆效应"分开？（提示：用同一批扰动题去测一个不可能见过该基准的小模型，做差值-差值） （c）给出你会报的最终指标（一个公式），并说明它的零假设是什么。

  4. Min-K% 的失效：某团队用 Min-K% Prob 得到 AUC = 0.92，宣布"9 成题目被污染"。 请写出至少三条你会提出的质疑（提示：校准集的域、文本长度、改写、API 的 tokenization 差异），并说明你会要求他们补报哪些数字。

  5. 饱和与污染的区分：模型 M 在基准 X（2021 年发布）上从 71% 涨到 88%，在基准 Y（2025 年发布）上从 55% 涨到 60%。 （a）最可能解释是什么？ （b）列出三个能进一步区分的实验； （c）如果确认 X 被污染，你如何仍然利用 X 做"回归门禁"？（提示：看相对变化与分层子集）

小结#

  • 饱和是可计算的：题目信息量 I(θ)=a2P(1−P) 在 P→1 时趋近 0；从 P=0.5 到 P=0.95，单题信息量只剩 19%，能力估计的标准误放大 2.3 倍。饱和基准上"名次靠噪声决定"是信息量的必然，不是数据没做好。
  • 污染分四层：输入污染、标签污染、模板污染、测试集过拟合（唯一不需要语料泄漏的一种，也是最普遍的一种）。传播主路径是公开数据集被混入 SFT 语料，多为管理不善而非有意。
  • 六类检测方法：时间切分、n-gram 重合、诱饵串、扰动不变性、成员推断（Min-K% Prob）、生成式变体；加上模型方的训练侧审计。
  • 每种方法都只能给证据，不能给证明：n-gram 有重合是硬证据，无重合什么也不能证明；扰动要配对照；Min-K% 依赖同域校准；canary 是探测器而非防线。
  • 审计的优先级：污染在低通过率题上的信号最强——那里"能力提升"解释不了高分。
  • 检出之后的四条路：分层报告（量化上界）、私有保留集（唯一结构性手段）、转向相对比较 + 滚动刷新、以及把审计写进评测报告。
  • 够用标准：要下影响产品的结论，至少做扰动不变性 + 一个时间/私有集交叉验证。
