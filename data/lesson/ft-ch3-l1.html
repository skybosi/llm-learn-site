低秩适配原理#

LoRA（Low-Rank Adaptation，低秩适配）是当前最流行的参数高效微调方法之一。它的核心洞察只有一个：微调带来的权重变化 ΔW 可以近似成一个低秩矩阵。本课从数学原理讲清"低秩"是什么、LoRA 为什么有效、以及它怎样用 1% 的参数逼近全参数微调。

一、概念讲解#

1. 微调的权重增量 ΔW#

回顾第 2 章：微调后的权重可以写成

W = W0 + ΔW

其中 W0 是冻结的预训练权重，ΔW 是训练产生的增量。全参数微调直接学习一个和 W0 同形状、同量级的 ΔW；而 LoRA 的思路是——不给 ΔW 这么大的自由度，而是假设它可以用两个小矩阵的乘积来表示。

2. 低秩分解：ΔW = BA#

设原始权重矩阵 W0 ∈ R^(d×k)（例如注意力层的一个投影矩阵，输入维度 k、输出维度 d）。LoRA 把增量写成两个小矩阵的乘积：

ΔW = B · A
A ∈ R^(r×k)，B ∈ R^(d×r)，其中 r ≪ min(d, k)

秩 r 通常取 4、8、16 这样的很小的数。于是可训练参数量从 d×k 降到 r×(d+k)，数量级大幅下降：

可训练参数减少比例 ≈ (d·k) / (r·(d+k))

以 d=k=4096、r=8 为例：原矩阵有 1677 万参数，而 A+B 只有约 6.5 万参数——减少了 99.6%。

3. 前向传播：原输出 + 低秩增量#

加入 LoRA 后，这一层的前向计算变为：

h = W0·x + ΔW·x = W0·x + B·A·x

即：先用原权重正常算一遍（冻结，不更新），再加上低秩支路 B·A·x 的增量（只训练 A、B）。原权重全程冻结，梯度只流向 A 和 B，因此显存中不需要为 W0 保存梯度与优化器状态。

4. 初始化与缩放系数 α#

两个关键设计细节：

  • 初始化：A 用小的随机高斯初始化，B 初始化为全零。这样训练开始时 ΔW = B·A = 0，模型行为与原模型完全一致，训练从"零扰动"平稳起步。
  • 缩放系数 α/r：前向时把低秩支路乘以 α/r（α 是超参数，常取 r 的 1~2 倍）。这样做的好处是改变 r 时不必重新调学习率——因为 α/r 归一化了支路的贡献幅度。实践上常用 α=16、r=8，即缩放 2。

5. 为什么低秩就够用#

这是 LoRA 论文（Hu et al., 2021）的关键论据：研究者发现，预训练大模型在下游任务上微调时，权重更新矩阵 ΔW 的内在秩（intrinsic rank）很低——即便允许全参数更新，学到的 ΔW 也主要集中在少数几个主导方向上。既然如此，与其让 ΔW 拥有 d×k 的自由度，不如从一开始就把它的秩限制在 r。

LoRA 的其他优势也随之而来：

  • 极少的可训练参数 → 显存需求大幅下降（第 3 课会量化对比）。
  • 原权重不动的扰动小 → 相对全参数微调，灾难性遗忘更轻。
  • 可插拔 → 不同任务各自存一份 A、B（通常只有几 MB），在同一个基座模型上快速切换。
  • 可合并 → 训练完可以把 BA 直接加回 W0（merge），推理时零额外延迟。

一句话总结：LoRA 冻结原权重，假设权重增量 ΔW 是低秩的，用两个小矩阵 A、B 的乘积来近似它，从而把可训练参数和显存开销都压缩了 2~3 个数量级。

二、可运行代码示例#

下面用 PyTorch 从零实现一个 LoRALinear 层，直观看到"冻结原权重 + 低秩旁路"是怎么回事。

import torch
import torch.nn as nn

class LoRALinear(nn.Module):
    """带低秩旁路的线性层：h = W0·x + (α/r)·B·A·x"""
    def __init__(self, in_features, out_features, r=8, alpha=16):
        super().__init__()
        # 原始权重 W0：冻结，不参与训练
        self.linear = nn.Linear(in_features, out_features, bias=False)
        for p in self.linear.parameters():
            p.requires_grad = False

        # 低秩矩阵 A（r × in）和 B（out × r）
        self.lora_A = nn.Parameter(torch.randn(r, in_features) * 0.01)  # 小随机初始化
        self.lora_B = nn.Parameter(torch.zeros(out_features, r))        # 全零初始化
        self.scaling = alpha / r

    def forward(self, x):
        # 原输出 + 低秩增量（开始时 ΔW=0，模型行为不变）
        return self.linear(x) + (x @ self.lora_A.T @ self.lora_B.T) * self.scaling

# 模拟一个 d=k=512 的投影矩阵，观察可训练参数变化
layer = LoRALinear(in_features=512, out_features=512, r=8, alpha=16)

total = sum(p.numel() for p in layer.parameters())
trainable = sum(p.numel() for p in layer.parameters() if p.requires_grad)
print(f"该层总参数量:   {total}")
print(f"可训练参数量:   {trainable}")
print(f"可训练占比:     {trainable/total*100:.2f}%")

# 验证前向传播和梯度流向
x = torch.randn(4, 512)          # 一个 batch 的输入
out = layer(x)
out.sum().backward()             # 反向传播
print("\nout 形状:", tuple(out.shape))
print("lora_A 是否收到梯度:", layer.lora_A.grad is not None)
print("原权重 W0 是否冻结:", layer.linear.weight.requires_grad)

再直观计算一下"低秩近似能省多少参数"，对比不同秩 r 的效果。

def param_reduction(d, k, r):
    """计算 LoRA 相对全参数微调的可训练参数保留比例"""
    full = d * k
    lora = r * (d + k)
    return lora / full

print("d=k=4096 的权重矩阵，不同秩 r 下的可训练参数保留比例：")
for r in [4, 8, 16, 64]:
    ratio = param_reduction(4096, 4096, r)
    print(f"  r={r:>2} -> 保留 {ratio*100:.2f}%（节省 {100 - ratio*100:.2f}%）")

print("\n结论：即便 r=64，可训练参数也不到原矩阵的 3%；")
print("     这正是 LoRA 能把显存和存储成本大幅压下来的原因。")
