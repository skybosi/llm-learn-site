编码器解码器#

前两章我们把注意力的零件全部造好了。这一课开始组装：用多头注意力搭出 Transformer 的编码器和解码器。整体结构依然是经典的"编码器读懂输入、解码器生成输出"，但内部已彻底摆脱 RNN——没有循环，只有自注意力、交叉注意力和前馈网络。我们先把骨架立起来，看清数据在编码器与解码器之间如何流动。

一、概念讲解#

1. 总体结构：一堆编码器 + 一堆解码器#

Transformer 的编码器和解码器都不是单个层，而是若干相同结构的小块（block）叠起来的栈：

  • 编码器栈：N 个编码器块。输入（词嵌入 + 位置编码）从底层进入，逐层向上，最终输出一串"富含上下文"的表示；
  • 解码器栈：N 个解码器块。它逐步生成输出序列，同时不断回头读取编码器的输出。

论文里 N = 6。每一层的输入输出维度相同，所以块可以像积木一样反复堆叠——这正是上一课"多头注意力保形"的直接红利。

2. 编码器块：自注意力 + 前馈#

每个编码器块内部只有两个子层：

  1. 多头自注意力：让输入序列内部互相"看"，融合上下文；
  2. 前馈网络：对每个位置独立地做非线性变换，增强表示能力。

两个子层都套着残差连接和层归一化（后面两课专门讲）。编码器是双向的：每个位置都能看到整条输入的所有位置，所以它负责"读懂"。

3. 解码器块：三件套#

解码器块比编码器多一个子层，共三个：

  1. 带掩码的多头自注意力：生成时不能偷看未来，所以注意力矩阵用下三角掩码挡住"未来的词"；
  2. 交叉注意力（cross-attention）：Query 来自解码器自己，Key/Value 来自编码器输出——这是解码器"向输入取信息"的通道，也是第一章普通注意力的直系后代；
  3. 前馈网络：同编码器。

解码器是自回归的：一步一步生成，当前步只能依赖已生成的部分和编码器的全部输出。

4. 两条数据流：编码流与生成流#

把编码器和解码器看成两条并行的数据流：

  • 编码流：输入序列 → 嵌入 → 编码器栈 → 得到上下文表示 enc_out，这一步一次性完成、全程并行；
  • 生成流：解码器以起始符起步，每生成一个词，就把"已生成的前缀"送进解码器栈，同时用 enc_out 做交叉注意力，输出对下一个词的预测。

交叉注意力是两条流的交汇点：Q 从生成流来，K、V 从编码流来。理解了这个交汇，就理解了整个架构的信息流向。

5. 与 RNN seq2seq 的对应#

对照第一课的 RNN seq2seq，Transformer 保留了同样的"编码-解码"分工，但替换了实现：

RNN seq2seq Transformer
编码方式 LSTM 逐词读入 自注意力并行融合
传递信息 最后一个隐藏状态 全部输出 + 交叉注意力
解码方式 LSTM 逐词生成 掩码自注意力 + 交叉注意力

骨架没变，变的是内部引擎：从"循环"换成了"注意力"。这也解释了 Transformer 为什么又快又能处理长序列。

二、可运行代码示例#

下面搭一个最精简的编码器块和解码器块，重点看子层顺序、残差连接、以及交叉注意力里 Q/K/V 的来源。前馈先用一个线性层占位，掩码用下三角矩阵。

import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

def attention(q, k, v, mask=None):
    """第二章实现的缩放点积注意力，这里直接复用。"""
    d = q.size(-1)
    scores = q @ k.transpose(-2, -1) / (d ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    return F.softmax(scores, dim=-1) @ v

class FFN(nn.Module):
    """前馈子层（细节下一课展开，这里先用单层线性占位）。"""
    def __init__(self, d_model):
        super().__init__()
        self.linear = nn.Linear(d_model, d_model)
    def forward(self, x):
        return self.linear(x)

class EncoderBlock(nn.Module):
    def __init__(self, d_model):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn = FFN(d_model)
        self.Wq = nn.Linear(d_model, d_model, bias=False)
        self.Wk = nn.Linear(d_model, d_model, bias=False)
        self.Wv = nn.Linear(d_model, d_model, bias=False)

    def forward(self, x):
        # 1) 自注意力 + 残差 + 归一化
        q, k, v = self.Wq(x), self.Wk(x), self.Wv(x)
        x = self.norm1(x + attention(q, k, v))
        # 2) 前馈 + 残差 + 归一化
        x = self.norm2(x + self.ffn(x))
        return x

class DecoderBlock(nn.Module):
    def __init__(self, d_model):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.ffn = FFN(d_model)
        self.Wq1 = nn.Linear(d_model, d_model, bias=False)
        self.Wk1 = nn.Linear(d_model, d_model, bias=False)
        self.Wv1 = nn.Linear(d_model, d_model, bias=False)
        self.Wq2 = nn.Linear(d_model, d_model, bias=False)
        self.Wk2 = nn.Linear(d_model, d_model, bias=False)
        self.Wv2 = nn.Linear(d_model, d_model, bias=False)

    def causal_mask(self, T):
        # 下三角矩阵：第 t 个位置只能看 0..t（不能偷看未来）
        return torch.tril(torch.ones(T, T))

    def forward(self, x, enc_out):
        # 1) 带因果掩码的自注意力（看不到未来的词）
        q, k, v = self.Wq1(x), self.Wk1(x), self.Wv1(x)
        x = self.norm1(x + attention(q, k, v, self.causal_mask(x.size(1))))
        # 2) 交叉注意力：Q 来自解码器，K/V 来自编码器
        q2, v2 = self.Wq2(x), self.Wv2(x)
        k2 = self.Wk2(enc_out)
        x = self.norm2(x + attention(q2, k2, v2))
        # 3) 前馈 + 残差 + 归一化
        x = self.norm3(x + self.ffn(x))
        return x

d_model = 16
enc = EncoderBlock(d_model)
dec = DecoderBlock(d_model)

src = torch.randn(2, 6, d_model)     # 源序列（编码器输入），长 6
tgt = torch.randn(2, 5, d_model)     # 目标序列（解码器输入），长 5

enc_out = enc(src)
dec_out = dec(tgt, enc_out)
print("编码器输出形状:", enc_out.shape)   # (2, 6, 16)
print("解码器输出形状:", dec_out.shape)   # (2, 5, 16)

运行后注意：

  • 编码器输出与 src 同形、解码器输出与 tgt 同形——两个块都保形，这正是能堆叠 6 层的原因；
  • 解码器里交叉注意力那一步，q2 来自 x（解码器当前表示），k2、v2 来自 enc_out（编码器输出），这就是"生成流向编码流取信息"的具象化。

把 EncoderBlock 和 DecoderBlock 各复制 6 份首尾相接，再加上嵌入层和最后的 softmax，就是论文里的完整 Transformer 骨架。

三、练习#

  1. 把 causal_mask 打印出来（torch.tril(torch.ones(5, 5))），解释为什么它是下三角，以及它在解码器自注意力里"挡住"了什么。
  2. 把交叉注意力里 k2、v2 的来源从 enc_out 改成解码器自己的 x，观察它退化成什么（提示：变成了又一次自注意力），思考交叉注意力的独特作用。
  3. 把单个 EncoderBlock 连续调用 3 次（x = enc(x)），确认形状始终不变；再比较"3 次同权重"与"3 个不同块"的区别，理解为什么要多个独立的块。
  4. 思考：为什么解码器的自注意力要带掩码，而编码器的自注意力不需要？如果给编码器也加上因果掩码，会损失什么能力？
