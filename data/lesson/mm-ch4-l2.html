图文对齐#

上一课我们搞清楚了 CLIP 用对比学习把图文"拉"进同一个嵌入空间的机制。本课时往深处走一层："对齐"到底意味着什么？这个共享空间长什么样？对齐的质量由什么决定？ 这些问题的答案，直接决定了后面的零样本分类（下一课）和多模态大模型（第五章）能走多远。

一、概念讲解#

1. "对齐"的三层含义#

说图像和文本"对齐了"，不是一句模糊的比喻，它至少包含三层递进的含义：

  1. 空间对齐（几何）：图像向量和文本向量落在同一个向量空间的同一块区域，可以用余弦相似度直接比较。这是最基础的层面，对比损失直接优化的就是它。
  2. 语义对齐（含义）：不仅"距离近"，而且"近得有道理"——"狗"的图片应该离"a photo of a dog"更近，离"a photo of a cat"更远，即便它俩在语言上只差一个词。这要求模型真的理解了词义，而不是靠表面特征（如颜色、构图）碰运气。
  3. 结构对齐（关系）：嵌入空间中，语义相近的概念聚成一簇，语义相对的关系（如"狗"与"猫"同属宠物，"猫"与"老虎"同属猫科）以一定的几何结构呈现出来。有了结构，向量运算才有意义——例如 king - man + woman ≈ queen 这样的类比在视觉侧也应成立（"戴王冠的男人"特征减去"男人"加上"女人"约等于"戴王冠的女人"）。

2. 双塔是怎样"对齐"的：同一批次内的正负样本拉锯#

回顾对比损失：每个 batch 里，模型要同时完成两件事——把 N 对正样本的相似度抬上去，把 N²−N 个负样本的相似度压下去。这是一场持续整个训练过程的"拉锯战"：

  • 如果负样本太容易（例如"狗"和"飞机"），模型学到的是粗糙的区分，嵌入空间的分辨率不足，遇到"哈士奇 vs 阿拉斯加"就分不清。
  • 如果负样本太相似（"同一场景的两张近义描述"），训练会非常困难，但学出的边界也更精细。

这就是为什么 CLIP 依赖海量且多样的数据：数据越多样，一个 batch 里"碰巧"采样到的负样本就越有代表性，模型被迫学到越来越细的语义区分。原论文 4 亿对图文数据，正是保证"负样本质量"的物质基础。

3. 归一化、温度与"均匀性-对齐性"视角#

从更理论的角度看，对比学习的目标可以拆成两个相互制约的力，这一视角来自对比表征学习的研究（Wang & Isola, 2020）：

  • 对齐性（alignment）：正样本对的向量要尽量靠近。损失里的正样本项负责这一点。
  • 均匀性（uniformity）：所有样本（含负样本）要尽量均匀地铺满单位球面，而不是挤成一团。损失里的负样本项负责把不相关的点推开。

两者天然存在张力：一味追求对齐会塌缩成一个点（所有向量都相同，损失里正样本项为零但模型毫无用处）；一味追求均匀又会破坏语义结构。温度 τ 和 L2 归一化就是调节这对张力的旋钮——归一化把所有向量限定在单位球面上，让"均匀性"有了明确的几何目标；温度则控制 softmax 的锐度，间接决定"推开负样本"的力度。

这个"均匀性"视角还能解释一个现象：训练好的 CLIP 嵌入空间里，随机两张图的相似度分布会偏向一个较低但非零的基线，而不是集中在 0.5 附近——因为负样本被系统性推开，整个球面被"撑"起来了。

4. 对齐质量如何衡量：检索指标#

"对齐得好不好"不能只看损失值。业界常用图文检索（image-text retrieval）来检验对齐质量：

  • 图搜文（I→T）：给定一张图，在 N 句候选文本里找正确的那句，看正确项是否排在前面。
  • 文搜图（T→I）：给定一句文本，在 N 张候选图里找正确的那张。

常用指标是 Recall@K：正确配对出现在 top-K 结果中的比例。例如 Recall@1 表示"一次就找对"的比例，Recall@5、Recall@10 放宽到前 5、前 10。对齐质量越好，Recall@K 越高。你在 COCO、Flickr30k 这类标准检索基准上能看到各模型（CLIP、SigLIP、ALIGN 等）的 Recall 对比。

5. 常见变体与改进#

  • SigLIP：把"batch 内 softmax 对比"换成逐对的 sigmoid 交叉熵，把每个图文对独立地判成"匹配 / 不匹配"。好处是不再需要 batch 内负样本，训练对 batch 大小不敏感，小 batch 也能稳定训练。
  • ALIGN：Google 的做法，用更大规模（18 亿对）但噪声更多的图文数据，靠"尺度大 + 双塔结构稳健"来容忍噪声标签。
  • 大 batch 与可学习温度：CLIP 原论文用 32768 的超大 batch 提供海量负样本，配合可学习温度，是工程上的关键细节。

二、可运行代码示例#

示例 1：可视化图文嵌入的相似度矩阵#

下面加载 CLIP，对一批图与一批文本做两两相似度，直观地"看见"对齐——对角线附近应该是热区。

from transformers import CLIPProcessor, CLIPModel
from PIL import Image
import torch

model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

texts = [
    "a photo of a cat",
    "a photo of a dog",
    "a photo of a car",
]
# 用三张不同颜色的占位图演示; 实际使用时替换为真实图片路径
images = [
    Image.new("RGB", (224, 224), color=(120, 120, 120)),
    Image.new("RGB", (224, 224), color=(60, 60, 60)),
    Image.new("RGB", (224, 224), color=(200, 200, 200)),
]

inputs = processor(text=texts, images=images, return_tensors="pt", padding=True)
with torch.no_grad():
    out = model(**inputs)

# 两两相似度矩阵 (3, 3)
sim = out.image_embeds @ out.text_embeds.T
print("图文相似度矩阵：")
print(sim.numpy().round(2))

把 texts 的顺序与 images 的顺序对应起来，你会看到（在真实数据上）对角线元素显著高于非对角线——这就是"对齐"最直接的视觉证据。

示例 2：对齐性与均匀性的数值检验#

我们做一个纯 PyTorch 实验，看对比损失的梯度如何同时"拉近正样本"和"推开负样本"，并理解均匀性的含义。

import torch
import torch.nn.functional as F

def infonce(image_emb, text_emb, temperature=0.07):
    sim = image_emb @ text_emb.T / temperature
    labels = torch.arange(sim.shape[0], device=sim.device)
    return (F.cross_entropy(sim, labels) + F.cross_entropy(sim.T, labels)) / 2

# 初始: 三对图文向量, 故意让它们挤在一起(全部指向同一方向)
torch.manual_seed(1)
N, d = 3, 4
image_emb = F.normalize(torch.randn(N, d) + 3.0, dim=-1)  # 加上大偏置 -> 都挤在球面同一点附近
text_emb  = F.normalize(torch.randn(N, d) + 3.0, dim=-1)

print("训练前, 任意两对之间的相似度(都接近 1 = 塌缩了):")
print((image_emb @ image_emb.T).numpy().round(2))

# 用对比损失做若干步梯度下降, 观察向量如何被"撑开"
image_emb = image_emb.clone().requires_grad_(True)
text_emb  = text_emb.clone().requires_grad_(True)
opt = torch.optim.Adam([image_emb, text_emb], lr=0.1)
for step in range(200):
    opt.zero_grad()
    loss = infonce(F.normalize(image_emb, dim=-1), F.normalize(text_emb, dim=-1))
    loss.backward()
    opt.step()

image_emb = F.normalize(image_emb, dim=-1)
text_emb  = F.normalize(text_emb, dim=-1)
print("\n训练后, 图像之间两两相似度(远离 1 = 均匀铺开):")
print((image_emb @ image_emb.T).numpy().round(2))
print("正样本(对角)图文相似度:")
print((image_emb * text_emb).sum(-1).numpy().round(2))

你会发现：初始时所有向量几乎重合（相似度 ≈ 1，这是"塌缩"状态，模型毫无意义）；经过对比损失优化后，图像之间被推开、不再挤在一起，同时每对正样本（图像与其对应文本）保持了较高相似度。对齐性由正样本项保证，均匀性由负样本项保证——这个实验把上一节的理论变成了可观测的数字。

三、练习#

  1. 概念辨析：用自己的话说明"空间对齐、语义对齐、结构对齐"三者的递进关系，并各举一个违反它的反例。
  2. 动手实验：把示例 2 中初始偏置 +3.0 改成 +0.0（初始向量已经比较分散），再训练同样步数。损失下降的幅度和最终相似度分布有什么不同？这说明了"初始塌缩"对训练的影响。
  3. 指标练习：某模型在 1000 条图文对上做图搜文，其中 810 条的正确文本出现在 top-1，930 条出现在 top-5。请计算它的 Recall@1 和 Recall@5。
  4. 思考题：SigLIP 用逐对 sigmoid 替代 batch 内 softmax 对比，为什么就能摆脱对超大 batch 的依赖？它可能牺牲了什么？
