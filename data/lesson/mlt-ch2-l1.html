最大似然估计回顾#

第 1 章结束时我们抛出一个问题：损失函数 ℓ 凭什么这么选？平方损失、交叉熵这些看似"约定俗成"的选择，背后到底有没有道理？答案在概率论里——绝大多数损失函数，都是从"最大似然估计（Maximum Likelihood Estimation, MLE）"这个母原理推导出来的。这一课先把 MLE 本身讲透，后两课再用它分别"生"出 MSE 和交叉熵。

一、概念讲解#

1. 似然：把概率"反着看"#

概率和似然是同一公式的两个解读方向。假设数据 x 服从一个由参数 θ 决定的分布 P(x | θ)：

  • 概率（固定 θ，变化 x）：θ 已知时，问"观察到 x 的可能性有多大"。
  • 似然（固定 x，变化 θ）：x 已知（数据已经拿到手）时，问"哪个 θ 最可能产生这批数据"。

似然函数定义为：

L(θ) = P(X = x | θ)

注意它的自变量是 θ，而不是 x。数据一旦被观测到，就是确定的常数；真正"可变、待求"的是参数 θ。MLE 的思路一句话：在所有可能的 θ 里，选那个让"已经发生的数据"最可能发生的 θ。

2. MLE 的定义与对数似然#

最大似然估计量是：

θ̂_MLE = argmax_θ L(θ) = argmax_θ P(x₁, …, xₘ | θ)

如果样本是独立同分布（i.i.d.）的，联合概率可以拆成乘积：

L(θ) = ∏ᵢ₌₁ᵐ P(xᵢ | θ)

乘积在数学上不好处理（求导麻烦、数值下溢），于是取对数——因为对数函数单调递增，"最大化 L"和"最大化 log L"给出相同的 θ̂，但乘积变成了求和：

log L(θ) = Σᵢ₌₁ᵐ log P(xᵢ | θ)

这就是对数似然（log-likelihood）。机器学习里几乎所有损失函数，本质上都是负对数似然的变体：最大化对数似然 ≡ 最小化负对数似然 ≡ 最小化一个求和形式的"损失"。这是 MLE 与第 1 章 ERM 打通的第一座桥。

3. 例一：伯努利分布的 MLE#

掷一枚可能不公平的硬币，正面概率为 θ，反面为 1−θ。掷 m 次，观测到 k 次正面。每次结果 xᵢ ∈ {0,1} 服从伯努利分布：

P(xᵢ | θ) = θ^{xᵢ} (1−θ)^{1−xᵢ}

似然与对数似然：

L(θ) = θᵏ (1−θ)^{m−k}
log L(θ) = k·log θ + (m−k)·log(1−θ)

对 θ 求导并令为 0：

d/dθ log L = k/θ − (m−k)/(1−θ) = 0
⟹  θ̂ = k/m

结论朴素而深刻：硬币正面概率的最大似然估计，就是"正面出现的频率"。这个 k/m 你从小就会算，但 MLE 告诉你它为什么"最优"。

4. 例二：高斯分布的 MLE#

样本 x₁, …, xₘ 来自高斯分布 N(μ, σ²)，密度：

p(x | μ, σ²) = (1/√(2πσ²)) · exp(−(x−μ)² / 2σ²)

对数似然（丢掉与参数无关的常数后）：

log L(μ, σ²) = −(m/2) log σ² − (1/2σ²) Σᵢ (xᵢ − μ)²

分别对 μ 和 σ² 求导令零：

∂/∂μ = (1/σ²) Σᵢ (xᵢ − μ) = 0      ⟹  μ̂ = (1/m) Σᵢ xᵢ（样本均值）
∂/∂σ² = −m/(2σ²) + (1/2σ⁴) Σᵢ (xᵢ − μ)² = 0
      ⟹  σ̂² = (1/m) Σᵢ (xᵢ − μ̂)²（样本方差，除以 m 而非 m−1）

注意到一个细节：这里方差用的是 1/m 而不是统计课本里的 1/(m−1)。前者的估计量是有偏的（期望略小于真值），后者才是无偏的。MLE 追求的是"最可能"，不追求"无偏"——MLE 给出的恰好是那个有偏版本。这个细节说明：MLE 的哲学是"概率最大"，不是"期望无偏"，两者不必重合。

5. MLE 的性质与局限#

MLE 有漂亮的大样本性质（在正则条件下）：

  • 一致性：样本量趋于无穷时，θ̂_MLE 依概率收敛到真实参数 θ*；
  • 渐近正态：√m(θ̂ − θ*) 趋于正态分布，方差由 Fisher 信息量的倒数给出；
  • 渐近有效：在无偏估计里，MLE 的方差渐近达到 Cramér–Rao 下界，即"最优"；
  • 等变性：若 φ = g(θ)，则 φ̂ = g(θ̂)，参数变换不破坏估计。

但也有局限：小样本下可能偏得厉害；模型若设定错（比如真实分布不是高斯却硬套高斯），MLE 会系统性地学偏。MLE 不是万能药，它是"给定模型假设后，用数据反推参数"的最优方法——模型假设本身的对错，是另一层问题（第 4 章的偏差）。

6. MLE 与 ERM 的等价关系#

把 MLE 换个说法：定义单样本损失 ℓ(xᵢ; θ) = −log P(xᵢ | θ)，则：

θ̂_MLE = argmin_θ Σᵢ −log P(xᵢ | θ) = argmin_θ (1/m)Σᵢ ℓ(xᵢ; θ)

这正是经验风险最小化，只是损失函数被特化为"负对数似然"。于是两条母原理在此汇合：

  • 从优化视角看，MLE 是 ERM 的一种特殊损失；
  • 从概率视角看，ERM 里的损失"该选什么"，由数据的概率模型决定。

二、可运行代码示例#

用 NumPy 手工验证两个 MLE 结论：伯努利的 θ̂ = k/m，以及高斯的 μ̂ = 样本均值、σ̂² = 样本方差(÷m)。我们不调任何统计库的 fit，直接算并和公式对照。

import numpy as np

rng = np.random.default_rng(7)

# —— 例一：伯努利 MLE，θ* = 0.3 ——
theta_true = 0.3
flips = rng.random(10000) < theta_true   # 10000 次抛硬币
k = int(flips.sum())
theta_hat = k / len(flips)
print(f"伯努利 MLE：k={k}, θ̂ = k/m = {theta_hat:.4f}（真实 θ*={theta_true}）")

# —— 例二：高斯 MLE，μ*=5, σ*=2 ——
mu_true, sigma_true = 5.0, 2.0
samples = rng.normal(mu_true, sigma_true, size=10000)
mu_hat = float(np.mean(samples))
sigma2_hat_mle = float(np.mean((samples - mu_hat) ** 2))   # 除以 m（MLE 版）
sigma2_hat_unbiased = float(np.var(samples, ddof=1))        # 除以 m-1（无偏版）
print(f"高斯 MLE：μ̂ = {mu_hat:.4f}（真实 μ*={mu_true}）")
print(f"高斯 MLE：σ̂²(MLE, ÷m)   = {sigma2_hat_mle:.4f}")
print(f"高斯方差：σ̂²(无偏, ÷m−1) = {sigma2_hat_unbiased:.4f}（真实 σ*²={sigma_true**2:.1f}）")

# 验证：σ̂²(MLE) 确实系统性偏小
print(f"MLE 方差偏差 = {sigma2_hat_mle - sigma_true**2:.4f}（应略为负）")

两个公式都被数据精确验证。特别观察最后一行：MLE 的方差估计略小于真实值——这就是"有偏但最可能"的体现，也是理解 MLE 哲学的关键一例。

三、练习#

  1. 从似然函数 L(θ) = θᵏ(1−θ)^{m−k} 出发，完整写出求导、令零、解出 θ̂ = k/m 的每一步，并说明二阶导数为何是负的（保证它是极大值而非极小值）。
  2. 高斯 MLE 中，为什么 σ̂² 用 1/m 而不是 1/(m−1)？请推导 𝔼[σ̂²_MLE] = (m−1)/m · σ²，从而看出它是偏小的。
  3. 把高斯 MLE 的推导推广到"均值未知但方差已知为 1"的情形，验证 μ̂ 仍是样本均值；再说明此时对数似然的最大化等价于最小化 Σᵢ(xᵢ − μ)²——这已是 MSE 的雏形。
  4. 思考：若硬币的正面概率 θ 的真实值是 0，但某次实验 3 次全是反面，MLE 给出的 θ̂ 是多少？这合理吗？它暴露了 MLE 在什么情况下会"过拟合"数据？

母原理连接#

本课属于母原理 "概率视角统一"。MLE 是"从数据反推参数"的标准动作，它给出了一条铁律：当你假设了数据的概率模型，损失函数就不再是自由选择，而是被推导出来的。同时，本课也第一次显式架起了 MLE 与 ERM（第 1 章"一切学习=优化"）之间的桥：负对数似然就是一种损失函数。后两课我们就把这条桥走通——从高斯噪声推出 MSE，从伯努利分布推出交叉熵。
