平稳性与自相关#

上一课我们知道时间序列"过去会影响现在"。那么，这种影响到底有多大、能持续多久？要回答它，需要两个工具：平稳性（序列的统计性质是否随位置漂移）和自相关（序列和自己过去的相关程度）。这两样东西几乎是后面所有模型（ARIMA、指数平滑、诊断）的"体检报告"。

一、概念讲解#

1. 弱平稳：三句话的定义#

平稳性描述序列的统计性质是否"平移不变"。严格的强平稳要求整个联合分布随时间平移都不变，太难验证；实务上我们用弱平稳（二阶平稳），只要求三条：

  1. 均值恒定：E[y_t] = μ，不随 t 变化；
  2. 方差恒定：Var(y_t) = σ²，不随 t 变化（没有"越往后波动越大"）；
  3. 自协方差只取决于滞后：Cov(y_t, y_{t+h}) 只依赖间隔 h，与起点 t 无关。

第三条的直觉是：序列"和自己的过去"之间的依赖强度，只由相隔多远决定，而与处在哪个时间点无关。今天和昨天、下个月和它前一天，相关性应当一样。

为什么在乎平稳？因为大多数经典模型（ARMA/ARIMA、谱方法等）都假设序列平稳。平稳意味着"规律不会随位置改变"，于是我们能用历史去估计未来；若序列不平稳，估计出来的参数本身就在漂移，预测无从谈起。

2. 自相关函数 ACF#

自相关度量的是：相隔 h 期的两个观测 y_t 与 y_{t+h} 之间的线性相关程度。定义滞后 h 的自相关系数：

ρ(h) = Cov(y_t, y_{t+h}) / Var(y_t)

在平稳假设下，分子分母都与 t 无关，ρ(h) 只是 h 的函数。对长度为 T 的样本，我们通常用样本自相关去估计它：

ρ̂(h) = Σ_{t=1}^{T-h} (y_t − ȳ)(y_{t+h} − ȳ) / Σ_{t=1}^{T} (y_t − ȳ)²

分子是"相隔 h 期的协方差"，分母是总方差，所以 ρ(0) = 1（自己和自己的相关恒为 1），且 |ρ(h)| ≤ 1。把 ρ(h) 对 h = 0, 1, 2, ... 画出来，就是自相关函数图（ACF 图）。

几个典型形状：

  • 白噪声：ρ(h) ≈ 0 对任意 h > 0，ACF 图几乎全是零（只在置信带内随机抖动）；
  • 有记忆的序列（如 AR(1)）：ρ(h) 随 h 增大指数衰减，拖出一条逐渐消失的尾巴；
  • 有季节的序列：ACF 在滞后 12、24（若周期为 12）出现凸起的尖峰。

3. 偏自相关函数 PACF#

ACF 有一个"混淆"问题：y_t 和 y_{t-2} 的相关，一部分可能是通过 y_{t-1} 间接传递的（t 依赖 t-1，t-1 又依赖 t-2）。偏自相关 PACF 把这条"中间链路"剔除掉，度量 y_t 与 y_{t-h} 在已扣除 1..h-1 期影响之后的"净相关"。

直觉：PACF(h) 是"只隔 h 期、直接"的相关强度；ACF(h) 是"隔着 h 期、直接 + 间接全部叠加"的总相关。两者配合，正是第 2 章识别 ARIMA 阶数的重要线索。

4. 白噪声：检验的基准#

白噪声是一串均值为 0、方差恒定、且各期互不相关的随机变量序列：E[ε_t]=0, Var(ε_t)=σ², Cov(ε_t, ε_s)=0 (t≠s)。

白噪声是"完全不可预测"的序列：知道过去对预测未来毫无帮助。它在建模里有两个用途：

  • 作为模型的误差项假设：一个好的模型，拟合后的残差应当"像白噪声一样干净"，说明可解释的信息都被抽走了；
  • 作为检验基准：常用 Ljung–Box 检验检验一批自相关系数是否同时为 0，原假设"序列是白噪声"。

5. 非平稳的头号例子：随机游走#

随机游走是理解非平稳最直观的模型：

y_t = y_{t-1} + ε_t，ε_t 为白噪声

它"下一步 = 上一步 + 一个随机扰动"。把 y_t 展开：y_t = y_0 + ε_1 + ... + ε_t，于是：

  • 均值 E[y_t] = y_0 看似恒定，但方差 Var(y_t) = t·σ² 随 t 线性增长——违反弱平稳的第 2 条；
  • 序列会"漫游"得离起点越来越远，没有任何"回到均值"的拉力。

随机游走的背后是一个单位根：把它写成 (1 − B)y_t = ε_t（B 是后移算子 By_t = y_{t-1}），特征多项式的根落在单位圆上（|φ| = 1），这正是"非平稳"的数学根源。股价、汇率常被近似成随机游走：今天的价格已经"吸收"了所有历史信息，下一步往哪走基本靠随机扰动。

6. ADF 检验：怎么"证明"不平稳#

ADF 检验（Augmented Dickey–Fuller）用来判断序列是否含单位根。它的原假设是：

H₀：序列有单位根（非平稳）

检验的思路是拟合一个"带差分的自回归"方程，看滞后项的系数是否显著小于 0（即序列有"回归均值"的倾向）。如果 p 值很小，拒绝原假设，说明序列平稳；p 值很大则"无法拒绝非平稳"，通常要先做差分。

一个实用流程：先画图看趋势，再看 ACF 是否衰减得很慢（慢衰减往往是非平稳信号），最后用 ADF 检验给出量化判断。非平稳不是坏事，它提示我们"先差分、再建模"（这正是 ARIMA 里 I 的含义，见第 2 章）。

二、可运行示例#

生成三条序列——白噪声、AR(1)、随机游走——看它们的 ACF/PACF 和 ADF 检验结果。

import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import acf, pacf, adfuller
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

rng = np.random.default_rng(7)
T = 200
e = rng.normal(0, 1, size=T)  # 共享的白噪声驱动

# 1) 白噪声
wn = e.copy()

# 2) AR(1)：y_t = 0.8 * y_{t-1} + e_t（平稳，|0.8|<1）
ar1 = np.zeros(T)
for t in range(1, T):
    ar1[t] = 0.8 * ar1[t - 1] + e[t]

# 3) 随机游走：y_t = y_{t-1} + e_t（非平稳）
rw = np.cumsum(e)

# 打印前几阶自相关，对比三者的"记忆"长度
for name, x in [("白噪声", wn), ("AR(1)", ar1), ("随机游走", rw)]:
    ac = acf(x, nlags=5, fft=False)
    print(f"{name:5s}  ACF(1~5) = {np.round(ac[1:], 3)}")

# ADF 检验：p 值越小越倾向平稳
for name, x in [("白噪声", wn), ("AR(1)", ar1), ("随机游走", rw)]:
    pval = adfuller(x, autolag="AIC")[1]
    verdict = "平稳" if pval < 0.05 else "非平稳"
    print(f"{name:5s}  ADF p值 = {pval:.4f} -> {verdict}")

运行后你会发现：

  • 白噪声的 ACF 各阶都接近 0，ADF p 值极小（平稳）；
  • AR(1) 的 ACF 从约 0.8 开始指数衰减，p 值很小（平稳）；
  • 随机游走的 ACF 在滞后 5 阶仍高达 0.9 以上（衰减极慢），ADF p 值很大（非平稳）——这正是单位根的典型指纹。

三、练习#

  1. 把 AR(1) 的系数从 0.8 改成 0.99 和 −0.8，分别观察 ACF 的形状变化，解释为什么 0.99 时 ACF 衰减特别慢、接近随机游走。
  2. 用 plot_acf / plot_pacf 画出 AR(1) 的 ACF 和 PACF 图，观察 ACF 拖尾、PACF 是否在滞后 1 之后截尾。
  3. 对随机游走做一次差分 np.diff(rw)，再跑 ADF 检验，观察 p 值变化，解释"差分能恢复平稳"的原理。
  4. 思考：Ljung–Box 检验的原假设是什么？如果对一个模型的残差做该检验得到 p=0.001，说明模型拟合得怎样？
