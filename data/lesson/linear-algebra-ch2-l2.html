矩阵乘法#

矩阵乘法是整个线性代数、也是整个深度学习里最重要的运算：神经网络的"前向传播"、线性回归的预测、数据的线性变换，本质都是矩阵乘法。它初看规则有点"绕"，但一旦把"结果里的每个数都是一个点积"抓住，就通了。这一课我们彻底搞懂它。

一、概念讲解#

1. 乘法规则：形状必须"对接"#

两个矩阵 A（形状 m×n）和 B（形状 p×q）能相乘的前提是：A 的列数必须等于 B 的行数，即 n = p。乘出来的结果 C 形状是 m×q。

一句话记忆：(m×n) · (n×q) = (m×q)，中间的 n 要"对得上"，两边剩下的 m 和 q 就是结果的形状。

2. 结果的每个元素 = 一次点积#

结果矩阵 C 的第 i 行第 j 列元素 cᵢⱼ，等于 A 的第 i 行 与 B 的第 j 列 做点积：

cᵢⱼ = (A 的第 i 行) · (B 的第 j 列)

也就是把对应元素相乘后累加。回忆上一章的点积，这里不过是"行向量"和"列向量"做点积而已。

3. 两种直觉理解#

理解一：点积的集合。 C 里的每个数，都是"A 的某一行"与"B 的某一列"的相似度度量。

理解二：列向量的线性组合。 把 B 的每一列看成一个列向量，A 的每一行提供一组系数，那么 C 的每一列，就是 B 的各列按系数线性组合出来的结果。这是 3Blue1Brown 里非常经典的视角，也是"线性变换"的由来。

4. 机器学习中的应用：一层神经网络#

设输入是一条特征向量 x（形状 n×1），这一层的权重矩阵是 W（形状 m×n），偏置向量是 b（形状 m×1）。那么这一层的输出就是：

z = W · x + b

其中 W · x 是矩阵乘法（m×n 乘 n×1 得到 m×1），+ b 是向量加法。这样，m 个输出神经元就各自算出了自己的激活值。深度学习里成千上万次的计算，就是这样的矩阵乘法不断套娃。

再比如线性回归：设特征矩阵 X（m 条样本 × n 个特征）乘权重向量 w（n×1），得到的 X·w 就是 m 条样本各自的预测值向量。

5. 矩阵乘法不满足交换律#

注意：A·B 和 B·A 通常不相等，甚至形状都可能对不上。矩阵乘法有"结合律"(AB)C = A(BC) 和"分配律"，但没有交换律。这一点和普通数字乘法完全不同。

二、可运行示例#

下面用 NumPy 演示矩阵乘法，并手写一次"点积式"计算，验证结果的每个元素。

import numpy as np

# 一个 2×3 的权重矩阵 W
W = np.array([
    [1, 2, 3],
    [4, 5, 6],
])

# 一个 3×1 的输入特征向量 x
x = np.array([[7], [8], [9]])

# 1) 矩阵乘法：np.matmul 或 @ 运算符
z = W @ x
print("z = W @ x =")
print(z)
print("z 的形状 =", z.shape)   # (2, 1)

# 2) 手动验证：z 的每个元素是"W 的某行 点积 x 的那一列"
row0_dot = W[0, :] @ x[:, 0]   # W 第 0 行 与 x 第 0 列 点积
row1_dot = W[1, :] @ x[:, 0]   # W 第 1 行 与 x 第 0 列 点积
print("手动计算 z[0] =", row0_dot)   # 1*7 + 2*8 + 3*9 = 50
print("手动计算 z[1] =", row1_dot)   # 4*7 + 5*8 + 6*9 = 122

# 3) 一次完整的线性回归预测：X(3 样本×3 特征) @ w(3×1)
X = np.array([
    [120, 3, 5],
    [90,  2, 10],
    [150, 4, 2],
])
w = np.array([[1000], [20000], [-5000]])  # 每个特征对房价的贡献
pred = X @ w
print("预测房价 =")
print(pred)   # 3 条样本各自的预测值

预期输出（大意）：

z = W @ x =
[[ 50]
 [122]]
z 的形状 = (2, 1)
手动计算 z[0] = 50
手动计算 z[1] = 122
预测房价 =
[[155000]
 [ 40000]
 [220000]]

要点：@ 和 np.matmul 都是矩阵乘法，注意别和 * 混淆——* 对数组是逐元素相乘；做矩阵乘法前先在心里过一遍形状：(2×3) @ (3×1) → (2×1)。

三、练习#

  1. 手算 [[1,2],[3,4]] · [[5,6],[7,8]] 的结果，再用 NumPy 验证（注意结果是一个 2×2 矩阵，共 4 个数）。
  2. 构造一个 2×3 的权重矩阵和一个 3×1 的输入，用 @ 计算输出，再手写 for 循环逐行点积，验证两者一致。
  3. 用示例中的 X @ w 做一次线性回归预测，试着把 w 里的系数改一改，观察预测房价如何变化，并解释为什么。
  4. 思考：(2×3) @ (2×3) 能相乘吗？为什么？如果交换成 x.T @ W.T，形状会变成什么？动手验证一下。
