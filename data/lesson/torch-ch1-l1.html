张量概念#

学完神经网络基础后，你已经在概念层面熟悉了"输入向量""权重矩阵""输出张量"这些对象。进入 PyTorch 的世界，第一步就是把所有这些对象统一成同一种数据结构——张量（Tensor）。本课不涉及训练，只回答三个问题：张量是什么、它有哪些核心属性、为什么它是深度学习框架的地基。

一、概念讲解#

1. 张量是对多维数组的统一抽象#

标量（一个数）、向量（一维数组）、矩阵（二维数组）都是张量的特例。张量用一个统一的叫法覆盖任意维度的数组：

名称 维度（dim） 例子 PyTorch 形状
标量 0 温度 36.5 torch.tensor(36.5) → shape=torch.Size([])
向量 1 [0.1, 0.2, 0.3] shape=torch.Size([3])
矩阵 2 一张灰度图 shape=torch.Size([28, 28])
三维张量 3 一批彩色图 shape=torch.Size([32, 3, 224, 224])

维度（dim，也叫"阶"）就是张量有多少个轴（axis）。图 1-1 把 0~3 维张量画成几何示意，你可以直观看到"每升一维就多套一层"。

2. 三个核心属性：shape、dtype、device#

任何张量都由三件事决定它的身份：

  • shape（形状）：每个轴的长度，例如 torch.Size([2, 3]) 表示 2 行 3 列。
  • dtype（数据类型）：元素用什么精度存储，常见的有 torch.float32（默认浮点）、torch.float64、torch.int64、torch.bool。做梯度计算时通常要求浮点类型。
  • device（设备）：张量放在哪里计算，cpu 或 cuda:0（GPU）。同一份数据只有移动到正确设备上才能被对应的算子处理。

图 1-2 展示了同一个 2×3 张量如何被 shape、dtype、device 三个维度描述。

3. 与 NumPy 的关系#

如果你写过 NumPy，张量并不陌生——二者在概念上高度对齐。区别在于：NumPy 的 ndarray 只负责存数据、做数值运算；而 PyTorch 张量额外携带自动微分所需的图信息（第 2 章详述），并能无缝迁移到 GPU。可以这样记：张量 ≈ "NumPy 数组 + 可求导 + 可上 GPU"。两者的互转在下一课专门讲。

4. 张量为什么是地基#

  • 表达数据：图像是 (N, C, H, W)，文本 token 是 (N, L)，批处理统一成"样本数"打头的张量。
  • 表达参数：神经网络每一层的权重和偏置都是张量，梯度也是同样形状的张量。
  • 统一运算：加减乘除、矩阵乘法、卷积、归一化，全部围绕张量展开。

二、可运行代码示例#

下面用一段脚本把"张量的阶、shape、dtype、device"一次看全。可以直接复制运行。

import torch

# ---- 0 维：标量 ----
s = torch.tensor(3.14)                 # 默认 float32
print("标量 s:", s)
print("  dim   =", s.dim())            # 0，即 0 维
print("  shape =", s.shape)            # torch.Size([])，空形状

# ---- 1 维：向量 ----
v = torch.tensor([1.0, 2.0, 3.0])      # 3 个元素
print("\n向量 v shape:", v.shape)      # torch.Size([3])

# ---- 2 维：矩阵 ----
m = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])          # 2 行 3 列
print("\n矩阵 m shape:", m.shape)      # torch.Size([2, 3])
print("  m[0, 2] =", m[0, 2].item())   # 取第 0 行第 2 列，item() 转 Python 数值

# ---- 3 维：常见于"批"数据 ----
t = torch.zeros(2, 3, 4)               # 2 批，每批 3 行 4 列
print("\n三维张量 t shape:", t.shape)  # torch.Size([2, 3, 4])

# ---- 指定 dtype 与 device ----
x = torch.tensor([1, 2, 3], dtype=torch.float32, device="cpu")
print("\nx 的 dtype :", x.dtype)       # torch.float32
print("x 的 device:", x.device)        # cpu

# ---- 常用构造器 ----
print("\n全 0:", torch.zeros(2, 2))          # 全 0
print("全 1:", torch.ones(2, 2))             # 全 1
print("随机:", torch.randn(2, 2))            # 标准正态随机
print("等差:", torch.arange(0, 6))           # [0,1,2,3,4,5]

预期输出要点：s.dim() 为 0；m.shape 为 torch.Size([2, 3])；x.dtype 为 torch.float32。

三、练习#

  1. 用 torch.zeros(3, 28, 28) 创建一个张量，回答：它的 dim 是几？shape 是什么？这个形状通常可以表示什么数据？
  2. 创建一个形状为 (4, 5)、全为 1 的 float32 张量，再把它转成 int64，打印两者的 dtype 对比。
  3. 判断题：torch.tensor(5) 是一个 0 维张量（标量），它的 shape 是 torch.Size([1])。这句话错在哪？
  4. 查阅你的机器是否支持 CUDA：运行 print(torch.cuda.is_available())，若为 True，尝试把一个张量 .to("cuda")，观察其 device 变化。
