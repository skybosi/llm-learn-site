极限的概念#

"极限"是微积分的第一块基石。导数和积分，本质上都建立在"无限逼近"这个想法之上。这一课我们不急着背定义，先用 Python 亲手"逼近"几次，让极限的直觉自然长出来。

一、概念讲解#

1. 极限的直觉：无限接近，但未必到达#

先看一个经典问题：函数

f(x) = sin(x) / x

当 x = 0 时，分子分母都是 0，0/0 没法直接算——函数在 0 这点"没有定义"。但如果我们让 x 从 1、0.5、0.1、0.01……一路越来越靠近 0，f(x) 会怎样？

直觉告诉我们：它越来越接近某个数。这个"越来越接近的目标值"，就是极限。

极限描述的是：当自变量无限逼近某一点时，函数值趋向于什么，而不是函数在该点真的等于什么。

用记号表示就是：

lim  f(x) = L
x→a

读作"当 x 趋向 a 时，f(x) 的极限是 L"。

2. 为什么要分"左极限"和"右极限"#

"逼近 0"可以从右边（x 取 0.1、0.01……），也可以从左边（x 取 -0.1、-0.01……）。如果两边逼近的结果一致，极限才存在；如果两边"对不上"，极限就不存在。

一个典型反例是符号函数：f(x) = 1（当 x>0），f(x) = -1（当 x<0）。从右边逼近 0 得 1，从左边逼近得 -1，两边不一致，所以 x→0 的极限不存在。理解这一点，下一课学"连续"会轻松很多。

3. 极限与机器学习#

你可能会问：极限这抽象概念，和 AI 有什么关系？

关系极大。机器学习的"梯度下降"本质就是：每走一小步，观察函数（损失函数）在这一步趋近的方向上是怎么变化的。导数的定义本身就是两个极限相除（下一章会讲）。先吃透"无限逼近"，导数就是水到渠成的事。

二、可运行示例#

下面我们用数值实验，亲眼看看 sin(x)/x 如何"逼近 1"。

import math

def f(x):
    """f(x) = sin(x) / x。注意：x=0 时不能直接算。"""
    return math.sin(x) / x

print("从右边逼近 0（x 越来越小）：")
x = 1.0
for _ in range(10):
    print(f"  x = {x:.8f}   f(x) = {f(x):.8f}")
    x = x / 2   # 每次减半，逐步靠近 0

print("\n从左边逼近 0（x 为负且越来越靠近 0）：")
x = -1.0
for _ in range(10):
    print(f"  x = {x:.8f}   f(x) = {f(x):.8f}")
    x = x / 2

运行结果（节选）：

从右边逼近 0（x 越来越小）：
  x = 1.00000000   f(x) = 0.84147098
  x = 0.50000000   f(x) = 0.95885108
  x = 0.25000000   f(x) = 0.98961584
  x = 0.03125000   f(x) = 0.99983725
  x = 0.00097656   f(x) = 0.99999984
  ...
从左边逼近 0（x 为负且越来越靠近 0）：
  x = -1.00000000   f(x) = 0.84147098
  x = -0.00097656   f(x) = 0.99999984
  ...

两边都在逼近同一个数：1。所以我们可以很有把握地写：

lim  sin(x)/x = 1
x→0

另一个实验：数列的极限#

极限不只在函数里，也在数列里。比如 a_n = 1/n：1、1/2、1/3、……越来越小，趋向 0。

print("\n数列 1/n 的前几项：")
for n in range(1, 8):
    print(f"  a_{n} = {1/n:.6f}")
print("  当 n 越来越大时，1/n 趋向 0 —— 记作 lim(1/n) = 0")

三、练习#

  1. 修改上面的代码，让 x 用 x = x / 10 逼近 0，观察逼近速度与用 / 2 时有什么不同（更快还是更慢？）。
  2. 用同样的"数值逼近"法，研究 f(x) = (1 - cos(x)) / x，猜一猜当 x→0 时它的极限是多少，再用 x 越来越小验证。
  3. 研究函数 g(x) = 1/x：分别让 x 从右边（正）和左边（负）逼近 0，观察两边的值分别趋向什么，思考这个极限是否存在。
  4. 想一想：sin(x)/x 在 x=0 处"没有定义"，但极限是 1。用你自己的话解释："函数值"和"极限值"为什么可以是两回事。
