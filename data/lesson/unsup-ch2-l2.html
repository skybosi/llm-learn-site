层次聚类实现#

一、概念讲解#

1.1 上一课的回顾#

上一课我们理解了凝聚式层次聚类的原理：每个样本自成一簇，然后反复合并"最亲近"的两个簇，直到合成一个簇。而"亲近"由链接准则（single / complete / average / ward）来定义。

这一课聚焦实现层面：用 sklearn 完整地跑通层次聚类，理解 AgglomerativeClustering 的关键参数，并重点体会 linkage 的选择如何改变聚类结果。

1.2 AgglomerativeClustering 关键参数#

sklearn 的 AgglomerativeClustering 主要参数如下：

  • n_clusters：最终要切出的簇数。注意，与 K-means 不同，这里的簇数只是"在哪一层切一刀"，并不改变"先建层级"这一根本过程。
  • linkage：链接准则，可选 'ward'、'complete'、'average'、'single'，默认 'ward'。
  • metric：样本间的距离度量，默认是欧氏距离（'euclidean'）；如果传入 'precomputed'，则表示输入的是已算好的距离矩阵。
  • distance_threshold：另一种"切割方式"。当设为某个非 None 值时，不再需要 n_clusters，而是把合并距离大于该阈值的簇视为不同簇。用它可以更直观地按"合并高度"切分。
  • compute_full_tree：是否构建完整的合并树。配合 distance_threshold 使用时很有用。

这里有一个 Ward 特有的注意点：Ward 准则要求使用欧氏距离，如果你指定 linkage='ward' 就不能用别的 metric（否则会报错）。这是很多人踩过的坑。

1.3 实现流程与 K-means 的对照#

工程上，层次聚类的实现流程和 K-means 有很多重叠：数据加载 → 标准化 → 选链接准则 → 决定簇数（或阈值）→ 训练 → 可视化。区别在于两处：

  1. K-means 用 init/n_init 管起点，层次聚类用 linkage 管"合并规则"；
  2. 层次聚类多了"距离阈值切割"这条路径，可以直接按合并高度决定簇数，这是 K-means 没有的。

下面的代码会同时展示 n_clusters 和 distance_threshold 两种用法，并可视化不同 linkage 的效果差异。

二、可运行代码示例#

# -*- coding: utf-8 -*-
# 第 2 课：层次聚类完整实现与 linkage 对比
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import AgglomerativeClustering
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_blobs

# 1. 生成数据：4 个球形簇，其中两个靠得较近
X, y_true = make_blobs(n_samples=400, centers=4,
                       cluster_std=0.9, random_state=42)

# 2. 标准化
X_scaled = StandardScaler().fit_transform(X)

# 3. 用 ward 准则，切到 4 个簇，做完整实现
model = AgglomerativeClustering(n_clusters=4, linkage="ward")
labels = model.fit_predict(X_scaled)
print("ward 准则下各簇样本数：",
      dict(zip(*np.unique(labels, return_counts=True))))

# 4. 用 distance_threshold 替代 n_clusters 的用法：
#    合并距离超过 6.0 就不再合并，簇数由算法自动决定
model2 = AgglomerativeClustering(
    linkage="ward", distance_threshold=6.0, n_clusters=None)
labels2 = model2.fit_predict(X_scaled)
print("distance_threshold=6.0 时自动得到的簇数：", len(np.unique(labels2)))

# 5. 对比不同 linkage 的聚类效果
fig, axes = plt.subplots(2, 2, figsize=(10, 8))
for ax, linkage in zip(axes.ravel(), ["single", "complete", "average", "ward"]):
    m = AgglomerativeClustering(n_clusters=4, linkage=linkage)
    lab = m.fit_predict(X_scaled)
    ax.scatter(X_scaled[:, 0], X_scaled[:, 1], c=lab, s=20, cmap="viridis")
    ax.set_title(f"linkage = {linkage}")
plt.tight_layout()
plt.show()

输出解读：四张子图展示了同一种数据在四种链接准则下的不同划分。对球形且分离度尚可的数据，ward、average、complete 通常都能给出比较合理的簇；而 single 由于"链式效应"容易把靠得近的两个簇串成一个大簇，或产生细长的异常簇。这正是链接准则影响力的直观体现。

提示：distance_threshold 与 n_clusters 只能二选一。当使用 distance_threshold 时，n_clusters 必须设为 None。
