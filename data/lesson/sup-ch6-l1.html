最大间隔原理#

前面学的决策树、集成方法都是"把空间切成一块块"来分类。支持向量机（Support Vector Machine，SVM）换了一个思路：在两类样本之间画一条最宽的"分界线"，让分界线离两边都尽量远。本课讲 SVM 的立身之本——最大间隔。

一、概念讲解#

1. 分类超平面与"间隔"#

在二维平面上，一个分类器就是一条直线；推广到高维，就是超平面（hyperplane）。能把两类样本完全分开的超平面通常不止一个——问题在于：选哪一条最好？

SVM 的回答是：选间隔（margin）最大的那条。间隔指的是超平面到它两侧最近样本点的距离之和。间隔越大，分界线离两边的"危险区域"越远，新样本被误分的概率通常越小，泛化能力越强。

2. 支持向量：决定分界线的少数派#

离超平面最近、恰好"撑"起间隔边界的那些样本，叫支持向量（support vectors）。SVM 的决策只由它们决定——其他离得远的样本，哪怕删掉也不影响分界线。这也解释了 SVM 的一个特性：模型由少数关键样本定义，与训练集大小关系不大（当维度较高时尤其明显）。

3. 硬间隔与软间隔#

  • 硬间隔（hard margin）：要求所有样本都被严格正确分类、且落在间隔之外。只有数据线性可分且无噪声时才做得到，现实数据很少满足。
  • 软间隔（soft margin）：允许少量样本进入间隔、甚至被分错，用一个参数 C 来控制"犯错"的代价：
    • C 大 → 惩罚重，倾向于严格分类，边界更"贴身"，容易过拟合；
    • C 小 → 容忍更多误分，边界更宽、更平滑，泛化更好。

4. 优化目标：平衡"间隔大"与"犯错少"#

SVM 的训练可概括为一个目标：在"让间隔尽量大"和"让误分尽量少"之间折中，由 C 加权。数学上这等价于最小化一个由正则项（间隔的倒数）加合页损失（hinge loss）组成的凸目标，因此能高效求解，且解是唯一的（线性可分情形下）。

5. 为什么是"最大"间隔#

从直觉与理论上，间隔越大，分类器对样本扰动的容忍度越高。可以把间隔理解为"安全垫"：垫子越厚，落在分界线附近的新样本越不容易翻到错误的一边。

二、可运行代码示例#

from sklearn.datasets import make_blobs
from sklearn.svm import SVC
import numpy as np

# 1. 生成线性可分的两类数据
X, y = make_blobs(n_samples=60, centers=2, random_state=6, cluster_std=1.0)

# 2. 用线性核 SVC 训练，C 取一个较大值（偏"硬"）
model = SVC(kernel="linear", C=1e5)
model.fit(X, y)

# 3. 打印模型的关键信息
print("支持向量个数：", model.support_vectors_.shape[0])
print("权重向量 w：", np.round(model.coef_[0], 3))
print("偏置 b：", np.round(model.intercept_, 3))

# 4. 分别用不同 C 值训练，观察支持向量数量的变化
for C in [0.01, 0.1, 1, 10, 1e5]:
    m = SVC(kernel="linear", C=C)
    m.fit(X, y)
    print("C={:<8} 支持向量数={}".format(C, m.support_vectors_.shape[0]))

要点：support_vectors_ 给出了真正"撑起"分界线的样本；C 越小（越软），容忍的误分越多、间隔越宽，参与决策的支持向量通常也越多。

三、练习#

  1. 修改 cluster_std（如 1.0、1.8、2.5），让两类数据混叠更严重，观察相同 C 下支持向量数量和准确率的变化。
  2. 固定数据，把 C 从 0.001 一路调到 10000，记录测试准确率与支持向量数，试着画出"准确率-C"的趋势并解释。
  3. 用 make_classification 生成一个类别重叠更强的数据集，对比软间隔 SVM 与"要求严格分类"的大 C 模型，哪个在测试集上更稳？
  4. 思考题：为什么说"SVM 的决策只由支持向量决定"？删除一个远离分界线的普通样本，会改变模型吗？删除一个支持向量呢？

为什么这样做？——理论推导#

从几何间隔推出 SVM 最大间隔优化问题#

先问"为什么"。 前面说"选间隔最大的那条线"，但这句口号背后有三个必须钉死的技术问题：(1) "间隔"怎么度量才不会被随意放大？(2) 为什么要最大化它？(3) 最大化间隔如何变成一个可求解的优化问题？

函数间隔 vs 几何间隔：为什么要区分。 对超平面 wᵀx + b = 0，样本 xᵢ 的函数间隔定义为：

γ̂ᵢ = yᵢ · (wᵀxᵢ + b)

它为正说明分类正确、绝对值越大说明"越确信"。但它有一个致命缺陷：把 w、b 同时放大 c 倍，超平面纹丝不动，函数间隔却凭空放大 c 倍——它随参数缩放，不能当"距离"用。真正的距离是把法向量单位化后的几何间隔：

γᵢ = yᵢ · (wᵀxᵢ + b) / ||w||

几何意义：|wᵀxᵢ + b| / ||w|| 正是点 xᵢ 到超平面的欧氏距离（点到平面距离公式），乘 yᵢ 只是带上符号。它是缩放不变的——这才是我们要最大化的对象。

为什么要最大化几何间隔？ 距离越远，决策函数在样本附近的"变化余地"越大：样本 x 发生小扰动 δx 时，wᵀ(x+δx)+b 要跨过 0 至少需要扰动超过 γ·||w||，决策才可能翻转。间隔大 = 决策对噪声鲁棒、对未见样本的泛化信心更高——统计学习理论中，间隔还直接出现在泛化误差的上界里。所以"最宽的带子"不只是直觉，而有理论背书。

固定尺度，推出优化问题。 几何间隔缩放不变，意味着我们可以自由选定参数尺度而不改变超平面。约定：把所有样本的函数间隔压到至少为 1：

yᵢ · (wᵀxᵢ + b) ≥ 1，对所有 i

（总能通过整体缩放 w、b 做到）。在此约束下，最小的函数间隔恰为 1，于是分类器的几何间隔退化为：

γ = minᵢ γᵢ = (1 / ||w||) · minᵢ yᵢ(wᵀxᵢ+b) = 1 / ||w||

最大化 γ，即最小化 ||w||。 为方便求导，平方再乘 1/2（单调变换，不改变最优点），得到硬间隔 SVM 的标准形式：

min    (1/2) · ||w||²
s.t.   yᵢ(wᵀxᵢ + b) ≥ 1，i = 1, …, m

这是一个凸二次规划：目标凸、约束线性，解存在且唯一，可用拉格朗日对偶高效求解。而"撑起"这个解的，正是约束取等号的那些"贴边"样本——支持向量（在对偶解里只有它们有非零系数）。

母原理连接： "最大化几何间隔"被等价改写为"最小化 (1/2)||w||²"——这是"用参数范数表达泛化偏好"的实例，与后面正则化（L2）同源：约束参数不要太大，换取决策边界对数据的"宽松"与稳定。SVM 只是把这条母原理做成了带约束的凸优化，再借对偶与核技巧推向高维与非线性。
