反向传播算法#

反向传播就是"沿着计算图倒着走"：从输出端开始，把每一层的局部梯度与上游梯度相乘，一层层传回输入端，从而一次性算出所有参数的梯度。

一、概念讲解#

1. 从链式法则到反向传播#

上一课我们看到，损失 L 对某个参数 w 的导数，是沿计算图路径上所有局部梯度的乘积。但一个神经网络有成千上万个参数，如果对每个参数都从头算一遍链式法则，会有大量重复计算。

反向传播（backpropagation）的关键洞察是：中间节点的梯度只算一次，然后共享给所有下游路径。它从输出端出发，逆着计算图的方向，逐层把梯度"分发"给每个节点。

2. 核心规则：上游梯度 × 局部梯度#

反向传播每走一步，用的都是同一条式子：

本节点收到的梯度 = 上游传来的梯度 × 本节点对输入的局部偏导

如果某个节点同时影响多个输出，那么它从各条路径收到的梯度要相加（对应链式法则里的"路径求和"）。这就是为什么实现时用 grad += 累加，而不是赋值覆盖。

3. 拓扑排序 + 逆序传播#

要正确地反向传播，需要先做一次拓扑排序：保证每个节点在"自己的所有子节点都被访问过之后"才被处理。然后从输出节点（梯度设为 1）开始，逆序依次执行每个节点的局部梯度传播。这个顺序天然满足"先算完依赖，再算依赖它的人"。

4. 解析梯度 vs 数值梯度#

  • 反向传播算出的是解析梯度：精确、快速，适合训练时反复使用；
  • 数值梯度（给参数加一个极小扰动再算损失变化）虽然慢且有小误差，但实现简单、几乎不会错，常用来做梯度检查（gradient check）——验证反向传播写对了没有。

二、可运行示例#

示例 1：实现一个最小的自动求导引擎#

下面的 Node 类支持加法和乘法，并实现了 backward()：先拓扑排序，再逆序传播梯度。

class Node:
    """计算图节点：存数值、子节点与运算名，反向传播时累加梯度。"""
    def __init__(self, value, children=(), op="", label=""):
        self.value = value
        self.grad = 0.0                 # 反向传播时累加的梯度
        self.children = tuple(children) # 产生本节点的子节点
        self.op = op                    # 运算名（仅用于阅读）
        self.label = label              # 便于阅读的名字
        self._backward = lambda: None   # 局部梯度传播函数，稍后填入

    def __add__(self, other):
        out = Node(self.value + other.value, (self, other), "+")
        def _backward():
            # z = a + b => dz/da = 1, dz/db = 1
            self.grad += 1.0 * out.grad
            other.grad += 1.0 * out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        out = Node(self.value * other.value, (self, other), "*")
        def _backward():
            # z = a * b => dz/da = b, dz/db = a
            self.grad += other.value * out.grad
            other.grad += self.value * out.grad
        out._backward = _backward
        return out

    def __neg__(self):
        return self * Node(-1.0, label="-1")

    def __sub__(self, other):
        return self + (-other)

    def backward(self):
        # 1) 拓扑排序：先访问所有子节点，再把自己加入列表
        topo = []
        seen = set()
        def visit(n):
            if n not in seen:
                seen.add(n)
                for c in n.children:
                    visit(c)
                topo.append(n)
        visit(self)
        # 2) 输出对自己的梯度设为 1，然后逆序逐层传播
        self.grad = 1.0
        for n in reversed(topo):
            n._backward()

# 测试：f = x * y + y，求 df/dx 与 df/dy
x = Node(2.0, label="x")
y = Node(3.0, label="y")
f = x * y + y
f.backward()

print("f =", f.value)
print("df/dx =", x.grad)   # 期望 y = 3
print("df/dy =", y.grad)   # 期望 x + 1 = 3

示例 2：单神经元的反向传播#

用同一个引擎，对"线性输出 + 平方损失"求 dL/dw 和 dL/db。

w = Node(1.0, label="w")
x = Node(0.5, label="x")
b = Node(0.0, label="b")
y_true = Node(1.0, label="y_true")

z = w * x + b        # 线性输出 z = w*x + b
d = z - y_true       # 误差 d = z - y
L = d * d            # 平方损失 L = d²

L.backward()
print("dL/dw =", w.grad)   # 2*(z - y_true)*x = -0.5
print("dL/db =", b.grad)   # 2*(z - y_true) = -1.0

示例 3：数值梯度检查#

给 w 加一个极小扰动，用数值差分估算 dL/dw，与反向传播结果对照，确认引擎实现正确。

def loss_value(w_val):
    # 复用同样的计算结构，只换掉 w 的数值
    w2 = Node(w_val, label="w")
    z2 = w2 * x + b
    d2 = z2 - y_true
    return (d2 * d2).value

eps = 1e-6
num_grad = (loss_value(w.value + eps) - loss_value(w.value - eps)) / (2 * eps)
print("反向传播 dL/dw =", w.grad)
print("数值差分 dL/dw ≈", round(num_grad, 6))
print("两者接近，说明反向传播实现正确。")

三、练习#

  1. 用示例 1 的 Node 类计算 f = (a * b) + (a * c)（a=2, b=3, c=4）的 df/da、df/db、df/dc，并手算验证。
  2. 给 Node 增加一个 square() 运算（z = a²，局部梯度 2a），然后用它重写示例 2 的损失，看结果是否一致。
  3. 解释为什么 backward() 里要用 grad += 累加而不是直接赋值——结合一个节点同时影响多个输出的场景说明。
