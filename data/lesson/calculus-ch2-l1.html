导数的定义与几何意义#

欢迎进入微积分最核心的一章。导数回答的是一个每天都在发生的问题："现在变化得有多快？" 车速表显示的是位移的变化率，而机器学习里"损失下降得有多快"正是梯度下降的发动机。这一课我们先搞懂导数到底是什么。

一、概念讲解#

1. 从"平均变化率"到"瞬时变化率"#

想象一辆车在一条直路上跑，位置随时间变化，记作 s(t)。

  • 从第 2 秒到第 4 秒，它走了 60 米，那么平均速度 = 60 / 2 = 30 m/s。
  • 但"平均速度"会掩盖细节：也许它中途猛踩油门又急刹车。我们更想知道第 3 秒这一瞬间的速度——瞬时速度。

瞬时速度怎么算？直觉是：把时间间隔取得越来越短，平均速度就会越来越接近"那一瞬间"的速度。这正是一个极限：

s'(t) = lim   s(t+h) - s(t)
        h→0   ---------------
                     h

这个极限值，就是 s(t) 在 t 处的导数，记作 s'(t) 或 ds/dt。它刻画的是函数瞬时的变化快慢。

2. 几何意义：切线的斜率#

把函数 y = f(x) 画成曲线。取曲线上两点，连成一条割线，割线的斜率就是"平均变化率"。当我们让第二个点沿着曲线无限靠近第一个点，割线就旋转成一条切线，切线的斜率就是导数。

导数的几何意义：曲线在该点切线的斜率。 斜率越大，曲线在该点越"陡"，函数变化越快。

3. 导数与机器学习：梯度下降的第一步#

机器学习训练模型时，要最小化损失函数 L(w)（w 是参数）。我们想知道：把 w 调大一点点，损失会变多还是变少？ 答案就在导数里：

  • 如果 L'(w) > 0，说明 w 增大时损失增大，就该把 w 调小；
  • 如果 L'(w) < 0，说明 w 增大时损失减小，就该把 w 调大。

导数告诉我们"往哪个方向走、走多快"，这正是梯度下降的核心。单参数的导数是"一维版"的梯度；下一章会推广到多维。

二、可运行示例#

下面我们用数值方法求导数，并直观地看它和切线的关系。

def derivative(f, x, h=1e-5):
    """用中心差分近似求 f 在 x 处的导数 f'(x)。"""
    return (f(x + h) - f(x - h)) / (2 * h)

# f(x) = x^2，它的真实导数是 f'(x) = 2x
def f(x):
    return x * x

print("f(x)=x^2 的数值导数 vs 真实导数(2x)：")
for x in [1, 2, 3, 4]:
    approx = derivative(f, x)
    exact = 2 * x
    print(f"  x={x}: 数值={approx:.6f}  真实={exact}  误差={abs(approx-exact):.2e}")

# 体会"平均变化率 -> 瞬时变化率"的逼近过程
print("\n在 x=1 处，用越来越小的 h 计算差商：")
for h in [0.5, 0.1, 0.01, 0.001, 0.0001]:
    slope = (f(1 + h) - f(1)) / h   # 前向差商
    print(f"  h={h:<7} 差商={slope:.6f}  （真实导数 = 2）")

运行结果（节选）：

f(x)=x^2 的数值导数 vs 真实导数(2x)：
  x=1: 数值=2.000000  真实=2  误差=0.00e+00
  x=2: 数值=4.000000  真实=4  误差=0.00e+00
  x=3: 数值=6.000000  真实=6  误差=0.00e+00
  x=4: 数值=8.000000  真实=8  误差=0.00e+00

在 x=1 处，用越来越小的 h 计算差商：
  h=0.5    差商=2.500000  （真实导数 = 2）
  h=0.1    差商=2.100000  （真实导数 = 2）
  h=0.01   差商=2.010000  （真实导数 = 2）
  h=0.001  差商=2.001000  （真实导数 = 2）
  h=0.0001 差商=2.000100  （真实导数 = 2）

看下半部分：h 越小，差商越接近 2——这就是"极限"在起作用，也是数值求导的原理。

用一个"不光滑"函数体会导数不存在#

绝对值函数 f(x)=|x| 在 x=0 处有一个"尖角"，在那里切线无法唯一确定，所以导数不存在。我们看看数值上会发生什么：

def abs_f(x):
    return abs(x)

print("\nf(x)=|x| 在 x=0 处的左右差商：")
h = 1e-6
left_slope = (abs_f(0) - abs_f(0 - h)) / h    # 左侧斜率
right_slope = (abs_f(0 + h) - abs_f(0)) / h   # 右侧斜率
print(f"  左侧斜率 = {left_slope}")
print(f"  右侧斜率 = {right_slope}")
print("  左右不一致 → 在 x=0 处导数不存在（尖点）")

三、练习#

  1. 用 derivative 求 f(x) = x³ 在 x = 2 处的数值导数，和真实公式 3x² 对比，验证误差很小。
  2. 用前向差商 (f(x+h)-f(x))/h 重写 derivative，对比它和中心差商在相同 h 下的精度（哪个更接近真实值？）。
  3. 定义损失函数 L(w) = (w - 3)²（一个"希望 w 靠近 3"的损失）。分别计算 L'(1) 和 L'(5) 的数值，根据正负判断"w 该调大还是调小"，体会导数是梯度下降的"指南针"。
  4. 想一想：为什么"尖点"处导数不存在？用"左右切线斜率不一致"这句话向朋友解释。
