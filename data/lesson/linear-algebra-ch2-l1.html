矩阵的概念与表示#

从这一章开始，我们从"单个向量"升级到"一批向量"。把多个向量整齐地排成一个矩形表格，就得到了矩阵（matrix）。矩阵是机器学习的核心数据结构：一个数据集、一张灰度图片、一层神经网络的权重，本质上都是矩阵。这一课我们先认识它长什么样，以及如何在 Python 里创建和查看它。

一、概念讲解#

1. 什么是矩阵#

矩阵是一个按行（row） 和列（column） 排列的数字表格。比如：

A = [ 1  2  3 ]
    [ 4  5  6 ]

这是一个 2 行 3 列 的矩阵，记作 2×3 矩阵。其中：

  • 第 1 行是 (1, 2, 3)；
  • 第 2 行是 (4, 5, 6)；
  • 第 1 列是 (1, 4)；
  • 第 2 列是 (2, 5)；
  • 第 3 列是 (3, 6)。

一般用大写字母（如 A、W、X）表示矩阵，矩阵中的每个数叫元素，位于第 i 行第 j 列的元素记作 aᵢⱼ。

矩阵的"尺寸"由行数 × 列数决定，这个尺寸叫做矩阵的形状（shape）。上面 A 的形状就是 (2, 3)。

2. 矩阵 = 一排向量#

把矩阵看成"向量的集合"，能极大帮助你理解后面的运算：

  • 按行看：矩阵的每一行是一个行向量；
  • 按列看：矩阵的每一列是一个列向量。

所以 (2, 3) 矩阵 A 既可以看成 2 个三维行向量叠起来，也可以看成 3 个二维列向量并排。

3. 机器学习中的矩阵#

  • 数据集：假设有 100 条样本，每条样本有 3 个特征。把 100 条样本一行一行地写下来，就得到一个 100×3 的特征矩阵。习惯上，"一行 = 一条样本，一列 = 一个特征"。
  • 权重矩阵：神经网络每一层之间的连接权重就是一个矩阵。比如输入层有 3 个神经元、下一层有 4 个神经元，那么两层之间的权重就是一个 4×3（或 3×4，取决于约定）的矩阵，每个元素代表一条连接的强度。
  • 图片：一张灰度图就是"每个像素一个数字"的矩阵，行列对应像素坐标；彩色图则是三个矩阵叠起来（RGB 三个通道）。

4. 常用特例#

  • 方阵：行数等于列数的矩阵（如 3×3），后面学的"逆矩阵"只对方阵定义。
  • 单位矩阵：对角线上全是 1、其余全是 0 的方阵，记作 I。它相当于"矩阵世界的 1"。
  • 零矩阵：所有元素都是 0。
  • 对角矩阵：只有主对角线（左上到右下）上有非零值。

二、可运行示例#

下面用 NumPy 创建矩阵，并把它理解成一个"数据集"。

import numpy as np

# 1) 用嵌套列表创建矩阵：外层列表的每个元素是一行
X = np.array([
    [120.0, 3.0, 5.0],    # 样本 0：面积、房间数、房龄
    [90.0,  2.0, 10.0],   # 样本 1
    [150.0, 4.0, 2.0],    # 样本 2
])
print("特征矩阵 X =")
print(X)
print("形状 shape =", X.shape)       # (3, 3)：3 行（样本）× 3 列（特征）

# 2) 用下标访问单个元素：X[行, 列]
print("第 2 个样本的房间数 =", X[1, 1])   # 第 1 行第 1 列，值为 2.0

# 3) 切片：取一整行（一条样本）或一整列（一个特征）
sample0 = X[0, :]        # 第 0 行所有列 → 一条完整样本
feature1 = X[:, 1]       # 所有行的第 1 列 → 所有样本的"房间数"特征
print("样本 0 =", sample0)
print("所有样本的房间数特征 =", feature1)

# 4) 特殊矩阵：单位矩阵、零矩阵
I = np.eye(3)            # 3×3 单位矩阵
Z = np.zeros((2, 3))     # 2×3 全零矩阵
print("单位矩阵 I =")
print(I)
print("零矩阵 Z =")
print(Z)

# 5) 改变形状：把 3×3 拉平成 9 个元素的向量，或反过来
flat = X.reshape(-1)     # -1 表示"自动计算剩下的维度"
print("拉平后的向量 =", flat)
print("拉平后形状 =", flat.shape)   # (9,)

预期输出（大意）：

特征矩阵 X =
[[120.   3.   5.]
 [ 90.   2.  10.]
 [150.   4.   2.]]
形状 shape = (3, 3)
第 2 个样本的房间数 = 2.0
样本 0 = [120.   3.   5.]
所有样本的房间数特征 = [3. 2. 4.]
单位矩阵 I =
[[1. 0. 0.]
 [0. 1. 0.]
 [0. 0. 1.]]
零矩阵 Z =
[[0. 0. 0.]
 [0. 0. 0.]]
拉平后的向量 = [120.   3.   5.  90.   2.  10. 150.   4.   2.]
拉平后形状 = (9,)

要点：np.array 传嵌套列表时，外层列表长度 = 行数，内层列表长度 = 列数；shape 永远按"（行数, 列数）"的顺序；X[行, 列] 用逗号分隔两个下标，切片 : 表示"取全部"。
