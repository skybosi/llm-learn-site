GAT 注意力#

GCN 给邻居分配的权重是预先算死的：1/sqrt(d_v · d_u)，只由图的度数结构决定，与节点特征、与当前任务毫无关系。GraphSAGE 的均值/池化聚合器虽然更灵活，但对不同邻居依然"一视同仁"。一个自然的疑问是：能不能让模型自己决定该多听哪个邻居的意见？

这就是图注意力网络（Graph Attention Network，GAT）的回答。它把 Transformer 里大名鼎鼎的注意力机制搬到图上，给每条边学出一个"重要性权重"——重要且相似的邻居被放大，无关或异质的邻居被抑制。更重要的是，这个权重是内容相关、逐边不同的，模型能根据节点特征动态地"看人下菜碟"。

一、概念讲解#

1. 直觉：给每条边一个"音量旋钮"#

想象节点 i 要听取它所有邻居的意见。有的邻居和它同属一个社区、特征相近，意见更可信；有的邻居是"噪音"，甚至是连接两个社区的桥梁节点，意见要打折。GAT 的做法是给每条边 (i, j) 装一个音量旋钮 α_ij，最终 i 的新表示是所有邻居表示的加权求和：

h_i' = σ( Σ_{j ∈ N(i)} α_ij · W h_j )

其中 α_ij ≥ 0 且 Σ_j α_ij = 1（对每个节点归一化成一个概率分布）。旋钮开多大，由注意力机制算出来，而不是靠人工或固定公式。

2. 逐步推导注意力系数#

设节点 i 的输入特征为 h_i（维度 F）。GAT 的注意力计算分四步：

第一步：共享线性变换。 所有节点先过同一个权重矩阵 W，把特征映射到维度 F'：

h_i' = W · h_i          (W ∈ R^(F' × F))

第二步：成对计算注意力得分。 对每条边 (i, j)，把两端的变换后特征拼起来，再与一个可学习向量 a（维度 2F'）做内积，经过 LeakyReLU：

e_ij = LeakyReLU( a^T · [ W h_i ‖ W h_j ] )

‖ 表示拼接，a 是注意力机制的"打分器"参数。这个得分的含义是"节点 j 对节点 i 有多重要"。

第三步：softmax 归一化。 为了让权重可比、可解释，对每个节点 i，把它的所有邻居得分归一化成概率：

α_ij = softmax_j( e_ij ) = exp( e_ij ) / Σ_{k ∈ N(i)} exp( e_ik )

注意归一化只针对 i 的邻居做（图结构在这里起到了"mask"的作用），这与 Transformer 里对全序列做 softmax 不同。

第四步：加权聚合。 用 α_ij 作为权重对邻居求和，过非线性激活：

h_i'' = σ( Σ_{j ∈ N(i)} α_ij · W h_j )

3. 多头注意力：多套旋钮并行#

单个注意力头可能学得不够稳（一次 softmax 容易"押注"某几个邻居）。GAT 借鉴 Transformer 的多头（multi-head）做法：并行跑 K 套独立的 (W^k, a^k)，各自算出权重再聚合：

h_i'' = ‖_{k=1..K} σ( Σ_{j} α_ij^k · W^k h_j )     （中间层：拼接）

最后一层（预测层）通常把多头的输出取平均而不是拼接，保证输出维度不变。多头让不同"头"可以关注不同类型的邻居关系（一个头关注同主题，一个头关注高被引），整体更鲁棒。

4. 为什么注意力"有效"：知其所以然#

这里不能只背公式，要理解它到底解决了什么：

  • 内容相关、逐边自适应：GCN 的 1/sqrt(d_v d_u) 只跟度数有关，两个邻居只要度数相同就分到同样的权重，哪怕一个和中心节点毫无共同点。GAT 的 α_ij 由两端特征共同决定，能把"特征不相关"的邻居权重压到接近 0，起到软性过滤噪音的作用。
  • 方向感知（非对称）：α_ij ≠ α_ji 通常是成立的，因为打分器里的 W h_i 和 W h_j 位置不同。这让"谁向谁传递信息"有了方向性，比 GCN 对称的权重更细腻。
  • 不需要预知全局结构：GCN 需要预先算好整张图的归一化拉普拉斯；GAT 只需要每个节点的局部邻居（用于 softmax 的 mask），权重完全由参数和特征即时算出。这使得 GAT 具备一定的归纳能力，也能较自然地用于新图。
  • 可解释性：α_ij 就是一条边的重要性分数。训练后可以把注意力可视化，看模型认为哪些边是"关键连接"，这对理解模型行为很有价值。

5. 一个已知局限与 GATv2 的修正#

原版 GAT 有个被后续研究指出的问题——静态注意力（static attention）：因为 a^T[Wh_i‖Wh_j] 可以整理成 a_1^T(Wh_i) + a_2^T(Wh_j)，当打分函数线性可分时，最终"谁最受关注"可能退化为只由"某个全局的键（key）节点"决定，而与查询节点 i 无关，表达能力受限。GATv2 的修正很简单：先拼接再做一次非线性变换，再打分，把 a 从向量换成一个小网络，使注意力真正随查询节点 i 动态变化。工程上若遇到注意力"学不动"、所有节点关注同一个邻居的情况，可考虑换用 GATv2。

二、可运行示例#

示例：用 PyG 的 GATConv 在 Cora 上做节点分类

import torch
import torch.nn.functional as F
from torch_geometric.nn import GATConv
from torch_geometric.datasets import Planetoid

dataset = Planetoid(root='./data/Cora', name='Cora')
data = dataset[0]

# 定义两层 GAT：第一层 8 个头（concat），第二层 1 个头（用于分类）
class GAT(torch.nn.Module):
    def __init__(self, in_ch, hidden_ch, out_ch):
        super().__init__()
        # heads=8：输出维度 = hidden_ch * 8（多头拼接）
        self.conv1 = GATConv(in_ch, hidden_ch, heads=8, dropout=0.6)
        # 第二层常用 1 个头 + 平均，输出维度 = hidden_ch（可加 concat=False）
        self.conv2 = GATConv(hidden_ch * 8, out_ch, heads=1,
                             concat=False, dropout=0.6)

    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.elu(x)                    # GAT 论文里用的是 ELU
        x = F.dropout(x, p=0.6, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)

model = GAT(dataset.num_features, 8, dataset.num_classes)
optimizer = torch.optim.Adam(model.parameters(), lr=0.005, weight_decay=5e-4)

def train():
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()
    return loss.item()

def evaluate():
    model.eval()
    out = model(data.x, data.edge_index)
    pred = out.argmax(dim=1)
    return [(int((pred[m] == data.y[m]).sum()) / int(m.sum()))
            for m in [data.train_mask, data.val_mask, data.test_mask]]

for epoch in range(200):
    loss = train()
    if epoch % 20 == 0:
        tr, va, te = evaluate()
        print(f'Epoch {epoch:03d} | Loss {loss:.4f} | '
              f'Train {tr:.4f} | Val {va:.4f} | Test {te:.4f}')

测试集准确率通常能到 0.80 上下，与同规模的 GCN/GraphSAGE 相当；注意力模型的优势在需要区分邻居重要性、或图里有大量异质邻居时会更明显。

观察注意力权重：把 GATConv 换成 GATConv(..., edge_dim=None) 的普通版本后，可以访问内部 alpha_ 属性查看每条边的注意力分数，验证"同类邻居权重更高"的直觉。

三、练习#

  1. 逐步推导：给定 W h_i、W h_j 和向量 a，写出 e_ij、α_ij、h_i'' 的完整计算过程，并指出 softmax 是在哪个集合上做的。
  2. 对比 GCN：GCN 的邻居权重是 1/sqrt(d_v d_u)，GAT 的权重是 α_ij。从"是否依赖特征""是否对称""是否需要预知全局结构"三个维度，列出两者差异。
  3. 多头的作用：把 heads 从 8 改成 1，重跑实验，观察准确率和训练稳定性的变化，并解释多头注意力的意义。
  4. 归一化范围：如果 softmax 改成对整张图所有节点做（而非仅邻居），注意力会发生什么变化？这样做的优缺点各是什么？
  5. 探究 GATv2：查阅 GATv2 论文，用自己的话解释"静态注意力"问题，并说明它是如何通过改变打分函数的次序来修正的。
