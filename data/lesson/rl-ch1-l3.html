马尔可夫决策过程 MDP#

前两课我们有了"智能体-环境"的直觉和"回报"的定义，但它们还停留在文字层面。要把强化学习变成一门能推导、能编程的科学，必须把环境那口"黑箱"翻译成精确的数学对象——这就是马尔可夫决策过程（Markov Decision Process, MDP）。MDP 是强化学习的"公理系统"：几乎所有算法都以它为地基。本课我们把这个五元组 (S, A, P, R, γ) 逐一拆解，重点搞懂那个被称为"环境模型"的动力学函数 p(s', r | s, a)，以及它如何通过边缘化派生出另外两个常用量。

一、概念讲解#

1. 马尔可夫性质：未来只取决于现在#

MDP 的第一个假设叫马尔可夫性质（Markov property）：

P( S_{t+1} | S_t, A_t ) = P( S_{t+1} | S_0, A_0, …, S_t, A_t )

读作：给定当前状态和当前动作，下一状态的概率分布与更早的历史无关。 换句话说，"现在"已经包含了所有对未来有用的信息，过去可以完全丢掉。

这个假设是一个建模选择，而非天然成立的事实。现实中，机器人此刻的位置未必包含"它三秒前的速度"这一信息；但只要我们把状态定义得足够"丰富"（把速度也塞进状态向量），马尔可夫性质就能近似成立。"状态设计得好不好"，很大程度上就是"马尔可夫性质成立得有多好"。这个假设之所以关键，是因为它保证：最优决策只需基于当前状态，无需回看整段历史——这使后面所有递推（贝尔曼方程）成为可能。

2. 五元组：MDP 的正式定义#

一个有限 MDP 由五样东西构成：

MDP = (S, A, P, R, γ)
  • 状态集 S：环境所有可能状态的集合（有限集）。
  • 动作集 A：智能体可选的有限动作集合。
  • 动力学 P：给定 (s, a) 后，转移到 s' 并获得奖励 r 的概率（下面展开）。
  • 奖励 R：即时奖励信号。
  • 折扣因子 γ ∈ [0, 1]：上一课引入的折扣旋钮。

其中 P 和 R 合起来，就是"环境"这个黑箱的完整说明书。强化学习的一个核心分支——基于模型（model-based） 的方法——假设这两样已知；而 免模型（model-free） 方法则假设未知、只能靠试错去"估"。动态规划（第 3 章）属于前者，蒙特卡洛和 TD（第 4 章）属于后者。是否知道 P 和 R，几乎决定了算法长什么样。

3. 动力学函数 p(s', r | s, a)：环境模型的核心#

环境模型用一个四元条件概率来精确刻画：

p(s', r | s, a) = P( S_{t+1} = s', R_{t+1} = r  |  S_t = s, A_t = a )

它的含义是："如果当前在状态 s、选了动作 a，那么下一状态是 s'、同时奖励是 r 的概率是多少。" 注意它把"下一状态"和"奖励"绑在一起看——因为现实中奖励往往和"去了哪里"同时发生。

它必须满足概率的基本约束：

Σ_{s' ∈ S} Σ_{r ∈ R} p(s', r | s, a) = 1       （对任意 s, a）

p(s', r | s, a) 是 MDP 里最底层、最完备的量。下面所有东西都能由它推出来。

4. 由 p 派生出三个常用量：边缘化#

"知其所以然"的时刻来了。工程上我们更常用下面三个"简化版"的量，而它们全部由 p(s', r | s, a) 边缘化（求和消除某个变量）得到。这是概率论里"边缘分布"的直接应用。

① 状态转移概率 p(s' | s, a)——只关心"去哪儿"，不管"得几分"：把奖励 r 求和消掉即可。

p(s' | s, a) = Σ_r p(s', r | s, a)

② 期望奖励 r(s, a)——只关心"这一步平均得几分"，把 s' 和 r 一起压缩成期望：

r(s, a) = E[ R_{t+1} | S_t = s, A_t = a ] = Σ_r r · Σ_{s'} p(s', r | s, a)

③ 三参数期望奖励 r(s, a, s')——在"已知去了 s'"条件下奖励的期望：

r(s, a, s') = E[ R_{t+1} | S_t = s, A_t = a, S_{t+1} = s' ]
            = Σ_r r · p(s', r | s, a) / p(s' | s, a)

其中 p(s', r | s, a) / p(s' | s, a) 是条件概率公式 P(r | s') = P(s', r)/P(s') 的直接应用。这几个量在贝尔曼方程里会反复出现：写状态价值方程时用 r(s, a) 形式，写动作价值方程时常用 r(s, a, s') 形式。理解了"它们都是 p 的边缘化"，你就不会在几种记法之间迷路。

5. 一个具体例子：三状态链式 MDP#

为了让抽象落地，构造一个最小的链式 MDP：三个状态 {s0, s1, s2}，一个动作集 {a0, a1}，奖励只有 0 或 1。设（这里是人为规定的环境说明书）：

  • 在 s0 选 a0：以概率 1 去 s1，得奖励 0；
  • 在 s0 选 a1：以概率 1 去 s0（原地），得奖励 0；
  • 在 s1 选 a0：以 0.5 去 s0、0.5 去 s2，都奖励 0；
  • 在 s1 选 a1：以概率 1 去 s2，得奖励 1；
  • s2 是终止状态（吸收），任何动作都回到自身、得 0。

于是比如 p(s'=s0, r=0 | s=s1, a=a0) = 0.5。把这些数填进一个表格或矩阵，就是"环境模型"。下一节代码就把这张表建出来，并验证第 4 节的三条边缘化公式。

二、可运行代码示例#

用 NumPy 把上面这个三状态 MDP 编码成"动力学张量"，然后①按它采样轨迹，②验证 p(s'|s,a)、r(s,a)、r(s,a,s') 三条边缘化公式。

import numpy as np

rng = np.random.default_rng(0)

# 状态 s0,s1,s2 编号为 0,1,2；动作 a0,a1 编号为 0,1；奖励只有 0 或 1
nS, nA = 3, 2
rewards = [0.0, 1.0]                    # 可能的奖励值

# P[a, s, s', r] = p(s', r | s, a)，即动力学张量
P = np.zeros((nA, nS, nS, len(rewards)))

# s0: 任意动作都不给奖励
P[0, 0, 1, 0] = 1.0   # s0, a0 -> s1, r=0
P[1, 0, 0, 0] = 1.0   # s0, a1 -> s0, r=0
# s1
P[0, 1, 0, 0] = 0.5   # s1, a0 -> s0, r=0
P[0, 1, 2, 0] = 0.5   # s1, a0 -> s2, r=0
P[1, 1, 2, 1] = 1.0   # s1, a1 -> s2, r=1
# s2: 吸收状态，任何动作都留在原地、奖励 0
P[0, 2, 2, 0] = 1.0
P[1, 2, 2, 0] = 1.0

# ---- ① 由 P 边缘化出 p(s'|s,a) 和 r(s,a) ----
# 对奖励求和 -> 状态转移概率；对 (s',r) 加权求和 -> 期望奖励
p_snext = P.sum(axis=3)                 # 形状 (nA, nS, nS)：p(s'|s,a)
r_sa = (P * np.array(rewards)).sum(axis=(2, 3))  # 形状 (nA, nS)：r(s,a)
print("状态转移概率 p(s'|s,a)（每行和为 1）：")
print(p_snext)
print("\n期望奖励 r(s,a)：")
print(r_sa)

# ---- ② 三参数期望奖励 r(s,a,s') = Σ_r r * p(s',r|s,a) / p(s'|s,a) ----
r_sas = np.zeros((nA, nS, nS))
for a in range(nA):
    for s in range(nS):
        for s2 in range(nS):
            denom = p_snext[a, s, s2]
            if denom > 0:
                num = (P[a, s, s2] * np.array(rewards)).sum()
                r_sas[a, s, s2] = num / denom
print("\n三参数期望奖励 r(s,a,s')：")
print(r_sas)

# ---- ③ 按动力学采样一条轨迹 ----
def step(state, action):
    """按 P[action, state] 的概率采样 (下一状态, 奖励)。"""
    probs = P[action, state].flatten()  # 展平成 (s', r) 的联合概率
    idx = rng.choice(len(probs), p=probs)
    s_next, r_idx = divmod(idx, len(rewards))
    return int(s_next), rewards[r_idx]

state, done = 0, False
traj = []
for t in range(10):
    action = rng.choice(nA)                       # 随机策略：动作各 50%
    s_next, r = step(state, action)
    traj.append((state, action, r, s_next))
    state = s_next
print("\n采样轨迹 (S_t, A_t, R_{t+1}, S_{t+1})：")
for t, (s, a, r, s2) in enumerate(traj):
    print(f" {t}: ({s}, {a}, {r:.0f}, {s2})")

运行后，p_snext 每行之和都应等于 1（验证了概率约束），而 r_sa 里 r(s1, a1) = 1.0 是唯一非零期望奖励——与第 5 节"只有在 s1 选 a1 才得 1 分"的设计完全吻合。这段代码的骨架（P[a, s, s', r] 张量 + 按它采样）就是后面所有环境模拟器的雏形，第 3 章动态规划会在更大的网格世界上复用同一种结构。

三、练习#

  1. 验证代码中 p_snext 的每一行（固定 a, s）之和都等于 1；再验证 r_sa 与手算结果一致，说明"对 r 求和"和"对 (s', r) 加权求和"两条边缘化公式成立。
  2. 给 MDP 加一点随机性：把 s0, a0 改成"以 0.6 去 s1、0.4 留原地"。重算 p(s'|s,a)，并观察轨迹中 s0 → s0 的自环是否出现得更频繁。
  3. 手推 r(s1, a0, s2) 和 r(s1, a1, s2) 的值，再与代码 r_sas 对照。为什么后者是 1.0 而前者是 0.0？说说 r(s,a,s') 相比 r(s,a) 多"知道"了什么。
  4. 思考：马尔可夫性质要求"未来只取决于现在"。举一个现实中不满足马尔可夫性质的例子（提示：股票价格只用"当前价格"一个标量作状态），并说明把状态扩充成向量（如加入最近 N 天的价格）后为何能更接近马尔可夫性质。
