pass 基础设施：如何写一个图级 pass#

一个 pass 看起来只是"读 IR、改 IR"的一段代码。但在真实编译器里它是一份合约：声明依赖、如实报告"是否改动"、失败要能被察觉、改写后 IR 必须还能通过验证器、能被并行调度。合约缺失的后果往往半年后才回来。本课把 pass 基础设施的零件写出来，并用一段 15 节点的图跑出三组数字：单趟 7 个节点 vs 不动点 5 个节点、一个真实 pattern bug 被逐元素对拍抓住、写错的 pass 被验证器当场拦下。

一、概念讲解#

1. pass 的最小契约#

MLIR 的 OperationPass 把规则写得很具体：pass 只作用于被锚定的那个 operation；不得查看兄弟 operation（可能正被别的线程改写）；不得修改它之外的状态（自身属性例外）；不得跨 runOnOperation 保存可变状态；而且必须可拷贝构造（pass manager 会复制它并行处理成千上万个函数）。失败要用 signalPassFailure 报出来，pipeline 立刻停，不带着半个非法 IR 往下跑。

TVM 侧精神一致：每个 pass 注册成 PassInfo（名字、opt_level、required 依赖），PassContext 负责门槛与黑白名单，required 让依赖自动排到前面。本课的 Pass / PassContext / PassManager 就是这两套设计的最小复刻。

2. pass 管理器：顺序、依赖、不动点#

管理器做三件事：按顺序跑（TVM 的 SequentialPass）、按依赖排（deps）、决定跑几趟。第三件最容易被低估。代码里的对比很直白：同一张 15 节点的图，单趟（max_rounds=1）跑完还剩 7 个节点（死链 z1 → z2 的孤儿留在图里），跑到不动点剩 5 个节点、用了 4 轮。原因在 DCE 的实现：本课故意把它写成"前向扫一遍"，删掉使用者时生产者早已被访问过，于是每轮只清一层；逆序扫能一轮清完，但任何 pass 组合都可能在后面制造新机会，所以在管理器层面迭代到不动点更省心（MLIR 的 greedy driver 就是跑到不动点）。

跑几趟必须可观测：统计表打印每个 pass 的调用次数、改写次数、IR 节点数；PassContext 还挂了 before / after 钩子，对应 MLIR 的 PassInstrumentation 与 TVM 的 PassInstrument。

3. pattern 改写：命中、改写、记账#

MLIR 把改写拆成两半：RewritePattern（静态 benefit、可选的 root op 名、matchAndRewrite）与 PatternRewriter（所有 IR 变更都必须经它，否则驱动器的状态会失效）。三条约束值得背下来：改写成功必须真的改了 IR（返回 success 而没改动是 bug）；失败时不得留下任何修改；递归应用必须显式声明边界（setHasBoundedRewriteRecursion），否则驱动器宁可判失败。

代码里的 AlgebraicSimplify 就是三条 pattern：x + 0 → x、x · 1 → x、relu(relu(x)) → relu(x)。它们全部通过 Graph 暴露的三个原语落地——replace（就地替换）、alias（把某个值的所有使用改指另一个值，等价于 MLIR 的 replaceOp / RAUW）、erase。pass 不直接改数据结构，这条纪律换来可审计：Graph.events 记录每一次改写。

4. 融合：pass 顺序与融合边界#

FusePointwise 把相邻 pointwise 链串成一个 fused 节点，命中条件两条：链上中间结果只被使用一次，且下一个节点真的消费了上一条链的结果。第二条不是多余的：本课第一版只检查了"单使用者"，把两条无关的链（死链 z1→z2 与 r2）融成一个节点，程序算错，是第 6 节的逐元素对拍报出 18.0 的最大绝对差才暴露的；修正后三个图全部 0.0e+00。这正是本课重点：pass 的正确性不能靠"看起来对"，只能靠对拍。

顺序同样重要：g3 的审计日志里，孤儿链 z1 → z2 先被融成一个节点、下一轮又被 DCE 删掉，白干一次——所以融合应排在死代码消除之后。真实调度器还要给融合打分：TorchInductor 用 can_fuse 判断能否融合、score_fusion 决定先融哪一对，因为有些融合会挡住后面更好的融合。

5. 可观测性与验证：pass 的"体检"#

  • 每个 pass 之后跑验证器（依赖闭合、声明类型 = 推导类型、输出存在）。第 5 节的 BuggyFuse 把 relu 的结果类型写成 (1,1)，验证器立刻报出四条（含 matmul 的 K 维不匹配）并中止 pipeline。
  • 类型推导规则只能有一份：infer() 被验证器与所有 pass 共用；pass 自己另写一套形状逻辑，第 5 节这类错误就会被"两边都错得一致"掩盖掉。
  • 改写前后逐元素对拍：第 6 节把五类改写后的图放进同一个解释器与优化前比对，最大绝对差全是 0.0e+00。

6. 常见坑#

  • 绕过改写原语直接动结构：分析缓存与 use-list 不会更新，后续 pass 读到幽灵节点。
  • 返回 success 却什么都没改：驱动器会反复重试，表现为编译时间暴涨。
  • 只跑单趟就宣布优化完成：本课 7 vs 5 个节点的差别就是这么来的。
  • 依赖靠"顺序碰巧对"：没写进 deps 的依赖，换个人重排 pipeline 就崩。

二、可运行代码示例#

纯 Python + numpy，本机 python3.10 + numpy 1.26.2 实跑，无需 GPU。六个小节分别对应上面六点：初始图、单趟、不动点、加融合、禁用某个 pass、写错的 pass、以及改写正确性对拍。

# ---- 图级 pass 基础设施：pass 管理器 + IR 验证器 + pattern 改写 + 统计（纯 Python + numpy）----
import numpy as np

F32 = np.dtype('float32')
POINTWISE = {'add', 'mul', 'relu'}


# ---------- 1. 最小图 IR：值带显式类型，改写只能走 Graph 暴露的三个原语 ----------
class Node:
    def __init__(self, name, op, operands=(), attrs=None, out_type=None):
        self.name, self.op, self.operands = name, op, tuple(operands)
        self.attrs, self.out_type = attrs or {}, out_type

    def __repr__(self):
        return (f'{self.name} = {self.op}({", ".join(self.operands)})'
                f'{self.attrs} : {self.out_type[0]}/{self.out_type[1].name}')


class Graph:
    def __init__(self, inputs, nodes, outputs):
        self.inputs = dict(inputs)                     # name -> (shape, dtype)
        self.nodes = {n.name: n for n in nodes}
        self.outputs = list(outputs)
        self.events = []                               # 改写审计日志
        self.decl = {n.name: i for i, n in enumerate(nodes)}    # 声明序 → 稳定拓扑序

    def producers(self):
        p = {k: [] for k in self.inputs}
        p.update({k: list(v.operands) for k, v in self.nodes.items()})
        return p

    def order(self):
        p = self.producers()
        indeg = {k: len([i for i in v if i in self.nodes]) for k, v in p.items()}
        ready = [k for k, d in indeg.items() if d == 0]
        out = []
        while ready:                                   # 同层按声明序挑，输出可复现
            ready.sort(key=lambda k: self.decl.get(k, -1))
            k = ready.pop(0)
            if k in self.nodes:
                out.append(self.nodes[k])
            for m, deps in p.items():
                if k in deps:
                    indeg[m] -= 1
                    if indeg[m] == 0:
                        ready.append(m)
        assert len(out) == len(self.nodes), 'IR 有环或存在不可达节点'
        return out

    def users_of(self, name):
        return [n.name for n in self.nodes.values() if name in n.operands]

    # --- 三个改写原语：就地替换、别名（≡ MLIR 的 replaceOp / RAUW）、删除 ---
    def replace(self, name, new_node):
        assert new_node.name == name
        self.nodes[name] = new_node
        self.events.append(f'replace {name} → {new_node.op}')

    def alias(self, name, keep):
        for n in self.nodes.values():
            n.operands = tuple(keep if o == name else o for o in n.operands)
        self.outputs = [keep if o == name else o for o in self.outputs]
        del self.nodes[name]
        self.events.append(f'alias {name} → {keep}')

    def erase(self, name):
        del self.nodes[name]
        self.events.append(f'erase {name}')

    def dump(self):
        return '\n'.join('    ' + repr(n) for n in self.order())


def infer(op, in_types, attrs):
    """类型推导：验证器与所有 pass 共用同一份规则，杜绝"pass 自己猜形状"。"""
    if op == 'const':                                  # 常量节点没有输入
        return tuple(attrs['shape']), attrs['dtype']
    if op == 'fused':                                  # 融合节点的类型由调度器写好
        return tuple(attrs['out_shape']), attrs['dtype']
    shapes = [t[0] for t in in_types]
    dt = in_types[0][1]
    if op in ('add', 'mul'):
        out = []
        for dims in zip(*[s[::-1] for s in shapes]):
            sizes = {d for d in dims if d != 1}
            assert len(sizes) <= 1, f'{op}: 无法广播 {shapes}'
            out.append(sizes.pop() if sizes else 1)
        return tuple(out[::-1]), dt
    if op == 'relu':
        return shapes[0], dt
    if op == 'matmul':
        (m, k), (k2, n) = shapes
        assert k == k2, f'matmul: K 维不匹配 {k} != {k2}'
        return (m, n), dt
    raise AssertionError(f'未知算子 {op}')


def verify(graph):
    """IR 验证器：依赖闭合 + 声明类型 = 推导类型 + 输出存在。每个 pass 之后都跑。"""
    problems, known = [], dict(graph.inputs)
    for n in graph.order():
        missing = [o for o in n.operands if o not in known]
        if missing:
            problems.append(f'{n.name}: 使用了未定义的值 {", ".join(missing)}')
            known[n.name] = n.out_type
            continue
        try:
            want = infer(n.op, [known[o] for o in n.operands], n.attrs)
        except AssertionError as e:
            problems.append(f'{n.name}: 类型推导失败（{e}）')
            known[n.name] = n.out_type
            continue
        if n.out_type != want:
            problems.append(f'{n.name}: 声明 {n.out_type} ≠ 推导 {want}')
        known[n.name] = n.out_type
    for out in graph.outputs:
        if out not in known:
            problems.append(f'输出 {out} 不存在')
    return problems


# ---------- 2. pass 基础设施：Pass / PassContext / PassManager ----------
class Pass:
    name, opt_level, deps = 'pass', 0, ()

    def run(self, graph, ctx):
        raise NotImplementedError


class PassContext:
    """opt_level 门槛 + 黑白名单 + instrumentation，对应 TVM PassContext / MLIR pass options。"""

    def __init__(self, opt_level=2, disabled=(), instruments=()):
        self.opt_level, self.disabled = opt_level, set(disabled)
        self.instruments, self.stats = list(instruments), {}

    def enabled(self, p):
        return p.name not in self.disabled and p.opt_level <= self.opt_level

    def report(self):
        print(f"    {'pass':<18}{'调用':>4}{'改写次数':>9}{'IR 节点':>9}")
        for k, v in self.stats.items():
            print(f"    {k:<18}{v['调用']:>4}{v['改写']:>9}{v['节点数']:>9}")


class PassManager:
    def __init__(self, ctx):
        self.ctx, self.passes = ctx, []

    def add(self, p):
        missing = set(p.deps) - {x.name for x in self.passes}
        assert not missing, f'{p.name} 依赖未加入：{missing}'
        self.passes.append(p)
        return self

    def run(self, graph, max_rounds=1):
        for round_ in range(1, max_rounds + 1):
            changed_any = False
            for p in self.passes:
                if not self.ctx.enabled(p):
                    print(f'    [跳过] {p.name}（PassContext 禁用）')
                    continue
                for hook in self.ctx.instruments:
                    hook('before', p, graph)
                p.rewrites = 0
                changed = p.run(graph, self.ctx)
                problems = verify(graph)
                if problems:                            # ≡ MLIR verify 失败 / signalPassFailure
                    print(f'    [失败] {p.name} 之后 IR 非法，pipeline 中止：')
                    for x in problems:
                        print(f'           - {x}')
                    return None
                st = self.ctx.stats.setdefault(p.name, {'调用': 0, '改写': 0, '节点数': 0})
                st['调用'] += 1
                st['改写'] += p.rewrites
                st['节点数'] = len(graph.nodes)
                changed_any |= changed
                for hook in self.ctx.instruments:
                    hook('after', p, graph)
            if not changed_any:
                return {'rounds': round_, 'converged': True}
        return {'rounds': max_rounds, 'converged': False}


# ---------- 3. 五个 pass ----------
class ConstFold(Pass):
    """常量折叠：所有输入都是常量 → 就地换成常量节点。"""
    name, opt_level, deps = 'ConstFold', 0, ()

    def run(self, g, ctx):
        changed = False
        for n in list(g.order()):
            if not n.operands or not all(o in g.nodes and g.nodes[o].op == 'const'
                                         for o in n.operands):
                continue
            vals = [np.full(g.nodes[o].attrs['shape'], g.nodes[o].attrs['value'],
                            dtype=g.nodes[o].attrs['dtype']) for o in n.operands]
            if n.op == 'add':
                v = vals[0] + vals[1]
            elif n.op == 'mul':
                v = vals[0] * vals[1]
            elif n.op == 'relu':
                v = np.maximum(vals[0], 0)
            else:
                continue
            g.replace(n.name, Node(n.name, 'const', (),
                                   {'value': float(v.reshape(-1)[0]), 'shape': v.shape,
                                    'dtype': v.dtype}, n.out_type))
            self.rewrites += 1
            changed = True
        return changed


class AlgebraicSimplify(Pass):
    """代数恒等式：x+0 → x、x·1 → x、relu(relu(x)) → relu(x)。"""
    name, opt_level, deps = 'AlgebraicSimplify', 0, ('ConstFold',)

    def run(self, g, ctx):
        changed = False
        for n in list(g.order()):
            if n.name not in g.nodes:
                continue
            if any(o not in g.nodes and o not in g.inputs for o in n.operands):
                continue                                   # 悬挂引用：不由本 pass 负责
            consts = [o for o in n.operands if o in g.nodes and g.nodes[o].op == 'const']
            if n.op == 'add' and any(g.nodes[c].attrs['value'] == 0 for c in consts):
                zero = [c for c in consts if g.nodes[c].attrs['value'] == 0][0]
                keep = [o for o in n.operands if o != zero]
                if len(keep) == 1:
                    g.alias(n.name, keep[0])
                    self.rewrites += 1
                    changed = True
            elif n.op == 'mul' and any(g.nodes[c].attrs['value'] == 1 for c in consts):
                one = [c for c in consts if g.nodes[c].attrs['value'] == 1][0]
                keep = [o for o in n.operands if o != one]
                if len(keep) == 1:
                    g.alias(n.name, keep[0])
                    self.rewrites += 1
                    changed = True
            elif (n.op == 'relu' and len(n.operands) == 1
                  and n.operands[0] in g.nodes and g.nodes[n.operands[0]].op == 'relu'):
                inner = g.nodes[n.operands[0]]
                g.replace(n.name, Node(n.name, 'relu', (inner.operands[0],), {}, n.out_type))
                self.rewrites += 1
                changed = True
        return changed


class DeadCodeElim(Pass):
    """朴素实现：前向扫一遍。缺点很真实 —— 一次删不干净，必须迭代到不动点。"""
    name, opt_level, deps = 'DeadCodeElim', 0, ()

    def run(self, g, ctx):
        changed = False
        for n in g.order():                                # 前向：生产者先于使用者被访问
            if n.name in g.outputs or g.users_of(n.name):
                continue
            g.erase(n.name)
            self.rewrites += 1
            changed = True
        return changed


class FusePointwise(Pass):
    """融合：把"结果只被用一次"的相邻 pointwise 串成一个 fused 节点（省中间 buffer）。"""
    name, opt_level, deps = 'FusePointwise', 1, ('AlgebraicSimplify',)

    def run(self, g, ctx):
        chains, cur = [], []
        for n in list(g.order()):
            external = all(o in g.inputs or g.nodes[o].op not in POINTWISE
                           for o in n.operands if o not in cur)
            ok = (n.op in POINTWISE
                  and all(o in g.nodes or o in g.inputs for o in n.operands)
                  and all(len(g.users_of(m)) <= 1 for m in cur) and external)
            if ok and cur and cur[-1] in n.operands:       # 必须真的消费上一条链的结果
                cur.append(n.name)
                continue
            if len(cur) > 1:
                chains.append(cur)
            cur = [n.name] if ok else []
        if len(cur) > 1:
            chains.append(cur)
        for chain in chains:
            last = g.nodes[chain[-1]]
            outer, ops = [], []
            for name in chain:                             # 外部输入按消费顺序排在操作数表里
                for o in g.nodes[name].operands:
                    if o not in chain:
                        outer.append(o)
                ops.append([g.nodes[name].op, len(g.nodes[name].operands)])
            for name in chain[:-1]:
                g.erase(name)
                self.rewrites += 1
            g.replace(last.name, Node(last.name, 'fused', outer,
                                      {'ops': ops, 'out_shape': last.out_type[0],
                                       'dtype': last.out_type[1]}, last.out_type))
            self.rewrites += 1
        return bool(chains)


class BuggyFuse(Pass):
    """故意写错的 pass：改写后把结果类型写成 (1,1) —— 验证器必须拒收。"""
    name, opt_level, deps = 'BuggyFuse', 0, ()

    def run(self, g, ctx):
        for n in list(g.order()):
            if n.op == 'relu':
                g.replace(n.name, Node(n.name, 'relu', n.operands, {},
                                       ((1, 1), g.inputs['%x'][1])))
                self.rewrites += 1
        return True


# ---------- 4. 一段能同时命中五条规则的图 ----------
def build():
    def c(name, value):
        return Node(name, 'const', (), {'value': value, 'shape': (2, 2), 'dtype': F32},
                    ((2, 2), F32))
    nodes = [
        c('c0', 0.0), c('c1', 1.0),
        Node('cadd', 'add', ('c0', 'c1'), {}, ((2, 2), F32)),        # 全常量 → 折叠成 1.0
        Node('dd', 'mul', ('cadd', '%b'), {}, ((2, 2), F32)),        # 折叠后 ·1 → 别名 %b
        Node('z1', 'mul', ('%x', '%b'), {}, ((2, 2), F32)),          # 死链头：含输入，折叠不了
        Node('z2', 'relu', ('z1',), {}, ((2, 2), F32)),
        Node('z3', 'mul', ('z2', '%b'), {}, ((2, 2), F32)),          # 死链尾
        Node('sum', 'add', ('%x', 'c0'), {}, ((2, 2), F32)),         # x + 0 → x
        Node('sq', 'mul', ('sum', 'c1'), {}, ((2, 2), F32)),         # · 1 → sum
        Node('r1', 'relu', ('sq',), {}, ((2, 2), F32)),
        Node('r2', 'relu', ('r1',), {}, ((2, 2), F32)),              # relu∘relu → relu
        Node('mm', 'matmul', ('r2', '%w'), {}, ((2, 2), F32)),       # 融合边界（要物化）
        Node('a1', 'relu', ('mm',), {}, ((2, 2), F32)),
        Node('a2', 'mul', ('a1', '%b'), {}, ((2, 2), F32)),
        Node('out', 'add', ('a2', '%b'), {}, ((2, 2), F32)),         # 链：relu→mul→add
    ]
    return Graph({'%x': ((2, 2), F32), '%w': ((2, 2), F32), '%b': ((2, 2), F32)},
                 nodes, ['out'])


base = build()
print(f'=== 0. 优化前：{len(base.nodes)} 个节点 ===')
print(base.dump())

print('\n=== 1. 单趟 pipeline（每 pass 只跑一遍，不查收敛）===')
g = build()
ctx = PassContext(opt_level=2, instruments=[
    lambda when, p, gr: print(f'    -> {when} {p.name}（{len(gr.nodes)} 节点）')])
pm = PassManager(ctx).add(ConstFold()).add(AlgebraicSimplify()).add(DeadCodeElim())
r = pm.run(g, max_rounds=1)
print(f"  单趟结束：{r['rounds']} 轮，收敛={r['converged']}；剩下 {len(g.nodes)} 个节点"
      '（前向 DCE 留下了孤儿）')
print(g.dump())
ctx.report()

print('\n=== 2. 跑到不动点（max_rounds=4）===')
g2 = build()
ctx2 = PassContext(opt_level=2)
pm2 = PassManager(ctx2).add(ConstFold()).add(AlgebraicSimplify()).add(DeadCodeElim())
r2 = pm2.run(g2, max_rounds=4)
print(f"  返回：{r2['rounds']} 轮，收敛={r2['converged']}；剩下 {len(g2.nodes)} 个节点")
print(g2.dump())
print('  审计日志：' + ' | '.join(g2.events))
ctx2.report()

print('\n=== 3. 再加融合 pass（opt_level=1，声明依赖 AlgebraicSimplify）===')
g3 = build()
ctx3 = PassContext(opt_level=2)
pm3 = (PassManager(ctx3).add(ConstFold()).add(AlgebraicSimplify())
       .add(DeadCodeElim()).add(FusePointwise()))
r3 = pm3.run(g3, max_rounds=4)
print(f"  返回：{r3['rounds']} 轮，收敛={r3['converged']}；剩下 {len(g3.nodes)} 个节点")

def numpy_exec(graph, feeds):
    env = dict(feeds)
    for n in graph.order():
        if n.op == 'const':
            env[n.name] = np.full(n.attrs['shape'], n.attrs['value'], dtype=n.attrs['dtype'])
            continue
        a = [env[o] for o in n.operands]
        if n.op == 'add':
            v = a[0] + a[1]
        elif n.op == 'mul':
            v = a[0] * a[1]
        elif n.op == 'relu':
            v = np.maximum(a[0], np.float32(0))
        elif n.op == 'matmul':
            v = a[0] @ a[1]
        elif n.op == 'fused':
            v, idx = None, 0                            # ops[k] 的 [算子, 元数]，元数从操作数表取
            for k, (op, arity) in enumerate(n.attrs['ops']):
                args = a[idx:idx + arity] if k == 0 else [v] + a[idx:idx + arity - 1]
                idx += arity if k == 0 else arity - 1
                v = (args[0] + args[1] if op == 'add' else
                     args[0] * args[1] if op == 'mul' else np.maximum(args[0], np.float32(0)))
        else:
            raise ValueError(n.op)
        env[n.name] = v
    return env


rng = np.random.default_rng(0)

y0 = numpy_exec(base, feeds)['out']
for tag, graph in (('单趟', g), ('不动点', g2), ('融合后', g3)):

三、练习#

  1. 实现：把 AlgebraicSimplify 的两条恒等式改成用 matchAndRewrite 风格的一对 (匹配函数, 改写函数) 注册表，并给每条 pattern 加一个 benefit 值；当 x + 0 与 relu(relu(x)) 同时可命中时，按 benefit 决定先做哪条，验证结果与顺序无关。
