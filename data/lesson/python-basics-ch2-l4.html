类型转换与输入输出#

前几课的程序，数据都是我们直接写死在代码里的。真正的程序应该能和用户互动：接收用户输入、把结果展示出来。这一课，我们就来学类型转换和输入输出，让程序真正"活"起来。

一、概念讲解#

1. 为什么需要类型转换#

看一个常见的坑：

age = input("请输入年龄：")   # 用户输入 20
print(age + 1)                 # 报错！

为什么会报错？因为 input() 接收到的永远是字符串（str）。字符串 "20" 和数字 20 不是一回事，字符串不能直接和数字相加。这时候就需要类型转换，把字符串转成数字：

age = int(input("请输入年龄："))   # 转成整数
print(age + 1)

2. 常用的转换函数#

Python 提供了几个内置函数，用于在不同类型之间转换：

函数 作用 例子 结果
int(x) 转成整数 int("20") 20
float(x) 转成浮点数 float("3.5") 3.5
str(x) 转成字符串 str(20) "20"
bool(x) 转成布尔值 bool(1) True 
print(int("20") + 5)    # 25
print(str(20) + "岁")   # 20岁
print(float("3") + 0.5) # 3.5

注意：转换不是万能的。int("abc") 会报错，因为 "abc" 里没有数字可转。另外，浮点数转整数是"直接截断"，不是四舍五入：int(3.9) 得到 3。

3. 输出 print#

print() 我们已经用了很多次，这里补充几个实用技巧：

  • 一次打印多个值：用逗号分隔，自动加空格。
  • 指定分隔符：用参数 sep（默认是空格）。
  • 指定结尾：用参数 end（默认是换行）。
print("a", "b", "c")              # a b c（默认空格分隔）
print("a", "b", "c", sep="-")     # a-b-c
print("你好", end="")             # 结尾不加换行
print("，世界")                   # 接着上一行输出：你好，世界

4. 输入 input#

input() 会让程序停下来，等待用户在键盘输入，用户按回车后，把输入的内容作为字符串返回：

name = input("请输入你的名字：")
print("你好，" + name)

记住那句最关键的话：input() 返回的永远是字符串，要做数学运算必须先转成数字。

5. 输入 → 处理 → 输出：程序的通用骨架#

几乎所有的简单程序，都遵循同一个流程：接收输入 → 处理数据 → 输出结果。理解这个骨架，你就理解了程序的基本形态。

二、可运行代码示例#

下面写一个完整的小程序：计算"你的出生年份"。把代码存成 .py 文件后运行，按提示输入内容。

# 完整演示：输入 -> 类型转换 -> 处理 -> 输出

# 1. 输入（input 返回字符串）
name = input("请问你叫什么名字？")
age_str = input("你今年几岁了？")

# 2. 类型转换：把字符串转成整数
age = int(age_str)

# 3. 处理：用当前年份减去年龄，估算出生年份
current_year = 2025
birth_year = current_year - age

# 4. 输出结果
print("你好，" + name + "！")
print("你大约是 " + str(birth_year) + " 年出生的。")

运行示例（用户输入用粗体标出）：

请问你叫什么名字？小明
你今年几岁了？20
你好，小明！
你大约是 2005 年出生的。

要点：age_str 是字符串，必须先 int() 转成数字才能参与减法；最后用 str() 把数字转回字符串，才能和文字拼接。

三、练习#

  1. 加法计算器：写一个程序，让用户输入两个数字，输出它们的和。注意要把输入转成数字类型。
  2. 字符串拼接：让用户输入"姓"和"名"，程序输出完整的姓名。
  3. 单位换算：让用户输入一个以"厘米"为单位的身高，程序把它换算成"米"并输出（例如输入 175 输出 1.75 米）。
  4. 探索 sep 和 end：用 print 的 sep 和 end 参数，把 1、2、3 打印成 1-2-3，并让两句 print 的输出连在同一行。
  5. 故意报错：直接运行 age = input("输入年龄：")，再 print(age + 1)，观察报错信息，然后加 int() 修复它，并用自己的话解释报错原因。
