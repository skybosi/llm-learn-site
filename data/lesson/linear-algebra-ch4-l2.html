线性组合、张成与基#

上一课我们认识了向量空间和子空间。这一课我们解决一个更具体的问题：给定几个向量，用加法和数乘能"造"出哪些向量？这些被造出来的全体，就是"张成"，而造出整个空间所需的最精简的一组向量，就是"基"。这套语言是理解 PCA、特征分解和神经网络权重矩阵的公共底座。

一、概念讲解#

1. 线性组合#

给定向量的集合 {v1​,v2​,…,vk​} 和一组标量系数 {c1​,c2​,…,ck​}，形如

c1​v1​+c2​v2​+⋯+ck​vk​

的向量就叫做这组向量的一个线性组合（linear combination）。换句话说，线性组合就是"把向量按不同比例放大再相加"。

2. 张成（span）#

一组向量的所有线性组合构成的集合，叫做这组向量的张成（span），记作 span{v1​,…,vk​}。

直观理解：两个不共线的二维向量，它们的张成是整个平面 R2；两个共线的向量，张成只是过原点的一条直线；一个向量的张成也是一条直线。张成的大小，取决于这组向量"覆盖的方向"有多少。

判断"向量 b 是否在 v1​,…,vk​ 的张成里"，等价于判断方程 c1​v1​+⋯+ck​vk​=b 是否有解——也就是把 vi​ 排成矩阵 A 后，Ax=b 是否有解。

3. 线性无关与基#

一组向量线性无关（linearly independent），指的是其中任何一个向量都不能由其余向量线性组合出来；换句话说，方程 c1​v1​+⋯+ck​vk​=0 只有"全零系数"这一种解。反之，若存在不全为零的系数让它等于零向量，就称这组向量线性相关。

一个向量空间的一组基（basis），要同时满足两个条件：

  1. 这组向量线性无关；
  2. 这组向量张成整个空间。

空间里向量个数（维数）虽然可以是无穷多，但基的向量个数是确定的，这个个数就是空间的维数（dimension）。例如 R3 的标准基是 {e1​,e2​,e3​}={(1,0,0),(0,1,0),(0,0,1)}，维数是 3。

4. 基与坐标：换个角度看数据#

基给了我们"坐标"：空间里任意一个向量，都可以唯一地写成基的线性组合，那组系数就是它在该基下的坐标。机器学习里"特征"其实就是一种坐标——同样的数据，换一组基（比如 PCA 找到的主成分基）表示，往往能去掉冗余、突出主要信息。这也是下一章特征分解、SVD 的伏笔。

二、可运行代码示例#

import numpy as np

# ---- 例 1：判断向量 b 是否在 span{v1, v2} 内 ----
v1 = np.array([1.0, 0.0, 0.0])
v2 = np.array([0.0, 1.0, 0.0])
A = np.column_stack([v1, v2])   # 两列就是 v1, v2

b = np.array([2.0, 3.0, 0.0])   # 在 xy 平面内
x, res, _, _ = np.linalg.lstsq(A, b, rcond=None)
print("b 的系数 x =", x)
print("A @ x =", A @ x, "是否等于 b：", np.allclose(A @ x, b))

c = np.array([2.0, 3.0, 5.0])   # 有 z 分量，不在 xy 平面内
x2, res2, _, _ = np.linalg.lstsq(A, c, rcond=None)
print("c 的重构 A @ x2 =", A @ x2, "，残差平方和 =", res2)  # 残差不为 0

# ---- 例 2：判断向量组是否线性无关 ----
e = np.eye(3)                    # 标准基 e1, e2, e3
print("标准基的秩 =", np.linalg.matrix_rank(e))   # 3 → 线性无关

redundant = np.array([1.0, 1.0, 1.0])   # = e1 + e2 + e3，是冗余向量
M = np.column_stack([e, redundant])     # 4 个列向量
print("加入冗余向量后秩 =", np.linalg.matrix_rank(M))  # 仍为 3 → 相关

# ---- 例 3：求向量在给定基下的坐标 ----
B = np.array([[1.0, 1.0],
              [1.0, -1.0]])     # 一组非标准基
w = np.array([3.0, 1.0])
coords = np.linalg.solve(B, w)
print("w 在基 B 下的坐标 =", coords)
print("验证 B @ coords =", B @ coords)

要点：例 1 中 np.linalg.lstsq 求的是最小二乘解；当 b 确实在张成内时残差为 0（精确有解），否则残差非 0，说明 b 在张成之外。

三、练习#

  1. 判断：span{(1,1),(2,2)} 是什么图形？它等于 span{(1,1)} 吗？为什么？
  2. 求解：b=(1,4,7) 是否在 span{(1,2,3),(0,1,2)} 内？先手算，再用代码验证。
  3. 代码：随机生成 3 个三维向量，用 np.linalg.matrix_rank 判断它们通常是否线性无关（可多试几次）。
  4. 思考：如果一组特征的张成维数远小于特征个数，说明数据里存在大量冗余，这对模型训练意味着什么？
