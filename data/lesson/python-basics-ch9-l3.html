项目三：学生信息管理系统#

最后一个项目，我们把整门课的知识来一次"总汇演"：结合面向对象、文件读写、异常处理、标准库，做一个学生信息管理系统。它能对一批学生信息做增、删、查、改，并且数据保存在 JSON 文件里，退出不丢失。

一、概念讲解#

1. 需求分析#

一个学生信息管理系统，通常要支持所谓的 CRUD 四类操作：

  • C（Create）增：添加一名学生；
  • R（Read）查：查看学生列表 / 查找某个学生；
  • U（Update）改：修改学生信息；
  • D（Delete）删：删除学生。

每名学生包含：学号、姓名、年龄、班级。学号是唯一标识，不能重复。

2. 设计思路#

  • 用类表示学生：定义 Student 类，字段有学号、姓名、年龄、班级；提供 to_dict() 把对象转成字典（方便存 JSON），以及一个 from_dict() 从字典重建对象。
  • 用列表管理所有学生：一个 students 列表装所有 Student 对象。
  • 持久化：把整个列表转成字典列表，用 json.dump 存进文件；启动时读回。
  • 主循环 + 菜单：和待办清单类似，用一个 while True 循环分发各个功能函数。

3. 为什么用类#

用类的好处是：学生的"数据"和"行为"绑在一起，代码更有组织，也更容易扩展（比如以后给 Student 加一个 introduce() 方法，让它做自我介绍）。这也正是第 6 章面向对象知识的实际应用。

二、可运行代码示例#

下面是一份完整可运行的程序，保存为 student_system.py 后运行。

import json
import os

FILENAME = "students.json"


class Student:
    """表示一名学生。"""

    def __init__(self, sid, name, age, cls):
        self.sid = sid        # 学号
        self.name = name      # 姓名
        self.age = age        # 年龄
        self.cls = cls        # 班级

    def to_dict(self):
        """转成字典，方便保存为 JSON。"""
        return {"sid": self.sid, "name": self.name,
                "age": self.age, "cls": self.cls}

    @classmethod
    def from_dict(cls, d):
        """从字典重建一个 Student 对象。"""
        return cls(d["sid"], d["name"], d["age"], d["cls"])

    def __str__(self):
        return f"{self.sid}  {self.name}  年龄{self.age}  班级{self.cls}"


def load_students():
    """从文件读取学生列表，文件不存在则返回空列表。"""
    if not os.path.exists(FILENAME):
        return []
    with open(FILENAME, "r", encoding="utf-8") as f:
        data = json.load(f)
    return [Student.from_dict(d) for d in data]


def save_students(students):
    """把学生列表写回文件。"""
    with open(FILENAME, "w", encoding="utf-8") as f:
        json.dump([s.to_dict() for s in students], f,
                  ensure_ascii=False, indent=2)


def show_menu():
    print("\n===== 学生信息管理系统 =====")
    print("1. 添加学生")
    print("2. 查看所有学生")
    print("3. 查找学生")
    print("4. 修改学生")
    print("5. 删除学生")
    print("6. 退出")


def find_by_sid(students, sid):
    """按学号查找学生，找到返回对象，否则返回 None。"""
    for s in students:
        if s.sid == sid:
            return s
    return None


def add_student(students):
    sid = input("请输入学号：").strip()
    if find_by_sid(students, sid):
        print("该学号已存在！")
        return
    name = input("请输入姓名：").strip()
    age = int(input("请输入年龄：").strip())
    cls = input("请输入班级：").strip()
    students.append(Student(sid, name, age, cls))
    print("已添加学生：", name)


def list_students(students):
    if not students:
        print("暂无学生信息。")
        return
    for s in students:
        print(" ", s)


def search_student(students):
    sid = input("请输入要查找的学号：").strip()
    s = find_by_sid(students, sid)
    print(" 找到：", s) if s else print("未找到该学号的学生。")


def update_student(students):
    sid = input("请输入要修改的学号：").strip()
    s = find_by_sid(students, sid)
    if not s:
        print("未找到该学号的学生。")
        return
    name = input(f"新姓名（当前 {s.name}，回车跳过）：").strip()
    if name:
        s.name = name
    age = input(f"新年龄（当前 {s.age}，回车跳过）：").strip()
    if age:
        s.age = int(age)
    cls = input(f"新班级（当前 {s.cls}，回车跳过）：").strip()
    if cls:
        s.cls = cls
    print("已更新。", s)


def delete_student(students):
    sid = input("请输入要删除的学号：").strip()
    s = find_by_sid(students, sid)
    if not s:
        print("未找到该学号的学生。")
        return
    students.remove(s)
    print("已删除学生：", s.name)


def main():
    students = load_students()
    while True:
        show_menu()
        choice = input("请选择操作（1-6）：").strip()
        if choice == "1":
            add_student(students)
        elif choice == "2":
            list_students(students)
        elif choice == "3":
            search_student(students)
        elif choice == "4":
            update_student(students)
        elif choice == "5":
            delete_student(students)
        elif choice == "6":
            save_students(students)
            print("数据已保存，再见！")
            break
        else:
            print("无效选择，请输入 1-6。")


if __name__ == "__main__":
    main()
