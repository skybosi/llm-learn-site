层归一化#

Transformer 的每个子层都套着一句 LayerNorm(x + sublayer(x))。残差连接我们已经懂了，剩下这个 层归一化（Layer Normalization，LN） 是最后一块拼图。它负责把每一层的数值拉回一个稳定的尺度，让几十层深、数值各异的网络能顺畅训练。这一课讲清 LN 在算什么、为什么序列模型选它而不选 BatchNorm。

一、概念讲解#

1. 归一化在干什么#

深度网络各层输出的大小、分布各不相同，若不加控制，前一层输出的尺度漂移会逐层放大，训练变得不稳定、收敛变慢。归一化就是给每一层的激活"定一个规矩"：减去均值、除以标准差，让输出回到一个统一、受控的范围。

通用公式：

y = (x - μ) / √(σ² + ε)

其中 μ 是均值，σ² 是方差，ε 是防止除零的小常数。归一化后，这一批数值的均值约为 0、方差约为 1。

2. 层归一化：在"特征维"上归一#

LN 的关键在于在哪个维度上求均值方差。对形状为 (batch, seq, features) 的输入，LN 对每个样本、每个位置的最后一维（特征维）单独求均值和方差。也就是说，一句话里第 3 个词的 512 维向量，自己算自己的均值方差，自己归一自己，与其它词、其它句子无关。

这个选择带来两个直接好处：

  • 与 batch 大小无关：LN 不跨样本统计，所以即使 batch 很小甚至为 1，统计量依然稳定；
  • 与序列长度无关：每个位置独立归一，所以变长序列（每个句子长度不同）也能自然处理。

3. 可学习的缩放与平移：γ 和 β#

纯归一化会把每维强制变成"均值 0、方差 1"，但网络未必希望每层都长这样——某些特征可能就该数值大一点。于是 LN 引入两个可学习参数：

y = γ ⊙ x̂ + β

γ（缩放）和 β（平移）的维度与特征维相同，逐元素作用。它们让网络在"归一化"的基础上，仍能学回自己想要的尺度和偏移，表达力不因归一化而受限。

4. LN 与 BatchNorm 的区别#

最容易混淆的是 Batch Normalization（BN）。二者都归一化，但统计的"轴"不同：

  • BN：对同一个特征、跨 batch 内所有样本和位置求均值方差。依赖 batch，batch 小或变长序列时统计不稳；
  • LN：对同一个样本的同一位置、跨特征维求均值方差。不依赖 batch，天然适配序列。

举例：batch 里有 8 句话、每句 10 个词、每词 512 维。BN 会对"第 512 维"在所有 8×10 个位置上统计；LN 则对"某一句第 3 个词"在它自己的 512 维上统计。序列任务里句子长度不一、batch 往往不大，所以 Transformer 用 LN。

5. 位置：先残差，后归一化#

标准 Transformer 用 post-LN：先做 x + sublayer(x) 的残差相加，再做 LN。后来的许多模型发现，把 LN 挪到子层之前（pre-LN）训练更稳、更容易加深。无论放哪，LN 的角色不变——稳住每一层的数值尺度。这个话题常被称作"pre-LN vs post-LN"，值得你在读大模型论文时留意。

二、可运行代码示例#

下面手写一个 LayerNorm，与 PyTorch 自带实现逐项对齐，再对比 BatchNorm 的统计方式，把"按特征维归一"看个明白。

import torch
import torch.nn as nn

torch.manual_seed(0)

x = torch.randn(2, 3, 4)      # (batch, seq, features)

# 1) 手写 LayerNorm：对"每个样本每个位置"的最后一维（特征维）归一化
def manual_layernorm(x, eps=1e-5, gamma=None, beta=None):
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, unbiased=False, keepdim=True)
    y = (x - mean) / torch.sqrt(var + eps)
    if gamma is not None:
        y = y * gamma + beta
    return y

y = manual_layernorm(x)
print("手写 LN 后每个样本-位置的均值（应≈0）:\n", y.mean(dim=-1))
print("手写 LN 后每个样本-位置的方差（应≈1）:\n", y.var(dim=-1, unbiased=False))

# 2) 与 PyTorch 自带实现对比（关闭 affine 时不带 gamma/beta）
ln = nn.LayerNorm(4, elementwise_affine=False)
print("与 nn.LayerNorm 一致:", torch.allclose(manual_layernorm(x), ln(x), atol=1e-5))

# 3) 带可学习 gamma/beta 的版本
ln_affine = nn.LayerNorm(4)
y2 = ln_affine(x)
print("带 gamma/beta 的 LN 输出形状:", y2.shape)
print("gamma 形状:", ln_affine.weight.shape, " beta 形状:", ln_affine.bias.shape)

# 4) 对比 BatchNorm：跨 batch 统计（需要 (batch, features, seq) 布局）
bn = nn.BatchNorm1d(4)
xb = x.transpose(1, 2)         # 变成 (batch, features, seq)
yb = bn(xb)
print("BatchNorm 输出形状:", yb.shape)

运行后注意：

  • 手写 LN 之后，每个样本的每个位置，其 4 维特征的均值都约等于 0、方差约等于 1——归一发生在特征维内部；
  • manual_layernorm(x) 与 nn.LayerNorm(4, elementwise_affine=False) 逐元素一致，说明我们的实现就是官方算法；
  • gamma、beta 的形状都是 (4,)，即每个特征维度一个可学习缩放/平移，与特征维对齐；
  • BatchNorm 需要把张量摆成 (batch, features, seq)，因为它是跨样本、按特征维统计——和 LN 的"单样本内按特征维"正好互补。

三、练习#

  1. 把 x 的 batch 改成 1（torch.randn(1, 3, 4)），分别跑 LN 和 BN，观察谁还能正常工作（BN 在 batch=1 且训练模式下会因为方差为 0 而出问题），理解 LN 对 batch 不敏感的优势。
  2. 给手写 LN 加上 gamma/beta（初始 gamma=1, beta=0），验证此时输出和"无 affine"版本完全一致，理解这两个参数的初始值是"恒等"。
  3. 把归一化的维度从 -1 改成 dim=1（对 seq 维归一），观察均值方差还对不对，体会"选错轴"会怎样破坏归一化的意义。
  4. 思考：pre-LN 和 post-LN 只是挪了 LN 的位置，为什么会显著影响深层 Transformer 的训练稳定性？结合残差连接的梯度流动谈谈你的猜想。
