从 AST 降到 IR：一次完整的 lowering#

前三课分别讲清了三件零件：三地址码（形状）、CFG 与基本块（结构）、SSA 与支配关系（分析友好性）。这一课把它们装成一条能被观察的流水线：源码 → AST → 三地址码（带标签）→ 基本块 → CFG。它会顺带回答一个很容易被跳过、但决定编译器正确性的问题：降级（lowering）改变了表示，但必须保住什么？

一、概念讲解#

1. lowering：把高层结构换成一串原语#

lowering（降级）指把高层语言结构翻译成更接近机器、语义等价的低层原语。Crafting Interpreters 第 2 章把编译写成"翻过山头、再下山"的过程，lowering 就是下山那段的主旋律：语义不变，表示越来越简单。

这里有个关键判断：lowering 的目标形态是设计选择，不是自然规律。同一门语言可以降到三地址码 + 标签（本课），也可以直接降到 LLVM IR（真实前端），还可以降到栈式字节码。选哪种形态，取决于后端和后续优化想看到什么。

2. 常见降级清单#

源结构 降级后 关键点
if (c) s1 else s2 三个标签 + 两条 goto 合流 合流标签就是 CFG 的汇合块
while (c) s 条件块在前，体末尾 goto 回条件块 回边由标签实现
for (init; c; step) init; while (c) { s; step } 步进必须搬进体末尾
c1 && c2（条件位置） 标签序列：c1 为假直接跳到假出口 短路必须是"真跳转"
c1 || c2 c1 为真直接跳到真出口 同上
a[i] 地址算术 base + i * sizeof(T) 再 load 数组访问变成指针算术

清单里最值得琢磨的是 for。一个自然的想法是在 parser 里就直接展开成 while——AST 里干脆不要 for 节点。真实编译器通常不这么做：AST 保留源语言结构，错误信息才能说清"是 for 的哪一段出错"，后续 pass 也才有机会对 for 整体做循环识别、步长分析。本课代码里 parse() 产出的顶层语句仍是 ('for', ...)，展开发生在 Lower.run() 里。

3. 语义保持的三条硬约束#

lowering 是"保持语义的改写"。验收它不能靠"看起来对"，要靠三条硬约束：

  1. 求值顺序：左右子表达式按源码顺序求值。把 f() + g() 降成先 g 后 f 会改变可观察行为。
  2. 副作用时机：调用、赋值、可能出错的运算（除零、越界）不能被提前、延后或重复执行。
  3. 短路：c1 && c2 里的 c2 只在 c1 为真时求值。这意味着条件位置上的 && 不能降成"先算两个布尔值再合并"——那会在 a == 0 时照样执行 b / a。

第 3 条最容易被当成优化技巧，其实它是语义要求。本课代码的例子里，源码写的是 if (a != 0 && sum / a > 2)：降级后除法的指令只落在"a != 0 为真才到达"的块里，这才是正确实现。判断标准很简单——短路是"不执行本不该执行的运算"，不是"少算一次"。

4. 一条完整流水线：29 条指令 → 11 个基本块#

下面代码对一段带 for 循环与短路条件的源码跑完四步，并打印每一步的结果。观察四件事：

  • for 已经不存在了：i = 1 落在入口块 B1，t3 = i + 1; i = t3 落在循环体 B4 末尾，goto L1 形成回边。
  • 短路在 CFG 里可见：if t4 goto L7 是 a != 0 的真分支，除法只出现在 B7；假分支直接去 else 块 B6。
  • 出现一批"只含 goto"的块（B3、B6、B8）：naive lowering 的必然产物，块数与源码分支数不成正比，清理它们是后续 pass 的工作。
  • 可见的"低效"：t2 = sum + i; sum = t2——赋值先算进临时名再 copy 回变量。这是最简单、也最不容易写错的 lowering 形态；复制传播（第 5 章）会把它消掉。

5. 与 LLVM 对照：alloca 与 mem2reg#

真实前端（clang）走的是同一条路，只是目标 IR 更精细。它在 -O0 下把局部变量放在栈上（alloca + load/store），因为 -O0 的首要目标是调试友好与编译速度；进入优化级别后，mem2reg 把未被取地址的 alloca 提升成 SSA 寄存器值。本课四课手工做的"切块 → 支配关系 → φ → 重命名"，正是 mem2reg 内部做的事——只不过它还要额外处理"变量被取地址"这类逃逸情况。

6. 常见坑#

  • 标签靠源码名字拼：lowering 里标签必须由计数器生成，用变量名拼标签必然冲突。
  • 条件位置与非条件位置混用：x = (a && b) 需要把布尔值落进临时名，不能复用"只发跳转"的 cond 路径。
  • 忘记 fall-through：if 的 then 分支末尾不补 goto 就会直接掉进 else 块。
  • 一次降太多层：把 for 直接降到机器码级细节（寄存器、帧布局）会让错误定位与调试信息全丢，分层降级是为可维护性服务的。
  • 不做验证：写完 lowering 至少要对"每个块最多一个入口"和"所有跳转目标存在"两条做断言，这是最便宜的正确性护栏。

二、可运行代码示例#

这段纯 Python（无第三方依赖）实现了完整的四阶段流水线。它把上一课的 split_blocks 与 CFG 构造也包含进来，因此可以一口气看到从源码到图的全过程。

# ---- 一次完整的 lowering：AST → 三地址码（带标签）→ 基本块 → CFG ----
# 纯 Python，无第三方依赖。源码见下方 SRC。
import re

TOKEN = re.compile(r'(\d+)|([a-zA-Z_]\w*)|(==|!=|<=|>=|&&|\|\||[-+*/()<>=;{}])')
WS = re.compile(r'\s*')
KW = {'if', 'else', 'while', 'for', 'print'}
OPNAME = {'+': 'add', '-': 'sub', '*': 'mul', '/': 'div'}

# ---------- 1. 前端：token → AST ----------
def tokenize(src):
    out, i = [], 0
    while i < len(src):
        i = WS.match(src, i).end()                # 空白与换行不产生 token
        if i >= len(src):
            break
        m = TOKEN.match(src, i)
        if not m:
            raise SyntaxError(f'非法字符 {src[i]!r} at {i}')
        i = m.end()
        num, name, op = m.groups()
        out.append(('NUM', int(num)) if num else
                   ('NAME', name) if name else ('OP', op))
    return out

def parse(tokens):
    pos = 0
    def peek(): return tokens[pos] if pos < len(tokens) else (None, None)
    def eat(kind, value=None):
        nonlocal pos
        k, v = peek()
        if k != kind or (value is not None and v != value):
            raise SyntaxError(f'期望 {kind}{value or ""}，得到 {(k, v)}')
        pos += 1; return v
    def block():
        eat('OP', '{'); body = []
        while peek() != ('OP', '}'):
            body.append(stmt())
        eat('OP', '}'); return body
    def stmt():
        k, v = peek()
        if k == 'NAME' and v in KW:
            if v == 'print':
                eat('NAME'); e = expr(); eat('OP', ';'); return ('print', e)
            if v == 'if':
                eat('NAME'); eat('OP', '('); c = expr(); eat('OP', ')')
                then = block(); els = []
                if peek() == ('NAME', 'else'):
                    eat('NAME'); els = block()
                return ('if', c, then, els)
            if v == 'while':
                eat('NAME'); eat('OP', '('); c = expr(); eat('OP', ')')
                return ('while', c, block())
            eat('NAME'); eat('OP', '(')
            var = eat('NAME'); eat('OP', '='); e1 = expr(); eat('OP', ';')
            cond = expr(); eat('OP', ';')
            v2 = eat('NAME'); eat('OP', '='); e2 = expr(); eat('OP', ')')
            return ('for', var, e1, cond, v2, e2, block())
        name = eat('NAME'); eat('OP', '='); e = expr(); eat('OP', ';')
        return ('assign', name, e)
    def expr():                                   # || < && < 比较 < +- < */ < atom
        node = and_()
        while peek() == ('OP', '||'):
            eat('OP'); node = ('or', node, and_())
        return node
    def and_():
        node = cmp_()
        while peek() == ('OP', '&&'):
            eat('OP'); node = ('and', node, cmp_())
        return node
    def cmp_():
        node = add()
        if peek()[0] == 'OP' and peek()[1] in ('<', '>', '<=', '>=', '==', '!='):
            op = eat('OP'); node = ('cmp', op, node, add())
        return node
    def add():
        node = mul()
        while peek() in (('OP', '+'), ('OP', '-')):
            node = ('bin', eat('OP'), node, mul())
        return node
    def mul():
        node = atom()
        while peek() in (('OP', '*'), ('OP', '/')):
            node = ('bin', eat('OP'), node, atom())
        return node
    def atom():
        k, v = peek()
        if k == 'NUM':  eat('NUM');  return ('num', v)
        if k == 'NAME': eat('NAME'); return ('var', v)
        if (k, v) == ('OP', '('):
            eat('OP', '('); node = expr(); eat('OP', ')'); return node
        raise SyntaxError(f'表达式起始处意外 token {(k, v)}')
    prog = []
    while pos < len(tokens):
        prog.append(stmt())
    return prog

# ---------- 2. 中端：AST → 三地址码 ----------
class Lower:
    def __init__(self):
        self.code, self.nt, self.nl = [], 0, 0
    def tmp(self):
        self.nt += 1; return f't{self.nt}'
    def label(self):
        self.nl += 1; return f'L{self.nl}'
    def emit(self, *ins):
        self.code.append(ins)
    def gen(self, node):
        k = node[0]
        if k == 'num': return ('const', node[1])
        if k == 'var': return ('name', node[1])
        _, op, l, r = node
        a1, a2 = self.gen(l), self.gen(r)         # 先子后父：求值顺序 = 源码顺序
        t = self.tmp()
        self.emit(OPNAME[op] if k == 'bin' else 'cmp', op, a1, a2, t)
        return ('name', t)
    def cond(self, node, lt, lf):
        """条件下降：只发跳转，不发"布尔值"；&& / || 靠标签实现短路"""
        k = node[0]
        if k == 'or':
            mid = self.label()
            self.cond(node[1], lt, mid); self.emit('label', mid)
            self.cond(node[2], lt, lf)
        elif k == 'and':
            mid = self.label()
            self.cond(node[1], mid, lf); self.emit('label', mid)
            self.cond(node[2], lt, lf)
        else:
            v = self.gen(node)                     # 比较表达式 → 一个临时布尔
            self.emit('ifgoto', v, lt); self.emit('goto', lf)
    def stmt(self, s):
        k = s[0]
        if k == 'assign':
            self.emit('copy', self.gen(s[2]), None, s[1])
        elif k == 'print':
            self.emit('print', self.gen(s[1]))
        elif k == 'if':
            lt, lf, le = self.label(), self.label(), self.label()
            self.cond(s[1], lt, lf)
            self.emit('label', lt)
            for x in s[2]: self.stmt(x)
            self.emit('goto', le)
            self.emit('label', lf)
            for x in s[3]: self.stmt(x)
            self.emit('goto', le); self.emit('label', le)
        elif k == 'while':
            ls, lb, le = self.label(), self.label(), self.label()
            self.emit('label', ls); self.cond(s[1], lb, le)
            self.emit('label', lb)
            for x in s[2]: self.stmt(x)
            self.emit('goto', ls); self.emit('label', le)
        elif k == 'for':
            # 降级发生在 lowering：for → 初始化 + while + 步进（AST 里仍保留 for）
            _, var, e1, cond, v2, e2, body = s
            self.stmt(('assign', var, e1))
            self.stmt(('while', cond, body + [('assign', v2, e2)]))
    def run(self, prog):
        for s in prog: self.stmt(s)
        return self.code

# ---------- 3. 基本块与 CFG ----------
SYM = {v: k for k, v in OPNAME.items()}

def val(x): return str(x[1])
def fmt(ins):
    t = ins[0]
    if t == 'copy':   return f'{ins[3]} = {val(ins[1])}'
    if t in SYM:      return f'{ins[4]} = {val(ins[2])} {SYM[t]} {val(ins[3])}'
    if t == 'cmp':    return f'{ins[4]} = {val(ins[2])} {ins[1]} {val(ins[3])}'
    if t == 'goto':   return f'goto {ins[1]}'
    if t == 'ifgoto': return f'if {val(ins[1])} goto {ins[2]}'
    if t == 'print':  return f'print {val(ins[1])}'
    if t == 'label':  return f'{ins[1]}:'
    return str(ins)

def leaders(prog):
    lead = {0}
    for i, ins in enumerate(prog):
        if ins[0] == 'goto':
            lead.add(i + 1); lead.add(next(j for j, x in enumerate(prog) if x == ('label', ins[1])))
        elif ins[0] == 'ifgoto':
            lead.add(i + 1); lead.add(next(j for j, x in enumerate(prog) if x == ('label', ins[2])))
    return sorted(i for i in lead if i < len(prog))

def split_blocks(prog, lead):
    blocks, label2block = [], {}
    for k, start in enumerate(lead):
        end = lead[k + 1] if k + 1 < len(lead) else len(prog)
        bid = f'B{k+1}'
        for ins in prog[start:end]:
            if ins[0] == 'label': label2block[ins[1]] = bid
        blocks.append((bid, [i for i in prog[start:end] if i[0] != 'label']))
    return blocks, label2block

def build_cfg(blocks, label2block):
    names = [b for b, _ in blocks]; succ = {}
    for idx, (bid, body) in enumerate(blocks):
        last = body[-1] if body else None
        fall = names[idx + 1] if idx + 1 < len(names) else None
        if last and last[0] == 'goto':       succ[bid] = [label2block[last[1]]]
        elif last and last[0] == 'ifgoto':   succ[bid] = [label2block[last[2]]] + ([fall] if fall else [])
        else:                                succ[bid] = [fall] if fall else []
    return succ

SRC = """sum = 0;
for (i = 1; i <= 3; i = i + 1) { sum = sum + i; }
if (a != 0 && sum / a > 2) { r = 1; } else { r = 0; }
print r;
"""
ast = parse(tokenize(SRC))
ir = Lower().run(ast)
blocks, label2block = split_blocks(ir, leaders(ir))
succ = build_cfg(blocks, label2block)

print(f'AST 顶层语句: {[s[0] for s in ast]}')
print(f'\n三地址码（{len(ir)} 条指令）:')
for i, ins in enumerate(ir):
    print(f'  {i:>2} {ins[0]:<7} {fmt(ins)}')
print(f'\n基本块（{len(blocks)} 个）与 CFG:')
for bid, body in blocks:
    print(f'  {bid}: ' + '；'.join(fmt(i) for i in body) + f'  → {succ[bid]}')

三、练习#

  1. 实现：给 Lower 增加 break（提示：维护一个"当前循环出口标签"的栈，块结构上 break 只是一条 goto，但 AST 阶段需要它）。
  2. 解释：为什么 for 的步进语句即使遇到 continue 也必须执行，而 while 的循环体不同？这决定了 continue 在两种结构里分别该跳到哪个标签。
  3. 对比/验证：把 SRC 里的 a != 0 && sum / a > 2 改成"先算两个布尔再合并"的降级方式（自己实现一版），比较两版 CFG 中除法所在块的前驱，说明为什么第二版是错的。
  4. 思考：如果语言有异常，try { ... } catch { ... } 需要给 CFG 补哪些隐式边？为什么"基本块只有一个出口"这个假设会被打破，编译器通常怎么处理？
