网格搜索#

学完交叉验证，我们有了"客观打分"的办法。但一个模型往往有好几个超参数（比如 SVM 的 C、gamma，决策树的 max_depth），每个超参数又有好几个候选值，人工一个个试既慢又容易漏。网格搜索（Grid Search） 就是把这个"试参"过程自动化、系统化。

一、概念讲解#

1. 先分清：参数 vs 超参数#

  • 参数（parameters）：模型从数据里"学"出来的，比如线性回归的权重、系数，fit 之后自动得到。
  • 超参数（hyperparameters）：在训练之前由人设定的"旋钮"，比如 KNN 的 k、决策树的深度、SVM 的 C。它们控制模型的"学习方式"。

调参调的正是超参数。超参数选得好坏，直接决定模型的成绩。

2. 网格搜索的思路：把候选值摆成一张"网格"#

给每个超参数列出若干候选值，把它们笛卡尔组合成一张多维网格，然后穷举每一个格子：

  • 例如 C ∈ {0.1, 1, 10}、gamma ∈ {0.01, 0.1, 1}，组合出 3×3=9 组参数。
  • 对每一组参数，用交叉验证打分（而不是单次划分，避免运气成分）。
  • 挑出平均分最高的那组，就是 best_params_。

3. GridSearchCV 的关键接口#

GridSearchCV 把"网格搜索 + 交叉验证"打包在一起，训练完成后可以拿到：

属性 含义
best_params_ 交叉验证得分最高的那组超参数
best_score_ 该组参数对应的交叉验证平均得分
best_estimator_ 用最优参数在全部训练数据上重新训练好的最终模型
cv_results_ 所有参数组合的详细结果，可转成 DataFrame 分析

核心参数：estimator（待调模型）、param_grid（参数网格字典）、cv（折数）、scoring（评分指标）。

4. 网格搜索的代价#

网格搜索是穷举，所以计算量 = 组合数 × 折数 × 单次训练时间，增长飞快。参数一多、候选值一密，"网格"就会爆炸，这叫维度灾难——下一课要讲的随机搜索正是为此而生。

二、可运行示例#

示例 1：用 GridSearchCV 调 SVM 的两个超参数

from sklearn.datasets import load_iris
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.svm import SVC

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0, stratify=y)

# 参数网格：两个超参数各 3 个候选值，共 3*3 = 9 组组合
param_grid = {
    "C": [0.1, 1, 10],
    "gamma": [0.01, 0.1, 1],
}

# cv=5 表示每组参数都用 5 折交叉验证来打分
gs = GridSearchCV(SVC(), param_grid, cv=5, scoring="accuracy")
gs.fit(X_train, y_train)   # 只在整个训练集上搜索

print("最优参数：", gs.best_params_)
print("最优交叉验证得分：", round(gs.best_score_, 3))
print("测试集得分：", round(gs.score(X_test, y_test), 3))

示例 2：查看完整的搜索过程

import pandas as pd
from sklearn.datasets import load_iris
from sklearn.model_selection import GridSearchCV
from sklearn.svm import SVC

X, y = load_iris(return_X_y=True)

param_grid = {"C": [0.1, 1, 10], "gamma": [0.01, 0.1, 1]}
gs = GridSearchCV(SVC(), param_grid, cv=5, scoring="accuracy")
gs.fit(X, y)

# cv_results_ 记录了每组参数的得分，转成 DataFrame 一目了然
results = pd.DataFrame(gs.cv_results_)
cols = ["param_C", "param_gamma", "mean_test_score", "std_test_score"]
print(results[cols])

示例 3：拿到最优模型直接用于预测

from sklearn.datasets import load_iris
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.ensemble import RandomForestClassifier

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0, stratify=y)

param_grid = {
    "n_estimators": [50, 100, 200],
    "max_depth": [None, 5, 10],
}
gs = GridSearchCV(RandomForestClassifier(random_state=0),
                  param_grid, cv=5)
gs.fit(X_train, y_train)

# best_estimator_ 是已经用最优参数重新训练好的模型，可直接用
best_model = gs.best_estimator_
print("最优参数：", gs.best_params_)
print("测试集准确率：", round(best_model.score(X_test, y_test), 3))

三、练习#

  1. 算组合数：如果 max_depth 有 4 个候选、min_samples_split 有 5 个候选、min_samples_leaf 有 3 个候选，cv=5，网格搜索一共要训练多少次模型？
  2. 看懂 cv_results_：运行示例 2，找出 mean_test_score 最高的那一行对应的参数，和 best_params_ 对照。
  3. 观察过拟合风险：把 cv 从 5 改成 3，比较 best_params_ 是否变化，思考为什么折数会影响选出来的参数。
  4. 换指标：把 scoring 从 "accuracy" 改成 "f1_macro"（多分类场景），观察最优参数是否不同，说明指标选择对调参的影响。
  5. 思考：为什么调参时要用交叉验证，而不是直接在测试集上调到分数最高？这样做会带来什么后果？
