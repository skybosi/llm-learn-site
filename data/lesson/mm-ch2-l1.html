前向加噪过程#

从这一课起进入扩散模型的正文。扩散模型（DDPM）把生成拆成两个方向相反的过程：前向把真实数据一步步"加噪"成纯噪声，反向再一步步"去噪"还原数据。先讲前向：它看似只是破坏数据，却藏着整套方法的数学根基——一条固定不动、无需训练、却能被解析求解的马尔可夫链。理解它，反向去噪和训练目标就水到渠成。

一、概念讲解#

1. 直觉：把数据"煮"成噪声#

想象一张清晰的照片，我们每隔一小步就往里掺一点高斯噪声。掺得足够多次后，原始内容被彻底淹没，剩下的是一团几乎纯高斯的噪声。前向加噪就是这个"破坏过程"：从数据 x_0 出发，经过 T 步得到 x_T，且 x_T 的分布逼近标准正态 N(0, I)。

为什么要先破坏？因为"一步从噪声变数据"太难（GAN/VAE 都卡在这），但"一小步去一点噪"很容易。前向过程人为地把"难的一步"切成了 "T 个容易的小步"，反向过程就可以逐小步逆转。

2. 数学定义：一条高斯马尔可夫链#

前向过程被定义为一条马尔可夫链，每一步只依赖上一步：

q(x_t | x_{t-1}) = N( x_t ;  sqrt(1 - β_t) · x_{t-1} ,  β_t · I )

其中 β_t ∈ (0, 1) 是噪声调度（noise schedule），控制每一步掺多少噪声；sqrt(1 - β_t) 让均值略向 0 收缩，β_t 给方差。用重参数化（上一课学过）写出来更直观：

x_t = sqrt(1 - β_t) · x_{t-1} + sqrt(β_t) · ε_{t-1},   ε_{t-1} ~ N(0, I)

定义 α_t = 1 - β_t，则 x_t = sqrt(α_t) x_{t-1} + sqrt(1 - α_t) ε。选高斯是因为它的共轭性：高斯在高斯变换下仍是高斯，这保证后面所有分布都能闭式写出——这是扩散模型数学简洁的根本原因。

3. 关键性质：一步直达任意时间步#

前向过程是马尔可夫的，x_t 理论上要迭代 t 步才能算出。但利用"高斯之和仍是高斯"，可以一步从 x_0 直接跳到 x_t。记：

ᾱ_t = α_1 · α_2 · … · α_t = ∏_{s=1}^{t} α_s

反复套用重参数化并合并噪声项（独立高斯的方差直接相加），得到：

x_t = sqrt(ᾱ_t) · x_0 + sqrt(1 - ᾱ_t) · ε,   ε ~ N(0, I)

等价地，条件分布是闭式高斯：

q(x_t | x_0) = N( x_t ;  sqrt(ᾱ_t) · x_0 ,  (1 - ᾱ_t) · I )

这个性质价值巨大：训练时不用真的跑 T 步，任意时间步的加噪样本都能一次性采样出来，训练目标因此能高效计算（第 3 课用到）。

4. 噪声调度：β 该怎么选#

β_t 的取值直接决定前向过程的"节奏"。常见两种：

  • 线性调度（DDPM 原文）：β_t 从 10^-4 线性增长到 0.02。简单，但后期噪声加得过快，信号消失太快；
  • 余弦调度（Improved DDPM）：β_t 按余弦曲线变化，噪声加得更"温柔"，中间段保留了更多信号，通常样本质量更好。

无论哪种，都要求末期 ᾱ_T ≈ 0，这样 q(x_T | x_0) ≈ N(0, I)，反向过程才能从一个"干净的"标准正态开始采样。

5. 前向过程"不用学"#

注意一个容易被忽略的点：前向过程没有任何可学习参数。β_t 是手工设定的超参数，q 完全由它确定。扩散模型的全部学习都发生在反向过程——下一课的主角。这种"前向固定、反向学习"的不对称设计，是 DDPM 训练稳定的一个重要原因：目标里没有 GAN 那种"生成器与判别器互相拉扯"的对抗性。

二、可运行代码示例#

用 PyTorch 实现前向加噪，亲手验证"加噪到末期就变成纯高斯"。

import torch

torch.manual_seed(0)
T = 1000

# —— 噪声调度：线性从 1e-4 到 0.02 ——
beta = torch.linspace(1e-4, 0.02, T)        # β_t
alpha = 1 - beta                             # α_t = 1 - β_t
alpha_bar = torch.cumprod(alpha, dim=0)      # ᾱ_t = α_1·α_2·…·α_t

# —— 一张"假图片"：2×2 的小图（真实场景替换成 [C,H,W] 图像张量即可） ——
x0 = torch.tensor([[[0.2, 0.8], [0.6, 0.4]]])   # 形状 [1, 2, 2]

def forward_diffuse(x0, t):
    """一步直达 x_t：x_t = sqrt(ᾱ_t)·x_0 + sqrt(1-ᾱ_t)·ε"""
    eps = torch.randn_like(x0)                # 随机噪声 ε ~ N(0,I)
    a = alpha_bar[t].sqrt()                   # sqrt(ᾱ_t)
    b = (1 - alpha_bar[t]).sqrt()             # sqrt(1-ᾱ_t)
    return a * x0 + b * eps

# —— 观察 t 从小到大，图像如何"褪色"成噪声 ——
for t in [0, 1, 10, 100, 500, 999]:
    xt = forward_diffuse(x0, t)
    print(f"t={t:4d}: ᾱ_t={alpha_bar[t].item():.4f}, x_t={xt.numpy().round(3)}")

再看逐步加噪版本，体会它与"一步直达"是同一件事：

# —— 逐步加噪：一次走一步的马尔可夫链（与一步直达等价，只是更慢） ——
x = x0.clone()
for t in range(T):
    eps = torch.randn_like(x)
    x = alpha[t].sqrt() * x + beta[t].sqrt() * eps   # x_t = sqrt(α_t) x_{t-1} + sqrt(β_t) ε
print("逐步加噪到末期的 x_T:", x.numpy().round(3))

# —— 验证：t=T-1 时 x_t 的均值接近 0、方差接近 1（即 ≈ N(0,I)） ——
xt = forward_diffuse(x0, T - 1)
print(f"末期均值: {xt.mean().item():.3f}, 末期方差: {xt.var().item():.3f}")

运行后你会看到两件事：ᾱ_t 从 1 一路降到接近 0；x_t 的数值从"清晰的 0.2/0.8"逐渐变成"乱糟糟的随机数"，末期均值≈0、方差≈1。这就是前向加噪的完整实现，全程没有一行代码在"训练"。

三、练习#

  1. 把 beta 从线性调度改成余弦调度（提示：可参考 Improved DDPM 的余弦公式，或自行构造一条"慢起慢落"的曲线），观察 ᾱ_t 下降曲线的形状差异，说说它对"信号保留"的影响。
  2. 手推一步直达公式：从 x_t = sqrt(α_t) x_{t-1} + sqrt(1-α_t) ε 出发，展开两步，验证合并后的噪声系数满足"方差相加"，进而得到 x_t = sqrt(ᾱ_t) x_0 + sqrt(1-ᾱ_t) ε。
  3. 增大 T（如 1000 → 10000）同时相应调小 β 范围，观察末期 ᾱ_T 是否仍接近 0；解释为什么"末期 ᾱ_T≈0"对反向采样至关重要。
  4. 思考题：为什么前向过程选高斯噪声而不是均匀噪声或拉普拉斯噪声？从"共轭性 / 闭式解"的角度说明。
  5. 把 x0 换成一个真实图像张量（用 PIL 读一张图转成 torch.float32），重复前向加噪，直观观察图像被噪声淹没的过程。
