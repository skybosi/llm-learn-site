为什么 ViT 有效（注意力 vs 卷积）#

上一课我们把 ViT 的零件拆开看了一遍。但"零件长什么样"和"这套零件为什么能工作"是两回事。这一课要回答一个更深的问题：同样是堆很多层、同样是处理像素，为什么把卷积换成注意力之后，模型的表现会发生变化？它到底赢在哪里、又输在哪里？我们会从"归纳偏置"这个概念切入，把注意力和卷积的差异讲清楚，再去看实验证据——注意力在浅层和深层究竟学到了什么。理解这些，你才能在选模型时不迷信"Transformer 一定更强"，而是知道它强在什么条件下。

一、概念讲解#

1. 归纳偏置：模型天生"信"什么#

机器学习里的"归纳偏置"（inductive bias），指的是模型在没看到足够多数据之前，就内置的、对"解应该长什么样"的假设。CNN 的归纳偏置非常强，而且是"视觉专属"的：

  • 局部性：卷积核只有 3×3 或 5×5 大，一个输出像素只依赖它周围一小块输入。模型被"告诉"了：图像里靠得近的像素关系更密切。
  • 平移等变性：同一个卷积核在整张图上滑动，一个特征无论出现在图上的哪个位置，都会被同样的方式检测出来。模型被"告诉"了：狗在左边和狗在右边是同一只狗。

这两个假设对自然图像几乎总是成立，所以 CNN 用很少的数据就能学会有意义的东西，还特别不容易过拟合。ViT 几乎丢弃了这两个假设——除了"切补丁 + 线性投影"这一层带了点局部性之外，后面的自注意力对位置没有任何先验，全靠可学习的位置编码自己摸索。所以 ViT 的归纳偏置很弱。

2. 注意力强在哪：全局感受野 + 内容相关#

归纳偏置弱，同时意味着模型更"自由"。注意力带来的两个能力，正好补上了卷积的短板：

  • 第一层起就是全局感受野：CNN 要叠很多层，感受野才慢慢扩大到全图。ViT 的第一个注意力层里，每个补丁就直接和其余 196 个补丁做了交互。长距离依赖（比如"狗的耳朵和尾巴的呼应"）在浅层就能建立。
  • 权重是"内容相关"的：卷积核的权重是训练好之后固定的，对所有输入一视同仁。而注意力的权重是 Query 和 Key 现场点积算出来的，不同输入、不同位置，权重都不同。这让模型能动态决定"此刻该看向哪里"，类似一种内容驱动的自适应路由。

3. 它弱在哪：需要更多数据#

自由的代价是"欠约束"。归纳偏置弱的模型，需要更多数据才能把那些 CNN 天生就知道的规律重新学出来。这正是 ViT 原论文里最著名的发现：在中小规模数据集（比如 ImageNet-1k 的 120 万张图）上直接训练，ViT 打不过同等规模的 CNN（如 ResNet、BiT）；只有在 ImageNet-21k（1400 万张）或 JFT-300M（3 亿张）这种海量数据上预训练后，ViT 才反超。换句直白的话：CNN 靠"先天知识"赢在小数据，ViT 靠"后天数据"赢在大数据。

这也能解释一个常见误区——很多教程只展示"ViT 精度更高"的最终榜单，却不提那个榜单是"在大规模预训练"的前提下的。脱离了数据规模的语境去比模型，结论往往不可靠。

4. 证据：注意力在浅层和深层学到了什么#

有一类分析工作专门解剖 ViT 的内部表征，结论很有意思：

  • 浅层就出现全局混合：即便是最底层的注意力，权重也已经分布到较远的补丁上，不像 CNN 第一层只看 3×3。这说明 ViT 从第一层就开始整合全局上下文。
  • 深层逐渐"局部化 + 语义化"：越往深层，注意力头越来越分化，有的头专注相邻补丁（像卷积），有的头专注同一物体的不同部分。特征从"低层的纹理/边缘"逐步演化为"高层的物体/部件"。
  • 表征更"平滑"：ViT 深层不同位置的 token 表征彼此更接近，模型倾向于把"属于同一物体的补丁"拉到相近的表征空间，这被一些研究者称为"注意力带来的表征质量优势"。

这些证据共同说明：ViT 不是"抛弃了卷积的规律"，而是用数据把这些规律重新学了一遍，而且学得更灵活——这正是它"知其所以然"层面的价值：注意力本身不保证更好，它保证的是"更强的表达能力，前提是喂够数据"。

二、可运行代码示例#

先直观对比"局部"与"全局"两种信息聚合方式：卷积只看邻域，单头注意力直接看到全图。

import torch
import torch.nn as nn
import torch.nn.functional as F

torch.manual_seed(0)

# 造一张 1 通道的小图：一个 9x9 的特征图
x = torch.randn(1, 1, 9, 9)

# 卷积：3x3 核，padding=1，保持尺寸 —— 每个输出只看 3x3 邻域
conv = nn.Conv2d(1, 1, kernel_size=3, padding=1, bias=False)
out_conv = conv(x)
print("卷积输出形状（局部感受野）:", out_conv.shape)  # (1, 1, 9, 9)

# 自注意力：把 9x9 展平成 81 个 token —— 每个 token 直接和全部 81 个交互
tokens = x.flatten(2).transpose(1, 2)          # (1, 81, 1)
q = k = v = tokens
scores = q @ k.transpose(-1, -2)               # (1, 81, 81) 全局相似度
weights = F.softmax(scores, dim=-1)
out_attn = weights @ v
print("注意力相似度矩阵形状（全局感受野）:", scores.shape)  # (1, 81, 81)

# 关键对比：卷积权重是训练好就固定的，注意力权重对每个位置都不同
print("卷积核参数数量:", conv.weight.numel())          # 3*3 = 9
print("注意力权重数量（仅当前这 81 个位置）:", weights.numel())  # 81*81

接下来用一个更贴近真实问题的例子，感受"内容相关"到底意味着什么。我们造一张图，中心一个亮块，观察注意力权重是否自动"聚焦"到与目标位置最相似的地方：

# 构造一个 5x5 的"图像"：中心 3x3 是 1，其余是 0
img = torch.zeros(5, 5)
img[1:4, 1:4] = 1.0
tokens = img.flatten().unsqueeze(0).unsqueeze(-1)  # (1, 25, 1)

q = k = tokens
scores = q @ k.transpose(-1, -2)                   # (1, 25, 25)
weights = F.softmax(scores, dim=-1)

# 看第 12 个 token（中心点）对全图的注意力分布，重塑回 5x5
center_attn = weights[0, 12].reshape(5, 5)
print("中心点对全图的注意力分布:\n", center_attn.round(decimals=2))

你会看到，中心点（值为 1）对"同为 1 的区域"给了明显更高的权重，对边角（值为 0）几乎不给权重。这就是"内容相关"：权重不是写死的卷积核，而是由"我（Query）和你（Key）像不像"现场决定的。把这个直觉放大到真实图像，就是 ViT 能动态选择关注区域的能力来源。

三、练习#

  1. 把上面第一个例子里的 9x9 换成 224x224 并在 CPU 上跑一次全图自注意力，观察相似度矩阵会变成多大、内存占用如何。这解释了 ViT 在高分辨率下为什么贵（平方复杂度），也为下一课"Swin 用窗口把复杂度降下来"埋下伏笔。
  2. 用 timm 加载预训练 ViT 与一个 ResNet，分别对同一张图做前向，取出 ViT 第一层注意力权重和 ResNet 第一层卷积核，对比它们的"关注范围"：谁第一层就跨越大范围，谁只看到局部？
  3. 设计一个实验论证"ViT 需要更多数据"：在某个小数据集上同时微调一个预训练 ViT 和一个预训练 ResNet，比较收敛速度和最终精度；再思考，如果不做预训练、两个都从零训练，结果会如何变化。
  4. 归纳偏置弱一定是坏事吗？结合"迁移学习"讨论：为什么弱偏置的模型有时在下游任务上反而更能适配新数据分布？
