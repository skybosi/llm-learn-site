求导法则#

上一课我们用极限定义求导数。如果每次都从头算极限，效率太低。好在数学家总结出了一套求导法则，把复杂函数的导数拆成几条简单规则的组合。这一课我们边学规则，边用 Python 验证，最后给机器学习里最常见的激活函数求导。

一、概念讲解#

1. 基本函数的导数公式#

先记几个"原材料"的导数（c 是常数）：

函数 f(x) 导数 f'(x)
c（常数） 0
xⁿ（幂函数） n·xⁿ⁻¹
eˣ eˣ
ln(x) 1/x
sin(x) cos(x)
cos(x) -sin(x)

常数导数为 0 很好理解：常数函数是一条水平直线，斜率处处为 0。

2. 四则运算的求导法则#

有了原材料，还需要"拼装"规则。设 u = f(x)、v = g(x)：

  • 加法/减法：(u ± v)' = u' ± v'——和的导数等于导数的和。
  • 常数倍：(c·u)' = c·u'——常数可以"提到外面"。
  • 乘法：(u·v)' = u'·v + u·v'——"前导后不导 + 前不导后导"。
  • 除法：(u/v)' = (u'·v - u·v') / v²。

3. 链式法则：复合函数求导#

这是深度学习中最重要的一条法则，没有之一。若 y = f(g(x))（函数套函数），则：

y' = f'(g(x)) · g'(x)

口诀是"外导乘内导"：先对外层求导（内层整体不动），再乘上内层自己的导数。反向传播算法本质上就是链式法则在多层函数上的系统化应用——第 4 章会专门展开。

4. 激活函数求导：机器学习的"高频考点"#

神经网络每层都要用激活函数，训练时反复求它们的导数：

  • Sigmoid：σ(x) = 1/(1+e⁻ˣ)，其导数 σ'(x) = σ(x)(1 - σ(x))——只需记住 σ 自己就能算导数，实现起来特别方便。
  • tanh：tanh'(x) = 1 - tanh²(x)。
  • ReLU：relu(x) = max(0, x)，x>0 时导数为 1，x<0 时导数为 0（x=0 处习惯上取 0）。

二、可运行示例#

先用数值求导"验证"几条法则，再亲手实现激活函数的导数。

import math

def derivative(f, x, h=1e-5):
    """中心差分数值求导。"""
    return (f(x + h) - f(x - h)) / (2 * h)

# --- 验证乘法法则 (u·v)' = u'v + uv' ---
def u(x): return x * x          # u = x^2, u' = 2x
def v(x): return math.sin(x)    # v = sin(x), v' = cos(x)
def uv(x): return u(x) * v(x)   # 乘积

def uv_rule(x):
    """按乘法法则手算的导数：u'v + uv'"""
    return (2 * x) * math.sin(x) + (x * x) * math.cos(x)

x = 1.0
print(f"乘积 u·v 在 x={x} 处：数值={derivative(uv, x):.6f}  法则={uv_rule(x):.6f}")

# --- 验证链式法则：y = sin(x^2)，y' = cos(x^2) * 2x ---
def inner(x): return x * x            # 内层 g(x) = x^2
def outer(g): return math.sin(g)      # 外层 f(g) = sin(g)
def chain(x): return outer(inner(x))  # 复合 f(g(x))

def chain_rule(x):
    """按链式法则：外导 cos(x^2) 乘内导 2x"""
    return math.cos(x * x) * (2 * x)

x = 2.0
print(f"复合 sin(x^2) 在 x={x} 处：数值={derivative(chain, x):.6f}  法则={chain_rule(x):.6f}")

# --- 激活函数及其导数 ---
def sigmoid(x):
    return 1 / (1 + math.exp(-x))

def sigmoid_prime(x):
    """sigmoid 的导数：σ(1-σ)，用 sigmoid 自己的值即可算出。"""
    s = sigmoid(x)
    return s * (1 - s)

def relu(x):
    return x if x > 0 else 0.0

def relu_prime(x):
    """relu 的导数：x>0 为 1，否则 0。"""
    return 1.0 if x > 0 else 0.0

print("\n激活函数求导验证（数值 vs 公式）：")
for xv in [-1.0, 0.0, 1.0]:
    print(f"  sigmoid  x={xv}: 数值={derivative(sigmoid, xv):.6f}  公式={sigmoid_prime(xv):.6f}")
for xv in [-0.5, 0.5]:
    print(f"  relu     x={xv}: 数值={derivative(relu, xv):.6f}  公式={relu_prime(xv):.6f}")

运行结果（节选）：

乘积 u·v 在 x=1 处：数值=1.922075  法则=1.922075
复合 sin(x^2) 在 x=2 处：数值=-3.027210  法则=-3.027210

激活函数求导验证（数值 vs 公式）：
  sigmoid  x=-1.0: 数值=0.196612  公式=0.196612
  sigmoid  x=0.0: 数值=0.250000  公式=0.250000
  sigmoid  x=1.0: 数值=0.196612  公式=0.196612
  relu     x=-0.5: 数值=0.000000  公式=0.000000
  relu     x=0.5: 数值=1.000000  公式=1.000000

每一行"数值"和"公式"都吻合，说明这些求导法则是可靠的。你在实现神经网络时，正是用这些公式在代码里计算梯度的。

三、练习#

  1. 用数值求导验证除法法则：设 u(x)=x²、v(x)=x+1，比较 derivative(u/v) 和 (u'v - uv')/v² 的结果。
  2. 用链式法则求 y = e^(x²) 的导数公式（提示：外导是 e^(x²) 自身，内导是 2x），再用代码验证。
  3. 自己实现 tanh 及其导数 tanh'(x) = 1 - tanh²(x)，用数值求导验证。
  4. 思考题：ReLU 在 x=0 处导数"习惯上取 0"，但严格来说这一点左右导数不一致。用一句话说明为什么深度学习实践中依然广泛使用 ReLU。
