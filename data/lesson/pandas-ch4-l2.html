重复值#

一、概念讲解#

数据里出现重复行很常见：同一订单被记录了两次、日志重复上报、多份表格合并时重叠。重复值会让统计结果失真——比如求销售额总和时，重复的订单会被多算一遍。因此清洗时要把它们识别出来并去重。

1. 识别：duplicated#

df.duplicated() 返回一个布尔 Series，标记每一行是否是前面已出现过的重复行：

  • 默认"整行完全相同"才算重复。
  • 第一次出现标 False，之后的重复标 True。
  • subset=[...]：只按指定列判断是否重复（例如只按"订单号"，哪怕其他列不同也算重复）。
  • keep：控制保留哪条标记为"非重复"：
    • keep="first"（默认）：保留第一次出现；
    • keep="last"：保留最后一次出现；
    • keep=False：所有重复行都标 True（用于找出全部重复记录）。

2. 去重：drop_duplicates#

df.drop_duplicates() 的参数与 duplicated 一一对应，直接返回删除重复后的新 DataFrame。它默认保留每个重复组的第一条记录。

3. 现实场景的提醒#

去重前要问一句："重复"是按整行，还是按某个业务主键？ 订单表通常按"订单号"去重，而不是要求整行一模一样——因为同一个订单号可能因状态更新而出现多行。这时就要用 subset=["订单号"] 精确指定。选 keep 也要结合业务：保留最早记录、最新记录，还是全部删掉，取决于你想要哪一版数据。

二、可运行代码示例#

import pandas as pd

df = pd.DataFrame({
    "订单号": ["A1", "A1", "A2", "A3", "A3", "A3"],
    "金额": [100, 100, 50, 80, 80, 80],
    "状态": ["已支付", "已支付", "已取消", "已支付", "已支付", "已支付"],
})
print("原始数据：\n", df)

# 1. 识别整行重复
print("\nduplicated() 整行判断：\n", df.duplicated())
print("duplicated(keep='last') 保留最后一条：\n", df.duplicated(keep="last"))

# 2. 删除整行重复
print("\ndrop_duplicates() 去重后：\n", df.drop_duplicates())

# 3. 只按"订单号"判断重复（业务主键）
print("\n按订单号判断 duplicated(subset=['订单号'])：\n", df.duplicated(subset=["订单号"]))
print("\n按订单号去重，保留第一条：\n", df.drop_duplicates(subset=["订单号"], keep="first"))
print("\n按订单号去重，保留最后一条：\n", df.drop_duplicates(subset=["订单号"], keep="last"))

# 4. keep=False：找出所有出现过的重复组
print("\nkeep=False 标记全部重复：\n", df.duplicated(subset=["订单号"], keep=False))

运行后重点看第 3、4 步：当只按"订单号"判断时，"A1" 和 "A3" 组内除了第一条外都被视为重复；keep=False 则把组内每一条都标出来，适合"把有问题的记录全部揪出来"的场景。

三、练习#

  1. 创建一个含重复行的 DataFrame，用 duplicated() 找出哪些行是重复的，再用 drop_duplicates() 去重并确认剩余行数。
  2. 对同一份数据，分别用 keep="first"、keep="last"、keep=False 调用 duplicated(subset=[...])，说明三者标记结果的差异。
  3. 思考题：一份订单表里，同一个"订单号"出现了三行，但"状态"分别是"待支付、已支付、已发货"。这是"重复数据"吗？去重时应该按整行还是按订单号？保留哪一条？
