层次聚类原理#

一、概念讲解#

1.1 另一种聚类思路#

上一章学的 K-means 是划分式聚类：给定 K，一次性把所有样本分到 K 个簇里。它要求你提前知道簇数，而且结果只有"一层"。

层次聚类（Hierarchical Clustering）走的是完全不同的路线：它不预设簇数，而是逐步构建一个"簇的层级结构"。这个结构记录着"哪些样本先合并、哪些后合并"的完整历史，你可以事后在任何粒度上"切开"它，得到任意数量的簇。这种灵活性是层次聚类最吸引人的地方——一次计算，多尺度可用。

根据构建方向，层次聚类分两种：

  • 自底向上（凝聚式，Agglomerative）：开始时每个样本自成一个簇，然后反复把"最相似的两个簇"合并，直到所有样本合成一个大簇。这是实践中最常用、sklearn 默认支持的方式。
  • 自顶向下（分裂式，Divisive）：开始时所有样本是一个大簇，然后反复把"最不紧凑"的簇一分为二，直到每个样本自成一簇。计算量通常更大，用得较少。

本课程默认讨论凝聚式层次聚类。

1.2 凝聚式算法的直观过程#

凝聚式层次聚类的每一步都在回答同一个问题：当前所有簇里，哪两个最"亲近"？ 把它们合并成一个新簇，然后重复。整个过程可以这样理解：

  1. 把 n 个样本各自当作一个簇，共 n 个簇；
  2. 计算所有簇两两之间的距离；
  3. 找到距离最近的两个簇，合并成一个新簇，簇的数量减一；
  4. 重新计算新簇与其他簇的距离；
  5. 重复 3~4 步，直到只剩一个簇。

1.3 关键问题：如何定义"簇与簇"的距离#

样本之间的距离好定义（欧氏距离、曼哈顿距离等），但"簇与簇"之间的距离有不同算法，这个选择直接决定了聚类结果的形状。常见的四种链接准则（linkage）如下（设 d(A,B) 表示簇 A 与簇 B 的距离）：

  • 单链接（single）：取两簇中距离最近的一对样本的距离，d(A,B)=mina∈A,b∈B​∥a−b∥。它容易把细长的、链状的簇连起来，但对噪声和离群点敏感（"链式效应"）。
  • 全链接（complete）：取两簇中距离最远的一对样本的距离，d(A,B)=maxa∈A,b∈B​∥a−b∥。它倾向于产生更紧凑、更"圆"的簇，但可能把本应合并的簇拆开。
  • 平均链接（average）：取两簇所有样本对之间距离的平均值，d(A,B)=∣A∣∣B∣1​∑a∈A​∑b∈B​∥a−b∥。它是单链接和全链接之间的折中。
  • Ward 链接：不直接算距离，而是选择"合并后使簇内方差增量最小"的两个簇合并。它倾向于产生大小均匀、形状规则（球形）的簇，在实践中非常常用。

理解这几种准则的差异，是理解层次聚类结果的关键：同一个数据集，换一种 linkage，得到的簇可能形状迥异。

1.4 层次聚类 vs K-means：一个初步印象#

  • 簇数：K-means 需要预先指定 K；层次聚类先建好整个层级，簇数事后决定。
  • 结果形态：K-means 只给出一份硬划分；层次聚类给出完整的分层结构（树状图），信息更丰富。
  • 代价：层次聚类的计算量通常更大——凝聚式算法的时间复杂度约 O(n3) 或 O(n2)（取决于实现），当样本量很大时可能吃不消；K-means 则能高效处理大规模数据。

二、可运行代码示例#

先用 sklearn 的 AgglomerativeClustering 做一个最小示例，体会"不指定 K 也能聚类"的用法。

# -*- coding: utf-8 -*-
# 第 1 课：凝聚式层次聚类原理最小示例
import numpy as np
from sklearn.cluster import AgglomerativeClustering
from sklearn.datasets import make_blobs

# 1. 生成 3 个球形簇的数据
X, y_true = make_blobs(n_samples=150, centers=3,
                       cluster_std=0.8, random_state=42)

# 2. 创建凝聚式层次聚类模型
#    n_clusters=3：本次切割到 3 个簇（注意：层次聚类先建层级，再按需切割）
#    linkage='ward'：用 Ward 准则，倾向于生成紧凑、均匀的簇
model = AgglomerativeClustering(n_clusters=3, linkage="ward")

# 3. 训练并查看标签
labels = model.fit_predict(X)
print("每个样本的簇标签（前 20 个）：", labels[:20])

# 4. 数一下每个簇各有多少样本
unique, counts = np.unique(labels, return_counts=True)
print("各簇样本数：", dict(zip(unique.tolist(), counts.tolist())))

输出解读：和 K-means 一样，fit_predict 返回每个样本的簇标签。不同之处在于，层次聚类内部先完成了"两两合并直到一个簇"的完整过程，然后才按 n_clusters=3 在合适的层级处切开——这个"层级"正是下一课和第 3 课要深入的内容。

提示：AgglomerativeClustering 直接接受特征矩阵，内部会按 linkage 准则计算簇间距离；如果你已经有现成的距离矩阵，也可以设置 metric='precomputed' 直接传入。
