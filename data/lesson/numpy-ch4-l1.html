矩阵乘法与点积#

在前面几章里，我们已经会创建数组、切片、广播，也学会了用 sum、mean 这类函数做聚合。这一课进入 NumPy 真正的"威力区"——线性代数运算。矩阵乘法是整个机器学习的地基：神经网络的前向传播、线性回归的预测、图像的几何变换，本质上都是一次又一次的"矩阵乘矩阵"或"矩阵乘向量"。

我们先从最熟悉的点积（dot product）讲起，再自然过渡到矩阵乘法，最后讲清 NumPy 里几个容易混淆的函数：np.dot、np.matmul 和 @ 运算符。

一、概念讲解#

1. 点积：对应分量相乘再求和#

点积是线性代数里最基础的运算。给定两个长度相同的向量 u 和 v，它们的点积定义为：把对应位置的元素两两相乘，再把所有乘积加起来。

u · v = u[0]*v[0] + u[1]*v[1] + ... + u[n-1]*v[n-1]

点积的结果是一个标量（一个数），而不是向量。它在数据科学里无处不在：

  • 加权求和：向量 w 是权重，向量 x 是特征，那么 w · x 就是"每个特征乘以对应权重后求和"，这正是线性回归预测值的核心公式。
  • 相似度：两个向量的点积越大（在长度相近时），往往意味着它们方向越接近，在推荐系统里被用来衡量"两个用户口味有多像"。
  • 线性组合的系数：矩阵乘法的每一个输出元素，其实都是一次点积。

在 NumPy 里，点积可以用 np.dot(u, v) 或者等价的 u @ v 来计算。

2. 矩阵乘法：一批点积打包进行#

矩阵乘法可以理解成"把很多次点积整齐地打包在一起"。先记住维度规则：

(m × n) 的矩阵 A  乘以  (n × p) 的矩阵 B，结果是 (m × p) 的矩阵 C

关键约束是：A 的列数必须等于 B 的行数（都是 n）。结果的第 i 行第 j 列元素 C[i, j]，就是 A 的第 i 行 与 B 的第 j 列 的点积。

矩阵乘法有两种最常见的"特殊形态"，值得单独记：

  • 矩阵乘向量：(m × n) @ (n,) → (m,)。它把一个 n 维向量"变换"成 m 维向量，是一种线性变换。神经网络的每一层，就是把上一层输出向量乘上一个权重矩阵。
  • 向量乘向量（退化为点积）：两个一维向量相乘就是点积，结果是一个标量。

3. np.dot、np.matmul、@ 到底有什么区别#

这三个写法大部分时候结果相同，但边界行为不一样，这里给出一个清晰的对照：

  • @ 运算符：Python 3.5+ 引入，专为矩阵乘法设计，等价于 np.matmul，推荐日常使用。
  • np.matmul(a, b)：标准矩阵乘法，严格遵循"行 × 列"规则，支持广播（两个数组的最后两个维度做矩阵乘法，前面的维度按广播对齐）。
  • np.dot(a, b)：更"老牌"也更多面。对二维数组它和矩阵乘法一样；但对一维数组，它做点积；对高维数组，它的行为是"把 a 的最后一个轴与 b 的倒数第二个轴求和"，规则和 matmul 略有不同。

对于初学者最实用的建议：做明确的矩阵乘法用 @，做向量点积两者皆可；一旦数组维度超过二维，请优先用 @/matmul，避免 dot 带来的意外。

另外注意：* 在 NumPy 里是逐元素相乘（element-wise），不是矩阵乘法。A * B 和 A @ B 是完全不同的两件事，这是新手最常见的坑。

二、可运行示例#

示例 1：向量点积 = 加权求和

import numpy as np

# 某线性回归模型的权重向量 w 与一条样本的特征向量 x
w = np.array([2.0, -1.0, 0.5])   # 三个特征的权重
x = np.array([120.0, 3.0, 5.0])  # 面积、房间数、房龄

# 点积：预测值 = 2*120 + (-1)*3 + 0.5*5
pred = np.dot(w, x)
print("预测值 =", pred)

# @ 运算符得到同样的结果
print("@ 运算符结果 =", w @ x)

# 手算验证，确认点积就是"对应相乘再求和"
manual = w[0]*x[0] + w[1]*x[1] + w[2]*x[2]
print("手算验证 =", manual)

示例 2：矩阵乘向量（线性变换）

import numpy as np

# 一个 2x3 的权重矩阵，把 3 维特征映射成 2 维输出
W = np.array([[1, 2, 3],
              [4, 5, 6]])        # 形状 (2, 3)
x = np.array([10, 20, 30])       # 形状 (3,)

# (2,3) @ (3,) -> (2,)
y = W @ x
print("结果向量 y =", y)
print("y 的形状 =", y.shape)      # 输出 (2,)

# 每个输出分量，就是 W 的某一行与 x 的点积
print("第 0 行点积 =", W[0] @ x)  # 1*10 + 2*20 + 3*30 = 140
print("第 1 行点积 =", W[1] @ x)  # 4*10 + 5*20 + 6*30 = 320

示例 3：矩阵乘矩阵

import numpy as np

# A 形状 (3,2)，B 形状 (2,3)，可以相乘
A = np.array([[1, 2],
              [3, 4],
              [5, 6]])
B = np.array([[7, 8, 9],
              [10, 11, 12]])

# (3,2) @ (2,3) -> (3,3)
C = A @ B
print("C 的形状 =", C.shape)
print(C)

# 逐个验证：C[0,1] 应等于 A 的第 0 行 与 B 的第 1 列 的点积
# A 第 0 行 = [1,2]，B 第 1 列 = [8,11] -> 1*8 + 2*11 = 30
print("C[0,1] =", C[0, 1], "，手算 =", 1*8 + 2*11)

# np.matmul 与 @ 完全等价
print("与 np.matmul 一致:", np.array_equal(C, np.matmul(A, B)))

示例 4： 是逐元素相乘，不是矩阵乘法*

import numpy as np

A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

print("A * B（逐元素）=\n", A * B)   # 对应位置相乘
print("A @ B（矩阵乘法）=\n", A @ B)  # 行点积列

# 矩阵乘法手算第一行第一列：1*5 + 2*7 = 19，与逐元素的 5 完全不同
