Actor-Critic#

REINFORCE 有两个软肋：必须等 episode 走完、且 G_t 方差大。Actor-Critic 把策略梯度与值函数方法合体：一个 actor（策略）负责"出动作"，一个 critic（价值函数）负责"打分数"，用 critic 给的信号替换 G_t，靠自举换取更低方差。本课讲清两者的分工、TD 误差为何能当优势用，以及实用化的 n-step 版本。

一、概念讲解#

1. Actor 与 Critic 的分工#

  • Actor：参数化的策略 π(a|s; θ)，任务是选动作。它的更新方向来自策略梯度定理，目标是让"被 critic 判为好的动作"更可能发生。
  • Critic：价值函数 V(s; w)（或 Q(s,a; w)），任务是评估。它用 TD 方法不断修正自己对"这个状态有多好"的判断。

Actor 相当于"演员"，Critic 相当于"评委"：演员照着评委的打分改进演技，评委对照真实票房修正打分，两者互相促进。

2. 为什么 TD 误差能当"优势"用#

策略梯度定理需要的是 Q^π(S,A)，而 baseline 技巧提示我们可以用优势函数替代：

A^π(s,a) = Q^π(s,a) - V^π(s)

A 度量"这个动作比当前状态的平均水平好多少"，用它替换 Q 不减偏、还降方差。但 A 需要同时估计 Q 和 V。有没有更省事的量？看一步 TD 误差：

δ_t = R_{t+1} + γ V(S_{t+1}) - V(S_t)

对它取条件期望：

E[ δ_t | S_t, A_t ] = E[ R_{t+1} + γ V(S_{t+1}) | S_t, A_t ] - V(S_t)
                    = Q^π(S_t, A_t) - V^π(S_t)
                    = A^π(S_t, A_t)

（当 V 是精确值时严格成立；用近似的 V̂ 则是它的一个估计）。TD 误差就是对优势函数的"一步采样估计"。于是 Actor 的更新可以写成：

θ ← θ + α · δ_t · ∇_θ log π(A_t | S_t; θ)

Critic 自己则按标准的 TD(0) 更新：

w ← w + β · δ_t · ∇_w V(S_t; w)        （线性时 ∇_w V = φ(S_t)）

两者共享同一个 δ_t，却各司其职：Critic 用它修正价值，Actor 用它修正策略。这就是one-step actor-critic。

3. 相比 REINFORCE 的取舍#

REINFORCE Actor-Critic
优势估计 完整回报 G_t（无自举） TD 误差 / n-step 回报（自举）
方差 高 低
偏差 无偏 有偏（自举 + critic 近似）
信号强度 强但抖 单步弱、n 步适中

这正是 TD 与 MC 那场"偏差-方差权衡"在策略梯度里的重演：Actor-Critic 让 critic 用自举截断回报，以一点偏差换取更低方差；n 取多大，就是"往 MC 还是往 TD 靠"的旋钮。

4. 从 one-step 到 n-step / A2C#

one-step 的 δ_t 只往后看一步，偏置大；而且在 CartPole 这类"每步都给 +1 奖励"的任务里，单步优势的尺度相对价值 V(s) 太小，几乎学不动。实用做法是把它升级为 n-step 回报：

G_t^(n) = R_{t+1} + γ R_{t+2} + ... + γ^{n-1} R_{t+n} + γ^n V(S_{t+n})

再用 G_t^(n) − V(S_t) 作优势，并在一条轨迹内对优势做标准化（减均值除方差）以稳定训练。这就是 A2C（Advantage Actor-Critic） 的核心；若再用多个 worker 异步并行采样、各自更新，就是 A3C。它们与后面的 PPO、SAC 一起构成现代深度 RL 的策略梯度主干——本课代码即采用"n-step + 优势标准化"的做法。

二、可运行代码示例#

用 NumPy 手写 n-step actor-critic（线性 actor + 线性 critic，即 A2C 的简化核心），跑自包含 CartPole。

import numpy as np

# ---- 自包含 CartPole（简化倒立摆物理，与前几课一致） ----
GRAVITY, MASS_CART, MASS_POLE = 9.8, 1.0, 0.1
LENGTH, FORCE, DT = 0.5, 10.0, 0.02
MAX_STEPS = 500                    # 单回合步数上限

def reset():
    return np.array([0.0, 0.0, 0.05 * (np.random.rand() - 0.5), 0.0])

def step(s, a):
    x, xd, th, thd = s
    force = FORCE if a == 1 else -FORCE
    total = MASS_CART + MASS_POLE
    cos_t, sin_t = np.cos(th), np.sin(th)
    temp = (force + MASS_POLE * LENGTH * thd**2 * sin_t) / total
    th_acc = (GRAVITY * sin_t - cos_t * temp) / (LENGTH * (4/3 - MASS_POLE * cos_t**2 / total))
    x_acc = temp - MASS_POLE * LENGTH * th_acc * cos_t / total
    x, xd = x + DT * xd, xd + DT * x_acc
    th, thd = th + DT * thd, thd + DT * th_acc
    return np.array([x, xd, th, thd]), 1.0, abs(x) > 2.4 or abs(th) > 0.2095

def phi(s):
    # 特征：偏置 + 归一化后的 4 个观测
    return np.concatenate([[1.0], [s[0] / 2.4, s[1] / 3.0, s[2] / 0.21, s[3] / 3.0]])

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

def policy(theta, s):
    return softmax(np.array([theta[0] @ phi(s), theta[1] @ phi(s)]))

def grad_log_pi(theta, s, a):
    p = policy(theta, s)
    g = np.zeros_like(theta)
    g[a] = (1 - p[a]) * phi(s)
    for b in range(2):
        if b != a:
            g[b] = -p[b] * phi(s)
    return g

# ---- n-step Actor-Critic ----
np.random.seed(0)
D = len(phi(reset()))
theta = np.random.randn(2, D) * 0.1            # actor：策略参数
w = np.zeros(D)                                # critic：线性价值 V(s)=wᵀφ(s)
ALPHA, BETA, GAMMA, N = 5e-2, 2e-2, 0.99, 5    # N = 回报回看步数
scores = []

for ep in range(300):
    s, done, step_count = reset(), False, 0
    states, actions, rewards = [], [], []
    while not done and step_count < MAX_STEPS:
        p = policy(theta, s)
        a = int(np.random.choice(2, p=p))
        states.append(s); actions.append(a)
        s, r, done = step(s, a)
        rewards.append(r)
        step_count += 1

    T = len(rewards)
    # 1) critic：TD(0) 更新，让 V 逼近"剩余折扣回报"；终止态 V=0
    for t in range(T):
        v_next = 0.0 if t + 1 >= T else w @ phi(states[t + 1])
        delta_c = rewards[t] + GAMMA * v_next - w @ phi(states[t])
        w += BETA * delta_c * phi(states[t])

    # 2) actor：用 n-step 回报做优势，再标准化
    advs = np.zeros(T)
    for t in range(T):
        G = 0.0
        for k in range(N):
            if t + k < T:
                G += (GAMMA ** k) * rewards[t + k]
        if t + N < T:
            G += (GAMMA ** N) * (w @ phi(states[t + N]))   # 用 critic 自举
        advs[t] = G - w @ phi(states[t])
    advs = (advs - advs.mean()) / (advs.std() + 1e-8)      # 优势标准化

    for t in range(T):
        theta += ALPHA * advs[t] * grad_log_pi(theta, states[t], actions[t])

    scores.append(step_count)
    if (ep + 1) % 20 == 0:
        print("回合 {:3d}  近20回合平均步数 {:.0f}".format(ep + 1, np.mean(scores[-20:])))

print("训练完成，最后一回合步数：{:.0f}".format(scores[-1]))

要点：Actor（theta）与 Critic（w）分工明确——critic 用 TD(0) 学价值，actor 用 n-step 回报 − V(s) 作优势做策略梯度；advs 的标准化是稳定训练的关键（否则优势尺度过大/过小都会让 actor 学不动）。相比 REINFORCE，这里用 critic 的 V(states[t+N]) 截断了回报（自举），方差更低。运行后平均步数会从随机策略的约 20 步爬到约 150 步。

三、练习#

  1. 把 N 从 5 改成 1、再改成 20，观察学习效果差异；N=1 时优势信号为何最弱？
  2. 删掉 advs = (advs - advs.mean())... 这一行（不做标准化），观察训练是否震荡或学不动，解释标准化的作用。
  3. 把 BETA 设成 0（冻结 critic），此时 advs[t] 退化成什么？算法是否退化为某种"无 baseline 的 REINFORCE"？
  4. 思考题：为什么说 n-step actor-critic 是有偏的？这个"偏"来自哪里（自举？critic 近似？）？N 越大，偏差越大还是越小？
