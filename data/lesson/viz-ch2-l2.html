柱状图#

柱状图用柱子的高度表示数量，适合比较离散类别之间的大小关系。它和直方图长得像，但用途不同——这一课先学柱状图，直方图留到下一章。

一、概念讲解#

1. 柱状图适合什么场景#

柱状图（bar chart）用于展示分类数据的取值对比：横轴是互不连续的类别（地区、产品、班级……），纵轴是该类别的某个数值（销售额、数量、成绩……）。柱子之间留有空隙，强调"类别是离散的"。

2. 基础用法：ax.bar#

ax.bar(x, height) 在位置 x 画出一组柱子，柱高为 height：

categories = ["A", "B", "C"]
values = [3, 7, 5]
ax.bar(categories, values)

若直接传入字符串类别，Matplotlib 会按顺序把它们放在 0、1、2 的位置。需要精确控制时，常配合 NumPy 生成位置数组。

3. 三种常见变体#

  • 水平柱状图：ax.barh(y, width)，把柱子横过来，适合类别名较长的场景。
  • 分组柱状图：多组数据并列展示。做法是先用 np.arange(n) 得到基准位置，再对每组数据加/减偏移 width，分别调用 ax.bar。
  • 堆叠柱状图：多组数据叠在同一根柱子上。做法是传入 bottom= 参数，让后画的柱子"垫"在前一组之上。

4. 其他常用参数#

参数 含义
width 柱子的宽度（默认 0.8）
color 柱子颜色
label 图例标签（配合 ax.legend()）
bottom 柱子底部的起始位置（用于堆叠）
yerr 误差棒（表示不确定度）

二、可运行代码示例#

下面的例子画一张分组柱状图，对比四个区域两个季度的销售额，并在柱顶标注数值。

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False

categories = ["华东", "华北", "华南", "西部"]
q1 = np.array([120, 90, 100, 70])
q2 = np.array([135, 110, 125, 80])

x = np.arange(len(categories))   # 基准位置 [0, 1, 2, 3]
width = 0.35

fig, ax = plt.subplots(figsize=(8, 5))

# 分组：一组左偏、一组右偏，柱宽相同
bars1 = ax.bar(x - width / 2, q1, width, label="第一季度", color="#4c72b0")
bars2 = ax.bar(x + width / 2, q2, width, label="第二季度", color="#dd8452")

ax.set_xticks(x)
ax.set_xticklabels(categories)
ax.set_ylabel("销售额（万元）")
ax.set_title("分组柱状图：两季度各区域销售额")
ax.legend()

# 在每根柱子顶部标注数值
for bar in list(bars1) + list(bars2):
    height = bar.get_height()
    ax.annotate(f"{height:.0f}",
                (bar.get_x() + bar.get_width() / 2, height),
                ha="center", va="bottom", fontsize=9)

plt.show()

三、练习#

  1. 绘制一张单系列柱状图，展示 ["语文", "数学", "英语"] 三科成绩 [88, 92, 79]，并把柱子颜色设为绿色。
  2. 在练习 1 基础上，用 ax.barh 把它改成水平柱状图，并说明哪种场景更适合水平布局。
  3. 用 bottom= 参数绘制一张堆叠柱状图：四个类别各有两个组成部分（例如"线上/线下"销量），让两段叠加在同一根柱子上。
