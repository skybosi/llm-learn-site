趋势可视化#

从这一章开始，我们把前面学到的布局、双轴、样式、配色、标注全部组装起来，做一份完整的数据报告。第一站是趋势可视化——回答"数据随时间的走向如何"。这是商业和科研报告里最常见、也最重要的图之一。

一、概念讲解#

1. 趋势图的核心问题#

趋势图要回答三个问题：往哪个方向走？走得快不快？有没有规律的波动？ 最基础的工具是折线图；在折线图上叠加"平滑"或"移动平均"，能把噪声和长期趋势分离开来。

2. 折线图 vs 面积图#

  • 折线图：强调"点的走势"，适合看趋势、比较多条序列。
  • 面积图（fill_between）：在折线下方填充颜色，强调"总量/体量"的感觉，也常用于展示"范围"（如预测区间的上下界）。

3. 移动平均：让趋势更清晰#

真实数据往往噪声很大，逐日/逐月剧烈跳动。移动平均（moving average）取一个滑动窗口内的平均值，能平滑掉短期波动、暴露长期趋势。窗口越大越平滑，但也会越"滞后"。常用窗口如 7 天（周）、30 天（月）。

二、可运行代码示例#

示例 1：原始趋势 + 移动平均 + 面积图#

下面模拟一家网店一年 365 天的每日销售额，并叠加 30 天移动平均：

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

rng = np.random.default_rng(7)
days = np.arange(1, 366)

# 模拟销售额：缓慢上升的长期趋势 + 周期性波动 + 随机噪声
trend = 100 + 0.3 * days                       # 长期趋势：每天约增长 0.3 元
season = 40 * np.sin(2 * np.pi * days / 365)   # 年周期波动
noise = rng.normal(0, 25, size=365)            # 随机噪声
sales = trend + season + noise

# 30 天移动平均（滑动窗口求均值）
window = 30
ma = np.convolve(sales, np.ones(window) / window, mode='valid')

fig, ax = plt.subplots(figsize=(11, 5.5))

# 面积图：展示"体量"，半透明
ax.fill_between(days, sales, color='tab:blue', alpha=0.15, label='每日销售额')

# 原始折线：细线、浅色，突出噪声
ax.plot(days, sales, color='tab:blue', linewidth=1, alpha=0.7)

# 移动平均线：粗线、深色，突出趋势
# convolve 的 'valid' 模式会让结果变短，对应下标从 window-1 开始
ax.plot(days[window - 1:], ma, color='tab:red', linewidth=2.2, label=f'{window} 天移动平均')

ax.set_title('网店全年每日销售额趋势', fontsize=15)
ax.set_xlabel('天数')
ax.set_ylabel('销售额（元）')
ax.grid(True, alpha=0.3)
ax.legend(loc='upper left')
fig.tight_layout()
plt.show()

要点：np.convolve 用等权窗口做移动平均，是"自己动手实现"最直观的方式；mode='valid' 会丢弃两端无法凑满窗口的部分，所以移动平均线的 x 下标要从 window - 1 开始。fill_between 的 alpha=0.15 让填充色足够淡，不盖住趋势线。

示例 2：展示预测区间（上下界）#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

x = np.linspace(0, 20, 100)
y = 10 + 0.5 * x
lower = y - (2 + 0.2 * x)     # 下界：随 x 变宽的区间
upper = y + (2 + 0.2 * x)     # 上界

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, y, color='tab:blue', linewidth=2, label='预测值')
ax.fill_between(x, lower, upper, color='tab:blue', alpha=0.2, label='置信区间')
ax.set_title('预测值与置信区间')
ax.set_xlabel('x')
ax.set_ylabel('y')
ax.legend()
fig.tight_layout()
plt.show()

要点：fill_between(x, lower, upper) 用两条曲线围出一个"带状区域"，非常适合展示预测的不确定性范围。

三、练习#

  1. 动手练习：把示例 1 的移动平均窗口从 30 天改成 7 天和 90 天，各画一次，观察"窗口越大越平滑、也越滞后"的现象，并写一句话总结窗口大小的取舍。
  2. 对比序列：在同一张图上画出两个城市的日均气温趋势（可用 rng.normal 造两组数据），用不同颜色区分，并加图例。
  3. 标注拐点：找出示例 1 中销售额的最高点，用 annotate 标注出来，并写出它出现在第几天。
  4. 思考：什么时候该用"面积图"而不是"折线图"？面积图有哪些容易误导的地方（例如多序列叠在一起时）？
