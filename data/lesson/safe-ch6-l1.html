这套方法论的边界：结论在什么前提下成立，以及何时必须重做威胁建模#

这一节要解决什么#

前五章给了很多东西：一套威胁模型与年化风险乘式（第 1 章）、一组对齐方法的目标函数与失效条件（第 2 章）、一套红队与有害行为评测的协议（第 3 章）、一套合规、责任与治理的落地结构（第 4 章），以及把零件装成一台机器的综合设计（第 5 章）。它们有一个共同的形状：

结论 = 一个判断 + 一组前提 + 一个适用区间 + 一个证伪方式

前五章把"一个判断"教透了。这一节处理的是后面三项——因为丢掉后面三项之后，同一个判断会变得不可比较、不可复核、不可追责。这不是修辞。本节块 0 会算出一个具体的数：

⚠️ 合成算例：同一句"模型会被越狱"，在两个部署下的年化风险相差 5000 倍。这个倍数与模型的强弱无关，它完全来自前提。

所以本节要回答四个问题：

  1. 结论到底依赖哪四个前提（§一）。把"威胁模型 / 能力档 / 检测器性能 / 评测样本量"写成四个可填的参数，并说明它们在算术上对称、在可测性上极不对称。
  2. 检测器性能为什么会反过来决定你测量出的风险（§二）。同一句话"检出率 90%"，在违规基率 0.50 与 0.01 时含义完全不同；前者几乎等于真话，后者几乎不含信息。给出精确率、假阳性、以及"台面翻转点"。
  3. 样本量不足时"没测出差异"不是结论（§三）。给出样本量公式、平方根标度、以及最小可检出效应。并说明当效应太小时，应当改的是"测什么"，不是"多测多少"。

一、结论依赖的四个前提#

1.1 把前提写成四个可填的参数#

第 1 章给出过年化风险的乘式（并在 §六 写出它的假设与陷阱），第 5 章把它用于防护预算。本节把它作为前提的载体用：

R = i∑​Ni​pi​Ei​ci​

四张牌分别代表：

前提 符号 含义 典型取值来源 可测性
威胁模型 Ni​ 第 i 类事件的年暴露量 业务台账、调用量统计 高（有台账）
能力档 pi​ 对手单次成功率 评测估计（只能估计） 低（要评测）
利用因子 Ei​ 单次成功转化成实际损失的因子 权限模型、工具清单 中（靠架构推定）
损失口径 ci​ 单次损失 财务/合规台账 高（有台账）
（附加） — 检测器性能与评测样本量 见 §二、§三 中低

把检测器性能与样本量单独列出来，是因为它们不改变 R，但决定你读到的 R 是不是真的——§二和§三分别处理。

1.2 块 0：同一句话，两个数量级#

⚠️ 合成算例：取三个部署与三个防护档，参数如下（手写常量）：

部署 N（次/年） 防护档 p E
公开问答 106 无额外防护 0.050 0.30
内部助手 103 加固模型 0.005 0.10
受控运维 2×102 加固 + 输入输出过滤 0.001 0.05

R ∈ [200, 3×108],Rmin​Rmax​​≈1.5×106

同一句"模型能被越狱"，在 9 个前提组合下的结论区间跨了六个数量级。 这不是模型有多少种表现，而是前提有多少种装法。

由此得到本节的第一条判据：

 任何不指明 (N,p,E,c) 的强度描述，都不可比较 ​

"不可比较"是一个很强的说法，需要说清它的意思：它不是说那句话错了，而是说它没有指称对象。"这个模型在越狱上很脆弱"这句话，在 N=106 的公开问答与 N=200 的受控运维里，指的是两个相差六个数量级的东西。要把它们放在一起比，先得把四个参数补齐。

1.3 块 1：算术上对称，可测性上极不对称#

一个容易被忽略的事实：在 R=NpEc 这个乘式里，四个参数在算术上完全对称。对任意一个参数单独做 ±20% 的扰动，R 的相对变化都相同。代码块 1 验证了这一点：

前提 −20% 基线 +20% 单侧相对变化
N 8×106 107 1.2×107 0.4000
p 8×106 107 1.2×107 0.4000
E 8×106 107 1.2×107 0.4000
c 8×106 107 1.2×107 0.4000

四行一模一样。 但它们背后的现实差别极大：

  • N 可以从调用网关拉数；
  • c 可以从财务与合规台账推；
  • E 可以从权限模型推（谁有写权限、能触达什么）；
  • p 只能靠评测估计，而评测本身带着 §二与 §三的两个误差源。

于是：

 结论有多稳，由最难测的那个前提决定，而不是由最容易测的决定 ​

这条判据有一个直接的操作含义：做敏感性分析时，不要均匀地扰动四个参数，而要按"可测性"排序，把最多的注意力给最难测的那个。 在本课的语境里，那个参数是 p——它同时是第 2 章（对齐方法）要压低的量、第 3 章（红队与评测协议）要测准的量，也是全课不确定性最大的一项。§二与§三就是把这个"难"拆成两个可算的部分。

1.4 边界与取舍#

  • 乘式本身是一个选择，不是自然律。 把风险写成 N×p×E×c（而不是相加、也不是取最大）隐含了一个假设：四个环节相互独立且串联——任何一环不发生，损失就不发生。第 5 章 §三 的防护层成本-效果模型与第 5 章第二节 §七 的共线失效正是为"不独立"准备的；一旦环节之间有相关性，乘式会低估风险。修正的办法是在 E 里放进"条件概率"的含义，而不是改成加法。
  • E 是最容易被拍出来的一个数。 它不像 N 和 c 那样有台账，也不像 p 那样有评测流程。工程上的可行做法是从权限模型导出它：能读的、能写的、能对外发起的，各给一个量级，然后让这个量级可核对（第 4 章的证据格式纪律）。
  • "结论区间跨六个数量级"不是失败，是信息。 它告诉你两件事：① 不补前提的讨论无法收敛；② 补完前提之后，R 的量级本身就成为判断"该先修哪一环"的输入（§4.3）。
  • 本节不讨论 p 的测量方法。 p 怎么测（红队用例生成、覆盖度、评测污染）属于第 3 章与本章第 2 节；本节只处理"p 的测量质量如何进入结论"。

二、检测器性能：同一个模型，换个台面，读数就变#

2.1 混淆矩阵给出的四个数#

假设我们用某检测器判定"这条回答违规"。它的性能由四个量决定（混淆矩阵）：

实际违规 实际正常
判为违规 真阳性 TP 假阳性 FP
判为正常 假阴性 FN 真阴性 TN

行业里挂在嘴边的是两个条件概率：

TPR=P(判违规∣实际违规),FPR=P(判违规∣实际正常)

而当你看到"检测器报了一批违规"时，你真正关心的是反向的条件概率——精确率：

精确率 = P(实际违规∣判违规) = πTPR+(1−π)FPRπTPR​

这里 π 是违规基率。注意 π 不在检测器里，它在台面里。

2.2 块 2：精确率随基率崩塌#

⚠️ 合成算例：取 TPR=0.90、FPR=0.10，并加一道人工复核（检出率 s=0.60 用于复核掉假阳性）。代码块 2 给出：

违规基率 π 观测阳性率 精确率 复核后精确率
0.50 0.5000 0.9000 0.9574
0.20 0.2600 0.6923 0.8491
0.05 0.1400 0.3214 0.5422
0.01 0.1080 0.0833 0.1852

π 从 0.50 降到 0.01，精确率从 0.9000 掉到 0.0833——跌了一个数量级还多。但检测器一个参数都没变：TPR 还是 0.90，FPR 还是 0.10。

所以：

 "检出率 90%"在低基率下几乎不携带信息——变的不是检测器，是分母 ​

2.3 台面翻转点#

还有一个更尖锐的量。当 π 足够低时，报出的阳性里假阳性占多数。翻转发生在精确率 =0.5 处，解

πTPR+(1−π)FPRπTPR​=0.5

得

π∗=TPR+FPRFPR​

π∗=TPR+FPRFPR​

代入 TPR=0.90,FPR=0.10 得 π∗=0.10。代码块 2 输出的"台面翻转点 0.5000"是另一个口径（按"观测阳性率 >0.5"定义），两种口径都指向同一件事：存在一个阈值，低于它时系统报出来的阳性以假阳性为主。工程上的含义：

  • 如果你的部署里真实违规基率低于某个水平，那么"今天报警了 100 条"这句话的默认解释应当是"又来了 100 条噪声"，而不是"又发生了 100 次违规"；
  • 提高 TPR 或降低 FPR 都能推迟翻转，但降低 FPR 的边际效果更大，因为分母里的 (1−π)FPR 在低基率下占主导。

2.4 检测器性能进入结论的两条路径#

检测器不改变真实风险，但它以两条路径改变你读到的结论：

  1. 它改变你估计的 p。 评测里用于判定"这条回答是否违规"的判据，本身就是个分类器。若判据有假阴性，你低估 p；有假阳性，你高估 p。§三的样本量公式假定判据是完美的——真实评测没有这个奢侈。
  2. 它改变你部署时的 E 与 c。 检测到的违规可以被拦下（E→0），漏掉的会继续走完流程。于是同一个模型的安全性，在"有这道闸门"与"没这道闸门"下是两个不同的 R。

2.5 边界与取舍#

  • TPR/FPR 是在某个特定测试集上测的。 换一个测试集（换一批分布、换一个时间窗），两个数都会动。所以"检出率 90%"这句话必须连同测试集口径一起报告，否则它不可复核。
  • 人工复核不是免费的精确率。 它把精确率从 0.3214 抬到 0.5422（π=0.05 时），代价是每一条阳性都要人看一遍。第 4 章 §2.2 的"概率输出不等于免责"里已算过抽查只买到零点几个百分点——这里也一样：复核要么全量、要么约等于没做。
  • 低基率场景下，不要用"阳性数"做指标。 应当用经过基率校正的量：要么报精确率与它的置信区间，要么直接报人工确认后的违规数（把人工当成判据的一部分）。
  • "台面"是可以设计的。 构造高基率的压力场景（第 4 章的红队设计）本质上就是在提高 π，让同一个检测器变得有分辨力。这是本章第 2 节"评估污染"之外的另一条提高测量质量的路子。

三、样本量：没测出差异，不等于没有差异#

3.1 样本量公式与它的输入#

设我们要检验"新模型的违规率 p1​ 是否低于基线 p0​"，单侧显著性 α=0.05、功效 1−β=0.80。标准做法把两个条件写成同一批样本上的两个约束：

{c=np0​+zα​np0​(1−p0​)​c=np1​−zβ​np1​(1−p1​)​​（H0​ 下错拒不超过 α）（H1​ 下功效至少 1−β）​

两式消去 c，解出 n：

 n ≥ (p0​−p1​)2(zα​p0​(1−p0​)​+zβ​p1​(1−p1​)​)2​ ​

其中 z0.05​=1.6449、z0.20​=0.8416。这是本节代码用的公式，也是唯一需要背的一个式子：分子是"两边的噪声"，分母是"要分辨的信号"的平方，所以样本量与效应大小的平方成反比。

3.2 块 3：平方根标度#

⚠️ 合成算例：基线 p0​=0.05，问"检出率相对下降 r"需要多少条评测：

相对下降 r 目标 p1​ 所需 n 以 50% 行为 1 的倍数
90% 0.0050 87 0.2 x
70% 0.0150 174 0.5 x
50% 0.0250 384 1.0 x
30% 0.0350 1171 3.0 x
20% 0.0400 2740 7.1 x
10% 0.0450 11362 29.6 x
5% 0.0475 46226 120.4 x

读数有三条：

  1. 效应越小，样本量按平方增长。 相对下降从 50% 缩到 10%（精确度 5 倍），n 涨约 25 倍。这是 n∝1/δ2 的直接后果。
  2. "测 200 条"这个习惯，只能分辨很大的效应。 200 条落在 r≈70% 与 50% 之间——也就是说，只有当违规率减半以上时你才可能有把握说"变好了"。
  3. 小效应场景下，n 会冲破任何合理预算。 想分辨 r=5%（绝对差 0.0025）要 4.6 万条。

3.3 反过来问：最小可检出效应（MDE）#

固定 n，把上面的公式反解 δ=∣p0​−p1​∣，得到 MDE。⚠️ 合成算例：

可用 n 可检出的绝对效应 相对下降 等价精确度（以 8000 条为 1）
500 0.0222 44.4% 1.0 倍
2000 0.0116 23.3% 1.9 倍
8000 0.0059 11.9% 3.7 倍

n 翻两番（500→2000），可检出效应只减半；再翻两番，再减半。这就是平方根标度的另一面：

 把评测数据量翻 4 倍，能分辨的效应只减半——小数应的边际收益极低 ​

于是本节的第三条判据：

 当效应小于 MDE 时，应当改的是"测什么"，不是"多测多少" ​

什么叫"改测什么"？把评测从自然分布换到压力分布：构造高基率的场景（让 p0​ 从 0.05 抬到 0.30），同样的 n 就能分辨小得多的相对变化；或者用第 3 章的对抗性用例设计，让违规事件在测试集里更密集。这是第 4 章红队部分的覆盖度与第 3 章的"检验功效"两件事的接口。

3.4 分摊到多个规格：随机化单位的陷阱#

评测常常在多条"规格"（模板、语言、场景）上跑。若把 n 条平均分到 k 个规格上，每个规格内部的样本量是 n/k——但只有当规格之间的效应方向一致、且你按规格做分层估计时，这个分摊才是有效的。⚠️ 合成算例（r=50%，总 n∗=384）：

规格数 k 每规格样本
1 384
5 77
10 39
50 8

每规格 8 条时，任何单规格的检验都不可能有效——这时的正确写法是事前登记合并口径（把规格当成区组，用合并估计），而不是"每个规格都跑一遍再看哪个显著"。后者会在 k 个规格上做 k 次检验，把整体的假阳性率抬到 1−(1−α)k：k=10 时是 0.4013。

3.5 边界与取舍#

  • 公式假设"一批样本、一次检验"。 如果评测是序贯的（边测边看、够了就停），α 会随查看次数膨胀；需要序贯检验的边界（第 4 章审计部分的 ARL0​ 是同一类工具）。
  • p0​ 本身是估计值。 上面的 n 公式把 p0​ 当成已知——真实的 p0​ 有它自己的不确定度。工程上的做法是取 p0​ 的上界估一个更保守的 n，而不是拿点估计直接代入。
  • 功效解决不了"选错指标"的问题。 一个功效 0.99 的检验，如果检验的是代理指标（例如"拒答率"），得到的仍然是关于代理指标的结论。这就是第 2 章的"对齐税"与本章第 2 节"评估污染"要一起看的原因。
  • 不要用"显著性"替代"大小"。 p<0.05 只说明"效应与 0 可区分"，不说明效应有多大。报告必须同时给出效应量与区间——第 2 章 §4 的对齐税已经把这个纪律写成了可证伪的断言。

四、何时必须重做威胁建模#

4.1 为什么需要一个判据#

威胁模型是在某个时刻、按当时的信息写下的。它会过期，但过期不会自己报警：系统的功能在涨，权限在变，用户在变，而文档停在原地。于是需要一个可判定的触发器，而不是"每年复核一次"这种日历规则。

受控运维：架构不变，损失口径 ×10 0.1250 否 不重做结构，只重算排序与阈值

注意第二行的关键设计：它的分数只有 0.3750，低于 0.50 的阈值，但因为命中了强制项，仍然要重做。这不是矛盾，而是刻意的：

 结构变化不能用分数摊平——分数是为"累积的小变化"设计的，不是为"一次跳跃"设计的 ​

"从无工具到有工具"不是若干小变化的累积，它把一个原来不存在的信道（第 2 章的间接注入路径）变成了存在。这类变化必须单独设一条硬规则。

4.3 把"重做"拆成两个动作#

这是本节最实用的一条重构。"重做威胁建模"其实是两种完全不同的工作：

动作 触发条件 改什么 成本 交付物
结构重做 谓词命中（尤其强制项） 改结论的形状：新的资产、新的信道、新的边界 高（数周） 新版威胁模型文档
参数重算 只有数值变（N、c 的量级变化） 改结论的数值：R 重算、措施重新排序 低（数小时） 新一版 R 与排序表

把这两件事混为一谈，会造成两种失败：要么每次损失口径微调都重写一遍文档（结果是文档没人维护，因为成本太高），要么把"新增工具调用"也当成一次参数更新（结果是边界在无人察觉的情况下失效）。

操作上的写法：在威胁模型文档里给每一条结论标注它依赖的结构谓词。结构谓词变了，那条结论作废；只有数值变了，那条结论重算。

4.4 边界与取舍#

  • 权重是主观的。 上面 2.0/3.0 这些数没有客观来源，它们是"这一条变化有多大"的组织内部约定。可核对的部分是口径：把权重写在文档里、由谁定的、多久复核一次——而不是权重本身有多"对"。这与第 4 章风险登记册的纪律是同一条。
  • 0.50 的阈值也是选出来的。 它的作用是让"要不要重做"变成一个可以争论的数字，而不是可以争论的态度。
  • 判据表本身要维护。 当一次真实事故的原因不在这 8 条谓词里时，这次的教训就是"判据表缺了一条"，补进去比写一份复盘报告更有用。
  • "无需重做"是一个有期限的结论。 它意味着"在当前谓词表下没有命中项"，而不是"这个系统永远不需要重做"。所以 §五的结论卡片里才有"边界"那一段。

六、边界与取舍#

6.1 本节自身的边界#

  1. 本节不判定"要不要做安全"。 它只处理"结论是否可比较、可复核、可追责"。一个组织可以读完本节后决定接受某个 R——那是风险偏好，不是技术结论。
  2. 四个前提不是穷尽的。 检测器性能与样本量是本节补上的两个，但还有别的：标注者的一致性、时间窗的选择、p 的估计方法（本章第 2 节的评测污染）。每补一个前提，R 的不确定度只会变大，不会变小。
  3. 权重与阈值都是组织约定。 §4.2 的 2.0/3.0 与 0.50 没有客观来源；可核对的是口径与负责人，不是数值本身。
  4. 本节的公式全是渐近的。 n 公式基于正态近似；在 p 很小（<0.01）或 n 很小（<30）时应当用精确二项。近似在工程预算量级上的误差通常可接受，但结论的措辞要跟着降级（"约需 400 条"而不是"需要 384 条"）。
  5. "不可判定"是一个合法结论。 §三的整个存在意义就是让"没测出差异"与"没有差异"分开。当样本量低于 MDE 时，正确的交付物是"不可判定 + 需要多少样本"，而不是一个勉强的方向性判断。

6.2 C 级推测与证伪方式#

以下三条是推测，不得当作结论使用；每条附带证伪方式。

编号 推测 证伪方式
C1 "把四个前提写全，会让安全讨论更快收敛" —— 未验证：写全前提增加了每次讨论的固定成本，在小团队、快节奏场景下可能反而降低决策速度 在一个团队里做前后对照：记录两次同类安全评审的时长与结论是否被复核；若写全前提后时长显著增加而结论质量无改善，本条不成立
C2 "结构谓词表能覆盖大多数需要重做威胁模型的变化" —— 未验证：8 条谓词是归纳，不是穷举；真实事故的成因分布未知 统计一段时间内实际发生的"边界失效"事件，看有多少落在表内；落在表外的比例就是这张表的漏检率
C3 "四种防护档的风险差可以按乘式叠加" —— 未验证：p 与 E 很可能不独立（加固模型会改变攻击者的行为，从而改变 E） 在真实系统上实测"分别加固"与"同时加固"的 p⋅E；若联合效果显著优于乘积，独立性假设不成立

def n_normal(p0, p1, alpha=0.05, power=0.80):
    """区分 p0 与 p1（|p1-p0| 为绝对效应）所需的单侧样本量，正态近似。

    z_a*se0 + z_b*se1 <= |p0-p1|*sqrt(n)  ->  n = (z_a*se0 + z_b*se1)^2 / (p0-p1)^2
    其中 se 是「单个比例」的标准误 sqrt(p(1-p))；两边都是同一批样本，这是单样本检验。
    """
    z_a = 1.6448536269514722      # alpha = 0.05 单侧
    z_b = 0.8416212335729143      # power = 0.80
    num = (z_a * math.sqrt(p0 * (1 - p0)) + z_b * math.sqrt(p1 * (1 - p1))) ** 2
    return num / (p1 - p0) ** 2


def mde(p0, n, alpha=0.05, power=0.80):
    """n 固定时能检出的最小绝对效应（解同一个方程）：|p1-p0| >= (z_a*se0+z_b*se1)/sqrt(n)。

    这里用迭代：先以 p1=p0 起算 se1，再回代。
    """
    z_a = 1.6448536269514722
    z_b = 0.8416212335729143
    p1 = p0
    for _ in range(60):
        gap = (z_a * math.sqrt(p0 * (1 - p0))
               + z_b * math.sqrt(max(p1 * (1 - p1), 1e-18))) / math.sqrt(n)
        p1 = max(0.0, p0 - gap)
    return p0 - p1

=== 1. 假设敏感性：哪一个前提最决定结论 ===

小结#

  • 结论 = 判断 + 前提 + 边界 + 证伪方式。 ⚠️ 合成算例里，同一句"模型会被越狱"在三个部署 × 三个防护档下的 R 区间是 200∼3×108，相差 1.5×106 倍——不指明 (N,p,E,c) 的强度描述不可比较。
  • 四个前提在算术上对称、在可测性上极不对称。 ±20% 的扰动给四个参数带来完全相同的相对变化（0.4000）；但 N 与 c 有台账、E 靠架构推定、p 只能靠评测。结论有多稳，由最难测的那个前提决定。
  • 检测器性能反过来决定你读到的风险。 TPR=0.90,FPR=0.10 时，π 从 0.50 降到 0.01 会让精确率从 0.9000 掉到 0.0833；变的不是检测器，是分母。人工复核（s=0.60）能把 π=0.05 的精确率抬到 0.5422，但必须覆盖全部阳性。
  • 样本量与效应平方成反比。 p0​=0.05 下，r=50% 需 384 条，r=10% 需 11362 条（29.6 倍），r=5% 需 46226 条。"测 200 条"只能分辨很大的效应。
  • MDE 与 n​ 成反比。 n 从 500 涨到 2000（4 倍），可检出效应从 0.0222 缩到 0.0116（1.9 倍）。"多测点数据"对小数应的边际收益极低——该改的是"测什么"。
  • 多规格分摊要事前登记合并口径。 k=10 时每规格只剩 39 条；若每规格各做一次检验，整体假阳性率涨到 1−0.9510=0.4013。
  • "重做威胁建模"要拆成两个动作。 ⚠️ 算例里"新增长记忆 + 只读工具"的加权分只有 0.3750（低于 0.50 阈值），却因命中强制项必须重做——结构变化不能用分数摊平。
  • 结论体检把可复核性变成可比的数。 ⚠️ 示范卡片 12/16 对典型内部汇报 4/16；最常缺的两项是"取值依据与不确定度"和"适用区间与越界判据"。
  • 本节交付物四件：① §1.2 的 (N,p,E,c) 四元组与 R 区间算法；② §2.2–2.3 的检测器读数表（精确率、复核后精确率、台面翻转点）；③ §3.1–3.3 的样本量公式、平方根标度表与 MDE 反解；④ §4.2 的加权谓词表 + 强制触发规则 + "结构重做 / 参数重算"二分。
