连续性#

上一课我们认识了极限。现在把它"接"起来，就得到另一个核心概念：连续。连续性是函数"能不能一口气画完"的直观描述，也是机器学习里优化算法得以工作的基本前提之一。

一、概念讲解#

1. 连续：铅笔不抬起来就能画完#

先给直觉：如果一条曲线你能不抬笔、一笔画完，它就是连续的；如果中途有"断口""跳跃"，就是不连续的。

严谨一点，函数 f(x) 在点 a 处连续，要同时满足三个条件：

  1. f(a) 有定义（这一点真的存在）；
  2. lim f(x)（x→a）存在（左右逼近结果一致）；
  3. 极限值等于函数值，即 lim f(x) = f(a)。

一句话：连续 = 极限存在，并且极限正好落在函数值上。 上一课那个 sin(x)/x 在 x=0 处就不满足条件 1（没有定义），所以它在 0 处是"不连续"的——哪怕它的极限是 1。

2. 间断点的几种类型#

函数"断"的方式主要有三种，认清楚它们很有用：

  • 可去间断点：只是某一点"漏了"或"填错"了，补上就连续。例如 sin(x)/x 在 0 处。
  • 跳跃间断点：曲线在某处"跳"了一下，左右极限不相等。例如符号函数在 0 处。
  • 无穷间断点：函数在某点附近冲向无穷大。例如 1/x 在 0 处。

3. 连续性与机器学习#

为什么学 AI 要关心"连续"？

  • 大部分损失函数都是连续函数。梯度下降依赖"损失随参数平滑变化"这一性质——如果损失函数到处都是断点，微小的参数调整会让损失剧烈跳动，优化就无从谈起。
  • 神经网络常用的激活函数（如 Sigmoid、ReLU）中，Sigmoid 处处连续，ReLU 在 0 处虽然"有拐角"但也是连续的。理解连续性，能帮你判断一个模型"好不好优化"。

二、可运行示例#

下面我们用 Python 数值检测"函数在某点是否连续"。

import math

def sign_like(x):
    """类似符号函数：x>0 取 1，x<0 取 -1，x=0 取 0。"""
    if x > 0:
        return 1
    elif x < 0:
        return -1
    else:
        return 0

def is_continuous_at(f, a, step=1e-6):
    """
    用数值法粗略判断 f 在 a 处是否连续：
    比较 a 左右两侧各一小步的函数值，看是否都靠近 f(a)。
    返回左右两边的偏差（越小越连续）。
    """
    fa = f(a)
    left = f(a - step)   # 从左边逼近
    right = f(a + step)  # 从右边逼近
    return abs(left - fa), abs(right - fa)

# 连续函数 f(x) = x^2 在 0 处
print("f(x)=x^2 在 0 处：", is_continuous_at(lambda x: x*x, 0))

# 符号函数在 0 处（左右极限不一致 → 不连续）
print("符号函数在 0 处：", is_continuous_at(sign_like, 0))

# 1/x 在 0 处（无定义 → 不连续）
def reciprocal(x):
    return 1 / x
try:
    print("1/x 在 0 处：", is_continuous_at(reciprocal, 0))
except ZeroDivisionError:
    print("1/x 在 0 处：无法计算（f(0) 无定义，不满足连续条件 1）")

运行结果：

f(x)=x^2 在 0 处： (1.0000000001109595e-12, 1.0000000001109595e-12)
符号函数在 0 处： (2.0, 2.0)
1/x 在 0 处：无法计算（f(0) 无定义，不满足连续条件 1）

看第一行：x² 左右两边的函数值都和 f(0)=0 几乎一样（偏差约 1e-12，接近 0），所以连续。第二行：符号函数左右都偏离 f(0)=0 足足 2.0，说明有"跳跃"，不连续。第三行：f(0) 根本没有定义，直接报错——三种情况正好对应连续性的三个条件。

连续函数的一个实用性质：零点定理#

连续函数有个很有用的性质：如果 f(a) 和 f(b) 一正一负，那么在 a 和 b 之间一定存在一个点 c，使 f(c) = 0。这直觉上很好懂：一笔画从"横轴上方"到"横轴下方"，中间必然穿过横轴。这个性质是很多"求根算法"（如二分法）的理论基础。

def bisection(f, a, b, tol=1e-6):
    """二分法求 f(x)=0 的根，前提：f(a) 与 f(b) 异号。"""
    if f(a) * f(b) >= 0:
        raise ValueError("f(a) 与 f(b) 必须异号")
    while b - a > tol:
        mid = (a + b) / 2
        if f(mid) == 0:
            return mid
        if f(a) * f(mid) < 0:
            b = mid
        else:
            a = mid
    return (a + b) / 2

# 求 x^2 - 4 = 0 在 [0, 3] 内的根
root = bisection(lambda x: x*x - 4, 0, 3)
print("\n二分法求得 x^2-4=0 的根：", root)

三、练习#

  1. 用 is_continuous_at 分别检测 f(x)=sin(x)/x、f(x)=|x|（绝对值）、f(x)=1/x 在 x=0 处的连续性，并说出每个结果对应的是"连续"还是哪类"间断"。
  2. 把上一课的 sin(x)/x 改成一个"补上缺口"的新函数：当 x=0 时返回 1，其余返回 sin(x)/x。现在它在 0 处连续吗？用代码验证。
  3. 用二分法求 x³ - 2 = 0 在 [1, 2] 内的根（即 2 的立方根），并和 2 ** (1/3) 对比。
  4. 想一想：ReLU 函数 relu(x) = max(0, x) 在 x=0 处连续吗？用 is_continuous_at 验证，并解释结果。
