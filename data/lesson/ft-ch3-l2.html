LoRA 实现#

上一课讲清了 LoRA 的数学原理，这一课用 Hugging Face PEFT 库把它落到工程上：怎么配置、往哪些层挂 LoRA、怎么训练、怎么保存与合并。学完本课，你就能把 LoRA 微调完整跑起来。

一、概念讲解#

1. PEFT 库与 LoraConfig#

PEFT（Parameter-Efficient Fine-Tuning）是 Hugging Face 推出的参数高效微调统一库。用 LoRA 只需两步：先定义一个 LoraConfig，再用 get_peft_model(model, config) 把普通模型包装成带 LoRA 的模型。

LoraConfig 的关键参数：

参数 含义 常见取值
r 低秩维度 4 / 8 / 16
lora_alpha 缩放系数 α 通常取 r 的 1~2 倍（如 16）
lora_dropout 低秩支路的 dropout 率 0.05
target_modules 挂 LoRA 的模块名列表 ["q_proj", "v_proj"] 等
bias 是否训练偏置 "none"（默认不训）
task_type 任务类型 "CAUSAL_LM"（因果语言模型）

2. target_modules：往哪里挂#

LoRA 不是挂在所有参数上，而是选择性地挂在注意力层的投影矩阵上。最常见的做法是挂 q_proj 和 v_proj（查询、值投影），有时再加 k_proj、o_proj，或 FFN 的 up_proj、down_proj。挂得越多，可训练参数越多、表达力越强，但成本也越高。

不同模型的模块命名不同（LLaMA 系叫 q_proj，GPT-2 系叫 c_attn），可以先用 model.named_modules() 查看实际名字，或直接用 target_modules="all-linear" 让库自动匹配所有线性层。

3. 训练流程#

包装成 PEFT 模型后，训练流程和第 2 章完全一样：Trainer 只更新 requires_grad=True 的参数（也就是 A、B），原权重冻结。训练中可以用 model.print_trainable_parameters() 实时查看可训练参数量。

4. 保存与合并（merge）#

  • 保存适配器：训练完用 model.save_pretrained(...) 只保存 LoRA 权重（A、B），通常只有几 MB。
  • 推理两种方式：
    • 加载适配器：PeftModel.from_pretrained(base_model, adapter_path)，推理时原权重 + 低秩旁路分开算，可动态切换不同任务的适配器。
    • 合并进基座：model.merge_and_unload() 把 BA 直接加进 W0，得到一份和原模型同结构的完整权重，推理零额外延迟、可正常量化/导出。

5. 常见坑#

  • pad_token 未设置：LoRA + 因果模型训练时常因 pad_token 报错，记得 tokenizer.pad_token = tokenizer.eos_token。
  • 精度不匹配：混合精度训练时，低秩矩阵的计算精度要和模型一致，PEFT 会自动处理，但要留意 bf16/fp16 可用性。
  • target_modules 名字写错：拼错会导致一个 LoRA 都没挂上，训练"看似在跑却毫无效果"。务必先打印模块名核对。
  • merge_and_unload 后忘了量化：如果要在合并后做量化，注意顺序——一般先合并再量化，或用 QLoRA（下一课讲）。

二、可运行代码示例#

下面完整走一遍"配置 → 包装 → 查看可训练参数 → 训练 → 保存"。

# 安装：pip install peft transformers datasets accelerate
from transformers import AutoTokenizer, AutoModelForCausalLM, Trainer, TrainingArguments
from peft import LoraConfig, get_peft_model
from datasets import Dataset

model_name = "Qwen/Qwen2.5-0.5B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
if tokenizer.pad_token is None:
    tokenizer.pad_token = tokenizer.eos_token

# 1) 加载基座模型
model = AutoModelForCausalLM.from_pretrained(model_name)

# 2) 配置 LoRA：只挂注意力层的 q_proj / v_proj
lora_config = LoraConfig(
    r=8,                              # 低秩维度
    lora_alpha=16,                    # 缩放系数
    target_modules=["q_proj", "v_proj"],  # 往哪里挂 LoRA
    lora_dropout=0.05,                # 低秩支路 dropout
    bias="none",                      # 不训练偏置
    task_type="CAUSAL_LM",            # 因果语言模型
)

# 3) 包装成 PEFT 模型，原权重冻结，只训练 A、B
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()    # 打印"可训练/总"参数量

# 4) 准备玩具数据（与第 2 章相同的 SFT 格式）
raw = [
    {"instruction": "把下面的句子翻译成英文", "input": "今天天气很好。", "output": "The weather is nice today."},
    {"instruction": "把下面的句子翻译成英文", "input": "我喜欢学习编程。", "output": "I like learning to program."},
]

def tokenize_fn(example):
    messages = [
        {"role": "user", "content": example["instruction"] + "\n" + example["input"]},
        {"role": "assistant", "content": example["output"]},
    ]
    prompt = tokenizer.apply_chat_template(messages[:-1], tokenize=False, add_generation_prompt=True)
    full = tokenizer.apply_chat_template(messages, tokenize=False)
    p_ids = tokenizer(prompt, add_special_tokens=False)["input_ids"]
    f_ids = tokenizer(full, add_special_tokens=False)["input_ids"]
    return {"input_ids": f_ids, "labels": [-100]*len(p_ids) + f_ids[len(p_ids):]}

dataset = Dataset.from_list(raw).map(tokenize_fn)

# 5) 训练（LoRA 通常能用更大的学习率，因为只训少量参数）
training_args = TrainingArguments(
    output_dir="./lora-output",
    per_device_train_batch_size=1,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,               # 比全参数微调大一个量级
    num_train_epochs=3,
    warmup_ratio=0.03,
    lr_scheduler_type="cosine",
    bf16=True,
    logging_steps=1,
    report_to="none",
)

trainer = Trainer(model=model, args=training_args, train_dataset=dataset, tokenizer=tokenizer)
trainer.train()

# 6) 保存适配器（只有几 MB）
model.save_pretrained("./lora-adapter")
print("\nLoRA 适配器已保存到 ./lora-adapter")

再看"合并"与"动态加载"两种推理方式的用法。

from peft import PeftModel

# 方式一：合并进基座，得到一份完整权重，推理零额外延迟
merged = model.merge_and_unload()
merged.save_pretrained("./lora-merged")

# 方式二：动态加载适配器，在同一基座上切换不同任务
# （需重新加载基座模型再挂适配器，此处仅示意接口）
base = AutoModelForCausalLM.from_pretrained(model_name)
peft_model = PeftModel.from_pretrained(base, "./lora-adapter")

print("\n两种用法：")
print("  merge_and_unload -> 完整权重，便于导出/量化，不可再切换任务")
print("  PeftModel.from_pretrained -> 可插拔，多任务共用一个基座")

三、练习#

  1. 填空：LoRA 用 PEFT 库的 ____ 类来配置，用 ____ 函数把普通模型包装成 PEFT 模型；target_modules 决定 ____，task_type 对因果语言模型应设为 ____。
  2. 判断：merge_and_unload() 之后，还能否在同一基座上动态切换多个任务？为什么？
  3. 动手实验：把 target_modules 从 ["q_proj", "v_proj"] 改为 ["q_proj", "v_proj", "k_proj", "o_proj"]，重新运行 print_trainable_parameters()，观察可训练参数如何变化。
  4. 思考题：为什么 LoRA 微调通常可以用比全参数微调更大的学习率（如 2e-4 vs 2e-5）？从"只更新少量低秩参数、扰动小"的角度解释。
