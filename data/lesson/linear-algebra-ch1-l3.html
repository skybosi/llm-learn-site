点积与范数#

掌握了加减与数乘之后，这一课学习向量最"出圈"的两个概念：点积（内积） 与范数（长度）。点积是衡量"两个向量有多像/有多相关"的利器，范数则是"向量有多长"的度量。它们在机器学习里无处不在：相似度计算、损失函数、正则化、注意力机制，全都离不开它们。

一、概念讲解#

1. 点积：对应分量相乘再求和#

两个同维度向量 a = (a₁, a₂, …, aₙ) 和 b = (b₁, b₂, …, bₙ) 的点积定义为：

a · b = a₁·b₁ + a₂·b₂ + … + aₙ·bₙ

也就是：把对应位置的分量相乘，然后把所有乘积加起来。结果是一个标量（一个普通数字），不再是一个向量。

例如：

(1, 2, 3) · (4, 5, 6) = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32

点积有很强的几何含义，它与两个向量的夹角 θ 有关：

a · b = ‖a‖ · ‖b‖ · cos(θ)

其中 ‖a‖ 是 a 的长度。由此可以推出一个非常重要的结论：

  • 点积为正：两个向量方向大致一致（夹角小于 90°）；
  • 点积为零：两个向量互相垂直（正交）；
  • 点积为负：两个向量方向大致相反。

2. 范数：向量的长度#

范数（norm） 用来度量向量的大小。最常用的是 L2 范数（欧几里得长度），它就是"从原点到这个点的直线距离"：

‖a‖₂ = √(a₁² + a₂² + … + aₙ²)

例如 (3, 4) 的 L2 范数是 √(9 + 16) = 5。你会发现，L2 范数的平方其实就等于向量与自己的点积：‖a‖² = a · a。

另一个常见的是 L1 范数，它是所有分量绝对值之和：

‖a‖₁ = |a₁| + |a₂| + … + |aₙ|

3. 余弦相似度：点积与范数的"合体"#

把点积公式变形，就得到两个向量夹角的余弦：

cos(θ) = (a · b) / (‖a‖ · ‖b‖)

这个值叫做余弦相似度（cosine similarity），取值在 [-1, 1] 之间。它只关心"方向是否一致"，不关心"向量有多长"，所以特别适合比较文本、图片、用户兴趣这类"长度没有固定含义"的向量。

4. 机器学习中的应用#

  • 相似度检索：把两句话、两张图编码成向量，用余弦相似度判断它们有多接近；推荐系统、搜索引擎、人脸识别都这么干。
  • 损失函数：回归问题的误差常用 ‖预测值 - 真实值‖² 来度量，这就是"平方误差"，本质就是范数平方。
  • 正则化：为了防止模型过拟合，常在损失里加 λ·‖w‖（L1 或 L2 范数），约束权重向量不要过大。

二、可运行示例#

下面用 NumPy 计算点积、范数和余弦相似度，并演示一个"用余弦相似度比较两句话"的简化例子。

import numpy as np

# 两个三维向量
a = np.array([1.0, 2.0, 3.0])
b = np.array([4.0, 5.0, 6.0])

# 1) 点积：np.dot 或 @ 运算符
dot = np.dot(a, b)
print("点积 a·b =", dot)              # 32.0

# 2) 范数：np.linalg.norm 默认是 L2 范数
norm_a = np.linalg.norm(a)
norm_b = np.linalg.norm(b)
print("a 的 L2 范数 =", norm_a)        # ≈3.7417
print("b 的 L2 范数 =", norm_b)        # ≈8.7750

# 3) 余弦相似度 = 点积 / (范数之积)
cos_sim = dot / (norm_a * norm_b)
print("a 与 b 的余弦相似度 =", cos_sim)  # ≈0.9746

# 4) L1 范数
l1_a = np.linalg.norm(a, ord=1)
print("a 的 L1 范数 =", l1_a)          # 6.0

# 5) 简化应用：用余弦相似度比较两句话的词频向量
# 词表顺序固定为：[猫, 狗, 喜欢, 鱼]
s1 = np.array([1, 0, 1, 1])   # "猫 喜欢 鱼"
s2 = np.array([0, 1, 1, 1])   # "狗 喜欢 鱼"
s3 = np.array([1, 0, 0, 0])   # "猫"

def cosine(u, v):
    """计算两个向量的余弦相似度。"""
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))

print("s1 与 s2 相似度 =", cosine(s1, s2))  # 两个句子主题接近，值较大
print("s1 与 s3 相似度 =", cosine(s1, s3))  # 一个句子 vs 单个词，值较小

预期输出（大意）：

点积 a·b = 32.0
a 的 L2 范数 = 3.7416573867739413
b 的 L2 范数 = 8.774964387392123
a 与 b 的余弦相似度 = 0.9746318461970762
a 的 L1 范数 = 6.0
s1 与 s2 相似度 = 0.6666666666666667
s1 与 s3 相似度 = 0.5773502691896258

要点：np.linalg.norm 默认算 L2 范数，加参数 ord=1 就是 L1 范数；余弦相似度公式自己动手写一遍，比死记 sklearn 的现成函数更能理解它的本质。

三、练习#

  1. 手算 (1, 2, 3) · (4, 5, 6) 和 (3, 4) 的 L2、L1 范数，再用 NumPy 验证。
  2. 构造两个互相垂直的向量（例如 (1, 0) 和 (0, 1)），验证它们的点积等于 0。
  3. 用 cosine 函数比较三个你自己设计的词频向量，观察"主题接近"与"主题不同"时相似度数值的差异。
