条件概率与独立性#

现实中的判断很少是在"一无所知"的情况下做出的：我们先观察到一些信息，再据此更新对某件事的判断。比如拿到一封邮件，看到里面出现了"免费""中奖"这些词，我们对"它是垃圾邮件"的把握就会变大。这种"在已知某事件发生的条件下，另一事件发生的概率"，就是条件概率。它是贝叶斯公式和朴素贝叶斯分类器的直接前提。

一、概念讲解#

1. 条件概率的定义#

在事件 B 已经发生的条件下，事件 A 发生的概率记作 P(A | B)，读作"在 B 发生的前提下 A 的概率"。它的定义是：

P(A | B) = P(A ∩ B) / P(B)，其中 P(B) > 0

直观理解：既然已经知道 B 发生了，样本空间就从原来的 Ω"收缩"到了 B，我们只在 B 这个范围里看 A 也发生的部分。分母 P(B) 是归一化，保证条件概率仍然落在 [0, 1]。

一个经典例子：从一副 52 张扑克牌里抽一张，已知抽到的是红牌（红桃或方块，共 26 张），问它是红桃的概率。此时"样本空间"缩到 26 张红牌，其中红桃 13 张，所以 P(红桃 | 红牌) = 13/26 = 1/2。

2. 乘法法则#

把条件概率的定义两边同乘 P(B)，就得到乘法法则：

P(A ∩ B) = P(A | B) · P(B)

它告诉我们"两件事同时发生"的概率等于"先发生一件，再在这基础上发生另一件"。这是计算联合概率的基本工具，可以推广到多个事件依次发生。

3. 独立性#

如果知道 B 发不发生，完全不影响 A 的概率，即 P(A | B) = P(A)，我们就说 A 与 B 独立。把它代入乘法法则，得到独立的等价刻画：

A 与 B 独立 ⇔ P(A ∩ B) = P(A) · P(B)

独立是概率论里最重要的简化假设：一旦两个随机量独立，联合概率就能拆成单独概率的乘积，计算量从"指数级"降到"线性级"。注意区分两个概念：互斥（A∩B = ∅，不能同时发生）和独立（互不影响）是两回事，甚至可以说互斥的事件反而不独立——一个发生另一个就必不发生。

4. 全概率公式（贝叶斯的铺垫）#

有时事件 A 的概率不好直接算，但它在一组"分情况"下的条件概率好算。设 B₁, B₂, …, Bₙ 两两互斥且并起来等于整个样本空间（它们构成一个"划分"），那么：

P(A) = P(A | B₁)P(B₁) + P(A | B₂)P(B₂) + … + P(A | Bₙ)P(Bₙ)

这就是全概率公式，意思是"把 A 按不同的前提拆开分别算，再加起来"。下一课的贝叶斯公式正是它的直接推论。

5. 机器学习视角：特征独立性假设#

朴素贝叶斯分类器之所以"朴素"（naive），就是因为它假设：给定类别后，各个特征之间相互独立。这样联合概率 P(词₁, 词₂, …, 词ₙ | 类别) 就能拆成 P(词₁ | 类别) · P(词₂ | 类别) · … · P(词ₙ | 类别)。这个假设在现实中常不成立（"免费"和"中奖"往往一起出现），但它在实践中出奇地好用，是"简化假设换效率"的典范。

二、可运行示例#

示例 1：扑克牌条件概率的精确计算#

# 构造一副 52 张扑克牌：4 种花色 × 13 种点数
suits = ["红桃", "方块", "黑桃", "梅花"]
deck = [(s, r) for s in suits for r in range(1, 14)]  # 共 52 张


def p_heart_given_red():
    """P(红桃 | 红牌)：已知抽到红牌，问是红桃的概率。"""
    red = [c for c in deck if c[0] in ("红桃", "方块")]   # 26 张红牌
    heart = [c for c in deck if c[0] == "红桃"]           # 13 张红桃
    return len(heart) / len(red)                          # 13/26 = 0.5


print(f"P(红桃 | 红牌) = {p_heart_given_red():.3f}")

示例 2：用频率模拟验证条件概率#

import random

random.seed(7)


def draw_card():
    """随机抽一张牌，返回 (花色, 点数)。"""
    suits = ["红桃", "方块", "黑桃", "梅花"]
    return random.choice(suits), random.randint(1, 13)


def conditional_probability(trials, event_a, event_b):
    """用频率法估计 P(A|B) = A、B 同时发生次数 / B 发生次数。"""
    both = 0
    b_count = 0
    for _ in range(trials):
        card = draw_card()
        if event_b(card):       # 先判断 B 是否发生
            b_count += 1
            if event_a(card):   # 在 B 发生的条件下再看 A
                both += 1
    return both / b_count if b_count else 0.0


is_heart = lambda c: c[0] == "红桃"
is_red = lambda c: c[0] in ("红桃", "方块")

p = conditional_probability(200000, is_heart, is_red)
print(f"P(红桃 | 红牌) 的模拟估计 = {p:.4f}（理论值 0.5000）")

示例 3：验证独立事件的联合概率#

import random

random.seed(1)


def two_coins(trials):
    """抛两次硬币。A：第一次正面；B：第二次正面。两次独立。"""
    both_heads = 0
    first_heads = 0
    for _ in range(trials):
        first = random.random() < 0.5
        second = random.random() < 0.5
        if first:
            first_heads += 1
            if second:
                both_heads += 1
    return both_heads / trials, first_heads / trials


p_both, p_first = two_coins(200000)
print(f"P(A 且 B) = {p_both:.4f}")
print(f"P(A) × P(B) = {p_first * 0.5:.4f}")  # 独立时两者应近似相等
