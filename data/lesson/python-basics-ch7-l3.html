上下文管理器 with#

前面读写文件时，我们每次都要手动调用 close()，一不留神就可能忘记。Python 提供了一个更优雅的写法 with，它能自动帮我们"善后"，让代码更简洁也更安全。这一课我们就来认识它。

一、概念讲解#

1. 为什么要用 with#

先回想一下之前写文件的方式：

f = open("data.txt", "w", encoding="utf-8")
f.write("hello")
f.close()   # 容易忘记这一句

如果 write() 的过程中突然出错，程序会直接跳走，close() 就永远执行不到，文件就一直是"打开"状态。with 语句可以保证：无论中间是否出错，离开 with 块时资源一定会被正确释放。

2. with 的基本写法#

with open("data.txt", "w", encoding="utf-8") as f:
    f.write("hello")
# 出了这个缩进块，文件已经自动关闭了
  • with 后面跟着 open(...)，用 as f 给它起个名字 f；
  • 缩进块里正常读写；
  • 缩进块结束（或中途出错跳出）时，Python 会自动调用 close()。

3. 上下文管理器协议#

with 之所以能这么"聪明"，是因为文件对象实现了上下文管理器协议，也就是两个特殊方法：

  • __enter__()：进入 with 块时调用，返回给 as 后面的变量；
  • __exit__()：离开 with 块时调用，负责清理资源。

凡是实现了这两个方法的对象，都可以用在 with 语句里。文件对象是内置支持的类型之一。

4. 自定义上下文管理器#

我们也可以给自己的类加上这两个方法，让它支持 with。这样一些"进入前要准备、离开后要收尾"的操作（比如连接数据库、锁定资源）就能写得非常干净。

5. 用 contextlib 快速构造#

对于简单的场景，标准库 contextlib 提供了 contextmanager 装饰器，让我们用一个生成器函数就能写一个上下文管理器，不用再定义完整的类。

二、可运行代码示例#

示例 1：用 with 读写文件#

# 写入
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
# 这里已经自动关闭，不需要手动 close()

# 读取
with open("note.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

示例 2：自定义上下文管理器#

class Timer:
    """一个用来测量代码块耗时的上下文管理器"""
    def __enter__(self):
        import time
        self.start = time.time()   # 记录开始时间
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        cost = time.time() - self.start
        print(f"这段代码用时 {cost:.3f} 秒")

with Timer():
    # 随便做一点耗时的计算
    total = 0
    for i in range(1000000):
        total += i
    print("求和结果：", total)

示例 3：用 contextlib 写一个简单管理器#

from contextlib import contextmanager

@contextmanager
def tag(name):
    # yield 之前的代码相当于 __enter__
    print(f"<{name}>")
    try:
        yield
    finally:
        # yield 之后的代码相当于 __exit__
        print(f"</{name}>")

with tag("h1"):
    print("这里是标题内容")

运行后输出：

<h1>
这里是标题内容
</h1>
