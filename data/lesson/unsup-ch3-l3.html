DBSCAN 与 K-means 对比#

一、概念讲解#

1.1 为什么要做对比#

学完 K-means、层次聚类和 DBSCAN 之后，摆在面前的现实问题是：拿到一份新数据，该用哪一个？ 没有一个算法在所有场景下都赢。把 DBSCAN 和 K-means 放在一起系统地对比，能帮我们在实践中做出更明智的选择。

1.2 逐维度对比#

① 簇的形状假设

  • K-means：隐式假设簇是球形、大小相近、密度均匀的。面对月牙形、环形、细长条或大小悬殊的簇，它的"均值中心 + 最近邻分配"机制会被扭曲，结果往往错误。
  • DBSCAN：不假设形状，靠密度连通识别任意形状的簇，月牙、环形都不在话下。

② 噪声 / 离群点的处理

  • K-means：每个点都必须归属某个簇，离群点会被硬拉进最近的簇，还可能把簇中心"带偏"。
  • DBSCAN：天然区分噪声，把孤立点标记为 -1，既识别了离群点，又不会污染正常簇。

③ 簇数是否需要预先指定

  • K-means：必须事先给定 K，选 K 本身是个额外难题。
  • DBSCAN：不需要指定簇数，由 eps 和 min_samples 自动决定簇的数量。

④ 参数敏感性与调参难度

  • K-means：主要调 K，且有肘部法则、轮廓系数等较成熟的辅助手段。
  • DBSCAN：对 eps 非常敏感，且当数据各簇密度差异大时，一个全局 eps 很难同时适配所有簇——这是它最大的短板之一。

⑤ 可扩展性与效率

  • K-means：计算高效，可轻松处理大规模、高维数据。
  • DBSCAN：依赖近邻搜索，虽然可用 KD-Tree / Ball-Tree 加速，但在高维数据上会遭遇"维度灾难"，距离变得没有区分度，效果下降明显；超大样本上通常也慢于 K-means。

⑥ 确定性与可解释性

  • K-means：结果依赖初始中心（可用 k-means++ 和 n_init 缓解）；簇有明确的中心，业务上较易解释"每个簇代表什么"。
  • DBSCAN：对同一参数结果基本确定；但没有"簇中心"概念，业务解释时需要换一种方式（如描述簇的分布范围或样本特征）。

1.3 选择的经验法则#

把上面的对比浓缩成几条可操作的准则：

  • 数据大致球形、大小相近、需要快速处理大规模数据 → 优先 K-means；
  • 数据形状复杂（月牙、环形）、有明显离群点、想自动发现簇数 → 优先 DBSCAN；
  • 需要分层结构、多尺度查看、且样本量适中 → 考虑层次聚类；
  • 高维数据 → 三者都需谨慎，通常要先降维（这也是下一章 PCA 的主题）。

记住：没有"最好"的算法，只有"在当前数据和目标下最合适"的算法。实际工作中，把三者都跑一遍、对比结果，往往比背结论更可靠。

二、可运行代码示例#

下面的代码在同一份"月牙 + 噪声"数据上同时运行 K-means 与 DBSCAN，直观对比两者的表现。

# -*- coding: utf-8 -*-
# 第 3 课：DBSCAN 与 K-means 的对比实验
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans, DBSCAN
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_moons

# 1. 生成月牙形数据，并掺入少量噪声
X, y_true = make_moons(n_samples=300, noise=0.08, random_state=42)
rng = np.random.RandomState(0)
noise = rng.uniform(low=-1.5, high=2.5, size=(15, 2))
X = np.vstack([X, noise])

# 2. 标准化（两者都要做）
X_scaled = StandardScaler().fit_transform(X)

# 3. K-means：固定 K=2（因为真实是两个月牙）
kmeans = KMeans(n_clusters=2, n_init=10, random_state=42)
kmeans_labels = kmeans.fit_predict(X_scaled)

# 4. DBSCAN：用上一课学过的方法选 eps（此处直接给出一个合适值）
dbscan = DBSCAN(eps=0.25, min_samples=5)
dbscan_labels = dbscan.fit_predict(X_scaled)

# 5. 可视化对比
fig, axes = plt.subplots(1, 2, figsize=(11, 5))
axes[0].scatter(X_scaled[:, 0], X_scaled[:, 1],
                c=kmeans_labels, s=20, cmap="viridis")
axes[0].set_title("K-means（K=2）")
axes[1].scatter(X_scaled[:, 0], X_scaled[:, 1],
                c=dbscan_labels, s=20, cmap="viridis")
# 把 DBSCAN 识别出的噪声点用黑色叉号标出
axes[1].scatter(X_scaled[dbscan_labels == -1, 0],
                X_scaled[dbscan_labels == -1, 1],
                c="black", s=40, marker="x", label="噪声")
axes[1].set_title("DBSCAN")
axes[1].legend()
plt.tight_layout()
plt.show()

# 6. 打印汇总
n_noise = int(np.sum(dbscan_labels == -1))
print("DBSCAN 簇数（不含噪声）：",
      len(set(dbscan_labels)) - (1 if -1 in dbscan_labels else 0))
print("DBSCAN 识别出的噪声点：", n_noise)
print("K-means 惯性：", round(kmeans.inertia_, 2))

输出解读：左图中，K-means 因为坚持"球形 + 中心最近"的假设，硬生生把两个月牙从中间"切"开，划分与真实结构明显不符；右图中，DBSCAN 顺着密度连通，完整识别出两个月牙，并把 15 个散落噪声点单独标出。这一对比正是"形状假设"差异的最直观注脚。
