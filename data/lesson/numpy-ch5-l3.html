聚合与归约#

上一课我们认识了均值、标准差这些统计量。你可能已经发现它们的共同点：都是把一堆数"压"成一个数。这种操作在 NumPy 里有个统一的名字——归约（reduction）。

归约是数据分析的"主循环"：把明细数据按维度压缩成汇总信息。这一课我们系统地掌握 sum、prod、cumsum 等归约与累加函数，理解 axis 和 keepdims 两个关键参数，最后看看"分组聚合"这个数据科学里最高频的操作思想。

一、概念讲解#

1. 什么是归约#

归约就是沿着某个轴反复应用一个二元运算，把数组的维度"消掉"，得到一个维度更低的数组。最典型的归约是求和 np.sum：

  • 对一维数组 sum 得到一个标量；
  • 对二维数组，指定 axis=0 会把行"压掉"，剩下列方向的汇总（每个特征的总和）。

除了求和，还有求积 np.prod、逻辑判断 np.all（全真）和 np.any（存在真）等，都是归约。

2. 累加 cumsum：不是归约，但同样重要#

np.cumsum（累加）和 np.cumprod（累乘）与归约不同，它们不降维，而是返回一个同样大小的数组，其中每个位置是"从开头累加到当前位置"的中间结果。累加在金融里用于计算"累计收益曲线"、在信号处理里用于积分，非常常用。

3. axis 与 keepdims#

  • axis：沿哪个轴归约。axis=None（默认）是对所有元素归约成一个标量；axis=0 沿行方向（逐列）；axis=1 沿列方向（逐行）。
  • keepdims=True：归约后保留被消掉的维度（用长度 1 占位）。这样做的好处是结果仍然能和原数组广播，写"每行减去该行均值"这类操作时特别方便。

4. 分组聚合：归约的现实应用#

现实数据分析最经典的模式是"按某列分组 → 对另一列做聚合"：按省份统计销售额、按月份统计订单量、按用户统计消费总额。虽然 NumPy 本身没有 Pandas 那样开箱即用的 groupby，但用花式索引 + 归约同样能实现，而且理解底层原理后，用 Pandas 会事半功倍。

二、可运行示例#

示例 1：各种归约

import numpy as np

a = np.array([[1, 2, 3],
              [4, 5, 6]])

print("全部求和 =", np.sum(a))            # 21
print("求积 =", np.prod(a))               # 1*2*...*6 = 720
print("是否存在大于 4 的元素 =", np.any(a > 4))   # True
print("是否全部大于 0 =", np.all(a > 0))          # True

# 沿轴归约
print("每列求和（axis=0）=", np.sum(a, axis=0))   # [5 7 9]
print("每行求和（axis=1）=", np.sum(a, axis=1))   # [6 15]

示例 2：累加 cumsum 与 keepdims

import numpy as np

# 某支股票 5 天的日收益率
daily_return = np.array([0.01, -0.02, 0.03, 0.01, 0.02])

# 累乘得到每天的累计净值（初始 1.0）
cumulative = np.cumprod(1 + daily_return)
print("累计净值（每天）=", np.round(cumulative, 4))

# keepdims 演示：每行减去该行均值（标准化）
data = np.array([[1.0, 2.0, 3.0],
                 [10.0, 20.0, 30.0]])
row_mean = np.mean(data, axis=1, keepdims=True)
print("每行均值（保持维度）=\n", row_mean)
print("去均值后 =\n", data - row_mean)

示例 3：分组聚合（按类别求均值）

import numpy as np

# 假设有 8 名用户，group 是他们的城市编号（0 或 1），amount 是消费金额
group = np.array([0, 1, 0, 0, 1, 1, 0, 1])
amount = np.array([50, 80, 30, 60, 120, 90, 40, 110])

# 城市 0 的消费均值
mean_0 = amount[group == 0].mean()
# 城市 1 的消费均值
mean_1 = amount[group == 1].mean()
print("城市 0 平均消费 =", mean_0)
print("城市 1 平均消费 =", mean_1)

# 两个城市各自的消费总额
print("城市 0 总消费 =", amount[group == 0].sum())
print("城市 1 总消费 =", amount[group == 1].sum())

示例 4：用归约做简单归一化

import numpy as np

# 三个学生的三门课成绩，每行一个学生
scores = np.array([[60, 80, 70],
                   [90, 85, 95],
                   [50, 55, 60]])

# 把每个学生（每行）的成绩归一化到 [0, 1]：减去最小值再除以极差
row_min = scores.min(axis=1, keepdims=True)
row_max = scores.max(axis=1, keepdims=True)
normalized = (scores - row_min) / (row_max - row_min)

print("归一化后的成绩（每行范围 0~1）=\n", normalized)
