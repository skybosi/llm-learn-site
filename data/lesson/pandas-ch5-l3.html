分组聚合 groupby#

"每个地区的平均订单金额是多少？""每个品类的总销量排名如何？"这类问题都有一个共同结构：先按某一列把数据分成若干组，再对每组做统计。这就是 Pandas 里最重要的分析利器之一——groupby 分组聚合。

一、概念讲解#

1. 核心思想：拆分—应用—合并#

groupby 的工作方式可以总结为三个英文单词，几乎是数据分析的通用范式：

  1. 拆分（split）：按某个键（一列或多列）把数据分成若干组；
  2. 应用（apply）：对每一组执行某个函数（求和、平均、计数……）；
  3. 合并（combine）：把每组的结果拼回一张表。

2. groupby 返回的是一个"待命"对象#

下面这行代码：

df.groupby("品类")

并不会立即得到结果。它返回一个 DataFrameGroupBy 对象，可以理解为"已经分好组、但还没开始算"的中间状态。只有当你对它调用聚合函数（如 sum()、mean()）时，真正的计算才发生。这种"先描述、后执行"的风格，让同一个分组可以被反复复用，做多种统计。

3. 常用聚合函数#

分好组后，直接调用聚合函数即可：

函数 含义
sum() 求和
mean() 平均值
count() 非空值的个数
max() / min() 最大值 / 最小值
median() 中位数
size() 每组行数（含空值） 
df.groupby("品类")["金额"].sum()      # 每个品类的金额总和
df.groupby("品类")["金额"].mean()     # 每个品类的平均金额

注意：聚合默认会把分组键变成结果的索引。

4. 用 agg() 一次做多种统计#

agg() 允许一次传入多个函数，或对不同的列分别指定：

df.groupby("品类")["金额"].agg(["sum", "mean", "count"])

也可以写成字典，给不同列配不同的统计：

df.groupby("品类").agg({"金额": "sum", "销量": "mean"})

agg() 是 groupby 里最灵活、最常用的方法，务必掌握。

5. 多列分组#

按两列分组，会得到更细的粒度，结果索引也变成两级：

df.groupby(["地区", "品类"])["金额"].sum()

6. 不改变形状的 transform()#

聚合（sum/mean）会把每组压成一行。有时我们想让结果保持和原表同样行数，比如给每一行都标上"它所在品类的平均金额"，这时用 transform()：

df["品类均值"] = df.groupby("品类")["金额"].transform("mean")

这行会新增一列，每行都是该行所属品类的平均值，常用来做"组内标准化"或计算占比。

二、可运行代码示例#

import pandas as pd

df = pd.DataFrame({
    "地区": ["华东", "华北", "华东", "华南", "华北", "华东", "华南", "华北"],
    "品类": ["数码", "数码", "家居", "数码", "家居", "服饰", "服饰", "家居"],
    "金额": [320, 150, 88, 450, 210, 199, 130, 96],
    "销量": [3, 2, 1, 4, 3, 2, 1, 2],
})
print(df)

示例 1：单列分组聚合#

# 每个品类的金额总和与平均金额
print(df.groupby("品类")["金额"].sum())
print(df.groupby("品类")["金额"].mean())

示例 2：agg 一次算多个指标#

# 每个品类：金额总和、金额平均值、记录条数
summary = df.groupby("品类")["金额"].agg(["sum", "mean", "count"])
print(summary)

# 对不同列用不同统计：金额求和，销量求平均
print(df.groupby("品类").agg({"金额": "sum", "销量": "mean"}))

示例 3：多列分组与 transform#

# 按地区 + 品类分组，求金额总和
print(df.groupby(["地区", "品类"])["金额"].sum())

# transform：给每行加上"所属品类的平均金额"这一列
df["品类均值"] = df.groupby("品类")["金额"].transform("mean")
print(df)

三、练习#

  1. 计算每个"地区"的订单总金额，并按总金额从高到低排序（提示：结果是一个 Series，可继续用 sort_values）。
  2. 用 agg() 一次性得到每个品类的金额"总和、最大值、最小值"三个指标。
  3. 用 transform() 给每行新增一列 金额占比，表示该行金额在其所属地区总金额中所占的比例（提示：先用 transform 算出地区总额，再相除）。
