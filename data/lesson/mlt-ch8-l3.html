用母原理重看 LLM#

这是《机器学习理论》的最后一课。我们把视野拉到最前沿：大语言模型（LLM）。Transformer、注意力、自回归、困惑度、缩放定律——这些词看起来离前面的凸优化、PAC、熵很远，但如果你已经掌握了五个母原理，你会发现 LLM 的每一个核心部件，都能被前面七章的知识一步步推出来。本课就是这场"豁然开朗"的收官。

一、母原理 2：自回归 = 链式法则#

LLM 要回答的问题是：给一段文本，预测下一个 token 的概率。用概率语言写，就是建模联合分布 p(x1​,…,xT​)。母原理 2 的核心工具——链式法则——直接给出分解：

p(x1​,…,xT​)=t=1∏T​p(xt​∣x1​,…,xt−1​).

"一次生成整句话"这个不可能完成的任务，被拆成了 T 个"给定上文预测下一个 token"的小任务。这就是自回归（autoregressive）：每个位置只依赖它前面的位置（因果性）。所以 LLM 的"生成"，本质是反复做条件概率的抽样——这条链式法则，和你在概率统计课里学到的 p(x,y)=p(x)p(y∣x) 是同一条。

二、母原理 5：注意力 = 在语义空间里的加权求和#

"给定上文，下一个 token 是什么"该怎么算？最朴素的想法是"加权平均"：把上下文的每个 token 表示成向量，按"和当前位置多相关"来加权，再求和得到当前 token 的新表示。这就是注意力的核心直觉（母原理 5：一切都在向量空间里做内积与线性组合）。

具体地，每个 token 有查询 q（"我在找什么"）、键 k（"我提供什么"）、值 v（"我的内容"）。token i 对 token j 的"注意力分数"由内积给出：

sij​=d​qiT​kj​​,

其中 q=WQ​x、k=WK​x、v=WV​x。除以 d​ 是缩放，防止内积随维度 d 变大而把 softmax 推进饱和区。再对分数做 softmax 得到权重，最后加权求和：

Attention(xi​)=j∑​softmax 权重∑j′​esij′​esij​​​​vj​=softmax(d​QKT​)V.

逐项拆解：

  • QKT（内积）＝ 用余弦相似度度量"相关程度"——母原理 5 的几何语言；
  • /d​ ＝ 控制方差、防饱和——保持梯度健康（呼应 chapter-8 的梯度消失）；
  • softmax ＝ 把分数变成概率权重（和为 1、非负）——母原理 2 的概率语言；
  • ×V ＝ 按权重做线性组合——"加权平均"的最终落地。

一句话：注意力 = 用内积度量相关性、用 softmax 归一成权重、再对值向量做加权平均。它不是新魔法，是母原理 5 与母原理 2 的一次标准会师。

三、母原理 1 + 2 + 4：训练 = 最小化交叉熵 = 最大似然#

LLM 的训练目标，和逻辑回归完全一样——最小化交叉熵。给定上文 x<t​，模型输出下一个 token 的分布 qθ​(⋅∣x<t​)，真实下一个 token 是 xt​（one-hot，即经验分布 p^​）。损失是：

L=−T1​t=1∑T​logqθ​(xt​∣x<t​).

这正是 chapter-6 的交叉熵，也是 chapter-2 的负对数似然。母原理 1 说"学习 = 优化目标函数"，母原理 2 说"目标函数 = 负对数似然"，母原理 4 说"负对数似然 = 交叉熵 = 最小化 KL 散度"。三条母原理在这里精确重合：训练 LLM，就是让模型的下一个 token 分布逼近真实数据的条件分布。

四、母原理 4：困惑度 = 2交叉熵#

评估 LLM 的困惑度（perplexity），定义是：

PPL=2H(p^​,qθ​)=exp(−T1​t∑​lnqθ​(xt​∣x<t​)).

它为什么是 2交叉熵？因为困惑度有个极其直观的含义：模型平均要把候选范围缩小到"约 PPL 个等可能选项"。若模型把 k 个 token 视为等可能（每个概率 1/k），交叉熵 = log2​k，于是 PPL = 2log2​k=k。所以：

  • PPL = 2：模型平均只需在 2 个 token 里猜（很有把握）；
  • PPL = 1000：模型平均要在 1000 个 token 里猜（几乎瞎蒙）。

困惑度把"交叉熵"这个抽象的比特数，翻译成了人可读的"等效猜测次数"——这是母原理 4（熵 = 平均编码/猜测代价）在 LLM 上的直接应用。

五、母原理 1 + 3：缩放定律 = "优化 + 表达力"的规模效应#

为什么"更大的模型 + 更多的数据 + 更多的算力"总能让损失下降？缩放定律给出了经验规律：损失 L 随参数量 N、数据量 D、算力 C 以幂律下降，即 L≈aN−α（α>0 是常数）。

用母原理解释它：

  • 母原理 3（可微函数逼近）：参数量 N 越大，可逼近的函数族越大，最优可达损失越低（表达力随规模上升）；
  • 母原理 1（优化）：更大的模型往往有更好的优化景观（回想 chapter-5 的过参数化），且更多算力 = 更充分地逼近经验风险最小；
  • 母原理 2（概率）：更多数据 = 经验分布更逼近真实分布，泛化更好（chapter-7 的 复杂度/m​）。

三条母原理叠加，就解释了"规模为什么有效"：规模同时提升表达力、优化质量与数据覆盖。缩放定律不是魔法，是三个母原理在"规模轴"上的联合作用。

六、验证性代码示例#

下面代码验证三件事：① 自回归的链式法则分解成立（逐 token 概率之积 = 整句概率）；② 注意力输出等价于"softmax 权重 × V 的加权和"；③ 困惑度确实等于 2交叉熵。代码只验证推导，不教 API。

import numpy as np

rng = np.random.default_rng(0)

# ---------- 1) 自回归 = 链式法则 ----------
# 用一个极小的 2-gram 计数模型估计 p(x_t | x_{t-1})
seq = [0, 1, 0, 2, 1, 0, 1, 2]          # 3 类 token 的短序列
p_joint = 1.0
for t in range(1, len(seq)):
    prev = seq[t-1]
    # 简单计数：P(x_t | x_{t-1}) 用整段里的转移频率近似
    pairs = list(zip(seq[:-1], seq[1:]))
    p = pairs.count((prev, seq[t])) / seq[:-1].count(prev)
    p_joint *= p
print("链式法则逐项相乘得到整句概率:", p_joint, "（>0 且逐项依赖上文）")

# ---------- 2) 注意力 = softmax(QK^T/√d) V ----------
d = 4
Q = rng.standard_normal((2, d)); K = rng.standard_normal((3, d)); V = rng.standard_normal((3, d))
scores = Q @ K.T / np.sqrt(d)            # (2,3) 内积 + 缩放
weights = np.exp(scores) / np.exp(scores).sum(axis=1, keepdims=True)  # softmax
attn = weights @ V                        # (2,d) 加权和
attn_direct = (np.exp(Q @ K.T / np.sqrt(d)) /
               np.exp(Q @ K.T / np.sqrt(d)).sum(axis=1, keepdims=True)) @ V
print("\n注意力 == softmax(QK^T/√d)V:", np.allclose(attn, attn_direct))

# ---------- 3) 困惑度 = 2^交叉熵 ----------
# 模型把 8 个 token 视为等可能 -> 交叉熵 = log2(8) = 3 bit -> PPL = 8
k = 8
ce = np.log2(k)
ppl = 2 ** ce
print(f"\n8 个等可能 token：交叉熵 = {ce} bit, 困惑度 PPL = {ppl}（=2^交叉熵）")

运行结果大致为：

链式法则逐项相乘得到整句概率: 0.021947873799725647 （>0 且逐项依赖上文）

注意力 == softmax(QK^T/√d)V: True

8 个等可能 token：交叉熵 = 3.0 bit, 困惑度 PPL = 8.0（=2^交叉熵）

三个结果分别坐实：① 自回归把整句概率拆成条件概率之积（母原理 2 的链式法则）；② 注意力公式是"内积 → softmax → 加权和"的精确实现（母原理 5+2）；③ 困惑度与交叉熵的换算 2H 严格成立（母原理 4）。

七、练习#

  1. 从链式法则写出 p(x1​,x2​,x3​)=p(x1​)p(x2​∣x1​)p(x3​∣x1​,x2​)，并说明"自回归模型"为什么必须逐 token 生成、而不能一步生成整句。
  2. 逐项解释 QKT/d​ 中每一项的作用：QKT 为什么度量相关性？d​ 为什么要除？softmax 把分数变成了什么？×V 在做什么？
  3. 证明：当模型对 k 个 token 等可能时，困惑度恰好等于 k。并说明困惑度 2 与 1000 分别意味着模型"平均要在几个候选里猜"。
  4. 用代码：给一个真实的 tiny 字符模型（如对 "abab" 计数），计算每个位置的交叉熵，再算整句的困惑度，验证 PPL 与"平均候选数"的对应关系。
  5. 思考：缩放定律 L≈aN−α 为什么是"幂律"而非"指数"？结合母原理 3（表达力随规模增长）、母原理 1（优化质量）、母原理 2（数据覆盖）各贡献了什么。
