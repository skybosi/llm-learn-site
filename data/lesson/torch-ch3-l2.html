网络层#

有了 nn.Module 这个"骨架"，还需要具体的"器官"——网络层。torch.nn 提供了一整套即拿即用的层：线性层、卷积层、归一化层、激活函数、正则化层等。本课不是罗列 API，而是讲清层是什么、怎么选、怎么拼：每一层本质都是"持有参数的 Module + 一个可导的前向函数"，你要做的是理解每层的输入输出形状约定，并把它们像积木一样接起来。

一、概念讲解#

1. 层的本质：参数 + 前向函数#

一个层（如 nn.Linear）内部就干两件事：

  • 持有参数：例如 Linear 有 weight（形状 [out_features, in_features]）和 bias（形状 [out_features]）；
  • 定义前向：y = x @ weight.T + bias。

因为它继承 nn.Module，所以参数会被自动收集、自动求梯度，你只需要在 forward 里调用它。图 3-2 画出几类常用层各自的输入输出形状约定。

2. 常用层速览#

层 作用 关键参数 输入形状约定
nn.Linear 全连接/仿射变换 in_features, out_features (..., in) → (..., out)
nn.Conv2d 二维卷积，提取局部特征 in_channels, out_channels, kernel_size (N, C, H, W)
nn.BatchNorm2d 批归一化，稳定训练 num_features (N, C, H, W)
nn.ReLU / nn.GELU 非线性激活（无参数） 无 任意形状，逐元素
nn.Dropout 正则化，随机置零 p（丢弃概率） 任意形状
nn.MaxPool2d 下采样 kernel_size, stride (N, C, H, W)

3. 输入输出形状是"契约"#

每一层都对输入形状有明确约定，接错就会报错。两条实用经验：

  • 看 in_features / in_channels：上一层的输出维度必须等于下一层的输入维度。
  • 匹配前后形状：卷积、池化会改变 H, W，全连接层要求输入是一维特征。把卷积输出喂给 Linear 之前，常用 x.view(x.size(0), -1)（或 torch.flatten(x, 1)）摊平。

4. 有参数层 vs 无参数层#

  • 有参数层（Linear、Conv2d、BatchNorm2d）：parameters() 里能看到它们，参与梯度更新。
  • 无参数层（ReLU、MaxPool2d、Dropout）：只是纯函数，没有可学习参数，但仍有 train/eval 行为差异（如 Dropout 在 eval 下关闭）。

5. 训练/评估模式对层的影响#

Dropout 和 BatchNorm 在 train() 与 eval() 下行为不同：训练时 Dropout 随机丢弃、BN 用当前 batch 的统计量；评估时 Dropout 关闭、BN 用训练期累计的滑动统计量。因此推理前必须调用 model.eval()，否则结果会有偏差。

二、可运行代码示例#

import torch
import torch.nn as nn

# ---- 1. Linear：全连接 ----
lin = nn.Linear(in_features=10, out_features=5)
x = torch.randn(3, 10)                       # 3 个样本，10 维
print("Linear 输出形状:", lin(x).shape)      # torch.Size([3, 5])
print("Linear 权重形状:", lin.weight.shape)  # torch.Size([5, 10])

# ---- 2. Conv2d：二维卷积 ----
conv = nn.Conv2d(in_channels=3, out_channels=16,
                 kernel_size=3, padding=1)   # padding=1 保持 H、W 不变
img = torch.randn(1, 3, 32, 32)              # (N, C, H, W)
print("\nConv2d 输出形状:", conv(img).shape) # torch.Size([1, 16, 32, 32])

# ---- 3. 卷积 -> 摊平 -> 全连接 ----
pool = nn.MaxPool2d(kernel_size=2)           # H、W 减半
conv_out = conv(img)                         # (1, 16, 32, 32)
pooled = pool(conv_out)                      # (1, 16, 16, 16)
flat = torch.flatten(pooled, 1)              # 摊平成 (1, 16*16*16)
fc = nn.Linear(16 * 16 * 16, 10)
print("\n摊平后形状:", flat.shape)           # torch.Size([1, 4096])
print("全连接输出形状:", fc(flat).shape)     # torch.Size([1, 10])

# ---- 4. 无参数层与 train/eval ----
drop = nn.Dropout(p=0.5)
data = torch.ones(1, 8)
drop.train()
print("\ntrain 下 Dropout:", drop(data))      # 大约一半元素变 0
drop.eval()
print("eval  下 Dropout:", drop(data))        # 原样输出

# ---- 5. 把层拼成一个模块 ----
class TinyCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 8, 3, padding=1),    # (N,1,28,28) -> (N,8,28,28)
            nn.ReLU(),
            nn.MaxPool2d(2),                  # -> (N,8,14,14)
        )
        self.head = nn.Linear(8 * 14 * 14, 10)

    def forward(self, x):
        x = self.features(x)
        x = torch.flatten(x, 1)
        return self.head(x)

model = TinyCNN()
sample = torch.randn(2, 1, 28, 28)            # 2 张 28x28 灰度图
print("\nTinyCNN 输出形状:", model(sample).shape)   # torch.Size([2, 10])

运行要点：padding=1 的 3×3 卷积保持空间尺寸；MaxPool2d(2) 让 H、W 各减半；flatten(x, 1) 只摊平除 batch 外的维度。

三、练习#

  1. 建一个 nn.Conv2d(3, 32, kernel_size=3, stride=2, padding=1)，输入形状 (4, 3, 64, 64)，手工按公式算出输出 H、W，再运行验证。
  2. 用 nn.Sequential 搭一个 MLP：784 → 256 → ReLU → 128 → ReLU → 10，打印每一层参数数量并求和。
  3. 给一个 nn.Dropout(p=0.3)，分别打印 train() 与 eval() 下对同一输入 torch.ones(1, 100) 的输出，解释差异。
  4. 思考：为什么把 Conv2d 的输出接 Linear 前必须先摊平？如果漏掉摊平直接喂给 Linear 会发生什么？写出正确的摊平写法。
