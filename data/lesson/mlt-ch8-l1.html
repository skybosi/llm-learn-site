用母原理重看监督学习#

前七章，我们从经验风险、最大似然、贝叶斯、偏差-方差、凸优化、信息论、泛化理论七个角度各走了一遍。现在到了画龙点睛的时刻：把它们全部收敛到五个母原理之下。本课先立起这五个母原理，然后用它们把四个经典监督学习算法——线性回归、逻辑回归、SVM、决策树——重新推导一遍，让你看到：你以为的四个不同算法，其实是同一套数学换了几件衣服。

一、五个母原理：全课程的"公理"#

在动笔之前，先把骨架立起来。整门课（乃至整个机器学习）的所有结论，都能挂到这五句话下：

  1. 母原理 1：一切学习 = 优化一个目标函数。 任何算法，先问"它最小化什么"。
  2. 母原理 2：概率视角统一一切。 损失函数从最大似然来，正则化从先验来。
  3. 母原理 3：神经网络 = 可微的函数逼近。 深度网络只是"用可微函数逼近数据"的存在性定理的工程实现。
  4. 母原理 4：信息论视角。 熵、交叉熵、KL、信息增益是同一套度量。
  5. 母原理 5：几何与线性代数视角。 空间变换、内积、谱分解提供"图像"。

本章的目标，就是证明一件事：抓住这五条，任何监督学习算法都能从第一性原理"推出来"，而不是"背下来"。

二、母原理 1 + 2：所有损失函数都从"最大似然"来#

监督学习的统一起点是：我们观察到的标签 y 是对某个条件分布 p(y∣x) 的抽样，模型要做的，是找到使这组样本最"可能出现"的参数。这就是最大似然。取负对数，我们得到统一的训练目标：

θ^=argθmin​−i∑​lnpθ​(yi​∣xi​).

母原理 1 说：这就是一个优化问题。母原理 2 说：目标函数的具体形状，完全由你对噪声/输出分布的假设决定。下面看它如何"长"出三个耳熟能详的损失：

（1）线性回归 → MSE。假设 y=wTx+ϵ，ϵ∼N(0,σ2)，即 p(y∣x)=N(y;wTx,σ2)。负对数似然：

−i∑​lnp(yi​∣xi​)=i∑​2σ2(yi​−wTxi​)2​+常数∝∥Xw−y∥2.

所以 MSE 不是"选的"，是"高斯噪声假设逼出来的"。

（2）逻辑回归 → 交叉熵。假设标签是伯努利：p(y∣x)=qy(1−q)1−y，其中 q=σ(wTx)（σ 是 sigmoid）。负对数似然：

−i∑​[yi​lnqi​+(1−yi​)ln(1−qi​)]=i∑​H(yi​,qi​).

每一项正是交叉熵（chapter-6 的定义）——所以交叉熵损失 = 伯努利最大似然。

（3）多分类 → softmax + 交叉熵。把伯努利换成分类分布 p(y∣x)=∏c​qcyc​​，q=softmax(z)，负对数似然同样是交叉熵。三种损失的"母体"都是同一个：负对数似然。

三、母原理 2 + 5：正则化从"先验"来#

最大似然只关心"拟合"，会过拟合（chapter-7）。修正是引入先验 p(w)，最大化后验（MAP）：

w^=argwmax​p(w)i∏​p(yi​∣xi​;w)=argwmin​似然项−i∑​lnp(yi​∣xi​;w)​​−先验项lnp(w)​​.

  • 高斯先验 p(w)∝e−∥w∥2/2τ2 给出 −lnp(w)=2τ2∥w∥2​ → L2 正则（岭回归）。
  • 拉普拉斯先验 p(w)∝e−∥w∥1​/b 给出 −lnp(w)=b∥w∥1​​ → L1 正则（Lasso），且 L1 的尖峰诱导稀疏解——这又是母原理 5（几何）：L1 球有尖角，最优解更容易"撞"在坐标轴上。

于是，"经验风险 + 正则化"不再是经验配方，而是 "似然 + 先验"的后验视角。母原理 1 的统一公式就此完整：

学习=argwmin​(数据拟合项+λ⋅复杂度惩罚项)​

四、母原理 1 + 5：SVM 是同一个框架的几何特例#

SVM 表面上最不像"损失函数"，其实完全能套进同一公式。它对每个样本要求 yi​(wTxi​+b)≥1（间隔约束），并最大化几何间隔。几何间隔是"分类超平面到最近点的距离"，由母原理 5 的解析几何给出：

间隔=∥w∥1​,

最大化间隔 = 最小化 21​∥w∥2。于是 SVM 的原始问题就是：

wmin​21​∥w∥2s.t.yi​(wTxi​+b)≥1.

它正是"目标函数（21​∥w∥2，一个复杂度惩罚）+ 约束（数据拟合）"的结构——和岭回归"∥Xw−y∥2+λ∥w∥2"惊人地同构，只是把"惩罚"与"拟合"换了个位置。支持向量就是那些"撑起间隔"的样本，是母原理 5 几何图像的直接产物。

五、母原理 4：决策树是"信息增益"的贪心优化#

决策树（chapter-6）同样逃不出母原理 1：它在每个节点解一个子优化问题——选特征 X 最大化信息增益

IG(Y;X)=H(Y)−H(Y∣X),

等价于最小化分裂后的加权条件熵。这是母原理 4 的直接应用：选"最能消除不确定性"的特征。而 C4.5 的增益率 IG/H(X) 又给这个目标加了一个"惩罚特征取值过多"的正则项——依然是"目标 + 正则"的统一结构。

六、统一收束：一张表看穿四个算法#

算法 目标函数（母原理 1） 从哪条母原理推出 正则化
线性回归 ∥Xw−y∥2 母原理 2（高斯 MLE） 岭回归（L2）/ Lasso（L1）
逻辑回归 交叉熵 H(y,σ(wTx)) 母原理 2（伯努利 MLE）+ 母原理 4 L1/L2 先验
SVM 21​∥w∥2 + 间隔约束 母原理 5（几何间隔） ∥w∥2 即正则
决策树 最小化加权条件熵 母原理 4（信息增益） 增益率 / 剪枝

结论：监督学习的所有算法，都是"在某个概率假设或几何解释下，最小化一个'拟合项 + 正则项'的目标函数"。掌握这一句，你就掌握了整个监督学习。

七、验证性代码示例#

下面代码做一件"统一"的事：用同一个梯度下降求解器，分别最小化 MSE、交叉熵、带 L2 的岭回归三个目标函数，证明"不同算法只是不同目标函数"。代码验证推导，不教 API。

import numpy as np

rng = np.random.default_rng(0)
n = 200
X = rng.standard_normal((n, 2))
w_true = np.array([2.0, -1.0])

# 三个目标函数 + 梯度（都关于 w）
def mse(w, y):        r = X @ w - y; return 0.5 * np.mean(r**2)
def mse_grad(w, y):   return X.T @ (X @ w - y) / n

def ce(w, y):         # 逻辑回归交叉熵，y ∈ {0,1}
    q = 1 / (1 + np.exp(-X @ w))
    q = np.clip(q, 1e-9, 1 - 1e-9)
    return -np.mean(y * np.log(q) + (1 - y) * np.log(1 - q))
def ce_grad(w, y):
    q = 1 / (1 + np.exp(-X @ w))
    return X.T @ (q - y) / n

def ridge(w, y, lam=0.5):
    r = X @ w - y; return 0.5 * np.mean(r**2) + 0.5 * lam * np.sum(w**2)
def ridge_grad(w, y, lam=0.5):
    return X.T @ (X @ w - y) / n + lam * w

def solve(grad, y, lr=0.1, steps=2000):
    w = np.zeros(2)
    for _ in range(steps):
        w = w - lr * grad(w, y)
    return w

y_reg = X @ w_true + 0.3 * rng.standard_normal(n)          # 回归标签
y_cls = (1 / (1 + np.exp(-X @ w_true)) > 0.5).astype(float)  # 分类标签

print("线性回归 MSE 最优 w      :", np.round(solve(mse_grad, y_reg), 4))
print("逻辑回归 CE 最优 w       :", np.round(solve(ce_grad, y_cls), 4))
print("岭回归(L2)最优 w         :", np.round(solve(ridge_grad, y_reg), 4))
print("真实 w_true              :", w_true)

运行结果大致为：

线性回归 MSE 最优 w      : [ 1.985  -0.9642]
逻辑回归 CE 最优 w       : [ 6.2138 -3.0893]
岭回归(L2)最优 w         : [ 1.2975 -0.623 ]
真实 w_true              : [ 2. -1.]

三组结果用同一个求解器分别逼近了真实方向，印证了母原理 1 的论断：算法的差异不在"怎么优化"，而在"优化什么目标"。注意岭回归的 w 被 L2 惩罚"往 0 拉"（1.2975<1.985），这是先验（母原理 2）在起作用。

八、练习#

  1. 从高斯噪声假设出发，完整写出线性回归负对数似然 = MSE 的推导（含常数项，说明它为何可忽略）。
  2. 从伯努利假设出发，写出逻辑回归负对数似然 = 交叉熵的推导，并说明 sigmoid 为什么出现在这个推导里（q=σ(wTx) 是概率参数化）。
  3. 证明高斯先验 → L2、拉普拉斯先验 → L1，并解释"拉普拉斯先验的尖峰诱导稀疏"与 L1 球"尖角"的几何对应（母原理 5）。
  4. 用代码：固定 X，分别求 MSE、CE、带 L1 正则的目标函数的解，观察 L1 解是否有坐标恰好为 0（稀疏性）。
  5. 把 SVM 的 21​∥w∥2+C∑i​max(0,1−yi​(wTxi​+b))（hinge 损失的软间隔形式）与"目标 + 正则"框架对照：哪一项是"数据拟合"、哪一项是"复杂度惩罚"？

母原理连接#

本课就是母原理的总纲落地。母原理 1 提供了统一的"优化"外壳，母原理 2 决定目标函数的形状（似然 + 先验），母原理 4 给出交叉熵/信息增益这类具体度量，母原理 5 给出 SVM 的几何间隔与正则化的几何直觉。四条线拧成一句话：监督学习 = 在概率假设下，最小化"拟合 + 正则"的目标函数。 下一课，我们把这个框架搬进深度学习的非凸世界，看它如何继续成立。
