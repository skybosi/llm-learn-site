数据集准备#

模型再强，喂给它的数据不对也白搭。这一课解决训练前的"备料"环节：数据该怎么组织、怎么读进内存、怎么做数据增强。torchvision 的 datasets 与 DataLoader 是这一环的主角，掌握它们，你就能把任意图片文件夹快速变成可训练的批次流。

一、概念讲解#

1. 数据的组织方式#

最通用的组织方式是按类别分文件夹，torchvision.datasets.ImageFolder 会自动把每个子文件夹当成一个类别：

data/
├── train/
│   ├── cat/     -> 标签 0
│   ├── dog/     -> 标签 1
│   └── bird/    -> 标签 2
└── val/
    ├── cat/
    ├── dog/
    └── bird/

这是约定俗成的"文件夹即标签"结构。对于 CIFAR、MNIST 这类标准数据集，torchvision.datasets 还提供了封装好的下载类（如 datasets.CIFAR10），一行代码就能拉下来。

2. transforms：读图与预处理#

transforms.Compose 把多个变换按顺序串起来，构成一条流水线。训练和验证通常用不同的变换：

  • 训练：随机裁剪、随机翻转（数据增强）+ 归一化；
  • 验证：中心裁剪、归一化（不做随机增强，保证评估稳定）。

最常见的变换有：

  • transforms.Resize / RandomResizedCrop：调整尺寸；
  • transforms.RandomHorizontalFlip：随机水平翻转；
  • transforms.ToTensor：把 PIL 图片转成 [0,1] 的张量，并交换成 (C,H,W) 布局；
  • transforms.Normalize：按 (mean, std) 做标准化。

3. 数据增强：给数据"变出"更多样本#

数据增强（augmentation）在训练时对每张图随机施加几何或色彩变换——翻转、裁剪、旋转、颜色抖动等。它的作用是在不增加标注成本的前提下扩充数据多样性，抑制过拟合。AlexNet 当年用随机裁剪和翻转就显著提升了精度。增强只在训练时开、验证时关，是必须牢记的细节。

4. DataLoader：把数据集变成批次流#

Dataset 负责"取一个样本"，DataLoader 负责"把样本打包成批、打乱顺序、多进程并行读取"：

loader = DataLoader(dataset, batch_size=64, shuffle=True, num_workers=2)
  • batch_size：每批多少张图；
  • shuffle：训练集打乱、验证集不打乱；
  • num_workers：并行加载的进程数，可加快读图，但过高会占用内存。

训练循环里 for x, y in loader: 每次迭代得到一批 (图片, 标签)，图片形状为 [batch, C, H, W]。

二、可运行代码示例#

下面加载 CIFAR-10，分别构造训练/验证两条变换流水线，并用 DataLoader 迭代一批数据查看形状。

import torch
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# 训练变换：随机裁剪 + 水平翻转（数据增强）+ 归一化
train_transform = transforms.Compose([
    transforms.RandomCrop(32, padding=4),        # 先四周补 4 再裁回 32，模拟平移
    transforms.RandomHorizontalFlip(),           # 随机水平翻转
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465),  # CIFAR-10 的统计值
                         (0.2470, 0.2435, 0.2616)),
])

# 验证变换：只做归一化，不随机增强
val_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465),
                         (0.2470, 0.2435, 0.2616)),
])

# 下载并加载 CIFAR-10（首次运行需联网下载）
train_set = datasets.CIFAR10(root="./data", train=True,
                             download=True, transform=train_transform)
val_set = datasets.CIFAR10(root="./data", train=False,
                           download=True, transform=val_transform)

print("训练样本数:", len(train_set))
print("验证样本数:", len(val_set))
print("类别:", train_set.classes)   # ['airplane', 'automobile', ...]

# 构造 DataLoader
train_loader = DataLoader(train_set, batch_size=64, shuffle=True, num_workers=2)
val_loader = DataLoader(val_set, batch_size=64, shuffle=False, num_workers=2)

# 取一批看看
images, labels = next(iter(train_loader))
print("一批图片形状:", tuple(images.shape))   # [64, 3, 32, 32]
print("一批标签形状:", tuple(labels.shape))   # [64]
print("标签数值范围:", labels.min().item(), "~", labels.max().item())

运行后你会看到训练集 5 万张、验证集 1 万张，每批图片形状为 [64, 3, 32, 32]。有了这条流水线，训练循环里只要 for images, labels in train_loader: 就能源源不断地拿数据。

下面再用 ImageFolder 读取一个按类别分文件夹的自定义数据集：

from torchvision import datasets, transforms

# 假设 ./data/train 下每个子文件夹是一个类别
transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
])
dataset = datasets.ImageFolder(root="./data/train", transform=transform)
print("类别 -> 编号:", dataset.class_to_idx)
print("样本数:", len(dataset))

ImageFolder 会自动把文件夹名映射成数字标签，并存入 class_to_idx，是处理自采数据集最省事的方式。

三、练习#

  1. 把 RandomCrop(32, padding=4) 去掉再运行，说明这种"先补边再裁剪"的增强模拟了什么真实场景。
  2. 打印 train_set[0] 返回的 (张量, 标签)，确认张量形状是 [3, 32, 32] 且数值已被归一化。
  3. 写一个 transforms.Compose，加入 transforms.ColorJitter(brightness=0.2, contrast=0.2) 和 transforms.RandomRotation(15)，观察它们对图像的影响。
  4. 思考：为什么验证集不能开 shuffle，也不能加随机增强？如果开了会怎样？
