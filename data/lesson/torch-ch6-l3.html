迁移学习#

从头训练一个能识别猫狗的 CNN，需要上百万张标注图片和几天的 GPU 时间——这对个人开发者几乎不可能。迁移学习（Transfer Learning）改变了这个局面：把别人在超大数据集上训练好的模型"借"过来，让它的通用特征能力为我所用，只花很小的代价就能解决你自己的小数据集任务。这是实战中最常用、性价比最高的一招。

一、概念讲解#

1. 核心思想：站在巨人的肩膀上#

深度网络是分层的：浅层学到的是边、角、纹理这类通用特征（换什么任务都差不多），深层学到的是更具体、更"任务专属"的特征（比如"这是猫还是狗"）。

迁移学习的思路因此非常自然：

拿一个在 ImageNet 上训练好的模型，冻结它的特征提取部分（不更新参数），只重新训练最后的分类型层，让通用特征直接复用到你的任务上。

2. 两种常见策略#

（1）特征提取（冻结 + 换头）——数据少时的首选：

  • 加载预训练模型，把最后几层分类器换掉（改成你的类别数）；
  • 冻结 backbone（特征提取部分）的参数，不让它们更新；
  • 只训练新换上的分类头。

（2）微调（fine-tune）——数据较多、想进一步提分：

  • 同样换掉分类头，但不冻结（或只冻结最浅层），用很小的学习率继续训练整个模型；
  • 让预训练权重在你的数据上"微调"得更贴合。

3. 怎么"冻结"参数#

把某个参数的 requires_grad 设为 False，反向传播就不会更新它：

for param in model.features.parameters():
    param.requires_grad = False   # 冻结特征提取层

同时，优化器只传入"需要更新"的参数，避免白算：

optimizer = torch.optim.Adam(model.classifier.parameters(), lr=1e-3)

4. 预训练模型从哪来#

torchvision.models 内置了 ResNet、VGG 等经典模型，并支持 weights= 参数一键加载 ImageNet 预训练权重：

from torchvision import models
model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)

二、可运行代码示例#

下面用一个内置的 ResNet18 演示"特征提取"策略：加载 ImageNet 预训练权重、冻结 backbone、把最后的全连接层换成 2 分类，然后跑几步训练。代码会自动下载权重，首次运行需要联网。

import torch
import torch.nn as nn
from torchvision import models


# 1) 加载 ImageNet 预训练的 ResNet18
model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)

# 2) 冻结 backbone：所有参数不参与梯度更新
for param in model.parameters():
    param.requires_grad = False

# 3) 换掉最后的全连接层：ImageNet 是 1000 类，我们改成 2 类（猫/狗）
num_features = model.fc.in_features          # ResNet18 输出 512 维特征
model.fc = nn.Linear(num_features, 2)        # 新分类头（默认 requires_grad=True）

# 4) 优化器只优化"需要更新"的参数（即新换的分类头）
optimizer = torch.optim.Adam(
    filter(lambda p: p.requires_grad, model.parameters()), lr=1e-3
)

# 统计可训练参数占比，体会迁移学习"只训练一小部分"的优势
total_params = sum(p.numel() for p in model.parameters())
trainable_params = sum(p.numel() for p in model.parameters() if p.requires_grad)
print(f"总参数量：{total_params / 1e6:.2f}M")
print(f"可训练参数量：{trainable_params / 1e6:.3f}M（仅分类头）")

# 5) 造一批假图像数据（3 通道 224x224），跑两步训练
x = torch.randn(8, 3, 224, 224)
y = torch.randint(0, 2, (8,))

criterion = nn.CrossEntropyLoss()
model.train()
for step in range(2):
    optimizer.zero_grad()
    loss = criterion(model(x), y)
    loss.backward()
    optimizer.step()
    print(f"step {step + 1}  损失 = {loss.item():.4f}")

运行后你会看到类似：

总参数量：11.18M
可训练参数量：0.002M（仅分类头）
step 1  损失 = 0.6931
step 2  损失 = 0.6863

最震撼的是那行参数统计：整个 ResNet18 有 1100 多万参数，但我们只训练了分类头的 2000 多个参数，占比不到万分之一。却已经能借助 ImageNet 学到的通用特征，在你的二分类任务上快速起步。这就是迁移学习"四两拨千斤"的威力。

三、练习#

  1. 把冻结范围收窄：先解冻全部参数，再只冻结 model.layer1 和 model.layer2，统计可训练参数数量，对比和"全冻结"的差异。
  2. 用 models.resnet50(weights=models.ResNet50_Weights.DEFAULT) 替换 ResNet18，观察 model.fc.in_features 变成多少，体会不同骨架换头时的写法。
  3. 试着加载 models.vgg16(weights=...)，找到它的分类器层（model.classifier），把它换成一个适用于 10 分类的新分类器。
  4. 想一想：为什么微调（fine-tune）时学习率通常要比从头训练小得多？学习率太大会对预训练权重造成什么影响？
