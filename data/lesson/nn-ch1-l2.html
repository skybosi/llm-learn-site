神经网络与深度学习#

上一课我们看到，单层感知机的死穴是"线性不可分"——连 XOR 都学不会。走出死胡同的关键一步，是在输入和输出之间再插一层，让多个神经元堆叠起来：这就是神经网络（Neural Network）。而"深度学习"，说穿了就是层数很多的神经网络，再配上大数据、大算力和更好的训练技巧。这一课我们把"感知机 → 神经网络 → 深度学习"这条演化线讲清楚，并首次接触 PyTorch 这个深度学习框架。

一、概念讲解#

1. 从一层到多层：加一个"隐藏层"#

感知机只有一层：输入直接连到输出，中间没有任何"加工"。要解决 XOR，思路是让模型先对输入做若干次"感知机式"的变换，再把这些变换结果组合起来做最终判断。这些中间变换就构成了隐藏层（hidden layer）：

输入层 ──▶ 隐藏层（若干神经元，各自做加权求和 + 非线性）──▶ 输出层（做最终判断）

直观地看，XOR 可以拆成"与、或、非"的组合：x1 XOR x2 = (x1 OR x2) AND NOT(x1 AND x2)。隐藏层的每个神经元可以去学"x1 与 x2 是否至少一个为 1""x1 与 x2 是否同时为 1"这样的中间特征，输出层再把这些中间结果组合起来——于是两个"线性"判断叠在一起，就能表达"非线性"的决策边界。叠层的本质，是用简单的线性变换 + 非线性激活，去逼近任意复杂的函数。

2. 让多层网络可训练：反向传播#

多加一层带来一个新难题：感知机的"犯错就改"规则只适用于单层，因为中间层的神经元没有"正确答案"可以直接对照——我们不知道隐藏层每个神经元"应该"输出什么。这个难题在 1986 年由 Rumelhart、Hinton 等人用反向传播（Backpropagation） 解决：

  • 用可导的激活函数（如 Sigmoid）替代不可导的阶跃函数；
  • 定义一个光滑的损失函数，衡量网络输出与真实标签的差距；
  • 用微积分链式法则，把误差从输出层逐层反传回去，算出每个权重该往哪个方向、改多大。

反向传播让"任意层数"的网络都能用梯度下降训练。它是深度学习的地基，我们会在后续章节专门用一课回顾链式法则、手推一遍梯度。这里只需记住一句话：有了反向传播，堆多少层都能训。

3. "深度学习"这个词：2012 年的分水岭#

多层神经网络其实早在上世纪 80–90 年代就已存在，但一直不温不火，原因是三个瓶颈：数据不够、算力不足、深网络难训练。真正的转折发生在 2012 年：Alex Krizhevsky 等人在 ImageNet 大规模图像识别竞赛中用 8 层的深度卷积网络 AlexNet，把 top-5 错误率从上一年冠军的约 26% 猛降到约 15%，甩开第二名一大截。

这个结果让整个学界意识到：只要数据够大、算力够强、网络够深，"深度学习"就能大幅超越手工特征 + 传统机器学习的方法。 从此，"深度学习"作为独立名词火遍全球，语音识别、机器翻译、推荐系统、围棋（AlphaGo）等领域相继被深度网络改写。我们今天说"深度学习"，通常指用多层神经网络自动从数据中学习特征表示的这一类方法。

4. 神经网络、深度学习、机器学习的关系#

三者是层层包含的关系，别把它们当并列概念：

  • 机器学习：一切"从数据中学规律"的方法，包括决策树、SVM、随机森林等；
  • 神经网络：机器学习中的一类模型，用"层 + 神经元 + 非线性激活"组织；
  • 深度学习：神经网络中"层数很深"的那一部分（严格说，指表征学习——自动学到多层特征）。

简单说：深度学习 ⊂ 神经网络 ⊂ 机器学习。很多人用"深度学习"泛指现代神经网络方法，但心里要清楚这层包含关系。

5. 真实场景：深度网络在哪里工作#

  • 图像识别：手机相册的人脸、物体分类；医疗影像里识别病灶；
  • 语音：语音助手的"语音 → 文字"（自动语音识别）与合成；
  • 自然语言：机器翻译、问答、文本摘要——近年的大语言模型本质也是极深的神经网络；
  • 推荐系统：短视频、电商首页"猜你喜欢"，用深度网络对用户与内容建模；
  • 自动驾驶：摄像头画面里检测行人、车辆、车道线。

这些任务的共同点是：输入是原始的、高维的、难以手工设计特征的数据，而这正是深度学习的强项。

二、可运行代码示例#

下面用 PyTorch 搭一个最小的多层神经网络，解决上一课感知机搞不定的 XOR 问题，直观感受"加一层"的威力。XOR 是二分类问题，我们用一层隐藏层（2 个神经元）+ Sigmoid 激活。

import torch
import torch.nn as nn

# XOR 数据：4 个样本，标签为 x1 XOR x2
X = torch.tensor([[0., 0.],
                  [0., 1.],
                  [1., 0.],
                  [1., 1.]])
y = torch.tensor([[0.], [1.], [1.], [0.]])   # 形状 (4,1) 配合二分类损失

# 一个极小的多层感知机：输入 2 → 隐藏层 2（Sigmoid）→ 输出 1（Sigmoid）
model = nn.Sequential(
    nn.Linear(2, 2),   # 隐藏层：2 输入 -> 2 神经元
    nn.Sigmoid(),      # 隐藏层激活（非线性，关键！）
    nn.Linear(2, 1),   # 输出层：2 -> 1
    nn.Sigmoid()       # 输出激活：把结果压到 0~1 当概率
)

# 二分类常用交叉熵损失；优化器用随机梯度下降
criterion = nn.BCELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=1.0)

# 训练：反复前向 -> 算损失 -> 反向传播 -> 更新参数
for epoch in range(2000):
    optimizer.zero_grad()          # 清空上一步的梯度
    y_pred = model(X)              # 前向传播
    loss = criterion(y_pred, y)    # 计算损失
    loss.backward()                # 反向传播：自动算所有参数的梯度
    optimizer.step()               # 沿梯度下降更新参数
    if epoch % 500 == 0:
        print(f"第 {epoch:4d} 轮，损失 = {loss.item():.4f}")

# 看最终预测：应接近 [[0],[1],[1],[0]]
with torch.no_grad():
    print("预测输出：", model(X).round())

运行后损失会从约 0.7 一路降到接近 0，最后四个样本的预测被"四舍五入"成 [[0],[1],[1],[0]]，与 XOR 完全一致。注意对比上一课：感知机永远学不会的 XOR，一个只有 2 个隐藏神经元的小网络几秒钟就学会了——差距全部来自那个 Sigmoid 隐藏层引入的非线性。

你可以做个对照实验：把上面网络里的两个 nn.Sigmoid() 都删掉，再训练，看看损失是否迟迟降不下来。结果会再次印证：没有非线性，再多的线性层也只是线性变换，仍然学不会 XOR。

三、练习#

  1. 对照实验：删掉两个 Sigmoid（只留线性层）重新训练 XOR，记录损失是否能降到接近 0，并解释原因。
  2. 调隐藏层宽度：把隐藏层神经元数从 2 改成 1、再改成 8，观察收敛速度和最终效果，说说宽度变化的影响。
  3. 理解反向传播的边界：为什么单层感知机的"犯错就改"规则无法直接推广到多层？中间层缺的是什么？
