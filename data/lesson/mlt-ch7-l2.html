PAC 学习直观#

上一课我们把"泛化"定义为期望风险与经验风险之差，并给了它一条手感的界 复杂度/m​。这一课要把这条手感变成定理：给定一个有限假设类，究竟需要多少样本，才能保证"训练误差低 ⟹ 测试误差也低"？答案就是 PAC 学习框架（Probably Approximately Correct，可能近似正确）。它的名字已经把结论说全了：我们追求的不是"绝对正确"，而是"以很高的概率，近似正确"。

一、概念讲解（含推导）#

1. 先问"为什么"：PAC 要保证的是什么？#

设假设类 H 是有限的（∣H∣<∞），数据独立同分布来自分布 P。对每个假设 h，记

R(h)=E(x,y)∼P​[1[h(x)=y]],R^(h)=m1​i=1∑m​1[h(xi​)=yi​]

（这里用 0/1 损失的分类误差，简洁且不失一般性）。

PAC 学习要回答的问题是：要多少样本 m，才能保证"经验风险最小的假设，其真实风险也很小"？ 形式化地说，我们希望存在样本量下界，使对任意分布 P，以至少 1−δ 的概率，ERM 选出的 h 满足

R(h)≤h′∈Hmin​R(h′)+ε.

参数含义：ε 是"近似程度"（准确到多好），δ 是"失败概率"（多大概率会踩到坏样本）。PAC = 以概率 1−δ 近似到 ε 以内。

2. 关键工具之一：霍夫丁不等式#

整个证明的引擎是霍夫丁（Hoeffding）不等式，它是"大数定律的定量版本"。设 Z1​,…,Zm​ 独立、取值于 [0,1]、均值 μ，样本均值 Zˉ=m1​∑i​Zi​。则对任意 ε>0：

Pr(∣Zˉ−μ∣≥ε)≤2exp(−2mε2).

对单个固定的假设 h，令 Zi​=1[h(xi​)=yi​]，则 Zˉ=R^(h)、μ=R(h)，立即得到：

Pr(∣R^(h)−R(h)∣≥ε)≤2exp(−2mε2).

注意：这是针对单个固定 h 的。而 ERM 是在整个 H 里挑一个最好的 h——挑的过程会"作弊"，所以我们不能只盯一个 h。

3. 关键工具之二：并集界（union bound）#

要把"对单个 h 成立"升级为"对所有 h 同时成立"，用并集界。事件"存在某个 h 的误差偏差超 ε"的概率，不超过各 h 偏差超 ε 的概率之和：

Pr(∃h∈H:∣R^(h)−R(h)∣≥ε)≤h∈H∑​Pr(∣R^(h)−R(h)∣≥ε)≤∣H∣⋅2exp(−2mε2).

这一步就是"模型复杂度"进入上界的方式：假设类越大，需要同时管住的 h 越多，坏事件的概率被加得越高。

4. 一致收敛：训练误差与真实误差处处接近#

由上面两条，我们得到一致收敛结论：以至少 1−δ 的概率，对所有 h∈H 同时有

∣R^(h)−R(h)∣≤ε,当 m≥2ε21​lnδ2∣H∣​.

（由 2∣H∣e−2mε2≤δ 反解出 m 即可。）在一致收敛成立的"好事件"下，ERM 的泛化性就水到渠成。

5. PAC 学习定理：把一致收敛翻译成泛化保证#

设 h^=argminh​R^(h)，h∗=argminh​R(h)。在一致收敛的好事件下：

R(h^)≤R^(h^)+ε≤R^(h∗)+ε≤R(h∗)+2ε.

R(h^)≤R^(h^)+ε≤R^(h∗)+ε≤R(h∗)+2ε.

三步分别用了：一致收敛（h^ 也满足）、h^ 的经验风险最小、一致收敛（h∗ 也满足）。于是得到 PAC 定理的核心结论：

R(h^)≤R(h∗)+2ε以概率≥1−δ,当 m≥2ε21​lnδ2∣H∣​​

R(h^)≤R(h∗)+2ε以概率≥1−δ,当 m≥2ε21​lnδ2∣H∣​​

读作：只要样本量 m 超过 O(ε2ln∣H∣​)，ERM 就以概率 1−δ 找到"真实风险逼近最优、误差不超过 2ε"的假设。 这就是"可能近似正确"的完整含义，也是机器学习"可学习性"的第一个严格定义。

直觉提炼：样本复杂度对 ε 是二次依赖（要准 10 倍，样本要 100 倍），对假设类大小 ∣H∣ 只是对数依赖（模型空间翻倍，样本只需加一个常数）。这解释了为什么"稍大一点的有限模型"并不可怕——代价是温和的对数增长。

二、验证性代码示例#

下面代码用数值实验验证 PAC 的两个核心机制：① 对固定 h，经验误差随 m 增大以 exp(−2mε2) 的概率收敛到真实误差；② 对含 ∣H∣ 个假设的有限类，一致收敛的失败率确实按 2∣H∣e−2mε2 被放大。

import numpy as np

rng = np.random.default_rng(0)

# ---------- 1) 固定 h：经验误差逼近真实误差 ----------
p_true = 0.3                      # 固定假设 h 的真实错误率 R(h)
eps = 0.1

def exceed_rate(m, trials=20000):
    """模拟 |R̂ - R| >= eps 的发生频率，与 Hoeffding 界对比"""
    hits = 0
    for _ in range(trials):
        X = rng.random(m) < p_true
        Rhat = X.mean()
        if abs(Rhat - p_true) >= eps:
            hits += 1
    return hits / trials

print("固定 h: |R̂-R|>=ε 的经验频率 vs Hoeffding 上界 2exp(-2mε²)")
for m in [50, 100, 200, 500]:
    emp = exceed_rate(m)
    bound = 2 * np.exp(-2 * m * eps**2)
    print(f"m={m:>4}: 经验={emp:.4f}  上界={bound:.4f}")

# ---------- 2) 有限假设类：并集界放大 ----------
H = 50                            # 假设类大小 |H|
print("\n有限类 |H|=50: 存在某 h 偏差超 ε 的经验频率 vs 并集界")
for m in [200, 500, 1000, 2000]:
    worst_cnt = 0
    for _ in range(2000):
        max_dev = 0.0
        for _ in range(H):
            p = rng.uniform(0.0, 1.0)          # 每个 h 一个随机真实错误率
            Rhat = (rng.random(m) < p).mean()  # 抽 m 个样本估计经验错误率
            max_dev = max(max_dev, abs(Rhat - p))
        if max_dev >= eps:
            worst_cnt += 1
    emp_worst = worst_cnt / 2000
    bound_worst = 2 * H * np.exp(-2 * m * eps**2)
    print(f"m={m:>4}: 经验={emp_worst:.4f}  并集界={min(bound_worst,1.0):.4f}")

运行结果大致为：

固定 h: |R̂-R|>=ε 的经验频率 vs Hoeffding 上界 2exp(-2mε²)
m=  50: 经验=0.1240  上界=0.7358
m= 100: 经验=0.0293  上界=0.2707
m= 200: 经验=0.0019  上界=0.0366
m= 500: 经验=0.0000  上界=0.0001

有限类 |H|=50: 存在某 h 偏差超 ε 的经验频率 vs 并集界
m= 200: 经验=0.0895  并集界=1.0000
m= 500: 经验=0.0000  并集界=0.0045
m=1000: 经验=0.0000  并集界=0.0000
m=2000: 经验=0.0000  并集界=0.0000

解读：① 固定 h 的实际偏离频率远低于 Hoeffding 上界（上界是"最坏情况"的保险线，现实中要松得多）；② 有限类的一致收敛失败率确实比单 h 高（因为要同时管住 50 个 h），但随 m 增大同样迅速归零——这正是"ln∣H∣ 只进对数、代价温和"的体现。

三、练习#

  1. 完整写出 PAC 定理三步证明（R(h^)≤R^(h^)+ε≤R^(h∗)+ε≤R(h∗)+2ε），说明每一步分别用了什么。
  2. 从 2∣H∣e−2mε2≤δ 反解出样本复杂度下界 m≥2ε21​lnδ2∣H∣​，并解释它对 ε 是二次、对 ∣H∣ 是对数依赖。
  3. 用代码：固定 ε=0.1,δ=0.05，对 ∣H∣=10,100,1000 计算所需样本量 m，观察 ∣H∣ 增大 100 倍时 m 只增加多少。
  4. 解释为什么并集界在本定理中是"松"的：如果两个假设高度相关，它们的坏事件并不独立，并集界会把概率加过头。据此谈谈为什么 PAC 界是"充分但保守"的。
  5. 思考：PAC 定理假设 H 有限。如果 H 无限（比如所有线性分类器），∣H∣ 写不进公式，问题出在哪？这为下一课"VC 维"埋下伏笔。

母原理连接#

本课是母原理 2（概率视角统一一切） 在"学习理论"中的巅峰应用：PAC 框架用两个纯粹的概率工具——霍夫丁不等式（大数定律的定量形式）与并集界（坏事件的叠加）——把"泛化"这个模糊目标变成了一个可计算的样本复杂度。它同时回望母原理 1（一切学习 = 优化）：ERM 之所以可靠，正是因为一致收敛保证了"优化经验风险"与"优化期望风险"在高概率下等价。记住这条主线：学习的可靠性，本质是概率论里"抽样均值逼近期望"的一个上界。
