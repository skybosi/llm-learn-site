模块与 import#

别人写好的工具，我们直接拿来用。本节课学习如何引入模块，以及把自己的代码也做成模块。

一、概念讲解#

1. 什么是模块#

一个 .py 文件就是一个模块。把相关的函数、变量写进同一个文件，就形成了一个可以反复使用的"工具包"。模块让代码可以按功能拆分、互相复用。

2. import：把模块请进来#

import 模块名

引入后，用 模块名.函数名() 的方式来调用里面的函数。Python 自带了大量"标准库"模块（如 math、random、datetime），装上 Python 就有了。

3. from ... import：只取需要的部分#

from 模块名 import 函数名

这样可以直接写 函数名()，不用再带模块名前缀。也可以用 import ... as ... 给模块起个别名，少敲几个字、也避免重名。

4. 自己写模块#

把函数写进一个 .py 文件（比如 my_utils.py），同目录下的另一个脚本就可以 import my_utils 来用。要注意：模块被 import 时，它顶层的代码会执行一遍，所以通常把"真正要运行的入口代码"放进 if __name__ == "__main__": 里。

5. name 与 "main"#

每个模块都有一个内置变量 __name__：

  • 当文件被直接运行时，__name__ 的值是 "__main__"；
  • 当文件被 import 时，__name__ 的值是模块名。

所以 if __name__ == "__main__": 里的代码，只有在"直接运行这个文件"时才执行，被别的文件 import 时不会执行——这是写模块的标准做法。

二、代码示例#

示例 1：使用标准库 math#

import math

print(math.sqrt(16))    # 开方，4.0
print(math.pi)          # 圆周率
print(math.floor(3.9))  # 向下取整，3

示例 2：from ... import 与别名#

from math import sqrt                 # 只引入 sqrt
from datetime import datetime as dt   # 起别名 dt

print(sqrt(81))                       # 9.0
print(dt.now())                       # 当前时间

示例 3：使用 random 模块#

import random

print(random.randint(1, 6))                        # 随机 1~6 的整数，像骰子
print(random.choice(["苹果", "香蕉", "橙子"]))     # 随机选一个

示例 4：自己写模块并 import#

先在 my_utils.py 里写：

# my_utils.py
def double(x):
    """返回 x 的两倍。"""
    return x * 2

if __name__ == "__main__":
    # 只有直接运行本文件时才执行
    print(double(21))

再在同目录的另一个文件里：

import my_utils

print(my_utils.double(5))   # 10

三、练习#

  1. 用 math 模块计算半径为 4 的圆的面积（提示：math.pi * r * r）。
  2. 用 random 模块写一个"掷两个骰子并打印点数之和"的小程序。
  3. 新建一个 tools.py 文件，里面写一个 triple(x) 函数（返回 x 的三倍），再用 if __name__ == "__main__": 包裹一段测试代码；最后在另一个脚本里 import tools 并调用 triple。
