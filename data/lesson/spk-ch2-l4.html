评测：WER/CER 的陷阱、置信区间与语言模型融合重打分#

这一节要解决什么#

前三节交付了三套对齐假设与三个可训练的目标。但一个识别系统最终要被回答的问题是：

它有多好？

这个问题看起来有一个标准答案——WER。而本节要说明的是：WER 是一个在"定义正确、口径声明完整、给出区间"三个条件同时满足时才成立的读数。 缺任何一条，这个数就可以被合法地改成完全不同的值，而每一步改动在算术上都无懈可击。

本节交付两件事。

第一，WER/CER 的五个陷阱，每一个都给出可复算的算术：

归一化口径不一 同一对转写，四种口径给出 0.5455、0.4545、0.4545、0.4000，最大最小比 1.36 倍

一、WER/CER 的定义与 S/D/I 分解#

1.1 定义#

参考转写 r=(r1​,…,rN​)、假设转写 h=(h1​,…,hM​)。词错误率定义为

WER=NS+D+I​=Nmin对齐​(#替换+#删除+#插入)​​

三个必须一起说的定义细节：

  • 分母是参考的词数 N，不是假设的词数。所以插入会同时增加分子、不改分母，WER 可以 >1——这是特性不是 bug（插入确实更严重）。
  • 三种错误同价：S=D=I=1。这个"同价"就是陷阱三的全部来源。
  • WER 不是度量（metric）：它不满足三角不等式。d(a,b)=0⇔a=b 成立，但它不能当距离用（不能用它做聚类、不能说"系统 A 离正确答案比 B 近 2 倍"）。

CER 把"词"换成"字符"：CER=(S+D+I)/Nchar​。中文、日文常用它，因为分母无歧义（见 §3）。

1.2 编辑距离与回溯#

S+D+I 就是 Levenshtein 距离，用 DP 算：

Di,j​=min⎩⎨⎧​Di−1,j​+1Di,j−1​+1Di−1,j−1​+[ri​=hj​]​删除 ri​插入 hj​匹配/替换​

D0,0​=0,Di,0​=i,D0,j​=j

算出距离不等于算出 S,D,I：距离只是一个数，S/D/I 的分解要靠回溯。同一个距离可以对应不同的分解，而不同的分解有完全不同的业务含义。

2.2 为什么这不是"细节"#

因为归一化同时改变分子与分母，所以它可以被用来把 WER 调低，而每一步都合法。 这不是打假——真实系统确实需要归一化（3rd 与 third 是同一个意思，"嗯"是否算错取决于任务）。问题在于不声明口径就没有可比性。

最低要求是同时声明五项：

  1. 大小写策略；
  2. 标点策略（保留/删除/单独评测标点）；
  3. 数字与缩写（3rd / third / 3；9:30 / nine thirty / nine 30）；
  4. 填充词与口头语（um / uh / 嗯 / 那个）；
  5. 分词器与词典（中文、日文必需）。

可算判据：如果你要比较两个系统的 WER，先检查它们的分母是否相等。表 3 里"原样"与"去填充词"的口径分母是 11 与 10——分母不同意味着它们连在算同一个量都不是。

三、陷阱二：标点与分词#

3.1 标点：它不是"小误差"#

标点在编辑距离里与词同价，但它有两个特殊性：

  • 数量少：一段话里标点只占几个位置，对 WER 的影响量级小；
  • 语义重：no, we should not go 与 no we should not go 的标点决定了停顿结构。

所以正确做法是分开报：词错误率（去标点）+ 标点错误率（F1）。混在一起报到 WER 里，等于把两个不相干的量按个数加权相加。

3.2 分词：中文的 CER 与 WER#

输出表 4。字符级：

r=今天天气很好我们出去走走 (N=12 字),h=今天天气好我们出去走

CER=120+2+0​=0.1667

词级（第一种分词）：r=今天/天气/很/好/我们/出去/走走（7 词），h=今天/天气/好/我们/出去/走：

WER=71+1+0​=0.2857

词级（第二种同样合法的分词）：r=今天/天气/很好/我们/出去/走走（6 词），h 不变：

WER=62+0+0​=0.3333

同一个假设，只因分词方案变了，WER 从 0.2857 变成 0.3333（1.17 倍）。 而 CER 全程无歧义。

结论：中文 ASR 报 CER（分母无歧义），或者把分词器连同 WER 一起固定并公开。用不公开的分词器报 WER 等于报了一个无法复现的数。

4.2 为什么必然如此#

WER 是词级均匀权重的平均：

WER=N1​i=1∑N​erri​,erri​∈{0,1}

它把每个词的误差权重都设成 1。这在"每个词同等重要"的假设下是对的——朗读转写、字幕生成大致如此。但只要任务里有槽位（订票、日程、医疗编码、金额），这个假设就不成立，而且不成立的幅度可以很大：

WERw​=∑i​wi​∑i​wi​erri​​,wi​={51​实体其他​

上表最后一列就是这个量：0.7143/0.1429/0.4857。A 与 B 的 WER 比值是 1.00，加权 WER 的比值是 5.00。

六、语言模型融合与重打分#

6.1 浅融合公式#

CTC 与 RNN-T 的标签先验是弱的（第 2 节：I(y1​;y2​)=0.0776 nats），所以工业系统几乎总要把外部 LM 接进来。最常用的形式是浅融合：

y^​=argymax​[声学logpam​(y∣x)​​+α语言logplm​(y)​​+β长度∣y∣​​]​

三个参数各有明确职责：

  • α：LM 的声音有多大。有最优值，不是越大越好（§6.2）；
  • β：长度值多少钱。不写它，重打分会系统性偏好短假设（§6.4）；
  • ∣y∣ 或 ∣y∣ 的某种归一化（如除以 ∣y∣）：对数分数是负的、随长度单调下降，不奖励长度就等于给"少输出"付钱。

融合的三种位置：

方式 在什么时候融合 代价
浅融合 只在解码打分时加 αlogplm​ 最便宜；LM 与 AM 各自独立训练
深融合 在解码器隐状态层拼接 LM 状态 需要两套网络同步推理，延迟高
冷融合 训练时把 LM 的预测作为额外输入 需要重训 AM；LM 换了要重训

后有重打分（rescoring）：先让 AM 产出一个 n-best 列表或 lattice，再用 LM 重新排序。它是浅融合的一种离线版本，好处是 LM 可以很贵（n-gram 之外还能上神经网络 LM），因为只跑 n 个候选。

6.5 融合的边界#

(1) oracle 上界不可超越。 候选表里没有的答案，重打分永远拿不到。所以重打分之前要先看 oracle WER：如果 1-best 与 oracle 只差 0.002，再贵的 LM 也只能买 0.002——应该去改 AM 或加候选生成的多样性。

(2) α∗ 不是常数。 它依赖领域（LM 与领域匹配度）、音频条件（噪声大时应该减小 α，因为 AM 更不可靠，需要更多语言先验？——不，噪声大时 AM 的错误更随机，LM 能修更多，所以往往要增大 α；但 LM 本身与领域不匹配时要减小）。可算判据：在 dev 上按条件（信噪比分档、领域分档）分别扫 α，如果各档的 α∗ 差得比 §6.3 的过拟合量还大，就值得做条件化的 α；否则统一 α 更稳。

(3) 融合会改变实体错误。 LM 倾向于把罕见专名改成常见词，所以 WER 降而实体错误率升是完全可能的。必须按 §4.3 的三层指标同时看，否则会选出一个"WER 更低但订票全错"的系统。

(4) 深融合与冷融合的取舍。 深融合把 LM 状态拼进解码器，表达能力最强但延迟与工程复杂度最高；冷融合把 LM 训练进 AM，推理最便宜但换 LM 要重训 AM，违背了"LM 可以独立升级"这个把语言拆出去的初衷。判据：如果你需要按会话注入热词（每天变），只有浅融合/重打分能在不重训的情况下做到。

七、取舍与边界#

(1) 报告的四个必备项。 任何 WER 读数必须同时给出：归一化口径五项（§2.2）、分词器、句数与词数、置信区间（自助法）。缺任一项，这个数就不能与别人的数比较。

(2) 置信区间不是可选的。 §5.1 的"1570 词/系统"与 §5.2 的"自助法宽 2.15 倍"是同一件事的两面：WER 的差别在常见样本量下经常不可区分。这条与第 3 节的延迟口径叠在一起，意味着"我们的 WER 5.2%、延迟 300 ms"与"我们的 WER 5.0%、延迟 600 ms"这两个陈述之间不存在一个可以比较的单一结论——必须把区间与延迟一起报。

(3) 指标选择必须匹配任务结构。 均匀权重的 WER 适合"每个词同等重要"的任务（朗读转写、字幕）；槽位型任务（订票、日程、金额、医疗编码）必须加实体/槽位指标。可算判据：把参考转写里的词按业务重要性分两三类，算加权 WER（§4.2），如果加权 WER 的排序与 WER 的排序不同，那么 WER 是你的系统选择的错误依据。

(4) 重打分的收益要按"净"报。 §6.3 给出调参代价是融合收益的 66.7%（在小 dev 集上）。所以"融合带来 15% 相对 WER 改善"这句话在真实的小 dev 集上可能只剩三分之一。做法：报两行——dev 上的最优值、以及用固定超参在 test 上的一次性结果。

(5) 一个容易漏掉的边界：CER 与 WER 不能互换比较。 CER 的分母是字符数，字符错误率天然比词错误率"看起来"高（一个字错可能对应一个词错）。跨语言、跨粒度比较必须先统一到同一粒度，或只做同粒度内的相对比较。

(6) 可复现性。 转写对、归一化规则、合成语料、n-best 分数表、AM/LM 分数与自助法重采样全部是合成的（⚠️），随机种子固定为 31337、99、20240922、5。代码只用标准库（math、random）。给定同一份代码，输出逐字节一致。

def edit_ops(ref, hyp):
    """返回 (S, D, I, 对齐操作序列)。标准 Levenshtein DP + 回溯。"""
    n, m = len(ref), len(hyp)
    D = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        D[i][0] = i
    for j in range(1, m + 1):
        D[0][j] = j
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            cost = 0 if ref[i - 1] == hyp[j - 1] else 1
            D[i][j] = min(D[i - 1][j] + 1, D[i][j - 1] + 1, D[i - 1][j - 1] + cost)
    # 回溯
    ops = []
    i, j = n, m
    while i > 0 or j > 0:
        if i > 0 and j > 0 and ref[i - 1] == hyp[j - 1] and D[i][j] == D[i - 1][j - 1]:
            ops.append(('=', ref[i - 1], hyp[j - 1])); i -= 1; j -= 1
        elif i > 0 and j > 0 and D[i][j] == D[i - 1][j - 1] + 1:
            ops.append(('S', ref[i - 1], hyp[j - 1])); i -= 1; j -= 1
        elif i > 0 and D[i][j] == D[i - 1][j] + 1:
            ops.append(('D', ref[i - 1], '')); i -= 1
        else:
            ops.append(('I', '', hyp[j - 1])); j -= 1
    ops.reverse()
    S = sum(1 for o in ops if o[0] == 'S')
    Dl = sum(1 for o in ops if o[0] == 'D')
    I = sum(1 for o in ops if o[0] == 'I')
    return S, Dl, I, ops, D

def wer(ref, hyp):
    """WER = (S+D+I)/N，N = 参考词数。"""
    S, Dl, I, ops, _ = edit_ops(ref, hyp)
    return (S + Dl + I) / len(ref), (S, Dl, I)

def corpus_wer(pairs):
    tot_e = tot_n = 0
    for ref, hyp in pairs:
        S, Dl, I, _, _ = edit_ops(ref, hyp)
        tot_e += S + Dl + I; tot_n += len(ref)
    return tot_e / tot_n, tot_e, tot_n

def norm(tokens, lower=False, strip_punct=False, expand_num=False, drop_filler=False):
    FILL = {"um", "uh", "er", "ah", "嗯", "呃"}
    NUM = {"1": "one", "2": "two", "3": "three", "9": "nine", "30": "thirty", "2024": "twenty twenty four"}
    out = []
    for w in tokens:
        if strip_punct:
            w = w.strip(".,!?;:\"'()")
        if lower:
            w = w.lower()
        if expand_num and w in NUM:
            w = NUM[w]
        if drop_filler and w.lower() in FILL:
            continue
        if w:
            out.append(w)
    return out

VOCAB = ["w%d" % i for i in range(10)]

def true_bigram():
    P = {}
    for a in VOCAB:
        row = {b: 0.02 for b in VOCAB}
        row[VOCAB[(VOCAB.index(a) + 1) % 10]] += 0.55
        row[VOCAB[(VOCAB.index(a) + 2) % 10]] += 0.23
        s = sum(row.values())
        P[a] = {b: v / s for b, v in row.items()}
    return P

def est_bigram(P, rng, n_sample):
    counts = {a: {b: 0 for b in VOCAB} for a in VOCAB}
    for _ in range(n_sample):
        a = rng.choice(VOCAB)
        for _ in range(6):
            r = rng.random(); acc = 0.0; nxt = VOCAB[-1]
            for b, p in P[a].items():
                acc += p
                if r <= acc:
                    nxt = b; break
            counts[a][nxt] += 1
            a = nxt
    Q = {}
    for a in VOCAB:
        tot = sum(counts[a].values()) + 10 * 0.5
        Q[a] = {b: (counts[a][b] + 0.5) / tot for b in VOCAB}
    return Q

def sample_seq(P, rng, L):
    s = [rng.choice(VOCAB)]
    for _ in range(L - 1):
        r = rng.random(); acc = 0.0; nxt = VOCAB[-1]
        for b, p in P[s[-1]].items():
            acc += p
            if r <= acc:
                nxt = b; break
        s.append(nxt)
    return s

def lm_logprob(Q, seq):
    return sum(math.log(Q[seq[i - 1]][seq[i]]) for i in range(1, len(seq)))

小结#

  • WER=(S+D+I)/N，分母是参考词数；S/D/I 要靠回溯才能分解，而同一距离的分解可能不唯一。它是均匀权重的平均值，等价于把每个词的错误权重都设为 1。
  • 陷阱一（归一化）：同一对转写在四种口径下是 0.5455/0.4545/0.4545/0.4000，最大最小比 1.36 倍。归一化同时改分子与分母，所以必须声明大小写、标点、数字、填充词、分词器五项。
  • 陷阱二（分词）：同一对中文的 CER =0.1667，两种合法分词下的 WER 分别是 0.2857 与 0.3333（1.17 倍）。中文报 CER 或公开固定分词器。
  • 陷阱三（实体）：三个系统 WER 都是 0.1429，实体错误率 1.00/0.00/0.60，加权 WER（权重 5）0.7143/0.1429/0.4857。用 WER 选系统会选错。 必须三层指标一起报。
  • 陷阱四（区间）：p^​=0.10、N=1000 的 95% CI 是 ±0.0186；检测 3% 绝对差异需每系统 1570 词（≈157 句）。句内聚集让自助法 CI 比二项 CI 宽 2.15 倍（句内误差聚集）。微平均 0.0685 与宏平均 0.1167 差 1.70 倍，必须声明用哪一个。
  • 融合：y^​=argmaxy​[logpam​+αlogplm​+β∣y∣]。本算例 1-best 0.0531，oracle 0.0359，α∗=0.80 时 0.0437（捕获 headroom 的 54.55%），α→∞ 退化到纯 LM 的 0.0594；α=7 处首次差于不用 LM。
  • 调参过拟合：dev 与 test 的最优 α 差 0.40，代价 0.0063 绝对（14.3% 相对），相当于融合收益的 66.7%。固定网格、test 只评一次。
  • 长度奖励：β 的翻转点在 (0.075,0.10]，可由 −0.30+6β≥0+3β 解出。不做长度归一化就等于给"少输出"付钱。
