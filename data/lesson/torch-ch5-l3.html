完整训练脚本#

前两课分别讲了"怎么训练"和"怎么评估"。这一课把它们拼成一个结构清晰、可直接复用的完整脚本——就像搭积木，把前面所有知识点（数据、模型、损失、优化器、训练、评估、保存）各归其位。学完这一课，你就拥有了一个能套用到大多数分类任务的模板。

一、概念讲解#

1. 好脚本的骨架：职责分离#

一份能长期维护的训练脚本，通常拆成几个单一职责的函数：

  • build_data()：构造数据与 DataLoader；
  • build_model()：构造模型；
  • train_one_epoch()：训练一个 epoch，返回平均损失；
  • evaluate()：在验证集上算指标；
  • main()：把所有零件串起来，跑多轮并记录、保存。

这样做的最大好处是可替换：想换个数据集，只改 build_data；想换个模型，只改 build_model；训练主逻辑一行都不用动。

2. 把"配置"集中起来#

学习率、batch 大小、epoch 数这些数字散落在代码里很容易改错。把它们收拢成一个配置字典或参数类，一眼看清全部可调项：

config = dict(epochs=20, batch_size=64, lr=0.01)

3. 让结果可追踪：记录与保存#

训练跑完如果什么都不留，等于白跑。两个习惯必须养成：

  • 记录：每个 epoch 打印/记录训练损失与验证指标，画成曲线能直观看出过拟合；
  • 保存：把最优（或最后）的模型权重存到磁盘，供推理复用。保存细节下一章专门讲。

二、可运行代码示例#

下面是一个完整的、可直接运行的 MNIST 手写数字分类脚本。它把上述骨架落实成真实代码：数据用 DataLoader 加载，模型用两层全连接，训练 3 个 epoch 后打印并保存模型。首次运行会自动下载 MNIST。

import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms


# ---------- 1) 数据 ----------
def build_data(batch_size=64):
    transform = transforms.Compose([
        transforms.ToTensor(),                      # (1, 28, 28)，像素归一到 [0,1]
        transforms.Normalize((0.1307,), (0.3081,)),  # MNIST 的经验均值和标准差
    ])
    train_set = datasets.MNIST("./data", train=True, download=True, transform=transform)
    val_set = datasets.MNIST("./data", train=False, download=True, transform=transform)
    train_loader = DataLoader(train_set, batch_size=batch_size, shuffle=True)
    val_loader = DataLoader(val_set, batch_size=batch_size, shuffle=False)
    return train_loader, val_loader


# ---------- 2) 模型 ----------
class MLP(nn.Module):
    """两层全连接：784 -> 128 -> 10。"""
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Flatten(),          # (N, 1, 28, 28) -> (N, 784)
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10),
        )

    def forward(self, x):
        return self.net(x)


# ---------- 3) 训练一个 epoch ----------
def train_one_epoch(model, loader, criterion, optimizer):
    model.train()
    total_loss, total = 0.0, 0
    for xb, yb in loader:
        optimizer.zero_grad()
        loss = criterion(model(xb), yb)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * xb.size(0)
        total += xb.size(0)
    return total_loss / total


# ---------- 4) 评估 ----------
def evaluate(model, loader):
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():
        for xb, yb in loader:
            pred = model(xb).argmax(dim=1)
            correct += (pred == yb).sum().item()
            total += yb.size(0)
    return correct / total


# ---------- 5) 主流程 ----------
def main():
    torch.manual_seed(0)
    config = dict(epochs=3, batch_size=64, lr=0.01)

    train_loader, val_loader = build_data(config["batch_size"])
    model = MLP()
    criterion = nn.CrossEntropyLoss()
    optimizer = torch.optim.SGD(model.parameters(), lr=config["lr"])

    for epoch in range(1, config["epochs"] + 1):
        train_loss = train_one_epoch(model, train_loader, criterion, optimizer)
        val_acc = evaluate(model, val_loader)
        print(f"epoch {epoch}/{config['epochs']}  "
              f"训练损失 = {train_loss:.4f}  验证准确率 = {val_acc:.4f}")

    torch.save(model.state_dict(), "mnist_mlp.pt")   # 保存训练好的权重
    print("已保存模型权重到 mnist_mlp.pt")


if __name__ == "__main__":
    main()

运行后你会看到类似：

epoch 1/3  训练损失 = 0.4849  验证准确率 = 0.8979
epoch 2/3  训练损失 = 0.2145  验证准确率 = 0.9287
epoch 3/3  训练损失 = 0.1571  验证准确率 = 0.9434
已保存模型权重到 mnist_mlp.pt

三个 epoch 就能到 94% 的准确率，说明这个"积木式"脚本骨架是有效的。后续你把 MLP 换成 CNN、把 MNIST 换成别的数据集，只需要改动对应函数，训练主流程保持不变。

三、练习#

  1. 把 epochs 加到 5，观察验证准确率是否继续提升，并思考什么时候该提前停止（早停）。
  2. 给 main() 加一个"记录列表"，把每个 epoch 的训练损失和验证准确率存进列表，最后用 print 画一个简单的文本趋势（如 loss: 0.48 -> 0.21 -> 0.16）。
  3. 把模型换成上一课见过的带 Dropout 的版本，并确认 train_one_epoch 里是 model.train()、evaluate 里是 model.eval()，观察准确率变化。
  4. 把 torch.save(model.state_dict(), ...) 改成只保存验证准确率最高的那一次（记录 best_acc，超过才保存），体会"选最优模型"的实战做法。
