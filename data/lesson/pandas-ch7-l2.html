探索性分析#

上一课我们把数据"体检"了一遍。现在数据长什么样已经清楚，接下来进入探索性数据分析（EDA）：不断用分组、聚合、透视这些工具去"问数据问题"，从各个角度挖出规律。这一步没有固定答案，核心是带着问题去切分数据。

一、概念讲解#

1. 探索性分析在做什么#

EDA 的本质是反复做两件事：看分布（谁多谁少）和做对比（哪组高哪组低）。常用的问题模板有：

  • 每个品类、地区各占多少？（value_counts）
  • 不同地区/品类的销售额谁高谁低？（groupby）
  • 销售额随时间如何变化？（按时间分组）
  • 地区 × 品类交叉起来看呢？（pivot_table）

2. 分类字段的分布：value_counts#

想知道"每个品类有多少订单"，一行搞定：

df["category"].value_counts()

默认按数量从高到低排列，加 normalize=True 可以得到占比。

3. 数值字段的分组对比：groupby#

看"各地区销售额"，就是第 5 章的分组聚合：

df.groupby("region")["amount"].sum()

想看得更细，可以把分组键换成列表，或在聚合后接 sort_values 排个序。

4. 时间趋势：按月汇总#

date 是日期列。要按月看趋势，先把日期取到"月"这一级，再分组：

monthly = df.groupby(df["date"].dt.to_period("M"))["amount"].sum()

.dt 是日期列的专用访问器，to_period("M") 把日期归到所属月份。这样得到的 monthly 就是"每月销售额"的时间序列。

5. 交叉视角：pivot_table 与相关性#

  • 想看"地区 × 品类"的交叉销售额，用第 6 章的透视表：
    pd.pivot_table(df, index="region", columns="category", values="amount", aggfunc="sum")
  • 想看两个数值列（如 price 与 amount）是否相关，用 df[["price", "amount"]].corr()，结果在 -1 到 1 之间，越接近 1 正相关越强。

二、可运行代码示例#

沿用上一课的数据（这里重新生成同一份，保证代码可独立运行）：

import pandas as pd
import numpy as np

np.random.seed(42)
n = 400
regions = ["华东", "华北", "华南", "西南"]
categories = ["数码", "家居", "服饰", "美妆"]
cat_prod = {"数码": ["手机", "耳机", "键盘"], "家居": ["台灯", "收纳盒", "毛巾"],
            "服饰": ["T恤", "牛仔裤", "卫衣"], "美妆": ["口红", "面膜", "香水"]}
cat = np.random.choice(categories, n)
df = pd.DataFrame({
    "order_id": [f"ORD{i:04d}" for i in range(n)],
    "date": pd.to_datetime("2024-01-01") + pd.to_timedelta(np.random.randint(0, 180, n), unit="D"),
    "region": np.random.choice(regions, n),
    "category": cat,
    "product": [np.random.choice(cat_prod[c]) for c in cat],
    "customer_type": np.random.choice(["新客", "老客"], n, p=[0.4, 0.6]),
    "payment": np.random.choice(["微信支付", "支付宝", "银行卡"], n),
    "quantity": np.random.randint(1, 5, n),
    "price": np.round(np.random.uniform(20, 800, n), 2),
})
df["amount"] = (df["price"] * df["quantity"]).round(2)

示例 1：分类字段分布#

# 各品类的订单数量（及占比）
print(df["category"].value_counts())
print(df["region"].value_counts(normalize=True).round(3))   # 占比

示例 2：分组对比#

# 各地区销售额，从高到低
region_sales = df.groupby("region")["amount"].sum().sort_values(ascending=False)
print(region_sales)

# 各品类销售额与平均客单价
print(df.groupby("category")["amount"].agg(["sum", "mean"]).round(2))

示例 3：时间趋势与交叉视角#

# 按月汇总销售额
monthly = df.groupby(df["date"].dt.to_period("M"))["amount"].sum()
print(monthly)

# 地区 × 品类的交叉销售额透视表
pivot = pd.pivot_table(df, index="region", columns="category",
                       values="amount", aggfunc="sum", fill_value=0)
print(pivot.round(2))

# 单价与金额的相关性
print(df[["price", "amount"]].corr().round(3))

三、练习#

  1. 统计 customer_type（新客/老客）的订单数量和占比，并分别计算两组的平均订单金额，看看谁更"值钱"。
  2. 用 groupby 找出销售额最高的地区，再用透视表看看这个地区里哪个品类贡献最大。
  3. 把按月汇总的 monthly 序列打印出来，观察销售额是否随月份有明显上升或下降，并思考可能的原因（提示：可结合促销、季节性）。
