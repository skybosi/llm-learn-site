采样、混叠与量化：为什么是 16 kHz#

这一节要解决什么#

把空气里的声压变成一串数，只需要三个参数：采样率 fs​、位深 b、通道数 C。工程上早有标准答案（16 kHz、16 bit、单声道），正因为看起来已经解决，绝大多数从业者从没算过这三个参数各自买到了什么、付出了什么。于是出现两类对称的误判：

  • 把采样率当成"越高越好"的质量旋钮：全链路 48 kHz，把语音语料存成 5 倍体积，让波形模型的注意力开销涨到 36 倍（本节表 10 给出确切倍数）；
  • 反过来把 8 kHz 当成"够用"：于是在 /s/ /sh/ /f/ /θ/ 这几个擦音上永久性地拿不回信息。这不是模型不够强，而是信息在采样那一刻就被折叠掉了（本节表 3、表 4 给出确切数字：擦音的类间可分裕度从 8 kHz 带宽下的 2.53 掉到 4 kHz 带宽下的 0.38，而 s 与 θ 的对数谱距离从 12.69 dB 掉到 2.02 dB）。

本节的判据是：采样率由一个双边不等式决定 —— 信息侧问"丢掉这一段频带会让哪些音类不可分"，成本侧算"每一档的码率、存储、FFT 与注意力的显式倍数"。16 kHz 要成为这个不等式的解，而不是一条惯例。

本节交付四件事：

  1. 采样定理的严格结论与违反它时的折叠公式 falias​=∣f−kfs​∣，并逐样本验证（表 1）；
  2. 量化：σq2​=Δ2/12 与 SQNR=6.02b+1.76 dB 的推导、实测偏差、以及"量化噪声不是白噪声"的证据（表 5–7）；
  3. 带宽买到了什么：用合成音类把"线索在 4 kHz 以上还是以下"隔离出来量（表 3、表 4）；
  4. 成本侧四张账与合成边际收益/成本比，给出 argmax（表 8–11）。

第一条纪律先写在这里：

 采样率与位深不是"质量旋钮"，是两个方向相反的约束在某一档上的交点 ​

⚠️ 本节代码中的全部信号、噪声与音类都是合成的。它们的作用是把取舍变成可核对的算术，不是给任何真实语料或系统背书。代码只用标准库。

一、采样：定理保证了什么，违反时发生了什么#

1.1 三个互相独立的操作#

"数字化"其实是三个可以独立选择、独立出错的操作：

操作 参数 丢掉的东西 是否可逆
采样（时间离散化） fs​ fs​/2 以上的全部频率 不可逆（混叠折叠进带内）
量化（幅度离散化） b 幅度细部 部分可补偿（加位深/降噪/多麦）
编码（表示） 浮点/定点/压缩 取决于编码器 有损则不可逆

把它们混在一起谈"音质"是无效的，因为三者的代价与可逆性完全不同。本节先处理前两个。

1.2 采样定理：频谱的周期重复#

理想采样是乘一个冲激串：

xs​(t)=x(t)⋅n=−∞∑∞​δ(t−nT),T=fs​1​

乘冲激串在频域是卷积冲激串，其结果是 X(f) 被复制到每个 kfs​ 上：

Xs​(f)=fs​k=−∞∑∞​X(f−kfs​)

于是全部结论都从这张图上读出来：只要 fmax​<fs​/2，这些副本互不重叠，用理想低通（截止 fs​/2）就能唯一恢复 x(t)。这就是采样定理。fs​/2 叫奈奎斯特频率，2fmax​ 叫奈奎斯特率。

三条假设必须记住，因为实际系统每一条都会破：

  1. 严格带限：真实的语音、音乐、环境声都不是严格带限的，只是高频衰减快；
  2. 无限长：有限长信号的频谱不是有限支撑的；
  3. 理想重建：理想低通不可实现，实际抗混叠滤波器有过渡带。

假设 3 直接给出工程上的裕量规则：如果抗混叠滤波器的过渡带是 [fp​,fs​/2]（fp​ 为通带边缘），那么可用的无混叠带宽只有 fp​，所以通常取 fs​≈2.2fmax​ 而不是 2fmax​。

1.3 违反时到底发生了什么：折叠公式#

falias​=∣f−kfs​∣,k=round(fs​f​),falias​∈[0,2fs​​]

1.4 一个可算的抗混叠代价#

"抽取"（decimation）是降采样率的标准操作：先低通，再每 M 点取一个。为什么不能直接取？设目标是从 fs​=48 kHz 降到 16 kHz，M=3。若不做滤波，9 kHz 处一个 −40 dB 的分量会折到 ∣9000−16000∣=7000 Hz。若目标带内在 7 kHz 处原本是 −60 dB，那么混叠后该处变成约 −40 dB——带内信噪比在这一点上劣化了 20 dB。

于是抗混叠滤波器的指标可以直接反推：为了把折叠分量压到带内噪声底以下，需要

Astop​ ≥ 带内底60 dB​​−强分量(−40 dB)​​+安全裕量20 dB​​=120 dB

这就是为什么高质量重采样器（例如 SoX 的 very high quality、libsamplerate 的最佳档）的阻带衰减指标都在 120 dB 以上，而实时语音前端常用 60–80 dB 的较松指标——指标不是"越高越好"，它由"带外最强分量有多强"和"带内底有多低"共同决定。

  • 量化误差是信号相关的，所以不能用"叠加白噪声"来仿真它。想验证一个系统对量化的鲁棒性，必须真的做量化，不能加一个 σq​ 的高斯噪声代替；
  • 误差的峰值因子约 2.6–3.5（均匀分布的理论值是 3​=1.73），说明存在少量远大于 RMS 的误差点——这正是"数字底噪"听起来不像白噪的原因。

2.3 μ-law：为什么电话用对数压扩#

语音的动态范围很大（轻声到爆破音可差 60 dB 以上），而均匀量化的 SQNR 只对满幅信号最优。对 b=8 的均匀量化，一个幅度只有满幅 1/32 的弱音，SQNR 只剩 26 dB 左右——完全不够。

μ-law 的做法是先压扩再均匀量化：

F(x)=sgn(x)ln(1+μ)ln(1+μ∣x∣)​,μ=255

小信号处 F′(0)=ln(1+μ)μ​=5.545255​=46.0，即量化台阶在信号域被缩小了 46 倍，理论上小信号 SNR 增益 20log10​46.0=33.3 dB。表 7 是实测：

2.4 过采样与噪声整形的耦合#

采样与量化不是独立的：把采样率提高 OSR 倍（过采样率），量化噪声功率摊到更宽的频带上，带内噪声变成 σq2​/OSR。一阶噪声整形（把量化误差高通滤过）可以把带内噪声压到

σq,in-band2​ ∝ OSR3σq2​​

也就是采样率每翻一倍，带内量化噪声降 9 dB（一阶）；二阶是 15 dB。这是 ΔΣ 调制器能用 1 bit 量化做到 16 bit 有效位的原因，也解释了一条实用规则：位深可以事后用位深补，采样率不行。

三、带宽买到了什么（信息侧）#

3.1 语音的能量分布与可懂度线索#

语音各音类的能量分布并不均匀。元音的能量集中在 F1​,F2​,F3​（约 250–3000 Hz），而擦音（/s/ /sh/ /f/ /θ/）的关键线索在更高处：/s/ 的谱峰常在 5–8 kHz，/ʃ/ 在 2–4 kHz。也就是说：

  • 元音身份几乎完全由 0–4 kHz 决定；
  • 擦音身份的一部分线索只能在 4 kHz 以上看到。

如果这个说法成立，那么"8 kHz 带宽不够"这句话就应该能被量化成：限定在 0–4 kHz 时，擦音的类间距离塌到类内散布之内，而元音的类间距离不变。

3.2 把"线索在高频还是低频"隔离出来的合成实验#

为了把这件事从"真实语料里说不清的一堆因素"里剥离出来，我们构造一个受控的合成模型：

  • 共享低频基线：所有擦音在 0–4 kHz 有同分布的低频包络（中心 1.5 kHz、带宽 1.4 kHz、电平 −22 dB）——它在带内不携带任何类别信息；
  • 类别专属高频成分：/s/ 是 4.5 kHz 起的 +20 dB 高频搁架，/f/ 是 5 kHz 起的 +8 dB 搁架，/ʃ/ 是 3 kHz 的 +16 dB 峰，/θ/ 什么都没有；
  • 类内扰动：每句有 ±5 dB 电平抖动、±6 dB 谱倾斜、±20% 峰位抖动——模拟说话人与声道差异。

元音用五极点共振峰模型，类内扰动为共振峰 ±12% 缩放（说话人声道长度差异）与 ±4 dB 谱倾斜。

判据用可分裕度：类间最小对数谱距离除以平均类内对数谱距离。裕度 >1 表示类中心彼此超出类内散布；<1 表示两类在统计上已经难以分开。

3.3 信息论视角：到底需要多少比特#

把上面的结论写成一个信息量估算。语音的音素率约 10–15 音素/秒；给定上下文，音素身份的条件熵约 1–2 bit：

Rphon​≈12 音素/s×1.5 bit≈18 bit/s

这远小于任何音频码率（16 kHz/16 bit = 256 kbit/s）。差额的存在是因为声学模型要处理的不是音素身份本身，而是"给定这段频谱，音素身份的后验"，而同一音素的声学实现随说话人、语速、协同发音大幅变化。上文的"可分裕度"正是这个后验难度的代理：类内散布越大，需要保留的频谱细节越多。

因此有一条比"比特率"更有用的判据：

所需带宽 ≥ 使 Dwithin​​mini=j​Dij​​>1 成立的最小带宽

本节的合成实验给出：对元音这个门槛在 4 kHz 以下就满足；对擦音需要 8 kHz。这就是 16 kHz 在信息侧的根据。

帧率由帧移决定，与 fs​ 无关：

帧/秒=Hfs​​,H=帧移样本数

而每帧的窗内样本数 ∝fs​，FFT 代价约 5Nlog2​N，所以每秒运算量 ∝fs​logfs​：

表 9  25 ms 窗 / 10 ms 帧移下的特征提取量（实 FFT 约 5N log2 N 次浮点运算）
==============================================================================
    fs (Hz) |     帧/秒 |      窗内样本 |  N_fft |   MFLOP/s
  ----------------------------------------------------
       8000 |     100 |       200 |    256 |     1.024
      16000 |     100 |       400 |    512 |     2.304
      32000 |     100 |       800 |   1024 |     5.120
      48000 |     100 |      1200 |   2048 |    11.264

16 kHz 的 2.304 MFLOP/s 对比 48 kHz 的 11.264 MFLOP/s，是 4.89 倍。注意：这一项在"手工特征 + 轻量声学模型"的系统里是主要成本，在波形端到端模型里几乎可以忽略（相对于注意力）。

4.3 波形建模的自注意力#

如果模型直接吃波形（wav2vec 类），序列长度 T∝fs​，自注意力开销 ∝T2∝fs2​：

表 10  原始波形建模：10 s 音频、卷积下采样 320 倍、d=768 的单层自注意力
==============================================================================
    fs (Hz) |       输入样本 |      下采样后 T |     自注意力 GFLOP |    相对 8 kHz
  ------------------------------------------------------------------
       8000 |      80000 |         250 |          0.192 |        1.00x
      16000 |     160000 |         500 |          0.768 |        4.00x
      32000 |     320000 |        1000 |          3.072 |       16.00x
      48000 |     480000 |        1500 |          6.912 |       36.00x
  (自注意力与 T^2 成正比：采样率翻倍 -> T 翻倍 -> 注意力 4 倍)

16 kHz 是 8 kHz 的 4.00 倍，48 kHz 是 36.00 倍。这一项是采样率最贵的成本，也是"为什么没有人用 48 kHz 训练波形 Transformer"的直接答案。

4.4 合成：离散候选上的边际收益/成本比#

把两侧合起来。收益侧用主观质量量级（窄带～宽带～超宽带的常用锚点，仅作量级锚点），成本侧用 C(fs​)=fs​/8000（因为码率、存储、FFT 都正比于 fs​）。逐档算边际比值：

==============================================================================
表 11  信息收益 vs 成本：逐档边际收益/成本比
==============================================================================
   fs (Hz) |   带宽 kHz |    质量 Q |    成本 C |     dQ |     dC |   dQ/dC
  --------------------------------------------------------------------
      8000 |      3.4 |    3.50 |   1.000 |      - |      - |       -
     16000 |      8.0 |    4.20 |   2.000 |   0.70 |  1.000 |   0.700
     22050 |     11.0 |    4.28 |   2.756 |   0.08 |  0.756 |   0.106
     32000 |     14.0 |    4.40 |   4.000 |   0.12 |  1.244 |   0.096
     48000 |     24.0 |    4.50 |   6.000 |   0.10 |  2.000 |   0.050
  门槛「每单位成本至少换到 0.15 单位质量」-> 可接受的最高档 = 16000 Hz
  第一档倍增(8->16 kHz)的比值是其后所有档位的 6.6 倍以上

  音素内容侧的带宽收益（来自表 3 的可分裕度）：
    带宽 4 kHz : 元音裕度 3.45, 擦音裕度 0.38  <- 擦音不可分
    带宽 8 kHz : 元音裕度 2.43, 擦音裕度 2.53  <- 擦音可分

读法：第一档倍增（8→16 kHz）每单位成本换到 0.700 单位质量，其后所有档位都 ≤0.106。若门槛设为"每单位成本至少换到 0.15"，可接受的最高档就是 16 kHz，而且第一档的比值是其后所有档位的 6.6 倍以上——这是一个很宽的拐点，不是毫厘之争。

五、取舍与边界#

(1) 16 kHz 不是普适解。 采样率的下界由"必须可分的音类"决定，而这个集合随任务变化：

任务 关键线索 常见采样率
语音识别（宽带） 擦音、爆破音 16 kHz
电话语音识别 无 4 kHz 以上内容 8 kHz
关键词唤醒 音节能量包络 8 kHz 常够
说话人识别 F4​,F5​、高频谱倾斜 16 kHz（更高仍有收益）
语音合成 合成音的明亮度与自然度 24–48 kHz
音乐 10 kHz 以上的空气感与镲片 44.1/48 kHz

(2) 混叠不可逆，量化可补偿。 这是第一章剩下部分最重要的一条区分：

  • 混叠分量与带内真实信号在同一频点上线性叠加，二者在观测上不可分离。任何线性滤波器都无法恢复；只能靠先验（稀疏性、统计模型）做概率性的部分恢复，且恢复质量随折叠强度迅速下降。
  • 量化误差是加性的、与信号弱相关的，可以用更高位深的重新录制（如果原始模拟信号还在）、多麦克风空间滤波、或降噪模型部分补偿。
  • 因此在数据流水线里，"降采样做过一次就永远回不去"这条规则比"量化位深够不够"重要得多。任何把 48 kHz 语料降到 16 kHz 的操作都必须先做合格的抗混叠滤波；反之，把 16 kHz 语料"上采样"到 48 kHz 不增加任何信息。

(3) 采样与量化可以互换。 由 2.4 节：过采样 OSR 倍 + 一阶噪声整形可以把带内量化噪声降 9log2​OSR dB。所以"fs​ 高一点、b 低一点"在某些硬件上是更经济的选择——这也是 ΔΣ ADC 用 1 bit 比较器做到 20 bit 有效位的原因。

(4) 成本项的权重随系统结构变化。 4.4 节的结论依赖"码率/存储/FFT/注意力都正比于 fs​、权重相同"这个简化。如果：

  • 系统是手工特征 + 轻量声学模型：注意力项不存在，成本主要落在带宽与存储，16 kHz 相对 48 kHz 的优势从 6× 变成更接近 3×，选择会更偏向高采样率；
  • 系统是云端离线批处理：存储便宜、算力充足，成本项权重低，选择也更偏向高采样率；
  • 系统是端侧流式：内存带宽与电量是硬约束，fs​ 的线性项直接进入功耗预算，8 kHz 或 16 kHz 更现实。

(5) 欠采样是合法的，前提是信号是带通的。 对带通信号（中心 fc​、带宽 B），带通采样定理要求 fs​>2B 而不是 2fc​。所以对 4–8 kHz 的带通信号用 fs​=8.4 kHz 是无混叠的。这个技巧在超声与射频里常用，在语音里偶尔用于"只要高频带"的分析。

(6) 奈奎斯特边界附近的病理。 f=fs​/2 处的分量在重构时会与自己的副本相接，结果取决于相位（可能是原样、可能是零、可能幅度减半）。工程上把可用带宽取到 0.45fs​ 而不是 0.5fs​，就是为了避开这一段。

def sine_tab(f, fs, n, phase=0.0):

def max_abs_diff(a, b):
    return max(abs(x - y) for x, y in zip(a, b))

def energy(xs):
    return sum(x * x for x in xs)

def pow_db(p):
    return 10.0 * math.log10(p) if p > 0 else float("-inf")

def fold_freq(f, fs):
    """把任意频率折叠进 [0, fs/2]：f_alias = |f - k*fs|, k = round(f/fs)。"""
    k = math.floor(f / fs + 0.5)
    return abs(f - k * fs), k

VOWELS = {                      # 典型成年男性共振峰 (Hz)，5 个极点
    "a": (730.0, 1090.0, 2440.0, 3400.0, 4000.0),
    "i": (270.0, 2290.0, 3010.0, 3500.0, 4200.0),

    "e": (530.0, 1840.0, 2480.0, 3500.0, 4200.0),
}
FORMANT_BW = (70.0, 100.0, 140.0, 180.0, 220.0)
# 擦音：共享的低频基线 + 类别专属的高频成分。这样构造是为了把
# 「可懂度线索落在 4 kHz 以上还是以下」这一件事单独隔离出来。
FRIC_LOW_FC, FRIC_LOW_BW, FRIC_LOW_LVL = 1500.0, 1400.0, -22.0
FRIC_HIGH = {                   # 类别: (形状, 中心, 带宽, 增益 dB)
    "s":  ("shelf", 4500.0, 500.0, 20.0),
    "sh": ("hump",  3000.0, 700.0, 16.0),
    "f":  ("shelf", 5000.0, 700.0,  8.0),
    "th": ("none",     0.0,   0.0,  0.0),
}
F_GRID = [50.0 * i for i in range(161)]      # 0 .. 8000 Hz, 50 Hz 步长


def formant_env(formants, f, jitter):
    """全极点共振峰包络：每个共振峰归一化到自身峰值为 1，含 ±jitter 扰动。"""
    mag = 0.0
    for k, fi in enumerate(formants):
        bw = FORMANT_BW[k % len(FORMANT_BW)]
        fc = fi * jitter
        r = math.exp(-math.pi * bw / 16000.0)     # 使 -3 dB 带宽 ≈ bw
        th = 2.0 * math.pi * fc / 16000.0
        w = 2.0 * math.pi * f / 16000.0
        a = 1.0 - 2.0 * r * math.cos(th) * math.cos(w) + r * r * math.cos(2.0 * w)
        b = 2.0 * r * math.cos(th) * math.sin(w) - r * r * math.sin(2.0 * w)
        raw = 1.0 / math.sqrt(a * a + b * b)
        a0 = 1.0 - 2.0 * r * math.cos(th) * math.cos(th) + r * r * math.cos(2.0 * th)
        b0 = 2.0 * r * math.cos(th) * math.sin(th) - r * r * math.sin(2.0 * th)
        peak = 1.0 / math.sqrt(a0 * a0 + b0 * b0)
        mag += raw / peak
    return mag


def vowel_spectrum(v, rng):
    jit = 1.0 + rng.uniform(-0.04, 0.04)
    tilt = rng.uniform(-1.5, 1.5)            # 整体谱倾斜 dB
    out = []
    for f in F_GRID:
        m = formant_env(VOWELS[v], f, jit)
        m *= 10.0 ** (tilt * f / 8000.0 / 20.0)
        m *= 10.0 ** (-6.0 * f / 8000.0 / 20.0)   # 声门 + 辐射的 -6dB/oct
        out.append(m * m)                          # 功率
    return out


def fricative_spectrum(c, rng):
    shape, fc0, bw0, gain = FRIC_HIGH[c]
    lvl = FRIC_LOW_LVL + rng.uniform(-2.0, 2.0)
    tilt = rng.uniform(-4.0, 4.0)
    fc = fc0 * (1.0 + rng.uniform(-0.10, 0.10))
    out = []
    for f in F_GRID:
        low = 10.0 ** (FRIC_LOW_LVL / 10.0) * \
            math.exp(-0.5 * ((f - FRIC_LOW_FC) / FRIC_LOW_BW) ** 2)
        if shape == "shelf":
            hi = gain / (1.0 + math.exp(-(f - fc) / bw0))
        elif shape == "hump":
            hi = gain * math.exp(-0.5 * ((f - fc) / bw0) ** 2)
        else:
            hi = 0.0
        p = (low + 1e-6) * 10.0 ** (hi / 10.0)
        p *= 10.0 ** (lvl / 10.0)
        p *= 10.0 ** (tilt * f / 8000.0 / 10.0)   # 每句随机谱倾斜
        out.append(p)
    return out


FRIC_NAMES = ["s", "sh", "f", "th"]


def band_log_energies(spec, f_hi, n_bands):
    """把 100..f_hi 划成 n_bands 个对数间距子带，返回归一化 log 能量。"""
    use = [i for i, f in enumerate(F_GRID) if f <= f_hi]
    lo, hi = 100.0, f_hi
    edges = [lo * (hi / lo) ** (b / n_bands) for b in range(n_bands + 1)]
    vals = []
    for b in range(n_bands):
        e = 0.0
        for i in use:
            f = F_GRID[i]
            if edges[b] <= f < edges[b + 1]:
                e += spec[i] * 50.0
        vals.append(pow_db(max(e, 1e-30)))
    mean = sum(vals) / len(vals)
    return [v - mean for v in vals]         # 逐句电平归一化（等价于 CMVN 的均值项）


def lsd(pa, pb, f_hi):
    """两个平均功率谱在 0..f_hi 上的对数谱距离 (dB, RMS)。"""
    acc, n = 0.0, 0
    for i, f in enumerate(F_GRID):
        if 100.0 <= f <= f_hi:
            d = pow_db(max(pa[i], 1e-30)) - pow_db(max(pb[i], 1e-30))
            acc += d * d
            n += 1
    return math.sqrt(acc / n) if n else float("nan")


def nearest_centroid(train, test):
    classes = sorted(train)
    cents = {}
    for c in classes:
        dim = len(train[c][0])
        cents[c] = [sum(x[d] for x in train[c]) / len(train[c])
                    for d in range(dim)]
    ok = 0
    tot = 0
    for c in classes:
        for x in test[c]:
            best, bd = None, float("inf")
            for c2 in classes:
                d = sum((a - b) ** 2 for a, b in zip(x, cents[c2]))
                if d < bd:
                    best, bd = c2, d
            ok += (best == c)
            tot += 1
    return ok / tot

# 3. 量化：SQNR 公式 vs 实测，μ-law 压扩

def quantize(xs, bits, full_scale=1.0):
    levels = 2 ** bits
    delta = 2.0 * full_scale / levels
    out = []
    for x in xs:
        q = math.floor(x / delta + 0.5) * delta
        out.append(max(-full_scale, min(full_scale - delta, q)))
    return out


def sqnr(xs, ys):
    e = energy([y - x for x, y in zip(xs, ys)])
    return pow_db(energy(xs) / e) if e > 0 else float("inf")


MU = 255.0
def mulaw_c(x):
    return math.copysign(math.log1p(MU * abs(x)) / math.log1p(MU), x)

def mulaw_e(y):
    return math.copysign(((1.0 + MU) ** abs(y) - 1.0) / MU, y)

小结#

  • 采样把频谱以 fs​ 为周期复制；fmax​<fs​/2 时无混叠。违反时的落点由 falias​=∣f−kfs​∣ 精确给出，实测两串样本的最大差只有 1.27×10−13，混叠是不可逆的。
  • 均匀量化的 SQNR=6.02b+1.76 dB 在 b≥6 时实测误差 <1.5 dB，在 b≤2 时失效（−4.24 dB）；量化误差不是白噪声（b=16 时与信号的相关性仍有 −0.018）。
  • μ-law 用满幅信号的 13.9 dB 换取小信号的 +21.6∼+30.9 dB，因为语音不缺大信号的信噪比。
  • 8 kHz 带宽买到的是擦音可分性（类间裕度 0.38→2.53，分类准确率 0.689→1.000），元音在 4 kHz 带宽下就已经可分（1.000→1.000）；4–8 kHz 携带更多的是说话人信息，甚至会让元音裕度略降（3.45→2.43）。
  • 成本侧：16 kHz 相对 8 kHz 在码率/存储/FFT 上是 2×、在波形自注意力上是 4×；相对 48 kHz 是 1/3 与 1/36。边际收益/成本比在第一档倍增后从 0.700 掉到 ≤0.106。
  • 因此 16 kHz 是"擦音可分 + 第一档倍增仍高回报"的交点，而不是一条惯例。
