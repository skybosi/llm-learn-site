字典 dict#

一、概念讲解#

字典（dict）是 Python 里另一个非常常用的数据结构。它和列表、元组不同：列表靠"位置编号"找元素，字典靠"名字"找元素。

可以把字典想象成一本真正的字典：你根据一个"词条"（key，键）去查它对应的"释义"（value，值）。所以字典里的数据总是成对出现的，每一对称为一个"键值对"（key-value pair）。

student = {"name": "小明", "age": 20, "city": "北京"}

上面这个字典里，"name" 是键，"小明" 是值；"age" 是键，20 是值。

1. 字典的特点#

  1. 通过键访问：用 字典[键] 就能拿到对应的值，而不是用数字编号。
  2. 键必须唯一且不可变：同一个字典里不能有两个相同的键；键通常是字符串、整数或元组，列表不能当键。
  3. 可变：可以随时增、删、改键值对。
  4. 查找速度快：无论字典里有多少数据，通过键查找都很快。

2. 访问与修改#

student = {"name": "小明", "age": 20}

print(student["name"])   # 小明

student["age"] = 21      # 修改已有键的值
student["city"] = "北京" # 新增一个键值对
print(student)           # {'name': '小明', 'age': 21, 'city': '北京'}

一个容易踩的坑：如果访问一个不存在的键，用 字典[键] 会直接报错。更安全的做法是用 get 方法，它找不到时返回 None 或你指定的默认值：

student = {"name": "小明"}

# print(student["age"])        # 会报 KeyError
print(student.get("age"))      # 输出 None，不报错
print(student.get("age", 18))  # 输出默认值 18

3. 删除与遍历#

student = {"name": "小明", "age": 20, "city": "北京"}

del student["city"]          # 删除指定键
print(student)

age = student.pop("age")     # 删除并返回该键的值
print(age, student)

遍历字典时，通常用 items() 同时拿到键和值：

student = {"name": "小明", "age": 20, "city": "北京"}
for key, value in student.items():
    print(f"{key} -> {value}")

4. 嵌套结构#

字典的值可以是列表、甚至另一个字典，这样可以表达更复杂的数据：

class_info = {
    "班级": "Python 基础班",
    "学生": ["小明", "小红", "小刚"],
    "老师": {"姓名": "王老师", "教龄": 5},
}
print(class_info["学生"][0])       # 小明
print(class_info["老师"]["姓名"])   # 王老师

二、可运行代码示例#

# ---- 1. 创建字典 ----
phone_book = {
    "小明": "13800001111",
    "小红": "13800002222",
    "小刚": "13800003333",
}
print("通讯录：", phone_book)

# ---- 2. 查询 ----
print("小明的电话：", phone_book["小明"])
print("查一个不存在的人：", phone_book.get("老王", "查无此人"))

# ---- 3. 增加与修改 ----
phone_book["老王"] = "13800004444"   # 新增
phone_book["小明"] = "13800009999"   # 修改
print("更新后：", phone_book)

# ---- 4. 删除 ----
phone_book.pop("小刚")
print("删除小刚后：", phone_book)

# ---- 5. 常用方法 ----
print("所有键：", list(phone_book.keys()))
print("所有值：", list(phone_book.values()))
print("是否包含小明：", "小明" in phone_book)

# ---- 6. 遍历 ----
for name, number in phone_book.items():
    print(f"{name} 的电话是 {number}")

# ---- 7. 统计词频（字典的经典用法）----
text = "apple banana apple orange banana apple"
word_count = {}
for word in text.split():
    word_count[word] = word_count.get(word, 0) + 1
print("词频统计：", word_count)

# ---- 8. 字典推导式 ----
squares = {n: n * n for n in range(1, 6)}
print("1 到 5 的平方表：", squares)

三、练习#

  1. 创建一个字典，存放你自己的信息：姓名、年龄、城市、爱好（爱好可以用列表表示），然后打印其中任意两项。
  2. 用 get 方法安全地查询一个不存在的键，并设置一个友好的默认值（例如"暂无数据"），打印结果。
  3. 写一段代码统计字符串 "红 蓝 红 绿 蓝 红" 中每种颜色出现的次数（提示：用 split() 和 get 配合）。
  4. 思考题：为什么列表不能作为字典的键，而元组可以？提示：想一想字典的键要求"不可变"这个条件。
