类型转换与异常值#

一、概念讲解#

数据清洗的最后两道工序，是把"类型不对的"改对、把"数值离谱的"找出来处理。本课是第 4 章的收尾，也是对前面所有知识的综合运用。

1. 类型转换#

类型问题在第 2 章已接触过，这里做一次"清洗视角"的强化：

  • pd.to_numeric(series, errors="coerce")：字符串转数值，无法解析的转成 NaN，而不是让程序崩溃——这是清洗脏数值列的首选。
  • pd.to_datetime(series, errors="coerce")：把混乱的日期字符串统一成 datetime64。
  • astype(...)：在已经"干净"的类型之间做精确互转。

2. 异常值（outlier）#

异常值是明显偏离其他观测的极端值，可能是录入错误（年龄填成 200），也可能是真实但极端的事件（某天大促销量暴涨）。处理前必须先识别，两种经典方法：

  • IQR 法（四分位距）：计算 Q1、Q3 和 IQR = Q3 − Q1，把落在 [Q1 − 1.5×IQR, Q3 + 1.5×IQR] 之外的值判为异常。它不依赖正态假设，稳健、常用。
  • Z 分数法：z = (x − 均值) / 标准差，把 |z| > 3（或 2）判为异常。它假设数据大致正态，容易受极端值本身影响。

3. 识别之后怎么办#

  • 纠错：确认是录入错误就直接改正。
  • 删除：异常样本极少且无意义时删掉。
  • 裁剪（clip）：df["列"].clip(lower, upper) 把越界值"压"到边界，保留样本但消除极端影响——适合不想丢数据、又想控制极端值的场景。
  • 保留：异常值可能是关键信号（如欺诈、爆款），不能一概抹掉，需要结合业务判断。

二、可运行代码示例#

import pandas as pd
import numpy as np

df = pd.DataFrame({
    "价格": ["100", "200", "abc", "150", "9999"],  # 混入非法字符串和极端值
    "销量": [10, 12, 15, 11, 120],                # 120 是明显异常值
})
print("原始数据：\n", df)

# 1. 类型转换：非法字符串 -> NaN
df["价格"] = pd.to_numeric(df["价格"], errors="coerce")
print("\n价格转数值（'abc' 变成 NaN）：\n", df)

# 2. 日期转换
s = pd.Series(["2024-01-01", "2024/06/15", "not-a-date"])
dt = pd.to_datetime(s, errors="coerce")
print("\n日期转换：\n", dt)

# 3. IQR 法识别销量异常值
q1 = df["销量"].quantile(0.25)
q3 = df["销量"].quantile(0.75)
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print("\nIQR 边界：", (lower, upper))
outliers = df[(df["销量"] < lower) | (df["销量"] > upper)]
print("IQR 判定的异常值：\n", outliers)

# 4. Z 分数法识别异常值
mean, std = df["销量"].mean(), df["销量"].std()
z = (df["销量"] - mean) / std
print("\nZ 分数：\n", z)
print("|z| > 2 的异常值：\n", df[np.abs(z) > 2])

# 5. 裁剪：把销量压到 IQR 边界内
df["销量_裁剪"] = df["销量"].clip(lower=lower, upper=upper)
print("\nclip 裁剪后：\n", df)

注意 9999 和 120 两种极端值：IQR 法和 Z 分数法都能把它们标记出来；而 clip 则是"不删数据、只削极端"的温和处理。

三、练习#

  1. 对一列混有非法字符的数字字符串用 to_numeric(errors="coerce") 转换，统计产生了多少个 NaN，并思考这些 NaN 后续该如何处理（呼应第 1 课）。
  2. 手写一遍 IQR 法：给定一列数值，计算 Q1、Q3、IQR 和上下边界，筛出落在边界外的异常值。
  3. 对含异常值的列分别用"删除异常值"和"clip 裁剪"两种方式处理，比较处理后数据的行数和极值范围，说明各自的适用场景。
