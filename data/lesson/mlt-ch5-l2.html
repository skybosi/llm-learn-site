梯度下降为何收敛#

上一课我们建立了凸性的语言，知道凸函数是一口"碗"。但"碗"只保证目标存在且唯一，它不保证你用梯度下降能走到碗底。本课要回答一个更硬的问题：为什么"沿负梯度走一步"这件事，能让函数值单调下降，并且最终逼近最小值？收敛有多快？步长取多大才安全？ 这些问题都有精确的数学答案，答案的骨架就是两个常数：利普希茨常数 L（光滑度） 和 强凸常数 μ。

一、概念讲解（含推导）#

1. 先问"为什么"：为什么是负梯度方向？#

梯度下降的迭代式是 xk+1​=xk​−η∇f(xk​)。为什么偏偏是"负梯度"，而不是别的方向？我们从第一性原理推导。

在点 x 处，沿单位方向 v（∥v∥=1）的方向导数是 f 在该方向的瞬时变化率：

Dv​f(x)=∇f(x)Tv.

由柯西-施瓦茨不等式 ∇f(x)Tv≥−∥∇f(x)∥∥v∥=−∥∇f(x)∥，且等号在 v=−∇f(x)/∥∇f(x)∥ 时取到。也就是说：在所有单位方向中，负梯度方向让函数下降得最快。所以"沿负梯度走"不是一种约定，而是"一阶近似下最贪心、最陡的下坡方向"这一事实的直接推论。

2. L-光滑：梯度不会"突变"#

要证明收敛，必须先给损失函数一个"脾气不太坏"的假设。称可微函数 f 是 L-光滑（L-smooth，也称梯度 L-利普希茨连续），若对所有 x,y：

∥∇f(x)−∇f(y)∥≤L∥x−y∥.

直观：梯度的变化速度有上界 L，函数不会突然陡峭得没边。这个条件等价于一条上下界控制式（对可微 f）：

f(y)≤f(x)+∇f(x)T(y−x)+2L​∥y−x∥2.

它说：函数值永远被"一阶泰勒展开 + 一个二次上界"压住。这条式子就是收敛证明的全部钥匙，称为下降引理的准备形式。

3. 下降引理：走一步，必然下降#

把迭代 y=x−η∇f(x) 代入上式：

f(xk+1​)≤f(xk​)+∇f(xk​)T(−η∇f(xk​))+2L​​η∇f(xk​)​2

=f(xk​)−η∥∇f(xk​)∥2+2Lη2​∥∇f(xk​)∥2=f(xk​)−η(1−2Lη​)∥∇f(xk​)∥2.

=f(xk​)−η∥∇f(xk​)∥2+2Lη2​∥∇f(xk​)∥2=f(xk​)−η(1−2Lη​)∥∇f(xk​)∥2.

=f(xk​)−η∥∇f(xk​)∥2+2Lη2​∥∇f(xk​)∥2=f(xk​)−η(1−2Lη​)∥∇f(xk​)∥2.

这就是下降引理。只要括号内系数为正，即

0<η<L2​​,

就有 f(xk+1​)≤f(xk​)−c∥∇f(xk​)∥2，其中 c>0。于是：

  1. 函数值单调不增，且只要梯度非零就严格下降；
  2. 把 k=0 到 K−1 的不等式累加（望远镜求和），再除以 K，得到平均梯度范数的界：

K1​k=0∑K−1​∥∇f(xk​)∥2≤cKf(x0​)−f(x∗)​.

K1​k=0∑K−1​∥∇f(xk​)∥2≤cKf(x0​)−f(x∗)​.

这说明：梯度的平均平方以 O(1/K) 速度趋于 0。特别地，若取经典步长 η=1/L，则 c=1/(2L)。因此只要 f 有下界（有最小值），梯度下降就"在平均意义下"收敛到平稳点 ∇f=0。对凸函数，平稳点就是全局最小点。

结论：收敛的根本原因不是"运气"，而是 L-光滑给了损失函数一个二次上界，把这个上界最小化恰好就是梯度下降——每一步都在压这个上界，从而必然下压真实函数值。

4. 强凸：收敛"有多快"由条件数决定#

"最终会到"还不够，我们想知道多快。为此再补一个更强的假设。称 f 是 μ-强凸，若 f(x)−2μ​∥x∥2 仍是凸函数，等价地：

f(y)≥f(x)+∇f(x)T(y−x)+2μ​∥y−x∥2.

强凸 = 函数比线性近似"再向上凸起一块" = 碗有真实的曲率下限 μ。

结合 L-光滑与 μ-强凸，可以证明梯度下降（步长 η≤2/L）满足：

∥xk+1​−x∗∥2≤(1−ημ(2−ηL))∥xk​−x∗∥2,

∥xk+1​−x∗∥2≤(1−ημ(2−ηL))∥xk​−x∗∥2,

取最优步长 η=1/L 时收缩因子为 1−μ/L。定义条件数 κ=L/μ≥1，则

f(xk​)−f(x∗)≤(1−κ1​)k(f(x0​)−f(x∗))​

f(xk​)−f(x∗)≤(1−κ1​)k(f(x0​)−f(x∗))​

这就是线性收敛：每步按固定比例 (1−1/κ) 缩小误差。κ 越接近 1（碗越"圆"），收敛越快；κ 越大（碗越"扁长"），收敛越慢。这就是"条件数"三个字在优化语境下的全部含义。

5. 一个完全可算的例子：二次函数#

设 f(x)=21​xTQx，Q 对称正定，其特征值 μ=λmin​,L=λmax​。它同时是 L-光滑和 μ-强凸的，κ=λmax​/λmin​。此时的梯度下降 xk+1​=xk​−ηQxk​=(I−ηQ)xk​ 是可精确求解的，误差沿每个特征方向按 (1−ηλi​) 衰减，最慢的方向是 λmin​，最快的约束是 λmax​。整条收敛曲线完全由这些特征值决定——这是"几何与线性代数视角"最干净的体现，下面的代码会验证它。

二、验证性代码示例#

下面用二维二次函数数值验证三个结论：① 步长 0<η<2/L 时收敛、η≥2/L 时发散；② 误差按 1−μ/L 的比例线性衰减；③ 条件数越大收敛越慢。

import numpy as np

def make_quadratic(L, mu):
    """构造 Hessian 特征值为 [L, mu] 的二次函数，条件数 kappa = L/mu"""
    Q = np.diag([L, mu])            # 特征值就是 L 与 mu
    def f(x):
        return 0.5 * x @ Q @ x
    def grad(x):
        return Q @ x
    return f, grad, Q

def run_gd(L, mu, eta, steps=200):
    f, grad, Q = make_quadratic(L, mu)
    x = np.array([1.0, 1.0])        # 初始点
    errs = []
    for _ in range(steps):
        x = x - eta * grad(x)
        errs.append(f(x))
    return errs, x

# ---------- 1) 步长阈值验证 ----------
L, mu = 10.0, 2.0                    # kappa = 5
eta_safe = 1.0 / L                   # 经典步长
eta_big  = 2.0 / L + 1e-3            # 略超 2/L 的阈值

err_safe, x_safe = run_gd(L, mu, eta_safe)
err_big,  x_big  = run_gd(L, mu, eta_big, steps=30)
print(f"eta=1/L   收敛到 x={np.round(x_safe,6)}, f={err_safe[-1]:.2e}")
print(f"eta>2/L   发散, f={err_big[-1]:.2e}  (爆炸)")

# ---------- 2) 线性收敛速率 = (1 - mu/L) ----------
theo_rate = 1 - mu / L
emp_rate  = (err_safe[-1] / err_safe[0]) ** (1 / len(err_safe))
print(f"理论每步收缩因子 1-mu/L = {theo_rate:.4f}")
print(f"实测每步收缩因子       = {emp_rate:.4f}")

# ---------- 3) 条件数越大越慢 ----------
for (Lc, muc) in [(10, 8), (10, 2), (10, 0.2)]:   # kappa=1.25 / 5 / 50
    errs, _ = run_gd(Lc, muc, eta=1.0/Lc, steps=400)
    kappa = Lc / muc
    print(f"kappa={kappa:6.1f}  400步后误差 f={errs[-1]:.2e}")

运行结果大致为：

eta=1/L   收敛到 x=[0. 0.], f=1.72e-39
eta>2/L   发散, f=9.08e+00  (爆炸)
理论每步收缩因子 1-mu/L = 0.8000
实测每步收缩因子       = 0.6414
kappa=   1.2  400步后误差 f=0.00e+00
kappa=   5.0  400步后误差 f=2.96e-78
kappa=  50.0  400步后误差 f=9.57e-09

注意第 2 组：理论值与实测值测的不是同一个量。1−μ/L=0.8 是参数误差 ∥xk​−x∗∥ 的每步收缩比；而代码里 errs.append(f(x)) 记录的是函数值，对二次函数 f 而言函数值是参数误差的二次量，所以按它的平方 (1−μ/L)2=0.64 收缩。实测 0.6414 正好落在 0.64 上——说明最慢特征方向（μ 方向）的衰减已被渐近取到。第 3 组里 κ=50（碗极扁）时 400 步还没完全收敛，而 κ=5 早就归零，直观印证了"条件数决定收敛速度"。

母原理连接#

本课是母原理 1（一切学习 = 优化一个目标函数） 的核心定理层：它把"优化"从一句口号变成可证明、可计算的事实——只要损失函数满足 L-光滑（或许再加 μ-强凸），梯度下降就必然下降并线性收敛，速率由条件数 κ=L/μ 决定。同时，二次函数那个例子又强烈呼应母原理 5（几何与线性代数视角）：收敛的每一步，本质都是误差向量在 Hessian 的特征方向上的独立衰减。你日后看到"学习率太大就发散""特征没归一化训练就慢"，本质都是 η 与 L、κ 的关系。
