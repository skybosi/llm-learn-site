REINFORCE#

策略梯度定理给出了 ∇J(θ) = E[ ∇log π(A|S) · Q^π(S,A) ]，但 Q^π 还不知道。最朴素的做法：用整条轨迹采到的真实回报 G_t 去顶替 Q^π(S_t, A_t)。这就是 REINFORCE（也叫 Monte Carlo Policy Gradient / Vanilla Policy Gradient）。本课讲清它的更新式、方差问题，以及baseline 为什么不改变期望却能降方差。

一、概念讲解#

1. 用 G_t 顶替 Q^π：蒙特卡洛策略梯度#

把定理里的期望换成采样，并把 Q^π(S_t, A_t) 换成它的无偏样本——从 t 时刻起真实的折扣回报：

G_t = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + ...

由于 E[G_t | S_t, A_t] = Q^π(S_t, A_t)，代入后仍是真实梯度的无偏估计。于是 REINFORCE 的更新就是：

θ ← θ + α · G_t · ∇_θ log π(A_t | S_t; θ)

一句话：跑一条完整轨迹 → 对每个时刻 t 算 G_t → 沿"让 A_t 更可能"的方向，用 G_t 加权走一步梯度上升。因为 G_t 来自蒙特卡洛（走完全程），所以 REINFORCE 也继承了 MC 的脾气：无偏、高方差、必须等 episode 结束。

2. 高方差是最大的敌人#

G_t 攒齐了从 t 到结束的所有随机性，方差很大；方差大意味着梯度方向抖得厉害、收敛慢，需要大量样本。降方差是策略梯度方法的永恒主题，最经典的一招就是减 baseline。

3. baseline：减一个"只依赖状态"的数（推导其无偏性）#

把更新改成：

θ ← θ + α · ( G_t - b(S_t) ) · ∇_θ log π(A_t | S_t; θ)

其中 b(S_t) 是一个只依赖状态、不依赖动作的函数（常见取价值函数 V(S_t) 的估计）。关键问题是：多减的这个 b(S_t) 会不会让梯度有偏？答案是不会。看它对期望的影响：

E[ b(S) · ∇log π(A|S) ] = b(S) · E[ ∇log π(A|S) ]        (b 不依赖 A，可提出)
                         = b(S) · Σ_a π(a|S) ∇log π(a|S)
                         = b(S) · ∇ Σ_a π(a|S)            (似然比技巧反用)
                         = b(S) · ∇ 1 = 0

Σ_a π(a|S) = 1 恒成立，所以它的梯度恒为 0。期望层面 baseline 被完全抵消，梯度仍无偏；但在单次采样层面，b(S_t) 削掉了回报里"状态本身好坏"那一大块共同的波动，只留下"这个动作相对平均好多少"，方差显著下降。这就是 baseline 的魔力：免费降方差。

4. 完整算法#

  1. 初始化策略参数 θ（以及 baseline 参数 w，若用可学习的 b）。
  2. 每个 episode：按当前策略 π_θ 跑一整条轨迹，收集 (S_t, A_t, R_{t+1})。
  3. 从后往前算出每个时刻的 G_t。
  4. 计算优势 δ_t = G_t - b(S_t)。
  5. 策略更新：θ ← θ + α Σ_t δ_t ∇log π(A_t|S_t; θ)。
  6. （若 baseline 可学习）用 δ_t 去拟合 b，如 w ← w + β Σ_t δ_t ∇_w b(S_t)。

补充两个常用降方差技巧：回报标准化（把一条轨迹里的 G_t 减均值除标准差）、折扣因子 γ<1（截断远期随机性）。它们与 baseline 正交，可叠加。

二、可运行代码示例#

用 NumPy 手写 REINFORCE（带线性 baseline），跑自包含的 CartPole。

import numpy as np

# ---- 自包含 CartPole（简化倒立摆物理） ----
GRAVITY, MASS_CART, MASS_POLE = 9.8, 1.0, 0.1
LENGTH, FORCE, DT = 0.5, 10.0, 0.02
MAX_STEPS = 500                    # 单回合步数上限，与 gym CartPole 一致

def reset():
    return np.array([0.0, 0.0, 0.05 * (np.random.rand() - 0.5), 0.0])

def step(s, a):
    x, xd, th, thd = s
    force = FORCE if a == 1 else -FORCE
    total = MASS_CART + MASS_POLE
    cos_t, sin_t = np.cos(th), np.sin(th)
    temp = (force + MASS_POLE * LENGTH * thd**2 * sin_t) / total
    th_acc = (GRAVITY * sin_t - cos_t * temp) / (LENGTH * (4/3 - MASS_POLE * cos_t**2 / total))
    x_acc = temp - MASS_POLE * LENGTH * th_acc * cos_t / total
    x, xd = x + DT * xd, xd + DT * x_acc
    th, thd = th + DT * thd, thd + DT * th_acc
    return np.array([x, xd, th, thd]), 1.0, abs(x) > 2.4 or abs(th) > 0.2095

def phi(s):
    # 特征：偏置 + 归一化后的 4 个观测。归一化让各分量尺度接近，利于线性策略学习
    return np.concatenate([[1.0], [s[0] / 2.4, s[1] / 3.0, s[2] / 0.21, s[3] / 3.0]])

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

def policy(theta, s):
    z = np.array([theta[0] @ phi(s), theta[1] @ phi(s)])   # 两个动作各一个分数
    return softmax(z)

def grad_log_pi(theta, s, a):
    p = policy(theta, s)                       # (2,)
    g = np.zeros_like(theta)                   # (2, D)
    g[a] = (1 - p[a]) * phi(s)                 # 选中动作：+（1-π）
    for b in range(2):
        if b != a:
            g[b] = -p[b] * phi(s)              # 其他动作：-π
    return g

# ---- REINFORCE（带 baseline）----
np.random.seed(0)
D = len(phi(reset()))
theta = np.random.randn(2, D) * 0.1            # 策略参数
w = np.zeros(D)                                # 线性 baseline：b(s) = wᵀφ(s)
ALPHA, BETA, GAMMA = 1e-2, 1e-2, 0.99
scores = []

for ep in range(300):
    s, done, step_count = reset(), False, 0
    states, actions, rewards = [], [], []
    while not done and step_count < MAX_STEPS:
        p = policy(theta, s)
        a = int(np.random.choice(2, p=p))
        states.append(s); actions.append(a)
        s, r, done = step(s, a)
        rewards.append(r)
        step_count += 1

    # 从后往前算折扣回报 G_t
    G = np.zeros(len(rewards)); running = 0.0
    for t in reversed(range(len(rewards))):
        running = rewards[t] + GAMMA * running
        G[t] = running
    G = (G - G.mean()) / (G.std() + 1e-8)      # 回报标准化（常用降方差技巧）

    for t in range(len(states)):
        delta = G[t] - w @ phi(states[t])      # 优势 = 回报 - baseline
        theta += ALPHA * delta * grad_log_pi(theta, states[t], actions[t])
        w += BETA * delta * phi(states[t])     # baseline 朝回报拟合
    scores.append(step_count)
    if (ep + 1) % 20 == 0:
        print("回合 {:3d}  近20回合平均步数 {:.0f}".format(ep + 1, np.mean(scores[-20:])))

print("训练完成，最后一回合步数：{:.0f}".format(scores[-1]))

要点：grad_log_pi 里"选中动作 +（1-π）、其他动作 -π"正是 softmax 的梯度结构；w @ phi(states[t]) 是可学习 baseline，它在期望上不影响梯度方向，却显著压低了更新方差。运行后近 20 回合平均步数会从随机策略的约 20 步稳步爬升到 150~300 步（REINFORCE 方差较大，不同随机种子略有差异）——这正是"策略梯度直接优化策略"的效果。

三、练习#

  1. 把 baseline 去掉（delta = G[t]），重跑，对比近 20 回合平均步数的波动幅度，直观感受方差差异。
  2. 关掉回报标准化（删掉 G = (G - G.mean())... 一行），观察是否还能学得动；若震荡，把 ALPHA 调小再试。
  3. 把 GAMMA 从 0.99 改成 0.9、1.0，观察对最终得分与稳定性的影响，解释折扣的作用。
  4. 思考题：严格证明"减 baseline 无偏"时，哪一步用到了"baseline 只依赖状态、不依赖动作"这个条件？如果 b 也依赖 A_t，结论还成立吗？
