指数平滑#

ARIMA 从"自相关结构"出发建模，而指数平滑走的是另一条更直觉的路线：对过去观测加权平均，越近的观测权重越大。它没有显式的概率模型作前提，却极其好用、计算便宜，是很多业务基线预测的首选。这一课从最简的 SES 一路推到带趋势和季节的 Holt–Winters，并说清它和 ARIMA 的深层联系。

一、概念讲解#

1. 简单指数平滑 SES：一个递推就够#

简单指数平滑（Simple Exponential Smoothing, SES）只适用于没有趋势、没有季节的序列。它的预测公式是一个递推：

ŷ_{t+1|t} = α·y_t + (1 − α)·ŷ_{t|t−1}

读作"下一期预测 = 平滑系数 α × 最新观测 + (1−α) × 上一期预测"。α 在 0 到 1 之间：α 大，预测紧跟最新观测（反应快、波动大）；α 小，预测平滑、抗噪声但反应慢。

为什么叫"指数"平滑？把递推反复代入自身：

ŷ_{t+1|t} = α·y_t + α(1−α)·y_{t-1} + α(1−α)²·y_{t-2} + α(1−α)³·y_{t-3} + ...

预测值其实是所有历史观测的加权平均，权重按 α(1−α)^k 呈几何（指数）衰减：越老的数据权重越小，但永远不会严格等于 0。这就是"指数平滑"名字的由来，也是它和"只取最近 k 期的简单移动平均"的本质区别——简单移动平均给窗内所有点相同权重、窗外权重硬切断，而指数平滑是连续衰减。

α 的选择：实务上由数据估计（最小化一步预测误差平方和 SSE），或用 statsmodels 自动优化。初值 ŷ_{1|0} 通常取序列开头的观测或前几期平均。

2. Holt：加上趋势#

SES 假设水平不变，遇到有趋势的序列就会系统性落后（预测总比实际低一截）。Holt 线性趋势法引入两个分量和两个平滑参数：

水平：   ℓ_t = α·y_t + (1 − α)·(ℓ_{t-1} + b_{t-1})
趋势：   b_t = β·(ℓ_t − ℓ_{t-1}) + (1 − β)·b_{t-1}
预测：   ŷ_{t+h|t} = ℓ_t + h·b_t

其中 ℓ_t 是当前水平（截距），b_t 是当前趋势（斜率）。预测时把斜率 b_t 外推 h 期。两个平滑参数 α、β 分别控制"水平"和"趋势"更新的快慢。

更进一步可加阻尼趋势（damped trend）：ŷ_{t+h|t} = ℓ_t + (φ + φ² + ... + φ^h)·b_t，让远期趋势逐渐"踩刹车"收敛到一个上限。很多实证表明阻尼趋势能显著改善长期预测，因为它避免了斜率无限外推导致的离谱结果。

3. Holt–Winters：再加上季节#

序列同时有趋势和季节时，用 Holt–Winters 法，在水平和趋势之外增加季节分量 s_t，并引入第三个平滑参数 γ。依季节组合方式分为两类：

加性季节（季节波动幅度恒定）：

水平：  ℓ_t = α·(y_t − s_{t−m}) + (1 − α)·(ℓ_{t-1} + b_{t-1})
趋势：  b_t = β·(ℓ_t − ℓ_{t-1}) + (1 − β)·b_{t-1}
季节：  s_t = γ·(y_t − ℓ_t) + (1 − γ)·s_{t−m}
预测：  ŷ_{t+h|t} = ℓ_t + h·b_t + s_{t+h−m}

乘性季节（季节波动随水平放大）：

水平：  ℓ_t = α·(y_t / s_{t−m}) + (1 − α)·(ℓ_{t-1} + b_{t-1})
季节：  s_t = γ·(y_t / ℓ_t) + (1 − γ)·s_{t−m}
预测：  ŷ_{t+h|t} = (ℓ_t + h·b_t)·s_{t+h−m}

这里的 m 是季节周期（月度数据 m=12，周数据 m=7）。注意季节分量的更新用了 s_{t−m}：今天的季节分量，是用上个季节周期同一位点的分量加上新信息平滑而来，所以季节本身可以缓慢演化，而不是每年固定不变。

4. ETS 状态空间框架：和 ARIMA 打通#

把上面的方法统一进一个框架，就是 ETS 模型，名字来自三个字母：Error（误差，加性 A 或乘性 M）、Trend（趋势，无/加性/阻尼）、Seasonal（季节，无/加性/乘性）。例如 "M,A,M" 表示"乘性误差、加性趋势、乘性季节"。

ETS 的关键价值在于，它给指数平滑套上了显式的概率状态空间模型，于是可以：

  • 计算似然、做参数估计与模型选择（AIC）；
  • 给出预测区间，而不仅是点预测；
  • 和 ARIMA 建立对应关系：例如"带漂移的 SES"等价于 ARIMA(0,1,1)，"Holt 线性趋势"等价于 ARIMA(0,2,2)。两套语言描述的是同一族模型的不同侧面。

什么时候选指数平滑、什么时候选 ARIMA？没有绝对答案。经验上：序列模式简单（水平/趋势/季节清晰）、样本不多时，指数平滑稳定且解释直观；需要利用自相关结构、协变量、或做严谨的残差诊断与统计推断时，ARIMA 更合适。第 3 课会给出用 AIC 等方法在两者之间做取舍的具体流程。

二、可运行示例#

对同一条"趋势 + 季节"序列，从 SES 一路升级到 Holt–Winters，对比效果。

import numpy as np
import pandas as pd
from statsmodels.tsa.holtwinters import SimpleExpSmoothing, ExponentialSmoothing

# 构造带线性趋势和年度季节（周期 12）的序列
idx = pd.date_range("2019-01-01", periods=72, freq="MS")
n = len(idx)
rng = np.random.default_rng(5)
y = 100 + 1.5 * np.arange(n) + 10 * np.sin(2 * np.pi * np.arange(n) / 12) \
    + rng.normal(0, 3, size=n)
series = pd.Series(y, index=idx)

# 1) 简单指数平滑（忽略趋势与季节，作为对照）
ses = SimpleExpSmoothing(series).fit()
print("SES 平滑系数 alpha =", round(ses.model.params["smoothing_level"], 3))

# 2) Holt 线性趋势（trend='add'，不带季节）
holt = ExponentialSmoothing(series, trend="add", seasonal=None).fit()
print("Holt 水平 alpha / 趋势 beta =",
      round(holt.model.params["smoothing_level"], 3),
      round(holt.model.params["smoothing_trend"], 3))

# 3) Holt–Winters 加性季节（trend='add', seasonal='add', 周期 12）
hw_add = ExponentialSmoothing(
    series, trend="add", seasonal="add", seasonal_periods=12
).fit()
print("Holt–Winters 季节 gamma =",
      round(hw_add.model.params["smoothing_seasonal"], 3))

# 4) 对比三种模型对最后 12 期的一步预测误差（样本内拟合）
def in_sample_sse(fit):
    resid = series - fit.fittedvalues
    return float((resid ** 2).sum())

print("\n样本内 SSE 对比：")
print("SES            =", round(in_sample_sse(ses), 1))
print("Holt           =", round(in_sample_sse(holt), 1))
print("Holt–Winters   =", round(in_sample_sse(hw_add), 1))

因为这条序列同时有趋势和季节，你会看到误差按 SES → Holt → Holt–Winters 递减——把该有的分量都建模进去，误差自然下降。

再做一次 12 期预测，并读取预测区间：

# 用 Holt–Winters 预测未来 12 期
forecast = hw_add.forecast(12)
print("\n未来 12 期预测：", np.round(forecast.values, 1))

# 用 ETSModel 可以直接拿到预测区间（statsmodels 新版接口）
from statsmodels.tsa.exponential_smoothing.ets import ETSModel
ets = ETSModel(series, error="add", trend="add", seasonal="add",
               seasonal_periods=12).fit()
pred = ets.get_prediction(start=len(series), end=len(series) + 11)
print("80% 预测区间下界：", np.round(pred.pred_int(alpha=0.2).iloc[:, 0].values, 1))

三、练习#

  1. 把示例序列的 seasonal_periods 改成 4 再拟合，观察季节分量周期变化对预测的影响；若周期设错（比如设成 6）会发生什么？
  2. 生成一条乘性季节序列（季节是比例、波动随趋势放大），分别用 seasonal="add" 和 seasonal="mul" 拟合，比较样本内 SSE，说明哪种更合适。
  3. 手写推导：从 SES 递推 ŷ_{t+1|t} = α·y_t + (1−α)·ŷ_{t|t−1} 展开，证明它是历史观测的加权平均，且权重和为 1。
  4. 思考：α 接近 0 和接近 1 时，SES 各像什么？为什么说"α 小 → 相当于更长的移动平均"？
