梯度与雅可比矩阵#

前面五章都在讲"矩阵如何作用在向量上"。这一章换一个角度：把向量和矩阵当作变量，问"函数对它们的变化有多敏感"。答案就是梯度和雅可比矩阵——它们是深度学习中"训练"二字的数学底座：梯度指向函数增长最快的方向，沿它的反方向走，就是梯度下降。

一、概念讲解#

1. 标量函数对向量的梯度#

设 f(x) 是以向量 x=(x1​,…,xn​) 为输入的标量函数（比如损失函数）。f 对 x 的梯度是一个向量，每个分量是 f 对对应分量的偏导数：

∇f(x)=(∂x1​∂f​,∂x2​∂f​,…,∂xn​∂f​)

几何上，梯度指向 f 增长最快的方向，其模长等于该方向上的最大增长率。训练神经网络时，我们沿着负梯度方向更新参数，让损失逐步下降。

2. 两个最常用的梯度公式#

  • 线性函数 f(x)=aTx=∑i​ai​xi​：梯度是 ∇f=a。
  • 二次型 f(x)=xTAx（A 对称）：梯度是 ∇f=2Ax。

这两个公式贯穿了整个机器学习：线性回归的损失、正则化项、二次优化目标，都能归结到它们。

3. 向量函数对向量的导数：雅可比矩阵#

如果函数本身也是向量 F(x)=(f1​(x),…,fm​(x))，那么它对 x 的导数不再是单个向量，而是一个 m×n 矩阵，叫雅可比矩阵（Jacobian）：

Jij​=∂xj​∂fi​​

每一行是某个输出分量对所有输入的偏导数，每一列是某个输入对所有输出的影响。雅可比是"多元链式法则"和神经网络反向传播的基础构件。

4. 二阶信息：海森矩阵（简介）#

梯度的"变化率"再求一次导，得到海森矩阵（Hessian），它是一个 n×n 对称矩阵 Hij​=∂xi​∂xj​∂2f​。海森矩阵描述了函数局部的曲率，在判断极值、牛顿法和优化收敛速度分析中用到。对很多模型，海森矩阵还是对称的——正好接上上一章的特征分解。

二、可运行代码示例#

import numpy as np

# ---- 例 1：梯度计算与数值验证 ----
# f(x) = x1^2 + 3 x2^2，解析梯度 = [2x1, 6x2]
def f(x):
    return x[0]**2 + 3*x[1]**2

def grad_analytic(x):
    return np.array([2*x[0], 6*x[1]])

def grad_numeric(f, x, h=1e-5):
    g = np.zeros_like(x)
    for i in range(len(x)):
        xp = x.copy(); xm = x.copy()
        xp[i] += h; xm[i] -= h
        g[i] = (f(xp) - f(xm)) / (2*h)   # 中心差分
    return g

x = np.array([1.5, -2.0])
print("解析梯度 =", grad_analytic(x))
print("数值梯度 =", grad_numeric(f, x))

# ---- 例 2：雅可比矩阵 ----
# F(x) = [x1^2 + x2, x1 * x2]^T
def F(x):
    return np.array([x[0]**2 + x[1], x[0]*x[1]])

def jac_analytic(x):
    return np.array([[2*x[0], 1.0],
                     [x[1],    x[0]]])

def jac_numeric(F, x, h=1e-5):
    n = len(x); m = len(F(x))
    J = np.zeros((m, n))
    for i in range(n):
        xp = x.copy(); xm = x.copy()
        xp[i] += h; xm[i] -= h
        J[:, i] = (F(xp) - F(xm)) / (2*h)
    return J

x = np.array([2.0, 3.0])
print("解析雅可比 =\n", jac_analytic(x))
print("数值雅可比 =\n", jac_numeric(F, x))

# ---- 例 3：梯度下降（训练的最小雏形） ----
# 最小化 f(x) = (x1-1)^2 + (x2+2)^2，最小值在 (1, -2)
def loss(x):
    return (x[0]-1)**2 + (x[1]+2)**2
def grad(x):
    return np.array([2*(x[0]-1), 2*(x[1]+2)])

x = np.array([0.0, 0.0])
lr = 0.1
for _ in range(50):
    x = x - lr * grad(x)
print("梯度下降结果 x =", x)   # 逼近 (1, -2)

要点：例 1、例 2 用"中心差分"做数值微分，是验证解析梯度是否正确的标准手段——在深度学习框架里，反向传播写错了，第一件事就是用数值梯度比对。

三、练习#

  1. 推导：求 f(x)=x12​+2x1​x2​+3x22​ 的梯度（可写成 xTAx 形式再用公式）。
  2. 验证：对 f(x)=aTx 取 a=(1,2,3)，分别手算和用代码验证梯度等于 a。
  3. 代码：把例 3 的学习率分别改成 0.01、1.5，观察梯度下降是变慢还是发散，体会学习率的作用。
  4. 思考：为什么梯度下降要沿"负梯度"方向走？沿正梯度方向走会发生什么？
