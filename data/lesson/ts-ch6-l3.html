结果评估与复盘#

上一课我们跑通了流水线，拿到了 MAE、RMSE 两个数字。但一个数字远远不够：它比基线好吗？误差是随机的还是系统性的？模型会在某些时段明显失灵吗？这一课我们把"评估"这件事做深——不只算指标，还要做误差诊断、回测验证、与基线对比，最后做一次结构化的复盘，把一个"能跑"的项目变成一个"可信赖"的项目。

一、概念讲解#

1. 指标各有性格，要组合使用#

单一指标会骗人。几个常用指标的"性格"：

  • MAE：误差绝对值的平均。对异常值不敏感，量纲直观，是"平均偏差"的稳健度量；
  • RMSE：先平方再开方，对大误差平方放大。它更"记仇"——偶尔一次大偏差会把 RMSE 顶得很高。适合"大错代价极高"的场景（如电力负荷预测里一次尖峰预测失败）；
  • MAPE：绝对百分比误差的平均。量纲无关、便于跨序列比较，但目标值接近 0 时会爆炸，且对"低估"和"高估"的惩罚不对称；
  • sMAPE：对称化的百分比误差，把分母改成"真实值+预测值"的均值，缓解了 MAPE 的不对称，但目标接近 0 仍不稳。

工程上的正确姿势是报一组指标（如 MAE + RMSE + sMAPE），并附上它们的业务含义。永远不要只挑最好看的那个报。

2. 误差诊断：看图比看数更重要#

把预测值和真实值画在同一张图上，往往一眼能看出数字掩盖的问题：

  • 相位错位：预测曲线形状对，但整体平移了一天。说明模型在"跟"但没"跟上"，可能是滞后特征没做好；
  • 峰值系统性偏低：尖峰总被低估，说明模型对突变不敏感（MAE 可能还好，RMSE 会很差）；
  • 误差随时间放大：预测步长越远误差越大，这是多步预测的固有规律，需要量化"每步的误差增长曲线"；
  • 某段持续失灵：节假日、促销期误差飙升，提示需要额外的协变量或分段建模。

把这些观察记下来，是复盘的原材料。

3. 回测：模拟真实部署的"试运行"#

单次测试集评估只能给一个点估计。更可信的是回测（backtesting）：用一个滚动窗口，反复"用截至 T 的数据训练、预测 T+1..T+H、再前进一格重来"。它模拟了模型上线后持续更新的真实场景，能得到误差的分布（均值、分位数、最坏情况），而不是一个点。代价是计算量大，但这是判断"模型能否长期稳定"的关键证据。

4. 与基线对比：没有参照的精度无意义#

任何模型的结果都要和至少一个基线同台比较。最简单的基线是 naive（用昨天预测今天）或季节性 naive（用上周同期预测）。复杂的深度学习模型如果打不过季节性 naive，说明它没有学到比"记住周期"更多的信息——要么数据本身太简单，要么模型没训好。这个对比在复盘中必须写清楚，它直接决定"这个模型值不值得上线"。

5. 复盘：把经验沉淀成下次的起点#

复盘不是写"我做了啥"，而是回答三个问题：

  • 什么有效？ 哪个特征、哪个模型、哪个技巧真正带来了提升？
  • 什么无效？ 哪些尝试浪费了时间、为什么？
  • 下一步？ 数据还缺什么？模型还能换什么？上线后如何监控漂移？

一份好的复盘，能让第二个项目少走一半弯路。

二、可运行代码示例#

下面延续上一课的训练成果（这里用一个小模型快速复现），做四件事：计算一组指标、画误差诊断图、和季节性 naive 基线对比、做一次简化的滚动回测。

import numpy as np
import pandas as pd
import torch
import torch.nn as nn
import matplotlib.pyplot as plt
from sklearn.metrics import mean_absolute_error, mean_squared_error

torch.manual_seed(0); np.random.seed(0)

# 沿用上一课的数据与模型（简化：单变量 LSTM，输入 14 预测 7）
dates = pd.date_range("2022-01-01", periods=730, freq="D")
t = np.arange(730)
sales = 0.05 * t + 8 * np.sin(t * 2 * np.pi / 7) + np.random.randn(730) * 2
sales = (sales - sales.mean()) / sales.std()          # 标准化
series = sales.astype(np.float32)

IN_LEN, OUT_LEN = 14, 7
def make_dataset(seg):
    X, y = [], []
    for i in range(len(seg) - IN_LEN - OUT_LEN):
        X.append(seg[i:i + IN_LEN]); y.append(seg[i + IN_LEN:i + IN_LEN + OUT_LEN])
    return torch.tensor(X).unsqueeze(-1), torch.tensor(y)

# 用最后 109 天做测试，其余训练
test = series[-109:]
train = series[:-109]
X_tr, y_tr = make_dataset(train)
X_te, y_te = make_dataset(test)

class LSTM(nn.Module):
    def __init__(self):
        super().__init__()
        self.lstm = nn.LSTM(1, 32, batch_first=True)
        self.fc = nn.Linear(32, OUT_LEN)
    def forward(self, x):
        _, (h, _) = self.lstm(x); return self.fc(h[-1])

model = LSTM(); opt = torch.optim.Adam(model.parameters(), 1e-3)
criterion = nn.MSELoss()
for _ in range(300):
    opt.zero_grad(); loss = criterion(model(X_tr), y_tr); loss.backward(); opt.step()

model.eval()
with torch.no_grad():
    pred = model(X_te).numpy()
true = y_te.numpy()

# 1) 一组指标（而非单个）
mae = mean_absolute_error(true, pred)
rmse = np.sqrt(mean_squared_error(true, pred))
def smape(a, f):
    return 100.0 * np.mean(2 * np.abs(f - a) / (np.abs(a) + np.abs(f) + 1e-8))
print(f"MAE={mae:.3f}  RMSE={rmse:.3f}  sMAPE={smape(true, pred):.2f}%")

# 2) 误差诊断：每步预测的 RMSE 随步长增长曲线
per_step_rmse = [np.sqrt(mean_squared_error(true[:, k], pred[:, k])) for k in range(OUT_LEN)]
plt.figure(figsize=(8, 3))
plt.plot(range(1, OUT_LEN + 1), per_step_rmse, marker="o")
plt.xlabel("预测步长 k"); plt.ylabel("RMSE"); plt.title("误差随预测步长的增长")
plt.show()

# 3) 季节性 naive 基线：用 7 天前预测今天
naive = np.stack([series[-109 - 7 + i : -109 - 7 + i + len(pred)] for i in range(len(pred))])
# 简单对齐：naive 预测第 k 步 = 真实值向前平移 7 天的对应值
naive_pred = np.stack([test[i:i + len(pred)] for i in range(len(pred))])
# 更清晰的 baseline：对每个测试样本，用"输入窗口最后 7 天"作为未来 7 天预测（季节 naive）
baseline = []
for i in range(len(X_te)):
    baseline.append(X_te[i, -7:, 0].numpy())          # 用最近一周重复作为未来一周
baseline = np.array(baseline)
base_mae = mean_absolute_error(true, baseline)
print(f"季节性 naive 基线 MAE={base_mae:.3f}  vs  模型 MAE={mae:.3f}  提升={100*(base_mae-mae)/base_mae:.1f}%")

# 4) 简化回测：滚动 3 次，每次前进 7 天重训，报告误差分布
print("\n=== 滚动回测（简化）===")
backtest_maes = []
for start in range(0, 21, 7):
    cut = len(series) - 109 + start
    tr, te = series[:cut], series[cut:cut + OUT_LEN]
    if len(te) < OUT_LEN: break
    Xb, yb = make_dataset(np.concatenate([tr, te]))    # 用截至 cut 的数据建样本
    Xb, yb = Xb[-1:], yb[-1:]
    m = LSTM(); o = torch.optim.Adam(m.parameters(), 1e-3)
    for _ in range(300):
        o.zero_grad(); l = criterion(m(Xb), yb); l.backward(); o.step()
    with torch.no_grad():
        pb = m(Xb).numpy()
    backtest_maes.append(mean_absolute_error(yb.numpy(), pb))
print("各次回测 MAE:", [round(x, 3) for x in backtest_maes])
print("回测 MAE 均值:", round(float(np.mean(backtest_maes)), 3),
      " 标准差:", round(float(np.std(backtest_maes)), 3))

这段代码把评估从"一个数字"升级成"一组证据"：

  • 一组指标（MAE + RMSE + sMAPE）同时报告，而非挑好看的；
  • 误差增长曲线暴露了多步预测的固有衰减，帮你判断"模型能可信地预测到第几步"；
  • 基线对比给出"提升百分比"，让精度有了参照系；
  • 回测给出误差的均值和标准差，让你知道模型在滚动部署下的波动范围。

三、练习#

  1. 把每步误差增长曲线画出来，找到 RMSE 开始明显恶化的那个步长 k。业务上"可信预测范围"应定为多少步？
  2. 在数据里人为加入一段"节假日尖峰"，重跑模型，观察 RMSE 是否被放大、误差诊断图能否定位这段失灵。你会如何修复？
  3. 用 MAPE 和 sMAPE 分别评估同一组预测，比较它们在"目标接近 0"时的稳定性差异，理解为什么要谨慎使用百分比误差。
