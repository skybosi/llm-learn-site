DataLoader#

上一课的 Dataset 回答了"有多少样本、怎么取一个样本"。但训练时我们不会一个样本一个样本地喂，而是一次喂一小批（batch），还要打乱顺序、用多线程并行读取。DataLoader 就是干这些活儿的：它把 Dataset 包装成一台"持续产出批次"的机器。

一、概念讲解#

1. 为什么需要 batch 和多线程#

  • batch（小批量）：一次梯度更新用一小批样本（例如 32 张图），而不是全部数据，也不是单条。这样既保证梯度方向比较稳定，又不需要把整个数据集塞进显存。
  • shuffle（打乱）：每个 epoch 开始前把样本顺序洗牌，避免模型"记住顺序"而学偏。
  • 多线程预取：读图、解压这些 I/O 操作很慢，用多个 worker 在后台并行加载，让 GPU 不至于"等数据"。

这些能力都由 torch.utils.data.DataLoader 提供。

2. 核心参数#

参数 含义 常用取值
dataset 要包装的 Dataset 上一课的实例
batch_size 每个 batch 的样本数 16 / 32 / 64
shuffle 是否打乱顺序 训练 True，验证/测试 False
num_workers 后台加载线程数 大于 0，如 2 或 4
drop_last 最后不足一个 batch 时是否丢弃 训练常 True

一个关键的形状问题：如果样本是形状 (3, 28, 28) 的图像，batch_size=16 时，DataLoader 会把 16 个样本堆叠成 (16, 3, 28, 28) 的张量。标签也一样被堆成 (16,)。

3. 如何遍历#

DataLoader 是一个可迭代对象，每个 epoch 都可以用 for 重新遍历一遍：

for epoch in range(2):
    for x_batch, y_batch in train_loader:
        # x_batch: (batch_size, ...)
        pass

每遍历完一遍，就是一个 epoch（把整个数据集看过一轮）。shuffle=True 会让每个 epoch 的顺序都不同。

二、可运行代码示例#

沿用上一课的 ParabolaDataset，完整演示 DataLoader 的 batch 堆叠、shuffle、drop_last，以及"训练集/验证集"的常见拆分方式。

import torch
from torch.utils.data import Dataset, DataLoader, random_split


# 1) 复用一个简单的数值 Dataset
class ParabolaDataset(Dataset):
    """y = 2x^2 - 3x + 1 的带噪声样本。"""

    def __init__(self, n=200, noise=0.2):
        super().__init__()
        self.x = torch.linspace(-3, 3, steps=n).unsqueeze(1)
        self.y = 2 * self.x ** 2 - 3 * self.x + 1
        self.y = self.y + noise * torch.randn_like(self.y)

    def __len__(self):
        return len(self.x)

    def __getitem__(self, index):
        return self.x[index], self.y[index]


ds = ParabolaDataset(n=200)

# 2) 用 random_split 把数据按比例切成训练集和验证集
train_ds, val_ds = random_split(ds, [160, 40])   # 160 + 40 = 200

# 3) 训练集：打乱 + 成批；验证集：不打乱
train_loader = DataLoader(train_ds, batch_size=32, shuffle=True)
val_loader = DataLoader(val_ds, batch_size=32, shuffle=False)

print("训练集 batch 数：", len(train_loader))   # 160 / 32 = 5
print("验证集 batch 数：", len(val_loader))     # 40 / 32 = 2（最后不足 32 也保留）

# 4) 观察一个 batch 的形状：自动在第 0 维堆叠成 batch
for x_batch, y_batch in train_loader:
    print("\n训练 batch 输入形状：", x_batch.shape)   # torch.Size([32, 1])
    print("训练 batch 标签形状：", y_batch.shape)     # torch.Size([32, 1])
    break   # 只看第一个 batch

# 5) drop_last 的作用：丢弃最后不足一个 batch 的"零头"
loader_drop = DataLoader(val_ds, batch_size=32, shuffle=False, drop_last=True)
print("\n开启 drop_last 后验证集 batch 数：", len(loader_drop))  # 32 个样本凑不满，只剩 1 个 batch

# 6) 每个 epoch 的顺序不同（shuffle 的效果）
print("\n两个 epoch 前 3 个样本的输入值对比：")
for epoch in range(2):
    first_three = []
    for x_batch, _ in train_loader:
        first_three = [round(v, 2) for v in x_batch[:3, 0].tolist()]
        break
    print(f"epoch {epoch + 1}: {first_three}")

运行后你会看到类似：

训练集 batch 数： 5
验证集 batch 数： 2
训练 batch 输入形状： torch.Size([32, 1])
训练 batch 标签形状： torch.Size([32, 1])
开启 drop_last 后验证集 batch 数： 1
两个 epoch 前 3 个样本的输入值对比：
epoch 1: [0.09, 2.61, -1.85]
epoch 2: [-2.79, 0.94, 1.73]

要点都在输出里：batch 在第 0 维堆叠；drop_last=True 丢掉了不足 32 的最后一批；shuffle=True 让每个 epoch 的前几个样本顺序都不一样。

三、练习#

  1. 把 batch_size 改成 25（200 个样本），观察 drop_last=True 和 drop_last=False 时 len(train_loader) 分别是多少，并解释差异。
  2. 给 DataLoader 设置 num_workers=2，重新跑上面的遍历，确认结果一致（多线程只影响速度，不影响数据内容）。
  3. 写一个循环，用 enumerate(train_loader) 打印出每个 batch 的下标、输入形状，统计"一个 epoch 里样本总数是不是等于训练集样本数"。
