INT4/INT8 量化#

前面几章反复提到"量化"能省显存、提速 decode，这一章正式展开。量化（quantization）的本质是：用更少的比特去近似表示原本的浮点权重，从而让模型变小、跑得更快。学完本课，你应当能写出对称量化的公式，算清 INT8/INT4 各自省多少，并说出量化误差从哪来。

一、概念讲解#

1. 为什么要量化#

模型默认用 FP16（甚至 FP32）存权重。一个 7B 模型 FP16 要 14GB，INT8 只需 7GB，INT4 只需 3.5GB。更关键的是，decode 阶段是访存密集的（第 1 章）：权重字节数减半，每 token 读权重的时间几乎减半，TPOT 也就近似减半。所以量化同时带来两大收益：

  • 省显存：同样的卡能放下更大的模型，或服务更多请求；
  • 提速：访存减少 → decode 每 token 更快。

2. 量化的基本公式#

最常用的对称线性量化，把一个浮点区间线性映射到整数区间：

xq​=round(sx​),x≈xq​⋅s

其中 s 是缩放因子（scale），通常取 s=max(∣x∣)/qmax​，qmax​ 是该整型能表示的最大值（INT8 是 127，INT4 是 7）。反量化就是乘回 s。所谓"量化 + 反量化"，就是来回做这个乘除与取整。

3. 量化误差的来源#

取整会丢信息，这就是量化误差。误差的大小取决于：

  • 比特数：比特越少，可表示的值越少，误差越大（INT4 比 INT8 更"糙"）；
  • 缩放粒度：整层共用一个 scale（per-tensor）误差较大；每个输出通道各用一个 scale（per-channel）误差明显更小，是权重量化的标配；
  • 是否感知激活分布：只看权重的极值（如 AWQ 之前的天真做法）不如"结合激活的重要性"（第 2 课的 AWQ）来得准。

4. 权重 vs 激活、PTQ vs QAT#

  • 权重量化：只量化权重，激活仍用浮点。最常用、最稳妥。
  • 激活量化：连激活也量化，能进一步提速（可用整数运算核），但误差更大、实现更难。
  • PTQ（训练后量化）：不重新训练，只用少量校准数据找 scale。主流做法。
  • QAT（量化感知训练）：训练时就模拟量化，精度保持最好，但成本高，LLM 上少见。

二、可运行示例#

下面的 Python 实现对称量化与反量化，并直观展示不同比特数带来的误差。

# -*- coding: utf-8 -*-
# 对称线性量化与反量化：INT8 vs INT4 的误差对比
import numpy as np

def quantize(w, bits):
    """对称量化：scale = max(|w|)/q_max，返回 (量化整数, scale)。"""
    q_max = 2 ** (bits - 1) - 1          # INT8->127, INT4->7
    s = np.max(np.abs(w)) / q_max
    wq = np.round(w / s).astype(np.int32)
    wq = np.clip(wq, -q_max, q_max)      # 截断到可表示范围
    return wq, s

def dequantize(wq, s):
    """反量化：乘回 scale。"""
    return wq.astype(np.float32) * s

# 用一段模拟的权重（正态分布 + 少量离群大值）
rng = np.random.default_rng(42)
w = rng.normal(0, 1, size=1000).astype(np.float32)
w[::50] *= 8   # 人为制造离群值，观察它如何"绑架" scale

for bits in [8, 4, 2]:
    wq, s = quantize(w, bits)
    w_rec = dequantize(wq, s)
    mse = np.mean((w - w_rec) ** 2)
    # 量化后字节占用（每值 bits/8 字节）
    bytes_per_val = bits / 8
    print(f"INT{bits}：scale={s:.4f} | MSE={mse:.5f} | 每值 {bytes_per_val} 字节")

# 对照 FP16 的字节占用与省下的显存
print(f"\n7B 模型权重：FP16=14.0 GB | INT8={7*10**9/1024**3:.1f} GB | "
      f"INT4={7*10**9*0.5/1024**3:.2f} GB")

运行后你会看到两个现象：比特越少 MSE 越大（4-bit 明显比 8-bit 糙）；离群大值会把 scale 拉大，导致普通权重被"挤"到很粗的格子，误差变大——这正是第 2 课 AWQ 要解决的"离群值问题"。

三、练习#

  1. 去掉离群值：把 w[::50] *= 8 删掉，重跑，观察 4-bit 的 MSE 是否大幅下降，说明离群值对量化的破坏。
  2. 改粒度：把整层一个 scale 改成"每 128 个数一组各算一个 scale"（per-group），重算 MSE，体会粒度变细对精度的改善。
  3. 算省显存：用代码验证：一个 13B 模型 FP16 约 26GB，量化到 INT8、INT4 各是多少 GB？量化到 2-bit 呢？
  4. 思考：为什么权重容易量化，激活更难量化？结合"激活的分布随输入动态变化"来谈。
