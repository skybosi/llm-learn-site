随机变量的概念#

第 1 章我们讨论的事件，还停留在"某个集合发生没发生"这种层面。但机器学习里的数据几乎都是数字：一封邮件的长度、一张图片的像素值、一只股票的价格。要把概率论的强大工具用在这些数字上，我们需要一个桥梁——随机变量。它把"随机试验的结果"翻译成"实数"，从而让我们能用函数、积分、求和去研究不确定性。

一、概念讲解#

1. 为什么需要随机变量#

假设掷两颗骰子，我们关心的是"点数之和"。直接描述很啰嗦："点数之和为 7"这件事，对应着 {(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)} 六种结果。如果能把"点数之和"写成一个函数 X，把每个结果映射到一个数字，那么"点数之和为 7"就简洁地写成 X = 7，我们就能用数学记号去求 P(X = 7)、E[X] 等等。

随机变量正是这样一个函数：它把样本空间中的每个结果，映射到一个实数。注意，随机变量本身不是"随机"的，它的取值是随机的——因为输入（试验结果）是随机的。

2. 形式化定义#

设样本空间为 Ω，随机变量 X 是一个函数：

X : Ω → ℝ

即对每个样本点 ω，X(ω) 是一个实数。掷一枚硬币，可以定义 X(正面) = 1，X(反面) = 0；掷一颗骰子，可以定义 X(ω) = ω（点数本身就是数字），也可以定义 Y(ω) = 1 若 ω 是偶数、否则 0。

有了这个映射，像 P(X = k) 这样的记号就表示"使得 X 取值为 k 的所有结果组成的集合的概率"。

3. 离散与连续（初步）#

随机变量按取值特点分成两大类：

  • 离散随机变量：取值是有限个或可列无限个，比如掷骰子的点数、抛硬币的正面次数。研究它用"某个值出现的概率" P(X = k)。
  • 连续随机变量：取值充满一个区间（不可列），比如身高、温度、神经网络输出的 logit 值。这时 P(X = k) 永远是 0，研究它要用"落在某个区间"的概率 P(a ≤ X ≤ b)。

两者在下一课会详细展开，这里先有个印象即可。

4. 机器学习视角：特征与标签都是随机变量#

在机器学习里，随机变量无处不在：

  • 标签 Y：一张图片的类别、一封邮件的标签，都是离散随机变量；
  • 特征 X：像素灰度、词频、价格、温度，多数是连续随机变量；
  • 模型的预测 ŷ：神经网络的输出，也是随机变量（它随输入分布而变化）。

把"特征"理解成随机变量后，我们说的"数据的分布""特征分布"就都有严格含义了：就是在问这个随机变量的概率规律是什么。

二、可运行示例#

示例 1：掷骰子定义随机变量并统计频率#

import random
from collections import Counter

random.seed(0)


def die():
    """掷一枚公平骰子，返回 1~6。"""
    return random.randint(1, 6)


# 随机变量 X：骰子的点数。重复试验，用频率逼近 P(X = k)。
n = 60000
rolls = [die() for _ in range(n)]
counts = Counter(rolls)

print("点数  频率    理论值")
for k in range(1, 7):
    print(f"  {k}   {counts[k] / n:.4f}   {1 / 6:.4f}")

示例 2：把"三次抛硬币的正面数"定义为随机变量#

import random
from collections import Counter

random.seed(3)


def count_heads():
    """抛三次硬币，返回正面数（这就是一个离散随机变量 X）。"""
    return sum(1 for _ in range(3) if random.random() < 0.5)


# 统计 P(X = 0/1/2/3)。理论分布：1/8, 3/8, 3/8, 1/8
n = 80000
values = [count_heads() for _ in range(n)]
counts = Counter(values)

print("正面数  频率    理论值")
for k in range(4):
    print(f"  {k}    {counts[k] / n:.4f}   {[1, 3, 3, 1][k] / 8:.4f}")

示例 3：用随机变量合成一个"数据集"#

import random

random.seed(42)


def student_height():
    """模拟某班级学生身高：基准 170cm 加一个随机扰动。"""
    base = 170
    noise = random.uniform(-15, 15)  # 在 [-15, 15) 之间均匀扰动
    return round(base + noise, 1)


# 生成 30 个样本，体会"数据 = 随机变量的观测值"
heights = [student_height() for _ in range(30)]
print("模拟得到的学生身高样本：")
print(heights)
print(f"样本均值 = {sum(heights) / len(heights):.2f} cm")
