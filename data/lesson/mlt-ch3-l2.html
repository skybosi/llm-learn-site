从高斯先验推出岭回归#

岭回归（Ridge Regression）的核心是给 MSE 加一个 L2 惩罚项 λ‖w‖²。这个"平方惩罚"是从哪冒出来的？上一课的 MAP 框架给了我们答案的方向：L2 正则 = 参数的先验是高斯分布。这一课我们把这个方向走到底，完整推导"高斯先验 + MAP → 岭回归"，并顺便解出岭回归的闭式解，看清 λ‖w‖² 为什么能让 (XᵀX)⁻¹ 稳定下来。

一、概念讲解#

1. 给参数安一个高斯先验#

线性回归里参数是权重向量 w（为简洁，把截距 b 也并入 w）。贝叶斯派先给 w 一个先验——最自然的选择是零均值、各向同性的高斯分布：

w ~ N(0, τ²I)

意思是：每个权重 wⱼ 独立地服从 N(0, τ²)，先验上"最相信"所有权重都在 0 附近，且没有任何一个方向被特别偏爱。τ² 是先验方差，τ² 越大代表先验越"松"（对权重约束越弱），越小代表先验越"紧"（强烈相信权重接近 0）。

写出这个多元高斯的密度：

P(w) = (1/√(2πτ²)ᵈ) · exp( −‖w‖² / (2τ²) )

其中 d 是参数维度，‖w‖² = Σⱼ wⱼ² 是权重向量的 L2 范数平方。

2. 写出后验，取对数#

数据的似然仍由高斯噪声假设给出（第 2 章第 2 课）：y | X, w ~ N(Xw, σ²I)。由贝叶斯公式，后验正比于似然乘先验：

P(w | X, y) ∝ P(y | X, w) · P(w)

取负对数（最大化后验 = 最小化负对数后验）：

−log P(w|X,y) = −log P(y|X,w) − log P(w) + 常数
              = (1/2σ²)‖y − Xw‖² + (1/2τ²)‖w‖² + 常数

第一项是残差平方和（MSE 的来源，见第 2 章），第二项就是先验带来的新成员 (1/2τ²)‖w‖²。

3. MAP 目标 = 岭回归#

把上面的式子整理成最小化目标（乘上常数 2σ² 不影响最小值点）：

J(w) = ‖y − Xw‖² + (σ²/τ²)·‖w‖²
     = ‖y − Xw‖² + λ·‖w‖²,      其中 λ = σ²/τ²

这正是岭回归（Ridge / L2 正则化）的目标函数。于是我们证明了：

高斯先验 w ~ N(0, τ²I)  +  MAP   ⟹   岭回归（L2 惩罚 λ‖w‖²）

两个漂亮的细节：

  • 正则系数 λ 有明确含义：λ = σ²/τ² = 噪声方差 / 先验方差。噪声越大（数据越不可信）或先验越紧（越相信权重≈0），λ 越大、正则越强。
  • L2 惩罚是"高斯先验的负对数"：高斯密度里的 e^{−‖w‖²/2τ²} 取负对数，恰好就是 ‖w‖²/(2τ²)。平方惩罚里的那个"平方"，和高斯钟形曲线的"平方"是同一个。

4. 岭回归的闭式解#

J(w) 是凸二次函数，直接求梯度令零：

∇J(w) = 2Xᵀ(Xw − y) + 2λw = 0
⟹  (XᵀX + λI) w = Xᵀy
⟹  w* = (XᵀX + λI)⁻¹ Xᵀy

对比普通最小二乘的 w = (XᵀX)⁻¹Xᵀy，岭回归只多了一个 λI。这个 λI 是关键：

  • 当特征强相关、XᵀX 接近奇异（不可逆）时，XᵀX + λI 只要 λ>0 就一定可逆——因为 λI 把每个特征值都抬高了 λ，把零特征值抬成正的。
  • 从数值上，λ 越大，解越"收缩"：λ→∞ 时 w* → 0；λ→0 时退化为普通最小二乘。

这就是"先验"在计算层面的红利：高斯先验不只是哲学立场，它实实在在地让矩阵求逆从"可能崩"变成"必然稳"。

5. 高斯先验为何"收缩而不归零"#

高斯先验在 0 处是平滑的钟形峰（不是尖刺），这意味着：它相信"权重在 0 附近"，但并不强烈地相信"权重精确等于 0"。于是 MAP 的结果是"所有权重被均匀地往 0 压缩"，但几乎没有权重被压到精确的 0。这一点与下一课的拉普拉斯先验（尖峰）形成鲜明对比——那才是"稀疏"的来源。

二、可运行代码示例#

构造一个特征强相关（XᵀX 接近奇异）的数据集，对比普通最小二乘与岭回归：普通最小二乘的解会因数值不稳定而剧烈放大系数，而岭回归用 λI 稳定求逆，系数被温和收缩。

import numpy as np

rng = np.random.default_rng(13)
m = 30
x1 = rng.normal(0, 1, size=m)
x2 = x1 + rng.normal(0, 1e-3, size=m)   # x2 几乎就是 x1（强共线）
X = np.c_[x1, x2]
y = 3.0 * x1 + rng.normal(0, 0.5, size=m)

# 普通最小二乘（求逆可能数值不稳）
w_ols = np.linalg.lstsq(X, y, rcond=None)[0]

# 岭回归闭式解
def ridge(X, y, lam):
    d = X.shape[1]
    return np.linalg.inv(X.T @ X + lam * np.eye(d)) @ X.T @ y

print("XᵀX 的条件数（越大越病态）=", f"{np.linalg.cond(X.T @ X):.2e}")
print("普通最小二乘 w =", np.round(w_ols, 4), "（系数被共线性放大）")
for lam in [0.01, 0.1, 1.0, 10.0]:
    w_r = ridge(X, y, lam)
    print(f"岭回归 λ={lam:<5} w =", np.round(w_r, 4))

你会看到：由于 x1≈x2，普通最小二乘可能给出 w≈[很大的正数, 很大的负数] 这样互相抵消的怪解；而岭回归的 λ 越大，系数越被拉回 0 附近、越稳定。这正是 λI 让病态矩阵"起死回生"的直观证据。

三、练习#

  1. 从 w ~ N(0, τ²I) 的密度出发，逐行推导 −log P(w) = (1/2τ²)‖w‖² + 常数，并说明为何最大化后验等价于最小化 ‖y−Xw‖² + (σ²/τ²)‖w‖²。
  2. 对 J(w) = ‖y−Xw‖² + λ‖w‖² 求梯度，证明梯度为 0 时 w = (XᵀX + λI)⁻¹Xᵀy，并解释为什么 λ>0 保证 XᵀX + λI 可逆（提示：特征值分解）。
  3. 令 λ→∞ 与 λ→0，分别求 w* 的极限，并对应解释"先验方差 τ² 趋于 0/∞"这两个极端在贝叶斯语言里的含义。
  4. 思考：为什么说"高斯先验收缩但不稀疏"？从高斯密度在 0 附近"平滑"（导数连续、非尖峰）的几何形状，对比你预想中的"稀疏先验"应长什么样。

母原理连接#

本课属于母原理 "概率视角统一"，是"正则项 = 先验负对数"这一等式的第一个实例。我们证明：L2 正则 = 高斯先验，且 λ = σ²/τ² 给了正则系数一个可解释的概率含义。这让我们把岭回归从"一个带惩罚的优化技巧"升级为"一个完整的概率模型"：先验、似然、后验、MAP，环环相扣。下一课换一个先验——拉普拉斯——你会看到同一条公式如何"变出"完全不同的稀疏行为。
