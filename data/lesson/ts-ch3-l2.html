机器学习回归预测#

上一课我们把时间序列摊平成 (X, y) 表格。有了表格，机器学习的十八般武艺就都能上场了。但"能跑"不等于"能预测准"：树模型有个致命盲区叫外推，多步预测有个陷阱叫误差累积。这一课讲清楚用 ML 做时序预测的正确姿势和边界。

一、概念讲解#

1. 回归视角下的时序预测#

在第 3 章第 1 课的框架里，预测 y_{t+h} 就是一个普通回归问题：

训练集：X_train = 历史特征，y_train = 对应未来值
模型：  f: X -> ŷ，最小化预测误差

可选模型从简到繁：

  • 线性回归 / 岭回归 / Lasso：可解释、外推能力强，但只能抓线性关系；
  • 随机森林 / 梯度提升（XGBoost、LightGBM、HistGradientBoosting）：能自动抓非线性与交互，是表格数据的主力；
  • 更深的神经网络（MLP、以及第 4 章的 LSTM/Transformer）留在后续课程。

一个关键提醒：ML 模型没有内建"时间"概念，它学到的一切规律都来自你喂给它的特征。滞后、滚动、日历这些特征的质量，直接决定模型的上限。

2. 树模型的外推盲区#

这是用 ML 做时序最重要的一课：树模型无法外推。

树模型（随机森林、梯度提升）的预测本质是"把样本分到某个叶子，输出该叶子训练样本的平均值"。它只能输出训练时见过的目标范围内的值，无法给出超出训练范围的连续外推。后果是：

  • 序列有上升趋势时，树模型的预测会被"钉"在历史水平附近，长期预测明显偏低、追不上趋势；
  • 序列出现历史未见的新高时，树模型只能预测到"见过的最接近值"。

而线性模型/线性回归天然支持外推：ŷ = w·x + b 是条直线，x 变大预测也跟着线性走。

对策：

  1. 把趋势"喂"成特征或先去掉：加入时间序号、dayofyear 等趋势代理特征，或先做差分/去趋势，让树模型去拟合"围绕趋势的波动"而不是趋势本身；
  2. 组合模型：用线性/统计模型外推趋势，用树模型拟合残差；
  3. 需求明确是"外推长期趋势"时，优先考虑线性、带趋势的统计模型，或能外推的模型族。

3. 直接预测 vs 递归预测（多步）#

单步预测简单：特征是截至 t 的过去，标签是 y_{t+1}。但业务常要预测未来 h 期，有两种做法：

直接预测（direct）：为每个 h 各训练一个模型 f_h，直接预测 y_{t+h}。优点：误差不累积、各步独立；缺点：要训练 h 个模型、且忽略了各步之间的依赖关系。

递归预测（recursive）：只训练一个单步模型 f，预测出 ŷ_{t+1} 后，把它当作已知喂回特征，再预测 ŷ_{t+2}，如此滚动。优点：一个模型走天下、天然保持时序衔接；缺点：误差会累积放大——第 1 步的小误差被当作第 2 步的输入，误差像滚雪球一样越滚越大，多步之后可能发散。

实务中常用混合策略：递归为主，中间夹带直接预测校准，或用"多输出"模型一次性输出多步。无论哪种，都要在验证集上实测多步误差，别只看单步指标（第 3 课会讲怎么科学地评估）。

4. 统计模型 vs 机器学习：什么时候选谁#

维度 统计模型（ARIMA/ETS） 机器学习（树/线性）
数据量 小样本也能用 通常需要更多样本
可解释性 参数含义清晰 树有特征重要性，但整体较"黑"
外推趋势 天然支持 树模型困难，需技巧
多变量/外部特征 需要专门扩展 天然支持多特征
非线性/交互 有限 强

经验法则：单一序列、样本不多、要快而稳 → 统计模型；多序列、多外部协变量、样本充足、要利用复杂交互 → 机器学习。两者也能组合（统计模型做基线，ML 做增强）。

二、可运行示例#

用梯度提升做单步预测，并演示"树模型外推弱"的问题。

import numpy as np
import pandas as pd
from sklearn.ensemble import HistGradientBoostingRegressor, RandomForestRegressor
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_absolute_error

# 1) 构造带上升趋势 + 周季节的日度序列
idx = pd.date_range("2023-01-01", periods=300, freq="D")
rng = np.random.default_rng(4)
t = np.arange(300)
y = 10 + 0.15 * t + 6 * np.sin(2 * np.pi * t / 7) + rng.normal(0, 2, size=300)
series = pd.Series(y, index=idx)

# 2) 特征工程：滞后 + 滚动 + 时间序号
def make_features(s, lags=(1, 2, 3, 7)):
    df = pd.DataFrame({"y": s})
    for lag in lags:
        df[f"lag_{lag}"] = s.shift(lag)
    df["roll_mean_7"] = s.shift(1).rolling(7).mean()
    df["time_idx"] = np.arange(len(s))  # 时间序号作为趋势代理特征
    df["target"] = s.shift(-1)          # 预测下一天
    return df.dropna()

data = make_features(series)
feats = [c for c in data.columns if c not in ("y", "target")]
X, yv = data[feats], data["target"]

# 3) 按时间切分：前 240 天训练，后 60 天测试（不能随机切！）
cut = 240
X_train, X_test = X.iloc[:cut], X.iloc[cut:]
y_train, y_test = yv.iloc[:cut], yv.iloc[cut:]

# 4) 三个模型对比
models = {
    "Ridge": Ridge(),
    "随机森林": RandomForestRegressor(n_estimators=300, random_state=0),
    "梯度提升": HistGradientBoostingRegressor(random_state=0),
}
for name, model in models.items():
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    mae = mean_absolute_error(y_test, pred)
    print(f"{name:6s}  测试集 MAE = {mae:.3f}")

# 5) 观察梯度提升的预测是否"追不上"上升趋势
best = models["梯度提升"]
pred_gb = best.predict(X_test)
print("\n真实值最后 5 期：", np.round(y_test[-5:], 2))
print("梯度提升预测  ：", np.round(pred_gb[-5:], 2))
print("真实值均值偏置：", round(y_test.mean() - pred_gb.mean(), 2))

你通常会发现：加入了 time_idx 特征后，梯度提升能部分缓解外推问题；若去掉 time_idx，它的预测会明显落后于持续上升的真实值——这正是树模型外推弱的直观表现。而 Ridge（线性）在趋势上的表现往往更稳。

三、练习#

  1. 把 make_features 里的 time_idx 去掉，重新训练梯度提升，观察测试集 MAE 和预测均值偏置的变化，解释原因。
  2. 实现一个递归多步预测：用梯度提升做单步模型，然后循环预测未来 14 天（把预测值喂回滞后特征），画出预测曲线，观察误差如何随步数累积。
  3. 对比"递归预测"和"直接预测"（为 h=1 和 h=7 各训一个模型）在 7 步预测上的 MAE，说明哪种更稳。
  4. 思考：如果序列是纯季节、无趋势，树模型的外推问题还严重吗？为什么？
