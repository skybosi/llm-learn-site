熵与不确定性#

从本章起，我们换一个视角看"学习"。前面几章一直在问"损失函数怎么来的、怎么优化"，本章问一个更底层的问题："不确定性"本身能不能被精确度量？ 如果可以，那么"模型预测与真实答案之间的差距""一个特征能带来多少信息"这类模糊的说法，就能变成可计算的量。香农在 1948 年给出的答案就是熵。这一课我们不背公式，而是从三条"任何合理的'不确定性度量'都必须满足"的公理出发，把熵推导出来。

一、概念讲解（含推导）#

1. 先问"为什么"：不确定性要满足什么？#

设随机变量 X 取值于有限集合，概率分布为 p=(p1​,…,pn​)，其中 ∑i​pi​=1。我们要找函数 H(p1​,…,pn​) 表示"看到结果前的不确定性"。直觉上，一个合理的度量至少应满足三条：

  • （A1）连续性：H 关于每个 pi​ 连续。概率只变一点点，不确定性不该跳变。
  • （A2）单调性：对均匀分布（n 个等可能结果），H 应随 n 增大而增大——选项越多越不确定。
  • （A3）可加性（分组原则）：信息可以分两步揭示，且总不确定性不变。具体地说，把前 k 个结果合并成一个"组事件"（概率 p1​+⋯+pk​），先揭晓落在哪组、再揭晓组内是哪个，两次不确定性之和应等于一步揭晓：

H(p1​,…,pn​)=H(p1​+⋯+pk​,pk+1​,…,pn​)+(p1​+⋯+pk​)H(Pp1​​,…,Ppk​​),P=p1​+⋯+pk​.

香农证明了：满足这三条的函数几乎唯一，只能是

H(p1​,…,pn​)=−Ki=1∑n​pi​logpi​​

其中 K>0 是任意正常数（对数的底决定单位）。这就是香农熵。下面给出这条结论的推导骨架。

2. 推导：三条公理如何"逼出"对数#

第 1 步——均匀分布的情形。记 A(n)=H(n1​,…,n1​)。把 n 个等概率结果平均分成 m 组、每组 m 个（n=m2），由 (A3)：

A(m2)=A(m)+m⋅m1​A(m)=2A(m).

更一般地，把 n 个结果按每组 m 个分成 n/m 组（设整除），可得 A(n)=A(n/m)+A(m)，即可加性 A(nm)=A(n)+A(m)。由 (A1) 连续性可推广到实数，结合 (A2) 单调性，可证明 A(n)=Klogn（K>0）。换句话说：均匀分布的不确定性必须正比于结果数目的对数。

第 2 步——有理数概率。设 pi​=ni​/N（N=∑ni​，分子分母都是整数）。把 N 个等概率结果分成 n 组，第 i 组含 ni​ 个。由 (A3)：

A(N)=H(p1​,…,pn​)+i=1∑n​pi​A(ni​).

代入 A(N)=KlogN、A(ni​)=Klogni​：

KlogN=H(p1​,…,pn​)+Ki∑​pi​logni​,

解得

H(p1​,…,pn​)=K(logN−i∑​pi​logni​)=K(i∑​pi​logN−i∑​pi​logni​)=−Ki∑​pi​logNni​​=−Ki∑​pi​logpi​.

第 3 步——任意实数概率：用 (A1) 连续性从有理数概率逼近任意概率，公式保持。于是熵的形式被唯一确定。通常取 K=1 且对数以 2 为底，单位记为比特（bit）；以 e 为底记奈特（nat）。∎

这条推导的美妙在于：我们从未"定义"熵，是三条朴素的公理逼着它长成 −∑plogp 的样子。

3. 熵的两个基本性质#

（1）非负性：H(p)≥0。因为 0≤pi​≤1 时 −logpi​≥0。当且仅当某个 pi​=1（完全确定）时 H=0。

（2）最大熵 = 均匀分布：对固定的 n，

H(p1​,…,pn​)≤logn,

等号当且仅当 pi​=1/n。证明用琴生不等式（上一章第 5 课的琴生不等式第一次派上用场）：log 是凹函数，取 X 在 {1/pi​} 上以概率 pi​ 取值，则

H(p)=i∑​pi​logpi​1​=E[logp1​]≤logE[p1​]=log(i∑​pi​⋅pi​1​)=logn.

这个结论的哲学含义很重要：在没有额外信息时，最"不确定"的猜测是均匀分布——这就是最大熵原理的雏形，也是"无信息先验"的信息论来源。

4. 熵的物理含义：最短平均编码长度#

熵不只是抽象数字，它有一个可操作的物理含义：它是无损编码下，每个符号所需的最短平均比特数。给概率 pi​ 的结果分配码长 ℓi​=−log2​pi​ 位（概率越小、码越长），平均码长就是

i∑​pi​ℓi​=−i∑​pi​log2​pi​=H(X).

香农的信源编码定理严格保证了：平均码长可以逼近 H(X)，但不能低于 H(X)。于是"熵 = 表达这个分布的信息所必需的比特数"，−log2​pi​ 就是"事件 i 发生所携带的信息量（自信息）"，概率越小的事件越"惊人"，携带的信息越多。

5. 联合熵、条件熵与链式法则#

把熵推广到多个变量，就得到决策树和互信息的全部原料：

  • 联合熵：H(X,Y)=−∑x,y​p(x,y)logp(x,y)。
  • 条件熵：H(Y∣X)=∑x​p(x)H(Y∣X=x)=−∑x,y​p(x,y)logp(y∣x)，含义是"知道 X 之后，Y 还剩多少不确定性"。
  • 链式法则：H(X,Y)=H(X)+H(Y∣X)。两边展开 p(x,y)=p(x)p(y∣x) 即可验证：

H(X,Y)=−x,y∑​p(x)p(y∣x)[logp(x)+logp(y∣x)]=−x∑​p(x)logp(x)−x,y∑​p(x,y)logp(y∣x)=H(X)+H(Y∣X).

链式法则是一句大白话的精确化："同时确定 X 和 Y 的信息 = 确定 X 的信息 + 已知 X 后确定 Y 的信息"。下一课的信息增益，就建立在这个等式之上。

二、验证性代码示例#

下面代码验证三条推导结论：① 熵公式对"确定分布"给出 0；② 均匀分布确实是最大熵（暴力搜索 + 与 logn 比对）；③ 链式法则 H(X,Y)=H(X)+H(Y∣X) 数值成立。

import numpy as np

def entropy(p):
    p = np.asarray(p, dtype=float)
    p = p[p > 0]                      # 只取正概率项（0*log0 约定为 0）
    return float(-np.sum(p * np.log2(p))) + 0.0   # +0.0 把 -0.0 规范回 0.0

# ---------- 1) 确定性分布 -> 熵为 0 ----------
print("H([1,0,0,0]) =", entropy([1, 0, 0, 0]), "（完全确定，零不确定性）")

# ---------- 2) 均匀分布最大：对 4 元分布随机采样验证 ----------
n = 4
rng = np.random.default_rng(0)
best = (0, None)
for _ in range(200_000):
    p = rng.dirichlet(np.ones(n))     # 随机抽取一个 n 元概率分布
    h = entropy(p)
    if h > best[0]:
        best = (h, p)
print(f"随机搜索到的最大熵 = {best[0]:.4f}")
print(f"理论上界 log2(n)   = {np.log2(n):.4f}")
print(f"对应分布（应接近均匀）:", np.round(best[1], 4))

# ---------- 3) 链式法则 H(X,Y) = H(X) + H(Y|X) ----------
p_xy = np.array([[0.25, 0.10],
                 [0.35, 0.30]])        # 联合分布 p(x,y)
p_x  = p_xy.sum(axis=1)                # 边际 p(x)
p_ygx = p_xy / p_x[:, None]            # 条件 p(y|x)

H_XY = entropy(p_xy.flatten())
H_X  = entropy(p_x)
H_YgX = sum(p_x[i] * entropy(p_ygx[i]) for i in range(len(p_x)))
print(f"\nH(X,Y) = {H_XY:.4f}")
print(f"H(X) + H(Y|X) = {H_X:.4f} + {H_YgX:.4f} = {H_X + H_YgX:.4f}")
print("链式法则成立:", np.isclose(H_XY, H_X + H_YgX))

运行结果大致为：

H([1,0,0,0]) = 0.0 （完全确定，零不确定性）
随机搜索到的最大熵 = 1.9999
理论上界 log2(n)   = 2.0000
对应分布（应接近均匀）: [0.2517 0.2533 0.2504 0.2446]

H(X,Y) = 1.8834
H(X) + H(Y|X) = 0.9341 + 0.9493 = 1.8834
链式法则成立: True

第 2 组里随机搜索在 20 万次后逼近的理论最大值正是 log2​4=2，且对应分布收敛到均匀分布——"最大熵 = 均匀分布"被数值坐实。第 3 组里两边精确相等，链式法则成立。
