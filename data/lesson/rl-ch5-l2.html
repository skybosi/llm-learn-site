函数逼近#

表格 Q-learning 一旦遇到连续状态或高维状态就彻底失效。函数逼近（function approximation）用一个参数化的函数 V̂(s; θ)（或 Q̂(s,a; θ)）去拟合价值函数，让相似的输入共享相近的输出，从而把"背表格"变成"学规律"。本课讲线性逼近的梯度更新与半梯度这个关键概念，并给出必须警惕的"死三角"。

一、概念讲解#

1. 为什么需要函数逼近#

真实任务的观测几乎总是连续的：小车的位移与速度、机械臂的关节角、股价的指标……它们不可数，更无法"一格一个状态"地枚举。函数逼近的思路是：不存每个状态的值，而是存一组参数 θ，用一个函数 V̂(s; θ) 把任意状态映射到价值估计。于是"学 Q 表"变成了"学参数"，状态空间再大，参数个数也是固定的。

2. 线性逼近与特征#

最基础的形式是线性逼近：V̂(s; θ) = θᵀ φ(s)。其中 φ(s) 是特征向量——把状态编码成若干数值特征。常见特征有：

  • 独热编码：把状态当离散 ID，φ(s) 是第 s 位为 1 的向量（此时线性逼近退化为表格！）；
  • 多项式/傅里叶基：对连续分量取 s, s², s³, ... 或正弦项；
  • 径向基（RBF）：在状态空间铺一圈高斯"鼓包"，φ_i(s) = exp(-‖s-c_i‖²/2σ²)，衡量"离中心 c_i 多近"；
  • 瓦片编码（tile coding）：多套错位网格叠加，落在哪些格子就点亮哪些特征。

特征的质量直接决定逼近能力——这就是传统 RL 里"特征工程"如此重要的原因。

3. 半梯度更新（推导）#

假设我们要让 V̂(s) 逼近某个"目标" u（对 MC 是 G_t，对 TD 是 r + γV̂(s')），自然的做法是最小化平方误差 (u - V̂(s))²，对参数 θ 做梯度下降：

θ ← θ - (α/2) ∇_θ (u - θᵀφ(s))²

关键来了：梯度作用在谁身上？ 展开：

∇_θ (u - θᵀφ(s))² = -2 (u - V̂(s)) · ∇_θ V̂(s)

对线性逼近，∇_θ V̂(s) = φ(s)，于是：

θ ← θ + α (u - V̂(s)) φ(s)

若 u 是不依赖 θ 的固定数（如 MC 的 G_t），这就是货真价实的 SGD，能保证收敛到局部最优。但 TD 的目标 u = r + γθᵀφ(s') 本身就依赖 θ——严格求导时还有一项"目标对 θ 的偏导"。经典 TD 方法故意忽略这一项，只对"当前状态的估计值"求导，把目标当成常数。这种"只求了一半梯度"的做法叫半梯度（semi-gradient）。代入 TD(0) 的目标，得到半梯度 TD(0)：

θ ← θ + α [ R + γ θᵀφ(s') - θᵀφ(s) ] φ(s)

半梯度牺牲了严格收敛的保证（在某些设置下可能发散），却换来了可以在线、逐步、无需走完轨迹的学习效率，仍是实践中的主力。

4. 死三角：必须警惕的发散组合#

函数逼近不是"表格方法的无害升级"。理论（与大量反例）指出，bootstrapping（自举）+ 函数逼近 + off-policy 三者凑齐时，更新可能发散——价值估计越学越离谱、甚至爆炸。这个组合叫 死三角（deadly triad）：

  • 自举：TD 用估计去估计（Q-learning 也在其中）；
  • 函数逼近：参数更新会"牵一发而动全身"，一个状态变、别处也跟着变；
  • off-policy：学习目标与数据分布不一致，重要性采样或 max 都可能放大误差。

表格方法只涉及前两者之一时通常没事；一旦引入非线性函数逼近（神经网络）并 off-policy 采样，稳定性问题就凸显出来——这正是下一课 DQN 要用"经验回放 + 目标网络"来专门对付的东西。

二、可运行代码示例#

用 9 个高斯径向基函数逼近一条连续状态随机游走的价值函数，跑半梯度 TD(0)。

import numpy as np

# 连续状态的一维随机游走：s ∈ [0,1]，每步随机 ±0.05；
# 碰到右端(s≥1)给奖励 1 并终止，碰到左端(s≤0)给 0 并终止。
GAMMA, ALPHA = 1.0, 0.05

# 9 个 RBF 特征：中心均匀铺在 [0,1]，宽度 sigma
CENTERS = np.linspace(0.0, 1.0, 9)
SIGMA = 0.12

def phi(s):
    """特征向量 φ(s)：每个高斯鼓包贡献一个分量。"""
    return np.exp(-((s - CENTERS) ** 2) / (2 * SIGMA ** 2))

theta = np.zeros(len(CENTERS))          # 线性逼近的参数 θ

def V(s):
    return float(theta @ phi(s))        # V̂(s) = θᵀφ(s)

def step(s):
    s_next = np.clip(s + np.random.choice([-0.05, 0.05]), 0.0, 1.0)
    r, done = 0.0, False
    if s_next >= 1.0:
        r, done = 1.0, True
    elif s_next <= 0.0:
        r, done = 0.0, True
    return s_next, r, done

for _ in range(1000):
    s, done = 0.5, False
    while not done:
        s_next, r, done = step(s)
        v_next = 0.0 if done else V(s_next)      # 终止态价值为 0
        # 半梯度 TD(0)：θ ← θ + α [r + γθᵀφ(s') - θᵀφ(s)] φ(s)
        td_error = r + GAMMA * v_next - V(s)
        theta += ALPHA * td_error * phi(s)
        s = s_next

# 采样打印估计值；该随机游走的真值是 V(s) = s（对称游走到右端的概率）
print("s    V(s)估计   真值")
for s in np.linspace(0.0, 1.0, 11):
    print("{:.2f}   {:.3f}     {:.2f}".format(s, V(s), s))

要点：phi(s) 让"位置相近的状态"产生相近的特征，从而共享参数、实现泛化；td_error * phi(s) 只在 s 附近那几个"被点亮"的鼓包上更新参数——这就是函数逼近里"局部学习"的直观来源。运行后估计值应大致贴着直线 V(s)=s。

三、练习#

  1. 把 RBF 中心数从 9 改成 3、再改成 20，比较逼近精度；特征太少（欠拟合）和太多（过拟合/震荡）各有什么表现？
  2. 把 SIGMA 从 0.12 改成 0.05、0.5，观察"鼓包太窄"与"太宽"对估计曲线的影响。
  3. 用 MC 目标 u = G_t 替换 TD 目标重写更新（走完一条轨迹再更新 θ），对比它与半梯度 TD(0) 的收敛稳定性。
  4. 思考题：半梯度方法"忽略"的那一项是什么？为什么说忽略它换来了在线学习能力，却放弃了严格收敛保证？举一个可能触发的"死三角"组合。
