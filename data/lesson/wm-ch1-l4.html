设计目标：可预测、可控、可规划、可泛化、可校准#

这一节要解决什么#

前三节建立了定义（状态 + 动力学）、状态的理论依据、以及复合误差的界。但还有一个问题没回答："一个好世界模型"到底是什么意思？

这不是文字问题，而是工程问题。因为"好"必须可测，而一旦写下来就会发现：五个自然的"好"互相冲突。

本节要回答：

  1. 一个世界模型的"好"可以拆成哪五个目标？每个目标的可操作度量是什么？
  2. 每个目标如果单独优化到极致，会把什么弄坏？（每个目标都有一个"专一化的病"）
  3. 冲突矩阵长什么样？哪几对冲突最尖锐、机制是什么？
  4. 必须牺牲一个目标时，判据是什么？为什么"看情况"不是答案——可执行的决策规则应该长什么样？
  5. 判别问句 D1–D4 与这五个目标是什么关系？它们是不是同一套东西？

本节的核心结论：

① 五个目标是"可预测 / 可控（动作敏感） / 可规划 / 可泛化 / 可校准"，每一个都有自己的度量，也都有自己的"专一化的病"。 ② 冲突不是实现缺陷，而是结构性的：忽略动作能让模型更可预测；锐化预测必然压低方差从而破坏校准；只追求可规划会让模型钻自己的误差空子。没有任何模型能在这五个维度上同时最优——你只能选一个折中，而折中点的位置由用途决定。 ③ 正确的目标不是"预测得更准"，而是"让下游决策损失更小"：模型误差按规划器的敏感度加权。这就是 value-aware model learning / value equivalence 的出发点，也是把"精度"与"可用性"接起来的唯一桥梁。

一、五个目标：定义、度量、以及"专一化的病"#

1.1 可预测（Predictability）#

定义：在留出数据上，模型对未来状态的预测分布与真实分布接近。

度量：

  • H 步负对数似然 E[−logpθ​(st+H​∣st​,at:t+H​)]（首选，因为它同时约束均值与方差）；
  • 加权 MSE / RMSE（次选，只看均值）；
  • 判定系数 R2=1−Var(s′)MSE​（用于判断"是否比预测均值更好"）。

专一化的病：追条件均值 → 多模态未来被抹平（wm-ch1-l3 的 1.2 节）；更糟的是，它可以用"忽略动作"来降低损失——如果环境里自然演化占方差的大部分，忽略动作的模型反而更"可预测"。所以可预测高不代表学到了动力学。

1.2 可控（Controllability / 动作敏感）#

定义：预测对动作的响应与真实世界一致——动作必须既不被忽略、也不被放大。

度量：

  • 反事实分离度 ρˉ​cf​（wm-ch1-l1 的 4.1 节）：合格区间 ≈1 且跨动作幅度稳定；
  • 动作可辨识性：能否从 (st​,st+1​) 反推出 at​（训练一个探针分类器/回归器，看 R2 或准确率）；
  • 敏感度矩阵的一致性：​∂a∂f^​​−∂a∂f​​ 在采样点上求平均。

专一化的病：为了"动作敏感"而放大梯度 → 对噪声动作过度反应，规划器被虚假的大梯度吸引到极端动作上。ρˉ​cf​≫1 与 ρˉ​cf​≈0 一样致命，只是失败方式不同。

1.3 可规划（Plannability）#

定义：模型能否支撑"在模型里搜索/优化，然后在真实环境里执行"这个过程，并带来真实回报。

度量（注意：这是唯一一个必须闭环的度量）：

  • 想象价值：在模型内用 MPC/CEM 规划、把动作序列在真实环境执行，测真实回报；
  • 后悔值：与"真实模型下的最优规划"回报之差；
  • 决策相关精度：模型误差在规划器敏感方向上的投影（见 3.3 节），而不是全局 MSE。

专一化的病（最危险的一个）：模型利用（model exploitation）。规划器是对模型做优化的，它会主动寻找模型误差最大的区域——因为那里往往"预测回报"最高。后果是：模型越好地服务于规划（越会被优化），越容易把误差当信号。可规划这个目标不能单独优化，必须与可校准配对（wm-ch2-l3 会给出定量处理）。

1.4 可泛化（Generalization）#

定义：在训练分布之外的动作、状态、组合上仍保持可用。

度量：

  • 分布外动作序列上的 H 步误差（例如训练动作幅度 ∣a∣≤1，测试 ∣a∣≈3）；
  • 组合泛化：训练见过 A 与 B，测试 A 与 B 的新组合；
  • 插值 vs 外推分开报（这两者的难度完全不同：插值通常可控，外推是模型结构问题）。

专一化的病：为泛化牺牲拟合精度（强正则、过度抽象的隐空间）→ 在训练分布内的控制精度下降。"抽象到失去控制所需的细节"是这条路线的典型失败（wm-ch3-l4 会正面讨论）。

1.5 可校准（Calibration）#

定义：模型给出的不确定性与真实误差的统计关系正确。

度量：

  • 期望校准误差 ECE=∑m​n∣Bm​∣​∣acc(Bm​)−conf(Bm​)∣；
  • NLL 与 MSE 的差（两者的差就是"方差预测带来的收益"）；
  • 区间覆盖率（1σ 区间应覆盖约 68%、2σ 约 95%，前提是高斯假设）；
  • epistemic 项随数据量下降（这是区分"学到了不确定性"与"输出一个常数方差"的判据，wm-ch2-l3）；
  • 锐度：区间宽度不能退化为无信息（这一条必须与覆盖率同时看，否则"永远输出大方差"能刷出漂亮覆盖率）。

专一化的病：保守化——不确定性永远巨大 → 规划器不敢行动（惩罚项压过回报项），或规划退化成"只在确定性区域挪动"。"校准得好但没用"是一种真实且常见的失败。

1.6 五目标速查表#

目标 一句话 主要度量 单独优化会坏掉什么
可预测 预测分布准 H 步 NLL / RMSE / R2 动作被忽略、多模态被抹平
可控 动作响应正确 ρˉ​cf​≈1、动作可辨识性 过度敏感、放大噪声
可规划 想象能换来真实回报 闭环回报、后悔、决策相关精度 模型利用、误差当信号
可泛化 分布外仍可用 OOD 动作/状态/组合误差 拟合精度下降、抽象掉控制所需细节
可校准 不确定性统计正确 ECE、覆盖率 + 锐度、epistemic 随数据下降 保守到无法规划、区间无信息

二、冲突矩阵：为什么它们不能同时最优#

下面五对是机制上最尖锐的冲突。每一条都给出机制，而不是"经验上难兼顾"。

2.1 可预测 ↑ 常常伴随 可控 ↓#

机制：可预测的最优解只依赖 s 时，把 a 当成条件里的一维"干扰"是安全的——如果 a 的方差在数据里小、或者 s 已经能解释大部分方差，模型会把权重压到 s 上。这不是训练不好，是风险最小化的正确解。 极端情形：一个完全忽略动作的模型可以比真模型有更低的 MSE（因为少估计一组参数、方差更小）。

判据：两者必须分开测。若 ρˉ​cf​≈0 而可预测指标很好，这个模型对规划的价值就是 0。

2.2 可校准 ↑ 与 可预测 ↑ 在有限数据下冲突#

机制：可预测（用 NLL 衡量）奖励"锐利的正确预测"；但锐化预测必然更低估计方差。在数据不足处，正确的做法是给出宽区间（保守），这会让 NLL 变差。校准的"正确答案"本身依赖于数据量：数据多的区域应收窄，数据少的区域应放宽。

判据：看分解后的 epistemic 项是否随数据下降。若一个模型在所有区域的方差都一样，它既没校准也没锐度。

2.3 可规划 ↑ 与 可预测 ↑ 冲突：决策相关 ≠ 全局准确#

机制：规划只需要模型在决策边界附近准确。一个在无关区域误差很大、但在关键区域精确的模型，规划收益可以高于一个全局 MSE 更低的模型。反过来，把容量平均分配给全局精度，会在规划器实际访问的区域欠拟合。

判据：模型选择时用闭环回报（1.3 的度量），而不是留出集 MSE。

2.4 可泛化 ↑ 与 可规划 ↑ 冲突：抽象的两面#

机制：泛化要求丢弃细节（抽象）；规划要求保留动作响应的细粒度因果结构。一个把"物体的颜色、接触细节"抽象掉的表征可能泛化得很好（跨物体迁移），却让抓取规划失效——因为接触动力学正是控制需要的细节。

判据：分别测"跨分布迁移后的规划回报"与"训练分布内的规划回报"；只看前者会选出空洞的模型。

2.5 可校准 ↑ 与 可控 ↑ 冲突：不确定性可以掩盖动作通道#

机制：一个把动作效应塞进"大方差"里的模型，可以在 NLL 上表现不错（因为方差覆盖了误差），同时 ρˉ​cf​ 很低。不确定性成了动作无能的遮羞布。

判据：校准指标必须与 ρˉ​cf​ 联测；同时看"条件方差是否随动作幅度变化"（真正学到动作效应的模型，不同动作的预测方差应当不同）。

2.6 冲突矩阵#

行目标提升时，列目标的变化方向（↓ = 容易变差，≈ = 大体正交，↑ = 常常一起变好）：

↓提升 / →影响 可预测 可控 可规划 可泛化 可校准
可预测 — ↓ ≈ ↓ ↓
可控 ↓ — ↑ ≈ ≈
可规划 ≈ ↑ — ↓ ↓（若无不确定性处理）
可泛化 ↓ ≈ ↓ — ≈
可校准 ↓ ≈ ↓（保守） ≈ —

⚠️ 这张表要按"机制"读，不要当定律背。方向和强度取决于环境、数据量与用途。它的用途是提醒：任何"我在所有指标上都更好"的宣称，都需要解释它是怎么绕开这些机制的。

三、必须牺牲一个时，判据是什么#

"看情况"不是判据。下面三条是可执行的决策规则。

3.1 规则一：按用途定权重#

用途 首要目标 可以牺牲 理由
短视界 MPC（在线规划） 可控 + 决策相关精度 全局可预测、长时泛化 只用前几步，误差来不及放大；每步都有真实观测纠偏
想象训练策略（Dreamer 类） 可校准 + 可预测（长时） 单步 MSE 策略会在模型里"钻空子"，不确定性是必需品；想象要能走远
数据增广 / 生成 可预测 + 可泛化 严格可控 目标是把数据分布扩开，不要求每条 rollout 可执行
策略评测 / 模拟器替代 可校准 + 可控 视觉保真 评测结论必须可信，伪影不重要

规则一的操作形式：先写下用途，再从上表查出"首要"与"可牺牲"，然后只为"首要"列设验收阈值，其余列作为诊断项。

3.2 规则二：按误差的不对称性定风险偏好#

如果两类错误代价不对称（例如机器人撞墙的代价远高于走得慢），那么目标不该是期望回报，而是风险度量，例如条件风险价值：

CVaRα​(Z)=E[Z∣Z≤VaRα​(Z)](最差的 α 分位上的平均)

此时aleatoric 不确定性会直接改变最优动作：一个"期望更好但尾部更差"的动作会被风险敏感的目标否决。这与"用不确定性做悲观惩罚"是两件不同的事（前者是目标函数，后者是模型信任域），wm-ch2-l3 会区分。

3.3 规则三：把误差按规划器的敏感度加权（决策相关）#

这是本节最重要的技术点。规划损失对模型误差的敏感度，取决于规划器在哪儿用它。

以视界 H、终端代价 c(sH​) 的 MPC 为例，规划器输出

J(θ)=a1:H​min​ c(s^H​(θ)).

模型误差 δ=f^​−f 经过 H 步传播到终端状态的偏差为 ΔsH​≈∑k​(∏j>k​Jj​)δk​（wm-ch1-l3 的 3.4 节）。于是

​J(θ)−J(θ∗)​ ≲ ​∂s∂c​​∞​⋅∥ΔsH​∥.

​J(θ)−J(θ∗)​ ≲ ​∂s∂c​​∞​⋅∥ΔsH​∥.

读法：模型误差只有在代价梯度大的方向上才伤害规划。因此正确的训练目标不是 E∥δ∥2，而是

θmin​ E[​∂s∂c​(s^H​)⋅ΔsH​​2]或更一般的θmin​ E[决策损失(f^​θ​)].

这条路线有两个名字：value-aware model learning（把模型学习与价值/决策目标对齐，Farahmand et al., 2017 的口径）与 value equivalence（只要求模型在值/策略/奖励意义上等价，Grimm et al., 2020/2021 的口径，MuZero 是它的著名实例）。代价是：目标依赖规划器，而规划器又依赖模型 → 目标会移动，训练不再是一个稳定的监督问题。

3.4 与模拟器近似的界#

另一个角度的定量判据来自经典的 simulation lemma（Kearns & Singh, 2002 的口径）。设奖励误差 ∣R^−R∣≤εR​，转移的 TV 距离 ∥T^−T∥TV​≤εP​，奖励有界 R∈[0,Rmax​]，则对任意策略

​VM^(π)−VM(π)​∞​ ≤ 1−γεR​+γεP​Rmax​/(1−γ)​.

推导思路（不是引用）：把 Vπ−V^π 按 Bellman 方程展开，每一步用 ∣Es′∼T^​[V^]−Es′∼T​[V^]∣≤εP​⋅span(V^)≤εP​Rmax​/(1−γ) 控制转移误差项，再对 t 求和得几何级数。关键结论是那个 1−γ1​ 的二次放大：模型误差不是以原尺度进入回报，而是以 1−γ1​ 的因子进入价值，再以 1−γ1​ 进入策略排序。所以"模型只要差不多准"这个说法是危险的——回报对模型误差的敏感度由折扣因子决定。

四、D1–D4 与五目标的关系#

它们不是两套东西，而是"目标 → 可执行测试"的映射：

判别问句 直接对应 间接对应
D1 状态问句 可预测（状态是否足以为预测提供信息） 可泛化（状态是否抽象掉无关细节）
D2 动作问句 可控 可规划（没有动作敏感就没有可排序的动作）
D3 rollout 问句 可规划（能走多远） 可预测（长时）
D4 校准问句 可校准 可规划（风险取舍必须靠它）

依赖方向是：D1 是前提，D2 是入场券，D3 决定视界，D4 决定能不能安全地用。任何一条挂了，系统在那个用途上就不成立——这也是为什么"模型的验收"必须是一张表，而不是一个数字。

代码#

这段代码在同一环境上训练四个候选模型，测五个目标，用数字展示没有哪个模型在所有列上都赢：

  • M1 全量线性模型：同时拟合状态与动作；
  • M2 忽略动作：只拟合状态（可预测的最优解可能选它）；
  • M3 动作系数衰减 70%：模拟"过度正则/误差变量/容量不足"导致的动作通道欠拟合；
  • M4 bootstrap 集成（5 个成员）：给出预测均值与方差，用于校准与悲观规划。

要看的四个模式：① M2 的单步 RMSE 可能最接近或最好，但 D2≈0、闭环规划完全失败；② M3 处在中间——单步也不差，D2 只有 0.3，规划明显退化；③ M4 的校准（1σ 覆盖率）最好，但它的单步精度并不占优；④ 分布外（大动作）时所有线性模型都过冲（D2 比值 >1），说明"可控"与"可泛化"是两个独立维度。

⚠️ 本代码数据全部为合成数据，不代表任何真实数据集。

"""WM ch1-l4：五个设计目标在同一环境上的冲突（合成数据）。
环境：2 维点质量 + 饱和动作效应（tanh）。刻意设两件事：
  ① 过程噪声大（aleatoric 主导单步误差）→ 单步指标区分不出模型；
  ② 动作在 tanh 饱和区 → 线性模型在大动作上过冲，把"可控"与"可泛化"分开。
四个候选：全量线性 / 忽略动作 / 动作衰减 0.3 / bootstrap 集成。
五个目标：可预测(RMSE) · 可控(D2) · 可规划(闭环终端距离) · 可泛化(OOD 动作) · 可校准(1σ 覆盖率)。
只依赖 numpy。运行：/opt/homebrew/bin/python3.10 <file>
"""
import numpy as np

SEED = 0
rng = np.random.default_rng(SEED)
D = 2
A = 0.98 * np.array([[np.cos(0.02), -np.sin(0.02)], [np.sin(0.02), np.cos(0.02)]])
B = np.array([0.08, 0.04])
SAT = 0.7          # tanh 饱和系数：|u|>~2 时动作效应饱和
NOISE = 0.20       # 过程噪声：aleatoric 主导单步误差（这是本实验的关键设定）
GOAL = np.array([1.0, 0.5])

def true_step(s, u):
    return A @ s + B * np.tanh(SAT * u) + rng.normal(0, NOISE, D)

def gen(n, u_std=1.0):
    S = rng.normal(0, 0.8, (n, D)); U = rng.normal(0, u_std, n)
    Y = np.array([A @ S[i] + B * np.tanh(SAT * U[i]) for i in range(n)]) + rng.normal(0, NOISE, (n, D))
    return S, U, Y

Str, Utr, Ytr = gen(4000)
Ste, Ute, Yte = gen(600)
So, Uo, Yo = gen(600, u_std=3.0)      # OOD：动作幅度是训练的 3 倍 → 进入 tanh 饱和区

def fit(S, U, Y, use_action=True, lam=1e-8):
    Phi = np.hstack([S, U[:, None]]) if use_action else S
    W = np.linalg.solve(Phi.T @ Phi + lam * np.eye(Phi.shape[1]), Phi.T @ Y)
    return (W[:D].T, W[D:].ravel()) if use_action else (W.T, np.zeros(D))

A1, b1 = fit(Str, Utr, Ytr)                       # M1 全量线性
A2, b2 = fit(Str, Utr, Ytr, use_action=False)     # M2 忽略动作
A3, b3 = A1, 0.30 * b1                            # M3 动作衰减 70%

# M4：bootstrap 集成（重采样拟合），成员分散度近似 epistemic 不确定性
members = []
for m in range(5):
    idx = rng.integers(0, len(Str), len(Str))
    members.append(fit(Str[idx], Utr[idx], Ytr[idx]))

# aleatoric 分量：模型无法解释的残差；预测不确定性 = epistemic(集成分散) + aleatoric(残差)
sigma_ale = float(np.sqrt(np.mean((Str @ A1.T + Utr[:, None] * b1 - Ytr) ** 2)))

def pred(m, S, U):
    if m == 2:
        return S @ A2.T
    if m == 3:
        return S @ A3.T + U[:, None] * b3
    return S @ A1.T + U[:, None] * b1

def pred_ens(S, U):
    P = np.stack([S @ Am.T + U[:, None] * bm for Am, bm in members])   # (M,N,D)
    return P.mean(axis=0), P.std(axis=0)

def rmse(m, S, U, Y):
    return float(np.sqrt(np.mean((pred(m, S, U) - Y) ** 2)))

def true_delta(S, U):
    """真实动作效应 f_true(s,+u)-f_true(s,-u)，形状 (N,D)。
    设计决策：B 是 (D,) 而 tanh 是 (N,)，必须显式广播。"""
    return B[None, :] * (np.tanh(SAT * U) - np.tanh(-SAT * U))[:, None]

def d2(m, S, U):
    """反事实分离度：|f(s,+u)-f(s,-u)| / |f_true(s,+u)-f_true(s,-u)|。"""
    num = np.linalg.norm(pred(m, S, U) - pred(m, S, -U), axis=1).mean()
    den = np.linalg.norm(true_delta(S, U), axis=1).mean()
    return float(num / den)

def mpc(m, s0, H=12, nM=400):
    """随机打靶 MPC：在模型里挑终端最接近目标的动作序列，只执行第一步（滚动重规划）。"""
    U = rng.normal(0, 1.0, (nM, H)); S = np.repeat(s0[None, :], nM, axis=0)
    for t in range(H):
        S = pred(m, S, U[:, t]) if m in (1, 2, 3) else pred_ens(S, U[:, t])[0]
    return U[np.argmin(np.linalg.norm(S - GOAL, axis=1)), 0]

def closed_loop(m, steps=30, episodes=5):
    dists = []
    for _ in range(episodes):
        s = rng.normal(0, 0.8, D)
        for _t in range(steps):
            s = true_step(s, mpc(m, s))
        dists.append(np.linalg.norm(s - GOAL))
    return float(np.mean(dists))

def coverage(S, U, Y):
    """用 M4 的预测标准差（epistemic + aleatoric）检验 |z|<=1 的比例；高斯下期望 ≈ 0.68。"""
    mean_, std_ens = pred_ens(S, U)
    std_pred = np.sqrt(std_ens ** 2 + sigma_ale ** 2)
    z = np.abs((Y - mean_) / (std_pred + 1e-12))
    return float((z <= 1.0).mean()), float(std_ens.mean())

print(f"[env] 2 维点质量 + tanh 饱和动作；过程噪声 sigma={NOISE}（aleatoric 主导）；seed={SEED}")
print(f"[数据] 训练/留出 {len(Str)}/{len(Ste)}；OOD 动作幅度 3x；闭环规划 30 步 x 5 episode")
print(f"[不确定度分解] aleatoric(残差) sigma_ale={sigma_ale:.4f}，epistemic(集成分散) 见下\n")

print(f"{'模型':<14} | {'可预测 RMSE':>10} | {'可控 D2':>7} | {'可泛化 D2(3x)':>12} | {'可规划 终端距离':>14} | {'可校准 1sig':>10}")

    print(f"{name:<14} | {rmse(m, Ste, Ute, Yte):>10.5f} | {d2(m, Ste, Ute):>7.3f} | "
          f"{d2(m, So, Uo):>12.3f} | {closed_loop(m):>14.4f} | {'—':>10}")

mean_o, std_ens = pred_ens(Ste, Ute)

读法：

  1. M2（忽略动作）的可预测列与 M1 几乎相同——因为 B⋅tanh(0.7u) 的方差相对状态演化很小。但它的 D2 ≈ 0、闭环终端距离接近"完全不动"，规划价值为 0。这正是 2.1 节冲突的实测。
  2. M3（动作衰减 0.3）处在中间：单步 RMSE 与 M1 同量级，D2 只有约 0.3，闭环规划明显退化但没有完全失效。"学得不够"和"完全没学"在单步指标上无法区分，在规划上可以。
  3. M4（集成）的 1σ 覆盖率接近 0.68（高斯假设下的期望），说明它的不确定性是可用的；但它的可预测精度并不比 M1 好——可校准与可预测是两个独立维度。
  4. OOD 那列（3 倍动作幅度）：所有线性模型的 D2 都大于 1，因为真实动力学在 tanh 饱和区，而线性模型线性外推 → 过冲。这解释了"可控"与"可泛化"为什么必须分开测：在训练分布内 D2≈1 的模型，在分布外可以系统性高估动作效应，而规划器会被这种高估吸引去用极端动作。

⚠️ 这段实验的边界：环境是低维、近似线性、噪声很小的合成系统，四个模型也都是线性/集成线性——它证明的是"五个目标可以互相背离"这个结构性事实，而不是某种方法的优劣。真实系统里"可规划"一列的噪声会大得多，闭环评测需要多次重复与置信区间（第 6 章的评测协议要处理这件事）。

练习#

  1. 给五个目标各写一个可执行测试：要求写出数据、对照、度量与阈值，不许出现"效果好"这类不可执行的判据。至少有一个测试必须是闭环的。
  2. 证明一个断言：构造一个环境，使得"忽略动作的模型"同时在 R2 与 NLL 上优于真模型（提示：让动作对下一状态的影响远小于自然演化的方差，同时真模型要估计更多参数）。用分解的语言说明这为什么不意味着它更好。
  3. 推导回报偏差界：按 3.4 节的思路推导 simulation lemma，写清每一步用到的假设（奖励有界、TV 距离、折扣），并说明 1−γ1​ 出现两次的原因。取 γ=0.99，算出模型误差被放大多少倍。
  4. 决策相关精度的度量设计：设计一个度量，用来衡量"模型误差在代价梯度方向上的投影"。说明它在什么情况下会与全局 MSE 给出相反的排序，并造一个小例子验证。
  5. 校准与可控的联测：设计一个实验，能够识别出"用大方差掩盖动作无能"的模型。要求给出至少两个判据（提示：条件方差是否随动作幅度变化；D2 与覆盖率的联合分布）。
  6. 风险敏感：构造一个两动作的例子，使期望回报最高的动作不是 CVaR0.25​ 最优的动作。写出两个动作的分布与两个目标值。
  7. 规则一的实操：给定"用世界模型给机器人抓取策略做在线 MPC"这一用途，从 3.1 的表里选出首要目标与可牺牲目标，写出你的验收阈值（至少三项），并说明你的选择在什么条件下会翻转。

小结#

  • 五个设计目标：可预测（NLL/RMSE/R2）、可控（ρˉ​cf​≈1、动作可辨识性）、可规划（闭环回报/后悔/决策相关精度）、可泛化（OOD 动作·状态·组合误差）、可校准（ECE、覆盖率 + 锐度、epistemic 随数据下降）。
  • 每个目标都有"专一化的病"：可预测 → 忽略动作；可控 → 过度敏感；可规划 → 模型利用；可泛化 → 抽象掉控制细节；可校准 → 保守到无法规划。
  • 冲突是结构性的，不是实现缺陷：可预测与可控冲突（少估动作参数能降方差）；可校准与可预测在有限数据下冲突（锐化必然低估方差）；可规划与全局可预测冲突（决策相关 ≠ 全局准确）；可泛化与可规划冲突（抽象 vs 细粒度因果）；可校准与可控冲突（不确定性能掩盖动作无能）。
  • 三条决策规则：① 按用途定权重（MPC / 想象训练 / 数据增广 / 策略评测各自的首要目标不同）；② 按误差不对称性选风险度量（CVaR 会让 aleatoric 不确定性直接改变最优动作）；③ 把误差按规划器敏感度加权——模型误差只有在代价梯度大的方向上才伤害规划，这是 value-aware model learning 与 value equivalence 的共同出发点。
  • simulation lemma 给出"模型要多准"的定量答案：∣VM^−VM∣∞​≤1−γεR​+γεP​Rmax​/(1−γ)​。模型误差以 1−γ1​ 的因子进入价值，再以 1−γ1​ 影响策略排序——所以"差不多准"是危险的说法。
  • D1–D4 是五目标的可执行投影：D1→可预测/可泛化，D2→可控，D3→可规划，D4→可校准。验收必须是这张表，而不是一个数字。
  • 本课的下一步：本章建立了判据，但没有回答"那个状态到底怎么学出来"。第 2 章进入表征学习与不确定性：重建目标为什么常常是错的激励、随机动力学怎么设计、不确定性怎么估、以及 rollout 为什么会发散、怎么抑制。
