机器学习工作流程#

机器学习不是"拿到数据、丢进模型"这么简单。一个靠谱的项目通常遵循一套固定的流程。本课把这套流程拆开讲清楚，并用一段代码把它从头到尾串起来。这一课也是后面 chapter-2（scikit-learn 工作流）的"地图"。

一、概念讲解#

一个典型的机器学习项目大致包含下面几个环节：

  1. 明确问题：先想清楚要解决什么——是分类、回归还是聚类？业务上怎么算"成功"？这一步决定后面所有选择。
  2. 获取数据：从数据库、CSV、接口等拿到数据。scikit-learn 也自带一些示例数据集（load_* 是打包好的小数据，fetch_* 会联网下载）。
  3. 数据清洗与预处理：处理缺失值、异常值、重复数据，把类别文字转成数值，把不同量纲的特征缩放到同一范围。这部分是 chapter-3 的重点。
  4. 划分数据集：把数据分成训练集和测试集。用训练集训练模型，用测试集检验它在"没见过的新数据"上的表现。绝不能用测试集来训练，否则评估结果会虚高。
  5. 选择并训练模型：根据问题类型选算法（分类用 KNN、逻辑回归等，回归用线性回归等），调用 fit() 训练。
  6. 评估模型：用准确率、混淆矩阵、均方误差等指标，在测试集上衡量好坏。
  7. 调优与部署：调整超参数、交叉验证，满意后再把模型上线供真实业务调用。

其中第 4 步"划分数据集"尤其重要。如果拿训练过的数据去评估，模型只要"背答案"就能得高分，却无法泛化到新数据。划分时通常还会保证训练集和测试集的类别比例一致（分层抽样 stratify）。

二、可运行代码示例#

下面用鸢尾花分类把上面 7 个环节走一遍。代码里每一步都有注释，标注它对应流程中的哪一环。

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import classification_report

# 环节 2 · 获取数据：加载自带数据集（150 朵花、4 个特征、3 个品种）
iris = load_iris()
X, y = iris.data, iris.target
print("特征形状：", X.shape, "标签形状：", y.shape)

# 环节 4 · 划分数据集：75% 训练，25% 测试；stratify 保证类别比例一致
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42
)

# 环节 3 · 预处理：标准化，让 4 个特征处于同一量纲
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)   # 在训练集上拟合统计量并变换
X_test = scaler.transform(X_test)         # 测试集只变换，不重新拟合

# 环节 5 · 训练模型：K 近邻分类器
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)

# 环节 6 · 评估模型：在测试集上查看分类报告
y_pred = model.predict(X_test)
print("\n分类报告：")
print(classification_report(y_pred, y_test, target_names=iris.target_names))

注意两个细节，它们会在后面的课程里反复出现：

  • fit_transform 只用在训练集；测试集只用 transform，这样才能用训练集学到的统计量去"翻译"测试集，避免信息泄漏。
  • 评估永远在测试集上进行（y_test vs y_pred），而不是在训练集上。

三、练习#

  1. 排序题：把下面步骤按正确的机器学习流程排序：训练模型 → 获取数据 → 评估模型 → 划分数据集 → 预处理 → 明确问题。
  2. 判断题："为了让模型多学点数据，可以把测试集也喂给 fit() 一起训练。" 这句话错在哪里？
  3. 动手实验：把代码里 test_size=0.25 改成 test_size=0.1，观察分类报告里的各项指标有没有变化。训练数据变多通常会让模型表现更好还是更差？
  4. 思考题：stratify=y 的作用是什么？如果不加它，而 150 个样本里某类只有 10 个，划分后测试集里可能发生什么不理想的情况？
