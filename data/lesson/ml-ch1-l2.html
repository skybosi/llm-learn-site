三大学习类型#

上一课我们知道了机器学习是"让模型从数据中学规律"。但数据长什么样、"学"的目标是什么，差别很大。业界通常把机器学习分成三大类：监督学习、无监督学习、强化学习。本课重点讲前两类（也是 scikit-learn 覆盖的主流），强化学习只做简要介绍。

一、概念讲解#

1. 监督学习（Supervised Learning）#

监督学习的特点是：训练数据里每条样本都带标签，模型学习"从特征映射到标签"的关系。

  • 分类（Classification）：标签是离散的类别。例如判断一封邮件是"垃圾邮件"还是"正常邮件"、识别图片里的花是"山鸢尾"还是"变色鸢尾"、判断贷款申请是"通过"还是"拒绝"。
  • 回归（Regression）：标签是连续的数值。例如预测房价、预测明天的气温、预测用户的消费金额。

判断是分类还是回归，只看一点：要预测的标签是"类别"还是"数值"。

2. 无监督学习（Unsupervised Learning）#

无监督学习的特点是：数据没有标签，模型要自己从数据内部发现结构。

  • 聚类（Clustering）：把相似的样本自动归成一组。例如把用户按消费行为分成几类人群，把新闻文章按主题自动分组。
  • 降维（Dimensionality Reduction）：在尽量保留信息的前提下，把高维特征压缩到低维，方便可视化和加速后续计算。例如把几十维的用户画像压到 2 维画散点图。

无监督学习没有"正确答案"来打分，评价好坏更依赖业务判断（比如"分出来的 3 组用户是否真的行为不同"）。

3. 强化学习（Reinforcement Learning）#

强化学习里没有现成的"正确答案样本"，而是一个智能体（Agent）在环境里不断做动作、获得奖励或惩罚，通过"试错"学会能拿到最多奖励的策略。典型应用：游戏 AI、机器人控制、自动驾驶。它需要交互式的训练环境，不是本课程和 scikit-learn 的重点，了解即可。

二、可运行代码示例#

下面用 scikit-learn 分别演示分类、回归、聚类三种任务。数据都来自 scikit-learn 自带的数据集，无需额外下载。

from sklearn.datasets import load_iris, load_diabetes, make_blobs
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.linear_model import LinearRegression
from sklearn.cluster import KMeans
from sklearn.metrics import accuracy_score, mean_squared_error

# ---------- 1. 监督学习 · 分类：识别鸢尾花品种 ----------
# 150 朵鸢尾花，4 个特征（花萼/花瓣的长宽），标签是 3 个品种
iris = load_iris()
X_tr, X_te, y_tr, y_te = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42
)
clf = KNeighborsClassifier(n_neighbors=3)   # K 近邻分类器
clf.fit(X_tr, y_tr)                          # 用带标签数据训练
print("分类准确率：", round(accuracy_score(y_te, clf.predict(X_te)), 3))

# ---------- 2. 监督学习 · 回归：预测糖尿病进展指标 ----------
# 442 名患者，10 个特征（年龄、BMI、血压等），标签是病情进展的连续数值
diabetes = load_diabetes()
X_tr2, X_te2, y_tr2, y_te2 = train_test_split(
    diabetes.data, diabetes.target, test_size=0.3, random_state=42
)
reg = LinearRegression()                     # 线性回归
reg.fit(X_tr2, y_tr2)
mse = mean_squared_error(y_te2, reg.predict(X_te2))
print("回归均方误差：", round(mse, 1))

# ---------- 3. 无监督学习 · 聚类：把样本自动分成 3 组 ----------
# 生成 300 个天然聚成 3 堆的点（这里故意不给出标签）
X_blob, _ = make_blobs(n_samples=300, centers=3, random_state=42)
km = KMeans(n_clusters=3, n_init=10, random_state=42)  # 让它自己找 3 个簇
km.fit(X_blob)                               # 注意：fit 时没有传任何标签 y
print("聚类中心坐标：\n", km.cluster_centers_.round(2))
print("前 5 个样本被分到的簇编号：", km.labels_[:5])

观察输出：分类和回归的 fit(X, y) 里有标签 y，而聚类的 fit(X) 里没有 y——这正是监督与无监督最本质的区别。

三、练习#

  1. 判断任务类型（分类 / 回归 / 聚类 / 降维）：
    • (a) 预测某商品明天的销量（连续数值）。
    • (b) 判断一张 X 光片是否含病灶（是 / 否）。
    • (c) 把 1 万名用户按购物偏好自动分成 5 类，但事先并不知道该分几类。
  2. 填空：监督学习要求训练数据里每条样本都有 ____；无监督学习的数据里 ____ 标签。
  3. 动手实验：把聚类代码里的 n_clusters=3 改成 n_clusters=4，运行后会怎样？结合 make_blobs 实际生成的是 3 堆数据，说说"聚类数 k"这个参数选错会有什么后果。
  4. 思考题：请为"垃圾邮件过滤"设计一个监督学习方案：特征可以有哪些？标签是什么？属于分类还是回归？
