反向传播算法#

上一课我们学会了用链式法则求单个神经元的梯度。本课要把它推广到整个多层网络，得到深度学习最核心的算法——反向传播（backpropagation）。可以说，理解了反向传播，就理解了神经网络"如何学习"的全部秘密；后面的损失函数、优化器、正则化，都建立在这个基础之上。

一、概念讲解#

1. 反向传播要解决的问题#

训练网络时，我们有一个损失函数 L，它是所有样本预测误差的汇总。我们想知道：损失对每一个权重、每一个偏置的偏导数是多少——有了这些梯度，才能沿"损失下降最快的方向"更新参数。

网络越深，参数越多（现代模型动辄上亿参数）。反向传播的价值在于：它只花一次前向 + 一次反向的代价，就能同时算出损失对所有参数的梯度，而不是对每个参数单独求一遍。

2. 前向与反向：对称的两个过程#

以最简单的两层网络为例（输入层 → 隐藏层 → 输出层）：

前向传播（从左往右算值）：

z₁ = W₁x + b₁      （第一层线性变换）
a₁ = σ(z₁)         （隐藏层激活）
z₂ = W₂a₁ + b₂     （第二层线性变换）
ŷ  = z₂            （输出，假设线性输出）
L  = ½(ŷ − y)²     （平方损失）

反向传播（从右往左算梯度），每一步都套用链式法则"上游梯度 × 局部导数"：

∂L/∂ŷ  = ŷ − y                      （损失层）
∂L/∂W₂ = ∂L/∂ŷ · a₁ᵀ               （第二层权重）
∂L/∂a₁ = W₂ᵀ · ∂L/∂ŷ              （梯度流过第二层）
∂L/∂z₁ = ∂L/∂a₁ ⊙ σ′(z₁)           （穿过 sigmoid）
∂L/∂W₁ = ∂L/∂z₁ · xᵀ               （第一层权重）

其中 ⊙ 表示逐元素相乘，σ′(z₁) = a₁(1−a₁)。可以看到：梯度像水流一样，从输出端一层层"倒流"回输入端，每经过一层就乘上该层的局部导数。这就是"反向传播"名字的由来。

3. 算法四步总结#

任何一次参数更新都可以概括成四步：

  1. 前向传播：把输入送进网络，逐层算出激活值和最终损失。
  2. 计算损失梯度：求出损失对输出层的梯度（这是反向传播的起点）。
  3. 反向传播：从输出层往回，用链式法则逐层求出每个参数的梯度。
  4. 更新参数：用梯度下降 W ← W − η·∂L/∂W 更新所有权重偏置（η 是学习率，第 5 章细讲）。

4. 关键：局部导数只依赖本层#

注意一个很省心的性质：反向传播时，每层的"局部导数"（比如 σ′(z₁)、W₂ᵀ）都只用到本层前向时已算出的值。因此只要把前向传播的中间结果缓存下来，反向时就不用重算。PyTorch 的自动微分引擎正是这样工作的：前向时记录计算图并缓存中间值，loss.backward() 时自动沿着图反向求导。

二、可运行示例#

下面用 NumPy 手写一个两层网络（2 输入 → 3 隐藏 → 1 输出）的完整前向 + 反向，并与数值梯度对照，验证手写代码正确。

import numpy as np

# 固定随机种子，保证结果可复现
rng = np.random.default_rng(0)

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

# —— 构造网络参数与一条训练样本 ——
x = np.array([[0.6], [0.2]])          # 输入，形状 (2, 1)
y = np.array([[1.0]])                 # 目标，形状 (1, 1)

W1 = rng.standard_normal((3, 2)) * 0.5   # 第一层权重 (3, 2)
b1 = rng.standard_normal((3, 1)) * 0.5   # 第一层偏置 (3, 1)
W2 = rng.standard_normal((1, 3)) * 0.5   # 第二层权重 (1, 3)
b2 = rng.standard_normal((1, 1)) * 0.5   # 第二层偏置 (1, 1)

def forward(x, W1, b1, W2, b2):
    """前向传播：返回输出和所有中间值（供反向使用）"""
    z1 = W1 @ x + b1          # (3,1)
    a1 = sigmoid(z1)          # (3,1) 隐藏层激活
    z2 = W2 @ a1 + b2         # (1,1)
    y_hat = z2                # 线性输出
    loss = 0.5 * (y_hat - y) ** 2
    # 缓存前向中间值，反向时直接用
    cache = (x, z1, a1, y_hat)
    return y_hat, loss, cache

def backward(cache, W2):
    """反向传播：从损失出发，逐层回传，返回各参数梯度"""
    x, z1, a1, y_hat = cache

    dL_dyhat = y_hat - y            # 损失层：∂L/∂ŷ
    dL_dz2 = dL_dyhat               # 输出是线性的，∂ŷ/∂z2 = 1
    dL_dW2 = dL_dz2 @ a1.T          # (1,1)@(1,3) -> (1,3)
    dL_db2 = dL_dz2                 # (1,1)

    dL_da1 = W2.T @ dL_dz2          # 梯度流经第二层：(3,1)
    dL_dz1 = dL_da1 * (a1 * (1 - a1))   # 穿过 sigmoid，逐元素乘
    dL_dW1 = dL_dz1 @ x.T           # (3,1)@(1,2) -> (3,2)
    dL_db1 = dL_dz1                 # (3,1)

    grads = {"W1": dL_dW1, "b1": dL_db1, "W2": dL_dW2, "b2": dL_db2}
    return grads

# —— 执行前向 + 反向 ——
_, loss, cache = forward(x, W1, b1, W2, b2)
grads = backward(cache, W2)

print("前向损失 L =", float(loss))
print("∂L/∂W1 =\n", grads["W1"])
print("∂L/∂W2 =", grads["W2"].ravel())

# —— 数值梯度检验：扰动 W2[0,0] 看损失变化率 ——
def compute_loss(W1, b1, W2, b2):
    z1 = W1 @ x + b1
    a1 = sigmoid(z1)
    z2 = W2 @ a1 + b2
    return 0.5 * (z2 - y) ** 2

eps = 1e-6
W2_plus = W2.copy();  W2_plus[0, 0] += eps
W2_minus = W2.copy(); W2_minus[0, 0] -= eps
num_grad = (compute_loss(W1, b1, W2_plus, b2) -
            compute_loss(W1, b1, W2_minus, b2)) / (2 * eps)

print("数值梯度 ∂L/∂W2[0,0] =", float(num_grad))
print("反向传播 ∂L/∂W2[0,0] =", grads["W2"][0, 0])

运行后，反向传播求出的 ∂L/∂W2[0,0] 与数值梯度几乎相等（相差在 1e-5 量级以内），证明手写的反向传播是正确的。

顺带一提：真实训练中还要把这套过程对一批样本向量化，并用 W ← W − η·∂L/∂W 反复迭代更新。用 PyTorch 时，上面几十行代码可以浓缩为：loss.backward() 一步完成全部求导。

三、练习#

  1. 补全梯度：示例里打印了 W1、W2 的梯度。请仿照 W2[0,0] 的检验方法，用数值差分验证 b1[0] 和 W1[0,0] 的梯度是否正确。
  2. 改激活函数：把隐藏层的 sigmoid 换成 tanh（导数 1 − tanh²），改写反向传播里"穿过激活层"的那一步，再跑一遍并做数值验证。
  3. 手推矩阵维度：∂L/∂W₂ = ∂L/∂z₂ · a₁ᵀ 为什么是"乘 a₁ 的转置"而不是直接乘 a₁？从矩阵乘法维度（(1,1)×(1,3)）说明它为什么必须这样写。
  4. 思考：反向传播里 ∂L/∂a₁ = W₂ᵀ · ∂L/∂z₂ 这一步，把"输出层的梯度"通过权重矩阵转置"分派"给了隐藏层每个神经元。请用一句话解释：为什么是转置？
  5. 前瞻：如果网络有 100 层，反向传播要连乘 100 次局部导数。请思考：如果这些局部导数普遍小于 1 或大于 1，最深处的梯度会发生什么？这就是下一课要讲的"梯度消失与爆炸"。

为什么这样做？——理论推导#

反向传播的链式法则严格推导#

第 0 步：标量损失是唯一的"根"。

反向传播要算的是标量 L 对每个可学习参数的梯度。设网络有 L 层，第 l 层线性变换 z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}，激活 a^{(l)} = σ^{(l)}(z^{(l)})，最终损失 L = ℓ(a^{(L)}, y)。目标：求 ∂L/∂W^{(l)} 与 ∂L/∂b^{(l)}。

第 1 步：单元素版本的链式法则。

先把量退化为标量。L 依赖 z^{(l)}_i，z^{(l)}_i 依赖 w^{(l)}_{ij} 与 b^{(l)}_i。对权重元素：

∂L/∂w^{(l)}_{ij} = ∂L/∂z^{(l)}_i · ∂z^{(l)}_i/∂w^{(l)}_{ij}

而 z^{(l)}_i = Σ_j w^{(l)}_{ij} a^{(l-1)}_j + b^{(l)}_i，故 ∂z^{(l)}_i/∂w^{(l)}_{ij} = a^{(l-1)}_j、∂z^{(l)}_i/∂b^{(l)}_i = 1。于是：

∂L/∂w^{(l)}_{ij} = δ^{(l)}_i · a^{(l-1)}_j
∂L/∂b^{(l)}_i  = δ^{(l)}_i

其中 δ^{(l)}_i := ∂L/∂z^{(l)}_i 是"误差信号"。核心洞察：参数梯度 = 该神经元的误差信号 × 它接收的输入激活。 参数再多，只要算出一个标量 δ，梯度就自动得到。

第 2 步：误差信号如何在层间"倒流"（递推关系）。

δ^{(l)} 可从下一层 δ^{(l+1)} 递推得到。因为 z^{(l+1)}_k = Σ_i w^{(l+1)}_{ki} a^{(l)}_i + … 且 a^{(l)}_i = σ(z^{(l)}_i)，链式法则展开：

δ^{(l)}_i = ∂L/∂z^{(l)}_i
          = Σ_k ∂L/∂z^{(l+1)}_k · ∂z^{(l+1)}_k/∂a^{(l)}_i · ∂a^{(l)}_i/∂z^{(l)}_i
          = (Σ_k δ^{(l+1)}_k · w^{(l+1)}_{ki}) · σ′(z^{(l)}_i)

即 δ^{(l)} = (W^{(l+1)})ᵀ δ^{(l+1)} ⊙ σ′(z^{(l)})。误差信号 = 上一层的误差信号被权重矩阵转置反向加权求和，再逐元素乘以本层激活导数。 从输出端 δ^{(L)} = ∇_{a^{(L)}} ℓ ⊙ σ′(z^{(L)}) 出发逐层递推，一趟从右到左即得所有 δ。

第 3 步：从标量升维到矩阵形式（向量化）。

把第 1 步对同一层所有 (i,j) 打包：∂L/∂W^{(l)} 的第 (i,j) 元是 δ^{(l)}_i a^{(l-1)}_j，这正是外积：

∂L/∂W^{(l)} = δ^{(l)} (a^{(l-1)})ᵀ       （列向量 × 行向量 = 外积）
∂L/∂b^{(l)} = δ^{(l)}

为什么要乘 a 的转置？ 因为 δ 与 a 都是列向量，外积 δ aᵀ 给出与 W 同形的矩阵，且每个元素恰好等于对应标量偏导——这不是约定，而是链式法则逐元素展开后的必然结果。

第 4 步：反向传播 = 计算图上的动态规划。

把每个运算看成有向无环图（DAG）的节点，链式法则是"局部导数相乘 + 沿路径求和"。朴素做法要对"每条参数→损失的路径"独立求一次，路径条数随深度指数增长；反向传播把它合并成一次拓扑逆序遍历：每个节点的梯度只算一次、被所有下游复用。这正是动态规划中"记忆化"的思想——总代价从"路径条数（指数级）"降为"节点数（线性级）"。

母原理连接：反向传播 = 链式法则 + 动态规划。链式法则提供数学正确性（局部导数如何合成全局导数），动态规划提供计算可行性（每个中间梯度只算一次）。这套"沿图反向累积"的模式不限于神经网络，在自动微分、物理系统的伴随法（adjoint method）、电路灵敏度分析中是同一母原理：把全局灵敏度分解为可复用局部灵敏度的乘积。
