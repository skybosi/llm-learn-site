运算符与表达式#

数据要动起来，靠的是运算符。把数据和运算符组合起来，就构成了表达式——程序里的每一次计算，都是一个表达式在发挥作用。

一、概念讲解#

1. 表达式是什么#

表达式 = 数据 + 运算符，计算后会得到一个结果。例如 3 + 4 就是一个表达式，结果是 7；"a" + "b" 的结果是 "ab"。表达式的计算结果，可以直接打印，也可以存进变量：

result = 3 + 4 * 2   # 这个表达式的值是 11

2. 算术运算符（数字运算）#

运算符 含义 例子 结果
+ 加 7 + 2 9
- 减 7 - 2 5
* 乘 7 * 2 14
/ 除（结果是小数） 7 / 2 3.5
// 整除（只留整数部分） 7 // 2 3
% 取余（余数） 7 % 2 1
** 乘方 2 ** 3 8

其中 /、//、%、** 这几个是初学者容易混淆的，务必亲手敲一遍感受区别：

print(7 / 2)    # 3.5  普通除法，结果是小数
print(7 // 2)   # 3    整除，丢掉小数部分
print(7 % 2)    # 1    取余，7 除以 2 的余数
print(2 ** 3)   # 8    2 的 3 次方

3. 比较运算符（得到布尔值）#

比较运算符用来比较大小关系，结果一定是布尔值 True 或 False：

运算符 含义 例子 结果
== 等于 5 == 5 True
!= 不等于 5 != 5 False
> 大于 5 > 3 True
< 小于 5 < 3 False
>= 大于等于 5 >= 5 True
<= 小于等于 5 <= 4 False

特别提醒：判断"相等"用的是两个等号 ==，一个等号 = 是赋值，两者完全不是一回事。

4. 逻辑运算符（组合条件）#

逻辑运算符用来组合多个布尔条件：

  • and（与）：两边都为 True，结果才是 True。
  • or（或）：两边只要有一个是 True，结果就是 True。
  • not（非）：取反，True 变 False，False 变 True。
print(True and False)   # False
print(True or False)    # True
print(not True)         # False

5. 运算符优先级（先算什么后算什么）#

当多个运算符混在一起时，Python 按固定的优先级计算。记住一个大致顺序即可：

  1. 括号 () —— 最优先，想先算就加括号；
  2. 乘方 **；
  3. 乘、除、整除、取余 * / // %；
  4. 加、减 + -；
  5. 比较运算符 > < == 等；
  6. 逻辑运算符 not → and → or。

不确定时，用括号明确表达你的意图，这是最稳妥也最清晰的做法：

print((2 + 3) * 4)   # 20，先算括号里的 2+3=5，再乘 4
print(2 + 3 * 4)     # 14，先算 3*4=12，再加 2

二、可运行代码示例#

# 演示各类运算符和表达式

# 算术运算
price = 9.9
count = 4
total = price * count
print("总价：", total)                 # 总价： 39.6

# 整除与取余：把 100 秒换算成"分 + 秒"
seconds = 100
minutes = seconds // 60               # 整除，得到整分钟数
remain = seconds % 60                 # 取余，得到剩余秒数
print(seconds, "秒 =", minutes, "分", remain, "秒")   # 100 秒 = 1 分 40 秒

# 比较运算
age = 17
print("是否成年：", age >= 18)        # 是否成年： False

# 逻辑运算：判断是否在合理温度区间
temp = 28
is_comfortable = temp >= 18 and temp <= 26
print("是否舒适温度：", is_comfortable)   # 是否舒适温度： False

# 用括号控制优先级
print("(2+3)*4 =", (2 + 3) * 4)       # 20

预期输出：

总价： 39.6
100 秒 = 1 分 40 秒
是否成年： False
是否舒适温度： False
(2+3)*4 = 20

要点：// 和 % 搭配可以优雅地做"拆分"；and 连接的比较要同时满足才为 True。

三、练习#

  1. 手算再验证：先手算出下列表达式的值，再用 Python 验证：15 // 4、15 % 4、3 ** 4、10 / 4。
  2. 时间换算：把 3661 秒换算成"时 + 分 + 秒"，用 // 和 % 完成，并打印结果。
  3. 比较运算：定义 a = 10、b = 3，分别打印 a > b、a == b、a != b、a % b == 1 的结果。
  4. 逻辑运算：判断"一个数既是偶数又大于 10"应如何用表达式写出来？用变量 n = 12 验证结果是 True，再换成 n = 9 验证是 False。
  5. 优先级：不加括号时，1 + 2 * 3 ** 2 等于多少？先按优先级手算，再运行验证，然后加上括号让结果变成 81。
