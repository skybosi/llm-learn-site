批量归一化与早停#

正则化家族的最后两位成员登场：批量归一化（Batch Normalization，简称 BatchNorm/BN）和早停（Early Stopping）。前者最初是为了加速训练、稳定深层网络而提出，同时自带一定正则效果；后者则是一个朴素却极有效的方法——在模型开始过拟合的那一刻，及时踩刹车。它们一个管"训练更稳"，一个管"停止更早"，配合前两课的权重衰减和 Dropout，构成了防止过拟合的完整工具箱。

一、概念讲解#

1. BatchNorm：让每层输入"规规矩矩"#

深层网络训练难，一个原因是：前一层参数一更新，后一层接收到的数据分布就跟着变（所谓内部协变量偏移），后面各层被迫不断重新适应。BatchNorm 的做法是，对每一层线性变换的输出，在当前 mini-batch 内做标准化：

x̂ = (x − μ_batch) / √(σ²_batch + ε)     （先归一化到均值 0、方差 1）
y  = γ · x̂ + β                            （再缩放和平移，恢复表达能力）

γ（缩放）和 β（平移）是两个可学习参数，让网络自己决定归一化后应该落在什么尺度。ε 是防止除零的小常数。

BN 的三大好处：

  1. 加速收敛：每层输入都被拉到合理尺度，可以用更大的学习率，收敛明显更快。
  2. 稳定训练：减轻对权重初始化的敏感度，深层网络也不易发散。
  3. 轻微正则：每个 batch 的均值方差带随机性，相当于给训练注入了轻微噪声，有一点抑制过拟合的效果（也因此 BN 有时能替代或削弱 Dropout 的需求）。

2. 训练与测试的差异（关键细节）#

训练时用当前 batch 的均值方差做归一化；但测试时可能只有一条样本，算不出 batch 统计量。于是 BN 在训练过程中维护一组全局统计量（running_mean、running_var），用指数滑动平均不断更新；测试时改用这组全局统计量。

在 PyTorch 里，这一切由 model.train() / model.eval() 自动切换——和 Dropout 一样，评估时忘记 model.eval() 是最常见的坑。

3. 早停：在过拟合前刹车#

训练时经常能看到：训练损失一路下降，而验证损失降到某个最低点后开始回升——回升的那一刻，就是过拟合开始的信号。早停的思想朴素而有效：持续监控验证损失，一旦它连续若干轮不再创新低，就停止训练，并回退到验证损失最低的那次参数。

  • patience（耐心值）：允许"验证损失不下降"的最大轮数。太小时容易过早停止（还没收敛就停了），太大时又回到过拟合。
  • 通常配合模型检查点（checkpoint）：每轮都把"当前最佳验证损失对应的参数"存下来，最后用那份参数。

早停之所以算正则化，是因为它限制了训练轮数，从而限制了模型"继续去背噪声"的机会。

二、可运行示例#

示例 1：BatchNorm 加速收敛

import torch
import torch.nn as nn

torch.manual_seed(0)

x = torch.linspace(-3, 3, 200).view(-1, 1)
y = torch.sin(x) + 0.1 * torch.randn_like(x)

def make_net(use_bn):
    layers = [nn.Linear(1, 64)]
    if use_bn:
        layers.append(nn.BatchNorm1d(64))   # 对 64 维隐藏层做 BN
    layers += [nn.ReLU(), nn.Linear(64, 64)]
    if use_bn:
        layers.append(nn.BatchNorm1d(64))
    layers += [nn.ReLU(), nn.Linear(64, 1)]
    return nn.Sequential(*layers)

loss_fn = nn.MSELoss()

def train(use_bn, epochs=800):
    net = make_net(use_bn)
    opt = torch.optim.Adam(net.parameters(), lr=0.01)
    for _ in range(epochs):
        net.train()                # 训练模式：BN 用 batch 统计量
        opt.zero_grad()
        loss = loss_fn(net(x), y)
        loss.backward()
        opt.step()
    net.eval()                     # 评估模式：BN 用全局 running 统计量
    with torch.no_grad():
        return loss_fn(net(x), y).item()

print(f"[无 BN] 800 轮后损失 = {train(use_bn=False):.4f}")
print(f"[有 BN] 800 轮后损失 = {train(use_bn=True):.4f}")

同样轮数下，带 BN 的网络通常收敛到更低的损失——它让训练更稳、更快。

示例 2：早停实现

import torch
import torch.nn as nn

torch.manual_seed(0)

# 训练/验证数据
x_tr = torch.linspace(-3, 3, 40).view(-1, 1)
y_tr = torch.sin(x_tr) + 0.3 * torch.randn_like(x_tr)
x_va = torch.linspace(-3, 3, 40).view(-1, 1)
y_va = torch.sin(x_va) + 0.3 * torch.randn_like(x_va)

net = nn.Sequential(nn.Linear(1, 128), nn.Tanh(),
                    nn.Linear(128, 128), nn.Tanh(), nn.Linear(128, 1))
opt = torch.optim.Adam(net.parameters(), lr=0.01)
loss_fn = nn.MSELoss()

class EarlyStopping:
    """监控验证损失，连续 patience 轮不下降就停止，并保存最佳参数"""
    def __init__(self, patience=50):
        self.patience = patience
        self.best_loss = float("inf")
        self.best_state = None
        self.counter = 0
        self.early_stop = False

    def __call__(self, val_loss, model):
        if val_loss < self.best_loss:
            self.best_loss = val_loss
            # 深拷贝当前参数，作为最佳检查点
            self.best_state = {k: v.clone() for k, v in model.state_dict().items()}
            self.counter = 0
        else:
            self.counter += 1
            if self.counter >= self.patience:
                self.early_stop = True

stopper = EarlyStopping(patience=50)

for epoch in range(3000):
    net.train()
    opt.zero_grad()
    loss = loss_fn(net(x_tr), y_tr)
    loss.backward()
    opt.step()

    net.eval()
    with torch.no_grad():
        val_loss = loss_fn(net(x_va), y_va).item()
    stopper(val_loss, net)
    if stopper.early_stop:
        print(f"第 {epoch} 轮触发早停，最佳验证损失 = {stopper.best_loss:.4f}")
        break

# 回退到验证损失最低的那份参数
net.load_state_dict(stopper.best_state)
net.eval()
with torch.no_grad():
    print("回退后验证损失 =", loss_fn(net(x_va), y_va).item())

早停让我们既不用猜"该训练多少轮"，又能在过拟合真正发生前拿到验证集上表现最好的那一份参数。

三、练习#

  1. 观察 running 统计量：在示例 1 里 print(net[1].running_mean[:3])（带 BN 的网络），在训练前后各打印一次，观察它是如何从初始值逐渐更新到数据真实统计量的。
  2. 调 patience：把示例 2 的 patience 改成 5 和 500，观察早停触发的轮次与最终验证损失，说说 patience 太小/太大的后果。
