行阶梯形与高斯消元#

上一课我们把线性方程组写成了 Ax = b。这一课学习手动解方程组的系统化方法——高斯消元（Gaussian elimination）：通过三种"合法"的行变换，把增广矩阵化简成"阶梯形"，从而一步一步求出未知数。这也是 np.linalg.solve 等求解器背后的核心思想。

一、概念讲解#

1. 三种行初等变换#

对增广矩阵做以下三种操作，不会改变方程组的解：

  1. 交换两行（swap）：把第 i 行和第 j 行对调；
  2. 数乘某一行（scale）：把某一行整体乘以一个非零常数；
  3. 一行加上另一行的倍数（add）：把第 j 行的 k 倍加到第 i 行上。

这三招就是"行初等变换"。高斯消元的目标，是用它们把矩阵变成好解的形式。

2. 什么是行阶梯形#

一个矩阵如果满足下面两条，就处于行阶梯形（row echelon form）：

  • 全零行（如果存在）都排在最下面；
  • 每行第一个非零元素（称为主元/pivot）所在的列，越往下越靠右。

例如下面的矩阵就是阶梯形（* 表示主元，# 表示任意数）：

[ *  #  #  # ]
[ 0  *  #  # ]
[ 0  0  *  # ]
[ 0  0  0  0 ]

如果更进一步，让每个主元都等于 1，并且主元所在列的其余元素全部为 0，就得到行最简形（reduced row echelon form, RREF），解可以一眼读出。

3. 高斯消元的两个阶段#

  • 前向消元（forward elimination）：从上到下，用每一行的主元把下面各行的对应位置"消"成 0，最终得到阶梯形。这一阶段本质是在做"用方程 ① 消去其他方程里的 x"，再"用方程 ② 消去剩余方程里的 y"，依次类推。
  • 回代（back substitution）：从阶梯形的最下面一行开始，自下而上逐个求出未知数。最下面一行往往只剩一个未知数，直接解出；代入上一行，再解出下一个，以此类推。

4. 一个手算例子#

方程组：

2x +  y +  z = 4
6x + 2y +  z = 8
2x + 3y + 2z = 5

增广矩阵：

[ 2  1  1 | 4 ]
[ 6  2  1 | 8 ]
[ 2  3  2 | 5 ]

第 1 步：用第 1 行的主元 2，消掉下面两行的第 1 列。 第 2 行减去 3×第 1 行；第 3 行减去 1×第 1 行，得到：

[ 2  1  1 |  4 ]
[ 0 -1 -2 | -4 ]
[ 0  2  1 |  1 ]

第 2 步：用第 2 行的主元 -1，消掉第 3 行的第 2 列。 第 3 行加上 2×第 2 行，得到：

[ 2  1  1 |  4 ]
[ 0 -1 -2 | -4 ]
[ 0  0 -3 | -7 ]

现在已经是阶梯形。第 3 步回代：由最后一行得 -3z = -7，即 z = 7/3；代入第 2 行得 -y - 2·(7/3) = -4，解出 y = -2/3；再代入第 1 行得 2x + (-2/3) + 7/3 = 4，解出 x = 7/6。

二、可运行示例#

下面用 Python 实现"前向消元 + 回代"，解上面同一个方程组。

import numpy as np

def gaussian_elimination(A, b):
    """用高斯消元（前向消元 + 回代）解 Ax = b。A 是方阵。"""
    n = len(b)
    # 构造增广矩阵，用浮点数类型，方便做除法
    M = np.column_stack([A.astype(float), b.astype(float)])

    # ---- 前向消元：把 M 化成上三角（阶梯）形 ----
    for col in range(n):
        # 1) 选主元：找到当前列绝对值最大的行，交换到顶部（部分主元法）
        pivot_row = max(range(col, n), key=lambda r: abs(M[r, col]))
        if abs(M[pivot_row, col]) < 1e-12:
            raise ValueError("矩阵奇异或接近奇异，无法唯一求解")
        M[[col, pivot_row]] = M[[pivot_row, col]]   # 交换两行

        # 2) 用当前行消掉下面所有行的这一列
        for row in range(col + 1, n):
            factor = M[row, col] / M[col, col]      # 要消掉的倍数
            M[row, col:] -= factor * M[col, col:]   # 第 row 行减去 factor 倍第 col 行

    # ---- 回代：自下而上解出每个未知数 ----
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        # x[i] = (b[i] - 已知项的和) / 对角元素
        x[i] = (M[i, -1] - np.dot(M[i, i + 1:n], x[i + 1:n])) / M[i, i]
    return x

# 方程组：2x + y + z = 4; 6x + 2y + z = 8; 2x + 3y + 2z = 5
A = np.array([
    [2.0, 1.0, 1.0],
    [6.0, 2.0, 1.0],
    [2.0, 3.0, 2.0],
])
b = np.array([4.0, 8.0, 5.0])

x = gaussian_elimination(A, b)
print("高斯消元求得的解 =", x)          # 应约等于 [7/6, -2/3, 7/3]
print("与 np.linalg.solve 对比 =", np.linalg.solve(A, b))

预期输出（大意）：

高斯消元求得的解 = [ 1.16666667 -0.66666667  2.33333333]
与 np.linalg.solve 对比 = [ 1.16666667 -0.66666667  2.33333333]

要点：前向消元的本质是"每一行减去主元行的某个倍数"，这正好对应三种行变换里的"一行加上另一行的倍数"；回代时注意 M[i, -1] 取的是增广矩阵最后一列（即 b 的位置），M[i, i+1:n] 是第 i 行已经求出的未知数对应的系数。

三、练习#

  1. 手算上面例子中"第 1 步"的两次行变换，确认你得到的矩阵和文中一致。
  2. 运行示例代码，在 gaussian_elimination 里打印每次消元后的增广矩阵，观察矩阵如何一步步变成阶梯形。
  3. 用这个函数解上一课练习里的 x + y + z = 6 方程组，和 np.linalg.solve 的结果对比。
