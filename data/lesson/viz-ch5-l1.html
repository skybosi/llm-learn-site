配色方案#

颜色是图里最先被眼睛接收到的信息，但也是最容易被用坏的。一张配色糟糕的图，轻则让人看不清，重则传达错误的含义。这一课讲清颜色的三类用途、Matplotlib 内置的配色体系，以及如何为不同场景挑对颜色。

一、概念讲解#

1. 颜色承载"含义"，不只是"好看"#

在数据可视化里，颜色大致承担三种角色：

  • 分类（categorical）：用颜色区分"不同类别"，类别之间没有大小顺序，如苹果/香蕉/橙子。此时颜色应彼此差异明显，且不宜让人误以为存在渐变。
  • 顺序（sequential）：用深浅表示"从低到高"，如气温从冷到热、销量从少到多。此时应使用由浅到深的单色渐变。
  • 发散（diverging）：突出"偏离中心值"的方向，如"高于/低于平均"，用两种颜色从中间向两端发散（红-白-蓝）。

选错颜色类型，会让读者错误地解读数据关系。

2. 色盲友好与可访问性#

大约有 8% 的男性和 0.5% 的女性患有红绿色盲。因此，不要依赖"红 vs 绿"作为唯一区分手段；优先选择对色盲友好的配色（如蓝-橙），或在颜色之外再加线型、标记、文字标注作为"第二重区分"。

3. Matplotlib 的内置配色#

Matplotlib 提供了两大类颜色资源：

  • 单色/调色板：如 tab:blue、tab:orange 等 tab 系列，以及 C0~`C9` 循环色，适合分类数据。
  • colormap（颜色映射）：一串连续渐变色，通过 cmap 参数使用，适合热力图、散点图等"数值→颜色"的映射。Matplotlib 内置了上百种 colormap，主要分为：
    • 顺序型：viridis、Blues、Greens、plasma 等
    • 发散型：RdBu、coolwarm、PiYG 等
    • 分类型：tab10、Set1、Pastel1 等

4. 一个简单可靠的默认选择#

如果不确定用什么，viridis 是当前 Matplotlib 的默认 colormap，它在色盲友好、感知均匀、打印转灰度后仍可读这三方面表现均衡，是顺序型数据的稳妥起点。

二、可运行代码示例#

示例 1：顺序型 colormap 画热力图#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

# 生成一个 10×10 的"温度"矩阵（0 到 1 之间）
rng = np.random.default_rng(0)
data = rng.random((10, 10))

fig, ax = plt.subplots(figsize=(7, 5))

# cmap 指定顺序型 colormap；imshow 把数值映射为颜色
im = ax.imshow(data, cmap='viridis')
ax.set_title('热力图（viridis 顺序色）')

# 添加颜色条，并给颜色条加标签
fig.colorbar(im, ax=ax, label='数值')
plt.show()

要点：imshow(data, cmap='viridis') 把矩阵中"小数值→深紫、大数值→亮黄"按渐变映射；fig.colorbar(im, ax=ax) 把颜色条绑定到当前坐标轴，让读者知道颜色对应的数值范围。

示例 2：对比顺序色与发散色的区别#

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

# 生成一个"有正有负"的数据（如温度距平：相对平均值的偏差）
rng = np.random.default_rng(1)
data = rng.normal(0, 1, (10, 10))

fig, axs = plt.subplots(1, 2, figsize=(11, 4.5))

# 左：顺序色（不适合有正负的数据，负值和高值颜色接近）
im0 = axs[0].imshow(data, cmap='Blues')
axs[0].set_title('顺序色 Blues（不适合有正负）')
fig.colorbar(im0, ax=axs[0])

# 右：发散色（负值偏蓝、正值偏红、中间偏白，一目了然）
im1 = axs[1].imshow(data, cmap='RdBu_r')
axs[1].set_title('发散色 RdBu_r（适合有正负）')
fig.colorbar(im1, ax=axs[1])

plt.show()

要点：有正有负（以 0 为界、两端都有意义）的数据，用发散色 RdBu_r 更合适——"偏离 0 的方向和大小"一眼可辨；而 Blues 这类顺序色只表达"从低到高"，无法突出"负值"这个方向。

示例 3：分类数据用调色板#

import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

categories = ['苹果', '香蕉', '橙子', '葡萄', '梨']
sales = [120, 85, 66, 40, 30]

# 用 tab10 分类色给每根柱子赋不同颜色
colors = plt.get_cmap('tab10').colors[:len(categories)]

fig, ax = plt.subplots(figsize=(7, 4.5))
ax.bar(categories, sales, color=colors)
ax.set_ylabel('销量（箱）')
ax.set_title('分类数据的配色（tab10）')
plt.show()

要点：分类数据用 tab10 这种"彼此差异大、无渐变含义"的调色板；颜色数量要和类别数量一致，且避免把顺序色或发散色用在无顺序的类别上。

三、练习#

  1. 动手练习：把示例 2 里的 RdBu_r 换成 coolwarm、PiYG，观察正负值的颜色映射有什么不同。
  2. 判断场景：为下面三个场景各选一种合适的 colormap 或调色板，并说明理由：① 全国各省 GDP 排名；② 一周七天每天的营业额；③ 某股票相对昨日的涨跌幅（有正有负）。
  3. 色盲测试：把你画的某张彩色分类柱状图，截图后转成灰度图，看能否仅凭明暗区分不同类别；如果分不清，思考该怎么改进。
  4. 思考：为什么说"颜色数量越多越难读"？一张分类图里，类别超过多少种时你该考虑改用别的图表形式（而不是继续堆颜色）？
