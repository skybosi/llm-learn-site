张量运算#

上节课我们知道了张量是"多维数组"。但张量的价值在于运算——神经网络的前向传播，本质就是把张量一层层地做线性变换、激活、归一化。本课把最常用的几类张量运算讲透：逐元素运算、广播、矩阵乘法、归约、索引，以及容易被忽略的原地操作陷阱。

一、概念讲解#

1. 逐元素运算：形状必须一致#

加、减、乘、除以及 torch.relu、torch.exp 等函数都是逐元素进行的：两个张量的形状完全相同时，对应位置一一计算，结果形状不变。形状不同时，先看能否"广播"，不能则报错。

2. 广播（Broadcasting）：形状不同也能算#

广播是一条对齐规则：当两个张量形状不完全一致时，PyTorch 从最后一个维度向前逐维比较，某一维满足以下任一条件即可对齐：

  • 两维长度相等；或
  • 其中一维长度为 1；或
  • 其中一方缺少该维度。

满足条件的维度按较大者扩展（逻辑上复制，不真正占内存）。例如形状 (2, 3) 的张量与形状 (3,) 的向量相加，向量会被"复制"成两行后逐行相加。图 1-3 画出了这一过程。广播让代码更简洁，也避免手动 expand 造成显存浪费。

3. 矩阵乘法：与逐元素乘法区分#

这是新手最容易踩的坑：

  • A * B 是逐元素乘法，要求形状可广播对齐。
  • A @ B（等价于 torch.matmul）是矩阵乘法，要求"左矩阵列数 = 右矩阵行数"。

两个形状为 (2, 3) 与 (3, 4) 的矩阵用 @ 相乘得到 (2, 4)；若用 *，因形状 (2, 3) 与 (3, 4) 无法对齐而直接报错。图 1-4 对比了这两种运算。

4. 归约：把某个维度"压掉"#

sum、mean、max、min 能把指定维度折叠。a.sum(dim=1) 表示沿着第 1 维（列）求和，结果那一维消失。dim=0 沿行方向压，dim=1 沿列方向压，方向感要练熟。

5. 原地操作：名字带下划线#

x.add_(1)、x.mul_(2)、x.zero_() 这类带 _ 后缀的方法是原地（in-place）修改张量本身。它们省内存，但在自动微分中可能覆盖掉计算图需要的中间值而报错。初学阶段建议：需要保留梯度时用普通运算，只有明确知道后果（例如手动 grad.zero_()）才用原地操作。

二、可运行代码示例#

import torch

# ---- 逐元素运算 ----
a = torch.arange(6, dtype=torch.float32).reshape(2, 3)  # [[0,1,2],[3,4,5]]
b = torch.ones(2, 3)                                    # 全 1
print("a + b =\n", a + b)      # 逐元素相加
print("a * b =\n", a * b)      # 逐元素相乘（不是矩阵乘法！）
print("relu(a-2) =\n", torch.relu(a - 2))

# ---- 广播 ----
c = torch.tensor([10.0, 20.0, 30.0])   # 形状 (3,)
print("\n广播 a + c =\n", a + c)       # c 被复制成 2 行，逐行相加

# ---- 矩阵乘法 ----
x = torch.randn(2, 3)
y = torch.randn(3, 4)
z = x @ y                       # 矩阵乘法，等价 torch.matmul(x, y)
print("\n矩阵乘法 (2,3) @ (3,4) ->", z.shape)   # torch.Size([2, 4])

# ---- 归约 ----
print("\na.sum()       =", a.sum())          # 全部元素求和
print("a.sum(dim=0)  =", a.sum(dim=0))       # 沿行压：每列求和 -> (3,)
print("a.mean(dim=1) =", a.mean(dim=1))      # 沿列压：每行求均值 -> (2,)

# ---- 索引与切片 ----
print("\n第 0 行:", a[0])                    # 取一行
print("第 1 列:", a[:, 1])                   # 取一列
print("布尔索引:", a[a > 3])                 # 取出大于 3 的元素

# ---- 原地操作（注意带下划线）----
d = torch.tensor([1.0, 2.0, 3.0])
d.add_(10)                                   # 原地加 10，直接修改 d
print("\n原地 add_ 后 d =", d)               # [11, 12, 13]

运行时要重点观察两处：a + c 能成功（广播），而如果把 z = x @ y 改成 z = x * y 会因形状 (2,3) 与 (3,4) 无法广播而报 RuntimeError。

三、练习#

  1. 创建 a = torch.arange(12).reshape(3, 4)，计算 a.sum(dim=0) 与 a.sum(dim=1)，分别解释结果的形状和每个数字的含义。
  2. 写一行代码实现：对形状 (100, 1) 的矩阵与形状 (1, 50) 的矩阵做广播加法，得到形状 (100, 50)，并说明为什么能广播。
  3. 已知 W 形状 (784, 10)，x 形状 (64, 784)（64 个样本），要得到 (64, 10) 的输出，应该写 x @ W 还是 W @ x？验证你的答案。
  4. 找出并说明错误：torch.tensor([1, 2, 3]) * torch.tensor([[1, 2], [3, 4]]) 会报错，原因是什么？如何用广播规则改写使其有意义？
