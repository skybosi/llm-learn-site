VC 维与模型复杂度#

上一课的 PAC 定理有个致命前提：假设类 H 是有限的。可现实中几乎所有模型——所有线性分类器、所有神经网络——都构成无限的假设类。∣H∣=∞ 时，"并集界 + 霍夫丁"这条老路直接断掉：无穷多个坏事件加起来必然无穷。那"模型复杂度"到底怎么度量？答案是一把更锋利的尺子——VC 维。它度量一个无限假设类"到底能拟合多复杂的东西"，并且能无缝替换 PAC 界里的 ln∣H∣。

一、概念讲解（含推导）#

1. 先问"为什么"：无限的假设类，复杂度怎么量？#

直觉上，100 万个线性分类器"其实都差不多"——它们的表达能力被"只能画直线"这个事实限制住了。所以真正的复杂度不是"有多少个假设"，而是"能打散多少点"。这就引出打散与 VC 维的定义。

2. 打散（shattering）：能摆出所有标签组合#

给定点集 S={x1​,…,xm​}（只看样本点，不考虑标签），如果对 S 的任意一种 {0,1} 标签分配，都存在某个 h∈H 恰好给出这种分类，就说 H 打散（shatter） 了 S。

换句话说：m 个点有 2m 种可能的"正负标注方式"，如果假设类能实现全部 2m 种，就说明它在这 m 个点上"无所不能"。

VC 维（Vapnik–Chervonenkis dimension）定义为：H 能打散的最大点集的大小：

VCdim(H)=max{m:∃m 个点被 H 打散}.

如果 H 能打散任意大的点集，记 VCdim=∞。

3. 三个经典例子：VC 维怎么算#

例 1：实数轴上的区间 [a,b]。两个点能被任意打散：{0,1}、{1,0}、{1,1}、{0,0} 都能用某个区间切出来。但三个点不行：把中间那个点标为 0、两端标为 1（{1,0,1}），任何一个连续区间都不可能"只漏掉中间、包住两端"。故 VCdim(区间)=2。

例 2：平面上的线性分类器（直线）。三个点：若三点不共线，任给标签都能找到一条直线分开（{1,0,1} 也能用两条线段的思路……更准确地说，三点成三角形时八种标签全可实现）。四个点不行：四个点呈"棋盘交叉"（对角同号）时，一条直线无法把对角线的点与另一对角线分开。故 VCdim(平面直线)=3。

例 3：d 维空间的线性分类器（超平面）。一般结论是 VCdim=d+1：d+1 个仿射无关的点（d 维中的"一般位置"）总能被打散，但 d+2 个点不能（受限于一个仿射依赖关系）。这解释了为什么"特征越多，线性模型越容易过拟合"——VC 维随维度线性增长。

4. 增长函数与 Sauer–Shelah 引理：VC 维如何"取代" ∣H∣#

要把 VC 维接回 PAC 界，需要一座桥——增长函数。定义

ΠH​(m)=∣S∣=mmax​​{h∣S​:h∈H}​,

即 H 在 m 个点上最多能产生多少种不同的标签组合。若 H 打散 m 个点，则 ΠH​(m)=2m；一旦 m>VCdim，增长函数就不再是指数级。Sauer–Shelah 引理给出精确上界：

ΠH​(m)≤i=0∑d​(im​)≤(dem​)d,d=VCdim(H),m≥d.

要点：当 m 超过 VC 维后，增长函数从指数 2m 降为多项式 md。这就是 VC 维度量复杂度的真正原因——它刻画了"假设类表达能力从指数爆炸转向多项式增长"的临界点。

5. VC 维版本的泛化界：无限假设类也能 PAC#

用增长函数替换并集界里的 ∣H∣（粗略地说，∣H∣ 在 m 个点上"实际生效"的假设只有 ΠH​(m) 种），可得 VC 维版本的泛化界：以至少 1−δ 的概率，

R(h)≤R^(h)+O(mVCdim(H)ln(m/VCdim)+ln(1/δ)​​).

于是样本复杂度为 m=O(ε2VCdim​)（忽略对数项）。与上一课的有限类结果 O(ε2ln∣H∣​) 相比，ln∣H∣ 被 VCdim 替换——VC 维就是无限假设类的"有效规模"。

这条界直接回答了"为什么 VC 维度量复杂度"：

  1. VC 维进分子：VC 维越大，泛化误差上界越大，需要越多样本。模型越"能打散"，越难泛化。
  2. 样本进分母：样本越多，界越紧——与上一课的 复杂度/m​ 完全同构。
  3. 对数项温和：ln(m/VCdim) 只作对数贡献，说明"样本数超过 VC 维后，增长函数的多项式化让代价变温和"。

这也解释了实践中"经验法则"：训练样本数应至少是参数个数/VC 维的若干倍，否则泛化界松得没有意义。

二、验证性代码示例#

下面代码验证 VC 维的两个核心事实：① 区间假设类的 VC 维确实是 2（3 个点无法打散）；② 平面线性分类器能打散 3 个点、打不散 4 个点（棋盘对角）。代码只做穷举验证，不教 API。

import numpy as np

# ---------- 1) 区间假设类：验证 VCdim = 2 ----------
def interval_shatters(points):
    """穷举：给定一维点，看区间 [a,b] 能否实现所有 {0,1} 标签"""
    xs = sorted(points)
    n = len(xs)
    # 区间分类器：落在 [a,b] 内标 1，否则 0。等价于"连续的一段 1"
    achievable = set()
    for i in range(n + 1):            # 1 段从位置 i 开始
        for j in range(i, n + 1):     # 到位置 j-1 结束
            mask = tuple(1 if i <= k < j else 0 for k in range(n))
            achievable.add(mask)
    return len(achievable) == 2 ** n

print("区间假设类：")
print("  2 个点能否打散:", interval_shatters([0.0, 1.0]), "（2^2=4 种全可实现）")
print("  3 个点能否打散:", interval_shatters([0.0, 1.0, 2.0]),
      "（{1,0,1} 无法实现 -> VCdim=2）")

# ---------- 2) 平面线性分类器：验证能打散 3、不能打散 4 ----------
def linear_shatters_2d(points, tries=20000):
    """穷举所有标签组合，看是否存在一条仿射直线（符号 w·x + b）实现它。
       必须是仿射（带偏置 b）：过原点的齐次直线 VC 维只有 2，永远打散不了 3 个点。
       做法：把偏置并进特征（x1,x2 → x1,x2,1），在 3 维上搜索 w。"""
    pts = np.array(points, dtype=float)
    n = len(pts)
    pts_aug = np.c_[pts, np.ones(n)]          # 增广一列常数 1，等价于引入偏置 b
    rng = np.random.default_rng(0)            # 固定种子，结果可复现
    for mask in range(2 ** n):
        y = np.array([(mask >> i) & 1 for i in range(n)]) * 2 - 1  # ±1 标签
        found = False
        for _ in range(tries):
            w = rng.standard_normal(3)
            if np.all(np.sign(pts_aug @ w) == y):
                found = True
                break
        if not found:
            return False, mask
    return True, None

tri  = [(0, 1), (1, 0), (0, -1)]                 # 三点不共线
quad = [(1, 1), (-1, 1), (1, -1), (-1, -1)]      # 四点在正方形四角
ok3, _ = linear_shatters_2d(tri)
ok4, bad4 = linear_shatters_2d(quad)
print("\n平面线性分类器：")
print("  3 个不共线点能否打散:", ok3)
print("  4 个角点能否打散:", ok4, f"（失败标签组合 mask={bad4}，即对角同号）")

运行结果大致为：

区间假设类：
  2 个点能否打散: True （2^2=4 种全可实现）
  3 个点能否打散: False （{1,0,1} 无法实现 -> VCdim=2）

平面线性分类器：
  3 个不共线点能否打散: True
  4 个角点能否打散: False （失败标签组合 mask=6，即对角同号）

两个结果都精确复现了理论：区间只能打散 2 个点，直线只能打散 3 个点。第 2 个实验里失败的是 mask=6（二进制 0110：编号 1、2 两点为正，编号 0、3 两点为负，而这两组恰好是正方形的一组对角）——任何一条直线都无法把正方形的对角同号分开，这正是"平面直线 VCdim=3"的关键反例。

母原理连接#

本课把母原理 2（概率视角统一一切） 推到了理论最深处，同时与母原理 5（几何与线性代数视角） 深度融合：VC 维本质是几何的——它问的是"一组点能被某种几何边界（区间、直线、超平面）切分出多少种组合"。而它之所以能进入泛化界，靠的是增长函数 + Sauer–Shelah 引理这把"几何 → 组合 → 概率"的桥。记住这条主线：模型的复杂度，不是参数个数，而是它"能打散多少点"；VC 维就是这把尺子，它让无限假设类也能被 PAC 理论驾驭。
