综合报告#

前面几课我们分别练了趋势、对比、配色、标注。这一课把它们拼成一份完整的数据报告：用一套统一的数据、统一的配色和排版，把"趋势 + 对比 + 构成"组织成一个有叙述顺序的仪表盘。学完这一课，你就具备独立产出数据报告的能力了。

一、概念讲解#

1. 一份好报告 = 有顺序的"故事"#

数据报告不是把图随便堆在一起，而是按叙述逻辑排布：

  1. 总览：先用一两个数字或一张大图，让读者知道"整体情况"。
  2. 展开：再分别展开趋势、对比、构成等角度。
  3. 结论：最后落到"所以应该怎么做"。

排布时遵循"先整体、后细节，先总览、后展开"的顺序，读者才不会迷路。

2. 统一风格：一张图里的一致性#

一份报告里的多张图，应该像"同一个人画的"：

  • 配色统一：同一变量在所有图里用同一个颜色。
  • 字体与字号统一：标题、轴标签、图例的层级一致。
  • 布局统一：用 GridSpec 或 subplots 规划好每张图的位置，再统一 tight_layout。

3. 标题即结论#

报告里的图，标题最好直接写"结论"而不是"现象"。比如把"各季度营收"改成"今年营收逐季加速增长"。读者扫一眼标题就知道你想表达什么。

二、可运行代码示例#

示例：把"趋势 + 对比 + 构成"拼成一份报告#

下面用一家网店的一年数据，拼出三块内容：全年趋势、季度对比、渠道构成。

import numpy as np
import matplotlib.pyplot as plt
import matplotlib.gridspec as gridspec

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

rng = np.random.default_rng(11)

# ---- 构造统一数据源 ----
days = np.arange(1, 366)
sales_daily = 100 + 0.3 * days + 40 * np.sin(2 * np.pi * days / 365) + rng.normal(0, 25, 365)

quarters = ['Q1', 'Q2', 'Q3', 'Q4']
q_sales = [sales_daily[0:90].sum(), sales_daily[90:181].sum(),
           sales_daily[181:273].sum(), sales_daily[273:365].sum()]   # 各季度总额

channels = ['线上', '线下']
channel_sales = [q_sales[0] * 0.6, q_sales[0] * 0.4]   # 以 Q1 为例看渠道构成（示意）

# 统一的品牌色
C_MAIN = 'tab:blue'
C_SUB = 'tab:orange'

# ---- 用 GridSpec 规划布局：上面一张大图，下面两张小图 ----
fig = plt.figure(figsize=(12, 9))
gs = gridspec.GridSpec(2, 2, height_ratios=[1.2, 1], figure=fig)

# ① 顶部大图：全年趋势（跨两列）
ax1 = fig.add_subplot(gs[0, :])
ax1.plot(days, sales_daily, color=C_MAIN, linewidth=1, alpha=0.7, label='每日销售额')
window = 30
ma = np.convolve(sales_daily, np.ones(window) / window, mode='valid')
ax1.plot(days[window - 1:], ma, color=C_SUB, linewidth=2.2, label='30 天移动平均')
ax1.set_title('全年销售趋势：整体向上，且带有季节性波动', fontsize=14)
ax1.set_xlabel('天数')
ax1.set_ylabel('销售额（元）')
ax1.grid(True, alpha=0.3)
ax1.legend(loc='upper left')

# ② 左下：季度对比（柱状图，基线从 0 开始）
ax2 = fig.add_subplot(gs[1, 0])
ax2.bar(quarters, q_sales, color=C_MAIN)
for i, v in enumerate(q_sales):
    ax2.text(i, v + max(q_sales) * 0.02, f'{v:.0f}', ha='center', fontsize=10)
ax2.set_title('各季度销售额：Q4 最高')
ax2.set_ylabel('销售额（元）')
ax2.set_ylim(0, max(q_sales) * 1.2)

# ③ 右下：渠道构成（饼图，仅两个类别，适合用饼图）
ax3 = fig.add_subplot(gs[1, 1])
ax3.pie(channel_sales, labels=channels, autopct='%1.1f%%',
        colors=[C_MAIN, C_SUB], startangle=90)
ax3.set_title('Q1 渠道构成：线上为主')

# 整张画布的大标题
fig.suptitle('某网店 2024 年度经营数据报告', fontsize=18, y=0.98)
fig.tight_layout(rect=[0, 0, 1, 0.95])
plt.show()
# fig.savefig('annual_report.png', dpi=300, bbox_inches='tight')   # 导出整份报告

要点：这是前面所有知识的综合应用——GridSpec 规划"上大下小"布局、统一配色、移动平均看趋势、柱状图基线从 0 开始、饼图只用于少数类别、suptitle 加总标题。修改 height_ratios=[1.2, 1] 可以控制上下两行的高度比例。

三、练习#

  1. 完整复刻：把示例代码跑通，然后换一组你自己的数据（如"本月每日学习时长"或"每周运动量"），重做一份三块布局的报告。
  2. 加第四块：在报告里增加一块"各月环比增长率"的折线图，用 GridSpec 扩成 2×2 或 3×2 布局，并保持配色统一。
  3. 标题改写：把示例里三个子图的标题，全部改写成"结论式标题"（直接写趋势、排名、占比的结论），对比改写前后的可读性。
  4. 导出与检查：用 savefig(dpi=300, bbox_inches='tight') 导出报告，逐张检查：有没有重叠、字号是否统一、颜色是否一致、每张图是否都能独立看懂。
