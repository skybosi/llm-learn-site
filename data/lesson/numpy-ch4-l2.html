求逆与求解#

上一课我们学会了矩阵乘法。这一课用它来解决一个经典问题：解线性方程组。形如 A x = b 的方程组在工程中无处不在——电路分析、回归拟合、物理模拟，最终都落到"已知矩阵 A 和向量 b，求未知向量 x"。

求 x 有两条路：一条是"先求逆再相乘"（x = A⁻¹ b），一条是直接"解方程"（np.linalg.solve）。我们会看到，这两条路结果一样，但后者更快、更稳，是工程上的首选。NumPy 把这套工具都放在 np.linalg 子模块里。

一、概念讲解#

1. 单位矩阵与逆矩阵#

单位矩阵记作 I，它的对角线全为 1，其余位置全为 0。它扮演的角色和数字 "1" 一样：任何矩阵乘上单位矩阵都等于它自己。

A @ I = I @ A = A

如果矩阵 A 是方阵（行数等于列数），并且存在一个矩阵 A⁻¹，使得：

A @ A⁻¹ = A⁻¹ @ A = I

那么这个 A⁻¹ 就叫 A 的逆矩阵。有了逆矩阵，线性方程组 A x = b 的解就可以写成：

x = A⁻¹ b

直观理解：A x = b 表示"把未知的 x 通过变换 A 变成了已知的 b"；要求回原来的 x，就用逆变换 A⁻¹ 再作用一次，把 b "变回去"。

2. 行列式与"可逆"的判据#

不是每个方阵都有逆矩阵。判断一个方阵是否可逆，最常用的工具是行列式（determinant），np.linalg.det 可以算它。

  • 行列式不等于 0：矩阵可逆，方程组有唯一解。
  • 行列式等于 0：矩阵不可逆（叫奇异矩阵），此时 A x = b 要么无解，要么有无穷多解。

一个直观的几何解释是：行列式的绝对值等于"矩阵代表的线性变换把单位面积/体积放大或缩小了多少倍"。行列式为 0，意味着这个变换把空间"压扁"了（比如把二维平面压成一条线），信息有丢失，自然就无法唯一地"还原"回去。

3. 直接求解：np.linalg.solve#

虽然 x = A⁻¹ b 在数学上很简洁，但工程上很少真的先去求逆。原因是：

  • 求逆本身计算量更大、数值误差更容易累积；
  • np.linalg.solve(A, b) 内部用更稳定的算法（如 LU 分解）直接解方程，结果和"求逆再乘"一致，但更快、更精确。

所以记住这条实用法则：要解方程组就用 solve，只有确实需要逆矩阵本身时才用 inv（例如某些公式推导里需要显式的 A⁻¹）。

4. 当方程组"无解"：最小二乘#

现实中数据常常"自相矛盾"——方程个数比未知数多（超定方程组），不存在能同时满足所有方程的精确解。这时我们退而求其次，找"让误差平方和最小"的近似解，这就是最小二乘法，对应 np.linalg.lstsq。它是线性回归的数学根基，后面实战章节会用到。

二、可运行示例#

示例 1：单位矩阵与逆矩阵

import numpy as np

# 3x3 单位矩阵
I = np.eye(3)
print("单位矩阵 I =\n", I)

A = np.array([[2, 1],
              [5, 3]])

# 求 A 的逆矩阵
A_inv = np.linalg.inv(A)
print("A 的逆矩阵 A_inv =\n", A_inv)

# 验证：A @ A_inv 应该等于单位矩阵（可能有极小的浮点误差）
print("A @ A_inv =\n", A @ A_inv)

示例 2：解二元一次方程组

import numpy as np

# 方程组：
#   2x + y = 5
#   5x + 3y = 12
A = np.array([[2, 1],
              [5, 3]])
b = np.array([5, 12])

# 方法一：先求逆再相乘
x_inv = np.linalg.inv(A) @ b

# 方法二：直接求解（工程首选）
x_solve = np.linalg.solve(A, b)

print("求逆得到的解 =", x_inv)
print("solve 得到的解 =", x_solve)

# 验证：把解代回方程 A @ x，应该得到 b
print("验证 A @ x =", A @ x_solve)

示例 3：行列式判断可逆性

import numpy as np

A = np.array([[2, 1],
              [5, 3]])
print("A 的行列式 =", np.linalg.det(A))   # 非 0，可逆

# 构造一个奇异矩阵：第二行是第一行的 2 倍（线性相关）
S = np.array([[1, 2],
              [2, 4]])
print("S 的行列式 =", np.linalg.det(S))   # 约等于 0，不可逆

# 尝试对奇异矩阵求逆会抛出 LinAlgError
try:
    np.linalg.inv(S)
except np.linalg.LinAlgError as e:
    print("求逆失败：", e)

示例 4：最小二乘拟合超定方程

import numpy as np

# 超定方程组：3 个方程、2 个未知数，通常没有精确解
# 想象成：用直线 y = a + b*x 去拟合三个点
#   0a + 1b = 2
#   1a + 1b = 3
#   2a + 1b = 5
A = np.array([[0, 1],
              [1, 1],
              [2, 1]])
b = np.array([2, 3, 5])

# lstsq 返回 (解, 残差, 秩, 奇异值)；我们取第一个返回值
x, residuals, rank, sv = np.linalg.lstsq(A, b, rcond=None)
print("最小二乘解（截距、斜率）=", x)

# 看看拟合误差有多大（残差平方和）
print("残差平方和 =", residuals)

三、练习#

  1. 动手求解：解方程组 3x + 2y = 8、x + 4y = 9，分别用 inv 和 solve 两种方式，并验证结果。
  2. 判断可逆：计算矩阵 [[4, 7], [2, 6]] 与 [[2, 3], [4, 6]] 的行列式，判断哪个可逆；对可逆的那个求逆矩阵。
  3. 数值体验：构造一个 100×100 的随机方阵和随机向量，用 solve 求解，并用 A @ x - b 检查误差是否接近 0。
  4. 几何思考：解释为什么"行列式为 0"意味着线性变换会"压扁"空间，从而不可逆。用一个 2×2 的具体例子说明。
  5. 最小二乘应用：用 np.linalg.lstsq 拟合一条直线 y = kx + c，使其尽量通过 (1,2)、(2,4)、(3,5) 三个点，并打印拟合出的 k 和 c。
