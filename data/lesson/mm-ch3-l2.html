文本条件与引导#

上一课搭好了 Stable Diffusion 的骨架，但没讲最关键的一环：文字是怎么"指挥"图像生成的？ 这一课回答两件事——文本条件如何注入去噪网络（交叉注意力），以及如何让模型"更听话"地遵循文本（无分类器引导 CFG）。理解这两点，你就掌握了现代文生图模型"可控性"的核心。

一、概念讲解#

1. 文本编码：CLIP 把词变成"图像语义向量"#

文本条件的第一步，是让模型"读懂" prompt。CLIP 文本编码器把一段自然语言变成一个序列化的语义向量（通常取末位 token 的输出作为整体表征）。因为 CLIP 是在图文对上用对比学习训练的（让"匹配的图文"表征相近、"不匹配的"拉远），它的文本向量天然携带了图像可理解的语义——这正是它能当文生图条件的根本原因。

2. 交叉注意力：让潜变量"看到"文本#

文本向量怎么进入去噪 U-Net？答案是交叉注意力（cross-attention）。回想 Transformer 的注意力（你在 LLM 课程里实现过）：Attention(Q, K, V) 里，Q 来自"当前需要查询的位置"，K/V 来自"要参考的序列"。

在 Stable Diffusion 的 U-Net 里：

  • Q 来自潜变量（去噪过程中的图像特征）；
  • K、V 来自文本嵌入（CLIP 输出的向量序列）。

于是每个图像位置都在"问"文本："我这里的特征，应该和哪些词对齐？" 文本语义被逐层、逐空间位置地注入图像特征。这就是"红熊猫在读一本书"这句话，能具体落到"红熊猫""书"这些视觉元素上的机制。

3. 引导：从"无条件生成"到"有文本引导"#

训练文生图模型时有个技巧：以一定概率（如 10%）把文本随机置空，让模型同时学会"无条件生成"和"有条件生成"两种模式。这样在推理时，就能比较两者，放大"文本带来的差异"——这就是无分类器引导（Classifier-Free Guidance, CFG）。

CFG 的合并公式非常简洁：

ε̂_θ(x_t, t, c) = ε_θ(x_t, t, ∅)  +  w · ( ε_θ(x_t, t, c) - ε_θ(x_t, t, ∅) )
                  └── 无条件分支 ──┘      └── 文本带来的"方向" ──┘

其中 c 是文本条件、∅ 是空条件、w 是引导强度（guidance scale）。直观理解：用"有文本的预测"减去"无文本的预测"，得到文本施加的"修正方向"，再把它放大 w 倍加上去，让生成结果更贴合文本。

4. w 的取舍：一致性与多样性的权衡#

  • w = 1：退化为纯条件生成，不带额外引导；
  • w 适中（如 7.5）：文本一致性显著提升，是 Stable Diffusion 的常用默认值；
  • w 过大（如 15+）：图像过饱和、对比过强、多样性崩溃，出现"过度锐利"的塑料感。

这背后的张力是：w 越大越"听话"，但越偏离真实数据分布、多样性越低。引导强度是文生图最重要的超参数之一。

5. 与"分类器引导"的对比#

在 CFG 之前，早期工作用分类器引导（classifier guidance）：额外训练一个分类器，用其梯度 ∇ log p(c|x_t) 引导采样。它的问题是要额外训练、且在噪声图上分类。CFG 完全绕开了分类器——只用同一个去噪网络跑两次（有条件/无条件），因此成为主流，也是 Stable Diffusion 的默认做法。

二、可运行代码示例#

手动实现 CFG 的合并公式，看清"同一网络跑两次 + 外推"的精髓。

import torch

# —— 伪代码：无分类器引导（CFG）的合并 ——
def guided_noise(unet, latent, t, text_emb, uncond_emb, w=7.5):
    # 1) 条件分支：带文本
    eps_cond = unet(latent, t, encoder_hidden_states=text_emb).sample
    # 2) 无条件分支：空文本（训练时置空的 token）
    eps_uncond = unet(latent, t, encoder_hidden_states=uncond_emb).sample
    # 3) CFG：在"文本方向"上外推 w 倍
    return eps_uncond + w * (eps_cond - eps_uncond)

在 diffusers 里，guidance_scale 参数就是这里的 w，管线内部自动做了上面这件事：

from diffusers import StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
).to("cuda")

prompt = "a red panda reading a book, studio light"

# 同一句 prompt，不同引导强度
for w in [1.0, 5.0, 7.5, 12.0]:
    img = pipe(prompt, num_inference_steps=25, guidance_scale=w).images[0]
    img.save(f"cfg_{w}.png")
    print(f"w={w} 已保存 cfg_{w}.png")

对比四张图：w=1 时文本约束弱、画面松散；w 越大越"听话"，但 w=12 可能开始过饱和、出现塑料感。这组对比就是 CFG 公式在视觉上的直接体现。

三、练习#

  1. 运行上面的循环，肉眼比较 w 从 1 到 12 的变化，用一句话描述每个档位的画面特征（贴合度、饱和度和多样性）。
  2. 手推 CFG 公式：说明为什么 w=1 时退化为纯条件预测、w=0 时退化为纯无条件预测，以及 w>1 时的"外推"几何含义。
  3. 在 guided_noise 里，把 w 换成负数（如 -1），分析结果会发生什么，并解释为什么实际从不这么用。
  4. 思考题：为什么 CFG 需要训练时"随机置空文本"？如果模型从未见过空条件，推理时的 ε_θ(x_t,t,∅) 还有意义吗？
  5. 调研题：查阅 Classifier-Free Guidance 原论文，说明它相比"分类器引导"省掉了什么、又付出了什么（两次前向的算力代价）。
