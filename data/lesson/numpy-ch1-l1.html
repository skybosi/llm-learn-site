ndarray 与创建#

在数据科学中，我们几乎总是在和"表格"打交道：一张特征矩阵可能有上万行样本、几百个特征列。如果用 Python 原生列表逐元素处理这些数据，速度会慢到不可接受。NumPy 的核心数据结构 ndarray（N 维数组）正是为了解决这个问题而设计的：它把同类型的数据放进一段连续的内存里，让整块数据可以像单个数值一样参与运算。

本课我们先认识 ndarray 是什么、它和 Python 列表的本质区别，再掌握用各种方式创建数组的写法。

一、概念讲解#

1. ndarray 是什么#

ndarray 是 "N-dimensional array" 的缩写，即 N 维数组。它的三个关键特征：

  • 同质性（homogeneous）：数组里的所有元素必须是同一种数据类型（dtype），例如全是 float64 或全是 int32。
  • 固定形状：数组创建后，其元素总数（size）是固定的，改变形状只是重新组织这些元素，而不是增删元素。
  • 连续内存：元素在内存中连续存放，这使 CPU 可以高效地批量读取和运算。

2. 为什么不用 Python 列表#

Python 列表是"指针的数组"：列表里的每个元素其实是一个指向 Python 对象的引用，对象本身散落在内存各处。这样虽然灵活（可以混装不同类型），但代价是：

  • 每次访问都要先解引用，速度慢；
  • 无法利用 CPU 的向量化指令和缓存预取；
  • 没有现成的批量数学运算。

ndarray 则把原始数值直接紧凑排列，配合 NumPy 的向量化运算，一个表达式就能对百万个元素同时完成加减乘除。后续章节里我们会反复看到：能向量化就不要写 for 循环。

3. 创建数组的常见方式#

函数 用途
np.array(...) 从列表/元组等序列创建数组
np.zeros(shape) 创建全 0 数组
np.ones(shape) 创建全 1 数组
np.full(shape, val) 创建填满指定值的数组
np.empty(shape) 创建未初始化的数组（内容不确定）
np.arange(start, stop, step) 按步长生成等间隔序列（类似 range）
np.linspace(start, stop, num) 生成指定个数的等间隔序列（含端点）
np.eye(n) 生成单位矩阵

二、可运行代码示例#

下面的示例都可以直接运行。中文说明写在注释里，程序输出尽量使用英文标签，避免终端编码问题。

示例 1：从列表创建一维和二维数组#

import numpy as np

# 从列表创建一维数组
scores = np.array([92.5, 87.0, 76.5, 88.0, 95.0])
print("scores:", scores)
print("type:", type(scores))

# 从嵌套列表创建二维数组（特征矩阵：3 个样本 x 4 个特征）
features = np.array([
    [1.2, 0.5, 3.1, 2.0],
    [0.8, 1.1, 2.4, 1.5],
    [1.5, 0.9, 3.3, 2.2],
])
print("features:\n", features)

示例 2：用辅助函数生成数组#

import numpy as np

# 全 0 / 全 1 / 指定值
zeros = np.zeros((2, 3))          # 形状 (2, 3) 的全 0 数组
ones = np.ones((3,))              # 一维全 1 数组
full = np.full((2, 2), 0.5)       # 全 0.5

print("zeros:\n", zeros)
print("ones:", ones)
print("full:\n", full)

# arange 与 linspace
step_seq = np.arange(0, 10, 2)    # 0, 2, 4, 6, 8（不含终点 10）
lin_seq = np.linspace(0, 1, 5)    # 0, 0.25, 0.5, 0.75, 1.0（含两端，共 5 个）

print("arange(0, 10, 2):", step_seq)
print("linspace(0, 1, 5):", lin_seq)

# 单位矩阵
identity = np.eye(3)
print("eye(3):\n", identity)

示例 3：注意浮点步长与显式指定类型#

import numpy as np

# arange 使用浮点步长时可能产生累积误差，结尾点不可靠
a = np.arange(0, 1, 0.1)
print("arange(0, 1, 0.1):", a)

# 需要精确控制端点个数时优先用 linspace
b = np.linspace(0, 1, 11)
print("linspace(0, 1, 11):", b)

# 创建时显式指定 dtype
ints = np.array([1, 2, 3], dtype=np.int32)
floats = np.array([1, 2, 3], dtype=np.float64)
print("dtype of ints:", ints.dtype, "| dtype of floats:", floats.dtype)

三、练习#

  1. 用 np.linspace 生成从 0 到 2π 的 100 个等间隔点，并用 np.zeros 创建一个形状为 (4, 4) 的全 0 矩阵。
  2. 分别用 np.arange(0, 1, 0.25) 和 np.linspace(0, 1, 5) 生成序列，观察两者结果是否一致，并解释为什么。
  3. 创建一个形状为 (3, 5)、所有元素都是 7 的数组，要求分别用 np.full 和 np.ones 配合乘法两种方式实现。
  4. 思考：np.array([1, 2, 3.5]) 生成的数组其 dtype 是什么？为什么？（提示：同质性要求 NumPy 做类型提升）
