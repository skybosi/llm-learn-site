综合项目#

这是《无监督学习》的最后一课。前面学到的降维、标准化、聚类、评估，现在是时候串成一个完整的端到端项目了。本课以葡萄酒数据为例，走一遍"加载 → 标准化 → PCA 降维 → 选 K → 聚类 → 可视化 → 评估"的全流程，把散落的知识点焊接成一条可复用的方法论。

一、概念讲解#

1. 一个无监督项目的标准流程#

无论数据是什么，一个无监督分析项目大致都遵循这几步：

  1. 加载与探查数据：看清有多少样本、多少特征，特征含义是什么；
  2. 预处理：标准化（聚类对量纲敏感）、必要时处理缺失值；
  3. 降维：用 PCA 压到 2~3 维，既为可视化，也常能去噪、加速聚类；
  4. 选择簇数 K：用肘部法 + 轮廓系数确定；
  5. 聚类：在预处理后的（高维）数据上运行 KMeans；
  6. 可视化与解释：在 PCA 平面上着色，结合质心解读每个簇；
  7. 评估：无标签时看轮廓系数；若恰好有参考标签，可用 ARI、NMI 做外部检验。

2. 无监督下如何"评估"#

无监督任务没有标准答案，评估分两种口径：

  • 内部指标：不看标签，只衡量簇本身的质量，如轮廓系数（紧凑且分离）；
  • 外部指标：当数据集恰好带真实标签（如本例的葡萄品种）时，可"借用"标签做检验，常用调整兰德指数 ARI 和归一化互信息 NMI，取值范围大致都在 -11 或 01，越接近 1 表示聚类结果与真实分组越吻合。

注意：真实业务里通常没有标签，外部指标只是教学环境里的一种"作弊式"验证手段，用来确认流程没写错。

3. 一个要点：聚类在高维做，可视化用低维#

本例中 KMeans 是在标准化后的 13 维数据上聚的（信息更全），而散点图只是把结果"投影"到 2 维给人看。二者用的是同一套标签，但空间不同——降维负责呈现，聚类负责计算，别混为一谈。

二、可运行代码示例#

综合项目：葡萄酒数据的降维 + 聚类 + 评估#

import matplotlib.pyplot as plt
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score, normalized_mutual_info_score

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

# 1. 数据
wine = load_wine()
X, y_true = wine.data, wine.target   # y_true 仅最后做外部检验，训练时不用

# 2. 标准化 + 降维到 2 维（用于可视化）
X_scaled = StandardScaler().fit_transform(X)
pca = PCA(n_components=2, random_state=42)
X2 = pca.fit_transform(X_scaled)
print("前两个主成分累计解释方差:", pca.explained_variance_ratio_.sum().round(3))

# 3. 选 K（在高维标准化数据上用轮廓系数）
best_k, best_score = 2, -1
for k in range(2, 7):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X_scaled)
    s = silhouette_score(X_scaled, labels)
    print(f"K={k} 轮廓系数={s:.3f}")
    if s > best_score:
        best_k, best_score = k, s

# 4. 用最优 K 聚类
km = KMeans(n_clusters=best_k, random_state=42, n_init=10)
labels = km.fit_predict(X_scaled)

# 5. 可视化：左为真实标签参照，右为聚类结果
centers2 = pca.transform(km.cluster_centers_)   # 把高维质心投影到 2 维
fig, axes = plt.subplots(1, 2, figsize=(13, 5.5))
axes[0].scatter(X2[:, 0], X2[:, 1], c=y_true, cmap='tab10', alpha=0.7)
axes[0].set_title('真实类别（仅作参照）')
axes[1].scatter(X2[:, 0], X2[:, 1], c=labels, cmap='tab10', alpha=0.7)
axes[1].scatter(centers2[:, 0], centers2[:, 1], c='red', marker='X',
                s=200, edgecolors='k', label='簇中心')
axes[1].set_title(f'KMeans 聚类结果（K={best_k}）')
axes[1].legend()
for ax in axes:
    ax.set_xlabel('第一主成分'); ax.set_ylabel('第二主成分')
plt.show()

# 6. 评估：内部 + 外部
print("轮廓系数:", silhouette_score(X_scaled, labels).round(3))
print("调整兰德指数 ARI:", adjusted_rand_score(y_true, labels).round(3))
print("归一化互信息 NMI:", normalized_mutual_info_score(y_true, labels).round(3))

要点：注意聚类的 fit_predict 作用在 13 维的 X_scaled 上，而 X2 只是它的二维投影。若 ARI 和 NMI 都明显大于 0，说明无监督聚类恢复出了与真实品种接近的分组结构——这正是我们希望看到的。

三、练习#

  1. 换数据重跑：把 load_wine 换成 load_iris，原样跑一遍这套流程，比较最终 K、轮廓系数与 ARI/NMI 的变化。
  2. 去掉降维：把第 2 步的 PCA 去掉（直接用 13 维做后续），对比轮廓系数和聚类结果是否有差异，思考降维在这里到底帮了什么。
  3. 写报告：仿照本课的结构，为 load_digits 写一份简短的无监督分析小结，包含：数据规模、选 K 的依据、聚类结果的内部指标、PCA 可视化结论。
  4. 思考：如果这是一个完全没有标签的真实业务数据，你会如何判断"聚成几类最合理"？外部指标 ARI/NMI 还能用吗？
