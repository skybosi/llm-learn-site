选择激活函数#

学完了 Sigmoid、Tanh、ReLU 这一大家子，最后落到一个实际问题：搭网络时，每一层到底该用哪个激活？ 好消息是，这个问题有非常成熟的经验法则，照着做基本不会错：隐藏层默认用 ReLU，输出层按任务类型选。这一课把"隐藏层怎么选、输出层怎么选、为什么要这样选"讲清楚，再用 PyTorch 搭两个端到端的分类网络收尾。

一、概念讲解#

1. 选择背后的三条主线#

激活函数千差万别，但选型时真正要权衡的是三条主线：

  1. 会不会梯度消失/爆炸：激活函数的导数在反向传播时会被连乘。若导数常小于 1（如 Sigmoid/Tanh 的饱和区），连乘后梯度迅速趋近 0，深层根本训不动，这就是梯度消失；反之若导数持续大于 1，梯度会爆炸。因此要选"导数在大部分区间稳定、不饱和"的函数；
  2. 计算代价：指数运算（Sigmoid/Tanh）比 max 运算（ReLU）贵得多，在大网络、大数据上差距可观；
  3. 输出语义是否匹配任务：输出层要把网络输出解释成"连续值"还是"概率"，这直接决定该用什么激活、配什么损失。

2. 隐藏层：默认 ReLU，有问题再换#

现代 MLP 隐藏层的第一选择是 ReLU，理由正是上一课讲的：正区间导数恒为 1、不饱和、计算快、天然稀疏。绝大多数情况下，直接用 ReLU 就能得到不错的结果，不要过度纠结。

什么时候考虑换？

  • 出现大量"死神经元"（训练中很多神经元的输出恒为 0、学习停滞）：可换 Leaky ReLU / PReLU / ELU，让负区间保留一点梯度；
  • 收敛慢、梯度消失：ReLU 本身已缓解梯度消失，若仍出问题，多半要回头查学习率、初始化或网络深度，而不是赖激活函数；
  • 追求平滑输出或特定领域：Transformer 等现代大模型常用 GELU / Swish（ReLU 的平滑变体），在极深网络上表现更稳。

一条实用原则：先上 ReLU 跑通，把激活当作"最后再调的旋钮"，而不是一开始就纠结。真正决定效果上限的，通常是数据、网络结构和优化，而非激活函数的微小差异。

3. 输出层：由任务决定，不可套用#

输出层的激活不看"哪个好"，只看"任务要什么语义"：

任务类型 输出层激活 配套损失（PyTorch） 说明
回归（预测连续值） 无（线性） nn.MSELoss 输出要能取任意实数，不能加激活
二分类 Sigmoid（1 个输出） nn.BCEWithLogitsLoss 输出解释为"正类概率"
多分类（k 类互斥） Softmax（k 个输出） nn.CrossEntropyLoss 输出 k 个概率，和为 1
多标签分类 Sigmoid（k 个输出） nn.BCEWithLogitsLoss 每类独立判断"是/否"

两个重要的 PyTorch 细节（能少踩很多坑）：

  • 二分类建议用 BCEWithLogitsLoss，它内部先做 Sigmoid 再算交叉熵，数值更稳定——所以输出层不要再加 Sigmoid，否则等于做了两次；
  • 多分类建议用 CrossEntropyLoss，它内部先做 Softmax 再算负对数似然——所以输出层不要再加 Softmax，标签直接给类别索引（如 [0, 2, 1]），不用 one-hot。

记住一句话：Sigmoid/Softmax 常被"藏"在损失函数里，显式写出反而容易错。

4. 一个小提醒：激活和"归一化"别混淆#

有人会把 ReLU 的"输出非负"或 Sigmoid 的"压到 0~1"误当成"数据归一化"来用。要分清楚：激活是给网络注入非线性，不是用来缩放数据的；数据缩放应交给前面机器学习课程里的 StandardScaler、MinMaxScaler，或深度学习里的 Batch Normalization（批归一化，后续章节会讲）。两者职责不同，不能互相替代。

二、可运行代码示例#

示例 1：多分类 MLP——隐藏层 ReLU，输出层交给 CrossEntropyLoss

用 PyTorch 自带的手写数字数据做一个 10 分类网络，重点看"输出层不用激活 + CrossEntropyLoss"的正确姿势。

import torch
import torch.nn as nn
import torch.optim as optim
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# 数据：8×8 手写数字（10 类），拉平成 64 维特征
X, y = load_digits(return_X_y=True)
X = StandardScaler().fit_transform(X)          # 特征缩放，帮助训练
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0, stratify=y)

X_tr = torch.tensor(X_train, dtype=torch.float32)
y_tr = torch.tensor(y_train, dtype=torch.long)   # 标签是类别索引，不是 one-hot
X_te = torch.tensor(X_test, dtype=torch.float32)
y_te = torch.tensor(y_test, dtype=torch.long)

# MLP：64 -> 32(ReLU) -> 10(无激活)
model = nn.Sequential(
    nn.Linear(64, 32),
    nn.ReLU(),           # 隐藏层激活：默认 ReLU
    nn.Linear(32, 10),   # 输出层：10 个单元，不加激活
)

criterion = nn.CrossEntropyLoss()   # 内部自带 softmax + 负对数似然
optimizer = optim.Adam(model.parameters(), lr=0.01)

for epoch in range(200):
    optimizer.zero_grad()
    logits = model(X_tr)            # 输出是"logits"（未经 softmax 的原始分数）
    loss = criterion(logits, y_tr)  # 损失函数内部会做 softmax
    loss.backward()
    optimizer.step()

with torch.no_grad():
    logits = model(X_te)
    pred = logits.argmax(dim=1)     # 取概率最大的类
    acc = (pred == y_te).float().mean().item()
    print(f"测试准确率：{acc:.3f}")

运行后准确率通常能到 0.95 以上。关键点：输出层只有 nn.Linear(32, 10)，没有显式 Softmax；CrossEntropyLoss 内部替我们完成了 softmax 与交叉熵，标签直接传类别索引即可。

示例 2：二分类 MLP——输出层交给 BCEWithLogitsLoss

换成二分类场景，演示 BCEWithLogitsLoss（内置 Sigmoid）的用法。

import torch
import torch.nn as nn
import torch.optim as optim
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

X, y = load_breast_cancer(return_X_y=True)     # 30 维特征，二分类
X = StandardScaler().fit_transform(X)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0, stratify=y)

X_tr = torch.tensor(X_train, dtype=torch.float32)
y_tr = torch.tensor(y_train, dtype=torch.float32).reshape(-1, 1)  # 二分类标签 (n,1)
X_te = torch.tensor(X_test, dtype=torch.float32)
y_te = torch.tensor(y_test, dtype=torch.float32).reshape(-1, 1)

model = nn.Sequential(
    nn.Linear(30, 16),
    nn.ReLU(),
    nn.Linear(16, 1),        # 输出层：1 个单元，不加 Sigmoid
)

criterion = nn.BCEWithLogitsLoss()   # 内部自带 Sigmoid + 交叉熵
optimizer = optim.Adam(model.parameters(), lr=0.01)

for epoch in range(200):
    optimizer.zero_grad()
    logits = model(X_tr)
    loss = criterion(logits, y_tr)
    loss.backward()
    optimizer.step()

with torch.no_grad():
    prob = torch.sigmoid(model(X_te))       # 预测阶段手动转成概率
    pred = (prob > 0.5).float()
    acc = (pred == y_te).float().mean().item()
    print(f"测试准确率：{acc:.3f}")

两个例子合起来就是本课要交付的完整方法论：隐藏层 ReLU + 输出层按任务选，并把 Sigmoid/Softmax 交给对应的损失函数处理。

三、练习#

  1. 查漏纠错：下面的网络定义有两处错误，找出来并改正——多分类任务：nn.Sequential(nn.Linear(64,10), nn.Softmax(dim=1)) + nn.CrossEntropyLoss。
  2. 任务匹配：为以下三个任务分别写出输出层激活与配套损失：(a) 预测房价（连续值）；(b) 判断邮件是否垃圾（二分类）；(c) 识别 10 类手写数字（多分类）。
  3. 跑通并观察：运行示例 1，把隐藏层 ReLU 换成 Sigmoid，观察准确率和收敛速度的变化，结合"梯度消失"解释差异。
  4. 验证内置激活：在示例 2 里把 nn.BCEWithLogitsLoss 换成 nn.BCELoss，观察是否会报错或结果异常，说明为什么（提示：BCELoss 期望输入已在 0~1 之间）。
  5. 思考：为什么说"激活函数是最后才调的旋钮"？如果换激活后模型还是训不动，你接下来应该排查哪些更可能的问题？
