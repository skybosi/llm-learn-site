偏导数#

面对多元函数 z = f(x, y)，怎么度量"变化率"？现在有多个输入，问题变成了："保持其他输入不动，只动其中一个，函数变化多快？" 答案就是偏导数。这一课我们把一元导数自然地推广到多元。

一、概念讲解#

1. 偏导数：固定别人，只对一个变量求导#

求 z = f(x, y) 对 x 的偏导数时，把 y 当成常数，只对 x 求导，记作：

∂z/∂x   或   f_x(x, y)

读作"z 对 x 的偏导"。同理，对 y 的偏导是固定 x 不变，对 y 求导，记作 ∂z/∂y 或 f_y(x, y)。

直觉：∂z/∂x 衡量的是"沿 x 轴方向走一步，z 会变多少"——其他变量都被"冻住"了。

2. 怎么求：把其他变量当常数#

规则极其简单：求导法则和一元完全一样，只是把不关心的变量当普通常数。

例：z = x²y + 3x

  • 对 x 求偏导：把 y 当常数，∂z/∂x = 2xy + 3；
  • 对 y 求偏导：把 x 当常数，∂z/∂y = x²。

再例：z = x² + y²，则 ∂z/∂x = 2x，∂z/∂y = 2y。

3. 几何意义：沿坐标轴方向的切线斜率#

二元函数是一张曲面。∂z/∂x 的几何意义是：用平行于 x 轴的平面去"切"曲面，交线上那一点的切线斜率。换句话说，偏导数只告诉我们"沿坐标轴方向"的变化率，还不涉及"任意方向"——那正是下一课梯度要补全的。

4. 偏导数与机器学习#

训练神经网络时，损失 L 依赖成千上万个参数 w₁, w₂, ...。对第 i 个参数求偏导 ∂L/∂wᵢ，就是在问："只微调 wᵢ 这一个参数，损失会怎么变？" 这恰恰是参数更新时需要的"指南针"。把所有参数的偏导拼在一起，就得到下一课的梯度。

二、可运行示例#

先用手写公式 + 数值求导双重验证偏导。

def f(x, y):
    """z = x^2 * y + 3x"""
    return x * x * y + 3 * x

# --- 手写偏导公式 ---
def partial_x(x, y):
    """∂z/∂x = 2xy + 3（把 y 当常数）"""
    return 2 * x * y + 3

def partial_y(x, y):
    """∂z/∂y = x^2（把 x 当常数）"""
    return x * x

# --- 数值偏导（中心差分）---
def numeric_partial_x(f, x, y, h=1e-5):
    """固定 y，只让 x 左右微扰，近似 ∂f/∂x。"""
    return (f(x + h, y) - f(x - h, y)) / (2 * h)

def numeric_partial_y(f, x, y, h=1e-5):
    """固定 x，只让 y 左右微扰，近似 ∂f/∂y。"""
    return (f(x, y + h) - f(x, y - h)) / (2 * h)

x, y = 2.0, 3.0
print(f"在点 (x={x}, y={y}) 处：")
print(f"  ∂z/∂x  公式={partial_x(x, y):.4f}  数值={numeric_partial_x(f, x, y):.4f}")
print(f"  ∂z/∂y  公式={partial_y(x, y):.4f}  数值={numeric_partial_y(f, x, y):.4f}")

运行结果：

在点 (x=2.0, y=3.0) 处：
  ∂z/∂x  公式=15.0000  数值=15.0000
  ∂z/∂y  公式=4.0000  数值=4.0000

公式和数值完全吻合，说明"把 y 当常数"的求导法完全正确。

偏导驱动参数更新（预告梯度）#

看一个更贴近机器学习的例子：损失 L(w, b) = (w·x + b − y)² 的偏导，会告诉我们每个参数该往哪调。

def loss(w, b, x, y):
    """单个数据点的平方损失：L = (w*x + b - y)^2"""
    return (w * x + b - y) ** 2

def dL_dw(w, b, x, y):
    """∂L/∂w = 2(wx + b - y) * x"""
    return 2 * (w * x + b - y) * x

def dL_db(w, b, x, y):
    """∂L/∂b = 2(wx + b - y)"""
    return 2 * (w * x + b - y)

# 一个数据点：真实 y=2x，当前参数 w=1, b=0（偏离真实）
w, b, x, y = 1.0, 0.0, 3.0, 6.0   # 真实 y = 2*3 = 6
print(f"\n当前参数 w={w}, b={b}，数据 (x={x}, y={y})")
print(f"  ∂L/∂w = {dL_dw(w, b, x, y):.2f}  （负 → w 该增大）")
print(f"  ∂L/∂b = {dL_db(w, b, x, y):.2f}  （负 → b 该增大）")
print("  预测值 w*x+b =", w*x+b, "比真实 6 小，所以两个参数都要增大。")

∂L/∂w 和 ∂L/∂b 都是负数，告诉我们"把 w、b 调大，损失会下降"——这正是偏导作为"方向指引"的作用。

三、练习#

  1. 对 z = x³ + 3xy + y²，手写出 ∂z/∂x 和 ∂z/∂y，再用数值偏导在 (1, 2) 处验证。
  2. 对 z = sin(x)·cos(y)，写出两个偏导公式并验证（提示：对 x 求导时 cos(y) 是常数）。
  3. 在"偏导驱动参数更新"的例子里，把数据点换成 (x=3, y=9)，观察 ∂L/∂w、∂L/∂b 的符号和大小如何变化，并解释。
  4. 思考题：偏导数只描述了"沿坐标轴方向"的变化率。为什么对优化来说这还不够？带着这个疑问进入下一课。
