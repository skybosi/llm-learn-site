直方图#

直方图回答的问题是："数据整体长什么样？" 它把连续数据切成若干区间，统计每个区间里的样本数量，用来观察分布的形状、中心位置和离散程度。这一章围绕"分布"展开，先学直方图。

一、概念讲解#

1. 直方图与柱状图的区别#

上一章的柱状图比较离散类别，柱与柱之间有空隙、顺序可任意调换；而直方图统计的是连续数值落在各区间（bin）中的频数，柱子紧挨着、顺序固定由小到大。二者长得像，但数据含义完全不同。

2. 分箱（bins）是关键参数#

ax.hist(x, bins=...) 中 bins 决定把数值范围切成多少个（或哪些）区间：

  • bins=30：切 30 个等宽区间。
  • bins=np.arange(150, 190, 5)：手动指定区间边界。
  • 分箱数太少会丢失细节，太多则曲线抖动明显，需要根据数据量权衡。

3. 归一化为密度：density#

默认情况下纵轴是频数（每个区间有多少个样本）。设 density=True 后，纵轴变成概率密度：直方图的总面积归一化为 1。这样不同样本量的直方图可以直接比较，也便于把直方图和理论概率密度曲线画在同一张图上。

4. 其他常用参数#

参数 含义
bins 分箱数量或边界数组
density 是否归一化为概率密度
alpha 透明度
color / edgecolor 填充色 / 柱子描边色
histtype 直方图类型（如 "step" 只画轮廓）
cumulative 是否画累计分布

二、可运行代码示例#

下面模拟 2000 个人的身高，画概率密度直方图，并用 NumPy 计算样本均值和标准差，叠加一条理论正态分布曲线。

import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False

rng = np.random.default_rng(7)
data = rng.normal(170, 7, 2000)   # 模拟 2000 人身高

fig, ax = plt.subplots(figsize=(8, 5))

# density=True 归一化为概率密度，使直方图总面积 = 1
ax.hist(data, bins=40, density=True, alpha=0.7,
        color="#4c72b0", edgecolor="white", label="身高分布")

# 用样本均值/标准差叠加理论正态分布曲线（纯 NumPy 实现）
mu, sigma = data.mean(), data.std()
xs = np.linspace(data.min(), data.max(), 200)
pdf = 1 / (sigma * np.sqrt(2 * np.pi)) * np.exp(-0.5 * ((xs - mu) / sigma) ** 2)
ax.plot(xs, pdf, color="crimson", linewidth=2, label="理论正态分布")

ax.set_xlabel("身高（cm）")
ax.set_ylabel("概率密度")
ax.set_title("直方图：身高分布与正态拟合")
ax.legend()

plt.show()

试试把 bins 改成 10 和 80，观察直方图形状的变化。

三、练习#

  1. 生成 1000 个均匀分布样本 rng.uniform(0, 10, 1000)，画直方图，观察其形状与正态分布样本的差异。
  2. 分别用 density=False 与 density=True 画同一份数据，说明纵轴含义的差别。
  3. 用 bins=np.arange(150, 190, 5) 手动指定边界重画示例直方图，并解释为什么柱子边界会是 150、155、160……
