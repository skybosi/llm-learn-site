行列操作#

一、概念讲解#

分析数据时，很少有"拿到手就能直接用"的表格：常常要挑出几列、算一个派生列、改个列名、删掉无效行。本课聚焦 DataFrame 的增、删、改、选四类行列操作。

1. 选列#

  • df["列名"]：取单列，得到的是一个 Series。
  • df[["列A", "列B"]]：取多列，得到的是一个 DataFrame（注意双层方括号）。

2. 增列#

最直接的方式是赋值：df["新列"] = 表达式。表达式可以是标量、另一个 Series，也可以是对已有列的运算（如 df["总分"] = df["语文"] + df["数学"]）。assign() 则更"函数式"，它返回一个新 DataFrame 而不修改原对象，适合链式调用。

3. 改：重命名与改单元格#

  • rename(columns={旧名: 新名}) 重命名列；rename(index={...}) 重命名行。
  • 用 .loc[行标签, 列名] = 值 精确定位并修改某个单元格。

4. 删：drop#

drop() 可以按标签删除行或列。删列用 drop(columns=[...])，删行用 drop(index=[...])。注意 drop 默认返回新对象、不改动原表，需要赋值回去才生效。

一个重要的使用习惯：优先用 .loc / .iloc 做行列定位，避免依赖容易被误读的链式下标。

二、可运行代码示例#

import pandas as pd

df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五"],
    "数学": [88, 79, 92],
    "英语": [90, 85, 88],
})
print("原始数据：\n", df)

# 1. 选列
print("\n单列（Series）：\n", df["数学"])
print("\n多列（DataFrame）：\n", df[["姓名", "英语"]])

# 2. 新增列：基于已有列计算
df["总分"] = df["数学"] + df["英语"]
df["及格"] = df["总分"] >= 170   # 布尔列
print("\n新增列后：\n", df)

# 3. assign：链式地一次加多列，并返回新对象
df2 = df.assign(平均分=lambda d: d["总分"] / 2)
print("\nassign 新增平均分：\n", df2)

# 4. 重命名列
df2 = df2.rename(columns={"数学": "math", "英语": "english"})
print("\n重命名列：\n", df2)

# 5. 修改单个单元格（用 .loc 精确定位）
df2.loc[0, "english"] = 95
print("\n修改 (0, 'english') 单元格：\n", df2)

# 6. 删除列与删除行
df2 = df2.drop(columns=["math"])   # 删列
print("\n删除 math 列：\n", df2)
df2 = df2.drop(index=[2])          # 删行（王五）
print("\n删除第 2 行（index=2）：\n", df2)

留意第 6 步：drop 不会就地修改，所以我们每次都把返回值赋回 df2。如果忘了赋值，原表保持不变，这是新手常犯的错误。

三、练习#

  1. 创建包含 姓名、语文、数学、英语 四列的 DataFrame，新增一列 平均分 = (语文+数学+英语)/3，再新增布尔列 优秀（平均分 ≥ 85 为 True）。
  2. 用 rename 把 语文、数学、英语 分别改成 chinese、math、english，然后用 .loc 把某位同学的 math 改成分数。
  3. 用 drop 删除 平均分 低于某个阈值的所有行（提示：先用布尔索引找出要删的行标签，再 drop(index=...)）。
