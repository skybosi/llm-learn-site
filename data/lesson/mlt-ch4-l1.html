偏差、方差与噪声#

前面三章都在回答"损失从哪来""正则从哪来"。这一章回答最后一个、也是最根本的问题：一个模型的泛化误差，究竟由哪几部分构成？为什么模型"太简单"和"太复杂"都会失败？ 答案藏在"偏差-方差分解"里。这一课先把三个主角——偏差（Bias）、方差（Variance）、噪声（Noise）——严格定义清楚，下一课再证明它们之和恰好等于期望误差。

一、概念讲解#

1. 一个关键视角：训练集是随机的#

要理解偏差和方差，必须先接受一个视角转换：把"训练集"本身看成一个随机变量。

同一个真实规律 f、同一个学习算法，如果换一批训练数据（哪怕是从同一个分布 𝒟 重新采样的另一批），学出来的模型 ĥ_D 会不一样。因为 ĥ_D 是训练集 D 的函数：

ĥ_D = 算法(D)

于是对一个固定的测试点 x，预测值 ĥ_D(x) 会随着 D 的随机性而波动。我们关心的，就是这个波动的性质：它平均起来准不准（偏差）、它抖得多厉害（方差）。

2. 三个概念的严格定义#

固定测试输入 x，其真实值为 f(x)。设 ĥ_D 是"在随机训练集 D 上训练出的模型"。定义：

  • 期望预测：𝔼_D[ĥ_D(x)]——把所有可能的训练集对应的预测做平均，得到"平均预测值"。
  • 偏差（Bias）：平均预测偏离真实值的程度（系统误差）。
Bias² = ( 𝔼_D[ĥ_D(x)] − f(x) )²
  • 方差（Variance）：预测值围绕其平均值的波动程度（随机误差）。
Variance = 𝔼_D[ ( ĥ_D(x) − 𝔼_D[ĥ_D(x)] )² ]
  • 噪声（Noise）：数据本身自带的、任何模型都无法消除的误差。若观测 y = f(x) + ε，ε ~ (0, σ²)：
Noise = σ² = 𝔼[ (y − f(x))² ]

3. 用"打靶"建立直觉#

把"预测 ĥ_D(x)"想象成向靶心（真实值 f(x)）射箭，每一箭代表一个随机训练集对应的预测：

  • 高偏差 = 打得偏：所有箭都稳定地落在靶心左边某处——平均落点偏离靶心。模型"系统性地看错方向"（太简单，没能力逼近真实函数）。
  • 高方差 = 打得散：箭在靶子上四散，虽然平均可能落在靶心附近，但每箭都离得很远。模型"对数据太敏感"（太复杂，换批数据就换副面孔）。
  • 噪声 = 靶心本身在抖：就算箭术完美，靶心位置本身有随机抖动（ε），这部分误差谁都消除不了。

一个"好模型"是低偏差 + 低方差，但下一课会证明这两者往往此消彼长。

4. 偏差-方差与模型复杂度的关系#

把"偏差"和"方差"放到"模型复杂度"的坐标轴上，趋势如下：

  • 简单模型（如低阶多项式、线性回归）：假设空间小，离真实 f 远 → 高偏差；但模型稳定，换批数据变化不大 → 低方差。
  • 复杂模型（如高阶多项式、深度网络）：假设空间大，能逼近 f → 低偏差；但对数据极其敏感，训练集稍有变化预测就大变 → 高方差。

所以"偏差"对应第 1 章的"假设空间够不够大"（表达能力），"方差"对应"ERM 对数据的敏感度"。三章的内容在这里汇合了。

5. 与统计点估计的对应#

偏差和方差这两个词，在统计点估计里早有对应（第 2 章第 1 课见过）：

  • 估计量 θ̂ 的偏差 = 𝔼[θ̂] − θ；
  • 估计量的方差 = 𝔼[(θ̂ − 𝔼θ̂)²]。

我们当时看到：高斯方差的 MLE σ̂² = (1/m)Σ(xᵢ−μ̂)² 是有偏但低方差的，无偏版本 (1/(m−1))Σ 是无偏但略高方差的。"无偏"与"低方差"不可兼得，正是偏差-方差权衡的微观雏形。机器学习只是把这个权衡从"标量估计"推广到了"整条函数"。

二、可运行代码示例#

用 NumPy 直观展示"简单模型高偏差低方差、复杂模型低偏差高方差"。固定一个真实的正弦规律，用 K 阶多项式在不同随机训练集上拟合，看预测值在测试点上的散布（方差）与平均偏离（偏差）。

import numpy as np

rng = np.random.default_rng(23)

def f(x):
    return np.sin(x)                      # 真实规律

def fit_poly(x, y, K):
    """拟合 K 阶多项式，返回测试点 x_test 上的预测"""
    A = np.vander(x, K + 1, increasing=True)
    w = np.linalg.lstsq(A, y, rcond=None)[0]
    return np.vander(np.array([x_test]), K + 1, increasing=True) @ w

x_test = 0.8
N_trials = 200                              # 重复采样 200 个训练集
for K in [1, 5, 15]:
    preds = []
    for _ in range(N_trials):
        x = rng.uniform(-3, 3, size=30)
        y = f(x) + rng.normal(0, 0.3, size=30)
        preds.append(fit_poly(x, y, K)[0])
    preds = np.array(preds)
    bias2 = (preds.mean() - f(x_test)) ** 2
    var = preds.var()
    print(f"K={K:>2}  偏差²={bias2:8.4f}  方差={var:8.4f}  均值={preds.mean():.4f} (真实={f(x_test):.4f})")

你会看到清晰的趋势：K=1（直线）偏差大、方差小；K=15（高阶）偏差小、方差爆炸。模型复杂度一升，偏差和方差就朝相反方向移动——这就是下一课要证明的权衡。

母原理连接#

本课横跨两条母原理。"概率视角统一"：偏差、方差、噪声全部是"对随机训练集取期望"的产物，概率论是把"模型表现"拆解开的唯一语言。"一切学习 = 优化"：偏差源于"假设空间太小（欠优化空间）"，方差源于"ERM 对数据过拟合（优化过头）"。三个概念是下一课"偏差-方差分解"的主角，而那个分解式，将成为我们诊断一切模型失败的总公式。
