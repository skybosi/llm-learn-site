逻辑回归原理与 sigmoid#

名字里带"回归"，干的却是分类的活——逻辑回归是监督学习里最经典的二分类算法。它的思路极其巧妙：在线性组合 wᵀx + b 的结果上套一个 sigmoid 函数，把"任意实数"压缩成"0 到 1 之间的概率"，再以 0.5 为界切一刀，就得到了类别标签。这一课我们拆解 sigmoid、交叉熵损失，以及为什么分类问题不能继续用均方误差。

一、概念讲解#

1. 从"预测数值"到"预测概率"#

线性回归输出的是一个任意实数，用来预测房价、温度很合适。但分类问题的答案只有两个（垃圾邮件 / 正常邮件、患病 / 健康），我们真正想要的是"它是正类的概率有多大"。逻辑回归分两步：

  1. 先算线性组合：z = wᵀx + b（和线性回归一模一样）；
  2. 再把 z 塞进 sigmoid 函数，得到概率：p = σ(z) = 1 / (1 + e⁻ᶻ)。

sigmoid 的妙处在于它的形状：z 很大时 σ(z) 逼近 1，z 很小时逼近 0，z = 0 时恰好等于 0.5。于是模型可以解读为：

P(y=1 | x) = σ(wᵀx + b)

如果概率 ≥ 0.5，就预测正类；否则预测负类。这条"0.5 分界线"正是后面要讲的决策边界。

2. sigmoid 的三个关键性质#

  1. 有界性：输出严格落在 (0, 1)，天然适合当概率；
  2. 单调性：z 越大输出越大，与"线性组合越大越像正类"的直觉一致；
  3. 平滑可导：导数有简洁形式 σ'(z) = σ(z)(1 − σ(z))，这让梯度下降的计算非常漂亮。

另外，sigmoid 曲线在中心附近近似线性、两端趋平，这使它成为神经网络早期最常用的激活函数之一——虽然现在隐藏层更多用 ReLU，但输出层做二分类时 sigmoid 依然常见。

3. 决策边界：模型画出的"分界线"#

把 σ(wᵀx + b) = 0.5 反解出来，等价于 wᵀx + b = 0。也就是说，逻辑回归的决策边界永远是一条线（高维下是超平面）。这条线把特征空间切成两块，一边判正类、一边判负类。

这是逻辑回归最重要的特性之一：它是一个线性分类器。如果两类数据本身"线性不可分"（比如一个圆环套一个圆），逻辑回归无能为力，需要特征工程或换模型——这个局限要牢记。

4. 为什么不用均方误差：交叉熵损失#

分类问题若沿用 MSE，会遇到两个麻烦：

  1. 梯度消失：当预测接近 0 或 1 时，MSE 的梯度趋近于 0，参数几乎不更新，训练卡住；
  2. 非凸：MSE + sigmoid 的损失曲面是非凸的，梯度下降可能掉进局部最优。

所以逻辑回归改用交叉熵损失（Cross-Entropy Loss），也叫对数损失：

J(w) = −(1/m) · Σᵢ [ yᵢ·ln(pᵢ) + (1−yᵢ)·ln(1−pᵢ) ]

直观理解：当真实标签 y=1 而模型预测 p 很小时，−ln(p) 会非常大，狠狠惩罚"明明该判正却给出低概率"的失误。交叉熵是凸函数，梯度下降能稳定找到全局最优。对 sigmoid + 交叉熵求导，会得到一个和线性回归"长得几乎一样"的简洁梯度：

∇J(w) = (1/m) · Xᵀ(p − y)

这也是为什么逻辑回归训练起来又快又稳。

二、可运行代码示例#

下面用 numpy 从零实现一个逻辑回归，用 sklearn 生成二维二分类数据，跑梯度下降并打印损失变化。

import numpy as np
from sklearn.datasets import make_classification

# 1) 生成二分类数据（2 个特征，方便想象平面上的点）
X, y = make_classification(
    n_samples=300, n_features=2, n_redundant=0, n_informative=2,
    n_clusters_per_class=1, random_state=42
)
X_b = np.c_[np.ones((X.shape[0], 1)), X]  # 加截距列
y = y.reshape(-1, 1)

def sigmoid(z):
    """把任意实数压缩到 (0,1)，数值上做了防溢出处理。"""
    return 1 / (1 + np.exp(-z))

def cross_entropy(w):
    """交叉熵损失，加 eps 防止 log(0)。"""
    p = sigmoid(X_b @ w)
    eps = 1e-12
    return float(-np.mean(y * np.log(p + eps) + (1 - y) * np.log(1 - p + eps)))

# 2) 梯度下降训练
w = np.zeros((3, 1))      # 参数：1 个截距 + 2 个权重
lr = 0.5                  # 学习率
for step in range(300):
    p = sigmoid(X_b @ w)
    grad = X_b.T @ (p - y) / len(y)   # 交叉熵损失的梯度
    w = w - lr * grad
    if step % 60 == 0:
        print(f"迭代 {step:3d} 步，交叉熵损失 = {cross_entropy(w):.4f}")

print("学习到的参数（截距, w1, w2）=", w.ravel())

# 3) 用 0.5 阈值做预测并统计准确率
p = sigmoid(X_b @ w)
y_pred = (p >= 0.5).astype(int).ravel()
print("训练准确率 =", round(float(np.mean(y_pred == y.ravel())), 3))

运行后你会看到交叉熵损失持续下降，最终准确率通常能达到 0.9 以上——这条由 w 确定的直线，就是把两类数据分开的决策边界。

三、练习#

  1. 画出 sigmoid 曲线：取 z = np.linspace(-8, 8, 200)，观察 z=0 处输出是否为 0.5，两端如何趋近 0 和 1。
  2. 把上面代码里生成数据改成 n_clusters_per_class=2（每类两簇），再训练，观察准确率为何大幅下降，联系"线性分类器"的局限。
  3. 手动验证 sigmoid 导数公式：分别用定义 (σ(z+ε)−σ(z))/ε 与 σ(z)(1−σ(z)) 计算某一点的导数，比较两者是否接近。
  4. 思考：若把阈值从 0.5 调到 0.3，模型预测为正类的样本会变多还是变少？这在"漏检代价很高"的场景（如疾病筛查）有什么意义？

为什么这样做？——理论推导#

从最大似然推出 sigmoid 与交叉熵损失#

先问"为什么"。 这一课有两个悬而未决的"凭什么"：(1) 凭什么概率非要用 sigmoid？(2) 凭什么损失非要用交叉熵？两个问题的答案藏在同一条第一性原理里：用"对数几率"把概率和线性模型接起来，再用最大似然推出损失。

sigmoid 从哪里来：odds → logit。 二分类中，令 p = P(y=1|x)。我们想用线性组合 wᵀx+b 去表达"正类的倾向"，但概率被锁在 [0,1]，而线性输出覆盖整个实数轴，两者尺度对不上。桥接它们的标准工具是几率（odds）与对数几率（logit）：

odds = p / (1 − p)，logit(p) = ln( p / (1 − p) )

p 从 0 走到 1 时，odds 从 0 走到 +∞；再取对数，logit 就覆盖整个实数轴 (−∞, +∞)。于是可以合法地令线性组合等于 logit：

wᵀx + b = ln( p / (1 − p) )

反解 p，即得 sigmoid：

p = e^(wᵀx+b) / (1 + e^(wᵀx+b)) = 1 / (1 + e^(−(wᵀx+b))) = σ(wᵀx+b)

所以 sigmoid 不是凭空挑的形状，而是"让 logit 等于线性组合"这一假设的逆映射；它天然保证 p ∈ (0,1)，这正是概率所要求的取值区间。

交叉熵从哪里来：伯努利 + 最大似然。 每个标签 y ∈ {0,1} 服从伯努利分布，其中 p = σ(wᵀx+b)：

P(y | x; w) = p^y · (1 − p)^(1 − y)

m 个样本独立同分布，似然连乘、再取负对数：

−ln L(w) = −Σᵢ [ yᵢ·ln pᵢ + (1−yᵢ)·ln(1−pᵢ) ]

除以 m 后，正是交叉熵损失：

J(w) = −(1/m) · Σᵢ [ yᵢ·ln pᵢ + (1−yᵢ)·ln(1−pᵢ) ]

这也顺带回答了"为什么分类不用 MSE"： MSE 对应的是"高斯噪声"假设下的负对数似然，而分类标签是伯努利变量，其"原生"的负对数似然就是交叉熵。用 MSE 等于给伯努利数据套了一个错误的分布假设，于是才出现非凸、梯度消失这些"水土不服"的症状。交叉熵 + sigmoid 之所以训练得又快又稳，本质是它精确匹配了数据的真实分布假设。

母原理连接： 与线性回归共用同一台引擎——"最大化似然 = 最小化负对数似然"——只是燃料从"高斯"换成了"伯努利"，产物从 MSE 变成了交叉熵；而 sigmoid 则是"logit 线性化"这条独立的链接函数原理给出的概率出口。
