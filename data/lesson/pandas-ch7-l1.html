数据概览#

从这一课开始，我们把前面六章学到的技能串起来，完整地走一遍数据分析流程。项目场景是一家线上零售店铺，拿到了它 2024 年上半年的一批订单明细，目标是弄清经营状况、找出增长点。第一步不是急着画图算数，而是先把数据摸清楚——这份数据长什么样、有哪些字段、质量如何。

一、概念讲解#

1. 先看结构，再谈分析#

拿到一份陌生数据，建议按固定顺序"体检"一遍：

  1. 规模：有多少行、多少列（shape）；
  2. 长相：字段名是什么、前几行长什么样（columns、head、tail）；
  3. 类型：每列是什么数据类型（info、dtypes）；
  4. 数值摘要：数值列的中心和离散程度（describe）；
  5. 质量：有没有缺失、有没有重复（isna、duplicated）。

2. 认识我们的订单数据#

本项目的订单表包含这些字段（真实业务里字段往往更多，但核心思路一致）：

字段 含义 类型
order_id 订单编号 字符串
date 下单日期 日期
region 收货地区 分类
category 商品品类 分类
product 具体商品 分类
customer_type 新客 / 老客 分类
payment 支付方式 分类
quantity 购买数量 数值
price 单价 数值
amount 订单金额（= 单价 × 数量） 数值

3. 两个"体检"函数#

  • df.info()：一屏看全列名、非空数量、数据类型、内存占用；
  • df.describe()：对数值列输出 count / mean / std / min / 四分位数 / max 等统计量，一眼看出量级和波动。

小提示：describe() 默认只统计数值列。想看分类列的分布，用 value_counts()，我们在下一课会重点用。

4. 质量初检：缺失与重复#

  • df.isna().sum()：统计每列的缺失值个数；
  • df.duplicated().sum()：统计完全重复的行有多少条。

这两行代码成本极低，却能避免后面分析被脏数据"带偏"。发现缺失与重复后如何处理，我们在第 4 章已经系统学过，这里先聚焦"发现"。

二、可运行代码示例#

下面用代码构造这份订单数据（真实项目里这一步通常是 pd.read_csv("订单.csv")；这里为了让你直接运行，用随机数据模拟一份）：

import pandas as pd
import numpy as np

# 固定随机种子，保证结果可复现
np.random.seed(42)

n = 400  # 订单数
regions = ["华东", "华北", "华南", "西南"]
categories = ["数码", "家居", "服饰", "美妆"]
cat_prod = {"数码": ["手机", "耳机", "键盘"], "家居": ["台灯", "收纳盒", "毛巾"],
            "服饰": ["T恤", "牛仔裤", "卫衣"], "美妆": ["口红", "面膜", "香水"]}

cat = np.random.choice(categories, n)
df = pd.DataFrame({
    "order_id": [f"ORD{i:04d}" for i in range(n)],
    "date": pd.to_datetime("2024-01-01") + pd.to_timedelta(np.random.randint(0, 180, n), unit="D"),
    "region": np.random.choice(regions, n),
    "category": cat,
    "product": [np.random.choice(cat_prod[c]) for c in cat],
    "customer_type": np.random.choice(["新客", "老客"], n, p=[0.4, 0.6]),
    "payment": np.random.choice(["微信支付", "支付宝", "银行卡"], n),
    "quantity": np.random.randint(1, 5, n),
    "price": np.round(np.random.uniform(20, 800, n), 2),
})
df["amount"] = (df["price"] * df["quantity"]).round(2)

# 人为注入少量质量问题，方便演示"质量初检"
df.loc[[11, 222], "price"] = np.nan                      # 两行价格缺失
df = pd.concat([df, df.iloc[[7, 7]]], ignore_index=True)  # 复制第 8 行，制造重复记录

示例 1：规模与长相#

print("数据形状：", df.shape)          # (行数, 列数)
print("字段列表：", df.columns.tolist())
print(df.head(3))                     # 看前 3 行
print(df.tail(3))                     # 看后 3 行

示例 2：类型与数值摘要#

df.info()        # 每列的非空数量与类型
print(df.describe().round(2))   # 数值列的统计摘要

示例 3：质量初检#

print("各列缺失值数量：\n", df.isna().sum())
print("重复行数量：", df.duplicated().sum())

# 看看重复的那条记录长什么样
print(df[df.duplicated(keep=False)])

三、练习#

  1. 打印 df.shape、df.columns 和 df.dtypes，用自己的话描述：这份数据有多少行、多少列，哪些列是数值、哪些是分类。
  2. 观察 df.describe() 的输出：金额（amount）的平均值和中位数（50% 分位）相差大吗？这能初步说明金额分布偏"均匀"还是偏"右偏"？
  3. 找出 price 缺失的那两行的 order_id，再用 df.isna().any(axis=1) 验证"按行判断是否存在缺失"的写法是否也能找到它们。
