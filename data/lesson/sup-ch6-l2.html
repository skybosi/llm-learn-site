核函数#

上一课的线性 SVM 只能画"直线（超平面）"来分类。可现实中大量数据线性不可分：比如一个环状分布，"内圈一类、外圈一类"，任何直线都切不开。本课讲 SVM 最优雅的武器——核函数（kernel），它让 SVM 在不显式升维的情况下学会非线性边界。

一、概念讲解#

1. 线性不可分怎么办：映射到高维#

看一个经典例子：二维平面上的点 (x1, x2)，如果数据呈同心圆分布，直线分不开；但若把它映射到三维 (x1, x2, x1² + x2²)，原本的圆在第三维"高度"上就错开了，一个平面即可分开。

思路就是：先把数据映射到更高维（甚至无限维）的特征空间，再在那边做线性 SVM。

2. 核技巧：不显式升维，也能算#

直接升维有个麻烦：维度可能爆炸式增长，计算代价难以承受。核技巧（kernel trick） 解决了这个问题——SVM 的目标和预测其实只依赖样本之间的内积 ⟨x, z⟩。如果存在一个核函数 K(x, z)，满足 K(x, z) = ⟨φ(x), φ(z)⟩（即核函数直接给出"升维后的内积"），那我们就永远不必真的算出 φ(x)，直接用 K 替换内积即可。

一句话：核函数让我们在"原始空间"花低维的成本，得到"高维空间"线性分类的效果。

3. 常用核函数#

核函数 表达式（示意） 特点与适用
linear K(x,z) = x·z 不做升维，数据线性可分或特征很多时用
poly K(x,z) = (γ·x·z + r)^d 多项式核，degree 控制曲线复杂度
rbf K(x,z) = exp(-γ‖x-z‖²) 高斯核/径向基核，默认首选，能拟合任意平滑边界
sigmoid tanh(γ·x·z + r) 类似神经网络激活，实践中较少用

rbf 是最常用的：它把每个样本变成"以自身为中心的高斯分布影响源"，通过组合这些高斯来拟合任意复杂边界。

4. 关键参数 γ（gamma）#

gamma 控制单个样本的影响范围，是 RBF 核最重要的超参数：

  • γ 大 → 每个样本"影响范围"小，边界弯弯曲曲、紧贴训练点，容易过拟合；
  • γ 小 → 影响范围大，边界更平滑，可能欠拟合。

通常与 C 一起调：C 管"多严格"，γ 管"多弯曲"。

5. 怎么选核#

经验顺序：先试 rbf（默认），配合调 C 和 γ；如果特征维度极高且样本少，linear 往往够用且更快；数据有明显多项式结构再试 poly。最后用交叉验证做决定，而不是凭感觉。

二、可运行代码示例#

from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC
import numpy as np

# 1. 生成"月牙形"非线性数据：任何直线都分不开
X, y = make_moons(n_samples=200, noise=0.25, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

# 2. 对比三种核函数在测试集上的表现
for kernel in ["linear", "poly", "rbf"]:
    # poly 核需要给定 degree，rbf 核需要给定 gamma
    if kernel == "poly":
        m = SVC(kernel=kernel, degree=3, C=1.0)
    elif kernel == "rbf":
        m = SVC(kernel=kernel, gamma=1.0, C=1.0)
    else:
        m = SVC(kernel=kernel, C=1.0)
    m.fit(X_train, y_train)
    print("{:<8} 测试准确率：{:.3f}".format(kernel, m.score(X_test, y_test)))

# 3. 观察 gamma 对 rbf 核的影响
for gamma in [0.1, 1.0, 10.0, 50.0]:
    m = SVC(kernel="rbf", gamma=gamma, C=1.0)
    m.fit(X_train, y_train)
    print("rbf gamma={:<6} 测试准确率：{:.3f}".format(
        gamma, m.score(X_test, y_test)))

要点：月牙数据上，linear 核几乎无能为力，rbf 能画出平滑的弯曲边界取得高准确率；gamma 取太大时边界过弯、开始过拟合，测试准确率反而下降。

三、练习#

  1. 用 make_circles 生成同心圆数据，分别跑 linear 和 rbf，确认核函数的作用；再调 degree 观察 poly 核的表现。
  2. 固定 C=1.0，让 gamma 取 0.01 到 100 之间的若干值，记录测试准确率，找到大致的最优区间，并解释两端（过小/过大）为什么变差。
  3. 在 make_moons 数据上，用 GridSearchCV 同时搜 C（如 0.1、1、10、100）和 gamma（如 0.1、1、10），输出最佳组合。
  4. 思考题：核技巧为什么能避免"显式升维"的巨大计算量？（提示：RBF 核对应的是无限维映射，显式算根本算不出来。）
