提示敏感性与评测方差：分差多少才算真差异#

这一节要解决什么#

评测里最日常、也最难回答的问题是："我们的模型比基线高了 1.8 个点，这算赢了吗？" 大多数人靠经验回答（"3 个点以内不当真"），但经验会随任务、样本量、评测集难度分布完全失效。这一节把它变成一个可计算的问题。

要做到这一点，必须先把"不确定性从哪来"拆开。评测分数有五个独立的方差来源，它们的大小关系决定了你该往哪里加预算：

① 题目抽样     ：换一批同分布的题，分数会变 —— 由 n 与题目难度分布决定
② 生成随机性   ：temperature/seed/服务端非确定性 —— 由采样数与解码参数决定
③ 提示模板     ：措辞、few-shot 数量与顺序、系统提示 —— 常常是最大的一项，却最常被当成"固定条件"
④ 抽取与后处理 ：答案解析规则、单位归一化 —— 上一节已量化
⑤ 环境         ：依赖版本、服务端行为 —— 由工程纪律解决

这一节的核心交付是四样东西：

  1. 标准误与置信区间的正确算法（含配对、分层/整簇 bootstrap、McNemar）；
  2. 样本量公式，回答"要检测 Δ 需要多少题"以及反向问题"给定题量，我能检出的最小差异是多少"；
  3. 方差分解：把"模板"当成随机效应，估计各来源的方差占比（附两因素随机效应 ANOVA 的矩估计实现）；
  4. 一个决策规则：显著性 ≠ 有意义，分数差异必须与决策阈值对齐。

方差分解：把"模型差异"与"评测噪声"分开#

一个可操作的模型#

设模型 m 在题目 i、模板 j 上的得分 ymij​∈{0,1}，写出线性（logit 尺度上的）模型：

logitPr(ymij​=1)=μ+τm​+ai​+bj​+(τa)mi​+εmij​

  • τm​：我们要测的模型效应；
  • ai​∼N(0,σa2​)：题目难度（随机效应）；
  • bj​∼N(0,σb2​)：模板效应（随机效应）——关键：不要把模板当固定条件；
  • (τa)mi​：模型 × 题目交互（不同模型擅长不同题型，真实存在）；
  • ε：其余噪声（含采样随机性）。

为什么模板必须当随机效应？ 因为它是一个你随意选定的样本，而不是世界给你的唯一条件。如果只固定一个模板，你测到的是"模型 × 该模板"的联合效果；换一个团队、换一个模板，结论可能反转。把 bj​ 当随机效应，方差里就会诚实地包含模板带来的不确定性——这是"提示敏感性"在统计上的正确处理方式。

方差如何影响结论#

分数的方差可以近似分解为：

Var(s^m​)≈题目nσa2​​​​+模板Jσb2​​​​+残差nJσε2​​​​

（n 题、J 个模板。）由此得到三条直接可用的行动准则：

  1. σb2​ 常常不属于 σa2​ 或 σε2​。当模板方差主导时，加题没用——必须加模板（J）。
  2. 加模板比加题便宜（模板数 × 一次评测的成本远低于把题量翻十倍），因此"多模板"是性价比最高的降方差手段之一。
  3. 模型差异必须与这个总方差比较，而不是与某个模板下的噪声比较。

实测经验（量级，不是定值）#

在开放生成任务上，同一模型换提示模板造成的分数波动，经常大于两个强模型之间的真实差距。这种现象在文献里有一个朴素的名字：prompt sensitivity。它有三个常见来源：

来源 机制 缓解
措辞与格式 指令的措辞激活不同的先验行为 多模板取平均；报模板间分布
few-shot 示例的数量与顺序 示例顺序会显著影响输出分布 固定并公开；把顺序纳入随机化
答案格式约定 影响抽取成功率 用宽松且公开的抽取规则（上一节）

因此，任何"我们的模型更强"的结论，都应该附一句"在多少个模板、多少个 seed 上验证过"。 只在一个模板上得到的 2 个点优势，在多数任务上不构成证据。

标准误与置信区间：四种情形#

情形 1：单个模型的准确率（最简单，也最容易被误用）#

SE=np(1−p)​​

它假设题目独立同分布。当题目成簇时（同一篇文档出多题、同一模板出多题），必须修正：

DEFF=1+(m−1)ICC,SEcluster​=SE⋅DEFF​

m 为平均簇大小，ICC 为簇内相关。忽略簇结构会系统性地低估置信区间宽度，让不该显著的结论变显著——这是评测里最常见的统计错误之一。

情形 2：两个模型的配对差值（第 1 章第 3 节已给）#

Δ^=n1​i=1∑n​(ai​−bi​),SEpaired​=n​sd​​

配对消掉了题目难度方差，因此 n 相同时 CI 更窄（典型 1.2~2 倍，收益上界由题目异质性决定，见第 1 章第 3 节）。这是"同一评测集上比较两个模型"与"两次独立评测比分数"的本质区别。

情形 3：0/1 配对数据的假设检验：McNemar#

只看不一致格：

B 对 B 错
A 对 a b
A 错 c d

χ2=b+c(∣b−c∣−1)2​ ∼ χ12​,b+c 小时用精确二项检验

b+c 就是不一致题数（discordance），它是决定检验效能的唯一关键量（见下）。

情形 4：任意指标的 CI：按题配对 bootstrap#

F1、pass@k、BLEU、胜率都没有简单的闭式标准误。统一的办法是按题配对重采样：

for b in 1..B:                       # B ≥ 2000
    从 n 道题中有放回抽 n 道（A、B 用同一次抽样 → 保持配对）
    重算指标差 Δ*_b
CI = [Δ* 的 2.5% 分位, Δ* 的 97.5% 分位]

三条纪律：

  1. 配对重采样（同一批索引同时用于两个模型）；
  2. 成簇时按簇重采样（整簇 bootstrap），否则 CI 系统性偏窄；
  3. 当结论依赖于模板选择时，还要在模板层做重采样（把模板当抽样单位）。这是"提示敏感性"最直接的统计表达：如果模板层 bootstrap 的 CI 跨 0，那么"模型更强"的结论不稳健。

样本量：要检测 Δ 需要多少题#

通用公式#

要在显著性水平 α、检验效能 1−β 下检测差异 Δ，所需样本量约为

n≈Δ22(z1−α/2​+z1−β​)2σ2​(两独立组，σ2=p(1−p) 对 0/1 数据),1−β=0.8 ⇒ z1−α/2​+z1−β​≈2.80

配对 0/1 数据（评测里最常用的形式）#

设不一致率 pdisc​=pb​+pc​（A、B 结果不同的题目比例），则

n≈Δ2(z1−α/2​+z1−β​)2⋅pdisc​​=Δ27.84pdisc​​

这条公式里最反直觉、也最有用的量是 pdisc​。 它意味着：要检测的差异越小、两个模型越像（不一致率越低），所需题量按平方增长。

几个具体数字（α=0.05、power 0.8）：

目标差 Δ 不一致率 pdisc​ 需要题数 n
5 个点 0.15 ≈470
3 个点 0.12 ≈1050
2 个点 0.10 ≈1960
1 个点 0.08 ≈6270
1 个点 0.05 ≈3920

注意最后两行说明一个重要事实：pdisc​ 越小，达到同样精度所需的题数反而可能更少（因为方差 =pdisc​−Δ2 更小）。真实估算必须用两个方差（零假设下的 2π 与备择下的 pdisc​−Δ2）分别算再取大者；上表用的是简化式，实际会略保守/略乐观，估算是给你定数量级，不是精确承诺。

反向问题：给定题量，我能检出的最小差异（MDD）#

MDD≈(z1−α/2​+z1−β​)npdisc​​​≈2.80npdisc​​​

  • n=1000、pdisc​=0.10 → MDD≈2.80×0.01=2.8 个点；
  • n=300、pdisc​=0.10 → MDD≈5.1 个点。

这是本节最该背下来的两个数字。 它直接解释了为什么"300 题的评测上 2 个点的提升"不是结论——这个评测在物理上就分辨不出 5 个点以下的差异。

"分差多少才算真差异"：一套决策流程#

① 是否配对？        否 → 先改成配对（同一批题），这是免费的方差缩减
② 算 CI（含簇/模板）  CI 跨 0 → 不能说"更好"，只能说"未检出差异"
③ 与 MDD 比较        分差 < MDD → 你的评测精度不足，不是模型不行
④ 与决策阈值比较      显著但 < 决策阈值 → "统计显著但实践无意义"
⑤ 多重比较修正        比较多于 2 个模型 / 多子域 → Bonferroni 或 FDR
⑥ 稳健性检查          换模板/换 seed/换子集，结论是否稳定？不稳定就报"不稳定"
⑦ 决策              以上全部通过，才允许说"换模型"

其中第 ④ 步最常被跳过。统计显著与决策有意义是两件事：

CI 不跨 0显著​​=Δ>决策阈值值得换​​

一个大 n 的评测可以让 0.3 个点的差异变得"高度显著"，但它不值得付出迁移成本。决策阈值必须在跑评测之前写下来（第 1 章第 4 节的预注册）。

报告规范：一张可复用的模板#

【评测协议】
  被测模型与版本：A@v3, B@v2（含知识截止日期）
  评测集：<名称> v1.2，n = 1000 题，来源与抽样方式，难度分布
  提示模板：固定 1 个 / 随机 J = 8 个（列出或公开）
  解码参数：temperature, top_p, max_tokens, seed 集合
  抽取规则：<正则或解析器>（公开可复现）
  配对方式：同题同模板逐一配对
【结果】
  A = 71.2%  B = 69.4%   Δ = +1.8pp（配对）
  95% CI（按题 bootstrap）= [+0.3, +3.3]
  簇内 ICC = 0.21，DEFF = 1.9 → 修正后 CI = [-0.2, +3.8]
  模板层 bootstrap CI = [-1.1, +4.5]  ← 结论对模板不稳健
  McNemar: b = 62, c = 44, p = 0.09
  MDD(n=1000, p_disc=0.106) = 2.9pp  ← 观测差小于 MDD
【结论】
  未检出可靠差异。建议：增加模板数至 16 或题量至 2500 后重测。
【污染审计】
  扰动不变性 PS = 0.04（对照组 0.03）；时间切分交叉验证一致；未做 n-gram（闭源）

这份模板的价值在于：它把"不能下结论"也变成一个合格的交付物。 在评测里，最常见的错误不是算错，而是在信息不足时给出了确定语气。

取舍#

降方差手段 降低哪一项 成本 副作用
加题（n↑） 题目抽样 中（算力） 若题目来源单一，反而加深对某分布的过拟合
加模板（J↑） 模板方差 低 需要聚合规则；模板本身的代表性成为新问题
加 seed（采样数） 生成随机性 中 只降"行为"方差，不降"能力"评估的偏差
配对设计 题目难度 几乎为零 需要能跑同一批题（对闭源 API 也成立）
整簇 bootstrap 修正 CI 偏窄 低 需要定义"簇"，定义方式影响结论
多数投票 / 自一致性 生成随机性 + 部分能力 高（k 倍算力） 改变了被测对象（从 pass@1 变成投票后的系统），必须重新声明测的是什么

最后一行是本节最容易踩的概念坑：多数投票不是"降噪"，它是换了一个系统。 投票后的 72% 不是"这个模型的准确率"，而是"这个模型 + 投票策略的准确率"。两者都可以报，但必须说清是哪一个（第 1 章第 1 节的能力/行为之分）。

代码：样本量、方差分解与模板层 bootstrap#

import numpy as np

rng = np.random.default_rng(42)

# ============ 1. 样本量与最小可检出差异 ============
Z = 1.959964 + 0.8416212          # alpha=0.05(双侧) + power=0.8
def n_paired(delta, discordance, z=Z):
    """配对 0/1 数据所需题数（简化式，用于定数量级）。"""
    return int(np.ceil(z**2 * discordance / delta**2))

def mdd(n, discordance, z=Z):
    """给定题量与不一致率，能检出的最小差异。"""
    return z * np.sqrt(discordance / n)

print("需要的题数（配对，power=0.8）：")
for delta, disc in [(0.05, 0.15), (0.03, 0.12), (0.02, 0.10), (0.01, 0.08)]:
    print(f"  Δ={delta:.0%}  p_disc={disc:.0%}  -> n ≈ {n_paired(delta, disc)}")

print("\n给定题量能检出的最小差异：")
for n in (300, 1000, 5000):
    print(f"  n={n:5d}  p_disc=10%  -> MDD ≈ {mdd(n, 0.10):.3%}")

# ============ 2. 方差分解：把"模板"当随机效应 ============
n_items, n_prompts, n_seeds = 200, 8, 3
sig_item, sig_prompt, sig_seed = 1.2, 0.55, 0.25

a = rng.normal(0, sig_item, n_items)                     # 题目难度（随机效应）
b = rng.normal(0, sig_prompt, n_prompts)                 # 模板效应（随机效应！）
logits = (a[:, None, None] + b[None, :, None]
          + rng.normal(0, sig_seed, (1, 1, n_seeds)))    # 采样随机性
P = 1 / (1 + np.exp(-logits))
y = (rng.random(P.shape) < P).astype(float)              # 一次评测 = 一次抽样

# 潜变量尺度的矩估计：从"边际均值的方差"里扣掉伯努利抽样噪声
item_means = y.mean(axis=(1, 2))                         # 每题在 8 模板 × 3 seed 上的均分
prompt_means = y.mean(axis=(0, 2))                       # 每模板在 200 题 × 3 seed 上的均分
var_item = max(0.0, item_means.var(ddof=1)
               - np.mean(item_means * (1 - item_means)) / (n_prompts * n_seeds))
var_prompt = max(0.0, prompt_means.var(ddof=1)
                 - np.mean(prompt_means * (1 - prompt_means)) / (n_items * n_seeds))
latent = var_item + var_prompt
var_obs = float(y.var())                                 # 观测总方差
resid = max(0.0, var_obs - latent)                       # 逐次抽样的伯努利噪声
print(f"\n方差分解（题 {n_items} × 模板 {n_prompts} × seed {n_seeds}）")
print(f"  观测总方差      = {var_obs:.4f}")
print(f"  潜变量: 题目方差 = {var_item:.4f}（{var_item/latent:.0%}）"
      f" / 模板方差 = {var_prompt:.4f}（{var_prompt/latent:.0%}）")
print(f"  逐次伯努利噪声  = {resid:.4f}，占观测总方差 {resid/var_obs:.0%}")
print(f"  各模板均分极差  = {prompt_means.max()-prompt_means.min():.3f}")

# ============ 3. 模板层 bootstrap：结论稳不稳 ============
# 模型 B：整体强度略低（-0.45 logit），但对模板的敏感模式与 A 不同（模型 × 模板交互）
bB = b + rng.normal(0, 0.9, n_prompts) - 0.45
logits_B = a[:, None, None] + bB[None, :, None] + rng.normal(0, sig_seed, (1, 1, n_seeds))
PB = 1 / (1 + np.exp(-logits_B))
yB = (rng.random(PB.shape) < PB).astype(float)

diff_per_prompt = y.mean(axis=(0, 2)) - yB.mean(axis=(0, 2))
print(f"\n各模板上的分差（A-B）: {np.round(diff_per_prompt, 3)}")
print(f"平均分差 = {diff_per_prompt.mean():+.4f}（A={y.mean():.3f}, B={yB.mean():.3f}）")

boot_items = [rng.choice(n_items, n_items, replace=True) for _ in range(2000)]
boot_prompt = [rng.choice(n_prompts, n_prompts, replace=True) for _ in range(2000)]
ci_item = np.percentile([(y[i].mean() - yB[i].mean()) for i in boot_items], [2.5, 97.5])
ci_prompt = np.percentile([diff_per_prompt[j].mean() for j in boot_prompt], [2.5, 97.5])
print(f"按题 bootstrap 95% CI   = [{ci_item[0]:+.4f}, {ci_item[1]:+.4f}]")
print(f"按模板 bootstrap 95% CI = [{ci_prompt[0]:+.4f}, {ci_prompt[1]:+.4f}]  <- 跨 0 则结论不稳健")

# ============ 4. McNemar：配对 0/1 的检验 ============
A = y.mean(axis=(1, 2)) > 0.5          # 把"多模板多 seed 的多数结果"压成 0/1，便于演示
B = yB.mean(axis=(1, 2)) > 0.5
b01 = int(np.sum(A & ~B)); c10 = int(np.sum(~A & B))
stat = (abs(b01 - c10) - 1) ** 2 / (b01 + c10) if (b01 + c10) else 0.0
print(f"\nMcNemar: b={b01} c={c10} chi2={stat:.2f} (df=1, 临界 3.84)")
print(f"不一致率 p_disc = {(b01+c10)/len(A):.3f} -> MDD(n={len(A)}) ≈ {mdd(len(A), (b01+c10)/len(A)):.3%}")

这段代码里要读出什么：

  • pdisc​ 是不一致率，不是准确率。它决定检验效能，因此每次比较都要报它——很多"不显著"的评测，根源是模型太像（不一致率太低）而题量不够。
  • 方差分解要在潜变量尺度上读：在 0/1 观测尺度上，逐次伯努利噪声会占掉总方差的七成以上（上面的输出就是如此）——这正是"单次评估不可靠、必须靠多题多模板平均掉它"的算术根据。把伯努利噪声扣掉之后，题目与模板的相对占比才有解释意义；如果模板在潜变量尺度上占到两三成，那么"只加题"就是低效的投入。
  • 模板层 bootstrap 是"提示敏感性"的判据：上面这段代码会给出一个非常典型的结果——按题 bootstrap 的 CI 不跨 0，按模板 bootstrap 的 CI 跨 0。此时正确结论是"在平均意义上 A 更高，但这个结论依赖模板选择"，而不是"A 更好"。
  • 矩估计是近似：扣噪声用的 p(1−p) 是插件的估计，且 0/1 尺度上的方差随均值变化。严谨做法是在 logit 尺度上用混合效应模型（y∼τ+(1∣item)+(1∣prompt)）。代码里的估计用于理解结构，不用于发表数值。
  • ⚠️ 所有数据都是合成的，数值不构成任何真实模型的结论。

练习#

  1. 样本量决策：你想要在 α=0.05、power 0.8 下检测 2 个点的差异，预算允许 1500 题。 （a）如果 pdisc​=0.10，够吗？用公式算； （b）如果两模型高度相似、pdisc​=0.05，够吗？ （c）如果预算只能做 800 题，你还能通过什么方式提高检验效能？写出两种，并说明它们改变了公式里的哪个量。

  2. 模板 vs 题目：某评测方差分解结果：题目方差占 55%、模板方差占 30%、残差 15%。当前设计是 500 题 × 1 个模板。 （a）如果把题量翻倍到 1000、模板仍为 1，总方差降低多少？ （b）如果改成 500 题 × 4 个模板，总方差降低多少？ （c）哪种方案更划算？如果模板方差占比其实是 5% 而不是 30%，结论会怎样反转？

  3. 簇结构：你的评测集是 50 篇文档 × 每篇 20 题（共 1000 题），簇内 ICC = 0.25。 （a）算 DEFF 与修正后的 SE 放大倍数； （b）等价于"独立样本量"是多少？ （c）按题 bootstrap 与按文档 bootstrap 得到的 CI 哪个更宽？为什么？

  4. 显著但无意义：某评测 n=20000，模型 A 比 B 高 0.4 个点，CI = [+0.1, +0.7]（不跨 0），p < 0.01。 （a）这个结果能说明什么？ （b）如果迁移成本是 2 人月，你会怎么决策？ （c）写出你会在报告里怎么措辞（不超过两句话）。

  5. 反例设计：构造一个场景，使得"按题 bootstrap CI 不跨 0"但"按模板 bootstrap CI 跨 0"。说明这个场景在真实评测里对应什么情况（提示：模型 A 只是更适应某种模板风格）。

小结#

  • 评测方差有五个来源：题目抽样、生成随机性、提示模板、抽取规则、环境。它们的相对大小决定你该加题、加模板还是加 seed。
  • 模板必须当随机效应。把模板固定成唯一条件，会漏掉常常最大的一项方差；分数方差近似为 Var(s^)≈σa2​/n+σb2​/J+σε2​/(nJ)。
  • 题目成簇时必须修正：DEFF=1+(m−1)ICC，否则 CI 系统性偏窄、假显著变多。
  • 样本量的关键量是不一致率 pdisc​：n≈7.84pdisc​/Δ2；反向的 MDD≈2.80pdisc​/n​ 告诉你"这份评测能分辨多小的差异"。n=1000、pdisc​=10% 时 MDD ≈ 2.8 个点——300 题上 2 个点的提升不构成结论。
  • 配对是免费的方差缩减（但有上界）：消掉题目难度方差（Var(d)=Var(a)+Var(b)−2Cov），典型收益 1.2~2 倍，题目同质时几乎为零；0/1 数据用 McNemar 只看不一致格。
  • 任意指标用按题配对 bootstrap；结论依赖模板时，还要做模板层 bootstrap。
  • 显著 ≠ 值得换：决策阈值必须在跑评测前写死；把"未检出可靠差异 + 建议怎么补数据"也当成合格交付物。
