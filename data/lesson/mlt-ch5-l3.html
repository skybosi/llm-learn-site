凸 vs 非凸（为什么深度学习仍能用梯度下降）#

前两课我们享受了凸性的红利：局部最优 = 全局最优，梯度下降必然收敛。但现实立刻泼来一盆冷水——深度神经网络的损失函数几乎从不凸。那么问题来了：如果凸性是"安心收敛"的保障，那深度学习凭什么还能用梯度下降训练成功？这一课先精确地证明"凸到底给了我们什么"，再正面回答"非凸世界里梯度下降为什么仍然可用"。这是把直觉变成定理的一课。

一、概念讲解（含推导）#

1. 凸性到底保证什么：局部最优 = 全局最优的证明#

命题：设 f 是凸函数，x∗ 是它的一个局部极小点，则 x∗ 是全局极小点。

证明（反证法）：假设存在某点 y 使 f(y)<f(x∗)。考虑 x∗ 与 y 连线上的点 zθ​=θy+(1−θ)x∗，其中 θ∈(0,1)。由凸性：

f(zθ​)≤θf(y)+(1−θ)f(x∗)<θf(x∗)+(1−θ)f(x∗)=f(x∗).

f(zθ​)≤θf(y)+(1−θ)f(x∗)<θf(x∗)+(1−θ)f(x∗)=f(x∗).

所以对任意 θ∈(0,1)，都有 f(zθ​)<f(x∗)。而 θ→0 时 zθ​→x∗，也就是说在 x∗ 的任意小邻域内都存在函数值严格更小的点——这与 "x∗ 是局部极小" 矛盾。故 y 不存在，x∗ 必是全局极小。∎

这个证明揭示了一个关键几何事实：凸函数不可能有两个"被上升坡隔开"的坑。任何一个比你当前点更低的地方，都会有一条"一路上都更低"的连线直达它，梯度下降不会被困在半路。

2. 非凸世界里的三类"陷阱"#

一旦丢掉凸性，损失曲面上会冒出三种让梯度"原地打转"的地方（假设 f 光滑）：

  1. 局部极小点：∇f=0 且 Hessian 半正定（∇2f⪰0）。附近所有方向都上升，梯度下降一旦落入就停住。
  2. 局部极大点：∇f=0 且 Hessian 半负定。几乎不可能被梯度下降"吸"进去（因为沿负梯度是下山，会远离它）。
  3. 鞍点：∇f=0，但 Hessian 既非半正定也非半负定——有的方向曲率为正、有的为负。它是"马鞍"：在某些方向是极小、在另一些方向是极大。

经典的一维非凸例子是 f(x)=x4−x2：它在 x=0 处是局部极大，在 x=±1/2​ 处是两个对称的局部极小。在低维空间里，局部极小是主要威胁；但下面我们会看到，高维空间里鞍点才是主角。

3. 为什么高维里"局部极小"反而没那么可怕：鞍点主导#

直觉上，一个点要是"局部极小"，必须所有方向都向上弯。在 d 维空间里，Hessian 有 d 个特征值，全部非负（半正定）是个很苛刻的条件。若曲率方向大致随机，那么"全是正曲率"的概率随维数指数下降——反之，至少有一个负方向（可逃逸的鞍点）的概率随维数指数上升。这正是严格鞍点理论（strict saddle property）的核心观察：

高维非凸曲面中，绝大多数"梯度为零"的点是鞍点，且这些鞍点都有某个负曲率方向可以逃逸。

对满足"严格鞍点性质"（每个鞍点都有一个特征值 ≤−γ<0 的逃逸方向）的函数，可以证明带扰动的梯度下降能以高概率不陷入鞍点、收敛到（近似）局部极小。关键机制是：

  • 一阶方法（纯梯度下降）在严格鞍点附近会慢慢滑向逃逸方向；
  • 注入一点随机噪声（或使用随机梯度下降 SGD 天然自带的噪声）会踢它一把，加速逃逸；
  • 一旦离开鞍点邻域，负曲率方向让函数值持续下降。

这解释了实践中一个反直觉现象：深度网络几乎从不停在"坏"的鞍点，反而能一路下降到相当好的解。

4. 过参数化：为什么"任意局部极小"往往都够好#

另一个更深的原因是过参数化。现代网络参数量（上亿）远大于样本数，导致损失景观出现大量"平坦的连通低值区"：

  • 当模型能拟合训练集到零误差（插值）时，许多局部极小其实是全局意义上的好解；
  • 在过参数化与某些结构假设下，可以证明几乎所有局部极小都接近全局最优（例如矩阵分解、两层线性网络的经典结果）；
  • 即使存在坏点，随机初始化的 SGD 也几乎必然落在"好"的那片景观上。

一句话概括：深度学习不需要"找到全局最优"，它只需要"找到一个足够好的局部最优"——而过参数化保证这样的点遍地都是，SGD 随便落一个都行。

5. 损失的景观是"一碗通心粉"：平坦区而非尖锐坑#

经验与理论（损失景观可视化、Neural Tangent Kernel 等）都指出：训练好的深度网络大多停在平坦的宽谷里，而不是尖锐的深坑。平坦的极小值点对参数扰动不敏感，因而泛化更好（这也呼应 chapter-4 的偏差-方差与 chapter-7 的泛化理论）。宽谷让 SGD 的噪声扰动"跳不出去"，反而稳定在谷底附近——这是非凸世界里"凸味"最浓的地方。

二、验证性代码示例#

下面代码验证两件事：① 同一个非凸函数，不同初始点会被梯度下降"困"在不同局部极小里；② 一个二维严格鞍点（如 f(x1​,x2​)=x12​−x22​）如何被"带扰动"的梯度下降从鞍点逃出。代码只用于验证推导，不教 API。

import numpy as np

# ---------- 1) 一维非凸函数：x^4 - x^2，两个局部极小 ----------
def f(x):    return x**4 - x**2
def df(x):   return 4*x**3 - 2*x

def gd_1d(x0, lr=0.05, steps=200):
    x = x0
    for _ in range(steps):
        x = x - lr * df(x)
    return x

for x0 in [0.5, -0.5]:
    x_star = gd_1d(x0)
    print(f"初始 x0={x0:+.1f} -> 收敛到 x*={x_star:+.4f}, f={f(x_star):+.4f}")

# 解析解：局部极小在 ±1/sqrt(2) ≈ ±0.7071
print("解析局部极小: ±1/√2 =", round(1/np.sqrt(2), 4), "（两个对称的坑，各困住一侧）")

# ---------- 2) 二维严格鞍点：f = x1^2 - x2^2 ----------
def f2(x):   return x[0]**2 - x[1]**2
def df2(x):  return np.array([2*x[0], -2*x[1]])

def gd_2d(x0, lr=0.1, steps=500, noise=0.0):
    x = x0.astype(float)
    rng = np.random.default_rng(1)
    for _ in range(steps):
        x = x - lr * df2(x)
        if noise > 0:
            x = x + noise * rng.standard_normal(2)   # 扰动帮助逃逸鞍点
    return x

x0 = np.array([0.01, 0.0])           # 恰好落在稳定流形上（x2 分量严格为 0）
print("\n纯梯度下降在鞍点:", np.round(gd_2d(x0, noise=0.0), 5), "（x1→0 且 x2 恒为 0：停在鞍点）")
print("带扰动梯度下降:  ", np.round(gd_2d(x0, noise=0.05), 3), "（噪声给出 x2 分量，被负曲率指数放大）")

运行结果大致为：

初始 x0=+0.5 -> 收敛到 x*=+0.7071, f=-0.2500
初始 x0=-0.5 -> 收敛到 x*=-0.7071, f=-0.2500
解析局部极小: ±1/√2 = 0.7071 （两个对称的坑，各困住一侧）

纯梯度下降在鞍点: [0. 0.] （x1→0 且 x2 恒为 0：停在鞍点）
带扰动梯度下降:   [-1.11000000e-01  8.87477672e+37] （噪声给出 x2 分量，被负曲率指数放大）

第一个实验展示"局部极小陷阱"：初始值在右半边就困在右坑，左半边就困在左坑，两者函数值相同——这正是非凸世界"停下来 ≠ 找到最好"的注脚。第二个实验展示"鞍点逃逸"：f=x12​−x22​ 在 (0,0) 是鞍点，x1​ 方向（正曲率）把点拉回原点、x2​ 方向（负曲率）则把它推开。起始点取在稳定流形上（x2​ 分量严格为 0）时，纯梯度下降让 x1​→0 而 x2​ 恒为 0，于是真的停在鞍点上；一旦加入噪声，x2​ 获得非零分量，就会被 x2​←1.2x2​ 指数放大，函数值 f=−x22​ 一路下降——噪声是逃逸的引擎。

  4. 用代码：固定 x0​=(0.01,0)（初始只有 x1​ 分量），跑纯梯度下降，观察它是否也停滞在鞍点；再从 x0​=(0,0.01) 出发，观察能否自然逃逸。结合特征方向解释差异。
  5. 思考：为什么"所有特征值都非负"在高维中很罕见？提示——设 Hessian 的特征值独立随机地以一半概率为正、一半为负，计算 d 维下"全正"的概率随 d 如何变化。

母原理连接#

本课同时收束母原理 1（一切学习 = 优化） 与母原理 3（神经网络 = 可微函数逼近）：它回答的是"当优化问题不再是凸的，母原理 1 的保证还剩多少"。结论是——凸性给的是"唯一全局解"的奢侈，而非凸世界的梯度下降靠三样东西照样有效：鞍点的可逃逸性（噪声）、过参数化带来的"处处皆好解"、以及平坦宽谷的稳定性。这三者都是"可微函数逼近 + 随机优化"这一现代深度学习配方之所以成立的深层原因。你日后看到"加权重衰减能帮 SGD 逃出坏点""SGD 的噪声是特性不是缺陷"这类说法，根子都在本课。
