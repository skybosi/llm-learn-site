基础索引切片#

数据很少需要"整体"处理，更多时候我们要从中取出一部分：取前 100 个样本、取某一列特征、取一个子矩阵。NumPy 的索引与切片沿用了 Python 列表的语法，但在多维数组上强大得多。本课先打牢基础索引与切片，下一课再讲布尔掩码和花式索引。

一、概念讲解#

1. 一维数组的索引与切片#

和 Python 列表几乎一致：

  • 索引：a[i] 取第 i 个元素，支持负数索引（a[-1] 是最后一个）；
  • 切片：a[start:stop:step]，左闭右开（含 start、不含 stop），step 可省略、可为负。

2. 多维数组的索引#

用逗号分隔各维：a[row, col]。

  • a[0, 2]：取第 0 行第 2 列的元素；
  • a[:, 1]：取所有行的第 1 列（返回一维数组）——数据科学里"取某一特征列"就是这么写；
  • a[1, :] 或 a[1]：取第 1 行的所有列；
  • a[0:2, 1:3]：取第 01 行、第 12 列的子矩阵（左闭右开）。

3. 切片是视图（view）#

这是 NumPy 与 Python 列表最关键的区别之一：对数组切片得到的是原数组的视图，而不是拷贝。也就是说，切片与原数组共享同一块内存，修改切片会反过来修改原数组。这一点在数据清洗时要格外小心；若确实需要独立副本，应显式调用 .copy()。

4. 用切片做特征抽取#

在一个 (n_samples, n_features) 的特征矩阵里：

  • X[:100] 取前 100 个样本；
  • X[:, 0] 取第 0 列特征；
  • X[:, :3] 取前 3 列特征；
  • X[::2] 隔行取样本（抽样）。

二、可运行代码示例#

示例 1：一维数组索引与切片#

import numpy as np

a = np.arange(10)          # 0 ~ 9
print("a:", a)

print("a[0]:", a[0])       # 0
print("a[-1]:", a[-1])     # 9（最后一个）
print("a[2:5]:", a[2:5])   # [2 3 4]，左闭右开
print("a[::2]:", a[::2])   # 步长 2：[0 2 4 6 8]
print("a[::-1]:", a[::-1]) # 反转：[9 8 ... 0]

示例 2：二维数组（特征矩阵）的索引#

import numpy as np

# 5 个样本 x 4 个特征
X = np.arange(20).reshape(5, 4)
print("X:\n", X)

print("X[0, 2]:", X[0, 2])      # 第 0 行第 2 列
print("X[1]:\n", X[1])          # 第 1 行（所有列）
print("X[:, 0]:", X[:, 0])      # 第 0 列（所有行）——某一列特征
print("X[:, :3]:\n", X[:, :3])  # 前 3 列特征
print("X[1:4, 1:3]:\n", X[1:4, 1:3])  # 子矩阵

示例 3：切片是视图的验证#

import numpy as np

X = np.arange(20).reshape(5, 4)
col = X[:, 0]           # 取第 0 列（视图）
print("original col:", col)

col[0] = 999            # 修改切片
print("X after modifying slice:\n", X)  # X[0, 0] 变成了 999

# 想要独立副本时显式拷贝
col_copy = X[:, 1].copy()
col_copy[0] = -1
print("X[:, 1] unchanged:", X[:, 1])    # 原数组不受影响

示例 4：用切片做数据抽样#

import numpy as np

# 模拟 8 个样本，每 2 行取 1 行做抽样
X = np.arange(32).reshape(8, 4)
print("full shape:", X.shape)

sampled = X[::2]          # 取第 0、2、4、6 行
print("sampled shape:", sampled.shape)
print("sampled:\n", sampled)

# 反向取样本（逆序）
reversed_samples = X[::-1]
print("first row of reversed:", reversed_samples[0])

三、练习#

  1. 创建 np.arange(25).reshape(5, 5)，分别取出：第 2 行、第 3 列、左上角 2x2 子矩阵、最后两行最后两列。
  2. 用切片取出 np.arange(20) 中所有偶数下标元素（0, 2, 4, ...），再用切片反转该数组。
  3. 验证"切片是视图"：对一个二维数组的某列切片赋值，观察原数组是否改变；再对 .copy() 出来的副本赋值，对比结果。
  4. 思考：X[:, 0] 和 X[:, [0]] 返回的结果形状有什么不同？（提示：后者是花式索引，将在第 3 课讲解；可以先运行观察）
