链式法则的矩阵形式#

上一课我们有了梯度和雅可比矩阵这两件工具。这一课把它们接起来：当函数一层套一层时，导数如何层层传递？答案就是链式法则的矩阵形式，而深度学习里大名鼎鼎的反向传播，本质就是沿计算图倒着应用链式法则。

一、概念讲解#

1. 从标量链式法则说起#

单变量情形下，若 y=g(u)、u=f(x)，则

dxdy​=dudy​⋅dxdu​

导数一层层"乘"过去。多元情形只是把"数"换成了"矩阵"。

2. 雅可比的乘积#

若 x∈Rp 经过 f 得到 u∈Rq，再经过 g 得到 y∈Rr，那么复合函数 y=g(f(x)) 的雅可比等于两个雅可比的矩阵乘积：

Jy←x​=Jy←u​⋅Ju←x​

注意顺序：从输出端往输入端乘。一个 r×q 的矩阵乘一个 q×p 的矩阵，得到 r×p——维度也对得上。

3. 标量损失：梯度沿计算图回传#

深度学习里最常出现的是"标量损失 L 对参数求梯度"。设 L 依赖中间变量 z，z=Wx+b。链式法则给出

∂W∂L​=∂z∂L​⋅xT,∂b∂L​=∂z∂L​,∂x∂L​=WT∂z∂L​

这些式子就是反向传播的核心更新规则：上游梯度 ∂L/∂z 与局部导数相乘，一路回传到每个参数和每层输入。

4. 计算图视角#

把一次前向计算画成一张计算图（节点是中间变量，边是运算），反向传播就是沿着这张图从输出倒推：对每个节点，用"上游传下来的梯度"乘以"该节点对输入的局部导数"，再继续往前传。链式法则保证这条"梯度流"最终到达每个可训练参数。

二、可运行代码示例#

下面用一个"极小神经网络"手写一遍前向与反向传播，并用数值梯度验证结果正确。

import numpy as np

# 结构：x(2维) → z = W x + b → a = relu(z) → y = a
# 损失 L = sum((y - t)^2)，目标 t
np.random.seed(0)
W = np.array([[0.5, -0.3],
              [1.0,  0.2]])   # 2×2 权重
b = np.array([0.1, -0.2])
x = np.array([1.0, 2.0])
t = np.array([0.8, 0.0])

# ---- 前向传播 ----
z = W @ x + b
a = np.maximum(0.0, z)        # ReLU
y = a
L = np.sum((y - t) ** 2)
print("前向：z =", z, "，a =", a, "，损失 L =", L)

# ---- 反向传播（链式法则逐层回传） ----
dL_dy = 2 * (y - t)                 # ∂L/∂y
dL_da = dL_dy                       # y = a，∂y/∂a = 1
da_dz = (z > 0).astype(float)       # ReLU 的导数：z>0 为 1，否则 0
dL_dz = dL_da * da_dz               # ∂L/∂z（上游梯度）
dL_dW = np.outer(dL_dz, x)          # ∂L/∂W = ∂L/∂z ⊗ x
dL_db = dL_dz                       # ∂L/∂b = ∂L/∂z
dL_dx = W.T @ dL_dz                 # ∂L/∂x = W^T ∂L/∂z

print("∂L/∂W =\n", dL_dW)
print("∂L/∂b =", dL_db)
print("∂L/∂x =", dL_dx)

# ---- 数值梯度验证反向传播是否正确 ----
def loss_of_W(Wmat):
    zz = Wmat @ x + b
    aa = np.maximum(0.0, zz)
    return np.sum((aa - t) ** 2)

h = 1e-6
num_grad = np.zeros_like(W)
for i in range(2):
    for j in range(2):
        Wp = W.copy(); Wm = W.copy()
        Wp[i, j] += h; Wm[i, j] -= h
        num_grad[i, j] = (loss_of_W(Wp) - loss_of_W(Wm)) / (2*h)
print("数值梯度 =\n", num_grad)
print("反向传播与数值梯度一致：", np.allclose(dL_dW, num_grad, atol=1e-4))

要点：反向传播算出的 dL_dW 与逐元素扰动得到的数值梯度一致，说明链式法则的矩阵形式正确——这也是 PyTorch、TensorFlow 自动求导引擎在底层做的事。

三、练习#

  1. 手推：对 z = W x + b，验证 ∂L/∂x=WT∂L/∂z（从分量展开推导）。
  2. 修改：把代码里的 ReLU 换成 sigmoid σ(z)=1/(1+e−z)（其导数为 σ(z)(1−σ(z))），改写 da_dz 并重新做数值验证。
  3. 代码：给上面的网络再加一层，写出两层网络的前向与反向传播，体会梯度如何在层间"接力"。
  4. 思考：为什么反向传播的梯度要用"从输出到输入"的顺序相乘，而不能倒过来？
