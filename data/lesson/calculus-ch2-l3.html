微分的意义与应用#

导数和微分像一对双胞胎，常被一起提起。粗浅地说：导数是一个"率"（变化快慢），微分是一个"量"（变化了多少）。这一课我们搞清微分的含义，并看看它如何帮我们"用小变化近似大世界"。

一、概念讲解#

1. 微分 dy：切线带来的"增量"#

回忆导数：f'(x) 是曲线在 x 处的切线斜率。现在问一个实际问题：如果自变量从 x 增加一个小量 Δx，函数值 f 大约会变多少？

答案是：沿着切线走。切线的斜率是 f'(x)，所以当 x 增加 dx 时，切线上的"上升量"是：

dy = f'(x) · dx

这个 dy 就是函数在 x 处的微分，dx 是自变量的微分。微分的意义是：用切线（线性）近似曲线，把一小段弯的曲线看成直的，从而估算函数值的变化量。

2. 线性近似：局部用直线代替曲线#

微分直接带来一个超实用的工具——线性近似。在 a 附近，函数可以近似成：

f(x) ≈ f(a) + f'(a)(x - a)

右边正是一条经过 (a, f(a))、斜率为 f'(a) 的切线方程。只要 x 离 a 不太远，这个近似就相当准。它的价值在于：用最简单的一次函数，去逼近任何复杂函数——只要在足够小的局部。

3. 微分与机器学习#

  • 梯度下降的一步：参数更新 w ← w - α·L'(w) 里，α·L'(w) 就是"沿切线走一小步"的量，本质是微分思想。
  • 局部线性化：很多优化方法（如牛顿法、泰勒展开）都是"用直线/二次曲线在局部近似损失函数"。
  • 反向传播：把误差一层层往回传时，每层贡献的"微小变化量"正是微分的概念。

二、可运行示例#

示例一：用微分估算 √(4.1)#

f(x) = √x 在 x=4 处：f(4)=2，f'(x)=1/(2√x)，所以 f'(4)=1/4。线性近似：

√(4.1) ≈ f(4) + f'(4)·0.1 = 2 + 0.1/4 = 2.025
import math

def sqrt_approx(a, target):
    """用 f(x)=√x 在 a 处的线性近似估算 f(target)。"""
    fa = math.sqrt(a)
    fprime = 1 / (2 * math.sqrt(a))   # (√x)' = 1/(2√x)
    return fa + fprime * (target - a)

approx = sqrt_approx(4, 4.1)
exact = math.sqrt(4.1)
print(f"√(4.1) 线性近似 = {approx:.6f}")
print(f"√(4.1) 真实值   = {exact:.6f}")
print(f"误差           = {abs(approx-exact):.6f}")

运行结果：

√(4.1) 线性近似 = 2.025000
√(4.1) 真实值   = 2.024846
误差           = 0.000154

误差只有约万分之 1.5，非常小——这就是"局部用直线代替曲线"的威力。

示例二：误差传播——输入有小误差，输出误差多大？#

工程和科学计算里常遇到：测量值有误差，经过函数计算后，结果的误差会放大还是缩小？微分给出答案：Δy ≈ f'(x)·Δx。

def error_propagation(f, fprime, x, dx):
    """用微分估算：输入误差 dx 引起的输出误差 f'(x)*dx。"""
    return fprime(x) * dx

# 测量圆的半径 r=10 cm，有 0.1 cm 误差，估算面积误差。
# 面积 A(r) = πr^2，A'(r) = 2πr
r, dr = 10.0, 0.1
area_err = error_propagation(
    f=lambda r: math.pi * r * r,
    fprime=lambda r: 2 * math.pi * r,
    x=r, dx=dr
)
print(f"\n半径 r={r}cm，测量误差 {dr}cm 时：")
print(f"  面积误差的微分估算 ≈ {area_err:.3f} cm²")
print(f"  真实面积误差       = {math.pi*(r+dr)**2 - math.pi*r*r:.3f} cm²")

示例三：梯度下降的一小步（预告）#

我们提前看一眼微分如何驱动机器学习（完整内容在第 3 章末）：

def L(w):
    """损失函数 L(w) = (w - 3)^2，最小值在 w=3。"""
    return (w - 3) ** 2

def dL(w):
    """损失函数的导数 L'(w) = 2(w - 3)。"""
    return 2 * (w - 3)

w = 0.0
alpha = 0.1   # 学习率
for step in range(1, 11):
    w = w - alpha * dL(w)   # 沿切线走一小步（微分思想）
    print(f"第 {step:2d} 步：w = {w:.4f}，损失 L = {L(w):.4f}")

运行后你会看到 w 一步步逼近 3、损失一步步逼近 0——每一步"走多远"，正是由微分 dL(w) 决定的。

三、练习#

  1. 用线性近似估算 √(9.2) 和 √(16.05)，并与真实值比较误差；说说为什么离展开点越远误差越大。
  2. 用微分估算 f(x)=eˣ 在 x=0.05 处的值（在 x=0 处展开，f'(0)=1），与真实值对比。
  3. 改写"误差传播"示例：求体积 V(r) = (4/3)πr³，当半径误差为 dr=0.1、r=10 时，体积误差约多大？
  4. 把"梯度下降"示例的 alpha 改成 0.5 和 0.01，观察收敛速度的变化，并思考学习率"太大/太小"各有什么问题。
