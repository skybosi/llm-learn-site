学习率与收敛#

学习率是梯度下降里最关键的"旋钮"：拧太大，会在最低点附近来回震荡甚至飞出去；拧太小，又会慢得让人抓狂。这一课我们学会怎么调，以及怎么判断"训好了"。

一、概念讲解#

1. 学习率决定每步走多远#

更新公式 θ ← θ - η·∇f(θ) 里的 η 就是学习率。它的大小直接决定收敛表现：

  • 太大：一步跨过最低点，来回震荡，甚至越走越远（发散）；
  • 太小：每步只挪一点点，收敛极慢，训练迟迟不结束；
  • 合适：快速、平稳地逼近最低点。

2. 收敛判据：怎么算"训好了"#

常见的停止条件有：

  • 梯度范数足够小：‖∇f‖ < ε，说明已经到了几乎水平的谷底；
  • 损失不再明显下降：连续若干轮损失变化小于阈值；
  • 达到最大迭代次数：作为兜底，防止无限循环。

3. 学习率调度：让步长"由大到小"#

一个常用技巧是学习率衰减：训练初期用较大的学习率快速前进，随着接近最优，逐步调小步长以免冲过头。常见做法有按轮数衰减、按固定比例衰减等。

4. 局部极小、鞍点与动量#

在非凸的损失曲面上，普通梯度下降可能卡在鞍点或局部极小。动量（momentum）会累积历史梯度，像"滚下坡的球"一样获得惯性，从而更快穿过平缓区域，是后来 Adam 等优化器的基础。

二、可运行示例#

示例 1：不同学习率的对比#

对 f(x) = (x-3)²，用四种学习率各跑一遍，观察最终结果。

def df(x):
    return 2 * (x - 3)   # f'(x)

def run(lr, steps=30):
    x = 0.0
    for _ in range(steps):
        x = x - lr * df(x)
    return x

for lr in [0.01, 0.1, 0.9, 1.01]:
    x_final = run(lr)
    print(f"学习率 {lr}: 30 步后 x = {x_final:+.4f}")
# 0.01 收敛慢，0.1 平稳收敛，0.9 震荡收敛，1.01 发散

示例 2：收敛判据 + 学习率衰减#

用"梯度范数足够小"作为停止条件，并让学习率随迭代轮数衰减。

def df(x):
    return 2 * (x - 3)

x = 0.0
lr = 0.1
for step in range(1000):
    g = df(x)
    if abs(g) < 1e-6:          # 收敛判据：梯度足够小
        print(f"第 {step} 步收敛：x = {x:.6f}")
        break
    x -= lr * g
    lr = 0.1 / (1 + 0.05 * step)   # 学习率随步数衰减
else:
    print("达到最大迭代次数，仍未完全收敛。")

示例 3：动量加速收敛#

对比普通梯度下降与带动量的梯度下降在 f(x) = (x-3)² 上的收敛速度。

def df(x):
    return 2 * (x - 3)

x_plain = 0.0          # 普通梯度下降
x_mom = 0.0            # 带动量的梯度下降
v = 0.0                # 动量速度
lr = 0.05
beta = 0.5             # 动量系数：每次保留一半历史速度

print("step | 普通 x | 动量 x")
for step in range(61):
    x_plain -= lr * df(x_plain)       # 普通更新
    v = beta * v - lr * df(x_mom)     # 速度先累积历史，再叠加当前梯度
    x_mom += v                        # 用速度更新位置
    if step % 10 == 0:
        print(f"{step:4d} | {x_plain:+.4f} | {x_mom:+.4f}")
# 可见约第 20 步时，动量已基本到达 x=3，而普通梯度下降仍在缓慢逼近。

三、练习#

  1. 把示例 1 的学习率换成 0.5、1.0、1.5，运行并描述各自的收敛行为。
  2. 在示例 2 的基础上，把收敛阈值 1e-6 改成 1e-3，观察达到收敛所需的步数变化，并解释原因。
  3. 结合示例 3，解释"动量"为什么能帮助梯度下降更快穿过平缓区域，以及 beta 取更大或更小会带来什么影响。
