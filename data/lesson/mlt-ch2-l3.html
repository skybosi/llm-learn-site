从 MLE 推出交叉熵#

上一课我们从"高斯噪声 + MLE"推出了 MSE。这一课换个任务：分类。逻辑回归为什么用交叉熵，而不用平方损失？答案与上一课同源——假设标签服从伯努利分布，再做最大似然估计，交叉熵就自动出现。更有意思的是，我们还能反过来看清"为什么分类不该用平方损失"。最后，交叉熵还会把我们引向信息论的母原理。

一、概念讲解#

1. 二分类的概率模型#

二分类里标签 y ∈ {0, 1}。我们想让模型输出"样本属于正类（y=1）的概率"，记作：

p = P(y = 1 | x) = σ(wᵀx + b),    σ(z) = 1/(1 + e⁻ᶻ)

sigmoid 函数把任意实数 z = wᵀx + b 压到 (0, 1)，恰好当概率用。那么 y 关于 x 的分布就是伯努利分布：

P(y | x; w) = p^y · (1 − p)^{1−y}

验证一下：当 y=1 时该式等于 p；当 y=0 时等于 1−p。一个式子同时覆盖两种情况，这就是伯努利分布的紧凑写法。

2. 写出似然，取对数#

训练集里 m 个样本独立同分布，似然是连乘：

L(w) = ∏ᵢ₌₁ᵐ pᵢ^{yᵢ} · (1 − pᵢ)^{1−yᵢ},   其中 pᵢ = σ(wᵀxᵢ + b)

取对数：

log L(w) = Σᵢ [ yᵢ log pᵢ + (1 − yᵢ) log(1 − pᵢ) ]

最大化 log L 等价于最小化它的相反数——这就是二分类交叉熵（binary cross-entropy）：

J(w) = −(1/m) Σᵢ [ yᵢ log pᵢ + (1 − yᵢ) log(1 − pᵢ) ]

结论：逻辑回归的交叉熵损失，就是"伯努利标签 + MLE"的必然产物，与上一课"MSE = 高斯噪声 + MLE"结构完全对称。至此第 2 章的母题闭环了：

高斯噪声    + MLE  ⟹  MSE（回归）
伯努利标签  + MLE  ⟹  交叉熵（分类）

3. 为什么不用平方损失做分类？#

现在能回答那个经典问题了。若在分类里硬用平方损失 (y − σ(z))²，会出两个毛病：

  • 梯度消失：对 z 求导得 2(σ(z)−y)·σ'(z)，而 σ'(z) = σ(z)(1−σ(z)) 在 σ 接近 0 或 1（即预测很自信但可能错得离谱）时趋于 0——错得越离谱，梯度反而越小，训练近乎停滞。
  • 非凸：平方损失 + sigmoid 的目标函数非凸，可能陷入局部最优。

而交叉熵的梯度则优雅得多：

∂J/∂z = (1/m) Σᵢ (pᵢ − yᵢ) · xᵢ

梯度正比于"预测概率 − 真实标签"，预测越错、梯度越大，且目标函数凸。这个漂亮的梯度，正是"MLE 派生损失"的礼物——概率模型会自动抵消 sigmoid 带来的梯度饱和。

4. 多分类：从伯努利到分类分布（softmax + 交叉熵）#

推广到 K 类，标签 y 用 one-hot 向量表示（真实类那一维为 1）。模型输出 K 个"得分" z₁,…,z_K，经 softmax 转成概率：

p_k = e^{z_k} / Σⱼ e^{zⱼ}

p_k 构成一个合法的分类分布（非负、求和为 1）。单个样本的似然是其真实类别的概率 p_{y}（y 是真实类索引），对数似然为 log p_y，交叉熵为：

J = −(1/m) Σᵢ log p_{yᵢ} = −(1/m) Σᵢ Σₖ yᵢₖ log pᵢₖ

当 K=2 时，它退化为二分类交叉熵。softmax 与交叉熵的组合，是多分类的 MLE，也是今天所有神经网络分类头的标准配置。

5. 交叉熵的信息论含义#

交叉熵不只是"方便的概率损失"，它有深刻的信息论含义。设真实标签分布为 q（one-hot），模型预测分布为 p，则交叉熵：

H(q, p) = −Σₖ qₖ log pₖ

可以拆成：

H(q, p) = H(q) + D_KL(q ‖ p)

其中 H(q) 是真实分布的熵（与模型无关的常数），D_KL(q ‖ p) 是模型 p 偏离真实 q 的 KL 散度。所以最小化交叉熵 ≡ 最小化 KL 散度 ≡ 让模型分布 p 尽可能贴近真实分布 q。交叉熵还可以理解为"用模型分布 p 的编码去编码真实数据时，平均所需的比特数下限"——编码越贴近真实分布，平均码长越短。这是第 2 章通向"信息论视角"母原理的钥匙。

二、可运行代码示例#

手工验证：① 伯努利 MLE 推出的交叉熵，其最优参数确实把 sigmoid 概率拟合到真实标签；② 用数值微分数值计算交叉熵梯度，与解析梯度 Xᵀ(p−y)/m 对照，证明推导无误。

import numpy as np

rng = np.random.default_rng(9)
m = 500
X = np.c_[np.ones(m), rng.normal(0, 1, size=m)]
true_w = np.array([-1.0, 2.0])                 # 真实分界
p_true = 1 / (1 + np.exp(-(X @ true_w)))
y = (rng.random(m) < p_true).astype(float)     # 按伯努利采样标签

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def ce_loss(w, X, y):
    p = sigmoid(X @ w)
    return float(-np.mean(y * np.log(p + 1e-12) + (1 - y) * np.log(1 - p + 1e-12)))

def ce_grad(w, X, y):
    p = sigmoid(X @ w)
    return (1 / len(y)) * X.T @ (p - y)        # 解析梯度

# 用解析梯度做梯度下降
w = np.zeros(2); lr = 0.1
for _ in range(5000):
    w = w - lr * ce_grad(w, X, y)
print("交叉熵最优 w =", np.round(w, 4), "（应接近真实 [-1, 2]）")

# 用数值微分验证梯度公式正确
w0 = np.array([0.3, -0.2]); eps = 1e-5
grad_numeric = np.zeros(2)
for j in range(2):
    w_p, w_m = w0.copy(), w0.copy()
    w_p[j] += eps; w_m[j] -= eps
    grad_numeric[j] = (ce_loss(w_p, X, y) - ce_loss(w_m, X, y)) / (2 * eps)
grad_analytic = ce_grad(w0, X, y)
print("解析梯度 =", np.round(grad_analytic, 6))
print("数值梯度 =", np.round(grad_numeric, 6))
print("两者一致：", np.allclose(grad_analytic, grad_numeric, atol=1e-4))

解析梯度与数值梯度吻合，说明交叉熵的推导与实现都正确；梯度下降收敛到的 w 也贴近真实分界参数。从伯努利假设到交叉熵、再到可运行的优化，整条推导链被代码逐环验证。

三、练习#

  1. 从 P(y|x;w) = p^y(1−p)^{1−y} 出发，完整推导交叉熵损失 J(w) = −(1/m)Σ[y log p + (1−y)log(1−p)]，并说明"最大化对数似然"为何等价于"最小化该式"。
  2. 对 z = wᵀx 求 J 的导数，证明 ∂J/∂z = p − y（单样本）。由此解释"预测越错、梯度越大"，并与平方损失+sigmoid 的梯度 (p−y)·p(1−p) 对比，指出后者会梯度消失。
  3. 推导 softmax 交叉熵的梯度：证明对第 k 维得分 z_k，∂(−log p_y)/∂z_k = p_k − y_k。这个"概率减 one-hot"的形式与二分类完全同构，请点明。
  4. 解释 H(q,p) = H(q) + D_KL(q‖p) 的拆解，并回答：为什么"最小化交叉熵"可以等价地说成"最小化模型分布与真实分布的 KL 散度"？H(q) 为何可以忽略？

母原理连接#

本课横跨两个母原理。其一，"概率视角统一"：交叉熵 = 伯努利/分类分布 + MLE，与上一课的"MSE = 高斯 + MLE"形成完美对称，把回归与分类的损失统一在"负对数似然"这一面旗帜下。其二，"信息论视角"：交叉熵 = 真实分布熵 + KL 散度，最小化交叉熵就是让模型分布逼近真实分布，也是压缩视角下"最短平均码长"的追求。从此，"损失函数"在你眼里有了三副面孔——优化目标、负对数似然、编码长度，它们是同一个东西。
