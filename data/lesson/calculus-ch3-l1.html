多元函数#

前两章的函数都只有一个输入 x。但现实中的模型很少只有一个参数——线性回归有"权重"和"偏置"，神经网络动辄上百万个参数。损失函数 L 依赖一大堆参数，这就是典型的多元函数。这一课我们进入"多维世界"。

一、概念讲解#

1. 多元函数：多个输入，一个输出#

单变量函数是 y = f(x)：一个输入，一个输出。多元函数则是：

z = f(x, y, ...)

多个输入，仍然只有一个输出（输出也可以是向量，但初学先聚焦标量输出）。

常见例子：

  • 矩形面积 S = x·y（两个输入：长和宽）；
  • 二元一次函数 z = ax + by + c；
  • 机器学习里，损失函数 L(w₁, w₂, ..., wₙ) 输入是 n 个参数，输出是一个"损失值"。

2. 怎么"看"多元函数#

单变量函数画在平面坐标系里是一条曲线；二元函数 z = f(x, y) 要画在三维空间里，是一张曲面——两个输入 x, y 铺成地面，高度就是输出 z。想象一张起伏的地形图：山峰是极大值，山谷是极小值，这正是优化算法要寻找的"最低谷"。

还有一种常用视角是等高线（等高线图/contour）：就像地图上用一圈圈线表示海拔，把曲面上"z 相同"的点连起来。同一圈等高线上，函数值处处相等。梯度下降时，我们常在高维损失函数上"下山"，等高线是理解"下山方向"的绝佳工具。

3. 损失函数：AI 里最重要的多元函数#

以最简单的线性回归为例，我们希望找到 w 和 b，使预测值 w·x + b 尽量接近真实值 y。常用的均方误差（MSE）损失是：

L(w, b) = (1/n) · Σ ( w·xᵢ + b − yᵢ )²

它的输入是 w 和 b 两个参数，输出是一个数"误差"。训练模型 = 找到使 L(w,b) 最小的那组 (w, b)。你看，整个机器学习训练，就是在一个多元函数的"地形"上寻找最低点。

二、可运行示例#

下面用 Python 亲手构造二元函数并计算它的值。

import math

def plane(x, y):
    """二元一次函数 z = 3x + 2y + 1（一张倾斜的平面）。"""
    return 3 * x + 2 * y + 1

def paraboloid(x, y):
    """z = x^2 + y^2（碗形曲面，最小值在原点）。"""
    return x * x + y * y

# 1) 直接算几个点
print("plane(1, 2)      =", plane(1, 2))        # 3+4+1 = 8
print("paraboloid(1, 2) =", paraboloid(1, 2))    # 1+4 = 5
print("paraboloid(0, 0) =", paraboloid(0, 0))    # 0，最低点

# 2) 用双层循环生成一张"数值网格"，模拟等高线图的数据
print("\nparaboloid 在 x,y ∈ {-2..2} 上的取值网格：")
for y in range(2, -3, -1):          # y 从上到下
    row = []
    for x in range(-2, 3):          # x 从左到右
        row.append(f"{paraboloid(x, y):3d}")
    print("  ".join(row))

运行结果：

plane(1, 2)      = 8
paraboloid(1, 2) = 5
paraboloid(0, 0) = 0

paraboloid 在 x,y ∈ {-2..2} 上的取值网格：
  8   5   4   5   8
  5   2   1   2   5
  4   1   0   1   4
  5   2   1   2   5
  8   5   4   5   8

看这个网格：正中间是 0（最低点），越往外数值越大，一圈圈扩散开——这就是"碗形"曲面的等高线，中间是谷底。梯度下降要做的，就是从某个点出发，一路"滑"向这个谷底。

一个真实的损失函数#

# 线性回归：数据点 (x, y)，用模型 y_hat = w*x + b 拟合，求 MSE 损失。
data = [(1, 2), (2, 4), (3, 6)]   # 三个点，真实关系恰好是 y = 2x

def mse_loss(w, b):
    """损失函数 L(w,b)：多个输入(w,b)，一个输出(误差)。"""
    total = 0.0
    for x, y in data:
        pred = w * x + b
        total += (pred - y) ** 2
    return total / len(data)

print("\n不同参数下的损失 L(w, b)：")
for w, b in [(2, 0), (1, 0), (3, 0), (2, 1)]:
    print(f"  w={w}, b={b} -> L = {mse_loss(w, b):.3f}")

print("\n(2,0) 的损失最小（为 0），因为数据正是 y=2x 生成的。")

运行结果：

不同参数下的损失 L(w, b)：
  w=2, b=0 -> L = 0.000
  w=1, b=0 -> L = 1.000
  w=3, b=0 -> L = 1.000
  w=2, b=1 -> L = 1.000

L 就是输入为 (w, b) 的多元函数：参数对上了，损失为 0；参数偏离，损失变大。训练模型 = 找到让 L 最小的 (w, b)。

三、练习#

  1. 定义二元函数 z = x² - y²（马鞍面），打印它在 x,y ∈ {-2..2} 上的取值网格，观察和 paraboloid 的"碗形"有什么不同。
  2. 修改 mse_loss 的数据为 [(1, 3), (2, 5), (3, 7)]，猜测使损失为 0 的 (w, b) 是什么，并验证。
  3. 用两重循环找出 paraboloid 在 x,y ∈ {-10..10} 上的最小值点，体会"穷举搜索"在参数空间变大时有多低效（提示：如果每个参数有 21 个候选，两个参数就要试 441 次；100 个参数呢？）。
  4. 想一想：为什么说"神经网络有上百万个参数"意味着损失函数是"上百万元的函数"？用一句自己的话说明这给优化带来的挑战。
