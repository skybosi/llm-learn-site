类型系统与类型检查规则#

"1" + 1        // JavaScript: "11"，不报错

一行不报错却含义诡异的代码，比报错的代码更危险。类型检查的目标不是"防止手误"，而是把"运行期才可能爆炸"的东西提前成编译期的判定。本课把它写成一张可运行的规则表：说清"类型"是什么、规则怎么写、哪里最容易漏，再用不到百行 Python 实现一个能给出准确诊断的检查器。

一、概念讲解#

1. 类型表达式：类型系统的词汇表#

龙书 §6.3.1 的起点：类型表达式（type expression）要么是基本类型，要么是对类型构造子（type constructor）的一次应用。构造子至少四种：数组 array(n, T)、记录 record(字段名与类型)、乘积 T1 × T2、函数 T1 → T2。本课只用两个基本类型加一个函数构造子：

写法 含义 出现位置
int / float 基本类型 字面量、变量、运算符规则
bool / string 基本类型 比较结果、+ 的字符串拼接
(T1, T2) → R 函数类型 函数调用规则
error 检查器内部哨兵，不是语言类型 第 6 小节

把类型写成数据而不是散落的字符串比较，规则才能变成"查表"，检查器也才能保持短小。

2. 类型等价：结构等价 vs 名字等价#

规则里到处要问"这两个类型是不是同一个"，龙书 §6.3.2 说这是两种流派：

  • 结构等价（structural）：递归比较类型表达式的结构，相同即等价。实现简单，但 type Meters = float 与 type Feet = float 会被当成同一个类型，单位信息丢了。
  • 名字等价（nominal）：只有同一个名字声明的类型才等价。Ada 的 type MyInteger is new Integer; 之下，两者的变量互相赋值就是类型错误——结构一样也没用。

要区分"语义不同的同构类型"（单位、ID、句柄）就用名字等价，只关心"能否按同一套操作处理"就用结构等价。例 2 是结构等价的实现：两个匿名记录在名字等价下永远不同。

3. 静态检查、可靠（sound）与强类型#

§6.5 把类型检查拆成三件事：语言提供类型系统（"什么类型能出现在哪"）；编译器为程序各部分赋类型；编译器保证用法符合规则。第三件事不必在编译期完成——检查可以推到运行期，但那时编译器的工作是"生成检查代码"而非"判定合法"。于是有两个易混术语：

  • 可靠（sound）的类型系统：保证所有检查都能在执行前完成。
  • 强类型的实现：编译出的程序保证不会出现类型错误。

"可靠"说的是系统性质，不是编译器的完成度。

4. 规则的两种形式：综合与推导#

§6.5.1 区分两类检查：类型综合（type synthesis）用子部分类型推出整体类型，自底向上（int + float → float）；类型推导（type inference）从用法反推类型，ML 系语言靠它做到不写标注也能检查。本课只做综合——它是下一课"隐式转换"的前置。加法规则写成判断式是：

Γ ⊢ e1 : int     Γ ⊢ e2 : int
─────────────────────────────          Γ 是类型环境：名字 → 类型
        Γ ⊢ e1 + e2 : int

Γ（Gamma）就是第 1 课符号表里 name → type 的投影；规则可以直译成字典键 (op, 左类型, 右类型)，表外一切组合都判错。

5. 一张检查清单#

真实编译器漏检查的地方高度集中，把规则列全比写代码更重要：

构造 规则 违反时
变量引用 名字在 Γ 中可查 未定义变量 + 引用处行号
二元算术 两侧同类型且属 int/float（+ 另允许 string） 运算符不接受 A 与 B
比较 两侧同类型且可比 同上
赋值 Γ(名字) 与右值类型相同 声明为 X，却赋了 Y
函数调用 函数存在；实参个数与逐个类型相等 未定义函数 / 个数 / 实参不匹配
条件表达式 条件为 bool，两分支类型一致 条件非布尔 / 分支不一致

本课刻意不做隐式转换：f / x 必须报错。这不是偷懒，而是把它留到下一课当显式规则引入。

6. error 类型：一个错误只报一次#

不加哨兵时，(z + 1) * 2 会因为 z 未定义而连报三条（+、* 各叠一条）。用户只需看第一条：给类型格加一个 error，子节点一旦是 error，父节点直接返回它、不再生成新诊断。例 1 用 suppress 开关对照，诊断条数是 1 与 3。

7. 常见坑#

  1. 报错不含位置与期望：只说 type error 等于没说；诊断至少要给位置、期望类型与实际类型。
  2. 把"类型不同"写成一句话：bool + int 与 int + string 是两类问题，混淆后不知该改哪边。
  3. 漏掉调用点的检查：最容易忘的是实参个数与返回类型。
  4. 规则表与文档不同步：规则表是唯一事实源；加了规则却没加表项，后续 pass 行为就会不一致。

二、可运行代码示例#

例 1 是一个完整检查器：RULES 是规则表，FUNCS 是函数签名表，Checker.check 自底向上综合类型，返回 ERR 抑制级联报错。

# ---- 例 1：类型检查器（严格规则：不做隐式转换）----
INT, FLOAT, BOOL, STR, ERR = 'int', 'float', 'bool', 'string', 'error'

RULES = {                      # (运算符, 左类型, 右类型) -> 结果类型；表里没有就是类型错误
    ('+', INT, INT): INT,     ('+', FLOAT, FLOAT): FLOAT, ('+', STR, STR): STR,
    ('-', INT, INT): INT,     ('-', FLOAT, FLOAT): FLOAT,
    ('*', INT, INT): INT,     ('*', FLOAT, FLOAT): FLOAT,
    ('/', INT, INT): INT,     ('/', FLOAT, FLOAT): FLOAT,   # int / int 是整数除法
    ('<', INT, INT): BOOL,    ('<', FLOAT, FLOAT): BOOL,
    ('==', INT, INT): BOOL,   ('==', FLOAT, FLOAT): BOOL,   ('==', STR, STR): BOOL,
}

FUNCS = {                      # 函数签名：名字 -> (形参类型元组, 返回类型)
    'add':  ((INT, INT), INT),
    'sqrt': ((FLOAT,), FLOAT),
    'len':  ((STR,), INT),
}

class Checker:
    """自底向上综合类型（type synthesis）；返回 ERR 以抑制级联报错"""
    def __init__(self, env, suppress=True):
        self.env = env             # 名字 -> 类型，由第 1 课的符号表给出
        self.suppress = suppress   # True: 子节点出错就返回 ERR，不再叠加错误
        self.errors = []

    def error(self, line, msg):
        self.errors.append(f'L{line}: {msg}')
        return ERR

    def check(self, node, line):
        tag = node[0]
        if tag == 'num':                                  # ('num', 值, 类型)
            return node[2]
        if tag == 'var':                                  # ('var', 名字)
            name = node[1]
            if name not in self.env:
                return self.error(line, f'未定义变量 {name!r}')
            return self.env[name]
        if tag == 'bin':                                  # ('bin', op, 左, 右)
            _, op, left, right = node
            lt, rt = self.check(left, line), self.check(right, line)
            if ERR in (lt, rt):
                if self.suppress:
                    return ERR                            # 关键：子节点已出错，不再报第二遍
                return self.error(line, f'运算符 {op!r} 不接受 {lt} 与 {rt}')
            if (op, lt, rt) not in RULES:
                return self.error(line, f'运算符 {op!r} 不接受 {lt} 与 {rt}')
            return RULES[(op, lt, rt)]
        if tag == 'call':                                 # ('call', 函数名, [实参...])
            _, name, args = node
            if name not in FUNCS:
                return self.error(line, f'未定义函数 {name!r}')
            params, ret = FUNCS[name]
            if len(args) != len(params):
                return self.error(line, f'{name} 要 {len(params)} 个参数，给了 {len(args)} 个')
            ats = [self.check(a, line) for a in args]
            if ERR in ats:
                return ERR
            bad = [(p, a) for p, a in zip(params, ats) if p != a]
            if bad:
                return self.error(line, f'{name} 实参不匹配：' +
                                  '；'.join(f'需要 {p} 得到 {a}' for p, a in bad))
            return ret
        if tag == 'assign':                               # ('assign', 名字, 右值)
            _, name, rhs = node
            rt = self.check(rhs, line)
            if rt == ERR:
                return ERR
            if name not in self.env:
                return self.error(line, f'赋值给未声明的变量 {name!r}')
            if self.env[name] != rt:
                return self.error(line, f'{name} 声明为 {self.env[name]}，却赋了 {rt}')
            return rt
        raise AssertionError(f'未知节点 {tag}')

ENV = {'x': INT, 'f': FLOAT, 's': STR, 'b': BOOL}
num = lambda v, t=INT: ('num', v, t)
var = lambda n: ('var', n)

CASES = [
    'x + x', 'x + s', 'b + x', 'f / x', 's + s',
    'add(x, x)', 'add(x, f)', 'add(x)', 'sqrt(x)', '(z + 1) * 2',
]
for src in CASES:
    ast = {
        'x + x':        ('bin', '+', var('x'), var('x')),
        'x + s':        ('bin', '+', var('x'), var('s')),
        'b + x':        ('bin', '+', var('b'), var('x')),
        'f / x':        ('bin', '/', var('f'), var('x')),
        's + s':        ('bin', '+', var('s'), var('s')),
        'add(x, x)':    ('call', 'add', [var('x'), var('x')]),
        'add(x, f)':    ('call', 'add', [var('x'), var('f')]),
        'add(x)':       ('call', 'add', [var('x')]),
        'sqrt(x)':      ('call', 'sqrt', [var('x')]),
        '(z + 1) * 2':  ('bin', '*', ('bin', '+', var('z'), num(1)), num(2)),
    }[src]
    c = Checker(dict(ENV))
    t = c.check(ast, 1)
    print(f'{src:12s} -> {"OK" if t != ERR else "REJECT":6s} type={t:6s} {c.errors}')

# 同一个错误表达式，关掉 ERR 短路后错误会"级联"成三条
for suppress in (True, False):
    c = Checker(dict(ENV), suppress=suppress)
    c.check(('bin', '*', ('bin', '+', var('z'), num(1)), num(2)), 1)
    print(f'suppress={suppress!s:5s} 错误条数={len(c.errors)} {c.errors}')
x + x        -> OK     type=int    []
x + s        -> REJECT type=error  ["L1: 运算符 '+' 不接受 int 与 string"]
b + x        -> REJECT type=error  ["L1: 运算符 '+' 不接受 bool 与 int"]
f / x        -> REJECT type=error  ["L1: 运算符 '/' 不接受 float 与 int"]
s + s        -> OK     type=string []
add(x, x)    -> OK     type=int    []
add(x, f)    -> REJECT type=error  ['L1: add 实参不匹配：需要 int 得到 float']
add(x)       -> REJECT type=error  ['L1: add 要 2 个参数，给了 1 个']
sqrt(x)      -> REJECT type=error  ['L1: sqrt 实参不匹配：需要 float 得到 int']
(z + 1) * 2  -> REJECT type=error  ["L1: 未定义变量 'z'"]
suppress=True  错误条数=1 ["L1: 未定义变量 'z'"]
suppress=False 错误条数=3 ["L1: 未定义变量 'z'", "L1: 运算符 '+' 不接受 error 与 int", "L1: 运算符 '*' 不接受 error 与 int"]

注意 f / x 被拒绝：严格规则下 float 与 int 不能相除。这条规则正是下一课的起点——真实语言会在这里插一次隐式转换。

例 2 把类型当数据结构，演示结构等价的判定：

# ---- 例 2：结构等价 vs 名字等价（龙书 §6.3.2）；独立可运行 ----
INT, FLOAT = 'int', 'float'        # 只为让本片段单独跑起来，与例 1 同值

def structural_eq(t1, t2):
    """把类型表达式本身当树递归比较：结构相同即等价"""
    if isinstance(t1, tuple) or isinstance(t2, tuple):
        if not (isinstance(t1, tuple) and isinstance(t2, tuple)):
            return False
        return len(t1) == len(t2) and all(structural_eq(a, b) for a, b in zip(t1, t2))
    return t1 == t2

CellA = ('record', (('x', INT), ('y', FLOAT)))
CellB = ('record', (('x', INT), ('y', FLOAT)))
CellC = ('record', (('x', INT), ('y', INT)))
print('结构等价 CellA==CellB:', structural_eq(CellA, CellB),
      '| CellA==CellC:', structural_eq(CellA, CellC))
print('名字等价 CellA==CellB:', 'CellA' == 'CellB', '（按名字比，两个匿名结构永不相同）')
结构等价 CellA==CellB: True | CellA==CellC: False
名字等价 CellA==CellB: False （按名字比，两个匿名结构永不相同）

同一对类型，两种等价观给出相反的答案。选哪种不是实现细节：它决定 Meters（米）能不能悄悄换成 Feet（英尺）。

三、练习#

  1. 实现：给 Checker 增加 ('if', 条件, 分支真, 分支假) 节点：条件须为 bool、两分支类型一致，规则用独立的表表达（别塞进 check 的分支）。
  2. 解释：error 为什么能抑制级联报错，又为什么不能当普通类型放进 RULES？不加哨兵时，5 层嵌套里的未定义变量最多报几条？
  3. 对比/验证：把 ('/', INT, INT): INT 改成 ('/', INT, INT): FLOAT 后重跑例 1，说明变化，并指出"整数除法"的责任转到了谁身上。
