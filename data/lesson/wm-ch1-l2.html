为什么需要状态：POMDP 视角下的观测 ≠ 状态#

这一节要解决什么#

上一节把世界模型的最小定义写成"状态表征 + 以动作为条件的前向动力学"，并留下一个没证明的断言：状态必须从观测里被显式地提出来。

这一节要把它证出来。要回答的问题是具体的：

  1. 在一个部分可观测的环境里，"用观测历史当输入"到底错在哪？错到什么程度——是"精度差一点"，还是"结构上没有最优解"？
  2. 如果说"状态"是"足以预测未来的压缩"，那凭什么存在这样一个压缩？它不是一句工程直觉，而是一个可以证明的数学对象吗？
  3. "压缩"与"可预测"之间为什么有张力？压得太狠、压得太松分别会发生什么？
  4. 既然状态是存在的，为什么我们不去精确计算它，而要学一个循环隐状态？
  5. 上一节的判别问句 D1（状态问句）测的到底是什么？它的合格线由什么决定？

本节的三条结论先放在这里：

① belief（观测历史下的状态后验）是历史的充分统计量，且以 belief 为状态的"belief MDP"是 Markov 的——这是"状态"存在的理论依据，也是"观测 ≠ 状态"的严格含义。 ② 感知别名下，"同一个观测对应相反的最优动作"，因此任何无记忆策略都必然在某些情形成错，且次优性可以任意大；记忆不是锦上添花，是策略存在的必要条件。 ③ 状态应是对"未来 + 奖励"的最小充分统计量，而不是对观测的最小充分统计量；这两者不等，正是重建式表征跑偏的根源。

一、POMDP 与 belief：状态存在的理论依据#

1.1 从 MDP 到 POMDP#

一个部分可观测马尔可夫决策过程写成七元组

M=⟨S,A,T,R,Ω,O,γ⟩

其中 T(s′∣s,a) 是真实动力学，O(o∣s′,a) 是观测似然，Ω 是观测空间，R(s,a) 是奖励。关键点：智能体看不到 st​，只能看到 ot​。 它所有的信息就是历史

ht​=(o1​,a1​,o2​,a2​,…,ot​).

于是问题立刻出现：策略的定义域是什么？

  • 如果定义成 π(a∣ot​)——只看当前观测——这叫无记忆策略（memoryless / reactive policy）；
  • 如果定义成 π(a∣ht​)——看整段历史——这才是一般策略；
  • 而 POMDP 的最优策略，只依赖历史的一个特定函数：belief。

1.2 belief：历史的充分统计量#

定义 belief 为给定历史时状态的后验：

bt​(s)≜P(st​=s∣ht​).

它按贝叶斯规则递推。给定 bt​、执行 at​、观测到 ot+1​：

bt+1​(s′)=s′′∑​O(ot+1​∣s′′,at​)s∑​T(s′′∣s,at​)bt​(s)O(ot+1​∣s′,at​)s∑​T(s′∣s,at​)bt​(s)​

分母是归一化常数 P(ot+1​∣bt​,at​)。注意这个递推的输入只有 (bt​,at​,ot+1​)——不需要保留 ht​ 本身。这就是"充分统计量"的准确含义：关于过去的一切、对预测未来有用的信息，都已经在 bt​ 里了。

1.3 belief MDP 是 Markov 的#

命题. 以 belief 单纯形 Δ(S) 为状态空间、转移为

P(b′∣b,a)=o′∈Ω∑​P(o′∣b,a)1[b′=BeliefUpdate(b,a,o′)]

期望奖励为 Rˉ(b,a)=∑s​b(s)R(s,a) 的 MDP，其最优策略与原 POMDP 的最优策略一一对应。

为什么成立（论证而非引用）. 值函数 V∗(b) 满足 Bellman 方程

V∗(b)=amax​[Rˉ(b,a)+γo′∑​P(o′∣b,a)V∗(BeliefUpdate(b,a,o′))].

V∗(b)=amax​[Rˉ(b,a)+γo′∑​P(o′∣b,a)V∗(BeliefUpdate(b,a,o′))].

右边只用到 b、a、o′，没有用到更早的历史。因此"以 history 为输入的决策问题"可以被无损地压缩成"以 belief 为输入的 MDP"——这就是"状态存在"的严格版本（Åström 1965；Kaelbling, Littman & Cassandra, 1998 给出了标准的 POMDP 综述）。

这条命题有三个直接推论，值得单独写出来：

  • 推论 1（观测 ≠ 状态）. 一般来说 bt​ 不能由 ot​ 恢复（否则观测就是状态）。所以 π(a∣ot​) 是对最优策略的结构性限制，不是近似。
  • 推论 2（状态是"有信息量"的，不是"高维"的）. b 的维度是 ∣S∣，通常远小于历史长度——状态是压缩，而且是有损但充分的压缩。
  • 推论 3（不确定性是状态的一部分）. b 是一个分布；"我知道我在哪"与"我大概知道我在哪"是两个不同的状态，最优动作可能不同。这就是为什么世界模型里的不确定性不是可选的附加项（第 2 章第 3 节）。

1.4 为什么"用观测当状态"会以策略次优的形式暴露#

把上面三条推论反过来读，就是本节最重要的一句话：

如果策略只看 ot​，那么当两个不同的 belief 产生同一个观测时，策略必须对它们给出同一个动作——而这两个 belief 的最优动作可能正好相反。

这不是"信息不够所以差一点"，而是函数形式本身排除了正确的解。下面用一个最小环境把它变具体。

二、感知别名：一个观测，两个相反的最优动作#

2.1 环境：走廊末端的两扇门#

考虑一个极简任务：智能体先经过一段走廊，走廊上有一串含噪线索，提示"终点左边还是右边有奖励"；到达终点时，它看到的场景完全相同（没有线索），必须选左或右。

  • 隐状态 c∈{L,R}：线索方向，先验均匀 P(c=L)=P(c=R)=1/2；
  • 线索阶段 k=1,…,K：观测 ok​∈{L,R}，以 1−ε 的概率等于 c，以 ε 的概率翻转；
  • 终点阶段：观测 o⋆​ 是常数（与 c 无关）——这就是别名点；
  • 动作 a∈{L,R}，奖励 r=1[a=c]。

在这个环境里：

  • 最优（belief）策略：a∗=argmaxc​b(c)，成功率 P(线索阶段的多数方向正确)，随 K 上升趋近 1；
  • 无记忆策略：在终点只能看到常数观测 o⋆​，对所有 episode 完全一样，因此只能固定选一个方向，成功率恒为 1/2；
  • 长度 k 的历史窗口策略：用最近 k 个线索观测投票，成功率随 k 上升（有上界，见代码）。

K=5,ε=0.25 的具体数字在代码里实测。这里先给出结构性结论：无记忆策略的上界不是"训练不够"，而是 1/2——无论用多大的网络、多少数据、什么优化器。

2.2 抽屉论证：为什么无记忆确定性策略必错#

不需要任何假设，一个抽屉论证就够了。设观测空间为 Ω，无记忆确定性策略是函数 π:Ω→A。若存在两个状态 s1​=s2​ 与一个观测 o，使得 O(o∣s1​)=O(o∣s2​)>0 而最优动作 a∗(s1​)=a∗(s2​)，那么 π(o) 至多等于其中一个，在另一个状态上必错。别名越普遍，错得越多。

这条论证解释了一个常见现象：同一个输入、不同时刻，人类给出的动作是相反的，而一个"输入→动作"的模型在训练集上只能学到两者之间的折中。 表现为策略抖动、成功率卡在中间、以及"再加大模型也没用"。

2.3 次优性可以任意大#

更强的结论是：存在 POMDP，使得任何无记忆策略的次优性任意大（相对最优策略的回报差距可以超过任意给定阈值）。

构造思路（不需要形式化证明，但要把机制说清）：把 K 个独立的"线索→终点"任务首尾串成一条长轨迹，每个终点的奖励取决于该段线索。无记忆策略在每段都以固定概率 1/2 猜错，H 段之后期望回报与最优策略的差距随 H 线性增长；把每段奖励放大，差距就任意大。这说明"记忆"不是工程优化项，而是策略可达性的一部分。

⚠️ 边界说明：belief MDP 的 Markov 性依赖"真实模型 T,O 已知且固定"。若环境本身非平稳、或 T,O 依赖未建模的隐变量（隐藏的上下文），那么 belief 也需要扩张（把上下文并入状态）。这是一个真实的开放方向，不是本节可以覆盖的。

三、压缩与可预测性：状态到底该保留什么#

3.1 状态 = 对未来的最小充分统计量#

1.2 节的 belief 是"对未来观测与奖励而言的充分统计量"。但 belief 并不是唯一的：任何可逆变换、任何包含了 belief 的更大对象都"充分"。所以我们真正要的是最小的那个。

这正是计算力学里因果状态（causal state / ε-machine）的定义（Crutchfield & Young, 1989；Shalizi & Crutchfield, 2001）：

状态=把"过去"按"对未来的预测分布"等价类划分后的等价类.

两条轨迹属于同一个因果状态，当且仅当它们对所有未来的预测分布完全相同。这个对象的性质正是我们要的：

  • 充分：它保留了全部可预测信息；
  • 最小：它不区分任何"对未来无差别"的过去——所有与预测无关的细节都被压掉了；
  • 它是可预测性的下界：如果两个过去的预测分布不同，任何状态都必须区分它们（否则动力学不可能是 Markov 的）。

预测性状态表示（Predictive State Representations，Littman, Sutton & Singh, 2002）是同一思想的另一条实现路径：不显式维护 ∣S∣ 维 belief，而是维护一组"未来可观测量的预测"作为状态。这两条路线共同说明：状态的正确定义锚定在"未来"上，而不是"过去"上。

3.2 信息瓶颈：把压缩与预测写成同一个目标#

把上面的直觉写成可优化的形式，就是信息瓶颈（Tishby, Pereira & Bialek, 1999）：

p(z∣x)min​I(Z;X)−βI(Z;Y)

其中 X = 过去（观测历史），Y = 未来（下一状态/观测/奖励），Z = 我们学出来的状态。两项的作用恰好相反：

项 作用 β 变大 β 变小
−I(Z;Y) 逼状态保留预测未来所需的信息 保留更多信息 → 状态变大、可能编码噪声 保留更少 → 状态变小、可预测性下降
+I(Z;X) 逼状态丢掉与未来无关的信息 压缩变弱 压缩变强 → 可能压掉未来需要的量

这条式子是"压缩 vs 可预测"张力的全部内容：β 的两端各有一个失败模式，中间才有一个最优。它不是调参技巧，而是一个有最优点的权衡。

3.3 太狠与太松：各自的症状#

  • 压得太狠（β 太小 / 状态维度过低 / 过度正则）：症状是可预测性上限被钉死——增加数据与算力都没用，误差曲线平在某个水平。诊断方式是判别问句 D1 的加长版：给模型更多历史、看预测是否变好；如果变好，说明此前状态不足以概括历史。
  • 压得太松（β 太大 / 状态维度太高 / 无正则）：症状是状态里带着一次性噪声——模型在训练轨迹上"预测"得很准，但换一条同分布轨迹就崩（它记住的是这条轨迹的细节，不是动力学的规律）。诊断方式是看"同状态不同轨迹"的预测方差：真随机性应当保留，外生噪声不该被当作可预测信号。
  • 两端都不对，且最优位置取决于任务：需要长时预测的任务（多步 rollout）需要的状态信息多于只需单步预测的任务；而做决策的任务只关心与奖励相关的子空间——这就引出下一条。

3.4 控制需要的状态 ≠ 预测需要的状态#

这是本节最容易被忽略、但对世界模型设计影响最大的一条。

设奖励只依赖状态的某个函数 g(s)（例如"离目标多远"），而观测还包含大量与奖励无关但完全可预测的结构（墙纸、光照、背景运动）。于是：

  • 为了控制，保留 g(s) 就够（甚至只需保留 g 的一个单调变换）；
  • 为了预测，你可能还需要那些跟奖励无关的可预测自由度（否则多步 rollout 会错）；
  • 为了重建，你需要保留全部观测信息——包括那些不可预测的噪声。

三者对状态的要求是嵌套但不等同的。一个优化重建目标的状态会保留最后一类信息，而这类信息恰恰是"预测未来"用不到的——这就是第 2 章第 1 节"重建像素为什么常常是错的激励"的全部前提。

一句话总结这一节：状态是对未来的最小充分统计量；"未来"包含奖励与观测两件事，而决策只需要它们与动作耦合的那一部分。 选择保留什么，就是世界模型设计的第一性选择。

四、为什么不用精确 belief：可解性与近似#

4.1 精确 belief 的维度灾难#

belief 是 Δ(S) 上的一个点。当 S 是连续空间（机器人位姿、流体场、任意高维感知输入）时，belief 是无穷维的分布——精确滤波（连续 Bayes 滤波）一般没有闭式解，粒子滤波的样本数随状态维度指数增长。

即便 S 有限，∣S∣ 稍大（例如把图像观测离散成 106 个状态），显式维护 belief 也不可行；而 belief 空间的规划是 PSPACE 难的（Papadimitriou & Tsitsiklis, 1987 的口径）。

4.2 于是只能学：循环隐状态作为近似 belief#

工程上的解法是学一个循环映射 ht​=ϕθ​(o≤t​,a<t​)，并让后续的动力学只在 h 上推进。它要扮演的角色正是 belief：足够充分（能预测未来）、足够小（可以在它上面做规划）、且不需要显式的状态空间。

这条路线带来三个新问题，它们构成后面章节的主线：

  1. 学到的状态是否充分？ → 表征目标怎么选（wm-ch2-l1）、D1 怎么测。
  2. 动力学该是确定的还是随机的？ belief 本身是分布的，"我大概知道"必须能被表达 → 随机隐变量（wm-ch2-l2）。
  3. 状态里的不确定性怎么被规划用？ → aleatoric/epistemic 与悲观规划（wm-ch2-l3）。

4.3 D1 就是"这个近似够不够"的测试#

回到判别问句 D1：把观测历史做受控扰动（加噪、遮蔽早期帧、删掉冗余帧），看预测误差是否只在真正丢失信息时才恶化。这个测试的操作含义正是本节的两端：

  • 如果删掉冗余帧误差不变→ 状态确实做了压缩，且没丢掉未来需要的信息（好信号）；
  • 如果删掉仍含信息的帧误差不变→ 状态没在用它，说明压缩过度或训练目标没把该信息纳入（坏信号）；
  • 如果加噪就崩→ 状态在记忆噪声，说明压缩不足（坏信号）。

D1 的合格线由任务定：它衡量的不是"状态维度多大"，而是"给定用途下，这个压缩是否足够"。

代码#

这段代码要验证两件事：① 精确 belief 递推给出的策略严格优于任何无记忆策略；② "近似 belief"需要记忆，且记忆长度决定成功率。

对一个 K 段含噪线索的环境，我们计算三种策略的成功率：

  • 无记忆策略：终点观测是常数，只能固定选一边 → 理论上限 50%；
  • 长度 k 的历史窗口策略：用最近 k 个线索投票；
  • 精确 belief 策略：按后验 argmaxc​b(c) 决策。

读者要看的三个数字：无记忆那一行恒等于 0.5（无论 K、ε 怎么变）；窗口策略随 k 上升；belief 策略是上限。

⚠️ 本代码数据全部为合成数据，不代表任何真实数据集。

"""WM ch1-l2：感知别名下"观测当状态"的结构性次优（合成数据）。
环境：K 段含噪线索 + 一个完全无信息的终点观测（别名点）；终点必须选方向。
对照：无记忆策略 / 长度-k 历史窗口 / 精确 belief 策略。
只依赖 numpy。运行：/opt/homebrew/bin/python3.10 <file>
"""
import numpy as np

SEED = 0
rng = np.random.default_rng(SEED)
EPS = 0.25          # 线索翻转概率：控制"观测有多不可靠"
K = 5               # 线索个数：控制 belief 能累积到多准
N_EP = 40000        # 蒙特卡洛 episode 数（纯 numpy，快）

# ---------- 1. 精确 belief 递推 ----------
# 设计决策：先验均匀 → 对数似然比(llr) 可直接相加，避免数值下溢；
#           belief b(c=1) = sigmoid(llr)，这是 1.2 节递推的解析特例。
LOGR = np.log((1.0 - EPS) / EPS)

def belief_from_obs(obs):
    """obs: (N, k) 的 0/1 线索观测 → 返回 P(c=1 | obs)。"""
    llr = np.where(obs == 1, LOGR, -LOGR).sum(axis=1)
    return 1.0 / (1.0 + np.exp(-llr))

def majority_obs(obs):
    """长度-k 窗口策略：多数投票；平票时随机（用 0.5 概率选 1）。"""
    votes = obs.sum(axis=1)
    pred = (votes > obs.shape[1] / 2).astype(int)
    tie = votes * 2 == obs.shape[1]
    pred[tie] = (rng.random(tie.sum()) > 0.5).astype(int)
    return pred

# ---------- 2. 生成 episode ----------
c = rng.integers(0, 2, size=N_EP)                      # 真实线索方向
flip = rng.random((N_EP, K)) < EPS                     # 每次观测是否翻转
obs = np.where(flip, 1 - c[:, None], c[:, None])       # 含噪线索序列

print(f"[env] 合成走廊任务：K={K} 段含噪线索，翻转概率 eps={EPS}，episode={N_EP}，seed={SEED}")
print(f"[alias] 终点观测与线索无关（常数）→ 只看当前观测的智能体信息量为 0\n")

# ---------- 3. 三种策略 ----------
mem_pred = rng.integers(0, 2, size=N_EP)               # 无记忆：只能固定概率猜
acc_mem = float((mem_pred == c).mean())

print("[策略成功率 · 终点二选一]")
print(f"   无记忆策略（只看当前观测）        : {acc_mem:.4f}   ← 理论上限恒为 0.5")
for k in (1, 2, 3, 5):
    acc = float((majority_obs(obs[:, :k]) == c).mean())
    print(f"   历史窗口 k={k:<2d}（最近 {k} 段线索投票）   : {acc:.4f}")
acc_belief = float((belief_from_obs(obs) > 0.5).astype(int).__eq__(c).mean())
print(f"   精确 belief（用完全部 {K} 段线索）  : {acc_belief:.4f}   ← 上限")

# ---------- 4. 看一条 belief 轨迹：不确定性如何随证据收缩 ----------
ex = np.array([[1, 1, 0, 1, 1]])
print("\n[belief 递推示例] 观测序列 1,1,0,1,1（1 表示线索指向右）")
b = 0.5
for t, o in enumerate(ex[0], 1):
    lik = (1 - EPS) if o == 1 else EPS          # P(o=1|c=1)
    lik0 = EPS if o == 1 else (1 - EPS)         # P(o=1|c=0)
    b = lik * b / (lik * b + lik0 * (1 - b))    # 1.2 节的贝叶斯递推
    print(f"   t={t}: o={o} → b(c=1)={b:.4f}")
print("\n读法：这一列数字就是'状态'——它不是任何一个观测，而是观测历史的充分统计量。")
print("     无记忆策略看不到它，所以成功率被钉在 0.5；这不是模型容量问题，是函数形式问题。")

这段实验想让你看到的三件事：

  1. 无记忆策略的成功率恒为 0.5，且与 ε、K 无关。 这是"观测 ≠ 状态"最硬的证据：终点观测对所有 episode 都一样，任何 π(a∣o) 都只能固定选一边。加大模型、加多数据都不会改变这个上界。
  2. 窗口策略随 k 上升，但它的提升来自"累积证据"，不是"记住更多历史"本身。 每段线索都是独立的含噪证据，投票越多越准——这正是 belief 递推在做的事，只不过 belief 把它写成了一个递推的分布，而窗口只是在做近似。
  3. belief 轨迹把"不确定性是状态的一部分"显示出来了：同一条观测序列上，b 从 0.5 一路变到接近 0/1。如果世界模型只输出点预测，它就丢掉了"我现在有多确定"这个对规划至关重要的量（第 2 章第 3 节）。

⚠️ 这段实验的边界：它证明的是结构性次优（无记忆策略的可达性上界），不是"某个学习方法不好"。真实高维任务里，别名往往不是"终点观测相同"这么干净，而是"当前帧看起来一样但物理状态不同"（例如视觉上的静止物体与极慢运动物体）。此时 D1 的受控扰动测试就是把它找出来的工具。

另外注意输出里 k=2 那一行比 k=1 略低：偶数窗口会出现平票，代码把平票随机决断（0.5 概率），于是"多看了证据"被平票惩罚抵消。这不是 belief 的问题，而是"窗口 + 多数投票"这个近似器的缺陷——它恰好说明为什么正确的做法是维护一个分布（belief），而不是维护一串硬投票。第 2 章第 2 节的随机隐变量就是这一点的直接后果。

小结#

  • 状态存在的理论依据是 belief MDP：belief bt​(s)=P(st​=s∣ht​) 是历史的充分统计量，且以 belief 为状态的决策过程是 Markov 的，Bellman 方程只依赖 (b,a,o′)。这不是比喻，是可证明的等价。
  • 观测 ≠ 状态：一般地 bt​ 不能由 ot​ 恢复，所以"观测→动作"是对最优策略的结构性限制。在感知别名下，同一个观测对应相反的最优动作，任何无记忆策略必错，且次优性可以任意大。
  • 状态 = 对未来的最小充分统计量：因果状态（ε-machine）把它定义为"对未来的预测分布相同"的过去等价类；预测性状态表示（PSR）用"未来可观测量的预测"作为状态的坐标。锚点在"未来"，不在"过去"。
  • 压缩与可预测有真实张力：信息瓶颈 minI(Z;X)−βI(Z;Y) 的两端各有一个失败模式——压太狠导致可预测性上限被钉死；压太松导致状态记住一次性噪声、换条轨迹就崩。最优位置由任务的多步预测需求决定。
  • 控制需要的状态 ≠ 预测需要的状态 ≠ 重建需要的状态：奖励相关子空间、可预测自由度、全部观测信息，三者是嵌套但不等同的要求。重建目标保留最后一类，而它恰恰是决策用不到的——这是第 2 章第 1 节的伏笔。
  • 精确 belief 不可行（连续高维下无穷维、规划是 PSPACE 难），所以工程上只能学循环隐状态作为近似 belief；由此产生三个主线问题：状态够不够（D1）、随机性怎么表达（第 2 章第 2 节）、不确定性怎么用于决策（第 2 章第 3 节）。
