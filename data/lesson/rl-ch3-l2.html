策略迭代#

上一课我们只会"评价"一个给定的策略（算出 v_π），但评价不是终点——我们要的是找到最优策略。本课讲动态规划三兄弟中的老二：策略迭代（policy iteration）。它的思想朴素而优美：先把当前策略评个分（策略评估），再据分数把它改得更好一点（策略改进），如此交替，直到再也改不动。 本课重点讲两件事：策略改进那一步凭什么保证"越改越好"（策略改进定理的证明），以及这个"评估↔改进"的循环凭什么必然收敛到最优。

一、概念讲解#

1. 策略改进：对当前价值贪心#

假设我们已经有了当前策略 π 的精确价值 v_π。怎么改出一个不更差的策略？一个自然的选择：在每个状态 s，贪心地选那个"即时奖励 + 折扣后续价值"最大的动作：

π'(s) = argmax_a  Σ_{s', r} p(s', r | s, a) · [ r + γ · v_π(s') ]
        = argmax_a  q_π(s, a)

注意这里 v_π 是旧策略 π 的价值，但贪心选择的动作却构成了新策略 π'。这一步叫策略改进（policy improvement）。它是严格贪心的：在每个状态都选当前看起来最好的动作。

2. 策略改进定理：贪心一步，全局不降#

这一步改进到底有没有效果？策略改进定理（policy improvement theorem） 给出保证：

若 π' 是上面这样由 π 贪心改进得到，则对所有 s，有 v_{π'}(s) ≥ v_π(s)；且若存在某个状态严格变好，则 π' 严格优于 π。

下面是它的证明（核心只有一步展开）：

第一步：因为 π' 在每个状态都选了 q_π(s, ·) 最大的动作，而 π 是"把概率分散在若干动作上"，所以对任意 s：

q_π(s, π'(s)) ≥ q_π(s, π(s)) = v_π(s)

（v_π(s) = Σ_a π(a|s) q_π(s,a) 是 q 的加权平均，加权平均不可能超过最大项 q_π(s, π'(s))。）

第二步：把 v_π(s) 展开，反复用"贪心 ≥ 旧策略"这条不等式一路往下推：

v_π(s) ≤ q_π(s, π'(s))
      = E[ R_{t+1} + γ v_π(S_{t+1}) | S_t=s, A_t=π'(s) ]
      ≤ E[ R_{t+1} + γ q_π(S_{t+1}, π'(S_{t+1})) | S_t=s, A_t=π'(s) ]
      ≤ E[ R_{t+1} + γ ( R_{t+2} + γ q_π(S_{t+2}, π'(S_{t+2})) ) | … ]
      ≤ …  （继续展开到无穷）
      = v_{π'}(s)

每一行"≤"都用到了同一个理由：在新策略 π' 的控制下，v_π(s) ≤ q_π(s, π'(s)) 这条不等式在每个到达的状态上都成立。一直展开下去，左边就变成了在 π' 下全程按旧 π 评价的期望回报，而右边收敛到 v_{π'}(s)——在新策略 π' 下按新策略评价的回报。 于是 v_π(s) ≤ v_{π'}(s) 得证。

一句话概括证明的精髓："贪心改进后的策略，在旧策略眼里就已经不差；而把这种'不差'沿整条未来轨迹传递下去，就推出它在自己眼里更不差。"

3. 策略迭代算法：评估 ↔ 改进交替#

把两件事拼起来，就得到策略迭代：

1. 初始化：任意策略 π_0（比如全均匀随机），任意价值 v
2. 策略评估：迭代算出 v_{π_k}（精确或近似）
3. 策略改进：对 v_{π_k} 贪心，得到 π_{k+1}
4. 若 π_{k+1} = π_k，停止；否则 k ← k+1，回到 2

每一次"评估 + 改进"，策略都严格变好（除非已最优）。停止条件"π 不再变化"意味着：改进步骤再也找不到更优动作，即对所有 s，π(s) = argmax_a q_π(s,a)——此时 π 满足贝尔曼最优方程，因而就是最优策略。

4. 为什么必然收敛：有限个策略 + 单调改进#

策略迭代一定在有限步内收敛到最优策略，理由直白而有力：

  • 策略空间有限：有限 MDP 里确定性策略只有 |A|^|S| 个（有限）；
  • 每步严格改进：只要 π 还不是最优，改进定理保证 v_{π_{k+1}} ≥ v_{π_k}，且至少一个状态严格变大；
  • 不能无限循环：一个严格递增（偏序意义下）且取值只能落在有限集合里的序列，必然在有限步停下。

停下的那一刻，π 已无法改进，必为最优。这比"价值迭代的压缩收敛"要简单——它甚至不依赖 γ < 1，只依赖"策略有限 + 每步单调不降"。策略迭代的收敛是"组合的"（有限搜索），而价值迭代的收敛是"分析的"（压缩映射），这是理解两者区别的一个好角度。

5. 策略评估要做到多精确：不必太精确#

一个实践要点：策略迭代里"评估"这一步并不需要收敛到 v_π 的小数点后十位。只要评估得"大致对"，贪心改进通常依然指向正确的方向。第 4 课的价值迭代，本质就是"只做一轮评估就立刻改进"的极端情形；而更广义的广义策略迭代（Generalized Policy Iteration, GPI） 认为，评估与改进可以在任意粒度、任意顺序交错进行。"评估让价值追着策略走，改进让策略追着价值走"，两者互相拉扯、最终一起收敛到最优——这是所有强化学习算法的共同骨架。

二、可运行代码示例#

在同一个 4×4 网格世界上跑完整的策略迭代：从等概率随机策略出发，交替做"评估 + 贪心改进"，直到策略稳定，并打印最优价值与最优策略。

import numpy as np

N = 4
nS, nA = N * N, 4
GAMMA = 1.0
TERMINAL = {0, 15}
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]
ARROWS = ["↑", "↓", "←", "→"]     # 对应上、下、左、右

def step(s, a):
    r, c = divmod(s, N)
    dr, dc = ACTIONS[a]
    nr, nc = r + dr, c + dc
    ns = (nr * N + nc) if (0 <= nr < N and 0 <= nc < N) else s
    return ns, -1.0

def q_of(s, a, v):
    """动作价值 q(s,a) = r + γ v(s')（确定性转移）。"""
    ns, r = step(s, a)
    return r + GAMMA * v[ns]

def policy_evaluation(pi, theta=1e-4):
    """就地更新的策略评估。"""
    v = np.zeros(nS)
    while True:
        delta = 0.0
        for s in range(nS):
            if s in TERMINAL:
                continue
            old = v[s]
            v[s] = sum(pi[s, a] * q_of(s, a, v) for a in range(nA))
            delta = max(delta, abs(old - v[s]))
        if delta < theta:
            break
    return v

def greedy_improvement(v):
    """对 v 贪心，返回 (新确定性策略, 是否已稳定)。"""
    pi_new = np.zeros((nS, nA))
    stable = True
    for s in range(nS):
        if s in TERMINAL:
            continue
        best_a = max(range(nA), key=lambda a: q_of(s, a, v))
        pi_new[s, best_a] = 1.0
    return pi_new

# ---- 策略迭代主循环 ----
pi = np.full((nS, nA), 0.25)          # 初始：等概率随机策略
for it in range(50):
    v = policy_evaluation(pi)         # ① 评估
    pi_new = greedy_improvement(v)    # ② 改进
    if np.array_equal(pi, pi_new):    # ③ 检查是否稳定
        print(f"策略迭代在第 {it} 轮收敛")
        break
    pi = pi_new

def print_policy(pi):
    for s in range(nS):
        if s in TERMINAL:
            print("  G".ljust(6), end="")   # G = 目标/终止
        else:
            a = int(np.argmax(pi[s]))
            print(f"  {ARROWS[a]}".ljust(6), end="")
        if s % N == N - 1:
            print()

print("\n最优价值 v_*：")
for row in v.reshape(N, N):
    print("  " + " ".join(f"{x:6.2f}" for x in row))
print("\n最优策略 π_*（箭头=该格的最优动作，G=终止状态）：")
print_policy(pi)

运行结果大致是：

策略迭代在第 2 轮收敛

最优价值 v_*：
    0.00   -1.00   -2.00   -3.00
   -1.00   -2.00   -3.00   -2.00
   -2.00   -3.00   -2.00   -1.00
   -3.00   -2.00   -1.00    0.00

最优策略 π_*：
  G      ←      ←      ↓
  ↑      ↑      ↑      ↓
  ↑      ↑      ↓      ↓
  ↑      ↑      →      G

读这张表：最优价值 v_*(s) 恰好等于"到最近终止状态的负最短距离"（如 (0,1) 到左上角需 1 步，价值 −1）；最优策略则是一条条"径直走向最近出口"的箭头。整个策略迭代只用了 2 轮评估+改进就收敛——印证了"策略空间有限、每步严格改进"的快速收敛。注意策略的箭头并非唯一（某些格子离两个出口等距，朝任一方向都可），但价值函数是唯一的。

三、练习#

  1. 把终止状态改成只有 {0}（去掉右下角出口），重跑策略迭代。最优价值和策略如何变化？说说为什么只剩一个出口时，价值函数不再对称。
  2. 把初始策略改成"全部选 →（右）"（pi[s, 3]=1），观察策略迭代需要几轮收敛，与从随机策略出发的 2 轮对比，说明初始策略如何影响收敛速度。
  3. 手推策略改进定理的第一步：为什么 q_π(s, π'(s)) ≥ q_π(s, π(s))？用"加权平均不超过最大项"解释。
  4. 思考：策略迭代的收敛不依赖 γ < 1，而价值迭代的收敛依赖压缩映射（γ < 1）。请各用一句话说明这两种收敛论证的本质区别。
