规划收益评测：把世界模型放进决策回路，测回报、后悔与样本效率#

这一节要解决什么#

前两节测的都是模型本身：预测得多准（第 1 节）、能维持多久（第 2 节）。但世界模型的存在理由是第三件事：

它能让你做出更好的决策吗？

第 4 章第 4 节已经给过一次答案的形状——"该不该用模型"是一笔可算的账（Cest​/N+ϵmodel​+ϵopt​）。这一节要把那笔账变成一套评测协议：怎么定义"规划收益"、相对什么基线报、怎么度量样本效率、以及最重要的——怎么避免"用模型自评当结果"这种自欺。

后者的危险在于它处处成立且毫不显眼：你在模型里规划，用模型算出的回报挑方案，然后报告"模型内回报 0.47"。这个数不是任何真实世界里的量。第 2 节已经量过它的一个版本（开环更准、闭环更差）；这一节要把它变成一个可测的差：

自评间隙 = V^模型​(π)− V真环境​(π).

这一节的交付是五样东西：

  1. 规划收益的完整定义：基线阶梯 + 收益 + 后悔 + 约束违反，四项缺一不可；
  2. 样本效率的读法：logN 轴上的曲线下面积（AUC），不是"最大 N 的终点分数"；
  3. 自评间隙的量化：本课实测"不挑选"与"挑最好的"两个口径差多少，以及它随选择预算 K 的变化；
  4. optimizer's curse 的形式化：为什么"多试几个就会更好看"是数学必然；
  5. 一条可执行协议：真环境复核、评估分布加权、预算绑定。

一、先把"规划收益"定义清楚#

1.1 基线阶梯#

"规划收益"是一个差值，所以它必须相对于某个基线。工程上常见做法是"和一个随机策略比"——这几乎没有信息量。正确的做法是报一整条阶梯，每一级都排除掉一类解释：

基线 回答"如果不用模型会怎样" 排除的解释
随机策略 任务本身是否可解 任务难度
行为策略（数据采集策略） 只用数据、不做任何优化会怎样 "收益"是否只是数据分布的均值
无模型（同样本量的 model-free） 把同样的样本花在别处会怎样 收益是否来自模型，而不是来自搜索/规划
模型 + 规划（同预算） 被测对象 ——
oracle 规划（真模型） 上界 距上界还有多少

第三行是最容易被漏掉的一行。 世界模型的收益常常与"搜索"的收益混在一起：只要你在候选动作上做 argmax，回报就会比行为策略高，与模型好不好无关。只有把"同样本量的 model-free"放进阶梯，才能说清收益来自模型还是来自搜索。

1.2 收益、后悔与约束#

设被测策略为 πp^​​=plan(p^​)，真实值为 Vπ：

gain收益​​=Vπp^​​−Vπbase​,regret后悔​​=V⋆−Vπp^​​,violation约束违反​​=Pr(安全约束被破).

gain收益​​=Vπp^​​−Vπbase​,regret后悔​​=V⋆−Vπp^​​,violation约束违反​​=Pr(安全约束被破).

三项都要报，因为它们的排序可以不同：一个模型可以在均值上收益最大而在尾部上最差（第 4 节会用本课的实测说明这一点）。

1.3 三个必须绑定的量#

报"收益 +0.26"这句话是不完整的，缺了三个坐标：

收益 ​ 基线阶梯 ​ 预算 (样本/规划/算力) ​ 分布 (起点 + 评估分布).

第 4 节专门讲预算与分布。这里先记住：任何收益数字离开这三个坐标都不可比。

二、样本效率：读曲线，不读终点#

2.1 为什么是 AUC#

样本效率的定义就是"在给定样本预算下的性能"。所以它的自然表示是一条曲线 V(N)，而不是一个数。工程上常见的那种"用 1M 步训练，报最终回报"的做法，恰恰丢掉了这个信息。

推荐读出量：

AUClog​=∫logNmin​logNmax​​V(N)d(logN) ≈ i∑​2V(Ni+1​)+V(Ni​)​ΔlogN.

在 logN 轴上取积分意味着每个数量级等权——这正是"样本效率"想要的口径。若在 N 轴上积分，N=800 那一段会压掉 N=20 那一段的全部信息。

2.2 本课实测：真有交叉#

表格来自一个 5×5 的表格 MDP（12% 打滑、γ=0.95、目标与陷阱各一个）。行为策略是 ε=0.25 的专家数据，两个方法共用同一批数据（配对），每个点 8 个种子平均：

样本量 N Q-learning（无模型） 模型 + 规划
20 −0.4000 +0.1643
50 −0.4005 +0.3240
100 −0.4000 +0.4376
200 −0.3571 +0.4659
400 +0.4663 +0.4379
800 +0.4949 +0.3495

参考线：随机策略 −0.5443，行为策略 +0.2021，oracle +0.5044。

三个读数：

  1. 交叉存在，位置在 N≈400 附近。 N≤200 时"模型 + 规划"大幅领先（N=50 时 +0.3240 vs −0.4005）；N≥400 后 Q-learning 反超。这正是第 4 章第 4 节那个交叉条件 ϵmodel​L 的实测版本："模型样本效率高"只在窗口内成立。
  2. AUC 把结论压缩成一个数：Q-learning −0.5356，模型 + 规划 +1.3869。若只看 N=800 那一列，结论会反过来——这正是"只报终点"最危险的地方。
  3. 模型 + 规划在 N=800 时反而下降（0.4659→0.4379→0.3495）。这看起来反直觉，但它与第 4 章第 4 节"精度越高越会外推"是同一现象：数据越集中在专家路径上，模型在未覆盖状态上的默认外推影响越大，规划器越容易在那些格子上做错决定。"训练集精度上升、闭环下降"不是 bug，是机制。

2.3 交叉点周边的三条纪律#

① 至少 5 个数量级跨度的 N（本课 20 -> 800）
② 每个 N 至少 5 个种子，报均值 + 方差（不是单点）
③ 报 AUC 与交叉点，并说明交叉点如何随 ε_model 变化（第 4 章第 4 节的判据）

三、避免"用模型自评"的自欺#

3.1 间隙的定义与两个口径#

同一批模型、同一个被选中的策略，用两套评估：

V^模型​(π)vsV真环境​(π),间隙=V^模型​−V真环境​.

关键是：这个间隙不是一个模型的固有属性，它依赖"你怎么用模型"。本课把它分成两个口径：

  • 口径 A（不挑选，K=1）：训练一个模型、规划一个策略、报间隙。
  • 口径 B（挑最好的，K>1）：跑 K 次独立实验，选模型内自评最高的那一个，报它。

3.2 optimizer's curse：为什么"挑"本身就是乐观偏差#

命题（选择偏差）. 设 K 个模型各自的间隙估计是 gk​=μ+εk​，εk​ i.i.d.、Eεk​=0、Var=σ2。选择 k^=argmaxk​gk​，则

E[gk^​] ≥ μ+σ2lnK​(1−o(1))(K→∞).

证明草图. 由高斯尾界 Pr(maxk​εk​<t)≈(1−Φ(t/σ))K，令其等于常数解出 t⋆≈σ2lnK​。□

这不是"模型变好了"，而是最大值统计量的期望随 K 增长。它在评测里对应一串非常常见的做法：多试几个种子、多看几个 checkpoint、多换几个超参、多跑几遍评估——只要你在评测数据上挑，报告的数就不再是任何配置的真实水平。

3.3 本课实测：间隙随 K 从负翻正#

实验二在 N∈{60,120,250} 上各跑 5 次重复、每次 32 个独立模型（各自一份数据、各自一个策略），记录 (模型内自评, 真环境精确值)：

数据量 N 口径 K=1 K=2 K=4 K=8 K=16 K=32
60 选中自评最高 −0.122 −0.094 −0.106 −0.070 +0.162 +0.182
60 前 K 个平均 −0.122 −0.147 −0.213 −0.222 −0.192 −0.184
120 选中自评最高 −0.213 −0.196 −0.157 −0.044 +0.058 +0.434
120 前 K 个平均 −0.213 −0.234 −0.227 −0.173 −0.188 −0.163
250 选中自评最高 −0.164 −0.097 −0.063 −0.014 +0.043 +0.167
250 前 K 个平均 −0.164 −0.143 −0.100 −0.112 −0.127 −0.146

两个结论同时成立，缺一不可：

  1. 平均间隙是负的（N=120 时稳定在 −0.16∼−0.23）。本课的模型用了保守默认外推（未见的 (s,a) 原地不动），所以它系统性低估自己。这说明"自评间隙"的符号由模型的偏差方向决定，不是一个固定常数。
  2. 选中间隙随 K 单调翻正并变大（N=120：−0.213→+0.434）。这正是 3.2 节的命题：挑选把 2lnK​ 那一项加进来。K=1 与 K=32 的差是 +0.65 —— 在你没有做任何模型改进的情况下。

⚠️ 这个结果的正确读法是：不要用"模型自评最高"来挑模型。如果你一定要挑（工程上不可避免），必须把 K 写进报告，并且用真环境的独立评估来做最终确认。

3.4 三条纪律#

① 最终结论必须来自真环境评估；模型自评只能用于筛查（便宜的那一层）
② 报告里必须写清选择预算 K（试了几个种子/checkpoint/超参）
③ 区分两个量：模型偏差（bias，K=1 就有）与选择偏差（K 带来的）；分开报

四、误差要测在策略诱导分布上#

第 2 节在连续控制任务上量过一次；这一节在表格 MDP 上再量一次，并给出一个更锋利的版本——模型在"数据分布"与"策略诱导分布"上的误差可以差一个量级。

实验三：用 N=200 条数据学一个模型（轻度乐观外推），在模型里规划出策略 π，然后在真环境里跑 π 收集 200 步的 (s,a) 访问分布，分别在两个分布上算转移全变差距离的加权平均：

量 数值
数据分布加权的模型误差（转移全变差） 0.1269
策略诱导分布加权的模型误差 0.8265（6.5 倍）
策略访问的 (s,a) 中零样本的比例 93.0%
该策略在真环境里的精确值 −0.3936（oracle =0.5044）

模型在数据分布上看着不差（0.1269），但在策略会去的地方几乎没有约束（0.8265）；93% 的访问落在数据里从未出现的 (s,a) 上。决定闭环收益的是后者。

这条实测把"评估集加权"从一句口号变成一条可执行规则：

报误差时必须写清 E(s,a)∼D​[err(s,a)] 里的 D 是什么;

D=Ddata​ 与 D=Dπ​ 是两个不同的数。建议两个都报，并报它们的比值——比值就是"规划器把模型带到多陌生地方"的度量（与第 2 节实验二的 gap 是同一个量）。

五、一份可执行的规划收益评测协议#

【定义】
  任务族 + 回报 R + 起点分布（全部在评测前写死，写进预注册）
  规划器族 + 预算（视界 H、采样数 K、迭代数）——被测对象与基线必须同预算
【基线阶梯】
  random / behavior / model-free(同样本量) / model+plan / oracle(真模型)
【数据】
  每个 N ∈ {5 个数量级跨度} × ≥5 个训练种子（配对：同一批数据给所有方法）
【指标】
  ① 收益与后悔（相对阶梯的每一级）
  ② 样本效率：log-N 轴 AUC + 交叉点
  ③ 约束违反率 / CVaR(α)（尾部）
  ④ 自评间隙：K=1 与 K=选择预算两口径，且最终值来自真环境
  ⑤ 评估分布：数据加权误差 + 策略诱导加权误差 + 零样本访问比例
【报告】
  数字必须带四个坐标：基线、预算、起点分布、评估分布
【禁止】
  ✗ 用模型自评当最终结果
  ✗ 只报最大 N 的终点分数
  ✗ 与被测对象不同预算的基线比较
  ✗ 不写选择预算 K

六、取舍与边界#

选择 好处 代价 / 边界
报 AUC（log-N） 一个数概括样本效率 对 N 的取点敏感；跨任务不可直接平均
报交叉点 直接回答"该不该用模型" 需要足够密的 N 网格；交叉点本身有方差
相对 oracle 的后悔 有绝对标尺 oracle 常常不存在（真模型不可得）
相对行为策略的收益 一定有 低估收益，因为行为策略通常不弱
真环境评估 唯一可信的最终口径 贵；有安全风险；必须与训练隔离
模型自评 便宜、可大批量 有系统性选择偏差（本课实测 +0.65）
策略诱导分布加权 与闭环相关 需要先有一个策略；分布本身随训练变化

三条必须写进报告的边界：

  1. "规划收益"是相对量。 换基线、换预算、换起点分布，数字就换。任何跨论文比较都必须先对齐这三个坐标。
  2. AUC 与交叉点都受任务难度影响。 在"随机策略也能解"的简单任务上，AUC 的差异会被压缩到看不出（本课的随机策略评分 −0.5443 说明任务不算简单，但这只是本课的选择）。
  3. 自评间隙的符号不是固定的。 本课是"平均为负、挑选后翻正"。换一个乐观外推的模型类，K=1 就可能是正的。报告间隙时要同时报它的两个分量（模型偏差 + 选择偏差），否则读者无法解释符号。

代码#

下面的代码把整节实验放在一个可精确求值的表格 MDP 上：策略值用线性方程解出（不是蒙特卡洛），所以"模型自评"与"真环境评估"的差值可以被干净地量出来——这是本节最重要的一处设计决策。

  • 实验一：基线阶梯 + logN 曲线 + AUC（两方法共用同一批数据，配对）；
  • 实验二：自评间隙随选择预算 K 的变化（K=1 为负 → K=32 翻正）；
  • 实验三：数据分布加权 vs 策略诱导分布加权的模型误差。

⚠️ 数据全部为本代码合成，不代表任何真实数据集。

"""WM ch6-l3 演示：规划收益怎么测 —— 基线阶梯、样本效率、自评间隙、评估分布
全部在一个可精确求值的表格 MDP 上做：策略值用线性方程解出（不是蒙特卡洛），
所以"模型自评"与"真环境评估"的差值可以被干净地量出来。
实验一：基线阶梯 + 样本效率（同样本量、同一批数据下 model+planning vs model-free）
实验二：模型自评间隙 —— K=1（不挑选）为负，随"挑最好的那一个"的预算 K 翻正并增大
实验三：误差要按**策略诱导分布**加权（数据加权 TV=0.13，策略加权 TV=0.85）
环境与数据全部为合成数据（⚠️ 不代表任何真实数据集），只用 Python 标准库。
运行：/opt/homebrew/bin/python3.10 <file>   环境：python 3.10.16
"""
import math
import random

# ==================== 0. 真实 MDP（可精确求值） ====================
W = H = 5
NS = W * H
GOAL, PIT = (4, 4), (2, 2)
SLIP, GAMMA = 0.12, 0.95
R_STEP, R_GOAL, R_PIT = -0.02, 1.0, -1.0
MOVES = [(-1, 0), (1, 0), (0, -1), (0, 1)]
NA = 4
S0 = 0

def idx(r, c):
    return r * W + c

def build_mdp():
    """P[s][a] = [(s', p), ...]；R[s][a] 含进入目标/陷阱那一步的一次性回报。
    目标/陷阱是吸收态且此后回报为 0（否则"在目标里刷分"会让价值发散，
    掩盖本节要量的规划收益差异）。"""
    P = [[[] for _ in range(NA)] for _ in range(NS)]
    R = [[0.0] * NA for _ in range(NS)]
    for r in range(H):
        for c in range(W):
            s = idx(r, c)
            if (r, c) in (GOAL, PIT):
                for a in range(NA):
                    P[s][a] = [(s, 1.0)]
                continue
            for a in range(NA):
                agg = {}
                for b, pr in ((a, 1 - SLIP), (a ^ 1, SLIP / 2), ((a + 2) % 4, SLIP / 2)):
                    dr, dc = MOVES[b]
                    s2 = idx(min(max(r + dr, 0), H - 1), min(max(c + dc, 0), W - 1))
                    agg[s2] = agg.get(s2, 0.0) + pr
                P[s][a] = list(agg.items())
                R[s][a] = R_STEP + sum(pr * (R_GOAL if s2 == idx(*GOAL)
                                             else R_PIT if s2 == idx(*PIT) else 0.0)
                                       for s2, pr in P[s][a])
    return P, R

P_TRUE, R_TRUE = build_mdp()

def solve(A, b):
    """高斯消元（列主元）；A 为 n x n 的行列表。"""
    n = len(A)
    M = [list(row) + [b[i]] for i, row in enumerate(A)]
    for col in range(n):
        p = max(range(col, n), key=lambda r: abs(M[r][col]))
        M[col], M[p] = M[p], M[col]
        pv = M[col][col]
        for j in range(col, n + 1):
            M[col][j] /= pv
        for r in range(n):
            if r != col and M[r][col] != 0.0:
                f = M[r][col]
                for j in range(col, n + 1):
                    M[r][j] -= f * M[col][j]
    return [M[i][n] for i in range(n)]

def policy_value(P, R, pi, gamma=GAMMA):
    """确定性策略的精确值：解 (I - gamma P^pi) V = R^pi。"""
    A = [[0.0] * NS for _ in range(NS)]
    b = [0.0] * NS
    for s in range(NS):
        a = pi[s]
        A[s][s] += 1.0
        b[s] = R[s][a]
        for s2, pr in P[s][a]:
            A[s][s2] -= gamma * pr
    return solve(A, b)

def stochastic_value(P, R, probs, gamma=GAMMA):
    """随机策略 probs[s][a] 的精确值。"""
    A = [[0.0] * NS for _ in range(NS)]
    b = [0.0] * NS
    for s in range(NS):
        A[s][s] += 1.0
        for a in range(NA):
            pa = probs[s][a]
            if pa == 0.0:
                continue
            b[s] += pa * R[s][a]
            for s2, pr in P[s][a]:
                A[s][s2] -= gamma * pa * pr
    return solve(A, b)

def value_iteration(P, R, gamma=GAMMA, iters=400):
    V = [0.0] * NS
    for _ in range(iters):
        nv, d = [0.0] * NS, 0.0
        for s in range(NS):
            nv[s] = max(R[s][a] + gamma * sum(pr * V[s2] for s2, pr in P[s][a])
                        for a in range(NA))
            d = max(d, abs(nv[s] - V[s]))
        V = nv
        if d < 1e-12:
            break
    Q = [[R[s][a] + gamma * sum(pr * V[s2] for s2, pr in P[s][a]) for a in range(NA)]
         for s in range(NS)]
    return V, Q

V_STAR, Q_STAR = value_iteration(P_TRUE, R_TRUE)
PI_STAR = [max(range(NA), key=lambda a: Q_STAR[s][a]) for s in range(NS)]
V_ORACLE = policy_value(P_TRUE, R_TRUE, PI_STAR)[S0]
EPS_BEH = 0.25
BEH = [[(1 - EPS_BEH) if a == PI_STAR[s] else EPS_BEH / (NA - 1) for a in range(NA)]
       for s in range(NS)]
V_BEHAVIOR = stochastic_value(P_TRUE, R_TRUE, BEH)[S0]
UNIF = [[1.0 / NA] * NA for _ in range(NS)]
V_RANDOM = stochastic_value(P_TRUE, R_TRUE, UNIF)[S0]

# ==================== 1. 数据、模型、基线 ====================
def greedy_policy(Q):
    return [max(range(NA), key=lambda a: Q[s][a]) for s in range(NS)]

def sample_data(N, rng):
    """行为策略：eps-greedy w.r.t. Q_STAR（有噪声的专家数据）；到目标/陷阱后回起点。"""
    s, data = S0, []
    for _ in range(N):
        a = rng.randrange(NA) if rng.random() < EPS_BEH else PI_STAR[s]
        outs = P_TRUE[s][a]
        x, acc, s2 = rng.random(), 0.0, outs[-1][0]
        for ss, pr in outs:
            acc += pr
            if x <= acc:
                s2 = ss
                break
        data.append((s, a, R_TRUE[s][a], s2))
        s = S0 if s2 in (idx(*GOAL), idx(*PIT)) else s2
    return data

def learn_model(data, prior_self=0.5):
    """计数式模型 + **保守默认外推**：先验只加在"自环"上，绝不凭均匀先验跳到别处。
    设计决策：默认外推决定纯模型规划的成败（第 4 章第 4 节）；给它均匀先验会让
    规划器以为"没见过的动作有 1/25 概率直达目标"。"""
    cnt = [[{} for _ in range(NA)] for _ in range(NS)]
    rsum = [[0.0] * NA for _ in range(NS)]
    rn = [[0] * NA for _ in range(NS)]
    for s, a, r, s2 in data:
        cnt[s][a][s2] = cnt[s][a].get(s2, 0) + 1
        rsum[s][a] += r
        rn[s][a] += 1
    Ph = [[[] for _ in range(NA)] for _ in range(NS)]
    Rh = [[0.0] * NA for _ in range(NS)]
    for s in range(NS):
        for a in range(NA):
            if not cnt[s][a]:
                Ph[s][a] = [(s, 1.0)]
                Rh[s][a] = R_STEP
                continue
            agg = dict(cnt[s][a])
            agg[s] = agg.get(s, 0) + prior_self
            T = sum(agg.values())
            Ph[s][a] = [(s2, c / T) for s2, c in agg.items()]
            Rh[s][a] = (rsum[s][a] + prior_self * R_STEP) / (rn[s][a] + prior_self)
    return Ph, Rh

def q_learning(data, alpha=0.25, gamma=GAMMA):
    Q = [[0.0] * NA for _ in range(NS)]
    for s, a, r, s2 in data:
        Q[s][a] += alpha * (r + gamma * max(Q[s2]) - Q[s][a])
    return Q

def auc(xs, ys):
    """曲线下面积（x 取 log 刻度 -> 各量级等权）。"""
    lx = [math.log(x) for x in xs]
    return sum((lx[i + 1] - lx[i]) * (ys[i] + ys[i + 1]) / 2 for i in range(len(xs) - 1))

NS_LIST = [20, 50, 100, 200, 400, 800]
N_SEED = 8

def exp1():
    keys = ("qlearn", "model+plan")
    acc = {k: [[] for _ in NS_LIST] for k in keys}
    for seed in range(N_SEED):
        rng = random.Random(100 + seed)
        for i, N in enumerate(NS_LIST):
            data = sample_data(N, rng)                       # 两方法共用同一批数据（配对）
            Ph, Rh = learn_model(data)
            _, Qh = value_iteration(Ph, Rh)
            acc["model+plan"][i].append(policy_value(P_TRUE, R_TRUE, greedy_policy(Qh))[S0])
            acc["qlearn"][i].append(policy_value(P_TRUE, R_TRUE, greedy_policy(q_learning(data)))[S0])
    return {k: [sum(v) / len(v) for v in acc[k]] for k in keys}

# ==================== 实验二：自评间隙与"挑最好的" ====================
# 对每个 N：跑 KMAX 次**独立**实验（各自一份数据、各自一个模型、各自一个规划出的策略），
# 每次都记录 (模型自评, 真环境精确值)。然后看两件事：
#   · K=1（不挑选）的间隙 —— 模型本身的偏差方向；
#   · K 增大时"选中自评最高那一个"的间隙 —— 选择压力把偏差推向乐观。
KS = (1, 2, 4, 8, 16, 32)

def exp2(N, seed, KMAX=32):
    rng = random.Random(seed)
    cands = []
    for _ in range(KMAX):
        data = sample_data(N, rng)
        Ph, Rh = learn_model(data)
        _, Qh = value_iteration(Ph, Rh)
        pi = greedy_policy(Qh)
        cands.append((policy_value(Ph, Rh, pi)[S0], policy_value(P_TRUE, R_TRUE, pi)[S0]))
    sel = {K: max(cands[:K], key=lambda t: t[0]) for K in KS}
    return ({K: sel[K][0] - sel[K][1] for K in KS},
            {K: sum(c[0] - c[1] for c in cands[:K]) / K for K in KS})

# ==================== 实验三：误差要按策略诱导分布加权 ====================
def learn_leak(data, eps):
    """轻度乐观外推（把 eps 质量摊到所有状态）——用来暴露"数据没覆盖"的代价。"""
    cnt = [[{} for _ in range(NA)] for _ in range(NS)]
    rsum = [[0.0] * NA for _ in range(NS)]
    rn = [[0] * NA for _ in range(NS)]
    for s, a, r, s2 in data:
        cnt[s][a][s2] = cnt[s][a].get(s2, 0) + 1
        rsum[s][a] += r
        rn[s][a] += 1
    Ph = [[[] for _ in range(NA)] for _ in range(NS)]
    Rh = [[0.0] * NA for _ in range(NS)]
    for s in range(NS):
        for a in range(NA):
            agg = {s2: eps / NS for s2 in range(NS)}
            tot = sum(cnt[s][a].values())
            for s2, c in cnt[s][a].items():
                agg[s2] += (1 - eps) * c / max(tot, 1)
            T = sum(agg.values())
            Ph[s][a] = [(s2, c / T) for s2, c in agg.items()]
            Rh[s][a] = (rsum[s][a] + 0.5 * R_STEP) / (rn[s][a] + 0.5)
    return Ph, Rh

def tv(Ph, s, a):
    """两个转移分布的全变差距离。"""
    q, pt = dict(Ph[s][a]), dict(P_TRUE[s][a])
    return 0.5 * sum(abs(q.get(k, 0.0) - pt.get(k, 0.0)) for k in set(q) | set(pt))

def exp3(N=200, seed=7, steps=200):
    rng = random.Random(seed)
    data = sample_data(N, rng)
    Ph, Rh = learn_leak(data, 0.06)
    _, Qh = value_iteration(Ph, Rh)
    pi = greedy_policy(Qh)
    cnt = {(s, a): 0 for s in range(NS) for a in range(NA)}
    for s, a, _, _ in data:
        cnt[(s, a)] += 1
    visits = {(s, a): 0 for s in range(NS) for a in range(NA)}
    s = S0
    for _ in range(steps):
        visits[(s, pi[s])] += 1
        outs = P_TRUE[s][pi[s]]
        x, acc, s2 = rng.random(), 0.0, outs[-1][0]
        for ss, pr in outs:
            acc += pr
            if x <= acc:
                s2 = ss
                break
        s = S0 if s2 in (idx(*GOAL), idx(*PIT)) else s2
    tot_c, tot_v = sum(cnt.values()), sum(visits.values())
    dw = sum(tv(Ph, s, a) * cnt[(s, a)] for s in range(NS) for a in range(NA)) / tot_c
    pw = sum(tv(Ph, s, a) * visits[(s, a)] for s in range(NS) for a in range(NA)) / tot_v
    un = sum(visits[(s, a)] for s in range(NS) for a in range(NA)
             if cnt[(s, a)] == 0) / tot_v
    return dw, pw, un, policy_value(P_TRUE, R_TRUE, pi)[S0]

这段代码想让你看到的四件事：

  1. "规划收益"是相对量，而且基线阶梯里最关键的一级是 model-free。 实验一：N=50 时"模型 + 规划"+0.3240 而 Q-learning −0.4005；N=800 时反过来（+0.3495 vs +0.4949）。交叉点存在，"样本效率高"只在窗口内成立。
  2. 只报终点分数会给出错误的总结论。 AUC 是 −0.5356 vs +1.3869（模型 + 规划领先），而 N=800 那一列说 Q-learning 更好。两种读法都对，但回答的是两个不同的问题——"平均每个样本预算下谁更好" vs "预算充足时谁更好"。
  3. 自评间隙的符号由"你怎么用模型"决定。 K=1（不挑选）时三个 N 的间隙都是负的（保守模型低估自己，N=120 时 −0.213）；K=32 时全部翻正（+0.182/+0.434/+0.167）。挑最好的那一个，等于给报告加了一个 O(lnK​) 的乐观偏置。
  4. 模型的误差分布极不均匀。 数据分布加权 0.1269、策略诱导分布加权 0.8265（6.5 倍），且策略有 93.0% 的访问落在零样本 (s,a) 上。"平均预测误差"这个数对闭环几乎没有预测力——它平均错了地方。

⚠️ 诚实说明这个实验的边界：环境是5×5 表格 MDP，所以可以用线性方程精确求策略值，把"模型偏差"与"选择偏差"干净地分开——这是本课最大的优点，也是它最大的局限：真实任务的状态连续、策略用函数逼近、奖励可能学出来，V^ 与 V 的量级与结构都会不同。 模型是计数式 + 保守默认外推，规划器是模型上的精确值迭代，因此"规划收益"里不含搜索误差（真机上搜索误差是收益的另一个来源）。它证明的是四条结构性事实（交叉存在、AUC 与终点分数可以给出不同结论、选择偏差随 K 增长、误差集中在策略诱导分布上），而不是任何具体系统的水平。

小结#

  • "规划收益"是相对量，必须相对一整条基线阶梯报告：随机 / 行为策略 / 同样本量的 model-free / 模型 + 规划 / oracle。第三级最容易被漏掉，而它正是"收益来自模型还是来自搜索"的分界线。
  • 样本效率要读曲线，不读终点。 本课实测：N≤200 时"模型 + 规划"领先（N=50：+0.3240 vs −0.4005），N≥400 后 Q-learning 反超；logN 轴 AUC 是 −0.5356 vs +1.3869。只报 N=800 会得到相反的总结论。
  • 模型 + 规划在 N 很大时可能下降（本课 0.4659→0.3495）：数据越集中在专家路径上，未覆盖状态的默认外推影响越大。这不是 bug。
  • 自评间隙 V^模型​−V真环境​ 的符号由用法决定。 本课"不挑选"（K=1）时为负（保守模型低估自己，−0.164∼−0.213），"挑最好的"（K=32）时全部翻正（+0.167∼+0.434）。
  • 选择偏差是数学必然：E[maxk​εk​]≈σ2lnK​。多试种子、多看 checkpoint、多换超参都会把它加进报告。报告必须写清选择预算 K，最终结论必须来自真环境的独立评估。
  • 误差要测在策略诱导分布上。 本课实测：数据加权转移误差 0.1269，策略诱导加权 0.8265（6.5 倍），策略 93.0% 的访问是零样本 (s,a)。建议两个都报，并报它们的比值（它就是"规划器把模型带到多陌生地方"的度量）。
  • 三条边界：收益是相对量（换基线/预算/分布就换数字）；AUC 与交叉点受任务难度影响；自评间隙的符号不固定，必须把"模型偏差"与"选择偏差"分开报。

下一节：这一节反复出现"必须同预算比较""必须写清种子""必须在真环境复核"——这些不是实验技巧，而是协议。下一节把整章收束成一份可执行的评测协议与陷阱清单：分布内/分布外怎么分离、种子与方差怎么报、算力怎么对齐，以及四类最常见的作弊路径（在评测环境上调参、模型自评当结果、只报均值不报方差、不等预算比较），每一类都给本课量出来的数字，最后给一个可以直接跑在评测记录上的 audit() 审查函数。
