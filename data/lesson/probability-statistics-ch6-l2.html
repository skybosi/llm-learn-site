假设检验#

有了样本统计量和抽样分布，我们就能回答一类更尖锐的问题："这个差异是真实存在的，还是只是随机波动？" 比如新算法真的比旧算法准，还是只是这次运气好？回答这类问题的工具就是假设检验。它是 A/B 测试、模型对比、科学实验结论的裁判标准。

一、概念讲解#

1. 原假设与备择假设#

假设检验从一个"默认立场"出发：

  • 原假设 H₀：默认成立的、保守的陈述。通常是"没有差异""没有效果"，比如"新算法和旧算法准确率相同"。
  • 备择假设 H₁：我们想要证明的对立陈述，比如"新算法准确率更高"。

检验的逻辑是"反证法"：先假设 H₀ 为真，看观测到的数据在这个假设下有多"离谱"。如果离谱到一定程度，就拒绝 H₀、转而支持 H₁。

2. p 值：数据有多"离谱"#

p 值的定义是：在 H₀ 为真的前提下，观察到"当前结果或更极端结果"的概率。

  • p 值很小 → 说明在 H₀ 下，出现这种数据非常罕见 → 我们有理由怀疑 H₀；
  • p 值较大 → 说明这种数据在 H₀ 下很常见 → 不足以推翻 H₀。

注意：p 值不是"H₀ 为真的概率"，这是最常见的误解。它是"假设 H₀ 为真时，数据有多极端"的概率。

3. 显著性水平 α 与拒绝域#

我们事先定一个门槛叫显著性水平 α（常用 0.05）。规则是：

  • 若 p 值 < α，拒绝 H₀，结果"统计显著"；
  • 若 p 值 ≥ α，不拒绝 H₀（注意：是"不拒绝"，不是"证明 H₀ 为真"）。

把"p 值 < α"对应的统计量取值范围画出来，就是拒绝域。

4. 两类错误：不是非黑即白#

任何决策都可能犯错，假设检验有两类：

  • 第一类错误（弃真）：H₀ 其实为真，我们却拒绝了它。概率正好是 α。
  • 第二类错误（存伪）：H₀ 其实为假，我们却没有拒绝。概率记为 β，1 − β 叫检验功效（power）。

增大样本量、提高 α，都能减小第二类错误，但会以增大第一类错误风险为代价，需要在具体问题里权衡。

5. 常见的检验方法#

  • z 检验：已知总体方差，用正态分布；
  • t 检验：方差未知，用小样本，用 t 分布（比正态更"厚尾"）；常见的有单样本 t 检验、两样本 t 检验、配对 t 检验；
  • 卡方检验：检验分类变量之间是否独立（列联表）。

机器学习里最常用的是两样本 t 检验：比较两组模型在多次实验上的性能均值是否有显著差异。

6. 在机器学习中的位置#

  • A/B 测试：比较新老版本的点击率、转化率；
  • 模型对比：判断模型 A 是否显著优于模型 B，而不只是"这次分数高一点"；
  • 特征筛选：检验某个特征在两组样本中的分布是否有显著差异。

二、可运行示例#

示例 A：单样本 t 检验#

import numpy as np
from scipy import stats

np.random.seed(0)
# 某产品声称平均重量 100g，抽 40 件称重（真实均值其实是 96g）
sample = np.random.normal(loc=96.0, scale=5.0, size=40)

# H0: 总体均值 = 100；H1: 总体均值 ≠ 100（双尾）
t_stat, p_value = stats.ttest_1samp(sample, popmean=100)
print(f"t 统计量 = {t_stat:.3f}")
print(f"p 值 = {p_value:.4f}")
alpha = 0.05
print("结论：", "拒绝 H0，均值与 100 有显著差异" if p_value < alpha
      else "不拒绝 H0，无充分证据说明均值不是 100")

预期输出（部分）：

t 统计量 = -2.860
p 值 = 0.0068
结论： 拒绝 H0，均值与 100 有显著差异

示例 B：A/B 测试——两组点击率是否有显著差异#

# 旧按钮：1000 次展示 60 次点击；新按钮：1000 次展示 85 次点击
n_old, click_old = 1000, 60
n_new, click_new = 1000, 85

# 用两样本比例的 z 检验
p_old, p_new = click_old / n_old, click_new / n_new
p_pool = (click_old + click_new) / (n_old + n_new)   # 合并比例
se = np.sqrt(p_pool * (1 - p_pool) * (1 / n_old + 1 / n_new))
z = (p_new - p_old) / se
p_value = 2 * (1 - stats.norm.cdf(abs(z)))           # 双尾
print(f"旧按钮点击率 = {p_old:.3f}，新按钮点击率 = {p_new:.3f}")
print(f"z = {z:.3f}，p 值 = {p_value:.4f}")
print("结论：", "新按钮显著更优" if p_value < 0.05 else "差异不显著")

预期输出（部分）：

旧按钮点击率 = 0.060，新按钮点击率 = 0.085
z = 2.156，p 值 = 0.0311
结论： 新按钮显著更优

要点：示例 A 中样本均值 97.56 与声称的 100 相差约 2.4g，t 统计量 −2.86、p 值 0.0068 < 0.05，判定为"有显著差异"；示例 B 中新旧点击率差 2.5 个百分点，z = 2.156、p 值 0.031 也达到显著——两例都说明，判断"差异是否真实"要依赖 p 值，而不是肉眼。

三、练习#

  1. 解释：用自己的话说清楚 p 值的含义，并指出"p 值是 H0 为真的概率"这句话错在哪。
  2. 改参数：把示例 A 的 size=40 改成 size=200 重新抽样，观察 p 值变化，并解释为什么样本量增大会让同样的真实差异更容易被"检验出来"。
  3. 两类错误：在 A/B 测试中，把"新按钮其实没用，却错误上线"对应哪类错误？"新按钮其实更好，却错误下线"又是哪类？各自应如何控制？
  4. 联系机器学习：你在验证集上跑 5 次模型 A 得 5 个准确率，跑 5 次模型 B 得 5 个准确率。用什么检验判断两者是否有显著差异？写出思路。
