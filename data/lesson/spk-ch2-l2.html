CTC：条件独立假设、前向后向与 blank 的作用#

这一节要解决什么#

上一节把端到端的问题定位成一句话：对齐是隐变量，而"对全部对齐求和"就是训练目标。 CTC 是这个想法最干净的实现，它的全部内容只有一个式子：

p(y∣x)=π∈B−1(y)∑​t=1∏T​p(πt​∣x)​

右边有三块，每一块都值得单独讲清：

  1. ∏t​p(πt​∣x)：路径层面的条件独立假设。它在哪一层成立、哪一层不成立，是本节的第一个问题；
  2. B−1(y)：一个多对一的折叠映射。它决定了"哪些路径算对"，也决定了 blank 为什么必需；
  3. ∑：对指数多个对齐求和。这一步若不能高效算，整个定义就只是纸面的——前向后向就是把它算出来的那个算法。

本节按这三块展开，每一块都给完整推导与可手算的数值算例。核心交付四件东西：

  • (a) 前向后向的完整推导 + T=6、y=’ab’ 的逐格数值算例：α、β 两张表全部打印，并且用暴力枚举 36=729 条路径验证 p(y∣x)=0.2245410000（误差 2.776×10−17）；
  • (b) 梯度的完整推导 + 有限差分验证：∂ut,k​∂L​=p(k∣xt​)−γt​(k)，解析与中心差分的最大误差 1.782×10−10；
  • (c) blank 的三件事，每件都带算式：重复标签的可表示性（最小帧数 Tmin​=L+#{相邻相同对}）、长度闸门（路径计数 (2LT+L​)）、以及blank 独占这个可量化的失效模式（blank 偏置 b=4 时期望输出长度从 2.80 掉到 0.2443，空串成为最大概率输出）；
  • (d) 与对齐的关系：CTC 给的是对齐的分布而不是一个切分（最大概率路径只占标签后验的 0.0982），以及一个常被误读的结论——CTC 的标签之间并不独立，实测 I(y1​;y2​)=0.0776 nats，但这 0.0776 完全由对齐竞争产生，模型没有为"语言"留任何参数。

一、CTC 的定义：把"对齐"变成求和#

1.1 三个对象#

设输入是 T 帧的编码器输出 x=(x1​,…,xT​)，输出是长度 L 的符号序列 y=(y1​,…,yL​)，L≤T。定义字母表

A=V∪{∅}

其中 V 是输出符号集（字符或子词），∅ 是 blank（一个不对应任何输出符号的特殊符号）。

对象 1：路径。 一条路径是长度恰好 T 的符号序列

π=(π1​,…,πT​),πt​∈A

CTC 的模型部分就是一个逐帧分类器，输出 p(k∣xt​)，k∈A，满足 ∑k​p(k∣xt​)=1。路径概率被定义为

p(π∣x)=t=1∏T​p(πt​∣xt​)

注意这里写的是 p(πt​∣xt​) 还是 p(πt​∣x) 是个关键区别，§1.3 会专门澄清。

对象 2：折叠映射 B。 对任意路径 π，B(π) 分两步得到：

B(π)=删掉 blank(合并相邻重复(π))

例：(∅,a,a,∅,a)合并​(∅,a,∅,a)删空​(a,a)。

对象 3：标签后验。 CTC 把 y 的概率定义为全部折叠到 y 的路径的概率之和：

p(y∣x)=π:B(π)=y∑​p(π∣x)=π∈B−1(y)∑​t=1∏T​p(πt​∣xt​)

训练目标就是最小化 −logp(y∣x)（对每条训练样本）。

1.2 为什么是"合并重复 + 删 blank"#

这两步不是随便定的，它们各自解决一个必要条件。

合并相邻重复：让"一个符号连续出现多帧"不改变输出。语音里一个音素通常持续几十毫秒（好几帧），如果每帧都算一个输出，T 帧就会产生 T 个符号。合并把"持续"与"重复"区分开：(a,a) 是"一个 a 持续两帧"，(a,∅,a) 才是"两个 a"。

删 blank：两件事。

  • 它给出"这个符号已经说完了"的分隔符：(a,∅,a) 需要 blank 才能与 (a,a) 区分。没有 blank，"aa"在任何 T 下都无法表示（输出字母表只有 {a,b} 时，两个 a 必然相邻，会被合并成一个）。
  • 它给出"这一帧不输出任何符号"的能力：静音、噪声、过渡段都可以落在 blank 上。没有 blank，长度必须严格等于 T，这是不可接受的。

代价是 blank 引入了一个新的分配问题：哪些帧是 blank？这个分配就是对齐，而 CTC 的做法是不决定它，而是把所有可能都加起来。

1.3 条件独立假设的准确位置#

这是 CTC 最常被误读的一句话，必须精确到层：

成立的是（路径层）：给定 x，路径上的各个符号相互独立，

p(π∣x)=t=1∏T​p(πt​∣x)

不成立的是（标签层）：折叠之后 p(y∣x) 不是乘积形式。§6.3 会实测：在一个合成模型上 I(y1​;y2​)=0.0776 nats，q(b,a) 对独立基线的比值达到 3.5389。

另一个必须掐掉的误读："CTC 假设输入帧独立"。它不假设。p(πt​∣x) 里的条件可以是整句 x（双向编码器），实践中就是。被假设独立的是输出符号，给定 x 之后。

把这三层写在一起：

编码器可以是任意函数，看得到全部 xp(πt​∣x)​​⟹输出符号条件独立（定义）p(π∣x)=t∏​p(πt​∣x)​​⟹折叠后不独立（后果）p(y∣x)=π∑​t∏​p(πt​∣x)​​

为什么这样设计：如果允许输出符号之间相依（像注意力解码器那样 p(yl​∣y<l​,x)），那么"对全部对齐求和"就失去了可分解的递推结构——和式里的每一项都要重新跑一次自回归解码，代价爆炸。条件独立是"能把求和写成线性链递推"的入场券。 第 3 节会看到 RNN-T 用了另一种入场券（联合网络 + 单调格点），换来了流式能力。

二、前向后向的完整推导#

2.1 扩展标签序列#

定义扩展标签

l=(∅,y1​,∅,y2​,∅,…,yL​,∅),∣l∣=2L+1

约定 l0​:=∅（一个虚拟的前置 blank，只用于让转移条件写得统一）。l 的第 s 项记作 ls​，s=1,…,2L+1。

为什么是 2L+1 而不是 L：折叠映射 B 的每条原像路径都必须"按顺序读出 l 的子序列，允许原地重复"。把 blank 显式插进标签之间，就把"允许原地重复"变成了"允许自环"，把整个问题变成了一条线性链——于是前向递推成立。

三种合法转移（从 s′ 到 s）：

转移 条件 含义
s→s 恒允许 原地重复（同一个符号持续）
s−1→s 恒允许 读下一个符号
s−2→s ls−2​=ls​ 跳过一个 blank（两个不同标签之间没有 blank）

第三条的条件值得展开：当 ls​=∅ 时，ls−2​ 也是 ∅，条件自动为假，所以 blank 状态永远不会被跳过；当 ls​ 是标签而 ls−2​ 是同一个标签时（即 y 里有相邻重复，如 aa），条件为假——必须有一个 blank 夹在中间，这正是 §1.2 说的分隔符作用。当 ls−2​=∅（第一个标签的情况）或 ls−2​=ls​ 时，允许跳过。

2.2 前向递推#

定义

αt​(s):=所有"走到 (t,s) 且折叠到 l1:s​"的路径概率之和

递推：

αt​(s)=(αt−1​(s)+αt−1​(s−1)+[ls−2​=ls​]αt−1​(s−2))p(ls​∣xt​)​

（下标越界的项取 0。）

初始化：

α1​(1)=p(∅∣x1​),α1​(2)=p(y1​∣x1​),α1​(s)=0 (s>2)

终止：

p(y∣x)=αT​(2L+1)+αT​(2L)​

为什么终止是两项：结尾可以是最后一个 blank（s=2L+1），也可以直接停在最后一个标签上（s=2L）。两者对应"说完之后还有 blank 帧"与"说完即结束"，都是合法路径。

复杂度：每一步要扫 2L+1 个状态，每个状态 O(1)，所以 O(T(2L+1))——这是表 9 里 CTC 那一行 10,100 的来历。它与词表大小 ∣V∣ 无关：词表只在算 p(ls​∣xt​) 这一步进入，而那一步是编码器的 softmax，只做一次。

2.3 后向递推#

定义

βt​(s):=所有"从 (t,s) 出发走到结束、且余下部分折叠到 ls:2L+1​"的路径概率之和

递推：

βt​(s)=βt+1​(s)p(ls​∣xt+1​)+βt+1​(s+1)p(ls+1​∣xt+1​)+[ls​=ls+2​]βt+1​(s+2)p(ls+2​∣xt+1​)​

终止：

βT​(2L+1)=βT​(2L)=1,βT​(s)=0 其余

注意最后一行的空项：输出表里 βT​ 是

β6​=(0,0,0,1,1)

只有最后两个状态非零。这与"终止是两项"完全对应。

2.4 三个恒等式#

恒等式 1（前向后向一致）：

s=1∑2L+1​αt​(s)βt​(s)=p(y∣x)∀t​

证明：每条 B−1(y) 中的路径唯一对应一条格点路径；每条格点路径在时刻 t 恰好经过一个状态 s；αt​(s)βt​(s) 是"经过 (t,s) 的全部完整路径的概率之和"；因此按 s 求和把每条路径正好数了一次。

恒等式 2（占用后验归一）：

γt​(s):=p(y∣x)αt​(s)βt​(s)​,s=1∑2L+1​γt​(s)=1

恒等式 3（标签级占用归一）：

γt(k)​:=s:ls​=k∑​γt​(s),k∈A∑​γt(k)​=1

这三个恒等式都是可数值检验的，输出表 4 与表 7 都做了检查。

三、梯度：完整推导#

3.1 对发射概率求导#

记 L=−logp(y∣x)。由恒等式 1，p(y∣x)=∑s​αt​(s)βt​(s)。对固定的 t，p 是发射概率向量 {p(k∣xt​)}k​ 的一次齐次函数：αt​(s) 对时刻 t 的发射是 1 次、βt​(s) 是 0 次。于是由 Euler 定理

k∈A∑​p(k∣xt​)∂p(k∣xt​)∂p(y∣x)​=p(y∣x)

而具体地，对 ls​=k 的状态，αt​(s) 中含因子 p(k∣xt​) 恰好一次、βt​(s) 不含它，所以

∂p(k∣xt​)∂p(y∣x)​=p(k∣xt​)1​s:ls​=k∑​αt​(s)βt​(s)=p(k∣xt​)γt(k)​p(y∣x)​

因此

∂p(k∣xt​)∂L​=−p(k∣xt​)γt(k)​​​

3.2 对 logits 求导#

设逐帧输出经 softmax：p(k∣xt​)=∑k′​eut,k′​eut,k​​，则 ∂ut,j​∂p(k∣xt​)​=p(k∣xt​)(δjk​−p(j∣xt​))。链式法则：

∂ut,j​∂L​=k∑​(−p(k∣xt​)γt(k)​​)⋅p(k∣xt​)(δjk​−p(j∣xt​))=−γt(j)​+p(j∣xt​)=1k∑​γt(k)​​​

∂ut,j​∂L​=p(j∣xt​)−γt(j)​​

这个式子的形式值得注意：它就是"预测分布 − 目标分布"，与逐帧交叉熵的梯度形式完全相同，唯一的区别是目标不是 one-hot 而是 γt(j)​（全部对齐路径归一后的软占用）。这与上一节表 7 的结论严丝合缝：端到端与帧级训练的差别只在责任度那一项。

两个可自查的恒等式：∑k​p(k∣xt​)=1 与 ∑k​γt(k)​=1，所以 ∑k​∂L/∂ut,k​=0——每一帧的梯度向量正交于"全体加同一个常数"这个方向，这正是 softmax 参数化的必然结果。

四、blank 的三件事#

4.1 重复标签的可表示性#

最小帧数（输出表 8）：

Tmin​(y)=L+#{i:yi​=yi−1​}

y L 相邻相同对 Tmin​ 说明
a 1 0 1 无需 blank
ab 2 0 2 无需 blank
aa 2 1 3 需要 1 个 blank 夹在重复之间
aba 3 0 3 无需 blank
aaa 3 2 5 需要 2 个 blank

没有 blank 时 aa 在任何 T 下都不可表示：取字母表 {a,b}、T=2，折叠成 aa 的路径数 =0，折叠成 ab 的路径数 =1。这不是"难学"，是表示能力的硬边界。

七、取舍与边界#

(1) CTC 买到的是"不需要对齐标注"，欠的是"没有语言模型"。 这两件事是同一枚硬币：正因为每个路径的每个符号条件独立，求和才能写成线性链递推；也正因为独立，标签之间没有可训练的先验。可算判据：I(y1​;y2​)=0.0776 nats 是结构上限（由发射几何决定）；要让系统真正"懂语言"，必须外接 LM 或用第 3 节的结构。

(2) 峰化是特征也是病。 损失下降时对齐熵从 0.9146 掉到 0.0695——这给了你一个免费的对齐器，但也把梯度推向 0/1。工程上的判据是监控 maxt,s​γt​(s)：若它长期 >0.99 而验证集指标不再改善，训练信号已经枯竭。

(3) blank 独占要在训练早期就监控。 本节的算例说明 b=3 时空串就是最大概率输出（P=0.51465）。监控量与阈值见 §4.3。注意这不是"过拟合"，是损失函数的一个鞍点区域：模型通过"少说"降低损失，而序列级损失对少说的惩罚被归一化摊薄。

(4) 一个容易被忽略的边界：L≤T。 §4.1 的 Tmin​ 公式给出一条硬约束。字符级 CTC 在短音频（<0.5 s）上要检查它；子词级 CTC 通常自动满足。

(5) CTC 的"条件独立"带来的推理后果。 因为 p(π∣x)=∏t​p(πt​∣xt​)，贪心解码 π^t​=argmaxk​p(k∣xt​) 是逐帧独立的最优，不需要 beam。但折叠之后，逐帧贪心并不最大化 p(y∣x)——这就是 prefix beam search 存在的原因：它要在折叠的约束下做搜索。"逐帧独立"负责训练可算，"折叠"负责解码要搜，这两件事常被混为一谈。

(6) 可复现性。 全部发射概率、标签序列、偏置扫描与温度扫描都是合成的（⚠️），本节不含随机数：全部是确定性的枚举与逐格扫描。代码只用标准库（itertools、math）。给定同一份代码，输出逐字节一致。

仅用标准库。⚠️ 所有发射概率、标签序列与损失值都是合成的。

import itertools
import math

NEG = float("-inf")
BL = '-'                       # blank 符号
SYMS = [BL, 'a', 'b']

# 0. 工具

def logsumexp(xs):
    m = max(xs)
    if m == NEG:
        return NEG
    return m + math.log(sum(math.exp(x - m) for x in xs))

def log_softmax(xs):
    m = max(xs)
    return [x - (m + math.log(sum(math.exp(v - m) for v in xs))) for x in xs]

def softmax(xs):
    l = log_softmax(xs)
    return [math.exp(v) for v in l]

def collapse(path):
    """CTC 的 B 映射：先合并相邻重复，再删 blank。"""
    out, prev = [], None
    for c in path:
        if c != prev:
            if c != BL:
                out.append(c)
            prev = c
    return tuple(out)

def extended(y):
    """扩展标签 l = [blank, y1, blank, y2, ..., blank]，长度 2L+1。"""
    l = [BL]
    for c in y:
        l.append(c); l.append(BL)
    return l

def brute_force(P, y):
    """枚举全部 |A|^T 条路径，返回 (p(y|x), 命中路径列表)。"""
    T = len(P)
    tot, hits = 0.0, []
    for path in itertools.product(SYMS, repeat=T):
        if collapse(path) == tuple(y):
            pr = 1.0
            for t, c in enumerate(path):
                pr *= P[t][c]
            tot += pr
            hits.append((pr, path))
    return tot, hits

def ctc_forward(P, l):
    """alpha[t][s]，s 从 1 编号。"""
    T, S = len(P), len(l)
    a = [[0.0] * (S + 1) for _ in range(T + 1)]
    a[1][1] = P[0][l[0]]
    a[1][2] = P[0][l[1]]
    for t in range(2, T + 1):
        for s in range(1, S + 1):
            if s == 1:
                a[t][s] = a[t - 1][s] * P[t - 1][l[s - 1]]
                continue
            v = a[t - 1][s] + a[t - 1][s - 1]
            if l[s - 1] != BL and s - 3 >= 0 and l[s - 3] != l[s - 1]:
                v += a[t - 1][s - 2]
            a[t][s] = v * P[t - 1][l[s - 1]]
    return a

def ctc_backward(P, l):
    T, S = len(P), len(l)
    b = [[0.0] * (S + 2) for _ in range(T + 2)]
    b[T][S] = 1.0
    b[T][S - 1] = 1.0
    for t in range(T - 1, 0, -1):
        for s in range(1, S + 1):
            v = b[t + 1][s] * P[t][l[s - 1]]
            if s + 1 <= S:
                v += b[t + 1][s + 1] * P[t][l[s]]
            if s + 2 <= S and l[s - 1] != BL and l[s + 1] != l[s - 1]:
                v += b[t + 1][s + 2] * P[t][l[s + 1]]
            b[t][s] = v
    return b

def ctc_loglik(P, y):
    l = extended(y)
    S = len(l)
    a = ctc_forward(P, l)
    T = len(P)
    return math.log(a[T][S] + a[T][S - 1]) if (a[T][S] + a[T][S - 1]) > 0 else NEG

def gamma(P, y):
    """返回 gamma[t][s]（s 从 1 编号）与 p(y|x)。"""
    l = extended(y)
    S = len(l); T = len(P)
    a = ctc_forward(P, l); b = ctc_backward(P, l)
    py = a[T][S] + a[T][S - 1]
    g = [[a[t][s] * b[t][s] / py for s in range(1, S + 1)] for t in range(1, T + 1)]
    return g, py, a, b

def lattice_viterbi(P, y):
    """在扩展标签格点上取最大概率路径（CTC 的『最优对齐』）。"""
    l = extended(y)
    S = len(l); T = len(P)
    dp = [[NEG] * (S + 1) for _ in range(T + 1)]
    bp = [[0] * (S + 1) for _ in range(T + 1)]
    for s in (1, 2):
        dp[1][s] = math.log(P[0][l[s - 1]])
    for t in range(2, T + 1):
        for s in range(1, S + 1):
            if s == 1:
                cands = [(dp[t - 1][s], s)]
            else:
                cands = [(dp[t - 1][s], s), (dp[t - 1][s - 1], s - 1)]
                if l[s - 1] != BL and s - 3 >= 0 and l[s - 3] != l[s - 1]:
                    cands.append((dp[t - 1][s - 2], s - 2))
            v, arg = max(cands)
            dp[t][s] = v + math.log(P[t - 1][l[s - 1]])
            bp[t][s] = arg
    s = S if dp[T][S] > dp[T][S - 1] else S - 1
    best = dp[T][s]
    st = [0] * (T + 1)
    for t in range(T, 0, -1):
        st[t] = s; s = bp[t][s]
    return [l[st[t] - 1] for t in range(1, T + 1)], best

小结#

  • CTC 的全部内容是一个式子：p(y∣x)=∑π∈B−1(y)​∏t​p(πt​∣x)。三块分别是条件独立（路径层）、折叠映射（合并重复 + 删 blank）、以及对指数多个对齐的求和。
  • 条件独立在路径层成立、在标签层不成立。实测 I(y1​;y2​)=0.0776 nats，q(b,a) 对独立基线的比值 3.5389；但这份相依不可训练，模型没有为语言留参数。它不假设输入帧独立——编码器看得到全部 x。
  • 前向后向的递推只有三种转移（自环、邻接、跳过 blank），跳过 blank 的条件是 ls−2​=ls​；终止是两项 αT​(2L+1)+αT​(2L)。T=6 的算例里 p(y∣x)=0.2245410000，与暴力枚举 36=729 条路径（其中 70 条折叠成 ab）的差是 2.776×10−17；恒等式 ∑s​αt​(s)βt​(s)=p(y∣x) 逐帧相对误差最大 3.71×10−16。
  • 梯度是 ∂L/∂ut,j​=p(j∣xt​)−γt(j)​，与逐帧交叉熵同形，只是目标从 one-hot 换成软占用 γ；有限差分最大误差 1.782×10−10。
  • blank 的三件事：让重复标签可表示（Tmin​=L+#{相邻相同对}，无 blank 时 aa 在 T=2 的路径数为 0）；给出长度闸门（路径数 (2LT+L​)，ab 在 T=6 是 70 条，占全空间 0.0960）；也给出一种失效模式（blank 偏置 b=4 时期望长度从 2.80 掉到 0.2443，空串概率 0.77461）。
  • 数值上必须用 log 域：(1/3)1000 直接连乘下溢为 0，log 域给出 −1098.612289；阈值是 T>308/log10​(1/p)。
  • 对齐是一个分布：最大概率路径只占标签后验的 0.098200。argmaxt​γt​ 给位置、∑t​γt​ 给时长（本算例 a 为 1.5668 帧、b 为 2.1065 帧），这就是 CTC 顺手当强制对齐器的依据。
  • 峰化是损失的副产品：损失 1.09087→0.12949 时峰值 γ 从 0.67351 升到 0.99755、占用熵从 0.9146 掉到 0.0695。它同时是对齐器与训练后期梯度变脆的原因。
