时序建模：光流、长时依赖与长视频的显存账#

这一节要解决什么#

第 2 节把四代表示摆出来，每一代都留了一个洞：第一代丢了顺序，第二代的时间感受野只有 0.4–0.6 秒，第三代把运动变成手工输入，第四代的注意力在 N 上二次。这一节把这三个洞逐个算清：

  1. 光流为什么在弱纹理处失效——这不是精度问题，是结构问题。 光流约束方程 Ix​u+Iy​v+It​=0 是一个方程两个未知数。在二维纹理上 Lucas–Kanade 的正常方程条件数是 1.3820，恢复值 (u,v)=(0.3956,−0.2867) 对真值 (0.4,−0.3) 的偏差来自一阶线性化；而在只沿 x 变化的一维边缘上 ∑Iy2​=0.0000、行列式为零、v 无解（表 1）。
  2. 条件数把误差放大成什么量级是可算的。 把 y 方向梯度按 ϵy​ 缩小，条件数从 1.38 涨到 13819.52，v 的绝对误差从 0.013312 涨到 2866.579682；除一下，误差/条件数稳定在 0.19–0.21——这正是误差界 ∥Δx∥/∥x∥≤cond⋅∥Δr∥/∥r∥（表 1）。
  3. 金字塔买到的是"能测多大位移"，公式是 2L−1。 层数 L=1–6 分别给出 1,3,7,15,31,63 像素的上界，像素代价从 1.000000 收敛到 1.333008（→4/3）。层数超过 ⌈log2​(D+1)⌉ 后每加一层只增加误差与重采样开销（表 2）。
  4. 长时依赖的三种记忆有精确的容量公式。 线性注意力/SSM 的递推 St​=St−1​+kt​vt⊤​ 与显式因果前缀和逐元素相同（最大差 1.776×10−15），状态恒为 d2；但用 ki​ 检索时 S⊤ki​=vi​+∑j=i​(ki​⋅kj​)vj​，单位随机键下串扰均方根 ≈(N−1)/d​：d=32、N=32 时实测 0.980130——已经与信号同量级（表 3）。
  5. "d 维状态能记 d 项"只是上界。 以串扰 ≤ϵ 为可用判据，可容纳项数 N≈dϵ2+1：d=32 时 ϵ=0.1 只有 1.3 项、ϵ=0.5 只有 9.0 项；d=768 时 ϵ=0.5 也只有 193 项（表 3）。
  6. 长视频的第一堵墙是 score 矩阵，不是参数。 单层单样本 nh​N2s：N=4096 时 384 MiB、N=16384 时 6.0000 GiB、N=65536 时 96 GiB。分块（只存行统计 2nh​Ns）把它降到 0.1875/0.7500/3.0000 MiB，比值 2048–32768 倍（表 4）。
  7. "不物化 score"能把 Nmax​ 提约 9 倍，但 FLOPs 一分不省。 24 GiB 激活预算、L=12、d=768 下：分块实现约 87,210 个 token，物化实现约 9,459 个（9.22×）；而 N=65536 时单层注意力核心就是 13,194.140 GFLOP、12 层 158,329.674 GFLOP（表 4）。
  8. 降复杂度的手段收益差别极大，而且各有形状代价。 12 层总 FLOPs（Nt​=512、Ns​=196、d=768）：联合 371,239.793 GFLOP；分解 0.007055（省 141.74×）、窗口 W=147 省 682.67×、线性/SSM 省 130.67×、而分层池化只省 4.50× 且与 Nt​ 无关（表 5）。
  9. 推理期的账是另一笔：KV cache。 每 token 2Lds=36864 B =0.0352 MiB；一段 10 分钟视频（600 s、2940 token/s）要 60.5621 GiB，1 小时要 363.3728 GiB（表 6）。长视频在推理侧先撞显存墙，不是算力墙。

本节的主线是一句话：时间维上的每一个"看得更远"的诉求，最后都会变成一笔显存或一串被压缩掉的信息。

一、光流：把运动显式解出来#

1.1 约束方程与孔径问题#

亮度恒定假设（brightness constancy）说：同一点在相邻两帧亮度不变。

I(x+u,y+v,t+1)=I(x,y,t).

一阶泰勒展开给出光流约束方程：

Ix​u+Iy​v+It​=0(记 Ix​=∂I/∂x, It​=∂I/∂t).

这一个方程里有两个未知数 (u,v)——这就是孔径问题（aperture problem）的全部来源。它不是一个可以靠更好的优化器绕过的数值困难，而是一个秩的缺陷：约束只确定了位移在梯度方向上的分量（法向流），切向分量完全不可知。

1.2 Lucas–Kanade：在窗口内凑出第二个方程#

LK 的做法是在窗口 W 内假设 (u,v) 恒定，把每个像素的约束堆起来做最小二乘：

u,vmin​(x,y)∈W∑​(Ix​u+Iy​v+It​)2 ⟹ A⊤A (结构张量)[∑Ix2​∑Ix​Iy​​∑Ix​Iy​∑Iy2​​]​​[uv​]=−[∑Ix​It​∑Iy​It​​].

可解性完全由 A⊤A 的谱决定：两个特征值都大且接近 ⇒ 良态；一个接近零 ⇒ 病态；两个都小 ⇒ 无纹理、不可解。条件数

cond=σmin​σmax​​=λmin​(A⊤A)λmax​(A⊤A)​​

就是"这个窗口的运动能不能被解出来"的判据。表 1：

1.4 金字塔：可测位移上界 2L−1 与代价#

1.5 什么时候不该用光流#

把第 2 节 3.4 的三条边界与这里的数值合起来，可以写成一个判据集合：

  • 区域内最小特征值太小（弱纹理、直边、大面积纯色）⇒ 条件数爆炸，法向流以外的分量不可信。
  • 位移超过 2L−1（快速运动、低帧率）⇒ 需要更多金字塔层，而层数带来误差与开销。
  • 遮挡边界：亮度恒定假设在遮挡处本身不成立，误差是模型误差而非数值误差。
  • 需要"任务相关的运动"：光流固定成 2 通道位移场，模型无法学"什么样的运动对该任务有用"。

所以第 2 节的第四代并不是"不要运动"，而是"让模型自己决定怎么用运动"——它把这件事从算子形状搬到了注意力权重上。代价就是接下来两节的二次项与容量问题。

二、长时依赖与记忆#

2.1 三种记忆的形状#

把"过去"压成定长状态，只有三条路：

机制 状态大小 计算代价 能无损记住多少项 顺序信息
池化 d O(Nd) 0（只留摘要） 全部丢失
注意力 O(N) KV / O(N2) score O(N2d) N 完整保留
线性递推 / SSM d2 O(Nd2) 约 dϵ2（ϵ 为可容忍串扰） 压缩保留

池化的问题第 2 节已经算过：平均/最大池化对时间反演逐元素相同（最大差 0.000000），T=8 时 40320 种排列被商成一个向量。注意池化并非"错"，它只是把记忆容量换成 O(Nd) 的最小代价——标签对顺序不敏感时它就是最优选择。

注意力的容量是 N（每个 token 都能被单独查询），代价是 O(N2d) 与 O(N2) 的 score 显存。

线性递推/SSM走第三条路：状态大小与 N 无关。

2.2 线性注意力/SSM 的递推恒等式#

因果线性注意力（causal linear attention）定义为

yi​=j≤i∑​(qi​⋅kj​)vj​.

它可以用一个 d×d 的状态递推实现：

St​=St−1​+kt​vt⊤​∈Rd×d,yt​=St⊤​qt​.

为什么两者等价：把 St​ 展开得 St​=∑j≤t​kj​vj⊤​，于是 St⊤​qt​=∑j≤t​(qt​⋅kj​)vj​，与定义式逐项相同。数值核对（N=8、d=4）：最大差 1.776×10−15，状态元素个数 4×4=16（与 N 无关）。

这条恒等式的意义：它把"注意力的容量"与"线性注意力的常数状态"放在了同一张表上——多出来的容量是用 O(N) 的状态与 O(N2) 的计算换来的。SSM 不是"注意力的小型化"，它是另一种记忆形状。

2.3 记忆容量：串扰的精确形式#

S⊤ki​=j∑​(ki​⋅kj​)vj​=vi​+串扰j=i∑​(ki​⋅kj​)vj​​​.

对 d 维单位随机键，E[(ki​⋅kj​)2]=1/d，所以串扰的均方根

RMSE≈dN−1​​⋅∥v∥.

三、长视频的显存与注意力二次项账#

3.1 三笔独立的账#

长视频的显存有三笔账，它们不能互相折算：

注意力中间矩阵（训练/推理都可能）Mscore​=Bnh​N2s​​,激活（仅训练）Mact​=Lcact​Nds​​,KV cache（仅推理）Mkv​=2LNds​​.

注意力中间矩阵（训练/推理都可能）Mscore​=Bnh​N2s​​,激活（仅训练）Mact​=Lcact​Nds​​,KV cache（仅推理）Mkv​=2LNds​​.

（B batch、nh​ 头数、s 每元素字节、L 层数、cact​ 每层保留的张量数。）

为什么必须分开算：分块注意力把 Mscore​ 从 O(N2) 降到 O(N)，但它对 Mact​ 与 Mkv​ 无影响；梯度检查点只改 Mact​；KV cache 只在推理期出现。把三笔账混成一笔，就会得出"用了 FlashAttention 就能训长视频"这类错误结论。

  • 分层池化：只改 token 数、不动注意力，但被合并掉的 token 无法再被单独查询。

import math

def dwidth(s: str) -> int:
    return sum(2 if unicodedata.east_asian_width(ch) in ("W", "F") else 1
               for ch in s)


def pad(s: str, w: int, align: str = ">") -> str:
    gap = max(0, w - dwidth(s))
    if align == ">":
        return " " * gap + s
    if align == "<":
        return s + " " * gap
    left = gap // 2
    return " " * left + s + " " * (gap - left)


def row(cells, widths, aligns=None) -> str:
    aligns = aligns or [">"] * len(cells)
    return " | ".join(pad(c, w, a) for c, w, a in zip(cells, widths, aligns))

def gib(x: float) -> str:

def gflop(x: float) -> str:

class LCG:
    """固定种子的线性同余发生器 + Box-Muller，保证输出可复现。"""

    def __init__(self, seed: int = 20260923):
        self.s = seed & 0xFFFFFFFFFFFFFFFF

    def u(self) -> float:
        self.s = (6364136223846793005 * self.s + 1442695040888963407) \
            & 0xFFFFFFFFFFFFFFFF
        return (self.s >> 11) / float(1 << 53)

    def n(self) -> float:
        u1 = max(self.u(), 1e-12)
        u2 = self.u()
        return math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)

def lk_solve(I, u_true, v_true, x0, x1, y0, y1, eps_y=1.0):
    """在整数网格窗口上做 LK。I 是可解析求导的亮度函数。"""
    sxx = sxy = syy = sxt = syt = 0.0
    for y in range(y0, y1 + 1):
        for x in range(x0, x1 + 1):
            ix = I.dx(x, y)
            iy = I.dy(x, y) * eps_y
            it = I.v(x - u_true, y - v_true) - I.v(x, y)
            sxx += ix * ix
            sxy += ix * iy
            syy += iy * iy
            sxt += ix * it
            syt += iy * it
    det = sxx * syy - sxy * sxy
    if abs(det) < 1e-18:
        return None, None, float("inf"), sxx, syy
    # 特征值
    tr = sxx + syy
    disc = math.sqrt(max(0.0, (sxx - syy) ** 2 + 4 * sxy * sxy))
    l1, l2 = (tr + disc) / 2, (tr - disc) / 2
    cond = float("inf") if l2 <= 1e-15 else math.sqrt(l1 / l2)
    u = (-syy * sxt + sxy * syt) / det
    v = (sxy * sxt - sxx * syt) / det
    return u, v, cond, sxx, syy

print("三种把「过去」压成定长状态的机制：")

N1, D1 = 8, 4
rng = LCG(7)
Q = [[rng.n() for _ in range(D1)] for _ in range(N1)]
K = [[rng.n() for _ in range(D1)] for _ in range(N1)]
V = [[rng.n() for _ in range(D1)] for _ in range(N1)]


def dot(a, b):
    return sum(x * y for x, y in zip(a, b))


# 因果线性注意力：显式前缀和
out_ref = []
for i in range(N1):
    acc = [0.0] * D1
    for j in range(i + 1):
        w = dot(Q[i], K[j])
        for c in range(D1):
            acc[c] += w * V[j][c]
    out_ref.append(acc)

# 递推：S += k v^T; out = S^T q
S = [[0.0] * D1 for _ in range(D1)]
out_rec = []
for i in range(N1):
    for a in range(D1):
        for b in range(D1):
            S[a][b] += K[i][a] * V[i][b]
    out_rec.append([sum(S[a][b] * Q[i][a] for a in range(D1))
                    for b in range(D1)])
maxdiff = max(abs(out_ref[i][c] - out_rec[i][c])
              for i in range(N1) for c in range(D1))

print("-" * 104)
print(row(["递推 vs 显式因果线性注意力（最大差）", f"{maxdiff:.3e}"], [40, 24],

小结#

  • 光流约束方程 Ix​u+Iy​v+It​=0 是一个方程两个未知数（孔径问题）。LK 用窗口最小二乘补出第二个方程，可解性由结构张量 A⊤A 的条件数决定（表 1）。
  • 数值证据：二维纹理 cond =1.3820，恢复 (0.3956,−0.2867) 对真值 (0.4,−0.3) 的偏差来自一阶线性化；一维边缘 ∑Iy2​=0.0000、det=0、v 无解，只能定法向流。
  • 条件数放大误差：ϵy​:1→10−4 时 cond 1.38→13819.52，v 误差 0.013312→2866.579682，误差/cond 稳定在 0.19–0.21；ϵy​=1 那一行的误差属于线性化残差，与 cond 无关。
  • 金字塔：可测位移 2L−1 px（L=6 时 63 px），像素代价 →4/3（1.333008）；L≥⌈log2​(D+1)⌉，超过后只增误差。
  • 三种记忆：池化 O(Nd) 状态 d（顺序全丢）；注意力 O(N2d) 容量 N；线性递推/SSM O(Nd2) 状态 d2（表 3）。
  • 递推恒等式：St​=St−1​+kt​vt⊤​、yt​=St⊤​qt​ 与因果线性注意力逐元素相同（最大差 1.776×10−15）。
  • 记忆容量：串扰 ≈(N−1)/d​；d=32、N=32 时实测 0.980130，与信号同量级。可用项数 N≈dϵ2+1：d=768、ϵ=0.5 只有 193 项。显存交叉点 2Nd=d2⇒N=d/2。
  • score 物化 M=nh​N2s：N=4096 时 384 MiB、16384 时 6.0000 GiB、65536 时 96 GiB；分块行统计只有 2nh​Ns（0.1875/0.7500/3.0000 MiB），比值 2048–32768 倍。省的是显存，4N2d 的 FLOPs 不变。
  • 反解：Nmax​=M/(Lb)，b=s(cact​d+2nh​)=24624 B/token/层；24 GiB 下分块 87,210 vs 物化 9,459（9.22×）。梯度检查点把激活降到 LNds+(cact​−1)Nds，代价 +33% 计算（表 4）。
  • 降复杂度收益（12 层、Nt​=512）：分解 141.74×、窗口 682.67×、线性 130.67×、分层池化只有 4.50× 且与 Nt​ 无关（表 5）。
  • KV cache =2LNds=36864 B/token：10 分钟视频 60.5621 GiB、1 小时 363.3728 GiB——推理侧先撞显存墙（表 6）。
