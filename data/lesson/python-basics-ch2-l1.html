变量与赋值#

从现在开始，我们进入"真正写程序"的世界。第一个要掌握的概念是变量——它是几乎所有程序的地基。

一、概念讲解#

1. 变量是什么#

变量，就是一个有名字的盒子，用来存放数据。 你可以把数据放进去，之后通过名字把它取出来用。

name = "小明"
age = 20

这两行分别创建了两个变量：

  • name 这个盒子里装的是文字 "小明"；
  • age 这个盒子里装的是数字 20。

等号 = 在这里叫赋值，意思是"把右边的值，放进左边的盒子里"。

2. 赋值的方向：先右后左#

这是初学者最容易搞错的一点。等号不是数学里的"相等"，而是"把右边交给左边"：

x = 10   # 把 10 放进 x
x = x + 5   # 先算右边的 x + 5（此时 x 还是 10，得 15），再把 15 放回 x

第二行执行后，x 变成了 15。理解"先算右边，再覆盖左边"，你就能看懂后面几乎所有的赋值语句。

3. 变量可以随时改变#

变量里的值不是固定死的，随时可以换成新的：

score = 60
score = 90    # 现在 score 变成 90，原来的 60 被覆盖

给一个已经存在的变量赋新值，旧值就被"挤掉"了。

4. 变量命名的规则（重要）#

给变量起名字时，要遵守三条规则，否则程序会报错：

  1. 只能由字母、数字、下划线组成，且不能以数字开头。例如 age2 合法，2age 不合法。
  2. 不能使用 Python 的关键字。关键字是 Python 自己占用的词，如 if、for、while、class、import 等。
  3. 区分大小写：name、Name、NAME 是三个不同的变量。

此外还有两条好习惯（不强制，但强烈推荐）：

  • 用有意义的英文单词或拼音，比如 student_age 比 a、x1 好懂得多。
  • 多个单词用下划线连接，这叫"蛇形命名法"，是 Python 社区的主流习惯。

5. 变量为什么要存在#

想想看，如果不用变量，你要用"小明 20 岁，再过 3 年 23 岁"这种内容时，每次都得把数字重写一遍。有了变量，改一处、处处更新，程序更清晰、更好维护。

二、可运行代码示例#

# 演示变量的创建、使用和重新赋值

student_name = "小明"        # 用字符串（文字）给变量赋值
student_age = 20             # 用整数给变量赋值
height = 1.75                # 用小数（浮点数）给变量赋值

print("姓名：", student_name)   # 取出变量里的值并打印
print("年龄：", student_age)
print("身高：", height, "米")

# 重新赋值：年龄增长了 1 岁
student_age = student_age + 1
print("一年后年龄：", student_age)

# 用变量做计算
years = 3
future_age = student_age + years
print("再过", years, "年，年龄是", future_age)

预期输出：

姓名： 小明
年龄： 20
身高： 1.75 米
一年后年龄： 21
再过 3 年，年龄是 24

要点：注意 print 里用逗号分隔多个内容，Python 会自动在它们之间加空格；student_age = student_age + 1 演示了"先右后左"的赋值。

三、练习#

  1. 创建变量：创建三个变量，分别保存你的姓名、年龄、所在城市，然后用 print 把它们打印出来。

  2. 交换练习：有两个变量 a = 3、b = 5，请用赋值语句把它们的内容交换（交换后 a 是 5、b 是 3）。提示：可能需要一个临时变量。

  3. 重新赋值：定义一个变量 count = 100，连续对它执行两次 count = count - 10，最后 count 是多少？先在纸上算，再运行验证。

  4. 判断命名合法性：以下名字哪些是合法变量名？3name、my_name、class、userAge、name-1、_tmp。写出你的判断和理由。

  5. 改错：下面的代码有两处错误，找出来并修正后运行：

    class = "三班"
student name = "小红"
print(class, student name)
