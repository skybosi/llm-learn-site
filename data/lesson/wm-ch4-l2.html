在模型里训练策略：想象训练、梯度穿过动力学与模型误差的对抗性利用#

这一节要解决什么#

上一节的规划器每一步都要花钱：B⋅H 次模型 rollout，H 越大越贵。这在低频决策（每 0.1 秒一次）里可以接受，但在高频、高维、连续动作的场景里会直接顶到算力墙。自然的想法是：把搜索摊薄到训练里——在模型里把策略训好，部署时只做一次前向。

这条路线的代表是 PlaNet 之后的整个 Dreamer 家族，以及更早的 SVG、MAESN 一类"解析梯度"方法。它有一个极具吸引力的性质：模型的更新-数据比可以做到极高（同一批真实数据被反复用来生成想象轨迹），因此在小数据场景下样本效率远高于无模型方法。

但这条路线也把上一节的第二个代价推到了极端。上一节我们看到：规划器的乐观间隙随 H 增长——因为 argmax 会主动挑选模型的误差。策略训练是比 argmax 更强的最大化过程：它不只在动作空间里搜一遍，而是用成千上万次梯度更新去搜。于是"策略找到并利用模型误差"不是可能的副作用，而是优化的必然结果。

这一节要回答四件事：

  1. 想象训练与在线规划的结构差别是什么：决策成本从 O(BH) 变成 O(1)，代价转移到了哪里？
  2. 梯度怎么穿过动力学：解析伴随递推怎么写，为什么它比得分函数估计器方差低、比有限差分便宜；以及一个具体的工程纪律——手写梯度必须用中心差分自检（本课实测：修掉一个极易漏的项之前相对误差 0.60，之后 2.9×10−10）。
  3. 模型误差如何被策略利用：把它写成"误差在策略诱导分布上的积分"，说明为什么这个积分会被最大化；并用本课代码量出来（想象回报从 −27.052 涨到 −7.190，真实回报同时从 −44.02 掉到 −59.41，乐观间隙从 16.97 涨到 52.22）。
  4. 保守化手段清单与真实代价：集成惩罚、KL 信任域、短 rollout，各自买什么、付什么；并诚实报告一条负面结果——短视界在这个任务里没有救回来，因为误差区在 3 步之内就可达。

三条结论先放在这里：

① 想象训练把"决策成本"换成了"模型误差的直接暴露"。 在线规划每次决策只用模型评价 B⋅H 条轨迹；想象训练则用模型生成任意多的训练数据，直到策略在模型里接近最优。于是模型误差不再是被"偶尔采到"，而是被系统性地搜索出来。本课表 A 是它的教科书形态：想象回报单调改善，真实回报单调恶化，两者的间隙（乐观间隙）从 16.97 涨到 52.22。 ② 保守化的所有手段本质是同一件事：限制策略的可达集合。 集成惩罚限制"去不确定区域"、KL 限制"偏离行为策略"、短 rollout 限制"看多远"、混合真实数据限制"模型主导的比例"。它们的差别只在限制的形状，代价都是想象回报下降（本课：无保守化想象 −6.602，集成惩罚 λ=20 时 −9.166，λ=100 时 −11.322）。"保守"不是一个开关，是一条曲线，要选点。 ③ 手写梯度的正确性不是"大概对"，而是必须自检到 10−9 量级。 本课代码在实现伴随递推时漏掉了一项（策略对状态的依赖在状态伴随中的传播），有限差分立刻把相对误差 0.60 抓了出来；补上后是 2.9×10−10。这一项在多步 rollout 里才出现，所以只在 H=1 上测梯度测不出来——这正是"想象训练"的代码最容易静默错的地方。

定位提醒：本节讨论的是给定一个模型，怎么把策略训在它里面。模型怎么学（第 2 章）、不确定性怎么估（第 2 章第 3 节）、什么时候干脆不该用模型（第 4 节）都不在这里。本节代码里的模型是用同一份数据、同一套特征拟合的集成，因此对比的差别只来自"怎么用这个模型"。

一、两种用法：在线规划 vs 想象训练#

把上一节与本节的做法放在一起，结构差别非常清楚：

在线规划（第 1 节） 想象训练（本节）
训练期做什么 学模型（+ 可选的终端价值） 学模型 + 在模型里学策略
每次决策的成本 O(BH) 次模型 rollout + 一次前向 一次策略前向 O(1)
模型被使用的方式 被"查询" BH 次，用于比较动作 被"展开" ∑iter​BH 次，用于产生梯度
策略改进的机制 每次决策重新搜索 训练期累积改进
误差暴露方式 偶发（采样到误差区） 系统性（优化去找误差区）
主要失效模式 视界过大 → 乐观间隙（第 1 节） 策略主动利用模型误差（本节 §3）
适合场景 低频决策、不可微模型、离散动作 高频决策、连续高维动作、可微模型

为什么这样设计（把搜索摊薄）：设在线规划每次决策要 M 次 rollout、一天要做 D 次决策，总成本是 M⋅D。想象训练的总成本是训练期的 Mtrain​（通常远大于单次 M，但只付一次），部署期是 D 次前向（极便宜）。所以当

Mtrain​+D⋅Cforward​ ≪ M⋅D

时，想象训练在总算力上胜出。这就是它成为主流的经济学理由——不是"更准"，而是"更便宜"。

代价转移到哪里：转移到目标函数上。在线规划的目标是"这一条轨迹上模型说的回报"；想象训练的目标是"在模型生成的状态分布上的期望回报"。后者的样本量由训练轮数决定，可以无限增大，因此策略会一直优化到模型误差成为唯一障碍为止。换句话说：

在线规划"没有时间去利用模型的每个误差"；想象训练"有时间把模型的每个误差都利用一遍"。

本节剩下的部分就在处理这件事。

二、梯度怎么穿过动力学#

2.1 目标与三种梯度估计#

设模型 s^t+1​=fϕ​(s^t​,at​)（确定性版；随机版把采样写成重参数化）、策略 at​=πθ​(s^t​)，想象目标

J(θ)=Es^0​​[t=0∑H−1​γtr(fϕ​(s^t​,πθ​(s^t​)),πθ​(s^t​))].

要 ∇θ​J，有三类估计：

方法 形式 方差 偏差 需要什么
解析伴随（BPTT） 沿 rollout 反传 低（无采样噪声） 无（给定模型） 模型可微；O(H) 内存
得分函数 / REINFORCE E[∑t​∇θ​logπθ​(at​)R^t​] 高（随 H 增长） 无 只需策略可微
有限差分 (J(θ+ϵei​)−J(θ−ϵei​))/2ϵ 中 O(ϵ2) 参数量小

为什么优先解析伴随：它的方差来自"模型/初始状态的采样"，不随 H 指数增长；得分函数估计器的方差随 H 增长，在长想象里需要大量样本。代价是：模型必须可微，且必须能手写（或自动微分）正确地穿过 H 步递推。

2.2 伴随递推：容易漏的那一项#

把 J 的依赖关系写清楚是全部关键。记

μt​ ≡ ∂s^t+1​∂J​(从第 t 步以后看，s^t+1​ 的总影响),λt​ ≡ ∂s^t​∂J​.

从最后一步往回推：

μt​=γt∂s^t+1​∂rt​​+λt+1​, ∂at​∂J​=μt​∂a∂fϕ​​+γt∂a∂rt​​ ​,λt​=μt​∂s^∂fϕ​​+容易漏∂s^t​∂at​​⋅∂at​∂J​​​+γt∂s^t​∂rt​​​直接​.

那个被框起来的、以及那个标了"容易漏"的项，就是本节的第一个工程要点。

  • ∂J/∂at​ 里必须包含通过未来状态传回来的那一部分（μt​∂f/∂a），否则梯度只看见"这一步的即时奖励"。
  • λt​ 里必须包含策略对状态依赖的传播项 ∂s^t​∂at​​∂at​∂J​。漏掉它，H=1 时梯度仍然正确（因为没有下一步要用到 λt​），但 H≥2 就开始偏。

本课代码的真实记录：第一次实现时漏了 λt​ 里的那一项，中心差分立刻抓到：

[修掉之前] 梯度自检 λ=0.0 β=0.0: 解析 [ 4.60164 -6.55998] 差分 [ 3.25951 -4.09954] → 最大相对误差 6.00e-01
[修掉之后] 梯度自检 λ=0.0 β=0.0: 解析 [ 3.25951 -4.09954] 差分 [ 3.25951 -4.09954] → 最大相对误差 2.89e-10

这就是为什么"必须自检"不是形式主义：这个错误不会让训练崩掉——它给出一个方向大致正确、幅度偏大 40% 的梯度，训练照样"看起来在收敛"，只是收敛到一个更糟的策略。而它只在 H≥2 时出现。

附加的一条：如果目标里还有别的项（本课的集成惩罚 λσ 与 KL 惩罚 β(at​−π0​)2），它们对 s^t​ 与 at​ 的直接偏导也必须加进 ∂rt​/∂s^t​ 与 ∂rt​/∂at​。本课代码把这两项一起写进 rt​ 再统一反传，因此四组 (λ,β) 组合的梯度自检全部通过：

2.3 怎么做：自检的可执行流程#

  1. 用中心差分，不要用前向差分（前向差分的截断误差是 O(ϵ)，中心是 O(ϵ2)；取 ϵ=10−6 时中心差分精度约 10−12，足够抓 10−9 的错）。
  2. 在 H>1 上测。本课的 bug 只在 H≥2 出现；只测 H=1 会给出"梯度正确"的假结论。
  3. 对每个目标项都测一遍：关掉所有正则项测一次（隔离核心递推），再逐项打开测一次。本课的四组配置就是这个流程。
  4. 用同一组输入（同一初始状态、同一参数），并且固定随机种子。
  5. 判据：最大相对误差 <10−6 可接受；10−9 量级说明实现与差分都健康。不要把"梯度范数变小了"当成正确。

2.4 取舍与边界#

边界 后果 应对
模型不可微（接触、离散、外部仿真器） 解析伴随不可用 得分函数 / 有限差分 / 学习一个可微代理（第 3 章第 3 节的"可交互"要求）
H 很大 梯度爆炸/消失；内存 O(H) 截断 BPTT、梯度裁剪、短 rollout + 价值自举（Dreamer 的做法）
模型随机（隐变量） 需要重参数化或得分函数 重参数化（连续隐变量）或 Gumbel/直通（离散）
梯度正确 只保证你优化的是"模型内的目标" 与"学到好策略"是两件事——见 §3

第 4 条是本节最重要的一条边界：梯度自检通过 = 训练有效。它只保证你没有在实现上出错；它完全不保证"模型内的最优"在真实环境里也是好的。这正是下一小节的主题。

三、模型误差如何被策略利用#

3.1 把误差写成"在策略诱导分布上的积分"#

设有真实回报 Jreal​(θ) 与模型回报 Jmodel​(θ)。定义在策略 πθ​ 诱导的状态分布 dπθ​ 上的模型误差

Δ(θ)=Es^∼dπθ​​[(Jreal​−Jmodel​)(s^)],Jreal​(θ)=Jmodel​(θ)−Δ(θ).

训练做的事是

θ⋆=argθmax​Jmodel​(θ) ⟹ Jreal​(θ⋆)=训练让它变大θmax​Jmodel​(θ)​​−Δ(θ⋆).

关键在于 Δ(θ) 不是常数：它依赖策略诱导的分布。而 argmax 做的事就是选择让 Jmodel​ 最大的那个 θ——如果某个 θ 恰好把状态分布推到模型误差最大的区域，那么 Δ 会同时变大，而训练完全看不见这一点。

形式化的一句话：训练在最大化 Jmodel​，同时也在最大化 Δ（除非 Δ 与 Jmodel​ 恰好反相关）。这就是"对抗性利用"（adversarial exploitation）的准确含义——不是模型被攻击，而是策略与模型误差在做一场零和博弈，而策略拥有全部优化预算。

为什么叫"对抗性"：想象 Jmodel​=Jreal​+Δ。策略可以选择"提高 Jreal​"或"提高 Δ"。前者需要真的把任务做好（难），后者只需要走到模型不知道的地方去（容易）。在数据覆盖之外的区域，模型误差通常是结构与幅度都不可控的，于是后者的梯度往往更大、更平滑、更好走。

3.2 本课实验：一个"悬崖"#

代码把这件事做成一个可控实验：

  • 真实环境是一维状态 x，动作 a∈[−1,1]，x′=x+0.15a；但一旦 x′>0.5 就掉下悬崖（x←−1.5，单步奖励 −(x−1)2 立刻变成 −6.25）。
  • 行为数据 2400 条转移，状态范围 [−0.994, 0.270]——全部在悬崖左侧，一次都没有越过 0.5。
  • 模型是 5 个随机 tanh 特征网络组成的集成（32 个隐藏特征，各自 bootstrap），在数据上拟合 RMSE 1.1×10−5。
  • 策略是 a=tanh(w1​x+w2​)，用 §2 的解析梯度在想象里训练。

先看模型的"无知"是什么形状（这正是第 2 章第 3 节的 epistemic 不确定性）：

3.4 边界：什么时候"利用"不会发生#

把机制讲清楚之后，边界也清楚了。策略不会利用模型误差，当且仅当下列条件之一成立：

  1. 模型在策略诱导分布上足够准。 注意不是"在数据分布上准"。本课模型在数据分布上 RMSE 10−5，仍然被彻底利用——因为策略把分布推到了数据之外。
  2. 策略没有能力到达误差区。例如参数化太窄、动作幅度受限、或误差区在物理上不可达。
  3. 有真实数据在持续锚定。这正是第 4 节的 Dyna 式混合（真实数据更新与想象更新交替）为什么重要：它让 Jmodel​ 与 Jreal​ 保持耦合。
  4. 目标里显式惩罚了不确定区域。这就是下一小节的保守化手段。

反过来，下列情形一定发生（可以当成警告清单）：模型在某个可达区域外推、策略容量足够大、训练轮数足够多、且目标里没有任何与不确定性/行为数据相关的项。

四、保守化手段清单与各自的代价#

4.1 四类手段#

手段 机制 它限制的是什么 它买什么 它的代价
集成/认知惩罚 rt​←rt​−λσ(s^t​,at​) 策略的空间可达集合（不确定区域变贵） 让策略避开模型不知道的区域 惩罚项本身有偏（σ 不是误差）；λ 太大则寸步难行
KL / 信任域 rt​←rt​−β(at​−π0​(s^t​))2 策略的动作偏离程度 保证策略不会离行为数据太远 上限被行为策略封死：β 大就只能复现旧策略
短 rollout 减小 H 策略的时间可达集合 减少复合误差与优化的搜索深度 长程信用分配变难；本课实测不足以阻止利用
混合真实数据 每个真实样本配 k 次想象更新（Dyna） 模型的话语权比例 用真实数据持续纠偏 需要与环境持续交互（离线设定下不可用）

为什么说它们"本质是同一件事"：都在缩小策略能去的地方。差别只在用哪种坐标去限制（状态空间 / 动作空间 / 时间 / 数据来源），以及这个限制是否与真实的风险对齐。

集成惩罚 λ=20 −9.166 −10.99 0.000
集成惩罚 λ=100 −11.322 −14.12 0.000

KL 信任域 β=20 −14.935 −18.57 0.000
集成惩罚 λ=20 + KL β=2 −10.863 −13.24 0.000

五条读法，每一条都值得单独记住：

  1. 无保守化比行为策略还差 3 倍（−62.53 vs −19.98）。"在模型里训练"本身不会让你比数据里的策略更好——如果模型有可利用的误差，它可能让你更差。
  2. λ 的最优点是内部的：λ=2 完全无效（−62.52，与无保守化持平），λ=20 得到最好的真实回报（−10.99，比行为策略好 1.8 倍），λ=100 反而变差（−14.12）。三个点连起来是一条倒 U 形曲线：太小不生效，太大把有用的改进也压掉了。
  3. 短视界没有救回来（−62.87，与 H=20 的 −62.53 持平）。这是一个负面结果，也是本节最反直觉的一条：直觉上"看得短一点就不会走到悬崖"，但事实上悬崖在 3 步之内就可达——从起点 x≈0.3 用 3 步就能越过 0.5。短 rollout 只在"危险区域距离 > H 步"时才有效。
  4. KL 是"温和"的护栏：β=2 保留了 1/40 的掉崖步（1.000 次/回合）但真实回报 −20.30，几乎等于行为策略；β=20 完全无掉崖（0.000）但真实回报 −18.57，也几乎等于行为策略。也就是说 KL 能保安全，但它把上限钉死在行为策略附近。
  5. 集成惩罚 λ=20 是唯一"既安全又变好"的配置（0 次掉崖、−10.99）。原因值得说清：σ 在数据区是 0.004∼0.012、在悬崖处是 0.09 量级——它把"危险"变成了一个可微的、单调的信号，于是策略可以在"向右走"和"避开不确定区"之间找一个折中（平均位置停在 x≈0.45，而不是 0.318 或 −1.5）。

4.3 边界与工程建议#

  1. λ 必须扫，而且要扫到"看到倒 U 形"为止。 只试一个值不足以判断"保守化有没有用"——本课 λ=2 与 λ=20 相差 6 倍。
  2. σ 的标定依赖集成质量。 本课用的是随机特征集成的 bootstrap 分歧，它只反映"数据覆盖"，不反映"模型类的表达误差"。如果误差是结构性的（模型类错了），集成成员会一致地错，σ 不涨，惩罚失效。
  3. KL 适合"安全关键但不需要超越数据"的场景；想要超越行为策略，必须用与不确定性挂钩的惩罚（集成/密度模型/OOD 检测），而不是与动作偏离挂钩的惩罚。
  4. 短 rollout 要与"危险距离"对比才有效。判据：先用模型估计"从数据分布出发，多少步能到达不确定区"，再取 H 小于它。本课的答案是 3 步左右，所以 H=3 无效。
  5. 所有保守化都会降低想象回报。如果你只报告想象回报，会得出"保守化有害"的错误结论——必须同时报告真实闭环。这与第 1 节的"乐观间隙"是同一条纪律。

代码：想象训练、解析梯度、模型被利用与四种保守化#

下面的代码不调用任何 API，只依赖 numpy。它分成四段：

  • 数据与模型：在"悬崖"环境里用行为策略采 2400 条转移（全部在悬崖左侧）；用 5 个随机 tanh 特征网络的集成拟合动力学，并打印集成 σ 随 x 的增长。
  • 解析梯度：手写伴随递推（含集成惩罚与 KL 项），并用中心差分在四种 (λ,β) 组合上自检。
  • 表 A：纯想象训练的迭代曲线（想象回报 / 真实回报 / 乐观间隙 / 掉崖次数）。
  • 表 B/C：保守化手段对照，以及同一条策略的"想象轨迹 vs 真实轨迹"。

每一处注释写的是设计决策，不是实现细节；§2.2 提到的那一项在代码里被显式标注。

⚠️ 环境与数据全部为本代码合成，不代表任何真实数据集。

"""WM ch4-l2 演示：在模型里训练策略（手写反向传播）/ 模型误差被策略利用 / 保守化手段
环境与数据全部为合成数据（不代表任何真实数据集），只依赖 numpy。
"""
import numpy as np
rng = np.random.default_rng(0)

DT, GOAL, WALL, CLIFF, GAMMA, ALPHA = 0.15, 1.0, 0.5, -1.5, 0.97, 0.01

def step_true(x, a):
    """真实动力学 x'=x+DT*a；一旦越过 0.5 就掉下悬崖（回到 -1.5）。模型看不到悬崖。"""
    a = np.clip(a, -1.0, 1.0)
    fell = (x + DT*a) > WALL
    xn = np.where(fell, CLIFF, x + DT*a)
    return xn, -(xn - GOAL)**2 - ALPHA*a**2

def pi0(x):                                  # 行为策略：把状态稳在 0.25 附近，远离悬崖
    return np.clip(0.6*(0.25 - x) + 0.05, -1.0, 1.0)

# ---------- 1. 行为数据：只覆盖 x<0.3 的区域 ----------
XS, US, XNS = [], [], []
for _ in range(300):
    x = rng.uniform(-1.0, 0.2)
    for _ in range(8):
        a = float(np.clip(pi0(x) + rng.normal(0, 0.05), -1, 1))
        xn, _ = step_true(x, a)
        XS.append(float(x)); US.append(a); XNS.append(float(xn)); x = float(xn)
XS, US, XNS = np.array(XS), np.array(US), np.array(XNS)
XMAX = float(XS.max())
print(f"[0] 行为数据 {len(XS)} 条转移，状态范围 [{XS.min():.3f}, {XMAX:.3f}]（都在悬崖 {WALL} 左侧）")
print(f"    真实环境里 x>{WALL} 会掉到 {CLIFF}；这份数据里一次都没出现过 → 模型在那里只能外推")

# ---------- 2. 模型：K 个随机特征网络（各自随机基 + 最小二乘读出） ----------
K, M = 5, 32
Wx = rng.normal(0, 1.6, (K, M)); Wa = rng.normal(0, 1.6, (K, M)); B = rng.normal(0, 0.8, (K, M))
def phi(x, a):
    return np.tanh(x[:, None, None]*Wx[None] + a[:, None, None]*Wa[None] + B[None])
C = np.zeros((K, M))
for k in range(K):
    idx = rng.integers(0, len(XS), len(XS))              # bootstrap：每个成员看一份重采样数据
    R = phi(XS[idx], US[idx])[:, k, :]
    C[k] = np.linalg.solve(R.T@R + 1e-6*np.eye(M), R.T@XNS[idx])
def f_all(x, a):
    return np.einsum('nkm,km->nk', phi(x, a), C)
def fmean(x, a):
    return f_all(x, a).mean(1)
def dfk(x, a, W):
    p = phi(x, a)
    return (((1 - p**2)*W[None])*C[None]).sum(2)
def df_dx(x, a):
    return dfk(x, a, Wx).mean(1)
def df_da(x, a):
    return dfk(x, a, Wa).mean(1)
def dvar_dx(x, a):
    f = f_all(x, a)
    return 2*np.mean((f - f.mean(1, keepdims=True))*dfk(x, a, Wx), axis=1)
def dvar_da(x, a):
    f = f_all(x, a)
    return 2*np.mean((f - f.mean(1, keepdims=True))*dfk(x, a, Wa), axis=1)
def sigma(x, a):
    return np.sqrt(f_all(x, a).var(1) + 1e-12)
print(f"[1] 集成 {K} 成员 x {M} 随机 tanh 特征；在数据上的拟合 RMSE = "
      f"{np.sqrt(np.mean((fmean(XS, US)-XNS)**2)):.6f}")
print("    x     | 模型预测x'(a=0.5) | 真实x'(a=0.5) | 集成 sigma")
for xv in (0.2, 0.3, 0.4, 0.5, 0.7, 1.0):
    xa, aa = np.array([xv]), np.array([0.5])
    print(f"    {xv:>4.2f} | {float(fmean(xa,aa)[0]):>16.4f} | "
          f"{float(step_true(xa,aa)[0][0]):>12.4f} | {float(sigma(xa,aa)[0]):>8.4f}")

# ---------- 3. 解析梯度：想象 rollout 的反向传播 ----------
def dpi0(x):                                     # π0 的导数（clip 之外为 0）
    return np.where(np.abs(0.6*(0.25 - x) + 0.05) <= 1.0, -0.6, 0.0)

def imagine(w, x0, H, lam, beta):
    """返回 (平均想象回报, 对 (w1,w2) 的梯度)。集成惩罚 σ 与 KL 信任域都写进回报里。"""
    x = [x0.copy()]; a = []; sg = []
    for t in range(H):
        at = np.tanh(w[0]*x[-1] + w[1]); a.append(at); sg.append(sigma(x[-1], at))
        x.append(fmean(x[-1], at))
    J = np.zeros_like(x0); dw1 = np.zeros_like(x0); dw2 = np.zeros_like(x0); gx = np.zeros_like(x0)
    for t in range(H-1, -1, -1):
        g = GAMMA**t; s = x[t+1]
        kl = a[t] - pi0(x[t])
        r = -(s - GOAL)**2 - ALPHA*a[t]**2 - lam*sg[t] - beta*kl**2
        dr_ds = -2*(s - GOAL)
        dr_dx = -lam*dvar_dx(x[t], a[t])/(2*sg[t]) + 2*beta*kl*dpi0(x[t])
        dr_da = -2*ALPHA*a[t] - lam*dvar_da(x[t], a[t])/(2*sg[t]) - 2*beta*kl
        J += g*r
        gs = gx + g*dr_ds
        dadt = 1 - a[t]**2
        ga = gs*df_da(x[t], a[t]) + g*dr_da
        dw1 += ga*dadt*x[t]; dw2 += ga*dadt
        gx = gs*df_dx(x[t], a[t]) + dadt*w[0]*ga + g*dr_dx   # 别漏掉 a_t 对 x_t 的依赖
    return J.mean(), np.array([dw1.mean(), dw2.mean()])

w_test = np.array([0.8, 0.1]); x0t = rng.uniform(-1.0, 0.2, 8)
for lam, beta in ((0.0, 0.0), (0.5, 0.0), (0.0, 2.0), (0.5, 2.0)):
    _, gan = imagine(w_test, x0t, 6, lam, beta)
    fd = []
    for i in range(2):
        wp, wm = w_test.copy(), w_test.copy(); wp[i] += 1e-6; wm[i] -= 1e-6
        fd.append((imagine(wp, x0t, 6, lam, beta)[0] - imagine(wm, x0t, 6, lam, beta)[0])/2e-6)
    fd = np.array(fd)
    print(f"[2] 梯度自检 λ={lam} β={beta}: 解析 {np.round(gan,5)} 差分 {np.round(fd,5)} "
          f"→ 最大相对误差 {np.max(np.abs(gan-fd)/np.maximum(1e-8, np.abs(fd))):.2e}")

# ---------- 4. 训练（Adam 上升）与评估（批量闭环） ----------
def train(H, lam, beta, iters=300, B=64, lr=0.05, seed=0):
    r = np.random.default_rng(seed); w = np.array([0.05, 0.05]); m = np.zeros(2); v = np.zeros(2)
    for it in range(1, iters+1):
        _, g = imagine(w, r.uniform(XS.min(), XMAX, B), H, lam, beta)
        m = 0.9*m + 0.1*g; v = 0.999*v + 0.001*g**2
        w = w + lr*(m/(1-0.9**it))/(np.sqrt(v/(1-0.999**it)) + 1e-8)
    return w

def eval_real(w, n=200, steps=40, seed=1, policy=None):
    r = np.random.default_rng(seed); x = r.uniform(XS.min(), XMAX, n)
    tot = np.zeros(n); g = 1.0; falls = np.zeros(n); mx = x.copy()
    for _ in range(steps):
        a = pi0(x) if policy == 'pi0' else np.tanh(w[0]*x + w[1])
        fell = (x + DT*np.clip(a, -1, 1)) > WALL
        falls += fell
        xn = np.where(fell, CLIFF, x + DT*np.clip(a, -1, 1))
        tot += g*(-(xn - GOAL)**2 - ALPHA*np.clip(a, -1, 1)**2); g *= GAMMA
        x = xn; mx = np.maximum(mx, x)
    return float(tot.mean()), float(falls.mean()), float(x.mean()), float(mx.max())

def eval_imag(w, H=20, n=400, seed=2):
    r = np.random.default_rng(seed); x = r.uniform(XS.min(), XMAX, n); tot = np.zeros(n); g = 1.0
    for _ in range(H):
        x = fmean(x, np.tanh(w[0]*x + w[1])); tot += g*(-(x - GOAL)**2); g *= GAMMA
    return float(tot.mean())

print("\n[表 A] 纯想象训练（无保守化）：想象回报涨、真实回报掉")
print("   迭代 | 想象回报(H=20) | 真实回报 | 乐观间隙 | 平均掉崖次数/回合")
w = np.array([0.05, 0.05])
for it in (0, 20, 40, 60, 100, 200):
    if it:
        w = train(20, 0.0, 0.0, iters=20 if it <= 60 else 40, seed=it)
    ir = eval_imag(w); rr, ff, _, _ = eval_real(w)
    print(f"   {it:>4} | {ir:>14.3f} | {rr:>8.2f} | {ir-rr:>8.2f} | {ff:>16.3f}")

print("\n[表 B] 保守化手段对照（同一份数据 / 同一集成 / 同一 300 步预算）")
b = eval_real(None, policy='pi0')
print(f"   参照·行为策略 π0          | {'—':>8} | {b[0]:>8.2f} | {b[1]:>16.3f}"
      f"   （平均位置 {b[2]:.3f}）")
print("   配置                     | 想象回报 | 真实回报 | 平均掉崖次数/回合")
for name, (H, lam, beta) in (("无保守化 H=20", (20, 0, 0)),
                             ("短视界 H=3", (3, 0, 0)),
                             ("集成惩罚 λ=2", (20, 2.0, 0)),
                             ("集成惩罚 λ=20", (20, 20.0, 0)),
                             ("集成惩罚 λ=100", (20, 100.0, 0)),
                             ("KL 信任域 β=2", (20, 0.0, 2.0)),
                             ("KL 信任域 β=20", (20, 0.0, 20.0)),
                             ("集成惩罚 λ=20 + KL β=2", (20, 20.0, 2.0))):
    wt = train(H, lam, beta, iters=300, seed=7)
    rr, ff, _, _ = eval_real(wt)
    print(f"   {name:24} | {eval_imag(wt):>8.3f} | {rr:>8.2f} | {ff:>16.3f}")

print("\n[表 C] 同一条策略：想象轨迹 vs 真实轨迹（无保守化）")
wt = train(20, 0.0, 0.0, iters=300, seed=7)
xs, xi = 0.3, 0.3
print("   t | 想象 x | 真实 x | 模型 sigma")
for t in range(9):
    a = float(np.tanh(wt[0]*xs + wt[1])); xn, _ = step_true(np.array([xs]), np.array([a]))
    ai = float(np.tanh(wt[0]*xi + wt[1]))
    sg = float(sigma(np.array([xi]), np.array([ai]))[0])
    xi = float(fmean(np.array([xi]), np.array([ai]))[0]); xs = float(xn[0])
    print(f"   {t:>1} | {xi:>6.3f} | {xs:>6.3f} | {sg:>8.4f}")

   8 |  0.760 | -0.453 |   0.0526

这段代码想让你看到的六件事：

  1. 模型在数据区内极准、在悬崖处自信外推。 [0]/[1] 段：数据止于 x=0.270，拟合 RMSE 1.1×10−5；而 x=0.5 时模型预测 0.5592、真实是 −1.5000，集成 σ 从 0.0043 涨到 0.0917。"不确定性存在"不等于"不确定性被用上"——这就是第 2 章第 3 节说的那件事在想象训练里的形态。
  2. 梯度自检抓出了一个真实的手写错误。 [2] 段四组配置全部到 10−9∼10−10；§2.2 给出了修掉那一项之前的输出（相对误差 0.60）。这个错误只在 H≥2 出现，因此"在 H=1 上测梯度"是无效的安全检查。
  3. 想象回报与真实回报同时朝相反方向走。 表 A：想象 −27.052→−7.190（改善 73%），真实 −44.02→−59.41（恶化 35%），乐观间隙 16.97→52.22。这不是训练不稳定，是策略找到了模型误差并住在了里面。
  4. 轨迹层面一眼可见。 表 C：第 0 步两条轨迹都在 0.42 附近，第 1 步想象到 0.507、真实到 −1.500。之后想象一路向目标（0.760），真实在悬崖底爬（−0.453）。
  5. 保守化是一条倒 U 形曲线，不是一个开关。 表 B：集成惩罚 λ=2（−62.52）≈ 无保守化（−62.53）；λ=20 最好（−10.99，且 0 次掉崖）；λ=100 变差（−14.12）。同时想象回报从 −6.602 降到 −11.322——真实回报的改善是用想象回报买的。
  6. 两条负面/边界结果：短视界 H=3 没有救回来（−62.87），因为悬崖在 3 步内可达；KL 信任域能保证安全但把上限钉在行为策略附近（β=20：0 掉崖、−18.57，而行为策略是 −19.98）。

⚠️ 诚实说明这个实验的边界：状态是一维、动力学是线性、危险区是一个固定的阈值、模型是随机特征集成（它捕捉的是数据覆盖型不确定性，不是模型类误差）。因此本课证明的是机制（Jreal​=Jmodel​−Δ 且 Δ 被最大化）与手段的相对形状（λ 的倒 U、短视界的失效条件、KL 的上限），不是任何具体系统的水平。特别地：如果模型误差是结构性的（模型类本身错了），集成成员的 σ 会一致地小，本课的集成惩罚会失效——那时需要的是换模型类或混合真实数据（下一节与第 4 节）。

练习#

  1. 补全并验证伴随递推。 在不看 §2.2 的情况下自己推一遍 ∂J/∂θ（含 H=3 的展开），然后对照本节公式找出你漏了哪些项。用 H∈{1,2,3,8} 各做一次中心差分自检，报告哪些 H 能暴露"漏项"错误。
  2. 把积分形式写成可测的量。 对 §3.1 的 Δ(θ) 给出一个可估计的版本（提示：用同一批初始状态、同一策略，分别在模型与真实环境里 rollout，取回报差的均值）。在你自己的实验里测出 Δ 随训练迭代的曲线，并检验"Δ 单调递增"这个论断在什么条件下不成立。
  3. 制造"σ 失效"的场景。 构造一个模型类系统性错误的世界（例如真实动力学含一个模型类完全不含的项），使集成成员一致地错。重跑表 B，说明集成惩罚为什么失效、以及此时应该用什么替代（提示：混合真实数据、密度模型 OOD 检测）。
  4. 短视界的失效条件。 在本课环境里定义"危险距离" d（从数据分布支撑的边界到危险区的步数）。把 H 取在 d 的两侧各跑一次，验证"H<d 时短视界有效、H≥d 时无效"。然后把这个判据写成一条可执行的工程规则（需要先测什么量）。
  5. KL 的上限实验。 用 β 从 0 扫到 100，画出"真实回报 vs β"与"策略与行为策略的动作平均偏离 vs β"。证明：当 β→∞ 时真实回报收敛到行为策略的回报；并给出反例说明"KL 上限"不是绝对的上限（提示：如果行为策略在某状态下不可达，KL 约束可能让策略在该状态下任意行动）。
  6. λ 的自适应。 把固定的 λ 换成一个自适应规则（例如：根据最近若干回合的"掉崖/超界比例"调整 λ，或按 σ 的分位数归一化）。对比自适应与最优固定 λ 的真实回报，并说明自适应的代价（引入新的超参、非平稳性）。
  7. 讨论题（有唯一答案）。 有人说："想象训练之所以被利用，是因为模型不够好；把模型做到足够准就行。"请给出至少三条反驳，每条都要落到可观测的失败上（提示：模型类误差不随数据消失；危险区可能是无限薄的集合，任何有限精度的模型都会在那儿出错；策略是最大化过程，会主动找最薄的地方）。

小结#

  • 想象训练的本质是把在线搜索摊薄到训练里：决策成本从 O(BH) 降到 O(1)，代价是模型误差会被系统性地搜索并利用。当 Mtrain​+D⋅Cforward​≪M⋅D 时它在总算力上胜出——这是它成为主流的理由，不是"更准"。
  • 梯度穿过动力学用手写伴随递推：∂J/∂at​=μt​∂f/∂a+γt∂rt​/∂a，λt​=μt​∂f/∂s^+∂s^t​∂at​​∂at​∂J​+γt∂rt​/∂s^​直接​。最后那个"策略对状态依赖"的项极易漏，而且只在 H≥2 暴露。本课修前相对误差 0.60，修后 2.89×10−10；四组 (λ,β) 配置全部通过。
  • 模型误差被利用是优化的必然，不是 bug：Jreal​=Jmodel​−Δ(θ)，而 θ⋆=argmaxJmodel​ 同时也在推高 Δ。本课把它量成乐观间隙：16.97→52.22，同时想象回报 −27.052→−7.190、真实回报 −44.02→−59.41。
  • 保守化手段本质是"限制策略的可达集合"：集成惩罚限制空间、KL 限制动作、短 rollout 限制时间、混合真实数据限制模型话语权。本课实测：λ 的最优点是内部的（λ=2 无效、λ=20 最好 −10.99、λ=100 变差 −14.12）；短视界 H=3 无效（危险距 3 步内可达）；KL 能保安全但把上限钉在行为策略附近。
  • 验收清单必须包含"在真实环境跑一次策略"。其余五个诊断量（梯度自检、乐观间隙、状态分布重叠、σ 对分布的响应、保守化参数形状）都可以从训练日志里得到，但没有一个能替代真实闭环。
  • 本节留下的接口：本课的集成惩罚之所以有效，是因为 σ 恰好在危险区变大。如果 σ 的形状与危险不重合，惩罚就会失效。 那就需要把"风险"直接写进规划目标——乐观、悲观、CVaR、分位数各管什么、什么时候用哪个，是下一节的主题。

下一节：wm-ch4-l3。这一节我们用"集成惩罚"把不确定性塞进了回报，但没有问"惩罚的形式对不对"。下一节要把这件事做完整：aleatoric 与 epistemic 在规划里对应两个不同的算子（前者是结果分布上的 CVaR / 分位数，后者是模型集合上的 min/max），它们的组合不是"均值减 λ 倍标准差"这么简单。我们会看到：同一个模型、同一组候选路线，只换规划目标就换一条路线——期望回报选了雷区（真实均值 −0.583、踩雷率 0.35），悲观/CVaR 选了安全路线（真实均值 0.524），而"均值 − σ_total"选了一条过度保守的远路。还会补上 exploring 的那一半：乐观目标为什么会去试未知区域、代价是多少、以及"风险目标不会创造信息"这条最硬的边界。
