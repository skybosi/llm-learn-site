项目：实现一个能编译小型语言并正确运行全部用例的编译器#

"每章都能讲清"和"能连起来跑"是两件事。前面的课时分别交付了扫描器、递归下降、符号表、IR、优化和后端知识，但它们从未在同一个程序里共存过。本课把它们装成一台完整的编译器：不到 500 行的单文件实现，支持 let、赋值、if/else、while、函数（含递归）与 print，编译到栈式字节码并在虚拟机上运行——8 个用例全部通过，并且必须在优化前后输出完全一致。

一、概念讲解#

1. 先定验收口径，再写代码#

# 用例 考什么
1 算术与优先级 2+3*4、括号、整除与取余
2 let 与赋值 变量声明与重新赋值
3 if/else 走 else 分支
4 while 求和 1..10 循环 + 条件跳转回填
5 函数与参数 调用协议、参数压栈、返回值
6 递归 fib(10) 帧栈、递归调用
7 常量折叠生效 优化改变指令数但不改变输出
8 常量条件剪枝 if (1<2) 被编译期判定

三条硬指标：功能（8/8 输出逐行一致）、一致性（同一用例"不优化"与"优化后"输出必须完全相同，这是第 5 章正确性要求在项目里的最小形式）、报错（未定义变量在编译期拦下并给出名字，除以 0 在运行期报错）。任何一条不满足，项目就不算完成。

2. 语言规格与"故意不支持"的边界#

program := { fn | stmt }
fn      := 'fn' NAME '(' [NAME {',' NAME}] ')' block
stmt    := 'let' NAME '=' expr ';' | NAME '=' expr ';'
         | 'if' '(' expr ')' block ['else' block] | 'while' '(' expr ')' block
         | 'return' [expr] ';' | 'print' '(' expr ')' ';' | expr ';'
expr    := cmp ;  cmp := add {('<'|'<='|'>'|'>='|'=='|'!=') add}
add     := mul {('+'|'-') mul} ;  mul := unary {('*'|'/'|'%') unary}
unary   := '-' unary | primary
primary := NUMBER | NAME | NAME '(' [expr {',' expr}] ')' | '(' expr ')'

明确不支持：浮点、字符串、数组、闭包、块级作用域（同一函数内同名变量共用一个槽位）、短路求值。边界写出来是为了让"这是 bug 吗"有答案——第 2 章的错误恢复在本项目里退化成"报第一个错就停"。

3. 五段流水线，每一段都能指回前面某章#

scan（第 2 章：正则手写扫描器，带行号）→ parse（第 2 章：递归下降 + 优先级爬升）→ resolve（第 3 章：名字绑定）→ codegen（第 4 章：IR 思路 + 第 6 章栈式机器模型）→ VM（执行）。两个设计决定值得记住：

  • 绑定槽位而不是名字：符号表把每个变量映射成帧内下标，运行时只做 slots[i] 数组访问，没有字典查找。
  • 编译成字节码而不是边走 AST 边算：AST 只需走一遍生成代码，之后同一份字节码可以被执行任意多次——这正是"编译"与"解释"的分界。

4. 指令集#

指令 语义 指令 语义
CONST k 压入常量 JMP a 跳到 a
LOAD s 压入槽位 s JZ a 弹出，为 0 则跳 a
STORE s 弹出并写入槽位 s CALL f n 调 f，n 个参数
ADD..NE 弹出两个、压入结果 RET 弹出返回值并退栈
NEG 取负 PRINT 弹出并打印
HALT 结束主程序

5. 三个最容易写错的地方（都实测踩过）#

  1. let 的求值顺序：本项目是"先算右值、再分配槽位"（self.gen(node[2]) 必须在 self.res.declare(node[1]) 之前）。顺序反了在这个语言里影响不大（同名变量复用同一槽位），但一旦引入块级作用域，{ let x = x + 1; } 就会先占住内层 x 的槽位再拿它当右值——经典的自引用 bug。
  2. 跳转回填：if/while 先发一条 JZ ? 占位，生成完分支再回填目标；while 末尾要 JMP 回到条件的位置而不是循环体开头。
  3. 优化不能改变可观察行为：本项目的常量折叠会把 1/0 从运行期错误提前成编译期错误——这是已知偏离，生产编译器必须保证"永不执行的代码不能导致编译失败"。另外整数除法要向零截断（C 语义），Python 的 // 是向下取整，负数上会不一致，必须自己写 idiv。

6. 做完之后还差什么#

错误恢复（第 2 章）、完整类型检查与隐式转换（第 3 章）、SSA 与数据流优化（第 4–5 章）、寄存器分配与指令调度（第 6 章——字节码 VM 恰好把这些都绕过去了）、真正的机器码生成（第 6 章）。把 Compiler 的出口从字节码换成 LLVM IR，这个项目就直接对接上了下一门课。

二、可运行代码示例#

单文件、纯 Python、无第三方依赖。CASES 里是 8 个用例（源码 + 期望输出），fold 是优化器，compile_source(src, optimize=...) 是统一入口——同一份源码分别走"不优化/优化"两条路，输出必须一致才算 PASS。

# ---- 项目：一个能编能跑的迷你编译器（扫描 → 解析 → 解析名字 → 字节码 → 栈式 VM）----
# 纯 Python，无第三方依赖。语言 "Mini" 支持：let / 赋值 / if-else / while / fn / return / print
# 算术 + - * / %、比较 < <= > >= == !=、函数调用（含递归）
import re
import unicodedata

# ============ 1. 词法 ============
TOKEN = re.compile(r'''(?P<space>\s+)|(?P<num>\d+)|(?P<name>[A-Za-z_]\w*)
|(?P<op>==|!=|<=|>=|[-+*/%<>=(){},;])''', re.X)
KEYWORDS = {'let', 'fn', 'if', 'else', 'while', 'return', 'print'}


def scan(src):
    """字符流 → token 流；带行号，供报错定位"""
    toks, i, line = [], 0, 1
    while i < len(src):
        m = TOKEN.match(src, i)
        if not m:
            raise SyntaxError(f'第 {line} 行：非法字符 {src[i]!r}')
        i = m.end()
        kind = m.lastgroup
        text = m.group()
        if kind == 'space':
            line += text.count('\n')
            continue
        if kind == 'name' and text in KEYWORDS:
            kind = text
        toks.append((kind, text, line))
    toks.append(('eof', '', line))
    return toks


# ============ 2. 语法（递归下降 + 优先级爬升）============
class Parser:
    def __init__(self, toks):
        self.toks, self.pos = toks, 0

    def peek(self):
        return self.toks[self.pos]

    def eat(self, kind, text=None):
        k, t, ln = self.peek()
        if k != kind or (text is not None and t != text):
            raise SyntaxError(f'第 {ln} 行：期望 {text or kind}，得到 {t or k!r}')
        self.pos += 1
        return t

    def program(self):
        fns, stmts = [], []
        while self.peek()[0] != 'eof':
            if self.peek()[0] == 'fn':
                fns.append(self.func())
            else:
                stmts.append(self.stmt())
        return ('program', fns, ('block', stmts))

    def func(self):
        self.eat('fn')
        name = self.eat('name')
        self.eat('op', '(')
        params = []
        if self.peek() != ('op', ')', self.peek()[2]):
            params.append(self.eat('name'))
            while self.peek()[0] == 'op' and self.peek()[1] == ',':
                self.eat('op', ','); params.append(self.eat('name'))
        self.eat('op', ')')
        return ('fn', name, params, self.block())

    def block(self):
        self.eat('op', '{')
        stmts = []
        while not (self.peek()[0] == 'op' and self.peek()[1] == '}'):
            stmts.append(self.stmt())
        self.eat('op', '}')
        return ('block', stmts)

    def stmt(self):
        k = self.peek()[0]
        if k == 'let':
            self.eat('let'); name = self.eat('name')
            self.eat('op', '='); e = self.expr(); self.eat('op', ';')
            return ('let', name, e)
        if k == 'if':
            self.eat('if'); self.eat('op', '('); c = self.expr(); self.eat('op', ')')
            then = self.block()
            els = None
            if self.peek()[0] == 'else':
                self.eat('else'); els = self.block()
            return ('if', c, then, els)
        if k == 'while':
            self.eat('while'); self.eat('op', '('); c = self.expr(); self.eat('op', ')')
            return ('while', c, self.block())
        if k == 'return':
            self.eat('return')
            e = None if self.peek()[1] == ';' else self.expr()
            self.eat('op', ';')
            return ('return', e)
        if k == 'print':
            self.eat('print'); self.eat('op', '('); e = self.expr(); self.eat('op', ')')
            self.eat('op', ';')
            return ('print', e)
        if k == 'name' and self.toks[self.pos + 1][1] == '=':
            name = self.eat('name'); self.eat('op', '=')
            e = self.expr(); self.eat('op', ';')
            return ('assign', name, e)
        e = self.expr(); self.eat('op', ';')
        return ('expr', e)

    def expr(self):
        return self.binop(self.add, ('<', '<=', '>', '>=', '==', '!='))

    def add(self):
        return self.binop(self.mul, ('+', '-'))

    def mul(self):
        return self.binop(self.unary, ('*', '/', '%'))

    def binop(self, sub, ops):
        node = sub()
        while self.peek()[0] == 'op' and self.peek()[1] in ops:
            op = self.eat('op'); node = ('bin', op, node, sub())
        return node

    def unary(self):
        if self.peek()[0] == 'op' and self.peek()[1] == '-':
            self.eat('op', '-')
            return ('un', '-', self.unary())
        return self.primary()

    def primary(self):
        k, t, ln = self.peek()
        if k == 'num':
            self.eat('num'); return ('num', int(t))
        if k == 'name':
            self.eat('name')
            if self.peek()[0] == 'op' and self.peek()[1] == '(':
                self.eat('op', '(')
                args = []
                if not (self.peek()[0] == 'op' and self.peek()[1] == ')'):
                    args.append(self.expr())
                    while self.peek()[1] == ',':
                        self.eat('op', ','); args.append(self.expr())
                self.eat('op', ')')
                return ('call', t, args)
            return ('var', t)
        if k == 'op' and t == '(':
            self.eat('op', '('); e = self.expr(); self.eat('op', ')'); return e
        raise SyntaxError(f'第 {ln} 行：表达式中意外的 {t or k!r}')


# ============ 3. 语义：查名与槽位分配（每个函数一张名字表）============
class Resolver:
    """把变量名绑到帧槽位；未定义的名字在编译期就报错（而不是运行时崩）"""
    def __init__(self):
        self.funcs = {}      # name -> (params, block)
        self.slots = {}      # 当前函数的 name -> slot
        self.nslots = 0

    def declare(self, name):
        if name not in self.slots:
            self.slots[name] = self.nslots
            self.nslots += 1
        return self.slots[name]

    def lookup(self, name):
        if name not in self.slots:
            raise NameError(f'未定义的变量 {name!r}')
        return self.slots[name]

    def walk(self, node):
        k = node[0]
        if k in ('num',):
            return
        if k == 'var':
            self.lookup(node[1])
        elif k == 'bin':
            self.walk(node[2]); self.walk(node[3])
        elif k == 'un':
            self.walk(node[2])
        elif k == 'call':
            if node[1] not in self.funcs:
                raise NameError(f'未定义的函数 {node[1]!r}')
            for a in node[2]:
                self.walk(a)
        elif k == 'let':
            self.walk(node[2]); self.declare(node[1])
        elif k == 'assign':
            self.lookup(node[1]); self.walk(node[2])
        elif k == 'if':
            self.walk(node[1]); self.walk_block(node[2])
            if node[3]:
                self.walk_block(node[3])
        elif k == 'while':
            self.walk(node[1]); self.walk_block(node[2])
        elif k == 'return':
            if node[1]:
                self.walk(node[1])
        elif k == 'print':
            self.walk(node[1])
        elif k == 'expr':
            self.walk(node[1])
        elif k == 'block':
            self.walk_block(node)
        else:
            raise TypeError(f'未知节点 {k}')

    def walk_block(self, block):
        for s in block[1]:
            self.walk(s)


# ============ 4. 优化：常量折叠 + 常量条件分支消除（第 5 章的正确性要求）============
def idiv(a, b):
    """C 语义的整数除法：向零截断"""
    if b == 0:
        raise ZeroDivisionError('除以 0')
    q = abs(a) // abs(b)
    return q if (a < 0) == (b < 0) else -q


def fold(node):
    k = node[0]
    if k in ('num', 'var'):
        return node
    if k == 'program':
        return ('program', [fold(f) for f in node[1]], fold(node[2]))
    if k == 'fn':
        return ('fn', node[1], node[2], fold(node[3]))
    if k == 'bin':
        l, r = fold(node[2]), fold(node[3])
        if l[0] == 'num' and r[0] == 'num':
            a, b, op = l[1], r[1], node[1]
            v = {'+': a + b, '-': a - b, '*': a * b,
                 '<': int(a < b), '<=': int(a <= b), '>': int(a > b), '>=': int(a >= b),
                 '==': int(a == b), '!=': int(a != b)}.get(op)
            if v is None:
                v = {'/': lambda: idiv(a, b), '%': lambda: a - idiv(a, b) * b}[op]()
            return ('num', v)
        return ('bin', node[1], l, r)
    if k == 'un':
        e = fold(node[2])
        return ('num', -e[1]) if e[0] == 'num' else ('un', '-', e)
    if k == 'call':
        return ('call', node[1], [fold(a) for a in node[2]])
    if k == 'let':
        return ('let', node[1], fold(node[2]))
    if k == 'assign':
        return ('assign', node[1], fold(node[2]))
    if k == 'print':
        return ('print', fold(node[1]))
    if k == 'expr':
        return ('expr', fold(node[1]))
    if k == 'return':
        return ('return', fold(node[1]) if node[1] else None)
    if k == 'block':
        return ('block', [fold(s) for s in node[1]])
    if k == 'if':
        c = fold(node[1])
        if c[0] == 'num':                       # 条件在编译期可判定 → 只留一条分支
            return fold(node[2] if c[1] != 0 else (node[3] or ('block', [])))
        return ('if', c, fold(node[2]), fold(node[3]) if node[3] else None)
    if k == 'while':
        c = fold(node[1])
        if c[0] == 'num' and c[1] == 0:         # while(0) 永远不会被执行
            return ('block', [])
        return ('while', c, fold(node[2]))
    raise TypeError(f'未知节点 {k}')


# ============ 5. 字节码生成 ============
BIN = {'+': 'ADD', '-': 'SUB', '*': 'MUL', '/': 'DIV', '%': 'MOD',
       '<': 'LT', '<=': 'LE', '>': 'GT', '>=': 'GE', '==': 'EQ', '!=': 'NE'}


class Code:
    def __init__(self, name, nparams, nslots):
        self.name, self.nparams, self.nslots, self.code = name, nparams, nslots, []

    def emit(self, *ins):
        self.code.append(ins)
        return len(self.code) - 1


class Compiler:
    def __init__(self, program):
        _, self.fns, self.main_stmts = program
        self.table = {}

    def compile(self):
        for f in self.fns:
            self.table[f[1]] = f                      # 先登记全部函数 → 支持前向调用与递归
        out = {}
        for _, name, params, body in self.fns:
            self.cur = Code(name, len(params), 0)
            self.res = Resolver()
            self.res.funcs = self.table
            for p in params:
                self.res.declare(p)
            self.gen(body)
            if not self.cur.code or self.cur.code[-1][0] != 'RET':
                self.cur.emit('CONST', 0); self.cur.emit('RET')  # 没写 return 时返回 0
            self.cur.nslots = self.res.nslots
            out[name] = self.cur
        self.cur = Code('<main>', 0, 0)
        self.res = Resolver()
        self.res.funcs = self.table
        self.gen(self.main_stmts)
        self.cur.emit('HALT')
        self.cur.nslots = self.res.nslots
        out['<main>'] = self.cur
        return out

    def gen(self, node):
        k = node[0]
        if k == 'num':
            self.cur.emit('CONST', node[1])
        elif k == 'var':
            self.cur.emit('LOAD', self.res.lookup(node[1]))
        elif k == 'bin':
            self.gen(node[2]); self.gen(node[3]); self.cur.emit(BIN[node[1]])
        elif k == 'un':
            self.gen(node[2]); self.cur.emit('NEG')
        elif k == 'call':
            for a in node[2]:
                self.gen(a)
            self.cur.emit('CALL', node[1], len(node[2]))
        elif k == 'let':
            self.gen(node[2])
            self.cur.emit('STORE', self.res.declare(node[1]))   # 先算值再占槽，顺序不能反
        elif k == 'assign':
            self.gen(node[2]); self.cur.emit('STORE', self.res.lookup(node[1]))
        elif k == 'print':
            self.gen(node[1]); self.cur.emit('PRINT')
        elif k == 'expr':
            self.gen(node[1])
        elif k == 'return':
            if node[1]:
                self.gen(node[1])
            else:
                self.cur.emit('CONST', 0)
            self.cur.emit('RET')
        elif k == 'if':
            self.gen(node[1])
            jz = self.cur.emit('JZ', None)
            self.gen(node[2])
            jmp = self.cur.emit('JMP', None)
            self.cur.code[jz] = ('JZ', len(self.cur.code))
            if node[3]:
                self.gen(node[3])
            self.cur.code[jmp] = ('JMP', len(self.cur.code))
        elif k == 'while':
            top = len(self.cur.code)
            self.gen(node[1])
            jz = self.cur.emit('JZ', None)
            self.gen(node[2])
            self.cur.emit('JMP', top)
            self.cur.code[jz] = ('JZ', len(self.cur.code))
        elif k == 'block':
            for s in node[1]:
                self.gen(s)
        elif k == 'fn':
            pass                                        # 函数体已在第一遍各自编译
        else:
            raise TypeError(f'未知节点 {k}')


# ============ 6. 栈式虚拟机 ============
class VM:
    def __init__(self, codes):
        self.codes = codes

    def run(self):
        out = []
        frames = [{'code': self.codes['<main>'], 'ip': 0, 'slots': [0] * self.codes['<main>'].nslots}]
        stack = []
        while frames:
            f = frames[-1]
            if f['ip'] >= len(f['code'].code):
                stack.append(0); frames.pop(); continue
            ins = f['code'].code[f['ip']]; f['ip'] += 1
            op = ins[0]
            if op == 'CONST':
                stack.append(ins[1])
            elif op == 'LOAD':
                stack.append(f['slots'][ins[1]])
            elif op == 'STORE':
                f['slots'][ins[1]] = stack.pop()
            elif op == 'NEG':
                stack.append(-stack.pop())
            elif op in ('ADD', 'SUB', 'MUL', 'DIV', 'MOD', 'LT', 'LE', 'GT', 'GE', 'EQ', 'NE'):
                b, a = stack.pop(), stack.pop()
                stack.append({'ADD': lambda: a + b, 'SUB': lambda: a - b, 'MUL': lambda: a * b,
                              'DIV': lambda: idiv(a, b), 'MOD': lambda: a - idiv(a, b) * b,
                              'LT': lambda: int(a < b), 'LE': lambda: int(a <= b),
                              'GT': lambda: int(a > b), 'GE': lambda: int(a >= b),
                              'EQ': lambda: int(a == b), 'NE': lambda: int(a != b)}[op]())
            elif op == 'PRINT':
                out.append(str(stack.pop()))
            elif op == 'JMP':
                f['ip'] = ins[1]
            elif op == 'JZ':
                if stack.pop() == 0:
                    f['ip'] = ins[1]
            elif op == 'CALL':
                name, argc = ins[1], ins[2]
                callee = self.codes[name]
                args = [stack.pop() for _ in range(argc)][::-1]
                slots = args + [0] * (callee.nslots - argc)
                frames.append({'code': callee, 'ip': 0, 'slots': slots})
            elif op == 'RET':
                v = stack.pop(); frames.pop(); stack.append(v)
            elif op == 'HALT':
                frames.pop()
            else:
                raise RuntimeError(f'未知指令 {op}')
        return out

CASES = [
    ('算术与优先级', 'print(2 + 3 * 4); print((2 + 3) * 4); print(20 / 3); print(20 % 3);',

    ('let 与赋值', 'let x = 1; x = x + 41; print(x);', ['42']),
    ('if/else 走 else', 'let x = 3; if (x > 10) { print(1); } else { print(0); }', ['0']),
    ('while 求和 1..10', 'let i = 1; let s = 0; while (i <= 10) { s = s + i; i = i + 1; } print(s);', ['55']),
    ('函数与参数', 'fn add(a, b) { return a + b; } print(add(2, 3)); print(add(add(1, 1), 5));', ['5', '7']),
    ('递归 fib(10)', 'fn fib(n) { if (n < 2) { return n; } return fib(n - 1) + fib(n - 2); } print(fib(10));',
     ['55']),
    ('常量折叠生效', 'let x = 2 * 3 + 4; print(x); print((1 + 2) * (3 + 4));', ['10', '21']),
    ('常量条件剪枝', 'if (1 < 2) { print(7); } else { print(0); } print(5 * 5);', ['7', '25']),
]


def compile_source(src, optimize=False):
    ast = Parser(scan(src)).program()
    if optimize:
        ast = fold(ast)
    codes = Compiler(ast).compile()
    ninstr = sum(len(c.code) for c in codes.values())
    return VM(codes), ninstr, codes


def dwidth(s):
    """显示宽度：中日韩全角字符算 2 列，否则对齐会歪"""
    return sum(2 if unicodedata.east_asian_width(ch) in 'WF' else 1 for ch in s)


def pad(s, n):
    return s + ' ' * max(0, n - dwidth(s))


def main():
    npass = 0
    print(pad('用例', 18) + pad('期望', 16) + pad('编译后', 16) + pad('优化后', 16)
          + pad('指令数(编/优)', 18) + '结果')
    for name, src, want in CASES:
        row = []
        for opt in (False, True):
            try:
                vm, n, _ = compile_source(src, optimize=opt)
                row.append((vm.run(), n))
            except Exception as e:                       # 编译期/运行期错误也要如实标出来
                row.append(([f'{type(e).__name__}: {e}'], -1))
        (got_u, n_u), (got_f, n_f) = row
        ok = got_u == want and got_f == want
        npass += ok
        print(pad(name, 18) + pad(','.join(want), 16) + pad(','.join(got_u), 16)
              + pad(','.join(got_f), 16) + pad(f'{n_u}/{n_f}', 18) + ('PASS' if ok else 'FAIL'))
    print(f'\n全部用例：{npass}/{len(CASES)} 通过（编译后与优化后都必须与期望一致）')

    print('\n--- 生成的字节码（while 求和，优化前）---')
    _, n, codes = compile_source(CASES[3][1])
    for i, ins in enumerate(codes['<main>'].code):
        print(f'  {i:>2}: {" ".join(str(x) for x in ins)}')
    print(f'  槽位：{codes["<main>"].nslots} 个，指令 {n} 条')

    print('\n--- 两类错误：编译期 vs 运行期 ---')
    try:
        compile_source('print(y);')                       # 名字没绑上 → 编译期就拦下
    except NameError as e:
        print(f'  编译期 NameError: {e}')
    try:
        vm, _, _ = compile_source('print(1 / 0);')        # 优化关闭：留到运行期才报
        vm.run()
    except ZeroDivisionError as e:
        print(f'  运行期 ZeroDivisionError: {e}')
    try:
        compile_source('print(1 / 0);', optimize=True)    # 优化开启：折叠时提前暴露
    except ZeroDivisionError as e:
        print(f'  优化期 ZeroDivisionError: {e}（折叠把一个运行期错误提前到了编译期，见正文"常见坑"）')


main()

三、练习#

  1. 实现：给语言加 break;。需要新增 BREAK 指令或在编译期回填跳出地址（后者更简单：维护一个"当前循环的跳出跳转待回填列表"），并用一个 while (1) { if (i > 3) { break; } i = i + 1; } 用例验证。
  2. 解释：为什么"先算右值、再分配槽位"对一个块级作用域语言会变得更复杂？如果允许 { let x = 1; } { let x = 2; } 复用同一个槽位，需要在什么时机释放槽位？
  3. 对比/验证：给优化器再加一条"强度削减"（x * 2 → x + x，见第 7 章第 1 课那个 LLVM pass），跑全部用例，确认 8/8 仍然通过、且指令数下降。如果某个用例不再通过，说明这条变换在什么前提下才成立？
  4. 思考：本项目 8/8 通过能证明编译器"正确"吗？请给出至少两个 8 个用例都覆盖不到的失败模式（提示：整数溢出、负数取余、深递归的栈深度、未定义行为）。
