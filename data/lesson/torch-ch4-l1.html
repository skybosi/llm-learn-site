Dataset#

前面三章我们学会了张量、自动微分和用 nn.Module 搭模型。但要真正训练一个模型，光有模型还不够——你得先把"一堆原始数据（图片、文本、数值）"变成模型能一口口吃进去的标准样本。这一课的主角是 PyTorch 的 Dataset：它是连接"杂乱原始数据"和"训练循环"的第一道关卡。

一、概念讲解#

1. Dataset 是什么：数据与模型之间的"统一接口"#

训练神经网络需要成百上千、甚至上百万个样本。如果每个样本的加载方式都不一样（有的是图片文件、有的是数据库记录、有的是内存里的数组），训练循环就没法写。PyTorch 用 torch.utils.data.Dataset 提供了一个统一约定：

只要你能回答两个问题——"总共有多少个样本"和"给我第 i 个样本"，你的数据就符合 Dataset 规范。

Dataset 是一个抽象基类，你继承它并实现两个方法：

  • __len__(self)：返回样本总数，len(dataset) 时被调用；
  • __getitem__(self, index)：给定下标 index，返回第 index 个样本（通常是一个 (输入, 标签) 元组，或一个字典）。

模型训练时不关心你的数据来自硬盘还是内存，只关心"按索引取样本"这个约定。这就是为什么把 MNIST 换成你自己的数据集时，训练循环几乎不用改。

2. 两种常见获取方式#

（1）现成数据集：torchvision.datasets 内置了 MNIST、CIFAR-10、FashionMNIST 等经典数据集。它们会自动下载、解压，并已经实现了 __len__ 和 __getitem__：

from torchvision import datasets

# root 指定存放目录，train=True 表示训练集，download=True 表示没有就自动下载
train_set = datasets.MNIST(root="./data", train=True, download=True)
print(len(train_set))       # 60000 张手写数字图
img, label = train_set[0]   # 第 0 张图（PIL 图像）和它的标签
print(label)                # 例如 5

（2）自定义 Dataset：真实项目里数据几乎都是你自己的。你只需继承 Dataset，在 __getitem__ 里完成"读取 + 预处理"，就能复用 PyTorch 整套数据流水线。

3. 一个最常用的"快捷方式"：TensorDataset#

如果你的数据本来就是内存里的张量（例如从 NumPy 转换而来），不需要写类。torch.utils.data.TensorDataset 能把多个张量"按第一维对齐"打包成一个 Dataset：

from torch.utils.data import TensorDataset
import torch

features = torch.randn(100, 4)   # 100 条样本，每条 4 个特征
labels = torch.randint(0, 2, (100,))  # 100 个二分类标签
dataset = TensorDataset(features, labels)
print(len(dataset))       # 100
print(dataset[7])         # (第7条特征张量, 第7个标签)

二、可运行代码示例#

下面完整实现一个自定义 Dataset：数据是"二次函数带噪声"的数值对 (x, y)，其中 y = 2x² - 3x + 1 + 噪声。这个例子不依赖任何外部文件，直接就能跑，重点体会 __len__ 与 __getitem__ 的写法。

import torch
from torch.utils.data import Dataset, TensorDataset, DataLoader


# 1) 自定义 Dataset：生成 y = 2x^2 - 3x + 1 的带噪声样本
class ParabolaDataset(Dataset):
    """把 (x, y) 数值对封装成标准 Dataset。

    每个样本：输入 x（1 维张量），标签 y（0 维张量，即标量）。
    """

    def __init__(self, n=200, noise=0.2):
        super().__init__()
        # 在 [-3, 3] 区间均匀取 n 个点作为输入
        self.x = torch.linspace(-3, 3, steps=n).unsqueeze(1)
        # 真实值 y = 2x^2 - 3x + 1，再加一点随机噪声
        self.y = 2 * self.x ** 2 - 3 * self.x + 1
        self.y = self.y + noise * torch.randn_like(self.y)

    def __len__(self):
        """样本总数。"""
        return len(self.x)

    def __getitem__(self, index):
        """返回第 index 个样本：输入 x 与标签 y。"""
        return self.x[index], self.y[index]


# 2) 使用自定义 Dataset
ds = ParabolaDataset(n=200)
print("样本总数：", len(ds))

sample_x, sample_y = ds[0]   # 取第一个样本
print("第 0 个样本的输入形状：", sample_x.shape, "标签值：", sample_y.item())

# 3) 用 TensorDataset 快速打包现成张量
features = torch.randn(50, 3)          # 50 条样本，每条 3 个特征
labels = torch.randint(0, 3, (50,))    # 三分类标签
tds = TensorDataset(features, labels)
print("\nTensorDataset 样本数：", len(tds))
print("第 12 个样本：", tds[12])

# 4) Dataset 本身只负责"取样本"，要配合 DataLoader 才能成批喂给模型
loader = DataLoader(ds, batch_size=8, shuffle=True)
first_batch_x, first_batch_y = next(iter(loader))
print("\n一个 batch 的输入形状：", first_batch_x.shape)  # torch.Size([8, 1])
print("一个 batch 的标签形状：", first_batch_y.shape)    # torch.Size([8, 1])

运行后你会看到类似：

样本总数： 200
第 0 个样本的输入形状： torch.Size([1]) 标签值： 27.5...
TensorDataset 样本数： 50
第 12 个样本： (tensor([...]), tensor(2))
一个 batch 的输入形状： torch.Size([8, 1])
一个 batch 的标签形状： torch.Size([8, 1])

注意最后一步：Dataset 只是"定义了样本长什么样、有多少个"，真正"一次取一批、打乱顺序、多线程预取"是下一课 DataLoader 的职责。两者分工明确。
