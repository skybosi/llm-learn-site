创建与结构#

一、概念讲解#

Series 是一维的"带标签数组"，而现实中的表格数据是二维的——有行、有列。Pandas 用 DataFrame 来表示二维表格：它既有行索引（index），又有列名（columns），是最常用的数据结构。

可以把 DataFrame 理解为一组共享行索引的 Series：每一列都是一个 Series，列名就是这些 Series 的 name。因此你已经在上一章掌握的知识——标签索引、缺失值、向量化运算——在 DataFrame 的每一列上依然成立。

从不同来源创建#

  • 字典（值为列表）：pd.DataFrame({"姓名": [...], "年龄": [...]})，字典的键成为列名，是手工构造表格最自然的写法。
  • 列表套字典：pd.DataFrame([{...}, {...}])，外层每个字典是一行，键的并集成为列名，缺失的键自动补成缺失值。
  • NumPy 二维数组：pd.DataFrame(arr, columns=[...])，复用已有矩阵运算的结果。
  • 外部文件：pd.read_csv(...) 等读取函数（第 3 章专门讲），这是真实场景最常用的来源。

创建时可用 index= 指定行标签、用 columns= 指定列名与顺序。

认识结构#

拿到一个 DataFrame 后，第一件事是"摸清结构"，常用这几招：

  • shape：返回 (行数, 列数) 元组。
  • index / columns：分别查看行标签与列名。
  • dtypes：查看每一列的数据类型。
  • head(n)：预览前 n 行，快速确认数据长什么样。
  • info()：汇总行数、列数、每列非空数量和类型。
  • describe()：对数值列给出计数、均值、标准差、四分位数等统计摘要。

二、可运行代码示例#

import pandas as pd
import numpy as np

# 1. 字典创建：键成为列名，列表长度必须一致
data = {
    "姓名": ["张三", "李四", "王五"],
    "年龄": [25, 30, 22],
    "城市": ["北京", "上海", "广州"],
}
df = pd.DataFrame(data)
print("字典创建：\n", df)

# 2. 列表套字典：每个字典是一行，缺键自动补 NaN
rows = [
    {"姓名": "张三", "年龄": 25},
    {"姓名": "李四", "年龄": 30, "城市": "上海"},
]
df2 = pd.DataFrame(rows)
print("\n列表套字典（注意缺失补 NaN）：\n", df2)

# 3. 指定行索引与列顺序
df3 = pd.DataFrame(data, index=["r1", "r2", "r3"], columns=["城市", "姓名", "年龄"])
print("\n指定 index 与 columns 顺序：\n", df3)

# 4. 从二维 NumPy 数组创建
arr = np.arange(12).reshape(3, 4)
df4 = pd.DataFrame(arr, columns=["A", "B", "C", "D"])
print("\n从 ndarray 创建：\n", df4)

# 5. 摸清结构
print("\nshape：", df.shape)
print("index：", df.index)
print("columns：", df.columns)
print("dtypes：\n", df.dtypes)
print("\nhead(2)：\n", df.head(2))
print("\ninfo()：")
df.info()
print("\ndescribe()：\n", df.describe())

观察第 2 步：第二个字典多了一个 "城市" 键，所以 df2 自动多了这一列，第一行对应位置被补成 NaN——这正呼应了上一章学的缺失值。

三、练习#

  1. 用一个字典创建一个 4 行 3 列的 DataFrame，字段为 姓名、语文、数学，然后用 shape、columns、dtypes 分别查看它的结构。
  2. 用"列表套字典"创建两行数据，其中一行故意少写一个键，观察缺失键对应的位置出现了什么值。
  3. 对一个包含数值列的 DataFrame 调用 describe()，解释输出里 mean、std、min、25%、50%、75%、max 各自的含义。
