线性代数在神经网络中的应用#

这是本课程的最后一课。我们把前面五章学到的所有工具——矩阵乘法、特征分解、SVD、梯度——串起来，看它们如何真实地驱动一个神经网络运转。你会发现：神经网络的前向传播是矩阵乘法，PCA 是特征分解，注意力机制是矩阵点积加归一化。线性代数不是纸上的数学，它就是 AI 的底层语言。

一、概念讲解#

1. 全连接层 = 矩阵乘法 + 偏置#

一个全连接层做的事极其简单：对输入 x，乘上权重矩阵 W，加上偏置 b，再过一个非线性激活函数

z=Wx+b,a=σ(z)

权重矩阵 W 的每一行，就是"某个输出神经元对所有输入特征的权重"。整层乃至整个网络，本质上是一连串的矩阵乘法穿插着逐元素非线性。理解了矩阵乘法，就理解了神经网络的计算骨架。

2. PCA：特征分解的完整落地#

PCA（主成分分析）是降维的经典方法，步骤可以完全用前面的知识写出来：

  1. 数据中心化（减去均值）；
  2. 求协方差矩阵 Σ=n−11​XcT​Xc​；
  3. 对 Σ 做特征分解，取最大 k 个特征值对应的特征向量作为投影方向；
  4. 把数据投影到这 k 个方向上，得到低维表示。

降维后既减少了计算量，又去掉了冗余和噪声，还能把高维数据可视化。

3. 注意力机制的矩阵形式#

Transformer 的核心——注意力——用矩阵语言表达非常干净：给定查询 Q、键 K、值 V，

Attention(Q,K,V)=softmax(d​QKT​)V

Q K^T 是矩阵乘法（计算相关性分数），softmax 按行归一化（变成权重），再乘 V（加权求和）。三步全是线性代数。

4. 为什么矩阵是 AI 的"母语"#

GPU 之所以能飞速训练网络，正因为矩阵乘法可以高度并行；所有深度学习框架（PyTorch、TensorFlow）底层都在做高效的矩阵运算。把问题写成矩阵，就是把它交给硬件最高效地执行。

二、可运行代码示例#

import numpy as np

# ---- 例 1：用特征分解实现 PCA 降维（3 维 → 2 维） ----
np.random.seed(0)
n = 300
x = np.random.randn(n)
y = 2.0 * x + 0.5 * np.random.randn(n)   # 主信息沿斜向
z = 0.3 * np.random.randn(n)             # 接近噪声
X = np.column_stack([x, y, z])
Xc = X - X.mean(axis=0)
Cov = Xc.T @ Xc / (n - 1)
vals, Q = np.linalg.eigh(Cov)            # 升序特征值
idx = np.argsort(vals)[::-1][:2]         # 取最大 2 个
P = Q[:, idx]
X_pca = Xc @ P                           # 投影到 2 维
print("协方差矩阵特征值 =", np.round(vals, 3))
print("降维后形状 =", X_pca.shape)

# ---- 例 2：全连接层就是矩阵乘法 ----
np.random.seed(1)
W = np.random.randn(3, 4) * 0.1          # 4 输入 → 3 输出
b = np.zeros(3)
x = np.array([0.5, -1.0, 0.2, 0.8])
y = W @ x + b
print("单样本输出 y =", y)

X_batch = np.random.randn(4, 5)          # 一批 5 个样本（每列一个）
Y_batch = W @ X_batch + b[:, None]       # 一次矩阵乘法处理整批
print("batch 输出形状 =", Y_batch.shape)  # (3, 5)

# ---- 例 3：注意力机制的矩阵形式（简化） ----
def softmax_rows(M):
    e = np.exp(M - M.max(axis=1, keepdims=True))
    return e / e.sum(axis=1, keepdims=True)

np.random.seed(2)
n, d = 4, 3                               # 4 个 token，每个 3 维
Q = np.random.randn(n, d)
K = np.random.randn(n, d)
V = np.random.randn(n, d)
scores = Q @ K.T / np.sqrt(d)             # 相关性分数 (n, n)
attn = softmax_rows(scores)               # 每行归一化为权重
out = attn @ V                            # 加权求和
print("注意力输出形状 =", out.shape)       # (n, d)

要点：例 1 完整复刻了 PCA；例 2 展示了 W @ X_batch 一次算完整批样本；例 3 用三步矩阵运算实现了简化版注意力。这三件事合起来，就是现代深度学习的地基。

三、练习#

  2. 理解：为什么 X_c @ P 就是"把数据投影到主成分方向"？从内积的角度解释每一行发生了什么。
