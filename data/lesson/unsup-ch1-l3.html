选择 K 与评估#

一、概念讲解#

1.1 问题的由来#

前两课我们把簇数 K 当成"已知"直接填了进去。但现实中，数据不会告诉你该分成几类——K 选得太小，不同群体被硬塞进同一簇；K 选得太大，本来一体的群体被切得稀碎。所以"如何选择 K"是 K-means 实践里绕不开的难题。

难点在于：监督学习有标签可以算准确率，而聚类没有标准答案。于是我们退而求其次，用一些"内部指标"来衡量聚类的质量——它们不看标签，只看数据本身的划分是否紧凑、分离得是否清晰。最常用的三个是：肘部法则（基于惯性）、轮廓系数、以及 Calinski-Harabasz 指数。

1.2 肘部法则（Elbow Method）#

回忆一下，惯性（inertia）是簇内误差平方和。K 越大，每个簇越"精致"，惯性自然越小；极端情况下 K 等于样本数时惯性为 0。因此惯性本身不能直接用来比较不同 K 的优劣。

肘部法则的思路是：画出"K - 惯性"曲线，寻找那个"拐点"。在拐点之前，增加 K 能显著降低惯性（说明确实还有该分的簇没分开）；在拐点之后，再增加 K 带来的收益越来越小（只是在切割本来就紧凑的簇）。这个拐点，像手臂弯曲的肘部，通常就是合理的 K 值。

肘部法则的优点是非常直观、计算便宜；缺点也很明显——现实数据的曲线往往"拐"得不明显，拐点靠肉眼判断，带有主观性。

1.3 轮廓系数（Silhouette Score）#

轮廓系数是为每个样本打一个"聚得有多好"的分数，取值范围在 [−1,1]。对某个样本 i：

  • a(i)：样本 i 到本簇内其他所有样本的平均距离，衡量"簇内紧凑度"，越小越好；
  • b(i)：样本 i 到最近的其他簇内所有样本的平均距离，衡量"与其他簇的分离度"，越大越好。

轮廓系数定义为：

s(i)=max(a(i),b(i))b(i)−a(i)​

  • s(i) 接近 1：样本离本簇很近、离别的簇很远，分得很好；
  • s(i) 接近 0：样本处在两个簇的边界上，归属模糊；
  • s(i) 接近 -1：样本可能被分错了簇。

把全数据集所有样本的 s(i) 求平均，就得到整个聚类的平均轮廓系数。我们可以在不同的 K 上分别算平均轮廓系数，取最高的那个 K。

1.4 其他常用指标与"评估"的正确心态#

除了上面两个，sklearn 还提供 Calinski-Harabasz 指数（簇间离散度与簇内离散度的比值，越大越好）和 Davies-Bouldin 指数（越小越好）。它们各有偏好，没有哪一个在所有数据上都最优。

需要特别强调：这些内部指标衡量的是"划分是否符合 K-means 假设下的紧凑簇结构"，并不等同于"符合业务真实含义"。在真实项目里，最终选 K 往往是"指标 + 业务可解释性"共同作用的结果——比如用户分群时，K=5 在指标上未必最好，但每个簇能讲出一个清晰的业务故事，就更值得采用。

二、可运行代码示例#

下面的代码在同一份数据上，用肘部法则和轮廓系数两种方法辅助选择 K。

# -*- coding: utf-8 -*-
# 第 3 课：选择 K 与评估聚类质量
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs
from sklearn.metrics import silhouette_score, calinski_harabasz_score

# 1. 生成含 4 个真实簇的数据
X, y_true = make_blobs(n_samples=500, centers=4,
                       cluster_std=1.0, random_state=42)

# 2. 在 K = 2..10 上分别训练，记录惯性和平均轮廓系数
K_range = range(2, 11)
inertias = []          # 记录惯性，用于肘部法则
silhouettes = []       # 记录平均轮廓系数
for k in K_range:
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    km.fit(X)
    inertias.append(km.inertia_)
    # 轮廓系数需要至少 2 个簇，这里 K 从 2 开始，天然满足
    sil = silhouette_score(X, km.labels_)
    silhouettes.append(sil)

# 3. 绘制肘部曲线
plt.figure(figsize=(12, 4))
plt.subplot(1, 2, 1)
plt.plot(list(K_range), inertias, marker="o")
plt.xlabel("簇数 K")
plt.ylabel("惯性 inertia")
plt.title("肘部法则")

# 4. 绘制轮廓系数曲线
plt.subplot(1, 2, 2)
plt.plot(list(K_range), silhouettes, marker="o", color="green")
plt.xlabel("簇数 K")
plt.ylabel("平均轮廓系数")
plt.title("轮廓系数法")
plt.tight_layout()
plt.show()

# 5. 打印结果，找出轮廓系数最大的 K
best_k = list(K_range)[int(np.argmax(silhouettes))]
print("各 K 的平均轮廓系数：", [round(s, 3) for s in silhouettes])
print("轮廓系数最高的 K =", best_k)

# 6. 用最优 K 重新训练，并计算 Calinski-Harabasz 指数作参考
km_best = KMeans(n_clusters=best_k, n_init=10, random_state=42)
km_best.fit(X)
print("Calinski-Harabasz 指数：",
      round(calinski_harabasz_score(X, km_best.labels_), 2))

输出解读：肘部曲线在 K=4 附近明显变平缓，轮廓系数也在 K=4 处达到峰值，两种方法互相印证，都正确地指出了真实簇数 4。calinski_harabasz_score 给出的 CH 指数同样是越大越好，可作为第三方佐证。

真实数据上两种方法的结论未必总是一致，此时应结合业务含义做最终判断，而不是迷信某个数字。

三、练习小节#

  1. 把上面代码里 make_blobs 的 centers 改成 5，重跑一次，观察肘部曲线和轮廓系数曲线的"拐点 / 峰值"是否移动到了 K=5。
  2. 改变 cluster_std 让簇重叠更严重（如 2.0），再画两条曲线，看看拐点是否还清晰，说明内部指标的局限性。
  3. 用 silhouette_samples（来自 sklearn.metrics）查看每个样本的轮廓系数，找出得分最低的几个样本，解释它们为什么"归属模糊"。
