蒙特卡洛方法#

前面学的动态规划需要已知环境模型（转移概率 p(s'|s,a) 与奖励分布），但在真实任务里我们往往拿不到模型。蒙特卡洛（Monte Carlo，MC）方法换了一条路：直接从"完整的一条条经验"（episode）里学习，只靠采样、不靠模型。本课讲 MC 如何估计价值函数，以及它"无偏但高方差"的根源。

一、概念讲解#

1. 从"平均回报"出发#

回顾价值函数的定义：状态 s 的价值是"从 s 出发，未来所有回报的折扣和"的期望：

V(s) = E[ G_t | S_t = s ]
G_t = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + ...  = R_{t+1} + γ G_{t+1}

MC 的核心思想朴素到只有一句话：用"实际发生的平均"去逼近"期望"。智能体跑出很多条完整轨迹，每条轨迹里凡经过状态 s 的那一时刻，都留下一个真实的回报 G_t；把所有这些 G_t 取平均，就得到 V(s) 的估计。采样足够多时，按大数定律它会收敛到真值——这就是 MC 名字的由来（"用随机采样做数值计算"）。

2. 首次访问 vs 每次访问#

同一条轨迹可能多次经过同一个状态 s。计数方式有两种约定：

  • 首次访问 MC（first-visit）：只在 s 第一次出现时记录一次回报，之后忽略。每条轨迹对 s 最多贡献一个样本。
  • 每次访问 MC（every-visit）：s 每出现一次都记录一次回报。

两者都依概率收敛到 V(s)（首次访问是无偏的；每次访问有偏但渐进一致，且样本利用率更高）。工程上常用首次访问，因为它每个样本相互"更独立"、方差分析更干净。

3. 增量更新与常数步长（推导）#

如果每次都把一堆 G 存起来重新求平均，既占内存又没法在线学习。设第 n 个回报为 G_n，前 n-1 个的均值为 μ_{n-1}，则：

μ_n = (1/n) Σ_{k=1..n} G_k
    = μ_{n-1} + (1/n)(G_n - μ_{n-1})

推导只需一步拆分：n·μ_n = (n-1)·μ_{n-1} + G_n，移项即得。这个式子揭示了 MC 更新的统一形态——"新估计 = 旧估计 + 步长 × 误差"：

V(S_t) ← V(S_t) + α [ G_t - V(S_t) ]

其中 G_t 是目标（target），G_t - V(S_t) 是当前估计偏离目标多少。取 α = 1/n 就是精确的样本均值；取常数 α 则是对"非平稳环境"的折中——它让新样本权重更大，但代价是估计永远有噪声、不再严格收敛到精确均值。

4. MC 的性质：无偏、高方差、只适合分幕任务#

  • 无偏：G_t 是从 s 出发的真实完整回报，没有用任何猜测值代替，所以 E[G_t] = V(s)，估计无偏。
  • 高方差：一条轨迹里的随机性（动作、转移、奖励）从头攒到尾，全压在 G_t 上，方差随轨迹长度累积，因此需要很多 episode 才能估稳。
  • 分幕（episodic）限制：必须等 episode 走完才能算出 G_t，因此 MC 无法处理永不终止的任务，也做不到"边跑边即时更新"——这正是下一课 TD 要解决的痛点。

5. MC 控制：在"估计价值"上叠加"改进策略"#

价值估计只是半程。要找到好策略，MC 走的是广义策略迭代（GPI）：一轮"策略评估"（用 MC 估出当前策略的 Q(s,a)）+ 一轮"策略改进"（对 Q 取 greedy）。为了在无模型时保证每个 (s,a) 都被访问到，常用两个手段——exploring starts（每次 episode 从一个随机 (s,a) 开始）或 ε-greedy（以 1-ε 概率选最优动作、以 ε 概率随机探索）。这是后面 SARSA / Q-learning 的前置铺垫。

二、可运行代码示例#

下面用一个 5 状态随机游走（两端为终止态，向右端走通得 +1）演示首次访问 MC 的价值估计。

import numpy as np

# 一个 5 状态随机游走（Markov Reward Process）：
#   状态 0~4，其中 0、4 是终止态；从状态 2 出发，每步等概率左/右走一格，
#   到达右端终止态(4)给奖励 +1，到达左端终止态(0)给 0。
N_STATES = 5
START = 2            # 起始状态
GAMMA = 1.0          # 折扣因子（分幕且有限，取 1 也收敛）
N_EPISODES = 2000

def generate_episode():
    """生成一条完整轨迹，返回 (状态序列, 奖励序列)。"""
    states, rewards = [START], []
    s = START
    while 0 < s < N_STATES - 1:               # 未到达两端终止态就继续走
        s = s + np.random.choice([-1, 1])     # 等概率左/右一步
        states.append(s)
        # 只有"迈进右端终止态"这一步有奖励 +1，其余为 0
        rewards.append(1.0 if s == N_STATES - 1 else 0.0)
    return states, rewards

# 首次访问 MC：只关心 1/2/3 三个非终止态
returns = {s: [] for s in range(1, N_STATES - 1)}
V = {s: 0.0 for s in range(1, N_STATES - 1)}

for _ in range(N_EPISODES):
    states, rewards = generate_episode()
    G = 0.0
    visited = set()
    # 从轨迹末尾往回累计：G_t = R_{t+1} + γ·G_{t+1}
    for t in reversed(range(len(rewards))):
        G = rewards[t] + GAMMA * G
        s = states[t]
        if s not in visited and 0 < s < N_STATES - 1:  # 首次访问才计入
            visited.add(s)
            returns[s].append(G)

# 对每个状态取回报均值，作为 V(s) 的估计
for s in V:
    V[s] = np.mean(returns[s])

print("MC 估计的 V(s)：", {s: round(v, 3) for s, v in V.items()})
print("随机游走的理论值：", {1: 0.25, 2: 0.5, 3: 0.75})

要点：reversed(range(len(rewards))) 从后往前累计，恰好把 G_t = R_{t+1} + γ G_{t+1} 变成一次线性扫描；visited 集合保证"首次访问"只记一次。运行后估计值会落在理论值 [0.25, 0.5, 0.75] 附近，且 episode 数越多越贴近。

三、练习#

  1. 把 N_EPISODES 从 2000 降到 50、再升到 10000，记录三个状态的估计值与理论值的最大偏差，观察"方差随样本数下降"的规律。
  2. 把"首次访问"改成"每次访问"（去掉 visited 判重），对比两种方式在相同 episode 数下的估计精度与稳定性。
  3. 用常数步长 V[s] += α * (G - V[s]) 重写价值更新（α 取 0.05、0.2、0.9），观察 α 对收敛速度与最终波动的影响。
  4. 思考题：为什么说 MC 的 G_t 是"无偏"的？如果轨迹里混入了策略在探索（ε-greedy）产生的动作，估计的对象还是当前策略的 V(s) 吗？
