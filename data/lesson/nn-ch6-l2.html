dropout#

上一课的 L2 权重衰减是"让权重别太大"。本课介绍另一种思路完全不同的正则化——Dropout：训练时随机丢弃一部分神经元，逼网络不能依赖任何单个神经元，从而学出更健壮、更泛化的表示。它实现简单、效果显著，是当年让深层网络训练突飞猛进的关键技巧之一。

一、概念讲解#

1. 核心思想：随机丢弃神经元#

Dropout 的做法是：每次前向传播时，以概率 p 随机把某些神经元的输出置为 0（"丢弃"），被丢弃的神经元这一轮不参与计算、也不更新。因为每一轮丢弃的组合都不同，网络就相当于在训练无数个"瘦身版"子网络。

这带来一个直接的好处：网络不能把"宝"押在某个特定神经元上——因为那个神经元随时可能被丢掉。于是它被迫让多个神经元协同工作、互为备份，学到的特征更加鲁棒，不再死记训练样本。

2. 训练与测试的行为不同#

Dropout 只在训练阶段生效；测试/推理阶段要关闭 Dropout，使用全部神经元。否则输出会不稳定、模型能力也发挥不出来。PyTorch 里这由 model.train() 与 model.eval() 自动切换。

3. inverted dropout：训练时顺带"放大"#

有个细节必须处理：训练时只保留 (1−p) 比例的神经元，输出总量会变小；而测试时全部神经元都在，输出会变大，两者尺度不一致。解决方法是 inverted dropout：训练阶段，对被保留的神经元输出乘以 1/(1−p) 放大，补偿丢弃造成的损失。这样测试时就不需要任何缩放，直接关 Dropout 即可。PyTorch 的 nn.Dropout 默认就是 inverted 形式。

训练时：h' = (m ⊙ h) / (1−p)    其中 m 是 0/1 随机掩码，保留概率 (1−p)
测试时：h' = h                   （直接使用全部神经元）

4. 为什么 Dropout 能抑制过拟合#

有两种主流解释，都很有启发性：

  1. 集成视角：每次丢弃组合产生一个不同的子网络，训练全程相当于在训练指数多个子网络，测试时把它们"平均"起来用。集成多个模型通常比单个模型更稳、更不易过拟合。
  2. 打破共适应：某些神经元会"串通"起来拟合噪声。Dropout 随机拆散这种组合，让每个神经元都必须独立地学到有用的特征。

5. 使用建议#

  • 丢弃率 p 常用 0.2～0.5（输入层通常用更小的 p，如 0.1～0.2）。
  • 一般在较大的全连接层上使用；卷积层有自己更合适的正则（后续架构课会讲）。
  • Dropout 会减慢收敛（每次只更新部分神经元），所以通常需要更多训练轮数。
  • 测试时务必 model.eval() 关闭 Dropout。

二、可运行示例#

示例 1：NumPy 手写 inverted dropout，理解放大机制

import numpy as np

rng = np.random.default_rng(0)

def dropout_forward(x, p, training=True):
    """inverted dropout：训练时随机丢弃并放大，测试时原样返回"""
    if not training:
        return x
    keep_prob = 1 - p
    mask = (rng.random(x.shape) < keep_prob) / keep_prob  # 0/1 掩码并放大
    return x * mask

x = np.array([1.0, 2.0, 3.0, 4.0])

out_train = dropout_forward(x, p=0.5, training=True)
print("训练时某次输出（部分被置 0）：", out_train)

# 多次训练取平均，期望值应接近原始 x
means = np.mean([dropout_forward(x, 0.5, True) for _ in range(100000)], axis=0)
print("训练时多次平均（接近原值）：", means)

print("测试时输出（原样）：", dropout_forward(x, 0.5, training=False))

运行后：训练时单次输出部分为 0，但多次平均后接近原始值——这正是 1/(1−p) 放大的功劳；测试时则原样输出。

示例 2：PyTorch 里用 nn.Dropout 对比有无 Dropout 的过拟合

import torch
import torch.nn as nn

torch.manual_seed(0)

# 小数据 + 大模型，容易过拟合
x = torch.linspace(-3, 3, 30).view(-1, 1)
y = torch.sin(x) + 0.4 * torch.randn_like(x)
x_val = torch.linspace(-3, 3, 30).view(-1, 1)
y_val = torch.sin(x_val) + 0.4 * torch.randn_like(x_val)

def make_net(use_dropout, p=0.5):
    layers = [nn.Linear(1, 128), nn.Tanh()]
    if use_dropout:
        layers.append(nn.Dropout(p))          # 在隐藏层后加 Dropout
    layers += [nn.Linear(128, 128), nn.Tanh()]
    if use_dropout:
        layers.append(nn.Dropout(p))
    layers += [nn.Linear(128, 1)]
    return nn.Sequential(*layers)

loss_fn = nn.MSELoss()

def train(use_dropout, epochs=3000):
    net = make_net(use_dropout)
    opt = torch.optim.Adam(net.parameters(), lr=0.01)
    for _ in range(epochs):
        net.train()                    # 训练模式：启用 Dropout
        opt.zero_grad()
        loss = loss_fn(net(x), y)
        loss.backward()
        opt.step()
    net.eval()                         # 评估模式：关闭 Dropout
    with torch.no_grad():
        tr = loss_fn(net(x), y).item()
        va = loss_fn(net(x_val), y_val).item()
    return tr, va

tr, va = train(use_dropout=False)
print(f"[无 Dropout] 训练损失 = {tr:.4f}, 验证损失 = {va:.4f}, 差距 = {va - tr:.4f}")

tr, va = train(use_dropout=True, p=0.5)
print(f"[Dropout 0.5] 训练损失 = {tr:.4f}, 验证损失 = {va:.4f}, 差距 = {va - tr:.4f}")

加了 Dropout 后，"训练—验证差距"通常会缩小、验证损失下降——模型不再死记那 30 个噪声点。

三、练习#

  1. 验证期望值：在示例 1 里把 p 改成 0.8 和 0.2，观察训练时单次输出被丢弃的比例变化，以及多次平均是否仍接近原值。
  2. 调丢弃率：在示例 2 中把 p 设为 0.1、0.5、0.9 各跑一遍，观察验证损失的变化，说说 p 太大或太小的后果。
  3. 找 bug：下面的用法哪里不对？
    model.eval()
# ... 训练代码里忘记切回 model.train() ...
loss.backward(); optimizer.step()
    说明为什么"忘记 model.train()"会让 Dropout 完全失效。
  4. 思考：为什么 Dropout 通常放在全连接层之后，而不是紧挨着输出层？放在输出层前会怎样？
  5. 拓展：Dropout 训练时会减慢收敛。请把示例 2 里无 Dropout 的模型 epoch 数减半，观察它是否更快但更容易过拟合，理解"正则与速度"的权衡。
