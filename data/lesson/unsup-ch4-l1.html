PCA 原理与方差#

前面几章我们把聚类当成了无监督学习的"主角"。但从这一章开始，我们要进入无监督学习的另一块核心拼图——降维。降维回答的是这样一个问题：当一份数据有几十、几百甚至上千个特征时，如何在不丢掉太多信息的前提下，把它"压缩"到更少的维度，方便后续的聚类、可视化或建模。而主成分分析（Principal Component Analysis，简称 PCA）正是最经典、使用最广的一种线性降维方法。这一课我们先讲清楚它背后的原理，尤其是它与"方差"的紧密关系。

一、概念讲解#

1. 为什么要降维#

高维数据会带来几个麻烦：特征之间互相冗余、计算变慢、难以可视化（人眼最多只能舒服地看 2 到 3 维），以及"维度灾难"——维度越高，样本在空间中越稀疏，很多基于距离的算法效果会变差。降维的目标，就是在尽量保留原始信息的前提下减少特征数量。

降维主要分两条路：一条是特征选择（从原始特征里挑出一部分，第 5 章讲），另一条是特征提取/构造（把原始特征"组合"成新的少数几个特征，PCA 属于这一类）。PCA 不会"挑"特征，而是把原始特征线性组合成全新的、互不相关的"主成分"。

2. PCA 的核心思想：找方差最大的方向#

想象平面上有一团椭圆形的点云，点的分布沿某个方向拉得特别长。如果只允许你用一条直线去"代表"这团点，你会选择哪条线？直觉上，你会选那条与点云"长轴"重合的线——因为沿着这条线，点的取值变化最大，能保留最多的差异信息。

PCA 就是把这种直觉数学化：

  • 第一主成分是数据投影后方差最大的方向；
  • 第二主成分在与第一主成分正交（垂直）的约束下，取方差次大的方向；
  • 依此类推，第 k 个主成分都是在前 k-1 个主成分的正交补空间里取方差最大的方向。

这里的"方差"衡量的是投影后数据点的分散程度。方差越大，说明这个方向"装下"了越多信息；反过来，方差几乎为零的方向意味着数据在那个方向上几乎不变，丢掉它损失最小。

3. 主成分与特征向量#

数学上，主成分方向来自数据的协方差矩阵的特征分解。协方差矩阵记录的是两两特征之间的协同变化关系；对它做特征分解后：

  • 每个特征向量给出一个主成分的方向；
  • 对应的特征值就是这个主成分方向上的方差大小。

所以"求主成分"这件事，本质上就是：中心化数据 → 求协方差矩阵 → 求特征值和特征向量 → 按特征值从大到小排序，取前几个特征向量作为新的坐标轴。你不需要手推这些公式，但理解"特征值 = 该主成分的方差"是读懂后文一切指标的关键。

4. 解释方差比例#

PCA 会给出每个主成分"解释了多少方差"，这个指标叫解释方差比例（explained variance ratio）。它等于该主成分的特征值除以所有特征值之和，取值范围在 0 到 1 之间。

  • 单个主成分的解释方差比例越大，说明它越重要；
  • 把前若干个主成分的比例累加，得到累计解释方差比例，它回答的是"我只保留前 m 个主成分，一共保住了原始数据多少方差"。

一个常用的经验做法是：画出累计解释方差随主成分个数的变化曲线，找到"拐点"或达到某个目标比例（如 90%、95%）所需的最少个数，作为降维的目标维度。

二、可运行代码示例#

示例 1：用 NumPy 手动算主成分方向#

先不借助 scikit-learn，用 NumPy 把"中心化 → 协方差 → 特征分解"这条链路走一遍，直观看到"特征值就是各主成分的方差"：

import numpy as np

# 生成一份沿"对角线方向"拉伸的二维数据：两个变量高度相关
rng = np.random.default_rng(42)
mean = [0.0, 0.0]
cov = [[3.0, 2.2], [2.2, 2.0]]   # 非对角元较大 → 两个变量相关
X = rng.multivariate_normal(mean, cov, size=400)

# 1. 中心化：减去每个变量的均值，把原点移到数据中心
Xc = X - X.mean(axis=0)

# 2. 计算协方差矩阵（rowvar=False 表示"每一列是一个变量"）
C = np.cov(Xc, rowvar=False)

# 3. 特征分解：eigh 返回升序排列的特征值
eigvals, eigvecs = np.linalg.eigh(C)
order = np.argsort(eigvals)[::-1]   # 反序，改成降序
eigvals = eigvals[order]
eigvecs = eigvecs[:, order]

print("协方差矩阵:\n", C)
print("特征值（即各主成分方向上的方差）:", eigvals)
print("解释方差比例:", eigvals / eigvals.sum())
print("主成分方向（特征向量）:\n", eigvecs)

要点：eigvals / eigvals.sum() 得到的就是 scikit-learn 里 explained_variance_ratio_ 的等价物。你可以看到第一个主成分方向几乎贴着数据的长轴。

示例 2：用 scikit-learn 的 PCA 复现同样结果#

同样的数据，用 PCA 一步完成，并核对属性：

from sklearn.decomposition import PCA
import numpy as np

rng = np.random.default_rng(42)
X = rng.multivariate_normal([0, 0], [[3.0, 2.2], [2.2, 2.0]], size=400)

pca = PCA(n_components=2)
pca.fit(X)

print("解释方差比例:", pca.explained_variance_ratio_)
print("主成分方向 components_:\n", pca.components_)
print("各主成分方差 explained_variance_:", pca.explained_variance_)

# 投影到主成分坐标后，第一主成分的样本方差应等于第一个特征值
X_pca = pca.transform(X)
print("投影后第一主成分的方差:", X_pca[:, 0].var())

要点：components_ 的每一行是一个主成分方向（单位向量），explained_variance_ 是它对应的方差，explained_variance_ratio_ 是归一化后的比例。三者的关系在本示例里与示例 1 的手算结果一一对应。

示例 3：高维数据的累计解释方差曲线#

手写数字数据集每张图是 8×8=64 维。看看多少个主成分就能"说清"大部分方差：

from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

digits = load_digits()
X = digits.data                      # 形状 (1797, 64)

pca = PCA().fit(X)                   # 不指定 n_components，算出全部主成分
cum = np.cumsum(pca.explained_variance_ratio_)

plt.plot(range(1, len(cum) + 1), cum, marker='o', markersize=3)
plt.xlabel('主成分个数')
plt.ylabel('累计解释方差比例')
plt.title('手写数字数据的累计解释方差')
plt.axhline(0.9, color='gray', linestyle='--', linewidth=0.8)
plt.show()

# 达到 90% 解释方差所需的最少主成分个数
n90 = np.searchsorted(cum, 0.9) + 1
print("达到 90% 解释方差约需主成分数:", n90, "（原始维度 64）")

要点：np.searchsorted(cum, 0.9) 找到第一个累计值不小于 0.9 的位置。对于这类像素数据，往往几十个主成分就能保留大部分方差，说明原始 64 维里有大量冗余。

三、练习#

  1. 动手验证：把示例 1 里的协方差矩阵改成 [[3.0, 0.0], [0.0, 3.0]]（两个变量不相关、方差相同），运行后观察主成分方向有什么变化，解释方差比例又变成多少？这说明了什么？
  2. 比较比例：用 load_wine 数据集（13 个特征）运行 PCA().fit(X)，打印 explained_variance_ratio_，回答：前两个主成分一共解释了约多少方差？
  3. 曲线找拐点：基于示例 3，把阈值从 0.9 改成 0.95，看看所需主成分数增加到多少；再肉眼找出曲线的"肘部"位置，比较"肘部"与"90% 阈值"这两个选维标准的差异。
  4. 思考：为什么 PCA 在拟合前通常要先把数据标准化（每个特征方差归一到 1）？如果某个特征的数值范围远大于其他特征，不标准化会发生什么？
