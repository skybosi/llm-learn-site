缺失值初识#

一、概念讲解#

真实数据几乎不可能完整：问卷里有人跳过问题、日志里某条记录没写全、两个数据源合并时对不上。这些"没有值"的位置，Pandas 统一用缺失值（missing value）来表示。本课先认识它长什么样、如何检测、如何简单处理，下一章和第 4 章会深入讲解。

1. 缺失值的几种写法#

Pandas 内部主要使用三种标记，多数时候可以混用：

  • None：Python 原生的空值，进入 Series 后通常会被自动转成 NaN。
  • np.nan（float("nan")）：NumPy 的"非数值"，是最常见的缺失值表示。
  • pd.NA：Pandas 1.0 引入的"实验性"通用缺失值，能更好地保留整数类型。

一个关键点：只要一列里出现缺失值，整列的类型通常会被提升为 float64。因为 NaN 本质是浮点数，而整数类型没有表示"缺失"的合法值。

2. 缺失值的检测#

isnull() 返回一个布尔 Series，缺失位置为 True；notnull() 恰好相反。配合 sum() 可以快速统计缺失个数，这是数据清洗的第一步"摸清家底"。

3. 缺失值的传播规则#

缺失值有一条重要的行为规则，务必记牢：

  • 逐元素运算会"传染"：s + 1 中，缺失位置仍是缺失。
  • 归约统计默认"跳过"：s.sum()、s.mean() 默认 skipna=True，会忽略缺失值直接算；只有显式写 skipna=False 才会返回 NaN。

4. 最简单的处理#

dropna() 直接丢掉含缺失的元素，fillna(value) 用指定值填补。更精细的策略（按列填充、插值、前向/后向填充）留到第 4 章展开。

二、可运行代码示例#

import pandas as pd
import numpy as np

# 1. 三种缺失写法混用，观察结果
s = pd.Series([10, None, 30, np.nan, 50], index=list("abcde"), name="样本")
print("原始数据：\n", s)
print("类型 dtype：", s.dtype)   # 自动提升为 float64

# 2. 检测缺失值
print("\nisnull()：\n", s.isnull())
print("notnull()：\n", s.notnull())
print("缺失个数：", s.isnull().sum())

# 3. 逐元素运算会传播缺失值
print("\n每个元素 +1 后（缺失仍在）：\n", s + 1)

# 4. 归约统计默认跳过缺失值
print("\nsum() 默认跳过缺失：", s.sum())          # 90
print("mean() 默认跳过缺失：", s.mean())          # 30.0
print("sum(skipna=False)：", s.sum(skipna=False))  # 显式不跳过 -> NaN

# 5. 最简单的处理：删除缺失
print("\ndropna() 删除缺失：\n", s.dropna())

# 6. 最简单的处理：填充
print("\nfillna(0) 用 0 填充：\n", s.fillna(0))
print("ffill() 前向填充：\n", s.ffill())   # 用前一个有效值填充

运行后重点观察第 3、4 步的反差：同样的缺失值，在 s + 1 里被"保留"，在 sum() 里却被"忽略"。理解这条规则，能避免很多统计结果出错却找不到原因的情况。

三、练习#

  1. 创建 pd.Series([1, None, None, 4, 5])，用 isnull().sum() 统计缺失个数，再用 notnull() 取出所有非缺失元素。
  2. 对上面的 Series 分别执行 s.sum() 和 s.sum(skipna=False)，观察结果差异并解释原因。
  3. 用 fillna() 把缺失值替换成这一列非缺失部分的均值，再用 ffill() 处理一次，比较两种填充结果的差别。
