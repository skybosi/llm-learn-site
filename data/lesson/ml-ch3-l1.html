缺失值与清洗#

真实世界的数据几乎不可能"干净"：问卷没填、传感器掉线、接口漏字段，都会产生缺失值。绝大多数 sklearn 模型不接受 NaN，所以训练前必须处理缺失值。本课讲清楚两种主流思路——删除和填充，并演示 SimpleImputer 的用法。

一、概念讲解#

1. 先发现缺失值#

用 Pandas 快速体检数据：

  • df.isna().sum()：统计每一列的缺失值个数。
  • df.info()：查看每列的非空数量和数据类型。

发现缺失后，要问两个问题：缺失是随机的还是系统性的？（例如高收入人群更不愿填收入，就是系统性的，简单填充会引入偏差）；缺失比例有多大？ 这决定了处理策略。

2. 删除法（Drop）#

直接丢掉含缺失值的行（dropna）或列。优点是简单、不引入人为假设；缺点是当缺失较多、样本本来就少时，会损失大量信息。一般只在缺失很少（例如不足 5%）或该行/列不重要时使用。

3. 填充法（Impute）#

用某个"合理值"补上缺口，保留样本数量。sklearn.impute.SimpleImputer 支持几种策略：

  • strategy="mean"：用该列均值填充（适合数值列、无异常值时）。
  • strategy="median"：用中位数填充（数值列有异常值时更稳健）。
  • strategy="most_frequent"：用众数填充（适合类别列，也兼容数值列）。
  • strategy="constant" + fill_value：用指定常量填充（如填 0 或"未知"）。

4. 关键约定#

和 StandardScaler 一样，SimpleImputer 也是变换器：必须在训练集上 fit（学习每列的均值/中位数/众数），再对测试集只 transform。若对全量数据一起 fit，等于偷看了测试集信息，属于数据泄漏。

二、可运行代码示例#

下面的例子构造一份"带缺口"的房价数据，演示删除和几种填充。

import numpy as np
import pandas as pd
from sklearn.impute import SimpleImputer

# 构造含缺失值的真实感数据：面积、卧室数、房龄、房价
df = pd.DataFrame({
    "面积": [90, 120, np.nan, 80, 150, np.nan, 100],
    "卧室": [3, 4, 3, np.nan, 4, 2, 3],
    "房龄": [5, np.nan, 8, 6, 1, 10, 7],
    "房价": [300, 420, 350, np.nan, 520, 260, 380],
})
print("原始数据：\n", df)
print("\n各列缺失值数量：\n", df.isna().sum())

# ---- 策略 1：删除法 ----
df_dropped = df.dropna()
print("\n删除含缺失值的行后：\n", df_dropped)

# ---- 策略 2：填充法（中位数）----
# SimpleImputer 是变换器：fit 学习每列中位数，transform 填入
imputer = SimpleImputer(strategy="median")
X = df[["面积", "卧室", "房龄"]]           # 对特征列做填充
X_filled = imputer.fit_transform(X)
print("\n学到的每列中位数：", imputer.statistics_)

df_filled = pd.DataFrame(X_filled, columns=["面积", "卧室", "房龄"])
df_filled["房价"] = df["房价"]              # 目标列保持原样（此处暂不处理）
print("\n中位数填充后：\n", df_filled)

# ---- 策略 3：众数填充（适合类别型特征）----
imputer_mf = SimpleImputer(strategy="most_frequent")
X_filled_mf = imputer_mf.fit_transform(X)
print("\n众数填充后：\n", pd.DataFrame(X_filled_mf, columns=["面积", "卧室", "房龄"]))

# ---- 策略 4：常量填充 ----
imputer_const = SimpleImputer(strategy="constant", fill_value=0)
print("\n常量 0 填充后：\n",
      pd.DataFrame(imputer_const.fit_transform(X), columns=["面积", "卧室", "房龄"]))

运行后可观察：中位数填充让"面积"的两个 NaN 都被换成该列中位数 95；imputer.statistics_ 里保存的就是各列学到的填充值。注意 fit_transform 之后得到的是 NumPy 数组，我们手动包回 DataFrame 是为了方便查看。

三、练习#

  1. 选择策略：以下场景分别更适合删除还是填充（若填充，选哪种策略）？
    • (a) 1000 行数据里，只有 8 行的"房龄"缺失。
    • (b) "收入"列缺失 30%，且高收入人群更倾向不填。
    • (c) "装修风格"这个类别列缺失了 10%。
  2. 填空：SimpleImputer(strategy="median") 是 ____（变换器/估计器），fit 学到的是每列的 ____。
  3. 动手实验：在构造数据的代码里多造几个极端值（例如把某行"面积"改成 10000），对比 mean 和 median 两种策略的填充结果，说说中位数为何更稳健。
  4. 思考题：为什么对测试集只能 transform 而不能 fit_transform？如果训练时"面积"的中位数是 95，而测试集来了一个新样本面积缺失，它会被填成什么？这个值来自哪里？
