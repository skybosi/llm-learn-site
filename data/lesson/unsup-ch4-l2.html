PCA 实现#

上一课我们理解了 PCA 的原理：找方差最大的方向。这一课把原理落到工程上——用 scikit-learn 的 PCA 类完成一条完整的降维流程：先标准化、再拟合、再变换，并学会看懂 components_、explained_variance_ratio_ 这些属性，以及如何用 n_components 和 inverse_transform 掌控降维的程度。

一、概念讲解#

1. sklearn 的 PCA 基本三步#

PCA 的用法和大部分 sklearn 估计器一致，三个动作：

  • fit(X)：在数据上"学习"主成分方向，不改变数据；
  • transform(X)：把数据投影到已学好的主成分坐标上，返回降维后的新数据；
  • fit_transform(X)：上面两步的合并，一次完成。

拟合完成后，pca 对象会带上几个常用属性：components_（主成分方向）、explained_variance_（各主成分方差）、explained_variance_ratio_（解释方差比例）以及 mean_（每个特征的均值，中心化时用）。

2. 为什么必须先标准化#

PCA 对特征的量纲非常敏感。因为它要最大化投影方差，而方差的大小直接受数值范围影响：假如一个特征是"身高（厘米，约 150190）"，另一个是"收入（元，约 3000100000）"，后者方差会碾压前者，导致主成分几乎完全被"收入"主导。因此通常的做法是先用 StandardScaler 把每个特征都变成均值为 0、方差为 1，再做 PCA。这是实战里最容易漏掉、也最影响结果的一步。

3. n_components 的两种传参#

n_components 决定了降维后的维度，它支持两种形式：

  • 整数（如 n_components=2）：直接指定降到几维；
  • 0 到 1 之间的浮点数（如 n_components=0.95）：表示"保留累计解释方差达到 95% 所需的主成分个数"，维度由算法根据数据自动决定。

用浮点数时，拟合后可以通过 pca.n_components_（注意结尾有下划线，是拟合后得到的值）查看实际选了几个主成分。

4. inverse_transform：从低维"还原"回高维#

inverse_transform 是 transform 的逆操作，把低维表示映射回原始特征空间。注意这只是一种近似重构：被丢掉的主成分信息永远找不回来，重构结果会与原始数据有误差。重构误差越小，说明保留下来的方差越多。这个能力有个实用用途——把噪声当作"低方差方向"丢掉，实现用 PCA 去噪。

二、可运行代码示例#

示例 1：完整的标准化 + PCA 流程#

用葡萄酒数据集（13 个特征）走一遍标准流程，并查看核心属性：

from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

wine = load_wine()
X, y = wine.data, wine.target       # 13 个物理化学指标

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)  # 先标准化：每个特征均值 0、方差 1

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

print("原始维度:", X.shape[1], "→ 降维后维度:", X_pca.shape[1])
print("components_ 形状:", pca.components_.shape)          # (2, 13)
print("各主成分解释方差:", pca.explained_variance_)
print("解释方差比例:", pca.explained_variance_ratio_)
print("累计解释方差:", pca.explained_variance_ratio_.sum())

要点：components_ 形状是 (n_components, n_features)，每一行是"新坐标轴在原特征空间里的方向"，行内每个数可以理解为该原始特征对主成分的"权重"。

示例 2：用浮点数让 PCA 自动选维#

不确定降到几维时，直接给一个目标解释方差比例：

from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X = load_wine().data
X_scaled = StandardScaler().fit_transform(X)

pca_auto = PCA(n_components=0.95, random_state=42)
X_auto = pca_auto.fit_transform(X_scaled)

print("保留 95% 方差实际用到的主成分数:", pca_auto.n_components_)
print("实际累计解释方差:", pca_auto.explained_variance_ratio_.sum().round(4))

要点：n_components=0.95 的语义是"我要保住 95% 的方差"，最终维度由算法决定；n_components_（带下划线）只有在 fit 之后才可用。

示例 3：用 inverse_transform 重构并估算误差#

降到 2 维再还原回 13 维，看看丢了多少信息：

import numpy as np
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X = load_wine().data
X_scaled = StandardScaler().fit_transform(X)

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
X_back = pca.inverse_transform(X_pca)   # 从 2 维近似重构回 13 维

mse = np.mean((X_scaled - X_back) ** 2)
print("重构均方误差 MSE:", mse.round(4))
print("未保留下来的方差比例:", (1 - pca.explained_variance_ratio_.sum()).round(4))

要点：重构误差与"被丢掉的方差"是同一件事的两面——保留下来的方差越多，重构就越准。若把 n_components 调大，MSE 会相应下降。

三、练习#

  1. 对比有无标准化：对 load_wine 的数据，分别做"直接 PCA"和"先 StandardScaler 再 PCA"，打印两次的 explained_variance_ratio_，观察前两个主成分的解释方差比例有何不同，并解释原因。
  2. 自动选维：把示例 2 的目标改成 0.90 和 0.99，记录两种情况下 n_components_ 的值，说说这个趋势说明了什么。
  3. 重构实验：固定 n_components 分别为 1、3、6、10，各自计算重构 MSE，画一张"MSE 随主成分数变化"的曲线，验证 MSE 是否单调下降。
  4. 思考：inverse_transform 还原出来的 13 维数据，和原始 13 维数据相比，为什么一定会有误差？在什么情况下这个误差会是 0？
