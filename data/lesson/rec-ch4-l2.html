DeepFM 等深度模型#

上一课我们用 GBDT 给 LR 补上了"自动特征组合"的能力。但树也有局限：连续特征被切成桶后信息有损、特征组合的阶数受限于树深、且 GBDT 和 LR 是两段式、不能端到端联合优化。本课我们进入深度排序模型的主线：从 FM 出发，理解 DeepFM 如何用一个网络同时完成"显式二阶交叉 + 隐式高阶交叉"。

一、概念讲解#

1. 先解决稀疏特征的稠密化：Embedding#

推荐系统的原始特征几乎都是高维稀疏的：用户 ID 有上亿个、物品 ID 有上千万个，one-hot 之后维度爆炸。深度模型的第一步，是把每个稀疏 ID 映射成一个低维稠密向量，也就是 Embedding：

用户 ID "u_12345" ──> embedding 表 ──> 向量 e_u ∈ R^d（d 通常取 8~64）
物品 ID "i_987"    ──> embedding 表 ──> 向量 e_i ∈ R^d

Embedding 的意义远超"降维"。它把"语义相近的东西映射到相近的位置"——两个口味相似的用户，学出来的 e_u 会天然接近。而且一旦有了向量，特征之间的交叉就可以用向量运算（内积）来表示，这正是 FM 和双塔召回的共同基础。

2. FM：用向量内积做二阶交叉#

矩阵分解只学"用户向量 · 物品向量"这一对交互。但排序阶段希望任意两个特征都能交叉。最直接的想法是给每对特征 (i, j) 都学一个权重 w_ij，预测值为：

y = w0 + Σ w_i x_i + Σ Σ w_ij x_i x_j

问题在于：w_ij 只有当特征 i 和 j 在训练数据里同时非零时才能被学到。推荐数据极稀疏，很多特征对从来没一起出现过，w_ij 学不到，也就无法泛化。

因子分解机（FM，Factorization Machine） 的解法很优雅：不给每对特征单独存一个权重，而是给每个特征学一个向量 v_i，用两个向量的内积作为交叉权重：

w_ij ≈ <v_i, v_j>

于是二阶项可以化简（利用平方差恒等式）：

ΣΣ <v_i, v_j> x_i x_j = 1/2 · ( (Σ v_i x_i)² - Σ (v_i x_i)² )

这条式子把"两两交叉"从 O(k²) 次内积降到了 O(k) 次向量运算，同时解决了稀疏问题：哪怕特征 i、j 从未一起出现，只要它们各自和其他特征共现过，各自的 v_i、v_j 就能被训练，交叉权重依然能算出来。这就是 FM 的核心洞察——用低秩的向量分解，去逼近高维的交叉权重矩阵。

3. DeepFM：FM 和 DNN 共享 Embedding#

FM 只做显式的二阶交叉，而且是固定二阶。DeepFM（2017 年华为诺亚方舟实验室提出）的动机是：把 FM 的"显式交叉"和 DNN 的"隐式高阶交叉"合并进一个端到端的网络，并且让两者共享同一套 Embedding。

DeepFM 的输出是三个部分相加：

y = sigmoid( linear 部分 + FM 部分 + DNN 部分 )
  • linear 部分：每个特征乘一个标量权重，再加一个偏置，承接"记忆"（把高频出现的强模式直接记住）。
  • FM 部分：对 Embedding 向量做上一节的二阶交叉，显式地建模两两组合。
  • DNN 部分：把所有字段的 Embedding 拼起来，过几层全连接，隐式地学任意高阶交叉。

三个部分共享同一张 Embedding 表，所以 FM 和 DNN 会互相约束、协同训练：Embedding 既要能被内积解释（FM 需要），又要能拼进 MLP（DNN 需要）。相比 GBDT+LR 的两段式，DeepFM 是端到端联合训练的，梯度可以一路回传到 Embedding，避免了"树先定死、后面只能凑"的信息损失。

4. 深度排序模型家族速览#

DeepFM 只是"深度 + 显式交叉"这一脉的代表。理解它之后，整个家族就是"在记忆、显式交叉、隐式交叉、序列建模这几个维度上做加减"：

  • Wide & Deep（Google, 2016）：wide（线性部分，需人工特征交叉）+ deep（MLP）。DeepFM 可视作它的改进——用 FM 自动生成二阶交叉，替代 wide 里的人工交叉。
  • DCN（Deep & Cross Network）：用一个 Cross Network 显式建模任意阶交叉（x_{k+1} = x_0 · x_kᵀ w + x_k），交叉阶数随层数线性增长。
  • DIN（Deep Interest Network，阿里, 2018）：引入用户历史行为序列，用注意力机制根据"当前候选物品"去加权用户的历史行为，解决"用户兴趣多种多样、只看当前一个物品猜不准"的问题。
  • xDeepFM / AFM：在交叉的阶数和交叉项的重要性加权上继续做文章。

它们的共同趋势是：显式交叉保证可解释和稳定，序列/注意力捕捉兴趣的动态性，端到端训练让特征表示和打分一起优化。本课的代码示例聚焦 DeepFM，因为它结构完整、足以作为理解其余模型的支点。

二、可运行示例#

示例 1：PyTorch 简化实现 DeepFM#

用一个精简但可训练的 DeepFM，跑在合成数据上。数据里埋了一个"字段 0 与字段 1 的交叉信号"，用来验证 FM 部分确实在学交叉。

import torch
import torch.nn as nn

class DeepFM(nn.Module):
    def __init__(self, field_dims, embed_dim=8, mlp_dims=(32, 16)):
        super().__init__()
        self.num_fields = len(field_dims)
        # 每个字段一张 Embedding 表，供 FM 和 DNN 共享
        self.embeddings = nn.ModuleList(
            [nn.Embedding(dim, embed_dim) for dim in field_dims]
        )
        # linear 部分：每个特征一个标量权重
        self.linear = nn.ModuleList(
            [nn.Embedding(dim, 1) for dim in field_dims]
        )
        self.bias = nn.Parameter(torch.zeros(1))

        # DNN 部分：拼接所有字段 embedding -> MLP -> 1
        input_dim = self.num_fields * embed_dim
        layers = []
        for out_dim in mlp_dims:
            layers.append(nn.Linear(input_dim, out_dim))
            layers.append(nn.ReLU())
            input_dim = out_dim
        layers.append(nn.Linear(input_dim, 1))
        self.mlp = nn.Sequential(*layers)

    def forward(self, x):
        # x: (batch, num_fields)，每列是离散特征 id
        # 1) linear 部分：每字段标量权重求和 + 偏置，得到 (batch, 1)
        lin = sum(self.linear[i](x[:, i]) for i in range(self.num_fields)) + self.bias

        # 2) FM 二阶交叉：1/2 * [(Σv)^2 - Σ(v^2)]
        emb = torch.stack([emb(x[:, i]) for i, emb in enumerate(self.embeddings)], dim=1)
        # emb: (batch, num_fields, embed_dim)
        sum_sq = emb.sum(dim=1).pow(2)                        # (Σ v_i)^2
        sq_sum = emb.pow(2).sum(dim=1)                        # Σ v_i^2
        fm = 0.5 * (sum_sq - sq_sum).sum(dim=1, keepdim=True) # (batch, 1)

        # 3) DNN 高阶交叉
        dnn = self.mlp(emb.view(x.size(0), -1))               # (batch, 1)

        logit = lin + fm + dnn
        return torch.sigmoid(logit)


def make_batch(field_dims, n=256):
    """构造带交叉信号的合成数据：字段0与字段1的 id 相等且为偶数时，正样本概率高。"""
    x = torch.stack([torch.randint(0, d, (n,)) for d in field_dims], dim=1)
    signal = ((x[:, 0] == x[:, 1]) & (x[:, 0] % 2 == 0)).float()  # 交叉信号
    y = (torch.rand(n) < 0.2 + 0.6 * signal).float().unsqueeze(1) # 0.2 基础 + 0.6 交叉
    return x, y

torch.manual_seed(0)
field_dims = [30, 30, 20, 20, 10]     # 5 个字段各自的词汇量
model = DeepFM(field_dims)
opt = torch.optim.Adam(model.parameters(), lr=2e-2)
loss_fn = nn.BCELoss()

for step in range(400):
    x, y = make_batch(field_dims, n=512)
    pred = model(x)
    loss = loss_fn(pred, y)
    opt.zero_grad()
    loss.backward()
    opt.step()
    if step % 100 == 0:
        print(f"step {step:>3}: loss = {loss.item():.4f}")

# 简单验证：模型对"交叉成立"的样本打分应明显高于"交叉不成立"的样本
with torch.no_grad():
    x_pos = torch.tensor([[4, 4, 3, 3, 1]])   # 字段0==字段1 且为偶数 -> 交叉成立
    x_neg = torch.tensor([[1, 2, 3, 3, 1]])   # 字段0!=字段1 -> 交叉不成立
    print("交叉成立样本 pCTR =", round(model(x_pos).item(), 4))
    print("交叉不成立样本 pCTR =", round(model(x_neg).item(), 4))

示例 2：验证 FM 公式的两种写法等价#

手工验证"两两内积"与"平方差恒等式"算出来的二阶交叉项数值一致，帮你看懂 DeepFM 里那行 0.5 * (sum_sq - sq_sum) 是怎么来的。

import torch

# 3 个特征向量，维度 d=4
v = torch.tensor([
    [1.0, 0.0, 2.0, 0.0],
    [0.0, 1.0, 0.0, 2.0],
    [1.0, 1.0, 0.0, 0.0],
])

# 写法一：显式枚举所有两两内积
explicit = 0.0
for i in range(len(v)):
    for j in range(i + 1, len(v)):
        explicit += torch.dot(v[i], v[j])

# 写法二：平方差恒等式
sum_sq = v.sum(dim=0).pow(2).sum()
sq_sum = v.pow(2).sum()
identity = 0.5 * (sum_sq - sq_sum)

print("两两内积求和 =", explicit.item())
print("平方差恒等式   =", identity.item())
print("两者相等？", torch.allclose(explicit, identity))

三、练习#

  1. 把示例 1 里的 mlp_dims 改成空元组 ()（去掉 DNN 部分），模型就退化成"LR + FM"。对比损失和打分，说明 DNN 部分提供了什么。
  2. 在 make_batch 里把交叉信号改成"字段 0、1、2 三个字段的 id 同时相等"（三阶交叉），观察 FM 部分还能否独立捕捉到它；若不能，思考为什么 FM 只有二阶、需要靠 DNN 补高阶。
  3. 说明 DeepFM 里"共享 Embedding"为什么重要：如果 FM 和 DNN 各用一套独立的 Embedding，会发生什么？训练和泛化上各有什么坏处？
  4. 思考题：DIN 引入"用户历史行为序列 + 注意力"，它和 DeepFM 解决的是同一类问题吗？二者关注的特征来源有什么不同？
