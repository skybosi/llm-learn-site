说话人分离与增强：掩码法的机制、上界与置换不变训练#

这一节要解决什么#

上一节的输入是一段只有一个主导说话人的音频——说话人验证的评测协议（注册一条、测试一条）就是按这个假设设计的。但真实录音常常不满足它：会议室里两个人同时说话、车载麦克风录到后排乘客、客服录音里有背景人声。这时"这段音频是谁说的"这个问题本身就没有唯一答案。

这就是鸡尾酒会问题：人类可以在一个混合声场里追踪某一个人的声音，而机器不行。本节要把它变成一个可算的问题。

先明确它和相邻问题的边界：

任务 输入 输出 判据
语音增强 含噪语音 干净语音 噪声抑制量 + 语音失真度
语音分离 多说话人混合 N 条语音 SDR/SI-SDR + 说话人追踪一致性
语音提取 混合 + 目标线索（注册语音/空间方向） 目标语音 与增强相同，但目标由线索指定

三者的数学骨架是同一个：在某个表示上估一个掩码。差别在于"谁是干扰"是否已知——增强的干扰是噪声（与目标不同类），提取的干扰是"其他所有人"（与目标同类，但有线索），分离连"有几个人"都要自己定。

本节要回答四个问题，每一个都给出可算的判据：

  1. 掩码法的机制是什么，上限在哪里？ 在时域里逐点乘标量 kt​，最小二乘解是 kt∗​=at2​/(at2​+bt2​)；在时频域里乘幅度比 ∣S1​∣/(∣S1​∣+∣S2​∣)。同一个混合里后者比前者高 18.7777 dB——但这个差距不是"掩码更好"，而是时频域让两个源的支撑集几乎不重叠（4.6982→23.4759 dB）。
  2. 为什么上限不是 100%？ 因为幅度掩码不动相位。理想复数掩码（给真相位）在这个合成例子上达到 288.8850 dB（数值精度上限）；换成幅度比掩码 + 混合相位掉到 21.2153 dB（在该例子里混合相位几乎就是目标相位）；而给目标分量加一个 90∘ 的整体相位旋转，SDR 从 4.6982 掉到 −0.6688 dB。
  3. 置换不变训练（PIT）为什么必要，代价是什么？ 网络输出的 N 个槽位没有内在顺序，所以损失必须对 N! 个置换取下确界：N=2 是 2 条路径，N=7 是 5040 条；N=7、batch=128 时一次前向要算 645120 条。
  4. PIT 什么时候失效？ 逐帧 PIT 允许标签每帧重选，当帧内两个源的判决裕度 ∥dt​∥ 与噪声同量级时标签开始跳。本节实测：∥d∥ 的中位量级是 1.3822（D=20 维、单位化后），σ=0.3 时翻转率 0.0079、σ=0.6 时 0.1095、σ=1.0 时 0.2801；理论式 2Φ(−∥d∥/(σ2​)) 在 0.6 以上量级吻合。更根本的是：两个说话人在半段互换时，一个整段置换最多只能对一半，实测错选率 0.5467（σ=0.01）到 0.5600（σ=0.1）。

 分离的上限由「表示 + 相位」决定；分离的可训练性由「置换的等价类」决定 ​

⚠️ 本节代码中的混合、源信号与噪声全部是合成的，只用标准库。它们的作用是把"掩码/置换"的取舍变成可核对的算术，不是对任何真实系统成绩的断言。

一、鸡尾酒会问题的形式化#

1.1 混合模型#

最常用的模型是瞬时线性混合：

x(t)=n=1∑N​sn​(t)+ν(t)

ν 是噪声，sn​ 是第 n 个说话人。在时频域（第 1 章的 STFT）里，如果窗长远小于房间混响时间，卷积混合可以近似成每个频点的瞬时混合：

X(t,f)=n=1∑N​Sn​(t,f)+V(t,f)

这个近似是有条件的，条件就是第 1 章讲过的时频分辨率：窗长 W 决定了频点上的相位在 W 内是否稳定。混响时间 T60​ 越大，需要越短的窗；而越短的窗频率分辨率越差。"用 STFT 做分离"这个决定本身就已经在时频分辨率上做了一次取舍。

1.2 "几个人"是一个必须外部给定的量#

N 是混合里说话人的个数。绝大多数分离系统把 N 当作输入（固定 N=2 或 N=3），原因很直接：网络的输出维度就是 N。要处理未知 N，需要额外的机制（递归分离、说话人计数、或者把"还剩几个人"作为停止条件）。

这是分离与识别的另一个结构差别：识别系统的输出类数是固定的；分离系统的输出个数是待定的。本节只处理 N 已知的情形，并在 4.3 节说明这个限制的后果。

1.3 上界：为什么"完美分离"不存在#

即使给定完美的掩码估计器，掩码法也有一个构造性上界。原因是：

  • 幅度掩码不动相位。在 X(t,f)=S1​+S2​ 里，X 的相位是 S1​ 与 S2​ 的合成相位，不等于 S1​ 的相位。
  • 逐点掩码是一个标量（或复数）乘法，它无法把"两个不同方向的分量"分开——它只能缩放，不能旋转。
  • 因此掩码法的可达成集合是 {k⋅X}，而真实目标是 S1​。当 S1​ 与 S2​ 在某个时频点上方向接近时（相位差小），任何缩放都无法把 S1​ 从 S1​+S2​ 里提出来。

形式化地，若只允许实数标量掩码，则最小均方误差解是

k∗=argkmin​ E[(kX−S1​)2]=E[X2]E[XS1​]​=σ12​+σ22​+2E[S1​S2​]σ12​+E[S1​S2​]​

k∗=argkmin​ E[(kX−S1​)2]=E[X2]E[XS1​]​=σ12​+σ22​+2E[S1​S2​]σ12​+E[S1​S2​]​

当两个源逐点不相关（E[S1​S2​]=0）时，k∗=σ12​/(σ12​+σ22​)——这就是理想比率掩码（IRM）在能量形式下的样子。本节的合成例子严格满足这一点：实测 ∑t​mt​at​/∑t​mt2​=0.500000（等能量时的理论值就是 0.5）。

关键读法：k∗ 是"在不动相位的前提下能做到的最好"，而不是"理论上能做到的最好"。要突破它，必须估计相位（复数掩码），或者换一个表示（波形域的直接生成）。

二、掩码法：从 IBM 到复数掩码#

2.1 三种掩码#

设某一时频点上两个源的复幅度为 S1​,S2​，混合为 M=S1​+S2​。

2.3 时频域 vs 时域：18.8 dB 的差距来自哪里#

同一个混合，换成 STFT 域（矩窗 256、帧移 128、74 帧）：

理想复数掩码（真相位） 288.8850 296.7467

幅度比掩码 + 混合相位 21.2153 21.5515

而时域的逐点能量比是 4.6982 dB。差距 18.7777 dB。这个差距的机制必须说清：

  • 本节的两个源是 440 Hz 与 1233 Hz 的窄带信号，频谱几乎不重叠；
  • 于是在目标频点上 ∥S2​∥≪∥S1​∥，掩码 ≈1；在干扰频点上掩码 ≈0；
  • 掩码几乎不需要"取舍"，所以时频域能接近完美分离。

如果两个源在同一频带重叠（真实语音的常态），这个差距会大幅缩小——那时掩码在重叠的时频点上必须在两个源之间分配，误差就回到时域量级。"时频域更好"不是一个无条件的结论。

三、置换不变训练（PIT）#

3.1 问题：输出槽位没有顺序#

一个 N 输出的分离网络给出 s^1​,…,s^N​，但训练标签 s1​,…,sN​ 的顺序是人为的。损失不能写成 ∑n​L(s^n​,sn​)——因为网络完全可以把说话人 A 放到槽位 2，此时损失很大却没有犯错。

PIT 的做法：对全部 N! 个置换取下确界。

LPIT​=π∈SN​min​ n=1∑N​L(s^n​, sπ(n)​)

置换数的量级（本节实测打印）：

N N! batch=128 时一次前向的路径数
2 2 256
3 6 768
4 24 3072
5 120 15360
6 720 92160

N=2 时这个额外开销可以忽略；N=3 是 3 倍；N≥5 时朴素枚举已经不现实，实际实现要用匈牙利算法（把"最小代价匹配"从 O(N!) 降到 O(N3)），或者用"先分离后追踪"的两阶段方案。

3.2 uPIT 与帧级 PIT 的差别#

  • uPIT（utterance-level PIT）：整段语音只用一个置换。它的隐含假设是"说话人身份在整段里不变"。
  • 帧级 PIT：每一帧独立选择置换。它更灵活（允许说话人在段中互换），但会产生标签抖动。

什么时候帧级 PIT 的灵活性是必要的？ 当两个说话人真的在半段交换了位置（例如一段多人对话里，两个人在某个时刻开始交换话语权）。什么时候它是纯粹的噪声来源？ 当一帧里的两个源能量接近时——此时两个置换的代价差接近零，argmin 由数值噪声决定。

3.3 判决裕度：什么时候标签会跳#

在 D 维帧表示上，两个源的向量单位化后是 v1​,v2​，令 d=v1​−v2​。给每帧的估计加白噪声 n1​,n2​∼N(0,σ2I)，则两个置换的代价差是

Δ=2∥d∥2+2⟨d, n2​−n1​⟩

正确判决要求 Δ>0，即

r=σ2​∥d∥​>∣N(0,1)∣,P(翻)≈2Φ(−r)

∥d∥ 的分布很集中：本节实测（D=4,8,20,64，各 20000 次）E∥d∥ 从 1.3588 到 1.4113，趋近于 2​——这是高维单位球上两个独立点距离的集中现象，维度越高越集中。所以 ∥d∥ 不能靠"增大维数"来避免接近零，只能靠降低噪声。

3.4 两类 PIT 都解不了的问题#

问题一：说话人中途互换。 实测：把一段 60 帧的语音做成"前 30 帧 A-B、后 30 帧 B-A"，用一个整段置换去拟合，错选率是 0.5467（σ=0.01）、0.5600（σ=0.1）、0.5467（σ=0.6）。与噪声几乎无关——这是结构性的：一个置换无法表达"身份在段中改变"。

问题二：置换在可辨识性层面就是不可判的。 如果两个源的统计完全对称（交换它们得到同一个分布），那么

E[L(s^,s)]=E[L(s^,sswap​)]

两个置换的期望代价恒等。此时 PIT 的损失函数在置换下不变，梯度里没有区分两个槽位的信息。这不是优化问题，是信息问题：要区分它们，必须引入额外的、与身份相关的不对称信息：

  • 注册语音（说话人提取）：把目标说话人的嵌入作为条件输入；
  • 时序连续性（追踪）：假设身份在时间上是分段常数；
  • 空间线索（多麦克风）：用到达时差/方向把源分开。

  1. IBM 在低 SNR 时优势很小（g=0.25：IBM 12.5160 对全通 12.0412，只多 0.4748 dB）。因为干扰本来就弱，全通已经"够好"。
  2. IRM 对 IBM 的优势在中高 SNR 时更明显（g=2：2.3927 对 1.0433，差 1.3494 dB）。这符合直觉：干扰弱时，二值化把目标"全部留下"的代价大于收益。

判据：报告分离增益时必须给混合 SNR。同一个系统在 −12 dB 和 +12 dB 的混合上，"相对全通的增益"分别是 1.13 dB 和 13.21 dB——差一个数量级。

4.2 增强与分离的判据不同#

增强 分离
干扰的性质 噪声（与目标不同类） 其他说话人（与目标同类）
输出个数 1 N（已知或未知）
主要指标 噪声抑制量（dB）、PESQ/STOI 类主观指标 SDR/SI-SDR + 追踪一致性
失效模式 音乐噪声（谱减法残留）、语音失真 置换错误、源泄漏、身份混淆
多麦克风 波束形成（用空间信息） 空间线索 + 掩码

最重要的区别是"目标是否由外部线索给定"。增强的目标永远是"那个说话的人"，不需要身份；分离必须决定"哪条输出对应哪个源"，而这一步在 3.4 节被证明是无条件不可判的。所以分离系统在评估时必须先做一次置换对齐，否则指标没有意义——这正是 PIT 在训练里做的事，在评测里也必须做。

4.3 N 未知时的做法与代价#

实际系统常把 N 固定为 2 或 3。当真实说话人数超过 N 时，多余的说话人会被当成"干扰"留在输出里；当少于 N 时，网络会输出重复或静音。

两种常见补救：

  • 递归分离：先分出"一个说话人 + 剩余混合"，再对剩余混合重复。优点是 N 灵活；缺点是误差累积（每一步的残留误差进入下一步），而且每一步都要重新判决"还有没有人"。
  • 说话人计数：先估计 N，再跑固定 N 的分离。计数的错误会直接变成结构错误（多分或少分），比掩码误差更难恢复。

4.4 分离与增强的评测协议#

分离的读数比识别更容易被口径操纵，因为它多了一个"输出顺序"的自由度。一份可复现的协议至少固定五项：

# 必须声明 不声明会怎样
1 混合 SNR（或每个源的 SDR 上界） 见 4.1 节：同一系统的相对增益在 −12 dB 与 +12 dB 上差一个数量级
2 置换对齐准则：整段一个置换、逐帧一个置换、还是逐段 逐帧对齐会把 3.3 节的 10.9% 翻转率"洗掉"，读数虚高
3 是否允许分段对齐及分段数上限 分段数可以任意多，指标会单调上升（极端情形是逐样本对齐）
4 评测的语音段长度分布 3.4 节：整段置换对"中途互换"的错选率是 54.67%∼56.00%，与段长直接相关
5 指标是 SDR 还是 SI-SDR（以及是否额外报输出电平） 2.2 节：SI-SDR 对整体幅度不敏感，掩码乘 2.0 时它仍是 2.9005 dB

第 2 与第 3 项是最容易被 silently 放宽的。常见的做法是"用最优置换（oracle permutation）评估"，这本身没错（它排除了置换错误这一项），但必须同时报一个"不允许任何重排"的读数，否则读者无法知道系统在真实使用（用户听到的两路输出没有标签）下是什么表现。

判据：分离系统的"可用性"由两件事共同决定——分离质量（SDR/SI-SDR）与追踪一致性（同一路输出在多长时间内对应同一个人）。后者需要一个显式的指标，例如

追踪错误率=#{t}#{t: 第 t 帧选中的置换=该段的多数置换}​

3.3 节的翻转率（σ=0.6 时 0.1095、σ=1.0 时 0.2801）就是它的一个上界估计。

def fft(a):
    n = len(a)
    a = list(a)
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j |= bit
        if i < j:
            a[i], a[j] = a[j], a[i]
    length = 2
    while length <= n:
        wl = cmath.exp(-2j * math.pi / length)
        for i in range(0, n, length):
            w = 1 + 0j
            for k in range(i, i + length // 2):
                u = a[k]
                v = a[k + length // 2] * w
                a[k] = u + v
                a[k + length // 2] = u - v
                w *= wl
        length <<= 1
    return a


def ifft(a):
    n = len(a)
    y = fft([x.conjugate() for x in a])
    return [x.conjugate() / n for x in y]


def stft(x):
    frames = []
    pos = 0
    while pos + N_FRAME <= len(x):
        frames.append(fft(x[pos:pos + N_FRAME]))
        pos += HOP
    return frames


def istft(frames, length):
    out = [0.0] * (length + N_FRAME)
    wsum = [0.0] * (length + N_FRAME)
    pos = 0
    for fr in frames:
        seg = ifft(fr)
        for i in range(N_FRAME):
            out[pos + i] += seg[i].real
            wsum[pos + i] += 1.0
        pos += HOP
    return [out[i] / wsum[i] for i in range(length)]


def sdr(est, ref):
    num = sum(r * r for r in ref)
    den = sum((e - r) ** 2 for e, r in zip(est, ref))
    return 10.0 * math.log10(num / max(den, EPS))


def si_sdr(est, ref):
    den = sum(r * r for r in ref)
    alpha = sum(e * r for e, r in zip(est, ref)) / den if den > 0 else 0.0
    proj = [alpha * r for r in ref]
    noise = [e - p for e, p in zip(est, proj)]
    return 10.0 * math.log10(sum(p * p for p in proj) / max(sum(n * n for n in noise), EPS))

小结#

  • 掩码法是一个受约束的估计问题。约束是"只做逐点缩放、不动相位"，它给出一个硬上界：理想比率掩码在逐点正交假设下就是最优的实数掩码，k∗=σ12​/(σ12​+σ22​)。本节实测时域 IRM 比 IBM 高 1.8804 dB，而时频 IRM 在频谱不重叠的例子中比时域高 18.7777 dB——后者是表示的功劳，不是掩码的功劳。
  • 相位是上界的真正来源。10∘ 以内可以忽略（损失 0.0659 dB），45∘ 损失 1.5027 dB，90∘ 时 SDR 变成负的（−0.6688 dB）。突破这个上界需要复数掩码或波形域生成。
  • SI-SDR 与 SDR 不能互相替代。SI-SDR 对整体幅度不变（掩码乘 0.5 到 2.0，SI-SDR 恒为 2.9005），因此它无法发现输出增益错误。
  • PIT 解决的是"标签顺序"问题，不是"谁是谁"问题。它的计算代价是 N!；它的失效条件是帧内判决裕度 ∥d∥ 与噪声同量级（σ≳1 时逐帧翻转率超过 28%）；它对"说话人中途互换"结构性无效（错选率 54.67%∼56.00%，与噪声无关）。
  • 置换的可辨识性需要外部信息。当两个源的统计对称时，两个置换的期望代价恒等——这是信息论层面的不可判，不是优化问题。要打破它，必须引入注册语音、时序连续性或空间线索中的至少一个。
  • 报告规范：分离的读数必须带上混合 SNR、参考/输出条数、置换对齐准则、以及是否允许分段对齐。少任何一项，"我们的 SDR 更高"都不构成可比较的结论。
