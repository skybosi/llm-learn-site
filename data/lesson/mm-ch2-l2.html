反向去噪与 DDPM#

前向加噪把数据变成了纯噪声，这一课讲怎么逆转它：学习一个反向过程，从 x_T ~ N(0, I) 出发，一步步把噪声"洗"回清晰数据。核心难题是——真正的反向分布 q(x_{t-1}|x_t) 无从计算，但一旦额外给定起点 x_0，反向分布就变成一个可解析的高斯。DDPM 的全部智慧，就是让网络去预测这个高斯里唯一未知的量：噪声 ε。

一、概念讲解#

1. 反向过程：学一条"去噪"的马尔可夫链#

反向过程也是马尔可夫链，但每一步是可学习的，用参数为 θ 的高斯来近似：

p_θ(x_{t-1} | x_t) = N( x_{t-1} ;  μ_θ(x_t, t) ,  Σ_θ(x_t, t) )

如果前向每一步只加一点点噪声，那么反向每一步也只"去一点点噪声"，于是单步去噪可以近似成高斯——这一步假设是 DDPM 成立的物理基础（前向步长足够小，反向也接近高斯）。

2. 真正的难点：q(x_{t-1}|x_t) 算不出来#

一个自然的想法是：让网络直接学"给定 x_t，上一步 x_{t-1} 的分布"。但 q(x_{t-1}|x_t) 需要对整个数据集求平均（要"见过所有可能的 x_0"才知道某张噪声图本来长啥样），这在实践中不可计算。

3. 突破口：给定 x_0 后，反向分布可解析#

妙处在于，把 x_0 也作为条件后，q(x_{t-1} | x_t, x_0) 可以用贝叶斯 + 高斯共轭精确解出来。上一课已经给出两个关键分布：

q(x_t | x_{t-1})      = N(x_t ;  sqrt(α_t) x_{t-1} ,  (1 - α_t) I)
q(x_t | x_0)          = N(x_t ;  sqrt(ᾱ_t) x_0     ,  (1 - ᾱ_t) I)

套贝叶斯公式，得到这个"可解析的后验"：

q(x_{t-1} | x_t, x_0) = N( x_{t-1} ;  μ̃_t(x_t, x_0) ,  β̃_t · I )

μ̃_t(x_t, x_0) = ( sqrt(ᾱ_{t-1}) β_t / (1 - ᾱ_t) ) · x_0
               + ( sqrt(α_t) (1 - ᾱ_{t-1}) / (1 - ᾱ_t) ) · x_t

β̃_t = (1 - ᾱ_{t-1}) / (1 - ᾱ_t) · β_t

直观理解：如果我知道噪声图 x_t 和它原本的干净图 x_0，我就能精确算出"上一步应该是什么"。这个 μ̃_t 是高斯均值的解析式，β̃_t 是解析式方差。

4. 用噪声 ε 重写后验均值#

把 x_t = sqrt(ᾱ_t) x_0 + sqrt(1 - ᾱ_t) ε 反解出 x_0，代入 μ̃_t，可以把它改写成只依赖噪声 ε 的形式：

x_0 = ( x_t - sqrt(1 - ᾱ_t) · ε ) / sqrt(ᾱ_t)

μ̃_t(x_t, x_0) = (1 / sqrt(α_t)) · ( x_t - (β_t / sqrt(1 - ᾱ_t)) · ε )

这一步是 DDPM 的关键设计选择：与其让网络直接预测 x_0 或 μ̃_t，不如让它预测"x_t 里掺了多少噪声 ε"——因为预测噪声这个任务，在"接近纯噪声"和"接近干净图"的各个时间步上都难度均匀、目标规范，实验上训练最稳、效果最好。

5. DDPM 的采样算法：从噪声逐步"洗"回数据#

于是采样过程变成：从 x_T ~ N(0, I) 出发，逐步执行

x_{t-1} = (1 / sqrt(α_t)) · ( x_t - (β_t / sqrt(1 - ᾱ_t)) · ε_θ(x_t, t) )  +  sqrt(β̃_t) · z

其中 z ~ N(0, I)（最后一步 t=0 时 z=0），ε_θ(x_t, t) 是网络预测的噪声。这个循环就是 DDPM 论文里的 Algorithm 2：每一步"减去预测出的噪声，再重新注入一小点随机噪声"，逐步把噪声图还原成清晰图。

6. 网络长什么样：U-Net#

预测噪声的网络 ε_θ(x_t, t) 通常用 U-Net：编码器逐步下采样提取语义、解码器逐步上采样恢复细节，中间有跳跃连接保留高频信息。它还必须"知道自己在哪个时间步"，因为不同 t 的噪声强度完全不同——做法是时间步嵌入（把 t 编码成向量，加进每一层）。Stable Diffusion 把这个 U-Net 搬到潜空间并加了注意力，第 3 章展开。

二、可运行代码示例#

实现 DDPM 的反向采样循环（Algorithm 2 的骨架）。为了独立运行，这里用一个"随机初始化的"噪声预测网络做演示；真实训练在第 3 课完成。

import torch

T = 1000
beta = torch.linspace(1e-4, 0.02, T)
alpha = 1 - beta
alpha_bar = torch.cumprod(alpha, dim=0)          # ᾱ_t

# —— 可解析后验 q(x_{t-1}|x_t, x_0) 的参数 ——
def posterior_mean(x_t, x0, t):
    """μ̃_t(x_t, x_0)：已知 x_0 时，上一步的均值"""
    at, at1 = alpha_bar[t], alpha_bar[t - 1] if t > 0 else torch.tensor(1.0)
    coef0 = at1.sqrt() * beta[t] / (1 - at)              # x_0 的系数
    coefx = alpha[t].sqrt() * (1 - at1) / (1 - at)       # x_t 的系数
    return coef0 * x0 + coefx * x_t

def posterior_var(t):
    """β̃_t：后验方差（DDPM 用固定方差）"""
    at, at1 = alpha_bar[t], alpha_bar[t - 1] if t > 0 else torch.tensor(1.0)
    return (1 - at1) / (1 - at) * beta[t]

# —— 反向采样循环（DDPM Algorithm 2 骨架） ——
def sample(eps_net, shape, device="cpu"):
    x = torch.randn(*shape, device=device)            # x_T ~ N(0, I)
    for t in reversed(range(T)):                      # 从 T-1 一路降到 0
        # 最后一步不再注入随机噪声，其余步骤注入 sqrt(β̃_t)·z
        z = torch.randn(*shape, device=device) if t > 0 else torch.zeros(*shape, device=device)
        eps_pred = eps_net(x, t)                      # 网络预测 x_t 里的噪声
        # x_{t-1} = (1/√α_t)·( x_t - (β_t/√(1-ᾱ_t))·ε_θ ) + √β̃_t · z
        a = 1 / alpha[t].sqrt()
        b = beta[t] / (1 - alpha_bar[t]).sqrt()
        x = a * (x - b * eps_pred) + posterior_var(t).sqrt() * z
    return x

# —— 演示：一个把"任意输入都当成零噪声"的占位网络，仅为了跑通循环 ——
class DummyEpsNet:
    def __call__(self, x, t):
        return torch.zeros_like(x)                    # 预测噪声 = 0

x_gen = sample(DummyEpsNet(), shape=(1, 2, 2))
print("采样得到的 x_0:", x_gen.numpy().round(3))

再看"用 ε 重写后验均值"这条关键代换的代码落点：

# 已知：μ̃_t 可写成只依赖噪声 ε 的形式
# μ̃_t = (1/√α_t) · ( x_t - (β_t/√(1-ᾱ_t)) · ε )
# 因此网络只要预测 ε，就能还原 μ̃_t，进而采样 x_{t-1}。
# 这就是上面 sample() 里 a * (x - b * eps_pred) 的来历。

注意：上面的 DummyEpsNet 只是"骨架演示"，它预测的全是零噪声，所以采样结果没有意义。把 eps_net 换成第 3 课训练好的真实网络，这个循环就能真正生成样本。

三、练习#

  1. 手推 q(x_{t-1}|x_t, x_0) 的均值 μ̃_t：写出贝叶斯公式 q(x_{t-1}|x_t,x_0) ∝ q(x_t|x_{t-1}) q(x_{t-1}|x_0)，代入两个已知高斯，按"指数项凑平方"得到 μ̃_t 与 β̃_t 的解析式。
  2. 把 sample() 里的 posterior_var 换成固定值（如 beta[t]），观察采样结果如何变化，说说方差选择对样本多样性的影响。
  3. 解释为什么最后一步（t=0）不再注入随机噪声 z（提示：生成样本应当是确定性的清晰图）。
  4. 思考题：为什么让网络预测噪声 ε 而不是直接预测 x_0？从"不同时间步任务难度是否均匀"的角度论证。
  5. 给 sample() 加一个"提前停止"参数：当 t 降到某阈值时直接返回当前 x，观察"没去完噪"的样本长什么样，理解"步数不足"如何导致质量下降（为第 3 章采样加速埋下伏笔）。
