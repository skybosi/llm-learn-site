图像分类#

前两章我们一直在"看懂"结构，这一章开始"动手跑"。图像分类是 CNN 最经典的任务：输入一张图片，输出它属于哪个类别。本课先建立端到端的整体认识，然后做一件性价比极高的事——迁移学习：不从头训练一个百万参数的网络，而是拿预训练好的 ResNet 微调，几分钟就能得到不错的分类器。

一、概念讲解#

1. 图像分类要解决什么#

形式上，图像分类是学一个函数：把一张 H×W×C 的图片映射到 K 个类别的概率分布。模型输出 K 个分数（logits），经过 softmax 转成概率，取概率最大的类别作为预测结果。

训练时用的是交叉熵损失：让正确类别的概率尽量接近 1。评估时常用 准确率（预测对的样本占比），有时也看 top-5 准确率（前五个预测里是否包含正确答案）。

2. 一条完整的流水线#

原始图片 → 预处理（缩放/归一化）→ 模型前向 → logits → softmax → 类别
训练时再加一条：真实标签 → 交叉熵损失 → 反向传播 → 更新参数

其中"预处理"至关重要：训练时的模型是在特定均值/方差归一化、特定尺寸下训出来的，推理时必须用完全一致的变换，否则精度会莫名其妙地掉。

3. 为什么要迁移学习#

从零训练一个 ResNet-50 在 ImageNet 上要几十块 GPU 跑好几天，普通学习者根本扛不住。但迁移学习绕开了这个坑：ImageNet 上训好的模型已经学到了大量通用的底层特征（边缘、纹理、物体部件），这些特征对绝大多数视觉任务都有用。我们只需：

  1. 载入预训练权重；
  2. 把最后一层全连接换成适应自己类别数的分类头；
  3. 用小学习率微调（fine-tune）整个网络，或只训练新换的分类头（冻结骨干）。

迁移学习把"海量数据 + 海量算力"的需求，降级成"少量数据 + 一块普通显卡"，是实际项目中用得最多的技巧。

4. torchvision 里的现成模型#

torchvision.models 提供了一整套预训练骨干：resnet18、resnet50、vgg16、mobilenet_v2、efficientnet_b0 等，一行代码即可载入。PyTorch 较新版本统一用 weights= 参数指定预训练权重，如：

from torchvision import models
net = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)

每个权重对象还自带 transforms() 方法，能给出官方推荐的预处理变换，帮我们避免"归一化参数配错"的坑。

二、可运行代码示例#

下面用预训练的 ResNet-18 对一张图片做推理，并演示如何把它的最后一层换成 10 类分类头。

import torch
from torchvision import models, transforms
from PIL import Image

# 1) 载入预训练 ResNet-18（会自动下载权重，需联网）
net = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)
net.eval()

# 2) 官方推荐的预处理变换
preprocess = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),        # ResNet 输入要求 224x224
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),   # ImageNet 统计值
])

# 3) 读取一张图片并前向（示例图片可自行替换成本地路径）
img = Image.open("cat.jpg").convert("RGB")
x = preprocess(img).unsqueeze(0)       # 加 batch 维度 -> [1, 3, 224, 224]

with torch.no_grad():
    logits = net(x)                    # [1, 1000] 的类别分数
prob = torch.softmax(logits, dim=1)
top5 = prob.topk(5)                    # 取 top-5
print("Top-5 类别编号:", top5.indices[0].tolist())
print("Top-5 概率:", [round(p, 4) for p in top5.values[0].tolist()])

# 4) 迁移学习：把最后一层全连接换成 10 类分类头
num_classes = 10
in_features = net.fc.in_features      # ResNet 的 fc 输入维度（512）
net.fc = torch.nn.Linear(in_features, num_classes)
print("替换后的分类头:", net.fc)

运行后，网络会输出 1000 个类别分数，取 top-5 大致能看出图片内容；替换 fc 后，网络就能被微调成任意类别数的分类器——这就是迁移学习的最小改动版本。

三、练习#

  1. 打印 net.fc 替换前后的形状，说明为什么只需改这一层，前面的卷积部分不用动。
  2. 用 models.ResNet18_Weights.IMAGENET1K_V1.transforms() 打印官方预处理，与你手写的 preprocess 对比，找出差异。
  3. 把模型换成 models.mobilenet_v2(weights=models.MobileNet_V2_Weights.IMAGENET1K_V1)，找到它的分类头（提示：net.classifier），做同样的 10 类替换。
  4. 思考：如果自己的任务只有 100 张图，为什么"冻结骨干、只训分类头"往往比"微调整个网络"更不容易过拟合？
