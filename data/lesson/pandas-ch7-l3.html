报告输出#

探索做完，规律也找到了，最后一步是把分析变成一份能给别人看的成果。这一步包含两件事：把零散结论汇总成关键指标，再把结果导出成 CSV / Excel 或一段清晰的文字报告。分析的最终价值，就在于能否用一句话把结论讲清楚。

一、概念讲解#

1. 从"发现"到"结论"#

探索阶段会产出很多中间结果，报告阶段要做的是收敛：选出最能回答业务问题的几个指标，例如：

  • 总销售额、总订单数、客单价（= 总销售额 ÷ 总订单数）；
  • 销售额最高的地区和品类；
  • 新客与老客的平均消费对比。

这些指标计算量都不大，但组合起来就能回答"生意整体怎么样、增长点在哪"。

2. 用字典汇总核心指标#

把关键指标算出来装进一个字典，是整理报告的好习惯：

metrics = {
    "总销售额": df["amount"].sum(),
    "订单数": len(df),
    "客单价": df["amount"].mean(),
}

之后无论是打印、写文件还是塞进表格，都用这一份数据，保证口径一致。

3. 导出数据：to_csv 与 to_excel#

  • df.to_csv("结果.csv", index=False)：导出 CSV，index=False 表示不把行索引写进去；
  • df.to_excel("结果.xlsx", index=False)：导出 Excel，需要额外安装 openpyxl 库。

汇总表（比如"各地区销售额"）本身也是 DataFrame，可以直接导出，方便贴进文档或交给同事。

4. 文字报告：用 f-string 拼结论#

数字本身不会说话。用 Python 的 f-string 把关键数字"嵌"进句子，就能自动生成一段可读的摘要：

print(f"本期总销售额为 {total:.2f} 元，客单价为 {avg:.2f} 元。")

5. 报告的结构建议#

一份清晰的数据报告通常按"结论先行 → 数据支撑 → 建议"来组织：先抛核心结论，再用关键指标和表格支撑，最后给出可行动的建议。图片、表格、文字各司其职。

二、可运行代码示例#

沿用前两课的数据（重新生成同一份）：

import pandas as pd
import numpy as np

np.random.seed(42)
n = 400
regions = ["华东", "华北", "华南", "西南"]
categories = ["数码", "家居", "服饰", "美妆"]
cat_prod = {"数码": ["手机", "耳机", "键盘"], "家居": ["台灯", "收纳盒", "毛巾"],
            "服饰": ["T恤", "牛仔裤", "卫衣"], "美妆": ["口红", "面膜", "香水"]}
cat = np.random.choice(categories, n)
df = pd.DataFrame({
    "order_id": [f"ORD{i:04d}" for i in range(n)],
    "date": pd.to_datetime("2024-01-01") + pd.to_timedelta(np.random.randint(0, 180, n), unit="D"),
    "region": np.random.choice(regions, n),
    "category": cat,
    "product": [np.random.choice(cat_prod[c]) for c in cat],
    "customer_type": np.random.choice(["新客", "老客"], n, p=[0.4, 0.6]),
    "payment": np.random.choice(["微信支付", "支付宝", "银行卡"], n),
    "quantity": np.random.randint(1, 5, n),
    "price": np.round(np.random.uniform(20, 800, n), 2),
})
df["amount"] = (df["price"] * df["quantity"]).round(2)

示例 1：计算核心指标#

metrics = {
    "总销售额": round(df["amount"].sum(), 2),
    "订单数": len(df),
    "客单价": round(df["amount"].mean(), 2),
    "月均销售额": round(df.groupby(df["date"].dt.to_period("M"))["amount"].sum().mean(), 2),
}
for k, v in metrics.items():
    print(f"{k}：{v}")

示例 2：生成汇总表并导出#

# 生成"各地区 × 各品类"的销售额汇总表
summary = pd.pivot_table(df, index="region", columns="category",
                         values="amount", aggfunc="sum", margins=True, fill_value=0)
summary = summary.round(2)
print(summary)

# 导出 CSV（index=False 不写行索引）
summary.to_csv("销售额汇总.csv", index=False, encoding="utf-8-sig")
print("已导出 销售额汇总.csv")

示例 3：生成文字报告#

# 沿用示例 1 计算好的 metrics
top_region = df.groupby("region")["amount"].sum().idxmax()
top_category = df.groupby("category")["amount"].sum().idxmax()
new_customer_avg = df[df["customer_type"] == "新客"]["amount"].mean()
old_customer_avg = df[df["customer_type"] == "老客"]["amount"].mean()

report = f"""
【线上零售店铺 2024 年上半年销售报告】

一、总体表现
本期总销售额为 {metrics['总销售额']} 元，共 {metrics['订单数']} 笔订单，客单价 {metrics['客单价']} 元。

二、结构亮点
销售额最高的地区是「{top_region}」，销售额最高的品类是「{top_category}」。

三、客户洞察
老客平均消费 {old_customer_avg:.2f} 元，新客平均消费 {new_customer_avg:.2f} 元，
{'老客消费力更强，建议加强复购运营。' if old_customer_avg > new_customer_avg else '新客表现亮眼，建议加大拉新投入。'}

四、建议
- 聚焦 {top_region} 与 {top_category} 的优势组合，加大投入；
- 针对消费较低的一方客户群体，设计针对性促活策略。
"""
print(report)

三、练习#

  1. 用上面的代码生成 metrics，并在此基础上补充"销售额最高的商品"这一指标（提示：按 product 分组求和后取最大）。
  2. 把"各地区销售额"和"各品类销售额"两张汇总表分别导出为 CSV，再打开文件确认内容与 index=False 的效果。
  3. 模仿示例 3 的写法，用 f-string 生成一段"月度趋势"的结论：找出销售额最高的月份和最低的月份，写一句包含这两个月份的摘要。
