TCN 时序卷积#

上一课我们用 LSTM 捕捉长程依赖。LSTM 有一个工程上的硬伤：它是逐时间步串行计算的——要算 t=100 的状态，必须先算完 t=1 到 99。这让训练没法充分利用 GPU 的并行性，序列一长就慢得难受。时序卷积网络（Temporal Convolutional Network，TCN）给出另一条路：用卷积同时处理整条序列，靠"因果卷积 + 空洞卷积"来既保持时序的因果性、又获得指数级增长的感受野。这一课我们把 TCN 的每一个设计动机讲透。

一、概念讲解#

1. 把卷积搬进时间序列：先解决"因果"#

图像上的卷积是在空间上滑窗；时间序列上卷积则在时间上滑窗。但时间序列有一个图像没有的硬约束：预测 t 时刻时，不能用 t 之后的信息，否则就是"偷看答案"。违背这一点的卷积叫"非因果卷积"，它会让模型靠未来的值"作弊"，训练时表现好、部署时完全失效。

解决办法是因果卷积（causal convolution）：卷积核只向右看，输出 y_t 只依赖 x_t, x_{t-1}, ...。实现上最简单的方式是在序列左端做单向 padding——把零补在左边，卷积核滑到任何位置都只看过去、不看未来。

2. 感受野太小：用"空洞"指数级扩张#

单靠因果卷积，感受野（输出能看到多远的过去）等于 核大小 k。要看到 100 步之前，就得叠 100 层，不现实。

空洞卷积（dilated convolution）的妙处是：在卷积核的元素之间插入"洞"（gap），让相隔 d 个时间步的元素参与一次卷积，而参数量不增加。d 叫膨胀率（dilation rate）。一个核大小 3、膨胀率 d 的卷积层，感受野大约翻倍。让每一层的膨胀率按 1, 2, 4, 8, ... 指数递增，那么 L 层之后的感受野是：

感受野 = (k - 1) × (2^L - 1) + 1

取 k=3, L=6，感受野约 2 × 63 + 1 = 127。只用 6 层、每层 3 个参数，就能看到 127 步之前——层数对数增长，感受野指数增长。这就是 TCN 能高效覆盖长程依赖的关键。

3. 残差连接：让深层网络训得动#

TCN 往往要叠很多层才能获得大感受野，深层网络会梯度消失。TCN 在每个块里引入残差连接：输出 = 输入 + 卷积变换(输入)。这样梯度有一条恒等映射的捷径，和 LSTM 细胞状态的"加法传送带"异曲同工——我们在上一课的"母原理"里已经点明。残差让 TCN 可以稳定地叠到十几层。

4. TCN vs RNN：并行性的胜利#

把 TCN 和 LSTM 放在一起看：

维度 LSTM TCN
训练并行度 串行，慢 全序列并行，快
长程依赖 靠门控 靠空洞卷积扩大感受野
内存 每步都要存中间状态 卷积更省
因果性 天然满足 靠单向 padding 保证
感受野可控性 隐式 显式可算

TCN 最大的红利是训练并行：整条序列一次性前向，不用等上一步。2018 年 Bai 等人的实证研究发现，在大量序列任务上，一个设计得当的 TCN 能打平甚至超过 LSTM/GRU。所以 TCN 常被当作"RNN 的卷积替代品"。

二、可运行代码示例#

下面实现一个最小 TCN，做和上一课相同的单步预测。核心是逐层加大膨胀率的因果卷积 + 残差连接。为了清楚，我们不调库，手写膨胀率递增的堆叠。

import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt

torch.manual_seed(0)
np.random.seed(0)

# 1) 同样生成一条"趋势 + 周期 + 噪声"序列
t = np.arange(0, 600)
series = 0.02 * t + 5 * np.sin(t / 12.0) + np.random.randn(600) * 0.3

# 2) 构造窗口样本（与上一课一致）
def make_dataset(series, L):
    X, y = [], []
    for i in range(len(series) - L):
        X.append(series[i:i + L])
        y.append(series[i + L])
    return torch.tensor(X, dtype=torch.float32), torch.tensor(y, dtype=torch.float32)

L = 128                                  # TCN 用更长的窗口，感受野大
X, y = make_dataset(series, L)
X = X.unsqueeze(1)                       # (样本, 通道=1, 时间=L)，适配 Conv1d
y = y.unsqueeze(-1)
print("X 形状:", X.shape)

# 3) 因果卷积：只在左侧 padding，保证"不偷看未来"
class CausalConv1d(nn.Module):
    def __init__(self, in_ch, out_ch, kernel_size, dilation):
        super().__init__()
        # 左侧 padding = (kernel_size - 1) * dilation，右侧不补
        self.pad = (kernel_size - 1) * dilation
        self.conv = nn.Conv1d(in_ch, out_ch, kernel_size,
                              dilation=dilation, padding=self.pad)

    def forward(self, x):
        x = self.conv(x)
        # 裁掉右侧因 padding 多出来的部分，保证输出长度与输入一致
        return x[:, :, :x.size(2) - 0] if self.pad == 0 else x

# 4) TCN 残差块：因果空洞卷积 + 激活，再与输入相加
class TCNBlock(nn.Module):
    def __init__(self, ch, kernel_size, dilation):
        super().__init__()
        self.conv1 = CausalConv1d(ch, ch, kernel_size, dilation)
        self.conv2 = CausalConv1d(ch, ch, kernel_size, dilation)
        self.relu = nn.ReLU()

    def forward(self, x):
        residual = x                       # 恒等捷径
        out = self.relu(self.conv1(x))
        out = self.conv2(out)
        return self.relu(out + residual)   # 残差连接

class TCN(nn.Module):
    def __init__(self, input_ch=1, hidden_ch=16, kernel_size=3, layers=5):
        super().__init__()
        # 每层膨胀率 1, 2, 4, 8, 16 ... 指数递增
        self.blocks = nn.ModuleList([
            TCNBlock(hidden_ch, kernel_size, 2 ** i) for i in range(layers)
        ])
        self.input_proj = nn.Conv1d(input_ch, hidden_ch, 1)
        self.fc = nn.Linear(hidden_ch, 1)

    def forward(self, x):
        x = self.input_proj(x)
        for block in self.blocks:
            x = block(x)
        # 取最后一个时间步的特征，预测下一个值
        return self.fc(x[:, :, -1])

model = TCN()
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

model.train()
for epoch in range(300):
    optimizer.zero_grad()
    pred = model(X)
    loss = criterion(pred, y)
    loss.backward()
    optimizer.step()
    if (epoch + 1) % 50 == 0:
        print(f"epoch {epoch+1:3d}  loss={loss.item():.4f}")

# 5) 自回归外推 60 步
model.eval()
with torch.no_grad():
    window = torch.tensor(series[-L:], dtype=torch.float32).reshape(1, 1, L)
    preds = []
    for _ in range(60):
        nxt = model(window)
        preds.append(nxt.item())
        window = torch.cat([window[:, :, 1:], nxt.reshape(1, 1, 1)], dim=2)

plt.figure(figsize=(9, 3.5))
plt.plot(range(-60, 0), series[-60:], label="真实值")
plt.plot(range(0, 60), preds, label="预测值", linestyle="--")
plt.legend(); plt.title("TCN 自回归外推 60 步")
plt.show()

注意几处容易踩坑的细节：

  • CausalConv1d 把 (kernel_size-1) * dilation 的零全补在左侧，卷积核滑到任何位置都只覆盖过去，因果性由此保证；
  • 残差连接要求 out 和 residual 形状一致，所以每个块的输入输出通道都固定为 hidden_ch；
  • 最末只取 x[:, :, -1] 一个时间步的特征做预测——它已经通过空洞卷积"看到"了整段窗口，等价于 LSTM 里取最后一步隐藏状态。

三、练习#

  1. 把 layers 从 5 改成 3 和 7，用公式 (k-1)×(2^L -1)+1 手算各自感受野，再与训练效果对照。感受野小于窗口长度时会发生什么？
  2. 把 CausalConv1d 的左侧 padding 改成双侧对称 padding（标准卷积），重跑训练。训练 loss 会明显偏低，但外推质量反而变差——解释为什么"训练偷看未来"会在部署时反噬。
  3. 把残差连接去掉（return self.relu(out) 而非 out + residual），观察深层下是否训不动。这印证了哪一条母原理？
  4. 思考：TCN 靠"最后一步的特征"预测，如果窗口长度远大于感受野，窗口开头的信息还能被用上吗？这时该调大什么参数？
