正态分布#

如果说要在所有概率分布里选一个"最重要"的，绝大多数人会投票给正态分布（Normal distribution），也叫高斯分布。它不但是现实世界里身高、测量误差、考试成绩等数据的常见模型，更是机器学习里"高斯噪声假设""参数初始化""数据标准化"的理论根基。这一课我们把它彻底讲清楚。

一、概念讲解#

1. 钟形曲线与两个参数#

正态分布的概率密度函数（PDF）长这样：

f(x) = (1 / (σ·√(2π))) · exp( −(x − μ)² / (2σ²) )

它由两个参数完全决定：

  • μ（均值）：曲线的中心位置，也是分布的期望；
  • σ（标准差）：曲线的"胖瘦"，决定数据围绕中心分散的程度；σ 越大曲线越扁平、越分散。

2. 标准正态分布与 z 分数#

当 μ = 0、σ = 1 时，称为标准正态分布 N(0, 1)。任何正态分布都可以通过"标准化"变成标准正态：

z = (x − μ) / σ

这个 z 值表示"x 距离均值有多少个标准差"，也叫 z 分数。标准化是机器学习里数据预处理（标准化 / z-score 归一化）的数学来源，它把不同量纲的特征拉到同一尺度，让梯度下降更稳定。

3. 68–95–99.7 经验法则#

对任意正态分布，有非常实用的经验结论：

  • 约 68% 的数据落在 μ ± 1σ 内；
  • 约 95% 的数据落在 μ ± 2σ 内；
  • 约 99.7% 的数据落在 μ ± 3σ 内。

记住这三个数字，你在看数据、判断"异常值"时能快速心算。比如某特征服从正态分布，那么偏离均值超过 3σ 的点就很可疑了。

4. 为什么正态分布无处不在：中心极限定理的直觉#

大量相互独立的微小随机因素叠加起来，其总和往往近似服从正态分布——这是中心极限定理的核心思想（第 6 章会专门展开）。身高由遗传、营养、环境等众多因素叠加，测量误差由无数微小扰动叠加，所以它们都接近正态。这也是正态分布被广泛用作"默认假设"的原因。

5. 在机器学习中的位置#

  • 噪声假设：线性回归里的误差项常假设为均值 0 的正态噪声，这使得"最小二乘"与"最大似然"等价；
  • 参数初始化：神经网络的权重常用小方差的高斯分布初始化；
  • 生成模型与不确定性：变分自编码器（VAE）、扩散模型等都大量使用高斯分布来建模潜在变量与噪声。

二、可运行示例#

下面的代码演示三件事：生成正态样本、用样本均值和样本方差去"拟合"（即估计）正态分布的参数，以及验证 68–95–99.7 法则。

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

np.random.seed(7)

# ---- 1. 从真实的正态分布抽样：真值 mu=170, sigma=6（模拟身高，单位 cm）----
mu_true, sigma_true = 170.0, 6.0
n_samples = 5000
data = np.random.normal(loc=mu_true, scale=sigma_true, size=n_samples)

# ---- 2. 用样本估计参数（这正是下一章要学的"最大似然估计"）----
mu_hat = data.mean()          # 样本均值 估计 μ
sigma_hat = data.std()        # 样本标准差 估计 σ（严格无偏估计分母用 n-1，见第 6 章）
print(f"真实参数：mu={mu_true}, sigma={sigma_true}")
print(f"估计参数：mu={mu_hat:.3f}, sigma={sigma_hat:.3f}")

# ---- 3. 把样本标准化，验证它接近标准正态 N(0,1) ----
z = (data - mu_hat) / sigma_hat
print("标准化后均值：", round(z.mean(), 4), "（应接近 0）")
print("标准化后标准差：", round(z.std(), 4), "（应接近 1）")

# ---- 4. 验证 68-95-99.7 法则 ----
for k in [1, 2, 3]:
    frac = np.mean(np.abs(z) <= k)  # 落在 ±kσ 内的比例
    print(f"落在 μ±{k}σ 内的比例：{frac:.3f}")

# ---- 5. 直方图 + 理论概率密度曲线 ----
x = np.linspace(mu_true - 4 * sigma_true, mu_true + 4 * sigma_true, 400)
pdf = norm.pdf(x, loc=mu_hat, scale=sigma_hat)
plt.hist(data, bins=60, density=True, alpha=0.6, label="样本直方图")
plt.plot(x, pdf, "r-", lw=2, label="拟合的正态 PDF")
plt.xlabel("身高 (cm)")
plt.ylabel("概率密度")
plt.title("样本直方图与拟合出的正态分布")
plt.legend()
plt.show()

预期输出（部分）：

真实参数：mu=170.0, sigma=6.0
估计参数：mu=169.867, sigma=5.969
标准化后均值： 0.0 （应接近 0）
标准化后标准差： 1.0 （应接近 1）
落在 μ±1σ 内的比例：0.684
落在 μ±2σ 内的比例：0.954
落在 μ±3σ 内的比例：0.997

要点：5000 个样本已经能非常准确地"还原"出 μ 和 σ；标准化后数据确实接近 N(0,1)；68–95–99.7 法则与实测比例几乎完全吻合。

三、练习#

  1. 手算 z 分数：某次考试成绩服从 N(70, 10²)。考了 85 分，z 分数是多少？大概落在百分之几的位置？
  2. 改参数观察：把代码里 sigma_true 改成 2 和 15 各跑一次，观察直方图形状如何变化，以及估计值是否仍然准确。
  3. 思考：为什么线性回归常假设误差服从均值 0 的正态分布？提示：如果误差有系统性偏置（均值不为 0），模型预测会怎样？
  4. 联系机器学习：给特征做 z-score 标准化后，特征的均值与标准差分别变成多少？这对梯度下降为什么有帮助？
