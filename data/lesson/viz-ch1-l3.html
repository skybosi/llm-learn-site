中文与样式#

图表最终要给别人看，中文能否正常显示、整体是否美观，直接决定一张图是否合格。这一课解决两个实际问题：中文乱码，以及如何快速统一图的样式。

一、概念讲解#

1. 中文显示问题#

Matplotlib 的默认字体不包含中文字形，因此直接在标题或标签里写中文，往往显示成一个个方块（俗称"豆腐块"）。解决办法是显式指定一个支持中文的字体：

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False
  • 第一行把无衬线字体列表替换为中文可用的字体：Windows 常用 SimHei（黑体）或 Microsoft YaHei（微软雅黑），macOS 常用 PingFang SC。列表按顺序尝试，第一个可用的会被采用。
  • 第二行 axes.unicode_minus = False 解决另一个常见问题：坐标轴上的负号 - 在部分字体下显示为方块。关闭后用 ASCII 连字符代替 Unicode 减号。

这两行要放在任何绘图语句之前。若某个字体在你的系统上不存在，Matplotlib 会继续尝试列表中的下一个；如果全部缺失，仍会退回默认字体并出现方块。

2. 用 rcParams 统一默认样式#

plt.rcParams 是一个全局配置字典，控制几乎所有默认外观，例如默认颜色、线宽、字号、网格等。除了中文字体，也可以在这里统一设置：

plt.rcParams["figure.figsize"] = (8, 5)     # 默认画布尺寸
plt.rcParams["font.size"] = 12              # 默认字号
plt.rcParams["axes.grid"] = True            # 默认显示网格

3. 内置样式表（style sheets）#

逐项改 rcParams 太琐碎，Matplotlib 内置了一批现成样式表，一行就能切换整体风格：

plt.style.use("seaborn-v0_8-whitegrid")

常用样式示例："ggplot"、"fivethirtyeight"、"seaborn-v0_8"、"seaborn-v0_8-whitegrid"、"bmh"、"dark_background"。可用 plt.style.available 查看全部可用样式。注意：样式表会影响字体等设置，因此建议先设置中文字体，再应用样式表，或应用样式后再用 rcParams 覆盖字体。

二、可运行代码示例#

import numpy as np
import matplotlib.pyplot as plt

# 1. 中文字体与负号配置（放在绘图前）
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "PingFang SC"]
plt.rcParams["axes.unicode_minus"] = False

# 2. 应用内置样式表，统一整体风格
plt.style.use("seaborn-v0_8-whitegrid")

x = np.linspace(-2, 2, 100)
y = x ** 3 - x  # 同时包含正负值，验证负号显示

fig, ax = plt.subplots(figsize=(8, 4.5))
ax.plot(x, y, color="crimson", linewidth=2.5, label="y = x³ - x")
ax.set_title("样式与中文字体示例")
ax.set_xlabel("x（含负值，验证负号显示）")
ax.set_ylabel("y")
ax.legend()
plt.show()

运行后你应该能看到：标题与标签的中文正常显示、负号不再变成方块、整体呈现所选样式表的网格风格。可把 plt.style.use(...) 换成其他样式名对比效果。

三、练习#

  1. 在只设置中文字体、不设置 axes.unicode_minus 的情况下绘制 y = -x（x 取 -5 到 5），观察负号是否异常，再补上该设置对比。
  2. 分别用 "ggplot"、"fivethirtyeight"、"dark_background" 三种样式绘制同一组数据，比较视觉差异。
  3. 通过 plt.style.available 查看你环境里可用的样式，并任选一个未在课程中出现的样式绘制一张带中文标题的折线图。
