凸函数与凸集#

在 chapter-4 我们得到了偏差-方差分解，知道"过拟合"是模型在训练集外犯错。接下来的问题就非常现实了：我们手中的优化算法（梯度下降）到底可不可信？ 它会不会把你带到一个"看起来不错、其实很糟"的地方？回答这个问题，需要一套精确的语言来描述"损失曲面长什么样"，这套语言就是凸优化。本章从最基础的概念——凸集、凸函数——讲起，一切推导都围绕一个母题：我们什么时候能放心地相信"局部最优 = 全局最优"。

一、概念讲解（含推导）#

1. 先问"为什么"：优化算法在怕什么#

梯度下降只告诉你"往哪里迈一步能下降"，它从来不告诉你"最终停下的地方是不是最好"。想象你蒙眼走在一张坑坑洼洼的地面上：你只能感觉到脚下是上坡还是下坡，于是你一直往下走，最后停在一个小坑里——但旁边不远就有一个更深的坑。这就是非凸曲面的麻烦：局部最低点很多，你停下的那个未必是全局最低。

反过来，如果地面是一个"碗"（任何两个点之间，碗面都在连接这两点的线段下方），那么只要一直往下走，就必然会走到碗底——因为根本不存在第二个坑。这个"碗"的性质，就是凸性。凸优化理论的全部价值，就是严格地刻画"什么时候损失曲面是一口碗，从而局部最优就是全局最优"。

2. 凸集：线段永远不出圈#

设集合 C⊆Rn。如果对任意 x,y∈C 和任意 θ∈[0,1]，都有

θx+(1−θ)y∈C,

就称 C 是凸集。换句话说：集合里任意两点连成的线段，整条都还落在集合内。

直观例子：

  • 圆盘、球、整个空间 Rn、超平面 {x:aTx=b}、半空间 {x:aTx≤b} 都是凸集。
  • 圆环（甜甜圈）、五角星的轮廓不是凸集——你总能找到两个点，连线穿过了"洞"或"凹口"。

一个关键事实是：凸集的交集仍是凸集。这解释了为什么"一组线性约束 aiT​x≤bi​"定义出来的可行域（一个多面体）是凸的——它是若干个半空间的交。后面 SVM 的约束优化、线性规划的可行域都建立在这个事实上。

3. 凸函数：函数图像是一口"碗"#

设 f 定义在凸集上。若对任意 x,y 和 θ∈[0,1]：

f(θx+(1−θ)y)≤θf(x)+(1−θ)f(y),

则称 f 是凸函数。这个不等式说的是：弦在函数图像的上方——你在图像上任取两点连一条直线，这条直线总是位于函数图像之上（或重合）。当不等式严格成立（且 θ∈(0,1),x=y）时，称严格凸；若 −f 是凸的，称 f 是凹函数。

这个定义和微积分里的两种刻画完全等价，后者更便于实际判断：

一阶条件（切线在下）：若 f 可微，则 f 凸 ⟺ 对所有 x,y：

f(y)≥f(x)+∇f(x)T(y−x).

左边是函数值，右边是"在 x 处沿切线做的一阶线性近似"。它说：凸函数永远位于自己任意一点的切超平面之上。这个式子日后会反复出现——它就是梯度下降收敛性证明里"下降引理"和"强凸性"的雏形。

二阶条件（曲率非负）：若 f 二阶可微，则 f 凸 ⟺ 其 Hessian 处处半正定：

∇2f(x)⪰0(对所有 x).

一维情形就是 f′′(x)≥0：二阶导数衡量曲率，曲率恒非负意味着图像一直向上弯，正是"碗"的形状。

快速判断（一维）：

函数 二阶导数 是否凸
x2 2 严格凸
eax a2eax 凸（a 任意）
−lnx 1/x2 凸（定义域 x>0）
xlnx 1/x 凸（定义域 x>0）
∥x∥ 在 0 处不可导 凸（但非光滑）
sinx −sinx 非凸（符号会变）

-log x 与 x log x 这两个凸函数在机器学习里极重要：前者是最大似然的"负对数似然"的骨架，后者是熵的骨架——这是 chapter-6 的伏笔。

4. 琴生不等式：凸性的一种"期望"读法#

凸函数定义可以用归纳法推广到任意多个点，再取极限就得到概率意义下的版本。设 f 凸、X 是随机变量，则：

f(E[X])≤E[f(X)]​

这就是琴生（Jensen）不等式。它几乎是全机器学习里最"忙碌"的一条不等式：熵的非负性、KL 散度的非负性、EM 算法的下界、变分推断的 ELBO……全都从它而来。你现在先记住它的几何含义："函数作用在平均上" ≤ "函数值的平均"，这正是"弦在图像上方"的期望版本。

5. 回到机器学习：最小二乘为什么"天生凸"#

线性回归的目标函数是均方误差（为方便去掉常数因子）：

f(w)=21​∥Xw−y∥22​.

对 w 求梯度得 ∇f(w)=XT(Xw−y)，再求 Hessian：

∇2f(w)=XTX.

对任意向量 v，vT(XTX)v=∥Xv∥2≥0，所以 XTX 半正定，f 是凸函数。这就是为什么线性回归有唯一的解析解（当 XTX 可逆时 w∗=(XTX)−1XTy），且梯度下降一定收敛到它。你不需要"碰运气"，因为损失曲面就是一口碗。

二、验证性代码示例#

下面的代码不是教你调库，而是用数值实验"验证上面每条定义"：① 验证凸函数满足定义式；② 验证琴生不等式；③ 用 Hessian 特征值验证"最小二乘凸、正弦非凸"。

import numpy as np

# ---------- 1) 验证凸函数定义式：弦在图像上方 ----------
def f_convex(x):
    return x * x          # f'' = 2 > 0，严格凸

def chord_above(theta, x, y, f):
    """左端 = f(theta*x+(1-theta)*y)，右端 = theta*f(x)+(1-theta)*f(y)"""
    lhs = f(theta * x + (1 - theta) * y)
    rhs = theta * f(x) + (1 - theta) * f(y)
    return lhs <= rhs + 1e-12

ok = all(chord_above(np.random.rand(), np.random.randn(),
                     np.random.randn(), f_convex)
         for _ in range(10000))
print("凸定义式（弦在上）对 x^2 全部成立:", ok)

# ---------- 2) 验证琴生不等式：f(E[X]) <= E[f(X)] ----------
rng = np.random.default_rng(0)
X = rng.normal(size=100_000)          # 大样本逼近期望
lhs = f_convex(X.mean())
rhs = np.mean(f_convex(X))
print(f"Jensen: f(E[X]) = {lhs:.4f}  <=  E[f(X)] = {rhs:.4f}  -> {lhs <= rhs}")

# ---------- 3) 用 Hessian 特征值判断凸性 ----------
def is_convex_2d(H):
    return np.all(np.linalg.eigvalsh(H) >= -1e-9)

# 最小二乘 f(w) = 0.5*||Xw-y||^2 的 Hessian = X^T X
Xmat = np.random.randn(50, 3)
print("最小二乘 Hessian=X^T X 半正定 -> 凸:",
      is_convex_2d(Xmat.T @ Xmat))

# 一维 sin x：二阶导数 = -sin x，在 (0, pi) 内为负 -> 非凸
x_vals = np.linspace(0.2, 3.0, 5)
print("sin x 在 (0,pi) 的二阶导数:",
      np.round(-np.sin(x_vals), 3), "（有负值 -> 非凸）")

运行结果大致为：

凸定义式（弦在上）对 x^2 全部成立: True
Jensen: f(E[X]) = 0.0000  <=  E[f(X)] = 1.0003  -> True
最小二乘 Hessian=X^T X 半正定 -> 凸: True
sin x 在 (0,pi) 的二阶导数: [-0.199 -0.783 -1.    -0.746 -0.141] （有负值 -> 非凸）

注意第二个输出：X 均值为 0，f(EX)=02=0，而 E[X2] 约等于方差 1——琴生不等式把"平均的平方 ≤ 平方的平均"这一常识变成了可计算的事实。

母原理连接#

本课属于母原理 1（一切学习 = 优化一个目标函数） 与母原理 5（几何与线性代数视角） 的交汇处：凸性回答的是"优化问题是否良态、梯度下降是否可信"这一母题的几何前提。你从 Hessian 半正定出发判断凸性，本质是在用线性代数（矩阵谱）给优化问题"画像"。记住这条主线：损失函数的凸性 = 优化问题有唯一可靠解的地图，后续梯度下降的收敛证明、SVM 的对偶推导全都站在这个几何底座上。
